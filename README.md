## 프로젝트 개요

`SeSac AIOps Lab`은 단순한 코드 저장소를 넘어, AI/ML 분야의 깊이 있는 학습과 실전 경험을 체계적으로 쌓아가는 과정을 담은 살아있는 포트폴리오입니다. 파이썬 기초부터 딥러닝 심화 이론, 알고리즘, 데이터베이스, 그리고 웹 프레임워크를 활용한 모델 서빙까지, AIOps 엔지니어로 성장하기 위한 모든 기술적 탐험을 기록합니다.

이 레포지토리는 다음과 같은 목표를 추구합니다:
- **Systematic Learning**: 분산된 지식을 체계적으로 구조화하고, 학습 경로를 명확히 제시합니다.
- **Practical Application**: 이론에 그치지 않고, 실제 데이터를 활용한 연습과 프로젝트를 통해 실무 역량을 강화합니다.
- **Portfolio of Growth**: 학습의 시작부터 완성된 프로젝트까지, 성장 과정을 투명하게 보여주는 포트폴리오를 구축합니다.

## 기술 스택 (Tech Stack)

이 레포지토리는 다음과 같은 핵심 기술들을 기반으로 구축되었습니다.

- **`Programming Language`**: Python
- **`Data Science`**: Pandas, Numpy, Scikit-learn, Matplotlib, Seaborn
- **`Machine Learning / Deep Learning`**: TensorFlow, Keras, PyTorch
- **`Web Frameworks / API`**: Django, FastAPI
- **`Database`**: MySQL, SQLite
- **`Development Environment`**: Conda, Jupyter Notebook

*전체 의존성 정보는 `environment.yml` 파일에서 확인하실 수 있습니다.*

## 레포지토리 구조

각 디렉터리는 명확한 목적을 가지고 유기적으로 연결되어 있습니다.

```
SeSac-AIOps-Lab/
│
├── 01_Notes/
│   └── AI/ML의 이론적 기반을 다지는 학습 노트 공간입니다.
│       ├── 01_Python: 파이썬 문법, 자료구조, OOP 등 프로그래밍 기초
│       ├── 02_Algorithm: 문제 해결 능력 향상을 위한 알고리즘 및 자료구조
│       ├── 03_SQL: 데이터 처리를 위한 데이터베이스 및 SQL
│       ├── 04_Django_Fast: 모델 서빙을 위한 Django, FastAPI 웹 프레임워크
│       ├── 05_Machine_Learning: 머신러닝 핵심 이론 및 라이브러리
│       ├── 06_Deep_Learning: 딥러닝, 신경망, 최신 모델 아키텍처
│       └── 07_etc: 기타 학습 자료 (취업, AI 최신 동향 등)
│
├── 02_Exercises/
│   └── 이론을 코드로 구현하며 실력을 단련하는 실습 공간입니다.
│       └── (각 01_Notes 디렉터리와 동일한 구조로, 실제 구현 코드 포함)
│
├── 03_Projects/
│   └── 학습한 모든 지식을 총동원하여 완성한 실전 프로젝트 포트폴리오입니다.
│       └── (프로젝트별 독립적인 디렉토리, 데이터/코드/결과/README 포함)
│
├── data/
│   └── 실습 및 프로젝트에 사용되는 데이터셋을 관리합니다.
│
├── environment.yml
│   └── 프로젝트 실행에 필요한 모든 패키지 목록 및 버전 정보
│
└── README.md
    └── 현재 보고 계신 레포지토리 안내서

```

## 시작하기 (Getting Started)

이 레포지토리의 코드를 실행하고 학습을 시작하려면 다음 단계를 따르세요.

1.  **레포지토리 클론:**
    ```bash
    git clone https://github.com/AlpineDolce/SeSac-AIOps-Lab.git
    cd SeSac-AIOps-Lab
    ```

2.  **Conda 가상환경 생성 및 활성화:**
    `environment.yml` 파일을 사용하여 프로젝트 실행에 필요한 모든 패키지를 한 번에 설치할 수 있습니다.
    ```bash
    conda env create -f environment.yml
    conda activate sesac_aiops
    ```

3.  **학습 시작:**
    `01_Notes`의 이론을 학습하고, `02_Exercises`의 코드를 직접 실행하며 개념을 체득하세요. `03_Projects`를 통해 실전 문제 해결 능력을 기를 수 있습니다.
