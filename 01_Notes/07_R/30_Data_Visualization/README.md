# 데이터 시각화: 데이터, 말하다

**`ggplot2` 패키지를 활용하여 데이터를 탐색하고, 복잡한 패턴을 시각적으로 이해하며, 분석 결과를 설득력 있게 전달하는 방법**

이 섹션은 R의 가장 강력한 시각화 패키지인 `ggplot2`의 문법(Grammar of Graphics)을 이해하고, 산점도, 막대 그래프, 선 그래프 등 기본 그래프를 생성하는 방법을 학습합니다. 또한, 통계적 변환, 테마, 레이아웃 조정, 다중 패널 그래프 등 고급 시각화 기법과 `plotly`, `shiny` 등 인터랙티브 시각화 도구를 익혀 분석의 꽃을 피웁니다.
