# 데이터 조작 및 전처리: 데이터를 내 손안에

**지저분한 원본 데이터를 분석에 적합한 형태로 가공하는 핵심 기술**

이 섹션은 R의 강력한 데이터 조작 패키지인 `dplyr`과 `tidyr`을 활용하여 데이터를 자유자재로 변형하고 정리하는 방법을 학습합니다. 데이터 필터링, 선택, 정렬, 변형, 요약 등 핵심 데이터 조작 기법과 결측치, 이상치, 중복 데이터 등을 식별하고 처리하는 실무적인 데이터 클리닝 방법을 익혀, 분석의 기반을 다집니다.

---

### 주요 내용:

- [**04_dplyr_데이터_변형_요약.md**](./04_dplyr_데이터_변형_요약.md): `dplyr` 패키지를 이용한 데이터 필터링, 선택, 정렬, 변형, 요약 등 핵심 데이터 조작.
- [**05_tidyr_데이터_정리.md**](./05_tidyr_데이터_정리.md): `tidyr` 패키지를 이용한 데이터 재구조화(pivot_longer, pivot_wider) 및 결측치 처리.
- [**06_데이터_클리닝_및_결측치_처리.md**](./06_데이터_클리닝_및_결측치_처리.md): 실제 데이터에서 흔히 발생하는 결측치, 이상치, 중복 데이터 등을 식별하고 처리하는 방법.
