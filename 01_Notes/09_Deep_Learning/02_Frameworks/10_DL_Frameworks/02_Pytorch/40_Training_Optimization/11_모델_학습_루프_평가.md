# PyTorch 딥러닝 모델 학습 루프 및 평가

## 1. 딥러닝 모델 학습 과정 개요

딥러닝 모델의 학습은 데이터를 통해 모델의 파라미터(가중치와 편향)를 최적화하는 반복적인 과정입니다. 이 과정은 일반적으로 다음과 같은 핵심 구성 요소와 단계를 포함합니다.

*   **데이터**: `Dataset`과 `DataLoader`를 통해 모델에 공급됩니다.
*   **모델**: `nn.Module`을 상속받아 정의된 신경망입니다.
*   **손실 함수 (Loss Function)**: 모델의 예측과 실제 정답 사이의 오차를 측정합니다.
*   **옵티마이저 (Optimizer)**: 손실 함수의 기울기를 사용하여 모델 파라미터를 업데이트합니다.

학습 과정은 크게 **학습 루프(Training Loop)**와 **평가 루프(Evaluation Loop)**로 나눌 수 있으며, 각 에포크(Epoch)마다 이 두 루프가 반복적으로 수행됩니다.

## 2. 학습 루프 (Training Loop) 구현

학습 루프는 모델이 데이터를 통해 학습하고 파라미터를 업데이트하는 핵심 과정입니다.

### 2.1. 데이터 준비

`Dataset`과 `DataLoader`를 사용하여 데이터를 배치(batch) 단위로 로드하고, 모델이 학습될 장치(CPU 또는 GPU)로 데이터를 이동시킵니다.

```python
import torch
from torch.utils.data import DataLoader, TensorDataset

# 가상의 데이터셋 생성
x_data = torch.randn(100, 10) # 100개 샘플, 10개 특징
y_data = torch.randint(0, 2, (100,)) # 100개 레이블 (0 또는 1)

dataset = TensorDataset(x_data, y_data)
dataloader = DataLoader(dataset, batch_size=16, shuffle=True)

# 장치 설정
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
print(f"Using device: {device}")
```

### 2.2. 모델, 손실 함수, 옵티마이저 정의

학습을 시작하기 전에 모델 아키텍처, 손실 함수, 그리고 파라미터 업데이트를 위한 옵티마이저를 정의해야 합니다.

```python
import torch.nn as nn
import torch.optim as optim

# 간단한 모델 정의
class SimpleModel(nn.Module):
    def __init__(self, input_dim, output_dim):
        super().__init__()
        self.linear = nn.Linear(input_dim, output_dim)

    def forward(self, x):
        return self.linear(x)

model = SimpleModel(input_dim=10, output_dim=2).to(device) # 모델을 장치로 이동

# 손실 함수 정의 (이진 분류 예시)
criterion = nn.CrossEntropyLoss()

# 옵티마이저 정의 (Adam 옵티마이저 사용)
optimizer = optim.Adam(model.parameters(), lr=0.001)

print("Model, criterion, optimizer defined.")
```

### 2.3. 에포크 (Epoch) 반복

하나의 에포크는 전체 데이터셋을 한 번 학습하는 것을 의미합니다. 일반적으로 모델은 여러 에포크에 걸쳐 학습됩니다.

```python
num_epochs = 5
print(f"\nStarting training for {num_epochs} epochs...")
```

### 2.4. 배치 (Batch) 반복

각 에포크 내에서 `DataLoader`를 통해 데이터를 배치 단위로 가져와 모델을 학습시킵니다. 이 과정은 다음과 같은 핵심 단계로 구성됩니다.

1.  **`optimizer.zero_grad()`**: 이전 배치의 역전파에서 계산된 기울기(gradient)를 0으로 초기화합니다. PyTorch는 기본적으로 기울기를 누적(accumulate)하기 때문에, 매 배치마다 새로운 기울기를 계산하기 전에 반드시 초기화해야 합니다.
2.  **순전파 (Forward Pass)**: 입력 데이터를 모델에 통과시켜 예측값을 얻습니다.
3.  **손실 계산 (Loss Calculation)**: 모델의 예측값과 실제 정답을 비교하여 손실을 계산합니다.
4.  **역전파 (Backward Pass)**: 손실에 대한 모델 파라미터들의 기울기를 계산합니다 (`loss.backward()`).
5.  **파라미터 업데이트 (Parameter Update)**: 계산된 기울기를 사용하여 옵티마이저가 모델의 파라미터들을 업데이트합니다 (`optimizer.step()`).

```python
# 학습 루프
for epoch in range(num_epochs):
    model.train() # 모델을 학습 모드로 설정 (Dropout, BatchNorm 등이 활성화됨)
    running_loss = 0.0

    for i, (inputs, labels) in enumerate(dataloader):
        inputs, labels = inputs.to(device), labels.to(device) # 데이터를 장치로 이동

        optimizer.zero_grad() # 기울기 초기화

        # 순전파
        outputs = model(inputs)
        loss = criterion(outputs, labels)

        # 역전파 및 파라미터 업데이트
        loss.backward()
        optimizer.step()

        running_loss += loss.item()

    print(f"Epoch {epoch+1}, Loss: {running_loss / len(dataloader):.4f}")
print("Training finished.")
```

### 2.5. 학습률 스케줄러 (Learning Rate Scheduler)

학습률 스케줄러는 학습 과정 중에 학습률(`lr`)을 동적으로 조정하여 모델의 수렴을 돕습니다. `torch.optim.lr_scheduler` 모듈에 다양한 스케줄러가 구현되어 있으며, 일반적으로 각 에포크 또는 배치마다 `scheduler.step()`을 호출하여 학습률을 업데이트합니다.

```python
from torch.optim import lr_scheduler

# StepLR 스케줄러 예시: 30 에포크마다 학습률을 0.1배로 감소
scheduler = lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

# 학습 루프 내에서 사용:
# for epoch in range(num_epochs):
#     # ... (학습 코드)
#     scheduler.step() # 각 에포크 끝에서 스케줄러 업데이트
```

## 3. 모델 평가 (Evaluation Loop) 구현

모델 평가는 학습된 모델이 새로운, 보지 못한 데이터에 대해 얼마나 잘 작동하는지 측정하는 과정입니다. 이는 학습 루프와는 다른 방식으로 수행됩니다.

### 3.1. `model.eval()`: 평가 모드 설정

모델을 평가하기 전에 `model.eval()`을 호출하여 모델을 평가 모드로 전환해야 합니다. 이는 `Dropout` 레이어를 비활성화하고 `BatchNorm` 레이어를 학습된 통계량(running mean/variance)을 사용하도록 설정합니다.

### 3.2. `torch.no_grad()`: 기울기 계산 비활성화

평가 단계에서는 파라미터를 업데이트할 필요가 없으므로, `torch.no_grad()` 컨텍스트 매니저를 사용하여 기울기 계산을 비활성화합니다. 이는 메모리 사용량을 줄이고 연산 속도를 향상시킵니다.

### 3.3. 배치 반복 및 메트릭 계산

평가 데이터셋에 대해 배치 단위로 순전파를 수행하고, 손실 및 정확도와 같은 평가 메트릭을 계산합니다.

### 3.4. 결과 집계

모든 배치에 대한 손실과 메트릭을 집계하여 에포크별 평균 손실 및 최종 메트릭을 계산합니다.

```python
# 평가 루프
model.eval() # 모델을 평가 모드로 설정
val_loss = 0.0
correct_predictions = 0
total_samples = 0

with torch.no_grad(): # 기울기 계산 비활성화
    for inputs, labels in dataloader:
        inputs, labels = inputs.to(device), labels.to(device)

        outputs = model(inputs)
        loss = criterion(outputs, labels)

        val_loss += loss.item()

        _, predicted = torch.max(outputs.data, 1)
        total_samples += labels.size(0)
        correct_predictions += (predicted == labels).sum().item()

print(f"\nValidation Loss: {val_loss / len(dataloader):.4f}")
print(f"Validation Accuracy: {100 * correct_predictions / total_samples:.2f}%")
```

### 4.2. 모델 저장 및 로드

PyTorch 모델을 저장하고 로드하는 가장 일반적이고 권장되는 방법은 모델의 `state_dict()`를 저장하는 것입니다. `state_dict()`는 모델의 모든 학습 가능한 파라미터(가중치, 편향 등)를 딕셔너리 형태로 포함합니다.

```python
# 모델의 state_dict 저장
PATH = "model_weights.pth"
torch.save(model.state_dict(), PATH)
print(f"Model weights saved to {PATH}")

# 모델 로드
# 1. 모델 아키텍처를 먼저 정의해야 합니다.
loaded_model = SimpleModel(input_dim=10, output_dim=2).to(device)
# 2. 저장된 state_dict를 로드합니다.
loaded_model.load_state_dict(torch.load(PATH))
# 3. 평가 모드로 전환합니다.
loaded_model.eval()

print("Model loaded successfully.")
```

## 5. 고급 학습 기법

모델 학습의 효율성과 성능을 더욱 높이기 위한 몇 가지 고급 기법들입니다.

### 5.1. 조기 종료 (Early Stopping)

검증 데이터셋에 대한 모델의 성능(예: 검증 손실)이 일정 에포크 동안 개선되지 않으면 학습을 조기에 중단하는 기법입니다. 이는 과적합을 방지하고 불필요한 학습 시간을 줄여줍니다.

### 5.2. 기울기 클리핑 (Gradient Clipping)

학습 과정에서 기울기 값이 너무 커져 모델의 가중치가 급격하게 변하는 기울기 폭주(exploding gradients) 현상을 방지하기 위해, 기울기의 크기를 특정 임계값 이하로 제한하는 기법입니다. `torch.nn.utils.clip_grad_norm_` 함수를 사용합니다.

```python
# 역전파 후 옵티마이저.step() 전에 호출
# torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```


## 6. 결론

PyTorch에서 딥러닝 모델을 학습시키고 평가하는 과정은 잘 정의된 학습 루프와 평가 루프를 통해 체계적으로 관리됩니다. 데이터 준비, 모델 정의, 순전파, 역전파, 파라미터 업데이트의 각 단계를 정확히 이해하고 구현하는 것이 중요합니다. 또한, `model.train()`/`eval()`, `torch.no_grad()`, 모델 저장/로드와 같은 PyTorch의 기능을 적절히 활용하고, 조기 종료, 기울기 클리핑, 혼합 정밀도 학습과 같은 고급 기법들을 적용함으로써 모델의 성능과 학습 효율을 극대화할 수 있습니다. 이러한 지식은 성공적인 딥러닝 프로젝트 수행을 위한 필수적인 기반이 됩니다.
