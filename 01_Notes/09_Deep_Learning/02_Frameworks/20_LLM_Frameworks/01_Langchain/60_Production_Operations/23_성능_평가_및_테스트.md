## 1. LLM 애플리케이션 평가의 어려움

기존 소프트웨어는 입력이 같으면 출력이 같아 예측과 테스트가 용이합니다. 하지만 LLM 애플리케이션은 다음과 같은 이유로 평가가 매우 어렵습니다.

- **정답의 부재**: "~에 대해 설명해줘"와 같은 개방형 질문에는 하나의 정답이 존재하지 않습니다.
- **비결정성**: 동일한 질문에도 답변이 미묘하게 달라질 수 있습니다.
- **복잡한 파이프라인**: RAG 시스템의 경우, Retriever의 성능과 Generator(LLM)의 성능을 분리하여 평가해야 원인 분석이 가능합니다.

따라서, 우리는 LLM의 성능을 다각도에서 측정할 수 있는 새로운 평가 패러다임이 필요합니다.

## 2. 평가의 첫걸음: 평가 데이터셋 구축

체계적인 평가를 위해서는 **'Golden Dataset'** 이라고 불리는 고품질의 평가 데이터셋을 구축하는 것이 가장 중요합니다. 이 데이터셋은 애플리케이션이 실제로 마주할 만한 다양한 유형의 질문들을 포함해야 합니다.

- **question**: 사용자가 입력할 질문
- **ground_truth**: 해당 질문에 대한 이상적인 정답 또는 반드시 포함되어야 할 정보. (실제 사람이 작성)
- **contexts**: (RAG의 경우) 질문에 답하기 위해 검색되어야 하는 이상적인 문서 조각들.

이 데이터셋은 프롬프트를 수정하거나 모델을 변경했을 때, 성능이 저하되지 않았는지 확인하는 **회귀 테스트(Regression Test)** 의 기준점이 됩니다.

## 3. RAG 시스템의 핵심 평가 지표

RAG 시스템의 최종 답변 품질은 **Retriever**와 **Generator** 두 부분의 성능에 모두 의존합니다. 따라서 각 부분을 나누어 평가해야 합니다.

### 3.1. Retriever 성능 평가
- **Context Precision**: 검색된 문서들이 실제로 질문과 얼마나 관련이 있는가? (관련 있는 문서 수 / 전체 검색된 문서 수)
- **Context Recall**: 정답을 생성하는 데 필요한 모든 문서들을 빠짐없이 검색해냈는가? (검색된 관련 문서 수 / 전체 관련 문서 수)

### 3.2. Generation 성능 평가
- **Faithfulness (충실성)**: 생성된 답변이 검색된 문서(context)의 내용에 얼마나 충실한가? LLM이 정보를 왜곡하거나 지어내지 않았는가?
- **Answer Relevancy (답변 관련성)**: 생성된 답변이 사용자의 질문 의도에 얼마나 부합하는가? 동문서답을 하지는 않았는가?

## 4. LLM 기반 평가 프레임워크 활용

Faithfulness나 Relevancy와 같은 질적인 지표들은 사람이 직접 평가하기 어렵습니다. 다행히 최근에는 **LLM을 사용하여 LLM을 평가**하는 강력한 프레임워크들이 등장했습니다.

### 4.1. RAGAs 소개
RAGAs (RAG Assessment)는 RAG 파이프라인의 성능을 평가하기 위한 대표적인 오픈소스 프레임워크입니다. 위에서 언급한 4가지 핵심 지표(Context Precision, Context Recall, Faithfulness, Answer Relevancy)를 LLM을 통해 자동으로 측정해줍니다.

### 4.2. RAGAs를 이용한 평가 실습

```bash
pip install ragas
```

```python
from datasets import Dataset
from ragas import evaluate
from ragas.metrics import (
    faithfulness,
    answer_relevancy,
    context_recall,
    context_precision,
)

# 1. 평가 데이터셋 준비 (Hugging Face Dataset 형식)
data = {
    "question": ["LangChain은 언제 출시되었나요?"],
    "answer": ["LangChain은 2022년 Harrison Chase에 의해 처음 출시되었습니다."], # 실제 RAG 시스템이 생성한 답변
    "contexts": [["LangChain은 2022년 Harrison Chase에 의해 처음 출시되었습니다."]], # RAG 시스템이 검색한 문서
    "ground_truth": ["LangChain은 2022년에 출시되었습니다."] # 우리가 준비한 정답
}
dataset = Dataset.from_dict(data)

# 2. 평가 실행
result = evaluate(
    dataset=dataset,
    metrics=[
        faithfulness,
        answer_relevancy,
        context_recall,
        context_precision,
    ],
)

# 3. 결과 확인
print(result)
# {'faithfulness': 1.0, 'answer_relevancy': 0.95, ...}
```

## 5. LangSmith를 활용한 평가 자동화

LangSmith는 이러한 평가 과정을 더욱 쉽게 만들어줍니다. LangSmith 대시보드에서 평가 데이터셋을 업로드하고, RAGAs와 같은 평가기를 연결하면, 특정 체인을 실행할 때마다 자동으로 성능 평가를 수행하고 그 결과를 시각적으로 추적할 수 있습니다. 이를 통해 프롬프트나 모델 변경에 따른 성능 변화를 지속적으로 모니터링하고 개선할 수 있습니다.
