## 1. 에이전트란 무엇인가?

### 1.1. LLM의 한계를 넘어서
LLM은 방대한 지식을 가지고 있지만, 그 자체로는 외부 세계와 상호작용할 수 없습니다. 예를 들어, "오늘 날씨 어때?"라고 물어도 LLM은 실시간 날씨 정보를 가져올 수 없으며, "345의 5제곱은 얼마야?"라는 질문에 정확한 계산을 보장하지 못합니다.

에이전트는 이러한 한계를 극복하기 위해 LLM에게 **'도구(Tool)'** 를 쥐여주는 개념입니다. LLM이 마치 사람처럼 생각해서, 어떤 도구가 필요한지 판단하고, 그 도구를 사용하여 얻은 정보를 바탕으로 최종 답변을 만들어내는 것입니다.

### 1.2. 에이전트의 작동 원리: 추론과 행동의 반복
에이전트는 일반적으로 다음과 같은 루프를 반복하며 작업을 수행합니다.
1.  **관찰 (Observation)**: 사용자의 질문이나 현재 상황을 관찰합니다.
2.  **생각 (Thought)**: 관찰한 내용을 바탕으로, 목표를 달성하기 위해 어떤 행동을 해야 할지 LLM이 추론합니다.
3.  **행동 (Action)**: 생각의 결과로, 특정 도구를 특정 입력값과 함께 사용하기로 결정합니다.
4.  **실행 및 결과 관찰**: 결정된 행동(도구 사용)을 실행하고, 그 결과를 다시 관찰합니다. 이 결과는 다음 루프의 입력이 됩니다.
5.  이 과정을 목표를 달성할 때까지 반복하고, 최종적으로 사용자에게 답변을 반환합니다.

## 2. 에이전트의 핵심 구성 요소

### 2.1. 도구 (Tools)
- **정의**: 에이전트가 사용할 수 있는 기능의 단위입니다. 파이썬 함수, 다른 체인, 외부 API 등 무엇이든 도구가 될 수 있습니다.
- **중요성**: 도구의 이름과 설명은 LLM이 언제 어떤 도구를 사용해야 할지 판단하는 데 매우 중요한 역할을 합니다. 명확하고 상세하게 작성해야 합니다.
- **예시**: 구글 검색 도구, 계산기 도구, 데이터베이스 조회 도구 등

### 2.2. 에이전트 (Agent)
- **정의**: LLM과 프롬프트를 포함하는 핵심 두뇌입니다. 사용자의 입력을 받아 어떤 도구를 사용할지 결정하는 역할을 합니다.
- **프롬프트**: 에이전트의 프롬프트는 매우 특별하게 설계되어, 사용 가능한 도구 목록과 이전 행동 기록을 포함하여 LLM이 최적의 결정을 내리도록 유도합니다.

### 2.3. 에이전트 실행기 (Agent Executor)
- **정의**: 에이전트가 내린 결정(행동)을 실제로 실행하고, 그 결과를 다시 에이전트에게 전달하며, 전체 루프를 관리하는 실행 환경입니다.
- **역할**: 에이전트와 도구 사이의 중간 관리자 역할을 하며, 작업이 완료되거나 특정 조건에 도달할 때까지 루프를 반복 실행합니다.

## 3. 기본 제공 도구를 활용한 에이전트 실습

LangChain은 웹 검색, 계산 등 일반적인 작업을 위한 다양한 도구들을 기본으로 제공합니다. 이를 활용하여 간단한 에이전트를 만들어 보겠습니다.

### 3.1. 필요한 라이브러리 설치
웹 검색을 위해 `duckduckgo-search` 라이브러리를 설치합니다.
```bash
pip install duckduckgo-search
```

### 3.2. 도구 준비
DuckDuckGo 웹 검색 도구를 준비합니다.
```python
from langchain_community.tools import DuckDuckGoSearchRun

search = DuckDuckGoSearchRun()
tools = [search]
```

### 3.3. 에이전트 생성 및 실행
LangChain은 ReAct 프레임워크를 기반으로 하는 강력한 에이전트를 쉽게 만들 수 있는 `create_react_agent` 함수를 제공합니다.

```python
from langchain import hub
from langchain.agents import create_react_agent, AgentExecutor
from langchain_openai import ChatOpenAI
from dotenv import load_dotenv

load_dotenv()

# LLM 초기화
llm = ChatOpenAI(temperature=0)

# 1. 도구 준비
from langchain_community.tools import DuckDuckGoSearchRun
tools = [DuckDuckGoSearchRun()]

# 2. 프롬프트 가져오기
# LangChain Hub에서 ReAct 에이전트를 위한 표준 프롬프트를 가져옴
prompt = hub.pull("hwchase17/react")

# 3. 에이전트 생성
agent = create_react_agent(llm, tools, prompt)

# 4. 에이전트 실행기 생성
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True) # verbose=True로 생각 과정을 확인

# 5. 실행
query = "현재 대한민국의 대통령은 누구이며, 그의 임기는 언제까지인가요?"
response = agent_executor.invoke({"input": query})

print(f"\n최종 답변: {response['output']}")
```
`verbose=True` 옵션을 통해 에이전트가 어떻게 생각하고(Thought), 어떤 도구를 사용하며(Action), 어떤 결과를 얻는지(Observation) 실시간으로 확인할 수 있습니다. 이를 통해 우리는 LLM이 단순히 글을 쓰는 것을 넘어, 목표를 달성하기 위해 '행동'하는 과정을 엿볼 수 있습니다.
