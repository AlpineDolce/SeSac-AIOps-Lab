## 1. 개발 환경 준비

### 1.1. Python 설치
LangChain은 Python 3.8 이상 버전에서 안정적으로 동작합니다. 시스템에 Python이 설치되어 있지 않다면, [python.org](https://www.python.org/downloads/)에서 최신 버전을 설치해 주세요.

### 1.2. 가상 환경 설정
프로젝트별로 독립적인 라이브러리 환경을 유지하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다. 이는 프로젝트 간의 의존성 충돌을 방지하고, 협업 시 동일한 환경을 쉽게 공유할 수 있게 해줍니다.

```bash
# 'langchain-env'라는 이름의 가상 환경 생성
python -m venv langchain-env

# 가상 환경 활성화 (Windows)
langchain-env\Scripts\activate

# 가상 환경 활성화 (macOS/Linux)
source langchain-env/bin/activate
```
이제 터미널 프롬프트 앞에 `(langchain-env)`가 표시되며, 모든 `pip` 설치는 이 가상 환경 내에서만 이루어집니다.

## 2. LangChain 및 필수 라이브러리 설치

### 2.1. 핵심 라이브러리 설치
LangChain의 핵심 기능은 `langchain` 패키지에 포함되어 있습니다.

```bash
pip install langchain
```

### 2.2. LLM 연동 라이브러리 설치
LangChain은 다양한 LLM 제공자와 연동할 수 있는 패키지를 별도로 제공합니다. 가장 일반적으로 사용되는 OpenAI 모델을 사용하기 위해 `langchain-openai`를 설치합니다.

```bash
pip install langchain-openai
```
또한, API 키를 안전하게 관리하기 위해 `.env` 파일을 사용하므로, `python-dotenv` 라이브러리도 함께 설치합니다.
```bash
pip install python-dotenv
```

## 3. API 키 발급 및 설정

### 3.1. OpenAI API 키 발급
1.  [OpenAI 웹사이트](https://platform.openai.com/)에 접속하여 회원가입 및 로그인을 합니다.
2.  우측 상단의 개인 프로필 메뉴에서 'View API keys'를 선택합니다.
3.  'Create new secret key' 버튼을 클릭하여 새로운 API 키를 생성합니다.
4.  **중요:** 생성된 키는 한 번만 전체를 볼 수 있습니다. 반드시 안전한 곳에 복사해 두세요.

### 3.2. 환경 변수를 사용한 안전한 키 관리
API 키는 민감한 정보이므로, 소스 코드에 직접 하드코딩하는 것은 매우 위험합니다. 대신, 환경 변수를 사용하여 안전하게 관리해야 합니다.

1.  프로젝트 루트 디렉터리에 `.env` 라는 이름의 파일을 생성합니다.
2.  `.env` 파일 안에 다음과 같이 발급받은 API 키를 저장합니다.

```
OPENAI_API_KEY="sk-..."
```

3.  소스 코드에서는 `dotenv` 라이브러리를 사용하여 이 키를 불러옵니다.

## 4. 설정 검증
모든 설정이 올바르게 완료되었는지 간단한 코드를 통해 확인해 보겠습니다.

`verify_setup.py`
```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAI

# .env 파일에서 환경 변수 로드
load_dotenv()

# OpenAI API 키가 제대로 로드되었는지 확인
api_key = os.getenv("OPENAI_API_KEY")
if not api_key:
    raise ValueError("OPENAI_API_KEY가 설정되지 않았습니다. .env 파일을 확인하세요.")

print("환경 설정이 성공적으로 완료되었습니다.")
print("OpenAI API 키가 로드되었습니다.")

# 간단한 LLM 호출 테스트
try:
    llm = OpenAI()
    response = llm.invoke("Hello, world!")
    print("LLM 호출 테스트 성공:")
    print(response)
except Exception as e:
    print(f"LLM 호출 중 오류가 발생했습니다: {e}")

```
위 코드를 실행했을 때 "환경 설정이 성공적으로 완료되었습니다." 메시지와 함께 LLM의 응답이 출력된다면, 개발 환경 구축이 성공적으로 완료된 것입니다.
