## 1. 애플리케이션 개요
우리가 만들 첫 번째 애플리케이션은 매우 간단합니다. 특정 '주제'를 입력하면, 해당 주제에 대한 농담을 생성하는 프로그램입니다. 예를 들어, '프로그래밍'이라는 주제를 입력하면 프로그래밍과 관련된 농담을 출력합니다.

## 2. 핵심 컴포넌트 준비
이 애플리케이션을 만들기 위해 두 가지 핵심 컴포넌트가 필요합니다.

### 2.1. LLM 모델 (Model)
LLM은 우리의 요청을 받아 텍스트를 생성하는 '뇌' 역할을 합니다. LangChain은 다양한 LLM을 표준화된 인터페이스로 제공합니다. 여기서는 OpenAI의 `gpt-3.5-turbo-instruct` 모델을 사용하겠습니다.

```python
from langchain_openai import OpenAI

# LLM 모델 초기화
# temperature: 모델의 창의성을 조절하는 파라미터 (0에 가까울수록 결정론적, 1에 가까울수록 창의적)
llm = OpenAI(temperature=0.7)
```

### 2.2. 프롬프트 템플릿 (Prompt Template)
프롬프트 템플릿은 LLM에게 전달할 지시문(프롬프트)의 '틀'입니다. 사용자의 입력을 받아 동적으로 프롬프트를 완성하는 역할을 합니다.

```python
from langchain_core.prompts import PromptTemplate

# 프롬프트 템플릿 정의
# {topic} 부분은 나중에 사용자의 입력으로 채워질 변수입니다.
prompt_template = PromptTemplate.from_template(
    "{topic}에 대한 재미있는 농담을 한 줄로 만들어줘."
)
```

## 3. 체인(Chain)으로 컴포넌트 연결

### 3.1. LLMChain 소개
`LLMChain`은 LangChain에서 가장 기본적이면서도 중요한 체인입니다. 이름에서 알 수 있듯이, 프롬프트 템플릿과 LLM 모델을 순차적으로 연결하여 하나의 실행 가능한 단위로 만들어 줍니다.

### 3.2. LCEL을 이용한 체인 구성
최신 LangChain에서는 LCEL(LangChain Expression Language)을 사용하여 파이프(`|`) 연산자로 컴포넌트들을 매우 직관적으로 연결할 수 있습니다.

```python
# 프롬프트 템플릿과 LLM 모델을 체인으로 연결
chain = prompt_template | llm
```
이 한 줄의 코드는 다음과 같은 데이터 흐름을 정의합니다.
1.  사용자 입력(딕셔너리 형태, 예: `{"topic": "프로그래밍"}`)이 `prompt_template`으로 전달됩니다.
2.  `prompt_template`은 입력을 받아 완전한 프롬프트 문자열(예: "프로그래밍에 대한 재미있는 농담을 한 줄로 만들어줘.")을 생성합니다.
3.  생성된 프롬프트 문자열이 `llm` 모델로 전달됩니다.
4.  `llm` 모델은 프롬프트를 기반으로 응답(농담)을 생성하여 최종 결과로 반환합니다.

## 4. 전체 코드 및 실행

`simple_joke_app.py`
```python
import os
from dotenv import load_dotenv
from langchain_openai import OpenAI
from langchain_core.prompts import PromptTemplate

# .env 파일에서 API 키 로드
load_dotenv()

# 1. LLM 모델 준비
llm = OpenAI(temperature=0.7)

# 2. 프롬프트 템플릿 준비
prompt_template = PromptTemplate.from_template(
    "{topic}에 대한 재미있는 농담을 한 줄로 만들어줘."
)

# 3. 체인으로 연결
chain = prompt_template | llm

# 4. 체인 실행 (invoke)
topic = "프로그래밍"
response = chain.invoke({"topic": topic})

# 5. 결과 출력
print(f"주제: {topic}")
print(f"농담: {response}")
```

**실행 결과 (예시):**
```
주제: 프로그래밍
농담: 왜 프로그래머는 어두운 곳을 좋아할까? 버그들이 빛을 싫어하니까!
```

## 5. 작동 원리 분석
이번 실습을 통해 우리는 LangChain의 핵심적인 작업 흐름을 경험했습니다.
- **입력**: 사용자는 'topic'이라는 변수만 제공했습니다.
- **프롬프트화**: `PromptTemplate`이 이 변수를 받아 LLM이 이해할 수 있는 완전한 지시문으로 만들었습니다.
- **실행**: `LLM` 모델이 완성된 프롬프트를 받아 작업을 수행했습니다.
- **연결**: `Chain` (LCEL의 `|`)이 이 모든 과정을 자연스럽게 연결하여 하나의 파이프라인으로 만들었습니다.

이것이 바로 LangChain의 기본이자 핵심입니다. 앞으로 우리는 더 복잡한 컴포넌트들을 이 파이프라인에 추가하여 훨씬 더 강력하고 지능적인 애플리케이션을 만들어 나갈 것입니다.
