## 1. LangChain 소개

### 1.1. LLM 시대, 새로운 개발의 장벽

ChatGPT의 등장 이후, 우리는 LLM이 가진 무한한 가능성을 목격했습니다. 하지만 이 강력한 기술을 실제 애플리케이션으로 만드는 과정은 생각보다 복잡합니다. 단순한 챗봇을 넘어, LLM을 우리 시스템의 일부로 통합하려고 할 때 다음과 같은 새로운 장벽에 부딪히게 됩니다.

*   **데이터 단절 (Data Disconnection)**: LLM은 학습된 시점까지의 데이터만 알고 있습니다. 실시간 정보나 우리 회사 내부의 문서와 같은 '외부' 데이터와는 단절되어 있습니다. 이로 인해 최신 정보에 대한 답변을 생성하지 못하거나, 특정 도메인에 대한 깊이 있는 질의에 응답할 수 없습니다.
*   **상태 부재 (Statelessness)**: LLM API는 기본적으로 '상태가 없습니다(stateless)'. 즉, 방금 나눈 대화를 기억하지 못합니다. 사용자와의 연속적인 대화를 기억하고 맥락을 유지하기 위해서는 별도의 복잡한 상태 관리 시스템이 필요합니다.
*   **외부 시스템과의 상호작용 부재**: LLM은 그 자체로 계산기, 데이터베이스 조회, API 호출 등 외부 시스템을 직접 사용할 수 없습니다. 사용자의 요청을 이해하고, 적절한 도구를 선택하여 실행하고, 그 결과를 다시 사용자에게 전달하는 '에이전트'로서의 기능이 필요합니다.
*   **프롬프트의 한계**: 복잡한 작업을 수행하기 위해서는 매우 길고 정교한 프롬프트를 작성해야 합니다. 이는 프롬프트를 관리하기 어렵게 만들고, 특정 작업에 과도하게 의존하게 만들어 유연성을 떨어뜨립니다.

이러한 문제들은 LLM을 단순한 'API 호출'의 대상으로만 봐서는 해결할 수 없으며, LLM을 중심으로 데이터와 도구를 유기적으로 연결하는 새로운 개발 패러다임이 필요하게 되었습니다.

### 1.2. 개발의 복잡성을 해결하는 열쇠, LangChain

**LangChain**은 바로 이러한 LLM 애플리케이션 개발의 복잡성을 해결하기 위해 탄생한 오픈소스 프레임워크입니다. LangChain은 LLM을 단독으로 사용하는 것이 아니라, 다양한 외부 데이터 소스, 다른 API, 그리고 상태 관리 시스템과 쉽게 '연결(chain)'할 수 있도록 돕는 접착제 역할을 합니다.

LangChain이 제공하는 핵심 가치는 **'추상화'** 와 **'표준화'** 입니다.
*   **추상화 (Abstraction)**: OpenAI, Google, Hugging Face 등 다양한 LLM 제공자의 API는 각기 다른 인터페이스를 가지고 있습니다. LangChain은 이를 'Model'이라는 하나의 표준 인터페이스로 추상화하여, 개발자가 코드를 거의 변경하지 않고도 기본 LLM을 쉽게 교체할 수 있게 해줍니다.
*   **표준화 (Standardization)**: 데이터를 불러오고(Loaders), 나누고(Splitters), 저장하는(Vector Stores) 등 LLM 애플리케이션 개발에 반복적으로 사용되는 패턴들을 표준화된 컴포넌트로 제공합니다. 이를 통해 개발자는 복잡한 내부 구현에 신경 쓸 필요 없이, 비즈니스 로직 자체에 집중할 수 있습니다.

마치 레고 블록처럼, LangChain이 제공하는 표준화된 컴포넌트들을 조립하여 복잡한 애플리케이션을 빠르고 견고하게 구축할 수 있게 되는 것입니다.

### 1.3. LangChain의 핵심 철학: 조합성과 모듈성

LangChain의 가장 강력한 특징은 **조합성(Composability)** 과 **모듈성(Modularity)** 입니다. LangChain은 LLM 애플리케이션을 구성하는 요소들을 독립적인 모듈(Models, Prompts, Chains, Agents 등)로 나누고, 이들을 자유롭게 조합하여 원하는 파이프라인을 만들 수 있도록 설계되었습니다.

최근 도입된 **LCEL (LangChain Expression Language)** 은 이러한 조합성을 극대화하는 도구입니다. 파이썬의 파이프(`|`) 연산자를 사용하여 마치 쉘 스크립트처럼 직관적으로 데이터의 흐름을 정의하고, 각 단계를 연결하여 복잡한 체인을 구성할 수 있습니다.

```python
# LCEL을 사용한 체인 구성 예시
chain = prompt | model | output_parser
```

이러한 접근 방식은 다음과 같은 장점을 가집니다.
*   **가독성 및 유지보수성**: 코드의 흐름이 명확하게 보여 가독성이 높고, 각 모듈이 독립적이므로 유지보수가 용이합니다.
*   **유연성 및 확장성**: 필요에 따라 새로운 모듈을 쉽게 추가하거나 기존 모듈을 교체할 수 있어, 변화하는 요구사항에 유연하게 대응할 수 있습니다.
*   **재사용성**: 잘 만들어진 체인이나 프롬프트는 다른 애플리케이션에서도 쉽게 재사용할 수 있습니다.

### 1.4. LangChain으로 무엇을 만들 수 있는가?

LangChain을 사용하면 기존에는 구현하기 매우 어려웠던 다양한 종류의 지능형 애플리케이션을 현실로 만들 수 있습니다.

*   **데이터 기반 Q&A 챗봇 (RAG)**:
    *   PDF, DOCX, 웹사이트 등 특정 문서나 데이터베이스를 기반으로 답변하는 챗봇을 만들 수 있습니다. 이는 LLM의 환각을 줄이고, 신뢰할 수 있는 정보 소스를 기반으로 답변하게 합니다.
    *   **예시**: 사내 규정 안내 챗봇, 특정 제품 매뉴얼 Q&A, 최신 뉴스 기반 질의응답 시스템

*   **자율적인 AI 에이전트 (Agent)**:
    *   LLM이 스스로 생각하여 필요한 도구(예: 구글 검색, 계산기, 코드 실행기)를 선택하고, 목표를 달성할 때까지 작업을 자율적으로 수행하는 에이전트를 구현할 수 있습니다.
    *   **예시**: "오늘 서울 날씨를 찾아서 알려주고, 날씨가 좋으면 근처 공원을 추천해줘"와 같은 복합적인 요청을 처리하는 개인 비서

*   **코드 분석 및 생성 도구**:
    *   주어진 코드 저장소를 분석하여 질문에 답하거나, 사용자의 요구사항에 맞춰 코드를 자동으로 생성하고 수정하는 개발 보조 도구를 만들 수 있습니다.

*   **복잡한 데이터 분석 및 요약**:
    *   구조화된 데이터(CSV, SQL)와 비구조화된 데이터(Text)를 모두 이해하고, 이를 종합하여 분석 보고서나 요약 자료를 생성하는 시스템을 구축할 수 있습니다.

LangChain은 이처럼 LLM의 지능을 외부 세계와 연결하여, 우리가 상상하는 거의 모든 종류의 AI 기반 서비스를 만들 수 있는 강력한 기반을 제공합니다. 이제 LangChain의 세계로 본격적으로 뛰어들어 볼 시간입니다.
