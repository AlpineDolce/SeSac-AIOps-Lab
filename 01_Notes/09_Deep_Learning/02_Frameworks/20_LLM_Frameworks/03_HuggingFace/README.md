# Hugging Face 실무 역량 강화 가이드

**Hugging Face 생태계 완전 정복: LLM 개발 및 배포의 핵심 플랫폼**

이 가이드는 LLM(거대 언어 모델) 개발 및 배포의 핵심 플랫폼인 Hugging Face의 다양한 도구와 라이브러리를 체계적으로 안내합니다. Hugging Face는 Transformers 라이브러리부터 Hub, Spaces, Optimum 등 LLM 관련 연구와 실무에 필요한 모든 것을 제공합니다. 이 가이드를 통해 여러분은 Hugging Face 생태계를 완벽하게 이해하고, 최신 LLM을 활용한 애플리케이션을 효율적으로 개발하고 배포하는 핵심 역량을 갖추게 될 것입니다.
