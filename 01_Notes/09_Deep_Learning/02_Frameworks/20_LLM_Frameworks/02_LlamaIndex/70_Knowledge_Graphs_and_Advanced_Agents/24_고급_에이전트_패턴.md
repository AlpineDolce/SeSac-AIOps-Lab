## 1. LlamaIndex 에이전트의 진화

LlamaIndex는 RAG(Retrieval-Augmented Generation)에 특화된 프레임워크이지만, 쿼리 엔진(Query Engine)을 도구(Tool)로 활용하여 LLM 기반 에이전트를 구축하는 강력한 기능도 제공합니다. 이는 LLM이 단순히 정보를 검색하고 답변하는 것을 넘어, 외부 서비스와 상호작용하거나 복잡한 다단계 작업을 수행할 수 있도록 합니다.

### 1.1. 쿼리 엔진을 도구로 활용
LlamaIndex의 핵심 강점 중 하나는 구축된 `QueryEngine`을 마치 하나의 함수처럼 에이전트의 도구로 쉽게 등록할 수 있다는 점입니다. 예를 들어, 특정 문서에 대한 `QueryEngine`을 도구로 등록하면, 에이전트는 사용자의 질문에 따라 해당 문서에서 정보를 검색하는 도구를 호출할 수 있습니다.

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader
from llama_index.core.tools import QueryEngineTool, ToolMetadata
from llama_index.llms.openai import OpenAI
from dotenv import load_dotenv

load_dotenv()

# 문서 로드 및 인덱스 구축 (예시)
documents = SimpleDirectoryReader(input_files=["./data/llama_index_docs.txt"]).load_data()
index = VectorStoreIndex.from_documents(documents)

# 쿼리 엔진 생성
query_engine = index.as_query_engine(llm=OpenAI(model="gpt-4o", temperature=0))

# 쿼리 엔진을 도구로 변환
query_tool = QueryEngineTool(n
    query_engine=query_engine,
    metadata=ToolMetadata(
        name="llama_index_docs_query_engine",
        description="LlamaIndex 문서에 대한 질문에 답변합니다.",
    ),
)
```

### 1.2. LangChain 에이전트와의 비교
LlamaIndex의 에이전트는 LangChain의 에이전트와 유사한 역할을 수행하지만, LlamaIndex는 특히 **데이터 소스와의 상호작용**에 더 중점을 둡니다. LlamaIndex 에이전트는 복잡한 데이터 검색 및 분석 작업을 수행하는 데 강점을 가지며, LangChain 에이전트는 다양한 외부 도구와의 연동 및 복합적인 워크플로우 제어에 강점을 가집니다. 두 프레임워크의 에이전트 기능은 상호 보완적으로 활용될 수 있습니다.

## 2. 고급 에이전트 패턴

LlamaIndex는 단순한 정보 검색 에이전트를 넘어, LLM의 추론 능력을 활용하여 더욱 복잡하고 자율적인 에이전트 패턴을 구축할 수 있도록 지원합니다.

### 2.1. 쿼리 계획 에이전트 (Query Planning Agent)
사용자의 복잡한 질문을 여러 개의 하위 질문으로 분해하고, 각 하위 질문에 가장 적합한 도구(예: 다른 쿼리 엔진, 외부 API)를 선택하여 순차적으로 실행하며 최종 답변을 종합하는 에이전트입니다. 이는 LLM이 스스로 문제 해결 계획을 세우고 실행하는 능력을 부여합니다.

### 2.2. 멀티 모달 에이전트 (Multi-modal Agent)
텍스트뿐만 아니라 이미지, 오디오, 비디오 등 다양한 형태의 데이터를 이해하고 처리할 수 있는 LLM(예: GPT-4o, Gemini)을 활용하여, 여러 모달리티의 정보를 조합하여 답변하거나 작업을 수행하는 에이전트입니다. LlamaIndex는 다양한 데이터 로더를 통해 멀티 모달 데이터를 인덱싱하고 검색할 수 있도록 지원합니다.

### 2.3. 데이터 에이전트 (Data Agent)
구조화된 데이터(예: SQL 데이터베이스, CSV 파일, Pandas DataFrame)와 상호작용하여 데이터 분석, 질의, 시각화 등을 수행하는 에이전트입니다. LLM이 자연어 질문을 SQL 쿼리나 Pandas 코드 등으로 변환하여 데이터를 조작하고 결과를 해석합니다.

### 2.4. 에이전트 간 협업 (Agent Collaboration)
여러 에이전트가 각자의 전문 분야에 따라 역할을 분담하고, 서로 소통하며 복잡한 문제를 해결하는 시스템입니다. 각 에이전트는 자신의 전문 도구를 가지고 있으며, 필요에 따라 다른 에이전트에게 작업을 위임하거나 정보를 요청합니다.

## 3. LlamaIndex에서 고급 에이전트 구축하기

LlamaIndex에서 고급 에이전트를 구축하는 과정은 기본적으로 도구를 정의하고, 이 도구들을 에이전트에 등록한 후 실행하는 방식으로 이루어집니다.

### 3.1. 도구 정의 및 등록
LlamaIndex는 `FunctionTool`, `QueryEngineTool` 등 다양한 유형의 도구를 제공합니다. 커스텀 파이썬 함수나 이미 구축된 쿼리 엔진을 쉽게 도구로 변환하여 에이전트가 사용할 수 있도록 등록합니다.

```python
from llama_index.core.agent import ReActAgent
from llama_index.core.tools import FunctionTool

# 쿼리 엔진 도구 (위에서 정의한 query_tool 사용)
# query_tool

# 커스텀 함수 도구 (예시)
def get_current_time() -> str:
    """현재 시간을 반환합니다."""
    from datetime import datetime
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

time_tool = FunctionTool.from_defaults(fn=get_current_time)

# 에이전트에 등록할 도구 목록
tools = [query_tool, time_tool]
```

### 3.2. 에이전트 생성 및 실행
LlamaIndex는 `ReActAgent`, `OpenAIAgent` 등 다양한 에이전트 구현체를 제공합니다. LLM과 도구 목록을 전달하여 에이전트를 생성하고, `chat()` 또는 `query()` 메서드를 통해 실행합니다.

```python
# ReActAgent 생성
agent = ReActAgent.from_tools(
    tools,
    llm=OpenAI(model="gpt-4o", temperature=0),
    verbose=True # 에이전트의 추론 과정을 확인
)
```
