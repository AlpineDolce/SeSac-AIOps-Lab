## 1. 쿼리 엔진이란?

### 1.1. RAG 파이프라인의 실행자
**쿼리 엔진**은 LlamaIndex에서 데이터에 질문하고 답변을 받는 가장 간단하고 일반적인 방법입니다. `index.as_query_engine()`을 호출하는 순간, LlamaIndex는 사용자의 쿼리를 받아 답변을 생성하기까지의 전체 RAG 파이프라인(검색 -> 생성)을 자동으로 구성하고 실행하는 편리한 객체를 만들어줍니다.

쿼리 엔진 내부에서는 다음과 같은 과정이 일어납니다.
1.  사용자의 쿼리를 받습니다.
2.  내부적으로 **Retriever**를 사용하여 인덱스에서 쿼리와 관련성 높은 `Node`(문서 조각)들을 검색합니다.
3.  검색된 `Node`들을 **Response Synthesizer**에 전달합니다.
4.  Response Synthesizer는 검색된 `Node`들과 원본 쿼리를 조합하여 프롬프트를 만들고, 이를 **LLM**에 전달하여 최종 답변을 생성합니다.

## 2. 쿼리 엔진 생성 및 사용

### 2.1. `index.as_query_engine()`
가장 기본적인 방법은 `VectorStoreIndex` 객체의 `as_query_engine()` 메소드를 호출하는 것입니다.

```python
from llama_index.core import load_index_from_storage, StorageContext

# 저장된 인덱스 로드
storage_context = StorageContext.from_defaults(persist_dir="./my_index_storage")
index = load_index_from_storage(storage_context)

# 쿼리 엔진 생성
query_engine = index.as_query_engine()

# 쿼리 실행
response = query_engine.query("What was the author's main focus during his work on Viaweb?")

print(response)
```

### 2.2. 스트리밍 응답
쿼리 엔진은 스트리밍을 지원하여 사용자 경험을 향상시킬 수 있습니다. `query()` 대신 `stream_query()` 메소드를 사용합니다.

```python
# 스트리밍 쿼리 실행
streaming_response = query_engine.stream_query("What was the author's main focus during his work on Viaweb?")

# 스트리밍 응답 처리
for token in streaming_response.response_gen:
    print(token, end="")
```

## 3. 쿼리 엔진 커스터마이징

`as_query_engine()`을 호출할 때 몇 가지 파라미터를 설정하여 동작 방식을 변경할 수 있습니다.

### 3.1. 검색할 노드 수 조절: `similarity_top_k`
`similarity_top_k`는 Retriever가 인덱스에서 검색할 가장 유사한 노드의 개수를 지정합니다. 이 값을 조절하여 LLM에 제공되는 컨텍스트의 양을 제어할 수 있습니다.

- **`similarity_top_k`를 늘리면**: 더 많은 컨텍스트가 LLM에 제공되어 더 포괄적인 답변을 생성할 수 있지만, 관련 없는 정보가 포함될 위험도 커지고 토큰 사용량(비용)이 증가합니다.
- **`similarity_top_k`를 줄이면**: 더 정확하고 집중된 컨텍스트를 제공하여 답변의 정확도를 높일 수 있지만, 질문에 답하는 데 필요한 정보가 누락될 수 있습니다.

```python
# 상위 5개의 가장 유사한 노드를 검색하도록 설정
query_engine_top5 = index.as_query_engine(similarity_top_k=5)

response = query_engine_top5.query("What was the author's main focus during his work on Viaweb?")

# 검색에 사용된 소스 노드 확인
# print(response.source_nodes)
```

적절한 `similarity_top_k` 값은 데이터의 특성과 사용자의 질문 유형에 따라 다르므로, 여러 값을 테스트하며 최적의 값을 찾는 것이 중요합니다. 쿼리 엔진은 이처럼 간단한 인터페이스 뒤에 복잡한 RAG 로직을 숨겨, 개발자가 쉽고 빠르게 데이터 기반 Q&A 시스템을 구축할 수 있도록 돕습니다.
