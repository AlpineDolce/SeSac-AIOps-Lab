## 1. 데이터 수집 파이프라인의 시작

RAG 시스템의 성능은 결국 어떤 데이터를 기반으로 하느냐에 달려있습니다. 데이터 로딩은 우리가 가진 원본 데이터(PDF, TXT, 웹사이트, Notion, Slack 등)를 LlamaIndex가 이해할 수 있는 `Document` 형식으로 가져오는 첫 번째이자 가장 중요한 단계입니다.

`Document` 객체는 텍스트 내용(`text`)과 함께, 해당 데이터의 출처 등 추가 정보를 담는 메타데이터(`metadata`)를 포함하는 LlamaIndex의 기본 데이터 구조입니다.

## 2. `SimpleDirectoryReader`: 가장 기본적인 로더

`SimpleDirectoryReader`는 지정된 디렉터리 안의 파일들을 읽어오는 가장 간단하고 널리 사용되는 로더입니다. 다양한 파일 형식을 자동으로 인식하고 처리합니다.

### 2.1. 기본 사용법
```python
from llama_index.core import SimpleDirectoryReader

# "data" 폴더 안의 모든 지원되는 파일(.txt, .pdf, .md 등)을 로드
reader = SimpleDirectoryReader(input_dir="./data/")
documents = reader.load_data()

# 로드된 첫 번째 문서의 내용과 메타데이터 확인
print(documents[0].text)
print(documents[0].metadata)
```

### 2.2. 특정 파일 로딩 및 재귀 설정
특정 파일만 로드하거나, 하위 디렉터리까지 모두 검색할지 여부를 설정할 수 있습니다.

```python
# 특정 파일만 로드
reader = SimpleDirectoryReader(
    input_files=["./data/essay.pdf", "./data/notes.txt"]
)

# 하위 폴더는 검색하지 않도록 설정
reader = SimpleDirectoryReader(
    input_dir="./data/",
    recursive=False
)
```

## 3. 웹페이지 데이터 로딩

웹페이지의 내용을 직접 불러와 RAG의 소스로 활용할 수 있습니다. 이를 위해서는 `beautifulsoup4`와 `llama-index-readers-web` 라이브러리가 필요합니다.

```bash
pip install beautifulsoup4 llama-index-readers-web
```

```python
from llama_index.readers.web import SimpleWebPageReader

# 로드하고 싶은 URL 리스트
urls = ["https://www.theverge.com/2024/2/15/24074223/google-gemini-1-5-pro-llm-ai-model-multimodal-context-window"]

# 웹페이지 로더 초기화 및 데이터 로드
loader = SimpleWebPageReader(html_to_text=True) # html_to_text=True로 순수 텍스트만 추출
documents = loader.load_data(urls)

print(documents[0].text)
```

## 4. LlamaHub: 데이터 커넥터의 보고

LlamaIndex는 PDF, 웹페이지만이 아니라 Notion, Slack, Discord, Google Docs, SQL 데이터베이스 등 수백 가지가 넘는 데이터 소스를 지원합니다. 이러한 모든 데이터 커넥터들은 **LlamaHub**라는 온라인 저장소에 공개되어 있으며, 누구나 쉽게 찾아보고 설치하여 사용할 수 있습니다.

**예시: Notion 페이지 로딩**

1.  필요한 라이브러리 설치:
    ```bash
    pip install llama-index-readers-notion
    ```
2.  Notion API 통합 토큰과 접근을 원하는 페이지 ID를 준비합니다.
3.  코드로 로더를 초기화하고 데이터를 불러옵니다.

    ```python
    from llama_index.readers.notion import NotionPageReader
    import os

    # 환경 변수 등으로 Notion 통합 토큰 설정
    integration_token = os.getenv("NOTION_INTEGRATION_TOKEN")
    page_ids = ["your-notion-page-id"]

    reader = NotionPageReader(integration_token=integration_token)
    documents = reader.load_data(page_ids=page_ids)
    ```

이처럼 LlamaHub를 활용하면, 우리가 상상할 수 있는 거의 모든 종류의 데이터를 LlamaIndex 파이프라인의 입력으로 손쉽게 가져올 수 있습니다.
