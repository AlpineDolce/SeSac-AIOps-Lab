## 1. LlamaIndex 에이전트의 철학

### 1.1. RAG 중심의 에이전트
LangChain의 에이전트가 범용적인 도구 사용과 복잡한 작업 계획에 중점을 둔다면, LlamaIndex의 에이전트는 **RAG를 핵심 능력으로 갖춘 에이전트**를 만드는 데 더 특화되어 있습니다. 즉, LlamaIndex 에이전트의 주된 임무는 구조화되거나 구조화되지 않은 방대한 데이터에 대해 깊이 있는 추론과 검색을 수행하는 것입니다.

LlamaIndex 에이전트는 LLM이 **'무엇을 모르는지'** 를 스스로 판단하고, 그 모르는 정보를 얻기 위해 자신의 RAG 도구(쿼리 엔진)를 사용하여 지식을 보충한 뒤, 최종 답변을 생성하는 방식으로 작동합니다.

## 2. 에이전트 구축의 핵심: `QueryEngineTool`

LlamaIndex 에이전트를 만드는 가장 기본적인 방법은 우리가 만든 `쿼리 엔진`을 `QueryEngineTool`로 감싸서 에이전트가 사용할 수 있는 도구로 만들어주는 것입니다.

- **`QueryEngineTool`**: LlamaIndex의 쿼리 엔진을 에이전트가 이해하고 사용할 수 있는 표준화된 '도구' 인터페이스로 변환합니다.
- **`ToolMetadata`**: 이 도구가 어떤 역할을 하는지, 어떤 종류의 질문에 답변할 수 있는지를 LLM에게 알려주는 설명서 역할을 합니다. 이 설명을 얼마나 잘 작성하는지가 에이전트의 성능에 직접적인 영향을 미칩니다.

## 3. 간단한 RAG 에이전트 구축 실습

### 3.1. 시나리오 설정
- **도구 1**: `pg_essay.txt` 문서에 대해 질문할 수 있는 RAG 쿼리 엔진
- **도구 2**: 간단한 덧셈을 수행하는 함수 도구
- **목표**: 사용자의 질문을 보고, 에세이에 대한 질문인지, 덧셈인지 판단하여 적절한 도구를 사용하는 에이전트 만들기

### 3.2. 도구 준비

```python
from llama_index.core.tools import FunctionTool, QueryEngineTool, ToolMetadata
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

# 1. RAG 도구 준비
pg_docs = SimpleDirectoryReader(input_files=["pg_essay.txt"]).load_data()
pg_index = VectorStoreIndex.from_documents(pg_docs)
pg_engine = pg_index.as_query_engine()

rag_tool = QueryEngineTool(
    query_engine=pg_engine,
    metadata=ToolMetadata(
        name="pg_essay_rag_tool",
        description="폴 그레이엄의 에세이에 대한 질문에 답변할 때 사용합니다."
    )
)

# 2. 함수 도구 준비
def add(a: int, b: int) -> int:
    """두 개의 정수를 더합니다."""
    return a + b

add_tool = FunctionTool.from_defaults(fn=add)

# 3. 도구 리스트 생성
tools = [rag_tool, add_tool]
```

### 3.3. 에이전트 생성 및 실행

LlamaIndex는 OpenAI의 함수 호출(Function Calling) 기능에 최적화된 `OpenAIAgent`를 제공합니다.

```bash
pip install llama-index-agent-openai
```

```python
from llama_index.agent.openai import OpenAIAgent
from dotenv import load_dotenv

load_dotenv()

# 에이전트 생성
agent = OpenAIAgent.from_tools(tools, verbose=True)

# 실행 1: RAG 질문
response1 = agent.chat("폴 그레이엄은 어린 시절에 무엇을 했나요?")
# verbose 로그: LLM이 pg_essay_rag_tool을 선택하고 실행하는 것을 보여줌
print(response1)

# 실행 2: 함수 호출 질문
response2 = agent.chat("123 + 456은 얼마인가요?")
# verbose 로그: LLM이 add_tool을 선택하고 a=123, b=456으로 실행하는 것을 보여줌
print(response2)
```

이처럼 LlamaIndex 에이전트는 강력한 RAG 기능을 핵심 도구로 장착하고, 필요에 따라 다른 외부 도구와 협력하여 복잡한 문제를 해결하는 지능형 시스템을 구축하는 기반을 제공합니다.
