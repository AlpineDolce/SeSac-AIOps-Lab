## 1. 개발 환경 준비

### 1.1. Python 및 가상 환경
LlamaIndex는 Python 3.8 이상을 권장합니다. 프로젝트별 의존성 관리를 위해 가상 환경을 사용하는 것이 좋습니다.

```bash
# 'llamaindex-env'라는 이름의 가상 환경 생성
python -m venv llamaindex-env

# 가상 환경 활성화 (Windows)
llamaindex-env\Scripts\activate

# 가상 환경 활성화 (macOS/Linux)
source llamaindex-env/bin/activate
```

## 2. LlamaIndex 설치

### 2.1. 기본 설치
LlamaIndex의 핵심 패키지는 `llama-index` 입니다.

```bash
pip install llama-index
```

### 2.2. OpenAI 연동 설치
LlamaIndex는 다양한 LLM 및 임베딩 모델과 연동할 수 있습니다. 가장 일반적으로 사용되는 OpenAI 모델과의 연동을 위해 관련 라이브러리를 함께 설치합니다.

```bash
pip install llama-index-llms-openai llama-index-embeddings-openai
```
API 키 관리를 위해 `python-dotenv`도 설치합니다.
```bash
pip install python-dotenv
```

## 3. API 키 설정

### 3.1. OpenAI API 키 발급
LLM과 임베딩 모델을 사용하기 위해 OpenAI의 API 키가 필요합니다.
1.  [OpenAI 웹사이트](https://platform.openai.com/)에 접속하여 로그인합니다.
2.  'API keys' 메뉴에서 새로운 시크릿 키를 생성하고 안전한 곳에 복사합니다.

### 3.2. 환경 변수로 키 관리
API 키를 코드에 직접 노출하지 않기 위해 `.env` 파일을 사용합니다.

1.  프로젝트 루트에 `.env` 파일을 생성합니다.
2.  파일 안에 API 키를 저장합니다.

```
OPENAI_API_KEY="sk-..."
```

## 4. 설정 검증
LlamaIndex가 API 키를 제대로 인식하는지 간단한 코드로 확인합니다.

`verify_llama_setup.py`
```python
import os
from dotenv import load_dotenv

# .env 파일 로드
load_dotenv()

# 환경 변수에서 API 키 읽기
# LlamaIndex는 기본적으로 `OPENAI_API_KEY` 환경 변수를 자동으로 읽어 사용합니다.
api_key = os.getenv("OPENAI_API_KEY")

if api_key and api_key.startswith("sk-"):
    print("환경 설정이 성공적으로 완료되었습니다.")
    print("OpenAI API 키가 성공적으로 로드되었습니다.")
else:
    print("오류: OPENAI_API_KEY를 찾을 수 없거나 형식이 올바르지 않습니다. .env 파일을 확인하세요.")

```
위 코드를 실행하여 성공 메시지가 출력되면, LlamaIndex를 사용할 모든 준비가 완료된 것입니다.
