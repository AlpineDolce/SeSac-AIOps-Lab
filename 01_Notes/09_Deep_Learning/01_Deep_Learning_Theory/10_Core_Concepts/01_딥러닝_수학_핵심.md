## 1. 선형대수 (Linear Algebra)

선형대수는 딥러닝에서 데이터를 표현하고 변환하는 데 필수적인 수학 분야입니다. 벡터와 행렬 연산을 통해 대규모 데이터를 효율적으로 처리할 수 있습니다.

### 1.1. 스칼라, 벡터, 행렬, 텐서

*   **스칼라 (Scalar)**: 하나의 단일 값 (예: 5, 3.14)
*   **벡터 (Vector)**: 크기와 방향을 가지는 값들의 배열 (예: `[1, 2, 3]`). 1차원 배열로 표현됩니다.
*   **행렬 (Matrix)**: 스칼라 값들을 직사각형 형태로 배열한 것 (예: `[[1, 2], [3, 4]]`). 2차원 배열로 표현됩니다.
*   **텐서 (Tensor)**: 스칼라, 벡터, 행렬을 일반화한 개념입니다. 0차원 텐서(스칼라), 1차원 텐서(벡터), 2차원 텐서(행렬) 등으로 확장될 수 있으며, 딥러닝에서는 고차원 데이터를 표현하는 데 사용됩니다.

### 1.2. 행렬 연산 (덧셈, 곱셈, 전치)

*   **덧셈 (Addition)**: 같은 크기의 행렬끼리 각 원소별로 더합니다.
    ```
    A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]]
    A + B = [[6, 8], [10, 12]]
    ```
*   **곱셈 (Multiplication)**: 행렬 곱셈은 앞 행렬의 열의 수와 뒤 행렬의 행의 수가 같아야 합니다. 결과 행렬의 (i, j) 원소는 앞 행렬의 i번째 행과 뒤 행렬의 j번째 열의 내적입니다.
    ```
    A = [[1, 2], [3, 4]], B = [[5, 6], [7, 8]]
    A * B = [[1*5+2*7, 1*6+2*8], [3*5+4*7, 3*6+4*8]] = [[19, 22], [43, 50]]
    ```
*   **전치 (Transpose)**: 행렬의 행과 열을 바꿉니다. `A^T`로 표기합니다.
    ```
    A = [[1, 2], [3, 4]]
    A^T = [[1, 3], [2, 4]]
    ```

### 1.3. 항등 행렬, 역행렬, 대각 행렬

*   **항등 행렬 (Identity Matrix, I)**: 주대각선 원소가 모두 1이고 나머지 원소는 모두 0인 정방 행렬입니다. 어떤 행렬에 항등 행렬을 곱해도 자기 자신이 됩니다. `AI = IA = A`
*   **역행렬 (Inverse Matrix, A^-1)**: 정방 행렬 A에 대해 `AA^-1 = A^-1A = I`를 만족하는 행렬 A^-1입니다. 역행렬이 존재하지 않는 행렬도 있습니다.
*   **대각 행렬 (Diagonal Matrix)**: 주대각선 원소를 제외한 모든 원소가 0인 행렬입니다.

### 1.4. 벡터의 내적과 외적

*   **내적 (Dot Product)**: 두 벡터의 각 원소를 곱한 후 모두 더한 스칼라 값입니다. 두 벡터의 유사도를 측정하는 데 사용됩니다. `a · b = |a||b|cosθ`
*   **외적 (Cross Product)**: 3차원 벡터에만 정의되며, 두 벡터에 모두 수직인 새로운 벡터를 생성합니다. (딥러닝에서는 내적이 더 중요하게 사용됩니다.)

### 1.5. 고유값(Eigenvalue)과 고유벡터(Eigenvector)

정방 행렬 A에 대해 `Av = λv`를 만족하는 0이 아닌 벡터 v를 고유벡터, 스칼라 λ를 고유값이라고 합니다. 고유값 분해는 데이터의 주요 성분을 분석하거나 차원 축소(PCA) 등에 활용됩니다.

## 2. 미적분학 (Calculus)

미적분학은 딥러닝 모델이 학습하는 과정, 즉 손실 함수를 최소화하기 위해 파라미터를 업데이트하는 경사 하강법의 핵심 원리입니다.

### 2.1. 함수와 극한

*   **함수 (Function)**: 입력에 따라 출력이 결정되는 관계입니다. `y = f(x)`
*   **극한 (Limit)**: 변수가 특정 값에 한없이 가까워질 때 함수의 값이 가까워지는 값입니다. 미분의 정의에 사용됩니다.

### 2.2. 미분 (Derivative)

함수의 특정 지점에서의 **변화율(기울기)**을 나타냅니다. `f'(x) = dy/dx`로 표기하며, 함수의 접선의 기울기를 의미합니다. 딥러닝에서는 손실 함수를 최소화하기 위해 각 파라미터가 손실에 얼마나 영향을 미치는지(기울기)를 계산하는 데 사용됩니다.

### 2.3. 편미분 (Partial Derivative)과 경사(Gradient)

*   **편미분**: 다변수 함수에서 특정 변수 하나만을 변화시키고 나머지 변수들은 상수로 간주하여 미분하는 것입니다.
*   **경사 (Gradient)**: 다변수 함수에서 각 변수에 대한 편미분 값들을 벡터로 모아놓은 것입니다. 경사 벡터는 함수 값이 가장 빠르게 증가하는 방향을 가리키며, 경사 하강법에서는 이 경사 벡터의 반대 방향으로 이동하여 손실을 줄입니다.
    ```
    ∇f(x, y) = [∂f/∂x, ∂f/∂y]
    ```

### 2.4. 연쇄 법칙 (Chain Rule)

합성 함수의 미분을 계산하는 규칙입니다. 딥러닝의 역전파 알고리즘은 이 연쇄 법칙을 반복적으로 적용하여 각 레이어의 가중치에 대한 손실 함수의 기울기를 계산합니다.

```

```

## 3. 확률 및 통계 (Probability and Statistics)

확률 및 통계는 딥러닝 모델의 불확실성을 다루고, 데이터를 분석하며, 모델의 성능을 평가하는 데 중요한 역할을 합니다.

### 3.1. 확률의 기본 개념

*   **확률 (Probability)**: 어떤 사건이 발생할 가능성을 0과 1 사이의 숫자로 나타낸 것입니다.
*   **표본 공간 (Sample Space)**: 발생 가능한 모든 결과의 집합.
*   **사건 (Event)**: 표본 공간의 부분집합.

### 3.2. 확률 변수와 확률 분포 (이산/연속)

*   **확률 변수 (Random Variable)**: 무작위 실험의 결과를 숫자로 나타낸 변수입니다.
*   **확률 분포 (Probability Distribution)**: 확률 변수가 가질 수 있는 모든 값과 그 값들이 나타날 확률을 나타내는 함수입니다.
    *   **이산 확률 분포 (Discrete Probability Distribution)**: 확률 변수가 셀 수 있는 값을 가질 때 (예: 베르누이 분포, 이항 분포).
    *   **연속 확률 분포 (Continuous Probability Distribution)**: 확률 변수가 연속적인 값을 가질 때 (예: 정규 분포, 균등 분포).

### 3.3. 기댓값(Expectation)과 분산(Variance)

*   **기댓값 (Expectation, E[X])**: 확률 변수가 가질 수 있는 값들의 가중 평균입니다. 확률 변수의 '평균'을 나타냅니다.
*   **분산 (Variance, Var(X))**: 확률 변수가 기댓값으로부터 얼마나 퍼져 있는지를 나타내는 척도입니다. 표준편차는 분산의 양의 제곱근입니다.

### 3.4. 공분산(Covariance)과 상관계수(Correlation Coefficient)

*   **공분산**: 두 확률 변수가 함께 변하는 정도를 나타냅니다. 양수이면 같은 방향, 음수이면 반대 방향으로 변하는 경향이 있습니다.
*   **상관계수**: 공분산을 표준화하여 -1과 1 사이의 값으로 나타낸 것입니다. 두 변수 간의 선형 관계의 강도와 방향을 나타냅니다.

### 3.5. 조건부 확률과 베이즈 정리

*   **조건부 확률 (Conditional Probability)**: 어떤 사건이 발생했다는 조건 하에 다른 사건이 발생할 확률입니다. `P(A|B) = P(A ∩ B) / P(B)`
*   **베이즈 정리 (Bayes' Theorem)**: 조건부 확률을 이용하여 사전 확률(Prior Probability)을 사후 확률(Posterior Probability)로 업데이트하는 방법입니다. 딥러닝에서는 베이지안 신경망 등에서 활용됩니다.

### 3.6. 주요 확률 분포 (정규 분포, 베르누이 분포 등)

*   **정규 분포 (Normal Distribution)**: 자연 현상에서 가장 흔하게 나타나는 종 모양의 대칭적인 분포입니다. 딥러닝에서 가중치 초기화나 노이즈 모델링 등에 사용됩니다.
*   **베르누이 분포 (Bernoulli Distribution)**: 결과가 두 가지(성공/실패)뿐인 시행의 확률 분포입니다.
*   **이항 분포 (Binomial Distribution)**: 베르누이 시행을 여러 번 반복했을 때의 성공 횟수에 대한 확률 분포입니다.
*   **다항 분포 (Multinomial Distribution)**: 여러 범주 중 하나를 선택하는 시행의 확률 분포입니다. 분류 문제의 출력층에서 소프트맥스(softmax) 함수와 함께 사용됩니다.
