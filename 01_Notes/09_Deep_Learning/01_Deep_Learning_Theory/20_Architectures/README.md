# 딥러닝 아키텍처: 모델의 구조와 설계

**다양한 딥러닝 태스크에 최적화된 모델 아키텍처의 구조와 작동 방식**

이 섹션은 이미지 처리, 시퀀스 데이터 처리, 새로운 데이터 생성 등 다양한 문제 해결을 위한 딥러닝 모델 아키텍처들을 다룹니다. 합성곱 신경망(CNN), 순환 신경망(RNN, LSTM, GRU), 어텐션 메커니즘과 트랜스포머, 생성 모델(VAE, GAN), 비지도 학습, 자기지도 학습, 강화 학습, 그래프 신경망(GNN) 등 주요 아키텍처의 원리와 특징을 학습합니다.

---

### 주요 내용:

- [**08_합성곱_신경망_CNN.md**](./08_합성곱_신경망_CNN.md): 이미지 처리에 뛰어난 CNN의 구조(Convolution, Pooling)와 주요 아키텍처(LeNet, AlexNet, VGG, ResNet 등).
- [**09_순환_신경망_RNN_LSTM_GRU.md**](./09_순환_신경망_RNN_LSTM_GRU.md): 시퀀스 데이터 처리를 위한 RNN의 구조와 장기 의존성 문제를 해결하는 LSTM, GRU.
- [**10_어텐션_메커니즘과_트랜스포머.md**](./10_어텐션_메커니즘과_트랜스포머.md): 최신 자연어 처리의 핵심인 어텐션 메커니즘과 트랜스포머 아키텍처.
- [**11_생성_모델_VAE_GAN.md**](./11_생성_모델_VAE_GAN.md): 데이터 분포를 학습하여 새로운 데이터를 생성하는 VAE, GAN과 같은 생성 모델의 원리.
- [**12_비지도_학습_자기지도_학습.md**](./12_비지도_학습_자기지도_학습.md): 레이블 없는 데이터를 활용하는 비지도 학습과 자기지도 학습(Self-supervised Learning)의 개념과 최신 동향.
- [**13_강화_학습_기초.md**](./13_강화_학습_기초.md): 순차적 의사결정 문제 해결을 위한 강화학습의 기본 개념(에이전트, 환경, 보상)과 주요 알고리즘.
- [**14_그래프_신경망_GNN_기초.md**](./14_그래프_신경망_GNN_기초.md): 관계형 데이터 처리를 위한 그래프 신경망(GNN)의 기본 원리와 활용 분야.
