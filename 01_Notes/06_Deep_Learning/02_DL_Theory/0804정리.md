## 1. Google Colab이란?

**Colaboratory**(줄여서 'Colab')는 Google에서 제공하는 클라우드 기반의 **Jupyter Notebook** 개발 환경입니다. Jupyter Notebook은 코드, 텍스트, 이미지, 차트 등을 하나의 문서에 담아 상호작용적으로 프로그래밍할 수 있는 매우 인기 있는 도구이며, Colab은 이 Jupyter Notebook을 별도의 설치나 구성 없이 웹 브라우저만으로 사용할 수 있게 해줍니다. 특히 딥러닝과 머신러닝 연구 및 개발에 강력한 기능을 제공합니다.

- **정식 명칭**: Colaboratory
- **접속 링크**: [https://colab.research.google.com/](https://colab.research.google.com/)
- **필수 사항**: 개인 Google 계정 (파일은 Google Drive에 저장됨)

## 2. 딥러닝에 Google Colab을 사용해야 하는 이유

로컬 컴퓨터의 사양에 구애받지 않고 복잡하고 큰 규모의 딥러닝 모델을 효율적으로 학습하고 실험할 수 있다는 점에서 Colab은 압도적인 우위를 가집니다.

### 2.1. 무료로 제공되는 고성능 하드웨어 (GPU/TPU)

- **서버 기반 GPU 활용**: 딥러닝 모델 학습에는 대규모 행렬 연산이 필수적이며, 이는 CPU보다 GPU(Graphics Processing Unit)에서 훨씬 빠르게 처리됩니다. Colab은 **NVIDIA Tesla K80, T4, P100** 등 고성능 GPU를 무료로 제공하여, 로컬에 고가의 GPU가 없어도 누구나 딥러닝 모델을 학습시킬 수 있습니다.
  - **GPU 확인 코드**: Colab 세션에 어떤 GPU가 할당되었는지 다음 명령어로 확인할 수 있습니다.
    ```python
    !nvidia-smi
    ```
- **대규모 모델 처리**: 최신 딥러닝 모델(e.g., GPT, BERT)은 수십억 개의 파라미터를 가지며, 이를 학습하려면 수십 GB의 메모리가 필요합니다. 일반적인 로컬 컴퓨터에서는 메모리 부족(Out of Memory) 오류가 발생하기 쉽지만, Colab의 GPU는 대용량 VRAM을 갖추고 있어 대규모 모델도 안정적으로 처리할 수 있습니다.
- **TPU(Tensor Processing Unit) 지원**: Google이 딥러닝 연산에 특화하여 개발한 하드웨어인 TPU도 사용할 수 있습니다. 특정 TensorFlow 모델의 경우, TPU를 사용하면 GPU보다 훨씬 빠른 학습 속도를 경험할 수 있습니다.

### 2.2. 제로 구성(Zero Configuration) 환경

- **설치 없는 개발 환경**: Colab은 웹 브라우저에서 바로 실행되므로, Python, Jupyter Notebook, 각종 드라이버(e.g., CUDA) 등을 직접 설치하고 설정하는 복잡한 과정이 필요 없습니다.
- **주요 라이브러리 사전 설치**: `TensorFlow`, `PyTorch`, `Keras`, `Scikit-learn`, `Pandas`, `NumPy` 등 데이터 분석과 딥러닝에 필수적인 대부분의 라이브러리가 이미 설치되어 있어, 환경 설정에 드는 시간을 절약하고 바로 코드 작성에 집중할 수 있습니다.
  - **설치된 라이브러리 확인**:
    ```python
    !pip list
    ```
  - **새로운 라이브러리 설치**: 필요한 라이브러리가 없는 경우, `pip`를 이용해 간단히 설치할 수 있습니다.
    ```python
    !pip install [라이브러리 이름]
    ```

### 2.3. 협업 및 공유의 용이성

- **간편한 공유**: Colab 노트북은 Google Docs처럼 우측 상단의 **'공유'** 버튼을 눌러 링크 하나로 쉽게 다른 사람과 공유할 수 있습니다. 공유 시 '보기', '댓글 작성', '수정' 권한을 부여하여 효율적인 협업이 가능합니다.
- **GitHub 연동**: GitHub에 있는 Jupyter Notebook 파일을 직접 열거나, 작업한 Colab 노트북을 GitHub 리포지토리로 저장하는 기능(commit/push)을 지원하여 버전 관리가 용이합니다.
  - **GitHub에서 노트북 열기**: Colab 시작 화면의 'GitHub' 탭에 URL을 붙여넣거나, `https://colab.research.google.com/github/` 뒤에 GitHub 경로를 추가하여 직접 열 수 있습니다.
  - **GitHub에 사본 저장**: '파일' > 'GitHub에 사본 저장' 메뉴를 통해 현재 노트북을 원하는 리포지토리에 저장할 수 있습니다.

### 2.4. Google 생태계와의 연동

- **Google Drive 통합**: Colab 노트북은 사용자의 Google Drive에 자동으로 저장됩니다. 대용량 데이터셋이나 학습된 모델 가중치 파일 등을 Google Drive에 업로드하고, Colab에서 직접 마운트하여 사용할 수 있어 데이터 관리가 편리합니다.
  - **Google Drive 마운트 코드**: 다음 코드를 실행하면 인증 절차를 거쳐 Colab 노트북에서 자신의 Google Drive 파일에 접근할 수 있습니다.
    ```python
    from google.colab import drive
    drive.mount('/content/drive')

    # 마운트 후에는 '/content/drive/MyDrive/' 경로를 통해 파일에 접근할 수 있습니다.
    # 예: !ls /content/drive/MyDrive/
    ```

## 3. Colab 요금제

기본적으로 무료로 강력한 기능을 제공하지만, 더 긴 실행 시간, 더 빠른 GPU, 더 많은 시스템 메모리가 필요한 사용자를 위해 유료 플랜(Colab Pro, Pro+)도 제공합니다. 유료 플랜은 다음과 같은 추가적인 이점을 제공합니다.

- **더 긴 런타임**: 무료 버전은 최대 12시간 사용 후 초기화되지만, 유료 플랜은 더 긴 시간 동안 세션을 유지할 수 있습니다.
- **백그라운드 실행**: 브라우저 창을 닫아도 세션이 유지되어 장시간 소요되는 학습을 안정적으로 수행할 수 있습니다.
- **우선적인 고성능 GPU 접근**: T4, P100, V100 등 더 빠르고 좋은 성능의 GPU에 우선적으로 접근할 수 있습니다.
- **더 많은 시스템 메모리**: 더 많은 RAM을 할당받아 대규모 데이터셋을 메모리에 올리고 작업할 수 있습니다.

- **요금제 상세 정보**: [https://colab.research.google.com/signup](https://colab.research.google.com/signup)

## 4. 사용법 요약

1.  **Colab 접속**: [https://colab.research.google.com/](https://colab.research.google.com/) 에 접속하고 Google 계정으로 로그인합니다.
2.  **새 노트북 생성**: 시작 팝업창에서 '새 노트'를 클릭하거나, 메뉴에서 '파일' > '새 노트'를 선택하여 새로운 Colab 노트북을 생성합니다.
3.  **런타임 유형 변경 (GPU/TPU 설정)**: 메뉴에서 '런타임' > '런타임 유형 변경'을 선택합니다. '하드웨어 가속기' 드롭다운 메뉴에서 'GPU' 또는 'TPU'를 선택합니다. 이 과정을 거쳐야 고성능 하드웨어를 사용할 수 있습니다. (기본값은 'None'으로 CPU만 사용합니다.)
4.  **코드 실행**: 일반 Jupyter Notebook과 동일하게 셀(cell)에 코드를 입력하고 `Shift + Enter` 키로 실행합니다. 셀 좌측의 실행 버튼(▶)을 클릭하여 실행할 수도 있습니다.
5.  **파일 시스템 및 데이터 관리**: 좌측 사이드바의 폴더 아이콘을 클릭하여 현재 세션의 파일 시스템을 확인하고, 파일을 업로드하거나 Google Drive를 마운트하여 데이터를 관리합니다.
