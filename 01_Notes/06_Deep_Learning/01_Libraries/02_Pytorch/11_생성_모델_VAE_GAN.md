## 1. 생성 모델 (Generative Models) 개요

### 1.1. 생성 모델의 개념과 목적

**생성 모델(Generative Models)**은 주어진 훈련 데이터셋의 내재된 분포(Underlying Distribution)를 학습하여, 해당 분포로부터 새로운 데이터를 생성하는 것을 목표로 하는 딥러닝 모델입니다. 단순히 데이터를 분류하거나 예측하는 판별 모델(Discriminative Models)과 달리, 생성 모델은 데이터의 특징과 구조를 깊이 이해하고 이를 바탕으로 현실과 유사한 새로운 데이터를 만들어낼 수 있습니다.

*   **목적**: 새로운 이미지, 텍스트, 음성 등 생성, 데이터 증강, 이상 탐지, 특징 학습 등

### 1.2. 생성 모델의 종류

생성 모델은 크게 다음과 같은 종류로 나눌 수 있습니다.

*   **명시적 밀도 모델 (Explicit Density Models)**: 데이터의 확률 분포 `p(x)`를 명시적으로 모델링합니다. (예: PixelRNN, NADE)
*   **암시적 밀도 모델 (Implicit Density Models)**: 데이터의 확률 분포를 직접 모델링하지 않고, 해당 분포로부터 샘플을 생성하는 방법을 학습합니다. (예: GAN)
*   **잠재 변수 모델 (Latent Variable Models)**: 데이터 `x`가 잠재 변수 `z`로부터 생성된다고 가정하고, `p(x|z)`와 `p(z)`를 모델링합니다. (예: VAE)

## 2. 변분 오토인코더 (Variational AutoEncoder, VAE)

### 2.1. 오토인코더 (AutoEncoder) 복습

**오토인코더(AutoEncoder)**는 입력 데이터를 압축된 잠재 표현(Latent Representation)으로 인코딩한 후, 이 잠재 표현으로부터 원본 데이터를 재구성(Reconstruct)하는 비지도 학습 모델입니다. 인코더와 디코더로 구성됩니다.

*   **인코더**: 입력 `x`를 잠재 벡터 `z`로 매핑합니다.
*   **디코더**: 잠재 벡터 `z`를 원본 데이터 `x_reconstructed`로 재구성합니다.

오토인코더는 입력 데이터를 잘 압축하고 복원하는 방법을 학습하지만, 잠재 공간 `z`가 특정 분포를 따르도록 강제하지 않기 때문에, 잠재 공간의 특정 지점에서 샘플링하여 새로운 데이터를 생성하기 어렵다는 한계가 있습니다.

### 2.2. VAE의 등장 배경

**변분 오토인코더(Variational AutoEncoder, VAE)**는 오토인코더의 생성 능력 한계를 극복하기 위해 2013년 킹마(Kingma)와 웰링(Welling)이 제안했습니다. VAE는 잠재 공간 `z`가 특정 확률 분포(일반적으로 표준 정규 분포)를 따르도록 강제함으로써, 잠재 공간에서 의미 있는 샘플링을 통해 새로운 데이터를 생성할 수 있게 합니다.

### 2.3. VAE의 구조와 원리

VAE는 인코더와 디코더로 구성되지만, 인코더가 잠재 벡터 `z`를 직접 출력하는 대신, 잠재 변수 `z`의 **평균(μ)**과 **분산(σ)**을 출력합니다. 그리고 이 평균과 분산을 사용하여 잠재 공간에서 `z`를 샘플링합니다.

#### 2.3.1. 인코더 (Encoder)

*   입력 `x`를 받아 잠재 변수 `z`의 확률 분포를 나타내는 평균 `μ`와 분산 `σ`를 출력합니다. (정확히는 `log(σ^2)`를 출력하여 양수 값을 보장합니다.)

#### 2.3.2. 잠재 공간 (Latent Space)

*   인코더가 출력한 `μ`와 `σ`를 사용하여 **재매개변수화 트릭(Reparameterization Trick)**을 통해 잠재 변수 `z`를 샘플링합니다. `z = μ + σ * ε` (여기서 `ε`는 표준 정규 분포에서 샘플링된 노이즈입니다.) 이 트릭은 역전파가 가능하도록 하여 학습을 가능하게 합니다.

#### 2.3.3. 디코더 (Decoder)

*   샘플링된 잠재 변수 `z`를 입력으로 받아 원본 데이터 `x`와 유사한 `x_reconstructed`를 재구성합니다.

### 2.4. VAE의 손실 함수 (ELBO)

VAE의 손실 함수는 두 가지 항으로 구성됩니다.

1.  **재구성 손실 (Reconstruction Loss)**: 디코더가 원본 데이터를 얼마나 잘 재구성하는지 측정합니다. (예: MSE, Binary Cross-Entropy)
2.  **KL 발산 (KL Divergence) 손실**: 인코더가 출력한 잠재 변수 `z`의 분포가 우리가 원하는 사전 분포(Prior Distribution, 일반적으로 표준 정규 분포)와 얼마나 다른지 측정합니다. 이 항은 잠재 공간을 정규화하고, 잠재 공간에서 의미 있는 샘플링을 가능하게 합니다.

VAE는 이 두 손실의 합인 **ELBO(Evidence Lower Bound)**를 최대화(또는 음의 ELBO를 최소화)하는 방향으로 학습합니다.

### 2.5. VAE의 특징과 장점

*   **연속적이고 의미 있는 잠재 공간**: 잠재 공간이 정규 분포를 따르도록 학습되므로, 잠재 공간의 특정 지점에서 샘플링하여 새로운 데이터를 생성할 때 부드럽고 의미 있는 변화를 얻을 수 있습니다.
*   **안정적인 학습**: GAN에 비해 학습이 훨씬 안정적입니다.
*   **데이터 압축 및 노이즈 제거**: 오토인코더의 장점인 데이터 압축 및 노이즈 제거 능력도 가집니다.

## 3. 생성적 적대 신경망 (Generative Adversarial Network, GAN)

### 3.1. GAN의 등장 배경

**생성적 적대 신경망(Generative Adversarial Network, GAN)**은 2014년 이안 굿펠로우(Ian Goodfellow)가 제안한 혁신적인 생성 모델입니다. VAE와 달리 확률 분포를 명시적으로 모델링하지 않고, 두 개의 신경망이 서로 경쟁하며 학습하는 **적대적 학습(Adversarial Training)** 방식을 사용합니다.

### 3.2. GAN의 구조와 원리

GAN은 두 개의 신경망으로 구성됩니다.

#### 3.2.1. 생성자 (Generator, G)

*   무작위 노이즈(Random Noise) `z`를 입력으로 받아 실제 데이터와 유사한 **가짜 데이터(Fake Data)**를 생성합니다.
*   목표: 판별자를 속여 자신이 만든 가짜 데이터가 진짜라고 믿게 만드는 것입니다.

#### 3.2.2. 판별자 (Discriminator, D)

*   생성자가 만든 가짜 데이터와 실제 데이터(Real Data)를 입력으로 받아, 입력된 데이터가 **진짜인지 가짜인지 판별**합니다.
*   목표: 생성자가 만든 가짜 데이터를 정확히 가려내고, 진짜 데이터를 진짜라고 판별하는 것입니다.

#### 3.2.3. 적대적 학습 (Adversarial Training)

생성자와 판별자는 서로 적대적인 관계를 가지며 경쟁적으로 학습합니다. 이는 마치 위조지폐범(생성자)과 경찰(판별자)이 서로의 능력을 향상시키는 과정과 유사합니다.

*   생성자는 판별자를 속이기 위해 더 정교한 가짜 데이터를 만듭니다.
*   판별자는 생성자가 만든 가짜 데이터를 더 잘 구별하기 위해 판별 능력을 향상시킵니다.

이러한 경쟁을 통해 두 네트워크는 점진적으로 발전하며, 최종적으로 생성자는 실제 데이터와 거의 구별할 수 없는 가짜 데이터를 생성할 수 있게 됩니다.

### 3.3. GAN의 학습 과정

GAN은 미니맥스 게임(Minimax Game) 형태로 학습됩니다.

1.  **판별자 학습**: 생성자가 만든 가짜 데이터와 실제 데이터를 판별자가 입력받아, 진짜는 1, 가짜는 0으로 정확히 분류하도록 학습합니다.
2.  **생성자 학습**: 생성자는 판별자가 자신의 가짜 데이터를 진짜라고 판별하도록 속이는 방향으로 학습합니다. 이때 판별자의 피드백(기울기)을 사용하여 가짜 데이터를 더 실제처럼 만들도록 업데이트합니다.

이 두 단계를 번갈아 가며 학습을 진행합니다.

### 3.4. GAN의 특징과 장점

*   **매우 사실적인 이미지 생성**: 특히 이미지 생성 분야에서 놀랍도록 사실적인 결과물을 만들어냅니다.
*   **명시적인 확률 분포 모델링 불필요**: 데이터의 복잡한 확률 분포를 직접 모델링하지 않고도 샘플을 생성할 수 있습니다.

### 3.5. GAN의 한계와 발전 (WGAN, DCGAN 등)

*   **학습의 불안정성**: 생성자와 판별자의 균형을 맞추기 어렵고, 학습이 불안정하여 수렴하지 않거나 모드 붕괴(Mode Collapse) 현상(생성자가 제한된 종류의 데이터만 생성하는 현상)이 발생할 수 있습니다.
*   **평가 지표의 부재**: 생성된 이미지의 품질을 정량적으로 평가하기 어렵습니다.

이러한 한계를 극복하기 위해 WGAN(Wasserstein GAN), DCGAN(Deep Convolutional GAN), StyleGAN 등 다양한 GAN 변형 모델들이 연구되고 발전하고 있습니다.

## 4. VAE와 GAN 비교

| 특징         | VAE (Variational AutoEncoder)        | GAN (Generative Adversarial Network)     |
| :----------- | :----------------------------------- | :--------------------------------------- |
| **학습 방식** | 인코더-디코더 구조, 재구성 손실 + KL 발산 | 생성자-판별자 간의 적대적 학습           |
| **목표**     | 데이터 분포 학습 및 재구성, 잠재 공간 정규화 | 실제와 구별 불가능한 데이터 생성         |
| **생성 품질** | GAN보다 떨어질 수 있으나 안정적        | 매우 사실적이나 학습 불안정성 존재       |
| **잠재 공간** | 연속적이고 의미 있는 잠재 공간         | 잠재 공간의 의미 해석이 어려움           |
| **학습 안정성** | 비교적 안정적                        | 학습이 불안정하고 모드 붕괴 가능성       |
| **주요 활용** | 데이터 압축, 노이즈 제거, 데이터 생성 | 이미지 생성, 스타일 변환, 데이터 증강    |

다음 장에서는 레이블 없는 데이터를 활용하는 **비지도 학습과 자기지도 학습**에 대해 알아보겠습니다.
