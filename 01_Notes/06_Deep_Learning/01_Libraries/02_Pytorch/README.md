# PyTorch 핵심 개념 정리: 딥러닝 실무 가이드

이 가이드는 PyTorch를 활용한 딥러닝 모델 개발 및 배포에 필요한 핵심 개념과 실무 기술을 체계적으로 정리합니다. 데이터 전처리부터 모델 구축, 학습, 평가, 그리고 실제 서비스 환경에서의 배포까지 전 과정을 다루어, 독자가 PyTorch를 실제 프로젝트에 효과적으로 적용할 수 있도록 돕는 것을 목표로 합니다.

### Part 1: PyTorch 개요 및 기본 개념
- **학습 목표:** PyTorch의 기본 데이터 구조인 Tensor를 이해하고, 자동 미분 기능(`autograd`)을 활용하는 방법을 익힙니다. 또한, `nn.Module`, 옵티마이저, 손실 함수 등 PyTorch로 딥러닝 모델을 구성하는 핵심 요소들을 학습합니다.
- **왜 중요한가?:** PyTorch의 가장 기본적인 구성 요소와 작동 방식을 이해하는 것은 모든 딥러닝 모델 구현의 출발점입니다. Tensor와 자동 미분은 PyTorch의 핵심이며, 이를 통해 복잡한 모델도 효율적으로 구축하고 학습시킬 수 있습니다.

-   [**19_PyTorch_소개.md**](./19_PyTorch_소개.md): PyTorch의 정의, 특징, 설치 및 환경 설정을 이해합니다.

### Part 2: 모델 아키텍처 설계
- **학습 목표:** `nn.Sequential`, `nn.ModuleList`를 사용하여 표준적인 모델을 구성하고, `nn.Module`을 상속받아 특정 문제에 최적화된 맞춤형 모델(Custom Model)을 설계하는 방법을 배웁니다. 또한, `torchvision`의 사전 학습된 모델을 활용한 전이 학습(Transfer Learning) 기법을 익힙니다.
- **왜 중요한가?:** 실제 연구 및 개발 환경에서는 기존에 없는 새로운 구조의 모델을 설계해야 하는 경우가 많습니다. PyTorch의 유연한 모델 설계 방법을 익히면, 최신 논문의 모델을 직접 구현하거나 자신만의 독창적인 아이디어를 코드로 실현할 수 있습니다.

-   [**22_모델_아키텍처_Sequential_ModuleList.md**](./22_모델_아키텍처_Sequential_ModuleList.md): PyTorch의 `nn.Sequential`과 `nn.ModuleList`를 이용한 모델 구축 방법을 학습합니다.
-   [**23_모델_아키텍처_Custom_Module.md**](./23_모델_아키텍처_Custom_Module.md): `nn.Module`을 상속하여 Custom Model, Custom Layer, Custom Loss/Metric 구현 방법을 학습합니다.
-   [**24_TorchVision_모델_전이_학습.md**](./24_TorchVision_모델_전이_학습.md): `torchvision.models`를 활용한 사전 학습된 모델과 전이 학습 전략을 학습합니다.

### Part 4: 모델 학습, 평가 및 최적화
- **학습 목표:** 모델 학습 루프(Training Loop)를 직접 구현하고, 학습률 스케줄링, 조기 종료(Early Stopping)와 같은 고급 학습 기법을 적용하는 방법을 배웁니다. 또한, Multi-GPU를 활용한 분산 학습(DP/DDP)과 자동 혼합 정밀도(AMP)를 통해 학습 속도를 최적화하는 기술을 익힙니다.
- **왜 중요한가?:** 모델을 빠르고 안정적으로 학습시키는 것은 딥러닝 프로젝트의 성패를 가르는 중요한 요소입니다. 대규모 데이터셋과 복잡한 모델을 다룰 때, 학습 최적화 기술은 제한된 자원 내에서 최상의 결과를 얻기 위해 반드시 필요합니다.

-   [**29_모델_학습_루프_평가.md**](./29_모델_학습_루프_평가.md): 모델 학습 루프(Training Loop) 구현, `torch.no_grad()`를 이용한 평가 및 예측 방법을 학습합니다.
-   [**30_학습률_스케줄러_EarlyStopping.md**](./30_학습률_스케줄러_EarlyStopping.md): 다양한 학습률 스케줄러(`torch.optim.lr_scheduler`) 및 Early Stopping 구현 방법을 학습합니다.
-   [**31_Gradient_Accumulation_AMP.md**](./31_Gradient_Accumulation_AMP.md): Gradient Accumulation 및 자동 혼합 정밀도(AMP, `torch.cuda.amp`) 기법을 학습합니다.
-   [**32_분산_학습_DP_DDP.md**](./32_분산_학습_DP_DDP.md): Multi-GPU 학습 전략(DataParallel, DistributedDataParallel)을 학습합니다.

### Part 5: 모델 저장, 로드 및 하이퍼파라미터 튜닝
- **학습 목표:** 학습된 모델의 상태(`state_dict`)를 저장하고 불러오는 방법과, 학습 중간 과정을 기록하는 체크포인트(Checkpoint) 관리법을 익힙니다. Optuna와 같은 자동화된 도구를 사용하여 최적의 하이퍼파라미터를 탐색하는 방법을 학습합니다.
- **왜 중요한가?:** 모델의 재현성을 보장하고, 장시간의 학습 과정이 중단되었을 때 손실을 최소화하기 위해 모델 저장 및 로드는 필수적입니다. 또한, 하이퍼파라미터 튜닝은 모델의 성능을 극한까지 끌어올리는 핵심적인 과정입니다.

-   [**36_모델_저장_로드_StateDict_체크포인트.md**](./36_모델_저장_로드_StateDict_체크포인트.md): `state_dict`를 이용한 모델 저장 및 로드, 체크포인트 관리 방법을 학습합니다.
-   [**37_하이퍼파라미터_튜닝_Optuna.md**](./37_하이퍼파라미터_튜닝_Optuna.md): Optuna, Ray Tune 등 외부 라이브러리를 이용한 하이퍼파라미터 튜닝 방법을 학습합니다.
