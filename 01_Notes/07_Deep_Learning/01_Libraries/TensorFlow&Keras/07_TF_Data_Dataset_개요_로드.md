## 1. 데이터 파이프라인 구축 (`tf.data`)

대규모 데이터셋을 효율적으로 처리하고 모델 학습에 공급하는 것은 딥러닝 프로젝트의 성공에 매우 중요합니다. `tf.data` API는 유연하고 성능 최적화된 데이터 파이프라인을 구축하기 위한 강력한 도구입니다.

### 1.1. `tf.data.Dataset` 개요

`tf.data.Dataset`은 데이터셋을 나타내는 추상화된 클래스로, 데이터 로드, 변환, 배치 처리 등을 위한 일련의 연산(transformation)을 정의할 수 있게 합니다. 이는 데이터를 메모리에 한 번에 로드하지 않고 필요할 때마다 스트리밍 방식으로 처리하여 대용량 데이터셋 학습에 필수적입니다.

**실무 관점:**
*   **메모리 효율성:** 대용량 데이터셋을 다룰 때, 전체 데이터를 메모리에 로드하는 대신 `tf.data` 파이프라인을 통해 필요한 만큼만 데이터를 읽어와 처리함으로써 메모리 부족 문제를 해결합니다.
*   **성능 최적화:** 데이터 로드 및 전처리 연산을 병렬화하고 비동기적으로 수행하여 GPU/TPU가 데이터 입력을 기다리는 시간을 최소화합니다. 이는 학습 속도를 크게 향상시킵니다.
*   **재현성:** 데이터 파이프라인을 코드로 명확하게 정의함으로써, 데이터 전처리 과정의 재현성을 보장하고 MLOps 파이프라인에 쉽게 통합할 수 있습니다.
*   **유연성:** 다양한 데이터 소스(메모리, 파일, TFRecord, 데이터베이스 등)와 복잡한 전처리 로직을 유연하게 조합할 수 있습니다.

### 1.2. 데이터 로드 (from_tensor_slices, from_generator, TFRecord, TFDS)

`tf.data.Dataset`은 다양한 방식으로 데이터를 로드할 수 있는 기능을 제공합니다.

*   **`tf.data.Dataset.from_tensor_slices()`:**
    *   **개념:** 메모리에 이미 로드된 NumPy 배열이나 텐서로부터 데이터셋을 생성합니다. 각 슬라이스(행)가 하나의 샘플이 됩니다.
    *   **실무 관점:** 소규모 데이터셋이나 이미 메모리에 있는 데이터를 빠르게 학습에 사용하고자 할 때 유용합니다. 프로토타이핑 단계에서 자주 사용됩니다.

*   **`tf.data.Dataset.from_generator()`:**
    *   **개념:** Python 제너레이터 함수로부터 데이터셋을 생성합니다. 제너레이터는 데이터를 필요할 때마다 생성하여 반환하므로, 대용량 데이터를 효율적으로 처리할 수 있습니다.
    *   **실무 관점:** 사용자 정의 데이터 로딩 로직이 필요하거나, 데이터를 실시간으로 생성해야 할 때 (예: 이미지 증강 시) 유용합니다. 복잡한 파일 시스템 구조나 외부 API로부터 데이터를 읽어올 때 활용됩니다.

*   **TFRecord:**
    *   **개념:** TensorFlow에서 권장하는 대용량 데이터셋 저장 형식입니다. 직렬화된 바이너리 레코드로 구성되어 있어 효율적인 읽기/쓰기가 가능하며, 분산 학습 환경에서 특히 유리합니다.
    *   **실무 관점:** 이미지, 오디오, 텍스트 등 다양한 형태의 데이터를 하나의 파일에 효율적으로 저장하고 로드할 수 있습니다. 대규모 이미지 데이터셋이나 복잡한 특징을 가진 데이터셋을 학습할 때 필수적으로 고려됩니다. `tf.Example` 프로토콜 버퍼를 사용하여 데이터를 구조화합니다.

*   **TFDS (TensorFlow Datasets):**
    *   **개념:** 널리 사용되는 공개 데이터셋(ImageNet, COCO, MNIST 등)을 `tf.data.Dataset` 형식으로 쉽게 로드할 수 있도록 미리 구현된 라이브러리입니다. 데이터 다운로드, 전처리, 분할 등이 자동으로 처리됩니다.
    *   **실무 관점:** 연구 및 개발 초기 단계에서 표준 데이터셋을 사용하여 모델을 빠르게 테스트하거나 벤치마킹할 때 매우 편리합니다. 데이터셋마다 고유한 전처리 로직을 직접 구현할 필요가 없어 생산성을 높입니다.
