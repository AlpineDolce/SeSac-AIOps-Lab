## 1. 트리 (Tree)

트리는 노드와 간선으로 이루어진 비선형 자료구조로, 사이클이 없는 연결 그래프의 한 종류입니다. 데이터를 계층적인 구조로 표현하며, 파일 시스템, 조직도, 데이터베이스 인덱스 등 다양한 분야에서 활용됩니다.

### 1.1. 트리의 개념과 기본 용어

*   **시각화 예시:**
    ```
          A (Root, Depth 0)
         / \
    (Edge)  (Edge)
       /     \
      B       C (Siblings)
     / \       \
    D   E       F (Leaf)
    (Subtree of B)
    ```
*   **노드 (Node):** 트리를 구성하는 기본 요소. 데이터를 저장합니다. (예: A, B, C, D, E, F)
*   **루트 노드 (Root Node):** 트리의 가장 상위에 있는 노드. 부모가 없습니다. (예: A)
*   **간선 (Edge):** 노드들을 연결하는 선. 부모-자식 관계를 나타냅니다.
*   **부모 노드 (Parent Node):** 특정 노드의 바로 위에 연결된 노드. (예: B는 D와 E의 부모)
*   **자식 노드 (Child Node):** 특정 노드의 바로 아래에 연결된 노드. (예: B와 C는 A의 자식)
*   **형제 노드 (Sibling Node):** 같은 부모를 가지는 노드들. (예: B와 C)
*   **조상 (Ancestor):** 특정 노드에서 루트까지의 경로에 있는 모든 노드. (예: D의 조상은 B와 A)
*   **자손 (Descendant):** 특정 노드를 루트로 하는 서브트리에 속한 모든 노드. (예: B의 자손은 D와 E)
*   **리프 노드 (Leaf Node):** 자식이 없는 노드 (단말 노드). (예: D, E, F)
*   **내부 노드 (Internal Node):** 리프 노드가 아닌 노드. 하나 이상의 자식을 가집니다. (예: A, B, C)
*   **경로 (Path):** 한 노드에서 다른 노드까지 간선들을 따라 이동하는 순서.
*   **깊이 (Depth):** 루트 노드로부터 특정 노드까지의 간선 수. 루트 노드의 깊이는 0입니다. (예: C의 깊이는 1)
*   **높이 (Height):** 특정 노드로부터 가장 먼 리프 노드까지의 간선 수. 트리의 높이는 루트 노드의 높이와 같습니다. (예: 위 트리의 높이는 2)
*   **차수 (Degree):** 노드가 가지는 자식 노드의 수. 트리의 차수는 모든 노드의 차수 중 가장 큰 값입니다. (예: A의 차수는 2)
*   **서브트리 (Subtree):** 트리의 한 노드와 그 노드의 모든 자손들로 이루어진 트리. (예: B, D, E는 A의 왼쪽 서브트리를 구성)
*   **숲 (Forest):** 서로 분리된 트리들의 집합. 트리의 루트를 제거하면 숲이 생성됩니다.

### 1.1.1. 트리의 주요 특징

트리는 다음과 같은 중요한 수학적 특징을 가집니다.

*   **노드와 간선의 관계:** `N`개의 노드를 가진 트리는 항상 `N-1`개의 간선을 가집니다.
*   **경로의 유일성:** 임의의 두 노드 사이에는 유일한 경로가 존재합니다.
*   **사이클 부재:** 트리에 어떤 두 노드를 잇는 간선을 추가하면 반드시 하나의 사이클이 만들어집니다.
*   **연결성:** 트리의 어떤 간선을 제거하면, 트리는 두 개의 분리된 트리(숲)로 나뉩니다.


### 1.2. 이진 트리 (Binary Tree)

이진 트리는 각 노드가 최대 두 개의 자식 노드(왼쪽 자식, 오른쪽 자식)를 가지는 트리입니다. 자식 노드는 순서가 있으며, 왼쪽 자식과 오른쪽 자식은 구별됩니다. 이는 데이터의 계층적 구조를 표현하고, 효율적인 탐색 및 정렬 알고리즘의 기반이 됩니다.

### 1.2.1. 이진 트리의 종류

*   **정 이진 트리 (Full Binary Tree):** 모든 노드가 0개 또는 2개의 자식 노드를 가집니다.
    ```
          A
         / \
        B   C
           / \
          D   E
    ```
*   **포화 이진 트리 (Perfect Binary Tree):** 모든 내부 노드가 두 개의 자식을 가지고, 모든 리프 노드가 같은 깊이에 있습니다. 가장 균형 잡힌 형태로, 높이가 `h`일 때 노드의 개수는 `2^(h+1) - 1`개입니다.
    ```
          A
         / \
        B   C
       / \ / \
      D  E F  G
    ```
*   **완전 이진 트리 (Complete Binary Tree):** 마지막 레벨을 제외한 모든 레벨이 완전히 채워져 있고, 마지막 레벨은 왼쪽부터 채워져 있습니다. **힙(Heap) 자료구조** 구현에 사용되어 배열로 표현하기 용이합니다.
    ```
          A
         / \
        B   C
       / \ / 
      D  E F
    ```
*   **편향 이진 트리 (Skewed Binary Tree):** 모든 노드가 한쪽 방향(왼쪽 또는 오른쪽)으로만 자식을 가지는 트리입니다. 이 경우 트리의 높이가 노드 수에 비례하여 `O(n)`이 되며, 탐색 성능이 연결 리스트와 유사하게 저하됩니다. 이는 이진 탐색 트리의 최악의 경우 성능을 야기합니다.
    ```
          A
         / 
        B   (or)    A
       /             \
      C               B
     /                 \
    D                   C
    ```

### 1.2.2. 이진 트리의 주요 특징

*   높이가 `h`인 이진 트리가 가질 수 있는 최대 노드 수는 `2^(h+1) - 1`개 입니다.
*   `n`개의 노드를 가진 이진 트리의 최소 높이는 `floor(log2(n))` 입니다.
*   리프 노드의 수를 `n0`, 차수가 2인 노드의 수를 `n2`라 할 때, 모든 비어있지 않은 이진 트리에서 `n0 = n2 + 1` 이 성립합니다.

### 1.2.3. 파이썬 구현

이진 트리의 노드는 값(value)과 두 개의 포인터(left, right)로 구성된 연결 구조의 핵심입니다. 이 노드들을 관리하고 체계적으로 생성하는 방법을 코드로 살펴보겠습니다.

**방법 1: 레벨 순서로 자동 삽입 (완전 이진 트리 생성)**

큐를 사용하여 트리의 위에서 아래로, 왼쪽부터 비어있는 자리를 찾아 노드를 삽입하는 방식입니다. 이 방법을 사용하면 항상 완전 이진 트리가 만들어집니다.

```python
from collections import deque

class Node:
    """기본적인 이진 트리 노드 클래스."""
    def __init__(self, value):
        self.value = value  # 노드의 값
        self.left = None    # 왼쪽 자식 노드에 대한 참조
        self.right = None   # 오른쪽 자식 노드에 대한 참조

class BinaryTree:
    """이진 트리 관리를 위한 헬퍼 클래스."""
    def __init__(self, root_value=None):
        if root_value is not None:
            self.root = Node(root_value)
        else:
            self.root = None

    def insert_level_order(self, value):
        """레벨 순서에 따라 가장 먼저 비어있는 자리에 노드를 삽입합니다."""
        if self.root is None:
            self.root = Node(value)
            return
        queue = deque([self.root])
        while queue:
            current_node = queue.popleft()
            if current_node.left is None:
                current_node.left = Node(value)
                return
            else:
                queue.append(current_node.left)
            if current_node.right is None:
                current_node.right = Node(value)
                return
            else:
                queue.append(current_node.right)

    def delete(self, value_to_delete):
        """특정 값을 가진 노드를 삭제합니다."""
        if self.root is None:
            return
        
        # 큐를 이용해 삭제할 노드, 가장 깊은 노드, 그리고 그 부모를 찾습니다.
        q = deque([(self.root, None)])
        node_to_delete = None
        deepest_node_parent = None
        deepest_node = None

        while q:
            current, parent = q.popleft()

            if current.value == value_to_delete:
                node_to_delete = current
            
            deepest_node = current
            deepest_node_parent = parent

            if current.left:
                q.append((current.left, current))
            if current.right:
                q.append((current.right, current))

        if not node_to_delete:
            print(f"Error: Node with value {value_to_delete} not found.")
            return

        # 삭제할 노드의 값을 가장 깊은 노드의 값으로 교체
        node_to_delete.value = deepest_node.value

        # 가장 깊은 노드를 삭제
        if deepest_node_parent:
            if deepest_node_parent.right == deepest_node:
                deepest_node_parent.right = None
            else:
                deepest_node_parent.left = None
        else: # 트리에 노드가 하나뿐인 경우
            self.root = None

    def find_nodes_without_siblings(self):
        """형제 노드가 없는 모든 노드를 찾아 리스트로 반환합니다."""
        if self.root is None:
            return []

        result = []
        queue = deque([self.root])
        while queue:
            node = queue.popleft()

            # 자식이 하나만 있는 경우, 그 자식은 형제가 없는 노드입니다.
            if node.left and not node.right:
                result.append(node.left.value)
            if node.right and not node.left:
                result.append(node.right.value)

            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        return result

# --- 예시 사용법 ---
# tree = BinaryTree()
# for val in [1, 2, 3, 4, 5, 6]:
#     tree.insert_level_order(val)
# # 생성된 트리:
# #      1
# #     / \
# #    2   3
# #   / \ /
# #  4  5 6

# print("형제 없는 노드:", tree.find_nodes_without_siblings()) # 출력: [6]

# tree.delete(3) # 노드 3을 삭제 (가장 깊은 노드 6의 값으로 대체)
# # 변경된 트리:
# #      1
# #     / \
# #    2   6
# #   / \
# #  4   5
# # inorder(tree.root) -> [4, 2, 5, 1, 6]
```

**방법 2: 특정 위치에 수동 삽입**

특정 구조의 트리를 만들고 싶을 때는 각 노드를 직접 생성하고 부모-자식 관계를 설정해주어야 합니다. 이는 포인터(참조)를 직접 연결하는 방식으로, 가장 기본적인 트리 구성 방법입니다.

```python
#      A
#     / \
#    B   C
#   /     \
#  D       F

# 1. 노드들을 생성합니다.
root = Node('A')
node_b = Node('B')
node_c = Node('C')
node_d = Node('D')
node_f = Node('F')

# 2. 부모-자식 관계를 직접 연결하여 '삽입'합니다.
root.left = node_b
root.right = node_c
node_b.left = node_d
node_c.right = node_f

# 이와 같이 일반 이진 트리는 삽입 위치를 직접 지정해야 하는 반면,
# 다음 섹션의 이진 탐색 트리는 키 값에 따라 삽입 위치가 자동으로 결정되는 규칙을 가집니다.
```

### 1.3. 이진 탐색 트리 (Binary Search Tree, BST)

이진 탐색 트리는 이진 트리의 일종으로, 효율적인 탐색, 삽입, 삭제를 위해 특정 규칙을 따릅니다. 이진 탐색 트리의 가장 중요한 특징은 **중위 순회(Inorder Traversal)를 할 경우, 노드들이 키 값 순서대로 정렬되어 방문된다**는 점입니다. 이 특성 때문에 정렬된 데이터를 관리하고 탐색하는 데 매우 효율적입니다.

*   **BST의 핵심 속성:**
    *   모든 노드의 왼쪽 서브트리에는 해당 노드의 키(key)보다 작은 값만 존재합니다.
    *   모든 노드의 오른쪽 서브트리에는 해당 노드의 키(key)보다 큰 값만 존재합니다.
    *   모든 서브트리 또한 이진 탐색 트리입니다.
    *   중복된 키는 허용되지 않습니다. (또는 특정 규칙에 따라 처리)

### 1.3.1. BST의 연산 (삽입, 삭제, 탐색)

*   **탐색 (Search):** 루트부터 시작하여 값을 비교하며 왼쪽 또는 오른쪽 서브트리로 이동합니다. 평균 `O(log n)`, 최악 `O(n)`.
*   **삽입 (Insertion):** 탐색과 유사하게 적절한 위치(리프 노드)를 찾아 새 노드를 추가합니다. 평균 `O(log n)`, 최악 `O(n)`.
    -   **삽입 예시: `45` 삽입**
        ```
             (Before)         (After)
                50               50
               /  \             /  \
              30  70           30  70
             /  \             /  \
            20  40           20  40
                                   \
                                   45
        ```

*   **삭제 (Deletion):** 노드를 삭제할 때 트리의 이진 탐색 트리 속성을 유지하는 것이 중요합니다. 삭제할 노드의 자식 수에 따라 세 가지 경우가 있습니다.
    1.  **자식 노드가 없는 경우 (리프 노드):** 단순히 해당 노드를 트리에서 제거합니다.
    2.  **자식 노드가 하나인 경우:** 삭제할 노드를 그 유일한 자식 노드로 대체합니다.
    3.  **자식 노드가 두 개인 경우:** 삭제할 노드를 대체할 노드를 찾아야 합니다. 일반적으로 삭제할 노드의 **오른쪽 서브트리에서 가장 작은 값**을 가진 노드(이를 **중위 후속자, Inorder Successor**라 함) 또는 **왼쪽 서브트리에서 가장 큰 값**을 가진 노드(이를 **중위 선임자, Inorder Predecessor**라 함)를 찾아 삭제할 노드의 위치로 옮기고, 원래 위치에 있던 대체 노드를 삭제합니다.
    -   **삭제 예시: `30` 삭제 (자식 2개)**
        ```
             (Before)         (After)
                50               50
               /  \             /  \
             (30) 70           40  70  <- 30의 중위 후속자인 40이 대체
             /  \             /      
            20  40           20
        ```

*   **시간 복잡도:** 탐색, 삽입, 삭제 모두 평균 `O(log n)`, 최악 `O(n)`. (최악의 경우는 트리가 편향되었을 때 발생하며, 이를 해결하기 위해 균형 이진 탐색 트리가 사용됩니다.)

### 1.3.2. 파이썬 구현

```python
class BSTNode:
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None

class BinarySearchTree:
    def __init__(self):
        self.root = None

    def insert(self, key):
        if self.root is None:
            self.root = BSTNode(key)
        else:
            self._insert_recursive(self.root, key)

    def _insert_recursive(self, node, key):
        if key < node.key:
            if node.left is None:
                node.left = BSTNode(key)
            else:
                self._insert_recursive(node.left, key)
        elif key > node.key:
            if node.right is None:
                node.right = BSTNode(key)
            else:
                self._insert_recursive(node.right, key)
        # else: key already exists, do nothing or handle duplicates

    def search(self, key):
        return self._search_recursive(self.root, key)

    def _search_recursive(self, node, key):
        if node is None or node.key == key:
            return node
        if key < node.key:
            return self._search_recursive(node.left, key)
        return self._search_recursive(node.right, key)

    def delete(self, key):
        self.root = self._delete_recursive(self.root, key)

    def _delete_recursive(self, node, key):
        if node is None:
            return node

        if key < node.key:
            node.left = self._delete_recursive(node.left, key)
        elif key > node.key:
            node.right = self._delete_recursive(node.right, key)
        else: # node.key == key, this is the node to be deleted
            # Case 1: No child or one child
            if node.left is None:
                return node.right
            elif node.right is None:
                return node.left
            
            # Case 2: Two children
            # Find the inorder successor (smallest in the right subtree)
            temp = self._min_value_node(node.right)
            node.key = temp.key # Copy the inorder successor's content to this node
            node.right = self._delete_recursive(node.right, temp.key) # Delete the inorder successor
        return node

    def _min_value_node(self, node):
        current = node
        while current.left is not None:
            current = current.left
        return current

    def inorder_traversal(self):
        # 중위 순회 (정렬된 순서로 노드 방문)
        result = []
        self._inorder_recursive(self.root, result)
        return result

    def _inorder_recursive(self, node, result):
        if node:
            self._inorder_recursive(node.left, result)
            result.append(node.key)
            self._inorder_recursive(node.right, result)
```

### 1.3.4. 활용 예시: 정렬된 연결 리스트를 균형 BST로 변환하기

정렬된 데이터가 주어졌을 때, 이를 평균 O(log n)의 탐색 성능을 보장하는 **균형 잡힌 이진 탐색 트리**로 만드는 것은 매우 유용한 작업입니다. 정렬된 연결 리스트를 균형 BST로 변환하는 과정은 다음과 같습니다.

1.  **연결 리스트를 배열로 변환:** 먼저 연결 리스트를 순회하여 모든 노드의 값을 배열(리스트)에 저장합니다.
2.  **정렬된 배열로 BST 구축:** 정렬된 배열을 사용하여 재귀적으로 균형 잡힌 BST를 만듭니다.
    a. 배열의 **중간 요소**를 찾아 트리의 루트 노드로 만듭니다.
    b. 중간 요소의 왼쪽 부분 배열을 가지고 재귀적으로 왼쪽 서브트리를 구축합니다.
    c. 중간 요소의 오른쪽 부분 배열을 가지고 재귀적으로 오른쪽 서브트리를 구축합니다.

이 분할 정복(Divide and Conquer) 접근법은 트리의 높이를 최소화하여 균형을 유지합니다.

```python
# 연결 리스트 노드 (예시를 위해 정의)
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# BSTNode 클래스는 3.1.3.2 섹션에 정의된 것을 재사용합니다.
# class BSTNode:
#    def __init__(self, key):
#        ...

def sorted_list_to_bst(head: ListNode) -> BSTNode:
    """정렬된 연결 리스트를 높이 균형 이진 탐색 트리로 변환합니다."""
    if not head:
        return None

    # 1. 연결 리스트를 배열로 변환
    nums = []
    current = head
    while current:
        nums.append(current.val)
        current = current.next
    
    # 2. 정렬된 배열을 사용하여 BST 구축
    def build_bst_from_sorted_array(arr):
        if not arr:
            return None
        
        # 배열의 중간 요소를 루트로 선택
        mid = len(arr) // 2
        root = BSTNode(arr[mid])
        
        # 재귀적으로 왼쪽과 오른쪽 서브트리 구축
        root.left = build_bst_from_sorted_array(arr[:mid])
        root.right = build_bst_from_sorted_array(arr[mid+1:])
        
        return root

    return build_bst_from_sorted_array(nums)
```

### 1.4. B-트리 (B-Tree) 및 B+트리 (B+Tree)

B-트리와 B+트리는 대용량 데이터를 **디스크(HDD, SSD)에 저장**하고 관리하는 데 최적화된 균형 탐색 트리입니다. 디스크 I/O 횟수를 최소화하여 성능을 높이는 것이 핵심 목표이며, 데이터베이스 인덱스 및 파일 시스템에서 널리 사용됩니다.

### 1.4.1. B-트리의 개념과 특징

*   **개념:** 모든 리프 노드가 같은 레벨에 있도록 자동으로 균형을 맞추는 자가 균형(Self-balancing) 탐색 트리입니다. 각 노드는 여러 개의 키와 자식 포인터를 가질 수 있습니다.
*   **디스크 I/O 최적화:** 디스크 I/O는 메모리 접근에 비해 매우 느리기 때문에, 한 번의 I/O로 최대한 많은 데이터를 읽어오는 것이 중요합니다. B-트리는 노드 하나에 여러 키를 저장하여 트리의 높이를 극단적으로 낮춤으로써 디스크 접근 횟수를 최소화합니다. 노드의 크기는 보통 디스크의 블록(페이지) 크기에 맞춰 설계됩니다.
*   **구조:** `m`차 B-트리의 각 노드는 `m-1`개 이하의 키를 가지며, 키와 키 사이에 자식 노드를 가리키는 포인터가 존재합니다. 키와 관련된 데이터는 내부 노드와 리프 노드 모두에 저장될 수 있습니다.
    - **노드 구조 시각화:**
        ```
        [ Ptr_1 | Key_1 | Ptr_2 | Key_2 | ... | Key_k | Ptr_k+1 ]
        ```
        *(Key_i보다 작은 값은 Ptr_i 서브트리에, 큰 값은 Ptr_i+1 서브트리에 존재)*

### 1.4.2. B+트리의 개념과 특징

*   **개념:** B-트리의 변형으로, 데이터베이스 인덱싱을 위해 더욱 최적화된 구조입니다.
*   **핵심 차이점:**
    1.  **데이터는 리프 노드에만 저장:** 내부 노드는 오직 키(인덱스)와 자식 포인터만을 가지며, 실제 데이터는 모두 리프 노드에만 저장됩니다. 이로 인해 내부 노드에 더 많은 키를 저장할 수 있어 트리의 높이가 더 낮아질 수 있습니다.
    2.  **리프 노드의 연결:** 모든 리프 노드들이 링크드 리스트처럼 서로 연결되어 있습니다. 이 구조는 특정 키를 시작으로 하는 순차적인 데이터 접근(Sequential Scan)을 매우 빠르게 만듭니다.
*   **구조 시각화:**
    ```
          [ 50 | 100 ] (Internal Node: Keys only)
         /     |     \
    [10,20]  [50,70]  [100,120] (Leaf Nodes: Data stored here)
       <------>   <------>
    (Leaf nodes are linked for sequential scan)
    ```

### 1.4.3. B-트리와 B+트리 비교

| 특징 | B-트리 (B-Tree) | B+트리 (B+Tree) |
| :--- | :--- | :--- |
| **데이터 저장 위치** | 모든 노드(내부, 리프)에 키와 데이터 저장 | **리프 노드**에만 키와 데이터 저장 |
| **내부 노드 구조** | 키 + 데이터 포인터 | 키 + 자식 노드 포인터 (인덱스 역할) |
| **리프 노드 연결** | 연결되어 있지 않음 | **링크드 리스트**로 연결되어 있음 |
| **검색 성능** | 키가 내부 노드에 있으면 더 빠를 수 있음 | 모든 검색이 리프 노드까지 가야 함 |
| **구간 검색** | 비효율적 (트리 순회 필요) | **매우 효율적** (리프 노드 순차 스캔) |
| **주요 용도** | 파일 시스템 | 데이터베이스 인덱스 |

### 1.4.4. B-트리/B+트리 활용 사례

*   **파일 시스템:** 대용량 파일 시스템(예: NTFS, HFS+)에서 파일 및 디렉토리 구조를 관리하는 데 B-트리가 사용됩니다.
*   **데이터베이스 인덱스:** MySQL의 InnoDB, PostgreSQL 등 대부분의 관계형 데이터베이스에서 테이블의 인덱스를 구현하는 데 B+트리가 사용되어 빠른 데이터 검색과 범위 검색을 가능하게 합니다.

### 1.4.5. 파이썬 구현 개요 (B-Tree, B+Tree)

B-트리와 B+트리의 완전한 삽입/삭제 구현은 노드의 분할(split)과 병합(merge) 처리로 인해 매우 복잡합니다. 여기서는 각 트리의 핵심 구조와 탐색(search) 연산을 중심으로 개념을 이해하는 데 초점을 맞춘 간략한 코드를 소개합니다.

**B-Tree 구현 개요**

```python
class BTreeNode:
    """B-트리 노드 클래스"""
    def __init__(self, leaf=False):
        self.leaf = leaf  # 리프 노드 여부
        self.keys = []    # 노드가 담고 있는 키들
        self.children = [] # 자식 노드들에 대한 참조

class BTree:
    """B-트리 클래스"""
    def __init__(self, t):
        self.root = BTreeNode(leaf=True)
        self.t = t  # 최소 차수 (minimum degree)

    def search(self, key):
        """키를 검색하는 메소드"""
        return self._search_recursive(self.root, key)

    def _search_recursive(self, node, key):
        i = 0
        # 현재 노드의 키들 중에서 key가 위치할 곳을 찾음
        while i < len(node.keys) and key > node.keys[i]:
            i += 1
        
        # 찾은 키가 현재 노드에 있으면 반환
        if i < len(node.keys) and key == node.keys[i]:
            return (node, i)
        
        # 현재 노드가 리프 노드이면, 더 이상 탐색할 곳이 없음
        if node.leaf:
            return None
        
        # 자식 노드로 재귀적으로 탐색을 계속함
        return self._search_recursive(node.children[i], key)

    # 참고: 실제 삽입(insert) 메소드는 노드가 가득 찼을 때
    # 노드를 분할(split)하는 복잡한 과정이 포함됩니다.
```

```python
class BPlusTreeNode:

    def __init__(self, leaf=False):
        self.leaf = leaf
        self.keys = []
        self.children = [] # 내부 노드에서만 사용
        self.values = []   # 리프 노드에서만 사용
        self.next = None   # 리프 노드에서 다음 리프 노드를 가리킴

class BPlusTree:
    """B+트리 클래스"""
    def __init__(self, t):
        self.root = BPlusTreeNode(leaf=True)
        self.t = t

    def search(self, key):
        """키에 해당하는 값을 검색합니다."""
        leaf_node = self._find_leaf(self.root, key)
        for i, k in enumerate(leaf_node.keys):
            if k == key:
                return leaf_node.values[i]
        return None

    def _find_leaf(self, node, key):
        """키가 존재할 수 있는 리프 노드를 찾습니다."""
        if node.leaf:
            return node
        
        i = 0
        while i < len(node.keys) and key >= node.keys[i]:
            i += 1
        return self._find_leaf(node.children[i], key)

    def range_search(self, start_key, end_key):
        """주어진 범위 내의 모든 키-값 쌍을 검색합니다."""
        results = []
        leaf_node = self._find_leaf(self.root, start_key)

        # 리프 노드를 순회하며 범위 내의 값을 찾음
        while leaf_node:
            for i, k in enumerate(leaf_node.keys):
                if k > end_key:
                    return results # 범위를 벗어나면 검색 종료
                if k >= start_key:
                    results.append(leaf_node.values[i])
            leaf_node = leaf_node.next # 다음 리프 노드로 이동
        return results

    # 참고: B+트리의 삽입/삭제 역시 노드 분할/병합 등 복잡한 로직이 필요합니다.
```

## 2. 트리 순회 (Tree Traversal)

트리 순회는 트리의 모든 노드를 체계적으로 방문하는 방법입니다. 트리의 구조를 탐색하고 데이터를 처리하는 데 필수적이며, 깊이 우선 탐색(DFS: Depth-First Search)과 너비 우선 탐색(BFS: Breadth-First Search)의 두 가지 주요 접근 방식이 있습니다. 순회 방식에 따라 노드를 방문하는 순서가 달라지며, 이는 문제 해결에 중요한 영향을 미칩니다.

### 3.2.1. 순회 종류와 특징 (전위, 중위, 후위, 레벨 순회)

트리 순회는 크게 깊이 우선 순회(DFS)와 너비 우선 순회(BFS)로 나눌 수 있습니다. 어떤 순서로 노드를 방문하는지에 따라 네 가지 주요 방식으로 구분됩니다.

*   **순회 예시 트리:**
    ```
          F
         / \
        B   G
       / \   \
      A   D   I
         / \   /
        C   E H
    ```

*   **깊이 우선 순회 (DFS: Depth-First Search):** 루트에서 시작하여 한쪽 자식의 가장 깊은 곳까지 탐색한 후 다른 쪽 자식으로 넘어가는 방식입니다.
    *   **전위 순회 (Preorder):** **Root** -> Left -> Right
        -   **결과:** `F, B, A, D, C, E, G, I, H`
        -   **특징:** 트리를 복사하거나, 표현식 트리를 전위 표기법으로 변환할 때, 트리의 구조를 그대로 출력할 때 유용합니다.
    *   **중위 순회 (Inorder):** Left -> **Root** -> Right
        -   **결과:** `A, B, C, D, E, F, G, H, I`
        -   **특징:** 이진 탐색 트리(BST)를 중위 순회하면 노드들이 **정렬된 순서로 방문**됩니다. 수식 트리를 중위 표기법으로 변환할 때 사용됩니다.
    *   **후위 순회 (Postorder):** Left -> Right -> **Root**
        -   **결과:** `A, C, E, D, B, H, I, G, F`
        -   **특징:** 트리를 삭제(자식 노드를 먼저 삭제해야 하므로)하거나, 후위 표기법으로 변환할 때, 파일 시스템 용량 계산 등 자식 노드의 처리가 부모보다 먼저 필요한 경우에 사용됩니다.

*   **너비 우선 순회 (BFS: Breadth-First Search):**
    *   **레벨 순회 (Level Order):** 트리의 각 레벨을 위에서 아래로, 같은 레벨에서는 왼쪽에서 오른쪽 순서로 노드를 방문합니다.
        -   **결과:** `F, B, G, A, D, I, C, E, H`
        -   **특징:** 큐(Queue) 자료구조를 사용하여 구현하며, 트리의 높이 계산이나 최단 경로 탐색(BFS)에 사용됩니다.

-   **DFS 순회 암기 팁: `Pre`, `In`, `Post`는 루트(Root) 노드를 언제 방문하는지를 의미합니다.**
    -   **Pre**-order (전위): 루트를 **먼저** 처리
    -   **In**-order (중위): 왼쪽과 오른쪽 서브트리 **사이에서** 루트를 처리
    -   **Post**-order (후위): 서브트리를 모두 처리한 후 **나중에** 루트를 처리

-   **순회 방식 요약**
    | 구분 | 방문 순서 (Root 기준) | 반복 구현 시 자료구조 | 주요 활용 사례 |
    | :--- | :--- | :--- | :--- |
    | **전위 순회** | **Root** -> Left -> Right | 스택 (Stack) | 트리 복사, 구조 출력, 전위 표기법 |
    | **중위 순회** | Left -> **Root** -> Right | 스택 (Stack) | 이진 탐색 트리 정렬, 중위 표기법 |
    | **후위 순회** | Left -> Right -> **Root** | 스택 (Stack) | 트리 삭제, 후위 표기법, 파일 시스템 용량 계산 |
    | **레벨 순회** | 레벨 1 -> 레벨 2 -> ... | 큐 (Queue) | 최단 경로 탐색(BFS), 트리 높이 계산 |

### 2.2. 재귀적 순회 구현

트리 순회는 자료구조의 재귀적 특성을 그대로 활용하여 구현하는 것이 가장 직관적이고 간결합니다. 각 순회 방식은 **(1) 현재 노드 방문, (2) 왼쪽 서브트리 순회, (3) 오른쪽 서브트리 순회**라는 세 가지 기본 작업의 순서만 바꾸면 됩니다.

```python
class Node:
    """예시를 위한 간단한 이진 트리 노드"""
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None

# --- 재귀 구현 ---

def preorder(node):
    """전위 순회 (Root -> Left -> Right)"""
    if node is None:
        return []
    # 1. 루트 방문 -> 2. 왼쪽 서브트리 순회 -> 3. 오른쪽 서브트리 순회
    return [node.key] + preorder(node.left) + preorder(node.right)

def inorder(node):
    """중위 순회 (Left -> Root -> Right)"""
    if node is None:
        return []
    # 1. 왼쪽 서브트리 순회 -> 2. 루트 방문 -> 3. 오른쪽 서브트리 순회
    return inorder(node.left) + [node.key] + inorder(node.right)

def postorder(node):
    """후위 순회 (Left -> Right -> Root)"""
    if node is None:
        return []
    # 1. 왼쪽 서브트리 순회 -> 2. 오른쪽 서브트리 순회 -> 3. 루트 방문
    return postorder(node.left) + postorder(node.right) + [node.key]

# --- 예시 사용법 ---
#      F
#     / \
#    B   G
#   / \   \
#  A   D   I
#     / \   /
#    C   E H

# 트리 생성 (3.2.1의 예시 트리와 동일)
root = Node('F')
root.left = Node('B')
root.right = Node('G')
root.left.left = Node('A')
root.left.right = Node('D')
root.left.right.left = Node('C')
root.left.right.right = Node('E')
root.right.right = Node('I')
root.right.right.left = Node('H')

print("전위 순회 (Preorder):", preorder(root))
# 출력: ['F', 'B', 'A', 'D', 'C', 'E', 'G', 'I', 'H']

print("중위 순회 (Inorder):", inorder(root))
# 출력: ['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I']

print("후위 순회 (Postorder):", postorder(root))
# 출력: ['A', 'C', 'E', 'D', 'B', 'H', 'I', 'G', 'F']
```

### 2.3. 반복적 순회 구현 (스택/큐 활용)

재귀는 내부적으로 시스템 스택을 사용하므로, 명시적인 스택이나 큐를 사용하여 반복적으로 순회를 구현할 수도 있습니다. 이는 재귀 호출의 깊이 제한을 피하거나, 특정 상황에서 성능을 최적화해야 할 때 유용합니다.

*   **전위 순회 (스택):**
    1.  스택에 루트 노드를 넣습니다.
    2.  스택이 빌 때까지 반복합니다.
    3.  노드를 pop하여 방문하고, 그 노드의 **오른쪽 자식, 그다음 왼쪽 자식**을 차례로 스택에 push합니다. (스택은 LIFO이므로 왼쪽 자식이 먼저 처리됩니다.)
    ```python
    def preorder_iterative(root):
        if not root: return []
        result = []
        stack = [root]
        while stack:
            node = stack.pop()
            result.append(node.key)
            if node.right: stack.append(node.right)
            if node.left: stack.append(node.left)
        return result
    ```

*   **중위 순회 (스택):**
    1.  현재 노드를 루트로 설정하고, 왼쪽 자식이 없을 때까지 계속 스택에 넣으며 왼쪽으로 이동합니다.
    2.  더 이상 왼쪽으로 갈 수 없으면, 스택에서 노드를 pop하여 방문합니다.
    3.  해당 노드의 오른쪽 자식으로 이동하여 1번 과정을 반복합니다.
    ```python
    def inorder_iterative(root):
        result = []
        stack = []
        current = root
        while current or stack:
            while current:
                stack.append(current)
                current = current.left
            current = stack.pop()
            result.append(current.key)
            current = current.right
        return result
    ```

*   **후위 순회 (스택):**
    후위 순회는 전위 순회(`Root -> Left -> Right`)를 응용하여 쉽게 구현할 수 있습니다.
    1.  전위 순회와 유사하게 탐색하되, 스택에 왼쪽 자식부터 push하여 `Root -> Right -> Left` 순서로 노드를 방문합니다.
    2.  이렇게 얻은 결과를 완전히 뒤집으면 `Left -> Right -> Root` 순서가 되어 후위 순회가 완성됩니다.
    ```python
    def postorder_iterative(root):
        if not root: return []
        stack = [root]
        temp_result = []
        while stack:
            node = stack.pop()
            temp_result.append(node.key)
            if node.left: stack.append(node.left)
            if node.right: stack.append(node.right)
        return temp_result[::-1] # 결과를 뒤집어 반환
    ```

*   **레벨 순회 (큐):**
    1.  큐에 루트 노드를 넣습니다.
    2.  큐가 빌 때까지 반복합니다.
    3.  큐에서 노드를 dequeue하여 방문하고, 해당 노드의 왼쪽 자식, 그다음 오른쪽 자식을 차례로 큐에 enqueue합니다.
    ```python
    from collections import deque

    def levelorder_iterative(root):
        if not root: return []
        result = []
        queue = deque([root])
        while queue:
            node = queue.popleft()
            result.append(node.key)
            if node.left: queue.append(node.left)
            if node.right: queue.append(node.right)
        return result
    ```

### 2.4. 이진 트리의 배열 표현

이진 트리, 특히 **완전 이진 트리(Complete Binary Tree)**는 배열을 사용하여 매우 효율적으로 표현할 수 있습니다. 노드 간의 관계를 포인터 대신 배열 인덱스 계산으로 처리하므로 공간 효율성이 높고, 힙(Heap)과 같은 자료구조를 구현하는 데 핵심적으로 사용됩니다.

**핵심 아이디어:** 트리의 노드에 레벨 순회 순서대로 번호를 붙여, 그 번호를 배열의 인덱스로 사용합니다.

```
      A (0)
     / \
    B (1) C (2)
   / \   / \
  D(3) E(4) F(5) G(6)

배열 표현: [A, B, C, D, E, F, G]
```

### 2.4.1. 인덱스를 이용한 부모/자식 노드 접근

배열의 인덱스만으로 특정 노드의 부모와 자식 노드에 쉽게 접근할 수 있습니다. 인덱스를 0부터 시작하는지, 1부터 시작하는지에 따라 계산법이 약간 다릅니다.

| 관계 | 0-based 인덱싱 (Python) | 1-based 인덱싱 (일반적인 알고리즘 교재) |
| :--- | :--- | :--- |
| **루트 노드** | `0` | `1` |
| **부모 `i`의 왼쪽 자식** | `2 * i + 1` | `2 * i` |
| **부모 `i`의 오른쪽 자식**| `2 * i + 2` | `2 * i + 1` |
| **자식 `j`의 부모** | `(j - 1) // 2` | `j // 2` |

### 2.4.2. 배열 표현의 장단점

-   **장점:**
    -   **공간 효율성:** 완전 이진 트리의 경우, 포인터를 저장할 추가 공간 없이 데이터를 연속된 메모리에 저장하므로 공간을 절약할 수 있습니다.
    -   **쉬운 접근:** 인덱스 계산만으로 부모와 자식 노드에 빠르게 접근할 수 있습니다.
-   **단점:**
    -   **공간 낭비:** 편향 트리와 같이 완전 이진 트리가 아닌 경우에는 사용되지 않는 배열 공간(`None` 값)이 많아져 심각한 메모리 낭비를 초래할 수 있습니다.
    -   **삽입/삭제의 어려움:** 중간에 노드를 삽입하거나 삭제하면, 트리의 구조를 유지하기 위해 배열의 많은 요소를 이동시켜야 할 수 있어 비효율적입니다. 이러한 이유로 배열 표현은 주로 노드의 개수나 구조가 크게 변하지 않는 힙(Heap)과 같은 자료구조에 사용됩니다.


### 2.5. 수식 트리와 순회 (전위, 중위, 후위 표기법)

수식 트리는 연산자와 피연산자로 구성된 이진 트리로, 수식을 표현하는 데 사용됩니다. 순회 방식에 따라 수식의 표기법이 달라지며, 이는 컴파일러나 계산기 구현에 활용됩니다.

*   **예시 수식:** `(A + B) * C`
    *   **전위 표기법 (Prefix Notation):** 연산자 -> 피연산자1 -> 피연산자2 (예: `* + A B C`)
        *   수식 트리에서 전위 순회 시 얻어지는 순서입니다.
    *   **중위 표기법 (Infix Notation):** 피연산자1 -> 연산자 -> 피연산자2 (예: `A + B * C`)
        *   우리가 일반적으로 사용하는 수식 표기법입니다. 수식 트리에서 중위 순회 시 얻어지는 순서입니다. (괄호는 연산자 우선순위를 명확히 하기 위해 필요할 수 있습니다.)
    *   **후위 표기법 (Postfix Notation):** 피연산자1 -> 피연산자2 -> 연산자 (예: `A B + C *`)
        *   역폴란드 표기법(Reverse Polish Notation, RPN)이라고도 불리며, 스택을 사용하여 수식을 쉽게 계산할 수 있습니다. 수식 트리에서 후위 순회 시 얻어지는 순서입니다.


## 3. 균형 이진 탐색 트리 (Balanced Binary Search Tree)

이진 탐색 트리는 평균적으로 `O(log n)`의 빠른 탐색 성능을 보이지만, 데이터가 정렬된 순서로 삽입될 경우 연결 리스트와 유사한 **편향 트리(Skewed Tree)**가 되어 성능이 최악의 경우 `O(n)`까지 저하될 수 있습니다. 

**균형 이진 탐색 트리**는 이러한 문제를 해결하기 위해, 삽입 및 삭제 시 특정 규칙에 따라 스스로 균형을 맞추는 **자가 균형(Self-balancing)** 기능을 가진 트리입니다. 이를 통해 트리의 높이를 항상 `O(log n)`으로 유지하여, 어떤 경우에도 안정적인 성능을 보장합니다. 대용량 데이터를 다루거나 실시간 응답이 중요한 시스템에서 필수적입니다.

### 3.1. AVL 트리 (AVL Tree)

*   **개념:** **가장 엄격하게 균형을 유지하는** 트리로, 모든 노드에서 **왼쪽 서브트리의 높이와 오른쪽 서브트리의 높이 차이가 1 이하**로 유지됩니다. 이 높이 차이를 **균형 인수(Balance Factor)**라고 하며, 항상 `-1`, `0`, `1` 중 하나의 값을 가집니다.
*   **재균형 (Rebalancing):** 삽입 또는 삭제 후 어떤 노드의 균형 인수가 `+2` 또는 `-2`가 되면, 트리는 **회전(Rotation)** 연산을 통해 스스로 균형을 맞춥니다. 회전은 `O(1)` 시간에 수행되는 매우 빠른 연산입니다.

*   **회전의 종류:** 불균형이 발생한 패턴에 따라 4가지 회전 방식이 있습니다.

    1.  **LL 회전 (Single Right Rotation):** 왼쪽 자식의 왼쪽에 노드가 삽입되어 불균형 발생
    2.  **RR 회전 (Single Left Rotation):** 오른쪽 자식의 오른쪽에 노드가 삽입되어 불균형 발생
        ```python
           (Y)           RR 회전           (X)
          / \          -------->          / \
         A  (X)        <--------         (Y)  C
            / \        LL 회전          / \
           B   C                      A   B
        ```
    3.  **LR 회전 (Double Rotation: Left -> Right):** 왼쪽 자식의 오른쪽에 노드가 삽입되어 불균형 발생 (Left Rotation 후 Right Rotation)
    4.  **RL 회전 (Double Rotation: Right -> Left):** 오른쪽 자식의 왼쪽에 노드가 삽입되어 불균형 발생 (Right Rotation 후 Left Rotation)

### 3.1.1. 파이썬 전체 구현

AVL 트리의 완전한 구현은 복잡하지만, 재귀를 사용하여 각 서브트리에서 연산 후 높이를 재계산하고 균형 인수를 확인하여 필요한 회전을 적용하는 방식으로 구현할 수 있습니다.

```python
from collections import deque

class AVLNode:
    """AVL 트리 노드 클래스"""
    def __init__(self, key):
        self.key = key
        self.left = None
        self.right = None
        self.height = 1 # 노드의 높이 정보

class AVLTree:
    """AVL 트리 클래스"""
    def get_height(self, node):
        if not node:
            return 0
        return node.height

    def get_balance(self, node):
        """노드의 균형 인수를 계산합니다."""
        if not node:
            return 0
        return self.get_height(node.left) - self.get_height(node.right)

    def _right_rotate(self, z):
        y = z.left
        T3 = y.right
        y.right = z
        z.left = T3
        z.height = 1 + max(self.get_height(z.left), self.get_height(z.right))
        y.height = 1 + max(self.get_height(y.left), self.get_height(y.right))
        return y

    def _left_rotate(self, z):
        y = z.right
        T2 = y.left
        y.left = z
        z.right = T2
        z.height = 1 + max(self.get_height(z.left), self.get_height(z.right))
        y.height = 1 + max(self.get_height(y.left), self.get_height(y.right))
        return y

    def insert(self, root, key):
        # 1. 일반적인 BST 삽입 수행
        if not root:
            return AVLNode(key)
        elif key < root.key:
            root.left = self.insert(root.left, key)
        else:
            root.right = self.insert(root.right, key)

        # 2. 조상 노드의 높이 업데이트
        root.height = 1 + max(self.get_height(root.left), self.get_height(root.right))

        # 3. 균형 인수 계산 및 재균형
        balance = self.get_balance(root)

        # LL Case
        if balance > 1 and key < root.left.key:
            return self._right_rotate(root)

        # RR Case
        if balance < -1 and key > root.right.key:
            return self._left_rotate(root)

        # LR Case
        if balance > 1 and key > root.left.key:
            root.left = self._left_rotate(root.left)
            return self._right_rotate(root)

        # RL Case
        if balance < -1 and key < root.right.key:
            root.right = self._right_rotate(root.right)
            return self._left_rotate(root)

        return root

    def _get_min_value_node(self, root):
        if root is None or root.left is None:
            return root
        return self._get_min_value_node(root.left)

    def delete(self, root, key):
        # 1. 일반적인 BST 삭제 수행
        if not root:
            return root
        if key < root.key:
            root.left = self.delete(root.left, key)
        elif key > root.key:
            root.right = self.delete(root.right, key)
        else:
            if root.left is None:
                return root.right
            elif root.right is None:
                return root.left
            temp = self._get_min_value_node(root.right)
            root.key = temp.key
            root.right = self.delete(root.right, temp.key)

        if root is None:
            return root

        # 2. 높이 업데이트
        root.height = 1 + max(self.get_height(root.left), self.get_height(root.right))

        # 3. 균형 인수 계산 및 재균형
        balance = self.get_balance(root)

        # LL Case (Right rotate)
        if balance > 1 and self.get_balance(root.left) >= 0:
            return self._right_rotate(root)

        # LR Case (Left-Right rotate)
        if balance > 1 and self.get_balance(root.left) < 0:
            root.left = self._left_rotate(root.left)
            return self._right_rotate(root)

        # RR Case (Left rotate)
        if balance < -1 and self.get_balance(root.right) <= 0:
            return self._left_rotate(root)

        # RL Case (Right-Left rotate)
        if balance < -1 and self.get_balance(root.right) > 0:
            root.right = self._right_rotate(root.right)
            return self._left_rotate(root)

        return root

    def level_order_traversal(self, root):
        """트리 구조 확인을 위한 레벨 순회"""
        if not root:
            return "Tree is empty"
        
        result = []
        q = deque([root])
        while q:
            level_nodes = []
            for _ in range(len(q)):
                node = q.popleft()
                level_nodes.append(node.key)
                if node.left:
                    q.append(node.left)
                if node.right:
                    q.append(node.right)
            result.append(level_nodes)
        return result

if __name__ == '__main__':
    avl = AVLTree()
    root = None

    # LL 회전 테스트
    print("--- LL Rotation Test ---")
    keys_ll = [30, 20, 10]
    for key in keys_ll:
        root = avl.insert(root, key)
        print(f"Inserted {key}: {avl.level_order_traversal(root)}")

    # RR 회전 테스트
    print("\n--- RR Rotation Test ---")
    root = None
    keys_rr = [10, 20, 30]
    for key in keys_rr:
        root = avl.insert(root, key)
        print(f"Inserted {key}: {avl.level_order_traversal(root)}")

    # LR 회전 테스트
    print("\n--- LR Rotation Test ---")
    root = None
    keys_lr = [30, 10, 20]
    for key in keys_lr:
        root = avl.insert(root, key)
        print(f"Inserted {key}: {avl.level_order_traversal(root)}")

    # RL 회전 테스트
    print("\n--- RL Rotation Test ---")
    root = None
    keys_rl = [10, 30, 20]
    for key in keys_rl:
        root = avl.insert(root, key)
        print(f"Inserted {key}: {avl.level_order_traversal(root)}")

    # 삭제 테스트
    print("\n--- Deletion Test ---")
    root = None
    keys = [9, 5, 10, 0, 6, 11, -1, 1, 2]
    for key in keys:
        root = avl.insert(root, key)
    print("Initial Tree:", avl.level_order_traversal(root))
    root = avl.delete(root, 10)
    print("After deleting 10:", avl.level_order_traversal(root))
```

### 3.2. 레드-블랙 트리 (Red-Black Tree)

*   **개념:** 노드를 **빨간색** 또는 **검은색**으로 색칠하여 균형을 유지하는 이진 탐색 트리입니다. AVL 트리보다 덜 엄격하게 균형을 유지하지만(높이 차이가 2배까지 날 수 있음), 삽입/삭제 시 회전 횟수가 적어 실제 많은 시스템에서 더 선호됩니다.
*   **규칙:** 레드-블랙 트리는 다음 다섯 가지 규칙을 항상 만족해야 합니다.
    1.  모든 노드는 빨간색 또는 검은색입니다.
    2.  루트 노드는 검은색입니다.
    3.  모든 리프 노드(NIL 노드, 실제 데이터가 없는 가상의 노드)는 검은색입니다.
    4.  빨간색 노드의 자식은 모두 검은색입니다. (즉, 빨간색 노드는 연속될 수 없습니다.)
    5.  어떤 노드로부터 그 노드의 자손 리프 노드까지의 모든 경로에는 같은 수의 검은색 노드가 있습니다. (이를 **검은 높이, Black Height**라고 합니다.)
*   **재균형:** 삽입/삭제 후 위 규칙에 위배되면, **회전**과 **재색칠(Recoloring)**의 조합을 통해 균형을 맞춥니다.

### 3.2.1. 파이썬 구현 개요

레드-블랙 트리의 재균형 로직은 복잡하지만, 노드 구조는 색상 정보를 추가하는 것으로 표현할 수 있습니다. 재균형 시 AVL 트리에서 본 `left_rotate`, `right_rotate`와 같은 회전 연산과, 노드의 색상을 변경하는 **재색칠(Recoloring)**이 함께 사용됩니다.

아래 코드는 삽입 연산과 그에 따른 재균형 과정을 중심으로 레드-블랙 트리를 구현한 예시입니다.

```python
class RBTNode:
    """레드-블랙 트리 노드 클래스"""
    def __init__(self, key):
        self.key = key
        self.parent = None
        self.left = None
        self.right = None
        self.color = "RED" # 새로 삽입된 노드는 일단 RED로 시작

class RedBlackTree:
    """레드-블랙 트리 클래스"""
    def __init__(self):
        # 모든 리프 노드를 표현하는 NIL 센티널 노드
        self.NIL = RBTNode(0)
        self.NIL.color = "BLACK"
        self.root = self.NIL

    def _left_rotate(self, x):
        y = x.right
        x.right = y.left
        if y.left != self.NIL:
            y.left.parent = x
        y.parent = x.parent
        if x.parent is None:
            self.root = y
        elif x == x.parent.left:
            x.parent.left = y
        else:
            x.parent.right = y
        y.left = x
        x.parent = y

    def _right_rotate(self, x):
        y = x.left
        x.left = y.right
        if y.right != self.NIL:
            y.right.parent = x
        y.parent = x.parent
        if x.parent is None:
            self.root = y
        elif x == x.parent.right:
            x.parent.right = y
        else:
            x.parent.left = y
        y.right = x
        x.parent = y

    def insert(self, key):
        new_node = RBTNode(key)
        new_node.left = self.NIL
        new_node.right = self.NIL
        
        parent = None
        current = self.root
        while current != self.NIL:
            parent = current
            if new_node.key < current.key:
                current = current.left
            else:
                current = current.right
        
        new_node.parent = parent
        if parent is None:
            self.root = new_node
        elif new_node.key < parent.key:
            parent.left = new_node
        else:
            parent.right = new_node

        if new_node.parent is None: # 루트 노드인 경우
            new_node.color = "BLACK"
            return

        if new_node.parent.parent is None: # 루트의 자식인 경우
            return

        self._insert_fixup(new_node)

    def _insert_fixup(self, z):
        """삽입 후 레드-블랙 트리의 속성을 유지하기 위해 재조정"""
        while z.parent.color == "RED":
            if z.parent == z.parent.parent.right:
                uncle = z.parent.parent.left
                if uncle.color == "RED": # Case 1: 삼촌이 RED
                    uncle.color = "BLACK"
                    z.parent.color = "BLACK"
                    z.parent.parent.color = "RED"
                    z = z.parent.parent
                else:
                    if z == z.parent.left: # Case 2: RL (삼촌이 BLACK, triangle)
                        z = z.parent
                        self._right_rotate(z)
                    # Case 3: RR (삼촌이 BLACK, line)
                    z.parent.color = "BLACK"
                    z.parent.parent.color = "RED"
                    self._left_rotate(z.parent.parent)
            else:
                uncle = z.parent.parent.right
                if uncle.color == "RED": # Case 1
                    uncle.color = "BLACK"
                    z.parent.color = "BLACK"
                    z.parent.parent.color = "RED"
                    z = z.parent.parent
                else:
                    if z == z.parent.right: # Case 2: LR
                        z = z.parent
                        self._left_rotate(z)
                    # Case 3: LL
                    z.parent.color = "BLACK"
                    z.parent.parent.color = "RED"
                    self._right_rotate(z.parent.parent)
            if z == self.root:
                break
        self.root.color = "BLACK"

    # 참고: 삭제 연산과 그에 따른 재균형 로직은 훨씬 복잡하여 생략합니다.
```

### 3.3. 활용 사례 (맵, 셋 구현)

*   **맵 (Map) 및 셋 (Set) 구현:** C++의 `std::map`, `std::set`이나 Java의 `TreeMap`, `TreeSet` 등 많은 표준 라이브러리에서 레드-블랙 트리를 사용하여 정렬된 키-값 쌍 또는 고유한 요소 집합을 효율적으로 관리합니다.
*   **데이터베이스 인덱스:** B-트리/B+트리와 함께 데이터베이스 인덱스 구현에 사용됩니다.
*   **운영체제 스케줄러:** Completely Fair Scheduler (CFS)와 같이 프로세스 스케줄링에 사용됩니다.
