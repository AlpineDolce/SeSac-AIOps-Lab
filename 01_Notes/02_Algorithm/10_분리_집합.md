## 1. 분리 집합의 개념 및 핵심 연산

**분리 집합 (Disjoint Set Union, DSU)**

분리 집합(Disjoint Set Union, DSU) 또는 서로소 집합(Union-Find)은 **서로 겹치지 않는(서로소) 집합들의 모음을 효율적으로 관리하는 자료구조**입니다. 이 자료구조는 원소들이 어떤 집합에 속하는지, 그리고 두 원소가 같은 집합에 속하는지 등을 매우 빠르게 판단하고, 필요에 따라 두 집합을 합치는(Union) 연산을 수행하는 데 사용됩니다. 특히 그래프 알고리즘에서 연결된 구성 요소를 추적하거나, 네트워크 연결성을 관리하는 등 복잡한 문제 해결에 핵심적인 역할을 합니다. 분리 집합은 그 단순함에도 불구하고 강력한 성능을 제공하여 다양한 알고리즘 문제 해결에 필수적인 도구로 활용됩니다.

분리 집합 자료구조는 일반적으로 **트리의 숲(Forest of Trees)** 형태로 표현됩니다. 각 집합은 하나의 트리로 표현되며, 트리의 **루트 노드(Root Node)**가 해당 집합의 **대표 원소(Representative Element)**가 됩니다. 분리 집합은 주로 세 가지 핵심 연산을 통해 관리됩니다.

### 1.1. `MakeSet(x)`: 새로운 집합 생성

*   **개념**: 원소 `x`를 포함하는 새로운 집합을 생성합니다. 초기에는 각 원소가 자기 자신을 대표 원소로 하는 독립적인 집합을 이룹니다.
*   **구현**: `parent[x] = x`로 설정합니다. 이는 `x`가 자기 자신의 부모이자 대표 원소임을 의미합니다. 모든 원소는 처음에는 각자의 집합에 속하게 됩니다.

### 1.2. `Find(x)`: 대표 원소 찾기

*   **개념**: 원소 `x`가 속한 집합의 대표 원소(루트 노드)를 찾습니다. 이 연산을 통해 두 원소가 같은 집합에 속하는지(`Find(x) == Find(y)`) 효율적으로 확인할 수 있습니다.
*   **동작 방식**: `x`부터 시작하여 부모 노드를 따라 계속 올라가면서 최종적으로 루트 노드(즉, `parent[root] == root`인 노드)를 찾습니다.
*   **예시**: `Find(D)`를 호출하면 `D -> B -> A` 경로를 따라 `A`가 반환됩니다.
    ```
        A
       / \
      B   C
     /
    D
    ```

### 1.3. `Union(x, y)`: 두 집합 합치기

*   **개념**: 원소 `x`가 속한 집합과 원소 `y`가 속한 집합을 합칩니다. 이 연산은 두 원소가 서로 다른 집합에 속해 있을 때만 의미가 있습니다.
*   **동작 방식**: 먼저 `Find(x)`와 `Find(y)`를 통해 각 원소가 속한 집합의 대표 원소(`root_x`, `root_y`)를 찾습니다. 만약 `root_x`와 `root_y`가 다르다면, 한 대표 원소를 다른 대표 원소의 자식으로 연결하여 두 트리를 병합합니다. 이 과정에서 트리의 구조를 최적화하는 기법(유니온 바이 랭크/사이즈)이 적용될 수 있습니다.
*   **구현**: `root_x = Find(x)`, `root_y = Find(y)`. 만약 `root_x != root_y`이면 `parent[root_y] = root_x`와 같이 한쪽을 다른 쪽의 자식으로 만듭니다. (최적화 기법 미적용 시)
*   **예시**: `Union(D, E)`를 호출하면 `Find(D)`는 `A`를, `Find(E)`는 `F`를 반환합니다. `A`와 `F` 중 하나를 다른 하나의 자식으로 연결하여 두 집합을 합칩니다.
    ```
        A       F
       / \
      B   C   G   E
     /
    D
    ```
    `Union(A, F)` 후 (예: F를 A의 자식으로):
    ```
        A
       /|\
      B C F
     /   / \
    D   G   E
    ```

## 2. 분리 집합의 성능 최적화 기법

기본적인 `Find`와 `Union` 연산은 트리의 높이에 따라 성능이 저하될 수 있습니다. 이를 개선하여 분리 집합의 효율성을 극대화하기 위해 두 가지 주요 최적화 기법이 사용됩니다.

### 2.1. 경로 압축 (Path Compression)

*   **개념**: `Find(x)` 연산을 수행할 때, `x`에서 루트까지의 경로에 있는 모든 노드들을 직접 루트에 연결하여 트리의 높이를 낮춥니다. 이는 다음 번에 이 노드들에 대해 `Find` 연산을 수행할 때 탐색 경로가 크게 단축되어 성능이 향상됩니다.
*   **동작 방식**: `Find(x)`가 루트를 재귀적으로 찾아 반환한 후, 경로를 다시 거슬러 올라오면서 경로상의 모든 노드의 부모를 최종적으로 찾은 루트로 변경합니다. 즉, `parent[i] = find(parent[i])`와 같은 형태로 구현됩니다.
*   **예시**: `Find(D)` 호출 후
    ```
        A
       /|\ 
      B C F
     /   / \
    D   G   E
    ```
    `D`의 부모를 `A`로, `B`의 부모를 `A`로 직접 연결하여 트리를 평평하게 만듭니다.
    ```
        A
       /|\ \
      B C F D
         / \
        G   E
    ```
*   **효과**: 이후 동일한 노드나 그 자손에 대한 `Find` 연산의 속도를 크게 향상시킵니다. 트리가 거의 평평해져서 탐색 시간이 줄어듭니다.

### 2.2. 유니온 바이 랭크 (Union by Rank) 또는 유니온 바이 사이즈 (Union by Size)

*   **개념**: `Union(x, y)` 연산 시, 두 집합의 대표 원소를 연결할 때 트리의 균형을 유지하여 트리의 높이가 불필요하게 높아지는 것을 방지합니다. 이는 `Find` 연산의 효율성을 높이는 데 기여합니다.
*   **유니온 바이 랭크 (Union by Rank)**:
    *   트리의 **높이(Rank)**를 기준으로 더 낮은 높이의 트리를 더 높은 높이의 트리에 연결합니다. 높이가 같을 경우, 한쪽을 다른 쪽에 연결하고 연결된 트리의 높이를 1 증가시킵니다.
    *   `rank` 배열을 사용하여 각 루트 노드의 랭크(트리의 대략적인 높이)를 기록합니다.
*   **유니온 바이 사이즈 (Union by Size)**:
    *   트리의 **크기(Size)**(포함된 원소의 수)를 기준으로 더 작은 크기의 트리를 더 큰 크기의 트리에 연결합니다.
    *   `size` 배열을 사용하여 각 루트 노드가 대표하는 집합의 원소 수를 기록합니다.
*   **효과**: 트리의 높이를 최소한으로 유지하여 `Find` 연산의 최악의 경우 성능을 개선하고, 전체적인 연산 효율성을 높입니다.

### 2.3. 시간 복잡도 분석

*   경로 압축과 유니온 바이 랭크(또는 사이즈) 두 가지 최적화 기법을 모두 적용할 경우, `MakeSet`, `Find`, `Union` 연산의 **상환 시간 복잡도(Amortized Time Complexity)**는 거의 상수 시간에 가깝습니다. 정확히는 **역 아커만 함수(Inverse Ackermann Function, `α(N)`)**에 비례합니다.
*   `α(N)`은 `N`이 매우 큰 값일 때도 4 또는 5를 넘지 않는 매우 느리게 증가하는 함수이므로, 사실상 상수 시간으로 간주할 수 있습니다. 이는 분리 집합 자료구조가 매우 효율적임을 의미합니다.

## 3. 분리 집합의 파이썬 구현

아래는 경로 압축(Path Compression)과 유니온 바이 랭크(Union by Rank) 최적화 기법이 모두 적용된 분리 집합 자료구조의 파이썬 구현입니다. `DisjointSet` 클래스는 `parent` 배열과 `rank` 배열을 사용하여 집합의 상태를 관리합니다.

```python
class DisjointSet:
    def __init__(self, n):
        # parent[i]는 i의 부모 노드를 저장합니다. 초기에는 각 원소가 자기 자신을 부모로 가집니다.
        self.parent = list(range(n)) 
        # rank[i]는 i를 루트로 하는 트리의 높이(또는 랭크)를 저장합니다. 유니온 바이 랭크에 사용됩니다.
        self.rank = [0] * n          
        # size[i]는 i를 루트로 하는 트리의 크기(포함된 원소 수)를 저장합니다. 유니온 바이 사이즈에 사용될 수 있습니다.
        # self.size = [1] * n 

    def find(self, i):
        """
        원소 i가 속한 집합의 대표 원소(루트)를 찾습니다.
        경로 압축(Path Compression)을 적용하여 트리를 평평하게 만듭니다.
        """
        if self.parent[i] == i: # i가 루트 노드인 경우
            return i
        # 재귀적으로 루트를 찾고, 경로상의 모든 노드의 부모를 루트로 변경합니다.
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        """
        원소 i가 속한 집합과 원소 j가 속한 집합을 합칩니다.
        유니온 바이 랭크(Union by Rank)를 적용하여 트리의 균형을 유지합니다.
        """
        root_i = self.find(i) # i가 속한 집합의 대표 원소
        root_j = self.find(j) # j가 속한 집합의 대표 원소

        if root_i != root_j: # 두 원소가 다른 집합에 속해 있다면 합칩니다.
            # 랭크가 더 낮은 트리를 랭크가 더 높은 트리에 연결합니다.
            if self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            elif self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            else: # 랭크가 같으면 한쪽을 다른 쪽에 연결하고 랭크를 1 증가시킵니다.
                self.parent[root_j] = root_i
                self.rank[root_i] += 1
            return True # 합치기 성공
        return False # 이미 같은 집합에 속해 있음

# 예시 사용법
if __name__ == "__main__":
    print("--- 분리 집합 예시 ---")
    # 0부터 4까지 5개의 원소를 가진 분리 집합 초기화
    ds = DisjointSet(5) 
    print(f"초기 상태 (parent): {ds.parent}") # [0, 1, 2, 3, 4]
    print(f"초기 상태 (rank): {ds.rank}\n") # [0, 0, 0, 0, 0]

    # 0과 1을 합칩니다.
    print("Union(0, 1) 시도...")
    result = ds.union(0, 1)
    print(f"Union(0, 1) 결과: {result}") # True
    print(f"Union(0, 1) 후 parent: {ds.parent}") # [0, 0, 2, 3, 4] (0이 1의 부모가 됨)
    print(f"Union(0, 1) 후 rank: {ds.rank}\n") # [1, 0, 0, 0, 0] (0의 랭크가 1 증가)

    # 1의 대표 원소를 찾습니다. (경로 압축 확인)
    print("Find(1) 시도...")
    root_of_1 = ds.find(1)
    print(f"Find(1) 결과: {root_of_1}") # 0
    print(f"Find(1) 후 parent (경로 압축 확인): {ds.parent}\n") # [0, 0, 2, 3, 4] (parent[1]이 0으로 직접 연결됨)

    # 2와 3을 합칩니다.
    print("Union(2, 3) 시도...")
    result = ds.union(2, 3)
    print(f"Union(2, 3) 결과: {result}") # True
    print(f"Union(2, 3) 후 parent: {ds.parent}") # [0, 0, 2, 2, 4] (2가 3의 부모가 됨)
    print(f"Union(2, 3) 후 rank: {ds.rank}\n") # [1, 0, 1, 0, 0] (2의 랭크가 1 증가)

    # 0과 2가 같은 집합에 속하는지 확인합니다.
    print(f"Find(0) == Find(2) 결과: {ds.find(0) == ds.find(2)}\n") # False

    # 0과 2를 합칩니다.
    print("Union(0, 2) 시도...")
    result = ds.union(0, 2)
    print(f"Union(0, 2) 결과: {result}") # True
    print(f"Union(0, 2) 후 parent: {ds.parent}") # [0, 0, 0, 2, 4] (0의 랭크가 더 높으므로 2가 0의 자식이 됨)
    print(f"Union(0, 2) 후 rank: {ds.rank}\n") # [1, 0, 1, 0, 0] (랭크가 높은 쪽에 붙었으므로 랭크 변화 없음)

    # 이제 0, 1, 2, 3이 모두 같은 집합에 속하는지 확인합니다.
    print("최종 집합 상태 확인:")
    print(f"Find(0) 결과: {ds.find(0)}")
    print(f"Find(1) 결과: {ds.find(1)}")
    print(f"Find(2) 결과: {ds.find(2)}")
    print(f"Find(3) 결과: {ds.find(3)}")
    print(f"Find(4) 결과: {ds.find(4)}\n")

    print(f"Find(0) == Find(3) 결과: {ds.find(0) == ds.find(3)}") # True
    print(f"Find(1) == Find(2) 결과: {ds.find(1) == ds.find(2)}") # True
    print(f"Find(4) == Find(0) 결과: {ds.find(4) == ds.find(0)}") # False
    print("\n")
```

## 4. 분리 집합의 활용 사례

분리 집합 자료구조는 그 효율성과 유연성 덕분에 다양한 알고리즘 문제에서 집합 관리 및 연결성 확인을 위해 광범위하게 사용됩니다. 다음은 주요 활용 사례들입니다.

### 4.1. 그래프의 연결성 확인 및 사이클 감지

*   **연결 요소(Connected Components) 찾기**: 그래프에서 서로 연결된 정점들의 집합을 연결 요소라고 합니다. 분리 집합을 사용하면 그래프의 모든 정점을 순회하면서 `Find` 연산을 통해 같은 집합에 속하는 정점들을 그룹화하여 연결 요소를 효율적으로 찾을 수 있습니다.
*   **사이클 감지**: 무방향 그래프에서 새로운 간선 `(u, v)`를 추가할 때, `Find(u)`와 `Find(v)`의 결과가 같다면 (즉, `u`와 `v`가 이미 같은 집합에 속해 있다면) 해당 간선은 사이클을 형성합니다. 이는 그래프 탐색 없이도 사이클 존재 여부를 빠르게 판단할 수 있게 해줍니다.

### 4.2. 최소 신장 트리 (Minimum Spanning Tree, MST) - 크루스칼 알고리즘

*   크루스칼 알고리즘은 그래프의 모든 정점을 연결하면서 간선 가중치의 합이 최소가 되는 트리를 찾는 알고리즘입니다. 이 알고리즘은 간선들을 가중치 오름차순으로 정렬한 후, 가장 가중치가 작은 간선부터 선택하여 MST를 구성합니다.
*   이때 분리 집합 자료구조는 간선이 추가될 때마다 사이클이 형성되는지 여부를 효율적으로 확인하는 데 사용됩니다. `Union(u, v)` 연산이 성공하면 사이클이 형성되지 않고 간선을 MST에 안전하게 추가할 수 있음을 의미합니다.

### 4.3. 네트워크 연결 관리

*   컴퓨터 네트워크, 통신망 등에서 어떤 두 노드(컴퓨터, 장치 등)가 서로 연결되어 있는지(같은 네트워크 그룹에 속하는지)를 실시간으로 확인하고, 네트워크 병합 시 그룹을 업데이트하는 데 분리 집합이 사용될 수 있습니다.
*   예를 들어, 새로운 연결이 생겼을 때 `Union` 연산을 통해 두 네트워크 그룹을 합치고, 특정 두 장치 간의 연결성을 `Find` 연산을 통해 빠르게 확인할 수 있습니다.

### 4.4. 격자(Grid) 기반 문제

*   **퍼콜레이션(Percolation)**: 격자(Grid) 형태의 공간에서 물이나 유체가 흐를 수 있는 경로를 찾는 문제에 적용될 수 있습니다. 각 셀을 원소로 보고, 연결된 셀들을 `Union` 연산으로 합쳐 유체의 흐름 가능성을 판단합니다.
*   **섬의 개수 세기**: 2D 격자에서 연결된 '1'의 덩어리(섬)의 개수를 세는 문제(예: LeetCode 200. Number of Islands)에 효과적으로 사용됩니다. 각 '1'을 원소로 보고 인접한 '1'들을 `Union` 연산으로 합쳐 하나의 집합으로 만듭니다. 최종적으로 `Find` 연산을 통해 서로 다른 대표 원소의 개수를 세면 섬의 개수를 알 수 있습니다.

### 4.5. 친구 관계 또는 그룹 관리

*   소셜 네트워크 서비스에서 사용자들 간의 친구 관계를 통해 형성되는 그룹을 관리하거나, 어떤 두 사람이 같은 그룹에 속하는지 확인하는 데 분리 집합이 활용될 수 있습니다.
*   새로운 친구 관계가 맺어지면 `Union` 연산을 통해 두 사용자의 그룹을 합치고, 특정 두 사용자가 같은 '친구 그룹'에 속하는지 `Find` 연산을 통해 빠르게 판단할 수 있습니다.
