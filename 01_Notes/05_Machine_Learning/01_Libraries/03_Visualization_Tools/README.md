# 데이터 시각화 도구: Matplotlib, Seaborn, Plotly 핵심 가이드

이 가이드는 파이썬의 주요 데이터 시각화 라이브러리인 Matplotlib, Seaborn, Plotly의 핵심 개념과 활용법을 상세히 다룹니다. 각 라이브러리의 특징, 설치 방법, 기본적인 플로팅부터 고급 시각화 기법까지 다양한 예제를 통해 설명하며, 머신러닝 및 딥러닝 프로젝트에서 데이터를 효과적으로 탐색하고 결과를 시각화하는 데 필요한 지식을 제공합니다.

---

### Part 1: 데이터 시각화 소개
 **학습 목표:** 데이터 시각화의 근본적인 중요성을 이해하고, 파이썬 시각화 생태계의 주요 라이브러리인 Matplotlib, Seaborn, Plotly의 역할과 특징을 파악합니다.
 **왜 중요한가?** 데이터 시각화는 복잡한 데이터를 직관적으로 이해하고, 숨겨진 패턴과 인사이트를 발견하며, 분석 결과를 효과적으로 전달하는 핵심 도구입니다. 올바른 시각화 도구의 선택은 분석의 효율성과 결과의 영향력을 결정합니다.
-   [**01_데이터_시각화_소개.md**](./01_데이터_시각화_소개.md): 데이터 시각화의 중요성, 파이썬 시각화 생태계, Matplotlib, Seaborn, Plotly의 소개 및 설치 방법을 이해합니다.

### Part 3: Seaborn - Statistical Visualization
 **학습 목표:** Matplotlib 기반의 고수준 통계 시각화 라이브러리인 Seaborn을 활용하여 데이터 분포, 관계, 범주형 데이터를 미려하고 효율적으로 시각화하는 방법을 숙달합니다.
 **왜 중요한가?** Seaborn은 통계적 인사이트를 빠르게 얻고, 복잡한 데이터 관계를 직관적으로 표현하는 데 최적화되어 있습니다. 이는 탐색적 데이터 분석(EDA) 및 모델 결과 분석의 효율성을 크게 향상시킵니다.
-   [**09_Seaborn_관계형_플롯.md**](./09_Seaborn_관계형_플롯.md): `scatterplot()` 및 `lineplot()`을 이용한 관계형 플롯을 다룹니다.
-   [**10_Seaborn_분포_플롯.md**](./10_Seaborn_분포_플롯.md): `histplot()`, `kdeplot()`, `displot()`을 이용한 분포 플롯을 다룹니다.
-   [**11_Seaborn_범주형_플롯.md**](./11_Seaborn_범주형_플롯.md): `boxplot()`, `violinplot()`, `stripplot()`, `swarmplot()`, `barplot()`, `countplot()`을 이용한 범주형 플롯을 다룹니다.
-   [**12_Seaborn_회귀_행렬_플롯.md**](./12_Seaborn_회귀_행렬_플롯.md): `regplot()`, `lmplot()`을 이용한 회귀 플롯과 `heatmap()`, `clustermap()`을 이용한 행렬 플롯을 다룹니다.
-   [**13_Seaborn_다변수_고급_사용자정의.md**](./13_Seaborn_다변수_고급_사용자정의.md): `pairplot()`, `jointplot()`을 이용한 다변수 분석 플롯과 `FacetGrid`를 이용한 고급 플롯 제어, 사용자 정의 및 테마 설정을 다룹니다.

### Part 4: Plotly - Interactive Visualization
