## 1. ndarray의 속성

`ndarray` 객체는 NumPy 배열의 구조와 특성을 정의하는 여러 유용한 속성들을 제공합니다. 이러한 속성들을 이해하는 것은 배열을 효과적으로 다루고 분석하는 데 필수적입니다.

### 1.1. `ndim`: 배열의 차원 수

`ndim` 속성은 배열의 차원(dimension) 수를 나타냅니다. 스칼라는 0차원, 벡터는 1차원, 행렬은 2차원, 텐서는 3차원 이상으로 간주됩니다.

```python
import numpy as np

# 0차원 배열 (스칼라)
arr0d = np.array(42)
print(f"0차원 배열: {arr0d}, 차원 수 (ndim): {arr0d.ndim}")

# 1차원 배열 (벡터)
arr1d = np.array([1, 2, 3, 4, 5])
print(f"1차원 배열: {arr1d}, 차원 수 (ndim): {arr1d.ndim}")

# 2차원 배열 (행렬)
arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print(f"2차원 배열: 
{arr2d}, 차원 수 (ndim): {arr2d.ndim}")

# 3차원 배열 (텐서)
arr3d = np.array([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print(f"3차원 배열: 
{arr3d}, 차원 수 (ndim): {arr3d.ndim}")
```

### 1.2. `shape`: 배열의 형태

`shape` 속성은 배열의 각 차원별 크기를 나타내는 튜플입니다. 이 튜플의 각 요소는 해당 차원의 길이를 의미합니다. `shape`을 통해 배열의 구조를 파악할 수 있습니다.

```python
import numpy as np

# 0차원 배열
arr0d = np.array(42)
print(f"0차원 배열: {arr0d}, 형태 (shape): {arr0d.shape}") # ()

# 1차원 배열 (5개의 요소)
arr1d = np.array([1, 2, 3, 4, 5])
print(f"1차원 배열: {arr1d}, 형태 (shape): {arr1d.shape}") # (5,)

# 2차원 배열 (2행 3열)
arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print(f"2차원 배열: 
{arr2d}, 형태 (shape): {arr2d.shape}") # (2, 3)

# 3차원 배열 (2개의 2x2 행렬)
arr3d = np.array([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print(f"3차원 배열: 
{arr3d}, 형태 (shape): {arr3d.shape}") # (2, 2, 2)
```

### 1.3. `dtype`: 배열 요소의 데이터 타입

`dtype` 속성은 배열 요소들의 데이터 타입(data type)을 나타냅니다. NumPy 배열의 모든 요소는 동일한 `dtype`을 가집니다. 이는 메모리 효율성과 연산 속도에 중요한 영향을 미칩니다. (자세한 내용은 아래 2번 섹션에서 다룹니다.)

```python
import numpy as np

arr_int = np.array([1, 2, 3])
print(f"정수 배열: {arr_int}, 데이터 타입 (dtype): {arr_int.dtype}")

arr_float = np.array([1.0, 2.5])
print(f"실수 배열: {arr_float}, 데이터 타입 (dtype): {arr_float.dtype}")

arr_bool = np.array([True, False])
print(f"불리언 배열: {arr_bool}, 데이터 타입 (dtype): {arr_bool.dtype}")
```

### 1.4. `size`: 배열의 전체 요소 개수

`size` 속성은 배열에 포함된 전체 요소의 개수를 반환합니다. 이는 `shape` 튜플의 모든 요소를 곱한 값과 같습니다.

```python
import numpy as np

arr1d = np.array([1, 2, 3, 4, 5])
print(f"1차원 배열: {arr1d}, 요소 개수 (size): {arr1d.size}") # 5

arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print(f"2차원 배열: 
{arr2d}, 요소 개수 (size): {arr2d.size}") # 2 * 3 = 6

arr3d = np.array([[[1, 2], [3, 4]], [[5, 6], [7, 8]]])
print(f"3차원 배열: 
{arr3d}, 요소 개수 (size): {arr3d.size}") # 2 * 2 * 2 = 8
```

## 2. 데이터 타입 지정 및 변환

NumPy 배열의 요소들은 모두 동일한 데이터 타입(`dtype`)을 가집니다. 데이터 타입을 명시적으로 지정하거나, 생성된 배열의 데이터 타입을 변환하는 것은 메모리 효율성, 연산 속도, 그리고 특정 라이브러리(예: 딥러닝 프레임워크)와의 호환성을 위해 매우 중요합니다.

### 2.1. 배열 생성 시 `dtype` 지정

`np.array()` 또는 다른 배열 생성 함수(예: `np.zeros`, `np.ones`)에서 `dtype` 인자를 사용하여 배열의 데이터 타입을 명시적으로 지정할 수 있습니다. 이는 데이터의 종류와 필요한 정밀도를 미리 알고 있을 때 유용합니다.

```python
import numpy as np

# 정수형 배열 생성 (int32로 명시적 지정)
# np.int32는 32비트 정수형 데이터 타입을 의미합니다.
# 이는 -2,147,483,648부터 2,147,483,647까지의 정수를 표현할 수 있습니다.
int_arr = np.array([1, 2, 3], dtype=np.int32)
print(f"int_arr: {int_arr}, dtype: {int_arr.dtype}")
```
**설명:** 이 예시는 `np.array()` 함수를 사용하여 정수형 배열을 생성하면서 `dtype`을 `np.int32`로 명시적으로 지정하는 방법을 보여줍니다. 이렇게 하면 배열의 모든 요소가 32비트 정수형으로 저장됩니다.

```python
# 부동 소수점 배열 생성 (float64로 명시적 지정)
# np.float64는 64비트 부동 소수점(double precision) 데이터 타입을 의미합니다.
# 이는 더 넓은 범위와 높은 정밀도를 제공하여 과학 계산에 주로 사용됩니다.
float_arr = np.array([1.0, 2.5, 3.7], dtype=np.float64)
print(f"float_arr: {float_arr}, dtype: {float_arr.dtype}")
```
**설명:** 이 예시는 부동 소수점 배열을 생성하면서 `dtype`을 `np.float64`로 명시적으로 지정하는 방법을 보여줍니다. 이는 배열의 모든 요소가 64비트 부동 소수점형으로 저장되도록 합니다.

```python
# 복소수 배열 생성 (complex64로 명시적 지정)
# np.complex64는 64비트 복소수(실수부와 허수부가 각각 32비트 부동 소수점) 데이터 타입을 의미합니다.
complex_arr = np.array([1+2j, 3+4j], dtype=np.complex64)
print(f"complex_arr: {complex_arr}, dtype: {complex_arr.dtype}")
```
**설명:** 이 예시는 복소수 배열을 생성하면서 `dtype`을 `np.complex64`로 명시적으로 지정하는 방법을 보여줍니다. 복소수는 실수부와 허수부로 구성되며, `j`를 사용하여 허수부를 표현합니다.

```python
# 불리언 배열 생성
# bool은 True 또는 False 값만을 저장하는 데이터 타입입니다.
# 0은 False로, 0이 아닌 모든 값은 True로 자동 변환됩니다.
bool_arr = np.array([0, 1, 0], dtype=bool)
print(f"bool_arr: {bool_arr}, dtype: {bool_arr.dtype}")
```
**설명:** 이 예시는 불리언 배열을 생성하면서 `dtype`을 `bool`로 명시적으로 지정하는 방법을 보여줍니다. 입력된 정수 `0`은 `False`로, `1`은 `True`로 자동 변환되어 저장됩니다.

### 2.2. `astype()` 메서드를 이용한 `dtype` 변환

`astype()` 메서드는 이미 생성된 배열의 데이터 타입을 다른 타입으로 변환할 때 사용됩니다. 이 메서드는 원본 배열의 데이터를 복사하여 새로운 `dtype`을 가진 새 배열을 반환합니다. 원본 배열은 변경되지 않습니다.

#### 2.2.1. `float` → `int` 변환: 소수점 이하 버림 (Truncation)
부동 소수점 값을 정수 타입으로 변환할 때는 소수점 이하 부분이 버려집니다. 예를 들어, `1.1`은 `1`로, `3.9`는 `3`으로 변환됩니다.

```python
import numpy as np

original_float_arr = np.array([1.1, 2.5, 3.9], dtype=np.float64)
print(f"원본 float 배열: {original_float_arr}, dtype: {original_float_arr.dtype}")

# float -> int 변환: 소수점 이하 버림 (truncation)
int_converted_arr = original_float_arr.astype(np.int32)
print(f"int로 변환 (소수점 버림): {int_converted_arr}, dtype: {int_converted_arr.dtype}")
```

#### 2.2.2. `int` → `float` 변환
정수 값을 부동 소수점 타입으로 변환할 때는 일반적으로 정밀도 손실이 발생하지 않습니다. 하지만 매우 큰 정수의 경우, 부동 소수점 타입의 표현 한계로 인해 정밀도가 손실될 수 있습니다.

```python
import numpy as np

original_int_arr = np.array([1, 2, 3], dtype=np.int32)
print(f"원본 int 배열: {original_int_arr}, dtype: {original_int_arr.dtype}")

# int -> float 변환
int_to_float_arr = original_int_arr.astype(np.float32)
print(f"float로 변환: {int_to_float_arr}, dtype: {int_to_float_arr.dtype}")
```

#### 2.2.3. 숫자 → `bool` 변환 (불리언 배열 생성)
숫자 데이터를 `bool` 타입으로 변환할 때, NumPy는 '참 같은(truthy)' 값과 '거짓 같은(falsy)' 값을 구분합니다.
- **Falsy**: `0`, `0.0`
- **Truthy**: `0`이 아닌 모든 값 (양수, 음수, 부동 소수점)

```python
import numpy as np

# 0은 False로, 0이 아닌 모든 값은 True로 변환
bool_arr = np.array([0, 1, 10, 0, -5, 3.14]).astype(bool)
print(f"숫자 -> 불리언 변환: {bool_arr}, dtype: {bool_arr.dtype}")
```

#### 2.2.4. `bool` → `int` 변환
불리언 값을 정수 타입으로 변환하면 `True`는 `1`로, `False`는 `0`으로 변환됩니다.

```python
import numpy as np

bool_arr = np.array([True, False, True])
print(f"원본 bool 배열: {bool_arr}, dtype: {bool_arr.dtype}")

# boolean -> int 변환
bool_to_int_arr = bool_arr.astype(np.int8)
print(f"불리언 -> int 변환: {bool_to_int_arr}, dtype: {bool_to_int_arr.dtype}")
```

#### 2.2.5. `int` → `bool` 변환
정수를 불리언으로 변환할 때, `0`은 `False`로, `0`이 아닌 모든 정수는 `True`로 변환됩니다.

```python
import numpy as np

int_arr = np.array([0, 1, 5, -2], dtype=np.int32)
print(f"원본 int 배열: {int_arr}, dtype: {int_arr.dtype}")

# int -> boolean 변환
int_to_bool_arr = int_arr.astype(bool)
print(f"정수 -> 불리언 변환: {int_to_bool_arr}, dtype: {int_to_bool_arr.dtype}")
```

#### 2.2.6. `float` → `bool` 변환
실수를 불리언으로 변환할 때, `0.0`은 `False`로, `0.0`이 아닌 모든 실수는 `True`로 변환됩니다.

```python
import numpy as np

float_arr = np.array([0.0, 0.1, -2.5], dtype=np.float32)
print(f"원본 float 배열: {float_arr}, dtype: {float_arr.dtype}")

# float -> boolean 변환
float_to_bool_arr = float_arr.astype(bool)
print(f"실수 -> 불리언 변환: {float_to_bool_arr}, dtype: {float_to_bool_arr.dtype}")
```

#### 2.2.3. 데이터 손실 및 오버플로우/언더플로우

`dtype` 변환 시, 원래 데이터가 새 `dtype`의 표현 범위를 벗어나면 **데이터 손실(data loss)**이나 **오버플로우(overflow)** / **언더플로우(underflow)**가 발생할 수 있습니다. 이는 예상치 못한 결과를 초래할 수 있으므로 특히 주의해야 합니다.

*   **오버플로우 (Overflow)**: 숫자가 해당 데이터 타입이 표현할 수 있는 최대 양수 값을 초과할 때 발생합니다.
*   **언더플로우 (Underflow)**: 숫자가 해당 데이터 타입이 표현할 수 있는 최소 음수 값을 초과할 때 발생합니다.
*   **정밀도 손실 (Precision Loss)**: 부동 소수점 타입 간 변환 시, 더 작은 비트 수를 가진 타입으로 변환하면 유효 숫자의 개수가 줄어들어 정밀도가 떨어집니다.

```python
import numpy as np

# int16 범위의 정수 (int16 범위: -32768 ~ 32767)
arr_int16 = np.array([30000, 40000, -30000], dtype=np.int16)
print(f"원본 int16 배열: {arr_int16}")

# int16을 int8로 변환 (int8 범위: -128 ~ 127)
# 30000, 40000, -30000은 int8 범위를 훨씬 초과하여 오버플로우/언더플로우 발생
# NumPy는 기본적으로 정수 오버플로우/언더플로우 시 모듈로(modulo) 연산을 수행합니다.
# 40000을 int8로 변환하면 (40000 % 256) - 128 = 64 - 128 = -64 (대략)
# -30000을 int8로 변환하면 (-30000 % 256) - 128 = -128 (대략)
arr_overflow_int8 = arr_int16.astype(np.int8)
print(f"int8로 변환 (오버플로우/언더플로우): {arr_overflow_int8}")
# 결과는 모듈로 연산에 따라 달라지며, 예상과 매우 다를 수 있습니다.
# 예: 40000은 int8의 최대값(127)을 넘어섰으므로, 127을 넘어서는 값은 다시 -128부터 시작하는 순환적인 방식으로 표현됩니다.

# float64를 float32로 변환 시 정밀도 손실
# float64는 약 15-17자리의 유효 숫자를 표현할 수 있습니다.
arr_float64 = np.array([1.2345678901234567, 0.12345678901234567], dtype=np.float64)
print(f"\n원본 float64 배열: {arr_float64}")
# float32는 약 6-9자리의 유효 숫자를 표현할 수 있습니다.
# 따라서 float64에서 float32로 변환하면 유효 숫자의 개수가 줄어들어 정밀도 손실이 발생합니다.
arr_float32 = arr_float64.astype(np.float32)
```
