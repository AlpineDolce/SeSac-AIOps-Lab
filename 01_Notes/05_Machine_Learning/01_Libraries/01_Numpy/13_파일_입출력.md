## 1. NumPy 바이너리 파일: `.npy`

`np.save()`와 `np.load()`는 NumPy 배열을 디스크에 가장 빠르고 효율적으로 저장하고 불러오는 방법입니다. 데이터는 압축되지 않은 원시 바이너리 형태로 `.npy` 확장자로 저장되며, 배열의 `dtype`, `shape` 등 모든 정보가 그대로 보존됩니다.

```python
import numpy as np

# 배열 생성
arr = np.arange(24).reshape(4, 6)
print(f"원본 배열:\n{arr}")

# .npy 파일로 저장
np.save('my_array.npy', arr)

# .npy 파일에서 불러오기
loaded_arr = np.load('my_array.npy')
print(f"\n불러온 배열:\n{loaded_arr}")
```

## 2. 여러 배열 저장하기: `.npz`

`np.savez()` 함수를 사용하면 여러 개의 NumPy 배열을 하나의 압축되지 않은 `.npz` 파일에 딕셔너리 형태로 저장할 수 있습니다. 각 배열은 키-값 쌍으로 저장됩니다.

`np.savez_compressed()`를 사용하면 동일한 작업을 수행하되, 데이터를 압축하여 디스크 공간을 절약할 수 있습니다.

```python
# 여러 배열 생성
arr1 = np.array([1, 2, 3])
arr2 = np.arange(6).reshape(2, 3)

# .npz 파일로 여러 배열 저장
np.savez('my_arrays.npz', array1=arr1, array2=arr2)

# .npz 파일 불러오기
loaded_data = np.load('my_arrays.npz')

print(f"\n저장된 키: {list(loaded_data.keys())}")
print(f"array1:\n{loaded_data['array1']}")
print(f"array2:\n{loaded_data['array2']}")

loaded_data.close() # 파일 핸들러를 닫아주는 것이 좋습니다.
```

## 3. 텍스트 파일 입출력

`np.savetxt()`와 `np.loadtxt()`는 배열을 CSV와 같은 텍스트 파일 형식으로 저장하고 불러올 때 사용합니다. 사람이 읽을 수 있는 형태로 저장되지만, 바이너리 형식보다 속도가 느리고 파일 크기가 큽니다.

```python
# 텍스트 파일로 저장 (쉼표로 구분)
np.savetxt('my_array.csv', arr, delimiter=',', fmt='%d')

# 텍스트 파일에서 불러오기
loaded_from_txt = np.loadtxt('my_array.csv', delimiter=',')
print(f"\n텍스트 파일에서 불러온 배열:\n{loaded_from_txt}")
```

## 4. 대용량 배열을 위한 메모리 매핑 (`np.memmap`)

### 4.1. 메모리 매핑이란?
메모리 매핑은 **배열 전체를 RAM으로 불러오지 않고, 디스크에 있는 파일의 일부를 메모리의 작은 조각처럼 사용하는 기술**입니다. 운영체제가 파일과 메모리 간의 데이터 동기화를 관리하므로, 사용자는 마치 거대한 배열이 메모리에 있는 것처럼 투명하게 데이터에 접근하고 수정할 수 있습니다.

### 4.2. `np.memmap` 사용법
`np.memmap`은 파일 경로, 데이터 타입(`dtype`), 모드(`mode`), 그리고 배열의 모양(`shape`)을 인자로 받아 메모리 매핑된 배열 객체를 생성합니다.

- `mode='r+'`: 읽기/쓰기 (기존 파일)
- `mode='w+'`: 읽기/쓰기 (새 파일 또는 덮어쓰기)
- `mode='r'`: 읽기 전용

```python
# 1. 1억 개의 요소를 가진 거대한 배열을 위한 공간 생성 (파일 생성)
# 실제로는 메모리에 300MB가 할당되지 않음
shape = (10_000, 10_000)
memmapped_arr = np.memmap('large_array.mmap', dtype='float32', mode='w+', shape=shape)

# 2. 배열의 일부에 데이터 쓰기 (메모리처럼 접근)
# 이 작업은 파일에 직접 데이터를 씁니다.
memmapped_arr[0, :] = np.arange(10_000)
memmapped_arr[:, 0] = np.arange(10_000)

# 3. 변경사항을 디스크에 반영 (필수)
memmapped_arr.flush()

# 4. 다른 세션에서 파일 열기 (읽기 모드)
# 다시 열어도 데이터는 그대로 유지됨
existing_mmap = np.memmap('large_array.mmap', dtype='float32', mode='r', shape=shape)

print(f"\n메모리 매핑된 배열의 (0,0) 값: {existing_mmap[0, 0]}")
print(f"메모리 매핑된 배열의 (0,100) 값: {existing_mmap[0, 100]}")

# 메모리에서 객체 삭제
del memmapped_arr, existing_mmap
```

### 4.3. 언제 사용해야 하는가?
- **RAM보다 큰 데이터셋 처리**: 배열 전체를 메모리에 로드할 수 없을 때, `np.memmap`은 유일한 해결책일 수 있습니다.
- **프로세스 간 데이터 공유**: 여러 파이썬 프로세스가 동일한 파일을 메모리 매핑하여 대용량 데이터를 공유하고 수정할 수 있습니다. 이는 다중 처리(multiprocessing) 환경에서 매우 유용합니다.

## 1. NumPy 파일 입출력

NumPy는 배열 데이터를 효율적으로 디스크에 저장하고 로드하는 기능을 제공합니다. 이는 대규모 데이터셋을 다루거나 모델의 가중치 등을 저장할 때 유용합니다.

### 1.1. 단일 배열 저장/로드: `np.save()`, `np.load()`

`np.save()`는 단일 NumPy 배열을 `.npy` 확장자를 가진 바이너리 파일로 저장하고, `np.load()`는 이 파일을 다시 로드합니다.


#### 1.1.1. 배열 생성 및 저장

`np.save()` 함수를 사용하여 NumPy 배열을 `.npy` 파일로 저장하는 과정을 보여줍니다. `.npy` 파일은 배열의 데이터 타입, 형상 등 모든 메타데이터를 함께 저장합니다.

```python
import numpy as np
import os # 파일 존재 여부 확인 및 삭제를 위해 os 모듈 임포트

# 저장할 배열 생성
data_to_save = np.random.rand(5) # 0과 1 사이의 난수 5개로 구성된 1차원 배열
print(f"저장할 배열: {data_to_save}")
print(f"저장할 배열의 타입: {type(data_to_save)}")
print(f"저장할 배열의 형상: {data_to_save.shape}")
print(f"저장할 배열의 데이터 타입: {data_to_save.dtype}")

file_name = 'datafile.npy'

# 배열 저장
# 파일 확장자는 자동으로 .npy가 붙습니다.
np.save(file_name, data_to_save)
print(f"\n'{file_name}' 파일이 생성되었습니다.")
print(f"파일 '{file_name}' 존재 여부: {os.path.exists(file_name)}")
```

#### 1.1.2. 저장된 배열 로드

`np.load()` 함수를 사용하여 `.npy` 파일에 저장된 배열을 다시 로드합니다. 로드된 배열은 원본 배열과 동일한 속성을 가집니다.

```python
# 저장된 배열 로드
# 로드하기 전에 변수를 비워두어 제대로 로드되는지 확인
loaded_data = None
print(f"로드 전 변수: {loaded_data}")

loaded_data = np.load(file_name)
print(f"로드된 배열: {loaded_data}")
print(f"로드된 배열의 타입: {type(loaded_data)}")
print(f"로드된 배열의 형상: {loaded_data.shape}")
print(f"로드된 배열의 데이터 타입: {loaded_data.dtype}")

# 로드된 배열은 저장했던 배열과 동일한지 확인
print(f"원본 배열과 로드된 배열이 동일한가? {np.array_equal(data_to_save, loaded_data)}")
```

#### 1.1.3. 기존 파일 덮어쓰기

`np.save()` 함수는 동일한 이름의 파일이 이미 존재할 경우, 경고 없이 기존 파일을 덮어씁니다.

```python
# 다른 데이터로 덮어쓰기 (Overwrite)
new_data = np.array([10, 20, 30, 40, 50])
print(f"\n새로 저장할 배열: {new_data}")
np.save(file_name, new_data) # 기존 파일이 있다면 덮어씁니다.
print(f"'{file_name}' 파일이 새로운 데이터로 덮어쓰기되었습니다.")

reloaded_data = np.load(file_name)
print(f"다시 로드된 배열: {reloaded_data}")
print(f"새로운 배열과 로드된 배열이 동일한가? {np.array_equal(new_data, reloaded_data)}")
```

#### 1.1.4. 파일 정리

예제 실행 후 생성된 파일을 삭제하여 깔끔하게 정리합니다.

```python
# 파일 정리 (선택 사항)
os.remove(file_name)
print(f"'{file_name}' 파일이 삭제되었습니다.")
print(f"파일 '{file_name}' 존재 여부: {os.path.exists(file_name)}")
```

### 1.2. 여러 배열 저장/로드: `np.savez()`

`np.savez()`는 여러 개의 NumPy 배열을 `.npz` 확장자를 가진 압축 파일 하나에 저장합니다. 각 배열은 키-값 쌍의 형태로 저장되며, 로드할 때는 딕셔너리처럼 접근할 수 있습니다.


```python
import numpy as np
import os

# 1. 저장할 여러 배열 생성
data1_save = np.arange(1, 11).reshape(2, 5) # 1부터 10까지의 정수 배열, 2x5 형상
data2_save = np.random.rand(3, 4) # 0과 1 사이의 난수 3x4 배열
data3_save = np.array(['apple', 'banana', 'cherry']) # 문자열 배열

print(f"저장할 data1:\n{data1_save}")
print(f"저장할 data2:\n{data2_save}")
print(f"저장할 data3:\n{data3_save}")

npz_file_name = 'multiple_data.npz'

# 2. 여러 배열을 '.npz' 파일에 저장
# 키워드 인자로 배열에 이름을 부여합니다.
np.savez(npz_file_name, array1=data1_save, array2=data2_save, fruits=data3_save)
print(f"\n'{npz_file_name}' 파일이 생성되었습니다.")
print(f"파일 '{npz_file_name}' 존재 여부: {os.path.exists(npz_file_name)}")

# 3. 저장된 여러 배열 로드
# np.load()는 NpzFile 객체를 반환합니다.
loaded_npz = np.load(npz_file_name)

# npz 파일에 저장된 배열들의 키(이름) 확인
print(f"\n저장된 배열 키: {loaded_npz.files}") # ['array1', 'array2', 'fruits']

# 키를 사용하여 각 배열에 접근
loaded_data1 = loaded_npz['array1']
loaded_data2 = loaded_npz['array2']
loaded_data3 = loaded_npz['fruits']

print(f"로드된 array1:\n{loaded_data1}")
print(f"로드된 array2:\n{loaded_data2}")
print(f"로드된 fruits:\n{loaded_data3}")

# 원본 배열과 로드된 배열이 동일한지 확인
print(f"원본 data1과 로드된 array1이 동일한가? {np.array_equal(data1_save, loaded_data1)}")
print(f"원본 data2와 로드된 array2이 동일한가? {np.array_equal(data2_save, loaded_data2)}")
print(f"원본 data3와 로드된 fruits이 동일한가? {np.array_equal(data3_save, loaded_data3)}")

# 4. 압축하여 저장 (np.savez_compressed)
# np.savez_compressed는 기본적으로 압축을 적용합니다.
npz_compressed_file_name = 'compressed_data.npz'
np.savez_compressed(npz_compressed_file_name, array1=data1_save, array2=data2_save)
print(f"\n'{npz_compressed_file_name}' (압축) 파일이 생성되었습니다.")

# 파일 크기 비교 (실제 압축률은 데이터 특성에 따라 다름)
print(f"일반 .npz 파일 크기: {os.path.getsize(npz_file_name)} bytes")
print(f"압축된 .npz 파일 크기: {os.path.getsize(npz_compressed_file_name)} bytes")

# 5. 파일 정리 (선택 사항)
loaded_npz.close() # NpzFile 객체는 사용 후 닫아주는 것이 좋습니다.
os.remove(npz_file_name)
os.remove(npz_compressed_file_name)
print(f"'{npz_file_name}' 및 '{npz_compressed_file_name}' 파일이 삭제되었습니다.")
```


### 1.3. 대용량 파일을 위한 메모리 매핑: `np.memmap`

RAM 용량을 초과하는 매우 큰 데이터 파일을 다뤄야 할 때 `np.memmap`은 핵심적인 도구입니다. 이는 디스크 상의 파일을 메모리에 있는 배열처럼 취급하게 해줍니다. `np.memmap` 객체는 파일의 특정 부분을 메모리에 매핑하여, 마치 전체 파일이 RAM에 로드된 것처럼 직접 접근하고 수정할 수 있게 합니다. 데이터의 필요한 부분만 메모리로 읽어오기 때문에, RAM보다 훨씬 큰 데이터셋도 효율적으로 처리할 수 있습니다.

**실무적 중요성:**
수십, 수백 GB 크기의 과학 데이터(예: 센서 데이터, 이미지 시퀀스, 시뮬레이션 결과)나 로그 데이터를 직접 분석해야 할 때, 데이터를 작은 조각으로 나누는 복잡한 과정 없이도 NumPy의 강력한 인덱싱과 슬라이싱을 그대로 활용할 수 있게 해줍니다. 이는 특히 딥러닝에서 대규모 데이터셋을 학습할 때, 전체 데이터를 메모리에 올리지 않고도 필요한 배치(batch)만 로드하여 사용하는 데 유용합니다.

**`np.memmap`의 주요 파라미터:**
*   `filename`: 메모리 매핑할 파일의 경로.
*   `dtype`: 배열의 데이터 타입. 파일이 이미 존재하면 이 타입으로 해석됩니다.
*   `mode`: 파일 접근 모드.
    *   `'r'`: 읽기 전용.
    *   `'c'`: 읽기/쓰기 (변경 사항은 `flush()` 호출 시 또는 객체 소멸 시 파일에 기록).
    *   `'r+'`: 읽기/쓰기 (파일이 존재해야 함).
    *   `'w+'`: 읽기/쓰기 (파일이 존재하면 덮어쓰고, 없으면 새로 생성).
    *   `'f'`: 읽기/쓰기 (파일이 존재하면 덮어쓰고, 없으면 새로 생성). `w+`와 유사하지만, `flush()`가 더 자주 호출될 수 있습니다.
*   `offset`: 파일 시작부터 데이터가 시작되는 바이트 오프셋.
*   `shape`: 배열의 형상.

**사용 예시:**

```python
import numpy as np
import os

# 1. 대용량 파일을 위한 메모리 매핑 생성 및 초기화
memmap_file = 'large_data.mmap'
data_shape = (1000, 1000) # 1000x1000 크기의 배열 (4MB, float64 기준)
data_dtype = np.float64 # 8 bytes per element

# 파일이 이미 존재하면 삭제 (예시를 위해)
if os.path.exists(memmap_file):
    os.remove(memmap_file)

# 'w+' 모드로 메모리 매핑 객체 생성 및 파일 초기화
# 이 시점에서 파일이 생성되고, 지정된 크기만큼 할당됩니다.
print(f"'{memmap_file}' 파일을 '{data_shape}' 형상으로 생성 중...")
mmap_array = np.memmap(memmap_file, dtype=data_dtype, mode='w+', shape=data_shape)

# 배열에 데이터 쓰기 (메모리 매핑된 파일에 직접 쓰여짐)
# 마치 일반 NumPy 배열처럼 인덱싱하여 데이터를 할당할 수 있습니다.
for i in range(data_shape[0]):
    mmap_array[i, :] = i # 각 행을 행 번호로 채움

# 변경 사항을 디스크에 강제로 쓰기 (선택 사항, 하지만 중요)
# 'c' 또는 'r+' 모드에서는 변경 사항이 즉시 디스크에 반영되지 않을 수 있습니다.
# flush()를 호출하여 명시적으로 디스크에 기록합니다.
mmap_array.flush()
print(f"데이터가 '{memmap_file}' 파일에 기록되었습니다.")

# 2. 메모리 매핑된 파일에서 데이터 읽기
# 'r' 모드로 기존 파일을 읽기 전용으로 엽니다.
print(f"\n'{memmap_file}' 파일에서 데이터 읽기 중...")
read_mmap_array = np.memmap(memmap_file, dtype=data_dtype, mode='r', shape=data_shape)

# 특정 부분만 읽어오기 (전체 파일을 메모리에 로드하지 않음)
# 예를 들어, 첫 5행만 읽어옵니다.
print(f"첫 5행:\n{read_mmap_array[:5, :]}")

# 특정 요소에 접근
print(f"mmap_array[100, 50]의 값: {read_mmap_array[100, 50]}")

# 3. 메모리 매핑된 파일 수정 및 확인
# 'r+' 모드로 읽기/쓰기 권한으로 엽니다.
print(f"\n'{memmap_file}' 파일 수정 중...")
modify_mmap_array = np.memmap(memmap_file, dtype=data_dtype, mode='r+', shape=data_shape)

# 특정 위치의 데이터 수정
modify_mmap_array[0, 0] = 999.99
modify_mmap_array[10, 20] = -123.45

# 변경 사항을 디스크에 반영
modify_mmap_array.flush()
print("데이터 수정 및 디스크에 반영 완료.")

# 수정된 데이터 확인을 위해 다시 읽기
re_read_mmap_array = np.memmap(memmap_file, dtype=data_dtype, mode='r', shape=data_shape)
print(f"수정된 mmap_array[0, 0]의 값: {re_read_mmap_array[0, 0]}")
print(f"수정된 mmap_array[10, 20]의 값: {re_read_mmap_array[10, 20]}")

# 4. 메모리 매핑 객체 닫기 (선택 사항, 파이썬 가비지 컬렉터가 처리하기도 함)
# 명시적으로 닫을 필요는 없지만, 자원 관리를 위해 호출할 수 있습니다.
del mmap_array
del read_mmap_array
del modify_mmap_array
del re_read_mmap_array

# 5. 파일 정리 (선택 사항)
os.remove(memmap_file)
print(f"\n'{memmap_file}' 파일이 삭제되었습니다.")
print(f"파일 '{memmap_file}' 존재 여부: {os.path.exists(memmap_file)}")
```

**`np.memmap` 사용 시 고려사항:**
*   **파일 크기:** `np.memmap`은 파일 시스템의 지원을 받으므로, 파일 시스템이 허용하는 최대 파일 크기에 제약됩니다.
*   **데이터 타입 및 형상:** `np.memmap` 객체를 생성할 때 지정한 `dtype`과 `shape`은 파일의 실제 물리적 구조와 일치해야 합니다. 기존 파일을 열 때는 이 정보가 정확해야 데이터를 올바르게 해석할 수 있습니다.
*   **`flush()`:** `mode='c'` 또는 `mode='r+'`로 파일을 열었을 때, 배열에 대한 변경 사항이 즉시 디스크에 기록되지 않을 수 있습니다. 변경 사항을 강제로 디스크에 쓰려면 `mmap_array.flush()`를 호출해야 합니다. 객체가 파이썬 가비지 컬렉터에 의해 소멸될 때 자동으로 `flush()`가 호출되기도 하지만, 중요한 변경 사항은 명시적으로 `flush()`하는 것이 안전합니다.
*   **운영체제 의존성:** 메모리 매핑은 운영체제의 기능을 활용하므로, 운영체제에 따라 미묘한 동작 차이가 있을 수 있습니다.
*   **동시 접근:** 여러 프로세스나 스레드에서 동일한 메모리 매핑 파일을 동시에 접근할 경우, 데이터 일관성 문제를 피하기 위해 적절한 동기화 메커니즘(예: 락)이 필요할 수 있습니다.

이러한 NumPy의 파일 입출력 기능들을 숙지하면 대규모 데이터를 효율적으로 관리하고 처리하는 데 큰 도움이 될 것입니다.
