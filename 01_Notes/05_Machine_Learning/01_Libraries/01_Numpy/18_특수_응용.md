## 1. 신호 처리의 핵심: 푸리에 변환 (Fourier Transform)

NumPy의 `fft` 모듈은 시간 영역(time-domain)의 신호를 주파수 영역(frequency-domain)으로 변환하는 푸리에 변환 기능을 제공합니다. 이를 통해 신호를 구성하는 주파수 성분을 분석할 수 있어 오디오 필터링, 이미지 압축 등 다양한 분야에 활용됩니다.

### 1.1. 1D 푸리에 변환 및 역변환
`np.fft.fft`로 신호를 변환하고, `np.fft.ifft`로 다시 원본 신호로 복원할 수 있습니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# 5Hz와 20Hz 주파수가 섞인 신호 생성
sampling_rate = 100
t = np.linspace(0, 1, sampling_rate, endpoint=False)
signal = 0.5 * np.sin(2 * np.pi * 5 * t) + 0.2 * np.sin(2 * np.pi * 20 * t)

# 1. 푸리에 변환 (시간 -> 주파수)
fft_result = np.fft.fft(signal)
freq_axis = np.fft.fftfreq(sampling_rate, d=1/sampling_rate)

# 2. 역 푸리에 변환 (주파수 -> 시간)
reconstructed_signal = np.fft.ifft(fft_result)

# 결과 확인
print(f"원본 신호와 복원된 신호가 거의 동일한가? {np.allclose(signal, reconstructed_signal.real)}")

# 시각화 (주파수 스펙트럼)
plt.figure(figsize=(12, 4))
plt.subplot(1, 2, 1)
plt.plot(t, signal)
plt.title('Original Signal (Time Domain)')
plt.xlabel('Time (s)')

plt.subplot(1, 2, 2)
plt.plot(freq_axis[:sampling_rate//2], np.abs(fft_result)[:sampling_rate//2])
plt.title('Frequency Spectrum')
plt.xlabel('Frequency (Hz)')
plt.show()
```

### 1.2. 2D 푸리에 변환 (이미지 처리)
`np.fft.fft2`를 사용하여 2차원 배열(이미지)에 대한 푸리에 변환을 수행할 수 있습니다. 이미지의 주파수 성분을 분석하여 저주파(배경)와 고주파(경계선)를 분리하는 등의 작업이 가능합니다.

```python
# 간단한 2D 이미지 생성 (중앙에 사각형)
image = np.zeros((100, 100))
image[40:60, 40:60] = 1

# 2D 푸리에 변환
fft_image = np.fft.fft2(image)
# 시각화를 위해 저주파 성분을 중앙으로 이동
fft_shifted = np.fft.fftshift(fft_image)

plt.figure(figsize=(10, 5))
plt.subplot(1, 2, 1)
plt.imshow(image, cmap='gray')
plt.title('Original Image')

plt.subplot(1, 2, 2)
plt.imshow(np.log(1 + np.abs(fft_shifted)), cmap='gray')
plt.title('2D FFT (Log Magnitude)')
plt.show()
```

## 2. 데이터 모델링: 다항식 피팅 (Polynomial Fitting)

`np.polyfit`은 주어진 데이터를 가장 잘 근사하는 다항식의 계수를 찾아 데이터의 추세를 모델링하는 데 사용됩니다.

### 2.1. 과소적합과 과적합 (Underfitting & Overfitting)
다항식의 차수(`deg`)를 어떻게 설정하느냐에 따라 모델의 성능이 크게 달라집니다.
- **과소적합 (Underfitting)**: 차수가 너무 낮아 데이터의 패턴을 제대로 표현하지 못함.
- **과적합 (Overfitting)**: 차수가 너무 높아 노이즈까지 학습하여 새로운 데이터에 대한 예측 성능이 떨어짐.

```python
x = np.linspace(-5, 5, 100)
y = 0.5 * x**2 - 2 * x + 1 + np.random.randn(100) * 2

# 차수별 피팅
coeffs_underfit = np.polyfit(x, y, 1) # 1차 (과소적합)
coeffs_goodfit = np.polyfit(x, y, 2)  # 2차 (적절)
coeffs_overfit = np.polyfit(x, y, 15) # 15차 (과적합)

poly_under = np.poly1d(coeffs_underfit)
poly_good = np.poly1d(coeffs_goodfit)
poly_over = np.poly1d(coeffs_overfit)

plt.figure(figsize=(10, 6))
plt.scatter(x, y, label='Original Data', alpha=0.4)
plt.plot(x, poly_under(x), 'r-', label='Underfit (deg=1)')
plt.plot(x, poly_good(x), 'g-', linewidth=2, label='Good Fit (deg=2)')
plt.plot(x, poly_over(x), 'm--', label='Overfit (deg=15)')
plt.legend()
plt.ylim(-10, 30)
plt.show()
```

### 2.2. 새로운 `numpy.polynomial` API
최신 NumPy에서는 더 객체지향적이고 안정적인 `numpy.polynomial` 모듈 사용을 권장합니다.

```python
from numpy.polynomial import Polynomial

p = Polynomial.fit(x, y, 2) # 클래스 메서드로 피팅
plt.plot(x, p(x), 'b-.', label='New API Fit') # 객체를 함수처럼 사용
plt.legend()
plt.show()
```

## 3. 과학 계산의 기초: 선형대수 (Linear Algebra)

`np.linalg` 모듈은 선형대수와 관련된 필수적인 기능들을 제공합니다.

### 3.1. 역행렬과 행렬식
- `np.linalg.inv(A)`: 행렬 A의 역행렬을 계산합니다.
- `np.linalg.det(A)`: 행렬 A의 행렬식(determinant)을 계산합니다.

```python
A = np.array([[1, 2], [3, 4]])
A_inv = np.linalg.inv(A)
det_A = np.linalg.det(A)

print(f"A의 역행렬:\n{A_inv}")
print(f"A @ A_inv (단위행렬):\n{A @ A_inv}")
print(f"A의 행렬식: {det_A:.2f}")
```

### 3.2. 선형 연립방정식 풀이
`Ax = b` 형태의 선형 연립방정식은 `np.linalg.solve(A, b)`를 사용하여 `x`를 효율적으로 구할 수 있습니다. 역행렬을 직접 구해 곱하는 것보다 수치적으로 안정적이고 빠릅니다.

```python
# 2x + y = 1
# x + 3y = -1
A = np.array([[2, 1], [1, 3]])
b = np.array([1, -1])

x = np.linalg.solve(A, b)
print(f"\n연립방정식의 해 x: {x}")
print(f"검증 (A @ x): {A @ x}") # b와 동일해야 함
```

### 3.3. 고유값과 고유벡터
`np.linalg.eig(A)`는 정방행렬 A의 고유값(eigenvalues)과 고유벡터(eigenvectors)를 계산합니다. 이는 주성분 분석(PCA) 등 다양한 알고리즘의 핵심 요소입니다.

```python
eigenvalues, eigenvectors = np.linalg.eig(A)
print(f"\n고유값: {eigenvalues}")
print(f"고유벡터:\n{eigenvectors}")
```

## 4. 데이터 정제: 결측치(NaN) 처리

`np.nan`은 결측치를 나타내며, 이를 안전하게 처리하는 전용 함수(`np.nansum`, `np.nanmean` 등)를 사용하는 것이 중요합니다.

### 4.1. NaN의 전파와 비교
- **전파(Propagation)**: `np.nan`과의 모든 산술 연산 결과는 `np.nan`이 됩니다. (`np.nan + 1` -> `nan`)
- **비교(Comparison)**: `np.nan == np.nan`은 항상 `False`를 반환합니다. 따라서 `np.isnan()` 함수를 사용해야만 `nan` 여부를 확인할 수 있습니다.

### 4.2. 마스크된 배열 (Masked Arrays)
`np.ma` 모듈은 데이터와 별도로 마스크(mask)를 유지하여 결측치나 유효하지 않은 값을 관리하는 더 정교한 방법을 제공합니다.

```python
arr = np.array([1, 2, -1, 4, 5])
masked_arr = np.ma.masked_where(arr < 0, arr) # -1을 마스킹

print(f"\n마스크된 배열: {masked_arr}")
print(f"마스크된 배열의 평균: {masked_arr.mean()}") # 마스킹된 값은 계산에서 제외됨
```

## 5. `einsum`을 이용한 텐서 연산

`np.einsum`은 아인슈타인 표기법을 사용하여 복잡한 다차원 배열 연산을 간결하고 효율적으로 수행합니다. 표기법의 핵심은 다음과 같습니다.
- `입력_인덱스 -> 출력_인덱스` 형식
- 입력에서 반복되는 인덱스는 해당 축에 대해 합산(summation)됩니다.
- 출력에 생략된 인덱스는 축소(reduction)됩니다.

```python
A = np.arange(9).reshape(3, 3)
B = np.arange(9).reshape(3, 3)

# 'ij->ji' : 전치 (Transpose)
print(f"A의 전치:\n{np.einsum('ij->ji', A)}")

# 'ii->' : 대각합 (Trace)
print(f"A의 대각합: {np.einsum('ii->', A)}")

# 'ij->i' : 행의 합 (Sum over columns)
print(f"A의 행별 합: {np.einsum('ij->i', A)}")

# 'ij,ij->ij' : 요소별 곱 (Element-wise product)
print(f"A와 B의 요소별 곱:\n{np.einsum('ij,ij->ij', A, B)}")

# 'i,j->ij' : 외적 (Outer product)
v1 = np.array([1, 2, 3])
v2 = np.array([4, 5])
print(f"v1과 v2의 외적:\n{np.einsum('i,j->ij', v1, v2)}")
```
