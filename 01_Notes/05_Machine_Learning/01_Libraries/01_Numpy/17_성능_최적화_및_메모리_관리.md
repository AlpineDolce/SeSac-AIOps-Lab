## 1. 핵심 메모리 관리: 뷰(View) vs. 복사(Copy)

NumPy 성능의 핵심은 메모리를 어떻게 다루는지에 있습니다. 연산 결과가 원본 데이터의 **뷰(View)**인지, 새로운 메모리를 할당받은 **복사본(Copy)**인지를 이해하는 것이 모든 최적화의 시작입니다.

-   **뷰 (View)**: 원본 배열의 메모리를 **공유**하는 창(window)입니다. 뷰를 수정하면 원본 배열도 변경됩니다. 메모리를 절약하고 싶거나 원본을 직접 수정할 때 유용합니다.
-   **복사 (Copy)**: 원본 배열과 완전히 **독립된** 새로운 배열입니다. 복사본을 수정해도 원본은 안전합니다.

### 1.1. 뷰(View)를 반환하는 경우
- **기본 슬라이싱**: `arr[1:5]`, `arr[:, 2]`
- **`reshape()`**: `arr.reshape(2, 5)` (단, 메모리 레이아웃이 호환될 때)
- **`transpose()`, `.T`**: `arr.transpose()`, `arr.T`
- **`ravel()`**: `arr.ravel()` (가능한 한 뷰를 반환)
- **필드 접근**: `structured_arr['field_name']`

### 1.2. 복사(Copy)를 반환하는 경우
- **`copy()` 메서드**: `arr.copy()`
- **고급 인덱싱**: 팬시 인덱싱(`arr[[0, 2]]`), 불리언 인덱싱(`arr[arr > 5]`)
- **산술 연산**: `arr + 2`, `arr * b`
- **`astype()`**: `arr.astype(np.float32)`

```python
import numpy as np
arr = np.arange(10)

# 뷰 예제 (슬라이싱)
view = arr[3:6]
view[0] = 99
print(f"뷰 수정 후 원본: {arr}") # 원본 변경됨

# 복사 예제 (불리언 인덱싱)
copy = arr[arr > 50]
# copy[0] = 100 # 이 코드는 copy가 비어있지 않을 때만 동작하며, arr에는 영향을 주지 않음
```

### 1.3. 고급 뷰 생성: 스트라이드 트릭 (Stride Tricks)
`np.lib.stride_tricks.as_strided`는 메모리 복사 없이, 기존 배열의 메모리를 특정 간격(stride)으로 건너뛰며 읽는 방식으로 새로운 뷰를 생성하는 강력한 기능입니다. 시계열 데이터의 롤링 윈도우(Rolling Window) 구현에 매우 효율적입니다.

**주의**: 잘못 사용하면 메모리 영역을 침범하여 프로그램을 충돌시킬 수 있으므로, 원리를 정확히 이해하고 사용해야 합니다.

```python
def rolling_window(a, window_size):
    shape = (a.shape[0] - window_size + 1, window_size)
    strides = (a.strides[0], a.strides[0])
    return np.lib.stride_tricks.as_strided(a, shape=shape, strides=strides)

x = np.arange(10)
rolling_view = rolling_window(x, 3)
print(f"롤링 윈도우 (뷰):
{rolling_view}")
# 결과는 메모리 복사 없이 생성된 뷰입니다.
```

## 2. 성능 최적화 기법

### 2.1. 벡터화(Vectorization): 루프를 제거하라
파이썬 `for` 루프 대신 NumPy의 내장 함수(ufunc)나 연산자를 사용하세요. NumPy 연산은 C 또는 Fortran으로 구현된 내부 루프를 통해 실행되므로, 순수 파이썬 코드보다 수십 배에서 수백 배 빠릅니다.

```python
# 이 예제는 성능 차이를 명확히 보여줍니다.
# (실행 환경에 따라 결과는 다를 수 있음)
import time
size = 10_000_000
a = np.random.rand(size)
b = np.random.rand(size)

start = time.time()
c_loop = [x + y for x, y in zip(a.tolist(), b.tolist())]
print(f"파이썬 루프: {time.time() - start:.4f} 초")

start = time.time()
c_np = a + b
print(f"NumPy 벡터화: {time.time() - start:.4f} 초")
```

### 2.2. 브로드캐스팅(Broadcasting): 불필요한 메모리 확장을 막아라
브로드캐스팅은 모양이 다른 배열 간의 연산을 가능하게 하는 강력한 메커니즘입니다. 데이터를 복사하여 메모리 상에서 배열의 모양을 맞추는 것이 아니라, **내부적으로 더 작은 배열의 요소를 재사용**하는 방식으로 동작합니다. 이는 불필요한 메모리 사용과 데이터 복사를 막아 성능을 향상시킵니다.

```python
a = np.random.rand(1000, 5)
b = np.array([1, 2, 3, 4, 5])

# 브로드캐스팅: b가 a의 각 행에 더해짐
# 메모리 상에서 b를 1000번 복사하지 않음!
c = a + b
```

### 2.3. 메모리 레이아웃 (C-order vs F-order)
NumPy 배열은 메모리에 데이터를 저장하는 방식에 따라 C-order(행 우선, 기본값)와 F-order(열 우선)로 나뉩니다. 데이터 접근 패턴과 메모리 레이아웃이 일치할 때 CPU 캐시 효율이 극대화되어 연산 속도가 크게 향상됩니다.

- **C-order (행 우선)**: 행 단위로 데이터에 접근할 때 빠릅니다. (`sum(axis=1)`)
- **F-order (열 우선)**: 열 단위로 데이터에 접근할 때 빠릅니다. (`sum(axis=0)`)

```python
size = 5000
arr_c = np.random.rand(size, size) # C-order
arr_f = np.asfortranarray(arr_c)   # F-order

print("--- C-order 배열 성능 ---")
%timeit arr_c.sum(axis=1) # 빠름
%timeit arr_c.sum(axis=0) # 상대적으로 느림

print("\n--- F-order 배열 성능 ---")
%timeit arr_f.sum(axis=1) # 상대적으로 느림
%timeit arr_f.sum(axis=0) # 빠름
```

### 2.4. 인플레이스(In-place) 연산 활용
연산 결과를 저장하기 위해 새로운 배열을 생성하는 대신, 기존 배열의 메모리에 덮어쓰는 방식입니다. 대규모 배열에서 불필요한 메모리 할당을 줄여줍니다.

- **연산자 활용**: `a += b`, `a *= b`
- **`out` 인자 활용**: `np.add(a, b, out=a)`

```python
a = np.ones(10_000_000)
b = np.ones(10_000_000)

# 새로운 배열 생성
%timeit c = a + b

# 인플레이스 연산 (메모리 할당 없음)
%timeit np.add(a, b, out=a)
```

### 2.5. `np.vectorize`의 올바른 이해
`np.vectorize`는 순수 파이썬 함수를 배열의 모든 요소에 적용하게 해주는 **편의 기능**입니다. 하지만 이름과 달리 **성능을 향상시키지 않습니다.** 내부적으로 파이썬 `for` 루프를 실행하므로, 진정한 벡터화 연산보다 훨씬 느립니다. 성능이 중요하다면 불리언 인덱싱, `np.where` 등을 사용하여 로직을 구현해야 합니다.

```python
def my_func(x):
    return x * 2 if x > 5 else x / 2

arr = np.array([1, 6, 3, 8])

# 느린 방식: np.vectorize
vectorized_func = np.vectorize(my_func)
%timeit vectorized_func(arr)

# 빠른 방식: np.where
%timeit np.where(arr > 5, arr * 2, arr / 2)
```

### 2.6. `einsum`: 아인슈타인 표기법의 힘
`np.einsum`은 복잡한 다차원 배열 연산(행렬 곱, 전치, 축 합계 등)을 간결하고 통일된 표기법으로 표현하게 해줍니다. 때로는 NumPy가 내부적으로 최적의 연산 순서를 찾아내어, 여러 단계를 거치는 것보다 더 빠르고 메모리 효율적일 수 있습니다.

```python
A = np.random.rand(3, 4)
B = np.random.rand(4, 5)

# 행렬 곱셈
C_dot = A @ B
C_einsum = np.einsum('ij,jk->ik', A, B)
assert np.allclose(C_dot, C_einsum)

# 기타 연산 예시
# 전치(Transpose): A.T
print(np.einsum('ij->ji', A))
# 대각합(Trace)
print(np.einsum('ii->', np.random.rand(5,5)))
# 배치 행렬 곱
C = np.random.rand(10, 3, 4)
D = np.random.rand(10, 4, 5)
E = np.einsum('bij,bjk->bik', C, D)
print(f"배치 행렬 곱 결과 shape: {E.shape}")
```
### 2.7. 코드 프로파일링 (Code Profiling)              
코드 프로파일링은 프로그램의 성능 병목 현상을 식별하고 최적화 기회를 찾는 데 필수적인 과정입니다. 단순히 코드를 빠르게 만드는 것 이상으로, 실제로 시간이 많이 소요되는 부분을 정확히 찾아내어 효율적인 최적화 전략을 수립할 수 있도록 돕습니다.                                       
                                                       
**주요 프로파일링 도구:**                              
-   **`cProfile` (내장 모듈)**: 파이썬 함수 호출의 시간과 횟수를 측정하여 함수 단위의 성능 분석을 제공합니다. 별도의 설치 없이 바로 사용할 수 있습니다.                                           
-   **`line_profiler` (외부 라이브러리)**:             
코드의 각 라인별 실행 시간을 측정하여 더 세밀한 성능 분석을 가능하게 합니다. (`pip install line_profiler`)                                             
-   **`memory_profiler` (외부 라이브러리)**:           
코드의 메모리 사용량을 추적하여 메모리 누수나 비효율적인 메모리 사용을 식별하는 데 도움을 줍니다. (`pip install memory_profiler`)                
                                                       
**`cProfile`을 이용한 NumPy 코드 프로파일링 예시:**                                                
`cProfile`은 특히 어떤 함수가 전체 실행 시간의 대부분을 차지하는지 파악하는 데 유용합니다.            
                                                       
```python                                              
import numpy as np                                     
import cProfile                                        
import pstats # 프로파일링 결과 분석을 위한 모듈       
                                                       
def complex_numpy_operation(size):                     
    a = np.random.rand(size, size)                     
    b = np.random.rand(size, size)                     
    c = np.dot(a, b) # 행렬 곱셈                       
    d = np.sum(c)    # 합계 계산                       
    e = np.linalg.inv(a) # 역행렬 계산 (비용이 큰 연산)                                               
    return d, e                                        
                                                       
# 프로파일링 실행                                      
profiler = cProfile.Profile()                          
profiler.enable() # 프로파일링 시작                    
                                                       
# 성능을 측정하고 싶은 코드 실행                       
result_d, result_e = complex_numpy_                    
operation(500)                                         
                                                       
profiler.disable() # 프로파일링 종료                   
                                                       
# 결과 분석 및 출력                                    
stats = pstats.Stats(profiler).sort                    
_stats('cumulative') # 누적 시간 기준으로 정렬         
stats.print_stats(10) # 상위 10개 함수 출력            
```
