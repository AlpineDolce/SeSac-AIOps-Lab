## 1. 난수 생성 (Random Number Generation)

NumPy의 `random` 모듈은 다양한 확률 분포로부터 난수를 생성하는 강력한 기능을 제공합니다. 이는 모델 초기화, 데이터 증강, 시뮬레이션 등에 활용됩니다.

난수 생성은 머신러닝 및 데이터 과학에서 매우 중요한 역할을 합니다.
- **데이터 증강(Augmentation)**: 기존 데이터를 무작위로 변형하여 학습 데이터 양을 늘립니다.
- **모델 파라미터 초기화**: 신경망의 가중치를 무작위로 초기화하여 학습을 최적화합니다.
- **데이터 샘플링**: 훈련/검증/테스트 세트를 나누거나, 부트스트래핑(Bootstrapping)과 같은 통계적 기법에 사용됩니다.
- **알고리즘의 무작위성**: 시뮬레이션이나 특정 알고리즘(예: RANSAC)에 무작위성을 부여합니다.

### 1.1. 기본 난수 생성 함수

NumPy의 `np.random` 모듈은 다양한 형태의 기본 난수를 생성하는 함수를 제공합니다.

#### 1.1.1. `np.random.rand()`

`np.random.rand(d0, d1, ..., dn)` 함수는 `0.0` 이상 `1.0` 미만의 균일 분포(uniform distribution)에서 난수를 생성합니다. 인수는 생성할 배열의 차원(shape)을 직접 지정합니다.

```python
import numpy as np

# 0.0에서 1.0 사이의 균일 분포 난수 5개 생성
random_uniform_rand = np.random.rand(5)
print(f"균일 분포 난수 (rand): {random_uniform_rand}")

# 2x3 형태의 균일 분포 난수 행렬
random_matrix_rand = np.random.rand(2, 3)
print(f"\n2x3 균일 분포 난수 행렬:\n{random_matrix_rand}")
```

#### 1.1.2. `np.random.randn()`

`np.random.randn(d0, d1, ..., dn)` 함수는 표준 정규 분포(standard normal distribution, 평균 0, 표준편차 1)에서 난수를 생성합니다. 인수는 생성할 배열의 차원(shape)을 직접 지정합니다.

```python
import numpy as np

# 표준 정규 분포 난수 5개 생성
random_normal_randn = np.random.randn(5)
print(f"표준 정규 분포 난수 (randn): {random_normal_randn}")

# 2x3 형태의 표준 정규 분포 난수 행렬
normal_dist_matrix_randn = np.random.randn(2, 3)
print(f"\n2x3 표준 정규 분포 난수 행렬:\n{normal_dist_matrix_randn}")
```

#### 1.1.3. `np.random.randint()`

`np.random.randint(low, high=None, size=None, dtype=int)` 함수는 `low` (포함)부터 `high` (미포함) 사이의 정수 난수를 생성합니다. `size`로 배열의 형태를 지정할 수 있습니다.

```python
import numpy as np

# 1부터 10까지의 정수 난수 5개 생성 (10은 포함 안됨)
random_int = np.random.randint(low=1, high=10, size=5)
print(f"정수 난수 (randint): {random_int}")

# 0부터 100까지의 정수 난수 3x3 행렬
random_int_matrix = np.random.randint(0, 101, size=(3, 3))
print(f"\n3x3 정수 난수 행렬:\n{random_int_matrix}")
```

#### 1.1.4. `np.random.random()`

`np.random.random(size=None)` 함수는 `0.0` 이상 `1.0` 미만의 균일 분포에서 난수를 생성합니다. `size` 인자를 통해 배열의 형태를 지정할 수 있습니다. `np.random.rand()`와 유사하지만, `size` 인자를 튜플로 직접 전달할 수 있다는 점에서 차이가 있습니다.

```python
import numpy as np

# 0.0에서 1.0 사이의 균일 분포 난수 (size 지정)
random_uniform_random = np.random.random(size=(2, 3))
print(f"균일 분포 난수 (random):\n{random_uniform_random}")
```

### 1.2. 다양한 확률 분포

NumPy는 다양한 통계적 분포를 따르는 난수를 생성하는 함수를 제공합니다.

#### 1.2.1. 정규 분포 (Normal Distribution)

정규 분포(Normal Distribution)는 가우시안 분포라고도 불리며, 자연 현상에서 가장 흔하게 나타나는 분포 중 하나입니다. 평균(`loc`)과 표준편차(`scale`)를 인자로 받아 난수를 생성합니다.

```python
import numpy as np

# 정규 분포 (Normal Distribution): 평균(loc)과 표준편차(scale) 지정
normal_dist = np.random.normal(loc=0, scale=1, size=(2, 2))
print(f"정규 분포 난수 (normal):\n{normal_dist}")
```

#### 1.2.2. 균일 분포 (Uniform Distribution)

균일 분포(Uniform Distribution)는 주어진 범위 내의 모든 값이 동일한 확률로 나타나는 분포입니다. 최소값(`low`)과 최대값(`high`)을 인자로 받아 난수를 생성합니다.

```python
import numpy as np

# 균일 분포 (Uniform Distribution): 최소값(low)과 최대값(high) 지정
uniform_dist = np.random.uniform(low=-1, high=1, size=3)
print(f"균일 분포 난수 (uniform): {uniform_dist}")
```

#### 1.2.3. 이항 분포 (Binomial Distribution)

이항 분포(Binomial Distribution)는 고정된 횟수의 독립적인 시행에서 성공 횟수를 나타내는 이산 확률 분포입니다. 시행 횟수(`n`)와 성공 확률(`p`)을 인자로 받아 난수를 생성합니다.

```python
import numpy as np

# 이항 분포 (Binomial Distribution): 시행 횟수(n), 성공 확률(p), 시행 횟수(size)
binomial_dist = np.random.binomial(n=10, p=0.5, size=5)
print(f"이항 분포 난수 (binomial): {binomial_dist}")
```

#### 1.2.4. 포아송 분포 (Poisson Distribution)

포아송 분포(Poisson Distribution)는 특정 시간 또는 공간 내에서 어떤 사건이 발생하는 횟수를 나타내는 이산 확률 분포입니다. 평균 발생 횟수(`lam`)를 인자로 받아 난수를 생성합니다.

```python
import numpy as np

# 포아송 분포 (Poisson Distribution): 평균 발생 횟수(lam), 시행 횟수(size)
poisson_dist = np.random.poisson(lam=2, size=5)
print(f"포아송 분포 난수 (poisson): {poisson_dist}")
```

#### 1.2.5. 감마 분포 (Gamma Distribution)

감마 분포(Gamma Distribution)는 양의 값을 가지는 연속 확률 분포로, 대기 시간이나 수명 분석 등에 사용됩니다. 형태 모수(`shape`)와 스케일 모수(`scale`)를 인자로 받아 난수를 생성합니다.

```python
import numpy as np

# 감마 분포 (Gamma Distribution): 형태 모수(shape), 스케일 모수(scale), 시행 횟수(size)
gamma_dist = np.random.gamma(shape=2, scale=1, size=3)
print(f"감마 분포 난수 (gamma): {gamma_dist}")
```

### 1.3. 재현 가능한 난수 생성: `np.random.seed`와 `RandomState`

난수 생성은 기본적으로 무작위적이지만, 연구나 디버깅 시에는 동일한 난수 시퀀스를 반복해서 생성해야 할 필요가 있습니다. 이를 위해 **시드(seed)**를 설정합니다.

-   `np.random.seed(seed)`: 전역 난수 생성기의 시드를 설정합니다. 한 번 설정하면 이후의 모든 `np.random` 호출에 영향을 미칩니다.
-   `np.random.RandomState(seed)`: 독립적인 난수 생성기 객체를 생성합니다. 여러 개의 독립적인 난수 스트림이 필요할 때 유용하며, 전역 시드 설정과 충돌하지 않습니다.

```python
import numpy as np

# np.random.seed를 사용한 재현성
np.random.seed(42)
rand_a = np.random.rand(3)
np.random.seed(42) # 다시 시드를 설정해야 동일한 시퀀스 시작
rand_b = np.random.rand(3)
print(f"\n시드 설정 후 난수 A (np.random.seed): {rand_a}")
print(f"시드 설정 후 난수 B (np.random.seed): {rand_b}") # rand_a와 동일한 결과

# RandomState 객체를 사용한 재현성 (권장)
# 각 RandomState 객체는 독립적인 난수 스트림을 가집니다.
rs1 = np.random.RandomState(123)
rs2 = np.random.RandomState(456)
rs3 = np.random.RandomState(123) # rs1과 동일한 시퀀스

print(f"\nRandomState 1 (첫 번째 호출): {rs1.rand(3)}")
print(f"RandomState 2 (첫 번째 호출): {rs2.rand(3)}")
print(f"RandomState 1 (두 번째 호출): {rs1.rand(3)}") # rs1의 다음 난수
print(f"RandomState 3 (첫 번째 호출): {rs3.rand(3)}") # rs1의 첫 번째 호출과 동일
```
### 1.4. 최신 난수 생성 API: `np.random.Generator`

NumPy 1.17 버전부터는 새로운 난수 생성 API 사용이 강력하게 권장됩니다. 이는 `np.random.default_rng()`를 통해 **생성기(`Generator`)** 객체를 먼저 만든 후, 그 객체의 메서드를 호출하는 방식입니다.

#### 1.4.1. 왜 새로운 API를 사용해야 하는가?

- **재현성(Reproducibility)**: `np.random.seed()`와 같은 전역(global) 상태에 의존하지 않고, 생성기 객체별로 독립적인 난수 스트림을 가집니다. 이는 코드의 다른 부분에 영향을 주지 않아 복잡한 프로그램에서도 실험의 재현성을 보장하기 훨씬 용이합니다.
- **성능 및 확장성**: 더 빠르고 통계적으로 우수한 품질의 난수를 생성하는 알고리즘(PCG64)을 기본으로 사용하며, 새로운 알고리즘으로 확장하기 쉽습니다.

#### 1.4.2. `Generator` 생성 및 시드(Seed) 설정
`np.random.default_rng()` 함수에 정수 시드 값을 전달하여 생성기를 초기화합니다. 동일한 시드로 생성된 생성기는 항상 동일한 순서의 난수를 반환합니다.

```python
import numpy as np

# 시드를 설정하여 난수 생성기 생성
rng = np.random.default_rng(seed=42)

# 생성기의 메서드를 사용하여 난수 생성
print(f"랜덤 실수 배열:\n{rng.random(size=(2, 3))}")
print(f"랜덤 정수 배열:\n{rng.integers(0, 10, size=(2, 3))}")

# 동일한 시드로 다시 생성하면 완전히 동일한 결과가 나옴
rng_same = np.random.default_rng(seed=42)
print(f"\n동일 시드로 다시 생성한 배열:\n{rng_same.random(size=(2, 3))}")
```

#### 1.4.3. 주요 난수 생성 메서드

`Generator` 객체는 다양한 분포의 난수를 생성하는 메서드를 제공합니다.

##### 1.4.3.1. `rng.random()`

`rng.random(size)` 메서드는 `[0.0, 1.0)` 범위에서 균등 분포의 실수를 생성합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 0.0에서 1.0 사이의 균등 분포 실수 배열 생성
random_floats_rng = rng.random(size=(2, 3))
print(f"균등 분포 실수 (rng.random):\n{random_floats_rng}")
```

##### 1.4.3.2. `rng.integers()`

`rng.integers(low, high, size)` 메서드는 `[low, high)` 범위에서 균등 분포의 정수를 생성합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 0부터 10까지의 정수 난수 배열 생성
random_integers_rng = rng.integers(0, 10, size=(2, 3))
print(f"정수 난수 (rng.integers):\n{random_integers_rng}")
```

##### 1.4.3.3. `rng.standard_normal()`

`rng.standard_normal(size)` 메서드는 표준 정규 분포(평균 0, 표준편차 1)의 실수를 생성합니다. 이는 전통적인 `np.random.randn()`과 유사합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 표준 정규 분포에서 2x3 크기의 배열 생성
normal_dist_rng = rng.standard_normal(size=(2, 3))
print(f"표준 정규 분포 (rng.standard_normal):\n{normal_dist_rng}")
```

##### 1.4.3.4. `rng.uniform()`

`rng.uniform(low, high, size)` 메서드는 `[low, high)` 범위에서 균등 분포의 실수를 생성합니다. 이는 전통적인 `np.random.uniform()`과 유사합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# -1부터 1까지의 균등 분포 실수 배열 생성
uniform_dist_rng = rng.uniform(low=-1, high=1, size=3)
print(f"균일 분포 실수 (rng.uniform): {uniform_dist_rng}")
```

##### 1.4.3.5. `rng.normal()`

`rng.normal(loc, scale, size)` 메서드는 정규 분포(평균 `loc`, 표준편차 `scale`)의 실수를 생성합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 평균 10, 표준편차 2인 정규 분포 난수 배열 생성
custom_normal_rng = rng.normal(loc=10.0, scale=2.0, size=3)
```

## 2. 샘플링 및 순열 (Sampling & Permutation)

데이터를 무작위로 섞거나 샘플링하는 것은 교차 검증(Cross-validation)이나 부트스트래핑(Bootstrapping) 등 통계적 검증 및 모델 학습 과정에서 매우 중요합니다. 여기서는 전통적인 `np.random` 모듈의 함수들을 살펴봅니다.

### 2.1. `np.random.shuffle()`

`np.random.shuffle(x)` 함수는 배열 `x`의 순서를 제자리에서(in-place) 무작위로 섞습니다. 원본 배열이 변경되며, 반환값이 없습니다.

```python
import numpy as np

arr_shuffle = np.arange(10)
print(f"원본 배열: {arr_shuffle}")

# 순서 섞기 (제자리 변경)
np.random.shuffle(arr_shuffle)
print(f"shuffle 후 배열: {arr_shuffle}")
```

### 2.2. `np.random.permutation()`

`np.random.permutation(x)` 함수는 배열 `x`의 순서를 무작위로 섞은 새로운 배열(복사본)을 반환합니다. 원본 배열은 변경되지 않습니다. 정수 `x`가 주어지면 `np.arange(x)`의 순열을 반환합니다.

```python
import numpy as np

# 순서 섞인 복사본 생성 (정수 인자)
arr_perm_int = np.random.permutation(10) # np.arange(10)의 순열
print(f"permutation 결과 (정수 인자): {arr_perm_int}")

# 순서 섞인 복사본 생성 (배열 인자)
arr_perm_array = np.random.permutation(np.array([1, 2, 3, 4, 5]))
print(f"permutation 결과 (배열 인자): {arr_perm_array}")
```

### 2.3. `np.random.choice()`

`np.random.choice(a, size=None, replace=True, p=None)` 함수는 배열 `a`에서 주어진 `size`만큼 무작위로 샘플을 추출합니다. `replace=True`는 복원 추출(중복 허용)을 의미하며, `p`는 각 요소가 선택될 확률을 지정합니다.

```python
import numpy as np

# 0~4 중에서 5개를 비복원 추출 (중복 없음)
choice_no_replace = np.random.choice(5, 5, replace=False)
print(f"비복원 추출: {choice_no_replace}")

# 0~4 중에서 10개를 복원 추출 (중복 허용)
choice_with_replace = np.random.choice(5, 10, replace=True)
print(f"복원 추출: {choice_with_replace}")

# 확률을 지정하여 샘플 추출
data = ['A', 'B', 'C', 'D']
probabilities = [0.1, 0.2, 0.3, 0.4]
weighted_choice = np.random.choice(data, size=5, p=probabilities)
print(f"확률을 고려한 샘플 추출: {weighted_choice}")
```

## 3. 데이터 샘플링 및 순열

생성된 `Generator` 객체는 데이터 샘플링과 순열 생성에도 사용됩니다.

### 3.1. 배열 섞기 (Permutation)

`Generator` 객체를 사용하여 배열을 섞거나 순열을 생성할 수 있습니다.

#### 3.1.1. `rng.shuffle()`

`rng.shuffle(arr)` 메서드는 배열의 내용을 **제자리에서(in-place)** 섞습니다. 반환값이 없습니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

arr_rng_shuffle = np.arange(10)
print(f"원본 배열: {arr_rng_shuffle}")

# 제자리에서 섞기
rng.shuffle(arr_rng_shuffle)
print(f"shuffle 후 배열: {arr_rng_shuffle}")
```

#### 3.1.2. `rng.permutation()`

`rng.permutation(arr)` 메서드는 배열의 내용이 섞인 **새로운 배열(복사본)**을 반환합니다. 원본은 변경되지 않습니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 복사본을 섞어 반환
arr_rng_permuted = rng.permutation(np.arange(10))
print(f"permutation 결과: {arr_rng_permuted}")
```

### 3.2. 무작위 샘플링 (Choice)

`rng.choice(a, size, replace, p)` 메서드는 배열 `a`에서 `size` 만큼의 샘플을 추출합니다.
  - `replace=True`: 복원 추출 (기본값, 중복 허용)
  - `replace=False`: 비복원 추출 (중복 없음)
  - `p`: 각 요소가 선택될 확률을 지정합니다.

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 0~4에서 5개를 비복원 추출 (결과는 0~4의 순열)
sample_no_replace_rng = rng.choice(5, size=5, replace=False)
print(f"비복원 추출: {sample_no_replace_rng}")

# 0~4에서 10개를 복원 추출 (가중치 부여)
weighted_sample_rng = rng.choice(5, size=10, replace=True, p=[0.1, 0.1, 0.5, 0.2, 0.1])
print(f"가중치 부여 복원 추출: {weighted_sample_rng}")
```

## 4. 전통적인(Legacy) 난수 생성 API

`np.random.rand()`, `np.random.randn()`, `np.random.randint()` 등은 전역 상태를 공유하는 전통적인 API입니다. 간단한 스크립트에서는 편리할 수 있지만, 재현성이 중요한 복잡한 애플리케이션에서는 **사용을 지양**하는 것이 좋습니다.

```python
import numpy as np

# 전통적인 방식: np.random.seed()로 전역 시드 설정
np.random.seed(42)
legacy_random = np.random.rand(2, 3)
print(f"\n전통적 API 결과:\n{legacy_random}")
```
