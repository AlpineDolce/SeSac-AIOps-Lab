## 1. 난수 생성 (Random Number Generation)

NumPy의 `random` 모듈은 다양한 확률 분포로부터 난수를 생성하는 강력한 기능을 제공합니다. 이는 모델 초기화, 데이터 증강, 시뮬레이션 등에 활용됩니다.

난수 생성은 머신러닝 및 데이터 과학에서 매우 중요한 역할을 합니다.
- **데이터 증강(Augmentation)**: 기존 데이터를 무작위로 변형하여 학습 데이터 양을 늘립니다.
- **모델 파라미터 초기화**: 신경망의 가중치를 무작위로 초기화하여 학습을 최적화합니다.
- **데이터 샘플링**: 훈련/검증/테스트 세트를 나누거나, 부트스트래핑(Bootstrapping)과 같은 통계적 기법에 사용됩니다.
- **알고리즘의 무작위성**: 시뮬레이션이나 특정 알고리즘(예: RANSAC)에 무작위성을 부여합니다.

### 1.1. 기본 난수 생성 함수

NumPy의 `np.random` 모듈은 다양한 형태의 기본 난수를 생성하는 함수를 제공합니다.

#### 1.1.1. `np.random.rand()`

`np.random.rand(d0, d1, ..., dn)` 함수는 **0.0 (포함) 이상 1.0 (미만) 사이의 균일 분포(uniform distribution)**에서 난수를 생성합니다. 이 함수는 인수로 생성할 배열의 차원(shape)을 직접 지정합니다. 즉, `d0, d1, ..., dn`은 각각 결과 배열의 첫 번째, 두 번째, ..., n번째 차원의 크기를 나타냅니다.

**주요 특징:**
*   **분포**: `[0.0, 1.0)` 범위의 균일 분포에서 난수를 추출합니다. 이는 모든 값이 동일한 확률로 나타나는 분포를 의미합니다.
*   **인수 방식**: `size` 키워드 인자 없이, 원하는 차원의 크기를 개별 인수로 전달합니다. 예를 들어, `np.random.rand(2, 3)`은 2x3 행렬을 생성합니다.
*   **반환 값**: 지정된 차원(shape)을 가진 `numpy.ndarray` 객체를 반환하며, 요소들은 부동 소수점(float) 난수입니다.
*   **레거시 API**: 이 함수는 `np.random` 모듈의 전통적인(legacy) API에 속합니다. 최신 코드에서는 `np.random.default_rng().random()` 사용이 권장됩니다.

**`np.random.random()`과의 차이점:**
`np.random.random(size=None)` 함수도 `[0.0, 1.0)` 범위의 균일 분포에서 난수를 생성합니다. 주요 차이점은 인수를 전달하는 방식입니다.
*   `np.random.rand(d0, d1, ...)`: 차원을 개별 인수로 받습니다.
*   `np.random.random(size=(d0, d1, ...))`: 차원을 `size` 키워드 인자의 튜플로 받습니다.

기능적으로는 매우 유사하지만, `np.random.random()`이 `size` 인자를 통해 더 명시적이고 유연한 차원 지정을 가능하게 합니다.

**`np.random.randn()`과의 차이점:**
`np.random.randn()`은 표준 정규 분포(평균 0, 표준편차 1)에서 난수를 생성하는 반면, `np.random.rand()`는 균일 분포에서 난수를 생성합니다. 두 함수는 인수를 전달하는 방식은 유사하지만, 생성하는 난수의 통계적 분포가 완전히 다릅니다.

**예시:**

```python
import numpy as np

# 단일 난수 생성 (0차원 배열과 유사)
random_single = np.random.rand()
print(f"단일 균일 분포 난수: {random_single}")

# 0.0에서 1.0 사이의 균일 분포 난수 5개 생성 (1차원 배열)
random_uniform_rand_1d = np.random.rand(5)
print(f"\n1차원 균일 분포 난수 (rand): {random_uniform_rand_1d}")

# 2x3 형태의 균일 분포 난수 행렬 (2차원 배열)
random_matrix_rand_2d = np.random.rand(2, 3)
print(f"\n2x3 균일 분포 난수 행렬 (rand):\n{random_matrix_rand_2d}")

# 2x2x2 형태의 3차원 배열
random_3d_array = np.random.rand(2, 2, 2)
print(f"\n2x2x2 균일 분포 난수 배열 (rand):\n{random_3d_array}")
```


#### 1.1.2. `np.random.randn()`

`np.random.randn(d0, d1, ..., dn)` 함수는 **표준 정규 분포(standard normal distribution)**에서 난수를 생성합니다. 표준 정규 분포는 평균(mean)이 0이고 표준편차(standard deviation)가 1인 정규 분포를 의미합니다. 이 함수도 `np.random.rand()`와 마찬가지로 인수로 생성할 배열의 차원(shape)을 직접 지정합니다.

**주요 특징:**
*   **분포**: 평균 0, 표준편차 1인 표준 정규 분포(가우시안 분포)에서 난수를 추출합니다. 이는 종 모양의 대칭적인 분포를 가지며, 0을 중심으로 값이 분포합니다.
*   **인수 방식**: `np.random.rand()`와 동일하게, 원하는 차원의 크기를 개별 인수로 전달합니다. 예를 들어, `np.random.randn(2, 3)`은 2x3 행렬을 생성합니다.
*   **반환 값**: 지정된 차원(shape)을 가진 `numpy.ndarray` 객체를 반환하며, 요소들은 부동 소수점(float) 난수입니다.
*   **레거시 API**: 이 함수는 `np.random` 모듈의 전통적인(legacy) API에 속합니다. 최신 코드에서는 `np.random.default_rng().standard_normal()` 또는 `np.random.default_rng().normal()` 사용이 권장됩니다.

**`np.random.rand()`와의 차이점:**
*   `np.random.rand()`: `[0.0, 1.0)` 범위의 **균일 분포**에서 난수를 생성합니다.
*   `np.random.randn()`: **표준 정규 분포**에서 난수를 생성합니다.

두 함수는 인수를 전달하는 방식은 유사하지만, 생성하는 난수의 통계적 분포가 완전히 다르므로 사용 목적에 맞게 선택해야 합니다.

**`np.random.normal()`과의 차이점:**
`np.random.normal(loc=0.0, scale=1.0, size=None)` 함수는 사용자가 직접 평균(`loc`)과 표준편차(`scale`)를 지정하여 정규 분포 난수를 생성할 수 있습니다. 반면 `np.random.randn()`은 평균 0, 표준편차 1로 고정된 표준 정규 분포만을 생성합니다. 따라서 특정 평균과 표준편차를 가진 정규 분포가 필요하다면 `np.random.normal()`을 사용하는 것이 더 적합합니다.

**예시:**

```python
import numpy as np

# 단일 표준 정규 분포 난수 생성
random_single_normal = np.random.randn()
print(f"단일 표준 정규 분포 난수: {random_single_normal}")

# 표준 정규 분포 난수 5개 생성 (1차원 배열)
random_normal_randn_1d = np.random.randn(5)
print(f"\n1차원 표준 정규 분포 난수 (randn): {random_normal_randn_1d}")

# 2x3 형태의 표준 정규 분포 난수 행렬 (2차원 배열)
normal_dist_matrix_randn_2d = np.random.randn(2, 3)
print(f"\n2x3 표준 정규 분포 난수 행렬 (randn):\n{normal_dist_matrix_randn_2d}")

# 2x2x2 형태의 3차원 표준 정규 분포 배열
random_3d_normal = np.random.randn(2, 2, 2)
print(f"\n2x2x2 표준 정규 분포 난수 배열 (randn):\n{random_3d_normal}")
```

#### 1.1.3. `np.random.randint()`

`np.random.randint(low, high=None, size=None, dtype=int)` 함수는 지정된 범위 내에서 **정수 난수**를 생성합니다. 이 함수는 `low` (포함)부터 `high` (미포함) 사이의 정수를 균일하게 추출합니다. `size` 인자를 통해 생성할 배열의 형태를 지정할 수 있습니다.

**주요 특징:**
*   **범위**: `low` 값은 결과에 포함되지만, `high` 값은 포함되지 않습니다. 예를 들어, `randint(1, 10)`은 1부터 9까지의 정수를 생성합니다.
*   **인수**: 
    *   `low`: 생성될 가장 작은 정수 (포함). `high`가 `None`이면, `[0, low)` 범위에서 난수를 생성합니다.
    *   `high`: 생성될 가장 큰 정수 (미포함). 기본값은 `None`입니다.
    *   `size`: 선택 사항. 생성할 배열의 형태를 지정하는 튜플 또는 정수. `None`이면 단일 정수를 반환합니다.
    *   `dtype`: 선택 사항. 반환될 정수의 데이터 타입. 기본값은 `int`입니다.
*   **반환 값**: `size`가 `None`이면 단일 정수를, 그렇지 않으면 지정된 형태의 `numpy.ndarray`를 반환합니다.
*   **분포**: 이산 균일 분포(discrete uniform distribution)에서 난수를 추출합니다.
*   **레거시 API**: 이 함수는 `np.random` 모듈의 전통적인(legacy) API에 속합니다. 최신 코드에서는 `np.random.default_rng().integers()` 사용이 권장됩니다.

**`np.random.default_rng().integers()`와의 차이점:**
최신 `Generator` 객체의 `integers()` 메서드는 `endpoint=True` 인자를 제공하여 `high` 값을 포함할지 여부를 명시적으로 제어할 수 있습니다. 이는 `np.random.randint()`의 `high` 미포함 동작으로 인한 혼란을 줄여줍니다.

**예시:**

```python
import numpy as np

# 1부터 10까지의 정수 난수 1개 생성 (10은 포함 안됨, 즉 1~9)
random_single_int = np.random.randint(1, 10)
print(f"단일 정수 난수 (1~9): {random_single_int}")

# 1부터 10까지의 정수 난수 5개 생성 (10은 포함 안됨, 즉 1~9)
random_int_1d = np.random.randint(low=1, high=10, size=5)
print(f"\n1차원 정수 난수 (1~9): {random_int_1d}")

# 0부터 100까지의 정수 난수 3x3 행렬 생성 (101은 포함 안됨, 즉 0~100)
random_int_matrix_2d = np.random.randint(0, 101, size=(3, 3))
print(f"\n3x3 정수 난수 행렬 (0~100):\n{random_int_matrix_2d}")

# high 인자 생략 시 (0부터 low-1까지)
random_int_no_high = np.random.randint(5, size=3) # 0부터 4까지의 정수 3개
print(f"\nhigh 생략 시 (0~4): {random_int_no_high}")
```

#### 1.1.4. `np.random.random()`

`np.random.random(size=None)` 함수는 `0.0` (포함) 이상 `1.0` (미만) 사이의 **균일 분포(uniform distribution)**에서 난수를 생성합니다. 이 함수는 `size` 인자를 통해 생성할 배열의 형태를 지정할 수 있습니다. `np.random.rand()`와 유사하지만, 차원 정보를 `size` 인자의 튜플로 직접 전달한다는 점에서 차이가 있습니다.

**주요 특징:**
*   **분포**: `[0.0, 1.0)` 범위의 균일 분포에서 난수를 추출합니다.
*   **인수 방식**: `size` 키워드 인자를 통해 생성할 배열의 형태를 튜플로 지정합니다. 예를 들어, `np.random.random(size=(2, 3))`은 2x3 행렬을 생성합니다. `size=None`이면 단일 스칼라 값을 반환합니다.
*   **반환 값**: `size`가 `None`이면 단일 부동 소수점(float) 값을, 그렇지 않으면 지정된 형태의 `numpy.ndarray`를 반환합니다.
*   **레거시 API**: 이 함수는 `np.random` 모듈의 전통적인(legacy) API에 속합니다. 최신 코드에서는 `np.random.default_rng().random()` 사용이 권장됩니다.

**`np.random.rand()`와의 차이점:**
두 함수 모두 `[0.0, 1.0)` 범위의 균일 분포에서 난수를 생성한다는 점에서 기능적으로 동일합니다. 그러나 인수를 전달하는 방식에서 차이가 있습니다.
*   `np.random.rand(d0, d1, ...)`: 차원을 개별 인수로 받습니다 (예: `np.random.rand(2, 3)`).
*   `np.random.random(size=(d0, d1, ...))`: 차원을 `size` 키워드 인자의 튜플로 받습니다 (예: `np.random.random(size=(2, 3))`).

`np.random.random()`의 `size` 인자 방식이 더 명시적이고 파이썬의 다른 함수들과 일관성이 있어 선호될 수 있습니다.

**`np.random.default_rng().random()`과의 관계:**
`np.random.default_rng().random()`은 `np.random.random()`의 최신 `Generator` API 버전입니다. 동일한 기능을 제공하지만, `Generator` 객체를 통해 난수 스트림을 독립적으로 관리할 수 있어 재현성 및 모범 사례 측면에서 더 우수합니다.

**예시:**

```python
import numpy as np

# 단일 난수 생성 (size=None)
random_single_random = np.random.random()
print(f"단일 균일 분포 난수 (random): {random_single_random}")

# 0.0에서 1.0 사이의 균일 분포 난수 5개 생성 (1차원 배열)
random_uniform_random_1d = np.random.random(size=5)
print(f"\n1차원 균일 분포 난수 (random): {random_uniform_random_1d}")

# 2x3 형태의 균일 분포 난수 행렬 (2차원 배열)
random_matrix_random_2d = np.random.random(size=(2, 3))
print(f"\n2x3 균일 분포 난수 행렬 (random):\n{random_matrix_random_2d}")

# 2x2x2 형태의 3차원 배열
random_3d_array_random = np.random.random(size=(2, 2, 2))
print(f"\n2x2x2 균일 분포 난수 배열 (random):\n{random_3d_array_random}")
```

### 1.2. 다양한 확률 분포

NumPy는 통계적 모델링 및 시뮬레이션에 필수적인 다양한 확률 분포로부터 난수를 생성하는 함수를 제공합니다. 각 분포는 특정 현상을 모델링하는 데 적합하며, 적절한 분포를 선택하는 것은 데이터 분석 및 모델링의 정확성을 높이는 데 중요합니다.

#### 1.2.1. 정규 분포 (Normal Distribution)

**정규 분포(Normal Distribution)**는 **가우시안 분포(Gaussian Distribution)**라고도 불리며, 자연 현상에서 가장 흔하게 나타나는 대칭적인 종(bell) 모양의 연속 확률 분포입니다. 통계학 및 데이터 과학에서 가장 중요하고 널리 사용되는 분포 중 하나입니다. **중심 극한 정리(Central Limit Theorem)**에 의해 많은 독립적인 확률 변수들의 합이나 평균은 표본의 크기가 커질수록 정규 분포를 따르는 경향이 있습니다.

**정의 및 파라미터:**
정규 분포는 두 가지 모수(parameter)에 의해 완전히 결정됩니다.
*   `loc` (평균, $\mu$): 분포의 중심을 나타냅니다. 종 모양 곡선의 정점 위치입니다.
*   `scale` (표준편차, $\sigma$): 분포의 퍼짐 정도를 나타냅니다. 표준편차가 클수록 곡선은 더 넓고 납작해집니다.

**주요 특징:**
*   **대칭성**: 평균을 중심으로 완벽하게 대칭인 종 모양을 가집니다.
*   **평균, 중앙값, 최빈값 일치**: 정규 분포에서는 평균, 중앙값, 최빈값이 모두 동일합니다.
*   **점근선**: 곡선은 x축에 점근적으로 접근하지만, 결코 닿지 않습니다.
*   **68-95-99.7 규칙 (경험적 규칙)**:
    *   데이터의 약 68%가 평균에서 1 표준편차 이내에 분포합니다.
    *   데이터의 약 95%가 평균에서 2 표준편차 이내에 분포합니다.
    *   데이터의 약 99.7%가 평균에서 3 표준편차 이내에 분포합니다.
*   **표준 정규 분포**: 평균이 0이고 표준편차가 1인 정규 분포를 특별히 **표준 정규 분포(Standard Normal Distribution)**라고 합니다. 모든 정규 분포는 표준화를 통해 표준 정규 분포로 변환될 수 있습니다.

**활용 분야:**
정규 분포는 다음과 같은 다양한 분야에서 핵심적으로 활용됩니다.
*   **자연 현상 모델링**: 사람의 키, 몸무게, 혈압, 시험 점수, 측정 오차 등 많은 자연 및 사회 현상의 데이터를 모델링하는 데 널리 사용됩니다.
*   **통계적 추론**: 가설 검정, 신뢰 구간 추정 등 통계적 추론의 기본 가정으로 사용됩니다.
*   **머신러닝**: 
    *   **데이터 전처리**: 특성 스케일링(예: 표준화)을 통해 데이터를 정규 분포와 유사하게 만들거나, 정규 분포를 가정하는 모델에 적합하게 만듭니다.
    *   **모델 가정**: 선형 회귀 모델의 잔차(오차)가 정규 분포를 따른다는 가정이 있습니다.
    *   **생성 모델**: 가우시안 혼합 모델(GMM), 변분 오토인코더(VAE) 등 일부 생성 모델은 정규 분포를 기반으로 합니다.
    *   **가중치 초기화**: 신경망의 가중치를 정규 분포에서 샘플링하여 초기화하는 경우가 많습니다.
    *   **노이즈 추가**: 모델의 강건성을 높이기 위해 데이터에 정규 분포 노이즈를 추가하기도 합니다.

**NumPy에서의 정규 분포 난수 생성:**
NumPy의 `np.random.default_rng().normal()` 함수를 사용하여 정규 분포 난수를 생성합니다. 이 함수는 `loc` (평균), `scale` (표준편차), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 표준 정규 분포 (평균 0, 표준편차 1) 난수 5개 생성
standard_normal_dist = rng.normal(loc=0, scale=1, size=5)
print(f"표준 정규 분포 난수 (평균 0, 표준편차 1):\n{standard_normal_dist}")

# 평균 10, 표준편차 2인 정규 분포 난수 2x3 행렬 생성
custom_normal_dist = rng.normal(loc=10, scale=2, size=(2, 3))
print(f"\n사용자 정의 정규 분포 난수 (평균 10, 표준편차 2):\n{custom_normal_dist}")

# 평균 0, 표준편차 0.1인 정규 분포 난수 3x3 배열 생성 (작은 노이즈)
small_noise_dist = rng.normal(loc=0, scale=0.1, size=(3, 3))
print(f"\n정규 분포 난수 (작은 노이즈, 평균 0, 표준편차 0.1):\n{small_noise_dist}")
```

#### 1.2.2. 균일 분포 (Uniform Distribution)

**균일 분포(Uniform Distribution)**는 주어진 범위 내의 모든 값이 동일한 확률로 나타나는 연속 확률 분포입니다. 즉, 분포 내의 어떤 값도 다른 값보다 더 자주 나타나지 않습니다. 이는 가장 단순한 형태의 확률 분포 중 하나이며, 난수 생성의 기본이 됩니다.

**정의 및 파라미터:**
균일 분포는 두 가지 모수(parameter)에 의해 정의됩니다.
*   `low` (최소값, $a$): 분포의 하한(inclusive). 생성될 난수의 최소값입니다.
*   `high` (최대값, $b$): 분포의 상한(exclusive). 생성될 난수의 최대값입니다.

**주요 특징:**
*   **확률 밀도 함수(PDF)**: 주어진 구간 $[a, b)$ 내에서는 확률 밀도가 일정하고, 구간 밖에서는 0입니다. 그래프로 그리면 직사각형 형태를 띠기 때문에 **직사각형 분포(Rectangular Distribution)**라고도 불립니다.
*   **동일한 확률**: 구간 내의 모든 점은 동일한 확률 밀도를 가집니다.
*   **평균**: $(a + b) / 2$
*   **분산**: $(b - a)^2 / 12$

**활용 분야:**
균일 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **시뮬레이션**: 무작위 선택이 필요한 시뮬레이션에서 기본 난수 생성기로 사용됩니다.
*   **게임 개발**: 주사위 굴리기, 카드 섞기 등 무작위성이 필요한 게임 요소 구현에 사용됩니다.
*   **암호화**: 암호화 키 생성 등 보안 관련 분야에서 예측 불가능한 난수를 생성하는 데 활용됩니다.
*   **머신러닝**: 
    *   **가중치 초기화**: 신경망의 가중치를 특정 범위의 균일 분포에서 초기화하는 기법(예: Glorot/Xavier 균일 초기화)이 있습니다.
    *   **하이퍼파라미터 튜닝**: 하이퍼파라미터의 탐색 범위를 정의하고, 그 범위 내에서 무작위로 값을 샘플링하는 랜덤 서치(Random Search)에 사용됩니다.
    *   **데이터 증강**: 이미지 회전 각도, 밝기 조절 범위 등을 균일 분포에서 샘플링하여 데이터 증강에 활용할 수 있습니다.
    *   **다른 분포의 난수 생성**: 역변환 샘플링(Inverse Transform Sampling)과 같은 기법을 통해 균일 분포 난수를 사용하여 다른 복잡한 분포의 난수를 생성할 수 있습니다.

**NumPy에서의 균일 분포 난수 생성:**
NumPy의 `np.random.default_rng().uniform()` 함수를 사용하여 균일 분포 난수를 생성합니다. 이 함수는 `low` (최소값), `high` (최대값), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 0.0에서 1.0 사이의 균일 분포 난수 5개 생성 (기본값: low=0.0, high=1.0)
uniform_dist_default = rng.uniform(size=5)
print(f"기본 균일 분포 난수 (0.0~1.0): {uniform_dist_default}")

# -1부터 1까지의 균일 분포 난수 5개 생성
uniform_dist_custom = rng.uniform(low=-1, high=1, size=5)
print(f"\n사용자 정의 균일 분포 난수 (-1~1): {uniform_dist_custom}")

# 10부터 20까지의 균일 분포 난수 2x2 행렬 생성
custom_uniform_dist_matrix = rng.uniform(low=10, high=20, size=(2, 2))
print(f"\n사용자 정의 균일 분포 난수 (10~20, 2x2 행렬):\n{custom_uniform_dist_matrix}")
```

#### 1.2.3. 이항 분포 (Binomial Distribution)

**이항 분포(Binomial Distribution)**는 고정된 횟수(`n`)의 독립적인 **베르누이 시행(Bernoulli trial)**에서 성공 횟수(`k`)를 나타내는 **이산 확률 분포**입니다. 베르누이 시행은 결과가 성공 또는 실패 두 가지 중 하나만 나오는 실험을 의미합니다. 각 시행의 성공 확률(`p`)은 일정하게 유지됩니다.

**정의 및 파라미터:**
이항 분포는 두 가지 모수(parameter)에 의해 정의됩니다.
*   `n` (시행 횟수): 독립적인 베르누이 시행의 총 횟수.
*   `p` (성공 확률): 각 시행에서 성공이 발생할 확률 (0과 1 사이의 값).

**주요 특징:**
*   **고정된 시행 횟수**: 실험은 미리 정해진 횟수 `n`만큼 반복됩니다.
*   **독립적인 시행**: 각 시행의 결과는 다른 시행의 결과에 영향을 미치지 않습니다.
*   **두 가지 결과**: 각 시행은 성공 또는 실패 두 가지 결과만 가집니다.
*   **일정한 성공 확률**: 각 시행에서 성공할 확률 `p`는 항상 동일합니다.
*   **확률 질량 함수(PMF)**: 이항 분포의 확률 질량 함수는 다음과 같습니다.
    $ P(X=k) = \binom{n}{k} p^k (1-p)^{n-k} $
    여기서 $\binom{n}{k} = \frac{n!}{k!(n-k)!}$는 $n$번의 시행 중 $k$번 성공하는 경우의 수를 나타냅니다.
*   **평균**: $np$
*   **분산**: $np(1-p)$

**활용 분야:**
이항 분포는 다음과 같은 상황에서 활용됩니다.
*   **품질 관리**: 특정 생산 라인에서 불량품이 나올 확률이 `p`일 때, `n`개의 제품 중 불량품의 개수를 모델링합니다.
*   **여론 조사**: 특정 질문에 대한 찬성/반대 응답 비율을 예측할 때 사용됩니다.
*   **의학 연구**: 특정 치료법의 성공률이 `p`일 때, `n`명의 환자 중 치료에 성공하는 환자의 수를 모델링합니다.
*   **스포츠 분석**: 농구 선수의 자유투 성공률이 `p`일 때, `n`번의 자유투 시도 중 성공 횟수를 예측합니다.
*   **A/B 테스트**: 웹사이트의 두 가지 버전(A, B) 중 어떤 버전이 더 높은 전환율을 보이는지 통계적으로 분석할 때 사용됩니다.

**NumPy에서의 이항 분포 난수 생성:**
NumPy의 `np.random.default_rng().binomial()` 함수를 사용하여 이항 분포 난수를 생성합니다. 이 함수는 `n` (시행 횟수), `p` (성공 확률), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 동전 10번 던져 앞면이 나온 횟수 (성공 확률 0.5)
# 5번의 시뮬레이션 결과
binomial_dist_coin = rng.binomial(n=10, p=0.5, size=5)
print(f"이항 분포 난수 (동전 던지기, 10회 시행, 5번 시뮬레이션): {binomial_dist_coin}")

# 불량률 20%인 제품 20개 중 불량품 수
# 3번의 시뮬레이션 결과
binomial_dist_defect = rng.binomial(n=20, p=0.2, size=3)
print(f"\n이항 분포 난수 (불량품 수, 20개 중, 3번 시뮬레이션): {binomial_dist_defect}")

# 주사위를 60번 던져 1이 나온 횟수 (성공 확률 1/6)
binomial_dist_dice = rng.binomial(n=60, p=1/6, size=1)
print(f"\n이항 분포 난수 (주사위 60회 던져 1 나온 횟수): {binomial_dist_dice}")
```

#### 1.2.4. 포아송 분포 (Poisson Distribution)

**포아송 분포(Poisson Distribution)**는 특정 시간 간격 또는 공간 영역 내에서 어떤 사건이 발생하는 횟수를 나타내는 **이산 확률 분포**입니다. 이 분포는 사건들이 평균적으로 알려진 상수 비율로 발생하고, 각 사건의 발생이 다른 사건의 발생과 독립적일 때 적용됩니다. 주로 드물게 발생하는 사건(rare events)을 모델링하는 데 사용됩니다.

**정의 및 파라미터:**
포아송 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `lam` (람다, $\lambda$): 주어진 시간 간격 또는 공간 영역에서 사건이 발생하는 평균 횟수. $\lambda > 0$ 이어야 합니다.

**주요 특징:**
*   **사건의 독립성**: 각 사건의 발생은 다른 사건의 발생에 영향을 미치지 않습니다.
*   **일정한 평균 발생률**: 단위 시간/공간당 사건의 평균 발생률은 일정합니다.
*   **희귀 사건 모델링**: 사건 발생 횟수가 적고, 넓은 시간/공간에 걸쳐 무작위로 발생하는 현상에 적합합니다.
*   **확률 질량 함수(PMF)**: 포아송 분포의 확률 질량 함수는 다음과 같습니다.
    $ P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!} $
    여기서 $k$는 특정 시간/공간에서 사건이 발생한 횟수 ($k=0, 1, 2, \dots$), $e$는 자연 상수(약 2.71828)입니다.
*   **평균과 분산**: 포아송 분포의 평균과 분산은 모두 $\lambda$와 같습니다. 즉, $E[X] = \text{Var}(X) = \lambda$ 입니다.

**활용 분야:**
포아송 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **콜센터 전화 수**: 특정 시간 동안 콜센터에 걸려오는 전화의 수.
*   **웹사이트 방문자 수**: 특정 시간 동안 웹사이트에 접속하는 방문자의 수.
*   **교통 사고 수**: 특정 도로 구간에서 하루 동안 발생하는 교통 사고의 수.
*   **생물학**: 특정 지역에서 발견되는 희귀 동식물의 수.
*   **보험**: 특정 기간 동안 발생하는 보험 청구 건수.
*   **방사성 붕괴**: 특정 시간 동안 방사성 물질에서 발생하는 붕괴 횟수.

**NumPy에서의 포아송 분포 난수 생성:**
NumPy의 `np.random.default_rng().poisson()` 함수를 사용하여 포아송 분포 난수를 생성합니다. 이 함수는 `lam` (평균 발생 횟수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 평균 2회 발생하는 사건의 횟수 (예: 콜센터에 시간당 걸려오는 전화 수)
# 5번의 시뮬레이션 결과
poisson_dist_calls = rng.poisson(lam=2, size=5)
print(f"포아송 분포 난수 (평균 2, 5번 시뮬레이션): {poisson_dist_calls}")

# 평균 0.5회 발생하는 희귀 사건의 횟수 (예: 특정 지역에서 하루 동안 발생하는 지진 수)
# 3번의 시뮬레이션 결과
poisson_dist_rare = rng.poisson(lam=0.5, size=3)
print(f"\n포아송 분포 난수 (평균 0.5, 3번 시뮬레이션): {poisson_dist_rare}")

# 평균 10회 발생하는 사건의 횟수 (예: 웹사이트에 분당 방문자 수)
poisson_dist_website = rng.poisson(lam=10, size=(2, 2))
print(f"\n포아송 분포 난수 (평균 10, 2x2 행렬):\n{poisson_dist_website}")
```

#### 1.2.5. 감마 분포 (Gamma Distribution)

**감마 분포(Gamma Distribution)**는 양의 값을 가지는 **연속 확률 분포**로, 주로 어떤 사건이 발생할 때까지 걸리는 시간(대기 시간)이나 특정 프로세스의 완료 시간 등을 모델링하는 데 사용됩니다. 이는 지수 분포(Exponential Distribution)와 카이제곱 분포(Chi-squared Distribution)를 포함하는 일반화된 분포입니다.

**정의 및 파라미터:**
감마 분포는 두 가지 모수(parameter)에 의해 정의됩니다.
*   `shape` (형태 모수, $k$ 또는 $\alpha$): 분포의 형태를 결정합니다. 양의 실수 값입니다. 이 값이 클수록 분포는 정규 분포에 가까워집니다.
*   `scale` (스케일 모수, $\theta$ 또는 $\beta$): 분포의 퍼짐 정도를 결정합니다. 양의 실수 값입니다. 이는 사건 발생률의 역수(평균 대기 시간)로 해석될 수 있습니다.

**주요 특징:**
*   **양의 값**: 감마 분포는 항상 0보다 큰 값을 가집니다.
*   **다양한 형태**: `shape` 모수에 따라 분포의 형태가 크게 달라집니다. `shape`가 1일 때는 지수 분포와 동일합니다.
*   **오른쪽으로 치우침**: `shape` 값이 작을 때는 오른쪽으로 치우친(right-skewed) 형태를 보이지만, `shape` 값이 커질수록 점차 대칭적인 종 모양에 가까워집니다.
*   **확률 밀도 함수(PDF)**: 감마 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; k, \theta) = \frac{1}{\Gamma(k) \theta^k} x^{k-1} e^{-x/\theta} \quad \text{for } x > 0 $
    여기서 $\Gamma(k)$는 감마 함수입니다.
*   **평균**: $k \theta$
*   **분산**: $k \theta^2$

**활용 분야:**
감마 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **신뢰성 공학**: 전자 부품이나 기계의 수명, 시스템 고장 시간 등을 모델링합니다.
*   **대기열 이론**: 콜센터나 은행 등에서 고객이 서비스를 받기까지 기다리는 시간 등을 모델링합니다.
*   **재무 모델링**: 보험 청구액, 주식 수익률의 변동성 등 손실 분포를 모델링합니다.
*   **강수량 모델링**: 특정 기간 동안의 강수량 분포를 모델링합니다.
*   **베이즈 통계학**: 정규 분포의 정밀도(분산의 역수)에 대한 사전 분포(prior distribution)로 사용되는 등 다양한 베이즈 추론에서 활용됩니다.

**NumPy에서의 감마 분포 난수 생성:**
NumPy의 `np.random.default_rng().gamma()` 함수를 사용하여 감마 분포 난수를 생성합니다. 이 함수는 `shape` (형태 모수), `scale` (스케일 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 형태 2, 스케일 1인 감마 분포 난수 5개 생성
# (평균: 2*1=2, 분산: 2*1^2=2)
gamma_dist = rng.gamma(shape=2, scale=1, size=5)
print(f"감마 분포 난수 (shape=2, scale=1): {gamma_dist}")

# 형태 0.5, 스케일 2인 감마 분포 난수 3개 생성
# (평균: 0.5*2=1, 분산: 0.5*2^2=2)
custom_gamma_dist = rng.gamma(shape=0.5, scale=2, size=3)
print(f"\n사용자 정의 감마 분포 난수 (shape=0.5, scale=2): {custom_gamma_dist}")

# 형태 10, 스케일 0.5인 감마 분포 난수 2x2 행렬 생성 (정규 분포에 가까워짐)
# (평균: 10*0.5=5, 분산: 10*0.5^2=2.5)
gamma_dist_large_shape = rng.gamma(shape=10, scale=0.5, size=(2, 2))
print(f"\n감마 분포 난수 (shape=10, scale=0.5, 2x2 행렬):\n{gamma_dist_large_shape}")
```

#### 1.2.6. 로지스틱 분포 (Logistic Distribution)

**로지스틱 분포(Logistic Distribution)**는 로지스틱 회귀와 같은 통계 모델에서 사용되는 S자 형태의 누적 분포 함수(Cumulative Distribution Function, CDF)를 가지는 **연속 확률 분포**입니다. 정규 분포와 유사하게 대칭적인 종 모양을 가지지만, 꼬리 부분이 더 두껍다는 특징이 있습니다. 주로 이진 분류 문제에서 확률을 모델링하거나, 신경망의 활성화 함수(시그모이드)와 관련이 깊습니다.

**정의 및 파라미터:**
로지스틱 분포는 두 가지 모수(parameter)에 의해 정의됩니다.
*   `loc` (위치 모수, $\mu$): 분포의 중심을 나타내며, 분포의 평균과 중앙값에 해당합니다.
*   `scale` (스케일 모수, $s$): 분포의 퍼짐 정도를 결정합니다. 값이 클수록 분포가 넓게 퍼집니다.

**주요 특징:**
*   **대칭성**: `loc` 값을 중심으로 대칭적인 형태를 가집니다.
*   **두꺼운 꼬리**: 정규 분포에 비해 꼬리 부분이 더 두껍습니다. 이는 극단적인 값에 더 높은 확률을 할당한다는 의미입니다.
*   **누적 분포 함수(CDF)와 시그모이드 함수**: 로지스틱 분포의 누적 분포 함수는 **로지스틱 함수(Logistic Function)** 또는 **시그모이드 함수(Sigmoid Function)**와 동일합니다. 이 함수는 0과 1 사이의 값을 반환하여 확률을 나타내는 데 사용됩니다.
    $ F(x; \mu, s) = \frac{1}{1 + e^{-(x-\mu)/s}} $
*   **확률 밀도 함수(PDF)**: 로지스틱 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; \mu, s) = \frac{e^{-(x-\mu)/s}}{s(1 + e^{-(x-\mu)/s})^2} $
*   **평균**: $\mu$
*   **분산**: $\frac{s^2 \pi^2}{3}$

**활용 분야:**
로지스틱 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **로지스틱 회귀(Logistic Regression)**: 이진 분류 문제에서 사건 발생 확률을 예측하는 데 사용되는 핵심 모델입니다. 로지스틱 함수를 통해 선형 모델의 출력을 확률 값으로 변환합니다.
*   **신경망 활성화 함수**: 시그모이드 함수는 한때 신경망의 은닉층에서 널리 사용되던 활성화 함수였습니다. 현재는 ReLU 등 다른 함수들이 더 많이 사용되지만, 출력층에서 이진 분류 확률을 나타낼 때 여전히 사용됩니다.
*   **성장 모델**: 인구 성장, 질병 확산 등 S자 형태의 성장 곡선을 모델링하는 데 사용됩니다.
*   **심리 측정학(Psychometrics)**: 문항 반응 이론(Item Response Theory)에서 개인의 능력에 따른 문항 정답 확률을 모델링하는 데 사용됩니다.
*   **생존 분석(Survival Analysis)**: 사건 발생까지의 시간을 모델링하는 데 사용될 수 있습니다.

**NumPy에서의 로지스틱 분포 난수 생성:**
NumPy의 `np.random.default_rng().logistic()` 함수를 사용하여 로지스틱 분포 난수를 생성합니다. 이 함수는 `loc` (위치 모수), `scale` (스케일 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 위치 0, 스케일 1인 로지스틱 분포 난수 5개 생성
logistic_dist = rng.logistic(loc=0, scale=1, size=5)
print(f"로지스틱 분포 난수 (loc=0, scale=1): {logistic_dist}")

# 위치 5, 스케일 0.5인 로지스틱 분포 난수 3개 생성
custom_logistic_dist = rng.logistic(loc=5, scale=0.5, size=3)
print(f"\n사용자 정의 로지스틱 분포 난수 (loc=5, scale=0.5): {custom_logistic_dist}")

# 로지스틱 함수 시각화를 위한 데이터 생성 예시
# x_values = np.linspace(-10, 10, 100)
# sigmoid_y = 1 / (1 + np.exp(-(x_values - 0) / 1))
# print(f"\n시그모이드 함수 예시 (일부): {sigmoid_y[:5]}...")
```

#### 1.2.7. 다항 분포 (Multinomial Distribution)

**다항 분포(Multinomial Distribution)**는 이항 분포의 일반화된 형태로, 두 가지 이상의 범주(category)를 가지는 시행을 여러 번 반복했을 때, 각 범주가 선택된 횟수를 나타내는 **이산 확률 분포**입니다. 즉, 고정된 횟수(`n`)의 독립적인 시행에서 각 범주가 나타날 확률(`pvals`)이 주어졌을 때, 각 범주가 나타나는 횟수의 조합에 대한 확률을 모델링합니다.

**정의 및 파라미터:**
다항 분포는 세 가지 모수(parameter)에 의해 정의됩니다.
*   `n` (시행 횟수): 독립적인 시행의 총 횟수.
*   `pvals` (확률 벡터): 각 범주가 선택될 확률을 나타내는 1차원 배열 또는 리스트. `pvals`의 요소들의 합은 반드시 1이어야 합니다.
*   `size`: 선택 사항. 생성할 난수 배열의 형태. `size`가 `None`이면 단일 샘플(1차원 배열)을 반환합니다.

**주요 특징:**
*   **고정된 시행 횟수**: 총 시행 횟수 `n`은 미리 정해져 있습니다.
*   **독립적인 시행**: 각 시행의 결과는 다른 시행의 결과에 영향을 미치지 않습니다.
*   **여러 범주**: 각 시행은 두 가지 이상($k \ge 2$)의 상호 배타적인 범주 중 하나를 결과로 가집니다.
*   **일정한 확률**: 각 범주가 나타날 확률은 모든 시행에서 동일합니다.
*   **확률 질량 함수(PMF)**: 다항 분포의 확률 질량 함수는 다음과 같습니다.
    $ P(X_1=k_1, \dots, X_m=k_m) = \frac{n!}{k_1! \dots k_m!} p_1^{k_1} \dots p_m^{k_m} $
    여기서 $k_i$는 $i$번째 범주가 나타난 횟수이고, $\sum k_i = n$, $\sum p_i = 1$ 입니다.
*   **이항 분포와의 관계**: 다항 분포는 $k=2$일 때 이항 분포와 동일합니다.

**활용 분야:**
다항 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **주사위 던지기**: 여러 면을 가진 주사위를 여러 번 던졌을 때, 각 면이 나온 횟수를 모델링합니다.
*   **설문 조사**: 여러 개의 선택지 중 하나를 고르는 설문에서, 각 선택지가 선택된 횟수를 모델링합니다.
*   **자연어 처리 (NLP)**: 문서 내에서 각 단어의 출현 빈도를 모델링하는 데 사용됩니다 (예: 토픽 모델링, 나이브 베이즈 분류기).
*   **유전학**: 여러 대립 유전자(allele)의 빈도를 모델링합니다.
*   **시장 조사**: 소비자들이 여러 제품 중 어떤 제품을 선택하는지, 각 제품의 선택 횟수를 모델링합니다.

**NumPy에서의 다항 분포 난수 생성:**
NumPy의 `np.random.default_rng().multinomial()` 함수를 사용하여 다항 분포 난수를 생성합니다. 이 함수는 `n` (시행 횟수), `pvals` (확률 벡터), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 10번의 시행, 3가지 범주 (확률 0.1, 0.2, 0.7)
# size=1이므로 10번 시행 후 각 범주가 나온 횟수 1세트
multinomial_dist_single = rng.multinomial(n=10, pvals=[0.1, 0.2, 0.7], size=1)
print(f"다항 분포 난수 (10회 시행, 3범주, 1세트): {multinomial_dist_single}")

# 5번의 시행, 4가지 범주 (확률 0.25씩, 주사위 5회 던지기)
# size=2이므로 5번 시행 후 각 범주가 나온 횟수 2세트
multinomial_dist_dice = rng.multinomial(n=5, pvals=[0.25, 0.25, 0.25, 0.25], size=2)
print(f"\n다항 분포 난수 (주사위 5회 던지기, 2세트):\n{multinomial_dist_dice}")

# 20번의 시행, 2가지 범주 (확률 0.6, 0.4) - 이항 분포와 유사
multinomial_dist_binary = rng.multinomial(n=20, pvals=[0.6, 0.4], size=3)
print(f"\n다항 분포 난수 (이항 분포 유사, 20회 시행, 3세트):\n{multinomial_dist_binary}")
```

#### 1.2.8. 지수 분포 (Exponential Distribution)

**지수 분포(Exponential Distribution)**는 어떤 사건이 발생할 때까지 걸리는 시간(대기 시간)을 모델링하는 데 사용되는 **연속 확률 분포**입니다. 특히, 사건 발생률이 시간에 따라 일정하게 유지되는 **메모리리스(memoryless) 속성**을 가집니다. 이는 포아송 과정(Poisson process)에서 사건과 사건 사이의 시간을 나타내는 분포입니다.

**정의 및 파라미터:**
지수 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `scale` (스케일 모수, $\beta$ 또는 $1/\lambda$): 평균 대기 시간 또는 사건 발생률($\lambda$)의 역수를 나타냅니다. 값이 클수록 사건 발생 간격이 길어집니다.

**주요 특징:**
*   **메모리리스 속성**: 지수 분포의 가장 중요한 특징입니다. 어떤 사건이 발생할 때까지 기다리는 시간이 이미 얼마나 지났는지와 관계없이, 앞으로 사건이 발생할 확률은 동일하다는 의미입니다. 예를 들어, 전구가 100시간 동안 고장 나지 않았다고 해서 앞으로 고장 날 확률이 더 높아지거나 낮아지지 않습니다.
*   **양의 값**: 지수 분포는 시간을 모델링하므로 항상 0보다 큰 값을 가집니다.
*   **오른쪽으로 치우침**: 확률 밀도 함수는 0에서 가장 높고, 값이 커질수록 지수적으로 감소하여 오른쪽으로 길게 늘어지는 형태를 보입니다.
*   **확률 밀도 함수(PDF)**: 지수 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; \lambda) = \lambda e^{-\lambda x} \quad \text{for } x \ge 0 $
    여기서 $\lambda = 1/\text{scale}$ 입니다.
*   **평균**: `scale`
*   **분산**: `scale`$^2$
*   **포아송 분포와의 관계**: 만약 단위 시간당 발생하는 사건의 수가 포아송 분포를 따른다면, 사건과 사건 사이의 시간 간격은 지수 분포를 따릅니다.

**활용 분야:**
지수 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **신뢰성 공학**: 전자 부품, 기계 장치 등의 수명이나 고장 발생 간격을 모델링합니다.
*   **대기열 이론**: 콜센터에 다음 전화가 올 때까지의 시간, 은행 창구에 다음 고객이 도착할 때까지의 시간 등을 모델링합니다.
*   **물리학**: 방사성 물질의 붕괴 시간, 입자 충돌 간격 등을 모델링합니다.
*   **생존 분석**: 특정 사건(예: 질병 재발, 사망)이 발생할 때까지의 시간을 모델링합니다.

**NumPy에서의 지수 분포 난수 생성:**
NumPy의 `np.random.default_rng().exponential()` 함수를 사용하여 지수 분포 난수를 생성합니다. 이 함수는 `scale` (스케일 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 스케일 1.0인 지수 분포 난수 5개 생성 (평균 대기 시간 1.0)
exponential_dist = rng.exponential(scale=1.0, size=5)
print(f"지수 분포 난수 (scale=1.0): {exponential_dist}")

# 스케일 0.5인 지수 분포 난수 3개 생성 (평균 대기 시간 0.5)
custom_exponential_dist = rng.exponential(scale=0.5, size=3)
print(f"\n사용자 정의 지수 분포 난수 (scale=0.5): {custom_exponential_dist}")

# 스케일 2.0인 지수 분포 난수 2x2 행렬 생성
exponential_dist_matrix = rng.exponential(scale=2.0, size=(2, 2))
print(f"\n지수 분포 난수 (scale=2.0, 2x2 행렬):\n{exponential_dist_matrix}")
```

#### 1.2.9. 카이제곱 분포 (Chi-square Distribution)

**카이제곱 분포(Chi-square Distribution)**는 통계학에서 매우 중요한 **연속 확률 분포** 중 하나입니다. 이 분포는 독립적인 표준 정규 분포(평균 0, 표준편차 1)를 따르는 확률 변수들을 제곱하여 더했을 때 나타나는 분포입니다. 주로 통계적 가설 검정(예: 적합도 검정, 독립성 검정) 및 신뢰 구간 추정 등에 사용됩니다.

**정의 및 파라미터:**
카이제곱 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `df` (자유도, $k$): 분포의 형태를 결정하는 유일한 모수입니다. 이는 독립적인 표준 정규 확률 변수의 개수를 나타냅니다.

**주요 특징:**
*   **양의 값**: 카이제곱 분포는 제곱의 합이므로 항상 0보다 크거나 같은 값을 가집니다.
*   **오른쪽으로 치우침**: 자유도(`df`)가 작을 때는 오른쪽으로 치우친 형태를 보이지만, 자유도가 증가할수록 점차 대칭적인 종 모양(정규 분포에 가까운 형태)으로 변합니다.
*   **감마 분포와의 관계**: 카이제곱 분포는 형태 모수 $k/2$와 스케일 모수 2를 가진 감마 분포의 특수한 경우입니다.
*   **확률 밀도 함수(PDF)**: 카이제곱 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; k) = \frac{1}{2^{k/2} \Gamma(k/2)} x^{k/2 - 1} e^{-x/2} \quad \text{for } x \ge 0 $
    여기서 $k$는 자유도입니다.
*   **평균**: `df`
*   **분산**: $2 \cdot \text{df}$

**활용 분야:**
카이제곱 분포는 다음과 같은 다양한 통계적 분석에서 핵심적으로 활용됩니다.
*   **카이제곱 검정 (Chi-square Test)**:
    *   **적합도 검정(Goodness-of-Fit Test)**: 관측된 빈도 분포가 특정 이론적 분포(예: 균일 분포, 정규 분포)와 일치하는지 검정합니다.
    *   **독립성 검정(Test of Independence)**: 두 범주형 변수(categorical variables) 사이에 통계적으로 유의미한 연관성(독립성)이 있는지 검정합니다.
    *   **동질성 검정(Test of Homogeneity)**: 여러 모집단에서 추출된 표본들이 특정 특성에 대해 동일한 분포를 가지는지 검정합니다.
*   **분산 분석 (ANOVA)**: 분산 분석에서 F-통계량의 분포를 이해하는 데 사용됩니다.
*   **신뢰 구간 추정**: 모집단의 분산에 대한 신뢰 구간을 추정할 때 사용됩니다.
*   **표본 분산의 분포**: 정규 분포를 따르는 모집단에서 추출한 표본 분산의 분포를 모델링합니다.

**NumPy에서의 카이제곱 분포 난수 생성:**
NumPy의 `np.random.default_rng().chisquare()` 함수를 사용하여 카이제곱 분포 난수를 생성합니다. 이 함수는 `df` (자유도), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 자유도 2인 카이제곱 분포 난수 5개 생성
chisquare_dist = rng.chisquare(df=2, size=5)
print(f"카이제곱 분포 난수 (df=2): {chisquare_dist}")

# 자유도 10인 카이제곱 분포 난수 3개 생성 (더 대칭적인 형태)
custom_chisquare_dist = rng.chisquare(df=10, size=3)
print(f"\n사용자 정의 카이제곱 분포 난수 (df=10): {custom_chisquare_dist}")

# 자유도 1인 카이제곱 분포 난수 2x2 행렬 생성
chisquare_dist_matrix = rng.chisquare(df=1, size=(2, 2))
print(f"\n카이제곱 분포 난수 (df=1, 2x2 행렬):\n{chisquare_dist_matrix}")
```

#### 1.2.10. 레일리 분포 (Rayleigh Distribution)

**레일리 분포(Rayleigh Distribution)**는 주로 2차원 평면에서 무작위로 움직이는 입자의 거리, 바람의 속도, 무선 통신 신호의 진폭 등 항상 양의 값을 가지는 데이터의 분포를 모델링하는 데 사용되는 **연속 확률 분포**입니다. 특히, 독립적이고 동일하게 분포된 평균이 0인 가우시안 확률 변수들의 제곱합의 제곱근(즉, 벡터의 크기)을 모델링할 때 나타납니다.

**정의 및 파라미터:**
레일리 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `scale` (스케일 모수, $\sigma$): 분포의 퍼짐 정도를 결정합니다. 값이 클수록 분포가 오른쪽으로 더 넓게 퍼집니다.

**주요 특징:**
*   **양의 값**: 레일리 분포는 항상 0보다 크거나 같은 값을 가집니다.
*   **오른쪽으로 치우침**: 0에서 시작하여 오른쪽으로 비대칭적인 형태를 가집니다. `scale` 값이 커질수록 분포의 봉우리가 오른쪽으로 이동하고 넓어집니다.
*   **확률 밀도 함수(PDF)**: 레일리 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; \sigma) = \frac{x}{\sigma^2} e^{-x^2/(2\sigma^2)} \quad \text{for } x \ge 0 $
*   **최빈값 (Mode)**: $\sigma$
*   **평균**: $\sigma \sqrt{\frac{\pi}{2}}$
*   **분산**: $\sigma^2 \left(2 - \frac{\pi}{2}\right)$

**활용 분야:**
레일리 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **신호 처리**: 가우시안 노이즈가 있는 신호의 진폭을 모델링합니다.
*   **무선 통신**: 페이딩 채널(fading channel)에서 수신 신호의 강도(envelope)를 모델링하는 데 널리 사용됩니다 (예: 레일리 페이딩).
*   **음향학**: 음압 수준을 모델링합니다.
*   **광학**: 레이저 스페클(speckle) 패턴의 강도 분포를 모델링합니다.
*   **풍속 모델링**: 특정 지역의 풍속 분포를 모델링합니다.
*   **이미지 처리**: 노이즈가 있는 이미지의 픽셀 강도 분포를 모델링합니다.

**NumPy에서의 레일리 분포 난수 생성:**
NumPy의 `np.random.default_rng().rayleigh()` 함수를 사용하여 레일리 분포 난수를 생성합니다. 이 함수는 `scale` (스케일 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 스케일 1.0인 레일리 분포 난수 5개 생성
rayleigh_dist = rng.rayleigh(scale=1.0, size=5)
print(f"레일리 분포 난수 (scale=1.0): {rayleigh_dist}")

# 스케일 0.5인 레일리 분포 난수 3개 생성
custom_rayleigh_dist = rng.rayleigh(scale=0.5, size=3)
print(f"\n사용자 정의 레일리 분포 난수 (scale=0.5): {custom_rayleigh_dist}")

# 스케일 2.0인 레일리 분포 난수 2x2 행렬 생성
rayleigh_dist_matrix = rng.rayleigh(scale=2.0, size=(2, 2))
print(f"\n레일리 분포 난수 (scale=2.0, 2x2 행렬):\n{rayleigh_dist_matrix}")
```

#### 1.2.11. 파레토 분포 (Pareto Distribution)

**파레토 분포(Pareto Distribution)**는 소수의 요소가 전체의 대부분을 차지하는 현상(예: 부의 분배, 도시 인구 규모, 단어 사용 빈도)을 모델링하는 데 사용되는 **연속 확률 분포**입니다. 이는 **파레토 법칙(Pareto Principle)** 또는 **80/20 법칙**과 밀접한 관련이 있으며, 불균형한 분포를 설명하는 데 특히 유용합니다.

**정의 및 파라미터:**
파레토 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `a` (형태 모수, $\alpha$): 분포의 형태를 결정하는 양의 실수 값입니다. 이 값이 클수록 분포의 꼬리가 더 가늘어집니다.

**주요 특징:**
*   **긴 꼬리(Long Tail)**: 파레토 분포의 가장 특징적인 성질로, 극단적으로 큰 값이 나타날 확률이 다른 분포(예: 정규 분포)에 비해 상대적으로 높습니다. 이는 소수의 개체가 전체의 대부분을 차지하는 현상을 잘 설명합니다.
*   **항상 양의 값**: 분포는 0보다 큰 값에서 정의됩니다.
*   **확률 밀도 함수(PDF)**: 파레토 분포의 확률 밀도 함수는 다음과 같습니다.
    $ f(x; \alpha, x_m) = \frac{\alpha x_m^{\alpha}}{x^{\alpha+1}} \quad \text{for } x \ge x_m $
    여기서 $x_m$은 분포의 최소값(보통 1로 설정)입니다.
*   **평균**: $\frac{\alpha x_m}{\alpha - 1}$ (단, $\alpha > 1$ 일 때)
*   **분산**: $\frac{x_m^2 \alpha}{(\alpha - 1)^2 (\alpha - 2)}$ (단, $\alpha > 2$ 일 때)

**활용 분야:**
파레토 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **경제학**: 소득 분배, 부의 분배, 기업 규모의 분포 등을 모델링합니다.
*   **사회학**: 도시 인구 규모, 범죄 발생률 등을 모델링합니다.
*   **언어학**: 텍스트에서 단어의 출현 빈도 (지프의 법칙과 관련).
*   **보험**: 대규모 손실 청구액의 분포를 모델링합니다.
*   **신뢰성 공학**: 특정 부품의 고장 시간 분포를 모델링합니다.
*   **인터넷 트래픽**: 웹사이트 방문 빈도, 파일 다운로드 크기 등을 모델링합니다.

**NumPy에서의 파레토 분포 난수 생성:**
NumPy의 `np.random.default_rng().pareto()` 함수를 사용하여 파레토 분포 난수를 생성합니다. 이 함수는 `a` (형태 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 형태 2.0인 파레토 분포 난수 5개 생성
pareto_dist = rng.pareto(a=2.0, size=5)
print(f"파레토 분포 난수 (a=2.0): {pareto_dist}")

# 형태 1.5인 파레토 분포 난수 3개 생성 (더 긴 꼬리)
custom_pareto_dist = rng.pareto(a=1.5, size=3)
print(f"\n사용자 정의 파레토 분포 난수 (a=1.5): {custom_pareto_dist}")

# 형태 3.0인 파레토 분포 난수 2x2 행렬 생성
pareto_dist_matrix = rng.pareto(a=3.0, size=(2, 2))
print(f"\n파레토 분포 난수 (a=3.0, 2x2 행렬):\n{pareto_dist_matrix}")
```

#### 1.2.12. 지프 분포 (Zipf Distribution)

**지프 분포(Zipf Distribution)**는 특정 순위의 빈도가 해당 순위의 역수에 비례하는 현상(예: 자연어 텍스트에서 단어의 출현 빈도)을 모델링하는 데 사용되는 **이산 확률 분포**입니다. 이는 **지프의 법칙(Zipf's Law)**으로 알려져 있으며, 소수의 항목이 매우 자주 나타나고 대다수의 항목은 드물게 나타나는 불균형한 패턴을 설명합니다.

**정의 및 파라미터:**
지프 분포는 단 하나의 모수(parameter)에 의해 정의됩니다.
*   `a` (형태 모수, $\alpha$): 분포의 형태를 결정하는 양의 실수 값입니다. 이 값이 클수록 빈도 감소가 더 가파르게 나타납니다.

**주요 특징:**
*   **순위-빈도 관계**: 가장 흔한 항목의 빈도가 두 번째로 흔한 항목의 두 배, 세 번째로 흔한 항목의 세 배가 되는 식으로, 빈도가 순위에 반비례합니다.
*   **이산 분포**: 정수 값을 가집니다.
*   **긴 꼬리**: 파레토 분포와 유사하게 긴 꼬리 특성을 가지며, 소수의 상위 랭크 항목이 전체 빈도의 상당 부분을 차지합니다.
*   **확률 질량 함수(PMF)**: 지프 분포의 확률 질량 함수는 다음과 같습니다.
    $ P(X=k; s, N) = \frac{1/k^s}{\sum_{n=1}^{N} (1/n^s)} $
    여기서 $k$는 순위, $s$는 `a`에 해당하는 모수, $N$은 총 항목의 수입니다. NumPy의 `rng.zipf`는 $N$을 무한대로 가정하고 $s$를 `a`로 사용합니다.

**활용 분야:**
지프 분포는 다음과 같은 다양한 상황에서 활용됩니다.
*   **언어학**: 자연어 텍스트에서 단어의 출현 빈도 분석 (가장 대표적인 응용 분야).
*   **도시 계획**: 도시의 인구 규모 분포.
*   **생물학**: 종의 다양성 분포.
*   **정보 과학**: 웹사이트 링크의 인기, 논문 인용 횟수 등.
*   **사회 과학**: 소득 분배, 기업 규모 등.

**NumPy에서의 지프 분포 난수 생성:**
NumPy의 `np.random.default_rng().zipf()` 함수를 사용하여 지프 분포 난수를 생성합니다. 이 함수는 `a` (형태 모수), `size` (생성할 배열의 형태)를 인자로 받습니다.

**예시:**

```python
import numpy as np
rng = np.random.default_rng(seed=42)

# 형태 2.0인 지프 분포 난수 5개 생성
# (작은 값이 더 자주 나타남)
zipf_dist = rng.zipf(a=2.0, size=5)
print(f"지프 분포 난수 (a=2.0): {zipf_dist}")

# 형태 1.5인 지프 분포 난수 3개 생성 (꼬리가 더 두꺼움)
custom_zipf_dist = rng.zipf(a=1.5, size=3)
print(f"\n사용자 정의 지프 분포 난수 (a=1.5): {custom_zipf_dist}")

# 형태 3.0인 지프 분포 난수 2x2 행렬 생성
zipf_dist_matrix = rng.zipf(a=3.0, size=(2, 2))
print(f"\n지프 분포 난수 (a=3.0, 2x2 행렬):\n{zipf_dist_matrix}")
```
