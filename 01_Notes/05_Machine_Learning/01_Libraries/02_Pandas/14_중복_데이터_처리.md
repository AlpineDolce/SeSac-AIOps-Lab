<h2>목차</h2>

### 1. 중복 데이터란 무엇이며 왜 중요한가?

중복 데이터는 DataFrame 내에서 두 개 이상의 행이 완전히 동일한 값을 갖거나, 특정 컬럼들의 값이 동일한 경우를 의미합니다.

-   **분석 왜곡**: 동일한 데이터가 여러 번 집계되면 특정 값의 중요도가 부풀려져 전체 통계가 왜곡될 수 있습니다. (예: 평균, 합계)
-   **모델 편향**: 머신러닝 모델이 중복된 데이터를 학습하면 특정 패턴에 과적합(overfitting)되어 새로운 데이터에 대한 예측 성능이 저하될 수 있습니다.
-   **자원 낭비**: 불필요한 데이터가 저장 공간과 계산 리소스를 낭비합니다.

따라서 데이터 분석 프로젝트 초기(EDA 단계)에 중복 데이터를 확인하고 처리하는 것은 매우 중요합니다.

### 2. 중복 데이터 식별: `.duplicated()`

`.duplicated()` 메서드는 각 행이 이전 행과 중복되는지 여부를 불리언(boolean) Series로 반환합니다.

-   **기본 사용법**:
    ```python
    import pandas as pd

    df = pd.DataFrame({
        'A': ['foo', 'bar', 'foo', 'bar', 'foo', 'baz'],
        'B': [1, 2, 1, 3, 1, 4],
        'C': ['x', 'y', 'x', 'y', 'x', 'z']
    })

    # 각 행이 중복인지 확인 (기본값: 첫 번째 등장 이후의 중복을 True로 표시)
    print(df.duplicated())
    # 0    False
    # 1    False
    # 2     True  <- (0번 행과 중복)
    # 3    False
    # 4     True  <- (0, 2번 행과 중복)
    # 5    False
    # dtype: bool
    ```

-   **`keep` 파라미터**: 중복된 행들 중 어떤 것을 `False`로 표시할지(즉, 보존할 것으로 간주할지) 결정합니다.
    -   `keep='first'` (기본값): 처음 나타나는 값은 `False`, 이후 중복은 `True`.
    -   `keep='last'`: 마지막으로 나타나는 값은 `False`, 이전 중복은 `True`.
    -   `keep=False`: 모든 중복 항목을 `True`로 표시. 고유한 값이 없는 모든 행을 식별할 때 유용합니다.

    ```python
    # 마지막 중복을 제외하고 모두 True
    print(df.duplicated(keep='last'))
    # 0     True
    # 1    False
    # 2     True
    # 3    False
    # 4     True
    # 5    False
    # dtype: bool

    # 고유한 값이 없는 모든 행을 True
    print(df.duplicated(keep=False))
    # 0     True
    # 1    False
    # 2     True
    # 3    False
    # 4     True
    # 5    False
    # dtype: bool
    ```

-   **`subset` 파라미터**: 특정 컬럼들을 기준으로 중복 여부를 검사합니다.
    ```python
    # 'A' 컬럼 기준으로 중복 확인
    print(df.duplicated(subset=['A']))
    # 0    False
    # 1    False
    # 2     True  <- 'foo'
    # 3     True  <- 'bar'
    # 4     True  <- 'foo'
    # 5    False
    # dtype: bool
    ```

### 3. 중복 데이터 제거: `.drop_duplicates()`

`.drop_duplicates()`는 중복된 행을 직접 제거하여 중복이 없는 DataFrame을 반환합니다. 파라미터는 `.duplicated()`와 거의 동일하게 동작합니다.

-   **기본 사용법**:
    ```python
    # 중복된 행 제거 (keep='first'가 기본값)
    df_deduped = df.drop_duplicates()
    print(df_deduped)
    #      A  B  C
    # 0  foo  1  x
    # 1  bar  2  y
    # 3  bar  3  y
    # 5  baz  4  z
    ```

-   **`subset`과 `keep` 활용**: 특정 컬럼을 기준으로 최신 데이터를 남기는 실무 예제
    ```python
    # 'A' 컬럼을 기준으로 중복을 제거하되, 마지막에 나타난 행을 남김
    df_last = df.drop_duplicates(subset=['A'], keep='last')
    print(df_last)
    #      A  B  C
    # 1  bar  2  y
    # 3  bar  3  y  <- 'bar'의 마지막 값
    # 4  foo  1  x  <- 'foo'의 마지막 값
    # 5  baz  4  z
    ```
    *실무 팁: 데이터를 시간순으로 정렬한 후 `drop_duplicates`를 사용하면 '가장 오래된' 또는 '가장 최신' 데이터를 쉽게 남길 수 있습니다.*

-   **`inplace` 파라미터**: `True`로 설정 시, 원본 DataFrame을 직접 수정합니다. (메모리 효율적이지만, 원본이 변경되므로 신중하게 사용해야 합니다.)
    ```python
    df_copy = df.copy()
    df_copy.drop_duplicates(subset=['A', 'B'], inplace=True)
    print(df_copy)
    #      A  B  C
    # 0  foo  1  x
    # 1  bar  2  y
    # 3  bar  3  y
    # 5  baz  4  z
    ```

### 4. 요약 및 모범 사례 (Summary & Best Practices)

1.  **탐색적 데이터 분석(EDA) 단계에서 항상 중복을 확인**하세요. `df.duplicated().sum()`으로 중복 행의 개수를 빠르게 파악할 수 있습니다.
2.  **무엇이 중복을 정의하는지 명확히 하세요.** 전체 행이 동일해야 하는지, 아니면 특정 키(key) 컬럼들만 같아도 중복으로 간주할지 비즈니스 로직에 따라 `subset`을 적절히 사용해야 합니다.
3.  **데이터 보존 전략을 결정하세요.** 중복된 데이터 중 어떤 것을 남길지(`keep='first'` 또는 `'last'`)는 데이터의 특성에 따라 달라집니다. (예: 로그 데이터는 보통 최신 것을 남깁니다.)
4.  **제거 전 데이터를 검토하세요.** `df[df.duplicated(subset=..., keep=False)]`와 같이 `keep=False`를 사용하여 제거될 후보군을 미리 확인하는 것이 안전합니다.
5.  **인덱스를 리셋하세요.** 중복 제거 후에는 인덱스가 중간중간 비게 되므로, `df.drop_duplicates().reset_index(drop=True)`를 사용하여 인덱스를 재정렬하는 것이 좋습니다.
