## 1. 데이터 그룹화 (`groupby`)

`groupby` 연산은 데이터를 특정 기준으로 여러 그룹으로 나누어, 각 그룹에 독립적으로 함수를 적용하고, 그 결과를 다시 하나의 데이터 구조로 합치는 강력한 기능입니다.

### 1.1. `groupby`의 개념: Split-Apply-Combine

`groupby`는 세 단계로 동작합니다.

1.  **Split**: 특정 기준(컬럼 값 등)에 따라 데이터를 여러 그룹으로 분할합니다.
2.  **Apply**: 각 그룹에 집계, 변환, 필터링 등 특정 함수를 독립적으로 적용합니다.
3.  **Combine**: 각 그룹에서 계산된 결과를 다시 하나의 `DataFrame`이나 `Series`로 결합합니다.

```python
import pandas as pd
import numpy as np

# 예제 데이터프레임 생성
df = pd.DataFrame({
    'Store': ['A', 'B', 'A', 'C', 'B', 'A'],
    'Product': ['Apple', 'Banana', 'Orange', 'Apple', 'Orange', 'Banana'],
    'Sales': [200, 150, 300, 250, 180, 120],
    'Quantity': [10, 15, 20, 25, 18, 12]
})
```

### 1.2. `groupby` 기본 사용법 및 집계 함수

가장 기본적인 형태는 특정 컬럼으로 그룹화한 뒤, 집계 함수(`sum`, `mean`, `count` 등)를 적용하는 것입니다.

```python
# 각 상점(Store)별 총 매출(Sales) 계산
store_sales = df.groupby('Store')['Sales'].sum()
print("--- 각 상점별 총 매출 ---")
print(store_sales)
```
**결과:**
```
--- 각 상점별 총 매출 ---
Store
A    620
B    330
C    250
Name: Sales, dtype: int64
```

*   `size()`: 각 그룹의 크기(행 개수)를 반환합니다. (NaN 포함)
*   `count()`: 각 그룹의 결측치를 제외한 데이터 개수를 반환합니다.

```python
# 각 상점별 판매 건수
store_counts = df.groupby('Store').size()
print("\n--- 각 상점별 판매 건수 ---")
print(store_counts)
```

### 1.3. `agg()`를 이용한 다중 집계

`agg()` (aggregate) 함수를 사용하면 여러 개의 집계 결과를 한 번에 얻을 수 있어 매우 효율적입니다.

**1. 단일 컬럼에 여러 함수 적용**
```python
# 각 상점별 매출의 합계와 평균을 동시에 계산
store_agg = df.groupby('Store')['Sales'].agg(['sum', 'mean', 'std'])
print("\n--- 상점별 매출의 합계, 평균, 표준편차 ---")
print(store_agg)
```

**2. 여러 컬럼에 다른 함수 적용**
```python
# 상점별로 매출(Sales)의 총합과 판매량(Quantity)의 평균을 계산
store_multi_agg = df.groupby('Store').agg({
    'Sales': 'sum',
    'Quantity': 'mean'
})
print("\n--- 상점별 매출 총합과 판매량 평균 ---")
print(store_multi_agg)
```

### 1.4. `transform`과 `filter`를 이용한 고급 그룹 연산

**1. `transform`**: 그룹별 계산 결과를 원래 `DataFrame`의 형태로 변환합니다. 원본과 동일한 인덱스를 가지므로, 그룹별 통계치를 기반으로 새로운 컬럼을 만들 때 유용합니다.

```python
# 각 판매 데이터가 해당 상점의 평균 매출에서 얼마나 차이 나는지 계산
df['Sales_Deviation'] = df.groupby('Store')['Sales'].transform(lambda x: x - x.mean())
print("\n--- 상점별 평균 매출 대비 편차 ---")
print(df)
```

**2. `filter`**: 그룹 전체에 대한 조건으로 데이터를 필터링합니다. 예를 들어, 총매출이 특정 기준을 넘는 상점의 데이터만 남길 수 있습니다.

```python
# 총 매출이 400을 초과하는 상점의 데이터만 필터링
filtered_df = df.groupby('Store').filter(lambda x: x['Sales'].sum() > 400)
print("\n--- 총 매출 400 초과 상점 데이터 ---")
print(filtered_df)
```

## 2. 데이터 병합 및 연결

여러 `DataFrame`을 하나로 합치는 방법은 크게 `concat` (연결)과 `merge` (병합)으로 나뉩니다.

### 2.1. `concat()` - 데이터 이어붙이기

`concat()`은 여러 `DataFrame`을 축(axis)을 기준으로 단순히 이어붙이는 기능입니다.

**예제 데이터**
```python
df1 = pd.DataFrame({'A': ['A0', 'A1'], 'B': ['B0', 'B1']})
df2 = pd.DataFrame({'A': ['A2', 'A3'], 'B': ['B2', 'B3']})
```

**1. 행(row) 기준으로 연결 (기본값 `axis=0`)**
```python
row_concat = pd.concat([df1, df2], ignore_index=True) # ignore_index=True: 기존 인덱스 무시
print("\n--- 행 기준 연결 ---")
print(row_concat)
```

**2. 열(column) 기준으로 연결 (`axis=1`)**
```python
col_concat = pd.concat([df1, df2], axis=1)
print("\n--- 열 기준 연결 ---")
print(col_concat)
```

### 2.2. `merge()` - SQL 스타일 조인

`merge()`는 특정 공통 키(key)를 기준으로 두 `DataFrame`을 SQL의 JOIN처럼 병합합니다. 데이터 분석에서 가장 중요한 기능 중 하나입니다.

**예제 데이터**
```python
df_employees = pd.DataFrame({
    'employee': ['Bob', 'Jake', 'Lisa', 'Sue'],
    'department_id': ['D01', 'D02', 'D01', 'D03']
})
df_departments = pd.DataFrame({
    'id': ['D01', 'D02', 'D04'],
    'department_name': ['HR', 'Engineering', 'Marketing']
})
```

**주요 `merge` 옵션**
*   `on`: 조인의 기준이 되는 공통 컬럼 이름.
*   `left_on`, `right_on`: 두 `DataFrame`의 기준 컬럼 이름이 다를 때 각각 지정.
*   `how`: 조인 방식 (`inner`, `outer`, `left`, `right`).

**1. Inner Join (기본값)**: 두 `DataFrame`에 모두 존재하는 키만 병합합니다.
```python
inner_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='inner')
print("\n--- Inner Join ---")
print(inner_join)
```

**2. Left Join**: 왼쪽 `DataFrame`(df_employees)의 모든 데이터를 유지하고, 오른쪽 `DataFrame`의 정보를 키 기준으로 붙입니다. 일치하는 키가 없으면 `NaN`으로 표시됩니다.
```python
left_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='left')
print("\n--- Left Join ---")
print(left_join)
```

**3. Outer Join**: 양쪽 `DataFrame`의 모든 데이터를 유지하며 병합합니다. 한쪽에만 키가 있는 경우, 다른 쪽의 데이터는 `NaN`으로 채워집니다.
```python
outer_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='outer')
print("\n--- Outer Join ---")
print(outer_join)
```

### 2.3. `join()` - 인덱스 기반 조인

`join()` 메서드는 `merge()`와 유사하지만, 주로 `DataFrame`의 인덱스를 기준으로 병합할 때 편리하게 사용됩니다.

**예제 데이터**
```python
df_left = pd.DataFrame({'A': ['A0', 'A1', 'A2']}, index=['K0', 'K1', 'K2'])
df_right = pd.DataFrame({'B': ['B0', 'B1']}, index=['K0', 'K1'])
```

```python
index_join = df_left.join(df_right)
print("\n--- 인덱스 기반 조인 ---")
print(index_join)
```
`df_left.join(df_right)`는 `pd.merge(df_left, df_right, left_index=True, right_index=True, how='left')`와 거의 동일하게 동작합니다.
```
