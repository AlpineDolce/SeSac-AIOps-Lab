## 1. 조건부 데이터 검색

`DataFrame`에서 특정 조건을 만족하는 데이터를 선택하는 것은 데이터 분석의 핵심 기능 중 하나입니다. Pandas는 불리언 인덱싱(Boolean Indexing)을 통해 강력하고 유연한 조건부 검색 기능을 제공합니다. 이를 통해 원하는 데이터를 효율적으로 추출하고 분석할 수 있습니다.

### 1.1. 기본 조건 검색

단일 조건을 사용하여 `DataFrame`의 행을 필터링할 수 있습니다. 조건식은 각 행에 대해 `True` 또는 `False`를 반환하는 불리언 `Series`를 생성하며, 이 `Series`를 사용하여 `True`인 행만 선택합니다.

```python
import pandas as pd

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경'],
    'kor': [90, 80, 70, 70, 60, 70],
    'eng': [99, 98, 97, 46, 77, 56],
    'mat': [90, 70, 70, 60, 88, 99],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울']
}
df = pd.DataFrame(data)
print("원본 DataFrame:\n", df)

print("\n--- 국어 점수가 80점 이상인 학생 ---")
print(df[df['kor'] >= 80])

print("\n--- 영어 점수가 90점 미만인 학생 ---")
print(df[df['eng'] < 90])

print("\n--- 거주 도시가 '서울'인 학생 ---")
print(df[df['city'] == '서울'])

# 조건에 맞는 행에서 특정 컬럼만 선택
print("\n--- 국어 점수가 70점인 학생의 이름과 영어 점수 ---")
print(df[df['kor'] == 70][['name', 'eng']])
```

### 1.2. 복합 조건 검색

여러 조건을 동시에 만족하거나(AND) 둘 중 하나라도 만족하는(OR) 데이터를 검색할 때는 복합 조건식을 사용합니다. 이때 파이썬의 기본 논리 연산자(`and`, `or`) 대신 비트wise 논리 연산자(`&`, `|`)를 사용해야 하며, 각 조건식은 반드시 괄호로 묶어야 합니다.

**주의사항**:
*   파이썬의 `and`, `or` 연산자는 `Series` 전체에 대해 불리언 값을 평가할 수 없으므로 사용 불가합니다.
*   NumPy 기반의 Pandas에서는 요소별(element-wise) 논리 연산을 위해 비트wise 연산자(`&` for AND, `|` for OR, `~` for NOT)를 사용해야 합니다.
*   각 개별 조건식은 반드시 괄호 `()`로 묶어야 합니다. 이는 연산자 우선순위 문제로 인해 발생할 수 있는 오류를 방지합니다.

#### 1.2.1. `&` (AND) 조건

두 개 이상의 조건을 모두 만족하는 데이터를 선택할 때 사용합니다. 각 조건식을 `&` 연산자로 연결합니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경'],
    'kor': [90, 80, 70, 70, 60, 70],
    'eng': [99, 98, 97, 46, 77, 56],
    'mat': [90, 70, 70, 60, 88, 99],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울']
}
df = pd.DataFrame(data)

print("--- 국어 점수가 70점 이상이고 영어 점수가 90점 이상인 학생 ---")
print(df[(df['kor'] >= 70) & (df['eng'] >= 90)])

print("\n--- 거주 도시가 '서울'이면서 수학 점수가 80점 이상인 학생 ---")
print(df[(df['city'] == '서울') & (df['mat'] >= 80)])

# 복합 조건에 맞는 행에서 특정 컬럼만 선택
print("\n--- 국어 점수 70점 이상, 영어 점수 90점 이상인 학생의 이름과 도시 ---")
print(df[(df['kor'] >= 70) & (df['eng'] >= 90)][['name', 'city']])
```

#### 1.2.2. `|` (OR) 조건

두 개 이상의 조건 중 하나라도 만족하는 데이터를 선택할 때 사용합니다. 각 조건식을 `|` 연산자로 연결합니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경'],
    'kor': [90, 80, 70, 70, 60, 70],
    'eng': [99, 98, 97, 46, 77, 56],
    'mat': [90, 70, 70, 60, 88, 99],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울']
}
df = pd.DataFrame(data)

print("--- 국어 점수가 90점 이상이거나 수학 점수가 90점 이상인 학생 ---")
print(df[(df['kor'] >= 90) | (df['mat'] >= 90)])

print("\n--- 거주 도시가 '부산'이거나 '대구'인 학생 ---")
print(df[(df['city'] == '부산') | (df['city'] == '대구')])
```

#### 1.2.3. `~` (NOT) 조건

특정 조건을 만족하지 않는 데이터를 선택할 때 사용합니다. 조건식 앞에 `~` 연산자를 붙입니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래'],
    'city': ['서울', '부산', '서울', '대구']
}
df = pd.DataFrame(data)

print("--- 거주 도시가 '서울'이 아닌 학생 ---")
print(df[~(df['city'] == '서울')])

print("\n--- 국어 점수가 80점 미만이 아닌 학생 (즉, 80점 이상인 학생) ---")
df_scores = pd.DataFrame({'name': ['A', 'B', 'C'], 'kor': [70, 85, 90]})
print(df_scores[~(df_scores['kor'] < 80)])
```

#### 1.2.4. `isin()`을 이용한 다중 값 필터링

하나의 컬럼에서 여러 개의 특정 값 중 하나라도 포함하는 데이터를 선택할 때 `isin()` 메서드를 사용합니다. `|` (OR) 조건을 여러 번 사용하는 것보다 간결하고 효율적입니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민'],
    'city': ['서울', '부산', '서울', '대구', '부산']
}
df = pd.DataFrame(data)

print("--- 거주 도시가 '서울' 또는 '대구'인 학생 ---")
print(df[df['city'].isin(['서울', '대구'])])

print("\n--- 이름이 '홍길동' 또는 '이상민'인 학생 ---")
print(df[df['name'].isin(['홍길동', '이상민'])])
```

#### 1.2.5. `query()` 메서드를 이용한 조건 검색

`query()` 메서드는 문자열 형태로 조건식을 작성하여 데이터를 필터링할 수 있게 해줍니다. 복잡한 조건식을 작성할 때 가독성을 높일 수 있으며, 특히 컬럼 이름에 공백이 포함된 경우 유용합니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래'],
    'kor score': [90, 80, 70, 70], # 컬럼 이름에 공백 포함
    'eng score': [99, 98, 97, 46]
}
df = pd.DataFrame(data)

print("--- query() 메서드를 이용한 조건 검색 ---")
# 'kor score'가 80점 이상인 학생
print(df.query('`kor score` >= 80')) # 컬럼 이름에 공백이 있으면 백틱(`)으로 묶음

# 'kor score'가 70점 이상이고 'eng score'가 90점 이상인 학생
print(df.query('`kor score` >= 70 and `eng score` >= 90'))

# 변수 사용
min_kor_score = 75
print(df.query('`kor score` >= @min_kor_score')) # @를 사용하여 외부 변수 참조
```

#### 1.2.6. `np.logical_and/or` 사용 (대안)

NumPy의 논리 함수 `np.logical_and()`, `np.logical_or()`, `np.logical_not()`를 사용하여 복합 조건을 구성할 수도 있습니다. 이는 비트wise 연산자(`&`, `|`, `~`)의 대안으로 사용될 수 있으며, 경우에 따라 가독성을 높이는 데 도움이 될 수 있습니다.

```python
import numpy as np
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래'],
    'kor': [90, 80, 70, 70],
    'eng': [99, 98, 97, 46]
}
df = pd.DataFrame(data)

print("--- np.logical_and/or 사용 ---")
# 국어 점수가 70점 이상이고 영어 점수가 90점 이상인 학생 (AND)
print(df[np.logical_and(df['kor'] >= 70, df['eng'] >= 90)])

# 국어 점수가 90점 이상이거나 영어 점수가 90점 이상인 학생 (OR)
print(df[np.logical_or(df['kor'] >= 90, df['eng'] >= 90)])

# 국어 점수가 80점 미만이 아닌 학생 (NOT)
print(df[np.logical_not(df['kor'] < 80)])
```

#### 1.2.7. 오류 예시 (`and`, `or` 사용 시)

파이썬의 기본 논리 연산자 `and`, `or`는 Pandas `Series` 전체에 대해 불리언 값을 평가할 수 없으므로 `ValueError`가 발생합니다. 각 요소를 개별적으로 평가하려면 비트wise 연산자(`&`, `|`)를 사용해야 합니다.

```python
import pandas as pd

data = {
    'name': ['홍길동', '임꺽정'],
    'kor': [90, 80]
}
df = pd.DataFrame(data)

try:
    # 이렇게 사용하면 에러 발생 (ValueError: The truth value of a Series is ambiguous.)
    df_error = df[df['kor'] >= 80 and df['kor'] < 90]
    print(df_error)
except ValueError as e:
    print(f"\n오류 발생 (파이썬 'and' 사용 시): {e}")
    print("Pandas Series에 대해 파이썬의 'and', 'or' 연산자를 직접 사용할 수 없습니다.")
    print("대신 비트wise 연산자 '&', '|'를 사용하고 각 조건을 괄호로 묶어야 합니다.")

# 올바른 사용 예시
print("\n--- 올바른 사용 예시 ---")
print(df[(df['kor'] >= 80) & (df['kor'] < 90)])
```
