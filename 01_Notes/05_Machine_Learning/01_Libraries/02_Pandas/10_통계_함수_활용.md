## 1. 통계 함수 활용

Pandas `DataFrame`과 `Series`는 데이터의 특성을 이해하고 요약하는 데 필수적인 다양한 통계 함수를 제공합니다. 이 함수들은 데이터의 중심 경향성, 분산, 분포, 그리고 변수 간의 관계 등을 파악하는 데 사용됩니다.

### 1.1. 주요 통계 함수 목록

`DataFrame`의 각 열은 `Series` 타입이므로, `Series`에 적용 가능한 모든 통계 함수를 개별 컬럼에 직접 적용할 수 있습니다. 또한, `DataFrame` 전체에 적용하여 각 컬럼별 통계량을 얻을 수도 있습니다.

*   `count()`: 유효한(Non-null) 값의 개수
*   `sum()`: 값들의 합계
*   `mean()`: 산술 평균
*   `median()`: 중앙값 (데이터를 정렬했을 때 중간에 위치한 값)
*   `std()`: 표준편차 (Standard Deviation)
*   `var()`: 분산 (Variance)
*   `min()`: 최솟값
*   `max()`: 최댓값
*   `quantile(q)`: 사분위수 (q는 0과 1 사이의 값, 예: `0.25`는 1사분위수)
*   `mode()`: 최빈값 (가장 자주 나타나는 값)
*   `value_counts()`: `Series`에서 고유한 값들의 빈도수를 `Series` 형태로 반환 (자세한 내용은 [08_DataFrame_기본_정보_확인.md - `value_counts()`](./08_DataFrame_기본_정보_확인.md#115-value_counts-고유-값-빈도-계산) 참조)
*   `corr()`: `DataFrame`의 컬럼 간 상관계수 행렬 계산
*   `cov()`: `DataFrame`의 컬럼 간 공분산 행렬 계산
*   `idxmax()`: 최댓값을 가지는 인덱스 반환
*   `idxmin()`: 최솟값을 가지는 인덱스 반환
*   `cumsum()`: 누적 합계
*   `cumprod()`: 누적 곱
*   `diff()`: 이전 요소와의 차이
*   `pct_change()`: 이전 요소와의 백분율 변화
*   `rank()`: 값들의 순위 (동일 값 처리 방식 지정 가능)
*   `clip(lower, upper)`: 값들을 지정된 하한(lower)과 상한(upper)으로 제한
*   `round(decimals)`: 지정된 소수점 자릿수로 반올림
*   `abs()`: 절대값

### 1.2. 통계 함수 활용 예시

간단한 예시 `DataFrame`을 사용하여 다양한 통계 함수를 적용하는 방법을 알아봅니다.

```python
import pandas as pd
import numpy as np

# 예시 DataFrame 생성
data = {
    'Score': [85, 92, 78, 95, 88, 75, 91, 80, np.nan],
    'Hours_Studied': [5, 7, 4, 8, 6, 3, 7, 5, 6],
    'Grade': ['A', 'A', 'B', 'A', 'A', 'C', 'A', 'B', 'B']
}
df = pd.DataFrame(data)
print("원본 DataFrame:\n", df)

# 1. count(): 유효한 값의 개수
print("\n--- count() ---")
print(df.count()) # 각 컬럼의 Non-null 개수

# 2. sum(): 합계
print("\n--- sum() ---")
print(df['Score'].sum()) # 'Score' 컬럼의 합계
print(df.sum(numeric_only=True)) # 숫자형 컬럼의 합계 (DataFrame 전체)

# 3. mean(): 평균
print("\n--- mean() ---")
print(df['Score'].mean()) # 'Score' 컬럼의 평균
print(df.mean(numeric_only=True)) # 숫자형 컬럼의 평균 (DataFrame 전체)

# 4. median(): 중앙값
print("\n--- median() ---")
print(df['Score'].median()) # 'Score' 컬럼의 중앙값

# 5. std(): 표준편차, var(): 분산
print("\n--- std() & var() ---")
print(f"Score 표준편차: {df['Score'].std():.2f}")
print(f"Score 분산: {df['Score'].var():.2f}")

# 6. min(), max(): 최솟값, 최댓값
print("\n--- min() & max() ---")
print(f"Score 최솟값: {df['Score'].min()}")
print(f"Score 최댓값: {df['Score'].max()}")

# 7. quantile(): 사분위수
print("\n--- quantile() ---")
print(f"Score 1사분위수 (Q1): {df['Score'].quantile(0.25)}")
print(f"Score 3사분위수 (Q3): {df['Score'].quantile(0.75)}")

# 8. mode(): 최빈값
print("\n--- mode() ---")
print(df['Grade'].mode()) # 'Grade' 컬럼의 최빈값

# 9. idxmax(), idxmin(): 최댓값/최솟값의 인덱스
print("\n--- idxmax() & idxmin() ---")
print(f"Score 최댓값의 인덱스: {df['Score'].idxmax()}")
print(f"Score 최솟값의 인덱스: {df['Score'].idxmin()}")

# 10. cumsum(): 누적 합계
print("\n--- cumsum() ---")
print(df['Hours_Studied'].cumsum())

# 11. diff(): 이전 값과의 차이
print("\n--- diff() ---")
print(df['Score'].diff())

# 12. pct_change(): 이전 값과의 백분율 변화
print("\n--- pct_change() ---")
print(df['Score'].pct_change())

# 13. rank(): 순위
print("\n--- rank() ---")
print(df['Score'].rank())

# 14. abs(): 절대값
print("\n--- abs() ---")
s_neg = pd.Series([-1, 2, -3])
print(s_neg.abs())

# 15. corr(): 상관계수, cov(): 공분산
print("\n--- corr() & cov() ---")
print(df[['Score', 'Hours_Studied']].corr()) # 'Score'와 'Hours_Studied' 간 상관계수
print(df[['Score', 'Hours_Studied']].cov()) # 'Score'와 'Hours_Studied' 간 공분산
```

## 2. 핵심 통계 개념 이해

Pandas 통계 함수를 효과적으로 활용하기 위해서는 그 기반이 되는 통계 개념들을 이해하는 것이 중요합니다.

### 2.1. 중심 경향성 (Central Tendency)

데이터의 분포에서 중심이 어디에 위치하는지를 나타내는 척도입니다.

*   **평균 (Mean)**:
    *   모든 값을 더한 후 데이터의 개수로 나눈 값입니다.
    *   데이터의 중심을 나타내는 가장 일반적인 척도이지만, 극단적인 값(이상치)에 민감하게 반응합니다.
    *   Pandas 함수: `mean()`

*   **중앙값 (Median)**:
    *   데이터를 크기 순으로 정렬했을 때 정확히 중간에 위치한 값입니다. 데이터의 개수가 짝수일 경우, 가운데 두 값의 평균입니다.
    *   평균값과 달리 극단적인 값(이상치)의 영향을 덜 받으므로, 데이터 분포가 비대칭이거나 이상치가 존재할 때 데이터의 중심을 나타내는 데 더 적합할 수 있습니다.
    *   Pandas 함수: `median()`

*   **최빈값 (Mode)**:
    *   데이터에서 가장 자주 나타나는 값입니다. 하나 이상 존재할 수 있습니다.
    *   범주형 데이터의 중심을 나타내는 데 특히 유용합니다.
    *   Pandas 함수: `mode()`

### 2.2. 분산도 (Dispersion)

데이터가 중심으로부터 얼마나 흩어져 분포하는지를 나타내는 척도입니다.

*   **분산 (Variance)**:
    *   데이터가 평균으로부터 얼마나 흩어져 있는지를 나타내는 척도로, 각 데이터 포인트와 평균 간의 차이를 제곱한 값들의 평균입니다.
    *   표준편차의 제곱 값입니다.
    *   Pandas 함수: `var()`

*   **표준편차 (Standard Deviation)**:
    *   데이터가 평균으로부터 얼마나 떨어져 분포하는지를 나타내는 척도로, 분산의 양의 제곱근입니다.
    *   값이 클수록 데이터가 평균에서 넓게 흩어져 분포하고, 값이 작을수록 데이터가 평균 주변에 밀집하여 모여 있음을 의미합니다.
    *   데이터의 변동성(variability)을 측정하는 데 사용되며, 분산보다 해석이 직관적입니다.
    *   Pandas 함수: `std()`

### 2.3. 사분위수 (Quantile)

데이터를 크기 순으로 정렬했을 때, 전체 데이터를 4등분하는 위치에 있는 값들을 의미합니다. 데이터의 분포 형태와 이상치 여부를 파악하는 데 도움을 받을 수 있습니다.

*   **1사분위수 (Q1, 25%)**: 전체 데이터의 하위 25% 지점에 해당하는 값.
*   **2사분위수 (Q2, 50%, 중앙값)**: 전체 데이터의 중간 지점에 해당하는 값. (중앙값과 동일)
*   **3사분위수 (Q3, 75%)**: 전체 데이터의 상위 25% 지점에 해당하는 값.
*   **사분위 범위 (IQR, Interquartile Range)**: Q3 - Q1. 데이터의 중간 50%가 퍼져 있는 범위를 나타냅니다.
*   Pandas 함수: `quantile(q)`

### 2.4. 관계성 (Relationship)

두 변수 간의 선형적인 관계의 강도와 방향을 나타내는 척도입니다.

*   **상관관계 (Correlation)**:
    *   두 변수가 함께 변화하는 경향의 강도와 방향을 나타내는 척도입니다. -1과 1 사이의 값을 가집니다.
    *   1에 가까울수록 강한 양의 선형 관계, -1에 가까울수록 강한 음의 선형 관계, 0에 가까울수록 선형 관계가 없음을 의미합니다.
    *   Pandas 함수: `corr()`

*   **공분산 (Covariance)**:
    *   두 변수가 함께 변화하는 정도를 나타내는 척도입니다.
    *   양수이면 두 변수가 같은 방향으로, 음수이면 반대 방향으로 움직이는 경향이 있음을 의미합니다.
    *   상관관계와 달리 값의 범위가 정해져 있지 않아 해석이 어렵지만, 상관관계 계산의 기반이 됩니다.
    *   Pandas 함수: `cov()`
