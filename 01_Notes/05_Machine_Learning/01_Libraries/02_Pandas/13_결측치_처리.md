## 1. 결측치(NaN) 처리 개요

### 1.1. 결측치란?

결측치(Missing Values)는 데이터셋에서 값이 누락되거나 기록되지 않은 부분을 의미합니다. Pandas에서는 이러한 누락된 데이터를 **`NaN` (Not a Number)** 으로 표현하며, 이는 NumPy 라이브러리의 `np.nan` 객체와 동일합니다. `None`과 같은 파이썬의 다른 '비어있는' 값들도 Pandas DataFrame에 로드될 때 `NaN`으로 변환되는 경우가 많습니다.

**결측치가 발생하는 일반적인 원인:**
*   **데이터 수집 오류**: 센서 고장, 설문 응답 누락, 데이터 입력 실수 등.
*   **데이터 통합 문제**: 여러 데이터 소스를 병합할 때, 특정 데이터가 한쪽 소스에만 존재하여 다른 쪽에 결측치가 발생하는 경우.
*   **데이터 변환 과정**: 데이터 전처리 중 특정 연산(예: 0으로 나누기, 존재하지 않는 값 참조)으로 인해 `NaN`이 생성되는 경우.
*   **의도적인 누락**: 특정 정보가 존재하지 않거나, 공개할 수 없는 경우.

### 1.1.1. `pd.NA`: Pandas의 새로운 결측치 표현

Pandas 1.0부터 도입된 `pd.NA`는 `np.nan`의 한계를 보완하기 위해 설계된 새로운 결측치 표현입니다. `np.nan`은 부동 소수점(float) 타입으로만 존재할 수 있어, 정수형(integer)이나 불리언(boolean) 컬럼에 결측치가 포함되면 해당 컬럼의 `dtype`이 `float`나 `object`로 강제 변환되는 문제가 있었습니다. `pd.NA`는 이러한 타입 강제 변환 없이 원래의 `dtype`을 유지하면서 결측치를 표현할 수 있게 해줍니다.

**`np.nan`의 한계:**
```python
import pandas as pd
import numpy as np

s_int_nan = pd.Series([1, 2, np.nan, 4])
s_bool_nan = pd.Series([True, False, np.nan, True])

print("np.nan을 포함한 정수형 Series:\n", s_int_nan)
print("dtype:", s_int_nan.dtype) # float64로 변환됨

print("\nnp.nan을 포함한 불리언 Series:\n", s_bool_nan)
print("dtype:", s_bool_nan.dtype) # object로 변환됨
```

**`pd.NA`의 장점:**
*   **타입 유지**: 정수형, 불리언형 등 다양한 `dtype`에서 `pd.NA`를 사용하여도 해당 컬럼의 `dtype`이 유지됩니다. (Pandas 1.0+에서 `Int64`, `boolean` 등 새로운 nullable dtypes와 함께 사용)
*   **명확한 결측치**: `np.nan`은 숫자형 연산에서 `NaN`으로 동작하지만, `pd.NA`는 `None`과 유사하게 동작하여 더 명확한 결측치 의미를 가집니다.
*   **연산 동작**: `pd.NA`와의 연산 결과는 대부분 `pd.NA`가 됩니다.

```python
import pandas as pd
import numpy as np

# Pandas의 새로운 nullable integer dtype (Int64) 사용
s_int_na = pd.Series([1, 2, pd.NA, 4], dtype='Int64')
# Pandas의 새로운 nullable boolean dtype (boolean) 사용
s_bool_na = pd.Series([True, False, pd.NA, True], dtype='boolean')

print("pd.NA를 포함한 정수형 Series (nullable Int64):\n", s_int_na)
print("dtype:", s_int_na.dtype) # Int64 (대문자 I)로 유지됨

print("\npd.NA를 포함한 불리언 Series (nullable boolean):\n", s_bool_na)
print("dtype:", s_bool_na.dtype) # boolean으로 유지됨

# pd.NA와의 연산
print("\npd.NA + 5:", pd.NA + 5)
print("pd.NA == pd.NA:", pd.NA == pd.NA) # np.nan == np.nan은 False
print("np.nan == np.nan:", np.nan == np.nan)
```

**결론**: `pd.NA`는 `np.nan`의 타입 관련 한계를 극복하고, Pandas에서 결측치를 더 일관되고 타입 안전하게 다룰 수 있도록 돕는 중요한 발전입니다. 최신 Pandas 버전에서는 `pd.NA`와 함께 제공되는 nullable dtypes(`Int64`, `boolean`, `Float64` 등)를 활용하는 것이 좋습니다.

### 1.2. 왜 결측치를 처리해야 하는가?

결측치는 데이터 분석 및 머신러닝 모델링 과정에서 다양한 문제를 야기할 수 있으므로, 적절하게 처리하는 것이 필수적입니다.

*   **모델 학습 방해**: 대부분의 머신러닝 알고리즘은 숫자형 입력을 기대하며, `NaN` 값을 직접 처리할 수 없습니다. 결측치가 있는 데이터를 모델에 입력하면 오류가 발생하거나, 모델 학습이 제대로 이루어지지 않을 수 있습니다.
*   **통계 분석 왜곡**: 결측치는 평균, 표준편차, 상관관계 등 통계량 계산을 왜곡할 수 있습니다. 예를 들어, 특정 컬럼에 결측치가 많다면, 그 컬럼의 평균은 실제 데이터의 중심 경향을 제대로 반영하지 못할 수 있습니다.
*   **데이터 손실**: 결측치가 있는 행이나 열을 단순히 제거하는 방식은 데이터 손실로 이어져, 분석에 필요한 중요한 정보가 사라질 수 있습니다.
*   **결과 해석의 어려움**: 결측치가 많거나 특정 패턴을 보인다면, 분석 결과의 신뢰성을 떨어뜨리고 해석을 어렵게 만듭니다.

따라서 효과적인 데이터 분석을 위해서는 이러한 결측치를 상황과 분석 목적에 맞게 탐지하고, 제거하거나, 합리적인 값으로 대체하는 전처리 과정이 필수적입니다.

## 2. 결측치 탐지

데이터에 결측치가 얼마나, 어디에 있는지 정확하게 파악하는 것이 결측치 처리의 첫걸음입니다. Pandas는 이를 위한 다양한 메서드를 제공합니다.

```python
import pandas as pd
import numpy as np

# 예시 DataFrame 생성
df_nan = pd.DataFrame({
    'A': [1, 2, np.nan, 4, 5],
    'B': [np.nan, 10, 20, np.nan, 30],
    'C': [100, 200, 300, 400, 500],
    'D': [np.nan, np.nan, np.nan, np.nan, np.nan], # 모든 값이 결측치인 컬럼
    'E': [60, 70, 80, 90, np.nan]
})
print("--- 원본 DataFrame ---")
print(df_nan)
```

### 2.1. `isnull()` / `isna()`: 각 요소의 결측치 여부 확인

`isnull()`과 `isna()`는 동일한 기능을 수행하며, `DataFrame` 또는 `Series`의 각 요소가 결측치(`NaN`, `None`, `NaT` 등)인지 여부를 `True`/`False`로 이루어진 불리언 `DataFrame` 또는 `Series`로 반환합니다.

```python
print("
--- df.isnull(): 각 요소의 결측치 여부 확인 (True: 결측치) ---")
print(df_nan.isnull())

print("
--- df_nan['A'].isna(): Series의 결측치 여부 확인 ---")
print(df_nan['A'].isna())
```

### 2.2. `notnull()` / `notna()`: 각 요소의 유효값 여부 확인

`notnull()`과 `notna()`는 `isnull()` / `isna()`의 정반대 결과를 보여줍니다. 즉, 각 요소가 결측치가 아니면 `True`, 결측치이면 `False`를 반환합니다.

```python
print("
--- df.notnull(): 각 요소의 유효값 여부 확인 (True: 유효값) ---")
print(df_nan.notnull())

print("
--- df_nan['B'].notna(): Series의 유효값 여부 확인 ---")
print(df_nan['B'].notna())
```

### 2.3. 결측치 개수 확인 (`.sum()`)

`True`는 1, `False`는 0으로 간주되므로, `isnull()` 또는 `isna()`의 결과에 `.sum()` 메서드를 적용하면 각 컬럼별 또는 전체 `DataFrame`의 결측치 개수를 쉽게 얻을 수 있습니다.

```python
# 컬럼별 결측치 개수: 가장 일반적인 방법
print("
--- df.isnull().sum(): 컬럼별 결측치 개수 ---")
print(df_nan.isnull().sum())

# DataFrame 전체 결측치 개수: sum()을 두 번 사용
print(f"
--- df.isnull().sum().sum(): DataFrame 전체 결측치 개수 ---")
print(df_nan.isnull().sum().sum())

# 행별 결측치 개수: axis=1 사용
print("
--- df.isnull().sum(axis=1): 행별 결측치 개수 ---")
print(df_nan.isnull().sum(axis=1))
```

### 2.4. 결측치 비율 확인

결측치의 절대적인 개수뿐만 아니라, 전체 데이터에서 결측치가 차지하는 비율을 파악하는 것도 중요합니다.

```python
# 컬럼별 결측치 비율
print("
--- 컬럼별 결측치 비율 ---")
print(df_nan.isnull().sum() / len(df_nan))

# DataFrame 전체 결측치 비율
print(f"
--- DataFrame 전체 결측치 비율: {df_nan.isnull().sum().sum() / df_nan.size:.2f} ---")
```

### 2.5. 결측치가 있는 행/열 필터링 (`.any()`, `.all()`)

`any()`와 `all()` 메서드를 `isnull()`의 결과와 함께 사용하면, 결측치가 포함된 행이나 열을 쉽게 필터링할 수 있습니다.

*   `any(axis=1)`: 각 행에 결측치가 **하나라도 있으면** `True`
*   `all(axis=1)`: 각 행의 **모든 값이 결측치**이면 `True`
*   `any(axis=0)`: 각 열에 결측치가 **하나라도 있으면** `True`
*   `all(axis=0)`: 각 열의 **모든 값이 결측치**이면 `True`

```python
# 결측치가 하나라도 있는 행만 필터링
print("
--- df[df.isnull().any(axis=1)]: 결측치가 하나라도 있는 행 ---")
print(df_nan[df_nan.isnull().any(axis=1)])

# 모든 값이 결측치인 행만 필터링
print("
--- df[df.isnull().all(axis=1)]: 모든 값이 결측치인 행 ---")
print(df_nan[df_nan.isnull().all(axis=1)])

# 결측치가 하나라도 있는 컬럼만 필터링
print("
--- df.loc[:, df.isnull().any(axis=0)]: 결측치가 하나라도 있는 컬럼 ---")
print(df_nan.loc[:, df_nan.isnull().any(axis=0)])

# 모든 값이 결측치인 컬럼만 필터링
print("
--- df.loc[:, df.isnull().all(axis=0)]: 모든 값이 결측치인 컬럼 ---")
print(df_nan.loc[:, df_nan.isnull().all(axis=0)])
```

## 3. 결측치 제거 (`dropna`)

결측치가 포함된 행이나 열을 제거하여 데이터의 정합성을 높이는 방법입니다. 결측치가 적거나, 해당 데이터가 분석에 중요하지 않을 때 사용합니다.

```python
# 원본 DataFrame 재사용
print("--- 원본 DataFrame ---")
print(df_nan)
```

### 3.1. 행 단위 결측치 제거

`dropna()` 메서드는 기본적으로 결측치가 하나라도 있는 행을 제거합니다 (`axis=0` 또는 `'index'`, `how='any'`가 기본값).

```python
print("
--- df.dropna(): 결측치가 하나라도 있는 행 제거 ---")
print(df_nan.dropna())
```

### 3.2. 열 단위 결측치 제거

`axis=1` 또는 `'columns'`를 지정하면 결측치가 하나라도 있는 열을 제거합니다.

```python
print("
--- df.dropna(axis=1): 결측치가 하나라도 있는 열 제거 ---")
print(df_nan.dropna(axis=1))
```

### 3.3. `how` 파라미터 (`'any'`, `'all'`)

*   `'any'` (기본값): 결측치가 **하나라도 있으면** 제거합니다.
*   `'all'`: **모든 값이 결측치**일 때만 제거합니다.

```python
print("
--- df.dropna(how='all'): 모든 값이 결측치인 행만 제거 ---")
print(df_nan.dropna(how='all')) # 이 예시에서는 모든 행에 유효값이 있으므로 변화 없음

print("
--- df.dropna(how='all', axis=1): 모든 값이 결측치인 열만 제거 ---")
print(df_nan.dropna(how='all', axis=1)) # 'D' 컬럼만 제거됨
```

### 3.4. `thresh` 파라미터 (유효값 개수 기준)

`thresh`는 `NaN`이 아닌 유효한 데이터가 **최소 `thresh` 개 이상** 있는 행/열만 남깁니다.

```python
print("
--- df.dropna(thresh=3): 유효한 값이 3개 이상인 행만 남기기 ---")
print(df_nan.dropna(thresh=3)) # 0, 2, 3, 4번 행은 유효값이 3개 이상이므로 남음
```

### 3.5. `subset` 파라미터 (특정 컬럼 기준)

`subset`은 특정 컬럼(들)에 결측치가 있는 경우에만 행을 제거하도록 범위를 제한합니다. 매우 유용합니다.

```python
print("
--- df.dropna(subset=['A', 'B']): 'A' 또는 'B' 컬럼에 NaN이 있는 행 제거 ---")
print(df_nan.dropna(subset=['A', 'B'])) # 2번 행 (A에 NaN), 0, 3번 행 (B에 NaN)이 제거됨
```

**주의**: `dropna()`는 데이터 손실을 야기하므로 신중하게 결정해야 합니다. 특히 결측치가 중요한 정보를 담고 있을 수도 있습니다.

## 4. 결측치 채우기 (`fillna`)

결측치를 제거하는 대신, 특정 값으로 대체하는 방법입니다. 데이터 손실을 막을 수 있어 더 선호되는 경우가 많습니다.

```python
# 원본 DataFrame 재사용
print("--- 원본 DataFrame ---")
print(df_nan)
```

### 4.1. 특정 값으로 채우기

결측치를 `0`, `'Unknown'`, `평균` 등 특정 값으로 모두 채웁니다.

```python
print("
--- df.fillna(0): 모든 결측치를 0으로 채우기 ---")
print(df_nan.fillna(0))

print("
--- df_nan['B'].fillna('Missing'): 'B' 컬럼의 결측치를 'Missing'으로 채우기 ---")
print(df_nan['B'].fillna('Missing'))
```

### 4.2. 통계량으로 채우기 (평균, 중앙값, 최빈값)

결측치를 해당 컬럼의 평균, 중앙값, 또는 최빈값 등으로 채우는 것은 데이터의 분포를 크게 왜곡하지 않으면서 결측치를 처리하는 일반적인 방법입니다.

```python
# 'A' 컬럼의 NaN을 'A' 컬럼의 평균으로 채우기
print(f"
--- 'A' 컬럼의 평균({df_nan['A'].mean():.2f})으로 NaN 채우기 ---")
print(df_nan['A'].fillna(df_nan['A'].mean()))

# 'B' 컬럼의 NaN을 'B' 컬럼의 중앙값으로 채우기
print(f"
--- 'B' 컬럼의 중앙값({df_nan['B'].median():.2f})으로 NaN 채우기 ---")
print(df_nan['B'].fillna(df_nan['B'].median()))

# 'E' 컬럼의 NaN을 'E' 컬럼의 최빈값으로 채우기 (최빈값이 여러 개일 수 있으므로 [0]으로 첫 번째 값 선택)
print(f"
--- 'E' 컬럼의 최빈값({df_nan['E'].mode()[0]})으로 NaN 채우기 ---")
print(df_nan['E'].fillna(df_nan['E'].mode()[0]))
```

### 4.3. 이전/이후 값으로 채우기 (`ffill`, `bfill`)

시계열 데이터 등에서 유용합니다.
*   `'ffill'` (forward fill): 바로 **앞의 유효한 값**으로 채웁니다.
*   `'bfill'` (backward fill): 바로 **뒤의 유효한 값**으로 채웁니다.

```python
df_fill_method = pd.DataFrame({
    'Data': [10, np.nan, np.nan, 40, np.nan, 50]
})
print("
--- 원본 (ffill/bfill 예시) ---")
print(df_fill_method)

print("
--- df.fillna(method='ffill'): 바로 앞의 유효한 값으로 채우기 ---")
print(df_fill_method.fillna(method='ffill'))

print("
--- df.fillna(method='bfill'): 바로 뒤의 유효한 값으로 채우기 ---")
print(df_fill_method.fillna(method='bfill'))
```

### 4.4. `limit` 파라미터 (채울 개수 제한)

`ffill` 또는 `bfill` 사용 시, 연속된 결측치를 최대 몇 개까지 채울지 제한합니다.

```python
df_fill_limit = pd.DataFrame({'Data': [10, np.nan, np.nan, np.nan, 20, np.nan, np.nan, 30]})
print("
--- 원본 (limit 예시) ---")
print(df_fill_limit)

print("
--- df.fillna(method='ffill', limit=1): 연속된 NaN 중 1개만 채우기 ---")
print(df_fill_limit.fillna(method='ffill', limit=1))

print("
--- df.fillna(method='ffill', limit=2): 연속된 NaN 중 2개만 채우기 ---")
print(df_fill_limit.fillna(method='ffill', limit=2))
```

### 4.5. 컬럼별 다른 값으로 채우기

딕셔너리를 사용하여 컬럼별로 다른 값을 지정하여 결측치를 채울 수 있습니다.

```python
fill_values_per_column = {
    'A': df_nan['A'].mean(), # 'A' 컬럼은 평균으로
    'B': 99,                 # 'B' 컬럼은 99로
    'E': df_nan['E'].mode()[0] # 'E' 컬럼은 최빈값으로
}
print("
--- 컬럼별 다른 값으로 채우기 ---")
print(df_nan.fillna(value=fill_values_per_column))
```

## 5. 결측치 보간 (`interpolate`)

`interpolate()`는 결측치를 주변 값들을 기반으로 "추정"하여 채우는 더 정교한 방법입니다. 특히 시계열 데이터처럼 데이터가 일정한 추세를 가질 때 매우 효과적입니다.

```python
df_inter = pd.DataFrame({
    'Data': [10, np.nan, np.nan, 40, np.nan, 70, 80, np.nan, 100]
})
print("--- 원본 DataFrame (보간 예시) ---")
print(df_inter)
```

### 5.1. 선형 보간 (`linear`)

`'linear'` (기본값) 메서드는 결측치 양옆의 값을 직선으로 잇고 그 사이를 채웁니다.

```python
print("
--- df.interpolate(method='linear'): 선형 보간 ---")
print(df_inter.interpolate(method='linear'))
# 10과 40 사이는 20, 30으로 채워지고, 40과 70 사이는 55로 채워짐
```

### 5.2. 시간 기반 보간 (`time`)

`DatetimeIndex`를 가진 시계열 데이터에서 시간 간격에 따라 보간합니다. 시간 간격이 불규칙할 때 유용합니다.

```python
df_time_inter = pd.DataFrame({
    'Value': [10, np.nan, 40, np.nan, np.nan, 70]
}, index=pd.to_datetime(['2023-01-01', '2023-01-03', '2023-01-07', '2023-01-08', '2023-01-10', '2023-01-15']))
print("
--- 원본 시계열 DataFrame (시간 기반 보간 예시) ---")
print(df_time_inter)

print("
--- df.interpolate(method='time'): 시간 기반 보간 ---")
print(df_time_inter.interpolate(method='time'))
# 10과 40 사이의 NaN은 시간 간격에 비례하여 채워짐
```

### 5.3. 다항식/스플라인 보간 (`polynomial`, `spline`)

더 복잡한 곡선으로 보간합니다. `order` 파라미터로 차수를 지정합니다. 데이터의 추세가 선형이 아닐 때 고려할 수 있습니다.

```python
df_poly_inter = pd.DataFrame({
    'Value': [1, 4, np.nan, 16, np.nan, 36]
})
print("
--- 원본 DataFrame (다항식 보간 예시) ---")
print(df_poly_inter)

# 2차 다항식 보간 (y = ax^2 + bx + c 형태)
print("
--- df.interpolate(method='polynomial', order=2): 2차 다항식 보간 ---")
print(df_poly_inter.interpolate(method='polynomial', order=2))
```

## 6. 결측치 처리 모범 사례 및 고려사항

결측치 처리는 분석의 목적과 데이터의 특성에 따라 최적의 방법이 달라지므로, 각 방법의 장단점을 이해하고 신중하게 선택해야 합니다.

1.  **결측치 발생 원인 파악**: 결측치가 왜 발생했는지 이해하는 것이 중요합니다. 데이터 수집 오류인지, 특정 조건에서만 발생하는지 등에 따라 처리 전략이 달라질 수 있습니다.
2.  **결측치 비율 확인**: `df.isnull().sum() / len(df)`를 통해 각 컬럼의 결측치 비율을 확인합니다.
    *   **매우 높은 비율 (예: 70% 이상)**: 해당 컬럼을 제거하는 것을 고려합니다. 정보가 너무 부족하여 채우는 것이 의미 없을 수 있습니다.
    *   **낮은 비율 (예: 5% 미만)**: 제거하거나 간단한 통계량으로 채우는 것을 고려합니다.
    *   **중간 비율**: 보간법이나 모델 기반의 복잡한 대체 방법을 고려합니다.
3.  **데이터 타입 고려**: 숫자형, 범주형, 시계열 데이터에 따라 적합한 처리 방법이 다릅니다.
    *   **숫자형**: 평균, 중앙값, 보간법, 특정 값으로 채우기.
    *   **범주형**: 최빈값, 'Unknown'과 같은 새로운 범주로 채우기.
    *   **시계열**: `ffill`, `bfill`, `interpolate(method='time')` 등 시간 순서를 고려한 방법.
4.  **데이터 분포 유지**: 결측치를 채울 때 원본 데이터의 분포를 크게 왜곡하지 않도록 주의합니다. 특히 평균으로 채우는 것은 분포의 분산(variance)을 줄일 수 있습니다.
5.  **도메인 지식 활용**: 해당 분야의 전문가 지식을 활용하여 결측치를 채우는 것이 가장 합리적인 결과를 가져올 수 있습니다. 예를 들어, '수익' 컬럼의 결측치는 '0'으로 채우는 것이 합리적일 수 있습니다.
6.  **모델 기반 대체**: `SimpleImputer` (Scikit-learn)와 같은 도구를 사용하거나, 머신러닝 모델(예: KNN Imputer, Iterative Imputer)을 사용하여 결측치를 예측하여 채우는 고급 방법도 있습니다.
7.  **`inplace=True` 사용 주의**: `dropna()`나 `fillna()` 사용 시 `inplace=True` 옵션은 원본 `DataFrame`을 직접 수정합니다. 이는 메서드 체이닝을 방해하고 예상치 못한 부작용을 일으킬 수 있으므로, 새로운 `DataFrame`을 반환받아 재할당하는 것을 권장합니다.

결측치 처리는 데이터 분석의 중요한 단계이며, 올바른 전략은 분석 결과의 신뢰성과 모델의 성능에 큰 영향을 미칩니다.
