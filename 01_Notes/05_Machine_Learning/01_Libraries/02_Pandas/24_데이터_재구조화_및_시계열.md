## 1. 고급 데이터 조작 및 분석

### 1.1. 피벗 테이블 (Pivot Table)

`pivot_table()` 함수는 데이터를 재구성하여 요약 통계를 생성하는 강력한 도구입니다. 스프레드시트의 피벗 테이블과 유사하게, 하나 이상의 컬럼을 인덱스(행), 다른 컬럼을 컬럼(열)으로 사용하여 데이터를 집계합니다. 이는 복잡한 데이터 요약 및 분석에 매우 효과적입니다.

#### 1.1.1. `pivot_table()` 개요 및 주요 옵션

`pivot_table(data, values=None, index=None, columns=None, aggfunc='mean', fill_value=None, margins=False, dropna=True, margins_name='All')`

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `values` | 집계할 값 컬럼. | `None` |
| `index` | 행 인덱스로 사용할 컬럼(들). 리스트로 여러 개 지정 가능. | `None` |
| `columns` | 열 컬럼으로 사용할 컬럼(들). 리스트로 여러 개 지정 가능. | `None` |
| `aggfunc` | 집계 함수. `mean`, `sum`, `count`, `median`, `np.sum` 등. 리스트로 여러 개 지정 가능. | `'mean'` |
| `fill_value` | `NaN` 값을 채울 값. | `None` |
| `margins` | 총계(subtotals/grand totals)를 추가할지 여부. | `False` |

#### 1.1.2. `pivot_table()` 활용 예시

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
df_sales = pd.DataFrame({
    'Date': ['2023-01-01', '2023-01-01', '2023-01-02', '2023-01-02', '2023-01-01', '2023-01-02'],
    'Region': ['East', 'West', 'East', 'West', 'East', 'West'],
    'Product': ['A', 'B', 'A', 'C', 'C', 'B'],
    'Sales': [100, 150, 200, 120, 180, 250],
    'Quantity': [10, 15, 20, 12, 18, 25]
})
print("원본 DataFrame:\n", df_sales)
```

**1. 날짜별, 지역별 판매액 합계**
```python
pivot_sales_sum = df_sales.pivot_table(values='Sales', index='Date', columns='Region', aggfunc='sum')
print("\n날짜별, 지역별 판매액 합계:\n", pivot_sales_sum)
```

**2. 날짜별, 제품별 판매액 평균 (NaN은 0으로 채움)**
```python
pivot_avg_sales = df_sales.pivot_table(values='Sales', index='Date', columns='Product',
                                 aggfunc='mean', fill_value=0)
print("\n날짜별, 제품별 판매액 평균 (NaN 0으로 채움):\n", pivot_avg_sales)
```

**3. 여러 인덱스/컬럼 및 여러 집계 함수 적용**
```python
pivot_multi = df_sales.pivot_table(
    values=['Sales', 'Quantity'],
    index=['Date', 'Region'],
    columns='Product',
    aggfunc={'Sales': 'sum', 'Quantity': 'mean'},
    fill_value=0,
    margins=True # 총계(Grand Total) 추가
)
print("\n다중 인덱스/컬럼 및 다중 집계:\n", pivot_multi)
```

### 1.2. 데이터 변형 (Melt)

`melt()` 함수는 DataFrame을 '넓은' 형식(wide format)에서 '긴' 형식(long format)으로 변형하는 데 사용됩니다. 이는 특히 시각화 라이브러리(예: Seaborn)에서 여러 변수를 하나의 컬럼으로 모아 플로팅할 때 유용합니다. 즉, 컬럼을 행으로 '녹이는' 작업입니다.

#### 1.2.1. `melt()` 개요 및 주요 옵션

`pd.melt(frame, id_vars=None, value_vars=None, var_name=None, value_name='value', col_level=None, ignore_index=True)`

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `id_vars` | 고정할(녹이지 않을) 컬럼(들). | `None` |
| `value_vars` | 녹일(행으로 변환할) 컬럼(들). 지정하지 않으면 `id_vars`를 제외한 모든 컬럼. | `None` |
| `var_name` | `value_vars`의 컬럼 이름들이 들어갈 새로운 컬럼의 이름. | `'variable'` |
| `value_name` | `value_vars`의 값들이 들어갈 새로운 컬럼의 이름. | `'value'` |

#### 1.2.2. `melt()` 활용 예시

```python
# 예시 데이터프레임 (넓은 형식)
df_scores_wide = pd.DataFrame({
    'Student_ID': [1, 2, 3],
    'Math': [90, 85, 78],
    'Science': [70, 95, 88],
    'English': [80, 75, 92]
})
print("원본 (넓은 형식) DataFrame:\n", df_scores_wide)
```

**1. 기본 `melt` (모든 과목을 녹이기)**
```python
df_scores_long = df_scores_wide.melt(id_vars=['Student_ID'], var_name='Subject', value_name='Score')
print("\n변형된 (긴 형식) DataFrame:\n", df_scores_long)
```

**2. 특정 과목만 녹이기 (`value_vars`)**
```python
df_partial_melt = df_scores_wide.melt(id_vars=['Student_ID'], value_vars=['Math', 'English'],
                                      var_name='Exam', value_name='Result')
print("\n특정 과목만 녹인 DataFrame:\n", df_partial_melt)
```

### 1.3. 시계열 데이터 처리 (Time Series)

Pandas는 시계열 데이터(시간 순서에 따라 기록된 데이터)를 다루는 데 매우 강력한 기능을 제공합니다. 날짜/시간 인덱싱, 리샘플링, 다양한 윈도우 함수 등이 포함됩니다.

#### 1.3.1. 날짜/시간 데이터 타입 (`datetime`)

Pandas에서 시계열 데이터를 다루기 위해서는 날짜/시간 컬럼이 `datetime` 타입이어야 합니다.

```python
# 문자열을 datetime 타입으로 변환
dates_str = ['2023-01-01', '2023-01-02 10:30:00', '2023/01/03']
datetime_obj = pd.to_datetime(dates_str)
print("문자열 -> datetime:\n", datetime_obj)

# 날짜 범위 생성: pd.date_range(start, end, periods, freq)
date_range_daily = pd.date_range(start='2023-01-01', periods=5, freq='D')
print("\n일별 날짜 범위:\n", date_range_daily)

date_range_hourly = pd.date_range(start='2023-01-01 09:00', periods=3, freq='H')
print("\n시간별 날짜 범위:\n", date_range_hourly)

# datetime 객체에서 연, 월, 일, 요일 등 추출
df_time = pd.DataFrame({'timestamp': pd.to_datetime(['2023-07-15 14:30:00', '2023-07-16 09:00:00']),
                        'value': [10, 20]})
df_time['year'] = df_time['timestamp'].dt.year
df_time['month'] = df_time['timestamp'].dt.month
df_time['day'] = df_time['timestamp'].dt.day
df_time['hour'] = df_time['timestamp'].dt.hour
df_time['dayofweek'] = df_time['timestamp'].dt.dayofweek # 월=0, 일=6
print("\ndatetime 구성 요소 추출:\n", df_time)
```

#### 1.3.2. 시계열 인덱싱 및 슬라이싱

`datetime` 인덱스를 사용하면 날짜 문자열을 이용한 편리한 슬라이싱이 가능합니다.

```python
# 시계열 데이터프레임 생성
dates = pd.date_range(start='2023-01-01', periods=30, freq='D')
ts_df = pd.DataFrame(np.random.randn(30, 2), index=dates, columns=['Value1', 'Value2'])
print("원본 시계열 DataFrame (일부):\n", ts_df.head())

# 특정 날짜 선택
print("\n2023년 1월 5일 데이터:\n", ts_df.loc['2023-01-05'])

# 특정 월 데이터 슬라이싱
print("\n2023년 1월 데이터 (일부):\n", ts_df['2023-01'].head())

# 날짜 범위 슬라이싱
print("\n2023년 1월 10일 ~ 1월 15일 데이터:\n", ts_df['2023-01-10':'2023-01-15'])
```

#### 1.3.3. 리샘플링 (`resample`)

`resample()`은 시계열 데이터의 빈도(frequency)를 변경하는 데 사용됩니다. 고빈도 데이터를 저빈도 데이터로(다운샘플링), 또는 저빈도 데이터를 고빈도 데이터로(업샘플링) 변환할 수 있습니다.

```python
# 예시: 시간별 데이터 생성
hourly_dates = pd.date_range(start='2023-01-01 00:00', periods=24 * 7, freq='H')
hourly_data = pd.Series(np.random.rand(len(hourly_dates)) * 100, index=hourly_dates)

print("원본 시간별 데이터 (일부):\n", hourly_data.head())

# 일별 평균으로 다운샘플링
daily_mean = hourly_data.resample('D').mean()
print("\n일별 평균 데이터:\n", daily_mean.head())

# 주별 합계로 다운샘플링
weekly_sum = hourly_data.resample('W').sum()
print("\n주별 합계 데이터:\n", weekly_sum.head())

# 월별 최대값으로 다운샘플링
monthly_max = hourly_data.resample('M').max()
print("\n월별 최대값 데이터:\n", monthly_max.head())

# 업샘플링: 일별 데이터를 시간별로 확장하고, 결측치는 이전 값으로 채우기 (ffill)
# (예시를 위해 일별 데이터를 다시 만듭니다)
daily_data_for_upsample = pd.Series([10, 20, 30], index=pd.to_datetime(['2023-01-01', '2023-01-03', '2023-01-05']))
upsampled_data = daily_data_for_upsample.resample('D').ffill()
print("\n업샘플링 (ffill):\n", upsampled_data)
```

#### 1.3.4. 윈도우 함수 (`rolling`, `expanding`, `ewm`)

윈도우 함수는 특정 기간(윈도우) 내의 데이터에 대해 연산을 수행합니다. 시계열 데이터의 추세나 패턴을 분석하는 데 필수적입니다.

```python
# 예시 시계열 데이터 생성
dates_for_window = pd.date_range(start='2023-01-01', periods=15, freq='D')
values_for_window = np.array([10, 12, 15, 13, 18, 20, 22, 25, 23, 28, 30, 32, 35, 33, 38])
ts_window = pd.Series(values_for_window, index=dates_for_window)
print("원본 시계열 데이터:\n", ts_window)
```

**1. `rolling()` (이동 윈도우)**: 고정된 크기의 윈도우를 이동시키며 연산을 수행합니다. 주로 이동 평균, 이동 표준편차 등을 계산할 때 사용됩니다.

*   `window`: 윈도우의 크기.
*   `min_periods`: 윈도우 내 최소 데이터 개수. 이보다 적으면 `NaN`.

```python
# 3일 이동 평균
rolling_mean_3d = ts_window.rolling(window=3).mean()
print("\n3일 이동 평균:\n", rolling_mean_3d)

# 5일 이동 합계 (최소 3개 데이터 필요)
rolling_sum_5d = ts_window.rolling(window=5, min_periods=3).sum()
print("\n5일 이동 합계 (min_periods=3):\n", rolling_sum_5d)
```

**2. `expanding()` (확장 윈도우)**: 윈도우의 크기가 데이터 시작점부터 현재까지 점차 확장되며 연산을 수행합니다. 누적 합계, 누적 평균 등을 계산할 때 사용됩니다.

```python
# 누적 합계
expanding_sum = ts_window.expanding().sum()
print("\n누적 합계:\n", expanding_sum)

# 누적 평균
expanding_mean = ts_window.expanding().mean()
print("\n누적 평균:\n", expanding_mean)
```

**3. `ewm()` (지수 가중 이동 윈도우)**: 최근 데이터에 더 큰 가중치를 부여하여 이동 평균 등을 계산합니다. 시계열 데이터의 최신 추세를 더 잘 반영합니다.

*   `span`: 스팬(span)을 기준으로 가중치를 계산. (일반적으로 많이 사용)
*   `halflife`: 반감기를 기준으로 가중치를 계산.

```python
# 지수 가중 이동 평균 (span=3)
ewm_mean_3span = ts_window.ewm(span=3).mean()
print("\n지수 가중 이동 평균 (span=3):\n", ewm_mean_3span)
```

이러한 고급 데이터 조작 및 시계열 처리 기능들을 통해 Pandas는 복잡한 데이터 분석 및 머신러닝 전처리 과정에서 강력한 도구로 활용됩니다.

```
