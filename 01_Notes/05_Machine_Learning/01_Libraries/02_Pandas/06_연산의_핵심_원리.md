## 1. Pandas 연산의 핵심 원리

Pandas 객체(Series, DataFrame) 간의 산술 연산은 NumPy를 기반으로 한 **벡터화된 방식**으로 수행되어 매우 효율적입니다. 이러한 연산의 바탕에는 모든 것을 관통하는 몇 가지 핵심 원리가 있습니다.

### 1.1. 원리 1: 인덱스 정렬 (Index Alignment)

Pandas 연산의 가장 중요한 첫 번째 원리는 **인덱스 정렬**입니다. 이는 단순히 같은 위치의 값끼리 계산하는 것이 아니라, **같은 인덱스 레이블을 가진 값끼리** 연산을 수행하는 방식입니다. 이 기능은 데이터의 무결성을 보장하고 의도치 않은 오류를 방지하는 강력한 안전장치 역할을 합니다.

- **정확한 연산 과정**:
  1.  **인덱스 통합**: 연산에 참여하는 모든 객체의 인덱스(행/열)를 모아 중복을 제거한 **인덱스의 합집합(union)**을 생성합니다. 이것이 결과 객체의 새로운 인덱스가 됩니다.
  2.  **값 정렬 및 연산**: 새로 만들어진 인덱스 합집합의 각 레이블에 대해, 원래 객체들에서 해당 레이블의 값을 찾아 연산을 수행합니다.
  3.  **결측치(`NaN`) 처리**: 만약 특정 레이블이 한 객체에는 있지만 다른 객체에는 없다면, 그 연산의 결과는 `NaN`(Not a Number)이 됩니다. 이는 데이터가 한쪽에 존재하지 않음을 명확하게 나타냅니다.

- **Series 연산 예시**:

    ```python
    import pandas as pd

    s1 = pd.Series([1, 2, 3], index=['a', 'b', 'c'])
    s2 = pd.Series([4, 5, 6], index=['b', 'c', 'd'])

    print(f"s1:\n{s1}")
    print(f"\ns2:\n{s2}")

    # 인덱스 'b', 'c'는 양쪽에 모두 존재하므로 덧셈 수행
    # 인덱스 'a', 'd'는 한쪽에만 존재하므로 NaN 처리
    print(f"\ns1 + s2:\n{s1 + s2}")
    ```

- **DataFrame 연산 예시**:

    DataFrame의 경우, **행 인덱스와 열 인덱스 모두**에 대해 정렬이 일어납니다.

    ```python
    import numpy as np

    df1 = pd.DataFrame(np.ones((2, 2)), columns=['A', 'B'], index=['가', '나'])
    df2 = pd.DataFrame(np.ones((3, 3)), columns=['A', 'B', 'C'], index=['가', '나', '다'])

    print(f"df1:\n{df1}")
    print(f"\ndf2:\n{df2}")

    # 두 DataFrame의 합집합 인덱스/컬럼에 대해 연산
    print(f"\ndf1 + df2:\n{df1 + df2}")
    # 결과 설명:
    # (가, A), (가, B), (나, A), (나, B)는 양쪽에 모두 존재하므로 1+1=2.0
    # (다, C) 처럼 한쪽에만 존재하는 모든 위치는 NaN이 됨
    ```

- **결측치 채우기 (`fill_value`)**:

    연산 시 `NaN`이 발생하는 것을 원치 않는다면, 연산 메서드(`add`, `sub` 등)의 `fill_value` 인자를 사용하여 한쪽 객체에 없는 값을 특정 값으로 대체할 수 있습니다.

    ```python
    # df1에는 있지만 df2에는 없는 값을 0으로 간주하고 연산
    print(f"\ndf1.add(df2, fill_value=0):\n{df1.add(df2, fill_value=0)}")
    ```

### 1.2. 원리 2: 브로드캐스팅 (Broadcasting)

**브로드캐스팅**은 모양(shape)이 다른 배열(DataFrame과 Series) 간의 연산을 가능하게 하는 강력한 메커니즘입니다. 작은 차원의 객체(Series)가 큰 차원의 객체(DataFrame)의 모양에 맞게 "확장"되어 연산이 수행됩니다.

- **기본 동작: 행 단위 브로드캐스팅 (axis = 1 또는 'columns')**

    별도의 축을 지정하지 않으면, Pandas는 Series의 인덱스를 DataFrame의 **컬럼(columns) 레이블**에 맞추려고 시도합니다. 성공하면, 해당 Series를 모든 **행**에 걸쳐 "아래로" 확장하여 적용합니다. 이는 DataFrame의 모든 행에 대해 동일한 값을 빼거나 더하는 것과 같습니다.

    ```python
    df = pd.DataFrame(np.arange(12.).reshape((4, 3)), columns=list('bde'))
    s = df.iloc[0] # 첫 번째 행을 Series로 추출 (index: [b, d, e])

    print(f"원본 DataFrame:\n{df}")
    print(f"\n연산에 사용할 Series (df의 첫 행):\n{s}")

    # df의 모든 행에 대해 s를 빼기 연산
    # (df의 0행 - s), (df의 1행 - s), ... 와 같이 동작
    print(f"\ndf - s (행 단위 브로드캐스팅):\n{df - s}")
    ```

- **축 지정: 열 단위 브로드캐스팅 (axis = 0 또는 'index')**

    연산 메서드(`add`, `sub` 등)에서 `axis='index'` (또는 `axis=0`)를 사용하면, Series의 인덱스를 DataFrame의 **행(index) 레이블**에 맞춥니다. 성공하면, 해당 Series를 모든 **열**에 걸쳐 "옆으로" 확장하여 적용합니다.

    이는 각 **열**에 대해 동일한 연산을 적용하고 싶을 때 매우 유용합니다. (예: 각 과목 점수에서 해당 과목의 평균점 빼기)

    ```python
    # 열을 기준으로 연산하기 위한 Series (df의 'e' 컬럼)
    s_col = df['e']

    print(f"\n연산에 사용할 Series (df의 'e' 컬럼):\n{s_col}")

    # df의 각 행 인덱스(0,1,2,3)와 s_col의 인덱스(0,1,2,3)를 맞춤
    # 그 후, s_col의 값을 모든 컬럼('b','d','e')에 "옆으로" 확장하여 뺄셈
    print(f"\ndf.sub(s_col, axis='index'):\n{df.sub(s_col, axis=0)}")
    ```

### 1.3. 원리 3: 유니버설 함수 (UFuncs) 적용

Pandas는 NumPy를 기반으로 하므로, NumPy의 **유니버설 함수(Universal Functions, ufuncs)**를 Pandas 객체에 직접 적용할 수 있습니다. UFuncs는 배열의 각 요소에 대해 빠른 연산을 수행하도록 C언어로 구현된 함수로, 파이썬 반복문보다 월등히 빠릅니다.

- **단항 유니버설 함수 (Unary UFuncs)**: 단일 배열(Series 또는 DataFrame)을 인자로 받아 각 요소에 함수를 적용합니다. 결과 객체의 인덱스는 그대로 유지됩니다.

    ```python
    # 예제 DataFrame 생성
    df = pd.DataFrame(np.random.randn(3, 3) * 4, columns=['A', 'B', 'C'])
    print(f"원본 DataFrame:\n{df}")

    # np.abs(): 각 요소의 절대값을 계산
    print(f"\n절대값 (np.abs):\n{np.abs(df)}")

    # np.sqrt(): 각 요소의 제곱근을 계산 (음수는 NaN으로 변환)
    print(f"\n제곱근 (np.sqrt):\n{np.sqrt(df)}")

    # np.exp(): 각 요소의 지수 함수(e^x) 계산
    print(f"\n지수 함수 (np.exp):\n{np.exp(df)}")
    ```

- **이항 유니버설 함수 (Binary UFuncs)**: 두 개의 배열을 인자로 받아 같은 위치의 요소끼리 연산을 수행합니다. 이 경우에도 **인덱스 정렬**이 동일하게 적용됩니다.

    사실, `df1 + df2`와 같은 표준 산술 연산은 내부적으로 `np.add(df1, df2)`와 같은 이항 UFunc를 호출하는 것입니다.

    ```python
    df1 = pd.DataFrame(np.arange(9.).reshape((3, 3)), columns=list('abc'))
    df2 = pd.DataFrame(np.arange(12.).reshape((4, 3)), columns=list('bce'))

    print(f"\ndf1:\n{df1}")
    print(f"\ndf2:\n{df2}")

    # np.add는 + 연산자와 동일 (인덱스 정렬 후 덧셈)
    print(f"\n덧셈 (np.add):\n{np.add(df1, df2)}")

    # np.maximum: 같은 위치의 요소 중 큰 값을 선택 (인덱스 정렬 후)
    print(f"\n최대값 (np.maximum):\n{np.maximum(df1, df2)}")
    ```

## 2. 실전 활용 팁 및 모범 사례

1.  **데이터 정합성 확인**: 연산 전에 `df.info()`나 `s.index` 등을 통해 데이터의 인덱스와 타입을 미리 확인하는 습관을 들이면 의도치 않은 `NaN` 발생을 줄일 수 있습니다.

2.  **`fill_value`의 적극적 활용**: 서로 다른 출처의 데이터를 조합할 때, `NaN`이 전파되는 것을 막기 위해 `fill_value=0`과 같은 옵션을 사용하는 것이 매우 유용합니다.

3.  **명시적인 축 지정**: 브로드캐스팅 시 `axis='index'` 또는 `axis='columns'`를 명시적으로 사용하여 코드의 가독성을 높이고 의도를 명확히 하세요. 기본 동작(행 단위)에 의존하기보다 명시하는 것이 좋습니다.

4.  **성능을 위한 벡터화**: Pandas와 NumPy의 핵심은 벡터화 연산입니다. `for` 루프를 사용하여 각 요소를 순회하며 계산하는 대신, UFuncs나 브로드캐스팅을 활용하면 훨씬 빠르고 간결한 코드를 작성할 수 있습니다.

5.  **인덱스 재설정 (`reset_index`)**: 인덱스 정렬을 원하지 않고, 단순히 위치를 기준으로 연산하고 싶다면, `df1.reset_index(drop=True) + df2.reset_index(drop=True)`와 같이 인덱스를 초기화한 후 연산하는 방법을 고려할 수 있습니다.
