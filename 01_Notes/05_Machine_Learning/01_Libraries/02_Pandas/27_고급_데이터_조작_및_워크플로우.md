## 1. MultiIndex (계층적 인덱싱) 활용

MultiIndex(또는 계층적 인덱싱)는 `DataFrame`의 인덱스를 여러 레벨(차원)로 구성하여, 고차원 데이터를 2차원의 표 형태로 효과적으로 표현하고 다룰 수 있게 해주는 강력한 기능입니다. `groupby()`나 `pivot_table()`의 결과로 자연스럽게 생성되며, 데이터를 더 세분화하여 분석하고 조작하는 데 필수적입니다.

### 1.1. MultiIndex 생성

가장 흔한 방법은 기존 `DataFrame`의 컬럼들을 인덱스로 지정하는 것입니다.

-   `set_index()`: 하나 이상의 컬럼을 리스트로 전달하여 MultiIndex를 생성합니다.

```python
import pandas as pd
import numpy as np

# 예시 데이터
data_multi = {
    'Region': ['East', 'East', 'West', 'West', 'East', 'West'],
    'Product': ['A', 'B', 'A', 'B', 'A', 'B'],
    'Year': [2022, 2022, 2022, 2022, 2023, 2023],
    'Sales': [100, 150, 200, 250, 110, 260]
}
df_multi = pd.DataFrame(data_multi)

# Region과 Year를 두 레벨의 인덱스로 설정
df_multi_indexed = df_multi.set_index(['Region', 'Year'])
print("MultiIndex DataFrame (set_index):\n", df_multi_indexed)
print("\nIndex 정보:\n", df_multi_indexed.index)
```

### 1.2. MultiIndex 데이터 접근 및 슬라이싱

계층적 구조 때문에 데이터에 접근하는 방법이 일반 인덱싱보다 조금 더 복잡하지만, 그만큼 강력합니다. **인덱스가 정렬되어 있을 때 최고의 성능**을 발휘하므로, `.sort_index()`를 먼저 사용하는 것이 좋습니다.

```python
# 효율적인 슬라이싱을 위해 인덱스 정렬
df_sorted = df_multi_indexed.sort_index()
print("\n정렬된 MultiIndex DataFrame:\n", df_sorted)

# 1. 기본 슬라이싱 (loc)
# 바깥쪽 레벨(Region)부터 접근
print("\nRegion 'East' 데이터 접근:\n", df_sorted.loc['East'])

# 튜플을 사용하여 안쪽 레벨까지 접근
print("\n('East', 2023) 데이터 접근:\n", df_sorted.loc[('East', 2023)])

# 2. 교차 선택 (xs)
# .xs() 메서드는 특정 레벨의 키 값을 지정하여 데이터를 선택할 때 유용합니다。
# .loc과 달리, 안쪽 레벨의 키만으로도 데이터를 쉽게 가져올 수 있습니다.
print("\nYear 2022 데이터 교차 선택 (xs):\n", df_sorted.xs(2022, level='Year'))

# 3. 고급 슬라이싱 (pd.IndexSlice)
# 복잡한 슬라이싱 조건을 간결하게 표현할 때 사용합니다.
idx = pd.IndexSlice
# 모든 Region에 대해 Year가 2022인 데이터 슬라이싱
print("\nIndexSlice로 2022년 데이터 슬라이싱:\n", df_sorted.loc[idx[:, 2022], :])
```

### 1.3. MultiIndex 조작 (`stack`, `unstack`, `reset_index`)

MultiIndex는 `stack()`과 `unstack()`을 통해 데이터의 구조를 유연하게 변경할 수 있습니다.

-   `unstack()`: **인덱스 레벨을 컬럼 레벨로** 변환합니다. (데이터를 '넓은' 형식으로)
-   `stack()`: **컬럼 레벨을 인덱스 레벨로** 변환합니다. (데이터를 '긴' 형식으로)
-   `reset_index()`: 인덱스 레벨의 일부 또는 전체를 다시 일반 컬럼으로 되돌립니다.

```python
# 예시: groupby로 생성된 MultiIndex Series
s_multi = df_multi.groupby(['Region', 'Year'])['Sales'].mean()
print("\nMultiIndex Series:\n", s_multi)

# unstack(): Year 인덱스를 컬럼으로 변환
df_unstacked = s_multi.unstack(level='Year')
print("\nUnstacked DataFrame:\n", df_unstacked)

# stack(): 위에서 unstack한 DataFrame을 다시 원래 Series 형태로 변환
s_stacked = df_unstacked.stack()
print("\nStacked Series:\n", s_stacked)

# reset_index(): MultiIndex를 모두 컬럼으로 변환
df_reset = s_multi.reset_index()
print("\nReset Index:\n", df_reset)
```
MultiIndex를 자유자재로 다룰 수 있게 되면, 복잡한 그룹별 집계 및 피벗 연산을 훨씬 효과적으로 수행할 수 있습니다.


## 2. 메서드 체이닝 (Method Chaining)

메서드 체이닝은 여러 데이터 처리 단계를 **하나의 연속된 흐름으로 연결**하여 코드의 가독성과 효율성을 높이는 강력한 코딩 스타일입니다. 대부분의 Pandas 메서드는 `DataFrame` 객체를 반환하므로, 반환된 `DataFrame`에 다시 점(`.`)을 찍어 다음 메서드를 연쇄적으로 호출할 수 있습니다.

**왜 메서드 체이닝을 사용할까?**

중간 과정에서 불필요한 변수(예: `df1`, `df2`, `df_filtered`, `df_grouped` 등)를 만들지 않아도 되기 때문입니다.

-   **Before (체이닝 미사용)**:
    ```python
    # df_chain은 예제 데이터라고 가정
    df_temp1 = df_chain.dropna(subset=['value1'])
    df_temp2 = df_temp1.query("category != 'C'")
    df_temp2['total'] = df_temp2['value1'] + df_temp2['value2']
    df_grouped = df_temp2.groupby('category')
    df_agg = df_grouped.agg(avg_total=('total', 'mean'), max_value1=('value1', 'max'))
    df_sorted = df_agg.sort_values(by='avg_total', ascending=False)
    final_df = df_sorted.reset_index()
    ```
    *단점: 중간 변수가 많아 코드가 길어지고, 전체적인 데이터의 흐름을 파악하기 어렵습니다.*

-   **After (메서드 체이닝 사용)**:
    ```python
    final_df_chained = (
        df_chain
        .dropna(subset=['value1'])
        .query("category != 'C'")
        .assign(total = lambda df: df.value1 + df.value2)
        .groupby('category')
        .agg(avg_total=('total', 'mean'), max_value1=('value1', 'max'))
        .sort_values(by='avg_total', ascending=False)
        .reset_index()
    )
    ```
    *장점: 데이터가 위에서 아래로 어떻게 흘러가며 변환되는지 명확하게 보입니다.*

--- 
**가독성을 높이는 모범 사례**

1.  **전체 체인을 괄호 `()`로 감싸기**: 파이썬은 괄호 안에서의 줄바꿈을 허용하므로, 각 메서드를 새로운 줄에 작성할 수 있어 가독성이 크게 향상됩니다.
2.  **각 메서드를 새로운 줄에서 시작하기**: 각 처리 단계를 시각적으로 구분할 수 있습니다.
3.  **적절한 주석 사용**: 각 라인이 어떤 작업을 수행하는지 간단한 주석을 달아두면, 나중에 코드를 다시 보거나 다른 사람과 협업할 때 도움이 됩니다.

**메서드 체이닝에 자주 사용되는 함수들**

-   **데이터 변환 및 추가**: `.assign()`, `.apply()`, `.map()`
-   **필터링 및 선택**: `.query()`, `.loc[]`, `.iloc[]`, `.drop()`, `.dropna()`
-   **그룹화 및 집계**: `.groupby()`, `.agg()`, `.pivot_table()`
-   **정렬 및 재구조화**: `.sort_values()`, `.sort_index()`, `.reset_index()`, `.rename()`

메서드 체이닝은 단순히 코드를 짧게 만드는 기술이 아니라, 데이터 처리의 논리적 흐름을 명확하게 표현하여 더 깔끔하고 유지보수하기 좋은 코드를 작성하는 패러다임입니다.

### 3. 재사용 가능한 워크플로우: `.pipe()` 활용

메서드 체이닝은 코드를 깔끔하게 만들지만, 체인 중간에 `lambda`가 아닌 복잡한 로직이나 재사용하고 싶은 함수를 적용하기는 어렵습니다. `.pipe()`는 이러한 문제를 해결하기 위해 등장했으며, **메서드 체인 내에서 사용자 정의 함수를 원활하게 통합**할 수 있도록 해주는 강력한 도구입니다.

**`.pipe()`는 왜 필요한가?**

메서드 체이닝 중간에 `my_function(df)`와 같은 일반 함수를 호출하려면 체인이 끊어집니다.

```python
# 체이닝이 끊어지는 예시
df1 = df.dropna()
df2 = my_custom_function(df1, arg1) # 체인이 끊어짐
df3 = df2.reset_index()
```

`.pipe()`는 `DataFrame` 자체를 첫 번째 인자로 받는 함수를 호출하여, 체인을 끊지 않고 계속 이어나갈 수 있게 합니다.

`df.pipe(my_function, arg1)`는 `my_function(df, arg1)`와 동일하게 동작합니다.

--- 
**`.pipe()`의 장점과 사용법**

-   **가독성**: `df.pipe(calculate_statistics)` 처럼, 각 단계가 명확한 함수 이름으로 표현되어 코드의 의도를 파악하기 쉽습니다.
-   **모듈성 및 재사용성**: 데이터 처리 단계를 독립적인 함수로 만들어, 다른 분석 파이프라인에서도 쉽게 재사용할 수 있습니다.
-   **유연성**: 함수에 필요한 추가 인자(arguments)를 `.pipe()`를 통해 전달할 수 있습니다.

**`.pipe()`를 활용한 데이터 전처리 파이프라인 구축**

```python
# 예시 데이터
df_pipe = pd.DataFrame({
    'ID': [1, 2, 3, 4, 5],
    'Name': ['Alice', 'Bob', 'Charlie', 'David', 'Eve'],
    'Score1': [85, 90, np.nan, 75, 92],
    'Score2': [70, np.nan, 88, 95, 80],
    'City': ['Seoul', 'Busan', 'Seoul', 'Jeju', 'Busan']
})
print("원본 DataFrame:\n", df_pipe)

# 1. 재사용 가능한 전처리 함수들 정의
# 각 함수는 DataFrame을 첫 번째 인자로 받습니다.
def fill_missing_scores(df, fill_value=0):
    """점수 컬럼의 결측치를 채우는 함수"""
    print(f"\n-> 결측치 채우기 (값: {fill_value})")
    # 중요한 컬럼만 선택하여 처리
    score_cols = ['Score1', 'Score2']
    df[score_cols] = df[score_cols].fillna(fill_value)
    return df

def calculate_total_score(df):
    """총점을 계산하고 원본 점수 컬럼을 제거하는 함수"""
    print("-> 총점 계산 및 원본 점수 제거")
    df = df.assign(Total_Score = df['Score1'] + df['Score2'])
    return df.drop(columns=['Score1', 'Score2'])

def convert_city_to_onehot(df, column_name='City'):
    """도시 컬럼을 One-Hot Encoding하는 함수"""
    print(f"-> {column_name} 컬럼 One-Hot Encoding")
    # get_dummies는 원본 DataFrame을 복사하여 작업하므로, 원본을 변경하지 않음
    return pd.get_dummies(df, columns=[column_name], prefix=column_name)

# 2. .pipe()를 이용한 워크플로우 구축
# 각 단계가 명확한 함수 호출로 구성된 파이프라인
processed_df = (
    df_pipe.copy() # 원본 데이터 수정을 방지하기 위해 복사본 사용
    .pipe(fill_missing_scores, fill_value=50) # fill_value=50 인자 전달
    .pipe(calculate_total_score)
    .pipe(convert_city_to_onehot, column_name='City') # column_name='City' 인자 전달
)

print("\n최종 처리된 DataFrame:\n", processed_df)
```

이처럼 `.pipe()`를 활용하면 복잡한 데이터 전처리 과정을 **'어떤 함수를', '어떤 인자와 함께'** 적용하는지 명확하게 보여주는 파이프라인으로 만들 수 있습니다. 이는 코드를 처음 보는 사람도 데이터의 흐름을 쉽게 이해하게 하고, 각 기능별로 테스트 및 유지보수를 용이하게 만듭니다.
