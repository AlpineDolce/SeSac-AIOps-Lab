## 1. 고급 데이터 조작 및 분석

### 1.1. 피벗 테이블 (Pivot Table)

`pivot_table()`은 엑셀의 피벗 테이블처럼, 기존의 긴 형식(long format)의 데이터를 **재구조화하여 요약 정보를 한눈에 파악하기 좋은 넓은 형식(wide format)으로 변환**하는 매우 강력한 도구입니다. 특정 컬럼의 값들을 새로운 인덱스(행)나 컬럼(열)으로 보내고, 그 교차점에 데이터의 요약 통계량을 채워 넣는 방식으로 동작합니다.

**`groupby()`와의 관계**

`pivot_table`은 사실 `groupby` 연산을 더 사용하기 쉽고 직관적인 형태로 감싼(wrapper) 기능이라고 볼 수 있습니다. 예를 들어, `df.pivot_table(index='A', columns='B', values='C', aggfunc='sum')`은 `df.groupby(['A', 'B'])['C'].sum().unstack()`과 유사한 결과를 생성합니다. `pivot_table`은 이 과정을 더 간결한 코드로 처리할 수 있게 해줍니다.

---

**`pivot_table()`의 주요 파라미터와 활용 예시**

`pivot_table(data, values=None, index=None, columns=None, aggfunc='mean', fill_value=None, margins=False)`

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
df_sales = pd.DataFrame({
    'Date': ['2023-01-01', '2023-01-01', '2023-01-02', '2023-01-02', '2023-01-01', '2023-01-02'],
    'Region': ['East', 'West', 'East', 'West', 'East', 'West'],
    'Product': ['A', 'B', 'A', 'C', 'C', 'B'],
    'Sales': [100, 150, 200, 120, 180, 250],
    'Quantity': [10, 15, 20, 12, 18, 25]
})
print("원본 DataFrame:\n", df_sales)
```

**1. 기본 피벗 테이블: `index`, `columns`, `values`**

가장 기본적인 세 가지 요소입니다.
- `index`: 피벗 테이블의 **행**이 될 컬럼을 지정합니다.
- `columns`: 피벗 테이블의 **열**이 될 컬럼을 지정합니다.
- `values`: `index`와 `columns`의 교차점에 채워질 **집계 대상** 데이터 컬럼을 지정합니다.

```python
# 지역(Region)을 행으로, 제품(Product)을 열로, 판매량(Sales)을 값으로 하는 피벗 테이블
# 기본 집계 함수(aggfunc)는 'mean' (평균)입니다.
pivot_basic = df_sales.pivot_table(index='Region', columns='Product', values='Sales')
print("\n기본 피벗 테이블 (평균 판매량):\n", pivot_basic)
```
*결과에서 NaN은 해당 지역과 제품에 대한 판매 기록이 없음을 의미합니다.*

**2. 집계 함수 변경: `aggfunc`**

`aggfunc` 파라미터를 통해 다양한 집계 함수를 적용할 수 있습니다. `sum`, `count`, `max`, `median` 등 문자열로 전달하거나, `np.std`와 같이 함수 객체를 직접 전달할 수도 있습니다.

```python
# 집계 함수를 'sum'(합계)으로 변경
pivot_sum = df_sales.pivot_table(index='Region', columns='Product', values='Sales', aggfunc='sum')
print("\n집계 함수 변경 (판매량 합계):\n", pivot_sum)
```

**3. 결측치 채우기: `fill_value`**

피벗 테이블 생성 시 나타나는 `NaN` 값을 특정 값으로 대체하고 싶을 때 사용합니다.

```python
# NaN 값을 0으로 채우기
pivot_filled = df_sales.pivot_table(index='Region', columns='Product', values='Sales', 
                                  aggfunc='sum', fill_value=0)
print("\nNaN을 0으로 채운 피벗 테이블:\n", pivot_filled)
```

**4. 다중 인덱스 및 다중 집계**

`index`, `columns`, `values`, `aggfunc`에 리스트를 전달하여 더 복잡하고 다차원적인 요약 테이블을 만들 수 있습니다.

```python
# 행에는 ['Region', 'Date'], 값에는 ['Sales', 'Quantity'], 함수에는 {'Sales':'sum', 'Quantity':'mean'} 적용
pivot_multi = df_sales.pivot_table(
    index=['Region', 'Date'],
    columns='Product',
    values=['Sales', 'Quantity'],
    aggfunc={'Sales': 'sum', 'Quantity': 'mean'},
    fill_value=0
)
print("\n다중 인덱스 및 다중 집계 피벗 테이블:\n", pivot_multi)
```

**5. 총계 추가: `margins`**

`margins=True`로 설정하면 각 행과 열의 소계 및 총계를 자동으로 추가해 줍니다. 총계 컬럼/행의 이름은 `margins_name` 파라미터로 변경할 수 있습니다.

```python
# 각 행과 열의 총계(합계)를 추가
pivot_margins = df_sales.pivot_table(index='Region', columns='Product', values='Sales', 
                                    aggfunc='sum', fill_value=0, margins=True, margins_name='Total')
print("\n총계가 추가된 피벗 테이블:\n", pivot_margins)
```


### 1.2. 데이터 변형 (Melt)

`melt()` 함수는 `pivot_table`의 반대 작업, 즉 **언피벗(unpivot)**을 수행합니다. 여러 컬럼에 걸쳐 있는 값들을 두 개의 새로운 컬럼(변수 이름, 값)으로 모아, '넓은(wide)' 형식의 데이터를 '긴(long)' 형식으로 변환합니다. '긴' 형식 데이터는 시각화나 특정 분석 작업에 더 적합한 경우가 많습니다.

**넓은 형식 vs 긴 형식**

-   **넓은 형식 (Wide Format)**: 각 관측 단위(예: 학생)가 하나의 행을 차지하고, 각 변수(예: 과목)가 별도의 컬럼을 가집니다. 사람이 표를 읽기에는 편합니다.
-   **긴 형식 (Long/Tidy Format)**: 각 관측 단위의 각 변수가 하나의 행을 차지합니다. '변수'와 '값'을 나타내는 컬럼이 새로 생깁니다. 컴퓨터가 데이터를 처리하거나 시각화 라이브러리(Seaborn, Plotly 등)에서 사용하기에 용이합니다.

---
#### 1.2.1. `explode()`: 리스트 형태의 값 확장

`explode()` 메서드는 `DataFrame` 또는 `Series`의 컬럼에 리스트(list-like) 형태의 값(예: 리스트, 튜플, 집합)이 포함되어 있을 때, 각 리스트의 요소를 개별적인 행으로 확장하는 기능을 제공합니다. 이는 중첩된 데이터를 평탄화(flattening)하여 분석하기 용이한 형태로 만들 때 매우 유용합니다.

**주요 특징:**
*   **리스트 요소별 행 확장**: 리스트의 각 요소가 새로운 행이 되며, 원래 행의 다른 컬럼 값들은 그대로 복제됩니다.
*   **결측치 처리**: 리스트 내에 `None`이나 `NaN`이 있으면 해당 요소는 `NaN`으로 처리된 행으로 확장됩니다.
*   **인덱스 유지**: 원래 행의 인덱스는 유지됩니다.

**예시:**
```python
import pandas as pd

# 리스트 형태의 값을 포함하는 DataFrame
df_explode = pd.DataFrame({
    'ID': [1, 2, 3],
    'Keywords': [['apple', 'banana'], ['orange'], ['grape', 'kiwi', 'apple']],
    'Value': [100, 200, 300]
})
print("원본 DataFrame:\n", df_explode)

# 'Keywords' 컬럼을 explode
df_exploded = df_explode.explode('Keywords')
print("\n'Keywords' 컬럼 explode 후:\n", df_exploded)

# 여러 컬럼에 리스트가 있는 경우 (각각 explode 해야 함)
df_multi_list = pd.DataFrame({
    'ID': [1, 2],
    'Items': [['A', 'B'], ['C']],
    'Prices': [[10, 20], [30]]
})
# df_multi_list.explode(['Items', 'Prices']) # 오류 발생: explode는 한 번에 하나의 컬럼만 가능
# 해결책: 여러 번 explode 하거나, 데이터 구조를 변경
# df_exploded_items = df_multi_list.explode('Items')
# df_exploded_prices = df_multi_list.explode('Prices')
# print("\nItems explode 후:\n", df_exploded_items)
# print("\nPrices explode 후:\n", df_exploded_prices)
```

**실무 활용 시나리오:**
*   **태그/키워드 분석**: 하나의 문서나 상품에 여러 개의 태그나 키워드가 리스트 형태로 저장되어 있을 때, 각 태그를 개별 행으로 분리하여 태그별 빈도 분석이나 그룹화를 수행할 수 있습니다.
*   **다중 응답 설문**: 설문조사에서 응답자가 여러 항목을 선택한 경우, 이를 리스트로 저장한 후 `explode()`를 사용하여 각 응답 항목을 개별 행으로 분리하여 분석합니다.
*   **JSON/API 데이터 처리**: JSON이나 API 응답에서 중첩된 리스트 형태의 데이터가 있을 때, `json_normalize()`와 함께 `explode()`를 사용하여 데이터를 완전히 평탄화할 수 있습니다.

`explode()`는 데이터 전처리 과정에서 복잡한 중첩 구조를 가진 데이터를 평탄화하여 분석 및 시각화에 적합한 형태로 만드는 데 매우 유용한 도구입니다.

**`melt()`의 주요 파라미터와 활용 예시**

`pd.melt(frame, id_vars=None, value_vars=None, var_name=None, value_name='value')`

```python
# 예시 데이터프레임 (넓은 형식)
df_scores_wide = pd.DataFrame({
    'Student_ID': [1, 2, 3],
    'Class': ['A', 'B', 'A'],
    'Math': [90, 85, 78],
    'Science': [70, 95, 88],
    'English': [80, 75, 92]
})
print("원본 (넓은 형식) DataFrame:\n", df_scores_wide)
```

**1. 기본 `melt`: `id_vars`로 기준 컬럼 지정**

-   `id_vars`: 변환 과정에서 **형태를 그대로 유지할 기준 컬럼**을 지정합니다. 이 컬럼의 값들은 다른 컬럼들이 행으로 변환될 때 반복적으로 나타납니다.
-   `var_name`: 행으로 변환된 컬럼들의 **이름**이 담길 새로운 컬럼의 이름입니다.
-   `value_name`: 행으로 변환된 컬럼들의 **값**이 담길 새로운 컬럼의 이름입니다.

```python
# Student_ID와 Class를 기준으로, 나머지 과목 컬럼들을 행으로 변환
df_scores_long = df_scores_wide.melt(
    id_vars=['Student_ID', 'Class'], # 기준이 될 컬럼
    var_name='Subject',              # 과목명이 들어갈 새 컬럼 이름
    value_name='Score'               # 점수가 들어갈 새 컬럼 이름
)
print("\n변형된 (긴 형식) DataFrame:\n", df_scores_long)
```
*`Math`, `Science`, `English` 컬럼이 'Subject'와 'Score'라는 두 개의 새로운 컬럼으로 녹아내렸습니다.*

**2. 특정 컬럼만 변형하기: `value_vars`**

`id_vars`를 제외한 모든 컬럼이 아닌, 특정 컬럼들만 선택하여 행으로 변환하고 싶을 때 사용합니다.

```python
# 'Math'와 'Science' 점수만 행으로 변환
df_partial_melt = df_scores_wide.melt(
    id_vars=['Student_ID', 'Class'],
    value_vars=['Math', 'Science'], # 행으로 녹일 컬럼들을 직접 지정
    var_name='Subject',
    value_name='Score'
)
print("\n'Math', 'Science'만 녹인 DataFrame:\n", df_partial_melt)
```
*`English` 컬럼은 `value_vars`에 포함되지 않았으므로 결과에서 제외됩니다.*

**`melt`의 실용적 가치: 시각화**

`melt`는 특히 Seaborn과 같은 시각화 라이브러리와 함께 사용할 때 매우 유용합니다. 예를 들어, 과목별 점수 분포를 박스 플롯(box plot)으로 그리고 싶을 때, `melt`로 변환한 '긴' 형식 데이터는 `x`축에 과목, `y`축에 점수를 매핑하기 완벽한 구조를 제공합니다.

```python
import seaborn as sns
import matplotlib.pyplot as plt

# melt로 변환한 df_scores_long 데이터를 사용하여 시각화
plt.figure(figsize=(8, 5))
sns.boxplot(data=df_scores_long, x='Subject', y='Score', hue='Class')
plt.title('Scores by Subject and Class')
plt.show()
```
이처럼 `melt`는 데이터를 분석 및 시각화에 적합한 'Tidy Data' 형태로 변환하는 데 필수적인 함수입니다.


### 1.3. 시계열 데이터 처리 (Time Series)

Pandas는 금융, 경제, 과학 등 다양한 분야에서 발생하는 시간 순서에 따른 데이터, 즉 **시계열 데이터**를 다루는 데 매우 강력하고 특화된 기능을 제공합니다. 이 기능들의 핵심은 **`DatetimeIndex`** 와 시간 기반의 다양한 연산에 있습니다.

--- 
#### 1.3.1. 날짜/시간 데이터 타입 (`datetime`)

모든 시계열 분석의 첫걸음은 날짜/시간 정보를 나타내는 컬럼을 Pandas가 인식할 수 있는 `datetime` 타입으로 변환하는 것입니다. 이 변환을 통해 시간 기반의 모든 고급 기능을 사용할 수 있게 됩니다.

**A. `pd.to_datetime()`: 문자열을 `datetime`으로**
가장 기본적이고 중요한 함수입니다. 다양한 형태의 날짜/시간 문자열을 `datetime` 객체로 변환합니다.

```python
# 다양한 형식의 날짜 문자열
dates_str = ['2023-01-01', '2023/01/02', '03-Jan-2023', '2023.01.04 10:30:00']
# to_datetime이 대부분의 형식을 자동으로 인식하여 변환
datetime_obj = pd.to_datetime(dates_str)
print("문자열 -> datetime:\n", datetime_obj)
```

**B. `pd.date_range()`: `DatetimeIndex` 생성**
연속적인 날짜/시간 인덱스를 생성할 때 매우 유용합니다.

- `start`, `end`: 시작일, 종료일
- `periods`: 생성할 날짜/시간의 개수
- `freq`: 생성할 날짜/시간의 간격 (Frequence). `'D'`(일), `'B'`(업무일), `'H'`(시간), `'T'`(분), `'S'`(초), `'M'`(월말), `'MS'`(월초) 등 다양합니다.

```python
# 2023년 1월 1일부터 5일간의 업무일(Business day) 인덱스 생성
date_index = pd.date_range(start='2023-01-01', periods=5, freq='B')
print("\n업무일 기준 날짜 범위:\n", date_index)
```

**C. `.dt` 접근자: `datetime` 정보 추출**
`datetime` 타입의 `Series`는 `.dt` 접근자를 통해 연, 월, 일, 요일, 주차 등 세부 시간 정보를 손쉽게 추출하여 새로운 특성으로 활용할 수 있습니다.

```python
s = pd.Series(pd.to_datetime(['2023-07-15 14:30:00', '2023-07-16 09:00:00']))
df_time = pd.DataFrame({'timestamp': s})
df_time['year'] = s.dt.year
df_time['month_name'] = s.dt.month_name()
df_time['day_name'] = s.dt.day_name()
df_time['hour'] = s.dt.hour
df_time['weekofyear'] = s.dt.isocalendar().week # 연중 몇 번째 주
print("\ndatetime 구성 요소 추출:\n", df_time)
```

#### 1.3.2. 시계열 인덱싱 및 슬라이싱

`DataFrame`의 인덱스가 `DatetimeIndex`일 때, 시간 순서를 활용한 강력하고 직관적인 데이터 선택 및 필터링이 가능해집니다.

```python
# 시계열 데이터프레임 생성
dates = pd.date_range(start='2023-01-01', periods=60, freq='D') # 2달치 데이터
ts_df = pd.DataFrame(np.random.randint(10, 100, size=(60, 2)), index=dates, columns=['Value1', 'Value2'])
print("원본 시계열 DataFrame (일부):\n", ts_df.head())

# 부분 문자열로 슬라이싱
print("\n2023년 1월 데이터:\n", ts_df['2023-01'].head())

# 날짜 범위 슬라이싱
print("\n2023년 2월 10일부터 15일까지:\n", ts_df['2023-02-10':'2023-02-15'])

# 특정 시간대의 데이터만 선택 (at_time, between_time)
# (예시를 위해 시간 정보가 있는 데이터로 변경)
dates_h = pd.date_range(start='2023-01-01', periods=48, freq='H')
ts_df_h = pd.DataFrame({'value': np.random.randn(48)}, index=dates_h)
print("\n오전 9시 데이터만 선택:\n", ts_df_h.at_time('09:00'))
print("\n오전 9시~12시 데이터만 선택:\n", ts_df_h.between_time('09:00', '12:00').head())
```

#### 1.3.3. 리샘플링 (`resample`)

`resample()`은 시계열 데이터의 **시간 빈도(frequency)를 변환**하는 강력한 기능입니다. 이는 시계열 데이터에 대한 `groupby` 연산과 유사합니다.

- **다운샘플링 (Down-sampling)**: 시간 빈도를 낮추는 것 (예: 일별 → 주별/월별). 데이터가 축소되므로 집계(`sum`, `mean` 등)가 필요합니다.
- **업샘플링 (Up-sampling)**: 시간 빈도를 높이는 것 (예: 일별 → 시간별). 데이터가 확장되므로 새로 생긴 빈 공간을 채우는 방법(`ffill`, `bfill`, `interpolate` 등)이 필요합니다.

```python
# 다운샘플링: 일별 데이터를 주별(W) 데이터로 리샘플링
# 각 주의 평균값, 최대값, 합계를 계산
weekly_resample = ts_df['Value1'].resample('W').agg(['mean', 'max', 'sum'])
print("\n주별 다운샘플링 (평균, 최대, 합계):\n", weekly_resample.head())

# 업샘플링: 일별 데이터를 12시간(12H) 간격으로 리샘플링
# 새로 생긴 NaN 값은 ffill(forward-fill)로 채움: 바로 앞의 유효한 값으로 채움
upsampled_ffill = ts_df['Value1'].resample('12H').ffill()
print("\n12시간 업샘플링 (ffill):\n", upsampled_ffill.head())

# bfill(backward-fill): 바로 뒤의 유효한 값으로 채움
upsampled_bfill = ts_df['Value1'].resample('12H').bfill()
print("\n12시간 업샘플링 (bfill):\n", upsampled_bfill.head())
```

#### 1.3.5. 고급 시계열 기능 (Advanced Time Series Features)

Pandas는 시계열 데이터의 복잡한 측면을 다루기 위한 고급 기능을 제공합니다.

**1. 시간대(Time Zone) 처리**

시간대 정보는 전 세계적으로 분산된 데이터를 다룰 때 매우 중요합니다. Pandas는 `tz_localize()`와 `tz_convert()`를 통해 시간대 정보를 추가하고 변환할 수 있습니다.

*   **`tz_localize()`**: 시간대 정보가 없는(naive) `DatetimeIndex`에 시간대 정보를 추가합니다.
*   **`tz_convert()`**: 이미 시간대 정보가 있는 `DatetimeIndex`를 다른 시간대로 변환합니다.

```python
import pandas as pd

# 시간대 정보가 없는 DatetimeIndex 생성
dates_naive = pd.date_range('2023-01-01 09:00', periods=3, freq='H')
s_naive = pd.Series([10, 20, 30], index=dates_naive)
print("시간대 정보 없는 Series:\n", s_naive)

# 'Asia/Seoul' 시간대 정보 추가
s_localized = s_naive.tz_localize('Asia/Seoul')
print("\n'Asia/Seoul' 시간대 추가 후:\n", s_localized)

# 'UTC' 시간대로 변환
s_converted_utc = s_localized.tz_convert('UTC')
print("\n'UTC' 시간대로 변환 후:\n", s_converted_utc)

# 'America/New_York' 시간대로 변환
s_converted_ny = s_localized.tz_convert('America/New_York')
print("\n'America/New_York' 시간대로 변환 후:\n", s_converted_ny)
```

**2. 불규칙 빈도 데이터 처리 (`asfreq`)**

시계열 데이터는 종종 불규칙한 간격으로 수집되거나, 특정 기간의 데이터가 누락될 수 있습니다. `asfreq()` 메서드는 `DatetimeIndex`를 원하는 빈도로 재색인(reindex)하여, 누락된 기간을 채우거나 기존 빈도를 변경할 때 사용합니다.

*   **`asfreq(freq, method=None, fill_value=None)`**:
    *   `freq`: 재색인할 새로운 빈도 (예: `'D'`, `'H'`).
    *   `method`: 새로운 빈도에 맞춰 값이 없는 경우 채울 방법 (예: `'ffill'`, `'bfill'`, `'pad'`, `'backfill'`).
    *   `fill_value`: `method`가 지정되지 않았을 때 `NaN` 대신 채울 값.

```python
import pandas as pd
import numpy as np

# 불규칙한 빈도의 시계열 데이터 생성
dates_irregular = pd.to_datetime(['2023-01-01', '2023-01-03', '2023-01-07', '2023-01-08'])
s_irregular = pd.Series([10, 20, 30, 40], index=dates_irregular)
print("불규칙 빈도 Series:\n", s_irregular)

# 일별 빈도로 재색인하고, 누락된 값은 NaN으로 채움 (기본 동작)
s_daily = s_irregular.asfreq('D')
print("\n일별 빈도로 재색인 (NaN):\n", s_daily)

# 일별 빈도로 재색인하고, 누락된 값은 이전 값으로 채움 (ffill)
s_daily_ffill = s_irregular.asfreq('D', method='ffill')
print("\n일별 빈도로 재색인 (ffill):\n", s_daily_ffill)

# 일별 빈도로 재색인하고, 누락된 값은 0으로 채움
s_daily_fill0 = s_irregular.asfreq('D', fill_value=0)
print("\n일별 빈도로 재색인 (fill_value=0):\n", s_daily_fill0)
```
