Pandas `groupby()` 연산의 핵심인 `agg()`, `transform()`, `filter()` 메서드를 심도 있게 이해하고 활용하여, 단순 집계를 넘어선 복잡한 그룹별 데이터 변환 및 특성 공학(Feature Engineering)을 효율적으로 수행하는 실무 역량을 강화합니다.

### 1. `groupby()`의 기본 복습

`groupby()`는 DataFrame을 특정 컬럼(들)의 고유 값에 따라 여러 그룹으로 분할하는 연산입니다. 분할된 그룹에 대해 집계(Aggregation), 변환(Transformation), 필터링(Filtering) 등의 연산을 적용할 수 있습니다.

```python
import pandas as pd
import numpy as np

data = {
    '도시': ['서울', '서울', '부산', '부산', '서울', '부산'],
    '연도': [2020, 2021, 2020, 2021, 2022, 2022],
    '판매량': [100, 150, 80, 120, 130, 90],
    '비용': [50, 70, 40, 60, 65, 45]
}
df = pd.DataFrame(data)
print("Original DataFrame:\n", df)

# 도시별 판매량 평균
print("\n도시별 판매량 평균:\n", df.groupby('도시')['판매량'].mean())
# 도시
# 부산    96.666667
# 서울   126.666667
# Name: 판매량, dtype: float64
```

### 2. `agg()` (Aggregation) 메서드

`agg()` 메서드는 그룹별로 하나 이상의 집계 함수를 적용할 때 사용합니다. 각 그룹에 대해 단일 값을 반환합니다.

-   **단일 컬럼에 여러 함수 적용**:
    ```python
    # 도시별 판매량의 평균, 합계, 최대값, 최소값
    city_sales_agg = df.groupby('도시')['판매량'].agg(['mean', 'sum', 'max', 'min'])
    print("\n도시별 판매량 집계 (agg):\n", city_sales_agg)
    #           mean  sum  max  min
    # 도시
    # 부산  96.666667  290  120   80
    # 서울 126.666667  380  150  100
    ```

-   **여러 컬럼에 여러 함수 적용**:
    ```python
    # 도시별 판매량과 비용에 대해 각각 다른 함수 적용
    multi_col_agg = df.groupby('도시').agg({
        '판매량': ['mean', 'sum'],
        '비용': ['min', 'max']
    })
    print("\n여러 컬럼에 여러 함수 적용 (agg):\n", multi_col_agg)
    #        판매량        비용
    #           mean  sum  min  max
    # 도시
    # 부산  96.666667  290   40   60
    # 서울 126.666667  380   50   70
    ```

-   **컬럼명 변경 (Named Aggregation)**:
    ```python
    # 집계 결과 컬럼에 사용자 정의 이름 부여
    named_agg = df.groupby('도시').agg(
        평균_판매량=('판매량', 'mean'),
        총_비용=('비용', 'sum'),
        최대_판매량=('판매량', 'max')
    )
    print("\n컬럼명 변경 (Named Aggregation):\n", named_agg)
    #       평균_판매량  총_비용  최대_판매량
    # 도시
    # 부산  96.666667   145    120
    # 서울 126.666667   185    150
    ```

### 3. `transform()` 메서드

`transform()` 메서드는 그룹별 연산을 수행한 후, 그 결과를 **원본 DataFrame의 인덱스 및 형태에 맞춰 반환**합니다. 이는 그룹별 통계량을 원본 DataFrame의 새로운 컬럼으로 추가할 때 매우 유용합니다.

-   **그룹별 평균을 원본 DataFrame에 추가**:
    ```python
    # 도시별 판매량 평균을 각 행에 추가
    df['도시별_평균_판매량'] = df.groupby('도시')['판매량'].transform('mean')
    print("\nDataFrame에 그룹별 평균 추가 (transform):\n", df)
    #    도시  연도  판매량  비용  도시별_평균_판매량
    # 0  서울  2020  100  50   126.666667
    # 1  서울  2021  150  70   126.666667
    # 2  부산  2020   80  40    96.666667
    # 3  부산  2021  120  60    96.666667
    # 4  서울  2022  130  65   126.666667
    # 5  부산  2022   90  45    96.666667
    ```

-   **그룹별 정규화 (Normalization)**:
    ```python
    # 도시별 판매량을 해당 도시의 최대 판매량으로 나누어 정규화
    df['도시별_정규화_판매량'] = df.groupby('도시')['판매량'].transform(lambda x: x / x.max())
    print("\nDataFrame에 그룹별 정규화 판매량 추가 (transform):\n", df)
    #    도시  연도  판매량  비용  도시별_평균_판매량  도시별_정규화_판매량
    # 0  서울  2020  100  50   126.666667      0.666667
    # 1  서울  2021  150  70   126.666667      1.000000
    # 2  부산  2020   80  40    96.666667      0.666667
    # 3  부산  2021  120  60    96.666667      1.000000
    # 4  서울  2022  130  65   126.666667      0.866667
    # 5  부산  2022   90  45    96.666667      0.750000
    ```

### 4. `filter()` 메서드

`filter()` 메서드는 그룹별 조건을 만족하는 **그룹 전체**를 선택할 때 사용합니다. `filter()`에 전달되는 함수는 각 그룹(DataFrame)을 인수로 받아 불리언 값(True/False)을 반환해야 합니다. `True`를 반환하는 그룹만 유지됩니다.

```python
# 판매량 합계가 300 이상인 도시만 필터링
filtered_df = df.groupby('도시').filter(lambda x: x['판매량'].sum() >= 300)
print("\n판매량 합계 300 이상인 도시 필터링 (filter):\n", filtered_df)
#    도시  연도  판매량  비용  도시별_평균_판매량  도시별_정규화_판매량
# 0  서울  2020  100  50   126.666667      0.666667
# 1  서울  2021  150  70   126.666667      1.000000
# 4  서울  2022  130  65   126.666667      0.866667
```

-   **특정 조건 만족하는 그룹만 남기기**:
    ```python
    # 각 그룹의 판매량 데이터 개수가 3개 이상인 그룹만 필터링
    filtered_by_count = df.groupby('도시').filter(lambda x: len(x) >= 3)
    print("\n데이터 개수 3개 이상인 그룹 필터링 (filter):\n", filtered_by_count)
    #    도시  연도  판매량  비용  도시별_평균_판매량  도시별_정규화_판매량
    # 0  서울  2020  100  50   126.666667      0.666667
    # 1  서울  2021  150  70   126.666667      1.000000
    # 2  부산  2020   80  40    96.666667      0.666667
    # 3  부산  2021  120  60    96.666667      1.000000
    # 4  서울  2022  130  65   126.666667      0.866667
    # 5  부산  2022   90  45    96.666667      0.750000
    ```

### 5. 실무 활용 시나리오

-   **특성 공학 (Feature Engineering)**:
    -   `transform()`: 고객별 평균 구매액, 상품 카테고리별 평균 가격, 지역별 인구 대비 판매량 등 그룹별 통계량을 원본 데이터에 새로운 특성으로 추가.
    -   `agg()`: 고객별 총 구매 횟수, 첫 구매일, 마지막 구매일 등 고객의 행동 패턴을 요약하는 특성 생성.
-   **데이터 클리닝 및 이상치 탐지**:
    -   `filter()`: 특정 기준(예: 최소 데이터 개수, 특정 값의 범위)을 만족하지 않는 그룹을 제거하여 데이터 품질 향상.
    -   `transform()`: 그룹별 표준편차를 계산하여 그룹 내에서 크게 벗어나는 이상치(outlier)를 식별.
-   **그룹별 정규화/스케일링**: `transform()`을 사용하여 각 그룹 내에서 데이터를 독립적으로 정규화하거나 스케일링하여 그룹 간의 스케일 차이를 제거.

### 6. 요약 및 모범 사례

-   **`agg()`**: 그룹별로 **요약된 단일 값**을 얻을 때 사용합니다. 결과는 그룹화된 컬럼을 인덱스로 하는 새로운 DataFrame입니다.
-   **`transform()`**: 그룹별 연산 결과를 **원본 DataFrame의 형태와 인덱스에 맞춰** 반환하여 새로운 컬럼을 추가할 때 사용합니다.
-   **`filter()`**: 그룹별 조건을 만족하는 **그룹 전체**를 선택할 때 사용합니다.

이 세 가지 메서드는 `groupby()` 연산을 통해 데이터에 대한 깊이 있는 분석과 유연한 변환을 가능하게 합니다. 각 메서드의 반환 형태와 목적을 명확히 이해하고 적절히 활용하는 것이 Pandas를 이용한 고급 데이터 분석의 핵심입니다.
