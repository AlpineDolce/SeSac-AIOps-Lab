# 데이터 과학자를 위한 Pandas 실무 역량 강화 가이드

이 가이드는 데이터 분석 및 머신러닝 실무에 필수적인 Pandas 라이브러리의 핵심 개념부터 고급 활용법까지 체계적으로 학습할 수 있도록 구성되었습니다. 각 문서는 특정 주제를 심도 있게 다루며, 신입 데이터 과학자가 현업에 빠르게 적응하는 것을 목표로 합니다.

---

### Part 1: Pandas 소개 및 기본 개념 (Introduction & Basic Concepts)
 **학습 목표:** Pandas 라이브러리의 기본 개념을 이해하고, 데이터 분석 환경을 설정하며, Pandas의 주요 구성 요소를 파악합니다.
 **왜 중요한가?** Pandas는 파이썬에서 정형 데이터를 효율적으로 다루는 데 가장 널리 사용되는 라이브러리입니다. 그 역할과 기본 설정을 이해하는 것은 모든 데이터 분석 작업의 출발점입니다.
- [**01_Pandas_소개.md**](./01_Pandas_소개.md): Pandas의 정의, 데이터 분석에서의 역할, 주요 구성 요소를 이해합니다.

### Part 2: Pandas 핵심 데이터 구조 (Core Data Structures)
 **학습 목표:** Pandas의 핵심 데이터 구조인 Series와 DataFrame의 개념을 명확히 이해하고, 다양한 방법으로 생성하며, 기본적인 접근 및 조작 방법을 숙달합니다.
 **왜 중요한가?** Series와 DataFrame은 Pandas를 이용한 모든 데이터 처리의 기본 단위입니다. 이 구조들을 정확히 이해하고 다룰 수 있는 능력은 효율적인 데이터 분석의 기반이 됩니다.

- [**04_Panel_Deprecated.md**](./04_Panel_Deprecated.md): 과거 3차원 데이터 구조였던 Panel의 사용 중단 이유와 대안을 알아봅니다.

### Part 4: 외부 파일 입출력 (External File I/O)
 **학습 목표:** Pandas를 사용하여 CSV, Excel 등 다양한 형식의 외부 파일을 효율적으로 읽고 쓰는 방법을 숙달합니다. 또한, 대용량 데이터 처리를 위한 고성능 파일 포맷 처리 방법을 학습합니다.
 **왜 중요한가?** 데이터는 대부분 외부 파일 형태로 존재하며, 이를 Pandas DataFrame으로 불러오고 분석 결과를 다시 저장하는 능력은 데이터 분석 워크플로우의 시작과 끝을 담당하는 필수적인 기술입니다. 특히 대용량 데이터 환경에서는 효율적인 파일 입출력 전략이 중요합니다.
- [**16_외부_파일_처리_개요.md**](./16_외부_파일_처리_개요.md): Pandas가 지원하는 파일 형식, 외부 파일 처리의 중요성, 파일 경로 처리 방법을 알아봅니다.
- [**17_CSV_파일_처리.md**](./17_CSV_파일_처리.md): CSV 파일의 특징, `read_csv()`의 다양한 옵션, `to_csv()`를 이용한 저장 방법을 학습합니다.
- [**18_Excel_파일_처리.md**](./18_Excel_파일_처리.md): Excel 파일의 장점, `read_excel()`, `to_excel()`을 이용한 읽기/쓰기 방법을 익힙니다.
- [**19_SQL_데이터_처리.md**](./19_SQL_데이터_처리.md): SQL 데이터베이스에서 데이터를 읽고 쓰는 방법 (`read_sql`, `to_sql`).
- [**20_JSON_데이터_처리.md**](./20_JSON_데이터_처리.md): JSON 형식의 데이터를 Pandas DataFrame으로 변환하고 저장하는 방법.
- [**21_고성능_파일_포맷_처리.md**](./21_고성능_파일_포맷_처리.md): Parquet, Feather 등 대용량 데이터 처리에 효율적인 파일 포맷 처리.

- [**23_고급_그룹화_연산.md**](./23_고급_그룹화_연산.md): `agg()`, `transform()`, `filter()`를 활용한 고급 그룹 연산 및 특성 공학.
