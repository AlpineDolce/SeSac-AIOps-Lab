## 1. Pandas가 지원하는 외부 파일 형식

Pandas는 다양한 외부 파일 형식을 `DataFrame`으로 읽어오거나 `DataFrame`을 외부 파일로 저장하는 기능을 강력하게 지원합니다. 이는 데이터 분석 워크플로우에서 필수적인 요소입니다.

### 1.1. Pandas가 지원하는 파일 형식

Pandas는 데이터 과학에서 널리 사용되는 다양한 파일 형식에 대한 읽기(`read_xxx()`) 및 쓰기(`to_xxx()`) 함수를 제공합니다.

| 파일 형식 | 설명 | Pandas 함수 (읽기) | Pandas 함수 (쓰기) |
| :-------- | :---------------------------------------------------------------- | :----------------- | :----------------- |
| **CSV**   | 쉼표(Comma)로 구분된 값 (Comma-Separated Values)을 가진 텍스트 파일. 가장 널리 사용되는 데이터 교환 형식. | `pd.read_csv()`    | `df.to_csv()`      |
| **Excel** | Microsoft Excel 스프레드시트 파일 (.xlsx, .xls). 여러 시트 지원. | `pd.read_excel()`  | `df.to_excel()`    |
| **JSON**  | JavaScript Object Notation. 웹 기반 데이터 교환에 주로 사용.   | `pd.read_json()`   | `df.to_json()`     |
| **HTML**  | 웹 페이지의 테이블 데이터를 읽어올 때 사용.                      | `pd.read_html()`   | `df.to_html()`     |
| **SQL**   | 관계형 데이터베이스에서 데이터를 직접 읽어오거나 저장.           | `pd.read_sql()`    | `df.to_sql()`      |
| **XML**   | eXtensible Markup Language. 구조화된 데이터 표현.               | `pd.read_xml()`    | `df.to_xml()`      |
| **Parquet** | 컬럼 기반의 효율적인 이진 파일 형식. 빅데이터 환경에서 성능 우수. | `pd.read_parquet()`| `df.to_parquet()`  |
| **Pickle** | 파이썬 객체를 직렬화하여 저장하는 형식.                           | `pd.read_pickle()` | `df.to_pickle()`   |
| **Clipboard** | 클립보드에 있는 데이터를 읽거나 클립보드로 저장.                 | `pd.read_clipboard()` | `df.to_clipboard()` |
| **기타**  | TSV (Tab-Separated Values), 고정폭 파일 등 다양한 형식 지원.   | `pd.read_fwf()`, `pd.read_table()` | - |

**각 파일 형식별 간단한 예시:**

```python
import pandas as pd
import numpy as np
import os

# 예시 DataFrame 생성
df_example = pd.DataFrame({
    'col1': [1, 2, 3],
    'col2': ['A', 'B', 'C'],
    'col3': [1.1, 2.2, 3.3]
})

# 파일 저장 및 읽기 경로 설정 (현재 디렉토리에 'temp_data' 폴더 생성)
if not os.path.exists('temp_data'):
    os.makedirs('temp_data')
file_path_base = 'temp_data/example'

# CSV
df_example.to_csv(f'{file_path_base}.csv', index=False)
df_csv = pd.read_csv(f'{file_path_base}.csv')
print("--- CSV 파일 읽기 ---")
print(df_csv)

# Excel
df_example.to_excel(f'{file_path_base}.xlsx', index=False)
df_excel = pd.read_excel(f'{file_path_base}.xlsx')
print("\n--- Excel 파일 읽기 ---")
print(df_excel)

# JSON
df_example.to_json(f'{file_path_base}.json', orient='records', indent=4)
df_json = pd.read_json(f'{file_path_base}.json', orient='records')
print("\n--- JSON 파일 읽기 ---")
print(df_json)

# Parquet
df_example.to_parquet(f'{file_path_base}.parquet', index=False)
df_parquet = pd.read_parquet(f'{file_path_base}.parquet')
print("\n--- Parquet 파일 읽기 ---")
print(df_parquet)

# Pickle
df_example.to_pickle(f'{file_path_base}.pkl')
df_pickle = pd.read_pickle(f'{file_path_base}.pkl')
print("\n--- Pickle 파일 읽기 ---")
print(df_pickle)

# 클립보드 (실행 시 클립보드에 데이터가 복사됨)
```

## 2. 외부 파일 처리의 중요성 및 기본 원리

### 2.1. 외부 파일 처리의 중요성

데이터 분석 프로젝트에서는 대부분 외부에서 제공되는 데이터를 활용하게 됩니다. 이는 데이터베이스, 웹 스크래핑, API 연동, 또는 파일 형태로 제공될 수 있습니다.

1.  **데이터 활용**: 실제 데이터 분석 프로젝트에서는 대부분 외부에서 제공되는 데이터를 활용하게 됩니다.
2.  **효율적인 데이터 처리**: Pandas는 다양한 소스에서 수집된 데이터를 일관된 `DataFrame` 형태로 효율적으로 불러오고 처리할 수 있는 기능을 제공하여 데이터 전처리 과정을 간소화합니다.
3.  **분석 결과 공유**: 데이터 분석을 통해 얻은 인사이트나 가공된 데이터를 다른 시스템이나 사용자에게 전달하기 위해, 분석 결과를 다시 외부 파일(CSV, Excel 등)로 저장하는 기능이 필수적입니다.
