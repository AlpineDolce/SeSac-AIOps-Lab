## 1. 성능 최적화 팁

대규모 데이터를 다룰 때 Pandas의 성능을 최적화하는 것은 매우 중요합니다. 비효율적인 코드는 메모리 부족이나 긴 처리 시간으로 이어질 수 있습니다. 다음은 Pandas 성능을 향상시키는 주요 팁들입니다.

### 1.1. 벡터화된 연산 활용

Pandas와 NumPy는 C/Cython으로 구현된 벡터화된 연산을 제공합니다. 이는 파이썬 `for` 루프를 사용하는 것보다 훨씬 빠르고 효율적입니다. 가능한 한 `for` 루프 대신 Pandas의 내장 함수나 연산자를 사용해야 합니다.

```python
import pandas as pd
import numpy as np
import time

size = 10**6 # 100만 개의 데이터
df_perf = pd.DataFrame({
    'A': np.random.rand(size),
    'B': np.random.rand(size)
})

print(f"데이터 크기: {size} 행")

# 비효율적인 for 루프
start_time = time.time()
result_list = []
for i in range(len(df_perf)):
    result_list.append(df_perf['A'][i] + df_perf['B'][i])
end_time = time.time()
print(f"For 루프 시간: {end_time - start_time:.4f} 초")

# 벡터화된 Pandas 연산
start_time = time.time()
result_pandas = df_perf['A'] + df_perf['B']
end_time = time.time()
print(f"Pandas 벡터화 시간: {end_time - start_time:.4f} 초")

# 조건부 연산도 np.where로 벡터화 가능
start_time = time.time()
df_perf['C'] = np.where(df_perf['A'] > 0.5, df_perf['A'] * 2, df_perf['B'] * 3)
end_time = time.time()
print(f"np.where 벡터화 시간: {end_time - start_time:.4f} 초")
```
**결과 분석**: `for` 루프는 매우 느리지만, Pandas의 벡터화된 연산은 수백 배 이상 빠릅니다. 이는 Pandas가 내부적으로 최적화된 C 코드를 사용하기 때문입니다.

### 1.2. `apply()` 대신 벡터화된 함수 사용

`apply()` 메서드는 `DataFrame`의 행 또는 열에 파이썬 함수를 적용할 수 있어 매우 유연합니다. 하지만 내부적으로 반복문을 사용하기 때문에 대규모 데이터에서는 성능 저하가 심합니다. 가능한 경우, 동일한 로직을 NumPy나 Pandas의 내장 벡터화 함수로 구현하는 것이 훨씬 효율적입니다.

```python
# apply()를 사용한 비효율적인 연산
start_time = time.time()
df_perf['D_apply'] = df_perf.apply(lambda row: row['A'] * 2 + row['B'] * 3, axis=1)
end_time = time.time()
print(f"Apply() 연산 시간: {end_time - start_time:.4f} 초")

# 벡터화된 연산으로 대체
start_time = time.time()
df_perf['D_vectorized'] = df_perf['A'] * 2 + df_perf['B'] * 3
end_time = time.time()
print(f"벡터화된 연산 시간: {end_time - start_time:.4f} 초")

# 복잡한 조건부 로직 (apply vs np.where)
# apply 예시: A가 0.5보다 크면 A*2, 아니면 B*3
start_time = time.time()
df_perf['E_apply'] = df_perf.apply(lambda row: row['A'] * 2 if row['A'] > 0.5 else row['B'] * 3, axis=1)
end_time = time.time()
print(f"Apply() 조건부 연산 시간: {end_time - start_time:.4f} 초")

# np.where를 사용한 벡터화된 구현
start_time = time.time()
df_perf['E_vectorized'] = np.where(df_perf['A'] > 0.5, df_perf['A'] * 2, df_perf['B'] * 3)
end_time = time.time()
print(f"np.where 조건부 연산 시간: {end_time - start_time:.4f} 초")
```
**결과 분석**: `apply()`는 벡터화된 연산에 비해 현저히 느립니다. 복잡한 로직이라도 `np.where`나 마스킹(masking)을 통해 대부분 벡터화할 수 있습니다.

**`apply`가 불가피한 경우**: 로직이 너무 복잡하여 벡터화가 어렵다면 `apply`를 사용할 수 있지만, 성능 저하를 감수해야 합니다. 이 경우 `numba`나 `cython`과 같은 라이브러리를 사용하여 파이썬 함수의 실행 속도 자체를 높이는 방법을 고려할 수 있습니다.

### 1.3. 적절한 데이터 타입 (`dtype`) 사용

데이터 타입을 적절하게 사용하면 메모리 사용량을 크게 줄이고 연산 속도를 높일 수 있습니다. Pandas는 기본적으로 `int64`나 `float64`를 사용하지만, 실제 데이터 범위에 따라 더 작은 타입을 사용할 수 있습니다.

```python
# 예시 데이터프레임 생성
df_dtype = pd.DataFrame({
    'ID': np.arange(1000000),
    'Value': np.random.randint(0, 255, 1000000),
    'Price': np.random.rand(1000000) * 1000
})

print("--- 원본 DataFrame 메모리 사용량 ---")
print(df_dtype.info(memory_usage='deep'))

# 데이터 타입 변경
df_dtype['ID'] = df_dtype['ID'].astype('int32') # 20억까지 표현 가능
df_dtype['Value'] = df_dtype['Value'].astype('int8') # -128 ~ 127 표현 가능
df_dtype['Price'] = df_dtype['Price'].astype('float32') # float64의 절반 메모리

print("\n--- 타입 변경 후 DataFrame 메모리 사용량 ---")
print(df_dtype.info(memory_usage='deep'))

# pd.to_numeric(downcast='integer')를 이용한 자동 다운캐스팅
df_downcast = pd.DataFrame({'col': [1, 2, 3, 100000]})
df_downcast['col'] = pd.to_numeric(df_downcast['col'], downcast='integer')
print("\n자동 다운캐스팅 후 dtype:\n", df_downcast['col'].dtype)
```
**결과 분석**: `int64`와 `float64`를 `int8`, `int32`, `float32` 등으로 변경함으로써 메모리 사용량이 크게 줄어든 것을 확인할 수 있습니다.

### 1.4. `inplace=True` 사용 주의

`inplace=True` 옵션은 원본 `DataFrame`을 직접 수정하고 `None`을 반환합니다. 이는 메모리 복사를 피할 수 있다는 장점이 있지만, 다음과 같은 이유로 사용에 주의해야 합니다.

*   **메서드 체이닝 방해**: `None`을 반환하므로 다음 메서드를 `.메서드()` 형태로 바로 연결할 수 없습니다.
*   **예상치 못한 부작용**: 원본 데이터가 수정되므로, 다른 곳에서 원본 데이터를 참조하고 있다면 문제가 발생할 수 있습니다.
*   **디버깅 어려움**: 중간 단계의 `DataFrame`을 확인할 수 없어 디버깅이 복잡해질 수 있습니다.

일반적으로 새로운 `DataFrame`을 반환받는 것이 더 안전하고 가독성이 좋습니다.

```python
# 안전한 방식 (새로운 DataFrame 반환)
df_safe = df_perf.drop(columns=['A'])

# inplace=True 사용 (권장하지 않음)
# df_perf.drop(columns=['A'], inplace=True)
```

### 1.5. `read_csv` 옵션 활용

대규모 CSV 파일을 읽을 때 `pd.read_csv()`의 옵션을 적절히 활용하면 로딩 속도와 메모리 사용량을 최적화할 수 있습니다.

*   `dtype`: 컬럼별 데이터 타입을 미리 지정하여 Pandas의 타입 추론 시간을 줄이고 메모리를 절약합니다.
*   `usecols`: 필요한 컬럼만 불러와 메모리 사용량을 줄입니다.
*   `chunksize`: 파일을 작은 덩어리(chunk)로 나누어 읽어, 메모리에 한 번에 로드할 수 없는 대용량 파일을 처리할 때 유용합니다.

```python
import io

# 가상의 대용량 CSV 데이터 생성
csv_content = "col1,col2,col3,col4\n" + \
              "\n".join([f"{i},{i*1.1},{str(i%10)},{i*2}" for i in range(100000)])

# 옵션 없이 읽기 (메모리 비효율적일 수 있음)
# df_large = pd.read_csv(io.StringIO(csv_content))
# print("\n옵션 없이 읽은 DataFrame 정보:\n", df_large.info(memory_usage='deep'))

# dtype과 usecols 활용
start_time = time.time()
df_optimized_read = pd.read_csv(io.StringIO(csv_content),
                                dtype={'col1': 'int32', 'col2': 'float32', 'col3': 'category'},
                                usecols=['col1', 'col2', 'col3'])
end_time = time.time()
print(f"\ndtype, usecols 사용 읽기 시간: {end_time - start_time:.4f} 초")
print("최적화하여 읽은 DataFrame 정보:\n", df_optimized_read.info(memory_usage='deep'))
```

### 1.6. `Categorical` 타입 활용

고유한 값의 개수가 적은(low cardinality) 문자열 컬럼의 경우 `Categorical` 타입으로 변환하면 메모리 사용량을 크게 줄일 수 있습니다. Pandas는 문자열 대신 정수형 코드를 저장하고, 이 코드를 실제 문자열에 매핑하는 방식으로 작동합니다.

```python
# 예시 데이터프레임 (문자열 컬럼 포함)
df_category = pd.DataFrame({
    'Product_ID': np.arange(100000),
    'Category': np.random.choice(['Electronics', 'Clothing', 'Books', 'Home'], size=100000),
    'Region': np.random.choice(['East', 'West', 'North', 'South'], size=100000)
})

print("--- 원본 문자열 컬럼 메모리 사용량 ---")
print(df_category.info(memory_usage='deep'))

# Category와 Region 컬럼을 Categorical 타입으로 변환
df_category['Category'] = df_category['Category'].astype('category')
df_category['Region'] = df_category['Region'].astype('category')

print("\n--- Categorical 타입 변환 후 메모리 사용량 ---")
print(df_category.info(memory_usage='deep'))
```
**결과 분석**: `object` 타입이었던 문자열 컬럼이 `category` 타입으로 변환되면서 메모리 사용량이 크게 줄어든 것을 확인할 수 있습니다.

### 1.7. 대용량 데이터 처리를 위한 `query()`와 `eval()`

`query()`와 `eval()` 메서드는 Numexpr 라이브러리(또는 유사한 최적화된 백엔드)를 사용하여 대용량 `DataFrame`에서 필터링 및 연산을 더 빠르고 메모리 효율적으로 수행합니다. 일반적인 파이썬 연산이 중간에 임시 객체를 생성하여 메모리 오버헤드를 발생시키는 반면, 이들은 이를 최소화합니다.

*   `query()`: 문자열로 조건을 전달하여 행을 필터링합니다.
*   `eval()`: 문자열로 수식을 전달하여 새로운 컬럼을 생성하거나 기존 컬럼을 수정합니다.

```python
size_eval = 5 * 10**6 # 500만 개의 데이터
df_eval = pd.DataFrame({
    'A': np.random.rand(size_eval),
    'B': np.random.rand(size_eval),
    'C': np.random.rand(size_eval),
    'D': np.random.rand(size_eval)
})

print(f"\n데이터 크기 (query/eval): {size_eval} 행")

# query() vs 일반 불리언 인덱싱
start_time = time.time()
result_boolean = df_eval[df_eval['A'] > 0.5]
end_time = time.time()
print(f"불리언 인덱싱 시간: {end_time - start_time:.4f} 초")

start_time = time.time()
result_query = df_eval.query('A > 0.5')
end_time = time.time()
print(f"query() 시간: {end_time - start_time:.4f} 초")

# eval() vs 일반 연산
start_time = time.time()
df_eval['E_normal'] = df_eval['A'] * df_eval['B'] + df_eval['C'] / df_eval['D']
end_time = time.time()
print(f"일반 연산 시간: {end_time - start_time:.4f} 초")

start_time = time.time()
df_eval.eval('E_eval = A * B + C / D', inplace=True)
end_time = time.time()
print(f"eval() 시간: {end_time - start_time:.4f} 초")
```
**결과 분석**: 대용량 데이터에서는 `query()`와 `eval()`이 일반적인 파이썬 연산보다 훨씬 빠르고 메모리 효율적입니다.
