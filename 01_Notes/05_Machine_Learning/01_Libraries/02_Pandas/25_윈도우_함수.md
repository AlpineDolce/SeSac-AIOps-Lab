** Pandas의 `rolling()`, `expanding()`, `ewm()`과 같은 윈도우(Window) 함수를 사용하여 시계열 데이터 및 순차 데이터에 대한 이동 평균, 누적 합계, 지수 가중 평균 등 다양한 통계량을 효율적으로 계산하는 방법을 숙달합니다. 이를 통해 데이터의 추세 분석, 평활화(smoothing), 그리고 특정 기간 내의 패턴을 파악하는 실무 역량을 강화합니다.

<h2>목차</h2>

### 1. 윈도우 함수란?

윈도우 함수는 데이터의 특정 "윈도우"(즉, 고정되거나 확장되는 행의 집합) 내에서 연산을 수행하는 함수입니다. 주로 시계열 데이터에 적용되지만, 순서가 있는 모든 데이터에 적용할 수 있습니다.

-   **개념**: 데이터 포인트 주변의 일정 범위(윈도우)를 정의하고, 이 윈도우 내의 데이터에 대해 통계 연산(평균, 합계, 표준편차 등)을 적용합니다.
-   **활용**: 데이터 평활화, 추세 파악, 변동성 측정, 누적 값 계산 등에 사용됩니다.

### 2. `rolling()` (이동 윈도우 함수)

`rolling()`은 고정된 크기의 윈도우가 데이터를 따라 이동하면서 연산을 수행합니다.

-   **주요 파라미터**:
    -   `window`: 윈도우의 크기 (포함할 데이터 포인트의 개수).
    -   `min_periods`: 윈도우 내에서 유효한 데이터 포인트의 최소 개수. 이 개수 미만이면 `NaN`을 반환합니다.
    -   `center`: 윈도우를 현재 데이터 포인트의 중앙에 위치시킬지 여부 (`True` 또는 `False`, 기본값 `False`).
-   **일반적인 집계 함수**: `.mean()`, `.sum()`, `.std()`, `.min()`, `.max()`, `.count()`, `.median()`, `.apply()` 등.

```python
import pandas as pd
import numpy as np

# 예시 시계열 데이터
data = pd.Series(np.random.randint(1, 100, size=10),
                 index=pd.date_range('2023-01-01', periods=10, freq='D'))
print("Original Series:\n", data)

# 3일 이동 평균 계산
rolling_mean = data.rolling(window=3).mean()
print("\n3-day Rolling Mean:\n", rolling_mean)
# 2023-01-01     NaN  (데이터 3개 미만)
# 2023-01-02     NaN
# 2023-01-03    50.0 (첫 3개 데이터의 평균)
# ...

# min_periods 활용 (최소 2개 데이터가 있으면 계산)
rolling_mean_min2 = data.rolling(window=3, min_periods=2).mean()
print("\n3-day Rolling Mean (min_periods=2):\n", rolling_mean_min2)
# 2023-01-01     NaN
# 2023-01-02    45.0 (첫 2개 데이터의 평균)
# 2023-01-03    50.0
# ...

# 3일 이동 합계
rolling_sum = data.rolling(window=3).sum()
print("\n3-day Rolling Sum:\n", rolling_sum)
```

### 3. `expanding()` (확장 윈도우 함수)

`expanding()`은 윈도우가 데이터의 시작점부터 현재 데이터 포인트까지 계속 확장됩니다. 즉, 윈도우의 크기가 고정되지 않고 데이터가 추가될수록 커집니다.

-   **주요 파라미터**: `min_periods` (윈도우 내에서 유효한 데이터 포인트의 최소 개수).
-   **일반적인 집계 함수**: `.mean()`, `.sum()`, `.std()`, `.min()`, `.max()`, `.count()`, `.median()`, `.apply()` 등.

```python
# 누적 합계 계산
expanding_sum = data.expanding().sum()
print("\nExpanding Sum (Cumulative Sum):\n", expanding_sum)
# 2023-01-01     5.0
# 2023-01-02    95.0
# 2023-01-03   145.0
# ...

# 누적 평균 계산
expanding_mean = data.expanding(min_periods=1).mean()
print("\nExpanding Mean (Cumulative Mean):\n", expanding_mean)
# 2023-01-01     5.0
# 2023-01-02    47.5
# 2023-01-03    48.333333
# ...
```

### 4. `ewm()` (지수 가중 이동 윈도우 함수)

`ewm()`은 지수 가중 이동(Exponentially Weighted Moving) 함수를 계산합니다. 최근 데이터 포인트에 더 큰 가중치를 부여하여 과거 데이터의 영향력을 점진적으로 감소시킵니다. 이는 데이터의 최신 추세를 더 잘 반영합니다.

-   **주요 파라미터**:
    -   `span`: 스팬(span)은 가중치 감소율을 결정하는 데 사용되는 기간입니다. (일반적으로 `span = 2 / (alpha - 1)` 관계)
    -   `halflife`: 반감기(halflife)는 가중치가 절반으로 줄어드는 데 필요한 기간입니다.
    -   `com`: 중심(center of mass)은 가중치 감소율을 직접 지정하는 파라미터입니다.
    -   이들 중 하나만 지정하면 됩니다.
-   **일반적인 집계 함수**: `.mean()`, `.std()`, `.var()`.

```python
# 지수 가중 이동 평균 (span=3)
ewm_mean = data.ewm(span=3).mean()
print("\nExponentially Weighted Moving Mean (span=3):\n", ewm_mean)
# 2023-01-01     5.000000
# 2023-01-02    65.000000
# 2023-01-03    60.000000
# ...
```

### 5. 실무 활용 시나리오

-   **금융 분석**:
    -   주식 가격의 이동 평균 계산 (`rolling().mean()`)으로 추세 파악.
    -   변동성 측정 (`rolling().std()`).
    -   지수 이동 평균 (`ewm().mean()`)으로 최신 가격 변동에 더 민감한 추세선 생성.
-   **센서 데이터 처리**:
    -   노이즈가 많은 센서 데이터를 평활화하여 안정적인 신호 추출 (`rolling().mean()`).
    -   누적 에너지 소비량 계산 (`expanding().sum()`).
-   **판매 및 수요 예측**:
    -   주간/월간 이동 판매량 계산으로 계절성 및 추세 분석.
    -   누적 판매량으로 총 실적 추적.
-   **품질 관리**:
    -   생산 라인의 불량률 이동 평균을 계산하여 공정 이상 감지.

### 6. 요약 및 모범 사례

-   **`rolling()`**: 고정된 기간 내의 단기적인 추세나 변동성을 분석할 때 사용합니다. (예: 7일 이동 평균)
-   **`expanding()`**: 데이터의 시작부터 현재까지의 누적된 통계량을 분석할 때 사용합니다. (예: 누적 수익률)
-   **`ewm()`**: 최근 데이터에 더 큰 가중치를 부여하여 최신 변화에 더 민감한 추세를 파악할 때 사용합니다.

윈도우 함수는 시계열 데이터의 특성을 이해하고, 효과적인 전처리 및 분석을 수행하는 데 필수적인 도구입니다. 각 함수의 특성을 이해하고 데이터의 목적에 맞게 적절히 활용하는 것이 중요합니다.
