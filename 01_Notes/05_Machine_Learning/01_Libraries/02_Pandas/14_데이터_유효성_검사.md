## 1. 데이터 유효성 검사 개요

데이터 유효성 검사(Data Validation) 및 정제(Data Cleaning)는 데이터 분석 및 머신러닝 프로젝트에서 가장 중요하고 시간이 많이 소요되는 단계 중 하나입니다. "Garbage In, Garbage Out"이라는 말처럼, 아무리 정교한 모델이나 분석 기법을 사용하더라도 입력 데이터의 품질이 낮으면 신뢰할 수 있는 결과를 얻기 어렵습니다.

### 1.1. 데이터 품질의 중요성

- **정확성 (Accuracy)**: 데이터가 실제 값을 얼마나 정확하게 반영하는가?
- **완전성 (Completeness)**: 필요한 모든 데이터가 누락 없이 존재하는가? (결측치 처리와 관련)
- **일관성 (Consistency)**: 데이터가 여러 소스나 시간에 걸쳐 동일한 형식과 의미를 유지하는가?
- **유효성 (Validity)**: 데이터가 정의된 규칙, 범위, 형식에 부합하는가?
- **적시성 (Timeliness)**: 데이터가 분석 시점에 최신 상태를 유지하는가?

이 문서에서는 특히 정확성, 일관성, 유효성에 초점을 맞춰 데이터 불일치, 이상치, 데이터 타입 문제, 중복 데이터 처리 기법을 다룹니다.

### 1.2. 데이터 정제 과정의 일반적인 단계

데이터 정제는 일반적으로 다음과 같은 단계를 포함합니다.

1.  **데이터 로드 및 초기 탐색**: `df.info()`, `df.describe()`, `df.head()` 등을 통해 데이터의 전반적인 구조와 특성을 파악합니다.
2.  **결측치 처리**: 누락된 데이터는 [**13_결측치_처리.md**](./13_결측치_처리.md)에서 상세히 다룹니다.
3.  **데이터 타입 검사 및 변환**: 각 컬럼의 데이터 타입이 올바른지 확인하고 필요에 따라 변환합니다. (`astype()`, `to_numeric()`, `to_datetime()` 등)
4.  **데이터 불일치 및 비일관성 처리**: 오타, 다른 표기법, 대소문자 문제 등을 통일합니다.
5.  **이상치 탐지 및 처리**: 데이터 분포에서 벗어나는 극단적인 값들을 식별하고 처리합니다.
6.  **중복 데이터 처리**: 중복된 행을 식별하고 제거하는 방법은 [**14_중복_데이터_처리.md**](./14_중복_데이터_처리.md)에서 상세히 다룹니다.
7.  **데이터 유효성 규칙 적용**: 비즈니스 로직이나 도메인 지식에 기반한 특정 규칙(예: 나이는 0보다 커야 함, 점수는 0-100 사이여야 함)을 적용하여 유효하지 않은 데이터를 식별하고 처리합니다.

이러한 과정을 통해 데이터의 신뢰성을 높이고, 후속 분석 및 모델링 단계에서 발생할 수 있는 오류를 최소화할 수 있습니다.

## 2. 데이터 불일치 처리

데이터 불일치(Data Inconsistency)는 동일한 의미를 가지는 데이터가 다양한 형태로 표현되거나, 오타, 대소문자 차이 등으로 인해 발생하는 문제입니다. 이는 데이터 분석의 정확성을 저해하고, 그룹화나 필터링 시 예상치 못한 결과를 초래할 수 있습니다. Pandas를 사용하여 이러한 불일치를 효과적으로 처리하는 방법을 살펴보겠습니다.

### 2.1. 대소문자 및 공백 통일

문자열 데이터에서 가장 흔한 불일치 중 하나는 대소문자 차이와 불필요한 공백입니다. `.str` 접근자를 사용하여 문자열 메서드를 적용할 수 있습니다.

```python
import pandas as pd

df = pd.DataFrame({
    'City': ['Seoul ', ' seoul', 'Busan', 'BUSAN', 'Jeju', 'jeju'],
    'Value': [10, 20, 30, 40, 50, 60]
})
print("원본 DataFrame:")
print(df)

# 1. 공백 제거 (앞뒤 공백)
df['City'] = df['City'].str.strip()
print("\n공백 제거 후:")
print(df)

# 2. 대소문자 통일 (모두 소문자로)
df['City'] = df['City'].str.lower()
print("\n모두 소문자로 통일 후:")
print(df)

# 3. 결과 확인 (고유값)
print("\n최종 고유 도시명:")
print(df['City'].unique())
```

**설명:**
- `str.strip()`: 문자열의 양 끝에 있는 공백을 제거합니다.
- `str.lower()`: 모든 문자를 소문자로 변환합니다. `str.upper()`는 대문자로 변환합니다.
- `str.capitalize()`: 첫 글자만 대문자로, 나머지는 소문자로 변환합니다.

### 2.2. 오타 및 대체어 처리

데이터 입력 시 발생할 수 있는 오타나, 동일한 의미를 가지지만 다르게 표현된 대체어(예: '남', '남자', 'M')를 통일하는 작업입니다. `replace()` 메서드나 `map()`/`apply()` 함수를 사용할 수 있습니다.

```python
df = pd.DataFrame({
    'Gender': ['남', '남자', '여', '여자', 'M', 'F', '남성'],
    'Age': [25, 30, 22, 28, 35, 29, 40]
})
print("원본 DataFrame:")
print(df)

# 1. replace() 메서드를 이용한 대체
# 단일 값 대체
df['Gender'] = df['Gender'].replace('남', '남자')
print("\n'남'을 '남자'로 대체 후:")
print(df)

# 여러 값 동시 대체 (딕셔너리 사용)
replace_map = {'남자': 'Male', '여자': 'Female', 'M': 'Male', 'F': 'Female', '남성': 'Male'}
df['Gender'] = df['Gender'].replace(replace_map)
print("\n여러 값 동시 대체 후:")
print(df)

print("\n최종 고유 성별:")
print(df['Gender'].unique())
```

**설명:**
- `Series.replace(to_replace, value)`: `to_replace`에 해당하는 값을 `value`로 대체합니다. `to_replace`에 리스트나 딕셔너리를 전달하여 여러 값을 동시에 대체할 수 있습니다.
- `Series.str.replace(pattern, repl, regex=True)`: 문자열 내의 특정 패턴을 다른 문자열로 대체합니다. `regex=True`로 설정하면 정규표현식을 사용할 수 있어 더욱 유연한 대체가 가능합니다.

### 2.3. 범주형 데이터 통일

범주형 데이터의 경우, 예상 범주 외의 값이 포함되어 있거나, 범주 간의 의미적 불일치가 있을 수 있습니다. 이를 표준화된 범주로 통일하는 것이 중요합니다.

```python
df = pd.DataFrame({
    'Rating': ['Excellent', 'Good', 'Average', 'Poor', 'Excllent', 'good', 'Avg'],
    'Score': [5, 4, 3, 2, 5, 4, 3]
})
print("원본 DataFrame:")
print(df)

# Rating 컬럼의 고유값 확인
print("\n초기 Rating 고유값:")
print(df['Rating'].unique())

# 매핑 딕셔너리 생성
rating_map = {
    'Excellent': 'Excellent',
    'Excllent': 'Excellent', # 오타 수정
    'Good': 'Good',
    'good': 'Good',     # 대소문자 통일
    'Average': 'Average',
    'Avg': 'Average',     # 약어 통일
    'Poor': 'Poor'
}

# map() 함수를 사용하여 범주 통일
df['Rating'] = df['Rating'].map(rating_map)
print("\nmap() 적용 후 DataFrame:")
print(df)

print("\n최종 Rating 고유값:")
print(df['Rating'].unique())
```

**설명:**
- `Series.map(mapping_dict)`: Series의 각 값을 `mapping_dict`에 따라 변환합니다. `mapping_dict`에 없는 값은 `NaN`으로 처리되므로 주의해야 합니다. 모든 가능한 불일치 값을 매핑 딕셔너리에 포함하는 것이 중요합니다.

### 2.4. 정규표현식을 이용한 복잡한 불일치 처리

`str.contains()`, `str.extract()`, `str.replace()` 등과 정규표현식을 결합하면 복잡한 패턴의 불일치를 처리할 수 있습니다.

```python
df = pd.DataFrame({
    'Product_ID': [
        'PROD-1234',
        'prod_5678',
        'ITEM-9012',
        'item_3456',
        'PROD-A1B2',
        'UNKNOWN'
    ]
})
print("원본 DataFrame:")
print(df)

# 'PROD' 또는 'prod'로 시작하는 ID를 'Product'로 통일
df['Product_ID'] = df['Product_ID'].str.replace(r'(?i)prod[_-]', 'Product-', regex=True)
print("\n'PROD'/ 'prod' 통일 후:")
print(df)

# 'ITEM' 또는 'item'으로 시작하는 ID를 'Item'으로 통일
df['Product_ID'] = df['Product_ID'].str.replace(r'(?i)item[_-]', 'Item-', regex=True)
print("\n'ITEM'/ 'item' 통일 후:")
print(df)

# ID에서 숫자 부분만 추출
df['Numeric_ID'] = df['Product_ID'].str.extract(r'(\d+)')
print("\n숫자 ID 추출 후:")
print(df)
```

**설명:**
- `(?i)`: 정규표현식 내에서 대소문자를 무시하도록 합니다.
- `[_-]`: 하이픈(-) 또는 언더스코어(_) 중 하나를 의미합니다.
- `str.extract(pattern)`: 정규표현식 패턴에 맞는 그룹을 추출하여 새로운 DataFrame을 반환합니다.

데이터 불일치 처리는 데이터의 일관성을 확보하고 분석의 신뢰도를 높이는 데 필수적인 과정입니다. 다음 섹션에서는 데이터 분포에서 벗어나는 이상치(Outlier)를 탐지하고 처리하는 방법에 대해 알아보겠습니다.

## 3. 이상치(Outlier) 탐지 및 처리

이상치(Outlier)는 대부분의 데이터와는 동떨어져 있는 극단적인 값을 의미합니다. 이상치는 데이터 입력 오류, 측정 오류, 또는 실제 현상의 특이한 경우(예: 매우 높은 소득을 가진 사람) 등 다양한 원인으로 발생할 수 있습니다. 이상치는 통계 분석이나 머신러닝 모델의 성능에 큰 영향을 미칠 수 있으므로, 적절하게 탐지하고 처리하는 것이 중요합니다.

### 3.1. 이상치 탐지 방법

이상치를 탐지하는 방법은 여러 가지가 있으며, 데이터의 분포 특성과 도메인 지식에 따라 적절한 방법을 선택해야 합니다.

#### 3.1.1. 통계적 방법: Z-score

Z-score는 데이터 포인트가 평균으로부터 얼마나 떨어져 있는지를 표준편차 단위로 나타내는 값입니다. 일반적으로 Z-score의 절댓값이 특정 임계값(예: 2, 3)을 초과하면 이상치로 간주합니다.

```python
import pandas as pd
import numpy as np
from scipy.stats import zscore

df = pd.DataFrame({
    'Value': [10, 12, 15, 13, 11, 100, 14, 16, 18, 10]
})
print("원본 DataFrame:")
print(df)

# Z-score 계산
df['Z_score'] = np.abs(zscore(df['Value']))
print("\nZ-score 계산 결과:")
print(df)

# 임계값 설정 (예: Z-score > 2)
outliers_zscore = df[df['Z_score'] > 2]
print("\nZ-score를 이용한 이상치 탐지 (임계값 2):")
print(outliers_zscore)
```

**설명:**
- Z-score는 데이터가 정규 분포를 따른다고 가정할 때 효과적입니다. 데이터가 정규 분포를 따르지 않는 경우, Z-score는 이상치를 정확하게 식별하지 못할 수 있습니다.

#### 3.1.2. 통계적 방법: IQR (Interquartile Range)

IQR은 데이터의 25번째 백분위수(Q1)와 75번째 백분위수(Q3) 사이의 범위입니다. IQR을 이용한 이상치 탐지는 데이터의 분포가 비대칭이거나 정규 분포를 따르지 않을 때 더 강건합니다.

- **하한 (Lower Bound)**: Q1 - 1.5 * IQR
- **상한 (Upper Bound)**: Q3 + 1.5 * IQR

이 범위를 벗어나는 데이터는 이상치로 간주합니다.

```python
# IQR 계산 및 이상치 탐지
Q1 = df['Value'].quantile(0.25)
Q3 = df['Value'].quantile(0.75)
IQR = Q3 - Q1

lower_bound = Q1 - 1.5 * IQR
upper_bound = Q3 + 1.5 * IQR

outliers_iqr = df[(df['Value'] < lower_bound) | (df['Value'] > upper_bound)]
print(f"\nQ1: {Q1}, Q3: {Q3}, IQR: {IQR}")
print(f"Lower Bound: {lower_bound}, Upper Bound: {upper_bound}")
print("IQR을 이용한 이상치 탐지:")
print(outliers_iqr)
```

**설명:**
- IQR 방법은 중앙값(Median)을 기반으로 하므로, 극단적인 값에 덜 민감합니다.
- 1.5라는 계수는 일반적인 기준이며, 도메인 지식에 따라 조절할 수 있습니다.

#### 3.1.3. 시각화 방법

Box plot, Histogram, Scatter plot 등 시각화 도구를 사용하여 데이터 분포를 확인하고 이상치를 직관적으로 탐지할 수 있습니다.

```python
import matplotlib.pyplot as plt
import seaborn as sns

# Box plot
plt.figure(figsize=(6, 4))
sns.boxplot(y=df['Value'])
plt.title('Box Plot of Value')
plt.ylabel('Value')
plt.show()

# Histogram
plt.figure(figsize=(6, 4))
sns.histplot(df['Value'], kde=True)
plt.title('Histogram of Value')
plt.xlabel('Value')
plt.ylabel('Frequency')
plt.show()
```

**설명:**
- Box plot은 IQR 기반의 이상치를 시각적으로 잘 보여줍니다. 상자 바깥의 점들이 이상치 후보입니다.
- Histogram은 데이터의 분포 형태를 보여주며, 극단적인 값의 존재 여부를 파악하는 데 도움을 줍니다.

### 3.2. 이상치 처리 방법

이상치를 탐지한 후에는 이를 어떻게 처리할지 결정해야 합니다. 처리 방법은 이상치의 원인, 데이터의 특성, 분석 목표에 따라 달라집니다.

#### 3.2.1. 이상치 제거 (Removal)

이상치가 데이터 입력 오류나 측정 오류로 명확하게 판단되고, 그 수가 적을 경우 해당 이상치를 포함하는 행을 제거할 수 있습니다.

```python
# Z-score를 이용해 탐지된 이상치 제거
df_cleaned_zscore = df[df['Z_score'] <= 2].drop(columns='Z_score')
print("\nZ-score 이상치 제거 후 DataFrame:")
print(df_cleaned_zscore)

# IQR을 이용해 탐지된 이상치 제거
df_cleaned_iqr = df[(df['Value'] >= lower_bound) & (df['Value'] <= upper_bound)]
print("\nIQR 이상치 제거 후 DataFrame:")
print(df_cleaned_iqr)
```

**주의:** 이상치 제거는 데이터 손실을 야기하므로 신중하게 결정해야 합니다. 특히 이상치가 중요한 정보를 담고 있을 수도 있습니다.

#### 3.2.2. 이상치 대체 (Imputation/Capping)

이상치를 제거하는 대신, 다른 값으로 대체하는 방법입니다. 이는 데이터 손실을 방지하면서 이상치의 영향을 줄일 수 있습니다.

- **평균/중앙값/최빈값으로 대체**: 이상치를 해당 컬럼의 평균, 중앙값, 또는 최빈값으로 대체합니다.
- **상한/하한 값으로 대체 (Capping/Winsorization)**: 이상치를 IQR 방법으로 계산된 상한 또는 하한 값으로 대체합니다.

```python
# 이상치 대체 (Capping)
df_capped = df.copy()
df_capped['Value'] = np.where(df_capped['Value'] > upper_bound, upper_bound, df_capped['Value'])
df_capped['Value'] = np.where(df_capped['Value'] < lower_bound, lower_bound, df_capped['Value'])
print("\n이상치를 상한/하한 값으로 대체 (Capping) 후 DataFrame:")
print(df_capped)

# 이상치를 중앙값으로 대체
median_value = df['Value'].median()
outlier_indices = df[(df['Value'] < lower_bound) | (df['Value'] > upper_bound)].index
df_median_imputed = df.copy()
df_median_imputed.loc[outlier_indices, 'Value'] = median_value
print("\n이상치를 중앙값으로 대체 후 DataFrame:")
print(df_median_imputed)
```

**설명:**
- `np.where(condition, value_if_true, value_if_false)`: 조건에 따라 값을 선택적으로 할당할 때 유용합니다。

#### 3.2.3. 변환 (Transformation)

데이터에 로그 변환(log transformation)이나 제곱근 변환(square root transformation) 등을 적용하여 데이터의 분포를 정규 분포에 가깝게 만들거나, 이상치의 영향을 줄일 수 있습니다. 이는 이상치 자체를 제거하거나 대체하지 않고, 데이터의 스케일을 변경하여 모델에 미치는 영향을 완화합니다.

```python
# 로그 변환 (0이나 음수가 없는 경우)
df_log_transformed = df.copy()
df_log_transformed['Value_log'] = np.log(df_log_transformed['Value'])
print("\n로그 변환 후 DataFrame:")
print(df_log_transformed)

# 로그 변환 후 Box plot
plt.figure(figsize=(6, 4))
sns.boxplot(y=df_log_transformed['Value_log'])
plt.title('Box Plot of Log Transformed Value')
plt.ylabel('Value (Log Transformed)')
plt.show()
```

**설명:**
- 로그 변환은 특히 오른쪽으로 긴 꼬리를 가진(right-skewed) 분포의 이상치를 완화하는 데 효과적입니다.

이상치 처리는 데이터 분석의 목적과 이상치의 특성을 고려하여 신중하게 접근해야 합니다. 다음 섹션에서는 데이터 타입 강제 변환 및 오류 처리 방법에 대해 알아보겠습니다.

## 4. 데이터 타입 강제 변환 및 오류 처리

데이터를 불러오거나 처리하는 과정에서 컬럼의 데이터 타입이 예상과 다르게 지정되거나, 숫자형이어야 할 컬럼에 문자열이 섞여 있는 등의 문제가 발생할 수 있습니다. Pandas는 이러한 데이터 타입 문제를 해결하고, 필요한 타입으로 강제 변환하며, 변환 중 발생하는 오류를 처리하는 다양한 기능을 제공합니다.

### 4.1. 데이터 타입 확인

가장 먼저 각 컬럼의 데이터 타입을 확인하여 문제가 있는 부분을 식별합니다.

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    'ID': [1, 2, 3, 4, 5],
    'Amount': ['100', '200', '300', '400', '500'],
    'Price': [10.5, 20.3, '30.0', 40.1, 50.9],
    'Date': ['2023-01-01', '2023-01-02', '2023-01-03', 'invalid_date', '2023-01-05'],
    'Category': ['A', 'B', 'A', 'C', 'B']
})
print("원본 DataFrame:")
print(df)

print("\n초기 데이터 타입:")
print(df.dtypes)
```

**설명:**
- `df.dtypes`: DataFrame의 각 컬럼에 대한 데이터 타입을 Series 형태로 반환합니다.

### 4.2. `astype()`을 이용한 타입 변환

`astype()` 메서드는 가장 기본적인 타입 변환 방법입니다. 변환하려는 컬럼의 모든 값이 해당 타입으로 변환 가능할 때 사용합니다.

```python
# 'ID' 컬럼을 int64로 변환 (이미 int64이지만 예시)
df['ID'] = df['ID'].astype(np.int64)

# 'Amount' 컬럼을 int로 변환
df['Amount'] = df['Amount'].astype(int)

print("\nastype() 변환 후 데이터 타입:")
print(df.dtypes)
print("\nastype() 변환 후 DataFrame (Amount 컬럼):")
print(df)
```

**주의:** `astype()`는 변환할 수 없는 값이 있을 경우 오류를 발생시킵니다.

### 4.3. `pd.to_numeric()`을 이용한 숫자형 변환 및 오류 처리

`pd.to_numeric()` 함수는 문자열을 숫자형으로 변환할 때 매우 유용하며, 변환 불가능한 값이 있을 경우 오류를 처리하는 옵션을 제공합니다.

```python
df_error = pd.DataFrame({
    'Value': ['10', '20', 'invalid', '30', '40']
})
print("\n오류 포함 DataFrame:")
print(df_error)

# 1. errors='coerce': 변환 불가능한 값을 NaN으로 대체
df_error['Value_numeric_coerce'] = pd.to_numeric(df_error['Value'], errors='coerce')
print("\nerrors='coerce' 적용 후:")
print(df_error)
print(df_error.dtypes)

# 2. errors='ignore': 변환 불가능한 값이 있으면 원본 Series 반환 (타입 변환 안됨)
# 이 경우, 'invalid' 때문에 전체 컬럼이 object 타입으로 유지됩니다.
df_error['Value_numeric_ignore'] = pd.to_numeric(df_error['Value'], errors='ignore')
print("\nerrors='ignore' 적용 후:")
print(df_error)
print(df_error.dtypes)

# 3. errors='raise': 기본값, 변환 불가능한 값이 있으면 오류 발생
# try:
#     df_error['Value_numeric_raise'] = pd.to_numeric(df_error['Value'], errors='raise')
# except ValueError as e:
#     print(f"\n오류 발생: {e}")
```

**설명:**
- `errors='coerce'`: 가장 일반적으로 사용되는 옵션입니다. 변환할 수 없는 데이터는 `NaN`(Not a Number)으로 대체됩니다. 이후 `NaN` 값은 결측치 처리 방법으로 다룰 수 있습니다.
- `errors='ignore'`: 변환할 수 없는 데이터가 있으면 원래의 Series를 반환합니다. 즉, 타입 변환이 일어나지 않습니다.
- `errors='raise'`: 기본값입니다. 변환할 수 없는 데이터가 있으면 `ValueError`를 발생시킵니다.

### 4.4. `pd.to_datetime()`을 이용한 날짜/시간 변환 및 오류 처리

날짜/시간 데이터는 다양한 형식으로 존재할 수 있으며, 잘못된 형식의 데이터가 포함될 수 있습니다. `pd.to_datetime()` 함수는 이러한 문제를 해결하는 데 특화되어 있습니다.

```python
# 원본 DataFrame의 'Date' 컬럼
print("\n원본 DataFrame의 'Date' 컬럼:")
print(df['Date'])
print(df['Date'].dtypes)

# 1. errors='coerce': 변환 불가능한 날짜를 NaT (Not a Time)으로 대체
df['Date_parsed'] = pd.to_datetime(df['Date'], errors='coerce')
print("\nerrors='coerce' 적용 후 'Date_parsed':")
print(df['Date_parsed'])
print(df['Date_parsed'].dtypes)

# 2. format 인자 사용: 특정 형식 지정
# 예를 들어, 'YYYYMMDD' 형식의 문자열을 변환할 때
df_date_format = pd.DataFrame({
    'Date_str': ['20230101', '20230215', '20231231']
})
df_date_format['Date_parsed_format'] = pd.to_datetime(df_date_format['Date_str'], format='%Y%m%d')
print("\nformat 인자 사용 후:")
print(df_date_format)
print(df_date_format.dtypes)
```

**설명:**
- `errors='coerce'`: `pd.to_numeric()`와 동일하게 변환 불가능한 값을 `NaT`(Not a Time)으로 대체합니다.
- `format`: 입력 문자열의 날짜 형식을 명시적으로 지정할 수 있습니다. 이는 변환 속도를 높이고, 모호한 날짜 형식을 정확하게 파싱하는 데 도움을 줍니다. (예: `%Y-%m-%d`, `%m/%d/%Y`)

### 4.5. `pd.to_timedelta()`를 이용한 시간 간격 변환

시간 간격(예: '1 day', '2 hours')을 나타내는 문자열을 `Timedelta` 객체로 변환할 때 사용합니다.


고유한 값이 적고 반복되는 문자열 컬럼은 `category` 타입으로 변환하면 메모리 사용량을 줄이고 연산 속도를 향상시킬 수 있습니다.

## 5. 외부 라이브러리를 이용한 고급 유효성 검사 (Advanced Validation with External Libraries)

Pandas 자체만으로는 복잡한 데이터 스키마 정의나 데이터 파이프라인 전반에 걸친 지속적인 유효성 검사를 수행하기에는 한계가 있습니다. 실무에서는 데이터 품질을 보장하고 데이터 파이프라인의 안정성을 높이기 위해 `pandera`나 `great_expectations`와 같은 외부 라이브러리를 활용하는 경우가 많습니다. 이 라이브러리들은 선언적인 방식으로 데이터 스키마를 정의하고, 데이터가 이 스키마를 준수하는지 자동으로 검사하며, 실패 시 상세한 보고서를 제공합니다.

### 5.1. `pandera`를 이용한 선언적 스키마 유효성 검사

`pandera`는 Pandas DataFrame의 스키마를 선언적으로 정의하고, 데이터가 이 스키마를 따르는지 검사하는 강력한 라이브러리입니다. 컬럼의 데이터 타입, 값의 범위, 고유성, 결측치 허용 여부 등 다양한 규칙을 명시할 수 있습니다.

**주요 특징:**
*   **선언적 스키마 정의**: Python 코드로 데이터 스키마를 명확하게 정의할 수 있습니다.
*   **자동 유효성 검사**: DataFrame에 스키마를 적용하여 데이터가 규칙을 준수하는지 자동으로 검사합니다.
*   **상세한 오류 보고**: 유효성 검사 실패 시 어떤 규칙이 위반되었는지 상세한 오류 메시지를 제공합니다.
*   **파이프라인 통합**: 데이터 전처리 파이프라인의 각 단계에서 데이터 품질을 검증하는 데 유용합니다.

**설치:**
```bash
pip install pandera
```

**예시:**
```python
import pandas as pd
import pandera as pa
from pandera import Column, DataFrameSchema, Check

# 1. 데이터 스키마 정의
# 'id'는 정수형이고 고유해야 하며, 'name'은 문자열,
# 'age'는 정수형이고 0보다 커야 하며, 'city'는 'Seoul', 'Busan', 'Jeju' 중 하나여야 합니다.
schema = DataFrameSchema(
    columns={
        "id": Column(int, Check.unique(), Check.greater_than_or_equal_to(0)),
        "name": Column(str, Check.str_matches(r"^[A-Za-z가-힣\s]+$")), # 한글, 영어, 공백만 허용
        "age": Column(int, Check.greater_than(0)),
        "city": Column(str, Check.isin(["Seoul", "Busan", "Jeju"])),
        "score": Column(float, Check.in_range(0.0, 100.0), nullable=True) # score는 float이고 0~100 사이, 결측치 허용
    },
    strict=True # 스키마에 정의되지 않은 컬럼은 허용하지 않음
)

# 2. 유효한 데이터프레임
valid_df = pd.DataFrame({
    "id": [1, 2, 3],
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, 30, 35],
    "city": ["Seoul", "Busan", "Jeju"],
    "score": [85.5, 90.0, 78.2]
})

# 3. 유효성 검사 (성공)
try:
    validated_df = schema.validate(valid_df)
    print("유효한 DataFrame: 스키마 검증 성공!")
    print(validated_df)
except pa.errors.SchemaErrors as err:
    print("유효한 DataFrame: 스키마 검증 실패!")
    print(err)

# 4. 유효하지 않은 데이터프레임 (오류 발생 예시)
invalid_df = pd.DataFrame({
    "id": [1, 2, 1], # id 중복
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, -5, 35], # age 음수
    "city": ["Seoul", "Busan", "New York"], # city 유효하지 않은 값
    "score": [85.5, 105.0, None], # score 범위 초과, None 허용
    "extra_col": [1, 2, 3] # 스키마에 없는 컬럼 (strict=True 시 오류)
})

# 5. 유효성 검사 (실패)
try:
    validated_df = schema.validate(invalid_df)
    print("\n유효하지 않은 DataFrame: 스키마 검증 성공 (오류 발생 예상)!")
    print(validated_df)
except pa.errors.SchemaErrors as err:
    print("\n유효하지 않은 DataFrame: 스키마 검증 실패!")
    print(err.failure_cases) # 어떤 규칙이 위반되었는지 상세 정보
    print(err.data) # 유효성 검사에 실패한 원본 데이터
```

### 5.2. `great_expectations`를 이용한 데이터 품질 관리

`great_expectations`는 데이터셋에 대한 "기대치(Expectations)"를 정의하고, 이 기대치를 데이터에 적용하여 데이터 품질을 검증하는 라이브러리입니다. 데이터 프로파일링, 데이터 품질 보고서 생성, 데이터 버전 관리 등 데이터 거버넌스 측면에서 강력한 기능을 제공합니다.

**주요 특징:**
*   **데이터 기대치 정의**: 데이터의 특성(예: 컬럼이 특정 값 범위 내에 있어야 함, 결측치 비율이 특정 임계값 미만이어야 함)을 기대치로 정의합니다.
*   **데이터 문서화**: 기대치 정의 자체가 데이터에 대한 문서 역할을 합니다.
*   **데이터 품질 보고서**: 기대치 검증 결과를 시각적인 보고서로 생성하여 데이터 품질 현황을 쉽게 파악할 수 있습니다.
*   **데이터 테스트**: 데이터 파이프라인의 각 단계에서 데이터가 예상대로 변환되었는지 테스트하는 데 활용됩니다.

`great_expectations`는 `pandera`보다 더 넓은 범위의 데이터 품질 관리 기능을 제공하며, 특히 데이터 파이프라인의 지속적인 데이터 품질 검증에 중점을 둡니다. 사용법은 `pandera`보다 복잡할 수 있으나, 대규모 데이터 프로젝트에서 데이터 신뢰성을 확보하는 데 필수적인 도구입니다.

(자세한 사용법은 `great_expectations` 공식 문서를 참조하세요.)

이처럼 외부 라이브러리를 활용하면 Pandas만으로는 구현하기 어려운 복잡하고 체계적인 데이터 유효성 검사 및 품질 관리 시스템을 구축할 수 있습니다. 이는 데이터 분석 및 머신러닝 프로젝트의 신뢰성과 안정성을 크게 향상시키는 데 기여합니다.
