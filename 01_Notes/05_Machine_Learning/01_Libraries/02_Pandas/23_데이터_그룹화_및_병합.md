## 1. 데이터 그룹화 (`groupby`)

`groupby`는 데이터 분석의 핵심으로, 특정 기준에 따라 데이터를 그룹으로 묶어 다양한 연산을 수행하게 해주는 강력한 기능입니다. SQL의 `GROUP BY` 절과 유사하지만, 훨씬 유연하고 다채로운 기능을 제공합니다.

### 1.1. `groupby`의 개념: Split-Apply-Combine

`groupby`의 모든 연산은 **"분할-적용-결합(Split-Apply-Combine)"** 이라는 세 단계의 과정을 거칩니다. 이 개념을 이해하는 것이 `groupby`를 마스터하는 첫걸음입니다. 이 패턴은 데이터 분석에서 매우 일반적이고 강력하기 때문에 Pandas의 핵심 기능으로 자리 잡았습니다.

**일상 생활의 비유: 우편물 분류**

이 과정을 우체국에서 우편물을 분류하는 작업에 비유할 수 있습니다.

1.  **Split (분할)**: 전국에서 모인 모든 우편물을 각 도시(예: 서울, 부산, 대구)별로 분류하여 큰 상자에 담습니다. 이는 원본 데이터를 특정 기준(도시)으로 나누는 것과 같습니다.
2.  **Apply (적용)**: 각 도시별 상자 안의 우편물에 특정 작업을 수행합니다. 예를 들어, 각 상자 안에 있는 우편물의 총개수를 세거나, 총 무게를 잽니다. 이는 각 데이터 그룹에 특정 함수(`count()`, `sum()`)를 적용하는 것과 같습니다.
3.  **Combine (결합)**: 각 도시별로 계산된 결과(우편물 개수, 총 무게)를 하나의 보고서로 취합합니다. "서울: 5000개, 부산: 3000개, 대구: 2500개"와 같이 말이죠. 이는 각 그룹의 계산 결과를 새로운 데이터 구조(Series 또는 DataFrame)로 합치는 것과 같습니다.

--- 

**Pandas 데이터로 단계별 살펴보기**

아래 코드가 어떻게 Split-Apply-Combine 원리에 따라 동작하는지 살펴보겠습니다.

```python
store_sales_sum = df.groupby('Store')['Sales'].sum()
```

**1. Split (분할 단계)**

`df.groupby('Store')`가 실행되는 순간, Pandas는 내부적으로 `Store` 컬럼의 고유값('A', 'B', 'C')을 기준으로 원본 `DataFrame`을 여러 개의 작은 `DataFrame` 그룹으로 나눕니다. 이 그룹들은 아직 눈에 보이지는 않지만, 메모리상에 다음과 같이 분할되어 존재합니다.

**원본 데이터 (`df`)**
```
  Store Product  Sales  Quantity
0     A   Apple    200        10
1     B  Banana    150        15
2     A  Orange    300        20
3     C   Apple    250        25
4     B  Orange    180        18
5     A  Banana    120        12
```

**분할된 그룹들**

*   **그룹 'A'**
    ```
      Store Product  Sales  Quantity
    0     A   Apple    200        10
    2     A  Orange    300        20
    5     A  Banana    120        12
    ```
*   **그룹 'B'**
    ```
      Store  Product  Sales  Quantity
    1     B   Banana    150        15
    4     B   Orange    180        18
    ```
*   **그룹 'C'**
    ```
      Store Product  Sales  Quantity
    3     C   Apple    250        25
    ```

**2. Apply (적용 단계)**

`['Sales'].sum()` 부분이 각 그룹에 독립적으로 적용됩니다. 즉, 각 그룹의 `Sales` 컬럼에 대해 `sum()` 함수가 실행됩니다.

*   **그룹 'A'에 적용**: `[200, 300, 120].sum()` → `620`
*   **그룹 'B'에 적용**: `[150, 180].sum()` → `330`
*   **그룹 'C'에 적용**: `[250].sum()` → `250`

이 단계에서는 집계(`sum`, `mean`), 변환(`transform`), 필터링(`filter`) 등 다양한 연산이 수행될 수 있습니다.

**3. Combine (결합 단계)**

적용 단계에서 계산된 각 그룹의 결과들이 새로운 `Series` 객체로 합쳐집니다. 이때 그룹의 이름('A', 'B', 'C')이 새로운 `Series`의 인덱스가 됩니다.

**최종 결과 (`store_sales_sum`)**
```
Store
A    620
B    330
C    250
Name: Sales, dtype: int64
```

이처럼 Split-Apply-Combine은 복잡해 보이는 `groupby` 연산을 세 개의 논리적 단위로 나누어 명확하게 이해할 수 있도록 돕는 핵심적인 개념입니다.

`groupby`의 모든 연산은 **"분할-적용-결합(Split-Apply-Combine)"** 이라는 세 단계의 과정을 거칩니다. 이 개념을 이해하는 것이 `groupby`를 마스터하는 첫걸음입니다.

1.  **Split (분할)**: 원본 `DataFrame`을 특정 기준(하나 또는 여러 컬럼의 값)에 따라 여러 개의 작은 그룹으로 나눕니다. 예를 들어, '상점' 컬럼을 기준으로 그룹화하면 각 상점(A, B, C)별로 데이터가 묶인 그룹들이 생성됩니다.
2.  **Apply (적용)**: 각 그룹에 사용자가 정의한 함수를 독립적으로 적용합니다. 이 함수는 주로 다음과 같은 연산을 수행합니다.
    *   **집계 (Aggregation)**: 각 그룹의 통계량을 계산합니다 (예: `sum()`, `mean()`, `count()`).
    *   **변환 (Transformation)**: 그룹별 계산을 수행하지만, 결과의 차원(shape)이 원본 데이터와 동일하게 유지됩니다 (예: 그룹 평균으로 결측치 채우기).
    *   **필터링 (Filtration)**: 그룹별 조건을 만족하는 데이터만 남깁니다 (예: 특정 기준을 충족하는 그룹 전체를 선택하거나 제외).
3.  **Combine (결합)**: 'Apply' 단계에서 각 그룹별로 도출된 결과들을 다시 하나의 `DataFrame`이나 `Series`로 합칩니다.

이 과정을 시각적으로 이해하면 `groupby`의 동작 방식을 명확히 파악할 수 있습니다.

```python
import pandas as pd
import numpy as np

# 예제 데이터프레임 생성
df = pd.DataFrame({
    'Store': ['A', 'B', 'A', 'C', 'B', 'A'],
    'Product': ['Apple', 'Banana', 'Orange', 'Apple', 'Orange', 'Banana'],
    'Sales': [200, 150, 300, 250, 180, 120],
    'Quantity': [10, 15, 20, 25, 18, 12]
})
```

### 1.2. `groupby` 기본 사용법 및 집계 함수

가장 일반적인 `groupby` 활용법은 특정 컬럼으로 그룹을 나눈 뒤, 각 그룹의 통계치를 계산하는 것입니다. 이 과정을 통해 데이터의 패턴과 특성을 파악할 수 있습니다.

**1. `GroupBy` 객체 이해하기**

`df.groupby('Store')` 코드를 실행하면, 그 자체만으로는 `DataFrame`이 반환되지 않습니다. 대신 **`DataFrameGroupBy`** 라는 특별한 객체가 생성됩니다. 이 객체는 각 그룹에 대한 모든 정보를 담고 있으며, 집계 함수가 호출되기 전까지는 실제 계산을 수행하지 않습니다. (이를 '지연 연산(Lazy Evaluation)'이라고 합니다.)

```python
# GroupBy 객체 생성
grouped = df.groupby('Store')
print(grouped)
# <pandas.core.groupby.generic.DataFrameGroupBy object at ...>

# groups 속성으로 그룹 정보 확인
print("\n--- 생성된 그룹 정보 ---")
print(grouped.groups)
# {'A': [0, 2, 5], 'B': [1, 4], 'C': [3]}

# get_group()으로 특정 그룹 데이터만 추출
print("\n--- 'A' 그룹 데이터 ---")
print(grouped.get_group('A'))
```

**2. 기본 집계 함수 활용**

`GroupBy` 객체가 생성된 후, 특정 컬럼을 선택하고 집계 함수를 적용하여 비로소 원하는 결과를 얻을 수 있습니다. `df.groupby('그룹화기준')['분석대상'].집계함수()` 형태가 기본입니다.

```python
# 각 상점(Store)별 평균 매출(Sales) 계산
store_sales_mean = df.groupby('Store')['Sales'].mean()
print("\n--- 각 상점별 평균 매출 ---")
print(store_sales_mean)

# 각 상점별 판매량(Quantity)의 최대값
store_quantity_max = df.groupby('Store')['Quantity'].max()
print("\n--- 각 상점별 최대 판매량 ---")
print(store_quantity_max)
```

**주요 내장 집계 함수와 예시:**

*   `sum()`: 그룹 데이터의 합계
*   `mean()`: 그룹 데이터의 평균
*   `std()`: 그룹 데이터의 표준편차
*   `var()`: 그룹 데이터의 분산
*   `min()` / `max()`: 그룹 데이터의 최소 / 최대값
*   `size()`: **`NaN` 값을 포함**한 각 그룹의 전체 행 개수를 반환 (Series)
*   `count()`: **`NaN` 값을 제외**한 각 그룹의 데이터 개수를 반환 (DataFrame 또는 Series)
*   `nunique()`: 그룹 내 고유한 값의 개수

```python
# size() vs count() 비교
print("\n--- size(): 그룹별 전체 크기 ---")
print(df.groupby('Store').size())

print("\n--- count(): 그룹별 유효 데이터 수 ---")
print(df.groupby('Store').count())
```

**3. 여러 컬럼으로 그룹화 (Multi-level Grouping)**

여러 컬럼을 리스트 형태로 `groupby`에 전달하면, 더 세부적인 그룹을 만들 수 있습니다. 이 경우 결과는 **`MultiIndex` (다중 인덱스)** 를 갖는 `Series`나 `DataFrame`이 됩니다.

```python
# 상점과 상품 종류를 기준으로 그룹화하여 판매량 합계 계산
multi_group_sum = df.groupby(['Store', 'Product'])['Quantity'].sum()
print("\n--- 상점 및 상품별 판매량 합계 (MultiIndex) ---")
print(multi_group_sum)
```

**4. 그룹화 결과를 인덱스가 아닌 컬럼으로 사용하기**

기본적으로 `groupby`는 그룹화 기준이 되는 컬럼을 인덱스로 만듭니다. 이를 원하지 않을 경우, 두 가지 방법이 있습니다.

*   **`as_index=False` 옵션 사용**: `groupby` 호출 시점에 설정합니다.
*   **`.reset_index()` 메서드 사용**: 집계 연산 후에 인덱스를 리셋합니다.

```python
# as_index=False 사용
store_sales_df = df.groupby('Store', as_index=False)['Sales'].sum()
print("\n--- 그룹화 결과를 컬럼으로 (as_index=False) ---")
print(store_sales_df)

# reset_index() 사용
store_sales_df_reset = df.groupby('Store')['Sales'].sum().reset_index()
print("\n--- 그룹화 결과를 컬럼으로 (reset_index) ---")
print(store_sales_df_reset)
```
이 두 방법은 `DataFrame`을 다룰 때 매우 흔하게 사용되는 패턴입니다.

**5. 그룹 순회 (Iterating through groups)**

`for` 루프를 사용하여 각 그룹의 이름과 해당 그룹의 데이터(`DataFrame`)를 순회할 수 있습니다. 이는 그룹별로 복잡한 연산을 수행하거나 디버깅할 때 유용합니다.

```python
print("\n--- 그룹별 데이터 순회 ---")
for name, group_df in df.groupby('Store'):
    print(f"\n[Store: {name}]")
    print(group_df)
```


### 1.3. `agg()`를 이용한 다중 집계

`agg()` (또는 `aggregate`) 함수는 `groupby`의 꽃이라고 할 수 있습니다. 이 함수를 사용하면 그룹별로 여러 개의 집계 결과를 **한 번에, 원하는 형태로** 계산할 수 있어 매우 효율적이고 가독성 높은 코드를 작성할 수 있습니다.

**1. 단일 컬럼에 여러 함수 적용하기**

가장 기본적인 사용법은 하나의 컬럼에 여러 집계 함수를 리스트 형태로 적용하는 것입니다.

```python
# 각 상점별 매출의 합계, 평균, 표준편차를 동시에 계산
store_agg = df.groupby('Store')['Sales'].agg(['sum', 'mean', 'std'])
print("--- 상점별 매출의 합계, 평균, 표준편차 ---")
print(store_agg)
```
결과 `DataFrame`의 컬럼 이름은 자동으로 `sum`, `mean`, `std`로 지정됩니다.

**2. 여러 컬럼에 각기 다른 함수 적용하기**

딕셔너리를 사용하면 각 컬럼에 적용할 집계 함수를 개별적으로 지정할 수 있습니다.

```python
# 상점별로 매출(Sales)의 총합과 판매량(Quantity)의 평균을 계산
store_multi_agg_dict = df.groupby('Store').agg({
    'Sales': 'sum',      # Sales 컬럼에는 sum 적용
    'Quantity': 'mean'  # Quantity 컬럼에는 mean 적용
})
print("--- 상점별 매출 총합과 판매량 평균 ---")
print(store_multi_agg_dict)
```

**3. 집계 결과 컬럼 이름 직접 지정하기 (Named Aggregation)**

집계 결과의 컬럼 이름이 마음에 들지 않거나, 더 명확한 이름으로 바꾸고 싶을 때가 많습니다. 이때 **"이름있는 집계(Named Aggregation)"** 를 사용하면 매우 편리합니다.

`agg()` 안에 `새로운컬럼명=('원본컬럼명', '함수명')` 형태의 키워드 인자를 전달합니다.

```python
# 상점별로 매출 총합, 평균 판매량, 판매 건수를 계산하고 컬럼 이름 지정
store_named_agg = df.groupby('Store').agg(
    Total_Sales=('Sales', 'sum'),
    Avg_Quantity=('Quantity', 'mean'),
    Num_Transactions=('Product', 'count') # Product 컬럼을 이용해 거래 건수 계산
)
print("\n--- 이름있는 집계를 사용한 결과 ---")
print(store_named_agg)
```
이 방식은 코드가 직관적이고, 결과 `DataFrame`이 바로 사용하기 좋은 형태로 만들어진다는 큰 장점이 있습니다.

**4. 사용자 정의 함수 및 `lambda` 활용하기**

`agg()`의 진정한 강력함은 Pandas가 제공하는 내장 함수뿐만 아니라, 사용자가 직접 만든 함수나 간단한 `lambda` 함수도 적용할 수 있다는 점에 있습니다.

```python
# 최대값과 최소값의 차이(range)를 계산하는 함수 정의
def calc_range(series):
    return series.max() - series.min()

# 사용자 정의 함수와 lambda를 함께 사용
store_custom_agg = df.groupby('Store').agg(
    Sales_Sum=('Sales', 'sum'),
    # lambda 함수로 매출의 분산을 계산
    Sales_Var_Lambda=('Sales', lambda s: s.var()),
    # 직접 만든 함수로 판매량의 범위를 계산
    Quantity_Range=('Quantity', calc_range)
)

print("\n--- 사용자 정의 함수 및 lambda 활용 ---")
print(store_custom_agg)
```

**5. 모든 기법을 종합한 복합 예제**

하나의 `agg` 연산 안에서 여러 컬럼에 대해, 내장 함수와 사용자 정의 함수를 섞어 쓰고, 결과 컬럼명을 모두 지정하는 것도 가능합니다.

```python
# 모든 기법을 종합하여 상점별 분석 수행
comprehensive_agg = df.groupby('Store').agg(
    # Sales 컬럼에 대한 집계
    Total_Sales=('Sales', 'sum'),
    Avg_Sales=('Sales', 'mean'),
    Sales_Range=('Sales', calc_range),
    
    # Quantity 컬럼에 대한 집계
    Total_Quantity=('Quantity', 'sum'),
    Sales_per_Quantity=('Sales', lambda s: s.sum() / df.loc[s.index, 'Quantity'].sum()),

    # Product 컬럼에 대한 집계
    Num_Products=('Product', 'size'),
    Unique_Products=('Product', 'nunique')
)

print("\n--- 종합적인 다중 집계 예제 ---")
print(comprehensive_agg)
```
이처럼 `agg()` 함수를 잘 활용하면, 복잡한 그룹별 분석을 단 몇 줄의 코드로 간결하고 명확하게 수행할 수 있습니다.


### 1.4. `transform`과 `filter`를 이용한 고급 그룹 연산

`agg`가 그룹별로 요약된 통계를 반환하는 것과 달리, `transform`과 `filter`는 원본 데이터의 형태를 유지하면서 그룹 연산을 수행하는 강력한 도구입니다.

**1. `transform`: 그룹별 연산을 통한 데이터 변환**

`transform`은 그룹별로 함수를 적용한 뒤, 그 결과를 **원본 `DataFrame`과 동일한 모양(shape)과 인덱스**로 반환합니다. 이 특성 덕분에 원본 데이터에 그룹별 통계치를 기반으로 한 새로운 컬럼을 손쉽게 추가할 수 있습니다.

**`agg` vs `transform` 핵심 차이**
*   `agg`: 그룹당 하나의 결과(요약 통계)를 반환합니다. 결과의 행 개수는 그룹의 개수와 같습니다.
*   `transform`: 원본 데이터와 동일한 수의 행을 가진 `Series`를 반환합니다. 각 행에는 해당 행이 속한 그룹의 계산 결과가 채워집니다.

**주요 활용 사례:**

**A. 그룹 내 표준화 (Z-score 계산)**
각 데이터가 그룹 내에서 통계적으로 어떤 위치에 있는지 확인할 때 유용합니다.
```python
# 각 상점(Store) 내에서 매출(Sales)을 표준화(Z-score)
# Z-score = (개별 데이터 - 그룹 평균) / 그룹 표준편차
z_score = lambda x: (x - x.mean()) / x.std()
df['Sales_ZScore'] = df.groupby('Store')['Sales'].transform(z_score)

print("--- 그룹별 표준화(Z-score) ---")
print(df)
```

**B. 그룹 평균으로 결측치(NaN) 대체**
데이터 전처리 시, 전체 평균보다 더 정교하게 그룹별 특성을 반영하여 결측치를 채울 수 있습니다.
```python
# 결측치가 있는 예제 데이터 생성
df_nan = df.copy()
df_nan.loc[[0, 4], 'Sales'] = np.nan # A와 B 상점 매출에 결측치 생성

# 상점별 평균 매출 계산
store_mean_sales = df_nan.groupby('Store')['Sales'].transform('mean')
print("\n--- 상점별 평균 매출 (transform 결과) ---")
print(store_mean_sales)

# fillna()와 함께 사용하여 결측치 대체
df_nan['Sales_Imputed'] = df_nan['Sales'].fillna(store_mean_sales)
print("\n--- 그룹 평균으로 결측치 대체 ---")
print(df_nan)
```

---

**2. `filter`: 그룹 단위 조건 필터링**

`filter`는 그룹 전체의 특성을 기반으로 데이터를 걸러내는 기능을 합니다. `filter`에 전달된 함수는 각 그룹에 대해 **단일 `True` 또는 `False`** 값을 반환해야 합니다. `True`를 반환하는 그룹의 모든 행은 남고, `False`를 반환하는 그룹의 모든 행은 제거됩니다.

**`filter` vs 일반 Boolean 인덱싱**
*   일반 Boolean 인덱싱: 각 **행(row)**에 대해 조건을 검사합니다.
*   `filter`: 각 **그룹(group)** 전체에 대해 조건을 검사합니다.

**주요 활용 사례:**

**A. 그룹 크기를 기준으로 필터링**
데이터가 충분하지 않은 그룹을 분석에서 제외할 때 유용합니다.
```python
# 거래가 3건 이상인 상점의 데이터만 남기기
filtered_by_size = df.groupby('Store').filter(lambda g: len(g) >= 3)

print("\n--- 거래가 3건 이상인 상점 데이터 ---")
print(filtered_by_size)
```

**B. 그룹의 통계치를 기준으로 필터링**
특정 조건을 만족하는 그룹 전체의 데이터를 살펴보고 싶을 때 사용합니다.
```python
# 평균 판매량(Quantity)이 15개를 초과하는 상점의 데이터만 필터링
filtered_by_mean = df.groupby('Store').filter(lambda g: g['Quantity'].mean() > 15)

print("\n--- 평균 판매량이 15개를 초과하는 상점 데이터 ---")
print(filtered_by_mean)
```
 위 예제에서 상점 'A'는 평균 판매량이 (10+20+12)/3 = 14개이므로 필터링되어 사라지고, 상점 'B'와 'C'의 데이터만 남게 됩니다.


### 1.5. `apply()`를 이용한 유연한 그룹 연산

`apply()`는 `groupby` 연산의 "만능 도구(Swiss Army Knife)"와 같습니다. `agg`, `transform`, `filter`가 각각 집계, 변환, 필터링이라는 정해진 목적에 최적화되어 있다면, `apply`는 **어떤 종류의 복잡한 연산이든** 그룹별로 수행할 수 있는 최고의 유연성을 제공합니다.

**`apply`의 핵심 동작 방식**
- **입력**: `apply`에 전달되는 함수는 각 그룹에 해당하는 **`DataFrame` 조각**을 통째로 인자로 받습니다.
- **처리**: 함수 내에서 해당 `DataFrame` 조각을 가지고 Pandas가 제공하는 모든 기능을 자유롭게 사용하여 원하는 연산을 수행할 수 있습니다.
- **출력**: 함수는 단일 값(스칼라), `Series`, 또는 `DataFrame` 등 다양한 형태의 결과를 반환할 수 있습니다. Pandas는 각 그룹에서 반환된 결과들을 지능적으로 조합하여 최종 결과물을 만듭니다.

**주요 활용 사례**

**A. 그룹별로 여러 행을 반환하는 경우 (예: 상위 N개 추출)**
`agg`나 `transform`으로는 구현하기 어려운, 각 그룹에서 조건에 맞는 여러 행을 추출하는 경우에 `apply`가 매우 유용합니다.

```python
# 각 상점에서 매출이 가장 높은 상위 2개 거래를 추출하는 함수
def get_top_n_sales(group, n):
    return group.sort_values(by='Sales', ascending=False).head(n)

# apply를 사용하여 각 그룹에 함수 적용. n=2 라는 추가 인자를 전달.
top_2_sales = df.groupby('Store').apply(get_top_n_sales, n=2)

print("--- 각 상점별 상위 2개 매출 데이터 ---")
print(top_2_sales)
```
이 결과에서 인덱스는 `(그룹명, 기존 인덱스)` 형태의 `MultiIndex`가 됩니다. `reset_index(drop=True)` 등을 사용하여 인덱스를 재구성할 수 있습니다.

**B. 그룹의 여러 컬럼을 복합적으로 계산하여 단일 값(스칼라) 반환**
그룹의 두 개 이상 컬럼을 사용하여 새로운 값을 계산할 때 `apply`를 사용할 수 있습니다 있습니다.

```python
# 매출(Sales)을 판매량(Quantity)으로 나눈 가중 평균을 계산하는 함수
def weighted_average(group):
    weights = group['Quantity']
    values = group['Sales']
    return (values * weights).sum() / weights.sum()

weighted_avg_sales = df.groupby('Store').apply(weighted_average)
print("\n--- 판매량 가중 평균 매출 ---")
print(weighted_avg_sales)
```

**C. 그룹별로 요약 통계 `Series` 반환**
`describe()`와 같이 여러 요약 통계치를 담은 `Series`를 반환하는 함수도 `apply`와 함께 사용할 수 있습니다.

```python
# 각 상점별 매출(Sales)의 요약 통계 계산
def describe_sales(group):
    return group['Sales'].describe()

sales_description = df.groupby('Store').apply(describe_sales)
print("\n--- 상점별 매출 요약 통계 ---")
print(sales_description)
```

**성능에 대한 중요 고려사항**

`apply`는 매우 유연하지만, 그 유연성에는 **성능 저하**라는 비용이 따를 수 있습니다. `agg`, `transform` 등에 내장된 함수(`sum`, `mean` 등)는 Pandas 내부에서 C로 구현된 코드를 통해 매우 빠르게 동작합니다. 반면, `apply`는 각 그룹에 대해 파이썬 함수를 호출하므로, 데이터가 클 경우 눈에 띄게 속도가 느려질 수 있습니다.

**결론: 언제 `apply`를 사용해야 하는가?**
1.  `agg`, `transform`, `filter`의 기능만으로는 해결할 수 없는 복잡한 로직이 필요할 때.
2.  그룹별로 여러 행/열을 반환하거나, 입력 `DataFrame`과 전혀 다른 새로운 구조의 `DataFrame`을 만들어야 할 때.
3.  성능보다 구현의 간결함과 유연성이 더 중요할 때.

**성능 최적화를 위한 팁**: 가능한 경우, `agg(['sum', 'mean'])`처럼 내장 함수를 여러 개 쓰는 것이 `apply(lambda x: x.agg(...)))` 보다 훨씬 빠릅니다. 항상 내장 함수로 해결할 수 있는지 먼저 고민하고, 최후의 수단으로 `apply`를 사용하는 것이 좋습니다.


`groupby` 연산은 데이터를 특정 기준으로 여러 그룹으로 나누어, 각 그룹에 독립적으로 함수를 적용하고, 그 결과를 다시 하나의 데이터 구조로 합치는 강력한 기능입니다.

## 2. 데이터 병합 및 연결

여러 `DataFrame`을 하나로 합치는 방법은 크게 `concat` (연결)과 `merge` (병합)으로 나뉩니다.

### 2.1. `concat()` - 데이터 이어붙이기

`pd.concat()` 함수는 여러 개의 `DataFrame`이나 `Series`를 말 그대로 "이어붙여서" 하나의 객체로 만드는 가장 직관적인 방법입니다. 마치 여러 장의 종이를 풀로 붙이는 것과 같습니다.

**핵심 파라미터 `axis`**: 이어붙일 방향을 결정합니다.
- `axis=0` (기본값): 위아래로, 즉 **행(row)** 방향으로 이어붙입니다.
- `axis=1`: 좌우로, 즉 **열(column)** 방향으로 이어붙입니다.

---

**1. 행 방향으로 연결 (`axis=0`)**

가장 일반적인 사용 사례로, 구조가 동일한 여러 `DataFrame`을 수직으로 쌓습니다.

**예제 데이터**
```python
df1 = pd.DataFrame({'A': ['A0', 'A1'], 'B': ['B0', 'B1']}, index=[0, 1])
df2 = pd.DataFrame({'A': ['A2', 'A3'], 'B': ['B2', 'B3']}, index=[2, 3])
df3 = pd.DataFrame({'A': ['A4', 'A5'], 'B': ['B4', 'B5']}, index=[0, 1]) # df1과 인덱스가 겹침
```

**A. 기본 연결**
```python
# df1과 df2를 행 기준으로 연결
row_concat_basic = pd.concat([df1, df2])
print("--- 기본 행 연결 ---")
print(row_concat_basic)
```
기존 인덱스가 그대로 유지됩니다.

**B. 인덱스 무시하고 새로 생성 (`ignore_index=True`)**
기존 인덱스가 의미 없거나 중복될 때, `ignore_index=True` 옵션을 주면 0부터 시작하는 새로운 인덱스를 생성해 줍니다.
```python
# df1과 df3는 인덱스가 겹치므로, ignore_index=True 사용이 권장됨
row_concat_ignore = pd.concat([df1, df3], ignore_index=True)
print("\n--- 인덱스를 무시하고 행 연결 ---")
print(row_concat_ignore)
```

**C. 출처를 구분하는 계층적 인덱스 생성 (`keys` 파라미터)**
어떤 데이터가 어느 `DataFrame`에서 왔는지 구분하고 싶을 때 `keys` 파라미터를 사용하면 편리합니다.
```python
row_concat_keys = pd.concat([df1, df2], keys=['DF1', 'DF2'])
print("\n--- 계층적 인덱스로 행 연결 ---")
print(row_concat_keys)

# 계층적 인덱스로 데이터 접근
print("\n--- DF1에서 온 데이터 접근 ---")
print(row_concat_keys.loc['DF1'])
```

---

**2. 열 방향으로 연결 (`axis=1`)**

서로 다른 정보를 가진 `DataFrame`들을 인덱스를 기준으로 좌우로 합칠 때 사용합니다.

**예제 데이터**
```python
df4 = pd.DataFrame({'C': ['C0', 'C1'], 'D': ['D0', 'D1']}, index=[0, 1])
df5 = pd.DataFrame({'E': ['E2', 'E3'], 'F': ['F2', 'F3']}, index=[2, 3]) # df1, df4와 인덱스가 다름
```

**A. 인덱스가 일치하는 경우**
```python
# df1과 df4는 인덱스가 0, 1로 동일
col_concat_aligned = pd.concat([df1, df4], axis=1)
print("\n--- 인덱스가 일치하는 열 연결 ---")
print(col_concat_aligned)
```

**B. 인덱스가 불일치하는 경우 (`join` 파라미터)**
`concat`은 기본적으로 **`join='outer'` (외부 조인)** 방식으로 동작합니다. 즉, 모든 인덱스를 유지하고, 한쪽에 데이터가 없으면 `NaN`으로 채웁니다.

```python
# df1과 df5는 인덱스가 불일치
outer_join_concat = pd.concat([df1, df5], axis=1)
print("\n--- 외부 조인 방식의 열 연결 (기본값) ---")
print(outer_join_concat)
```

`join='inner'` (내부 조인)으로 설정하면, 양쪽 `DataFrame`에 **공통으로 존재하는 인덱스**의 데이터만 남깁니다.
```python
# df1과 df5는 공통 인덱스가 없으므로 결과는 비어있음
inner_join_concat = pd.concat([df1, df5], axis=1, join='inner')
print("\n--- 내부 조인 방식의 열 연결 ---")
print(inner_join_concat)
```
`concat`은 주로 구조가 같은 데이터들을 쌓을 때(행 연결) 많이 사용되며, 열 연결 시에는 다음 섹션에서 배울 `merge`나 `join`이 더 직관적이고 강력한 경우가 많습니다.

### 2.2. `merge()` - SQL 스타일 조인

`pd.merge()`는 관계형 데이터베이스(SQL)의 `JOIN`과 매우 유사한 개념으로, Pandas에서 가장 중요하고 강력한 데이터 결합 기능입니다. `merge`는 하나 이상의 공통된 값(키, key)을 기준으로 두 `DataFrame`의 행을 논리적으로 연결합니다.

--- 

**핵심 개념과 주요 파라미터**

`pd.merge(left_df, right_df, how='inner', on=None, left_on=None, right_on=None, suffixes=('_x', '_y'))`

*   `left`, `right`: 병합할 두 `DataFrame` 객체.
*   `how`: 조인 방식을 결정합니다.
    *   `'inner'`: 양쪽 `DataFrame`에 모두 존재하는 키만 포함 (교집합).
    *   `'left'`: 왼쪽 `DataFrame`의 모든 키를 포함.
    *   `'right'`: 오른쪽 `DataFrame`의 모든 키를 포함.
    *   `'outer'`: 양쪽 `DataFrame`의 모든 키를 포함 (합집합).
*   `on`: 조인의 기준이 되는 **공통 컬럼명**. 양쪽 `DataFrame`에 같은 이름의 기준 컬럼이 있을 때 사용.
*   `left_on`, `right_on`: 조인의 기준이 되는 컬럼명이 **양쪽 `DataFrame`에서 다를 때** 각각 지정.
*   `suffixes`: 조인 대상이 아닌 컬럼 중, 양쪽에 이름이 같은 컬럼이 있을 경우, 구분을 위해 붙여줄 접미사.

--- 

**다양한 조인(Join) 방식 상세히 알아보기**

**예제 데이터**
```python
df_employees = pd.DataFrame({
    'employee_id': ['E1', 'E2', 'E3', 'E4', 'E5'],
    'name': ['Bob', 'Jake', 'Lisa', 'Sue', 'John'],
    'department_id': ['D1', 'D2', 'D1', 'D3', 'D4']
})

df_departments = pd.DataFrame({
    'id': ['D1', 'D2', 'D3', 'D5'],
    'department_name': ['HR', 'Engineering', 'Marketing', 'Sales']
})
```

**1. Inner Join (내부 조인)**
양쪽 `DataFrame`에 **모두 존재하는 키**를 기준으로 데이터를 병합합니다. `department_id` 'D1', 'D2', 'D3'만 양쪽에 공통으로 존재합니다.
```python
# 'department_id'와 'id' 컬럼을 기준으로 내부 조인
inner_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='inner')
print("---" + "Inner Join 결과" + " ---")
print(inner_join)
```
*결과: 'D4'(John)와 'D5'(Sales) 관련 정보는 사라집니다.*

**2. Left Join (왼쪽 조인)**
**왼쪽 `DataFrame`(df_employees)의 모든 행을 유지**하고, 오른쪽 `DataFrame`의 정보를 키를 기준으로 붙입니다. 오른쪽 `DataFrame`에 일치하는 키가 없으면 해당 부분은 `NaN` (Not a Number)으로 채워집니다.
```python
left_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='left')
print("\n---" + "Left Join 결과" + " ---")
print(left_join)
```
*결과: 'E5' 직원 John의 `department_id`인 'D4'는 `df_departments`에 없으므로, `id`와 `department_name`이 `NaN`으로 표시됩니다.*

**3. Right Join (오른쪽 조인)**
**오른쪽 `DataFrame`(df_departments)의 모든 행을 유지**합니다. 왼쪽 조인과 반대로 동작합니다.
```python
right_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='right')
print("\n---" + "Right Join 결과" + " ---")
print(right_join)
```
*결과: 'D5' 부서(Sales)는 소속된 직원이 `df_employees`에 없으므로, `employee_id`, `name`, `department_id`가 `NaN`으로 표시됩니다.*

**4. Outer Join (외부 조인)**
**양쪽 `DataFrame`의 모든 키를 유지**하며 병합합니다. 한쪽에만 키가 있는 경우, 다른 쪽의 데이터는 `NaN`으로 채워집니다.
```python
outer_join = pd.merge(df_employees, df_departments, left_on='department_id', right_on='id', how='outer')
print("\n---" + "Outer Join 결과" + " ---")
print(outer_join)
```
*결과: 왼쪽의 'D4'와 오른쪽의 'D5' 관련 정보가 모두 포함되며, 짝이 없는 부분은 `NaN`으로 채워집니다.*

--- 

**고급 `merge` 활용법**

**A. 중복된 컬럼명 처리 (`suffixes`)**
만약 조인 키가 아닌 컬럼의 이름이 양쪽 `DataFrame`에 중복으로 존재하면, `merge`는 자동으로 `_x`(왼쪽), `_y`(오른쪽) 접미사를 붙입니다. `suffixes` 파라미터로 이 접미사를 직접 지정할 수 있습니다.

```python
df_left = pd.DataFrame({'key': ['K0', 'K1'], 'value': [1, 2]})
df_right = pd.DataFrame({'key': ['K0', 'K1'], 'value': [3, 4]})

# 'value' 컬럼이 중복됨
merged_suffixes = pd.merge(df_left, df_right, on='key', suffixes=('_left', '_right'))
print("\n---" + " Suffixes 활용 예제 " + "---")
print(merged_suffixes)
```

**B. 여러 개의 키를 기준으로 병합**
리스트 형태로 여러 개의 컬럼명을 `on` 파라미터에 전달하여, 여러 조건을 동시에 만족하는 행을 기준으로 병합할 수 있습니다.
```python
df_multi_key_left = pd.DataFrame({
    'key1': ['K0', 'K0', 'K1', 'K2'],
    'key2': ['A', 'B', 'A', 'B'],
    'data1': [1, 2, 3, 4]
})
df_multi_key_right = pd.DataFrame({
    'key1': ['K0', 'K1', 'K1', 'K2'],
    'key2': ['A', 'A', 'B', 'B'],
    'data2': [5, 6, 7, 8]
})

# key1과 key2가 모두 일치하는 경우에만 병합
merged_multi_key = pd.merge(df_multi_key_left, df_multi_key_right, on=['key1', 'key2'])
print("\n---" + " 다중 키 기준 병합 " + "---")
print(merged_multi_key)
```

### 2.3. `join()` - 인덱스 기반 조인

`DataFrame.join()` 메서드는 `merge()`를 기반으로 만들어진, **인덱스 기반**의 병합을 더욱 편리하게 수행하기 위한 함수입니다. `merge()`로도 인덱스 기반 조인을 할 수 있지만, `join()`은 더 간결한 문법을 제공합니다.

**`join()` vs `merge()` 핵심 차이**
*   **기본 기준**: `join()`은 호출하는 `DataFrame`의 **인덱스**를 기본 조인 키로 사용합니다. `merge()`는 컬럼을 기본 기준으로 사용합니다.
*   **기본 조인 방식**: `join()`은 `how='left'`가 기본값입니다. `merge()`는 `how='inner'`가 기본값입니다.
*   **문법 형태**: `join()`은 `DataFrame`의 메서드(`df1.join(df2)`)이고, `merge()`는 주로 Pandas의 최상위 함수(`pd.merge(df1, df2)`)로 사용됩니다.

> **결론**: `df1.join(df2)`는 `pd.merge(df1, df2, left_index=True, right_index=True, how='left')`와 거의 동일하게 동작합니다.

--- 

**다양한 `join` 활용법**

**예제 데이터**
```python
df_left = pd.DataFrame(
    {'A': ['A0', 'A1', 'A2'], 'B': ['B0', 'B1', 'B2']},
    index=pd.Index(['K0', 'K1', 'K2'], name='key')
)

df_right = pd.DataFrame(
    {'C': ['C0', 'C1'], 'D': ['D0', 'D1']},
    index=pd.Index(['K0', 'K1'], name='key')
)
```

**1. 인덱스-대-인덱스 조인 (기본)**
가장 기본적인 형태로, 두 `DataFrame`의 인덱스를 기준으로 병합합니다.
```python
# df_left의 인덱스를 기준으로 df_right를 조인 (left join)
index_join = df_left.join(df_right)
print("--- 기본 인덱스 조인 (Left Join) ---")
print(index_join)

# how='inner'를 사용하여 공통 인덱스만 남기기
inner_index_join = df_left.join(df_right, how='inner')
print("\n--- Inner 인덱스 조인 ---")
print(inner_index_join)
```

**2. 컬럼-대-인덱스 조인 (`on` 파라미터)**
`join`의 강력한 기능 중 하나로, 호출하는 `DataFrame`의 **특정 컬럼**과 상대방 `DataFrame`의 **인덱스**를 기준으로 병합할 수 있습니다.

```python
df_left_on = pd.DataFrame({
    'key_col': ['K0', 'K1', 'K2', 'K0'],
    'data': [1, 2, 3, 4]
})

# df_left_on의 'key_col'과 df_right의 인덱스를 기준으로 조인
col_to_index_join = df_left_on.join(df_right, on='key_col')
print("\n--- 컬럼-대-인덱스 조인 ---")
print(col_to_index_join)
```
*`df_left_on`의 'K0' 키가 두 개이므로, `df_right`의 'K0' 인덱스에 해당하는 행이 두 번 매칭되어 나타납니다.*

**3. 여러 개의 DataFrame을 동시에 조인**
`join` 메서드는 리스트를 전달하여 여러 개의 `DataFrame`을 한 번에 조인할 수 있는 편리함을 제공합니다.
```python
df_another = pd.DataFrame({'F': ['F0', 'F2']}, index=['K0', 'K2'])

# df_right와 df_another를 df_left에 동시에 조인
multi_join = df_left.join([df_right, df_another])
print("\n--- 다중 DataFrame 조인 ---")
print(multi_join)
```

**4. 중복 컬럼명 처리 (`lsuffix`, `rsuffix`)**
`merge`의 `suffixes`와 동일한 역할을 합니다. 조인하는 `DataFrame` 간에 인덱스를 제외한 컬럼명이 겹칠 경우, 접미사를 붙여 구분합니다.
```python
df_left_suffix = pd.DataFrame({'A': [1, 2]}, index=['K0', 'K1'])
df_right_suffix = pd.DataFrame({'A': [3, 4]}, index=['K0', 'K1'])

# 'A' 컬럼이 중복되므로 lsuffix, rsuffix 사용
suffix_join = df_left_suffix.join(df_right_suffix, lsuffix='_left', rsuffix='_right')
print("\n--- 접미사를 이용한 중복 컬럼 처리 ---")
print(suffix_join)
```
`join`은 특히 인덱스가 중요한 시계열 데이터나, 여러 데이터 소스를 인덱스 기준으로 빠르게 통합할 때 매우 유용합니다.
```
