## 1. 중복 데이터 처리 개요

중복 데이터(Duplicate Data)는 데이터셋 내에 동일하거나 거의 동일한 레코드(행)가 여러 번 나타나는 것을 의미합니다. 이는 데이터 수집 과정의 오류, 데이터 통합 문제, 또는 시스템의 결함 등으로 인해 발생할 수 있습니다. 중복 데이터는 데이터 분석 및 머신러닝 모델링 과정에서 다양한 문제를 야기할 수 있으므로, 적절하게 처리하는 것이 필수적입니다.

### 1.1. 왜 중복 데이터를 처리해야 하는가?

중복 데이터는 데이터 분석 및 머신러닝 모델링 과정에서 다음과 같은 문제를 야기할 수 있습니다.

*   **통계 분석 왜곡**: 중복된 데이터는 통계량(예: 평균, 합계, 빈도)을 부풀려 실제 데이터의 분포나 특성을 왜곡할 수 있습니다. 예를 들어, 특정 고객의 구매 기록이 중복되어 있다면, 총 구매액이나 구매 횟수가 실제보다 과대평가될 수 있습니다.
*   **모델 학습 방해**: 머신러닝 모델은 중복된 데이터를 실제와 다른 패턴으로 인식하여 과적합(Overfitting)될 위험이 있습니다. 특히 중복된 데이터가 특정 클래스에 편중되어 있다면, 모델이 해당 클래스를 더 잘 예측하는 것처럼 보일 수 있습니다.
*   **데이터 저장 효율성 저하**: 불필요한 중복 데이터는 저장 공간을 낭비하고, 데이터베이스 쿼리나 파일 로딩 속도를 저하시킬 수 있습니다.
*   **결과 해석의 어려움**: 중복 데이터가 많다면 분석 결과의 신뢰성을 떨어뜨리고, 비즈니스 의사결정에 잘못된 정보를 제공할 수 있습니다.

따라서 효과적인 데이터 분석을 위해서는 이러한 중복 데이터를 상황과 분석 목적에 맞게 탐지하고, 제거하는 전처리 과정이 필수적입니다.

## 2. 중복 데이터 탐지 (`duplicated`)

Pandas의 `duplicated()` 메서드는 `DataFrame` 또는 `Series` 내에서 중복된 행 또는 값을 탐지하여 불리언 `Series`를 반환합니다. 이 메서드는 중복 데이터 처리의 첫걸음입니다.

```python
import pandas as pd
import numpy as np

# 예시 DataFrame 생성
df_dup = pd.DataFrame({
    'col1': ['A', 'B', 'A', 'C', 'B', 'A'],
    'col2': [1, 2, 1, 3, 2, 1],
    'col3': ['X', 'Y', 'Z', 'W', 'Y', 'X']
})
print("--- 원본 DataFrame ---")
print(df_dup)
```

### 2.1. `duplicated()` 함수 개요

`duplicated(subset=None, keep='first')`

*   **`subset` (선택)**: 중복을 확인할 컬럼(들)을 지정합니다. 기본값은 `None`이며, 이 경우 모든 컬럼을 기준으로 중복을 확인합니다. 특정 컬럼의 조합이 중복될 때만 중복으로 간주하고 싶을 때 유용합니다.
*   **`keep` (선택)**: 중복된 값들 중에서 어떤 것을 `False`(고유한 것으로 간주)로 남길지 지정합니다.
    *   `'first'` (기본값): 첫 번째로 나타나는 중복 값은 `False`로, 나머지는 `True`로 표시합니다.
    *   `'last'`: 마지막으로 나타나는 중복 값은 `False`로, 나머지는 `True`로 표시합니다.
    *   `False`: 모든 중복 값을 `True`로 표시합니다.

### 2.2. `duplicated()` 활용 예시

**1. 모든 컬럼을 기준으로 중복 탐지 (기본값)**

```python
print("
--- df.duplicated(): 모든 컬럼 기준 중복 탐지 (keep='first') ---")
print(df_dup.duplicated())
# 결과:
# 0    False  (A,1,X) - 첫 등장
# 1    False  (B,2,Y) - 첫 등장
# 2    False  (A,1,Z) - 첫 등장
# 3    False  (C,3,W) - 첫 등장
# 4     True  (B,2,Y) - 1번 행과 중복
# 5     True  (A,1,X) - 0번 행과 중복
```

**2. 특정 컬럼을 기준으로 중복 탐지 (`subset`)**

```python
print("
--- df.duplicated(subset=['col1']): 'col1' 기준 중복 탐지 ---")
print(df_dup.duplicated(subset=['col1']))
# 'A'는 0, 2, 5번 행에, 'B'는 1, 4번 행에 중복
# 0    False
# 1    False
# 2     True  (A)
# 3    False
# 4     True  (B)
# 5     True  (A)
```

**3. 중복된 모든 값 표시 (`keep=False`)**

```python
print("
--- df.duplicated(keep=False): 모든 중복 값 표시 ---")
print(df_dup.duplicated(keep=False))
# 0     True  (A,1,X) - 5번 행과 중복
# 1     True  (B,2,Y) - 4번 행과 중복
# 2    False  (A,1,Z) - 고유
# 3    False  (C,3,W) - 고유
# 4     True  (B,2,Y) - 1번 행과 중복
# 5     True  (A,1,X) - 0번 행과 중복
```

**4. 중복된 행의 개수 확인**

`sum()` 메서드를 `duplicated()`의 결과에 적용하면 중복된 행의 총 개수를 알 수 있습니다.

```python
print(f"
중복된 행의 총 개수 (keep='first' 기준): {df_dup.duplicated().sum()}")
print(f"중복된 행의 총 개수 (keep=False 기준, 즉 모든 중복): {df_dup.duplicated(keep=False).sum()}")
```

## 3. 중복 데이터 제거 (`drop_duplicates`)

`duplicated()` 메서드로 중복된 데이터를 탐지한 후, `drop_duplicates()` 메서드를 사용하여 실제로 중복된 행을 `DataFrame`에서 제거합니다.

### 3.1. `drop_duplicates()` 함수 개요

`drop_duplicates(subset=None, keep='first', inplace=False, ignore_index=False)`

*   **`subset` (선택)**: 중복을 확인할 컬럼(들)을 지정합니다. 기본값은 `None`이며, 이 경우 모든 컬럼을 기준으로 중복을 확인합니다.
*   **`keep` (선택)**: 중복된 값들 중에서 어떤 것을 남길지 지정합니다.
    *   `'first'` (기본값): 첫 번째로 나타나는 중복 값만 남기고, 나머지는 제거합니다.
    *   `'last'`: 마지막으로 나타나는 중복 값만 남기고, 나머지는 제거합니다.
    *   `False`: 모든 중복 값을 제거합니다 (즉, 고유한 값만 남깁니다).
*   **`inplace` (선택)**: `True`로 설정 시 원본 `DataFrame`을 직접 수정합니다. 기본값은 `False`이며, 이 경우 중복이 제거된 새로운 `DataFrame`을 반환합니다. (최근 Pandas 버전에서는 `inplace=True` 사용을 권장하지 않습니다.)
*   **`ignore_index` (선택)**: `True`로 설정 시 중복 제거 후 `DataFrame`의 인덱스를 0부터 시작하는 새로운 정수 인덱스로 재설정합니다. 기본값은 `False`이며, 이 경우 기존 인덱스를 유지합니다.

### 3.2. `drop_duplicates()` 활용 예시

**1. 모든 컬럼을 기준으로 중복 제거 (기본값)**

```python
print("--- 원본 DataFrame ---")
print(df_dup)

print("
--- df.drop_duplicates(): 모든 컬럼 기준 중복 제거 (keep='first') ---")
print(df_dup.drop_duplicates())
# (A,1,X)와 (B,2,Y)의 첫 등장만 남고, 나머지는 제거됨
```

**2. 특정 컬럼을 기준으로 중복 제거 (`subset`)**

```python
print("
--- df.drop_duplicates(subset=['col1']): 'col1' 기준 중복 제거 ---")
print(df_dup.drop_duplicates(subset=['col1']))
# 'col1'의 고유값 'A', 'B', 'C' 중 첫 등장만 남음
```

**3. 중복된 값 중 마지막 값 남기기 (`keep='last'`)**

```python
print("
--- df.drop_duplicates(keep='last'): 마지막 중복 값 남기기 ---")
print(df_dup.drop_duplicates(keep='last'))
# (A,1,X)의 마지막 등장 (5번 행)과 (B,2,Y)의 마지막 등장 (4번 행)이 남음
```

**4. 중복된 모든 값 제거 (`keep=False`)**

```python
print("
--- df.drop_duplicates(keep=False): 모든 중복 값 제거 ---")
print(df_dup.drop_duplicates(keep=False))
# (A,1,X)와 (B,2,Y)는 모두 중복이므로 제거되고, 고유한 (A,1,Z)와 (C,3,W)만 남음
```

**5. 중복 제거 후 인덱스 재설정 (`ignore_index=True`)**

```python
print("
--- df.drop_duplicates(ignore_index=True): 중복 제거 후 인덱스 재설정 ---")
print(df_dup.drop_duplicates(ignore_index=True))
# 인덱스가 0, 1, 2, 3으로 새로 부여됨
```

## 4. 중복 데이터 처리 모범 사례 및 고려사항

중복 데이터 처리는 데이터 분석의 중요한 단계이며, 올바른 전략은 분석 결과의 신뢰성과 모델의 성능에 큰 영향을 미칩니다.

1.  **중복의 정의 명확화**: '중복'의 기준을 명확히 정의해야 합니다. 모든 컬럼이 일치해야 중복인지, 아니면 특정 식별자 컬럼(예: `user_id`, `order_id`)만 일치해도 중복으로 볼 것인지 결정해야 합니다. `subset` 파라미터를 사용하여 이 기준을 명시합니다.
2.  **중복 데이터의 원인 파악**: 중복 데이터가 왜 발생했는지 이해하는 것이 중요합니다. 데이터 수집 오류, 시스템 문제, 데이터 통합 과정의 문제 등 원인에 따라 재발 방지 대책을 세울 수 있습니다.
3.  **`keep` 파라미터 신중하게 선택**: `keep='first'`, `'last'`, `False` 중 어떤 옵션을 사용할지는 분석 목적과 데이터의 특성에 따라 달라집니다.
    *   `'first'` 또는 `'last'`: 중복된 레코드 중 하나만 남기고 싶을 때 사용합니다. 시간 순서가 중요한 데이터에서는 `first` 또는 `last`가 의미를 가질 수 있습니다.
    *   `False`: 모든 중복된 레코드를 제거하고 싶을 때 사용합니다. 이는 데이터셋에 완전히 고유한 레코드만 남기고자 할 때 적합합니다.
4.  **데이터 손실 고려**: 중복 데이터 제거는 데이터 손실을 야기합니다. 제거하기 전에 중복된 데이터의 양과 특성을 충분히 탐색하고, 제거로 인해 중요한 정보가 손실되지 않는지 확인해야 합니다.
5.  **`inplace=True` 사용 주의**: `drop_duplicates()` 사용 시 `inplace=True` 옵션은 원본 `DataFrame`을 직접 수정합니다. 이는 메서드 체이닝을 방해하고 예상치 못한 부작용을 일으킬 수 있으므로, 새로운 `DataFrame`을 반환받아 재할당하는 것을 권장합니다.
6.  **인덱스 재설정 고려**: `ignore_index=True`를 사용하여 중복 제거 후 인덱스를 재설정하면, 인덱스가 연속적인 정수형으로 깔끔하게 정리되어 후속 작업에 편리할 수 있습니다.

중복 데이터 처리는 데이터의 품질을 높이고 분석의 신뢰성을 확보하는 데 필수적인 과정입니다.
