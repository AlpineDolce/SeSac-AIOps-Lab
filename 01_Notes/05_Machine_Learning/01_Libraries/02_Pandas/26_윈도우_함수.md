### 1. 윈도우 함수란?

윈도우 함수(Window Functions)는 순서가 있는 데이터(주로 시계열)의 특정 부분 집합, 즉 **"윈도우(창문)"** 위에서 통계량을 계산하는 강력한 기능입니다. 이 창문을 데이터 위에서 움직여가며 계산을 수행함으로써, 데이터의 추세를 파악하거나 노이즈를 줄이는 등 다양한 분석을 수행할 수 있습니다.

**핵심 비유: 창문으로 긴 그림을 훑어보기**

아주 긴 파노라마 그림(전체 데이터)이 있다고 상상해 보세요. 이 그림을 한 번에 보는 대신, **일정한 크기의 창문(윈도우)**을 통해 부분부분 훑어본다고 가정합시다.

-   **`rolling()` (이동 윈도우)**: 창문의 크기를 **고정**하고(예: 7일치), 그림의 왼쪽 끝에서 오른쪽 끝으로 창문을 **일정하게 이동시키며** 창문 안의 그림만 분석하는 것과 같습니다. 이를 통해 그림의 단기적인 패턴이나 변화를 파악할 수 있습니다.
-   **`expanding()` (확장 윈도우)**: 창문의 왼쪽 끝은 그림의 시작점에 **고정**하고, 오른쪽 끝을 계속 확장하며 **점점 더 넓은 영역**을 보는 것과 같습니다. 이는 그림이 시작된 이래로 현재까지의 누적된 특징을 분석하는 데 사용됩니다.

**윈도우 함수의 주요 역할**

1.  **데이터 평활화 (Smoothing)**: 데이터에 포함된 단기적인 변동이나 노이즈(noise)를 줄여 전체적인 추세를 더 명확하게 만듭니다. 이동 평균이 대표적인 예입니다.
2.  **추세 파악 (Trend Identification)**: 데이터가 장기적으로 상승하는지, 하락하는지, 또는 일정한 수준을 유지하는지 등의 추세를 파악하는 데 도움을 줍니다.
3.  **계절성 및 이상치 탐지 (Seasonality & Anomaly Detection)**: 원본 데이터와 윈도우 함수를 적용한 결과를 비교하여 주기적인 패턴(계절성)이나 갑자기 튀는 값(이상치)을 발견할 수 있습니다.
4.  **누적 분석 (Cumulative Analysis)**: `expanding`을 사용하여 특정 시점까지의 누적 합계, 누적 평균 등을 계산하여 전체적인 성과를 추적합니다.

Pandas에서는 이러한 윈도우 함수를 `rolling()`, `expanding()`, `ewm()` 세 가지 주요 메서드를 통해 제공하며, 각기 다른 특성과 활용 사례를 가집니다.

### 2. `rolling()` (이동 윈도우 함수)

`rolling()`은 **고정된 크기의 창(window)**이 데이터를 따라 순서대로 **이동**하며 연산을 수행하는 가장 대표적인 윈도우 함수입니다. 주로 데이터의 단기적인 추세를 보거나 노이즈를 제거하는 '평활화'에 사용됩니다.

---
**주요 파라미터 상세 설명**

-   `window`: **(필수)** 창의 크기를 지정합니다.
    -   **정수**: `window=3` 처럼 지정하면, 3개의 데이터 포인트를 하나의 창에 포함합니다.
    -   **시간 오프셋 문자열**: 인덱스가 `DatetimeIndex`일 때, `'3D'`, `'2H'` 와 같이 시간 기반의 창을 지정할 수 있습니다. 이는 데이터가 불규칙한 간격으로 존재할 때 매우 유용합니다.
-   `min_periods`: 창 내에서 연산을 수행하기 위해 필요한 **최소 데이터 개수**. 지정하지 않으면 `window` 값과 동일하게 적용됩니다. 예를 들어 `window=5, min_periods=3` 이면, 창 안에 데이터가 3개만 있어도 연산을 수행하고, 2개 이하면 `NaN`을 반환합니다.
-   `center`: 계산된 결과의 레이블을 창의 중앙에 위치시킬지 여부. 기본값은 `False`로, 창의 맨 오른쪽에 결과가 위치합니다. `center=True`로 하면 시각화 시 추세선이 원본 데이터의 중앙에 그려져 위상 지연(phase shift)이 줄어드는 효과가 있습니다.
-   `on`: `DataFrame`에서 시계열 인덱스가 아닌 특정 컬럼을 기준으로 `rolling`을 적용하고 싶을 때 해당 컬럼명을 지정합니다.

---
**다양한 활용 예시**

```python
import pandas as pd
import numpy as np

# 예시 시계열 데이터 (일부 날짜가 누락됨)
s = pd.Series(
    [10, 15, 12, 18, 25, 22, 28, 30],
    index=pd.to_datetime(['2023-01-01', '2023-01-02', '2023-01-03', '2023-01-05',
                          '2023-01-06', '2023-01-07', '2023-01-10', '2023-01-11'])
)
print("Original Series:\n", s)
```

**1. 기본 이동 평균 및 이동 합계**
```python
# 3개 데이터 포인트를 사용한 이동 평균
rolling_mean = s.rolling(window=3).mean()
print("\n3-point Rolling Mean:\n", rolling_mean)

# 3개 데이터 포인트를 사용한 이동 합계
rolling_sum = s.rolling(window=3).sum()
print("\n3-point Rolling Sum:\n", rolling_sum)
```

**2. 시간 기반 윈도우**
데이터의 인덱스가 불규칙적일 때(예: 주말 데이터 누락), 시간 기반 윈도우를 사용하면 실제 시간 간격을 기준으로 연산할 수 있습니다.
```python
# 3일(Day)을 기준으로 하는 이동 합계
# 각 날짜를 기준으로 과거 3일(자신 포함) 내의 모든 데이터 합산
rolling_3d_sum = s.rolling(window='3D').sum()
print("\n3-Day Rolling Sum:\n", rolling_3d_sum)
```
*예를 들어, '2023-01-05'의 결과(45.0)는 '01-03'(12), '01-05'(18) 두 값의 합입니다. ('01-04'는 없으므로 제외)*

**3. 이동 변동성 및 사용자 정의 함수**
이동 표준편차로 변동성을 측정하거나, `apply`를 사용하여 직접 정의한 함수를 적용할 수 있습니다.
```python
# 3개년 이동 표준편차 (변동성)
rolling_std = s.rolling(window=3).std()
print("\n3-point Rolling Std Dev (Volatility):\n", rolling_std)

# 3개년 이동 최대값-최소값 범위 (range)
range_func = lambda x: x.max() - x.min()
rolling_range = s.rolling(window=3).apply(range_func)
print("\n3-point Rolling Range (apply):\n", rolling_range)
```
`rolling`은 시계열 분석의 가장 기본적이면서도 중요한 도구로, 데이터의 국소적인(local) 패턴과 추세를 파악하는 데 핵심적인 역할을 합니다.


### 3. `expanding()` (확장 윈도우 함수)

`expanding()`은 `rolling()`과 달리 윈도우의 크기가 고정되어 있지 않습니다. 대신, 윈도우가 데이터의 **시작점에서부터 현재 데이터 포인트까지 계속 확장**됩니다. 이 특성 때문에 `expanding`은 주로 **누적(Cumulative)** 통계량을 계산하는 데 사용됩니다.

**`rolling()` vs `expanding()` 동작 방식 비교**

| 데이터 | `rolling(window=3).sum()` | `expanding().sum()` | 설명 |
| :--- | :--- | :--- | :--- |
| 2 | NaN | 2 | **expanding**: 첫 번째 값 (2) |
| 8 | NaN | 10 | **expanding**: 2 + 8 |
| 5 | 15 (2+8+5) | 15 | **expanding**: 2 + 8 + 5 |
| 9 | 22 (8+5+9) | 24 | **expanding**: 15 + 9 |
| 4 | 18 (5+9+4) | 28 | **expanding**: 24 + 4 |

--- 
**주요 파라미터 및 활용 예시**

-   `min_periods`: 연산을 수행하기 위해 필요한 최소 데이터 개수. 기본값은 `1`입니다.

```python
# 예시를 위한 새로운 Series 생성
s_exp = pd.Series([2, 8, 5, 9, 4])
print("Original Series for Expanding:", s_exp)
```

**1. 누적 합계 (Cumulative Sum)**
데이터가 시작된 이래로 현재까지의 총합을 계산합니다. `cumsum()` 메서드와 동일한 결과를 반환합니다.
```python
# 확장 윈도우를 이용한 누적 합계
expanding_sum = s_exp.expanding().sum()
print("\nExpanding Sum:", expanding_sum)

# cumsum() 메서드 결과와 비교
print("\nCumulative Sum (cumsum):
", s_exp.cumsum())
```

**2. 누적 평균 및 누적 최대/최소값**
시간이 지남에 따라 평균값이 어떻게 변하는지, 또는 현재까지의 최고/최저 기록이 얼마인지 추적할 때 유용합니다.
```python
# 누적 평균
expanding_mean = s_exp.expanding().mean()
print("\nExpanding Mean:", expanding_mean)

# 누적 최대값 (High-water mark)
expanding_max = s_exp.expanding().max()
print("\nExpanding Max (High-water mark):
", expanding_max)
```

**3. 사용자 정의 함수와 함께 사용 (`apply`)**
`expanding` 윈도우에 `apply`를 적용하여 직접 정의한 누적 함수를 계산할 수 있습니다.
```python
# 누적 양수 개수 계산
count_positives = lambda x: (x > 0).sum()
expanding_pos_count = s_exp.expanding().apply(count_positives)
print("\nExpanding Count of Positive Numbers:
", expanding_pos_count)
```
`expanding`은 전체 기간에 걸쳐 데이터의 성장, 축적, 변화 추이를 분석하는 데 매우 효과적인 도구입니다.


### 4. `ewm()` (지수 가중 이동 윈도우 함수)

`ewm()`은 **지수 가중(Exponentially Weighted)** 이동 통계량을 계산하는 함수입니다. 단순 이동 평균(`rolling`)이 창 안의 모든 데이터에 동일한 가중치를 부여하는 것과 달리, `ewm`은 **최신 데이터에 가장 큰 가중치를 부여**하고, 과거 데이터일수록 가중치를 지수적으로 감소시킵니다.

이러한 특성 때문에 `ewm`은 갑작스러운 변동에 대한 민감도를 줄이면서도, 최근의 추세를 더 잘 반영하는 부드러운(smooth) 시계열을 만드는 데 매우 효과적입니다.

**핵심 개념: 가중치**
- `rolling(window=3).mean()`: `(값1 * 1/3) + (값2 * 1/3) + (값3 * 1/3)` -> 모든 가중치가 동일
- `ewm(span=3).mean()`: `(값1 * w1) + (값2 * w2) + (값3 * w3)` -> `w3 > w2 > w1` (최신 값일수록 가중치가 높음)

---
**주요 파라미터 상세 설명**

가중치가 얼마나 빨리 감소할지를 결정하는 파라미터가 가장 중요하며, 보통 아래 세 가지 중 하나를 선택하여 사용합니다.

-   `span` (기간): 가장 직관적인 파라미터. 대략 "N일 지수 이동 평균"과 비슷한 의미로 사용됩니다. `span` 값이 클수록 가중치 감소가 완만해져 더 부드러운 곡선(느린 반응)이 되고, 작을수록 가파른 감소(빠른 반응)를 보입니다.
-   `com` (질량 중심, Center of Mass): 물리학적 개념에서 유래한 파라미터로, `span = 1 + 2 * com` 관계가 성립합니다.
-   `halflife` (반감기): 가중치가 절반으로 줄어드는 데 걸리는 기간을 의미합니다.
-   `adjust`: 계산 초기에 데이터 포인트가 적을 때, 불균형을 보정할지 여부를 결정합니다. 기본값은 `True`이며, 대부분의 경우 그대로 사용하는 것이 좋습니다.

---
**`rolling` vs `ewm` 비교**

```python
# 예시를 위한 Series 생성
s_ewm = pd.Series([10, 20, 15, 25, 30], index=pd.to_datetime(['2023-01-01', '2023-01-02', '2023-01-03', '2023-01-04', '2023-01-05']))
print("Original Series for EWM:\n", s_ewm)

# 3일 단순 이동 평균 (SMA)
sma_3 = s_ewm.rolling(window=3).mean()
print("\n3-day Simple Moving Average (SMA):\n", sma_3)

# 3일 지수 가중 이동 평균 (EWMA)
ewma_3 = s_ewm.ewm(span=3).mean()
print("\n3-day Exponentially Weighted Moving Average (EWMA):\n", ewma_3)
```
**결과 분석**:
- 2023-01-03: SMA는 (10+20+15)/3 = 15.0 입니다. EWMA는 15.71로, 최신 값인 15에 더 가깝습니다.
- 2023-01-04: 새로운 값 25가 들어왔습니다. SMA는 16.67 -> 20.0으로 변했지만, EWMA는 15.71 -> 20.35로 더 크게 반응합니다. 이는 EWMA가 최신 값인 25에 더 높은 가중치를 부여하기 때문입니다.

**`span` 값에 따른 변화**

`span` 값이 작을수록 최신 데이터에 더 민감하게 반응합니다.

```python
# span 값에 따른 EWMA 비교
ewma_span3 = s_ewm.ewm(span=3).mean()
ewma_span5 = s_ewm.ewm(span=5).mean()

df_compare = pd.DataFrame({
    'Original': s_ewm,
    'EWMA (span=3)': ewma_span3,
    'EWMA (span=5)': ewma_span5
})
print("\nComparison of EWMA with different spans:\n", df_compare)
```
`span=5`가 `span=3`보다 더 완만한(부드러운) 값을 가지는 것을 볼 수 있습니다. `ewm`은 금융 데이터 분석에서 주가 추세를 분석하거나, 노이즈가 많은 센서 데이터에서 안정적인 신호를 추출하는 등 고급 시계열 분석에 널리 사용됩니다.


### 5. 실무 활용 시나리오

윈도우 함수는 다양한 데이터 분석 분야에서 유용하게 사용됩니다. 각 함수의 특성이 특정 문제 상황을 해결하는 데 어떻게 도움이 되는지 구체적인 시나리오를 통해 알아보겠습니다.

**1. 금융 분석 (Financial Analysis)**

-   **추세 추종 전략 (`rolling`, `ewm`)**: 주식 가격이나 지수와 같은 금융 시계열 데이터에서 추세를 파악하는 것은 매우 중요합니다. 
    -   `rolling(window=20).mean()`: **20일 이동평균선(단순이동평균, SMA)**을 계산하여 주가의 장기적인 추세를 파악합니다. 
    -   `ewm(span=12).mean()`: **12일 지수이동평균(EMA)**을 계산합니다. EMA는 최근 가격 변화에 더 민감하게 반응하므로, 단기적인 추세 변화를 포착하거나 골든크로스/데드크로스 같은 매매 신호를 만드는 데 자주 사용됩니다.

-   **변동성 측정 (`rolling`)**: 자산의 리스크를 평가하기 위해 가격 변동성을 측정합니다.
    -   `rolling(window=20).std()`: **20일 이동 표준편차**를 계산하여 특정 기간의 변동성을 파악합니다. 이는 볼린저 밴드(Bollinger Bands)의 핵심 구성 요소입니다.

**2. 센서 데이터 및 IoT 분석 (Sensor Data & IoT)**

-   **신호 평활화 (Signal Smoothing)**: 센서에서 수집된 데이터는 노이즈가 많은 경우가 많습니다.
    -   `rolling(window=10).mean()`: 10개 측정값의 이동 평균을 계산하여 센서 데이터의 무작위 노이즈를 제거하고, 더 안정적이고 의미 있는 신호를 추출할 수 있습니다.

-   **누적 사용량 모니터링 (`expanding`)**: 장비의 총 가동 시간이나 누적 에너지 소비량을 추적합니다.
    -   `expanding().sum()`: 장비가 가동된 이후 현재까지의 총 에너지 소비량을 계산하여 장비의 유지보수 시점을 예측하거나 에너지 효율을 분석하는 데 사용합니다.

**3. 판매 및 수요 예측 (Sales and Demand Forecasting)**

-   **단기 판매 추세 분석 (`rolling`)**: 일별 또는 주별 판매 데이터의 변동을 완화하고 추세를 파악합니다.
    -   `rolling(window=7).mean()`: **7일 이동 평균 판매량**을 계산하여 요일별 변동성을 줄이고, 주간 판매 추세를 명확하게 파악할 수 있습니다.

-   **프로모션 기간 총 판매량 추적 (`expanding`)**: 특정 이벤트나 프로모션 기간 동안의 누적 실적을 모니터링합니다.
    -   `expanding().sum()`: 프로모션 시작일로부터 현재까지의 누적 판매량을 실시간으로 추적하여 목표 달성률을 계산하는 데 활용할 수 있습니다.

**4. 품질 관리 (Quality Control)**

-   **공정 이상 감지 (`rolling`)**: 생산 라인에서 수집되는 품질 지표(예: 제품 무게, 불량률)를 모니터링하여 공정의 안정성을 평가합니다.
    -   `rolling(window=50).mean()`: **최근 50개 제품의 불량률 이동 평균**을 계산하고, 이 값이 관리 기준선을 벗어나는지 실시간으로 감시하여 생산 공정의 문제를 조기에 발견할 수 있습니다.

### 6. 요약 및 모범 사례

`rolling`, `expanding`, `ewm`은 각기 다른 방식으로 윈도우를 정의하므로, 분석 목적에 맞는 함수를 선택하는 것이 매우 중요합니다. 아래 요약과 모범 사례를 통해 올바른 함수를 선택하고 효과적으로 활용하는 방법을 숙지하세요.

**한눈에 보는 윈도우 함수 선택 가이드**

| 구분 | `rolling()` | `expanding()` | `ewm()` |
| :--- | :--- | :--- | :--- |
| **핵심 개념** | **고정된 크기**의 창을 이동 | 창이 **점점 확장**됨 | **최신 데이터에 가중치**를 부여 |
| **주요 목적** | 단기 추세 분석, 데이터 평활화 | **누적** 통계량 계산 | 최근 변화에 민감한 추세 분석 |
| **언제 사용할까?** | "최근 7일간의 평균은?" | "서비스 시작 후 현재까지의 총매출은?" | "최근 주가 변동을 반영한 추세선은?" |
| **핵심 파라미터**| `window` (창 크기) | `min_periods` (최소 데이터 수) | `span` 또는 `halflife` (가중치 감소율) |

---

**윈도우 함수 활용을 위한 모범 사례 (Best Practices)**

1.  **데이터 정렬은 필수**
    윈도우 함수를 적용하기 전, 반드시 데이터를 시간 순서나 분석하려는 순서에 맞게 **정렬(sort)**해야 합니다. 정렬되지 않은 데이터에 윈도우 함수를 적용하면, 창에 포함되는 데이터의 순서가 뒤죽박죽이 되어 의미 없는 결과가 나옵니다.
    ```python
    # 시계열 인덱스를 기준으로 반드시 정렬합니다.
    df_sorted = df.sort_index()
    ```

2.  **초기 `NaN` 값 처리**
    `rolling`이나 `ewm` 연산의 결과는 필연적으로 시작 부분에 `NaN` 값을 포함하게 됩니다. (창 크기를 채울 데이터가 부족하기 때문) 후속 분석이나 머신러닝 모델에 사용하기 전에 이 결측치들을 어떻게 처리할지 결정해야 합니다.
    -   `dropna()`: `NaN` 값을 가진 행을 제거합니다.
    -   `fillna()`: 특정 값(예: 0)이나, 다른 값(예: 전체 평균)으로 채웁니다.

3.  **시간 기반 윈도우의 적극적인 활용**
    시계열 데이터의 간격이 불규칙하다면(예: 주말이나 공휴일 데이터 누락), 정수 기반 `window=7` 보다 시간 기반 `window='7D'`를 사용하는 것이 훨씬 정확하고 안정적인 결과를 제공합니다. 이는 실제 시간의 흐름을 기준으로 윈도우를 구성하기 때문입니다.

4.  **시각화를 통한 결과 검증**
    윈도우 함수를 적용한 후에는 반드시 원본 데이터와 결과를 함께 시각화하여 의도한 대로 동작했는지 확인하는 습관을 들이는 것이 좋습니다. 그래프를 통해 파라미터(예: `window` 크기, `span` 값)가 결과에 미치는 영향을 직관적으로 파악하고 최적의 값을 찾을 수 있습니다.
    ```python
    import matplotlib.pyplot as plt

    plt.figure(figsize=(12, 6))
    original_series.plot(label='Original', style='--')
    rolling_series.plot(label='Rolling Mean')
    ewm_series.plot(label='EWM Mean')
    plt.legend()
    plt.show()
    ```

이러한 원칙들을 잘 따르면 윈도우 함수를 더욱 정확하고 효과적으로 활용하여 데이터에 숨겨진 의미 있는 패턴과 추세를 발견할 수 있습니다.
