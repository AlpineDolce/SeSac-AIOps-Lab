# 데이터 크롤링 도구: Selenium, BeautifulSoup 핵심 가이드

이 가이드는 파이썬의 주요 웹 크롤링 라이브러리인 Requests, BeautifulSoup, Selenium의 핵심 개념과 활용법을 상세히 다룹니다. 각 라이브러리의 특징, 설치 방법, 기본적인 데이터 추출부터 동적인 웹 페이지 제어까지 다양한 예제를 통해 설명하며, 실제 웹 데이터를 수집하고 분석하는 데 필요한 지식을 제공합니다.

---

### Part 1: 웹 크롤링 소개 및 기본

-   [**01_웹_크롤링_소개.md**](./01_웹_크롤링_소개.md): 웹 크롤링의 개념, 중요성, 윤리적 고려사항 및 파이썬 웹 크롤링 생태계를 이해합니다.
-   [**02_Requests_라이브러리.md**](./02_Requests_라이브러리.md): HTTP 요청을 보내는 Requests 라이브러리의 기본 사용법을 학습합니다.

### Part 2: 정적 웹 페이지 크롤링 (BeautifulSoup)

-   [**03_BeautifulSoup_소개_및_설치.md**](./03_BeautifulSoup_소개_및_설치.md): BeautifulSoup의 기본 개념과 설치 방법을 학습합니다.
-   [**04_BeautifulSoup_HTML_파싱.md**](./04_BeautifulSoup_HTML_파싱.md): HTML 문서 파싱 및 요소 탐색(`find`, `find_all`) 방법을 익힙니다.
-   [**05_BeautifulSoup_데이터_추출.md**](./05_BeautifulSoup_데이터_추출.md): 태그 속성, 텍스트, CSS 선택자(`select`)를 이용한 데이터 추출 방법을 학습합니다.

### Part 3: 동적 웹 페이지 크롤링 (Selenium)

-   [**06_Selenium_소개_및_설치.md**](./06_Selenium_소개_및_설치.md): Selenium의 기본 개념, 설치 방법 및 WebDriver 설정을 학습합니다.
-   [**07_Selenium_요소_찾기_및_클릭.md**](./07_Selenium_요소_찾기_및_클릭.md): 웹 요소 찾기(`find_element`, `find_elements`) 및 클릭, 텍스트 입력 등 상호작용 방법을 익힙니다.
-   [**08_Selenium_페이지_스크롤_대기.md**](./08_Selenium_페이지_스크롤_대기.md): 페이지 스크롤, 명시적/암시적 대기, 동적 콘텐츠 로딩 처리 방법을 학습합니다.
-   [**09_Selenium_팝업_프레임_처리.md**](./09_Selenium_팝업_프레임_처리.md): 팝업, 알림창, iframe 등 특수 요소 처리 방법을 다룹니다.

### Part 4: 고급 크롤링 기법 및 윤리

-   [**10_크롤링_성능_최적화.md**](./10_크롤링_성능_최적화.md): 병렬 처리, 비동기 크롤링, 캐싱 등 크롤링 성능 최적화 팁을 다룹니다.
-   [**11_우회_기술_및_로봇_배제.md**](./11_우회_기술_및_로봇_배제.md): User-Agent 변경, 프록시 사용, CAPTCHA 우회 등 고급 기술과 `robots.txt` 이해를 학습합니다.

-   [**13_크롤링_윤리_및_법적_고려사항.md**](./13_크롤링_윤리_및_법적_고려사항.md): 웹 크롤링 시 발생할 수 있는 윤리적, 법적 문제와 주의사항을 이해합니다.

-   [**14_실전_프로젝트_예제.md**](./14_실전_프로젝트_예제.md): 특정 웹사이트를 대상으로 한 실제 크롤링 프로젝트 예제를 통해 전체 워크플로우를 적용합니다.
-   [**15_크롤링_데이터_분석_활용.md**](./15_크롤링_데이터_분석_활용.md): 수집된 데이터를 Pandas, Matplotlib 등을 활용하여 분석하고 시각화하는 방법을 학습합니다.
