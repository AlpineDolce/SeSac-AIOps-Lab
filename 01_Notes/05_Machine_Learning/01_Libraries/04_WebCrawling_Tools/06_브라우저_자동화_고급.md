## 1. 페이지 속의 또 다른 페이지: iframe 전환

`<iframe>`은 웹 페이지 안에 또 다른 웹 페이지를 삽입하는 태그입니다. 지도, 외부 동영상, 광고 등이 주로 iframe으로 삽입됩니다. Selenium은 기본적으로 메인 페이지의 컨텍스트에서만 작동하므로, iframe 내부의 요소를 찾으려면 **컨텍스트를 해당 iframe으로 전환**해야 합니다.

**핵심 흐름:**
1.  `driver.switch_to.frame(iframe_요소_또는_id)`: 제어권을 원하는 iframe으로 넘깁니다.
2.  iframe 내부에서 원하는 요소 찾기 및 작업 수행
3.  `driver.switch_to.default_content()`: 작업 완료 후, 반드시 원래의 메인 페이지로 제어권을 되돌립니다.

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get("https://www.w3schools.com/tags/tryit.asp?filename=tryhtml_iframe")

# 1. iframe으로 컨텍스트 전환 (id 'iframeResult'를 가진 iframe)
WebDriverWait(driver, 10).until(EC.frame_to_be_available_and_switch_to_it((By.ID, "iframeResult")))

# 2. 이제 iframe 내부의 요소를 찾을 수 있음
iframe_h1 = driver.find_element(By.TAG_NAME, 'h1')
print(f"Iframe 내부의 H1 태그: {iframe_h1.text}")

# 3. 원래 페이지로 컨텍스트 복귀
driver.switch_to.default_content()

# 4. 이제 다시 메인 페이지의 요소를 찾을 수 있음
main_page_btn = driver.find_element(By.ID, "runbtn")
print(f"메인 페이지의 버튼 텍스트: {main_page_btn.text}")

driver.quit()
```

## 2. 여러 개의 창과 탭 다루기

링크를 클릭했을 때 새 탭이나 새 창이 열리는 경우, Selenium의 제어권은 여전히 원래의 창에 머물러 있습니다. 새 창을 제어하려면 명시적으로 제어권을 옮겨주어야 합니다.

- **`driver.window_handles`**: 현재 열려있는 모든 창의 고유 핸들(ID)을 리스트로 반환합니다.
- **`driver.switch_to.window(핸들)`**: 해당 핸들을 가진 창으로 제어권을 전환합니다.

```python
# ... (새 창을 여는 링크를 클릭한 후)

# 현재 열린 모든 창의 핸들을 가져옴 (리스트 형태)
all_windows = driver.window_handles
print(f"열린 창 핸들: {all_windows}")

# 원래 창 핸들
original_window = all_windows[0]
# 새 창 핸들
new_window = all_windows[1]

# 새 창으로 전환
driver.switch_to.window(new_window)
print(f"새 창 제목: {driver.title}")

# 새 창에서 작업 수행...
driver.close() # 현재 제어중인 새 창 닫기

# 다시 원래 창으로 돌아오기
driver.switch_to.window(original_window)
print(f"원래 창 제목: {driver.title}")
```

## 3. JavaScript 알림(Alert) 처리하기

`alert`, `confirm`, `prompt` 같은 JavaScript 알림창은 HTML 요소가 아니므로 `find_element`로 찾을 수 없습니다. 별도의 방법으로 제어해야 합니다.

```python
from selenium.webdriver.common.alert import Alert

# ... (알림창을 띄우는 동작 실행)

# 1. 알림창으로 컨텍스트 전환
alert = Alert(driver)

# 2. 알림창의 텍스트 가져오기
print(f"알림창 메시지: {alert.text}")

# 3. 확인(accept) 또는 취소(dismiss) 버튼 누르기
alert.accept()
# alert.dismiss()
```

## 4. 상황별 예외 처리로 견고성 높이기

크롤러는 언제든 예외적인 상황으로 실패할 수 있습니다. (e.g., 페이지 구조 변경, 네트워크 오류, 요소 로딩 실패) `try...except` 구문으로 이런 예외를 처리해주어야 갑작스럽게 멈추지 않는 안정적인 크롤러를 만들 수 있습니다.

**주요 Selenium 예외:**
- **`NoSuchElementException`**: `find_element`로 요소를 찾았는데 없을 때 발생합니다.
- **`TimeoutException`**: `WebDriverWait`가 지정된 시간 내에 조건을 만족하지 못했을 때 발생합니다. (가장 흔하고 중요!)
- **`ElementNotInteractableException`**: 요소는 찾았지만, 다른 요소에 가려져 있거나 비활성화되어 클릭/입력 등을 할 수 없을 때 발생합니다.

```python
from selenium.common.exceptions import TimeoutException, NoSuchElementException

# ... (driver 설정)

try:
    # WebDriverWait을 사용했으므로 TimeoutException을 주로 처리
    element = WebDriverWait(driver, 5).until(
        EC.presence_of_element_located((By.ID, "some-id"))
    )
    element.click()

except TimeoutException:
    print("에러: 5초 내에 요소를 찾지 못했습니다. 페이지 로딩이 느리거나 선택자가 변경되었을 수 있습니다.")

except ElementNotInteractableException:
    print("에러: 요소를 찾았지만 클릭할 수 없습니다. 다른 요소에 가려져 있는지 확인하세요.")

except Exception as e:
    print(f"예상치 못한 에러가 발생했습니다: {e}")

finally:
    # 에러 발생 여부와 관계없이 항상 브라우저를 종료
    driver.quit()
```

**핵심 요약:** 복잡한 웹 페이지를 안정적으로 다루려면 **iframe과 창 전환 메커니즘**을 반드시 이해해야 합니다. 또한 모든 자동화 로직은 **`try...except` 블록으로 감싸고, 발생 가능한 예외를 명시적으로 처리**하는 습관을 들여야 합니다.
