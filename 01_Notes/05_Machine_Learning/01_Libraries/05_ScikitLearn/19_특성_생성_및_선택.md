#### 1.2.2. 상호작용 특성 (Interaction Features)
**상호작용 특성(Interaction Features)**은 두 개 이상의 기존 특성을 곱하거나 조합하여 새로운 특성을 만드는 것입니다. 이는 특성들 간의 **상호작용 효과(Interaction Effect)**를 모델이 학습할 수 있도록 돕습니다. 예를 들어, 주택 가격 예측에서 '방 개수'와 '면적'이 단순히 합쳐지는 것보다, 이 둘을 곱한 '방 개수 * 면적'이라는 특성이 더 큰 의미를 가질 수 있습니다.

*   **필요성:** 많은 현실 세계의 현상들은 특성들이 독립적으로 작용하기보다는 서로 영향을 주고받으며 결과를 만들어냅니다. 선형 모델과 같은 단순한 모델은 이러한 상호작용을 자동으로 포착하지 못하므로, 상호작용 특성을 명시적으로 생성해주면 모델의 표현력을 높일 수 있습니다.
*   **`PolynomialFeatures` 활용:** `PolynomialFeatures` 변환기는 `interaction_only=True` 옵션을 통해 상호작용 특성만 생성할 수도 있습니다. 이 옵션을 사용하면 단일 특성의 거듭제곱 항($x_1^2, x_2^2$)은 생성되지 않고, 특성 간의 곱셈 항($x_1 x_2$)만 생성됩니다.

```python
from sklearn.preprocessing import PolynomialFeatures
import numpy as np

# 원본 특성 데이터 (이전 예시와 동일)
X = np.array([[1, 2],
              [3, 4]])

# interaction_only=True로 상호작용 특성만 생성
# degree=2: 2차항까지 고려하되, interaction_only=True이므로 x1*x2만 생성됩니다.
# include_bias=False: 절편 항을 생성하지 않습니다.
poly_interaction = PolynomialFeatures(degree=2, include_bias=False, interaction_only=True)
# fit_transform(): 훈련 데이터로부터 상호작용 특성 변환 규칙을 학습하고, 데이터를 변환합니다.
X_interaction = poly_interaction.fit_transform(X)
print("\n상호작용 특성 생성 후:\n", X_interaction)
# get_feature_names_out(): 생성된 특성들의 이름을 원래 특성 이름을 기반으로 반환합니다.
print("생성된 특성 이름:", poly_interaction.get_feature_names_out(['feature1', 'feature2']))
```

**상호작용 특성 사용 시 고려사항:**
*   **도메인 지식:** 어떤 특성들 간에 상호작용이 있을지 예측하는 데 도메인 지식이 매우 중요합니다.
*   **차원의 증가:** 상호작용 특성도 특성의 수를 증가시키므로, 과도하게 생성하면 차원의 저주 문제가 발생할 수 있습니다.
*   **모델 복잡도:** 상호작용 특성을 추가하면 모델의 복잡도가 증가하므로, 과적합을 방지하기 위한 정규화 기법을 함께 고려해야 합니다.


#### 1.2.3. 비닝/이산화 (Binning/Discretization)
**비닝(Binning)** 또는 **이산화(Discretization)**는 연속형 특성을 여러 개의 구간(bin)으로 나누어 범주형 특성으로 변환하는 기법입니다. 이는 모델이 비선형 관계를 학습하거나, 이상치의 영향을 줄이는 데 도움이 될 수 있습니다.

*   **필요성:**
    *   **비선형 관계 학습:** 선형 모델은 특성과 타겟 변수 간의 선형 관계만 학습할 수 있습니다. 비닝을 통해 비선형 관계를 구간별로 선형화하여 모델이 더 복잡한 패턴을 포착할 수 있도록 돕습니다.
    *   **이상치 영향 감소:** 극단적인 이상치가 있는 경우, 해당 이상치를 특정 구간에 포함시켜 이상치의 직접적인 영향을 줄일 수 있습니다.
    *   **모델의 견고성 증가:** 데이터의 미세한 변동에 모델이 덜 민감하게 반응하도록 하여 모델의 견고성을 높일 수 있습니다.
    *   **해석 용이성:** 연속형 특성을 몇 개의 의미 있는 범주로 나누면 모델의 결과를 더 쉽게 해석할 수 있습니다.
*   **`KBinsDiscretizer`:** Scikit-learn의 `KBinsDiscretizer`는 연속형 데이터를 이산화하는 데 사용됩니다.
    *   **`n_bins`:** 나눌 구간의 개수를 지정합니다.
    *   **`encode`:** 변환된 데이터를 어떤 형태로 반환할지 지정합니다 (`'ordinal'`은 정수 레이블, `'onehot'`은 원-핫 인코딩).
    *   **`strategy`:** 구간을 나누는 전략을 지정합니다.
        *   `'uniform'`: 모든 구간의 너비를 동일하게 합니다.
        *   `'quantile'`: 각 구간에 동일한 수의 샘플이 포함되도록 합니다 (분위수 기반).
        *   `'kmeans'`: K-평균 클러스터링을 사용하여 구간을 정의합니다.

```python
from sklearn.preprocessing import KBinsDiscretizer
import numpy as np
import pandas as pd # 데이터 시각화를 위해 사용

# 가상 연속형 데이터
data = np.array([1.2, 3.5, 2.1, 4.8, 0.5, 6.0, 2.9, 5.1, 7.3, 8.9]).reshape(-1, 1)
print("원본 연속형 데이터:\n", data.flatten())

# 3개의 구간으로 비닝 (균등 너비)
# n_bins=3: 3개의 구간으로 나눕니다.
# encode='ordinal': 각 구간을 정수 레이블(0, 1, 2)로 인코딩합니다.
# strategy='uniform': 각 구간의 너비를 동일하게 설정합니다.
est = KBinsDiscretizer(n_bins=3, encode='ordinal', strategy='uniform')
# fit_transform(): 훈련 데이터로부터 비닝 규칙을 학습하고, 데이터를 변환합니다.
data_binned = est.fit_transform(data)
print("\n비닝 후 데이터 (ordinal):\n", data_binned.flatten())

# 비닝 후 원-핫 인코딩 (encode='onehot')
est_onehot = KBinsDiscretizer(n_bins=3, encode='onehot-dense', strategy='uniform')
data_binned_onehot = est_onehot.fit_transform(data)
print("\n비닝 후 데이터 (one-hot):\n", data_binned_onehot)

# 비닝 경계 확인
print("\n비닝 경계 (bins_edges_):", est.bin_edges_)
```

**비닝/이산화 사용 시 고려사항:**
*   **정보 손실:** 연속형 데이터를 이산화하면 정보 손실이 발생할 수 있습니다. 구간의 개수(`n_bins`)를 너무 적게 설정하면 중요한 패턴을 놓칠 수 있습니다.
*   **구간 전략 선택:** `strategy` 선택은 중요합니다. `uniform`은 이상치에 민감할 수 있고, `quantile`은 각 구간의 샘플 수를 동일하게 유지하지만 구간 너비가 불균등할 수 있습니다.
*   **과적합 위험:** 너무 많은 구간을 만들면 모델이 훈련 데이터에 과적합될 위험이 있습니다.
*   **도메인 지식:** 비닝은 도메인 지식을 활용하여 의미 있는 구간을 설정할 때 가장 효과적입니다.


#### 1.2.4. 사용자 정의 변환 (Custom Transformations)
**사용자 정의 변환(Custom Transformations)**은 Scikit-learn에서 제공하는 표준 변환기 외에, 사용자가 직접 정의한 함수를 사용하여 특성을 변환하는 기법입니다. 이는 특정 도메인 지식을 활용하거나, 복잡한 비즈니스 로직을 반영하여 새로운 특성을 생성할 때 매우 유용합니다. `sklearn.preprocessing.FunctionTransformer`를 사용하면 파이썬 함수를 Scikit-learn 파이프라인에 통합할 수 있습니다.

*   **필요성:**
    *   **도메인 특화 변환:** 특정 산업이나 문제에만 적용되는 고유한 변환이 필요할 때.
    *   **비선형 관계 처리:** 로그 변환, 제곱근 변환, 역수 변환 등 수학적 변환을 통해 데이터의 분포를 정규화하거나 이상치의 영향을 줄이고, 비선형 관계를 선형화할 수 있습니다.
    *   **복잡한 로직:** 여러 특성을 조합하거나 조건부 로직을 사용하여 새로운 특성을 생성할 때.
*   **`FunctionTransformer`:** 이 클래스는 일반 파이썬 함수를 Scikit-learn의 변환기 인터페이스(`fit`, `transform`)를 따르도록 래핑(wrap)해줍니다. 이를 통해 사용자 정의 변환도 `Pipeline`에 쉽게 통합할 수 있습니다.
    *   **`func`:** 변환을 수행할 함수를 지정합니다.
    *   **`inverse_func`:** 역변환을 수행할 함수를 지정할 수 있습니다 (선택 사항).
    *   **`validate`:** `False`로 설정하면 입력 유효성 검사를 건너뛰어 더 유연한 입력 형태를 허용합니다.
    *   **`accept_sparse`:** 희소 행렬 입력을 허용할지 여부를 지정합니다.

```python
from sklearn.preprocessing import FunctionTransformer
import numpy as np

# 로그 변환 함수 정의
# np.log1p(X)는 log(1+X)를 계산하여 X가 0일 때도 안전하게 변환합니다.
def log_transform(X):
    return np.log1p(X) 

# 사용자 정의 변환기 생성
# validate=False는 입력 데이터가 1차원 배열일 때 발생하는 경고를 방지합니다.
transformer = FunctionTransformer(log_transform, validate=False)

# 변환할 데이터 (2차원 배열 형태여야 합니다.)
X_data = np.array([[1, 10], [0, 100], [5, 50]])
print("원본 데이터:\n", X_data)

# 변환기 적용
X_log = transformer.fit_transform(X_data)
print("\n로그 변환 후 데이터:\n", X_log)

# 역변환 (원래 스케일로 되돌리기)
# np.expm1(X)는 exp(X) - 1을 계산하여 log1p의 역함수입니다.
# transformer_inverse = FunctionTransformer(np.expm1, validate=False)
# X_original = transformer_inverse.fit_transform(X_log)
# print("\n역변환 후 데이터:\n", X_original)
```

**사용자 정의 변환 사용 시 고려사항:**
*   **데이터 누수 방지:** `FunctionTransformer`도 다른 Scikit-learn 변환기와 마찬가지로 `fit()`은 훈련 데이터에만, `transform()`은 훈련 및 테스트 데이터 모두에 적용해야 합니다.
*   **입력 형태:** `FunctionTransformer`에 전달되는 함수는 Scikit-learn의 변환기처럼 2차원 배열 형태의 입력을 기대합니다. 단일 특성을 변환할 때도 `reshape(-1, 1)`을 사용하여 2차원 배열로 만들어주어야 합니다.
*   **해석:** 사용자 정의 변환은 데이터의 원래 의미를 크게 바꿀 수 있으므로, 모델 해석 시 변환의 효과를 명확히 이해하고 있어야 합니다.
*   **파이프라인 통합:** `FunctionTransformer`를 사용하면 복잡한 전처리 파이프라인 내에 사용자 정의 변환을 쉽게 포함시킬 수 있어 코드의 모듈성과 재사용성을 높일 수 있습니다.

### 1.3. 날짜/시간 특성 공학
날짜/시간(Datetime) 특성은 그 자체로 머신러닝 모델에 직접 입력되기 어렵거나, 입력되더라도 모델이 시간의 주기성, 추세, 계절성 등 복잡한 패턴을 제대로 학습하기 어렵습니다. 따라서 날짜/시간 특성으로부터 다양한 파생 특성을 생성하여 모델의 예측력을 높이는 **날짜/시간 특성 공학**이 필요합니다.

*   **필요성:**
    *   **주기성/계절성:** 시간 데이터는 일, 주, 월, 연 단위의 주기성이나 계절성을 가질 수 있습니다 (예: 요일별 판매량, 월별 기온). 이러한 주기성을 모델이 학습할 수 있도록 특성으로 만들어야 합니다.
    *   **추세:** 시간의 흐름에 따른 데이터의 변화 추세(trend)를 반영하는 특성이 필요할 수 있습니다.
    *   **이벤트:** 특정 날짜(공휴일, 이벤트일)가 예측에 중요한 영향을 미칠 수 있습니다.
    *   **모델의 이해:** 대부분의 머신러닝 모델은 숫자형 입력을 기대하므로, 날짜/시간 정보를 숫자로 변환해야 합니다.

*   **주요 파생 특성:** `pandas` 라이브러리의 `DatetimeIndex` 객체(`dt` 접근자)를 활용하면 다양한 시간 관련 특성을 쉽게 추출할 수 있습니다.

```python
import pandas as pd

# 가상 날짜/시간 데이터 (Pandas DatetimeIndex로 변환)
dates = pd.to_datetime(['2023-01-01 10:00:00', '2023-01-02 15:30:00', '2023-03-15 08:00:00', '2023-07-20 20:00:00'])
df_time = pd.DataFrame({'timestamp': dates})

print("원본 날짜/시간 데이터:\n", df_time)

# 날짜/시간 특성 추출
# .dt 접근자를 사용하여 다양한 시간 관련 속성을 추출합니다.
df_time['year'] = df_time['timestamp'].dt.year # 연도
df_time['month'] = df_time['timestamp'].dt.month # 월
df_time['day'] = df_time['timestamp'].dt.day # 일
df_time['hour'] = df_time['timestamp'].dt.hour # 시간
df_time['dayofweek'] = df_time['timestamp'].dt.dayofweek # 요일 (월요일=0, 일요일=6)
df_time['dayofyear'] = df_time['timestamp'].dt.dayofyear # 연중 몇 번째 날
df_time['weekofyear'] = df_time['timestamp'].dt.isocalendar().week.astype(int) # 연중 몇 번째 주
df_time['quarter'] = df_time['timestamp'].dt.quarter # 분기
df_time['is_weekend'] = df_time['timestamp'].dt.dayofweek.isin([5, 6]).astype(int) # 주말 여부 (0: 평일, 1: 주말)
df_time['is_month_start'] = df_time['timestamp'].dt.is_month_start.astype(int) # 월의 시작일 여부
df_time['is_month_end'] = df_time['timestamp'].dt.is_month_end.astype(int) # 월의 마지막일 여부

print("\n날짜/시간 특성 공학 후:\n", df_time)
```

**날짜/시간 특성 공학 시 고려사항:**
*   **주기성 특성:** 요일, 월, 시간 등 주기성을 가지는 특성은 원-핫 인코딩이나 사인/코사인 변환을 통해 모델에 더 잘 반영될 수 있습니다.
*   **시간 간격:** 두 날짜/시간 사이의 차이(예: 경과 시간)도 중요한 특성이 될 수 있습니다.
*   **도메인 지식:** 특정 비즈니스 주기(예: 분기별, 연말)나 이벤트(예: 공휴일, 프로모션 기간)가 예측에 중요한 영향을 미친다면, 이를 반영하는 특성을 생성해야 합니다.
*   **데이터 누수 방지:** 날짜/시간 특성 공학도 훈련 데이터에만 `fit`하고 테스트 데이터에는 `transform`을 적용하는 원칙을 지켜야 합니다. (Pandas `dt` 접근자는 `fit/transform` 패턴을 따르지 않으므로, 파이프라인에 통합 시 `FunctionTransformer` 등을 활용해야 합니다.)

### 1.4. 텍스트 특성 추출 기초
텍스트 데이터는 머신러닝 모델에 직접 입력될 수 없으므로, 수치형 특성으로 변환하는 과정이 필요합니다. 이 과정을 **텍스트 벡터화(Text Vectorization)**라고 하며, `CountVectorizer`와 `TfidfVectorizer`가 대표적인 Scikit-learn의 텍스트 특성 추출 도구입니다.

*   **필요성:**
    *   **모델의 이해:** 머신러닝 모델은 텍스트와 같은 비정형 데이터를 직접 처리할 수 없습니다. 텍스트를 숫자로 변환해야 모델이 이를 이해하고 학습할 수 있습니다.
    *   **정보 추출:** 텍스트 내에서 단어의 빈도, 중요도, 또는 단어 간의 관계와 같은 의미 있는 정보를 수치적으로 표현해야 합니다.

*   **`CountVectorizer`:**
    *   **작동 원리:** 문서 집합(corpus)에서 모든 고유한 단어(토큰)를 추출하여 단어 사전(vocabulary)을 만듭니다. 각 문서는 이 단어 사전의 단어들이 해당 문서에 얼마나 많이 출현했는지(빈도)를 나타내는 벡터로 변환됩니다. 즉, 단어의 출현 빈도 기반의 특성을 생성합니다.
    *   **특징:** 단순하고 직관적이며, 단어의 빈도 정보를 직접적으로 반영합니다.

*   **`TfidfVectorizer`:**
    *   **작동 원리:** TF-IDF(Term Frequency-Inverse Document Frequency)는 단어의 중요도를 반영하는 통계적 가중치입니다. TF(단어 빈도)는 특정 단어가 문서 내에 얼마나 자주 나타나는지를, IDF(역문서 빈도)는 특정 단어가 전체 문서 집합에서 얼마나 희귀하게 나타나는지를 측정합니다. TF-IDF는 특정 문서에서는 자주 나타나지만 전체 문서에서는 희귀한 단어에 높은 가중치를 부여하여, 문서의 특징을 잘 나타내는 단어를 식별하는 데 효과적입니다.
    *   **특징:** 단순히 빈도만 고려하는 `CountVectorizer`와 달리, 단어의 중요도를 반영하여 문서 간의 유사도 측정이나 문서 분류에 더 효과적일 수 있습니다.

```python
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer
import numpy as np # toarray() 사용을 위해 필요

corpus = [
    'This is the first document.',
    'This document is the second document.',
    'And this is the third one.',
    'Is this the first document?'
]

print("원본 텍스트 데이터:\n", corpus)

# CountVectorizer: 단어의 출현 빈도 기반 특성 추출
vectorizer_count = CountVectorizer()
# fit_transform(): 문서 집합으로부터 단어 사전을 학습하고, 각 문서를 단어 빈도 벡터로 변환합니다.
X_count = vectorizer_count.fit_transform(corpus)
print("\nCountVectorizer 변환 후 (희소 행렬):\n", X_count.toarray()) # 희소 행렬을 일반 배열로 변환하여 출력
print("단어 사전:", vectorizer_count.get_feature_names_out()) # 학습된 단어 사전 확인

# TfidfVectorizer: TF-IDF (Term Frequency-Inverse Document Frequency) 기반 특성 추출
# 단어의 중요도를 반영 (문서 내 빈도와 문서 집합 내 희귀도)
vectorizer_tfidf = TfidfVectorizer()
# fit_transform(): 문서 집합으로부터 TF-IDF 가중치를 학습하고, 각 문서를 TF-IDF 벡터로 변환합니다.
X_tfidf = vectorizer_tfidf.fit_transform(corpus)
print("\nTF-IDF Vectorizer 변환 후 (희소 행렬):\n", X_tfidf.toarray()) # 희소 행렬을 일반 배열로 변환하여 출력
print("단어 사전:", vectorizer_tfidf.get_feature_names_out()) # 학습된 단어 사전 확인
```

**텍스트 특성 추출 시 고려사항:**
*   **희소 행렬:** 텍스트 데이터는 벡터화 후 대부분의 값이 0인 희소 행렬(Sparse Matrix)이 되는 경우가 많습니다. Scikit-learn의 벡터화기는 기본적으로 희소 행렬을 반환하여 메모리 효율성을 높입니다.
*   **전처리:** 텍스트 데이터는 벡터화 전에 소문자 변환, 구두점 제거, 불용어(stopwords) 제거, 어간 추출(stemming) 또는 표제어 추출(lemmatization) 등 다양한 전처리 과정을 거치는 것이 일반적입니다.
*   **N-gram:** 단일 단어(unigram) 외에 두 개 이상의 단어 조합(bigram, trigram 등)을 특성으로 사용할 수 있습니다. 이는 단어의 순서 정보를 반영하여 더 풍부한 의미를 포착할 수 있습니다.
*   **도메인 지식:** 특정 도메인에서는 특정 단어나 구문이 중요한 의미를 가질 수 있으므로, 도메인 지식을 활용한 맞춤형 전처리가 필요할 수 있습니다.


### 1.5. 이미지 특성 추출 기초
이미지 데이터는 픽셀 값 자체를 특성으로 사용할 수 있지만, 때로는 이미지의 특징을 더 잘 나타내는 고수준 특성을 추출하기도 합니다. 이미지 특성 추출은 컴퓨터 비전 분야의 핵심이며, 머신러닝 모델이 이미지 데이터를 이해하고 분류, 탐지, 분할 등의 작업을 수행할 수 있도록 합니다.

*   **픽셀 값:** 가장 기본적인 방법으로, 이미지를 구성하는 각 픽셀의 밝기(흑백) 또는 RGB 값(컬러)을 그대로 특성으로 사용합니다. 이는 이미지의 원시적인 정보를 담고 있지만, 고차원이며 노이즈에 민감할 수 있습니다.

*   **색상 히스토그램:** 이미지의 색상 분포를 나타내는 히스토그램을 특성으로 사용합니다. 이는 이미지의 전반적인 색상 정보를 요약하여 표현하며, 이미지 검색이나 분류에 활용될 수 있습니다.

*   **엣지/코너 검출:** 이미지의 경계선(Edge)이나 모서리(Corner) 등 구조적인 특징을 추출합니다. 이는 이미지 내의 객체 형태나 윤곽선을 파악하는 데 유용하며, 이미지 인식의 초기 단계에서 사용될 수 있습니다.

*   **사전 학습된 모델(Pre-trained Models)을 이용한 특성 추출 (전이 학습):
    *   이미지 분류를 위해 ImageNet과 같은 대규모 데이터셋으로 미리 학습된 딥러닝 모델(예: VGG, ResNet, Inception, EfficientNet 등)의 중간 레이어 출력을 특성으로 활용하는 방법이 가장 강력하고 널리 사용됩니다.
    *   이러한 사전 학습된 모델들은 이미지의 저수준 특징(엣지, 질감)부터 고수준 특징(객체의 부분, 전체 객체)까지 계층적으로 학습된 매우 풍부한 특징 표현(Feature Representation)을 가지고 있습니다.
    *   **전이 학습(Transfer Learning):** 대규모 데이터셋으로 학습된 모델의 특징 추출 능력을 새로운, 더 작은 데이터셋에 전이하여 사용하는 기법입니다. 이는 데이터가 부족하거나 모델을 처음부터 학습시키기 어려운 경우에 매우 효과적입니다.

```python
# 이미지 특성 추출은 Scikit-learn 자체보다는 OpenCV (cv2), Pillow (PIL), 또는
# 딥러닝 프레임워크인 TensorFlow (tf.keras.applications)나 PyTorch (torchvision.models) 등
# 외부 라이브러리와 딥러닝 프레임워크를 주로 사용합니다.
# Scikit-learn은 이미지 처리보다는 추출된 수치형 특성을 기반으로 모델을 학습하는 데 중점을 둡니다.

# 여기서는 개념적인 설명으로 대체합니다.
# 예시: 흑백 이미지의 픽셀 값을 특성으로 사용 (Scikit-learn의 내장 데이터셋 활용)
from sklearn.datasets import load_digits

# load_digits()는 8x8 픽셀의 손글씨 숫자 이미지 데이터셋을 로드합니다.
digits = load_digits()

# digits.data는 각 이미지를 1차원 배열(64개의 픽셀 값)로 펼친 형태입니다.
print("\nMNIST 숫자 이미지 픽셀 특성 형태:", digits.data.shape) # (1797, 64) -> 1797개의 8x8 이미지
print("첫 번째 이미지의 픽셀 값 (일부):", digits.data[0, :10]) # 첫 번째 이미지의 처음 10개 픽셀 값

# 이 픽셀 값 배열이 머신러닝 모델의 입력 특성으로 사용될 수 있습니다.
```

**이미지 특성 추출 시 고려사항:**
*   **차원의 저주:** 원시 픽셀 값을 그대로 사용하면 이미지의 해상도가 높을수록 특성의 차원이 매우 커져 차원의 저주 문제가 발생할 수 있습니다.
*   **전처리:** 이미지 데이터는 모델에 입력하기 전에 크기 조정(resizing), 정규화(normalization), 증강(augmentation) 등 다양한 전처리 과정을 거쳐야 합니다.
*   **딥러닝의 역할:** 최근에는 컨볼루션 신경망(CNN)과 같은 딥러닝 모델이 이미지에서 자동으로 계층적인 특징을 추출하는 데 탁월한 성능을 보여, 수동적인 특성 공학의 필요성을 크게 줄였습니다.


## 2. 특성 선택 (Feature Selection)

### 2.1. 왜 특성 선택이 필요한가?
**특성 선택(Feature Selection)**은 모델 학습에 가장 관련성이 높거나 중요한 특성들만 선택하여 모델의 복잡성을 줄이고, 과적합을 방지하며, 학습 시간을 단축시키는 과정입니다. 이는 머신러닝 모델의 성능과 효율성을 극대화하는 데 필수적인 단계입니다.

특성 선택이 필요한 주요 이유는 다음과 같습니다:

1.  **모델 성능 향상:**
    *   **과적합 방지:** 불필요하거나 중복되는 특성, 또는 노이즈가 많은 특성은 모델이 훈련 데이터에 과도하게 맞춰지도록(과적합) 유도할 수 있습니다. 특성 선택은 이러한 특성들을 제거하여 모델의 일반화 성능을 향상시킵니다.
    *   **예측 정확도 향상:** 관련 없는 특성이나 중복 특성을 제거함으로써 모델이 핵심적인 패턴에 더 집중할 수 있게 되어 예측 정확도가 높아질 수 있습니다.

2.  **모델의 복잡성 감소 및 해석 가능성 향상:**
    *   특성의 수가 많아질수록 모델은 더 복잡해지고, 이를 이해하고 해석하기 어려워집니다. 특성 선택은 모델에 사용되는 특성의 수를 줄여 모델을 더 단순하게 만들고, 그 결과 모델의 작동 방식을 더 쉽게 이해할 수 있도록 돕습니다.
    *   어떤 특성들이 예측에 가장 중요한 영향을 미치는지 파악하는 데 도움이 됩니다.

3.  **학습 시간 단축 및 계산 효율성 증가:**
    *   특성의 수가 많으면 모델 학습에 필요한 계산 자원(메모리, CPU/GPU 시간)이 증가하고, 학습 시간이 길어집니다. 특성 선택을 통해 불필요한 특성을 제거하면 학습 시간을 단축하고 계산 효율성을 높일 수 있습니다.
    *   특히 대규모 데이터셋이나 복잡한 모델을 다룰 때 이러한 효율성 증가는 매우 중요합니다.

4.  **차원의 저주(Curse of Dimensionality) 완화:**
    *   특성의 수가 데이터 샘플 수에 비해 너무 많아지면, 데이터 공간이 희소해지고 모델이 의미 있는 패턴을 찾기 어려워지는 '차원의 저주' 문제가 발생할 수 있습니다. 특성 선택은 이러한 고차원 문제를 완화하는 데 기여합니다.

5.  **데이터 수집 비용 절감:**
    *   실제 비즈니스 환경에서는 데이터 수집에 비용이 발생할 수 있습니다. 특성 선택을 통해 가장 중요한 특성들을 식별하면, 향후 데이터 수집 시 불필요한 특성 수집 비용을 절감할 수 있습니다.

이러한 이유들로 인해 특성 선택은 머신러닝 파이프라인에서 데이터 전처리만큼이나 중요한 단계로 간주됩니다. 다음 섹션에서는 특성 선택을 수행하는 다양한 방법론에 대해 자세히 다룹니다.

### 2.2. 특성 선택 방법론
특성 선택 방법론은 크게 세 가지로 나뉩니다. 각 방법론은 특성 선택을 수행하는 방식과 계산 비용, 그리고 모델 성능에 미치는 영향에서 차이를 보입니다.

#### 2.2.1. 필터 방법 (Filter Methods)
**필터 방법(Filter Methods)**은 각 특성과 타겟 변수 간의 통계적 관계를 평가하여 독립적으로 특성을 선택합니다. 모델 학습 전에 수행되며, 모델에 독립적이므로 계산 비용이 낮고 빠릅니다. 주로 특성 간의 상관관계, 분산, 또는 통계적 테스트(카이제곱, F-값 등)를 기준으로 특성을 필터링합니다.

*   **작동 원리:** 특성 자체의 통계적 특성이나 특성과 타겟 변수 간의 통계적 연관성을 측정하여 점수를 매기고, 점수가 높은 특성을 선택합니다.
*   **장점:**
    *   **빠르고 효율적:** 모델 학습 없이 특성 자체의 특성만으로 평가하므로 계산 비용이 낮고 대규모 데이터셋에 적용하기 용이합니다.
    *   **모델 독립적:** 특정 머신러닝 모델에 종속되지 않아 일반적인 특성 선택에 활용될 수 있습니다.
*   **단점:**
    *   특성 간의 상호작용이나 다중공선성(Multicollinearity)을 고려하지 않습니다.
    *   선택된 특성 집합이 항상 모델의 성능을 최적화한다고 보장할 수 없습니다.
*   **예시:** 상관 계수, 카이제곱($\chi^2$) 통계량, 분산 임계값(Variance Threshold), F-값(F-value) 등.
*   **Scikit-learn:** `SelectKBest` (가장 높은 점수를 가진 K개의 특성 선택), `SelectPercentile` (가장 높은 점수를 가진 상위 N%의 특성 선택), `VarianceThreshold` (분산이 낮은 특성 제거).

```python
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.datasets import load_iris
import numpy as np # for X.shape

# Iris 데이터셋 로드
iris = load_iris()
X, y = iris.data, iris.target

print("원본 특성 데이터 형태:", X.shape)

# 상위 2개의 특성 선택 (분류 문제이므로 f_classif 사용)
# score_func=f_classif: 분류 문제에서 F-값을 사용하여 특성 점수를 계산합니다.
# k=2: 가장 높은 점수를 가진 2개의 특성을 선택합니다.
selector = SelectKBest(score_func=f_classif, k=2)
# fit_transform(): 훈련 데이터로부터 특성 점수를 학습하고, 데이터를 선택된 특성으로 변환합니다.
X_selected = selector.fit_transform(X, y)

print("\n필터 방법 (SelectKBest) 선택된 특성 데이터 형태:", X_selected.shape)
# get_support(indices=True): 선택된 특성의 원본 인덱스를 반환합니다.
print("선택된 특성 인덱스:", selector.get_support(indices=True))
# scores_: 각 특성의 통계 점수(여기서는 F-값)를 반환합니다.
print("각 특성의 점수:", selector.scores_)
```

#### 2.2.2. 래퍼 방법 (Wrapper Methods)
**래퍼 방법(Wrapper Methods)**은 특성 부분 집합을 선택한 후, 실제 머신러닝 모델을 학습시켜 성능을 평가하는 방식으로 최적의 특성 조합을 찾습니다. 모델의 성능을 직접적으로 반영하므로 필터 방법보다 더 좋은 특성 집합을 찾을 가능성이 높지만, 계산 비용이 매우 높습니다.

*   **작동 원리:** 가능한 모든 특성 조합을 탐색하거나, 휴리스틱한 방법(예: 순방향 선택)을 사용하여 특성 집합을 생성하고, 각 집합에 대해 모델을 훈련하고 평가합니다.
*   **장점:**
    *   모델의 성능에 직접적으로 기여하는 특성 조합을 찾을 가능성이 높습니다.
    *   특성 간의 상호작용을 고려할 수 있습니다.
*   **단점:**
    *   **계산 비용이 매우 높음:** 특성 조합의 수가 기하급수적으로 증가하므로, 특성 수가 많을수록 계산 시간이 매우 오래 걸립니다.
    *   과적합 위험: 특정 모델에 과적합될 수 있습니다.
*   **예시:** 순방향 선택(Forward Selection), 역방향 제거(Backward Elimination), 재귀적 특성 제거(Recursive Feature Elimination, RFE).
*   **Scikit-learn:** `RFE` (재귀적 특성 제거).

```python
from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import load_iris
import numpy as np # for X.shape

# Iris 데이터셋 로드
iris = load_iris()
X, y = iris.data, iris.target

print("원본 특성 데이터 형태:", X.shape)

# LogisticRegression을 기반으로 RFE 수행, 2개의 특성 선택
# estimator: 특성 중요도를 평가할 모델 (여기서는 로지스틱 회귀)
# n_features_to_select: 최종적으로 선택할 특성의 개수
# step: 각 반복에서 제거할 특성의 개수 (기본값 1)
selector_rfe = RFE(estimator=LogisticRegression(max_iter=1000, random_state=42), n_features_to_select=2)
# fit_transform(): 모델을 반복적으로 학습시키면서 특성을 제거하고, 데이터를 선택된 특성으로 변환합니다.
X_selected_rfe = selector_rfe.fit_transform(X, y)

print("\n래퍼 방법 (RFE) 선택된 특성 데이터 형태:", X_selected_rfe.shape)
# support_: 선택된 특성(True)과 제거된 특성(False)을 나타내는 불리언 배열
print("선택된 특성 인덱스 (True: 선택됨):", selector_rfe.support_)
# ranking_: 특성의 랭킹을 나타냅니다. 1이 가장 중요한 특성입니다.
print("특성 랭킹 (1이 가장 중요):", selector_rfe.ranking_)
```

#### 2.2.3. 임베디드 방법 (Embedded Methods)
**임베디드 방법(Embedded Methods)**은 모델 학습 과정에 특성 선택이 내장되어 있는 방법입니다. 모델 자체가 특성 중요도를 계산하거나 불필요한 특성의 가중치를 0으로 만듭니다. 필터 방법과 래퍼 방법의 장점을 결합한 형태로, 계산 효율성과 모델 성능을 동시에 고려합니다.

*   **작동 원리:** 모델 학습 알고리즘 자체에 특성 선택 메커니즘이 포함되어 있습니다. 예를 들어, 정규화(L1 정규화)를 통해 불필요한 특성의 계수를 0으로 만들거나, 트리 기반 모델이 특성 중요도를 계산하는 방식입니다.
*   **장점:**
    *   필터 방법보다 모델의 성능을 더 잘 반영합니다.
    *   래퍼 방법보다 계산 효율성이 높습니다.
    *   특성 간의 상호작용을 고려할 수 있습니다.
*   **단점:** 특정 모델에 종속적입니다.
*   **예시:** 라쏘 회귀(Lasso Regression) (L1 정규화), 트리 기반 모델(의사결정 트리, 랜덤 포레스트, Gradient Boosting)의 특성 중요도.
*   **Scikit-learn:** `SelectFromModel` (특성 중요도나 계수 크기를 기반으로 특성 선택).

```python
from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
import numpy as np # for X.shape

# Iris 데이터셋 로드
iris = load_iris()
X, y = iris.data, iris.target

print("원본 특성 데이터 형태:", X.shape)

# RandomForestClassifier를 기반으로 특성 선택
# estimator: 특성 중요도를 계산할 모델 (여기서는 RandomForestClassifier)
# threshold='median': 특성 중요도 중앙값 이상인 특성만 선택합니다.
# (threshold='mean' 또는 특정 숫자 값으로 설정 가능)
selector_sfm = SelectFromModel(estimator=RandomForestClassifier(random_state=42), threshold='median')
# fit_transform(): 모델을 학습시키면서 특성을 선택하고, 데이터를 선택된 특성으로 변환합니다.
X_selected_sfm = selector_sfm.fit_transform(X, y)

print("\n임베디드 방법 (SelectFromModel) 선택된 특성 데이터 형태:", X_selected_sfm.shape)
# get_support(indices=True): 선택된 특성의 원본 인덱스를 반환합니다.
print("선택된 특성 인덱스:", selector_sfm.get_support(indices=True))
# estimator_.feature_importances_: 학습된 모델의 특성 중요도를 반환합니다.
print("각 특성의 중요도:", selector_sfm.estimator_.feature_importances_)
```

**특성 선택 방법론 선택 가이드:**
*   **데이터 크기 및 특성 수:** 데이터가 매우 크거나 특성 수가 많을 때는 필터 방법이 가장 효율적입니다. 특성 수가 적당하다면 래퍼나 임베디드 방법을 고려할 수 있습니다.
*   **모델 성능 vs. 계산 비용:** 모델 성능이 최우선이라면 래퍼 방법이 좋지만, 계산 비용을 고려해야 한다면 임베디드 방법이나 필터 방법을 고려합니다.
*   **해석 가능성:** 모델의 해석이 중요하다면, 선택된 특성들이 어떤 의미를 가지는지 명확히 알 수 있는 방법을 선택하는 것이 좋습니다.
*   **도메인 지식:** 도메인 지식을 활용하여 불필요한 특성을 사전에 제거하거나, 특정 특성들의 중요도를 예측하는 데 활용할 수 있습니다.


#### 2.2.2. 래퍼 방법 (Wrapper Methods)
특성 부분 집합을 선택한 후, 실제 모델을 학습시켜 성능을 평가하는 방식으로 최적의 특성 조합을 찾습니다. 계산 비용이 높지만, 모델의 성능에 직접적으로 기여하는 특성을 찾을 가능성이 높습니다.
*   **예시:** 순방향 선택(Forward Selection), 역방향 제거(Backward Elimination), 재귀적 특성 제거(RFE).
*   **Scikit-learn:** `RFE`

```python
from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression

# Iris 데이터셋 로드
iris = load_iris()
X, y = iris.data, iris.target

# LogisticRegression을 기반으로 RFE 수행, 2개의 특성 선택
selector_rfe = RFE(estimator=LogisticRegression(max_iter=1000, random_state=42), n_features_to_select=2)
X_selected_rfe = selector_rfe.fit_transform(X, y)

print("\n래퍼 방법 (RFE) 선택된 특성 데이터 형태:", X_selected_rfe.shape)
print("선택된 특성 인덱스 (True: 선택됨):", selector_rfe.support_)
print("특성 랭킹 (1이 가장 중요):", selector_rfe.ranking_)
```

#### 2.2.3. 임베디드 방법 (Embedded Methods)
모델 학습 과정에 특성 선택이 내장되어 있는 방법입니다. 모델 자체가 특성 중요도를 계산하거나 불필요한 특성의 가중치를 0으로 만듭니다.
*   **예시:** 라쏘 회귀(Lasso Regression), 트리 기반 모델의 특성 중요도.
*   **Scikit-learn:** `SelectFromModel`

```python
from sklearn.feature_selection import SelectFromModel

```

## 3. 결론: 특성 공학 및 선택 시 고려사항
*   **도메인 지식:** 특성 공학은 도메인 지식이 매우 중요합니다. 데이터에 대한 깊은 이해가 새로운 특성 생성의 핵심입니다.
*   **데이터 누수 방지:** 특성 공학 및 선택은 훈련 데이터에만 적용하고, 테스트 데이터에는 훈련 데이터에서 학습된 변환기나 선택기를 사용하여 `transform`만 수행해야 합니다. `Pipeline`을 활용하면 데이터 누수를 효과적으로 방지할 수 있습니다.
*   **반복적인 과정:** 특성 공학 및 선택은 모델 학습 및 평가와 함께 반복적으로 수행되며, 모델 성능 개선에 가장 큰 영향을 미칠 수 있는 부분 중 하나입니다.

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.datasets import load_iris
from sklearn.feature_selection import SelectFromModel
from sklearn.ensemble import RandomForestClassifier
from sklearn.feature_selection import RFE
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import KBinsDiscretizer
import pandas as pd
from sklearn.preprocessing import FunctionTransformer
from sklearn.feature_extraction.text import CountVectorizer, TfidfVectorizer

# Iris 데이터셋 로드
iris = load_iris()
X, y = iris.data, iris.target

print("원본 특성 데이터 형태:", X.shape)

# 2차 다항 특성 생성 (degree=2)
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X)
print("\n2차 다항 특성 생성 후:", X_poly)
print("생성된 특성 이름:", poly.get_feature_names_out(['feature1', 'feature2']))

# 상위 2개의 특성 선택 (분류 문제이므로 f_classif 사용)
selector = SelectKBest(score_func=f_classif, k=2)
X_selected = selector.fit_transform(X, y)

print("\n선택된 특성 데이터 형태:", X_selected.shape)
print("선택된 특성 인덱스:", selector.get_support(indices=True)) # 선택된 특성의 원본 인덱스
print("각 특성의 점수:", selector.scores_) # 각 특성의 통계 점수

# RandomForestClassifier를 기반으로 특성 선택
# threshold='median'은 특성 중요도 중앙값 이상인 특성 선택
selector = SelectFromModel(estimator=RandomForestClassifier(random_state=42), threshold='median')
X_selected = selector.fit_transform(X, y)

print("\n선택된 특성 데이터 형태:", X_selected.shape)
print("선택된 특성 인덱스:", selector.get_support(indices=True))
print("각 특성의 중요도:", selector.estimator_.feature_importances_)

# LogisticRegression을 기반으로 RFE 수행, 2개의 특성 선택
selector = RFE(estimator=LogisticRegression(max_iter=1000, random_state=42), n_features_to_select=2)
X_selected = selector.fit_transform(X, y)

print("\n선택된 특성 데이터 형태:", X_selected.shape)
print("선택된 특성 인덱스 (True: 선택됨):", selector.support_)
print("특성 랭킹 (1이 가장 중요):", selector.ranking_)
```
