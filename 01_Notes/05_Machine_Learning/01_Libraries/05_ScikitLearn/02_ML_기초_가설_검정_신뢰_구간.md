## 1. 통계적 추론의 기본 개념
통계적 추론(Statistical Inference)은 표본(Sample) 데이터를 분석하여 우리가 실제로 관심 있는 전체 집단인 모집단(Population)에 대한 결론을 도출하는 과정입니다. 이는 제한된 정보(표본)를 바탕으로 더 큰 그림(모집단)을 이해하려는 시도입니다.

### 1.1. 모집단과 표본
*   **모집단(Population):** 연구 대상이 되는 모든 개체 또는 관측값의 전체 집합입니다. 우리가 궁극적으로 알고자 하는 특성을 가진 모든 요소를 포함합니다. 현실적으로 모집단 전체를 조사하는 것은 어렵거나 불가능한 경우가 많습니다.
    *   **예시:** 대한민국 모든 성인의 평균 키, 특정 공장에서 생산된 모든 전구의 수명, 특정 질병을 앓고 있는 전 세계 모든 환자.
*   **표본(Sample):** 모집단에서 추출된, 모집단의 특성을 대표한다고 가정되는 부분 집합입니다. 표본을 통해 얻은 정보를 바탕으로 모집단의 특성을 추론하게 됩니다.
    *   **예시:** 대한민국 성인 1,000명의 평균 키, 특정 공장에서 무작위로 추출한 전구 100개의 수명, 특정 병원에서 치료받은 질병 환자 50명.
*   **통계적 추론의 목적:** 표본의 특성(표본 통계량)을 분석하여 모집단의 특성(모수)을 추정하거나, 모집단에 대한 가설을 검정하는 것입니다.

### 1.2. 표본 분포와 중심 극한 정리
*   **표본 분포(Sampling Distribution):** 모집단에서 동일한 크기의 표본을 무수히 많이 반복 추출하여, 각 표본에서 계산된 특정 통계량(예: 표본 평균, 표본 분산)들이 이루는 분포를 의미합니다. 이 표본 분포는 모집단의 특성을 추론하는 데 핵심적인 역할을 합니다.
    *   **예시:** 대한민국 성인 모집단에서 100명씩 무작위로 1000번 표본을 추출하고, 각 표본의 평균 키를 계산했을 때, 이 1000개의 표본 평균들이 형성하는 분포.
*   **중심 극한 정리(Central Limit Theorem, CLT):** 통계적 추론의 가장 중요하고 강력한 정리 중 하나입니다. 이 정리는 다음과 같이 요약됩니다.
    *   **내용:** 모집단의 분포 형태가 정규 분포이든 아니든 상관없이, 모집단에서 충분히 큰 크기($n$)의 표본을 무작위로 반복 추출할 경우, 표본 평균들의 분포는 모집단의 평균($\mu$)을 중심으로 하는 정규 분포에 가까워집니다. 이때 표본 평균 분포의 표준편차는 모집단 표준편차($\sigma$)를 표본 크기의 제곱근($\sqrt{n}$)으로 나눈 값($\sigma/\sqrt{n}$)이 됩니다. 이를 **표준 오차(Standard Error)**라고 합니다.
    *   **"충분히 큰 크기"의 기준:** 일반적으로 표본 크기 $n \ge 30$일 때 중심 극한 정리가 적용된다고 봅니다. 하지만 모집단이 이미 정규 분포를 따른다면 표본 크기에 상관없이 표본 평균 분포는 정규 분포를 따릅니다.
    *   **왜 중요한가?** 중심 극한 정리는 모집단의 분포를 알지 못하더라도, 충분히 큰 표본만 있다면 표본 평균에 대한 통계적 추론(가설 검정, 신뢰 구간 추정 등)을 정규 분포의 성질을 이용하여 수행할 수 있게 해줍니다. 이는 통계적 분석의 범위를 크게 확장시킵니다.

## 2. 가설 검정 (Hypothesis Testing)
**가설 검정**은 모집단에 대한 특정 주장(가설)이 옳은지 아닌지를 표본 데이터를 사용하여 통계적으로 판단하는 체계적인 절차입니다. 이는 데이터가 특정 현상이나 효과를 지지하는 충분한 증거를 제공하는지 여부를 결정하는 데 사용됩니다.

### 2.1. 귀무가설과 대립가설
가설 검정은 항상 두 가지 상호 배타적인 가설을 설정하는 것에서 시작합니다.
*   **귀무가설 ($H_0$):** 현재까지 알려진 사실, 기존의 주장, 또는 '차이가 없다', '효과가 없다', '관계가 없다'는 등의 '변화 없음'을 나타내는 가설입니다. 가설 검정의 목표는 귀무가설이 틀렸다는 충분한 증거를 찾는 것입니다. 귀무가설은 항상 등호(=)를 포함합니다.
    *   **예시:** "새로운 약을 복용한 그룹과 기존 약을 복용한 그룹 간에 평균 혈압 강하 효과에 차이가 없다."
*   **대립가설 ($H_1$ 또는 $H_a$):** 귀무가설과 반대되는 가설로, 우리가 통계적으로 증명하고자 하는 '새로운 주장' 또는 '차이가 있다', '효과가 있다', '관계가 있다'는 가설입니다. 대립가설은 귀무가설이 기각될 때 받아들여집니다.
    *   **예시:** "새로운 약을 복용한 그룹이 기존 약을 복용한 그룹보다 평균 혈압 강하 효과가 더 크다."

### 2.2. 유의 수준 (Significance Level, $\alpha$)
유의 수준($\alpha$)은 귀무가설이 실제로 옳음에도 불구하고 우리가 귀무가설을 잘못 기각할 확률, 즉 1종 오류를 범할 최대 허용치입니다. 이는 가설 검정에서 '얼마나 엄격하게 판단할 것인가'를 결정하는 기준이 됩니다. 일반적으로 0.05 (5%) 또는 0.01 (1%)을 사용합니다.
*   $\alpha$ 값이 작을수록 귀무가설을 기각하기 위한 증거가 더 강력해야 합니다.

### 2.3. p-value
**p-value (확률값)**는 귀무가설이 옳다는 가정 하에, 현재 관찰된 표본 데이터 또는 그보다 더 극단적인 결과가 우연히 발생할 확률입니다. p-value는 가설 검정의 핵심적인 판단 기준이 됩니다.
*   **p-value < $\alpha$:** 관찰된 결과가 귀무가설 하에서는 매우 드물게 나타나는 현상이므로, 귀무가설을 기각합니다. 이는 대립가설을 지지하는 통계적으로 유의미한 증거가 있다고 해석됩니다.
*   **p-value $\ge$ $\alpha$:** 관찰된 결과가 귀무가설 하에서도 충분히 발생할 수 있는 현상이므로, 귀무가설을 기각할 충분한 통계적 증거가 없다고 판단합니다. (주의: 귀무가설을 '채택'하는 것이 아니라, '기각하지 못한다'는 의미입니다. 귀무가설이 옳다는 것을 증명하는 것은 아닙니다.)

### 2.4. 1종 오류와 2종 오류
가설 검정에서는 항상 오류를 범할 가능성이 존재하며, 주로 두 가지 유형의 오류를 고려합니다.
*   **1종 오류 (Type I Error):** 귀무가설이 실제로 참인데도 불구하고, 우리가 귀무가설을 기각하는 오류입니다 (False Positive). '무고한 사람을 유죄로 판단하는 것'에 비유할 수 있습니다. 1종 오류를 범할 확률은 유의 수준 $\alpha$와 같습니다.
*   **2종 오류 (Type II Error):** 귀무가설이 실제로 거짓인데도 불구하고, 우리가 귀무가설을 기각하지 못하는 오류입니다 (False Negative). '유죄인 사람을 무죄로 판단하는 것'에 비유할 수 있습니다. 2종 오류를 범할 확률은 $\beta$로 표기하며, 검정력(Power, $1-\beta$)과 반비례 관계에 있습니다.

### 2.5. 가설 검정 절차
가설 검정은 다음의 표준적인 절차를 따릅니다.
1.  **가설 설정:** 연구 질문에 따라 귀무가설($H_0$)과 대립가설($H_1$)을 명확하게 설정합니다.
2.  **유의 수준 설정:** 1종 오류를 허용할 최대 확률인 $\alpha$ 값을 결정합니다 (예: 0.05, 0.01).
3.  **검정 통계량 계산:** 수집된 표본 데이터를 바탕으로 적절한 통계적 검정 방법(예: Z-검정, t-검정, 카이제곱 검정 등)을 선택하고, 해당 검정 통계량(Test Statistic) 값을 계산합니다.
4.  **p-value 계산:** 계산된 검정 통계량과 해당 분포를 이용하여 p-value를 구합니다. 이는 귀무가설이 참일 때 현재 결과가 나올 확률입니다.
5.  **결론 도출:** 계산된 p-value와 설정한 유의 수준 $\alpha$를 비교합니다.
    *   p-value < $\alpha$ 이면 귀무가설을 기각하고 대립가설을 채택합니다.
    *   p-value $\ge$ $\alpha$ 이면 귀무가설을 기각할 충분한 증거가 없다고 결론 내립니다.
6.  **결과 해석:** 통계적 결론을 실제 문제 상황에 맞게 해석하고 보고합니다.

## 3. 주요 가설 검정 방법

### 3.1. Z-검정 (Z-test)
Z-검정은 모집단의 표준편차($\sigma$)를 알고 있거나, 표본의 크기($n$)가 충분히 큰 경우(일반적으로 $n \ge 30$)에 사용되는 통계적 가설 검정 방법입니다. 중심 극한 정리에 의해 표본 크기가 충분히 크면 표본 평균의 분포가 정규 분포를 따르므로 Z-분포를 활용할 수 있습니다.

*   **주요 사용 사례:**
    *   **단일 모집단 평균 Z-검정:** 표본 평균이 특정 모집단 평균과 통계적으로 유의미하게 다른지 검정할 때.
    *   **두 모집단 평균 Z-검정:** 두 독립적인 모집단의 평균이 통계적으로 유의미하게 다른지 검정할 때 (모집단 표준편차를 아는 경우).
*   **검정 통계량 (Z-statistic) 공식 (단일 표본 평균의 경우):**
    $ Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}} $
    *   $\bar{x}$: 표본 평균
    *   $\mu_0$: 귀무가설 하의 모집단 평균
    *   $\sigma$: 모집단 표준편차
    *   $n$: 표본 크기
*   **가정:**
    *   데이터는 정규 분포를 따르거나, 표본 크기가 충분히 커서 중심 극한 정리가 적용됩니다.
    *   모집단 표준편차($\sigma$)를 알고 있어야 합니다. (모르는 경우, 표본 크기가 크면 표본 표준편차로 대체 가능)
    *   표본은 무작위로 추출되고 독립적이어야 합니다.
*   **해석:** 계산된 Z-값이 표준 정규 분포에서 얼마나 극단적인 위치에 있는지를 파악하여 p-value를 계산하고 귀무가설 기각 여부를 결정합니다.

### 3.2. t-검정 (t-test)
t-검정은 모집단의 표준편차를 모르거나, 표본의 크기가 작은 경우($n < 30$)에 주로 사용되는 가설 검정 방법입니다. Z-검정과 달리 t-분포를 사용하며, t-분포는 표본 크기가 작을수록 꼬리가 두꺼워져 불확실성을 반영합니다. 표본 크기가 커질수록 t-분포는 정규 분포에 가까워집니다.

*   **가정:**
    *   데이터는 정규 분포를 따르거나, 표본 크기가 충분히 커야 합니다.
    *   표본은 무작위로 추출되고 독립적이어야 합니다.
    *   (독립 표본 t-검정의 경우) 두 그룹의 분산이 동일하다는 가정이 필요할 수 있습니다 (등분산성).

#### 3.2.1. 단일 표본 t-검정
하나의 표본 평균이 특정 모집단 평균(알려진 값)과 통계적으로 유의미하게 다른지 검정할 때 사용됩니다.
*   **주요 사용 사례:** 어떤 제품의 평균 무게가 표준 무게와 다른지, 특정 학급의 평균 점수가 전국 평균과 다른지 등을 검정.
*   **검정 통계량 (t-statistic) 공식:**
    $ t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} $
    *   $\bar{x}$: 표본 평균
    *   $\mu_0$: 귀무가설 하의 모집단 평균
    *   $s$: 표본 표준편차
    *   $n$: 표본 크기
    *   자유도 (df): $n-1$

#### 3.2.2. 독립 표본 t-검정
서로 독립적인 두 표본 그룹(예: 남성 그룹과 여성 그룹, A 치료법 그룹과 B 치료법 그룹) 간에 평균 차이가 통계적으로 유의미한지 검정할 때 사용됩니다.
*   **주요 사용 사례:** 새로운 교육 방법이 기존 교육 방법보다 효과적인지, 두 가지 비료가 식물 성장에 미치는 영향이 다른지 등을 검정.
*   **검정 통계량 (t-statistic) 공식 (등분산 가정 시):**
    $ t = \frac{(\bar{x}_1 - \bar{x}_2) - (\mu_1 - \mu_2)}{\sqrt{s_p^2 (\frac{1}{n_1} + \frac{1}{n_2})}} $
    *   $\bar{x}_1, \bar{x}_2$: 각 그룹의 표본 평균
    *   $\mu_1 - \mu_2$: 귀무가설 하의 모집단 평균 차이 (보통 0)
    *   $s_p^2$: 통합 분산 (Pooled Variance)
    *   $n_1, n_2$: 각 그룹의 표본 크기
    *   자유도 (df): $n_1 + n_2 - 2$

#### 3.2.3. 대응 표본 t-검정
동일한 표본 그룹에 대해 두 번 측정된 값(예: 약 복용 전후, 교육 프로그램 참여 전후) 간에 평균 차이가 통계적으로 유의미한지 검정할 때 사용됩니다. 각 개체에 대한 두 측정값의 차이를 이용하여 분석합니다.
*   **주요 사용 사례:** 특정 약 복용 전후 환자의 혈압 변화, 다이어트 프로그램 참여 전후 체중 변화 등을 검정.
*   **검정 통계량 (t-statistic) 공식:**
    $ t = \frac{\bar{d} - \mu_d}{s_d / \sqrt{n}} $
    *   $\bar{d}$: 각 개체별 두 측정값의 차이($d_i$)에 대한 평균
    *   $\mu_d$: 귀무가설 하의 차이의 모집단 평균 (보통 0)
    *   $s_d$: 차이($d_i$)에 대한 표본 표준편차
    *   $n$: 쌍의 수 (개체 수)
    *   자유도 (df): $n-1$

### 3.3. 카이제곱 검정 ($\chi^2$-test)
카이제곱($\chi^2$) 검정은 주로 범주형 변수(Categorical Variable) 간의 관계를 분석하거나, 관찰된 빈도가 특정 이론적 분포(기대 빈도)와 일치하는지 여부를 검정할 때 사용되는 비모수 통계 방법입니다. 이는 명목 척도나 서열 척도로 측정된 데이터에 적합합니다.

*   **주요 사용 사례:**
    *   **적합도 검정 (Goodness-of-Fit Test):** 하나의 범주형 변수에 대해 관찰된 빈도 분포가 특정 이론적 분포(예: 균등 분포, 알려진 비율)와 통계적으로 유의미하게 다른지 검정합니다. 즉, 표본이 특정 모집단 분포를 잘 대표하는지 확인합니다.
        *   **예시:** 주사위가 공정한지 검정 (각 면이 나올 확률이 1/6인지).
    *   **독립성 검정 (Test of Independence):** 두 범주형 변수 간에 통계적인 독립성(연관성 없음)이 있는지 검정합니다. 교차표(Contingency Table)를 사용하여 각 변수의 범주 조합에 대한 관찰 빈도를 분석합니다.
        *   **예시:** 성별(남/여)과 특정 제품 선호도(선호/비선호) 간에 연관성이 있는지 검정.
*   **검정 통계량 ($\chi^2$-statistic) 공식:**
    $ \chi^2 = \sum \frac{(O_i - E_i)^2}{E_i} $
    *   $O_i$: 각 범주 또는 셀의 관찰된 빈도 (Observed Frequency)
    *   $E_i$: 각 범주 또는 셀의 기대 빈도 (Expected Frequency) (귀무가설이 참일 때 예상되는 빈도)
    *   계산된 카이제곱 통계량은 카이제곱 분포를 따르며, 자유도(df)는 (행의 수 - 1) * (열의 수 - 1) 또는 (범주의 수 - 1)로 결정됩니다.
*   **가정:**
    *   데이터는 범주형이어야 합니다.
    *   각 셀의 기대 빈도가 충분히 커야 합니다 (일반적으로 5 이상). 기대 빈도가 너무 작으면 검정 결과의 신뢰성이 떨어집니다.
    *   관찰값은 독립적이어야 합니다.
    *   표본은 무작위로 추출되어야 합니다.
*   **해석:** 계산된 카이제곱 통계량이 클수록 관찰된 빈도와 기대 빈도 간의 차이가 크다는 것을 의미하며, 이는 귀무가설을 기각할 강력한 증거가 됩니다. p-value가 유의 수준($\alpha$)보다 작으면 귀무가설을 기각하고, 두 변수 간에 통계적으로 유의미한 연관성(독립성 검정)이 있거나 분포가 유의미하게 다르다(적합도 검정)고 결론 내립니다.

### 3.4. ANOVA (분산 분석)
**ANOVA (Analysis of Variance)**, 즉 분산 분석은 세 개 이상의 독립적인 그룹 간에 평균 차이가 통계적으로 유의미한지 검정하는 데 사용되는 통계적 방법입니다. 여러 그룹의 평균을 한 번에 비교할 수 있어, 다중 t-검정을 반복할 때 발생할 수 있는 1종 오류 증가 문제를 해결합니다.

*   **기본 원리:** 그룹 내 분산(Within-group variance)과 그룹 간 분산(Between-group variance)을 비교하여, 그룹 간 평균 차이가 우연에 의한 것인지, 아니는 실제 모집단 평균의 차이인지를 판단합니다. 그룹 간 분산이 그룹 내 분산보다 충분히 크다면, 그룹 평균 간에 유의미한 차이가 있다고 결론 내립니다.
*   **검정 통계량 (F-statistic) 공식:**
    $ F = \frac{\text{그룹 간 분산}}{\text{그룹 내 분산}} $
*   **가정:**
    *   **독립성:** 각 그룹의 표본은 서로 독립적이어야 합니다.
    *   **정규성:** 각 그룹 내 데이터는 정규 분포를 따라야 합니다 (표본 크기가 충분히 크면 중심 극한 정리에 의해 완화될 수 있습니다).
    *   **등분산성:** 각 그룹의 모집단 분산은 동일해야 합니다 (Levene's test 등으로 검정 가능).
*   **주요 사용 사례:**
    *   세 가지 다른 비료가 작물 수확량에 미치는 영향 비교.
    *   여러 교육 방법이 학생들의 학업 성취도에 미치는 영향 비교.
    *   다양한 마케팅 전략이 제품 판매량에 미치는 영향 분석.
*   **해석:** ANOVA 검정 결과 p-value가 유의 수준($\alpha$)보다 작으면, '적어도 한 그룹의 평균은 다른 그룹의 평균과 다르다'는 결론을 내립니다. 하지만 ANOVA는 어떤 그룹들이 서로 다른지는 알려주지 않으므로, 구체적인 차이를 파악하기 위해서는 사후 분석(Post-hoc test, 예: Tukey HSD, Bonferroni)이 필요합니다.


## 4. 신뢰 구간 (Confidence Interval)
**신뢰 구간(Confidence Interval, CI)**은 표본 통계량(예: 표본 평균)을 바탕으로 모집단 모수(예: 모집단 평균)가 존재할 것으로 예상되는 구간을 추정하는 방법입니다. 점 추정(Point Estimation)이 하나의 값으로 모수를 추정하는 반면, 신뢰 구간은 추정의 불확실성을 구간의 형태로 제시하여 더 많은 정보를 제공합니다.

### 4.1. 신뢰 구간이란?
신뢰 구간은 표본에서 얻은 정보를 바탕으로 모집단의 모수(예: 평균, 비율)가 포함될 것이라고 '신뢰'할 수 있는 구간을 의미합니다. 예를 들어, "95% 신뢰 구간은 [10, 20]이다"라고 하면, 이는 동일한 방식으로 100번 표본을 추출하여 신뢰 구간을 계산했을 때, 그 중 약 95개의 신뢰 구간이 실제 모집단 모수를 포함할 것이라는 의미입니다. **주의할 점은, 특정 한 번 계산된 신뢰 구간이 모집단 모수를 포함할 확률이 95%라는 의미가 아니라는 것입니다.**

*   **신뢰 구간의 일반적인 공식:**
    $ \text{점 추정치} x (	ext{임계값} 	imes 	ext{표준 오차}) $
    *   **점 추정치:** 표본에서 계산된 통계량 (예: 표본 평균 $ar{x}$)
    *   **임계값:** 신뢰 수준과 분포(Z-분포 또는 t-분포)에 따라 결정되는 값 (예: 95% 신뢰 수준에서 Z-분포의 임계값은 약 1.96)
    *   **표준 오차 (Standard Error, SE):** 표본 통계량의 표준편차로, 표본 통계량이 모집단 모수로부터 얼마나 떨어져 있을 수 있는지를 나타냅니다. (예: 표본 평균의 표준 오차 $SE = s / √{n}$ 또는 $s / √{n}$)

### 4.2. 신뢰 수준 (Confidence Level)
신뢰 수준은 신뢰 구간을 계산할 때 사용되는 확률로, 일반적으로 90%, 95%, 99% 등을 사용합니다. 이는 장기적으로 동일한 방식으로 반복하여 신뢰 구간을 만들었을 때, 그 신뢰 구간들이 실제 모집단 모수를 포함할 비율을 의미합니다.
*   **신뢰 수준과 신뢰 구간의 폭:**
    *   신뢰 수준이 높을수록 (예: 95%에서 99%로) 신뢰 구간의 폭은 넓어집니다. 이는 모수를 포함할 확률을 높이기 위해 더 넓은 범위를 제시하기 때문입니다.
    *   표본 크기가 커질수록 신뢰 구간의 폭은 좁아집니다. 표본 크기가 커지면 표준 오차가 줄어들어 추정의 정밀도가 높아지기 때문입니다.
*   **가설 검정과의 관계:** 신뢰 구간은 가설 검정과 밀접한 관련이 있습니다. 예를 들어, 어떤 모수에 대한 95% 신뢰 구간이 귀무가설에서 제시하는 모수 값(예: $µ_0$)을 포함하지 않는다면, 해당 귀무가설은 유의 수준 0.05에서 기각될 수 있습니다.

## 5. 실습: 가설 검정 및 신뢰 구간 계산
이 실습에서는 Python의 `SciPy` 라이브러리를 활용하여 단일 표본 t-검정, 독립 표본 t-검정, 그리고 단일 표본 평균에 대한 신뢰 구간을 계산하는 방법을 보여줍니다. 이를 통해 앞서 학습한 통계적 추론 개념들을 실제 데이터에 적용하는 경험을 할 수 있습니다.

```python
import numpy as np
from scipy import stats # 통계 함수를 제공하는 SciPy 라이브러리 임포트

# 1. 단일 표본 t-검정 실습
# 시나리오: 어떤 제품의 평균 무게가 100g이라고 주장합니다. 
# 우리는 20개의 샘플을 추출하여 평균 무게가 98g, 표준편차 5g임을 확인했습니다.
# 과연 이 제품의 평균 무게가 100g과 통계적으로 유의미하게 다르다고 할 수 있을까요?
sample_weights = np.array([98, 101, 95, 103, 99, 97, 100, 102, 96, 98, 100, 99, 101, 97, 95, 103, 99, 98, 100, 97])
pop_mean_h0 = 100 # 귀무가설(H0): 모집단 평균은 100g이다.

# t-test 수행 (stats.ttest_1samp: 단일 표본 t-검정 함수)
# sample_weights: 표본 데이터
# pop_mean_h0: 귀무가설 하의 모집단 평균
t_statistic, p_value = stats.ttest_1samp(sample_weights, pop_mean_h0)

print("---"" 단일 표본 t-검정 ---"" ")
print(f"표본 평균: {np.mean(sample_weights):.2f}") # 표본 데이터의 평균 출력
print(f"t-statistic: {t_statistic:.4f}") # 계산된 t-통계량 출력
print(f"p-value: {p_value:.4f}") # 계산된 p-value 출력

alpha = 0.05 # 유의 수준 설정 (일반적으로 0.05 사용)
if p_value < alpha: # p-value가 유의 수준보다 작으면 귀무가설 기각
    print(f"p-value ({p_value:.4f}) < {alpha} 이므로, 귀무가설 기각. 제품의 평균 무게는 100g과 통계적으로 유의미하게 다릅니다.")
else: # p-value가 유의 수준보다 크거나 같으면 귀무가설 기각 실패
    print(f"p-value ({p_value:.4f}) >= {alpha} 이므로, 귀무가설 채택. 제품의 평균 무게는 100g과 통계적으로 유의미하게 다르지 않습니다.")

# 2. 독립 표본 t-검정 실습
# 시나리오: 새로운 교육 방법(A)과 기존 교육 방법(B)의 효과를 비교합니다.
# 각 교육 방법을 적용한 학생들의 시험 점수 데이터가 주어졌습니다.
group_a_scores = np.array([85, 88, 90, 82, 87, 84, 89, 86, 83, 91])
group_b_scores = np.array([78, 80, 82, 75, 79, 77, 81, 76, 79, 78])

# t-test 수행 (stats.ttest_ind: 독립 표본 t-검정 함수)
# group_a_scores: 첫 번째 그룹의 데이터
# group_b_scores: 두 번째 그룹의 데이터
t_statistic_ind, p_value_ind = stats.ttest_ind(group_a_scores, group_b_scores)

print("\n---"" 독립 표본 t-검정 ---"" ")
print(f"그룹 A 평균: {np.mean(group_a_scores):.2f}, 그룹 B 평균: {np.mean(group_b_scores):.2f}") # 각 그룹의 평균 점수 출력
print(f"t-statistic: {t_statistic_ind:.4f}") # 계산된 t-통계량 출력
print(f"p-value: {p_value_ind:.4f}") # 계산된 p-value 출력

if p_value_ind < alpha: # p-value가 유의 수준보다 작으면 귀무가설 기각
    print(f"p-value ({p_value_ind:.4f}) < {alpha} 이므로, 귀무가설 기각. 두 교육 방법 간에 통계적으로 유의미한 차이가 있습니다.")
else: # p-value가 유의 수준보다 크거나 같으면 귀무가설 기각 실패
    print(f"p-value ({p_value_ind:.4f}) >= {alpha} 이므로, 귀무가설 채택. 두 교육 방법 간에 통계적으로 유의미한 차이가 없습니다.")

# 3. 신뢰 구간 계산 실습 (단일 표본 평균의 신뢰 구간)
# 시나리오: 위에서 사용한 sample_weights 데이터를 이용하여 제품의 평균 무게에 대한 95% 신뢰 구간을 계산합니다.
sample_mean = np.mean(sample_weights) # 표본 평균 계산
sample_std = np.std(sample_weights, ddof=1) # 표본 표준편차 계산 (ddof=1은 비편향 추정치를 위해 사용)
n = len(sample_weights) # 표본 크기

# 95% 신뢰 수준 (alpha=0.05)에 해당하는 t-값 (임계값) 계산
# stats.t.ppf(확률, 자유도)는 t-분포의 누적 분포 함수(CDF)의 역함수입니다.
# 양측 검정이므로 1 - alpha/2 (상위 꼬리 확률)를 사용합니다.
# 자유도(df) = n-1
t_critical = stats.t.ppf(1 - alpha/2, df=n-1)

# 표준 오차 (Standard Error) 계산
standard_error = sample_std / np.sqrt(n)

# 신뢰 구간 계산: 표본 평균 +/- (임계값 * 표준 오차)
lower_bound = sample_mean - t_critical * standard_error # 하한
upper_bound = sample_mean + t_critical * standard_error # 상한

print("\n---"" 95% 신뢰 구간 계산 ---"" ")
print(f"표본 평균: {sample_mean:.2f}") # 표본 평균 출력
print(f"95% 신뢰 구간: ({lower_bound:.2f}, {upper_bound:.2f})") # 계산된 신뢰 구간 출력
print("해석: 이 표본을 통해 추정한 모집단 평균은 95%의 신뢰도로 이 구간 안에 있을 것으로 예상됩니다.")
```
