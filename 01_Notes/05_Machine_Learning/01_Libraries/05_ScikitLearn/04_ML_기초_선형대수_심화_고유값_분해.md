## 1. 고유값과 고유벡터
고유값(Eigenvalue)과 고유벡터(Eigenvector)는 선형대수학에서 매우 중요한 개념으로, 특히 행렬이 나타내는 선형 변환의 본질적인 특성을 이해하는 데 필수적입니다. 이들은 정방 행렬(Square Matrix)에 대해서만 정의됩니다.

### 1.1. 정의
행렬 $A$에 어떤 0이 아닌 벡터 $\mathbf{v}$를 곱했을 때, 그 결과가 원래 벡터 $\mathbf{v}$의 스칼라 배($\lambda \mathbf{v}$)가 되는 관계를 만족하는 벡터 $\mathbf{v}$를 **고유벡터(Eigenvector)**, 그리고 스칼라 $\lambda$를 **고유값(Eigenvalue)**이라고 합니다.

*   **수식:** $ A\mathbf{v} = \lambda\mathbf{v} $
    *   $A$: $n \times n$ 정방 행렬 (선형 변환을 나타냄)
    *   $\\mathbf{v}$: 0이 아닌 고유벡터 (행렬 $A$에 의해 방향이 변하지 않는 벡터)
    *   $\\lambda$: 고유값 (고유벡터 $\\mathbf{v}$가 행렬 $A$에 의해 '확대' 또는 '축소'되는 비율)
*   **고유값과 고유벡터 찾기:** 위 식을 $ (A - \lambda I)\\mathbf{v} = \mathbf{0} $으로 변형할 수 있습니다. 여기서 $I$는 항등 행렬입니다. 0이 아닌 고유벡터 $\\mathbf{v}$가 존재하려면 행렬 $ (A - \lambda I) $가 역행렬을 가지지 않아야 하므로, 이 행렬의 행렬식(Determinant)이 0이 되어야 합니다: $ \text{det}(A - \lambda I) = 0 $. 이 방정식을 '특성 방정식(Characteristic Equation)'이라고 하며, 이 방정식을 풀면 고유값 $\\lambda$를 찾을 수 있습니다. 찾아진 각 고유값에 대해 $ (A - \lambda I)\\mathbf{v} = \mathbf{0} $을 풀면 해당 고유벡터 $\\mathbf{v}$를 구할 수 있습니다.

### 1.2. 기하학적 의미
고유값과 고유벡터는 선형 변환이 공간을 어떻게 '변형'시키는지를 직관적으로 이해하는 데 도움을 줍니다.
*   **고유벡터:** 선형 변환(행렬 $A$를 곱하는 것)을 적용했을 때 **방향이 변하지 않고 크기만 변하는** 특별한 벡터입니다. 즉, 고유벡터는 변환에 의해 '회전'되지 않고, 원래 자신이 놓여 있던 '축'을 유지합니다.
*   **고유값:** 해당 고유벡터가 변환에 의해 얼마나 '확대'되거나 '축소'되는지를 나타내는 비율입니다. 고유값이 양수이면 같은 방향으로 크기가 변하고, 음수이면 반대 방향으로 크기가 변합니다. 고유값이 1이면 크기가 변하지 않습니다.
*   **예시:** 이미지를 회전시키는 행렬의 경우, 회전축에 해당하는 벡터가 고유벡터가 되고, 고유값은 1이 됩니다 (방향과 크기가 변하지 않으므로).

### 1.3. 고유값 분해 (Eigen-decomposition)
고유값 분해는 정방 행렬 $A$를 고유값과 고유벡터를 이용하여 세 개의 행렬의 곱으로 분해하는 방법입니다. 이를 통해 행렬 $A$가 나타내는 선형 변환을 고유벡터 축을 따라 스케일링하는 것으로 해석할 수 있습니다.
*   **수식:** $ A = P \Lambda P^{-1} $
    *   $P$: 행렬 $A$의 고유벡터들을 열 벡터로 가지는 행렬입니다. 고유벡터들이 선형 독립이면 $P$는 역행렬 $P^{-1}$을 가집니다.
    *   $\\Lambda$: 행렬 $A$의 고유값들을 주대각선 원소로 가지는 대각 행렬입니다. 대각선 외의 모든 원소는 0입니다.
    *   $P^{-1}$: 행렬 $P$의 역행렬입니다.
*   **의미:** 이 분해는 행렬 $A$에 의한 변환이 다음 세 단계로 이루어진다는 것을 의미합니다.
    1.  $P^{-1}$에 의한 변환: 데이터를 고유벡터 축으로 회전시킵니다.
    2.  $\\Lambda$에 의한 변환: 고유값에 따라 각 고유벡터 축을 따라 스케일링(확대/축소)합니다.
    3.  $P$에 의한 변환: 원래 공간으로 다시 회전시킵니다.
*   **활용:** 고유값 분해는 주로 데이터의 분산 구조를 분석하거나, 선형 미분 방정식의 해를 구하는 등 다양한 분야에서 활용됩니다. 특히 주성분 분석(PCA)의 이론적 기반이 됩니다.

## 2. 주성분 분석 (PCA)과 고유값 분해
**주성분 분석(Principal Component Analysis, PCA)**은 고차원 데이터를 저차원 공간으로 축소하는 데 사용되는 대표적인 차원 축소(Dimensionality Reduction) 기법입니다. 데이터의 분산을 최대한 보존하면서 데이터의 복잡성을 줄이는 것이 목표입니다. PCA는 데이터의 공분산 행렬(Covariance Matrix) 또는 상관 행렬(Correlation Matrix)의 고유값 분해를 기반으로 합니다.

*   **공분산 행렬:** 데이터의 각 특성(변수) 간의 선형 관계를 나타내는 정방 행렬입니다. 대각선 요소는 각 특성의 분산을, 비대각선 요소는 두 특성 간의 공분산을 나타냅니다. PCA는 이 공분산 행렬의 고유값 분해를 통해 데이터의 분산 구조를 파악합니다.
*   **PCA의 핵심 아이디어:**
    1.  데이터의 분산이 가장 큰 방향을 찾습니다. 이 방향이 첫 번째 주성분(Principal Component)이 됩니다.
    2.  첫 번째 주성분과 직교하면서 남은 분산을 가장 잘 설명하는 방향을 찾습니다. 이 방향이 두 번째 주성분이 됩니다.
    3.  이 과정을 반복하여 데이터의 분산을 설명하는 새로운 직교 축들을 찾아냅니다.
*   **고유값과 고유벡터의 역할:**
    *   **고유벡터:** 공분산 행렬의 고유벡터들은 새로운 축, 즉 **주성분(Principal Components)**의 방향을 결정합니다. 이 주성분들은 서로 직교(Orthogonal)합니다.
    *   **고유값:** 각 고유벡터에 해당하는 고유값의 크기는 해당 주성분이 설명하는 데이터의 **분산의 양**을 나타냅니다. 고유값이 클수록 해당 주성분이 데이터의 더 많은 정보를 담고 있다는 의미입니다.
*   **PCA 절차 (고유값 분해 기반):**
    1.  **데이터 표준화:** 각 특성의 평균을 0, 표준편차를 1로 맞춥니다 (선택 사항이지만 권장).
    2.  **공분산 행렬 계산:** 표준화된 데이터의 공분산 행렬을 계산합니다.
    3.  **고유값 분해:** 공분산 행렬을 고유값 분해하여 고유값과 고유벡터를 얻습니다.
    4.  **주성분 선택:** 고유값의 크기가 큰 순서대로 주성분(고유벡터)을 선택합니다. 보통 누적 설명 분산 비율(Cumulative Explained Variance Ratio)을 보고 적절한 수의 주성분을 결정합니다.
    5.  **데이터 투영:** 선택된 주성분(고유벡터)들을 새로운 축으로 사용하여 원본 데이터를 저차원 공간으로 투영합니다.
*   **활용:** 차원 축소, 데이터 시각화, 노이즈 제거, 특성 추출 등 머신러닝 전처리 단계에서 광범위하게 사용됩니다.

## 3. 특이값 분해 (Singular Value Decomposition, SVD)
**특이값 분해(Singular Value Decomposition, SVD)**는 고유값 분해와 달리 정방 행렬뿐만 아니라 **모든 종류의 행렬(직사각 행렬 포함)**에 적용 가능한 강력한 행렬 분해 기법입니다. SVD는 행렬을 세 개의 다른 행렬의 곱으로 분해하여, 원래 행렬이 나타내는 선형 변환을 더 단순하고 해석하기 쉬운 형태로 이해할 수 있게 합니다.

### 3.1. 정의
임의의 $m \times n$ 행렬 $A$는 다음과 같이 세 개의 행렬의 곱으로 분해될 수 있습니다.

*   **수식:** $ A = U \Sigma V^T $
    *   $A$: 분해하고자 하는 $m \times n$ 행렬입니다.
    *   $U$: $m \times m$ 크기의 직교 행렬(Orthogonal Matrix)입니다. $U$의 열 벡터들은 '좌측 특이벡터(Left Singular Vectors)'라고 불리며, $A A^T$의 고유벡터들로 구성됩니다.
    *   $\Sigma$: $m \times n$ 크기의 직사각 대각 행렬(Diagonal Matrix)입니다. 주대각선에는 '특이값(Singular Values)' $s_1, s_2, \dots, s_k$ (여기서 $k = \min(m, n)$)가 큰 값부터 내림차순으로 배열되어 있고, 나머지 원소는 모두 0입니다. 특이값은 항상 음이 아닌 실수입니다.
    *   $V^T$: $n \times n$ 크기의 직교 행렬 $V$의 전치 행렬입니다. $V$의 열 벡터들은 '우측 특이벡터(Right Singular Vectors)'라고 불리며, $A^T A$의 고유벡터들로 구성됩니다.

### 3.2. SVD의 기하학적 의미
SVD는 어떤 선형 변환이든 세 가지 기본적인 기하학적 변환의 조합으로 해석할 수 있음을 의미합니다.
1.  **회전 (Rotation):** $V^T$ 행렬은 입력 공간을 회전시킵니다.
2.  **스케일링 (Scaling):** $\Sigma$ 행렬은 특정 축을 따라 데이터를 확대하거나 축소(스케일링)합니다. 특이값의 크기가 스케일링의 정도를 나타냅니다.
3.  **다시 회전 (Another Rotation):** $U$ 행렬은 출력 공간을 다시 회전시킵니다.

이러한 기하학적 해석은 SVD가 데이터의 본질적인 구조를 파악하고, 차원 축소나 노이즈 제거와 같은 작업에 왜 효과적인지를 이해하는 데 도움을 줍니다.

### 3.3. SVD의 활용
SVD는 머신러닝 및 데이터 과학 분야에서 매우 광범위하게 활용되는 강력한 도구입니다.
*   **차원 축소 (Dimensionality Reduction):**
    *   PCA의 일반화된 형태로 볼 수 있습니다. 공분산 행렬을 직접 계산하지 않고도 SVD를 통해 데이터의 주요 분산 방향(주성분)을 얻을 수 있습니다. 특이값이 큰 순서대로 몇 개의 특이값과 해당 특이벡터만 사용하여 데이터를 저차원으로 압축할 수 있습니다.
*   **추천 시스템 (Recommender Systems):**
    *   사용자-아이템 평점 행렬과 같은 희소 행렬(Sparse Matrix)을 SVD로 분해하여 잠재 요인(Latent Factors)을 추출합니다. 이를 통해 사용자의 선호도를 예측하고 아이템을 추천하는 잠재 요인 모델(Latent Factor Model)을 구축합니다.
*   **이미지 압축 및 노이즈 제거:**
    *   이미지를 행렬로 표현한 후 SVD를 적용하여, 큰 특이값에 해당하는 부분만 사용하여 이미지를 압축하거나 노이즈를 제거할 수 있습니다. 작은 특이값은 주로 노이즈나 미세한 패턴을 나타내기 때문입니다.
*   **텍스트 마이닝 (Text Mining) 및 자연어 처리 (NLP):**
    *   **잠재 의미 분석 (Latent Semantic Analysis, LSA):** 문서-단어 행렬에 SVD를 적용하여 문서와 단어 간의 숨겨진 의미 관계(잠재 의미)를 파악하고, 텍스트 데이터의 차원을 축소하여 효율적인 검색 및 분류를 가능하게 합니다.
*   **행렬 근사 (Matrix Approximation):** 원본 행렬을 더 낮은 랭크(Rank)의 행렬로 근사할 때 SVD가 최적의 해를 제공합니다. 이는 데이터 압축이나 노이즈 제거에 유용합니다.
*   **의사 역행렬 (Pseudoinverse):** 역행렬이 존재하지 않는 행렬에 대해 의사 역행렬을 계산하는 데 SVD가 사용됩니다. 이는 선형 회귀 문제에서 해를 구할 때 유용합니다.

## 4. 실습: NumPy를 이용한 고유값 분해 및 SVD
이 실습에서는 Python의 `NumPy` 라이브러리를 사용하여 고유값 분해(Eigen-decomposition)와 특이값 분해(SVD)를 수행하는 방법을 보여줍니다. NumPy의 `linalg` 모듈은 선형대수학 연산을 효율적으로 처리하는 데 최적화되어 있습니다.

```python
import numpy as np # NumPy 라이브러리 임포트

# 1. 고유값 분해 실습
# 고유값 분해는 정방 행렬에만 적용 가능하며, 특히 대칭 행렬은 항상 고유값 분해가 가능합니다.
A = np.array([[4, 2],
              [2, 4]]) # 2x2 대칭 행렬 A 정의

# np.linalg.eig() 함수를 사용하여 고유값과 고유벡터를 계산합니다.
# eigenvalues: 고유값 배열
# eigenvectors: 고유벡터를 열 벡터로 가지는 행렬
eigenvalues, eigenvectors = np.linalg.eig(A)

print("---", "고유값 분해", "---")
print("행렬 A:\n", A)
print("고유값:", eigenvalues) # 출력된 고유값은 실수 또는 복소수일 수 있습니다.
print("고유벡터:\n", eigenvectors) # 각 열이 대응하는 고유값의 고유벡터입니다.

# 고유값 분해 확인: A @ v = lambda * v
# 첫 번째 고유벡터와 고유값을 사용하여 A @ v = lambda * v 관계를 확인합니다.
v1 = eigenvectors[:, 0] # 첫 번째 고유벡터 (첫 번째 열)

# 2. 특이값 분해 (SVD) 실습
# SVD는 정방 행렬이 아닌 직사각 행렬에도 적용 가능합니다.
B = np.array([[1, 2, 3],
              [4, 5, 6]]) # 2x3 직사각 행렬 B 정의

# np.linalg.svd() 함수를 사용하여 SVD를 계산합니다.
# U: 좌측 특이벡터 행렬
# s: 특이값 배열 (대각 행렬의 대각선 원소)
# Vt: 우측 특이벡터 행렬의 전치
U, s, Vt = np.linalg.svd(B)

print("\n---", "특이값 분해 (SVD)", "---")
print("행렬 B:\n", B)
print("U (좌측 특이벡터):\n", U)
print("s (특이값 - 대각 행렬의 대각선 원소):\n", s)
print("Vt (우측 특이벡터의 전치):\n", Vt)

# SVD를 이용한 행렬 재구성 확인: U @ Sigma @ Vt
# 특이값 배열 s를 원래 행렬 B의 차원에 맞는 대각 행렬 Sigma로 변환합니다.
Sigma = np.zeros((B.shape[0], B.shape[1])) # B와 동일한 차원의 0 행렬 생성
Sigma[:B.shape[0], :B.shape[0]] = np.diag(s) # 특이값을 대각선에 삽입

reconstructed_B = U @ Sigma @ Vt # U, Sigma, Vt를 곱하여 원본 행렬 B를 재구성
print("\n재구성된 행렬 B:\n", reconstructed_B)
# np.allclose() 함수는 두 배열이 부동 소수점 오차를 고려하여 거의 같은지 확인합니다.
print("원본 행렬과 재구성된 행렬이 근사적으로 같은가?", np.allclose(B, reconstructed_B))

# SVD를 이용한 차원 축소 (예: 1차원으로 압축)
# 가장 큰 특이값(s[0]) 하나만 사용하여 행렬을 압축하고 재구성합니다.
# 이는 데이터의 가장 중요한 정보를 보존하면서 차원을 줄이는 방법입니다.
s_truncated = s[0] # 가장 큰 특이값
U_truncated = U[:, :1] # U의 첫 번째 열 (가장 중요한 좌측 특이벡터)
Vt_truncated = Vt[:1, :] # Vt의 첫 번째 행 (가장 중요한 우측 특이벡터)

# 압축된 행렬 재구성
B_compressed = U_truncated @ np.diag([s_truncated]) @ Vt_truncated
print("\n1차원으로 압축 후 재구성된 행렬 B:\n", B_compressed)
# 압축된 행렬은 원본 행렬의 근사치이며, 정보 손실이 발생할 수 있습니다.
```
