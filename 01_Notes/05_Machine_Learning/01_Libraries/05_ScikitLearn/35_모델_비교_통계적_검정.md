## 1. 왜 모델 성능을 통계적으로 비교해야 하는가?

### 1.1. 단순 수치 비교의 한계
머신러닝 모델을 개발할 때, 우리는 다양한 모델을 훈련시키고 평가 지표(예: 정확도, F1-점수, MSE)를 통해 성능을 비교합니다. 예를 들어, 모델 A의 정확도가 0.90이고 모델 B의 정확도가 0.91이라면, 우리는 직관적으로 모델 B가 더 좋다고 생각할 수 있습니다.

하지만 이 0.01%의 차이가 **우연에 의한 것인지, 아니면 모델 B가 실제로 모델 A보다 더 우수한 것인지**를 판단하기는 어렵습니다. 특히 데이터셋의 크기가 작거나, 모델의 성능 차이가 미미할 경우 이러한 의문은 더욱 커집니다.

이러한 단순 수치 비교의 한계는 다음과 같은 문제점을 야기할 수 있습니다:

*   **우연에 의한 오해**: 특정 데이터 분할이나 무작위 초기화 등으로 인해 일시적으로 더 좋은 성능을 보일 수 있습니다. 이러한 우연한 차이를 실제 성능 차이로 오인할 수 있습니다.
*   **과도한 자원 소모**: 통계적으로 유의미한 개선이 없음에도 불구하고, 미미한 수치 차이 때문에 더 복잡하거나 학습 비용이 높은 모델을 도입하려는 시도를 할 수 있습니다.
*   **잘못된 의사결정**: 실제 서비스에 배포될 모델을 선택할 때, 통계적 근거 없이 단순히 숫자가 높은 모델을 선택하면 기대했던 성능을 얻지 못하거나 오히려 더 나쁜 결과를 초래할 수 있습니다.

### 1.2. 통계적 유의성(Statistical Significance)
**통계적 유의성**은 관찰된 결과가 우연히 발생했을 가능성이 얼마나 낮은지를 나타내는 척도입니다. 모델 성능 비교에서 통계적 검정을 사용하는 이유는 다음과 같습니다.
*   **신뢰성 있는 결론:** 모델 간의 성능 차이가 통계적으로 유의미한지 판단하여, 우연에 의한 결과가 아닌 신뢰할 수 있는 결론을 내릴 수 있습니다.
*   **객관적인 모델 선택:** 여러 모델 중 어떤 모델을 최종 선택할지에 대한 객관적인 근거를 제공합니다.
*   **자원 효율성:** 통계적으로 유의미한 성능 향상이 없다면, 더 복잡하거나 학습 비용이 높은 모델을 도입할 필요가 없다는 판단을 내릴 수 있습니다.

### 1.3. 통계적 검정의 필요성

머신러닝 모델의 성능은 다양한 요인에 의해 영향을 받습니다. 데이터의 노이즈, 샘플링 편향, 모델의 무작위 초기화, 교차 검증 시 데이터 분할 방식 등 여러 변수가 모델의 평가 지표에 영향을 미칠 수 있습니다. 따라서 단순히 하나의 평가 지표 값만으로 두 모델의 우열을 가리는 것은 위험합니다.

통계적 검정은 이러한 불확실성 속에서 모델 간의 성능 차이가 **'진정으로 존재하는 차이'**인지, 아니면 **'우연히 발생한 잡음'**인지를 과학적으로 판단할 수 있는 도구를 제공합니다.

*   **일반화 성능에 대한 확신**: 우리가 모델을 훈련시키는 목적은 학습 데이터뿐만 아니라, 아직 보지 못한 새로운 데이터에 대해서도 잘 작동하는 모델을 만드는 것입니다. 통계적 검정은 모델이 새로운 데이터에 대해서도 일관되게 더 나은 성능을 보일 것이라는 확신을 주는 데 도움을 줍니다.
*   **과학적 방법론 준수**: 머신러닝 연구 및 개발은 과학적인 방법론을 따라야 합니다. 통계적 검정은 가설 설정, 데이터 수집, 분석, 결론 도출이라는 과학적 절차의 중요한 부분입니다. 이는 모델 선택 과정에 대한 투명성과 신뢰성을 높여줍니다.
*   **비용-효과 분석**: 실제 비즈니스 환경에서는 모델의 성능 향상이 곧 비용 절감이나 수익 증대로 이어질 수 있습니다. 하지만 미미한 성능 향상을 위해 모델을 교체하거나 더 많은 자원을 투자하는 것은 비효율적일 수 있습니다. 통계적 검정은 이러한 비용-효과 분석의 중요한 판단 기준이 됩니다.

결론적으로, 모델 성능을 통계적으로 비교하는 것은 머신러닝 모델 개발 과정에서 **더욱 견고하고 신뢰할 수 있는 의사결정**을 내리기 위한 필수적인 단계입니다. 이는 단순히 숫자를 넘어선 '의미 있는' 차이를 발견하고, 자원을 효율적으로 배분하며, 궁극적으로 더 나은 머신러닝 솔루션을 구축하는 데 기여합니다.

## 2. 분류 모델 비교를 위한 통계적 검정

분류 모델의 성능을 비교할 때는 단순히 정확도나 F1-점수와 같은 단일 지표를 비교하는 것을 넘어, 통계적 검정을 통해 그 차이가 우연이 아닌 실제 유의미한 차이인지 확인하는 것이 중요합니다. 여기서는 분류 모델 비교에 주로 사용되는 두 가지 통계적 검정 방법인 McNemar's Test와 Paired t-test에 대해 자세히 설명합니다.

### 2.1. McNemar's Test
McNemar's Test는 **동일한 데이터셋**에 대해 두 분류 모델의 성능을 비교할 때 사용되는 비모수 검정입니다. 특히 두 모델이 **서로 다른 유형의 오류**를 얼마나 많이 범하는지에 초점을 맞춥니다. 이는 두 모델이 동일한 샘플에 대해 예측을 수행했을 때, 한 모델은 맞추고 다른 모델은 틀린 경우의 수를 비교하여 모델 간의 차이를 평가합니다.

*   **가정:** 두 모델이 동일한 샘플에 대해 예측을 수행해야 합니다 (쌍을 이룬 데이터).
*   **핵심 아이디어:** 두 모델 중 하나만 틀리고 다른 하나는 맞춘 샘플의 수를 비교합니다. 이 정보를 바탕으로 2x2 혼동 행렬을 구성합니다.
    *   $n_{01}$: 모델 1은 틀리고 모델 2는 맞춘 샘플 수 (Model 1: Incorrect, Model 2: Correct)
    *   $n_{10}$: 모델 1은 맞추고 모델 2는 틀린 샘플 수 (Model 1: Correct, Model 2: Incorrect)
    *   $n_{00}$: 두 모델 모두 틀린 샘플 수 (Model 1: Incorrect, Model 2: Incorrect)
    *   $n_{11}$: 두 모델 모두 맞춘 샘플 수 (Model 1: Correct, Model 2: Correct)

    McNemar's Test는 주로 $n_{01}$과 $n_{10}$의 차이에 기반하여 통계적 유의성을 판단합니다. 만약 두 모델의 성능에 차이가 없다면, $n_{01}$과 $n_{10}$은 비슷할 것으로 기대합니다.

*   **귀무가설 ($H_0$):** 두 모델의 성능에는 통계적으로 유의미한 차이가 없다. 즉, $n_{01} = n_{10}$이다.
*   **대립가설 ($H_1$):** 두 모델의 성능에는 통계적으로 유의미한 차이가 있다. 즉, $n_{01} 
eq n_{10}$이다.

*   **적용 시점:** McNemar's Test는 특히 두 모델이 동일한 테스트 세트에서 예측을 수행했을 때, 어떤 모델이 다른 모델보다 특정 유형의 오류를 더 많이 또는 적게 범하는지 분석하는 데 유용합니다. 예를 들어, 한 모델은 오탐(False Positive)이 많고 다른 모델은 미탐(False Negative)이 많을 때, 이 테스트를 통해 그 차이가 통계적으로 유의미한지 확인할 수 있습니다.

### 2.2. Paired t-test (교차 검증 점수 비교)
Paired t-test는 교차 검증을 통해 얻은 여러 폴드(fold)별 성능 점수(예: 정확도, F1-점수)를 사용하여 두 모델의 평균 성능에 통계적으로 유의미한 차이가 있는지 비교합니다. 이는 동일한 데이터 분할(폴드)에 대해 두 모델의 성능을 비교하므로 '쌍을 이룬(paired)' 검정이라고 불립니다.

*   **가정:** 각 폴드에서 얻은 두 모델의 성능 점수 차이가 정규 분포를 따른다고 가정합니다. (중심 극한 정리에 의해 폴드 수가 충분히 많으면 이 가정이 완화될 수 있습니다.)
*   **핵심 아이디어:** 각 교차 검증 폴드 $k$에서 모델 A의 성능 점수 $S_{A,k}$와 모델 B의 성능 점수 $S_{B,k}$를 계산합니다. 그리고 각 폴드에서의 성능 차이 $D_k = S_{A,k} - S_{B,k}$를 구합니다. Paired t-test는 이 차이 $D_k$들의 평균이 0과 통계적으로 유의미하게 다른지 검정합니다.

*   **귀무가설 ($H_0$):** 두 모델의 평균 성능에는 통계적으로 유의미한 차이가 없다. 즉, $E[D_k] = 0$이다.
*   **대립가설 ($H_1$):** 두 모델의 평균 성능에는 통계적으로 유의미한 차이가 있다. 즉, $E[D_k] 
eq 0$이다.

*   **적용 시점:** Paired t-test는 주로 5x2 교차 검증(5번 반복된 2-fold 교차 검증)이나 10-fold 교차 검증과 같이 여러 번의 교차 검증을 통해 얻은 성능 점수들을 비교할 때 사용됩니다. 이는 단일 테스트 세트에서의 성능 비교보다 모델의 일반화 성능에 대한 더 안정적인 추정치를 제공합니다.

### 2.3. McNemar's Test vs. Paired t-test

두 검정 방법은 모두 두 분류 모델의 성능을 비교하지만, 그 초점과 적용 상황이 다릅니다.

| 특징 | McNemar's Test | Paired t-test |
| :--- | :--- | :--- |
| **비교 대상** | 두 모델의 **오류 패턴** (어떤 샘플에서 한 모델만 틀리고 다른 모델은 맞추는지) | 두 모델의 **평균 성능 점수** (교차 검증 폴드별 점수) |
| **데이터 요구사항** | 동일한 테스트 세트에 대한 두 모델의 예측 결과 | 동일한 교차 검증 폴드에 대한 두 모델의 성능 점수 |
| **가정** | 비모수 검정 (정규성 가정 불필요) | 성능 차이의 정규성 가정 (폴드 수가 충분하면 완화) |
| **주요 사용처** | 두 모델이 서로 다른 종류의 오류를 범하는지 분석할 때, 특히 모델의 '강점과 약점'을 파악할 때 | 여러 교차 검증 반복을 통해 얻은 평균 성능의 통계적 유의미한 차이를 확인할 때 |
| **예시 질문** | "모델 A는 모델 B보다 스팸 메일을 더 잘 걸러내는가?" (오탐/미탐 패턴) | "모델 A의 평균 정확도가 모델 B의 평균 정확도보다 통계적으로 유의미하게 높은가?" |

일반적으로, 단일 테스트 세트에서 두 모델의 예측 결과를 세밀하게 분석하고 싶을 때는 McNemar's Test를, 교차 검증을 통해 얻은 전반적인 평균 성능의 차이를 통계적으로 검정하고 싶을 때는 Paired t-test를 사용합니다. 경우에 따라 두 가지 검정을 모두 사용하여 모델 비교에 대한 더 깊은 통찰을 얻을 수 있습니다.

## 3. 회귀 모델 비교를 위한 통계적 검정

회귀 모델의 성능을 비교할 때도 분류 모델과 마찬가지로 통계적 검정을 통해 그 차이가 우연이 아닌 실제 유의미한 차이인지 확인하는 것이 중요합니다. 회귀 모델에서는 주로 평균 제곱 오차(Mean Squared Error, MSE), 평균 절대 오차(Mean Absolute Error, MAE), R-제곱(R-squared)과 같은 평가 지표를 사용합니다. 이 지표들은 연속적인 값을 예측하는 모델의 정확도를 측정합니다.

### 3.1. Paired t-test (교차 검증 점수 비교)

회귀 모델의 경우에도 분류 모델과 유사하게 교차 검증을 통해 얻은 폴드별 성능 점수(예: MSE, RMSE)를 사용하여 Paired t-test를 수행할 수 있습니다. 이 방법은 두 회귀 모델이 동일한 데이터 분할에 대해 얼마나 일관되게 다른 성능을 보이는지 평가하는 데 적합합니다.

*   **가정:** 각 교차 검증 폴드에서 두 모델의 성능 점수 차이가 정규 분포를 따른다고 가정합니다. 분류 모델과 마찬가지로, 충분한 수의 폴드를 사용하면 이 가정이 완화될 수 있습니다.

*   **핵심 아이디어:**
    1.  먼저, K-Fold 교차 검증과 같은 방법을 사용하여 각 모델에 대해 여러 개의 성능 점수(예: 10-fold 교차 검증 시 10개의 MSE 값)를 얻습니다.
    2.  각 폴드 $k$에서 모델 A의 성능 점수 $S_{A,k}$와 모델 B의 성능 점수 $S_{B,k}$를 계산합니다.
    3.  각 폴드에서의 성능 차이 $D_k = S_{A,k} - S_{B,k}$를 구합니다. (여기서 $S_{A,k}$와 $S_{B,k}$는 MSE와 같이 '낮을수록 좋은' 지표일 경우, 차이의 부호에 유의해야 합니다. 예를 들어, $MSE_A - MSE_B$가 음수이고 통계적으로 유의미하다면 모델 A가 더 좋다는 의미가 됩니다.)
    4.  Paired t-test는 이 차이 $D_k$들의 평균이 0과 통계적으로 유의미하게 다른지 검정합니다.

*   **귀무가설 ($H_0$):** 두 회귀 모델의 평균 성능에는 통계적으로 유의미한 차이가 없다. 즉, $E[D_k] = 0$이다.
*   **대립가설 ($H_1$):** 두 회귀 모델의 평균 성능에는 통계적으로 유의미한 차이가 있다. 즉, $E[D_k] 
eq 0$이다.

*   **적용 시점:**
    *   두 회귀 모델 중 어떤 모델이 특정 데이터셋에 대해 전반적으로 더 우수한 예측 성능을 보이는지 확인하고자 할 때 사용됩니다.
    *   특히, 새로운 특성 공학 기법이나 다른 알고리즘을 적용했을 때, 그 변화가 실제 모델 성능에 통계적으로 유의미한 개선을 가져왔는지 평가하는 데 유용합니다.
    *   분류 모델과 마찬가지로, 단일 테스트 세트에서의 성능 비교보다는 교차 검증을 통해 얻은 여러 점수를 기반으로 하는 것이 모델의 일반화 성능에 대한 더 신뢰성 있는 결론을 도출하는 데 도움이 됩니다.

*   **주의사항:**
    *   회귀 모델의 평가 지표(MSE, MAE 등)는 값이 낮을수록 좋은 경우가 많습니다. 따라서 t-statistic의 부호와 p-value를 해석할 때 이 점을 고려해야 합니다. 예를 들어, `scores1 - scores2`의 평균이 음수이고 p-value가 유의수준보다 작다면, `scores1`이 `scores2`보다 통계적으로 유의미하게 낮다는 의미이므로, `scores1`에 해당하는 모델이 더 우수하다고 해석할 수 있습니다.
    *   평가 지표의 분포가 심하게 비대칭이거나 이상치가 많을 경우, Paired t-test의 정규성 가정이 위배될 수 있습니다. 이 경우 비모수적인 대안(예: Wilcoxon signed-rank test)을 고려할 수 있습니다.

### 3.2. 기타 고려사항

*   **잔차 분석 (Residual Analysis):** 통계적 검정 외에도 회귀 모델의 성능을 비교할 때는 잔차 분석이 매우 중요합니다. 두 모델의 잔차 분포를 시각화하거나 잔차의 특성을 비교하여, 어떤 모델이 특정 예측 구간에서 더 큰 오류를 범하는지, 또는 예측 편향이 있는지 등을 파악할 수 있습니다.
*   **시각화:** 예측값과 실제값의 산점도, 잔차 플롯 등을 통해 두 모델의 예측 경향을 시각적으로 비교하는 것은 통계적 검정 결과와 함께 모델 선택에 대한 직관적인 이해를 돕습니다.
*   **다중 비교 문제 (Multiple Comparisons Problem):** 만약 세 개 이상의 회귀 모델을 비교해야 한다면, 단순히 모든 쌍에 대해 Paired t-test를 반복하는 것은 다중 비교 문제를 야기할 수 있습니다 (Type I 오류, 즉 귀무가설을 잘못 기각할 확률이 증가). 이 경우 ANOVA(분산 분석)와 같은 다중 비교 검정을 사용하거나, Bonferroni correction, Holm correction과 같은 p-value 조정 방법을 적용해야 합니다.

## 4. 실습: 두 모델의 성능 통계적 비교

이 실습을 통해 회귀 모델의 성능 차이도 통계적으로 검정하여, 어떤 모델이 특정 회귀 문제에 더 적합한지 객관적으로 판단할 수 있습니다.

### 4.1. McNemar's Test 실습

McNemar's Test는 두 분류 모델이 동일한 샘플에 대해 얼마나 다르게 예측 오류를 범하는지 비교하는 데 사용됩니다. 다음 실습에서는 로지스틱 회귀와 랜덤 포레스트 모델을 사용하여 McNemar's Test를 수행합니다.

```python
import numpy as np
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import confusion_matrix
from statsmodels.stats.contingency_tables import mcnemar # McNemar's Test를 위한 라이브러리

# 데이터 로드 및 분할
cancer = load_breast_cancer()
X, y = cancer.data, cancer.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

# 모델 1: 로지스틱 회귀
model1 = LogisticRegression(max_iter=2000, random_state=42)
model1.fit(X_train, y_train)
y_pred1 = model1.predict(X_test)

# 모델 2: 랜덤 포레스트
model2 = RandomForestClassifier(random_state=42)
model2.fit(X_train, y_train)
y_pred2 = model2.predict(X_test)

# 두 모델의 예측 결과 비교
# 모델 1은 맞추고 모델 2는 틀린 경우 (1, 0)
# 모델 1은 틀리고 모델 2는 맞춘 경우 (0, 1)
# (y_test == y_pred1)은 모델 1의 정답 여부 (True/False)
# (y_test == y_pred2)는 모델 2의 정답 여부 (True/False)
# True=1, False=0으로 변환하여 비교
contingency_table = confusion_matrix((y_test == y_pred1), (y_test == y_pred2), labels=[False, True])

print("두 모델의 예측 일치/불일치 혼동 행렬:")
print(contingency_table)

# McNemar's Test 수행
result = mcnemar(contingency_table, exact=True) # exact=True는 작은 샘플 크기에서 정확한 p-value 계산
print(f"
McNemar's Test statistic: {result.statistic:.4f}")
print(f"McNemar's Test p-value: {result.pvalue:.4f}")

# p-value 해석
alpha = 0.05
if result.pvalue < alpha:
    print(f"p-value ({result.pvalue:.4f}) < {alpha} 이므로, 귀무가설 기각. 두 모델의 성능에는 통계적으로 유의미한 차이가 있습니다.")
else:
    print(f"p-value ({result.pvalue:.4f}) >= {alpha} 이므로, 귀무가설 채택. 두 모델의 성능에는 통계적으로 유의미한 차이가 없습니다.")
```

#### 4.1.1. 코드 설명 및 결과 해석

1.  **데이터 준비 및 모델 훈련**: 유방암 데이터셋(`load_breast_cancer`)을 로드하고 훈련 세트와 테스트 세트로 분할합니다. 이후 로지스틱 회귀(`model1`)와 랜덤 포레스트(`model2`) 두 분류 모델을 훈련시키고 테스트 세트에 대한 예측을 수행합니다.
2.  **혼동 행렬 생성**: `confusion_matrix`를 사용하여 두 모델의 예측 결과를 비교하는 2x2 혼동 행렬을 생성합니다. 이 행렬은 다음과 같은 구조를 가집니다:
    *   `contingency_table[0, 0]`: 모델 1과 모델 2 모두 틀린 샘플 수 ($n_{00}$)
    *   `contingency_table[0, 1]`: 모델 1은 틀리고 모델 2는 맞춘 샘플 수 ($n_{01}$)
    *   `contingency_table[1, 0]`: 모델 1은 맞추고 모델 2는 틀린 샘플 수 ($n_{10}$)
    *   `contingency_table[1, 1]`: 모델 1과 모델 2 모두 맞춘 샘플 수 ($n_{11}$)
    McNemar's Test는 주로 대각선이 아닌 요소들($n_{01}$과 $n_{10}$)에 관심이 있습니다. 이 값들이 크게 다르면 두 모델의 오류 패턴에 유의미한 차이가 있음을 시사합니다.
3.  **McNemar's Test 수행**: `statsmodels.stats.contingency_tables.mcnemar` 함수를 사용하여 McNemar's Test를 수행합니다. `exact=True`는 작은 샘플 크기에서 정확한 p-value를 계산하도록 합니다.
4.  **p-value 해석**: McNemar's Test의 결과로 `statistic` (검정 통계량)과 `pvalue` (p-값)가 반환됩니다.
    *   **p-value < $\alpha$ (유의수준, 보통 0.05)**: 귀무가설을 기각합니다. 이는 두 모델의 성능에 통계적으로 유의미한 차이가 있음을 의미합니다. 즉, 두 모델이 동일한 샘플에 대해 예측 오류를 범하는 방식에 차이가 있다는 결론을 내릴 수 있습니다.
    *   **p-value $\ge$ $\alpha$**: 귀무가설을 채택합니다. 이는 두 모델의 성능에 통계적으로 유의미한 차이가 없음을 의미합니다. 즉, 관찰된 성능 차이는 우연에 의한 것일 가능성이 높습니다.

이 실습을 통해 두 분류 모델의 성능 차이가 단순한 수치적 차이를 넘어 통계적으로 의미 있는 차이인지 객관적으로 판단할 수 있습니다.

### 4.2. Paired t-test 실습 (분류 모델)

Paired t-test는 교차 검증을 통해 얻은 두 모델의 폴드별 성능 점수를 비교하여 평균 성능에 통계적으로 유의미한 차이가 있는지 검정합니다. 이는 모델의 일반화 성능을 더 신뢰성 있게 평가하는 데 도움을 줍니다.

```python
from sklearn.model_selection import cross_val_score, KFold
from scipy import stats # t-test를 위한 라이브러리

# 데이터 로드 (위와 동일)
# X, y = cancer.data, cancer.target

# K-Fold 교차 검증 설정
kf = KFold(n_splits=10, shuffle=True, random_state=42)

# 모델 1 (로지스틱 회귀)의 교차 검증 점수
scores1 = cross_val_score(LogisticRegression(max_iter=2000, random_state=42), X, y, cv=kf, scoring='accuracy')

# 모델 2 (랜덤 포레스트)의 교차 검증 점수
scores2 = cross_val_score(RandomForestClassifier(random_state=42), X, y, cv=kf, scoring='accuracy')

print(f"
모델 1 (로지스틱 회귀) 교차 검증 점수: {scores1}")
print(f"모델 2 (랜덤 포레스트) 교차 검증 점수: {scores2}")

# Paired t-test 수행
t_statistic, p_value = stats.ttest_rel(scores1, scores2) # ttest_rel은 paired t-test

print(f"
Paired t-test statistic: {t_statistic:.4f}")
print(f"Paired t-test p-value: {p_value:.4f}")

# p-value 해석
alpha = 0.05
if p_value < alpha:
    print(f"p-value ({p_value:.4f}) < {alpha} 이므로, 귀무가설 기각. 두 모델의 평균 성능에는 통계적으로 유의미한 차이가 있습니다.")
else:
    print(f"p-value ({p_value:.4f}) >= {alpha} 이므로, 귀무가설 채택. 두 모델의 평균 성능에는 통계적으로 유의미한 차이가 없습니다.")
```

#### 4.2.1. 코드 설명 및 결과 해석

1.  **데이터 및 교차 검증 설정**: 유방암 데이터셋을 사용하며, `KFold`를 이용하여 10-겹 교차 검증을 설정합니다. `shuffle=True`와 `random_state`를 설정하여 재현성을 확보합니다.
2.  **교차 검증 점수 획득**: `cross_val_score` 함수를 사용하여 각 모델(로지스틱 회귀, 랜덤 포레스트)에 대해 10개의 교차 검증 정확도 점수를 얻습니다. 이 점수들은 각 폴드에서 모델이 얼마나 잘 수행되었는지를 나타냅니다.
3.  **Paired t-test 수행**: `scipy.stats.ttest_rel` 함수를 사용하여 두 모델의 교차 검증 점수 배열에 대한 Paired t-test를 수행합니다. 이 함수는 두 배열의 각 요소 간 차이(paired difference)를 기반으로 t-통계량과 p-값을 계산합니다.
4.  **p-value 해석**: Paired t-test의 결과로 `t_statistic` (t-통계량)과 `p_value` (p-값)가 반환됩니다.
    *   **p-value < $\alpha$ (유의수준, 보통 0.05)**: 귀무가설을 기각합니다. 이는 두 모델의 **평균 성능**에 통계적으로 유의미한 차이가 있음을 의미합니다. 즉, 한 모델이 다른 모델보다 전반적으로 더 우수하다고 결론 내릴 수 있습니다.
    *   **p-value $\ge$ $\alpha$**: 귀무가설을 채택합니다. 이는 두 모델의 평균 성능에 통계적으로 유의미한 차이가 없음을 의미합니다. 관찰된 평균 성능 차이는 우연에 의한 것일 가능성이 높습니다.

이 실습은 교차 검증을 통해 얻은 모델의 일반화 성능을 통계적으로 비교하여, 어떤 모델이 더 신뢰성 있게 우수한지 판단하는 데 유용합니다.

### 4.3. Paired t-test 실습 (회귀 모델)

회귀 모델의 성능 비교에도 Paired t-test를 적용할 수 있습니다. 여기서는 캘리포니아 주택 가격 데이터셋을 사용하여 선형 회귀와 릿지 회귀 모델의 평균 제곱 오차(MSE)를 비교합니다.

```python
from sklearn.datasets import fetch_california_housing
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.metrics import mean_squared_error, make_scorer # make_scorer로 MSE를 scoring 함수로 변환
from sklearn.model_selection import cross_val_score, KFold
from scipy import stats # t-test를 위한 라이브러리

# 데이터 로드
housing = fetch_california_housing()
X_reg, y_reg = housing.data, housing.target

# K-Fold 교차 검증 설정
kf_reg = KFold(n_splits=10, shuffle=True, random_state=42)

# MSE를 scoring 함수로 정의 (낮을수록 좋으므로 neg_mean_squared_error 사용 후 -1 곱함)
mse_scorer = make_scorer(mean_squared_error, greater_is_better=False)

# 모델 1 (선형 회귀)의 교차 검증 점수 (MSE)
scores_lr_reg = -cross_val_score(LinearRegression(), X_reg, y_reg, cv=kf_reg, scoring=mse_scorer)

# 모델 2 (릿지 회귀)의 교차 검증 점수 (MSE)
scores_ridge_reg = -cross_val_score(Ridge(alpha=1.0, random_state=42), X_reg, y_reg, cv=kf_reg, scoring=mse_scorer)

print(f"
모델 1 (선형 회귀) 교차 검증 MSE 점수: {scores_lr_reg}")
print(f"모델 2 (릿지 회귀) 교차 검증 MSE 점수: {scores_ridge_reg}")

# Paired t-test 수행
t_statistic_reg, p_value_reg = stats.ttest_rel(scores_lr_reg, scores_ridge_reg)

print(f"
Paired t-test statistic (회귀): {t_statistic_reg:.4f}")
print(f"Paired t-test p-value (회귀): {p_value_reg:.4f}")

# p-value 해석
alpha = 0.05
if p_value_reg < alpha:
    print(f"p-value ({p_value_reg:.4f}) < {alpha} 이므로, 귀무가설 기각. 두 모델의 평균 MSE에는 통계적으로 유의미한 차이가 있습니다.")
else:
    print(f"p-value ({p_value_reg:.4f}) >= {alpha} 이므로, 귀무가설 채택. 두 모델의 평균 MSE에는 통계적으로 유의미한 차이가 없습니다.")
```

#### 4.3.1. 코드 설명 및 결과 해석

1.  **데이터 및 교차 검증 설정**: 캘리포니아 주택 가격 데이터셋을 로드하고, 10-겹 교차 검증을 설정합니다.
2.  **MSE 스코어러 정의**: `mean_squared_error`는 값이 낮을수록 좋은 지표이므로, `cross_val_score`의 `scoring` 파라미터에 직접 사용하면 점수가 음수로 반환됩니다. 이를 양수로 변환하고 `greater_is_better=False`로 설정하여 `make_scorer`를 통해 MSE를 스코어러로 정의합니다. 이렇게 하면 `cross_val_score`가 반환하는 점수가 직관적인 MSE 값이 됩니다.
3.  **교차 검증 점수 획득**: 선형 회귀와 릿지 회귀 모델에 대해 10개의 교차 검증 MSE 점수를 얻습니다.
4.  **Paired t-test 수행**: `scipy.stats.ttest_rel` 함수를 사용하여 두 모델의 MSE 점수 배열에 대한 Paired t-test를 수행합니다.
5.  **p-value 해석**: Paired t-test의 결과로 `t_statistic_reg`와 `p_value_reg`가 반환됩니다.
    *   **p-value < $\alpha$ (유의수준, 보통 0.05)**: 귀무가설을 기각합니다. 이는 두 모델의 **평균 MSE**에 통계적으로 유의미한 차이가 있음을 의미합니다. 만약 `scores_lr_reg`의 평균이 `scores_ridge_reg`의 평균보다 낮고 p-값이 유의미하다면, 선형 회귀 모델이 릿지 회귀 모델보다 통계적으로 유의미하게 더 좋은 성능을 보인다고 해석할 수 있습니다.
    *   **p-value $\ge$ $\alpha$**: 귀무가설을 채택합니다. 이는 두 모델의 평균 MSE에 통계적으로 유의미한 차이가 없음을 의미합니다. 관찰된 평균 MSE 차이는 우연에 의한 것일 가능성이 높습니다.

## 5. 결론: 통계적 검정의 중요성

머신러닝 모델 개발 과정에서 모델의 성능을 평가하고 비교하는 것은 핵심적인 단계입니다. 하지만 단순히 평가 지표의 수치만을 비교하는 것은 여러 가지 한계를 가집니다. 이러한 한계를 극복하고 **더욱 견고하고 신뢰할 수 있는 의사결정**을 내리기 위해 통계적 검정은 필수적인 도구입니다.

**통계적 검정이 중요한 이유를 다시 한번 강조하면 다음과 같습니다:**

1.  **우연과 실제 차이의 구분**: 모델 A가 모델 B보다 0.5% 더 높은 정확도를 보였다고 해서, 이것이 모델 A가 실제로 더 우수하다는 의미는 아닙니다. 데이터의 무작위성, 샘플링 편향, 모델 초기화 등 다양한 요인으로 인해 이러한 차이가 우연히 발생할 수 있습니다. 통계적 검정은 이러한 관찰된 차이가 **우연에 의한 것인지, 아니면 통계적으로 유의미한 실제 차이인지**를 객관적으로 판단할 수 있는 기준을 제공합니다.

2.  **객관적인 모델 선택의 근거**: 비즈니스나 연구 환경에서 모델을 선택할 때는 명확하고 객관적인 근거가 필요합니다. 통계적 검정은 "이 모델이 저 모델보다 통계적으로 유의미하게 더 좋다"는 강력한 주장을 뒷받침할 수 있는 과학적인 증거를 제공합니다. 이는 의사결정의 신뢰도를 높이고, 불필요한 논쟁을 줄이는 데 기여합니다.

3.  **자원 효율성 증대**: 더 복잡하거나 학습 비용이 높은 모델을 도입하는 것은 추가적인 컴퓨팅 자원, 시간, 인력을 요구합니다. 만약 새로운 모델이 기존 모델보다 통계적으로 유의미한 성능 향상을 가져오지 못한다면, 이러한 투자는 비효율적일 수 있습니다. 통계적 검정은 자원을 효율적으로 배분하고, '투자 대비 효과'를 판단하는 데 중요한 기준이 됩니다.

4.  **모델의 일반화 성능에 대한 확신**: 우리는 모델이 학습 데이터뿐만 아니라, 실제 환경에서 마주할 새로운 데이터에 대해서도 잘 작동하기를 기대합니다. 교차 검증과 함께 통계적 검정을 사용하면, 모델이 다양한 데이터 분할에서도 일관되게 우수한 성능을 보일 것이라는 **일반화 성능에 대한 더 큰 확신**을 얻을 수 있습니다.

5.  **과학적 연구 및 보고의 필수 요소**: 머신러닝 관련 논문이나 연구 보고서에서는 모델 성능 비교 시 통계적 유의성을 검증하는 것이 표준적인 요구사항입니다. 이는 연구 결과의 타당성과 신뢰성을 높이는 데 필수적입니다.

**결론적으로,** 머신러닝 모델 성능 비교를 위한 통계적 검정은 단순한 숫자의 나열을 넘어, 데이터 과학자가 **더욱 정교하고 합리적인 의사결정**을 내릴 수 있도록 돕는 강력한 도구입니다. 이는 모델 개발의 전반적인 품질을 향상시키고, 실제 문제 해결에 기여하는 신뢰성 높은 머신러닝 솔루션을 구축하는 데 필수적인 역량입니다.
