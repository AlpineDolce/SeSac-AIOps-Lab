## 1. 의사결정 트리 회귀 (Decision Tree Regression)

### 1.1. 핵심 개념
의사결정 트리 회귀 모델은 분류와 유사하게 트리 구조를 사용하여 예측을 수행합니다. 하지만 리프 노드에서 클래스를 예측하는 대신, 해당 노드에 속한 데이터 포인트들의 **평균값**을 예측값으로 사용합니다.

트리는 각 분기에서 데이터의 **분산(Variance)을 가장 많이 줄이는 방향**으로 학습됩니다. 즉, 분기 후 각 노드에 속한 데이터들의 타겟 값(y)이 최대한 균일해지도록 하는 특성과 분할 지점을 찾습니다. 일반적으로 분산 대신 **평균 제곱 오차(Mean Squared Error, MSE)**를 불순도(Impurity) 측정 기준으로 사용합니다.

### 1.2. 장단점
*   **장점:**
    *   모델의 구조가 직관적이고 해석이 용이합니다.
    *   데이터 스케일링 등 전처리가 거의 필요 없습니다.
    *   비선형적인 관계도 학습할 수 있습니다.
*   **단점:**
    *   과적합되기 매우 쉬워, 가지치기(Pruning) 등 규제가 필수적입니다. (`max_depth` 등)
    *   데이터의 작은 변화에도 모델이 크게 변동할 수 있어 안정성이 낮습니다.

## 2. 앙상블 회귀 모델 (Ensemble Regressors)
분류 문제와 마찬가지로, 회귀 문제에서도 여러 개의 약한 학습기(주로 의사결정 트리)를 결합하여 성능을 높이는 앙상블 기법이 매우 효과적입니다.

### 2.1. 랜덤 포레스트 회귀 (Random Forest Regressor)
랜덤 포레스트는 **배깅(Bagging)**을 기반으로 하는 앙상블 모델입니다. 여러 개의 의사결정 트리 회귀 모델을 독립적으로 학습시킨 후, 각 트리가 예측한 값들의 **평균**을 최종 예측값으로 사용합니다. 이를 통해 단일 의사결정 트리의 가장 큰 단점인 과적합 문제를 효과적으로 해결하고 안정적인 성능을 냅니다.

### 2.2. 그레디언트 부스팅 회귀 (Gradient Boosting Regressor)
그레디언트 부스팅은 **부스팅(Boosting)**을 기반으로 하는 앙상블 모델입니다. 여러 개의 의사결정 트리를 순차적으로 학습시키며, 이전 트리가 예측하지 못한 **오차(잔차, Residual)**를 다음 트리가 학습하도록 합니다. 이 과정을 반복하며 점진적으로 모델의 성능을 향상시킵니다. 일반적으로 랜덤 포레스트보다 더 높은 예측 성능을 보이지만, 하이퍼파라미터에 더 민감하고 학습 시간이 더 오래 걸릴 수 있습니다.

## 3. 실습: 캘리포니아 주택 가격 예측

### 3.1. 데이터 준비
일관된 비교를 위해 모든 모델에 동일한 데이터를 사용합니다.
```python
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split

# 데이터 로드
housing = fetch_california_housing()
X, y = housing.data, housing.target

# 훈련/테스트 데이터 분리
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
```

### 3.2. 의사결정 트리 회귀 모델
```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_squared_error

# 모델 생성 및 학습
# max_depth를 지정하여 과적합을 제어하는 것이 중요
tree_reg = DecisionTreeRegressor(max_depth=5, random_state=42)
tree_reg.fit(X_train, y_train)

# 예측 및 평가
y_pred_tree = tree_reg.predict(X_test)
mse_tree = mean_squared_error(y_test, y_pred_tree)
print(f"의사결정 트리 회귀 MSE: {mse_tree:.4f}")
```

### 3.3. 랜덤 포레스트 회귀 모델
```python
from sklearn.ensemble import RandomForestRegressor

# 모델 생성 및 학습
# n_jobs=-1: 사용 가능한 모든 CPU 코어 사용
rf_reg = RandomForestRegressor(n_estimators=100, random_state=42, n_jobs=-1)
rf_reg.fit(X_train, y_train)

# 예측 및 평가
y_pred_rf = rf_reg.predict(X_test)
mse_rf = mean_squared_error(y_test, y_pred_rf)
print(f"랜덤 포레스트 회귀 MSE: {mse_rf:.4f}")
```

### 3.4. 그레디언트 부스팅 회귀 모델
```python
from sklearn.ensemble import GradientBoostingRegressor

# 모델 생성 및 학습
gb_reg = GradientBoostingRegressor(n_estimators=100, learning_rate=0.1, max_depth=3, random_state=42)
gb_reg.fit(X_train, y_train)

# 예측 및 평가
y_pred_gb = gb_reg.predict(X_test)
mse_gb = mean_squared_error(y_test, y_pred_gb)
print(f"그레디언트 부스팅 회귀 MSE: {mse_gb:.4f}")
```

## 4. 어떤 트리 기반 회귀 모델을 선택해야 할까?

| 모델 | 주요 특징 | 사용 추천 상황 |
| :--- | :--- | :--- |
| **의사결정 트리** | 단일 트리, 해석 용이 | 베이스라인 모델, 모델의 결정 과정을 시각적으로 이해하고 싶을 때 |
| **랜덤 포레스트** | 배깅 기반, 과적합에 강함, 병렬 처리 가능 | 안정적이고 준수한 성능이 필요할 때, 하이퍼파라미터 튜닝에 많은 시간을 쏟기 어려울 때 |
| **그레디언트 부스팅** | 부스팅 기반, 높은 예측 성능 | 최고의 성능을 목표로 할 때, 하이퍼파라미터 튜닝을 통해 성능을 극한으로 끌어올리고 싶을 때 |

**결론:** 일반적으로 **랜덤 포레스트**로 시작하여 안정적인 베이스라인 성능을 확보한 후, 더 높은 성능이 필요할 경우 **그레디언트 부스팅** 모델을 시도하고 하이퍼파라미터를 튜닝하는 접근 방식이 효과적입니다. 단일 **의사결정 트리**는 최종 모델보다는 데이터의 구조를 이해하거나 앙상블의 기본 원리를 학습하는 데 주로 사용됩니다.
