## 1. 이상 탐지(Anomaly Detection)란?
이상 탐지는 대다수의 정상적인 데이터와는 다른, 예상치 못한 패턴을 보이는 데이터 포인트(이상치 또는 이상값)를 식별하는 기술입니다. 대부분의 경우 레이블이 없는 비지도 학습 방식으로 접근하지만, 일부 정상/비정상 레이블이 있는 경우 지도 학습이나 준지도 학습으로도 해결할 수 있습니다.

### 1.1. 이상 탐지의 중요성 및 활용 분야
*   **사기 탐지 (Fraud Detection):** 신용카드 거래, 보험 청구 등에서 비정상적인 패턴을 감지하여 금융 사기를 방지합니다.
*   **제조업 품질 관리:** 생산 공정에서 발생하는 불량품이나 장비의 이상 신호를 감지합니다.
*   **IT 시스템 모니터링:** 네트워크 침입, 시스템 오류, 비정상적인 트래픽 등 보안 위협이나 시스템 장애를 조기에 발견합니다.
*   **의료:** 환자의 생체 신호에서 비정상적인 패턴을 감지하여 질병을 조기에 진단합니다.

### 1.2. 이상치의 종류
*   **점 이상치 (Point Anomaly):** 개별 데이터 포인트 자체가 전체 데이터 분포에서 크게 벗어나는 경우.
*   **문맥적 이상치 (Contextual Anomaly):** 특정 문맥에서는 정상이지만, 다른 문맥에서는 이상치로 간주되는 경우. (예: 여름에 코트 판매량이 급증하는 경우)
*   **집단적 이상치 (Collective Anomaly):** 개별 데이터 포인트는 정상이지만, 여러 데이터 포인트가 모여서 비정상적인 패턴을 형성하는 경우.

## 2. Isolation Forest

### 2.1. 핵심 원리
Isolation Forest는 "고립"이라는 개념을 기반으로 하는 효율적인 이상 탐지 알고리즘입니다. 핵심 아이디어는 다음과 같습니다.
> **"이상치는 정상 데이터보다 더 적은 분할(split)로 고립시키기 쉽다."**

알고리즘은 데이터를 무작위로 분할하는 여러 개의 트리(Isolation Tree)를 생성합니다. 정상 데이터는 트리의 깊은 곳까지 내려가야 고립되지만, 이상치는 트리의 상단부에서 적은 분할만으로도 쉽게 고립됩니다. 각 데이터 포인트에 대해 모든 트리에서의 평균 경로 길이를 계산하여 이상 점수(anomaly score)를 산출하고, 이를 통해 이상치를 판별합니다.

### 2.2. 장단점
*   **장점:**
    *   대용량 데이터셋에서도 빠르고 효율적으로 작동합니다.
    *   데이터의 분포에 대한 가정이 필요 없습니다.
    *   고차원 데이터에서도 잘 작동합니다.
*   **단점:**
    *   지역적인 밀도 차이가 큰 데이터셋에서는 성능이 저하될 수 있습니다.

## 3. One-Class SVM

### 3.1. 핵심 원리
One-Class SVM은 이름에서 알 수 있듯이, **하나의 클래스(정상 데이터)만을 학습**하여 정상 데이터의 경계(boundary)를 찾는 알고리즘입니다. 이 경계 밖에 위치하는 데이터 포인트를 이상치로 간주합니다.

일반적인 SVM이 두 클래스를 나누는 초평면을 찾는 것과 달리, One-Class SVM은 원점을 기준으로 모든 정상 데이터를 둘러싸는 가장 작은 초구(hypersphere) 또는 경계를 찾으려고 합니다. 커널 트릭을 사용하여 비선형적인 데이터 분포에 대한 경계도 찾을 수 있습니다.

### 3.2. 주요 하이퍼파라미터
*   `nu` (nu): 훈련 데이터에서 이상치로 간주될 비율의 상한선이자, 서포트 벡터의 비율의 하한선을 결정하는 중요한 파라미터입니다. 0과 1 사이의 값을 가집니다.
*   `kernel`: 데이터를 매핑할 커널 함수를 지정합니다. (`'rbf'`, `'poly'` 등)
*   `gamma`: RBF 커널의 영향 범위를 조절합니다.

## 4. 실습: 이상 탐지 모델 구현

### 4.1. Isolation Forest 실습
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.ensemble import IsolationForest

# 데이터 생성
rng = np.random.RandomState(42)
X_train = 0.2 * rng.randn(1000, 2)
X_train = np.r_[X_train + 2, X_train - 2] # 정상 데이터
X_outliers = rng.uniform(low=-4, high=4, size=(50, 2)) # 이상치
X = np.r_[X_train, X_outliers]

# Isolation Forest 모델 생성 및 학습
clf = IsolationForest(n_estimators=100, contamination='auto', random_state=42)
y_pred = clf.fit_predict(X) # -1: 이상치, 1: 정상

# 결과 시각화
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=y_pred, cmap='viridis')
plt.title("Isolation Forest Anomaly Detection")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.show()
```

### 4.2. One-Class SVM 실습
```python
from sklearn.svm import OneClassSVM

# 데이터는 위와 동일
# One-Class SVM 모델 생성 및 학습
# nu: 예상되는 이상치 비율 (예: 50/1050)
svm_clf = OneClassSVM(gamma='auto', nu=0.05)
y_pred_svm = svm_clf.fit_predict(X) # -1: 이상치, 1: 정상

# 결과 시각화
plt.figure(figsize=(8, 6))
plt.scatter(X[:, 0], X[:, 1], c=y_pred_svm, cmap='viridis')
plt.title("One-Class SVM Anomaly Detection")
plt.xlabel("Feature 1")
plt.ylabel("Feature 2")
plt.show()
```

## 5. 다른 이상 탐지 기법들
*   **Local Outlier Factor (LOF):** 개별 데이터 포인트의 지역적인 밀도를 주변 이웃과 비교하여 이상치를 탐지합니다. 데이터의 지역적 밀도 차이가 클 때 유용합니다.
*   **타원 봉투 (Elliptic Envelope):** 데이터가 가우시안 분포를 따른다고 가정하고, 데이터의 중심에 타원을 그려 그 밖에 있는 데이터를 이상치로 식별합니다.
*   **Autoencoders (딥러닝 기반):** 정상 데이터를 잘 복원하도록 오토인코더를 학습시킨 후, 복원 오차(reconstruction error)가 큰 데이터를 이상치로 탐지합니다. 복잡한 비선형 데이터에 효과적입니다.
