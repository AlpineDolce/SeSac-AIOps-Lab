## 1. 클러스터링(Clustering)이란?
클러스터링은 **레이블이 없는(unlabeled)** 데이터들을 유사한 특성을 가진 데이터들끼리 그룹(클러스터)으로 묶는 대표적인 비지도 학습 기법입니다. 데이터의 숨겨진 구조나 패턴을 발견하는 데 사용되며, 다음과 같은 다양한 분야에서 활용됩니다.
*   **고객 세분화 (Customer Segmentation):** 구매 패턴, 인구 통계 정보 등을 기반으로 고객들을 여러 그룹으로 나누어 타겟 마케팅 전략을 수립합니다.
*   **이미지 분할 (Image Segmentation):** 이미지의 픽셀들을 유사한 색상이나 질감을 가진 영역으로 그룹화합니다.
*   **이상 탐지 (Anomaly Detection):** 어떤 클러스터에도 속하지 않는 데이터 포인트를 이상치로 간주하여 탐지합니다.

## 2. K-평균 (K-Means)

### 2.1. 핵심 원리
K-평균은 가장 널리 사용되는 클러스터링 알고리즘 중 하나로, 데이터를 미리 정해진 **K개의 클러스터**로 나누는 것을 목표로 합니다.

1.  **초기화:** K개의 클러스터 중심(Centroid)을 임의로 선택합니다.
2.  **할당:** 각 데이터 포인트를 가장 가까운 클러스터 중심에 할당합니다.
3.  **업데이트:** 각 클러스터에 속한 데이터 포인트들의 평균값으로 클러스터 중심을 새로 계산하여 이동시킵니다.
4.  **반복:** 클러스터 중심이 더 이상 변하지 않을 때까지 2번과 3번 과정을 반복합니다.

### 2.2. 최적의 K 찾기: 엘보우 방법 (Elbow Method)
K-평균의 가장 큰 단점은 최적의 클러스터 개수(K)를 미리 지정해야 한다는 것입니다. **엘보우 방법**은 K값을 변화시켜가며 각 K에 대한 클러스터 내 오차 제곱합(Inertia)을 계산하고, 이 값이 급격하게 줄어드는 지점(팔꿈치처럼 꺾이는 부분)을 최적의 K로 판단하는 방법입니다.

### 2.3. 장단점 및 사용 시나리오
*   **장점:** 알고리즘이 간단하고 빠르며, 대용량 데이터에도 적용 가능합니다.
*   **단점:**
    *   최적의 클러스터 개수(K)를 사전에 지정해야 합니다.
    *   클러스터의 모양이 원형(spherical)이라고 가정하므로, 길쭉하거나 복잡한 모양의 클러스터는 잘 찾지 못합니다.
    *   초기 중심 위치에 따라 결과가 달라질 수 있습니다.
*   **사용 시나리오:** 클러스터의 개수를 대략적으로 알고 있고, 데이터가 구형으로 군집화될 수 있을 때 효과적입니다.

## 3. DBSCAN (Density-Based Spatial Clustering of Applications with Noise)

### 3.1. 핵심 원리
DBSCAN은 데이터의 **밀도(Density)**를 기반으로 클러스터를 형성하는 알고리즘입니다. K-평균과 달리 클러스터의 개수를 미리 지정할 필요가 없으며, 복잡한 모양의 클러스터도 잘 찾아냅니다.

*   **`eps` (epsilon):** 개별 데이터 포인트를 중심으로 하는 이웃의 반경.
*   **`min_samples`:** 하나의 클러스터를 형성하기 위해 `eps` 반경 내에 포함되어야 하는 최소 데이터 포인트의 수.
*   **핵심 포인트(Core Point):** `eps` 반경 내에 `min_samples` 이상의 포인트를 가진 데이터.
*   **경계 포인트(Border Point):** 다른 핵심 포인트의 `eps` 반경 내에 있지만, 자신은 핵심 포인트가 아닌 데이터.
*   **노이즈(Noise):** 핵심 포인트도, 경계 포인트도 아닌 데이터.

### 3.2. 장단점 및 사용 시나리오
*   **장점:**
    *   클러스터 개수를 미리 지정할 필요가 없습니다.
    *   임의의 모양을 가진 클러스터를 찾을 수 있습니다.
    *   노이즈(이상치)를 효과적으로 식별합니다.
*   **단점:**
    *   데이터 밀도가 다양한 경우 성능이 떨어질 수 있습니다.
    *   고차원 데이터(많은 특성)에서는 거리 계산이 어려워 성능이 저하됩니다.
*   **사용 시나리오:** 데이터에 노이즈가 많거나, 클러스터의 모양이 비정형적일 때 유용합니다.

## 4. 계층적 군집 분석 (Hierarchical Clustering)

### 4.1. 핵심 원리
계층적 군집 분석은 개별 데이터 포인트를 클러스터로 간주하여 시작한 후, 가장 가까운 클러스터들을 점진적으로 병합해 나가는 **상향식(bottom-up) 또는 병합(agglomerative)** 방식을 사용합니다. 이 과정을 통해 데이터 포인트들이 어떻게 그룹화되는지에 대한 계층적인 구조(나무 모양)를 만들 수 있습니다.

*   **연결 기준(Linkage Criteria):** 클러스터 간의 거리를 측정하는 방법입니다.
    *   `ward`: 클러스터 내의 분산을 최소화하는 방향으로 병합합니다. (기본값)
    *   `complete`: 두 클러스터에 속한 데이터 포인트 간의 최대 거리를 기준으로 합니다.
    *   `average`: 두 클러스터에 속한 모든 데이터 포인트 간의 평균 거리를 기준으로 합니다.

### 4.2. 덴드로그램 (Dendrogram)
계층적 군집 분석의 결과는 **덴드로그램**이라는 트리 다이어그램으로 시각화할 수 있습니다. 덴드로그램을 통해 데이터가 어떤 계층 구조로 묶이는지, 그리고 적절한 클러스터 개수가 몇 개인지 시각적으로 판단할 수 있습니다.

## 5. 실습 및 알고리즘 비교

### 5.1. 데이터 준비

```python
from sklearn.datasets import make_blobs, make_moons
from sklearn.preprocessing import StandardScaler
import numpy as np

# K-Means와 계층적 군집 분석을 위한 데이터
X_blobs, y_blobs = make_blobs(n_samples=300, centers=4, cluster_std=0.8, random_state=42)
X_blobs = StandardScaler().fit_transform(X_blobs)

# DBSCAN을 위한 데이터
X_moons, y_moons = make_moons(n_samples=200, noise=0.05, random_state=42)
X_moons = StandardScaler().fit_transform(X_moons)
```

(실제 코드에서는 각 모델을 학습시키고, `matplotlib`이나 `seaborn`을 사용하여 결과를 시각화합니다.)

## 7. 클러스터링 평가 지표
클러스터링은 비지도 학습이므로, 분류나 회귀처럼 명확한 정답(레이블)이 없어 모델 성능을 평가하기가 더 어렵습니다. 하지만 클러스터링의 품질을 객관적으로 측정하기 위한 다양한 지표들이 존재합니다. 이 지표들은 크게 **내부 평가 지표**와 **외부 평가 지표**로 나뉩니다.

### 7.1. 내부 평가 지표 (Internal Evaluation Metrics)
실제 레이블(정답)이 없는 상황에서 클러스터링 결과 자체의 품질을 평가합니다. 클러스터 내의 응집도(cohesion)와 클러스터 간의 분리도(separation)를 측정합니다.

#### 7.1.1. 실루엣 점수 (Silhouette Score)
각 데이터 포인트가 자신의 클러스터에 얼마나 잘 군집되어 있는지, 그리고 다른 클러스터와 얼마나 잘 분리되어 있는지를 측정합니다.
*   **범위:** -1에서 1 사이.
*   **해석:**
    *   1에 가까울수록: 자신의 클러스터에 잘 군집되어 있고, 다른 클러스터와 잘 분리됨.
    *   0에 가까울수록: 클러스터 경계에 위치하여 모호함.
    *   -1에 가까울수록: 잘못된 클러스터에 할당됨.
*   **장점:** 클러스터의 밀도와 분리도를 동시에 고려.
*   **단점:** 볼록한(convex) 클러스터에 유리하며, 고차원 데이터에서는 성능이 저하될 수 있음.

```python
from sklearn.metrics import silhouette_score
from sklearn.cluster import KMeans

# 데이터 준비 (K-Means 실습의 X_scaled 사용)
# X_scaled는 make_blobs로 생성된 스케일링된 데이터

# K=3으로 클러스터링
kmeans_3 = KMeans(n_clusters=3, random_state=42, n_init=10)
labels_3 = kmeans_3.fit_predict(X_blobs)
score_3 = silhouette_score(X_blobs, labels_3)
print(f"K=3일 때 실루엣 점수: {score_3:.4f}")

# K=4로 클러스터링
kmeans_4 = KMeans(n_clusters=4, random_state=42, n_init=10)
labels_4 = kmeans_4.fit_predict(X_blobs)
score_4 = silhouette_score(X_blobs, labels_4)
print(f"K=4일 때 실루엣 점수: {score_4:.4f}")
```

#### 7.1.2. 데이비스-볼딘 지수 (Davies-Bouldin Index)
클러스터 내의 분산과 클러스터 간의 거리를 기반으로 클러스터링의 품질을 평가합니다.
*   **범위:** 0 이상.
*   **해석:** **값이 작을수록** 좋은 클러스터링을 의미합니다 (클러스터 내 응집도는 높고, 클러스터 간 분리도는 높음).
*   **장점:** 클러스터의 모양에 덜 민감.
*   **단점:** 클러스터가 겹치는 경우 정확하지 않을 수 있음.

```python
from sklearn.metrics import davies_bouldin_score

# K=3일 때 데이비스-볼딘 지수
db_score_3 = davies_bouldin_score(X_blobs, labels_3)
print(f"K=3일 때 데이비스-볼딘 지수: {db_score_3:.4f}")

# K=4일 때 데이비스-볼딘 지수
db_score_4 = davies_bouldin_score(X_blobs, labels_4)
print(f"K=4일 때 데이비스-볼딘 지수: {db_score_4:.4f}")
```

#### 7.1.3. 칼린스키-하라바즈 지수 (Calinski-Harabasz Index)
클러스터 간의 분산과 클러스터 내의 분산 비율을 기반으로 클러스터링의 품질을 평가합니다.
*   **범위:** 0 이상.
*   **해석:** **값이 클수록** 좋은 클러스터링을 의미합니다 (클러스터 간 분리도는 높고, 클러스터 내 응집도는 높음).
*   **장점:** 계산이 빠름.
*   **단점:** 볼록한 클러스터에 유리.

```python
from sklearn.metrics import calinski_harabasz_score

# K=3일 때 칼린스키-하라바즈 지수
ch_score_3 = calinski_harabasz_score(X_blobs, labels_3)
print(f"K=3일 때 칼린스키-하라바즈 지수: {ch_score_3:.4f}")

# K=4일 때 칼린스키-하라바즈 지수
ch_score_4 = calinski_harabasz_score(X_blobs, labels_4)
print(f"K=4일 때 칼린스키-하라바즈 지수: {ch_score_4:.4f}")
```

### 7.2. 외부 평가 지표 (External Evaluation Metrics)
클러스터링 결과와 **실제 레이블(정답)**을 비교하여 클러스터링의 품질을 평가합니다. 실제 레이블이 있는 경우에만 사용할 수 있습니다.

#### 7.2.1. 조정 랜드 지수 (Adjusted Rand Index, ARI)
두 클러스터링 결과(모델의 클러스터링과 실제 레이블)가 얼마나 유사한지 측정합니다. 무작위 할당에 의해 얻을 수 있는 점수를 보정하여 0에 가까우면 무작위, 1에 가까우면 완벽한 일치를 의미합니다.
*   **범위:** -1에서 1 사이.
*   **해석:** 1에 가까울수록 두 클러스터링이 완벽하게 일치함을 의미.

```python
from sklearn.metrics import adjusted_rand_score

# K-Means 실습의 X_blobs와 y_blobs (실제 레이블) 사용
# labels_3는 K=3으로 클러스터링한 결과

# K=3일 때 ARI (실제 레이블 y_blobs와 비교)
ari_3 = adjusted_rand_score(y_blobs, labels_3)
print(f"K=3일 때 ARI: {ari_3:.4f}")

# K=4일 때 ARI (실제 레이블 y_blobs와 비교)
ari_4 = adjusted_rand_score(y_blobs, labels_4)
print(f"K=4일 때 ARI: {ari_4:.4f}")
```

#### 7.2.2. 상호 정보량 기반 지표 (Mutual Information based scores)
두 클러스터링 결과 간의 상호 정보량(Mutual Information)을 기반으로 합니다.
*   **Homogeneity (동질성):** 각 클러스터가 단일 클래스의 샘플만 포함하는 정도.
*   **Completeness (완전성):** 동일 클래스의 샘플이 모두 동일한 클러스터에 할당되는 정도.
*   **V-measure:** Homogeneity와 Completeness의 조화 평균.

*   **범위:** 0에서 1 사이.
*   **해석:** 1에 가까울수록 좋은 클러스터링을 의미.

```python
from sklearn.metrics import homogeneity_score, completeness_score, v_measure_score

# K=3일 때 상호 정보량 기반 지표
homogeneity_3 = homogeneity_score(y_blobs, labels_3)
completeness_3 = completeness_score(y_blobs, labels_3)
v_measure_3 = v_measure_score(y_blobs, labels_3)

print(f"K=3일 때 Homogeneity: {homogeneity_3:.4f}")
print(f"K=3일 때 Completeness: {completeness_3:.4f}")
print(f"K=3일 때 V-measure: {v_measure_3:.4f}")

# K=4일 때 상호 정보량 기반 지표
homogeneity_4 = homogeneity_score(y_blobs, labels_4)
completeness_4 = completeness_score(y_blobs, labels_4)
v_measure_4 = v_measure_score(y_blobs, labels_4)

print(f"K=4일 때 Homogeneity: {homogeneity_4:.4f}")
print(f"K=4일 때 Completeness: {completeness_4:.4f}")
print(f"K=4일 때 V-measure: {v_measure_4:.4f}")
```

## 8. 결론: 클러스터링 평가 시 고려사항
*   **목표에 맞는 지표 선택:** 클러스터링의 목적(예: 데이터 탐색, 특정 클래스 분리)에 따라 적절한 평가 지표를 선택해야 합니다.
*   **내부 vs. 외부 지표:** 실제 레이블이 있다면 외부 지표를 우선적으로 고려하고, 없다면 내부 지표를 활용하여 클러스터링의 품질을 평가합니다.
*   **여러 지표 종합:** 단일 지표에만 의존하기보다는 여러 지표를 종합적으로 고려하여 클러스터링 결과를 판단하는 것이 중요합니다.
*   **시각화와 함께:** 평가 지표는 숫자로 된 요약일 뿐입니다. 항상 클러스터링 결과를 시각화하여 지표가 나타내는 바를 직관적으로 확인해야 합니다.
