## 1. 문제 정의 및 데이터 로드

**MNIST(Modified National Institute of Standards and Technology) 데이터셋**은 0부터 9까지의 손글씨 숫자 이미지로 구성된 대규모 데이터셋입니다. 이는 컴퓨터 비전 분야에서 이미지 분류 문제의 'Hello World'와 같은 고전적인 예제로 널리 사용되며, 다양한 머신러닝 및 딥러닝 알고리즘의 성능을 벤치마킹하는 데 활용됩니다.

**문제의 중요성:**
*   **다중 클래스 분류의 기본:** 10개의 클래스(0~9)를 분류하는 다중 클래스 분류(Multi-class Classification) 문제 해결을 위한 기본적인 머신러닝 워크플로우를 학습하는 데 매우 적합합니다.
*   **이미지 데이터 전처리:** 이미지 데이터를 모델이 이해할 수 있는 형태로 변환하는 과정(픽셀 값 정규화, 평탄화 등)을 연습하기 좋습니다.
*   **모델 평가:** 정확도 외에 혼동 행렬, 분류 보고서 등 다중 클래스 분류 모델 평가 지표의 중요성을 이해하는 데 도움이 됩니다.

**데이터셋 특징:**
*   **이미지 크기:** 원본 MNIST 이미지는 28x28 픽셀의 흑백 이미지입니다. Scikit-learn의 `load_digits`는 8x8 픽셀의 축소된 버전을 제공합니다.
*   **픽셀 값:** 각 픽셀은 0(검은색)부터 255(흰색)까지의 정수 값을 가집니다.
*   **클래스:** 0부터 9까지의 10개 숫자 클래스.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_digits # MNIST와 유사한 digits 데이터셋 로드
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix

# 1. MNIST와 유사한 digits 데이터셋 로드 (Scikit-learn 내장)
# load_digits() 함수는 손글씨 숫자 이미지 데이터셋을 로드합니다.
# X는 이미지 데이터(픽셀 값), y는 해당 이미지의 실제 숫자 레이블입니다.
digits = load_digits()
X, y = digits.data, digits.target

print("데이터셋 로드 완료.")
print(f"이미지 데이터 형태 (X): {X.shape}") # (샘플 수, 픽셀 수) - 1797개의 8x8 이미지이므로 1797x64
print(f"레이블 데이터 형태 (y): {y.shape}") # (샘플 수) - 1797개의 레이블
print(f"타겟 변수(숫자) 분포:\n{pd.Series(y).value_counts().sort_index()}")

# 2. 첫 번째 이미지 시각화
# X[0]은 첫 번째 이미지의 픽셀 값 배열입니다. 이를 8x8 형태로 재구성하여 이미지로 표시합니다.
plt.figure(figsize=(4, 4))
plt.imshow(X[0].reshape(8, 8), cmap='gray') # digits 데이터는 8x8 이미지이므로 reshape(8, 8)
plt.title(f"Label: {y[0]}") # 이미지의 실제 레이블을 제목으로 표시
plt.axis('off') # 축 정보 숨기기
plt.show()
```

**데이터 로드 시 고려사항:**
*   **데이터 형태:** Scikit-learn의 `load_digits`는 이미지를 1차원 배열(평탄화된 형태)로 로드합니다. 대부분의 Scikit-learn 모델은 이러한 2D 배열(샘플 수, 특성 수) 형태를 입력으로 기대합니다.
*   **실제 MNIST 데이터:** 더 큰 28x28 픽셀의 원본 MNIST 데이터셋은 `tensorflow.keras.datasets.mnist.load_data()`나 `torchvision.datasets.MNIST` 등을 통해 로드할 수 있습니다. 이 경우 픽셀 값이 0-255 범위이므로 추가적인 정규화가 필요합니다.
*   **클래스 분포:** MNIST 데이터셋은 클래스별 샘플 수가 비교적 균등하여 클래스 불균형 문제는 크지 않습니다.


## 2. 이미지 데이터 전처리

### 2.1. 데이터 형태 확인 및 변환
이미지 데이터는 픽셀 값의 배열로 구성됩니다. 머신러닝 모델, 특히 Scikit-learn의 전통적인 모델들은 일반적으로 2차원 배열 형태의 데이터를 입력으로 기대합니다. 여기서 각 행은 하나의 샘플(이미지)을 나타내고, 각 열은 하나의 특성(픽셀)을 나타냅니다.

*   **Scikit-learn 모델의 입력 형태:**
    *   `X` (특성 데이터): `(n_samples, n_features)` 형태의 2차원 배열.
    *   `y` (타겟 레이블): `(n_samples,)` 형태의 1차원 배열.

*   **이미지 데이터의 평탄화 (Flattening):**
    *   원본 이미지는 보통 `(height, width)` (흑백) 또는 `(height, width, channels)` (컬러)와 같은 2차원 또는 3차원 배열 형태입니다.
    *   Scikit-learn 모델에 입력하기 위해서는 이 다차원 배열을 1차원 벡터로 '평탄화(flattening)'해야 합니다. 예를 들어, 8x8 픽셀 이미지는 64개의 특성을 가진 1차원 벡터로 변환됩니다.

*   **MNIST (digits) 데이터셋의 경우:**
    *   Scikit-learn의 `load_digits()` 함수는 이미지를 로드할 때 자동으로 픽셀 데이터를 1차원 배열로 평탄화하여 `(n_samples, n_pixels)` 형태의 2차원 배열로 제공합니다. 따라서 이 데이터셋의 경우 추가적인 형태 변환은 필요 없습니다.

```python
# X는 이미 load_digits()에 의해 1차원 배열로 평탄화되어 있습니다.
# digits 데이터셋의 각 이미지는 8x8 픽셀이므로, 64개의 특성을 가집니다.
print(f"\n이미지 데이터 형태 (X): {X.shape}") # (샘플 수, 픽셀 수)
print(f"레이블 데이터 형태 (y): {y.shape}") # (샘플 수)

# 첫 번째 이미지의 픽셀 값 (평탄화된 형태)
print(f"첫 번째 이미지 픽셀 값 (일부, 평탄화): {X[0, :10]}")

# 이미지를 다시 2D 형태로 변환하여 시각화할 수 있습니다.
plt.figure(figsize=(4, 4))
plt.imshow(X[0].reshape(8, 8), cmap='gray') # 8x8 이미지로 재구성
plt.title(f"Label: {y[0]}")
plt.axis('off')
plt.show()
```

**데이터 형태 확인 및 변환 시 고려사항:**
*   **모델 요구사항:** 사용하는 머신러닝 모델이 어떤 형태의 입력을 기대하는지 항상 확인해야 합니다. 대부분의 Scikit-learn 모델은 `(n_samples, n_features)` 형태를 요구합니다.
*   **평탄화의 의미:** 이미지를 평탄화하면 픽셀 간의 공간적 관계 정보가 손실됩니다. 이는 전통적인 머신러닝 모델(예: 로지스틱 회귀, SVM)에는 큰 문제가 되지 않지만, 이미지의 공간적 특징을 학습하는 데 특화된 CNN(Convolutional Neural Network)과 같은 딥러닝 모델에서는 원본 이미지 형태를 유지하는 것이 중요합니다.
*   **데이터 타입:** 픽셀 값은 일반적으로 정수형이지만, 모델 학습을 위해 부동 소수점 형태로 변환하는 것이 일반적입니다 (예: `X.astype(float)`).


### 2.2. 픽셀 값 정규화
이미지 픽셀 값은 일반적으로 0부터 255까지의 정수 범위에 있습니다 (흑백 이미지의 경우 0은 검은색, 255는 흰색). 머신러닝 모델, 특히 신경망 기반 모델은 입력 특성들의 스케일이 크게 다를 경우 학습이 불안정해지거나 수렴 속도가 느려질 수 있습니다. 따라서 모델 학습 전에 픽셀 값들을 일정한 범위로 정규화하거나 표준화하는 것이 필수적입니다.

*   **정규화(Normalization)의 필요성:**
    *   **모델 학습 안정화:** 큰 범위의 픽셀 값은 모델의 가중치 업데이트에 영향을 미쳐 학습 과정을 불안정하게 만들 수 있습니다.
    *   **수렴 속도 향상:** 정규화된 데이터는 모델이 최적의 가중치를 찾는 데 필요한 반복 횟수를 줄여 학습 속도를 향상시킵니다.
    *   **성능 향상:** 많은 머신러닝 알고리즘(예: SVM, 신경망)은 스케일링된 데이터에서 더 좋은 성능을 보입니다.

*   **일반적인 정규화 방법:**
    *   **0-1 스케일링:** 픽셀 값을 0과 1 사이의 범위로 조정합니다. 이는 각 픽셀 값을 최대 픽셀 값(일반적으로 255)으로 나누는 방식으로 간단하게 수행할 수 있습니다.
    *   **표준화(Standardization):** `StandardScaler`를 사용하여 각 픽셀 특성의 평균을 0으로, 표준편차를 1로 조정합니다. 이는 데이터의 분포가 정규 분포를 따르지 않아도 사용할 수 있습니다.

*   **digits 데이터셋의 경우:**
    *   `load_digits()`로 로드된 데이터의 픽셀 값은 0부터 16까지의 범위에 있습니다. 따라서 이 데이터셋의 경우 최대값인 16으로 나누어 0-1 범위로 정규화합니다.

```python
# 픽셀 값 정규화 (0-16 -> 0-1)
# X는 0부터 16까지의 픽셀 값을 가지므로, 각 픽셀 값을 16.0으로 나누어 0과 1 사이의 값으로 정규화합니다.
X_normalized = X / 16.0 

print(f"
정규화 전 첫 번째 이미지 픽셀 값 (일부): {X[0, :5]}")
print(f"정규화 후 첫 번째 이미지 픽셀 값 (일부): {X_normalized[0, :5]}")
print(f"정규화 후 픽셀 값의 최솟값: {X_normalized.min()}, 최댓값: {X_normalized.max()}")
```

**픽셀 값 정규화 시 고려사항:**
*   **데이터 범위:** 이미지 데이터의 픽셀 값 범위(예: 0-255, 0-16)를 정확히 파악하고 이에 맞는 정규화 방법을 선택해야 합니다.
*   **훈련/테스트 데이터 일관성:** 훈련 데이터로 학습된 정규화/표준화 파라미터(평균, 표준편차, 최솟값, 최댓값)를 테스트 데이터 및 새로운 데이터에 동일하게 적용해야 합니다. 이를 위해 `StandardScaler`와 같은 변환기를 파이프라인에 포함하는 것이 좋습니다.
*   **모델 유형:** 딥러닝 모델(CNN)의 경우, 특정 전이 학습 모델은 특정 정규화 방식을 요구할 수 있습니다. 이 경우 해당 모델의 요구사항에 맞춰 정규화를 수행해야 합니다.

## 3. 특성 추출 (픽셀 값 활용)

이미지 데이터를 머신러닝 모델에 입력하기 위해서는 이를 수치형 특성으로 변환하는 과정이 필요합니다. 가장 간단하고 직접적인 방법은 이미지의 각 픽셀 값을 그대로 특성으로 사용하는 것입니다.

*   **픽셀 값 활용:**
    *   **설명:** 흑백 이미지의 경우, 각 픽셀은 하나의 숫자 값(밝기)을 가집니다. 이 픽셀 값들을 순서대로 나열하여 하나의 긴 벡터로 만듭니다. 예를 들어, 8x8 픽셀 이미지는 64개의 특성을 가진 벡터가 되고, 28x28 픽셀 이미지는 784개의 특성을 가진 벡터가 됩니다.
    *   **장점:** 구현이 매우 간단하고, 이미지의 모든 원시 정보를 보존합니다.
    *   **단점:**
        *   **고차원성:** 이미지 크기가 커질수록 특성의 수가 기하급수적으로 증가하여 '차원의 저주(Curse of Dimensionality)' 문제가 발생할 수 있습니다.
        *   **공간적 정보 손실:** 픽셀 값들을 1차원 벡터로 평탄화하면서 픽셀 간의 공간적 관계(예: 이웃 픽셀 정보, 형태, 패턴)가 손실됩니다. 이는 이미지 인식에 중요한 정보입니다.
        *   **변형에 취약:** 이미지의 약간의 회전, 이동, 크기 변화에도 픽셀 값의 위치가 크게 변하여 모델이 동일한 객체로 인식하기 어려워질 수 있습니다.

*   **고급 특성 추출 (개념적):**
    픽셀 값을 직접 사용하는 것의 한계를 극복하기 위해, 이미지의 고유한 특징을 더 잘 나타내는 추상적인 특성을 추출하는 다양한 고급 기법들이 개발되었습니다.
    *   **HOG (Histogram of Oriented Gradients):**
        *   **설명:** 이미지 내에서 객체의 형태나 윤곽선을 나타내는 에지(Edge)의 방향성 분포를 기반으로 특성을 추출합니다. 이미지의 지역적인 밝기 변화와 그래디언트 방향을 분석하여 특징 벡터를 생성합니다.
        *   **장점:** 조명 변화나 약간의 기하학적 변형에 강건하며, 객체 인식 및 분류에 효과적입니다.
        *   **활용:** 보행자 감지, 얼굴 인식 등 전통적인 컴퓨터 비전 분야에서 널리 사용되었습니다.
    *   **CNN (Convolutional Neural Network) 특징 (전이 학습):**
        *   **설명:** 딥러닝 분야에서 가장 강력한 이미지 특성 추출 방법입니다. ImageNet과 같은 대규모 이미지 데이터셋으로 미리 학습된 CNN 모델(예: VGG, ResNet, Inception, EfficientNet 등)의 중간 레이어 출력을 새로운 이미지의 특성으로 활용합니다.
        *   **장점:** 모델이 이미지의 저수준 특징(엣지, 질감)부터 고수준 특징(객체의 부분, 전체 객체)까지 계층적으로 학습한 매우 풍부하고 추상적인 특징 표현을 제공합니다. 데이터가 부족한 경우에도 뛰어난 성능을 발휘할 수 있습니다.
        *   **활용:** 이미지 분류, 객체 탐지, 이미지 검색 등 거의 모든 현대 컴퓨터 비전 문제에서 핵심적으로 사용됩니다.

이 실습에서는 Scikit-learn의 기본 모델을 사용하므로, 가장 간단한 픽셀 값 활용 방식을 특성으로 사용합니다. 하지만 실제 이미지 분류 프로젝트에서는 문제의 복잡성과 데이터의 양에 따라 HOG나 CNN 특징과 같은 고급 특성 추출 기법을 고려해야 합니다.

## 4. 파이프라인 구축
이미지 데이터 전처리(정규화/스케일링)와 분류 모델 학습을 하나의 파이프라인으로 묶어 워크플로우를 자동화합니다.

```python
# 훈련 세트와 테스트 세트 분리
X_train, X_test, y_train, y_test = train_test_split(X_normalized, y, test_size=0.2, random_state=42, stratify=y)

# 파이프라인 구축 (StandardScaler + LogisticRegression)
# 이미지 픽셀 값은 이미 정규화되었지만, StandardScaler를 통해 평균 0, 표준편차 1로 표준화할 수 있습니다.
model_pipeline = Pipeline([
    ('scaler', StandardScaler()), # 픽셀 값 표준화
    ('classifier', LogisticRegression(max_iter=1000, random_state=42, solver='saga', multi_class='multinomial')) # 다중 클래스 분류
])
```

## 5. 모델 학습 및 예측

정의된 `model_pipeline` 객체는 Scikit-learn의 일반적인 모델과 동일하게 `fit()` 메서드를 사용하여 훈련하고, `predict()` 메서드를 사용하여 새로운 데이터에 대한 예측을 수행합니다. 파이프라인을 사용하면 이미지 데이터 전처리부터 모델 학습까지의 모든 과정이 자동으로 처리되므로, 코드가 매우 간결해지고 데이터 누수 위험이 줄어듭니다.

```python
print("\n모델 학습 시작...")
# model_pipeline.fit(X_train, y_train)을 호출하면:
# 1. 'scaler' 단계의 StandardScaler가 X_train에 대해 fit_transform()을 수행하여 픽셀 값을 표준화합니다.
# 2. 표준화된 픽셀 데이터가 'classifier' 단계의 LogisticRegression으로 전달되어 fit() 메서드가 호출되고 모델이 학습됩니다.
model_pipeline.fit(X_train, y_train)
print("모델 학습 완료.")

# 테스트 세트에 대한 예측 수행
# model_pipeline.predict(X_test)를 호출하면:
# 1. 'scaler' 단계의 StandardScaler가 X_test에 대해 transform()을 수행합니다. (훈련 데이터로 학습된 스케일러 사용)
# 2. 변환된 픽셀 데이터가 'classifier' 단계의 LogisticRegression으로 전달되어 predict() 메서드가 호출되고 예측 결과가 반환됩니다.
y_pred = model_pipeline.predict(X_test)

print("\n테스트 세트 예측 완료.")
print(f"예측 결과 (일부): {y_pred[:10]}")
```

**모델 학습 및 예측 과정의 자동화:**
*   **간결한 코드:** 파이프라인을 사용하면 이미지 전처리부터 모델 학습까지의 복잡한 과정을 단 두 줄의 코드(`fit()`, `predict()`)로 실행할 수 있습니다.
*   **데이터 누수 방지:** `train_test_split` 이후 파이프라인을 `fit()`하면, 스케일러는 훈련 데이터에만 `fit`되고, 테스트 데이터에는 `transform`만 적용됩니다. 이는 테스트 데이터의 정보가 훈련 과정에 유입되는 것을 방지하여 모델 평가의 신뢰성을 높입니다.
*   **재현성:** 파이프라인 객체는 전체 워크플로우를 캡슐화하므로, 동일한 파이프라인을 사용하여 언제든지 동일한 결과를 재현할 수 있습니다.


## 6. 모델 평가

모델 학습 및 예측이 완료되면, 모델의 성능을 객관적으로 평가하는 것이 중요합니다. MNIST와 같은 다중 클래스 분류 문제에서는 단순히 정확도(Accuracy)만을 보는 것이 아니라, 각 클래스별 성능과 모델의 전반적인 분류 능력을 나타내는 다양한 평가 지표를 종합적으로 활용해야 합니다.

```python
print("\n--- 모델 평가 결과 ---")

# 1. 정확도 (Accuracy)
# 전체 예측 중 올바르게 예측한 비율입니다. 다중 클래스 분류에서 가장 직관적인 지표입니다.
accuracy = accuracy_score(y_test, y_pred)
print(f"정확도 (Accuracy): {accuracy:.4f}")

# 2. 분류 보고서 (Classification Report)
# 각 클래스별 정밀도(Precision), 재현율(Recall), F1-점수(F1-Score)를 보여줍니다.
# - 정밀도: 모델이 특정 클래스라고 예측한 것 중 실제 그 클래스인 비율 (오탐 감소)
# - 재현율: 실제 특정 클래스인 것 중 모델이 올바르게 예측한 비율 (미탐 감소)
# - F1-점수: 정밀도와 재현율의 조화 평균
# - macro avg: 각 클래스 지표의 단순 평균
# - weighted avg: 각 클래스 지표를 샘플 수에 따라 가중 평균
print("\n분류 보고서 (Classification Report):\n", classification_report(y_test, y_pred))

# 3. 혼동 행렬 (Confusion Matrix) 시각화
# 모델의 예측이 실제 레이블과 어떻게 일치하거나 불일치하는지 시각적으로 보여줍니다.
# 행은 실제 클래스, 열은 예측 클래스를 나타냅니다.
# 대각선 값은 올바르게 분류된 샘플 수, 비대각선 값은 잘못 분류된 샘플 수입니다.
cm = confusion_matrix(y_test, y_pred)
plt.figure(figsize=(8, 7))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
            xticklabels=digits.target_names, yticklabels=digits.target_names) # digits.target_names는 0부터 9까지의 숫자 레이블
plt.xlabel('예측 레이블')
plt.ylabel('실제 레이블')
plt.title('혼동 행렬')
plt.show()
```

**모델 평가 결과 해석:**
*   **정확도:** MNIST 데이터셋은 클래스별 샘플 수가 균등하므로, 정확도는 모델의 전반적인 성능을 잘 나타냅니다.
*   **분류 보고서:** 각 숫자 클래스(0~9)별로 정밀도, 재현율, F1-점수를 확인할 수 있습니다. 이를 통해 모델이 특정 숫자를 다른 숫자보다 더 잘 또는 못 예측하는지 파악할 수 있습니다. 예를 들어, 특정 숫자에 대한 재현율이 낮다면, 모델이 해당 숫자를 잘 인식하지 못하고 다른 숫자로 오분류하는 경향이 있음을 의미합니다.
*   **혼동 행렬:** 혼동 행렬은 모델이 어떤 숫자들을 서로 혼동하는지 시각적으로 보여줍니다. 예를 들어, '4'를 '9'로, '7'을 '1'로 잘못 예측하는 패턴 등을 파악할 수 있습니다. 이는 모델 개선을 위한 중요한 단서가 됩니다.

이러한 다양한 지표들을 종합적으로 고려하여 모델의 성능을 평가하고, 비즈니스 목표에 가장 적합한 모델을 선택해야 합니다. 이미지 분류에서는 특히 혼동 행렬을 통해 모델의 오분류 패턴을 분석하는 것이 중요합니다.


## 7. 결론

이 문서를 통해 MNIST 숫자 분류라는 실제 이미지 분류 문제를 데이터 로딩부터 전처리, 특성 추출(픽셀 값), 파이프라인 구축, 모델 학습 및 평가까지 **엔드-투-엔드(End-to-End) 워크플로우**로 해결하는 방법을 상세히 학습했습니다. 이 과정에서 다음과 같은 핵심 개념과 실무적 중요성을 이해할 수 있었습니다.

*   **문제 정의 및 데이터 로드:** 다중 클래스 이미지 분류 문제의 특성과 MNIST 데이터셋의 구조를 이해했습니다.
*   **이미지 데이터 전처리:** 픽셀 값 정규화와 같은 이미지 데이터에 특화된 전처리 방법의 중요성을 학습했습니다. 이는 모델 학습의 안정성과 성능에 직접적인 영향을 미칩니다.
*   **특성 추출 (픽셀 값 활용):** 가장 기본적인 이미지 특성 추출 방법인 픽셀 값 활용의 장단점을 이해하고, 고급 특성 추출 기법(HOG, CNN 특징)에 대한 개념을 파악했습니다.
*   **파이프라인 구축:** 이미지 데이터 전처리(정규화/스케일링)와 분류 모델 학습을 하나의 `Pipeline`으로 묶어 워크플로우를 자동화하고 데이터 누수(Data Leakage)를 방지하는 방법을 익혔습니다. 이는 이미지 기반 머신러닝 프로젝트에서 필수적인 모범 사례입니다.
*   **모델 학습 및 예측:** 구축된 파이프라인을 사용하여 모델을 훈련하고 새로운 이미지에 대한 숫자 예측을 수행하는 과정을 자동화했습니다.
*   **모델 평가:** 정확도뿐만 아니라 분류 보고서, 혼동 행렬 등 다중 클래스 분류 모델 평가 지표를 사용하여 모델의 성능을 종합적이고 객관적으로 평가하는 방법을 학습했습니다. 특히 혼동 행렬을 통해 모델의 오분류 패턴을 분석하는 것이 중요함을 이해했습니다.

이러한 엔드-투-엔드 워크플로우는 MNIST 숫자 분류 문제뿐만 아니라, 다른 이미지 분류 문제에도 유사하게 적용될 수 있는 일반적인 머신러닝 프로젝트의 접근 방식입니다. 각 단계의 중요성을 이해하고 체계적으로 접근하는 것이 성공적인 머신러닝 모델 개발의 핵심입니다.

**다음 단계:**
*   **다른 분류 모델 시도:** `LogisticRegression` 외에 `SVC`, `RandomForestClassifier`, `GradientBoostingClassifier` 등 다양한 분류 모델을 시도하고 비교해볼 수 있습니다.
*   **고급 특성 추출:** HOG와 같은 전통적인 이미지 특성 추출 기법이나, 사전 학습된 CNN 모델의 특징을 활용하는 전이 학습(Transfer Learning)을 적용하여 모델 성능을 향상시킬 수 있습니다.
*   **딥러닝 모델:** TensorFlow, PyTorch와 같은 딥러닝 프레임워크를 사용하여 CNN 모델을 직접 구축하고 훈련하여 이미지 분류 성능을 극대화할 수 있습니다.
*   **데이터 증강 (Data Augmentation):** 이미지 데이터의 양이 부족한 경우, 기존 이미지를 회전, 확대, 이동 등으로 변형하여 훈련 데이터셋을 확장하는 데이터 증강 기법을 적용해볼 수 있습니다.
*   **하이퍼파라미터 튜닝:** `GridSearchCV`나 `RandomizedSearchCV`를 사용하여 모델의 하이퍼파라미터를 최적화하여 성능을 더욱 향상시킬 수 있습니다.
