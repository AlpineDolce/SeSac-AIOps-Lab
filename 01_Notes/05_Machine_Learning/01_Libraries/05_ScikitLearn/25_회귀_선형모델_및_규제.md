## 1. 선형 회귀와 과적합의 문제

### 1.1. 선형 회귀 (Linear Regression)
선형 회귀는 입력 특성과 타겟 변수 간의 선형적인 관계를 가정하고, 이 관계를 가장 잘 나타내는 직선(또는 초평면)을 찾는 알고리즘입니다. 모델이 단순하고 해석이 용이하여 회귀 문제의 베이스라인 모델로 널리 사용됩니다.

### 1.2. 과적합과 규제의 필요성
선형 회귀 모델은 특성의 수가 많아지거나 특성 간의 상관관계(다중공선성)가 높을 경우, 훈련 데이터에만 과도하게 최적화되는 **과적합(Overfitting)** 현상이 발생하기 쉽습니다. 과적합된 모델은 훈련 데이터에 대해서는 높은 성능을 보이지만, 새로운 데이터(테스트 데이터)에 대해서는 예측 성능이 급격히 떨어집니다.

**규제(Regularization)**는 이러한 과적합을 해결하기 위한 기법입니다. 모델의 **회귀 계수(coefficients)** 크기에 페널티를 부과하여 모델의 복잡도를 낮추고, 훈련 데이터에 대한 과도한 최적화를 방지합니다. 이를 통해 모델의 일반화 성능을 높일 수 있습니다.

## 2. 릿지 회귀 (Ridge Regression): L2 규제

### 2.1. 핵심 개념
릿지 회귀는 기본 선형 회귀의 비용 함수(Cost Function)에 **L2 규제항**을 추가한 모델입니다. L2 규제는 모든 회귀 계수의 **제곱합**을 최소화하는 방향으로 작동합니다.

*   **효과:** 회귀 계수의 크기를 전반적으로 작게 만들어 모델을 더 안정적으로 만듭니다. 계수를 0에 가깝게 만들지만, 완전히 0으로 만들지는 않습니다.
*   **장점:** 다중공선성 문제가 있는 경우에도 비교적 안정적인 성능을 보입니다.

### 2.2. 주요 하이퍼파라미터
*   `alpha`: 규제의 강도를 조절합니다.
    *   `alpha`가 클수록 규제가 강해져 계수들이 0에 더 가까워집니다 (과소적합 방향).
    *   `alpha`가 작을수록 규제가 약해져 일반 선형 회귀와 유사해집니다 (과적합 방향).

## 3. 라쏘 회귀 (Lasso Regression): L1 규제

### 3.1. 핵심 개념과 특성 선택
라쏘 회귀는 기본 선형 회귀의 비용 함수에 **L1 규제항**을 추가한 모델입니다. L1 규제는 모든 회귀 계수의 **절대값 합**을 최소화하는 방향으로 작동합니다.

*   **효과:** 중요하지 않은 특성의 회귀 계수를 **완전히 0으로** 만들어 버립니다.
*   **장점:** 모델의 예측에 큰 영향을 주지 않는 불필요한 특성을 자동으로 제거하는 **특성 선택(Feature Selection)** 효과가 있습니다. 이를 통해 모델을 더 단순하고 해석하기 쉽게 만들 수 있습니다.

### 3.2. 주요 하이퍼파라미터
*   `alpha`: 릿지 회귀와 마찬가지로 규제의 강도를 조절합니다. `alpha`가 클수록 더 많은 계수들이 0이 됩니다.

## 4. 엘라스틱넷 회귀 (ElasticNet Regression): L1과 L2의 결합
엘라스틱넷은 릿지(L2)와 라쏘(L1) 규제를 모두 결합한 모델입니다. 릿지의 안정성과 라쏘의 특성 선택 능력을 모두 활용할 수 있어, 특성 간에 높은 상관관계가 있는 데이터셋에서 좋은 성능을 보입니다.

*   `alpha`: 전체 규제의 강도를 조절합니다.
*   `l1_ratio`: L1 규제와 L2 규제의 비율을 조절합니다. `l1_ratio=0`이면 릿지, `l1_ratio=1`이면 라쏘와 같습니다.

## 5. 서포트 벡터 회귀 (Support Vector Regression, SVR)

### 5.1. 핵심 개념
SVR은 분류 문제의 SVM과 유사하게 **마진(Margin)** 개념을 회귀 문제에 적용한 모델입니다. 예측 오차가 특정 허용 범위($ε$) 내에 있는 데이터 포인트에 대해서는 페널티를 부과하지 않고, 이 허용 범위를 벗어나는 오차에 대해서만 페널티를 부과하여 모델을 학습합니다. 이를 통해 이상치에 강건한(robust) 모델을 만들 수 있습니다.

*   **커널 트릭(Kernel Trick):** 분류 SVM과 마찬가지로 커널 트릭을 사용하여 비선형적인 관계를 학습할 수 있습니다.
*   **장점:** 
    *   이상치에 강건합니다.
    *   비선형적인 관계를 잘 모델링할 수 있습니다.
    *   고차원 데이터에서도 효과적입니다.
*   **단점:** 
    *   대규모 데이터셋에서는 학습 속도가 느릴 수 있습니다.
    *   하이퍼파라미터 설정에 민감합니다.

### 5.2. 주요 하이퍼파라미터
*   `kernel`: 사용할 커널 함수를 지정합니다 (`'rbf'`, `'linear'`, `'poly'` 등).
*   `C`: 규제의 강도를 조절합니다. 오차에 대한 페널티 강도를 결정합니다.
*   `epsilon` (eps): 허용 오차 범위. 이 범위 내의 오차는 페널티를 받지 않습니다.
*   `gamma`: RBF, poly 커널 등에서 사용되는 파라미터로, 하나의 훈련 데이터가 미치는 영향의 범위를 결정합니다.

## 6. 실습: 캘리포니아 주택 가격 예측

### 6.1. 데이터 준비 및 파이프라인 구성
규제 모델은 특성의 스케일에 영향을 받으므로, `StandardScaler`를 사용한 데이터 스케일링을 파이프라인에 포함하는 것이 매우 중요합니다. SVR 또한 스케일링에 민감합니다.

```python
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet
from sklearn.svm import SVR # SVR 추가
from sklearn.pipeline import Pipeline
from sklearn.metrics import mean_squared_error

# 데이터 로드 및 분할
housing = fetch_california_housing()
X_train, X_test, y_train, y_test = train_test_split(housing.data, housing.target, test_size=0.3, random_state=42)

# 파이프라인 생성 (스케일링 -> 모델)
pipe_lr = Pipeline([('scaler', StandardScaler()), ('model', LinearRegression())])
pipe_ridge = Pipeline([('scaler', StandardScaler()), ('model', Ridge(alpha=1.0, random_state=42))])
pipe_lasso = Pipeline([('scaler', StandardScaler()), ('model', Lasso(alpha=0.1, random_state=42))])
pipe_elastic = Pipeline([('scaler', StandardScaler()), ('model', ElasticNet(alpha=0.1, l1_ratio=0.5, random_state=42))])
pipe_svr = Pipeline([('scaler', StandardScaler()), ('model', SVR(kernel='rbf', C=100, gamma=0.1))]) # SVR 파이프라인 추가
```

### 6.2. 모델별 성능 비교
```python
# 모델 학습
pipe_lr.fit(X_train, y_train)
pipe_ridge.fit(X_train, y_train)
pipe_lasso.fit(X_train, y_train)
pipe_elastic.fit(X_train, y_train)
pipe_svr.fit(X_train, y_train) # SVR 학습

# 예측
y_pred_lr = pipe_lr.predict(X_test)
y_pred_ridge = pipe_ridge.predict(X_test)
y_pred_lasso = pipe_lasso.predict(X_test)
y_pred_elastic = pipe_elastic.predict(X_test)
y_pred_svr = pipe_svr.predict(X_test) # SVR 예측

# MSE 평가
mse_lr = mean_squared_error(y_test, y_pred_lr)
mse_ridge = mean_squared_error(y_test, y_pred_ridge)
mse_lasso = mean_squared_error(y_test, y_pred_lasso)
mse_elastic = mean_squared_error(y_test, y_pred_elastic)
mse_svr = mean_squared_error(y_test, y_pred_svr) # SVR MSE

print(f"선형 회귀 MSE: {mse_lr:.4f}")
print(f"릿지 회귀 MSE: {mse_ridge:.4f}")
print(f"라쏘 회귀 MSE: {mse_lasso:.4f}")
print(f"엘라스틱넷 회귀 MSE: {mse_elastic:.4f}")
print(f"SVR MSE: {mse_svr:.4f}") # SVR 결과 출력

# 라쏘 회귀의 계수 확인 (특성 선택 효과)
lasso_coef = pipe_lasso.named_steps['model'].coef_
print(f"\n라쏘 회귀의 계수 (0이 된 특성 수: {sum(lasso_coef == 0)} / {len(lasso_coef)})")
```

## 7. 어떤 회귀 모델을 선택해야 할까?

| 모델 | 주요 특징 | 사용 추천 상황 |
| :--- | :--- | :--- |
| **선형 회귀** | 규제 없음 | 베이스라인 모델, 특성이 적고 과적합 위험이 낮을 때 |
| **릿지 회귀** | L2 규제 (모든 특성 유지) | 특성 대부분이 중요하고, 다중공선성 문제가 있을 때 |
| **라쏘 회귀** | L1 규제 (특성 선택 효과) | 불필요한 특성이 많다고 의심될 때, 해석 가능한 모델이 필요할 때 |
| **엘라스틱넷** | L1 + L2 규제 | 특성 간 상관관계가 높으면서 특성 선택도 필요할 때 |
| **SVR** | 마진 기반, 커널 트릭, 이상치 강건 | **비선형 관계**가 예상될 때, **이상치에 강건한 모델**이 필요할 때, 데이터셋이 너무 크지 않을 때 |
