## 1. 차원 축소란?
차원 축소는 데이터의 **특성(feature) 개수, 즉 차원을 줄이는** 과정입니다. 이 과정에서 데이터의 본질적인 정보는 최대한 유지하면서, 모델의 성능을 향상시키고, 데이터를 시각화하며, 저장 공간을 절약하는 등 다양한 이점을 얻을 수 있습니다.

### 1.1. 차원의 저주 (Curse of Dimensionality)
데이터의 차원(특성 수)이 증가할수록, 동일한 데이터 양으로는 공간을 충분히 채우기 어려워 데이터 포인트들이 서로 멀어지고 희소(sparse)해지는 현상을 '차원의 저주'라고 합니다. 이는 다음과 같은 문제를 야기합니다.
*   **성능 저하:** 머신러닝 모델의 예측 성능이 저하됩니다.
*   **과적합 증가:** 모델이 불필요한 노이즈까지 학습하여 과적합될 위험이 커집니다.
*   **계산 비용 증가:** 차원이 높을수록 계산 복잡도가 기하급수적으로 증가합니다.

차원 축소는 이러한 '차원의 저주' 문제를 해결하는 핵심적인 방법입니다.

### 1.2. 특성 선택 vs. 특성 추출
차원 축소는 크게 두 가지 접근 방식으로 나뉩니다.
*   **특성 선택 (Feature Selection):** 기존 특성들 중에서 가장 중요하거나 관련성이 높은 특성들만 **선택**하는 방식입니다. (예: `SelectKBest`, `RFE`)
*   **특성 추출 (Feature Extraction):** 기존 특성들을 조합하여 정보를 가장 잘 함축하는 **새로운 특성**을 만들어내는 방식입니다. 이 문서에서 다루는 PCA, t-SNE, NMF가 여기에 해당합니다.

## 2. 주성분 분석 (Principal Component Analysis, PCA)

### 2.1. 핵심 원리
PCA는 가장 널리 사용되는 **선형 차원 축소** 기법입니다. 데이터의 **분산(variance)을 가장 잘 보존**하는 새로운 직교 좌표계(축)를 찾아 데이터를 투영합니다. 이 새로운 축을 **주성분(Principal Component)**이라고 하며, 첫 번째 주성분이 데이터의 분산을 가장 많이 설명하고, 두 번째 주성분은 첫 번째와 직교하면서 나머지 분산을 가장 많이 설명하는 식으로 생성됩니다.

### 2.2. 최적의 주성분 개수 선택
몇 개의 주성분으로 차원을 축소할지는 어떻게 결정할까요? `explained_variance_ratio_` 속성을 확인하여 결정할 수 있습니다. 이는 각 주성분이 전체 데이터의 분산을 얼마나 설명하는지를 나타냅니다. 일반적으로 누적 설명 분산이 95% 이상이 되는 지점까지의 주성분 개수를 선택합니다.

## 3. t-SNE (t-Distributed Stochastic Neighbor Embedding)

### 3.1. 핵심 원리
t-SNE는 고차원 공간에 있는 데이터 포인트 간의 **지역적 유사성(local similarities)**을 저차원 공간(주로 2D 또는 3D)에 최대한 보존하는 **비선형 차원 축소** 기법입니다. 특히 고차원 데이터의 시각화에 매우 강력한 성능을 보입니다.

### 3.2. PCA vs. t-SNE
*   **PCA:** 데이터의 전역적인(global) 분산을 보존하는 데 중점을 둡니다. 데이터의 전체적인 구조를 파악하는 데 유용합니다.
*   **t-SNE:** 데이터의 지역적인(local) 구조, 즉 이웃 간의 관계를 보존하는 데 중점을 둡니다. 군집(cluster) 구조를 시각화하는 데 매우 효과적입니다.
*   **주의사항:** t-SNE는 계산 비용이 높고, 결과로 나온 클러스터 간의 거리나 크기는 특별한 의미를 갖지 않을 수 있습니다. 주로 **탐색적 데이터 시각화**에 사용되며, t-SNE로 변환된 데이터를 직접 모델 학습에 사용하는 것은 권장되지 않습니다.

## 4. 비음수 행렬 분해 (Non-negative Matrix Factorization, NMF)
NMF는 모든 원소가 **음수가 아닌 행렬**을 두 개의 비음수 행렬의 곱으로 분해하는 차원 축소 기법입니다. 원본 데이터가 덧셈으로 구성된다고 가정할 수 있는 경우에 유용합니다.
*   **주요 활용 분야:**
    *   **텍스트 마이닝 (토픽 모델링):** 문서-단어 행렬을 문서-토픽 행렬과 토픽-단어 행렬로 분해하여 문서의 잠재적인 토픽을 추출합니다.
    *   **이미지 처리:** 여러 이미지를 부분 이미지들의 조합으로 표현합니다.
    *   **추천 시스템:** 사용자-아이템 평점 행렬을 분해하여 잠재 요인을 찾습니다.

## 5. 다른 매니폴드 학습 기법 (Other Manifold Learning Techniques)
매니폴드 학습(Manifold Learning)은 고차원 데이터가 실제로는 더 낮은 차원의 비선형 매니폴드(manifold) 상에 존재한다고 가정하고, 이 매니폴드를 찾아 데이터를 저차원으로 임베딩하는 비선형 차원 축소 기법입니다.

### 5.1. Isomap
Isomap은 고차원 공간에서 데이터 포인트 간의 **측지 거리(Geodesic Distance)**를 보존하면서 저차원으로 임베딩합니다. 측지 거리는 데이터가 놓여 있는 매니폴드를 따라 측정되는 실제 거리입니다.

*   **핵심 아이디어:** 데이터 포인트 간의 유클리드 거리가 아닌, 그래프 상의 최단 경로 거리를 사용하여 매니폴드의 구조를 파악합니다.
*   **장점:** 전역적인 구조를 잘 보존합니다.
*   **단점:** 계산 비용이 높고, 노이즈에 민감할 수 있습니다.

### 5.2. LLE (Locally Linear Embedding)
LLE는 각 데이터 포인트가 그 이웃들의 선형 조합으로 표현될 수 있다는 가정을 기반으로 합니다. 이 선형 관계를 저차원 공간에서도 보존하도록 데이터를 임베딩합니다.

*   **핵심 아이디어:** 각 데이터 포인트와 그 이웃들 간의 선형 관계를 찾고, 이 관계를 저차원 공간에서도 유지합니다.
*   **장점:** 복잡한 비선형 구조를 잘 처리합니다.
*   **단점:** 이웃의 개수(n_neighbors) 설정에 민감하고, 데이터셋이 클 경우 계산 비용이 높습니다.

## 6. 실습: 손글씨 숫자 데이터 시각화
고차원 데이터인 손글씨 숫자(digits) 데이터를 PCA와 t-SNE를 사용하여 2차원으로 축소하고 시각화하여 비교해봅니다.

```python
import matplotlib.pyplot as plt
from sklearn.datasets import load_digits
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.manifold import TSNE, Isomap, LocallyLinearEmbedding # Isomap, LLE 추가

# 데이터 로드
digits = load_digits()
X, y = digits.data, digits.target

# 데이터 스케일링
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# PCA로 차원 축소
pca = PCA(n_components=2, random_state=42)
X_pca = pca.fit_transform(X_scaled)

# t-SNE로 차원 축소
tsne = TSNE(n_components=2, random_state=42, init='pca', learning_rate='auto', n_iter=500) # 파라미터 조정
X_tsne = tsne.fit_transform(X_scaled)

# Isomap으로 차원 축소
isomap = Isomap(n_components=2, n_neighbors=10) # n_neighbors는 중요한 파라미터
X_isomap = isomap.fit_transform(X_scaled)

# LLE로 차원 축소
lle = LocallyLinearEmbedding(n_components=2, n_neighbors=10, random_state=42) # n_neighbors는 중요한 파라미터
X_lle = lle.fit_transform(X_scaled)


# 시각화
fig, axes = plt.subplots(2, 2, figsize=(14, 12))
axes = axes.flatten() # 2x2 배열을 1차원으로 평탄화

# PCA 결과
axes[0].scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[0].set_title('PCA of Digits Dataset')
axes[0].set_xlabel('Principal Component 1')
axes[0].set_ylabel('Principal Component 2')

# t-SNE 결과
axes[1].scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[1].set_title('t-SNE of Digits Dataset')
axes[1].set_xlabel('t-SNE feature 1')
axes[1].set_ylabel('t-SNE feature 2')

# Isomap 결과
axes[2].scatter(X_isomap[:, 0], X_isomap[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[2].set_title('Isomap of Digits Dataset')
axes[2].set_xlabel('Isomap feature 1')
axes[2].set_ylabel('Isomap feature 2')

# LLE 결과
axes[3].scatter(X_lle[:, 0], X_lle[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[3].set_title('LLE of Digits Dataset')
axes[3].set_xlabel('LLE feature 1')
axes[3].set_ylabel('LLE feature 2')

plt.suptitle('Dimensionality Reduction for Visualization', y=1.02)
plt.tight_layout()
plt.show()
```
