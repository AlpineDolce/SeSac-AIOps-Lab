## 1. 회귀 모델 평가 지표의 중요성
회귀 모델은 연속적인 숫자 값을 예측하는 모델입니다. 분류 모델과 마찬가지로, 회귀 모델의 성능을 객관적으로 평가하고 비즈니스 목표에 부합하는 최적의 모델을 선택하기 위해서는 다양한 평가 지표를 이해하고 활용하는 것이 필수적입니다. 예측 오차의 크기, 모델의 설명력, 그리고 비즈니스 상황에 따른 해석 용이성 등 여러 관점에서 모델을 평가해야 합니다.

### 1.1. 왜 다양한 지표가 필요한가?
단일 지표만으로는 모델의 성능을 완벽하게 파악하기 어렵습니다. 예를 들어, MSE는 오차의 제곱을 사용하므로 큰 오차에 더 큰 페널티를 부여하여 이상치에 민감하게 반응합니다. 반면 MAE는 오차의 절댓값을 사용하므로 이상치에 덜 민감합니다. 비즈니스 상황에 따라 어떤 유형의 오차가 더 중요한지에 따라 적절한 지표를 선택해야 합니다.

## 2. 오차 기반 평가 지표
이 지표들은 모델의 예측값과 실제값 사이의 **오차 크기**를 측정합니다. 값이 작을수록 모델의 예측 성능이 좋습니다.

### 2.1. 평균 절대 오차 (Mean Absolute Error, MAE)
예측값과 실제값의 차이(오차)의 절댓값을 취하여 평균한 값입니다.
*   **특징:** 오차의 크기를 직관적으로 이해하는 데 도움이 되며, 이상치에 덜 민감합니다.
*   **수식:** $ MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i| $

### 2.2. 평균 제곱 오차 (Mean Squared Error, MSE)
예측값과 실제값의 차이(오차)를 제곱하여 평균한 값입니다.
*   **특징:** 오차를 제곱하기 때문에 큰 오차에 더 큰 페널티를 부여하며, 이상치에 민감하게 반응합니다.
*   **수식:** $ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $

### 2.3. 평균 제곱근 오차 (Root Mean Squared Error, RMSE)
MSE에 제곱근을 취한 값입니다.
*   **특징:** MSE와 마찬가지로 이상치에 민감하지만, 오차를 실제값과 같은 단위로 해석할 수 있어 MAE보다 직관적입니다.
*   **수식:** $ RMSE = \sqrt{MSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2} $

### 2.4. 평균 절대 백분율 오차 (Mean Absolute Percentage Error, MAPE)
예측값과 실제값의 차이를 실제값으로 나눈 후 절댓값을 취하여 백분율로 평균한 값입니다.
*   **특징:** 오차를 백분율로 표현하므로, 서로 다른 스케일의 데이터셋이나 비즈니스 상황에서 모델의 예측 정확도를 비교하는 데 유용합니다.
*   **수식:** $ MAPE = \frac{100}{n} \sum_{i=1}^{n} \left| \frac{y_i - \hat{y}_i}{y_i} \right| $
*   **주의사항:** 실제값 $y_i$가 0이거나 0에 매우 가까울 경우 MAPE가 무한대가 되거나 매우 큰 값을 가질 수 있어 불안정합니다.

## 3. 설명력 기반 평가 지표
이 지표들은 모델이 타겟 변수의 **분산을 얼마나 잘 설명하는지**를 측정합니다.

### 3.1. R-제곱 (R-squared)
결정 계수(Coefficient of Determination)라고도 불리며, 모델이 타겟 변수의 분산을 얼마나 잘 설명하는지를 나타냅니다.
*   **특징:** 0과 1 사이의 값을 가지며, 1에 가까울수록 모델이 데이터를 잘 설명합니다. 음수 값도 가질 수 있으며, 이는 모델이 평균보다도 성능이 나쁘다는 것을 의미합니다.
*   **수식:** $ R^2 = 1 - \frac{SS_{res}}{SS_{tot}} $
    *   $SS_{res}$: 잔차 제곱합 (Sum of Squares of Residuals) = $ \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $
    *   $SS_{tot}$: 총 제곱합 (Total Sum of Squares) = $ \sum_{i=1}^{n} (y_i - \bar{y})^2 $

### 3.2. 수정된 R-제곱 (Adjusted R-squared)
R-제곱은 모델에 특성이 많아질수록 무조건 증가하는 경향이 있습니다. 수정된 R-제곱은 모델에 포함된 특성의 개수를 고려하여 R-제곱 값을 보정합니다.
*   **특징:** 새로운 특성이 모델의 설명력을 충분히 높이지 못하면 오히려 값이 감소할 수 있습니다. 따라서 **서로 다른 개수의 특성을 가진 모델들을 비교할 때** 더 적합한 지표입니다.
*   **수식:** $ Adjusted R^2 = 1 - (1 - R^2) \frac{n - 1}{n - p - 1} $
    *   $n$: 데이터 포인트 수
    *   $p$: 모델에 사용된 특성(독립 변수)의 수

## 4. 실습: 캘리포니아 주택 가격 예측
캘리포니아 주택 가격 데이터셋을 사용하여 선형 회귀 모델을 학습시키고 다양한 회귀 평가 지표를 계산합니다.

```python
import numpy as np
from sklearn.datasets import fetch_california_housing
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score

# 데이터 로드 및 분할
housing = fetch_california_housing()
X, y = housing.data, housing.target
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 선형 회귀 모델 학습
model = LinearRegression()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

# 오차 기반 지표 계산
mae = mean_absolute_error(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)
rmse = np.sqrt(mse)

# MAPE 계산 (수동 구현)
# y_test가 0이거나 0에 가까운 값이 있을 경우 MAPE가 불안정해질 수 있으므로 주의
mape = np.mean(np.abs((y_test - y_pred) / y_test)) * 100
# Scikit-learn 1.0 이상 버전에서는 mean_absolute_percentage_error 함수 제공
# from sklearn.metrics import mean_absolute_percentage_error
# mape = mean_absolute_percentage_error(y_test, y_pred) * 100

print(f"MAE: {mae:.4f}")
print(f"MSE: {mse:.4f}")
print(f"RMSE: {rmse:.4f}")
print(f"MAPE: {mape:.4f}%")

# 설명력 기반 지표 계산
r2 = r2_score(y_test, y_pred)

# 수정된 R-제곱 계산
n = X_test.shape[0] # 테스트 데이터 샘플 수
p = X_test.shape[1] # 특성(독립 변수) 수
adjusted_r2 = 1 - (1 - r2) * (n - 1) / (n - p - 1)

print(f"R-제곱: {r2:.4f}")
print(f"수정된 R-제곱: {adjusted_r2:.4f}")
```

## 5. 어떤 회귀 모델 평가 지표를 선택해야 할까?

| 지표 | 특징 | 사용 추천 상황 |
| :--- | :--- | :--- |
| **MAE** | 오차의 절댓값 평균, 이상치에 덜 민감 | 오차의 크기를 직관적으로 이해하고 싶을 때, 이상치의 영향을 줄이고 싶을 때 |
| **MSE/RMSE** | 오차 제곱 평균/제곱근, 큰 오차에 페널티, 이상치에 민감 | 모델의 예측 오차에 대한 엄격한 평가가 필요할 때, 이상치 탐지가 중요할 때 |
| **MAPE** | 오차를 백분율로 표현, 스케일 독립적 | 예측 오차를 백분율로 이해하고 싶을 때, 서로 다른 스케일의 모델 비교 시 (단, 실제값이 0에 가까우면 불안정) |
| **R-제곱** | 모델의 설명력, 0~1 사이 값 | 모델이 타겟 변수의 분산을 얼마나 잘 설명하는지 전반적으로 평가할 때 |
| **수정된 R-제곱** | 특성 개수 고려, R-제곱 보정 | **서로 다른 특성 개수를 가진 모델들을 비교할 때** |

**결론:** 단일 지표에 의존하기보다는, 문제의 특성과 비즈니스 목표를 명확히 이해하고, **여러 평가 지표를 종합적으로 고려**하여 모델의 성능을 판단해야 합니다. 특히 비즈니스 담당자와의 소통 시에는 MAE나 RMSE처럼 실제 단위로 해석 가능한 지표나 MAPE처럼 백분율로 해석 가능한 지표가 유용할 수 있습니다.
