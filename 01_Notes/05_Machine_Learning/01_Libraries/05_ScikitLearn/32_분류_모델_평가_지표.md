## 1. 모델 평가 지표의 중요성
머신러닝 모델의 성능을 평가하는 것은 모델 개발 과정에서 가장 중요한 단계 중 하나입니다. 모델이 얼마나 잘 작동하는지, 어떤 유형의 오류를 범하는지, 그리고 실제 비즈니스 문제에 얼마나 적합한지를 객관적으로 판단하기 위해서는 적절한 평가 지표를 선택하고 해석하는 능력이 필수적입니다.

### 1.1. 왜 다양한 지표가 필요한가?
가장 직관적인 지표인 **정확도(Accuracy)**는 전체 예측 중 올바르게 예측한 비율을 나타냅니다. 하지만 정확도만으로는 모델의 성능을 완벽하게 파악하기 어렵습니다. 특히 **클래스 불균형(Class Imbalance)**이 심한 데이터셋에서는 정확도가 모델의 실제 성능을 오도할 수 있습니다. 예를 들어, 99%가 정상이고 1%가 사기인 데이터셋에서 모든 것을 정상으로 예측하는 모델의 정확도는 99%가 되지만, 이 모델은 사기를 전혀 탐지하지 못하는 쓸모없는 모델입니다.

따라서 문제의 특성과 비즈니스 목표에 따라 다양한 평가 지표를 종합적으로 고려해야 합니다.

## 2. 혼동 행렬 (Confusion Matrix)
혼동 행렬은 분류 모델의 예측 결과를 표 형태로 요약한 것으로, 모든 분류 평가 지표의 **기본(Foundation)**이 됩니다. 실제 클래스와 예측 클래스 간의 관계를 보여주며, 모델이 어떤 유형의 오류를 범하는지 파악하는 데 매우 유용합니다.

### 2.1. 혼동 행렬의 구성 요소
| | **예측: 양성 (Positive)** | **예측: 음성 (Negative)** |
| :--- | :--- | :--- |
| **실제: 양성 (Positive)** | **TP (True Positive)**: 실제 양성을 양성으로 올바르게 예측 | **FN (False Negative)**: 실제 양성을 음성으로 잘못 예측 (2종 오류) |
| **실제: 음성 (Negative)** | **FP (False Positive)**: 실제 음성을 양성으로 잘못 예측 (1종 오류) | **TN (True Negative)**: 실제 음성을 음성으로 올바르게 예측 |

*   **TP (True Positive):** 실제 양성(True)을 양성(Positive)으로 올바르게 예측한 경우.
*   **TN (True Negative):** 실제 음성(False)을 음성(Negative)으로 올바르게 예측한 경우.
*   **FP (False Positive):** 실제 음성(False)을 양성(Positive)으로 잘못 예측한 경우 (1종 오류, Type I Error). '거짓 양성'이라고도 합니다.
*   **FN (False Negative):** 실제 양성(True)을 음성(Negative)으로 잘못 예측한 경우 (2종 오류, Type II Error). '거짓 음성'이라고도 합니다.
