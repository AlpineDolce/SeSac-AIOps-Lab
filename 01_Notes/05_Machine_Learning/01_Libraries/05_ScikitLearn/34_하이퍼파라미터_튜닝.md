## 1. 하이퍼파라미터 튜닝이란?

### 1.1. 모델 파라미터 vs. 하이퍼파라미터
*   **모델 파라미터 (Model Parameters):** 모델이 데이터를 통해 **학습하는** 값입니다. (예: 선형 회귀의 계수, 신경망의 가중치)
*   **하이퍼파라미터 (Hyperparameters):** 모델 학습 전에 사용자가 직접 **설정하는** 값으로, 모델의 구조나 학습 방식에 영향을 미칩니다. (예: 의사결정 트리의 `max_depth`, SVM의 `C`, `gamma`, K-NN의 `n_neighbors`)

### 1.2. 왜 하이퍼파라미터 튜닝이 필요한가?
하이퍼파라미터는 모델의 성능에 지대한 영향을 미칩니다. 잘못된 하이퍼파라미터 설정은 모델을 과적합(Overfitting)시키거나 과소적합(Underfitting)시켜 일반화 성능을 저하시킬 수 있습니다. 하이퍼파라미터 튜닝은 주어진 데이터와 문제에 대해 모델의 최적 성능을 발휘할 수 있는 하이퍼파라미터 조합을 찾는 과정입니다.

## 2. 그리드 서치 (Grid Search)

### 2.1. `GridSearchCV` 핵심 개념
`GridSearchCV`는 사용자가 지정한 하이퍼파라미터의 모든 가능한 조합에 대해 모델을 학습하고 교차 검증을 수행하여 최적의 조합을 찾습니다. 마치 격자(Grid)처럼 모든 지점을 탐색한다고 하여 그리드 서치라고 불립니다.

### 2.2. 장단점
*   **장점:**
    *   모든 조합을 탐색하므로, 주어진 탐색 공간 내에서는 **최적의 조합을 찾을 가능성이 높습니다.**
    *   구현이 직관적이고 쉽습니다.
*   **단점:**
    *   탐색 공간이 커질수록 (하이퍼파라미터의 종류가 많아지거나 각 파라미터의 후보 값이 많아질수록) **기하급수적으로 많은 시간이 소요됩니다.** (차원의 저주)
    *   비효율적일 수 있습니다. 성능에 영향을 미치지 않는 파라미터 조합까지 모두 탐색합니다.

### 2.3. 실습
`Pipeline`과 함께 `GridSearchCV`를 사용하여 하이퍼파라미터를 튜닝하는 예제입니다.

```python
from sklearn.model_selection import GridSearchCV
from sklearn.svm import SVC
from sklearn.datasets import load_iris
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

# 데이터 로드
iris = load_iris()
X, y = iris.data, iris.target

# 파이프라인 정의: 스케일링 -> SVM
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('svc', SVC(random_state=42))
])

# 탐색할 하이퍼파라미터 그리드 정의
# 파이프라인 내의 파라미터는 '단계이름__파라미터이름' 형식으로 지정
param_grid = {
    'svc__C': [0.1, 1, 10, 100],
    'svc__gamma': [0.1, 0.01, 0.001],
    'svc__kernel': ['rbf', 'linear']
}

# GridSearchCV 객체 생성
grid_search = GridSearchCV(pipe, param_grid, cv=5, scoring='accuracy', n_jobs=-1)

# 그리드 서치 수행
grid_search.fit(X, y)

# 최적의 하이퍼파라미터 조합
print(f"최적의 하이퍼파라미터: {grid_search.best_params_}")

# 최적의 모델 성능
print(f"최고 교차 검증 정확도: {grid_search.best_score_:.4f}")

# 최적의 모델
best_model = grid_search.best_estimator_
```

## 3. 랜덤 서치 (Random Search)

### 3.1. `RandomizedSearchCV` 핵심 개념
`RandomizedSearchCV`는 `GridSearchCV`와 달리, 사용자가 지정한 하이퍼파라미터 공간에서 **무작위로 샘플링된 조합**에 대해서만 모델을 학습하고 교차 검증을 수행합니다. 탐색할 조합의 개수(`n_iter`)를 지정하여 탐색 시간을 제어할 수 있습니다.

### 3.2. 장단점
*   **장점:**
    *   `GridSearchCV`보다 **빠르게** 탐색을 수행할 수 있습니다.
    *   탐색 공간이 매우 클 때, 그리드 서치보다 더 넓은 영역을 탐색하여 **더 좋은 조합을 찾을 가능성**이 있습니다.
*   **단점:**
    *   무작위 샘플링이므로, **최적의 조합을 놓칠 가능성**이 있습니다.

### 3.3. 실습
```python
from sklearn.model_selection import RandomizedSearchCV
from sklearn.ensemble import RandomForestClassifier
from sklearn.datasets import load_iris
from scipy.stats import randint, uniform # 하이퍼파라미터 분포 정의를 위함
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler

# 데이터 로드
iris = load_iris()
X, y = iris.data, iris.target

# 파이프라인 정의: 스케일링 -> 랜덤 포레스트
pipe_rf = Pipeline([
    ('scaler', StandardScaler()),
    ('rf', RandomForestClassifier(random_state=42))
])

# 탐색할 하이퍼파라미터 분포 정의
param_dist = {
    'rf__n_estimators': randint(10, 200), # 10에서 200 사이의 정수
    'rf__max_depth': randint(1, 10),     # 1에서 10 사이의 정수
    'rf__min_samples_split': randint(2, 20),
    'rf__max_features': uniform(0.5, 0.5) # 0.5에서 1.0 사이의 실수 (0.5 + 0.5 * random_value)
}

# RandomizedSearchCV 객체 생성
random_search = RandomizedSearchCV(pipe_rf, param_dist, n_iter=20, cv=5, scoring='accuracy', random_state=42, n_jobs=-1)

# 랜덤 서치 수행
random_search.fit(X, y)

# 최적의 하이퍼파라미터 조합
print(f"최적의 하이퍼파라미터: {random_search.best_params_}")

# 최적의 모델 성능
print(f"최고 교차 검증 정확도: {random_search.best_score_:.4f}")
```

## 4. 베이지안 최적화 (Bayesian Optimization)

### 4.1. 핵심 개념
그리드 서치나 랜덤 서치는 이전 시도 결과를 활용하지 않고 독립적으로 탐색을 수행합니다. 반면 **베이지안 최적화**는 이전 시도에서 얻은 하이퍼파라미터와 그 성능 정보를 바탕으로, 다음 번에 시도할 하이퍼파라미터 조합을 **지능적으로 예측**하여 탐색 효율을 높이는 방법입니다.

*   **대체 모델 (Surrogate Model):** 하이퍼파라미터 공간과 모델 성능 간의 관계를 모델링합니다. (예: 가우시안 프로세스)
*   **획득 함수 (Acquisition Function):** 대체 모델을 기반으로 다음 번에 탐색할 가장 유망한 하이퍼파라미터 조합을 선택합니다. (예: Expected Improvement)

### 4.2. 장단점
*   **장점:**
    *   그리드 서치나 랜덤 서치보다 **훨씬 적은 시도로 최적의 하이퍼파라미터를 찾을 가능성이 높습니다.**
    *   탐색 시간이 중요한 복잡한 모델이나 대규모 데이터셋에 특히 유용합니다.
*   **단점:**
    *   구현이 더 복잡하고, 개념적 이해가 필요합니다.
    *   병렬 처리가 제한적일 수 있습니다.

### 4.3. 주요 라이브러리
Scikit-learn 자체에는 베이지안 최적화 기능이 내장되어 있지 않지만, 다음과 같은 외부 라이브러리들이 널리 사용됩니다.
*   **`scikit-optimize` (skopt):** Scikit-learn과 유사한 API를 제공하여 사용하기 편리합니다.
*   **`Optuna`:** 동적 탐색 공간 정의, 병렬 처리, 시각화 등 강력한 기능을 제공하는 최신 라이브러리입니다.
*   **`Hyperopt`:** Tree-Parzen Estimator (TPE) 알고리즘을 기반으로 합니다.

## 5. 자동화된 머신러닝 (AutoML)

### 5.1. AutoML이란?
AutoML (Automated Machine Learning)은 데이터 전처리, 특성 공학, 모델 선택, 하이퍼파라미터 튜닝, 앙상블 구성 등 머신러닝 파이프라인의 **전 과정을 자동화**하는 기술을 의미합니다. 데이터 과학자의 수동적인 개입을 최소화하여 모델 개발 시간을 단축하고, 비전문가도 고성능 모델을 쉽게 구축할 수 있도록 돕습니다.

### 5.2. 주요 AutoML 프레임워크
*   **`Auto-Sklearn`:** Scikit-learn 기반의 AutoML 프레임워크로, 베이지안 최적화와 메타 학습(Meta-learning)을 사용하여 최적의 파이프라인을 찾습니다.
*   **`TPOT`:** 유전 프로그래밍(Genetic Programming)을 사용하여 최적의 Scikit-learn 파이프라인을 탐색합니다.
*   **`H2O.ai AutoML`:** H2O 플랫폼에서 제공하는 AutoML 기능으로, 다양한 모델과 앙상블을 자동으로 탐색합니다.
*   **클라우드 기반 AutoML 서비스:** Google Cloud AutoML, Azure Machine Learning AutoML, AWS SageMaker Autopilot 등 클라우드 벤더들이 제공하는 서비스도 있습니다.

## 6. 어떤 튜닝 방법을 선택해야 할까?

| 방법 | 특징 | 사용 추천 상황 |
| :--- | :--- | :--- |
| **그리드 서치** | 모든 조합 탐색, 최적 보장 | 하이퍼파라미터 수가 적고, 각 파라미터의 후보 값이 적을 때 |
| **랜덤 서치** | 무작위 샘플링, 효율적 | 탐색 공간이 넓고, 시간이 제한적일 때 |
| **베이지안 최적화** | 지능적 탐색, 효율성 높음 | 탐색 시간이 매우 중요하고, 복잡한 모델의 튜닝이 필요할 때 |
| **AutoML** | 전 과정 자동화 | 머신러닝 전문 지식이 부족하거나, 빠른 베이스라인/탐색이 필요할 때 |

**결론:** 일반적으로 **랜덤 서치**로 넓은 탐색 공간을 빠르게 탐색하여 유망한 영역을 찾은 후, 해당 영역에서 **그리드 서치**나 **베이지안 최적화**를 사용하여 더 세밀하게 최적의 하이퍼파라미터를 찾는 전략이 효과적입니다.
