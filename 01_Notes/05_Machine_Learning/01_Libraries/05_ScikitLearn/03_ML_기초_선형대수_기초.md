## 1. 선형대수학이란?
**선형대수학(Linear Algebra)**은 벡터(Vector), 행렬(Matrix), 그리고 이들 사이의 선형 변환(Linear Transformation) 및 연산을 다루는 수학의 한 분야입니다. 기하학적인 개념(점, 선, 평면)을 대수적인 표현(숫자 배열)으로 나타내고, 이러한 표현들을 조작하는 방법을 연구합니다. 현대 과학, 공학, 컴퓨터 과학 등 다양한 분야에서 핵심적인 도구로 활용됩니다.

### 1.1. 왜 머신러닝에 선형대수학이 필요한가?
머신러닝은 데이터를 기반으로 패턴을 학습하고 예측을 수행하는 분야이며, 이 과정에서 선형대수학은 이론적 기반이자 실질적인 구현 도구로서 필수적인 역할을 합니다.

*   **데이터 표현:** 머신러닝에서 다루는 모든 데이터는 선형대수학의 기본 요소인 벡터나 행렬의 형태로 표현됩니다. 예를 들어, 이미지는 픽셀 값으로 이루어진 행렬로, 텍스트는 단어의 빈도나 임베딩 벡터로, 센서 데이터는 시계열 벡터로 변환되어 모델의 입력으로 사용됩니다.
*   **알고리즘 구현 및 이해:** 선형 회귀(Linear Regression), 서포트 벡터 머신(SVM), 주성분 분석(PCA), 신경망(Neural Networks) 등 대부분의 머신러닝 알고리즘은 선형대수학 개념을 기반으로 설계되고 구현됩니다. 가중치(weights)는 행렬로, 입력 데이터는 벡터로 표현되어 행렬-벡터 곱셈과 같은 선형 연산을 통해 예측이 이루어집니다. 선형대수학을 이해하면 이러한 알고리즘의 동작 원리를 깊이 있게 파악하고, 모델을 효과적으로 개선할 수 있습니다.
*   **효율적인 계산:** 대규모 데이터셋을 다루는 머신러닝에서는 계산 효율성이 매우 중요합니다. NumPy와 같은 파이썬 라이브러리는 C나 Fortran으로 구현된 최적화된 선형대수학 루틴을 활용하여, 벡터 및 행렬 연산을 매우 빠르게 수행할 수 있도록 합니다. 이는 수백만 개의 데이터 포인트와 수천 개의 특성을 가진 데이터셋에서도 머신러닝 모델을 효율적으로 학습시키고 실행할 수 있게 합니다.

## 2. 벡터 (Vector)

### 2.1. 벡터의 정의
**벡터(Vector)**는 크기(Magnitude)와 방향(Direction)을 동시에 가지는 수학적 객체입니다. 기하학적으로는 원점(Origin)에서 시작하여 특정 점으로 향하는 화살표로 시각화할 수 있습니다. 대수적으로는 수치들의 순서 있는 리스트(Ordered List) 또는 배열(Array)로 표현됩니다.

*   **벡터의 구성 요소 (Components):** 벡터를 이루는 각각의 숫자를 '요소' 또는 '성분'이라고 합니다. 벡터의 차원(Dimension)은 이러한 요소의 개수를 의미합니다.
    *   예시: 2차원 벡터 $\mathbf{v} = (v_1, v_2)$, 3차원 벡터 $\mathbf{w} = (w_1, w_2, w_3)$.
*   **머신러닝에서의 활용:** 머신러닝에서는 주로 데이터 포인트나 특성(Feature)을 나타내는 데 벡터가 사용됩니다.
    *   **데이터 포인트:** 하나의 샘플(예: 한 명의 사람)을 여러 특성(예: 키, 몸무게, 나이)으로 표현할 때, 이 특성들을 모아 하나의 벡터로 나타낼 수 있습니다.
    *   **특성 벡터:** 각 특성 자체가 벡터로 표현될 수도 있습니다 (예: 워드 임베딩).
*   **표기법:**
    *   **열 벡터(Column Vector):** 데이터를 세로로 나열한 형태입니다. 머신러닝에서 가장 흔하게 사용되는 표기법입니다.
        $ \mathbf{x} = \begin{pmatrix} x_1 \ x_2 \ \vdots \ x_n \end{pmatrix} $
    *   **행 벡터(Row Vector):** 데이터를 가로로 나열한 형태입니다.
        $ \mathbf{x}^T = (x_1, x_2, \dots, x_n) $
    *   일반적으로 벡터는 굵은 소문자($\mathbf{v}$)로 표기합니다.

### 2.2. 벡터 연산
벡터는 다양한 연산을 통해 조작될 수 있으며, 이러한 연산들은 머신러닝 알고리즘의 핵심 구성 요소가 됩니다.

#### 2.2.1. 벡터 덧셈과 뺄셈
두 벡터의 각 요소를 대응하는 위치에 있는 요소끼리 더하거나 뺍니다. 두 벡터의 차원(크기)이 반드시 같아야 합니다. 결과는 원래 벡터와 동일한 차원의 새로운 벡터가 됩니다.
*   **덧셈:** $ \mathbf{a} + \mathbf{b} = (a_1+b_1, a_2+b_2, \dots, a_n+b_n) $
*   **뺄셈:** $ \mathbf{a} - \mathbf{b} = (a_1-b_1, a_2-b_2, \dots, a_n-b_n) $
*   **기하학적 의미:** 벡터 덧셈은 한 벡터의 끝에 다른 벡터를 이어 붙여 새로운 벡터를 만드는 것과 같습니다 (삼각형 법칙 또는 평행사변형 법칙).
*   **머신러닝 활용:** 특성 벡터의 결합, 오차 벡터 계산 (예측값 - 실제값).

#### 2.2.2. 스칼라 곱셈
벡터의 각 요소에 스칼라(단일 숫자)를 곱하는 연산입니다. 벡터의 방향은 유지하면서 크기만 변경됩니다.
*   **공식:** $ c \mathbf{a} = (c a_1, c a_2, \dots, c a_n) $
*   **기하학적 의미:** 벡터를 늘리거나 줄이는 것과 같습니다. 스칼라가 음수이면 방향이 반대가 됩니다.
*   **머신러닝 활용:** 학습률(Learning Rate)을 적용하여 가중치 업데이트, 특성 스케일링.

### 2.3. 벡터의 내적 (Dot Product)
두 벡터의 내적(Dot Product)은 두 벡터의 각 요소를 곱한 후 그 결과들을 모두 더한 값입니다. 결과는 스칼라(단일 숫자)이며, 두 벡터의 차원(크기)이 같아야 합니다. 내적은 두 벡터가 얼마나 같은 방향을 향하고 있는지를 나타내는 척도로 사용될 수 있습니다.

*   **공식:** $ \mathbf{a} \cdot \mathbf{b} = \sum_{i=1}^{n} a_i b_i = a_1 b_1 + a_2 b_2 + \dots + a_n b_n $
*   **기하학적 의미:** 내적은 두 벡터의 크기와 그 사이 각도의 코사인 값의 곱으로도 표현될 수 있습니다.
    $ \mathbf{a} \cdot \mathbf{b} = ||\mathbf{a}|| \cdot ||\mathbf{b}|| \cdot \cos(\theta) $
    *   여기서 $||\mathbf{a}||$와 $||\mathbf{b}||$는 각 벡터의 크기(노름)를, $\theta$는 두 벡터 사이의 각도를 나타냅니다.
    *   이를 통해 두 벡터의 유사도를 측정하는 코사인 유사도(Cosine Similarity)를 계산할 수 있습니다. 두 벡터가 같은 방향을 가리킬수록 내적 값은 커집니다.
*   **머신러닝 활용:**
    *   **유사도 측정:** 텍스트 분석에서 문서나 단어 벡터 간의 유사도를 측정하거나, 추천 시스템에서 사용자-아이템 유사도를 계산할 때 사용됩니다.
    *   **선형 회귀:** 선형 회귀 모델에서 특성 벡터와 가중치 벡터의 내적을 통해 예측값을 계산합니다.
    *   **신경망:** 신경망의 각 뉴런에서 입력 벡터와 가중치 벡터의 내적을 계산하여 활성화 함수에 전달합니다.

### 2.4. 벡터의 노름 (Norm)
벡터의 노름(Norm)은 벡터의 '크기' 또는 '길이'를 측정하는 방법입니다. 원점에서 벡터의 끝까지의 거리를 나타내며, 다양한 방식으로 정의될 수 있습니다. 머신러닝에서는 주로 모델의 복잡도를 측정하거나 오차를 계산하는 데 사용됩니다.

*   **L2 노름 (Euclidean Norm, 유클리드 노름):** 가장 흔하게 사용되는 노름으로, 벡터의 각 요소의 제곱합에 제곱근을 취한 값입니다. 유클리드 공간에서의 '직선 거리'를 의미합니다.
    *   **공식:** $ ||\mathbf{a}||_2 = \sqrt{\sum_{i=1}^{n} a_i^2} $
    *   **특징:** 벡터의 크기를 직관적으로 나타내며, 미분 가능하여 최적화 알고리즘에 널리 사용됩니다.
*   **L1 노름 (Manhattan Norm, 맨해튼 노름):** 벡터의 각 요소의 절댓값 합입니다. '맨해튼 거리' 또는 '택시 거리'라고도 불립니다.
    *   **공식:** $ ||\mathbf{a}||_1 = \sum_{i=1}^{n} |a_i| $
    *   **특징:** 특정 요소를 0으로 만드는 경향이 있어 특성 선택(Feature Selection)에 유용합니다.
*   **Lp 노름 (Minkowski Norm):** L1 노름과 L2 노름을 일반화한 형태입니다. $p \ge 1$인 실수 $p$에 대해 정의됩니다.
    *   **공식:** $ ||\mathbf{a}||_p = (\sum_{i=1}^{n} |a_i|^p)^{1/p} $
*   **무한대 노름 (Maximum Norm, $L_\infty$ Norm):** 벡터 요소의 절댓값 중 가장 큰 값입니다.
    *   **공식:** $ ||\mathbf{a}||_\infty = \max_i |a_i| $
*   **머신러닝 활용:**
    *   **정규화 (Regularization):** L1 노름(Lasso)과 L2 노름(Ridge)은 모델의 가중치 벡터에 페널티를 부여하여 과적합(Overfitting)을 방지하고 모델의 복잡도를 제어하는 데 사용됩니다.
    *   **오차 측정:** 예측값과 실제값 사이의 차이(오차 벡터)의 크기를 측정하여 모델의 성능을 평가합니다.
    *   **거리 측정:** 데이터 포인트 간의 유사성 또는 비유사성을 측정하는 데 사용됩니다 (예: K-NN 알고리즘).

## 3. 행렬 (Matrix)

### 3.1. 행렬의 정의
**행렬(Matrix)**은 숫자들을 직사각형 형태로 행(Row)과 열(Column)로 배열한 2차원 배열입니다. 벡터가 1차원 배열이라면, 행렬은 그 벡터들이 모여 이루어진 2차원 구조라고 생각할 수 있습니다. 행렬은 여러 벡터를 동시에 표현하거나, 선형 변환을 나타내는 데 사용됩니다.

*   **행렬의 차원 (Dimension):** 행렬의 크기는 '행의 개수($m$)'와 '열의 개수($n$)'로 표현되며, $m \times n$ 행렬이라고 표기합니다.
    *   예시: $2 \times 3$ 행렬은 2개의 행과 3개의 열을 가집니다.
*   **행렬의 요소 (Elements):** 행렬 내의 각 숫자를 요소 또는 원소라고 부릅니다. 일반적으로 $A_{ij}$는 $i$번째 행과 $j$번째 열에 위치한 요소를 나타냅니다.
*   **머신러닝에서의 활용:** 머신러닝에서 행렬은 데이터를 표현하는 가장 기본적인 구조입니다.
    *   **데이터셋 표현:** 전체 데이터셋은 종종 행렬로 표현됩니다. 이때 각 행은 하나의 데이터 샘플(예: 한 명의 환자, 하나의 이미지)을 나타내고, 각 열은 해당 샘플의 특정 특성(Feature)을 나타냅니다.
    *   **가중치 행렬:** 신경망에서 각 레이어 간의 연결 강도를 나타내는 가중치(weights)는 행렬 형태로 저장됩니다.
    *   **변환:** 데이터를 다른 공간으로 변환하거나 회전시키는 선형 변환을 행렬로 표현할 수 있습니다.
*   **예시:** 
    $ A = \begin{pmatrix}
    a_{11} & a_{12} & \dots & a_{1n} \\
    a_{21} & a_{22} & \dots & a_{2n} \\
    \vdots & \vdots & \ddots & \vdots \\
    a_{m1} & a_{m2} & \dots & a_{mn}
    \end{pmatrix} $
    *   위는 $m$개의 행과 $n$개의 열을 가진 행렬 $A$를 나타냅니다.


### 3.2. 행렬 연산
행렬은 벡터와 마찬가지로 다양한 연산을 통해 조작될 수 있으며, 이러한 연산들은 머신러닝 모델의 핵심적인 계산을 구성합니다.

#### 3.2.1. 행렬 덧셈과 뺄셈
두 행렬의 각 요소를 대응하는 위치에 있는 요소끼리 더하거나 뺍니다. 두 행렬의 크기(행과 열의 수)가 반드시 같아야 합니다. 결과는 원래 행렬과 동일한 크기의 새로운 행렬이 됩니다.
*   **덧셈:** $ A + B = \begin{pmatrix} a_{11}+b_{11} & \dots \\ \vdots & \ddots \end{pmatrix} $
*   **뺄셈:** $ A - B = \begin{pmatrix} a_{11}-b_{11} & \dots \\ \vdots & \ddots \end{pmatrix} $
*   **특징:** 교환 법칙($A+B = B+A$)과 결합 법칙($(A+B)+C = A+(B+C)$)이 성립합니다.
*   **머신러닝 활용:** 여러 데이터셋의 결합, 오차 행렬 계산.

#### 3.2.2. 스칼라 곱셈
행렬의 각 요소에 스칼라(단일 숫자)를 곱하는 연산입니다. 행렬의 차원은 변하지 않고 각 요소의 값만 변경됩니다.
*   **공식:** $ cA = \begin{pmatrix} c a_{11} & \dots \\ \vdots & \ddots \end{pmatrix} $
*   **머신러닝 활용:** 학습률(Learning Rate) 적용, 특성 스케일링.

#### 3.2.3. 행렬 곱셈 (Matrix Multiplication)
두 행렬을 곱하는 연산은 가장 중요하고 복잡한 행렬 연산 중 하나입니다. 첫 번째 행렬의 열 수와 두 번째 행렬의 행 수가 같아야만 곱셈이 가능합니다. 결과 행렬의 각 요소는 첫 번째 행렬의 행 벡터와 두 번째 행렬의 열 벡터의 내적으로 계산됩니다.
*   **조건:** $ (m \times n) \times (n \times p) = (m \times p) $ 행렬
    *   첫 번째 행렬 $A$의 차원이 $m \times n$이고, 두 번째 행렬 $B$의 차원이 $n \times p$일 때, 결과 행렬 $C = AB$의 차원은 $m \times p$가 됩니다.
*   **공식:** $ C_{ij} = \sum_{k=1}^{n} A_{ik} B_{kj} $
*   **특징:** 교환 법칙이 성립하지 않습니다 ($AB \ne BA$). 결합 법칙은 성립합니다 ($(AB)C = A(BC)$).
*   **머신러닝 활용:**
    *   **신경망:** 신경망의 각 레이어에서 입력 데이터와 가중치 행렬의 곱셈을 통해 다음 레이어의 출력을 계산합니다.
    *   **선형 변환:** 데이터를 다른 차원 공간으로 변환하거나 회전시키는 데 사용됩니다.
    *   **주성분 분석 (PCA):** 공분산 행렬과 고유 벡터의 곱셈을 통해 주성분을 추출합니다.


### 3.3. 전치 행렬 (Transpose Matrix)
전치 행렬(Transpose Matrix)은 주어진 행렬의 행과 열을 서로 바꾼 행렬입니다. 즉, 원래 행렬의 $i$번째 행은 전치 행렬의 $i$번째 열이 되고, 원래 행렬의 $j$번째 열은 전치 행렬의 $j$번째 행이 됩니다. 행렬 $A$의 전치 행렬은 $A^T$ 또는 $A'$로 표기합니다.

*   **공식:** 행렬 $A$의 요소가 $A_{ij}$일 때, 전치 행렬 $A^T$의 요소는 $A^T_{ji} = A_{ij}$가 됩니다.
*   **예시:**
    $ A = \begin{pmatrix} a & b \\ c & d \\ e & f \end{pmatrix} \implies A^T = \begin{pmatrix} a & c & e \\ b & d & f \end{pmatrix} $
    *   $2 \times 3$ 행렬 $A$의 전치 행렬 $A^T$는 $3 \times 2$ 행렬이 됩니다.
*   **특징:**
    *   $(A^T)^T = A$
    *   $(A+B)^T = A^T + B^T$
    *   $(cA)^T = cA^T$
    *   $(AB)^T = B^T A^T$ (행렬 곱셈의 순서가 바뀝니다)
*   **머신러닝 활용:**
    *   **행렬 곱셈의 조건 맞추기:** 행렬 곱셈을 수행할 때, 첫 번째 행렬의 열 수와 두 번째 행렬의 행 수가 일치해야 합니다. 이 조건을 맞추기 위해 전치 행렬을 사용하기도 합니다.
    *   **선형 회귀:** 최소 제곱법(Least Squares Method)을 이용한 선형 회귀 모델의 해를 구할 때 정규 방정식(Normal Equation)에서 전치 행렬이 사용됩니다.
    *   **공분산 행렬:** 데이터의 공분산 행렬은 대칭 행렬(Symmetric Matrix, $A = A^T$)의 특성을 가지며, 이는 전치 행렬의 개념과 관련이 깊습니다.
    *   **신경망:** 역전파(Backpropagation) 과정에서 가중치 업데이트를 계산할 때 전치 행렬 연산이 빈번하게 사용됩니다.


### 3.4. 역행렬 (Inverse Matrix)
역행렬(Inverse Matrix)은 숫자에서의 역수와 유사한 개념입니다. 정방 행렬(Square Matrix, 행과 열의 수가 같은 행렬) $A$에 대해, $A A^{-1} = A^{-1} A = I$를 만족하는 행렬 $A^{-1}$을 $A$의 역행렬이라고 합니다. 여기서 $I$는 항등 행렬(Identity Matrix)입니다. 모든 정방 행렬이 역행렬을 가지는 것은 아닙니다.

*   **역행렬의 존재 조건:**
    *   행렬은 반드시 정방 행렬이어야 합니다.
    *   행렬의 행렬식(Determinant)이 0이 아니어야 합니다. 행렬식이 0인 행렬은 '특이 행렬(Singular Matrix)' 또는 '비가역 행렬(Non-invertible Matrix)'이라고 하며, 역행렬이 존재하지 않습니다.
*   **공식 (2x2 행렬의 경우):**
    $ A = \begin{pmatrix} a & b \\ c & d \end{pmatrix} $
    $ A^{-1} = \frac{1}{ad-bc} \begin{pmatrix} d & -b \\ -c & a \end{pmatrix} $
    *   여기서 $ad-bc$는 행렬 $A$의 행렬식(Determinant)입니다.
*   **특징:**
    *   $(A^{-1})^{-1} = A$
    *   $(AB)^{-1} = B^{-1} A^{-1}$
    *   $(A^T)^{-1} = (A^{-1})^T$
*   **머신러닝 활용:**
    *   **선형 시스템 해 찾기:** $A\mathbf{x} = \mathbf{b}$ 형태의 선형 방정식 시스템에서 $\mathbf{x} = A^{-1}\mathbf{b}$를 통해 해를 구할 수 있습니다. 이는 선형 회귀 모델의 가중치를 직접 계산하는 데 사용될 수 있습니다.
    *   **최소 제곱법 (Least Squares Method):** 선형 회귀에서 최적의 가중치를 찾는 정규 방정식(Normal Equation) $ (X^T X)\mathbf{w} = X^T\mathbf{y} $의 해는 $ \mathbf{w} = (X^T X)^{-1} X^T\mathbf{y} $로 주어지며, 여기서 역행렬 계산이 필요합니다.
    *   **데이터 변환:** 데이터를 원래 공간으로 되돌리거나 특정 변환을 '취소'하는 데 역행렬이 사용될 수 있습니다.

### 3.5. 항등 행렬 (Identity Matrix)
항등 행렬(Identity Matrix)은 정방 행렬(Square Matrix)의 특별한 형태로, 주대각선(Principal Diagonal, 왼쪽 위에서 오른쪽 아래로 이어지는 대각선)의 모든 원소가 1이고, 나머지 모든 원소는 0인 행렬입니다. 행렬 곱셈에서 숫자 1과 같은 역할을 합니다. 즉, 어떤 행렬 $A$에 항등 행렬 $I$를 곱하면 원래 행렬 $A$가 그대로 유지됩니다 ($AI = IA = A$). 

*   **표기법:** 일반적으로 $I$ 또는 차원을 명시하여 $I_n$ (n차 정방 행렬)으로 표기합니다.
*   **예시:**
    *   $I_2 = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} $ 
    *   $I_3 = \begin{pmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{pmatrix} $ 
*   **특징:**
    *   항등 행렬은 항상 정방 행렬입니다.
    *   역행렬의 정의에서 사용됩니다 ($A A^{-1} = A^{-1} A = I$).
    *   전치 행렬을 취해도 자기 자신과 같습니다 ($I^T = I$). 
*   **머신러닝 활용:**
    *   **선형 변환:** 데이터를 변환하지 않고 그대로 유지하는 선형 변환을 나타낼 때 사용됩니다.
    *   **정규화 (Regularization):** 릿지 회귀(Ridge Regression)와 같은 일부 정규화 기법에서는 항등 행렬을 사용하여 가중치에 페널티를 부여하는 항을 구성합니다.
    *   **행렬 분해:** 특이값 분해(SVD)나 고유값 분해(Eigen-decomposition)와 같은 행렬 분해 기법에서 중요한 역할을 합니다.

## 4. 실습: NumPy를 이용한 선형대수학 연산
NumPy는 파이썬에서 선형대수학 연산을 효율적으로 수행할 수 있도록 돕는 핵심 라이브러리입니다. C나 Fortran으로 구현된 최적화된 루틴을 사용하여 대규모 데이터셋에서도 빠른 계산을 가능하게 합니다. 이 실습에서는 NumPy를 사용하여 벡터와 행렬의 기본 연산을 수행하는 방법을 보여줍니다.

```python
import numpy as np # NumPy 라이브러리 임포트

# 1. 벡터 생성
# np.array() 함수를 사용하여 1차원 배열(벡터)을 생성합니다.
vec1 = np.array([1, 2, 3])
vec2 = np.array([4, 5, 6])
print("벡터 1:", vec1)
print("벡터 2:", vec2)

# 2. 벡터 덧셈
# NumPy 배열은 요소별(element-wise) 연산을 지원하여 벡터 덧셈을 쉽게 수행할 수 있습니다.
print("\n벡터 덧셈 (vec1 + vec2):", vec1 + vec2)

# 3. 스칼라 곱셈
# 벡터에 스칼라(단일 숫자)를 곱하면 벡터의 모든 요소에 해당 스칼라가 곱해집니다.
print("스칼라 곱셈 (2 * vec1):", 2 * vec1)

# 4. 벡터 내적
# np.dot() 함수를 사용하여 두 벡터의 내적을 계산합니다. 결과는 스칼라입니다.
print("벡터 내적 (vec1 . vec2):", np.dot(vec1, vec2))

# 5. 벡터 L2 노름
# np.linalg.norm() 함수를 사용하여 벡터의 L2 노름(유클리드 길이)을 계산합니다.
print("벡터 1의 L2 노름:", np.linalg.norm(vec1))

# 6. 행렬 생성
# np.array() 함수에 중첩 리스트를 전달하여 2차원 배열(행렬)을 생성합니다.
mat1 = np.array([[1, 2],
                 [3, 4]])
mat2 = np.array([[5, 6],
                 [7, 8]])
print("\n행렬 1:\n", mat1)
print("행렬 2:\n", mat2)

# 7. 행렬 덧셈
# 행렬 덧셈도 벡터 덧셈과 마찬가지로 요소별 연산으로 수행됩니다.
print("\n행렬 덧셈 (mat1 + mat2):\n", mat1 + mat2)

# 8. 행렬 곱셈
# 행렬 곱셈은 @ 연산자 또는 np.dot() 함수를 사용하여 수행합니다.
# 이는 요소별 곱셈(element-wise multiplication)이 아님에 유의합니다.
print("행렬 곱셈 (mat1 @ mat2):\n", mat1 @ mat2) # 또는 np.dot(mat1, mat2)

# 9. 전치 행렬
# 행렬 객체의 .T 속성을 사용하여 전치 행렬을 얻을 수 있습니다.
print("행렬 1의 전치 행렬 (mat1.T):\n", mat1.T)

# 10. 역행렬 (존재하는 경우)
# np.linalg.inv() 함수를 사용하여 역행렬을 계산합니다.
# 역행렬이 존재하지 않는 경우(행렬식이 0인 경우) LinAlgError가 발생하므로 try-except 블록으로 처리합니다.
try:
    mat_inv = np.linalg.inv(mat1)
    print("행렬 1의 역행렬:\n", mat_inv)
    # 역행렬 확인: 원래 행렬과 역행렬을 곱하면 항등 행렬에 가까운 결과가 나옵니다.
    print("역행렬 확인 (mat1 @ mat_inv):\n", mat1 @ mat_inv) 
except np.linalg.LinAlgError:
    print("행렬 1은 역행렬이 존재하지 않습니다.")

# 11. 항등 행렬
# np.eye(n) 함수를 사용하여 n x n 크기의 항등 행렬을 생성합니다.
identity_matrix = np.eye(3) # 3x3 항등 행렬
print("\n3x3 항등 행렬:\n", identity_matrix)
```
