## 1. 선형 SVM의 기본 아이디어

**서포트 벡터 머신(Support Vector Machine, SVM)**은 분류 및 회귀 분석을 위한 강력한 지도 학습 모델입니다. 특히 분류 문제에서 뛰어난 성능을 보이며, 그 핵심 아이디어는 두 클래스를 분리하는 최적의 **결정 경계(Decision Boundary)**를 찾는 것입니다. 이때, 단순히 클래스를 분리하는 것을 넘어, 결정 경계와 가장 가까운 훈련 데이터 포인트들 사이의 **마진(Margin)**을 최대화하는 데 중점을 둡니다.

### 1.1. 결정 경계와 마진
선형 SVM의 목표는 두 클래스를 가장 잘 분리하는 **결정 경계(Decision Boundary)**를 찾는 것입니다. 이 결정 경계는 고차원 공간에서 두 클래스를 나누는 초평면(hyperplane)으로 표현됩니다.
이때, 단순히 두 클래스를 분리하는 것을 넘어, 결정 경계와 각 클래스에 속하는 가장 가까운 데이터 포인트(서포트 벡터) 사이의 거리를 **마진(Margin)**이라고 하며, 이 마진을 **최대화**하는 결정 경계를 찾습니다.

*   **결정 경계:** $ \mathbf{w} \cdot \mathbf{x} + b = 0 $
    *   $\mathbf{w}$: 결정 경계에 수직인 벡터 (가중치 벡터)
    *   $\mathbf{x}$: 데이터 포인트
    *   $b$: 절편 (bias)
*   **마진 최대화의 중요성:** 마진이 클수록 모델의 일반화 성능이 좋다고 알려져 있습니다. 이는 새로운, 보지 못한 데이터에 대해서도 분류 오류를 범할 가능성이 낮아진다는 것을 의미합니다. 마진이 넓을수록 모델이 데이터의 노이즈나 이상치에 덜 민감하게 반응하며, 더 견고한 분류를 수행할 수 있습니다.

### 1.2. 서포트 벡터 (Support Vector)
**서포트 벡터**는 결정 경계에 가장 가까이 위치한 데이터 포인트들입니다. 이 데이터 포인트들은 마진을 정의하는 데 직접적으로 기여하며, 결정 경계의 위치와 방향을 결정하는 데 핵심적인 역할을 합니다.

*   **역할:** 오직 이 서포트 벡터들만이 결정 경계를 정의하는 데 영향을 미치며, 나머지 마진 바깥에 위치한 데이터 포인트들은 결정 경계에 영향을 주지 않습니다. 이는 SVM이 데이터의 부분집합(서포트 벡터)만을 사용하여 모델을 구축하므로, 대규모 데이터셋에서도 효율적으로 작동할 수 있는 이유 중 하나입니다.
*   **수학적 의미:** 서포트 벡터들은 $ \mathbf{w} \cdot \mathbf{x} + b = 1 $ 또는 $ \mathbf{w} \cdot \mathbf{x} + b = -1 $ 을 만족하는 데이터 포인트들입니다. 이 두 초평면 사이의 거리가 마진이 됩니다.

### 1.3. 하드 마진 (Hard Margin) SVM
**하드 마진 SVM**은 매우 엄격한 분류 기준을 적용합니다.

*   **정의:** 모든 훈련 데이터 포인트가 결정 경계에 의해 완벽하게 분리되어야 하며, 마진 바깥에 위치해야 합니다. 즉, 분류 오류를 전혀 허용하지 않습니다.
*   **장점:** 데이터가 선형적으로 완벽하게 분리 가능하고 노이즈가 없을 때, 매우 강력하고 명확한 결정 경계를 제공합니다.
*   **단점:**
    *   **과적합(Overfitting) 위험:** 데이터에 노이즈나 이상치(Outlier)가 존재하거나, 데이터가 선형적으로 완벽하게 분리되지 않는 경우, 하드 마진 SVM은 과적합되기 쉽습니다. 이상치 하나 때문에 결정 경계가 크게 왜곡될 수 있습니다.
    *   **적용 한계:** 선형적으로 완벽하게 분리되지 않는 현실의 대부분의 데이터에는 적용할 수 없습니다.

### 1.4. 소프트 마진 (Soft Margin) SVM
현실의 데이터는 대부분 노이즈를 포함하거나 선형적으로 완벽하게 분리되지 않습니다. 이러한 문제를 해결하기 위해 **소프트 마진 SVM**이 도입되었습니다.

*   **정의:** 분류 오류를 어느 정도 허용하면서 마진을 최대화하는 SVM입니다. 마진을 침범하거나 잘못 분류된 데이터 포인트에 대해 **슬랙 변수(Slack Variable, $\xi$)**를 도입하여 페널티를 부과합니다.
*   **하이퍼파라미터 `C`:** 소프트 마진 SVM에서 가장 중요한 하이퍼파라미터는 `C`입니다. `C`는 **오류에 대한 페널티의 강도**를 조절합니다.
    *   `C`가 **작을수록**: 분류 오류에 대한 페널티가 약해집니다. 이는 모델이 더 많은 오류를 허용하고 마진을 넓게 설정하는 경향을 보입니다 (과소적합 경향). 모델의 복잡도가 낮아집니다.
    *   `C`가 **클수록**: 분류 오류에 대한 페널티가 강해집니다. 이는 모델이 오류를 적게 허용하고 마진을 좁게 설정하는 경향을 보입니다 (과적합 경향). 모델의 복잡도가 높아집니다.
*   **편향-분산 트레이드오프:** `C` 값은 SVM의 편향-분산 트레이드오프를 조절하는 역할을 합니다. `C`가 작으면 편향은 증가하고 분산은 감소하며, `C`가 크면 편향은 감소하고 분산은 증가합니다.

소프트 마진 SVM은 현실의 복잡한 데이터셋에 더 유연하게 적용될 수 있도록 하여 SVM의 실용성을 크게 높였습니다.

## 2. 커널 트릭 (Kernel Trick)

선형 SVM은 데이터가 선형적으로 분리 가능할 때 매우 효과적입니다. 하지만 현실의 많은 데이터는 선형적으로 분리할 수 없는 비선형적인 패턴을 가집니다. 이러한 비선형 문제를 해결하기 위해 SVM은 **커널 트릭(Kernel Trick)**이라는 매우 강력하고 우아한 기법을 사용합니다.

### 2.1. 비선형 문제의 해결
SVM의 가장 큰 특징 중 하나는 **커널 트릭(Kernel Trick)**을 사용하여 선형적으로 분리할 수 없는 데이터를 고차원 공간으로 매핑하여 선형 분리가 가능하도록 만드는 것입니다.

*   **기본 아이디어:** 저차원 공간에서 선형적으로 분리 불가능한 데이터도, 충분히 높은 차원의 공간으로 변환하면 선형적으로 분리 가능해질 수 있다는 아이디어에서 출발합니다. 예를 들어, 2차원 평면에서 원형으로 분포된 데이터를 3차원 공간으로 변환하면 평면으로 분리할 수 있게 됩니다.
*   **커널 트릭의 마법:** 이때, 실제로 고차원 공간으로 데이터를 변환하지 않고, 고차원 공간에서의 **내적(Dot Product)** 값을 계산하는 **커널 함수(Kernel Function)**를 사용합니다. SVM의 최적화 문제(쌍대 문제)는 데이터 포인트 간의 내적만을 포함하기 때문에, 이 내적 연산을 커널 함수로 대체함으로써 데이터를 명시적으로 고차원 공간으로 변환하는 복잡하고 계산 비용이 큰 과정을 피할 수 있습니다. 이를 통해 계산 비용을 크게 줄이면서 비선형 분류 문제를 효율적으로 해결할 수 있습니다.
*   **수학적 표현:** $\phi(\mathbf{x})$를 저차원 공간의 데이터 $\mathbf{x}$를 고차원 공간으로 매핑하는 함수라고 할 때, 커널 함수 $K(\mathbf{x}, \mathbf{x'})$는 고차원 공간에서의 내적을 계산합니다: $ K(\mathbf{x}, \mathbf{x'}) = \phi(\mathbf{x})^T \phi(\mathbf{x'}) $.

### 2.2. 주요 커널 함수
다양한 커널 함수들이 존재하며, 문제의 특성에 따라 적절한 커널을 선택하는 것이 중요합니다.

*   **선형 커널 (Linear Kernel):**
    $ K(\mathbf{x}, \mathbf{x'}) = \mathbf{x}^T \mathbf{x'} $
    *   가장 단순한 커널로, 데이터를 고차원 공간으로 매핑하지 않고 원래의 특성 공간에서 선형 결정 경계를 찾습니다.
    *   데이터가 선형적으로 분리 가능할 때 사용하며, 계산 비용이 낮습니다.
    *   릿지 회귀나 라쏘 회귀와 유사하게 작동할 수 있습니다.

*   **다항 커널 (Polynomial Kernel):**
    $ K(\mathbf{x}, \mathbf{x'}) = (\gamma \mathbf{x}^T \mathbf{x'} + r)^d $
    *   `d`: 다항식의 차수(degree). 이 값이 클수록 모델의 복잡도가 증가합니다.
    *   `gamma` (감마): 각 훈련 샘플이 미치는 영향의 범위를 결정합니다. 값이 클수록 영향의 범위가 좁아져 결정 경계가 더 복잡해지고, 과적합될 가능성이 높아집니다.
    *   `r` (coef0): 독립항.
    *   데이터가 다항식 형태로 분리될 수 있을 때 유용합니다. 예를 들어, 2차 다항 커널은 원형 또는 타원형의 결정 경계를 만들 수 있습니다.

*   **RBF 커널 (Radial Basis Function Kernel, 가우시안 커널):**
    $ K(\mathbf{x}, \mathbf{x'}) = \exp(-\gamma ||\mathbf{x} - \mathbf{x'}||^2) $
    *   `gamma` (감마): 하나의 훈련 데이터가 미치는 영향의 범위를 결정합니다. 값이 클수록 영향의 범위가 좁아져 결정 경계가 더 복잡해지고, 과적합될 가능성이 높아집니다. 값이 작을수록 영향의 범위가 넓어져 결정 경계가 부드러워집니다.
    *   가장 널리 사용되는 커널 중 하나로, 매우 복잡하고 비선형적인 데이터 패턴을 효과적으로 처리할 수 있습니다. 무한 차원의 공간으로 데이터를 매핑하는 효과를 가집니다.
    *   데이터가 선형적으로 분리 불가능할 때 기본적으로 시도해볼 만한 커널입니다.

*   **시그모이드 커널 (Sigmoid Kernel):**
    $ K(\mathbf{x}, \mathbf{x'}) = \tanh(\gamma \mathbf{x}^T \mathbf{x'} + r) $
    *   신경망의 활성화 함수와 유사한 형태를 가집니다.

커널 트릭은 SVM이 선형 분류기의 한계를 넘어 비선형 분류 문제에서도 강력한 성능을 발휘할 수 있도록 하는 핵심적인 기술입니다. 적절한 커널 함수와 그에 따른 하이퍼파라미터(`C`, `gamma`, `d` 등)를 선택하는 것이 SVM 모델의 성능에 큰 영향을 미칩니다.


## 3. SVM의 최적화 문제: 쌍대 문제 (Dual Problem)

SVM은 마진을 최대화하는 동시에, 모든 데이터 포인트가 올바르게 분류되어야 한다는 **제약 조건(Constraints)**을 만족해야 하는 **제약 조건부 최적화 문제(Constrained Optimization Problem)**입니다. 이러한 문제는 일반적인 미분 기반의 최적화 방법으로는 직접 해결하기 어렵습니다. 이를 해결하기 위해 **라그랑주 승수법(Lagrange Multipliers)**을 사용하여 문제를 **쌍대 문제(Dual Problem)**로 변환하여 해결합니다.

### 3.1. 라그랑주 승수법 (Lagrange Multipliers)
SVM은 마진을 최대화하는 동시에 제약 조건(데이터 포인트가 올바르게 분류되어야 함)을 만족해야 하는 **제약 조건부 최적화 문제**입니다. 이를 해결하기 위해 **라그랑주 승수법(Lagrange Multipliers)**을 사용하며, 원래의 최적화 문제(원시 문제, Primal Problem)를 **쌍대 문제(Dual Problem)**로 변환하여 해결합니다.

*   **원시 문제 (Primal Problem):** SVM의 원래 최적화 문제는 마진을 최대화하는 가중치 벡터 $\mathbf{w}$와 절편 $b$를 찾는 것입니다. 이는 다음과 같은 형태로 표현됩니다.
    $ \text{Minimize} \quad \frac{1}{2} ||\mathbf{w}||^2 $
    $ \text{Subject to} \quad y_i (\mathbf{w} \cdot \mathbf{x}_i + b) \ge 1 \quad \text{for all } i $
    (소프트 마진의 경우 슬랙 변수 $\xi_i$와 페널티 항 $C \sum \xi_i$가 추가됩니다.)

*   **라그랑주 승수법:** 제약 조건이 있는 최적화 문제를 풀기 위해 라그랑주 함수(Lagrangian Function)를 구성합니다. 라그랑주 함수는 목적 함수와 제약 조건을 라그랑주 승수($\alpha_i$)를 사용하여 결합한 것입니다. 이 라그랑주 함수를 미분하여 최적해를 찾습니다.

*   **쌍대 문제로의 변환:** 라그랑주 함수를 $\mathbf{w}$와 $b$에 대해 미분하여 0으로 놓고 정리하면, 원래의 원시 문제가 **쌍대 문제**로 변환됩니다. 쌍대 문제는 라그랑주 승수($\alpha_i$)에 대한 최적화 문제가 되며, 놀랍게도 이 쌍대 문제는 데이터 포인트 간의 **내적(Dot Product)**으로만 표현됩니다.
    $ \text{Maximize} \quad \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i=1}^{n} \sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (\mathbf{x}_i \cdot \mathbf{x}_j) $
    $ \text{Subject to} \quad \sum_{i=1}^{n} \alpha_i y_i = 0 $
    $ \quad \quad \quad \quad 0 \le \alpha_i \le C \quad \text{for all } i $ (소프트 마진의 경우)

이 내적 부분($\mathbf{x}_i \cdot \mathbf{x}_j$)을 커널 함수 $K(\mathbf{x}_i, \mathbf{x}_j)$로 대체함으로써, 데이터를 실제로 고차원 공간으로 매핑하지 않고도 고차원 공간에서의 계산을 수행할 수 있게 됩니다. 이것이 바로 **커널 트릭(Kernel Trick)**의 핵심입니다.

### 3.2. 쌍대 문제의 장점
쌍대 문제로 변환하여 SVM을 해결하는 것은 여러 가지 중요한 장점을 제공합니다.

*   **커널 트릭 적용 가능:** 가장 큰 장점입니다. 최적화 문제가 데이터 포인트 간의 내적 형태로 표현되기 때문에, 이 내적을 커널 함수로 대체하여 비선형 분류 문제를 효율적으로 해결할 수 있습니다. 이는 데이터를 명시적으로 고차원 공간으로 변환하는 것보다 훨씬 계산 효율적입니다.
*   **서포트 벡터만 사용:** 쌍대 문제의 해인 라그랑주 승수 $\alpha_i$ 중에서 0이 아닌 값($\alpha_i > 0$)을 가지는 데이터 포인트들만이 서포트 벡터가 됩니다. 최종 결정 경계는 오직 이 서포트 벡터들에 의해서만 결정됩니다. 따라서 훈련 데이터의 전체 크기에 관계없이 서포트 벡터의 수에만 의존하여 계산 효율성을 높일 수 있습니다. 이는 대규모 데이터셋에서도 SVM이 효율적으로 작동할 수 있는 이유입니다.
*   **볼록 최적화 문제:** 원시 문제가 비볼록일 수 있는 경우에도, 쌍대 문제는 항상 볼록 최적화 문제(Convex Optimization Problem)가 됩니다. 볼록 문제는 전역 최적해를 항상 찾을 수 있다는 장점이 있습니다.
*   **강력한 이론적 기반:** 쌍대 문제는 강력한 수학적 이론에 기반하고 있어, SVM의 견고성과 예측 성능에 대한 신뢰를 더합니다.

쌍대 문제와 커널 트릭의 결합은 SVM을 선형 분류기를 넘어 비선형 분류 문제에서도 강력하고 효율적인 알고리즘으로 만들어주는 핵심적인 요소입니다.

## 4. 실습: SVM 결정 경계 시각화

이 실습에서는 Scikit-learn 라이브러리를 사용하여 SVM 모델을 학습시키고, 다양한 커널 함수(선형, RBF)와 하이퍼파라미터(`gamma`)에 따른 결정 경계의 변화를 시각적으로 확인합니다. 이를 통해 커널 트릭과 하이퍼파라미터가 SVM 모델의 분류 성능과 복잡도에 미치는 영향을 직관적으로 이해할 수 있습니다.

### 4.1. 코드 설명

```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn import svm, datasets
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from matplotlib.colors import ListedColormap

# 1. 데이터 생성 (Iris 데이터셋의 처음 두 특성 사용)
# Scikit-learn의 내장 Iris 데이터셋을 로드합니다.
iris = datasets.load_iris()
# 꽃잎 길이(petal length)와 꽃잎 너비(petal width) 두 가지 특성만 사용합니다.
X = iris.data[:, :2]  
y = iris.target # 타겟 변수 (붓꽃의 종류)

# 이진 분류 문제로 단순화 (클래스 0과 1만 사용)
# Iris 데이터셋은 3개의 클래스(0, 1, 2)를 가지지만, 시각화를 단순화하기 위해 클래스 0과 1만 사용합니다.
X = X[y < 2]
y = y[y < 2]

# 데이터 스케일링
# SVM은 특성 스케일에 민감하므로, StandardScaler를 사용하여 데이터를 표준화합니다.
# 이는 모든 특성이 동일한 스케일을 가지도록 하여 모델 학습의 안정성을 높입니다.
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 훈련/테스트 데이터 분리
# 데이터를 훈련 세트와 테스트 세트로 7:3 비율로 분리합니다.
X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.3, random_state=42)

# 2. SVM 모델 학습 및 결정 경계 시각화 함수
# 이 함수는 주어진 SVM 모델을 사용하여 2차원 데이터의 결정 경계를 시각화합니다.
def plot_decision_boundary(model, X, y, title):
    # 데이터의 최소/최대 값을 기준으로 그리드 범위를 설정합니다.
    x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
    y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
    # 그리드 포인트 생성: 결정 경계를 부드럽게 그리기 위해 작은 간격으로 그리드를 만듭니다.
    xx, yy = np.meshgrid(np.arange(x_min, x_max, 0.02),
                         np.arange(y_min, y_max, 0.02))

    # 그리드 포인트에 대한 모델의 예측값을 계산합니다.
    # np.c_는 xx.ravel()과 yy.ravel()을 열 방향으로 합쳐 2차원 배열로 만듭니다.
    Z = model.predict(np.c_[xx.ravel(), yy.ravel()])
    # 예측값을 원래 그리드 형태로 재구성합니다.
    Z = Z.reshape(xx.shape)

    # 결정 경계 영역을 색칠하기 위한 컬러맵을 정의합니다.
    cmap_light = ListedColormap(['#FFAAAA', '#AAFFAA']) # 배경색
    cmap_bold = ListedColormap(['#FF0000', '#00FF00']) # 데이터 포인트 색

    plt.figure(figsize=(8, 6))
    # 결정 경계 영역을 색칠합니다.
    plt.pcolormesh(xx, yy, Z, cmap=cmap_light, shading='auto')

    plt.scatter(X[:, 0], X[:, 1], c=y, cmap=cmap_bold, edgecolor='k', s=20)
    # x, y 축 범위 설정
    plt.xlim(xx.min(), xx.max())
    plt.ylim(yy.min(), yy.max())
    plt.title(title) # 그래프 제목
    plt.xlabel("Feature 1 (Scaled)") # x축 레이블
    plt.ylabel("Feature 2 (Scaled)") # y축 레이블
    plt.show() # 그래프 표시

# 3. 다양한 SVM 모델 학습 및 시각화
# Scikit-learn의 svm.SVC 클래스를 사용하여 다양한 커널과 하이퍼파라미터로 SVM 모델을 생성하고 학습시킵니다.

# 선형 커널 SVM
# kernel='linear': 선형 결정 경계를 사용합니다.
# C=1: 소프트 마진 하이퍼파라미터 C를 1로 설정합니다.
svm_linear = svm.SVC(kernel='linear', C=1, random_state=42)
svm_linear.fit(X_train, y_train) # 훈련 데이터로 모델 학습
plot_decision_boundary(svm_linear, X_scaled, y, "SVM with Linear Kernel") # 결정 경계 시각화

# RBF 커널 SVM (gamma=0.5)
# kernel='rbf': 가우시안 RBF 커널을 사용합니다. 비선형 결정 경계를 생성할 수 있습니다.
# gamma=0.5: RBF 커널의 gamma 값을 0.5로 설정합니다.
svm_rbf = svm.SVC(kernel='rbf', C=1, gamma=0.5, random_state=42)
svm_rbf.fit(X_train, y_train)
plot_decision_boundary(svm_rbf, X_scaled, y, "SVM with RBF Kernel (gamma=0.5)")

# RBF 커널 SVM (gamma=5)
# gamma 값을 5로 높여 RBF 커널의 영향을 확인합니다.
svm_rbf_high_gamma = svm.SVC(kernel='rbf', C=1, gamma=5, random_state=42)
svm_rbf_high_gamma.fit(X_train, y_train)
plot_decision_boundary(svm_rbf_high_gamma, X_scaled, y, "SVM with RBF Kernel (gamma=5)")
```

### 4.2. 실습 결과 해석

이 실습을 통해 SVM의 커널 함수와 하이퍼파라미터 `gamma`가 결정 경계의 형태와 모델의 복잡도에 어떻게 영향을 미치는지 시각적으로 확인할 수 있습니다.

*   **선형 커널 SVM:**
    *   데이터를 직선으로 분리하는 결정 경계를 생성합니다. 데이터가 선형적으로 분리 가능할 때 효과적입니다.
    *   그래프에서 두 클래스를 나누는 직선 형태의 경계를 볼 수 있습니다.

*   **RBF 커널 SVM (gamma=0.5):**
    *   비선형 결정 경계를 생성하여 선형적으로 분리하기 어려운 데이터도 잘 분류할 수 있습니다.
    *   `gamma` 값이 적절할 때, 데이터의 복잡한 패턴을 잘 포착하면서도 과적합되지 않는 부드러운 비선형 경계를 형성합니다.

*   **RBF 커널 SVM (gamma=5):**
    *   `gamma` 값이 높아지면 각 데이터 포인트의 영향 범위가 좁아져, 모델이 훈련 데이터에 더 민감하게 반응하고 결정 경계가 매우 복잡해집니다.
    *   그래프에서 결정 경계가 훈련 데이터 포인트 하나하나에 거의 맞춰지는 형태로 나타나며, 이는 **과적합(Overfitting)**의 가능성을 시사합니다. 새로운 데이터에 대해서는 성능이 떨어질 수 있습니다.

이 실습은 SVM에서 커널 함수와 하이퍼파라미터 튜닝의 중요성을 보여줍니다. 적절한 커널과 하이퍼파라미터 선택은 모델의 일반화 성능에 결정적인 영향을 미칩니다.
