## 1. 모델 학습의 목표: 손실 함수 최소화

머신러닝 모델을 학습시킨다는 것은, 모델이 주어진 데이터를 통해 특정 작업을 가장 잘 수행하도록 만드는 과정을 의미합니다. 이 '가장 잘 수행한다'는 기준을 정량적으로 평가하고, 그 평가 지표를 최소화하는 방향으로 모델을 조정하는 것이 바로 모델 학습의 핵심 목표입니다. 이때 사용되는 핵심 개념이 바로 **손실 함수(Loss Function)**입니다.

### 1.1. 손실 함수(Loss Function)란?

**손실 함수(Loss Function)**는 모델의 예측값($\hat{y}$)이 실제 정답($y$)과 얼마나 다른지, 즉 **모델의 예측이 얼마나 틀렸는지**를 수치적으로 측정하는 함수입니다. 이 함수는 개별 데이터 포인트에 대한 모델의 '오류' 또는 '페널티'를 계산합니다.

*   **예측과 실제값의 차이:** 손실 함수는 모델이 내놓은 예측과 실제 데이터의 참값 사이의 불일치 정도를 나타냅니다. 이 불일치가 클수록 손실 함수의 값은 커집니다.
*   **모델 성능의 지표:** 손실 함수의 값이 작을수록 모델의 예측이 실제값에 더 가깝다는 것을 의미하며, 이는 모델의 성능이 더 좋다는 것을 나타냅니다.
*   **학습의 방향 제시:** 모델은 손실 함수의 값을 최소화하는 방향으로 자신의 내부 파라미터(가중치, 편향 등)를 조정해 나갑니다. 마치 내비게이션이 목적지(최소 손실)까지 가는 가장 효율적인 경로(파라미터 업데이트 방향)를 알려주는 것과 같습니다.

### 1.2. 비용 함수(Cost Function)와 목적 함수(Objective Function)

손실 함수와 유사하게 사용되지만, 미묘한 차이가 있는 개념들이 있습니다.

*   **비용 함수(Cost Function):** 손실 함수가 개별 데이터 포인트에 대한 오류를 측정한다면, 비용 함수는 **전체 훈련 데이터셋에 대한 평균 손실**을 나타냅니다. 즉, 모든 데이터 포인트에 대한 손실 함수의 값을 합산하여 평균을 낸 값입니다. 모델의 전반적인 성능을 평가하고, 이 값을 최소화하는 것이 일반적인 학습 목표가 됩니다. 예를 들어, 회귀 문제에서 사용되는 평균 제곱 오차(MSE)는 개별 예측 오차의 제곱을 평균한 값이므로, 손실 함수이면서 동시에 비용 함수로 사용될 수 있습니다.

*   **목적 함수(Objective Function):** 모델 학습의 궁극적인 목표를 정의하는 가장 포괄적인 함수입니다. 일반적으로 비용 함수를 최소화하는 것이 목적 함수가 되지만, 때로는 모델의 복잡도를 제어하기 위한 **규제(Regularization) 항**이 추가되기도 합니다. 규제 항은 모델이 너무 훈련 데이터에만 과도하게 맞춰지는(과적합, Overfitting) 것을 방지하여, 새로운 데이터에 대한 일반화 성능을 높이는 데 기여합니다. 따라서 목적 함수는 '비용 함수 + 규제 항'의 형태를 가질 수 있으며, 이 전체 값을 최소화하는 것이 모델 학습의 최종 목표가 됩니다.

**요약:**
*   **손실 함수:** 개별 데이터 포인트의 예측 오류.
*   **비용 함수:** 전체 데이터셋에 대한 평균 예측 오류 (손실 함수의 평균).
*   **목적 함수:** 모델 학습의 최종 목표 (비용 함수 + 선택적 규제 항).

머신러닝 모델 학습의 궁극적인 목표는 이 목적 함수(대부분의 경우 비용 함수)의 값을 최소화하는 모델 파라미터를 찾는 것입니다. 이를 통해 모델은 주어진 데이터의 패턴을 가장 잘 학습하고, 새로운 데이터에 대해서도 정확한 예측을 수행할 수 있게 됩니다.

## 2. 주요 손실 함수의 종류

### 2.1. 회귀 문제의 손실 함수
회귀(Regression) 문제는 주택 가격 예측, 주식 가격 변동 예측, 온도 예측 등과 같이 **연속적인 값을 예측**하는 모델에서 사용됩니다. 회귀 모델의 목표는 실제 값과 예측 값 사이의 오차를 최소화하는 것이며, 이를 위해 다양한 손실 함수가 활용됩니다.

#### 2.1.1. 평균 제곱 오차 (Mean Squared Error, MSE)
**평균 제곱 오차(Mean Squared Error, MSE)**는 회귀 문제에서 가장 널리 사용되는 손실 함수 중 하나입니다. 모델의 예측값($\hat{y}_i$)과 실제값($y_i$)의 차이(오차)를 제곱한 후, 이들을 모두 더하여 데이터 개수($n$)로 나눈 값입니다.

*   **수식:** $ MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 $
    *   $y_i$: $i$번째 실제 값
    *   $\hat{y}_i$: $i$번째 예측 값
    *   $n$: 데이터 포인트의 총 개수
*   **특징:**
    *   **큰 오차에 대한 민감성:** 오차를 제곱하기 때문에, 실제 값과 예측 값 사이의 차이가 클수록 손실 값이 기하급수적으로 증가합니다. 이는 모델이 큰 오차를 더 심각하게 받아들이고, 이를 줄이는 방향으로 학습하도록 유도합니다. 따라서 이상치(Outlier)에 매우 민감하게 반응하는 경향이 있습니다.
    *   **미분 가능성:** MSE 함수는 모든 지점에서 미분 가능하며, 이는 경사 하강법과 같은 최적화 알고리즘을 적용하기에 매우 유리합니다. 기울기 계산이 용이하여 최적화 과정이 부드럽게 진행될 수 있습니다.
    *   **해석의 어려움:** 손실 값이 제곱된 형태이므로, 실제 오차의 단위와 달라 직관적인 해석이 어려울 수 있습니다. 이를 보완하기 위해 MSE의 제곱근인 RMSE(Root Mean Squared Error)를 사용하기도 합니다.

#### 2.1.2. 평균 절대 오차 (Mean Absolute Error, MAE)
**평균 절대 오차(Mean Absolute Error, MAE)**는 예측값($\hat{y}_i$)과 실제값($y_i$)의 차이에 절댓값을 취한 후, 이들을 모두 더하여 데이터 개수($n$)로 나눈 값입니다.

*   **수식:** $ MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i| $
*   **특징:**
    *   **이상치에 대한 강건함(Robustness):** 오차에 절댓값을 취하므로, MSE와 달리 큰 오차에 대해 선형적인 페널티를 부여합니다. 이로 인해 이상치의 영향을 덜 받으며, 데이터에 이상치가 많을 때 MSE보다 더 안정적인 성능을 보일 수 있습니다.
    *   **직관적인 해석:** 손실 값이 실제 오차와 동일한 단위를 가지므로, 모델의 평균적인 예측 오차를 직관적으로 이해하기 쉽습니다.
    *   **미분 불가능성:** MAE 함수는 오차가 0인 지점(즉, 예측값과 실제값이 정확히 일치하는 지점)에서 미분이 불가능합니다. 이는 경사 하강법을 사용할 때 최적화 과정에 어려움을 줄 수 있지만, 서브그래디언트(subgradient) 등의 기법을 통해 해결 가능합니다.

**MSE vs. MAE 선택 가이드:**
*   **MSE:** 모델이 큰 오차에 대해 더 민감하게 반응하고, 이상치를 중요하게 다루어야 할 때 적합합니다. 미분 가능하여 최적화가 용이합니다.
*   **MAE:** 데이터에 이상치가 많거나, 모든 오차에 대해 동일한 중요도를 부여하고 싶을 때 적합합니다. 손실 값을 직관적으로 이해하기 쉽습니다.

### 2.2. 분류 문제의 손실 함수
분류(Classification) 문제는 이미지 분류, 스팸 메일 분류, 질병 진단 등과 같이 데이터를 미리 정의된 **범주형 클래스(Categorical Class)** 중 하나로 예측하는 모델에서 사용됩니다. 분류 모델의 목표는 각 클래스에 대한 예측 확률을 실제 클래스 분포에 가깝게 만드는 것이며, 이를 위해 주로 확률 분포 간의 차이를 측정하는 손실 함수가 활용됩니다.

#### 2.2.1. 이진 교차 엔트로피 (Binary Cross-Entropy)
**이진 교차 엔트로피(Binary Cross-Entropy, BCE)**는 이름에서 알 수 있듯이 **이진 분류(Binary Classification)** 문제, 즉 두 개의 클래스(예: 0 또는 1, 참 또는 거짓) 중 하나를 예측할 때 사용되는 손실 함수입니다. 주로 모델의 마지막 레이어에서 시그모이드(Sigmoid) 활성화 함수를 사용하여 0과 1 사이의 확률 값을 출력할 때 사용됩니다.

*   **수식:** $ BCE = - \frac{1}{n} \sum_{i=1}^{n} [y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i)] $
    *   $y_i$: $i$번째 실제 레이블 (0 또는 1)
    *   $\hat{y}_i$: $i$번째 예측 확률 (클래스 1에 속할 확률)
    *   $n$: 데이터 포인트의 총 개수
*   **특징:**
    *   **확률 분포 간의 거리 측정:** BCE는 실제 이진 레이블의 확률 분포와 모델이 예측한 확률 분포 간의 '거리'를 측정합니다. 두 분포가 멀어질수록 손실 값이 커집니다.
    *   **예측 오류에 대한 민감성:** 모델이 실제 레이블과 다른 클래스에 높은 확률을 할당할수록 손실이 급격하게 증가합니다. 예를 들어, 실제 레이블이 1인데 모델이 0에 가까운 확률을 예측하면 손실이 매우 커집니다.
    *   **로그 함수 사용:** 로그 함수는 작은 값에 대해 큰 음수 값을 반환하므로, 예측이 틀렸을 때 큰 페널티를 부여하여 모델이 올바른 방향으로 빠르게 학습하도록 돕습니다.

#### 2.2.2. 다중 클래스 교차 엔트로피 (Categorical Cross-Entropy)
**다중 클래스 교차 엔트로피(Categorical Cross-Entropy, CCE)**는 **다중 클래스 분류(Multi-class Classification)** 문제, 즉 세 개 이상의 클래스 중 하나를 예측할 때 사용되는 손실 함수입니다. 주로 모델의 마지막 레이어에서 소프트맥스(Softmax) 활성화 함수를 사용하여 각 클래스에 대한 확률 분포를 출력할 때 사용됩니다. 실제 레이블은 원-핫 인코딩(One-Hot Encoding)된 형태로 주어집니다.

*   **수식:** $ CCE = - \frac{1}{n} \sum_{i=1}^{n} \sum_{j=1}^{C} y_{ij} \log(\hat{y}_{ij}) $
    *   $y_{ij}$: $i$번째 샘플의 실제 레이블 중 $j$번째 클래스 (원-핫 인코딩: 해당 클래스면 1, 아니면 0)
    *   $\hat{y}_{ij}$: $i$번째 샘플이 $j$번째 클래스에 속할 예측 확률
    *   $n$: 데이터 포인트의 총 개수
    *   $C$: 클래스의 총 개수
*   **특징:**
    *   **다중 클래스 확률 분포 비교:** BCE와 유사하게, 실제 클래스의 확률 분포(원-핫 인코딩)와 모델이 예측한 각 클래스에 대한 확률 분포 간의 차이를 측정합니다.
    *   **가장 널리 사용됨:** 다중 클래스 분류 문제에서 가장 보편적으로 사용되는 손실 함수입니다.
    *   **스파스(Sparse) 레이블과의 관계:** 만약 실제 레이블이 원-핫 인코딩이 아닌 정수 형태로 주어지는 경우, `Sparse Categorical Cross-Entropy`를 사용하기도 합니다. 이는 내부적으로 원-핫 인코딩 변환을 수행하여 CCE와 동일하게 작동합니다.

#### 2.2.3. 힌지 손실 (Hinge Loss)
**힌지 손실(Hinge Loss)**은 주로 **서포트 벡터 머신(Support Vector Machine, SVM)**과 같은 '최대 마진(Maximum Margin)' 분류기에서 사용되는 손실 함수입니다. 이진 분류 문제에 주로 적용되며, 분류 경계로부터의 거리를 기반으로 손실을 계산합니다.

*   **수식:** $ L(y, \hat{y}) = \max(0, 1 - y \cdot \hat{y}) $
    *   $y$: 실제 레이블 (-1 또는 1)
    *   $\hat{y}$: 모델의 예측값 (분류 경계로부터의 거리, 또는 결정 함수 값)
*   **특징:**
    *   **마진 기반:** 올바르게 분류된 샘플이라도 분류 경계로부터 충분한 마진(Margin)을 확보하지 못하면 손실이 발생합니다. 즉, 단순히 정답을 맞추는 것을 넘어, '확실하게' 정답을 맞추도록 유도합니다.
    *   **0 손실 구간:** $y \cdot \hat{y} \ge 1$인 경우 손실이 0이 됩니다. 이는 모델이 충분한 마진을 가지고 올바르게 분류했을 때를 의미합니다.
    *   **선형적인 페널티:** 마진 내에 있거나 잘못 분류된 샘플에 대해서는 오차에 비례하여 선형적으로 손실이 증가합니다.
    *   **미분 불가능성:** $y \cdot \hat{y} = 1$인 지점에서 미분이 불가능하지만, 서브그래디언트 최적화를 통해 해결 가능합니다.
    *   **확률 해석 불가:** 교차 엔트로피와 달리 힌지 손실은 모델의 출력을 확률로 해석할 수 없습니다.

## 3. 최적화(Optimization) 개념

최적화는 손실 함수를 최소화하는 모델의 파라미터(가중치와 편향)를 찾는 과정입니다. 이는 모델이 데이터에 가장 잘 맞도록 조정하는 것을 의미하며, 모델의 예측이 실제 값에 얼마나 가까운지를 결정하는 핵심 단계입니다.

### 3.1. 경사 하강법(Gradient Descent)
경사 하강법은 손실 함수의 기울기(경사)를 사용하여 손실이 가장 가파르게 감소하는 방향으로 모델 파라미터를 조금씩 업데이트하는 반복적인 최적화 알고리즘입니다. 마치 산에서 가장 낮은 지점(최소값)을 찾기 위해 경사가 가장 가파른 방향으로 한 걸음씩 내려가는 것과 같습니다.

*   **기울기(Gradient):** 손실 함수를 각 모델 파라미터에 대해 편미분한 벡터입니다. 손실이 증가하는 가장 가파른 방향을 가리킵니다.
*   **업데이트 규칙:** $ \theta_{new} = \theta_{old} - \alpha \nabla J(\theta_{old}) $ 
    *   $ \theta $: 모델 파라미터
    *   $ \alpha $: 학습률 (Learning Rate)
    *   $ \nabla J(\theta) $: 손실 함수의 기울기

#### 학습률(Learning Rate)
**학습률($\alpha$)**은 경사 하강법에서 모델 파라미터를 업데이트할 때 한 번에 얼마나 크게 이동할지를 결정하는 하이퍼파라미터입니다. 학습률이 너무 크면 최적점을 지나칠 수 있어 손실이 발산하거나 진동할 수 있고, 너무 작으면 수렴하는 데 시간이 오래 걸리거나 지역 최적점에 갇힐 수 있습니다. 적절한 학습률 설정은 모델 학습의 성공에 매우 중요합니다.

### 3.2. 지역 최적점(Local Minima)과 전역 최적점(Global Minima)
#### 전역 최적점
손실 함수가 가질 수 있는 가장 낮은 값으로, 모델이 도달할 수 있는 최상의 성능 지점입니다.
#### 지역 최적점
특정 범위 내에서 손실 함수가 가장 낮은 값입니다. 경사 하강법은 시작점에 따라 지역 최적점에 갇힐 수 있으며, 이는 모델이 최적의 성능에 도달하지 못하게 할 수 있습니다. 볼록(convex) 손실 함수에서는 지역 최적점이 곧 전역 최적점이지만, 비볼록(non-convex) 손실 함수에서는 여러 지역 최적점이 존재할 수 있습니다.

### 3.3. 다양한 최적화 알고리즘
경사 하강법의 단점(느린 수렴, 지역 최적점 문제)을 보완하고 학습 효율성을 높이기 위해 다양한 최적화 알고리즘이 개발되었습니다.

#### 확률적 경사 하강법(Stochastic Gradient Descent, SGD)
전체 데이터셋 대신 무작위로 선택된 하나의 샘플에 대해 기울기를 계산하여 파라미터를 업데이트합니다. 계산 비용이 적고, 노이즈가 많아 지역 최적점에 덜 갇히는 경향이 있지만, 업데이트의 변동성이 커서 수렴이 불안정할 수 있습니다.
#### 미니 배치 경사 하강법(Mini-batch Gradient Descent)
전체 데이터셋과 SGD의 중간 형태로, 미니 배치(작은 데이터 묶음)에 대해 기울기를 계산하여 파라미터를 업데이트합니다. SGD보다 안정적이고 배치 경사 하강법보다 효율적이며, 현대 딥러닝에서 가장 널리 사용되는 방식입니다.
#### 모멘텀(Momentum)
이전 업데이트의 '관성'을 이용하여 현재 업데이트 방향에 가속도를 붙여줍니다. 이는 경사가 일관된 방향으로 유지될 때 학습 속도를 높이고, 지역 최적점을 탈출하는 데 도움을 줍니다.
#### Adagrad
각 파라미터에 대해 과거 기울기의 제곱합에 비례하여 학습률을 조절합니다. 자주 업데이트되는 파라미터는 학습률이 작아지고, 드물게 업데이트되는 파라미터는 학습률이 커집니다. 그러나 학습이 진행될수록 학습률이 너무 빠르게 감소하는 경향이 있습니다.
#### RMSprop
Adagrad의 학습률 감소 문제를 해결하기 위해, 과거 기울기의 제곱합 대신 지수 이동 평균을 사용하여 학습률을 조절합니다.
#### Adam (Adaptive Moment Estimation)
모멘텀과 RMSprop의 장점을 결합한 알고리즘입니다. 각 파라미터에 대해 학습률을 적응적으로 조절하며, 이전 기울기의 지수 이동 평균과 이전 기울기 제곱의 지수 이동 평균을 모두 사용합니다. 뛰어난 성능과 안정성으로 인해 딥러닝에서 가장 인기 있는 최적화 알고리즘 중 하나입니다.

최적화 과정은 모델이 주어진 데이터로부터 효과적으로 학습하고, 새로운 데이터에 대해 정확한 예측을 수행할 수 있도록 하는 핵심 단계입니다. 손실 함수를 통해 모델의 성능을 측정하고, 최적화 알고리즘을 통해 이 성능을 지속적으로 개선해 나가는 것이 머신러닝 모델 학습의 본질입니다. 올바른 최적화 알고리즘과 학습률 선택은 모델의 수렴 속도와 최종 성능에 큰 영향을 미칩니다.

## 4. 실습: 손실 함수와 경사 하강법의 시각화

이 실습에서는 간단한 선형 회귀 문제를 통해 손실 함수(MSE)와 경사 하강법이 어떻게 작동하며, 모델이 데이터를 학습하는 과정을 시각적으로 이해합니다.

### 4.1. 코드 설명

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 가상 데이터 생성
# 선형 관계를 가지는 가상의 데이터 X와 y를 생성합니다.
# y = 4 + 3x + noise 형태의 데이터를 만듭니다.
X = 2 * np.random.rand(100, 1)
y = 4 + 3 * X + np.random.randn(100, 1) # y = 4 + 3x + noise

# 2. MSE 손실 함수 정의
# 평균 제곱 오차(MSE)를 계산하는 함수입니다.
# (실제값 - 예측값)^2의 평균을 반환합니다.
def mse_loss(y_true, y_pred):
    return np.mean((y_true - y_pred)**2)

# 3. 경사 하강법 구현
# 선형 회귀 모델의 파라미터(theta0, theta1)를 경사 하강법으로 최적화하는 함수입니다.
def gradient_descent(X, y, learning_rate=0.01, n_iterations=1000):
    # X에 편향(bias) 항을 추가합니다. (x0 = 1)
    # 이는 절편(theta0)을 모델에 포함시키기 위함입니다.
    X_b = np.c_[np.ones((len(X), 1)), X]
    
    # 모델 파라미터(theta0: 절편, theta1: 기울기)를 무작위로 초기화합니다.
    theta = np.random.randn(2, 1)
    
    # 각 반복(iteration)마다 계산된 MSE 손실을 저장할 리스트입니다.
    mse_history = []

    # 지정된 반복 횟수(n_iterations)만큼 경사 하강법을 수행합니다.
    for iteration in range(n_iterations):
        # 현재 파라미터(theta)를 사용하여 예측값(y_pred)을 계산합니다.
        y_pred = X_b.dot(theta)
        # 현재 예측값으로 MSE 손실을 계산하고 기록합니다.
        mse_history.append(mse_loss(y, y_pred))
        
        # 손실 함수에 대한 파라미터의 기울기(gradients)를 계산합니다.
        # 이 기울기는 손실이 가장 가파르게 증가하는 방향을 나타냅니다.
        gradients = 2/len(X) * X_b.T.dot(y_pred - y)
        
        # 계산된 기울기에 학습률을 곱한 값을 현재 파라미터에서 빼서 파라미터를 업데이트합니다.
        # 이는 손실이 감소하는 방향으로 파라미터를 이동시키는 과정입니다.
        theta = theta - learning_rate * gradients
        
    # 최종적으로 학습된 파라미터와 손실 기록을 반환합니다.
    return theta, mse_history

# 4. 경사 하강법 실행
# 학습률과 반복 횟수를 설정하고 경사 하강법 함수를 실행합니다.
learning_rate = 0.1
n_iterations = 100
theta_final, mse_history = gradient_descent(X, y, learning_rate, n_iterations)

# 최종적으로 학습된 모델의 파라미터와 최종 MSE 손실을 출력합니다.
print(f"최종 모델 파라미터 (theta0, theta1): {theta_final.flatten()}")
print(f"최종 MSE: {mse_history[-1]:.4f}")

# 5. 손실 함수 변화 시각화
# 학습 반복 횟수에 따른 MSE 손실의 변화를 그래프로 나타냅니다.
plt.figure(figsize=(10, 5))
plt.plot(range(n_iterations), mse_history)
plt.xlabel("반복 횟수 (Iterations)")
plt.ylabel("MSE 손실")
plt.title("경사 하강법에 따른 MSE 손실 변화")
plt.grid(True)
plt.show()

# 6. 모델 예측 시각화
# 실제 데이터 포인트와 경사 하강법으로 학습된 선형 회귀 모델의 예측 선을 함께 시각화합니다.
plt.figure(figsize=(10, 6))
plt.scatter(X, y, label="실제 데이터", alpha=0.6)
plt.plot(X, np.c_[np.ones((len(X), 1)), X].dot(theta_final), color='red', label="경사 하강법으로 학습된 모델")
plt.xlabel("X")
plt.ylabel("y")
plt.title("선형 회귀 모델 예측")
plt.legend()
plt.grid(True)
plt.show()
```

### 4.2. 시각화 결과 해석

1.  **경사 하강법에 따른 MSE 손실 변화 그래프**:
    *   이 그래프는 x축이 경사 하강법의 반복 횟수(Iterations)이고, y축이 MSE 손실 값입니다.
    *   그래프가 아래로 향하며 손실 값이 점차 감소하는 것을 볼 수 있습니다. 이는 경사 하강법이 손실 함수를 성공적으로 최소화하고 있음을 의미합니다.
    *   초기에는 손실이 빠르게 감소하다가, 반복 횟수가 늘어날수록 감소 폭이 줄어들며 수렴하는 모습을 보입니다. 이는 모델이 최적의 파라미터에 가까워지고 있음을 나타냅니다.

2.  **선형 회귀 모델 예측 그래프**:
    *   파란색 점들은 `X`와 `y`로 생성된 가상의 실제 데이터 포인트입니다.
    *   빨간색 선은 경사 하강법을 통해 학습된 모델이 예측하는 선형 관계를 나타냅니다.
    *   이 빨간색 선이 파란색 데이터 포인트들을 잘 통과하며 데이터의 전반적인 추세를 반영하고 있다면, 모델이 데이터를 성공적으로 학습했음을 의미합니다. 즉, 손실 함수를 최소화하여 데이터에 가장 잘 맞는 선형 모델을 찾았다는 것을 시각적으로 보여줍니다.
```
