## 1. 의사결정 트리 (Decision Tree)

### 1.1. 핵심 개념
**의사결정 트리(Decision Tree)**는 데이터에 대한 질문(특성 분할)을 통해 데이터를 유사한 그룹으로 나누는 과정을 반복하여 예측을 수행하는 모델입니다. 마치 스무고개처럼 질문을 통해 정답을 찾아가는 과정과 유사하며, 그 결과가 나무(Tree) 구조로 표현되어 모델의 결정 과정을 직관적으로 이해하고 시각화하기 쉽습니다.

*   **트리 구조의 구성 요소:**
    *   **노드(Node):** 트리를 구성하는 각 요소입니다. 데이터를 분할하는 질문(조건)을 담고 있거나, 최종 예측 결과를 나타냅니다.
    *   **루트 노드(Root Node):** 트리의 가장 상단에 위치한 시작 노드입니다. 전체 데이터셋을 포함하며, 첫 번째 분할이 이루어지는 지점입니다.
    *   **내부 노드(Internal Node):** 루트 노드와 리프 노드 사이에 위치한 노드입니다. 특정 특성 값을 기준으로 데이터를 두 개 이상의 하위 노드로 분할하는 질문을 포함합니다.
    *   **리프 노드(Leaf Node) / 터미널 노드(Terminal Node):** 트리의 가장 마지막에 위치한 노드로, 더 이상 분할되지 않습니다. 이 노드에 도달한 데이터 포인트들에 대한 최종 예측 클래스(분류) 또는 값(회귀)을 나타냅니다.

*   **분할 기준 (Splitting Criteria):**
    *   의사결정 트리는 각 노드에서 데이터를 가장 잘 분리할 수 있는 특성과 분할 기준(threshold)을 찾습니다. 이 '가장 잘 분리'한다는 것은 분할 후 각 하위 노드의 **불순도(Impurity)**를 가장 많이 감소시키는 방향을 의미합니다.
    *   **불순도(Impurity):** 노드에 얼마나 다양한 클래스의 데이터가 섞여 있는지를 나타내는 지표입니다. 불순도가 낮을수록 해당 노드는 '순수'하며, 한 클래스의 데이터로만 구성되어 있음을 의미합니다.
        *   **지니 불순도(Gini Impurity):** $ G = 1 - \sum_{i=1}^{C} p_i^2 $ (여기서 $p_i$는 특정 클래스 $i$에 속할 확률, $C$는 클래스 개수). 0이면 순수 노드(모든 샘플이 한 클래스에 속함)를 의미하며, 0.5에 가까울수록 불순도가 높습니다.
        *   **엔트로피(Entropy):** $ H = -\sum_{i=1}^{C} p_i \log_2(p_i) $ (여기서 $p_i$는 특정 클래스 $i$에 속할 확률). 정보 이론에서 사용하는 불확실성 측정 지표입니다. 엔트로피가 0이면 순수 노드, 1에 가까울수록 불확실성이 높습니다.

*   **학습 과정:**
    *   의사결정 트리는 재귀적으로 데이터를 분할하며 성장합니다. 각 분할 단계에서 모든 특성과 가능한 모든 분할 기준을 고려하여 불순도를 가장 많이 감소시키는 최적의 분할을 찾습니다.
    *   트리의 성장은 미리 정의된 중단 조건(예: `max_depth`, `min_samples_split`, `min_samples_leaf`)에 도달할 때까지 계속됩니다.

*   **장점:**
    *   **해석 용이성 (White-box model):** 모델의 결정 과정을 나무 구조로 시각화할 수 있어 인간이 이해하고 설명하기 매우 쉽습니다.
    *   **전처리 간소화:** 특성 스케일링(Scaling)이나 정규화(Normalization)와 같은 데이터 전처리가 거의 필요 없습니다.
    *   **수치형/범주형 특성 모두 처리:** 숫자형 특성과 범주형 특성 모두를 자연스럽게 처리할 수 있습니다.
    *   **비선형 관계 학습:** 데이터 간의 복잡한 비선형 관계를 학습할 수 있습니다.
*   **단점:**
    *   **과적합(Overfitting)되기 쉬움:** 트리가 너무 깊게 성장하면 훈련 데이터에 과도하게 맞춰져 새로운 데이터에 대한 일반화 성능이 떨어질 수 있습니다.
    *   **불안정성:** 데이터의 작은 변화에도 트리의 구조가 크게 바뀔 수 있어 불안정합니다.
    *   **지역 최적화:** 각 분기에서 최적의 분할을 찾지만, 전역적으로 최적의 트리를 보장하지는 않습니다.

### 1.2. 주요 하이퍼파라미터
의사결정 트리는 모델의 복잡도와 일반화 성능에 큰 영향을 미치는 다양한 하이퍼파라미터를 가집니다. 이들을 적절히 튜닝하는 것이 과적합을 방지하고 최적의 성능을 얻는 데 중요합니다.

*   **`criterion` (불순도 측정 기준):**
    *   **설명:** 노드의 분할 품질을 측정하는 함수를 지정합니다. 즉, 어떤 특성과 임계값을 기준으로 분할했을 때 불순도가 가장 많이 감소하는지를 평가하는 기준입니다.
    *   `'gini'` (지니 불순도): 기본값이며, 계산이 빠르고 일반적으로 좋은 성능을 보입니다.
    *   `'entropy'` (엔트로피): 정보 이득(Information Gain)을 최대화하는 방향으로 분할합니다. 계산 비용이 지니 불순도보다 높을 수 있습니다.
    *   **선택:** 대부분의 경우 `'gini'`와 `'entropy'` 간의 성능 차이는 크지 않으므로, `'gini'`를 먼저 사용하고 필요에 따라 `'entropy'`를 시도해볼 수 있습니다.

*   **`max_depth` (트리의 최대 깊이):**
    *   **설명:** 트리의 루트 노드로부터 리프 노드까지의 최대 깊이를 제한합니다. 트리가 너무 깊어지는 것을 방지하여 과적합을 제어하는 가장 중요한 하이퍼파라미터 중 하나입니다.
    *   **값이 클수록:** 모델이 훈련 데이터에 더 복잡하게 맞춰져 과적합될 가능성이 높아집니다.
    *   **값이 작을수록:** 모델이 단순해져 과소적합될 가능성이 높아지지만, 일반화 성능은 향상될 수 있습니다.
    *   **선택:** 일반적으로 3~10 사이의 값을 탐색하며, 데이터의 복잡도에 따라 조절합니다.

*   **`min_samples_split` (노드 분할을 위한 최소 샘플 수):**
    *   **설명:** 노드를 분할하기 위해 필요한 최소 샘플(데이터 포인트) 수를 지정합니다. 이 값보다 적은 샘플을 가진 노드는 더 이상 분할되지 않고 리프 노드가 됩니다.
    *   **값이 클수록:** 트리의 분할이 줄어들어 모델이 단순해지고 과적합 방지에 도움이 됩니다.
    *   **값이 작을수록:** 트리가 더 세분화되어 과적합될 가능성이 높아집니다.
    *   **선택:** 일반적으로 2 (기본값)부터 시작하여 데이터셋 크기에 비례하여 증가시킵니다.

*   **`min_samples_leaf` (리프 노드의 최소 샘플 수):**
    *   **설명:** 리프 노드가 되기 위해 필요한 최소 샘플 수를 지정합니다. 분할 후 각 리프 노드에 이 값보다 적은 샘플이 포함되면 해당 분할은 허용되지 않습니다.
    *   **값이 클수록:** 트리의 분할이 줄어들어 모델이 단순해지고 과적합 방지에 도움이 됩니다.
    *   **값이 작을수록:** 트리가 더 세분화되어 과적합될 가능성이 높아집니다.
    *   **선택:** `min_samples_split`과 함께 과적합 제어에 사용됩니다.

*   **`max_features` (최대 특성 수):**
    *   **설명:** 각 노드에서 최적의 분할을 찾기 위해 고려할 특성의 최대 개수를 지정합니다. 모든 특성을 고려하는 대신 무작위로 일부 특성만 선택하여 분할합니다.
    *   **선택:** `'auto'`, `'sqrt'`, `'log2'` 또는 정수 값을 지정할 수 있습니다. 랜덤 포레스트와 같은 앙상블 모델에서 주로 사용되지만, 단일 의사결정 트리에서도 과적합을 줄이는 데 도움이 될 수 있습니다.

*   **`random_state`:**
    *   **설명:** 모델의 초기화나 내부적인 무작위성이 포함된 작업의 재현성을 보장하기 위한 난수 시드입니다. 특정 정수 값을 지정하면 동일한 결과를 항상 얻을 수 있습니다.

**하이퍼파라미터 튜닝:**
의사결정 트리는 단일 모델로 사용될 때 과적합되기 쉽기 때문에, 위 하이퍼파라미터들을 `GridSearchCV`나 `RandomizedSearchCV`와 같은 교차 검증 기반의 튜닝 도구를 사용하여 최적화하는 것이 매우 중요합니다. 특히 `max_depth`, `min_samples_split`, `min_samples_leaf`는 트리의 복잡도를 직접적으로 제어하므로 신중하게 조정해야 합니다.

### 1.3. 장단점
의사결정 트리는 그 구조적 특성 때문에 명확한 장점과 단점을 가집니다.

*   **장점:**
    *   **해석 용이성 (White-box model):**
        *   의사결정 트리는 모델의 결정 과정을 나무 구조로 시각화할 수 있어 인간이 이해하고 설명하기 매우 쉽습니다. 이는 '블랙박스' 모델과 대조되는 '화이트박스' 모델의 대표적인 예시입니다.
        *   비즈니스 의사결정자나 도메인 전문가에게 모델의 작동 방식을 설명하고 신뢰를 얻는 데 매우 유리합니다.
    *   **전처리 간소화:**
        *   데이터 스케일링(Scaling)이나 정규화(Normalization)와 같은 특성 전처리가 거의 필요 없습니다. 이는 특성 값의 절대적인 크기보다는 상대적인 순서나 임계값을 기준으로 분할하기 때문입니다.
        *   결측치(Missing Values)를 자체적으로 처리할 수 있는 알고리즘도 있습니다.
    *   **수치형/범주형 특성 모두 처리:**
        *   숫자형 특성뿐만 아니라 범주형 특성도 자연스럽게 처리할 수 있습니다. 범주형 특성은 각 범주를 기준으로 분할합니다.
    *   **비선형 관계 학습:**
        *   데이터 간의 복잡한 비선형 관계를 학습할 수 있는 능력을 가집니다. 각 분할이 데이터를 비선형적으로 나누기 때문입니다.

*   **단점:**
    *   **과적합(Overfitting)되기 쉬움:**
        *   트리가 너무 깊게 성장하면 훈련 데이터의 노이즈나 특이 패턴까지 학습하여 과적합될 가능성이 매우 높습니다. 이는 새로운 데이터에 대한 모델의 일반화 성능을 떨어뜨립니다.
        *   이를 방지하기 위해 `max_depth`, `min_samples_split`, `min_samples_leaf`와 같은 하이퍼파라미터를 통해 트리의 성장을 제어해야 합니다.
    *   **불안정성:**
        *   데이터의 작은 변화(예: 하나의 데이터 포인트 추가/제거)에도 트리의 구조가 크게 바뀔 수 있어 불안정합니다. 이는 모델의 예측 결과가 일관되지 않을 수 있음을 의미합니다.
        *   이러한 불안정성은 앙상블 기법(예: 랜덤 포레스트)을 통해 완화될 수 있습니다.
    *   **지역 최적화:**
        *   각 분할 단계에서 불순도를 가장 많이 감소시키는 최적의 분할을 찾지만, 이는 전역적으로 최적의 트리를 보장하지는 않습니다. 즉, 한 번 잘못된 분할이 이루어지면 이후의 모든 분할에 영향을 미쳐 전역 최적해를 찾지 못할 수 있습니다.
    *   **클래스 불균형에 취약:**
        *   클래스 불균형이 심한 데이터셋에서는 다수 클래스에 편향된 트리가 생성될 수 있습니다. 이를 해결하기 위해 `class_weight` 조정이나 리샘플링 기법을 사용해야 합니다.

### 1.4. 실습: 붓꽃 데이터 분류
의사결정 트리를 사용하여 붓꽃(Iris) 데이터셋을 분류하는 실습 예제입니다. 붓꽃 데이터셋은 다중 클래스 분류 문제에 적합하며, 의사결정 트리의 시각화 기능을 통해 모델의 결정 과정을 직관적으로 이해할 수 있습니다.

```python
from sklearn.tree import DecisionTreeClassifier, plot_tree # 의사결정 트리 분류기 및 트리 시각화 함수
from sklearn.model_selection import train_test_split # 데이터 분할
from sklearn.datasets import load_iris # 붓꽃 데이터셋 로드
import matplotlib.pyplot as plt # 그래프 시각화
import numpy as np

# 1. 데이터 로드
# load_iris() 함수는 붓꽃 데이터셋을 로드합니다.
# X는 특성 데이터, y는 타겟 레이블(3가지 붓꽃 품종)입니다.
iris = load_iris()
X, y = iris.data, iris.target

print(f"데이터셋 형태 (X): {X.shape}")
print(f"타겟 레이블 분포 (y): {np.bincount(y)}") # 클래스 0, 1, 2의 개수

# 2. 훈련/테스트 데이터 분리
# 훈련 세트와 테스트 세트로 데이터를 분할합니다.
# test_size=0.3: 전체 데이터의 30%를 테스트 세트로 사용합니다.
# random_state=42: 재현성을 위한 난수 시드입니다.
# stratify=y: 타겟 변수(y)의 클래스 비율을 훈련 세트와 테스트 세트에서 동일하게 유지합니다.
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)

print(f"\n훈련 세트 형태: {X_train.shape}, {y_train.shape}")
print(f"테스트 세트 형태: {X_test.shape}, {y_test.shape}")

# 3. 의사결정 트리 모델 생성 및 학습
# max_depth=3으로 트리의 최대 깊이를 제한하여 과적합을 방지합니다.
dt_clf = DecisionTreeClassifier(max_depth=3, random_state=42)
dt_clf.fit(X_train, y_train)

# 4. 모델 평가
# score() 메서드는 분류 문제에서 정확도(Accuracy)를 반환합니다.
print(f"\n의사결정 트리 정확도: {dt_clf.score(X_test, y_test):.4f}")

# 5. 트리 시각화
# plot_tree 함수를 사용하여 학습된 의사결정 트리를 시각화합니다.
# filled=True: 노드의 클래스 비율에 따라 색상을 채웁니다.
# feature_names: 특성 이름을 지정하여 각 분할 기준을 명확히 합니다.
# class_names: 클래스 이름을 지정하여 리프 노드의 예측 클래스를 명확히 합니다.
plt.figure(figsize=(12, 8))
plot_tree(dt_clf, filled=True, feature_names=iris.feature_names, class_names=iris.target_names)
plt.title("의사결정 트리 시각화 (Iris 데이터셋)")
plt.show()
```

**실습 결과 해석:**
*   **정확도:** 모델이 테스트 데이터에서 얼마나 정확하게 분류했는지 보여줍니다.
*   **트리 시각화:**
    *   각 노드의 질문(예: `petal length (cm) <= 2.45`)을 통해 데이터가 어떻게 분할되는지 확인할 수 있습니다.
    *   `gini` 또는 `entropy` 값은 해당 노드의 불순도를 나타냅니다. 값이 0에 가까울수록 순수 노드입니다.
    *   `samples`는 해당 노드에 속한 샘플의 개수입니다.
    *   `value`는 해당 노드에 속한 각 클래스별 샘플의 개수입니다.
    *   `class`는 해당 노드에서 가장 많은 샘플을 가진 클래스입니다.

이 실습은 의사결정 트리가 데이터의 패턴을 규칙 기반으로 학습하고, 그 과정을 시각적으로 쉽게 이해할 수 있음을 보여줍니다. 하지만 단일 트리는 과적합되기 쉽다는 단점을 가집니다.


## 2. 앙상블 학습 (Ensemble Learning)

### 2.1. 앙상블이란?
**앙상블 학습(Ensemble Learning)**은 여러 개의 개별 모델(약한 학습기, Weak Learner)을 조합하여 하나의 강력한 모델(강한 학습기, Strong Learner)을 만드는 기법입니다. '집단 지성'의 원리와 유사하게, 여러 모델의 예측을 결합함으로써 단일 모델을 사용하는 것보다 예측 성능이 뛰어나고 안정적인 경우가 많습니다.

*   **핵심 아이디어:**
    *   **다양성(Diversity):** 앙상블을 구성하는 개별 모델들이 서로 다른 방식으로 오류를 범하도록 만듭니다. 이는 모델들이 서로 다른 데이터 부분에 집중하거나, 다른 특성 조합을 사용하거나, 다른 알고리즘을 사용함으로써 달성될 수 있습니다.
    *   **오류 상쇄:** 개별 모델의 예측 오류가 서로 독립적이라면, 여러 모델의 예측을 결합했을 때 오류가 상쇄되어 전체 앙상블 모델의 성능이 향상됩니다.

*   **앙상블 학습의 장점:**
    *   **예측 성능 향상:** 단일 모델보다 더 높은 예측 정확도를 달성하는 경우가 많습니다. 특히 복잡한 데이터셋에서 강력한 성능을 보입니다.
    *   **과적합 감소:** 여러 모델의 예측을 평균하거나 투표하는 방식으로 최종 예측을 결정하므로, 개별 모델의 과적합 경향을 줄이고 모델의 일반화 성능을 높입니다.
    *   **안정성:** 데이터의 작은 변화에 개별 모델의 예측이 크게 변하더라도, 앙상블 모델은 더 안정적인 예측을 제공합니다.
    *   **강력한 베이스라인:** 많은 캐글(Kaggle) 경연 대회에서 우승 모델들이 앙상블 기법을 활용할 정도로 강력한 성능을 보입니다.

*   **앙상블 학습의 단점:**
    *   **모델 복잡도 증가:** 단일 모델보다 여러 모델을 관리해야 하므로 모델의 복잡도가 증가합니다.
    *   **학습 시간 증가:** 여러 모델을 학습시켜야 하므로 단일 모델보다 학습 시간이 오래 걸릴 수 있습니다.
    *   **해석의 어려움:** 여러 모델의 조합이므로 단일 모델보다 해석이 어렵습니다. (하지만 SHAP, LIME과 같은 XAI 도구를 통해 해석을 시도할 수 있습니다.)

### 2.2. 배깅(Bagging)과 부스팅(Boosting)
앙상블 기법은 개별 모델을 조합하는 방식에 따라 크게 **배깅(Bagging)**과 **부스팅(Boosting)**으로 나뉩니다. 이 두 가지 접근 방식은 모델의 다양성을 확보하고 오류를 줄이는 데 다른 전략을 사용합니다.

*   **배깅 (Bagging - Bootstrap Aggregating):**
    *   **작동 원리:** 원본 훈련 데이터셋에서 **중복을 허용하여(부트스트랩 샘플링)** 여러 개의 부분 데이터셋을 생성합니다. 각 부분 데이터셋에 대해 독립적으로 개별 모델(약한 학습기)을 학습시킵니다. 모든 개별 모델의 학습이 완료된 후, 분류 문제에서는 다수결 투표(Voting) 방식으로, 회귀 문제에서는 평균(Averaging) 방식으로 최종 예측을 종합합니다.
    *   **특징:**
        *   **병렬 학습:** 개별 모델들이 독립적으로 학습되므로 병렬 처리가 가능하여 학습 속도가 빠릅니다.
        *   **분산(Variance) 감소:** 개별 모델의 예측이 서로 독립적이기 때문에, 개별 모델의 높은 분산(과적합 경향)을 줄여 모델의 일반화 성능을 향상시킵니다.
        *   **과적합 방지:** 각 모델이 다른 데이터 샘플과 특성 서브셋으로 학습되므로, 개별 모델의 과적합을 완화하는 데 효과적입니다.
    *   **대표적인 알고리즘:** **랜덤 포레스트(Random Forest)**

*   **부스팅 (Boosting):**
    *   **작동 원리:** 여러 개의 개별 모델을 **순차적으로(Sequentially)** 학습시킵니다. 각 모델은 이전 모델의 예측 오류(잔차, Residual)를 보정하는 데 집중하여 학습합니다. 즉, 이전 모델이 잘못 예측한 데이터 샘플에 더 높은 가중치를 부여하여 다음 모델이 해당 샘플을 더 잘 학습하도록 합니다. 최종 예측은 모든 개별 모델의 예측을 가중합하여 얻습니다.
    *   **특징:**
        *   **순차 학습:** 개별 모델들이 순차적으로 학습되므로 병렬 처리가 어렵습니다.
        *   **편향(Bias) 감소:** 이전 모델의 오류를 지속적으로 보정하므로, 모델의 편향을 줄이고 예측 성능을 극대화하는 데 효과적입니다.
        *   **강력한 성능:** 일반적으로 배깅보다 더 높은 예측 성능을 달성하는 경우가 많습니다.
    *   **대표적인 알고리즘:** **그레디언트 부스팅(Gradient Boosting)**, AdaBoost, XGBoost, LightGBM, CatBoost

**배깅과 부스팅의 주요 차이점 요약:**
| 특징 | 배깅 (Bagging) | 부스팅 (Boosting) |
| :--- | :--- | :--- |
| **모델 학습 방식** | 병렬적, 독립적 | 순차적, 의존적 |
| **오류 감소 목표** | 분산(Variance) 감소 | 편향(Bias) 감소 |
| **데이터 샘플링** | 중복 허용 부트스트랩 샘플링 | 이전 모델의 오류에 따라 가중치 부여 |
| **최종 예측 결합** | 투표 또는 평균 | 가중합 |
| **대표 알고리즘** | 랜덤 포레스트 | 그레디언트 부스팅, XGBoost, LightGBM |

두 기법 모두 앙상블 학습의 강력함을 보여주지만, 데이터의 특성과 문제의 요구사항에 따라 적절한 기법을 선택하는 것이 중요합니다.

## 3. 랜덤 포레스트 (Random Forest)

### 3.1. 핵심 개념
**랜덤 포레스트(Random Forest)**는 앙상블 학습 기법 중 **배깅(Bagging)**의 대표적인 예로, 여러 개의 **의사결정 트리**를 앙상블하여 최종 예측을 수행하는 모델입니다. 이름에서 알 수 있듯이 '랜덤'하게 생성된 '숲'(포레스트)처럼 여러 개의 트리를 만들고, 이들의 예측을 종합하여 단일 트리의 단점(과적합, 불안정성)을 보완하고 성능을 향상시킵니다.

*   **작동 원리:**
    1.  **부트스트랩 샘플링 (Bootstrap Sampling):** 원본 훈련 데이터셋에서 중복을 허용하여 `n_estimators` (생성할 트리의 개수)만큼의 부트스트랩 샘플을 생성합니다. 각 샘플은 원본 데이터셋과 동일한 크기를 가집니다.
    2.  **특성 무작위 선택 (Feature Randomness):** 각 트리를 학습할 때, 모든 특성을 고려하는 대신 무작위로 선택된 일부 특성(`max_features` 파라미터로 제어) 중에서만 최적의 분할을 찾습니다. 이는 개별 트리의 다양성을 높이는 데 기여합니다.
    3.  **개별 트리 학습:** 각 부트스트랩 샘플과 무작위로 선택된 특성 서브셋을 사용하여 독립적으로 의사결정 트리를 학습시킵니다. 개별 트리는 일반적으로 깊게 성장하도록 허용하여 낮은 편향을 가집니다.
    4.  **예측 종합:** 분류 문제에서는 각 트리의 예측 결과에 대한 다수결 투표(Voting)를 통해 최종 클래스를 결정하고, 회귀 문제에서는 각 트리의 예측 결과에 대한 평균을 취하여 최종 값을 결정합니다.

*   **랜덤 포레스트의 장점:**
    *   **과적합 감소:** 부트스트랩 샘플링과 특성 무작위 선택을 통해 개별 트리의 과적합 경향을 줄이고 모델의 일반화 성능을 높입니다.
    *   **높은 예측 성능:** 여러 트리의 예측을 종합하므로 단일 의사결정 트리보다 훨씬 높은 예측 정확도를 달성하는 경우가 많습니다.
    *   **안정성:** 데이터의 작은 변화에도 강건하며, 개별 트리의 불안정성을 완화합니다.
    *   **특성 중요도 제공:** 모델 학습 후 각 특성의 중요도를 계산하여 제공합니다. 이는 모델 해석에 유용합니다.
    *   **전처리 간소화:** 의사결정 트리 기반이므로 특성 스케일링이 필요 없습니다.

*   **랜덤 포레스트의 단점:**
    *   **학습 시간 및 메모리:** 여러 개의 트리를 학습하고 저장해야 하므로 단일 트리에 비해 학습 시간과 메모리 사용량이 많습니다.
    *   **해석의 어려움:** 개별 트리는 해석하기 쉽지만, 수많은 트리의 앙상블이므로 전체 모델의 결정 과정을 직관적으로 이해하기는 어렵습니다.

### 3.2. 주요 하이퍼파라미터
랜덤 포레스트는 여러 의사결정 트리를 앙상블하는 과정에서 모델의 복잡도와 일반화 성능을 제어하는 다양한 하이퍼파라미터를 가집니다. 이들을 적절히 튜닝하는 것이 중요합니다.

*   **`n_estimators` (생성할 트리의 개수):**
    *   **설명:** 앙상블에 포함될 의사결정 트리의 개수를 지정합니다. 즉, 몇 개의 '나무'를 만들 것인지를 결정합니다.
    *   **값이 클수록:** 모델의 예측 성능이 일반적으로 안정되고 향상됩니다. 더 많은 트리가 다양한 패턴을 학습하고 오류를 상쇄하기 때문입니다. 하지만 학습 시간과 메모리 사용량이 비례하여 증가합니다.
    *   **선택:** 충분히 큰 값을 설정하여 성능이 더 이상 향상되지 않는 지점을 찾는 것이 좋습니다. 일반적으로 100~1000 사이의 값을 사용합니다.

*   **`max_features` (각 분기에서 고려할 최대 특성의 수):**
    *   **설명:** 각 의사결정 트리가 노드를 분할할 때, 모든 특성을 고려하는 대신 무작위로 선택된 `max_features` 개수의 특성 중에서만 최적의 분할을 찾습니다. 이는 개별 트리의 다양성을 높이는 핵심적인 요소입니다.
    *   **선택:**
        *   분류 문제: `'sqrt'` (기본값) 또는 `'log2'`가 일반적으로 좋은 성능을 보입니다.
        *   회귀 문제: `'sqrt'` 또는 `1.0` (모든 특성 고려)이 자주 사용됩니다.
    *   **`'auto'` (Scikit-learn 0.23부터 `'sqrt'`로 변경됨):** `sqrt(n_features)`를 의미합니다.

*   **`max_depth` (트리의 최대 깊이):**
    *   **설명:** 개별 의사결정 트리의 최대 깊이를 제한합니다. 랜덤 포레스트에서는 개별 트리가 과적합되더라도 앙상블을 통해 일반화 성능을 높이므로, 단일 의사결정 트리만큼 `max_depth`에 민감하지 않을 수 있습니다.
    *   **선택:** `None` (제한 없음)으로 두거나, 데이터의 복잡도에 따라 적절한 값을 설정합니다.

*   **`min_samples_split` (노드 분할을 위한 최소 샘플 수):**
    *   **설명:** 노드를 분할하기 위해 필요한 최소 샘플 수를 지정합니다. 이 값보다 적은 샘플을 가진 노드는 더 이상 분할되지 않습니다.
    *   **선택:** 기본값인 2부터 시작하여 조정합니다.

*   **`min_samples_leaf` (리프 노드의 최소 샘플 수):**
    *   **설명:** 리프 노드가 되기 위해 필요한 최소 샘플 수를 지정합니다. 분할 후 각 리프 노드에 이 값보다 적은 샘플이 포함되면 해당 분할은 허용되지 않습니다.
    *   **선택:** 기본값인 1부터 시작하여 조정합니다.

*   **`bootstrap` (부트스트랩 샘플링 사용 여부):**
    *   **설명:** 각 트리를 학습할 때 부트스트랩 샘플링을 사용할지 여부를 지정합니다. `True` (기본값)로 설정하면 배깅의 원리에 따라 중복을 허용하여 샘플링합니다.

*   **`oob_score` (OOB 샘플을 사용하여 일반화 정확도 평가):**
    *   **설명:** `True`로 설정하면, 각 트리가 학습에 사용하지 않은 'OOB(Out-Of-Bag)' 샘플을 사용하여 모델의 일반화 성능을 평가합니다. 이는 별도의 검증 세트 없이도 모델의 성능을 추정할 수 있게 합니다.

*   **`random_state`:**
    *   **설명:** 모델의 초기화나 내부적인 무작위성이 포함된 작업의 재현성을 보장하기 위한 난수 시드입니다. 특정 정수 값을 지정하면 동일한 결과를 항상 얻을 수 있습니다.

**하이퍼파라미터 튜닝:**
랜덤 포레스트는 비교적 하이퍼파라미터에 덜 민감하지만, 최적의 성능을 위해서는 `GridSearchCV`나 `RandomizedSearchCV`와 같은 교차 검증 기반의 튜닝 도구를 사용하여 `n_estimators`, `max_features`, `max_depth` 등을 최적화하는 것이 좋습니다.

### 3.3. 실습: 유방암 데이터 분류
랜덤 포레스트 모델을 사용하여 유방암 데이터셋을 분류하는 실습 예제입니다. 랜덤 포레스트는 여러 의사결정 트리를 앙상블하여 단일 트리의 과적합 문제를 해결하고 더 안정적인 성능을 제공합니다.

```python
from sklearn.ensemble import RandomForestClassifier # 랜덤 포레스트 분류기
from sklearn.datasets import load_breast_cancer # 유방암 데이터셋 로드
from sklearn.model_selection import train_test_split # 데이터 분할
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix # 모델 평가 지표
import matplotlib.pyplot as plt
import seaborn as sns
import numpy as np

# 1. 데이터 로드
# load_breast_cancer() 함수는 유방암 데이터셋을 로드합니다.
# X는 특성 데이터, y는 타겟 레이블(양성/음성)입니다.
cancer = load_breast_cancer()
X, y = cancer.data, cancer.target

print(f"데이터셋 형태 (X): {X.shape}")
print(f"타겟 레이블 분포 (y): {np.bincount(y)}") # 클래스 0(악성), 클래스 1(양성)의 개수

# 2. 훈련/테스트 데이터 분리
# 훈련 세트와 테스트 세트로 데이터를 분할합니다.
# test_size=0.3: 전체 데이터의 30%를 테스트 세트로 사용합니다.
# random_state=42: 재현성을 위한 난수 시드입니다.
# stratify=y: 타겟 변수(y)의 클래스 비율을 훈련 세트와 테스트 세트에서 동일하게 유지합니다.
X_train, X_test, y_train, y_test = train_test_split(cancer.data, cancer.target, test_size=0.3, random_state=42, stratify=y)

print(f"\n훈련 세트 형태: {X_train.shape}, {y_train.shape}")
print(f"테스트 세트 형태: {X_test.shape}, {y_test.shape}")

# 3. 랜덤 포레스트 모델 생성 및 학습
# n_estimators=100: 100개의 의사결정 트리를 생성합니다.
# random_state=42: 재현성을 위한 난수 시드입니다.
rf_clf = RandomForestClassifier(n_estimators=100, random_state=42)
rf_clf.fit(X_train, y_train)

# 4. 모델 평가
# score() 메서드는 분류 문제에서 정확도(Accuracy)를 반환합니다.
print(f"\n랜덤 포레스트 정확도: {rf_clf.score(X_test, y_test):.4f}")

# 테스트 세트에 대한 예측 수행
y_pred_rf = rf_clf.predict(X_test)

# 분류 보고서 및 혼동 행렬을 통한 상세 평가
print("\n분류 보고서:\n", classification_report(y_test, y_pred_rf))

cm_rf = confusion_matrix(y_test, y_pred_rf)
plt.figure(figsize=(6, 5))
sns.heatmap(cm_rf, annot=True, fmt='d', cmap='Blues',
            xticklabels=cancer.target_names, yticklabels=cancer.target_names)
plt.xlabel('예측 레이블')
plt.ylabel('실제 레이블')
plt.title('랜덤 포레스트 혼동 행렬')
plt.show()

# 5. 특성 중요도 출력
# 랜덤 포레스트는 각 특성의 중요도를 제공합니다. 이는 모델 해석에 유용합니다.
print("\n특성 중요도:")
# feature_importances_ 속성은 각 특성의 중요도를 나타내는 배열입니다.
# zip을 사용하여 특성 이름과 중요도를 묶어 출력합니다.
for name, importance in zip(cancer.feature_names, rf_clf.feature_importances_):
    print(f"{name}: {importance:.4f}")

# 특성 중요도 시각화
sns.barplot(x=rf_clf.feature_importances_, y=cancer.feature_names)
plt.title('랜덤 포레스트 특성 중요도')
plt.xlabel('특성 중요도')
plt.ylabel('특성 이름')
plt.tight_layout()
plt.show()
```

**실습 결과 해석:**
*   **정확도:** 단일 의사결정 트리보다 높은 정확도를 보이는 경우가 많습니다.
*   **분류 보고서 및 혼동 행렬:** 모델의 정밀도, 재현율, F1-점수, 그리고 오분류 패턴을 상세히 파악할 수 있습니다.
*   **특성 중요도:** 모델이 예측을 수행하는 데 어떤 특성들이 가장 중요한 역할을 했는지 수치적으로 확인할 수 있습니다. 이는 도메인 지식과 결합하여 데이터에 대한 새로운 인사이트를 얻는 데 도움이 됩니다.

랜덤 포레스트는 높은 예측 성능과 안정성, 그리고 특성 중요도 제공이라는 장점 덕분에 실제 문제 해결에 매우 널리 사용되는 강력한 앙상블 모델입니다.


## 4. 그레디언트 부스팅 (Gradient Boosting)

### 4.1. 핵심 개념
**그레디언트 부스팅(Gradient Boosting)**은 앙상블 학습 기법 중 **부스팅(Boosting)**의 한 종류로, 여러 개의 약한 학습기(주로 의사결정 트리)를 순차적으로 학습시켜 강력한 예측 모델을 구축합니다. 이전 모델의 예측 오차(잔차, Residual)를 다음 모델이 학습하도록 하는 방식으로 모델을 점진적으로 개선해 나갑니다.

*   **작동 원리:**
    1.  **초기 모델 학습:** 첫 번째 약한 학습기(예: 얕은 의사결정 트리)를 훈련 데이터에 학습시킵니다.
    2.  **잔차 계산:** 첫 번째 모델의 예측과 실제 타겟 값 사이의 오차(잔차)를 계산합니다.
    3.  **다음 모델 학습:** 두 번째 약한 학습기는 첫 번째 모델의 예측 오차(잔차)를 예측하도록 학습합니다. 즉, 모델이 틀린 부분을 집중적으로 학습합니다.
    4.  **예측 업데이트:** 이전 모델의 예측에 현재 모델의 예측(오차에 대한 예측)을 더하여 전체 앙상블 모델의 예측을 업데이트합니다.
    5.  **반복:** 이 과정을 미리 정해진 `n_estimators` (트리 개수)만큼 반복합니다. 각 단계에서 새로운 약한 학습기는 이전까지의 앙상블 모델이 잘 예측하지 못하는 부분에 집중하여 학습합니다.

*   **경사 하강법 (Gradient Descent)과의 관계:**
    *   그레디언트 부스팅은 손실 함수(Loss Function)를 최소화하는 방향으로 모델을 업데이트합니다. 이때, 손실 함수의 '음의 그레디언트'(Negative Gradient)를 잔차처럼 사용하여 다음 약한 학습기가 학습할 목표로 삼습니다.
    *   즉, 각 약한 학습기는 이전 앙상블 모델의 예측이 손실 함수를 최소화하는 방향으로 나아가도록 돕는 역할을 합니다.

*   **장점:**
    *   **매우 높은 예측 성능:** 일반적으로 매우 높은 예측 성능을 보이며, 다양한 데이터셋에서 강력한 성능을 발휘합니다. 많은 캐글 경연 대회에서 우승 모델로 사용됩니다.
    *   **다양한 손실 함수 지원:** 분류(로지스틱 손실)와 회귀(제곱 오차, 절대 오차 등) 문제 모두에 적용 가능하며, 다양한 손실 함수를 지원합니다.
    *   **특성 중요도 제공:** 모델 학습 후 각 특성의 중요도를 계산하여 제공합니다.
*   **단점:**
    *   **학습 시간:** 순차적으로 학습하므로 병렬 처리가 어려워 학습 시간이 오래 걸릴 수 있습니다.
    *   **과적합 위험:** 너무 많은 트리를 사용하거나, 학습률을 너무 높게 설정하면 과적합될 위험이 있습니다.
    *   **하이퍼파라미터 민감성:** 하이퍼파라미터 설정에 민감하며, 최적의 조합을 찾는 것이 중요합니다.

### 4.2. 주요 하이퍼파라미터
*   `n_estimators`: 생성할 트리의 개수.
*   `learning_rate`: 각 트리가 이전 트리의 오차를 얼마나 강하게 보정할지 결정하는 학습률입니다. 값이 작을수록 학습 시간이 길어지지만, 더 안정적인 성능을 얻을 수 있습니다.
*   `subsample`: 각 트리를 학습할 때 사용할 훈련 데이터의 샘플 비율. 1.0보다 작게 설정하면 과적합 방지에 도움이 됩니다 (Stochastic Gradient Boosting).
*   `max_depth`: 각 트리의 최대 깊이. 일반적으로 3~5 사이의 낮은 값으로 설정하여 과적합을 방지합니다.

### 4.3. 실습: 유방암 데이터 분류
```python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split

# 데이터 로드
cancer = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(cancer.data, cancer.target, random_state=42)

# 그레디언트 부스팅 모델 생성 및 학습
gb_clf = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1, max_depth=3, random_state=42)
gb_clf.fit(X_train, y_train)

# 모델 평가
print(f"그레디언트 부스팅 정확도: {gb_clf.score(X_test, y_test):.4f}")
```
