# 데이터 분석가를 위한 SQL 실무 학습 가이드

> **현업 데이터 분석가의 조언:**
>
> SQL은 데이터를 다루는 모든 직무의 **기본 언어**이자, 가장 강력한 무기입니다. 이 학습 가이드는 여러분이 단순히 문법을 암기하는 것을 넘어, **'왜(Why)'** 이 기능이 필요하고 **'어떻게(How)'** 실무에 적용되는지를 이해하는 데 초점을 맞췄습니다. 각 문서를 순서대로 따라가며 실습하다 보면, 여러분은 어느새 데이터를 자유자재로 탐색하고, 정제하며, 비즈니스 질문에 대한 답을 찾아내는 유능한 데이터 분석가로 성장해 있을 것입니다.

---

### Part 1: 데이터베이스 기초 및 환경 설정
> **학습 목표:** 데이터를 담을 그릇(DB)을 직접 만들고, 데이터를 탐색할 수 있는 효율적인 분석 환경을 구축합니다.
>
> **왜 중요한가?** 모든 분석은 데이터를 불러오는 것에서 시작됩니다. 데이터베이스의 구조를 이해하고, 내 PC에 분석 환경을 직접 구축할 수 있어야만 진짜 분석을 시작할 수 있습니다.

-   [**01_SQL_시작하기.md**](./01_SQL_시작하기.md): 데이터 분석을 위한 MySQL 환경 구축, RDBMS 아키텍처 이해, GUI 도구(DBeaver) 연동, 데이터베이스 및 사용자 관리 기초를 학습합니다.
-   [**02_테이블과_제약조건.md**](./02_테이블과_제약조건.md): 데이터 타입 선택 기준, 테이블 생성(CREATE), 데이터 무결성을 위한 제약조건(PK, FK, UNIQUE, NOT NULL, CHECK, DEFAULT), 정규화 기초를 학습합니다.

### Part 2: 데이터 조작 및 조회 (SQL의 핵심)
> **학습 목표:** 원하는 데이터를 **'어떻게'** 가져올지, **'어떻게'** 계산하고 요약할지를 배웁니다. 데이터 분석의 80%는 데이터 전처리 및 탐색(EDA)이며, 이 파트가 그 핵심입니다.
>
> **왜 중요한가?** 현업의 데이터는 절대 깔끔하지 않습니다. 여러 테이블에 흩어져 있는 데이터를 결합(JOIN)하고, 원하는 조건으로 필터링하며, 의미 있는 단위로 그룹화(GROUP BY)하여 인사이트를 도출하는 능력이 바로 분석가의 핵심 역량입니다.

-   [**03_데이터_조작과_조회.md**](./03_데이터_조작과_조회.md): DML(INSERT, UPDATE, DELETE)을 이용한 데이터 조작, `SELECT` 문의 기본 구조, `WHERE` 절을 이용한 데이터 필터링, `ORDER BY`를 이용한 정렬 방법을 학습합니다.
-   [**04_데이터_집계와_그룹화.md**](./04_데이터_집계와_그룹화.md): 데이터 분석의 핵심인 집계 함수(COUNT, SUM, AVG, MAX, MIN), `GROUP BY`를 이용한 데이터 그룹화, `HAVING` 절을 이용한 그룹 필터링을 학습합니다.
-   [**05_테이블_연결_JOIN.md**](./05_테이블_연결_JOIN.md): 여러 테이블의 데이터를 결합하는 JOIN의 종류(INNER, LEFT/RIGHT/FULL OUTER), SELF JOIN, 그리고 실무에서 자주 사용하는 JOIN 활용 팁을 학습합니다.

### Part 3: 고급 SQL 쿼리
> **학습 목표:** 복잡한 비즈니스 질문에 답하기 위해 SQL의 고급 기능을 활용하여, 다차원적인 분석 쿼리를 작성하는 능력을 기릅니다.
>
> **왜 중요한가?** '매출 상위 10% 고객의 평균 구매액' 또는 '부서별 누적 매출'과 같은 복잡한 분석은 단순한 `GROUP BY`만으로는 한계가 있습니다. 서브쿼리, 윈도우 함수, CTE를 자유자재로 사용할 수 있을 때, 비로소 '시니어' 분석가로 나아갈 수 있습니다.

-   [**06_서브쿼리와_CASE.md**](./06_서브쿼리와_CASE.md): 쿼리 내의 쿼리인 서브쿼리(단일 행, 다중 행, 스칼라, 인라인 뷰)의 다양한 활용법과 `CASE` 표현식을 이용한 조건부 데이터 처리를 학습합니다.
-   [**07_윈도우함수와_CTE.md**](./07_윈도우함수와_CTE.md): 순위, 누적, 이동 평균 등 복잡한 분석을 위한 윈도우 함수(분석 함수)와 가독성 높은 쿼리 작성을 위한 CTE(Common Table Expressions)를 학습합니다.

### Part 4: 데이터베이스 성능 및 파이썬 연동
> **학습 목표:** 대용량 데이터 환경에서 쿼리 성능을 최적화하고, Python을 통해 데이터 분석 및 파이프라인 자동화 작업을 수행하는 방법을 배웁니다.
>
> **왜 중요한가?** 분석 쿼리가 몇 시간씩 걸린다면 비즈니스는 기다려주지 않습니다. 인덱스를 이해하고 실행 계획을 분석하여 쿼리 성능을 튜닝하는 것은 분석가의 중요한 역량입니다. 또한, 분석 결과를 자동화하고 다른 시스템과 연동하기 위해 Python과의 연결은 필수적입니다.

-   [**08_성능튜닝과_인덱스.md**](./08_성능튜닝과_인덱스.md): 쿼리 성능 최적화의 기초인 실행 계획 분석, 인덱스의 개념과 종류, 그리고 효과적인 인덱스 설계 및 활용 전략을 학습합니다.
-   [**09_트랜잭션과_DB객체.md**](./09_트랜잭션과_DB객체.md): 데이터의 일관성을 보장하는 트랜잭션(ACID)과 TCL, 그리고 뷰(View), 스토어드 프로시저(Stored Procedure) 등 재사용 가능한 데이터베이스 객체를 학습합니다.
-   [**10_Python과_SQL_기본_연동.md**](./10_Python과_SQL_기본_연동.md): Python에서 데이터베이스에 연결하고 쿼리를 실행하기 위한 DB-API(`pymysql`) 사용법과 기본적인 연동 코드 작성법을 학습합니다.
-   [**11_SQLAlchemy_ORM_활용.md**](./11_SQLAlchemy_ORM_활용.md): 파이썬스러운 방식으로 데이터베이스를 다루는 SQLAlchemy Core와 ORM의 개념을 이해하고, 이를 활용한 CRUD 작업을 학습합니다.
-   [**12_데이터_파이프라인_자동화.md**](./12_데이터_파이프라인_자동화.md): Airflow, Prefect와 같은 워크플로우 관리 도구를 사용하여 데이터 수집, 처리, 분석 작업을 자동화하는 데이터 파이프라인의 기본 개념을 학습합니다.
-   [**13_Django와_SQLite_연동.md**](./13_Django와_SQLite_연동.md): 웹 프레임워크 Django의 ORM을 통해 경량 데이터베이스인 SQLite를 다루는 방법을 학습합니다.
