# 데이터 분석가를 위한 SQL 실무 역량 강화 가이드

이 가이드는 데이터 분석 및 AI 개발에 필수적인 SQL의 기초부터 고급 주제까지 체계적으로 다루며, 데이터를 통해 비즈니스 문제를 해결하고 가치를 창출하는 실무 역량을 강화하는 데 초점을 맞춥니다. 이 여정을 통해 여러분은 복잡한 데이터를 효율적으로 다루고, 통찰력을 도출하여 비즈니스 성장에 기여하는 유능한 데이터 분석가로 성장할 것입니다.

---

### Part 1: 분석가의 작업 환경 준비
 **학습 목표:** SQL 기반 데이터 분석을 위한 개발 환경을 구축하고, 관계형 데이터베이스의 기본적인 구조와 관리 원리를 이해합니다.

 **왜 중요한가?** 효율적인 데이터 분석은 올바른 환경 설정에서 시작됩니다. 데이터베이스 시스템의 기초를 다져 안정적인 분석 작업을 수행할 수 있습니다.

-   [**01_SQL_시작하기.md**](./01_SQL_시작하기.md): MySQL과 DBeaver를 활용한 최적의 분석 환경 구축, RDBMS 아키텍처의 핵심 원리, 데이터베이스와 사용자 관리 기초를 학습합니다.
-   [**02_테이블과_제약조건.md**](./02_테이블과_제약조건.md): 데이터 타입 선택 기준, 테이블 설계(CREATE), 데이터 무결성을 위한 제약조건(PK, FK, UNIQUE 등)과 정규화의 기본 원칙을 학습합니다.

### Part 2: 데이터 탐색과 정제의 기술 (EDA의 핵심)
 **학습 목표:** SQL을 활용하여 데이터를 조회, 조작, 집계하고, 복잡한 데이터를 효과적으로 탐색하고 정제하는 실무 기술을 습득합니다.

 **왜 중요한가?** 데이터 분석의 핵심은 원본 데이터에서 의미 있는 정보를 추출하고, 분석 가능한 형태로 가공하는 능력입니다. SQL은 이 과정에서 가장 강력한 도구입니다.

-   [**03_데이터_조작과_조회.md**](./03_데이터_조작과_조회.md): `SELECT`, `WHERE`, `ORDER BY` 등 기본 조회 구문과 `INSERT`, `UPDATE`, `DELETE` 등 데이터 조작의 기본기를 다집니다.
-   [**04_데이터_집계와_그룹화.md**](./04_데이터_집계와_그룹화.md): `COUNT`, `SUM`, `AVG` 등 핵심 집계 함수와 `GROUP BY`, `HAVING`을 활용해 데이터를 의미 있는 단위로 요약하고 비교하는 방법을 학습합니다.
-   [**05_테이블_연결_JOIN.md**](./05_테이블_연결_JOIN.md): 여러 테이블에 분산된 정보를 `INNER`, `OUTER JOIN` 등으로 결합하는 관계형 데이터베이스의 핵심 원리와 실무 활용법을 깊이 있게 학습합니다.
-   [**06_서브쿼리와_CASE.md**](./06_서브쿼리와_CASE.md): `CASE`문, `NULL` 처리 함수(`COALESCE`, `IFNULL`), 문자열/날짜 처리 함수 등 실무 데이터 정제에 필수적인 기능들을 학습합니다.

### Part 3: 다차원 분석을 위한 고급 쿼리
 **학습 목표:** 서브쿼리, 윈도우 함수, CTE 등 SQL의 고급 기능을 활용하여 복잡한 비즈니스 로직을 구현하고, 대용량 데이터의 쿼리 성능을 최적화하는 방법을 익힙니다.

 **왜 중요한가?** 고급 쿼리 작성 능력은 복잡한 분석 요구사항을 충족시키고, 대규모 데이터셋에서 효율적으로 인사이트를 도출하는 데 필수적입니다.

-   [**07_윈도우함수와_CTE.md**](./07_윈도우함수와_CTE.md): 쿼리의 가독성과 재사용성을 높이는 CTE(Common Table Expressions)와 순위, 누적, 비율 등 복잡한 분석을 위한 윈도우 함수(Window Functions)를 학습합니다.
-   [**08_성능튜닝과_인덱스.md**](./08_성능튜닝과_인덱스.md): 대용량 데이터 환경에서 쿼리 속도를 극적으로 개선하는 실행 계획 분석과 인덱스 설계 전략을 학습합니다.
-   [**09_트랜잭션과_DB객체.md**](./09_트랜잭션과_DB객체.md): 데이터의 일관성을 보장하는 트랜잭션(ACID)과, 자주 사용하는 쿼리를 저장하는 뷰(View) 등 데이터베이스의 재사용 가능한 객체들을 학습합니다.

### Part 4: 분석 결과의 활용과 자동화
 **학습 목표:** SQL 쿼리 결과를 Python과 연동하고, 데이터 파이프라인을 자동화하여 분석 결과를 효율적으로 활용하고 공유하는 방법을 학습합니다.

 **왜 중요한가?** 분석 결과를 실제 비즈니스 프로세스에 통합하고 자동화하는 능력은 데이터 분석가의 가치를 극대화하며, 반복적인 작업을 줄여 생산성을 높입니다.

-   [**10_보안과_사용자_관리.md**](./10_보안과_사용자_관리.md): 데이터베이스 보안의 중요성을 이해하고, 사용자 계정 생성, 권한 부여 및 회수 등 데이터 접근 제어 방법을 학습합니다.
-   [**11_Python과_SQL_기본_연동.md**](./11_Python과_SQL_기본_연동.md): Python `pymysql` 라이브러리를 통해 DB에 연결하고 쿼리 결과를 가져오는 기본 원리를 학습합니다.
-   [**12_SQLAlchemy_ORM_활용.md**](./12_SQLAlchemy_ORM_활용.md): SQL 쿼리를 Python 코드처럼 다루게 해주는 SQLAlchemy Core와 ORM의 개념을 이해하고, **Pandas DataFrame과의 연동(`pd.read_sql`)**을 중심으로 실무 데이터 핸들링 방법을 학습합니다.
-   [**13_Django와_SQLite_연동.md**](./13_Django와_SQLite_연동.md): Django 프레임워크와 SQLite 데이터베이스를 연동하여 웹 애플리케이션에서 데이터를 관리하는 기본 방법을 학습합니다.
-   [**14_데이터_파이프라인_자동화.md**](./14_데이터_파이프라인_자동화.md): Python 스케줄링 라이브러리(e.g., `schedule`)나 간단한 대시보드 툴(e.g., `Streamlit`)을 활용하여 **주기적인 리포트를 자동화**하고, 분석 결과를 공유하는 실용적인 방법을 학습합니다.
