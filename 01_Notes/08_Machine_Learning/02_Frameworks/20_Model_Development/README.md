# 모델 개발: Scikit-learn과 앙상블

**다양한 머신러닝 모델을 구축하고 평가하는 데 사용되는 주요 라이브러리 및 기법**

이 섹션은 파이썬의 대표적인 머신러닝 라이브러리인 Scikit-learn을 중심으로 선형 모델, 비선형 모델, 앙상블 모델 등 다양한 머신러닝 알고리즘의 기본 원리와 활용 방법을 학습합니다. 또한, 모델의 성능을 평가하고 최적의 하이퍼파라미터를 찾는 교차 검증 및 튜닝 기법을 익혀, 실제 문제에 적용 가능한 모델을 개발하는 능력을 기릅니다.

---

### 주요 내용:

- [**01_Scikit_learn_기본.md**](./01_Scikit_learn_기본.md): Scikit-learn의 기본 구조, 데이터셋 로드, 모델 학습 및 예측의 기본 워크플로우.
- [**02_선형_모델.md**](./02_선형_모델.md): 선형 회귀, 로지스틱 회귀 등 선형 모델의 원리와 Scikit-learn을 이용한 구현.
- [**03_비선형_모델.md**](./03_비선형_모델.md): SVM, 결정 트리, K-최근접 이웃 등 비선형 모델의 원리와 Scikit-learn을 이용한 구현.
- [**04_앙상블_모델.md**](./04_앙상블_모델.md): 랜덤 포레스트, 그래디언트 부스팅(XGBoost, LightGBM) 등 앙상블 모델의 원리와 구현.
- [**05_모델_평가_교차_검증.md**](./05_모델_평가_교차_검증.md): 분류/회귀 모델 평가 지표, 교차 검증(Cross-Validation)의 원리와 활용.
- [**06_하이퍼파라미터_튜닝.md**](./06_하이퍼파라미터_튜닝.md): 그리드 탐색, 랜덤 탐색, 베이지안 최적화 등 하이퍼파라미터 튜닝 기법.
