## 1. 데이터 스케일링 (Data Scaling)

### 1.1. 왜 데이터 스케일링이 필요한가?
**데이터 스케일링(Data Scaling)**은 머신러닝 모델을 훈련하기 전에 특성(Feature)들의 값 범위를 조정하는 과정입니다. 이는 모델 학습 시 특정 특성이 다른 특성보다 더 큰 영향을 미치는 것을 방지하고, 모델의 수렴 속도 및 성능을 향상시키는 데 필수적인 역할을 합니다.

데이터 스케일링이 필요한 주요 이유는 다음과 같습니다:

1.  **특성 중요도의 균등화 (Feature Dominance Prevention):**
    *   데이터셋의 특성들이 서로 다른 스케일(값의 범위)을 가질 때, 스케일이 큰 특성이 모델 학습 과정에서 더 큰 영향력을 행사할 수 있습니다. 예를 들어, 주택 가격 예측 모델에서 '방 개수'(1~5)와 '면적'(100~5000) 특성이 있다면, 면적 특성이 모델에 훨씬 더 큰 영향을 미치게 됩니다.
    *   스케일링을 통해 모든 특성들이 유사한 값 범위를 가지도록 조정함으로써, 모델이 특정 특성에 편향되지 않고 모든 특성을 공정하게 고려하여 학습할 수 있도록 돕습니다.

2.  **거리 기반 알고리즘의 성능 향상:**
    *   K-최근접 이웃(KNN), 서포트 벡터 머신(SVM), K-평균(K-Means) 클러스터링 등과 같이 특성 간의 거리를 계산하여 작동하는 알고리즘들은 특성 스케일에 매우 민감합니다.
    *   스케일이 큰 특성이 거리 계산에 지배적인 영향을 미치게 되어, 실제 데이터의 유사성이나 패턴을 왜곡할 수 있습니다. 스케일링을 통해 모든 특성이 동일한 중요도를 가지도록 하여 알고리즘이 올바른 거리를 계산하고 더 정확한 결과를 도출하도록 합니다.

3.  **경사 하강법 기반 알고리즘의 수렴 속도 및 안정성 향상:**
    *   선형 회귀, 로지스틱 회귀, 신경망 등 경사 하강법(Gradient Descent)을 사용하여 모델 파라미터를 최적화하는 알고리즘들은 특성 스케일에 영향을 받습니다.
    *   특성들의 스케일이 크게 다르면 손실 함수의 등고선이 매우 길고 좁은 타원형(좁고 긴 골짜기)을 형성하게 됩니다. 이 경우 경사 하강법은 최적점을 향해 지그재그로 움직이며 매우 느리게 수렴하거나, 심지어 발산할 수도 있습니다.
    *   스케일링을 통해 손실 함수의 형태를 더 원형에 가깝게 만들어 경사 하강법이 더 빠르고 안정적으로 최적점에 도달할 수 있도록 돕습니다.

4.  **정규화(Regularization) 효과:**
    *   릿지(Ridge)나 라쏘(Lasso)와 같은 정규화 기법은 모델 파라미터의 크기에 페널티를 부과합니다. 스케일링되지 않은 데이터에 정규화를 적용하면, 스케일이 큰 특성의 계수에 더 큰 페널티가 부과되어 불공평한 정규화가 이루어질 수 있습니다.
    *   스케일링을 통해 모든 특성의 계수가 동일한 스케일에서 정규화되도록 하여 공정한 페널티를 적용할 수 있습니다.

이러한 이유들로 인해 데이터 스케일링은 머신러닝 모델의 성능과 학습 효율성을 극대화하는 데 필수적인 전처리 단계입니다.

### 1.2. `StandardScaler`
`StandardScaler`는 각 특성의 평균(mean)을 0, 표준편차(standard deviation)를 1로 조정하여 데이터를 표준 정규 분포와 유사하게 만듭니다. 이를 **표준화(Standardization)**라고도 합니다.

*   **수식:** 각 특성 $X$에 대해 다음과 같이 스케일링됩니다.
    $ X_{scaled} = \frac{X - \mu}{\sigma} $
    *   $\mu$: 특성의 평균
    *   $\sigma$: 특성의 표준편차

*   **특징:**
    *   **평균 0, 표준편차 1:** 스케일링 후 모든 특성은 평균이 0이고 표준편차가 1인 분포를 가지게 됩니다.
    *   **데이터 분포 유지:** 데이터의 원래 분포 형태(예: 정규 분포, 왜곡된 분포)는 유지됩니다. 즉, 데이터의 상대적인 순위나 간격은 변하지 않습니다.
    *   **이상치에 민감:** 이상치(Outlier)가 존재할 경우, 평균과 표준편차가 이상치에 의해 크게 영향을 받을 수 있으므로, 스케일링 결과가 왜곡될 수 있습니다. 따라서 이상치에 강건하지 않습니다.

*   **사용 시기:**
    *   특성들이 정규 분포를 따르거나, 이상치의 영향이 크지 않을 때.
    *   선형 모델(Linear Regression, Logistic Regression), SVM, 신경망(Neural Networks) 등 대부분의 알고리즘에 일반적으로 사용됩니다. 특히 경사 하강법 기반의 모델에서 수렴 속도를 향상시키는 데 효과적입니다.
    *   PCA(주성분 분석)와 같이 분산에 민감한 알고리즘을 적용하기 전에 사용하면 좋습니다.

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt
import seaborn as sns

# 스케일링할 데이터 (가상)
# feature1은 작은 범위, feature2는 큰 범위를 가집니다.
data = np.array([
    [1, 100],
    [2, 200],
    [3, 300],
    [4, 400],
    [5, 500]
])

print("원본 데이터:\n", data)
print(f"원본 데이터 평균: {np.mean(data, axis=0)}")
print(f"원본 데이터 표준편차: {np.std(data, axis=0)}")

# StandardScaler 객체 생성
scaler = StandardScaler()
# fit_transform(): 훈련 데이터로부터 평균과 표준편차를 학습(fit)하고, 데이터를 변환(transform)합니다.
data_scaled = scaler.fit_transform(data)
print("\nStandardScaler 적용 후:\n", data_scaled)
print(f"스케일링 후 평균: {np.mean(data_scaled, axis=0)}")
print(f"스케일링 후 표준편차: {np.std(data_scaled, axis=0)}")

# 시각화를 통한 분포 확인 (선택 사항)

```

**`StandardScaler` 사용 시 고려사항:**
*   **데이터 누수 방지:** `fit()` 메서드는 반드시 훈련 데이터에만 적용해야 합니다. 테스트 데이터나 새로운 데이터에 대해서는 훈련 데이터로 `fit`된 `scaler` 객체의 `transform()` 메서드를 사용해야 합니다. `fit_transform()`은 훈련 데이터에만 사용하고, 테스트 데이터에는 `transform()`만 사용해야 합니다.
*   **이상치 영향:** 이상치가 많은 데이터셋에서는 `RobustScaler`와 같은 다른 스케일러를 고려하는 것이 좋습니다.
*   **해석:** 스케일링 후 특성 값의 원래 의미를 잃을 수 있으므로, 모델 해석 시 주의가 필요합니다.


### 1.3. `MinMaxScaler`
`MinMaxScaler`는 각 특성의 값을 0과 1 사이(또는 지정된 범위)로 조정합니다. 이를 **정규화(Normalization)**라고도 합니다. 데이터의 최솟값과 최댓값을 사용하여 데이터를 선형적으로 변환합니다.

*   **수식:** 각 특성 $X$에 대해 다음과 같이 스케일링됩니다.
    $ X_{scaled} = \frac{X - X_{min}}{X_{max} - X_{min}} $
    *   $X_{min}$: 특성의 최솟값
    *   $X_{max}$: 특성의 최댓값

*   **특징:**
    *   **고정된 범위:** 스케일링 후 모든 특성은 0과 1 사이의 값을 가지게 됩니다 (기본값). `feature_range` 파라미터를 통해 다른 범위(예: -1과 1 사이)로도 조정할 수 있습니다.
    *   **데이터 분포 유지:** `StandardScaler`와 마찬가지로 데이터의 원래 분포 형태는 유지됩니다.
    *   **이상치에 매우 민감:** 최솟값과 최댓값을 기준으로 스케일링하므로, 데이터에 이상치(Outlier)가 존재할 경우 스케일링 결과가 크게 왜곡될 수 있습니다. 이상치가 최솟값이나 최댓값을 극단적으로 밀어내어 대부분의 정상 데이터가 매우 좁은 범위에 압축될 수 있습니다.

*   **사용 시기:**
    *   특성의 최댓값과 최솟값이 명확하고, 이상치의 영향이 적을 때.
    *   이미지 픽셀 데이터(0-255 범위의 값을 0-1로 정규화)나 신경망의 입력 특성으로 자주 사용됩니다. 신경망은 입력 값의 범위가 작을 때 학습이 더 안정적인 경향이 있습니다.
    *   데이터의 스케일이 중요하지만, 정확한 정규 분포를 따를 필요가 없는 경우.

```python
from sklearn.preprocessing import MinMaxScaler
import numpy as np # np.array 사용을 위해 필요

# 스케일링할 데이터 (가상)
# feature1은 작은 범위, feature2는 큰 범위를 가집니다.
data = np.array([
    [1, 100],
    [2, 200],
    [3, 300],
    [4, 400],
    [5, 500]
])

print("원본 데이터:\n", data)
print(f"원본 데이터 최솟값: {np.min(data, axis=0)}")
print(f"원본 데이터 최댓값: {np.max(data, axis=0)}")

# MinMaxScaler 객체 생성
scaler = MinMaxScaler()
# fit_transform(): 훈련 데이터로부터 최솟값과 최댓값을 학습(fit)하고, 데이터를 변환(transform)합니다.
data_scaled = scaler.fit_transform(data)
print("\nMinMaxScaler 적용 후:\n", data_scaled)
print(f"스케일링 후 최솟값: {np.min(data_scaled, axis=0)}")
print(f"스케일링 후 최댓값: {np.max(data_scaled, axis=0)}")

# 다른 범위로 스케일링 (예: -1에서 1 사이)
scaler_neg1_to_1 = MinMaxScaler(feature_range=(-1, 1))
data_scaled_neg1_to_1 = scaler_neg1_to_1.fit_transform(data)
print("\nMinMaxScaler (-1 to 1) 적용 후:\n", data_scaled_neg1_to_1)
```

**`MinMaxScaler` 사용 시 고려사항:**
*   **데이터 누수 방지:** `StandardScaler`와 동일하게 `fit()`은 훈련 데이터에만, `transform()`은 훈련 및 테스트 데이터 모두에 적용해야 합니다.
*   **이상치 영향:** 이상치가 많은 데이터셋에서는 `RobustScaler`를 고려하는 것이 더 적합합니다.
*   **0으로 나누기 오류:** `X_max - X_min`이 0이 되는 경우(즉, 특성의 모든 값이 동일한 경우) `MinMaxScaler`는 0으로 나누기 오류를 발생시킬 수 있습니다. Scikit-learn 구현에서는 이를 자동으로 처리하여 해당 특성을 0으로 변환합니다.


### 1.4. `RobustScaler`
`RobustScaler`는 중앙값(median)과 사분위 범위(IQR: Interquartile Range)를 사용하여 특성을 스케일링합니다. 이 방법은 **이상치(Outlier)의 영향을 최소화**하는 데 강점이 있습니다. `StandardScaler`나 `MinMaxScaler`가 이상치에 민감하게 반응하는 것과 달리, `RobustScaler`는 중앙값과 IQR을 사용하므로 이상치에 의해 통계량이 크게 왜곡되지 않습니다.

*   **수식:** 각 특성 $X$에 대해 다음과 같이 스케일링됩니다.
    $ X_{scaled} = \frac{X - Q_2}{Q_3 - Q_1} $
    *   $Q_2$: 특성의 중앙값 (Median, 50번째 백분위수)
    *   $Q_1$: 특성의 1사분위수 (25번째 백분위수)
    *   $Q_3$: 특성의 3사분위수 (75번째 백분위수)
    *   $Q_3 - Q_1$: 사분위 범위 (IQR, Interquartile Range)

*   **특징:**
    *   **이상치에 강건:** 중앙값과 IQR은 이상치에 덜 민감한 통계량이므로, 이상치가 많은 데이터셋에서 `StandardScaler`나 `MinMaxScaler`보다 안정적인 스케일링 결과를 제공합니다.
    *   **분포 유지:** 데이터의 원래 분포 형태는 유지됩니다.
    *   **범위 비고정:** 스케일링 후 특성 값의 범위가 고정되지 않습니다.

*   **사용 시기:**
    *   데이터에 이상치가 많거나, 특성 분포가 심하게 왜곡되어 있을 때 (예: 극단적인 왜도(skewness)를 가진 데이터).
    *   이상치의 영향을 최소화하면서 스케일링을 수행해야 할 때.

```python
from sklearn.preprocessing import RobustScaler
import numpy as np # np.array 사용을 위해 필요

# 스케일링할 데이터 (이상치 포함)
# feature1과 feature2에 각각 100과 10000이라는 큰 이상치가 포함되어 있습니다.
data_outlier = np.array([
    [1, 100],
    [2, 200],
    [3, 300],
    [4, 400],
    [100, 10000] # 이상치
])

print("원본 데이터 (이상치 포함):\n", data_outlier)
print(f"원본 데이터 중앙값: {np.median(data_outlier, axis=0)}")
print(f"원본 데이터 1사분위수 (Q1): {np.percentile(data_outlier, 25, axis=0)}")
print(f"원본 데이터 3사분위수 (Q3): {np.percentile(data_outlier, 75, axis=0)}")

# RobustScaler 객체 생성
scaler = RobustScaler()
# fit_transform(): 훈련 데이터로부터 중앙값과 IQR을 학습(fit)하고, 데이터를 변환(transform)합니다.
data_scaled = scaler.fit_transform(data_outlier)
print("\nRobustScaler 적용 후 (이상치 포함 데이터):\n", data_scaled)

# 스케일링 후 중앙값과 IQR 확인 (거의 0과 1에 가까워짐)
# print(f"스케일링 후 중앙값: {np.median(data_scaled, axis=0)}")
# print(f"스케일링 후 IQR: {np.percentile(data_scaled, 75, axis=0) - np.percentile(data_scaled, 25, axis=0)}")
```

**`RobustScaler` 사용 시 고려사항:**
*   **데이터 누수 방지:** 다른 스케일러와 동일하게 `fit()`은 훈련 데이터에만, `transform()`은 훈련 및 테스트 데이터 모두에 적용해야 합니다.
*   **분포 형태:** `RobustScaler`는 이상치에 강건하지만, 데이터의 분포를 정규 분포로 만들지는 않습니다. 분포를 정규화해야 한다면 `PowerTransformer`와 같은 변환기를 추가로 고려해야 합니다.
*   **해석:** 스케일링 후 특성 값의 원래 의미를 잃을 수 있으므로, 모델 해석 시 주의가 필요합니다.


## 2. 데이터 변환 (Data Transformation)

### 2.1. 왜 데이터 변환이 필요한가?
**데이터 변환(Data Transformation)**은 특성들의 분포를 변경하거나, 특성 간의 관계를 선형화하는 등 데이터의 형태를 바꾸는 과정입니다. 이는 단순히 값의 범위를 조정하는 스케일링과는 다른 목적으로 사용되며, 모델의 성능과 안정성을 크게 향상시킬 수 있습니다.

데이터 변환이 필요한 주요 이유는 다음과 같습니다:

1.  **모델의 가정 충족:**
    *   많은 통계적 모델과 머신러닝 알고리즘(특히 선형 회귀와 같은 선형 모델)은 입력 특성들이 정규 분포를 따르거나, 특성 간에 선형 관계를 가진다는 가정을 합니다. 데이터가 이러한 가정을 충족하지 못할 경우, 모델의 성능이 저하되거나 잘못된 추론을 할 수 있습니다.
    *   데이터 변환은 특성들의 분포를 정규 분포에 가깝게 만들거나, 비선형 관계를 선형 관계로 변환하여 모델의 가정을 충족시키는 데 도움을 줍니다.

2.  **이상치(Outlier)의 영향 감소:**
    *   심하게 왜곡된 분포를 가진 데이터(예: 긴 꼬리를 가진 분포)는 극단적인 이상치를 포함하는 경우가 많습니다. 이러한 이상치는 모델 학습에 부정적인 영향을 미칠 수 있습니다.
    *   로그 변환이나 Box-Cox 변환과 같은 변환 기법은 데이터의 스케일을 압축하여 이상치의 영향을 완화하고, 데이터 분포를 더 대칭적으로 만들어 모델이 이상치에 덜 민감하게 반응하도록 돕습니다.

3.  **모델 성능 향상:**
    *   특성들의 분포를 개선하거나 선형 관계를 강화함으로써, 모델이 데이터의 패턴을 더 잘 학습하고 예측 성능을 향상시킬 수 있습니다.
    *   특히, 선형 모델은 입력 특성들이 정규 분포를 따르고 선형 관계를 가질 때 최적의 성능을 발휘하는 경향이 있습니다.

4.  **해석 가능성 향상:**
    *   일부 변환은 데이터의 해석을 더 용이하게 만들 수 있습니다. 예를 들어, 로그 변환된 데이터는 비율 변화를 더 잘 나타낼 수 있습니다.

데이터 변환은 데이터의 본질적인 정보를 유지하면서도 모델이 더 잘 학습할 수 있는 형태로 데이터를 재구성하는 강력한 도구입니다. 하지만 변환 후에는 특성 값의 원래 의미가 달라질 수 있으므로, 모델 해석 시 주의가 필요합니다.

### 2.2. 로그 변환 (Log Transformation)
**로그 변환(Log Transformation)**은 데이터가 오른쪽으로 치우쳐진(right-skewed) 분포를 가질 때, 분포를 정규 분포에 가깝게 만들거나 대칭적으로 만드는 데 사용되는 일반적인 데이터 변환 기법입니다. 또한, 극단적인 값(이상치)의 영향을 완화하는 데도 효과적입니다.

*   **수식:**
    *   $ \log(X) $: 가장 일반적인 로그 변환입니다. 데이터에 0이나 음수 값이 없을 때 사용합니다.
    *   $ \log(1+X) $: 데이터에 0이 포함되어 있을 때 사용합니다. $X$가 0이면 $\log(1)=0$이 되어 정의됩니다.
    *   로그의 밑은 10($\log_{10}$)이나 자연로그($\ln$)를 주로 사용하지만, 분포의 형태를 바꾸는 효과는 동일합니다.

*   **작동 원리:** 로그 함수는 큰 값을 압축하고 작은 값을 확장하는 특성을 가집니다. 따라서 양의 왜도(오른쪽으로 긴 꼬리)를 가진 데이터에 로그 변환을 적용하면, 큰 값들의 간격이 줄어들어 분포가 왼쪽으로 당겨지면서 더 대칭적인 형태로 변환됩니다.

*   **사용 시기:**
    *   소득, 인구, 판매량, 부동산 가격 등 양의 값을 가지며 왜곡된 분포를 보이는 데이터.
    *   이상치의 영향을 줄이고자 할 때.
    *   선형 모델의 가정을 만족시키기 위해 데이터 분포를 정규화해야 할 때.

```python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 양의 왜도(right-skewed)를 가진 가상 데이터 생성
np.random.seed(42)
# np.random.exponential은 지수 분포를 따르며, 양의 왜도를 가집니다.
original_data = np.random.exponential(scale=2, size=100)

# 로그 변환
# np.log1p(x)는 log(1+x)를 계산하여 x가 0일 때도 정의됩니다.
log_transformed_data = np.log1p(original_data) 

# 데이터 분포 시각화
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
sns.histplot(original_data, kde=True) # 원본 데이터의 히스토그램과 커널 밀도 추정(KDE) 그래프
plt.title('원본 데이터 분포 (양의 왜도)')
plt.xlabel('값')
plt.ylabel('빈도')

plt.subplot(1, 2, 2)
sns.histplot(log_transformed_data, kde=True) # 로그 변환 후 데이터의 히스토그램과 KDE 그래프
plt.title('로그 변환 후 데이터 분포')
plt.xlabel('로그 변환된 값')
plt.ylabel('빈도')

plt.tight_layout() # 그래프 간의 간격 자동 조절
plt.show()
```

**로그 변환 시 고려사항:**
*   **음수 값 처리:** 로그 함수는 0이나 음수 값에 대해 정의되지 않으므로, 데이터에 이러한 값이 포함되어 있다면 `log(1+X)`와 같은 변환을 사용하거나 다른 변환 방법을 고려해야 합니다.
*   **해석:** 로그 변환된 특성의 계수는 원래 특성 스케일에서의 변화율로 해석될 수 있습니다. 예를 들어, 로그 변환된 특성의 계수가 0.01이라면, 해당 특성이 1% 증가할 때 종속 변수가 0.01 단위로 변한다는 의미일 수 있습니다. 이는 원래 특성 스케일에서의 해석보다 복잡할 수 있습니다.

### 2.3. Box-Cox 변환 (Box-Cox Transformation)
**Box-Cox 변환**은 데이터 분포를 정규 분포에 가깝게 만드는 데 사용되는 강력한 변환 기법입니다. 이 변환은 데이터의 왜도(skewness)를 줄여 선형 모델의 가정을 만족시키고, 모델의 성능을 향상시키는 데 기여합니다. Box-Cox 변환은 최적의 람다($\lambda$) 값을 찾아 자동으로 변환을 수행합니다.

*   **수식:** Box-Cox 변환은 람다($\lambda$) 값에 따라 두 가지 형태로 정의됩니다.
    *   $ \frac{X^\lambda - 1}{\lambda} $ (if $\lambda \neq 0$)
    *   $ \log(X) $ (if $\lambda = 0$)
    여기서 $\lambda$는 데이터로부터 학습되는 파라미터이며, 일반적으로 -5에서 5 사이의 값을 가집니다. 최적의 $\lambda$ 값은 변환된 데이터의 정규성을 최대화하도록 선택됩니다.

*   **특징:**
    *   **정규성 향상:** 데이터 분포를 정규 분포에 가깝게 만듭니다.
    *   **이상치 영향 감소:** 로그 변환과 유사하게 이상치의 영향을 완화하는 효과가 있습니다.
    *   **자동 최적화:** 최적의 $\lambda$ 값을 데이터로부터 자동으로 찾아주므로, 사용자가 수동으로 변환 형태를 선택할 필요가 없습니다.

*   **사용 시기:**
    *   데이터 분포를 정규화하여 선형 모델의 가정을 만족시키고자 할 때.
    *   데이터에 왜도가 심하고, 이상치의 영향을 줄이고자 할 때.
    *   **주의:** Box-Cox 변환은 **양수 값만** 가질 때 적용할 수 있습니다. 데이터에 0이나 음수 값이 포함되어 있다면 `Yeo-Johnson` 변환(PowerTransformer에서 지원)과 같은 다른 변환을 고려해야 합니다.

```python
from scipy.stats import boxcox
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# Box-Cox 변환은 양수 데이터에만 적용 가능
# 카이제곱 분포는 양의 왜도를 가지며, 모든 값이 양수입니다. +1을 하여 0을 피합니다.
np.random.seed(42)
data_positive = np.random.chisquare(df=3, size=100) + 1 

print("원본 데이터 (Box-Cox 예시):\n", data_positive[:5]) # 상위 5개 샘플 출력

# boxcox() 함수를 사용하여 변환을 수행합니다.
# 함수는 변환된 데이터와 최적의 람다 값을 반환합니다.
transformed_data, lambda_val = boxcox(data_positive)

print(f"\nBox-Cox 변환 후 (최적 람다: {lambda_val:.2f}):\n", transformed_data[:5])

# 데이터 분포 시각화
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
sns.histplot(data_positive, kde=True)
plt.title('원본 데이터 분포 (Box-Cox)')
plt.xlabel('값')
plt.ylabel('빈도')

plt.subplot(1, 2, 2)
sns.histplot(transformed_data, kde=True)
plt.title(f'Box-Cox 변환 후 (lambda={lambda_val:.2f})')
plt.xlabel('변환된 값')
plt.ylabel('빈도')

plt.tight_layout()
plt.show()
```

**`Box-Cox 변환` 사용 시 고려사항:**
*   **양수 데이터:** 데이터에 0이나 음수 값이 있다면 적용할 수 없습니다. 이 경우 `PowerTransformer`의 `yeo-johnson` 메서드를 고려해야 합니다.
*   **해석:** 변환된 데이터는 원래 데이터의 스케일과 의미를 잃으므로, 모델 해석 시 주의가 필요합니다. 예측값을 원래 스케일로 되돌리려면 역변환을 수행해야 합니다.

### 2.4. `QuantileTransformer` 및 `PowerTransformer`
Scikit-learn은 데이터 분포를 정규 분포에 가깝게 만들거나, 특정 범위로 변환하는 다양한 변환기를 제공합니다. 이들은 데이터의 비선형적인 변환을 통해 모델의 성능을 향상시키는 데 기여합니다.

*   **`QuantileTransformer`:**
    *   **작동 원리:** 데이터를 분위수(quantile)에 따라 변환하여 균등 분포(uniform distribution) 또는 정규 분포(normal distribution)로 만듭니다. 이는 데이터의 순위를 기반으로 변환을 수행하므로, 이상치에 매우 강건합니다.
    *   **`output_distribution`:**
        *   `'uniform'` (기본값): 데이터를 0과 1 사이의 균등 분포로 변환합니다.
        *   `'normal'`: 데이터를 평균 0, 표준편차 1의 정규 분포로 변환합니다.
    *   **사용 시기:** 데이터에 이상치가 많거나, 분포가 매우 비대칭적일 때, 또는 특정 분포(균등/정규)를 따르도록 강제해야 할 때 유용합니다.

*   **`PowerTransformer`:**
    *   **작동 원리:** 데이터 분포를 정규 분포에 가깝게 만드는 거듭제곱 변환(Power Transformation)을 적용합니다. Box-Cox 변환과 Yeo-Johnson 변환 두 가지 방법을 포함합니다.
    *   **`method`:**
        *   `'box-cox'`: 양수 값만 가지는 데이터에 적용 가능합니다. 최적의 람다($\lambda$) 값을 찾아 변환합니다.
        *   `'yeo-johnson'`: 음수 값을 포함하는 데이터에도 적용 가능합니다. Box-Cox 변환의 일반화된 형태입니다.
    *   **사용 시기:** 데이터 분포를 정규화하여 선형 모델의 가정을 만족시키고자 할 때, 또는 이상치의 영향을 줄이고자 할 때 사용합니다. `Box-Cox`는 양수 데이터에, `Yeo-Johnson`은 음수 데이터에도 적용 가능하므로 더 범용적입니다.

```python
from sklearn.preprocessing import QuantileTransformer, PowerTransformer
import numpy as np

# 가상 데이터 (이상치 포함 및 왜도 가짐)
# 이 데이터는 양의 왜도를 가지며, 큰 이상치(1000)를 포함합니다.
data_skewed = np.array([1, 2, 3, 4, 5, 10, 20, 50, 100, 1000]).reshape(-1, 1)

print("원본 데이터 (왜도 및 이상치 포함):\n", data_skewed.flatten())

# QuantileTransformer (정규 분포 출력)
# 데이터를 분위수에 따라 정규 분포로 변환합니다. 이상치에 강건합니다.
qt = QuantileTransformer(output_distribution='normal', random_state=42)
data_qt = qt.fit_transform(data_skewed)
print("\nQuantileTransformer (normal) 적용 후:\n", data_qt.flatten())

# PowerTransformer (Yeo-Johnson)
# 데이터 분포를 정규 분포에 가깝게 만듭니다. 음수 값에도 적용 가능합니다.
pt = PowerTransformer(method='yeo-johnson') 
data_pt = pt.fit_transform(data_skewed)
print("\nPowerTransformer (Yeo-Johnson) 적용 후:\n", data_pt.flatten())

**`QuantileTransformer` 및 `PowerTransformer` 사용 시 고려사항:**
*   **데이터 누수 방지:** 다른 스케일러/변환기와 동일하게 `fit()`은 훈련 데이터에만, `transform()`은 훈련 및 테스트 데이터 모두에 적용해야 합니다.
*   **해석:** 변환된 데이터는 원래 데이터의 스케일과 의미를 잃으므로, 모델 해석 시 주의가 필요합니다. 예측값을 원래 스케일로 되돌리려면 역변환(`inverse_transform`)을 수행해야 합니다.
*   **선택:** 데이터의 특성(양수/음수 포함 여부, 이상치 존재 여부, 왜도 정도)과 모델의 요구사항에 따라 적절한 변환기를 선택해야 합니다. `QuantileTransformer`는 이상치에 강건하며 특정 분포로 강제하는 반면, `PowerTransformer`는 데이터의 원래 순서를 유지하면서 정규성에 가깝게 만듭니다.


## 3. 결론: 스케일링 및 변환 시 고려사항

데이터 스케일링과 변환은 머신러닝 모델의 성능과 안정성을 크게 좌우하는 중요한 전처리 단계입니다. 이러한 과정에서 다음과 같은 핵심 사항들을 고려해야 합니다.

*   **알고리즘의 특성:**
    *   **거리 기반 모델 (KNN, SVM, K-Means 등):** 특성 간의 거리를 계산하므로, 스케일링이 **필수적**입니다. 스케일이 큰 특성이 모델에 지배적인 영향을 미 미치지 않도록 모든 특성을 동일한 스케일로 맞춰야 합니다.
    *   **경사 하강법 기반 모델 (선형 회귀, 로지스틱 회귀, 신경망 등):** 손실 함수의 최적화 과정에서 스케일링이 **필수적**입니다. 스케일링을 통해 손실 함수의 형태를 더 원형에 가깝게 만들어 경사 하강법이 더 빠르고 안정적으로 수렴하도록 돕습니다.
    *   **트리 기반 모델 (의사결정 트리, 랜덤 포레스트, 부스팅 모델 등):** 스케일링에 **덜 민감**합니다. 이들은 특성의 절대적인 값보다는 순위나 상대적인 관계를 기반으로 분할하기 때문입니다. 하지만 일부 앙상블 모델의 경우 스케일링이 성능 향상에 도움이 될 수도 있습니다.
    *   **선형 모델:** 특성들이 정규 분포를 따르거나 선형 관계를 가질 때 더 좋은 성능을 보일 수 있으므로, 데이터 변환을 고려할 수 있습니다.

*   **데이터 분포:**
    *   데이터의 **왜도(Skewness)**, **이상치(Outlier)** 존재 여부에 따라 적절한 스케일러나 변환기를 선택해야 합니다.
    *   **이상치가 적고 정규 분포에 가까운 데이터:** `StandardScaler`가 적합합니다.
    *   **이상치가 적고 고정된 범위가 필요한 데이터:** `MinMaxScaler`가 적합합니다.
    *   **이상치가 많은 데이터:** `RobustScaler`가 이상치에 강건하므로 더 적합합니다.
    *   **심하게 왜곡된 데이터:** `로그 변환`, `Box-Cox 변환`, `PowerTransformer` 등을 사용하여 분포를 정규화하거나 대칭적으로 만들 수 있습니다.

*   **데이터 누수 방지 (Data Leakage Prevention):**
    *   가장 중요한 고려사항 중 하나입니다. 스케일링이나 변환을 위한 통계량(평균, 표준편차, 최솟값, 최댓값 등)은 **오직 훈련 데이터에서만** 학습되어야 합니다.
    *   훈련 데이터에 `fit_transform()`을 적용하고, 테스트 데이터나 새로운 데이터에는 훈련 데이터로 `fit`된 변환기 객체의 `transform()` 메서드만 적용해야 합니다.
    *   Scikit-learn의 `Pipeline`을 활용하면 이러한 데이터 누수 문제를 자동으로 방지하고, 전처리 단계를 모델 학습 과정에 통합하여 코드의 재현성과 안정성을 높일 수 있습니다.

*   **도메인 지식:**
    *   어떤 스케일링이나 변환이 데이터의 의미를 왜곡하지 않고 모델 성능에 도움이 될지 판단하기 위해 **도메인 지식(Domain Knowledge)**을 활용하는 것이 중요합니다.
    *   예를 들어, 특정 특성의 0 값이 특별한 의미를 가지는 경우(`MinMaxScaler`로 0-1 스케일링 시 0의 의미가 유지됨)나, 로그 변환이 비즈니스적으로 타당한 해석을 제공하는지 등을 고려해야 합니다.

데이터 스케일링과 변환은 머신러닝 모델의 성능을 최적화하고, 모델의 안정성과 해석 가능성을 높이는 데 필수적인 과정입니다. 데이터의 특성과 모델의 요구사항을 종합적으로 고려하여 가장 적절한 전처리 전략을 선택하는 것이 중요합니다.
