## 1. 선형 회귀와 과적합의 문제

### 1.1. 선형 회귀 (Linear Regression)
선형 회귀는 입력 특성(독립 변수)과 타겟 변수(종속 변수) 간의 선형적인 관계를 가정하고, 이 관계를 가장 잘 나타내는 직선(또는 초평면)을 찾는 알고리즘입니다. 모델이 단순하고 해석이 용이하여 회귀 문제의 베이스라인 모델로 널리 사용됩니다.

**수학적 표현:**
선형 회귀 모델은 다음과 같은 형태로 표현됩니다:

$ \hat{y} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \dots + \beta_n x_n $

여기서:
*   $ \hat{y} $는 예측된 타겟 값입니다.
*   $ \beta_0 $는 절편(intercept)입니다.
*   $ \beta_1, \beta_2, \dots, \beta_n $는 각 특성 $ x_1, x_2, \dots, x_n $에 대한 회귀 계수(coefficients)입니다. 이 계수들은 각 특성이 타겟 값에 미치는 영향의 크기와 방향을 나타냅니다.

**최소 제곱법 (Ordinary Least Squares, OLS):**
선형 회귀 모델은 예측값과 실제 타겟 값 사이의 **잔차(Residual)** 제곱합을 최소화하는 방식으로 최적의 회귀 계수($\beta$)를 찾습니다. 이 방법을 **최소 제곱법(Ordinary Least Squares, OLS)**이라고 합니다. OLS는 다음과 같은 손실 함수(Cost Function)를 최소화합니다:

$ J(\beta) = \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{m} (y_i - (\beta_0 + \beta_1 x_{i1} + \dots + \beta_n x_{in}))^2 $

여기서 $m$은 데이터 샘플의 개수입니다. 이 손실 함수를 최소화하는 $ \beta $ 값들을 찾는 것이 선형 회귀의 목표입니다.

### 1.2. 과적합과 규제의 필요성
선형 회귀 모델은 다음과 같은 경우에 훈련 데이터에만 과도하게 최적화되는 **과적합(Overfitting)** 현상이 발생하기 쉽습니다. 과적합된 모델은 훈련 데이터에 대해서는 높은 성능을 보이지만, 새로운 데이터(테스트 데이터)에 대해서는 예측 성능이 급격히 떨어집니다.

*   **과적합의 주요 원인:**
    *   **특성의 수가 너무 많을 때:** 모델이 너무 많은 특성을 사용하여 훈련 데이터의 노이즈까지 학습하게 됩니다.
    *   **특성 간의 상관관계(다중공선성)가 높을 때:** 서로 강하게 연관된 특성들이 모델의 계수를 불안정하게 만들 수 있습니다.
    *   **모델의 복잡도가 높을 때:** 예를 들어, 다항 회귀에서 너무 높은 차수의 다항식을 사용할 경우, 모델이 훈련 데이터의 미세한 변동까지 포착하려 하여 과적합됩니다.
    *   **훈련 데이터의 양이 부족할 때:** 모델이 충분히 다양한 데이터를 학습하지 못하여 특정 패턴에만 과도하게 맞춰질 수 있습니다.

**규제(Regularization)**는 이러한 과적합을 해결하기 위한 핵심 기법입니다. 선형 회귀 모델에서 규제는 모델의 **회귀 계수(coefficients)** 크기에 페널티를 부과하여 모델의 복잡도를 낮추고, 훈련 데이터에 대한 과도한 최적화를 방지합니다. 이를 통해 모델의 일반화 성능을 높일 수 있습니다.

**규제의 작동 원리:**
규제는 선형 회귀의 손실 함수(OLS의 잔차 제곱합)에 **규제항(Regularization Term)**을 추가하는 방식으로 작동합니다. 이 규제항은 회귀 계수($\beta$)의 크기가 커지는 것을 억제하여, 모델이 특정 특성에 과도하게 의존하는 것을 방지합니다. 결과적으로 계수들의 값이 작아지거나 일부는 0이 되어 모델이 더 단순해지고 일반화 성능이 향상됩니다.

## 2. 릿지 회귀 (Ridge Regression): L2 규제

### 2.1. 핵심 개념
릿지 회귀는 기본 선형 회귀의 비용 함수(Cost Function)에 **L2 규제항**을 추가한 모델입니다. L2 규제는 모든 회귀 계수의 **제곱합**을 최소화하는 방향으로 작동합니다.

**비용 함수:**
릿지 회귀의 비용 함수는 다음과 같습니다:

$ J(\beta) = \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^{n} \beta_j^2 $

여기서:
*   $ \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 $는 일반 선형 회귀의 잔차 제곱합(RSS)입니다.
*   $ \alpha \sum_{j=1}^{n} \beta_j^2 $는 L2 규제항입니다.
    *   $ \alpha $ (알파)는 규제의 강도를 조절하는 하이퍼파라미터입니다. $ \alpha \ge 0 $.
    *   $ \sum_{j=1}^{n} \beta_j^2 $는 모든 회귀 계수($\beta_j$)의 제곱합입니다. 절편($\beta_0$)은 규제 대상에서 제외됩니다.

**효과:**
*   L2 규제는 회귀 계수의 크기를 전반적으로 작게 만들어 모델을 더 안정적으로 만듭니다.
*   계수를 0에 가깝게 만들지만, 완전히 0으로 만들지는 않습니다. 즉, 모든 특성이 모델에 기여하지만 그 영향력이 줄어듭니다.
*   **장점:** 다중공선성(Multicollinearity) 문제가 있는 경우에도 비교적 안정적인 성능을 보입니다. 이는 서로 상관관계가 높은 특성들이 있을 때, L2 규제가 계수들을 고르게 축소시켜 모델의 분산을 줄이기 때문입니다.

### 2.2. 주요 하이퍼파라미터
*   `alpha`: 규제의 강도를 조절하는 하이퍼파라미터입니다. `alpha` 값은 0보다 크거나 같아야 합니다.
    *   `alpha`가 **클수록**:
        *   규제의 강도가 강해져 회귀 계수들이 0에 더 가깝게 축소됩니다.
        *   모델의 복잡도가 감소하고, 훈련 데이터에 대한 적합도가 낮아져 **과소적합(Underfitting)** 방향으로 갈 수 있습니다.
        *   모델의 분산(Variance)이 감소하고 편향(Bias)이 증가합니다.
    *   `alpha`가 **작을수록**:
        *   규제의 강도가 약해져 회귀 계수들이 0에 덜 가깝게 축소됩니다.
        *   `alpha`가 0에 가까워지면 일반 선형 회귀와 유사해지며, **과적합(Overfitting)** 위험이 증가할 수 있습니다.
        *   모델의 분산이 증가하고 편향이 감소합니다.

**하이퍼파라미터 튜닝:**
`alpha` 값은 모델의 성능에 큰 영향을 미치므로, `GridSearchCV`나 `RandomizedSearchCV`와 같은 교차 검증(Cross-validation) 기법을 사용하여 최적의 `alpha` 값을 찾는 것이 중요합니다.

## 3. 라쏘 회귀 (Lasso Regression): L1 규제

### 3.1. 핵심 개념과 특성 선택
라쏘 회귀는 기본 선형 회귀의 비용 함수에 **L1 규제항**을 추가한 모델입니다. L1 규제는 모든 회귀 계수의 **절대값 합**을 최소화하는 방향으로 작동합니다.

**비용 함수:**
라쏘 회귀의 비용 함수는 다음과 같습니다:

$ J(\beta) = \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^{n} |\beta_j| $

여기서:
*   $ \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 $는 일반 선형 회귀의 잔차 제곱합(RSS)입니다.
*   $ \alpha \sum_{j=1}^{n} |\beta_j| $는 L1 규제항입니다.
    *   $ \alpha $ (알파)는 규제의 강도를 조절하는 하이퍼파라미터입니다. $ \alpha \ge 0 $.
    *   $ \sum_{j=1}^{n} |\beta_j| $는 모든 회귀 계수($\beta_j$)의 절대값 합입니다.

**효과: 특성 선택 (Feature Selection)**
*   L1 규제의 가장 큰 특징은 중요하지 않은 특성의 회귀 계수를 **완전히 0으로** 만들어 버린다는 점입니다. 이는 모델의 예측에 큰 영향을 주지 않는 불필요한 특성을 자동으로 제거하는 효과를 가져옵니다.
*   **왜 0이 되는가?** L1 규제는 기하학적으로 계수 공간에서 마름모 형태의 제약 조건을 만듭니다. 손실 함수의 등고선이 이 마름모의 꼭짓점(축에 닿는 부분)에서 처음으로 접할 가능성이 높기 때문에, 해당 축에 해당하는 계수가 0이 되는 경향이 있습니다.
*   **장점:**
    *   모델을 더 단순하고 해석하기 쉽게 만듭니다. (모델의 희소성 증가)
    *   불필요한 특성으로 인한 과적합을 방지하고 모델의 일반화 성능을 향상시킵니다.
    *   특히 특성의 수가 매우 많을 때 유용합니다.

### 3.2. 주요 하이퍼파라미터
*   `alpha`: 규제의 강도를 조절하는 하이퍼파라미터입니다. `alpha` 값은 0보다 크거나 같아야 합니다.
    *   `alpha`가 **클수록**:
        *   규제의 강도가 강해져 더 많은 회귀 계수들이 0이 됩니다.
        *   모델의 희소성(Sparsity)이 증가하고, 불필요한 특성들이 제거됩니다.
        *   지나치게 크면 중요한 특성마저 0이 되어 과소적합될 수 있습니다.
    *   `alpha`가 **작을수록**:
        *   규제의 강도가 약해져 0이 되는 계수의 수가 줄어듭니다.
        *   `alpha`가 0에 가까워지면 일반 선형 회귀와 유사해지며, 특성 선택 효과가 줄어듭니다.

**하이퍼파라미터 튜닝:**
`alpha` 값은 라쏘 회귀의 특성 선택 능력과 모델의 성능에 직접적인 영향을 미치므로, `GridSearchCV`나 `RandomizedSearchCV`와 같은 교차 검증 기법을 사용하여 최적의 `alpha` 값을 찾는 것이 중요합니다.

## 4. 엘라스틱넷 회귀 (ElasticNet Regression): L1과 L2의 결합
엘라스틱넷 회귀는 릿지(L2)와 라쏘(L1) 규제를 모두 결합한 모델입니다. 릿지의 안정성(다중공선성 처리)과 라쏘의 특성 선택 능력(계수를 0으로 만듦)을 모두 활용할 수 있어, 특성 간에 높은 상관관계가 있는 데이터셋에서 특히 좋은 성능을 보입니다.

**비용 함수:**
엘라스틱넷 회귀의 비용 함수는 다음과 같습니다:

$ J(\beta) = \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 + \alpha \rho \sum_{j=1}^{n} |\beta_j| + \frac{1}{2} \alpha (1 - \rho) \sum_{j=1}^{n} \beta_j^2 $

여기서:
*   $ \sum_{i=1}^{m} (y_i - \hat{y}_i)^2 $는 일반 선형 회귀의 잔차 제곱합(RSS)입니다.
*   $ \alpha \rho \sum_{j=1}^{n} |\beta_j| $는 L1 규제항입니다.
*   $ \frac{1}{2} \alpha (1 - \rho) \sum_{j=1}^{n} \beta_j^2 $는 L2 규제항입니다.
    *   $ \alpha $ (알파)는 전체 규제의 강도를 조절하는 하이퍼파라미터입니다. $ \alpha \ge 0 $.
    *   $ \rho $ (로, `l1_ratio`에 해당)는 L1 규제와 L2 규제의 비율을 조절하는 하이퍼파라미터입니다. $ 0 \le \rho \le 1 $.

**주요 하이퍼파라미터:**
*   `alpha`: 전체 규제의 강도를 조절합니다.
    *   `alpha`가 클수록 전체적인 규제가 강해집니다.
    *   `alpha`가 0이면 규제가 없는 일반 선형 회귀와 동일합니다.
*   `l1_ratio` (`rho`): L1 규제와 L2 규제의 혼합 비율을 조절합니다.
    *   `l1_ratio = 0`: L2 규제만 적용되어 릿지 회귀와 동일합니다.
    *   `l1_ratio = 1`: L1 규제만 적용되어 라쏘 회귀와 동일합니다.
    *   `0 < l1_ratio < 1`: L1과 L2 규제가 혼합되어 적용됩니다.

**엘라스틱넷의 장점:**
*   **다중공선성 처리:** 라쏘 회귀는 상관관계가 높은 특성들 중 하나만 선택하고 나머지는 계수를 0으로 만들 수 있습니다. 반면 엘라스틱넷은 이러한 특성들을 함께 유지하면서 계수를 축소시킬 수 있어, 다중공선성 문제에 더 강건합니다.
*   **특성 선택과 계수 축소:** 라쏘의 특성 선택 능력과 릿지의 계수 축소 및 안정화 능력을 모두 가집니다.
*   **다양한 시나리오 적용:** 특성 수가 많고 특성 간 상관관계가 높은 복잡한 데이터셋에서 특히 유용합니다.

**하이퍼파라미터 튜닝:**
`alpha`와 `l1_ratio` 두 가지 하이퍼파라미터를 동시에 튜닝해야 하므로, `GridSearchCV`나 `RandomizedSearchCV`를 사용하여 최적의 조합을 찾는 것이 일반적입니다.

## 5. 서포트 벡터 회귀 (Support Vector Regression, SVR)

### 5.1. 핵심 개념
SVR은 분류 문제의 SVM(Support Vector Machine)과 유사하게 **마진(Margin)** 개념을 회귀 문제에 적용한 모델입니다. SVM이 클래스 간의 경계선을 찾는다면, SVR은 예측값과 실제값 사이의 오차가 특정 허용 범위($\epsilon$) 내에 있는 데이터 포인트에 대해서는 페널티를 부과하지 않고, 이 허용 범위를 벗어나는 오차에 대해서만 페널티를 부과하여 모델을 학습합니다. 이를 통해 이상치에 강건한(robust) 모델을 만들 수 있습니다.

**$\epsilon$-insensitive tube ($\epsilon$-튜브):**
SVR의 핵심 아이디어는 예측 함수 주변에 폭이 $2\epsilon$인 **$\epsilon$-튜브**를 설정하는 것입니다. 이 튜브 안에 들어오는 데이터 포인트에 대해서는 오차를 0으로 간주하여 페널티를 주지 않습니다. 즉, 모델은 튜브 안에 가능한 한 많은 데이터 포인트를 포함하면서도 튜브 바깥에 있는 데이터 포인트에 대해서는 최소한의 페널티를 부과하도록 학습됩니다.

**슬랙 변수 (Slack Variables):**
튜브 바깥에 있는 데이터 포인트에 대해서는 슬랙 변수($\xi, \xi^*$)를 도입하여 튜브를 벗어난 정도에 비례하는 페널티를 부과합니다. 이 페널티는 비용 함수에 포함되며, `C` 하이퍼파라미터에 의해 그 중요도가 조절됩니다.

**서포트 벡터 (Support Vectors):**
튜브 경계선에 있거나 튜브 바깥에 있는 데이터 포인트들을 **서포트 벡터**라고 합니다. 이 서포트 벡터들만이 모델의 결정 함수를 정의하는 데 사용되며, 나머지 튜브 안의 데이터 포인트들은 모델 학습에 직접적인 영향을 미치지 않습니다.

*   **커널 트릭(Kernel Trick):** 분류 SVM과 마찬가지로 커널 트릭을 사용하여 비선형적인 관계를 학습할 수 있습니다. 이를 통해 선형 모델로는 해결하기 어려운 복잡한 비선형 회귀 문제도 해결할 수 있습니다.
*   **장점:** 
    *   **이상치에 강건합니다:** $\epsilon$-튜브 덕분에 작은 오차나 이상치에 덜 민감합니다.
    *   **비선형적인 관계를 잘 모델링할 수 있습니다:** 커널 트릭을 통해 복잡한 비선형 패턴을 학습할 수 있습니다.
    *   **고차원 데이터에서도 효과적입니다:** 차원의 저주에 비교적 덜 민감합니다.
*   **단점:** 
    *   **대규모 데이터셋에서는 학습 속도가 느릴 수 있습니다:** 특히 비선형 커널을 사용할 경우 계산 비용이 높습니다.
    *   **하이퍼파라미터 설정에 민감합니다:** `C`, `epsilon`, `gamma` 등 여러 하이퍼파라미터의 조합에 따라 성능이 크게 달라질 수 있습니다.

### 5.2. 주요 하이퍼파라미터
SVR의 성능은 하이퍼파라미터 설정에 매우 민감하므로, 교차 검증을 통해 최적의 조합을 찾는 것이 중요합니다.

*   `kernel`: 사용할 커널 함수를 지정합니다. 데이터의 특성과 비선형성에 따라 적절한 커널을 선택해야 합니다.
    *   `'linear'`: 선형 커널. 데이터가 선형적으로 분리 가능할 때 사용합니다.
    *   `'poly'`: 다항식 커널. `degree` 파라미터로 다항식의 차수를 조절합니다.
    *   `'rbf'` (Radial Basis Function, 가우시안 커널): 기본값. 비선형 관계를 모델링하는 데 가장 널리 사용됩니다. `gamma` 파라미터와 함께 사용됩니다.
    *   `'sigmoid'`: 시그모이드 커널.

*   `C`: 규제(Regularization)의 강도를 조절하는 하이퍼파라미터입니다. 오차에 대한 페널티 강도를 결정합니다.
    *   `C`가 **클수록**:
        *   모델이 훈련 데이터의 오차에 더 민감하게 반응하여 페널티를 강하게 부과합니다.
        *   훈련 데이터에 더 잘 맞추려 노력하므로, 과적합될 가능성이 높아집니다.
    *   `C`가 **작을수록**:
        *   모델이 훈련 데이터의 오차에 덜 민감하게 반응하여 페널티를 약하게 부과합니다.
        *   더 많은 데이터 포인트가 $\epsilon$-튜브 바깥에 허용될 수 있으며, 모델이 단순해져 과소적합될 수 있습니다.

*   `epsilon` (eps): $\epsilon$-튜브의 폭을 결정하는 하이퍼파라미터입니다. 이 범위 내의 오차는 페널티를 받지 않습니다.
    *   `epsilon`이 **클수록**:
        *   더 넓은 튜브를 허용하므로, 더 많은 데이터 포인트가 튜브 안에 포함되어 페널티를 받지 않습니다.
        *   모델이 단순해지고, 이상치에 더 강건해지지만, 과소적합될 수 있습니다.
    *   `epsilon`이 **작을수록**:
        *   더 좁은 튜브를 허용하므로, 더 많은 데이터 포인트가 페널티를 받게 됩니다.
        *   모델이 훈련 데이터에 더 민감하게 반응하여 과적합될 수 있습니다.

*   `gamma`: `'rbf'`, `'poly'`, `'sigmoid'` 커널에서 사용되는 파라미터로, 하나의 훈련 데이터 샘플이 미치는 영향의 범위를 결정합니다.
    *   `gamma`가 **클수록**:
        *   하나의 샘플이 미치는 영향 범위가 좁아져, 모델이 훈련 데이터에 더 복잡하게 맞춰집니다.
        *   과적합될 가능성이 높아집니다.
    *   `gamma`가 **작을수록**:
        *   하나의 샘플이 미치는 영향 범위가 넓어져, 모델이 더 일반화됩니다.
        *   과소적합될 가능성이 높아집니다.
    *   `'scale'` (기본값): `1 / (n_features * X.var())`로 설정됩니다.
    *   `'auto'`: `1 / n_features`로 설정됩니다.

**하이퍼파라미터 튜닝:**
SVR은 `C`, `epsilon`, `gamma` 등 여러 하이퍼파라미터의 조합에 따라 성능이 크게 달라질 수 있으므로, `GridSearchCV`나 `RandomizedSearchCV`와 같은 교차 검증 기법을 사용하여 최적의 하이퍼파라미터 조합을 찾는 것이 매우 중요합니다.

## 6. 실습: 캘리포니아 주택 가격 예측

### 6.1. 데이터 준비 및 파이프라인 구성
규제 모델은 특성의 스케일에 영향을 받으므로, `StandardScaler`를 사용한 데이터 스케일링을 파이프라인에 포함하는 것이 매우 중요합니다. SVR 또한 스케일링에 민감합니다.

```python
from sklearn.datasets import fetch_california_housing # 캘리포니아 주택 가격 데이터셋 로드
from sklearn.model_selection import train_test_split # 데이터 분할
from sklearn.preprocessing import StandardScaler # 특성 스케일링
from sklearn.linear_model import LinearRegression, Ridge, Lasso, ElasticNet # 선형 회귀 모델들
from sklearn.svm import SVR # 서포트 벡터 회귀
from sklearn.pipeline import Pipeline # 파이프라인 구성
from sklearn.metrics import mean_squared_error # 모델 평가 지표 (MSE)
import matplotlib.pyplot as plt # 시각화
import seaborn as sns # 시각화
import numpy as np # 수치 연산

# 1. 데이터 로드 및 분할
# fetch_california_housing() 함수는 캘리포니아 주택 가격 데이터셋을 로드합니다.
housing = fetch_california_housing()
X, y = housing.data, housing.target

print(f"데이터셋 형태 (X): {X.shape}")
print(f"타겟 변수 형태 (y): {y.shape}")

# 훈련 세트와 테스트 세트로 데이터를 분할합니다.
# test_size=0.3: 전체 데이터의 30%를 테스트 세트로 사용합니다.
# random_state=42: 재현성을 위한 난수 시드입니다.
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

print(f"\n훈련 세트 형태: {X_train.shape}, {y_train.shape}")
print(f"테스트 세트 형태: {X_test.shape}, {y_test.shape}")

# 2. 파이프라인 생성 (스케일링 -> 모델)
# 모든 모델에 대해 StandardScaler를 적용하는 파이프라인을 구성합니다.
# 규제 모델과 SVR은 특성 스케일에 민감하므로 스케일링이 필수적입니다.
pipe_lr = Pipeline([('scaler', StandardScaler()), ('model', LinearRegression())])
pipe_ridge = Pipeline([('scaler', StandardScaler()), ('model', Ridge(alpha=1.0, random_state=42))])
pipe_lasso = Pipeline([('scaler', StandardScaler()), ('model', Lasso(alpha=0.01, random_state=42))]) # alpha 값 조정
pipe_elastic = Pipeline([('scaler', StandardScaler()), ('model', ElasticNet(alpha=0.01, l1_ratio=0.5, random_state=42))]) # alpha 값 조정
pipe_svr = Pipeline([('scaler', StandardScaler()), ('model', SVR(kernel='rbf', C=100, gamma=0.1))]) # SVR 파이프라인

print("\n모델 파이프라인 구성 완료.")
```


### 6.2. 모델별 성능 비교

```python
# 3. 모델 학습
print("모델 학습 시작...")
pipe_lr.fit(X_train, y_train)
pipe_ridge.fit(X_train, y_train)
pipe_lasso.fit(X_train, y_train)
pipe_elastic.fit(X_train, y_train)
pipe_svr.fit(X_train, y_train) # SVR 학습
print("모델 학습 완료.")

# 4. 예측 수행
y_pred_lr = pipe_lr.predict(X_test)
y_pred_ridge = pipe_ridge.predict(X_test)
y_pred_lasso = pipe_lasso.predict(X_test)
y_pred_elastic = pipe_elastic.predict(X_test)
y_pred_svr = pipe_svr.predict(X_test) # SVR 예측

# 5. MSE 평가
mse_lr = mean_squared_error(y_test, y_pred_lr)
mse_ridge = mean_squared_error(y_test, y_pred_ridge)
mse_lasso = mean_squared_error(y_test, y_pred_lasso)
mse_elastic = mean_squared_error(y_test, y_pred_elastic)
mse_svr = mean_squared_error(y_test, y_pred_svr) # SVR 결과 출력

print(f"\n선형 회귀 MSE: {mse_lr:.4f}")
print(f"릿지 회귀 MSE: {mse_ridge:.4f}")
print(f"라쏘 회귀 MSE: {mse_lasso:.4f}")
print(f"엘라스틱넷 회귀 MSE: {mse_elastic:.4f}")
print(f"SVR MSE: {mse_svr:.4f}") # SVR 결과 출력

# 6. 라쏘 회귀의 계수 확인 (특성 선택 효과)
# 라쏘 모델에서 학습된 회귀 계수를 추출합니다.
lasso_coef = pipe_lasso.named_steps['model'].coef_
print(f"\n라쏘 회귀의 계수 (0이 된 특성 수: {sum(lasso_coef == 0)} / {len(lasso_coef)})")

# 특성 이름 가져오기
feature_names = housing.feature_names

# 라쏘 계수 시각화
plt.figure(figsize=(10, 7))
sns.barplot(x=lasso_coef, y=feature_names)
plt.title('라쏘 회귀 계수 (특성 중요도 및 선택)')
plt.xlabel('계수 값')
plt.ylabel('특성 이름')
plt.axvline(x=0, color='gray', linestyle='--', linewidth=0.8) # 0 기준선 추가
plt.tight_layout()
plt.show()

# 7. 모델별 예측 시각화 (선택적)
# 실제 값과 예측 값 비교 시각화 (일부 샘플만)
plt.figure(figsize=(12, 6))
plt.scatter(y_test, y_pred_lr, alpha=0.5, label='Linear Regression')
plt.scatter(y_test, y_pred_ridge, alpha=0.5, label='Ridge Regression')
plt.scatter(y_test, y_pred_lasso, alpha=0.5, label='Lasso Regression')
plt.scatter(y_test, y_pred_elastic, alpha=0.5, label='ElasticNet Regression')
plt.scatter(y_test, y_pred_svr, alpha=0.5, label='SVR')
plt.plot([y_test.min(), y_test.max()], [y_test.min(), y_test.max()], 'k--', lw=2, label='Ideal Prediction')
plt.xlabel('실제 값')
plt.ylabel('예측 값')
plt.title('모델별 실제 값 vs 예측 값')
plt.legend()
plt.grid(True)
plt.show()
```

**실습 결과 해석:**
*   **MSE 비교:** 각 모델의 MSE 값을 비교하여 예측 성능을 평가합니다. 일반적으로 규제 모델(릿지, 라쏘, 엘라스틱넷)은 선형 회귀보다 낮은 MSE를 보여 과적합이 줄어들고 일반화 성능이 향상되었음을 알 수 있습니다. SVR은 비선형 관계를 잘 포착하여 선형 모델보다 더 좋은 성능을 보일 수 있습니다.
*   **규제의 효과:**
    *   **릿지 회귀:** 모든 특성의 계수를 0에 가깝게 축소시켜 모델의 안정성을 높입니다. MSE가 선형 회귀보다 낮아졌다면, 이는 L2 규제가 과적합을 효과적으로 제어했음을 의미합니다.
    *   **라쏘 회귀:** 불필요한 특성의 계수를 완전히 0으로 만들어 특성 선택 효과를 보여줍니다. 시각화된 라쏘 계수에서 0이 된 특성들을 확인할 수 있습니다. 이는 모델을 더 간결하게 만들고 해석력을 높이는 데 기여합니다.
    *   **엘라스틱넷 회귀:** 릿지와 라쏘의 장점을 결합하여, 다중공선성이 있는 상황에서도 안정적인 특성 선택을 수행합니다. MSE가 라쏘나 릿지보다 더 낮을 수도 있습니다.
*   **SVR의 성능:** SVR은 커널 트릭을 통해 비선형 관계를 모델링할 수 있으므로, 데이터에 비선형성이 강하게 존재한다면 선형 모델들보다 우수한 성능을 보일 수 있습니다. MSE 값을 통해 SVR의 성능을 다른 선형 모델들과 비교할 수 있습니다.
*   **계수 시각화:** 라쏘 회귀의 계수 시각화는 어떤 특성들이 모델에서 중요하게 작용하고, 어떤 특성들이 제거되었는지 직관적으로 보여줍니다. 이는 모델 해석에 매우 유용합니다.

이 실습을 통해 선형 회귀의 한계와 규제 모델들이 이를 어떻게 극복하는지, 그리고 SVR이 비선형 회귀 문제에 어떻게 접근하는지 이해할 수 있습니다. 실제 문제에서는 데이터의 특성과 목표에 따라 적절한 모델과 하이퍼파라미터를 선택하는 것이 중요합니다.

```python
# 모델 학습
pipe_lr.fit(X_train, y_train)
pipe_ridge.fit(X_train, y_train)
pipe_lasso.fit(X_train, y_train)
pipe_elastic.fit(X_train, y_train)
pipe_svr.fit(X_train, y_train) # SVR 학습

# 예측
y_pred_lr = pipe_lr.predict(X_test)
y_pred_ridge = pipe_ridge.predict(X_test)
y_pred_lasso = pipe_lasso.predict(X_test)
y_pred_elastic = pipe_elastic.predict(X_test)

# MSE 평가
mse_lr = mean_squared_error(y_test, y_pred_lr)
mse_ridge = mean_squared_error(y_test, y_pred_ridge)
mse_lasso = mean_squared_error(y_test, y_pred_lasso)
mse_elastic = mean_squared_error(y_test, y_pred_elastic)
mse_svr = mean_squared_error(y_test, y_pred_svr) # SVR MSE

print(f"선형 회귀 MSE: {mse_lr:.4f}")
print(f"릿지 회귀 MSE: {mse_ridge:.4f}")
print(f"라쏘 회귀 MSE: {mse_lasso:.4f}")
print(f"엘라스틱넷 회귀 MSE: {mse_elastic:.4f}")
print(f"SVR MSE: {mse_svr:.4f}") # SVR 결과 출력

# 라쏘 회귀의 계수 확인 (특성 선택 효과)
lasso_coef = pipe_lasso.named_steps['model'].coef_
print(f"\n라쏘 회귀의 계수 (0이 된 특성 수: {sum(lasso_coef == 0)} / {len(lasso_coef)})")
```

## 7. 어떤 회귀 모델을 선택해야 할까?

회귀 모델을 선택할 때는 데이터의 특성, 문제의 목표, 모델의 해석 가능성 요구 사항 등 여러 요소를 고려해야 합니다. 아래 표는 각 모델의 주요 특징과 사용 추천 상황을 요약한 것입니다.

| 모델 | 주요 특징 | 사용 추천 상황 |
| :--- | :--- | :--- |
| **선형 회귀** | 규제 없음, 단순하고 해석 용이 | 베이스라인 모델, 특성이 적고 과적합 위험이 낮을 때, 선형 관계가 명확할 때 |
| **릿지 회귀** | L2 규제 (모든 특성 유지, 계수 축소) | 특성 대부분이 중요하고, 다중공선성 문제가 있을 때, 모델의 안정성이 중요할 때 |
| **라쏘 회귀** | L1 규제 (특성 선택 효과, 계수 0으로 만듦) | 불필요한 특성이 많다고 의심될 때, 모델의 희소성(간결성)과 해석 가능한 모델이 필요할 때 |
| **엘라스틱넷** | L1 + L2 규제 (두 규제의 장점 결합) | 특성 간 상관관계가 높으면서 특성 선택도 필요할 때, 라쏘의 불안정성을 보완하고 싶을 때 |
| **SVR** | 마진 기반, 커널 트릭, 이상치 강건 | **비선형 관계**가 예상될 때, **이상치에 강건한 모델**이 필요할 때, 데이터셋이 너무 크지 않을 때 (계산 비용 고려) |

**모델 선택을 위한 추가 고려사항:**

*   **데이터의 특성:**
    *   **선형성:** 데이터가 선형적인 관계를 보이는지, 아니면 비선형적인 관계를 보이는지에 따라 선형 모델(선형 회귀, 릿지, 라쏘, 엘라스틱넷) 또는 비선형 모델(SVR with non-linear kernel)을 선택합니다.
    *   **특성 간 상관관계:** 특성들 간에 강한 상관관계(다중공선성)가 있다면 릿지나 엘라스틱넷이 더 안정적인 성능을 보일 수 있습니다.
    *   **특성의 수:** 특성의 수가 매우 많고 그 중 불필요한 특성이 많다고 판단되면 라쏘나 엘라스틱넷을 통해 특성 선택을 고려할 수 있습니다.
    *   **이상치 존재 여부:** 데이터에 이상치가 많다면 SVR과 같이 이상치에 강건한 모델을 고려할 수 있습니다.

*   **모델의 해석 가능성:**
    *   모델의 예측 결과를 설명해야 하는 경우, 선형 회귀나 라쏘 회귀(특성 선택으로 인해)와 같이 해석이 용이한 모델이 유리합니다.
    *   SVR과 같은 커널 기반 모델은 비선형 관계를 잘 모델링하지만, 해석이 어렵다는 단점이 있습니다.

*   **계산 비용 및 학습 시간:**
    *   데이터셋의 크기가 매우 크다면 학습 시간이 오래 걸릴 수 있는 SVR보다는 선형 모델이나 앙상블 모델(예: 트리 기반 회귀 모델)을 고려하는 것이 좋습니다.

*   **교차 검증 및 하이퍼파라미터 튜닝의 중요성:**
    *   어떤 모델을 선택하든, 모델의 성능을 객관적으로 평가하고 과적합을 방지하기 위해 **교차 검증(Cross-validation)**은 필수적입니다.
    *   각 모델의 하이퍼파라미터는 모델의 성능에 지대한 영향을 미치므로, `GridSearchCV`, `RandomizedSearchCV`와 같은 도구를 사용하여 최적의 하이퍼파라미터 조합을 찾는 과정이 반드시 필요합니다.

**결론적으로, 단 하나의 '최고의' 회귀 모델은 없습니다.** 데이터와 문제의 특성을 깊이 이해하고, 다양한 모델을 시도하며 교차 검증을 통해 성능을 비교하는 것이 가장 중요합니다. 이 문서를 통해 학습한 선형 모델, 규제 기법, 그리고 SVR에 대한 이해를 바탕으로 실제 문제 해결에 적합한 모델을 선택하고 최적화하는 데 도움이 되기를 바랍니다.
