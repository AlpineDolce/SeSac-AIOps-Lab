# 데이터 탐색 및 획득: 시각화와 크롤링

**데이터 과학 프로젝트의 시작: 데이터를 이해하고 수집하는 핵심 도구와 기법**

이 섹션은 Matplotlib, Seaborn 등 파이썬의 대표적인 데이터 시각화 라이브러리를 사용하여 데이터를 탐색하고 이해하는 방법을 학습합니다. 또한, 웹 크롤링, API 연동 등 다양한 방법으로 필요한 데이터를 수집하는 기법을 익혀, 데이터 기반 문제 해결의 기반을 다집니다.

---

### 주요 내용:

- [**01_Matplotlib_기본.md**](./01_Matplotlib_기본.md): Matplotlib을 이용한 기본적인 그래프(선 그래프, 산점도, 막대 그래프 등) 생성 및 커스터마이징.
- [**02_Seaborn_고급_시각화.md**](./02_Seaborn_고급_시각화.md): Seaborn을 이용한 통계 기반의 고급 시각화(히스토그램, 박스 플롯, 히트맵 등) 및 데이터 분포 탐색.
- [**03_웹_크롤링_기본.md**](./03_웹_크롤링_기본.md): Beautiful Soup, Scrapy 등 라이브러리를 이용한 웹 크롤링의 기본 원리와 실제 데이터 수집 방법.
- [**04_API_연동_데이터_획득.md**](./04_API_연동_데이터_획득.md): Requests 라이브러리를 이용한 RESTful API 연동, 공공 데이터 포털 등 외부 API를 통한 데이터 획득.
