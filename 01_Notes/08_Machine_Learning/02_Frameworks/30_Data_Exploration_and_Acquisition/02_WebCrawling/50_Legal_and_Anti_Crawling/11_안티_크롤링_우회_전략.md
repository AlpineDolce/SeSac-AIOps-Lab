## 1. 안티-크롤링(Anti-Crawling)이란?

안티-크롤링은 웹사이트가 자동화된 봇(크롤러)의 접근을 탐지하고 차단하기 위해 사용하는 모든 기술을 의미합니다. 웹사이트는 다음과 같은 이유로 크롤러를 차단합니다.

- 서버 리소스 보호
- 자사 콘텐츠 및 데이터베이스 보호
- 스팸 및 어뷰징 방지

우리의 목표는 크롤러가 최대한 사람처럼 행동하도록 만들어, 봇으로 탐지될 가능성을 최소화하는 것입니다.

## 2. 기본 우회 기법 (복습)

고급 기술을 사용하기 전에, 가장 기본적인 예의를 지키는 것만으로도 많은 차단을 피할 수 있습니다.

- **User-Agent 변경:** `requests` 헤더나 Scrapy 미들웨어를 통해 요청 헤더의 User-Agent를 실제 브라우저의 것으로 설정합니다. 주기적으로 여러 User-Agent를 번갈아 사용하는 것이 더 좋습니다.
- **Referer 헤더 설정:** 일부 사이트는 요청의 `Referer` 헤더(이전 페이지의 주소)를 확인합니다. Scrapy에서는 `DEFAULT_REQUEST_HEADERS` 설정으로 `Referer`를 추가할 수 있습니다.
- **딜레이 설정:** Scrapy의 `DOWNLOAD_DELAY`를 1~3초 정도로 설정하여 서버에 부담을 주지 않습니다.

## 3. IP 기반 차단 우회: 프록시 로테이션

가장 흔한 차단 방식은 특정 IP 주소에서 비정상적으로 많은 요청이 올 때 해당 IP를 차단하는 것입니다. **프록시(Proxy)**는 내 컴퓨터와 목표 웹사이트 사이의 중계 서버 역할을 하여, 웹사이트가 내 실제 IP가 아닌 프록시 서버의 IP를 보도록 만듭니다.

**프록시 로테이션(Proxy Rotation)**은 여러 개의 프록시 서버를 준비해두고, 요청마다 다른 프록시를 통해 보내는 전략입니다. 

- **구현:** Scrapy의 다운로더 미들웨어에서 `request.meta['proxy']` 값을 설정하는 방식으로 구현합니다. (이전 `09_...md` 문서 참고)
- **프록시 종류:**
    - **데이터센터 프록시:** 저렴하고 빠르지만, 데이터센터 IP 대역이 알려져 있어 사이트에서 탐지하기 쉽습니다.
    - **주거용 프록시 (Residential Proxy):** 실제 가정집에서 사용하는 ISP의 IP입니다. 비싸지만 탐지가 매우 어렵습니다.
- **현실:** 안정적인 프록시를 대량으로 직접 구하는 것은 거의 불가능하며, 보통 Bright Data, Oxylabs 같은 유료 프록시 서비스를 이용합니다.

## 4. 고도화된 탐지 우회: 브라우저 핑거프린팅

고급 봇 탐지 시스템은 IP나 User-Agent만 보지 않습니다. 자바스크립트를 이용해 사용자의 브라우저 환경에 대한 고유한 **지문(Fingerprint)**을 수집합니다.

- **수집 정보:** 화면 해상도, 설치된 폰트, 브라우저 플러그인, 운영체제, WebGL 렌더링 정보, Canvas 핑거프린트 등
- **탐지 원리:** 이 정보들의 조합은 각 사용자를 식별할 만큼 고유하며, 일반적인 Selenium 브라우저는 실제 사용자와 다른 특징을 보여 봇으로 탐지됩니다.
- **대응 방안:** `Selenium`이나 `Playwright`를 사용할 때, 자동화 탐지를 우회하도록 특별히 설계된 라이브러리를 함께 사용합니다.
    - **`selenium-stealth`**: `pip install selenium-stealth`로 설치하며, Selenium이 제어하는 브라우저의 여러 특징을 사람의 것처럼 위장해줍니다.
    ```python
    from selenium import webdriver
    from selenium_stealth import stealth

    driver = webdriver.Chrome()

    # 스텔스 기능 적용
    stealth(driver,
            languages=["ko-KR", "ko"],
            vendor="Google Inc.",
            platform="Win32",
            webgl_vendor="Intel Inc.",
            renderer="Intel Iris OpenGL Engine",
            fix_hairline=True,
            )

    driver.get("https://bot.sannysoft.com/") # 봇 탐지 테스트 사이트
    ```

## 5. 최후의 보루: CAPTCHA 처리

CAPTCHA는 봇과 사람을 구별하기 위한 마지막 관문입니다. CAPTCHA가 나타났다는 것은 이미 크롤러가 봇으로 의심받고 있다는 신호입니다.

- **최고의 전략 - 회피:** CAPTCHA를 마주치지 않는 것이 최선입니다. 요청 속도를 더 늦추거나, 더 좋은 품질의 프록시를 사용하거나, 데이터를 가져올 수 있는 다른 API 엔드포인트가 있는지 찾아보세요.
- **CAPTCHA 해결 서비스:** `2Captcha`, `Anti-CAPTCHA`와 같은 유료 서비스를 이용하는 방법입니다. API를 통해 CAPTCHA 이미지나 관련 키를 보내면, 서비스에 고용된 사람들이 수동으로 풀어 그 결과값을 반환해줍니다. 이를 코드에 다시 입력하여 인증을 통과합니다. (단, 저임금 노동력에 의존하는 윤리적 문제가 있습니다.)
- **머신러닝:** 특정 유형의 CAPTCHA를 인식하도록 직접 이미지 인식 모델을 훈련시키는 방법입니다. 매우 어렵고 많은 비용과 시간이 필요하여 현실적인 대안은 아닙니다.

**핵심 요약:** 안티-크롤링은 창과 방패의 싸움입니다. **가장 중요한 것은 사람처럼 행동하는 것**입니다. 요청 속도를 조절하고, 헤더를 관리하고, 양질의 프록시를 사용하는 것만으로도 대부분의 문제를 해결할 수 있습니다. 항상 가장 간단하고 예의 바른 방법부터 시도하세요.
