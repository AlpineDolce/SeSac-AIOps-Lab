# 데이터 과학자를 위한 NumPy 실무 역량 강화 가이드

**NumPy, 그 이상의 가치를 담아내다: 단순한 라이브러리를 넘어 데이터 과학의 심장부로**

이 가이드는 데이터 과학 및 머신러닝 실무의 핵심 도구인 NumPy 라이브러리의 기초부터 고급 활용법까지 체계적으로 다룹니다. NumPy는 단순한 배열 계산 도구가 아닙니다. Pandas, Scikit-learn, TensorFlow, PyTorch 등 현대 데이터 과학 생태계를 지탱하는 근간이며, 효율적인 데이터 처리와 분석을 통해 여러분이 견고하고 최적화된 AI 모델을 개발하는 데 필요한 실무 역량을 강화하는 데 초점을 맞춥니다. 이 여정을 통해 여러분은 데이터의 잠재력을 최대로 이끌어내는 문제 해결 능력을 갖춘 유능한 데이터 과학자로 성장할 것입니다.

---

### Part 1: NumPy 핵심 개념 (Core Concepts)
- **학습 목표:** NumPy의 기본 구조인 배열(ndarray)의 개념을 이해하고, 다양한 방법으로 배열을 생성하며, 배열의 기본적인 속성을 파악합니다.
- **왜 중요한가?** NumPy 배열은 파이썬에서 수치 데이터를 효율적으로 다루는 기본 단위입니다. 이 핵심 개념을 정확히 이해하는 것은 모든 고급 연산과 데이터 처리의 기반이 됩니다.
- **주요 내용:**
    - [**01_NumPy_소개.md**](./01_NumPy_소개.md): NumPy의 정의와 ML/DL에서의 중요성을 이해합니다.
    - [**02_배열_생성.md**](./02_배열_생성.md): `np.array`, `arange`, `linspace` 등 다양한 배열 생성 기법을 익힙니다.
    - [**03_배열_속성_및_데이터_타입.md**](./03_배열_속성_및_데이터_타입.md): `shape`, `dtype`, `ndim` 등 배열의 기본 속성과 데이터 타입 변환 방법을 학습합니다.

### Part 2: 배열 조작 (Array Manipulation)
- **학습 목표:** 생성된 NumPy 배열의 데이터를 효율적으로 선택하고, 배열의 형태를 변경하며, 여러 배열을 조합하거나 분리하는 방법을 숙달합니다.
- **왜 중요한가?** 실제 데이터는 다양한 형태로 존재하며, 분석 및 모델링을 위해 데이터를 원하는 구조로 변환하고 필요한 부분만 추출하는 능력은 데이터 처리의 핵심입니다.
- **주요 내용:**
    - [**04_인덱싱_및_슬라이싱.md**](./04_인덱싱_및_슬라이싱.md): 배열의 특정 데이터에 접근하고 부분집합을 추출하는 기본 기술을 다룹니다.
    - [**05_배열_형태_변경.md**](./05_배열_형태_변경.md): `reshape`, `transpose`를 이용해 배열의 형태를 자유자재로 변경합니다.
    - [**06_배열_결합_및_분할.md**](./06_배열_결합_및_분할.md): 여러 배열을 합치거나(`concatenate`, `vstack`, `hstack`) 하나의 배열을 나누는(`split`, `vsplit`, `hsplit`) 방법을 배웁니다.

### Part 3: 필수 연산 (Essential Operations)
- **학습 목표:** NumPy의 강력한 벡터화 연산(유니버설 함수, 브로드캐스팅)의 원리를 이해하고, 배열에 대한 다양한 수학적 및 통계적 연산을 효율적으로 수행합니다.
- **왜 중요한가?** NumPy의 벡터화 연산은 파이썬 루프에 비해 압도적인 성능을 제공합니다. 이를 통해 대규모 데이터셋에 대한 빠르고 효율적인 계산이 가능해지며, 이는 머신러닝 알고리즘 구현의 기반이 됩니다.
- **주요 내용:**
    - [**07_유니버설_함수(UFuncs).md**](./07_유니버설_함수(UFuncs).md): 벡터화 연산의 핵심인 유니버설 함수의 개념과 활용법을 알아봅니다.
    - [**08_브로드캐스팅.md**](./08_브로드캐스팅.md): 형태가 다른 배열 간의 연산을 가능하게 하는 브로드캐스팅의 규칙과 원리를 심도 있게 학습합니다.
    - [**09_수학_및_통계_함수.md**](./09_수학_및_통계_함수.md): 합계, 평균, 표준편차 등 기술 통계와 관련된 집계 함수 사용법을 익힙니다.
    - [**10_정렬_검색_및_카운팅.md**](./10_정렬_검색_및_카운팅.md): `sort`, `argsort`, `where`, `unique` 등 데이터를 정렬하고 조건에 맞는 값을 찾는 방법을 다룹니다.

### Part 4: 응용 (Applied NumPy)
- **학습 목표:** NumPy를 활용하여 머신러닝 및 딥러닝의 기반이 되는 선형대수 연산을 수행하고, 다양한 확률 분포의 난수를 생성하며, 배열 데이터를 효율적으로 파일로 저장하고 불러오는 방법을 익힙니다.
- **왜 중요한가?** 실제 머신러닝 프로젝트에서는 선형대수 연산, 데이터 샘플링, 그리고 대규모 데이터셋의 효율적인 입출력이 필수적입니다. 이 응용 기술들은 모델 개발 및 데이터 전처리 과정에서 직접적으로 활용됩니다.
- **주요 내용:**
    - [**11_선형대수.md**](./11_선형대수.md): 행렬 곱, 역행렬, 고유값 분해 등 머신러닝의 기반이 되는 선형대수 연산을 `np.linalg` 모듈을 통해 학습합니다.
    - [**12_난수_생성_및_확률_분포.md**](./12_난수_생성_및_확률_분포.md): NumPy의 난수 생성 기본 함수와 다양한 확률 분포의 특징 및 활용법을 학습합니다.
    - [**13_재현성_샘플링_및_Generator_API.md**](./13_재현성_샘플링_및_Generator_API.md): 재현 가능한 난수 생성 기법, 최신 `np.random.Generator` API의 사용법, 그리고 데이터 샘플링 및 순열 방법을 학습합니다.
    - [**14_파일_입출력.md**](./14_파일_입출력.md): `np.save`/`load`를 이용한 효율적인 바이너리 저장, 그리고 RAM 용량을 초과하는 대용량 데이터셋을 다루기 위한 `np.memmap`을 학습합니다.
