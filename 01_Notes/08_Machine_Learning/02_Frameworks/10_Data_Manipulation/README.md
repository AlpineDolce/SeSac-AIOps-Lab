# 데이터 조작: Pandas와 NumPy

**데이터 과학 및 머신러닝에서 데이터를 효율적으로 조작하고 전처리하는 데 필요한 핵심 라이브러리**

이 섹션은 파이썬의 대표적인 데이터 과학 라이브러리인 Pandas와 NumPy의 기본 개념과 활용 방법을 학습합니다. 데이터 로딩, 클리닝, 변환, 집계 등 데이터 전처리 과정에서 필요한 다양한 데이터 조작 기술을 익혀, 머신러닝 모델 학습을 위한 데이터를 효과적으로 준비하는 능력을 기릅니다.

---

### 주요 내용:

- [**01_Pandas_기본.md**](./01_Pandas_기본.md): Pandas DataFrame과 Series의 개념, 데이터 로딩(CSV, Excel), 기본 데이터 탐색 및 선택.
- [**02_Pandas_데이터_전처리.md**](./02_Pandas_데이터_전처리.md): 결측치 처리, 중복 데이터 제거, 데이터 타입 변환, 문자열/날짜 데이터 처리.
- [**03_Pandas_데이터_변환_집계.md**](./03_Pandas_데이터_변환_집계.md): 데이터 병합(merge, join), 그룹화(groupby), 피벗 테이블, 데이터 변형(apply, map).
- [**04_NumPy_기본.md**](./04_NumPy_기본.md): NumPy 배열(ndarray)의 개념, 배열 생성, 인덱싱, 슬라이싱, 기본 연산.
- [**05_NumPy_고급_연산.md**](./05_NumPy_고급_연산.md): 브로드캐스팅, 선형 대수 연산, 난수 생성 등 NumPy의 고급 기능.
