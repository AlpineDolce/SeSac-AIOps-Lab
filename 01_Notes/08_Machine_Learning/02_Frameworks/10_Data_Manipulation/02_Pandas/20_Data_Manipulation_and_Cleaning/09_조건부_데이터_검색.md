### 1.1. 기본 조건 검색

Pandas `DataFrame`에서 데이터를 필터링하는 가장 기본적인 방법은 **불리언 인덱싱(Boolean Indexing)**을 활용하는 것입니다. 이는 특정 조건을 만족하는 행(row)만을 선택하여 새로운 `DataFrame`을 생성하는 강력하고 유연한 기법입니다.

**불리언 인덱싱의 원리**:
1.  **조건식 생성**: 먼저 `DataFrame`의 특정 컬럼에 대해 조건식을 적용합니다 (예: `df['kor'] >= 80`).
2.  **불리언 `Series` 반환**: 이 조건식은 `DataFrame`의 각 행에 대해 `True` 또는 `False` 값을 가지는 불리언 `Series`를 반환합니다. `True`는 해당 행이 조건을 만족함을 의미하고, `False`는 만족하지 않음을 의미합니다.
3.  **행 필터링**: 이 불리언 `Series`를 원본 `DataFrame`에 인덱스로 전달하면, Pandas는 `True`에 해당하는 위치의 행들만 선택하여 새로운 `DataFrame`으로 반환합니다.

**사용 가능한 비교 연산자**:
*   `==` (같다)
*   `!=` (같지 않다)
*   `>` (크다)
*   `<` (작다)
*   `>=` (크거나 같다)
*   `<=` (작거나 같다)

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희'],
    'kor': [90, 80, 70, 70, 60, 70, np.nan], # 결측치 포함
    'eng': [99, 98, 97, 46, 77, 56, 85],
    'mat': [90, 70, 70, 60, 88, 99, 75],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울', '인천'],
    'gender': ['남', '여', '남', '남', '여', '여', '여']
}
df = pd.DataFrame(data)
print("--- 원본 DataFrame ---\n", df)

print("\n--- 1. 단일 조건 필터링 ---")

# 1.1. 국어 점수가 80점 이상인 학생
condition_kor_80_plus = df['kor'] >= 80
print("\n1.1.1. 'kor' >= 80 조건식의 결과 (불리언 Series):\n", condition_kor_80_plus)
print("\n1.1.2. 국어 점수가 80점 이상인 학생 (불리언 Series를 이용한 필터링):\n", df[condition_kor_80_plus])

# 1.2. 영어 점수가 90점 미만인 학생
print("\n1.2. 영어 점수가 90점 미만인 학생:\n", df[df['eng'] < 90])

# 1.3. 거주 도시가 '서울'인 학생
print("\n1.3. 거주 도시가 '서울'인 학생:\n", df[df['city'] == '서울'])

# 1.4. 성별이 '남'이 아닌 학생 (즉, '여'인 학생)
print("\n1.4. 성별이 '남'이 아닌 학생:\n", df[df['gender'] != '남'])

# 1.5. 국어 점수가 결측치인 학생
print("\n1.5. 국어 점수가 결측치인 학생:\n", df[df['kor'].isnull()])

# 1.6. 국어 점수가 결측치가 아닌 학생
print("\n1.6. 국어 점수가 결측치가 아닌 학생:\n", df[df['kor'].notnull()])


print("\n--- 2. 필터링된 결과에서 특정 컬럼만 선택 ---")

# 2.1. 국어 점수가 70점인 학생의 이름과 영어 점수
# 필터링된 DataFrame에 다시 컬럼 선택을 위한 대괄호([])를 사용합니다.
print("\n2.1. 국어 점수가 70점인 학생의 이름과 영어 점수:\n", df[df['kor'] == 70][['name', 'eng']])

# 2.2. 거주 도시가 '부산'인 학생의 모든 정보
print("\n2.2. 거주 도시가 '부산'인 학생의 모든 정보:\n", df[df['city'] == '부산'])


print("\n--- 3. 필터링된 결과에 새로운 컬럼 추가 또는 수정 (SettingWithCopyWarning 주의) ---")

# SettingWithCopyWarning 발생 가능성이 있는 잘못된 방법 (체이닝 인덱싱)
# df[df['kor'] == 70]['status'] = 'Passed'

# 올바른 방법: .loc 사용
# .loc[행 조건, 열 조건] = 값
df.loc[df['kor'] == 70, 'status'] = 'Passed'
df.loc[df['city'] == '서울', 'region'] = '수도권'
print("\n3.1. 국어 점수가 70점인 학생에게 'status' 컬럼 추가 후:\n", df)

# 기존 값 수정 예시
df.loc[df['name'] == '홍길동', 'kor'] = 95
print("\n3.2. '홍길동'의 국어 점수 수정 후:\n", df)
```

*   **다양한 데이터 타입 필터링**: 숫자형 데이터뿐만 아니라 문자열, 날짜/시간, 불리언 등 모든 데이터 타입에 대해 조건식을 적용하여 필터링할 수 있습니다.
*   **결측치 필터링**: `isnull()` 또는 `notnull()` 메서드를 사용하여 결측치(`NaN`)를 포함하거나 제외하는 조건 검색을 수행할 수 있습니다.
*   **체이닝 인덱싱 주의 (`SettingWithCopyWarning`)**: 필터링된 `DataFrame`에 새로운 컬럼을 추가하거나 기존 컬럼을 수정할 때 `df[condition]['new_col'] = value`와 같은 체이닝 인덱싱은 `SettingWithCopyWarning`을 발생시킬 수 있습니다. 이는 원본 `DataFrame`의 뷰(view)에 작업하는 것인지 복사본(copy)에 작업하는 것인지 Pandas가 명확히 판단하기 어렵기 때문입니다. **항상 `.loc` 또는 `.iloc`를 사용하여 명시적으로 선택하는 것이 안전하고 권장됩니다.** (예: `df.loc[condition, 'new_col'] = value`)
*   **가독성 유지**: 복잡한 조건식은 변수에 할당하여 사용하면 코드의 가독성을 높일 수 있습니다 (예: `condition = df['kor'] >= 80`).
*   **성능 고려**: 매우 큰 `DataFrame`의 경우, 필터링 작업이 성능에 영향을 미칠 수 있습니다. 필요한 경우 `query()` 메서드나 `NumPy` 기반의 연산을 고려할 수 있습니다.

*   **불리언 인덱싱**은 Pandas에서 데이터를 필터링하는 가장 기본적이고 강력한 방법입니다.
*   조건식은 `True`/`False` 값을 가진 **불리언 `Series`**를 반환하며, 이 `Series`를 사용하여 `DataFrame`의 행을 선택합니다.
*   다양한 비교 연산자를 사용하여 숫자, 문자열, 결측치 등 여러 타입의 데이터를 필터링할 수 있습니다.
*   필터링된 `DataFrame`에 값을 할당하거나 수정할 때는 `SettingWithCopyWarning`을 피하기 위해 **`.loc`를 사용하는 것이 모범 사례**입니다.


### 1.2. 복합 조건 검색

여러 조건을 동시에 만족하거나(AND) 둘 중 하나라도 만족하는(OR) 데이터를 검색할 때는 복합 조건식을 사용합니다. 이때 파이썬의 기본 논리 연산자(`and`, `or`) 대신 비트wise 논리 연산자(`&`, `|`)를 사용해야 하며, 각 조건식은 반드시 괄호로 묶어야 합니다.

**주의사항**:
*   파이썬의 `and`, `or` 연산자는 `Series` 전체에 대해 불리언 값을 평가할 수 없으므로 사용 불가합니다.
*   NumPy 기반의 Pandas에서는 요소별(element-wise) 논리 연산을 위해 비트wise 연산자(`&` for AND, `|` for OR, `~` for NOT)를 사용해야 합니다.
*   각 개별 조건식은 반드시 괄호 `()`로 묶어야 합니다. 이는 연산자 우선순위 문제로 인해 발생할 수 있는 오류를 방지합니다.

#### 1.2.1. `&` (AND) 조건

`DataFrame`에서 두 개 이상의 조건을 **모두 만족하는(AND)** 데이터를 선택할 때 비트wise 논리 연산자 `&`를 사용합니다. 이는 각 조건식이 반환하는 불리언 `Series`에 대해 요소별(element-wise) AND 연산을 수행하여, 모든 조건이 `True`인 위치의 행만을 최종적으로 선택합니다.

**핵심 원리**:
*   각 개별 조건식은 `True` 또는 `False`로 이루어진 불리언 `Series`를 반환합니다.
*   `&` 연산자는 이 불리언 `Series`들을 서로 비교하여, 두 `Series`의 같은 위치에 있는 요소가 모두 `True`일 때만 `True`를 반환하는 새로운 불리언 `Series`를 생성합니다.
*   이 최종 불리언 `Series`를 `DataFrame`에 적용하여 필터링을 수행합니다.

**주의사항 (재강조)**:
*   **괄호 사용 필수**: 각 개별 조건식은 반드시 괄호 `()`로 묶어야 합니다. 이는 파이썬의 연산자 우선순위 규칙 때문입니다. 비교 연산자(`>=`, `==` 등)의 우선순위가 비트wise 연산자(`&`, `|`)보다 높기 때문에, 괄호로 묶지 않으면 예상치 못한 오류가 발생하거나 잘못된 결과가 나올 수 있습니다.
*   **`and` 대신 `&` 사용**: 파이썬의 기본 논리 연산자 `and`는 `Series` 전체의 참/거짓을 평가하려 하기 때문에 `ValueError`를 발생시킵니다. Pandas에서는 요소별 연산을 위해 반드시 비트wise 연산자 `&`를 사용해야 합니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희', '최민수'],
    'kor': [90, 80, 70, 70, 60, 70, 95, 85],
    'eng': [99, 98, 97, 46, 77, 56, 88, 92],
    'mat': [90, 70, 70, 60, 88, 99, 80, 75],

print("\n2.1. 국어 점수가 80점 이상이고, 영어 점수가 90점 이상이며, 도시가 '서울'인 학생:")
```

**모범 사례 및 활용 팁**:
*   **괄호는 습관처럼**: 복합 조건을 사용할 때는 각 개별 조건식을 항상 괄호로 묶는 습관을 들이세요. 이는 오류를 방지하고 코드의 가독성을 높이는 가장 중요한 규칙입니다.
*   **변수 할당으로 가독성 향상**: 복잡한 조건식은 여러 개의 개별 조건으로 나누어 변수에 할당한 후, 이 변수들을 `&` 연산자로 연결하여 사용하면 코드의 가독성을 크게 향상시킬 수 있습니다.
*   **`&`와 `and`의 차이 명확히 이해**: 파이썬의 `and`는 단일 불리언 값에 대해 작동하며, `Series` 전체에 적용할 수 없습니다. Pandas에서는 요소별 논리 연산을 위해 반드시 비트wise 연산자 `&`를 사용해야 합니다.
*   **결측치(`NaN`) 처리**: `&` 연산은 `NaN` 값을 포함하는 경우 `False`로 평가되거나 `NaN`으로 전파될 수 있습니다. 따라서 결측치가 있는 컬럼에 조건을 적용할 때는 `isnull()` 또는 `notnull()`을 함께 사용하여 명시적으로 결측치를 처리하는 것이 좋습니다.
*   **성능 고려**: 매우 큰 `DataFrame`에서 복잡한 `&` 조건을 자주 사용해야 한다면, `query()` 메서드나 `NumPy`의 `logical_and` 함수를 사용하는 것을 고려해볼 수 있습니다. `query()`는 문자열 기반으로 조건식을 작성하여 가독성이 좋고, 내부적으로 최적화되어 있어 성능상 이점을 가질 수 있습니다.

**핵심 요약 (Key Takeaways)**:
*   `&` 연산자는 `DataFrame`에서 **두 개 이상의 조건을 모두 만족하는 행**을 필터링할 때 사용합니다.
*   각 개별 조건식은 **반드시 괄호 `()`로 묶어야** 하며, 파이썬의 `and` 대신 **비트wise 연산자 `&`**를 사용해야 합니다.
*   조건식을 변수에 할당하여 사용하면 **코드의 가독성**을 높일 수 있습니다.
*   `&` 연산은 `NaN` 값을 포함하는 경우 주의가 필요하며, 필요에 따라 `isnull()`/`notnull()`과 함께 사용해야 합니다.

#### 1.2.2. `|` (OR) 조건

`DataFrame`에서 두 개 이상의 조건 중 **하나라도 만족하는(OR)** 데이터를 선택할 때 비트wise 논리 연산자 `|`를 사용합니다. 이는 각 조건식이 반환하는 불리언 `Series`에 대해 요소별(element-wise) OR 연산을 수행하여, 조건 중 하나라도 `True`인 위치의 행들을 최종적으로 선택합니다.

**핵심 원리**:
*   각 개별 조건식은 `True` 또는 `False`로 이루어진 불리언 `Series`를 반환합니다.
*   `|` 연산자는 이 불리언 `Series`들을 서로 비교하여, 두 `Series`의 같은 위치에 있는 요소 중 하나라도 `True`일 때 `True`를 반환하는 새로운 불리언 `Series`를 생성합니다.
*   이 최종 불리언 `Series`를 `DataFrame`에 적용하여 필터링을 수행합니다.

**주의사항 (재강조)**:
*   **괄호 사용 필수**: `&` 연산자와 마찬가지로, 각 개별 조건식은 반드시 괄호 `()`로 묶어야 합니다. 이는 파이썬의 연산자 우선순위 규칙 때문입니다.
*   **`or` 대신 `|` 사용**: 파이썬의 기본 논리 연산자 `or`는 `Series` 전체의 참/거짓을 평가하려 하기 때문에 `ValueError`를 발생시킵니다. Pandas에서는 요소별 연산을 위해 반드시 비트wise 연산자 `|`를 사용해야 합니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희', '최민수'],
    'kor': [90, 80, 70, 70, 60, 70, 95, 85],
    'eng': [99, 98, 97, 46, 77, 56, 88, 92],
    'mat': [90, 70, 70, 60, 88, 99, 80, 75],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울', '인천', '부산'],
    'grade': ['A', 'B', 'C', 'D', 'C', 'B', 'A', 'B']
}
df = pd.DataFrame(data)
print("---\n", df)

print("\n--- 1. 두 가지 조건 중 하나라도 만족하는 데이터 검색 ---")

# 1.1. 국어 점수가 90점 이상이거나 수학 점수가 90점 이상인 학생
# (df['kor'] >= 90)  -> [True, False, False, False, False, False, True, False]
# (df['mat'] >= 90)  -> [True, False, False, False, False, True, False, False]
# 결과: [True, False, False, False, False, True, True, False]
print("\n1.1. 국어 점수가 90점 이상이거나 수학 점수가 90점 이상인 학생:")
print(df[(df['kor'] >= 90) | (df['mat'] >= 90)])

# 1.2. 거주 도시가 '부산'이거나 '대구'인 학생
print("\n1.2. 거주 도시가 '부산'이거나 '대구'인 학생:")
print(df[(df['city'] == '부산') | (df['city'] == '대구')])

# 1.3. 영어 점수가 50점 미만이거나 수학 점수가 60점 미만인 학생
print("\n1.3. 영어 점수가 50점 미만이거나 수학 점수가 60점 미만인 학생:")
print(df[(df['eng'] < 50) | (df['mat'] < 60)])


print("\n--- 2. 세 가지 이상의 조건 중 하나라도 만족하는 데이터 검색 ---")

# 2.1. 국어 점수가 95점 이상이거나, 영어 점수가 99점 이상이거나, 도시가 '인천'인 학생
print("\n2.1. 국어 점수가 95점 이상이거나, 영어 점수가 99점 이상이거나, 도시가 '인천'인 학생:")
print(df[(df['kor'] >= 95) | (df['eng'] >= 99) | (df['city'] == '인천')])

# 2.2. 등급이 'A'이거나 'D'이거나 이름에 '장'이 포함된 학생
print("\n2.2. 등급이 'A'이거나 'D'이거나 이름에 '장'이 포함된 학생:")
print(df[(df['grade'] == 'A') | (df['grade'] == 'D') | (df['name'].str.contains('장'))])


print("\n--- 3. 복합 조건에 맞는 행에서 특정 컬럼만 선택 ---")

# 3.1. 국어 점수 90점 이상 또는 수학 점수 90점 이상인 학생의 이름과 도시
print("\n3.1. 국어 점수 90점 이상 또는 수학 점수 90점 이상인 학생의 이름과 도시:")
print(df[(df['kor'] >= 90) | (df['mat'] >= 90)][['name', 'city']])

# 3.2. 도시가 '인천'이거나 '대구'인 학생의 이름과 국어 점수
print("\n3.2. 도시가 '인천'이거나 '대구'인 학생의 이름과 국어 점수:")
print(df[(df['city'] == '인천') | (df['city'] == '대구')][['name', 'kor']])


print("\n--- 4. 조건식을 변수에 할당하여 가독성 높이기 ---")

condition1 = df['kor'] >= 90
condition2 = df['mat'] >= 90
condition3 = df['city'] == '인천'

print("\n4.1. 국어 점수 90점 이상이거나 수학 점수 90점 이상인 학생 (변수 사용):")
print(df[condition1 | condition2])

print("\n4.2. 국어 점수 90점 이상이거나 수학 점수 90점 이상이거나 도시 '인천'인 학생 (변수 사용):")
print(df[condition1 | condition2 | condition3])


print("\n--- 5. `isin()` 메서드와의 비교 ---")

# 'city' 컬럼이 '부산' 또는 '대구'인 경우 (isin() 사용)
print("\n5.1. `isin()`을 사용한 'city' 필터링 ('부산' 또는 '대구'):")
print(df[df['city'].isin(['부산', '대구'])])

# 위와 동일한 결과를 '|' 연산자로 구현
print("\n5.2. `|` 연산자를 사용한 'city' 필터링 ('부산' 또는 '대구'):")
print(df[(df['city'] == '부산') | (df['city'] == '대구')])
print("  - 단일 컬럼에 대한 다중 OR 조건은 `isin()`이 더 간결하고 가독성이 좋습니다.")

print("\n--- 6. 결측치(`NaN`)를 포함하는 컬럼에 `|` 조건 적용 시 ---")

# 결측치 포함 데이터프레임 생성
df_nan_example = pd.DataFrame({
    'A': [1, 2, np.nan, 4],
    'B': [True, False, True, np.nan],
    'C': ['X', 'Y', 'X', 'Z']
})
print("\n6.1. 결측치 포함 DataFrame:\n", df_nan_example)

# 'A'가 2보다 크거나 'B'가 True인 경우
```

**모범 사례 및 활용 팁**:
*   **괄호는 습관처럼**: `&` 연산자와 마찬가지로, `|` 연산자를 사용할 때도 각 개별 조건식을 항상 괄호로 묶는 습관을 들이세요. 이는 오류를 방지하고 코드의 가독성을 높이는 가장 중요한 규칙입니다.
*   **변수 할당으로 가독성 향상**: 복잡한 `|` 조건식도 여러 개의 개별 조건으로 나누어 변수에 할당한 후, 이 변수들을 `|` 연산자로 연결하여 사용하면 코드의 가독성을 크게 향상시킬 수 있습니다.
*   **`|`와 `or`의 차이 명확히 이해**: 파이썬의 `or`는 단일 불리언 값에 대해 작동하며, `Series` 전체에 적용할 수 없습니다. Pandas에서는 요소별 논리 연산을 위해 반드시 비트wise 연산자 `|`를 사용해야 합니다.
*   **`isin()`과의 비교**: 하나의 컬럼에 대해 여러 값 중 하나라도 만족하는 조건을 찾을 때는 `isin()` 메서드를 사용하는 것이 `|` 연산자를 여러 번 사용하는 것보다 훨씬 간결하고 가독성이 좋습니다. `|` 연산자는 서로 다른 컬럼 간의 OR 조건이나, `isin()`으로 표현하기 어려운 복잡한 OR 조건에 더 적합합니다.
*   **결측치(`NaN`) 처리**: `|` 연산은 `NaN` 값을 포함하는 경우 `True`로 평가되거나 `NaN`으로 전파될 수 있습니다. `NaN`과 `True`의 OR 연산은 `True`가 되므로, `NaN`이 포함된 행이 예상치 않게 필터링 결과에 포함될 수 있습니다. 따라서 결측치가 있는 컬럼에 조건을 적용할 때는 `isnull()` 또는 `notnull()`을 함께 사용하여 명시적으로 결측치를 처리하는 것이 좋습니다.
*   **성능 고려**: 매우 큰 `DataFrame`에서 복잡한 `|` 조건을 자주 사용해야 한다면, `query()` 메서드나 `NumPy`의 `logical_or` 함수를 사용하는 것을 고려해볼 수 있습니다.

**핵심 요약 (Key Takeaways)**:
*   `|` 연산자는 `DataFrame`에서 **두 개 이상의 조건 중 하나라도 만족하는 행**을 필터링할 때 사용합니다.
*   각 개별 조건식은 **반드시 괄호 `()`로 묶어야** 하며, 파이썬의 `or` 대신 **비트wise 연산자 `|`**를 사용해야 합니다.
*   단일 컬럼에 대한 다중 OR 조건에는 `isin()`이 더 효율적이고 간결합니다.
*   `|` 연산은 `NaN` 값을 포함하는 경우 주의가 필요하며, 필요에 따라 `isnull()`/`notnull()`과 함께 사용해야 합니다.

#### 1.2.3. `~` (NOT) 조건

`DataFrame`에서 특정 조건을 **만족하지 않는(NOT)** 데이터를 선택할 때 비트wise 논리 연산자 `~`를 사용합니다. 이 연산자는 조건식이 반환하는 불리언 `Series`의 `True`/`False` 값을 반전(invert)시켜, 원래 조건에 해당하지 않는 행들을 선택할 수 있도록 합니다.

**핵심 원리**:
*   `~` 연산자는 단일 불리언 `Series`에 적용됩니다.
*   `True`는 `False`로, `False`는 `True`로 변환됩니다.
*   이 반전된 불리언 `Series`를 `DataFrame`에 적용하여 필터링을 수행합니다.

**주의사항**:
*   **괄호 사용 필수**: `~` 연산자를 사용할 때도 대상 조건식을 괄호 `()`로 묶는 것이 안전합니다. 특히 복합 조건에 `~`를 적용할 때는 괄호가 필수적입니다.
*   **결측치(`NaN`) 처리**: `~` 연산은 `NaN` 값을 `True`나 `False`로 변환하지 않고 `NaN`으로 유지합니다. 따라서 `NaN`이 포함된 행은 필터링 결과에서 제외될 수 있습니다. `isnull()`/`notnull()`과 함께 사용하면 결측치 여부를 명확하게 반전시킬 수 있습니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희'],
    'kor': [90, 80, 70, 70, 60, 70, np.nan],
    'eng': [99, 98, 97, 46, 77, 56, 85],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울', '인천'],
    'pass': [True, True, False, False, True, False, True]
}
df = pd.DataFrame(data)
print("--- 원본 DataFrame ---\
", df)

print("\n--- 1. 단일 조건의 반전 ---")

# 1.1. 거주 도시가 '서울'이 아닌 학생
# (df['city'] == '서울') -> [True, False, True, False, False, True, False]
# ~(df['city'] == '서울') -> [False, True, False, True, True, False, True]
print("\n1.1. 거주 도시가 '서울'이 아닌 학생:")
print(df[~(df['city'] == '서울')])

# 1.2. 국어 점수가 80점 미만이 아닌 학생 (즉, 80점 이상인 학생)
print("\n1.2. 국어 점수가 80점 미만이 아닌 학생 (즉, 80점 이상인 학생):")
print(df[~(df['kor'] < 80)])

# 1.3. 'pass' 컬럼이 True가 아닌 학생 (즉, False인 학생)
print("\n1.3. 'pass' 컬럼이 True가 아닌 학생:")
print(df[~(df['pass'] == True)]) # df[~df['pass']] 와 동일


print("\n--- 2. 결측치(`NaN`) 조건의 반전 ---")

# 2.1. 국어 점수가 결측치가 아닌 학생 (즉, 유효한 국어 점수를 가진 학생)
print("\n2.1. 국어 점수가 결측치가 아닌 학생:")
print(df[~df['kor'].isnull()]) # df[df['kor'].notnull()] 과 동일

# 2.2. 국어 점수가 결측치인 학생 (notnull()의 반전)
print("\n2.2. 국어 점수가 결측치인 학생 (notnull()의 반전):")
print(df[~df['kor'].notnull()]) # df[df['kor'].isnull()] 과 동일


print("\n--- 3. 복합 조건의 반전 ---")

# 3.1. 국어 점수가 70점 이상이고 영어 점수가 90점 이상인 조건의 반전
# 즉, (국어 < 70) 또는 (영어 < 90) 인 학생
print("\n3.1. (국어 점수가 70점 이상이고 영어 점수가 90점 이상)이 아닌 학생:")
print(df[~((df['kor'] >= 70) & (df['eng'] >= 90))])

# 3.2. 도시가 '서울'이거나 '부산'인 조건의 반전 (즉, '서울'도 '부산'도 아닌 학생)
print("\n3.2. (도시가 '서울'이거나 '부산')이 아닌 학생:")
print(df[~((df['city'] == '서울') | (df['city'] == '부산'))])


print("\n--- 4. `!=` 연산자와 `~` 연산자의 비교 ---")

# 'city'가 '서울'이 아닌 학생 (!= 사용)
print("\n4.1. 'city'가 '서울'이 아닌 학생 (!= 사용):")
print(df[df['city'] != '서울'])

# 'city'가 '서울'이 아닌 학생 (~ 사용)
print("\n4.2. 'city'가 '서울'이 아닌 학생 (~ 사용):")
print(df[~(df['city'] == '서울')])
print("  - 단순 '같지 않다' 조건에는 `!=`가 더 직관적일 수 있습니다.")
print("  - `~`는 복잡한 조건식 전체를 반전시킬 때 유용합니다.")
```

**모범 사례 및 활용 팁**:
*   **괄호 사용 필수**: `~` 연산자를 사용할 때도 대상 조건식을 항상 괄호로 묶는 습관을 들이세요. 특히 `~`를 복합 조건에 적용할 때는 괄호가 필수적입니다. (예: `~((df['kor'] >= 70) & (df['eng'] >= 90)))`
*   **`!=`와의 선택**: 단순하게 "같지 않다"를 표현할 때는 `!=` 연산자가 더 직관적이고 가독성이 좋습니다 (예: `df['city'] != '서울'`). 하지만 기존에 정의된 복잡한 조건식 전체를 반전시켜야 할 때는 `~` 연산자가 매우 유용합니다.
*   **결측치(`NaN`) 처리**: `~df['col'].isnull()`은 `df['col'].notnull()`과 동일하게 결측치가 아닌(유효한) 값을 선택하는 데 자주 사용됩니다. 이는 데이터 클리닝 과정에서 유효한 데이터만 추출할 때 유용합니다.
*   **가독성 유지**: 복잡한 조건식에 `~`를 적용하기 전에, 조건식을 변수에 할당하여 가독성을 높이는 것을 고려하세요. (예: `condition = (df['kor'] >= 70) & (df['eng'] >= 90); df[~condition]`) 

**핵심 요약 (Key Takeaways)**:
*   `~` 연산자는 `DataFrame`에서 **특정 조건을 만족하지 않는 행**을 필터링할 때 사용하며, 불리언 `Series`의 `True`/`False` 값을 반전시킵니다.
*   단순한 "같지 않다" 조건에는 `!=`가 더 직관적이지만, 복잡한 조건식 전체를 반전시킬 때는 `~`가 강력합니다.
*   `isnull()`/`notnull()`과 함께 사용하여 결측치 필터링을 반전시키는 데 유용하게 활용됩니다.
*   `~`를 사용할 때도 대상 조건식을 **반드시 괄호 `()`로 묶어야** 합니다.

#### 1.2.4. `isin()`을 이용한 다중 값 필터링

`DataFrame`의 특정 컬럼에서 여러 개의 특정 값 중 **하나라도 포함하는(is in)** 데이터를 선택할 때 `isin()` 메서드를 사용합니다. 이 메서드는 단일 컬럼에 대한 다중 `|` (OR) 조건을 여러 번 사용하는 것보다 훨씬 간결하고 효율적이며, 코드의 가독성을 크게 향상시킵니다.

**핵심 원리**:
*   `Series.isin(values)`: `Series`의 각 요소가 `values` (리스트, 튜플, 다른 Series 등) 내에 존재하는지 여부를 확인합니다.
*   결과로 `True` 또는 `False`로 이루어진 불리언 `Series`를 반환합니다. `True`는 해당 요소가 `values` 내에 있음을 의미하고, `False`는 없음을 의미합니다.
*   이 불리언 `Series`를 `DataFrame`에 적용하여 필터링을 수행합니다.

**`isin()`의 장점**:
*   **간결성**: 여러 `or` 조건을 `|` 연산자로 연결하는 대신, `isin()` 하나로 표현할 수 있어 코드가 훨씬 짧아집니다.
*   **가독성**: 필터링하려는 값들이 명확하게 리스트 형태로 제시되어 코드의 의도를 쉽게 파악할 수 있습니다.
*   **효율성**: 내부적으로 최적화되어 있어, 특히 필터링할 값의 목록이 길어질수록 `|` 연산자를 반복하는 것보다 성능상 이점을 가질 수 있습니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희', '최민수'],
    'kor': [90, 80, 70, 70, 60, 70, 95, 85],
    'eng': [99, 98, 97, 46, 77, 56, 88, 92],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울', '인천', '부산'],
    'grade': ['A', 'B', 'C', 'D', 'C', 'B', 'A', 'B']
}
df = pd.DataFrame(data)
print("--- 원본 DataFrame ---\
", df)

print("\n--- 1. `isin()`을 이용한 다중 값 필터링 ---")

# 1.1. 거주 도시가 '서울' 또는 '대구'인 학생
# df['city'].isin(['서울', '대구']) -> [True, False, True, True, False, True, False, False]
print("\n1.1. 거주 도시가 '서울' 또는 '대구'인 학생:")
print(df[df['city'].isin(['서울', '대구'])])

# 1.2. 이름이 '홍길동' 또는 '이상민'인 학생
print("\n1.2. 이름이 '홍길동' 또는 '이상민'인 학생:")
print(df[df['name'].isin(['홍길동', '이상민'])])

# 1.3. 국어 점수가 60, 80, 95점 중 하나인 학생
print("\n1.3. 국어 점수가 60, 80, 95점 중 하나인 학생:")
print(df[df['kor'].isin([60, 80, 95])])

# 1.4. 등급이 'A' 또는 'C'인 학생
print("\n1.4. 등급이 'A' 또는 'C'인 학생:")
print(df[df['grade'].isin(['A', 'C'])])


print("\n--- 2. `isin()`과 `~` (NOT) 연산자를 이용한 다중 값 제외 필터링 ---")

# 2.1. 거주 도시가 '서울'도 '대구'도 아닌 학생
print("\n2.1. 거주 도시가 '서울'도 '대구'도 아닌 학생:")
print(df[~df['city'].isin(['서울', '대구'])])

# 2.2. 국어 점수가 60, 80, 95점 중 어느 하나도 아닌 학생
print("\n2.2. 국어 점수가 60, 80, 95점 중 어느 하나도 아닌 학생:")
print(df[~df['kor'].isin([60, 80, 95])])


print("\n--- 3. `isin()`과 다른 조건의 조합 ---")

# 3.1. 거주 도시가 '서울' 또는 '부산'이면서 영어 점수가 90점 이상인 학생
print("\n3.1. 거주 도시가 '서울' 또는 '부산'이면서 영어 점수가 90점 이상인 학생:")
print(df[df['city'].isin(['서울', '부산']) & (df['eng'] >= 90)])

# 3.2. 등급이 'A' 또는 'B'가 아니면서 국어 점수가 80점 미만인 학생
print("\n3.2. 등급이 'A' 또는 'B'가 아니면서 국어 점수가 80점 미만인 학생:")
print(df[~df['grade'].isin(['A', 'B']) & (df['kor'] < 80)])


print("\n--- 4. `isin()`과 `|` (OR) 연산자의 비교 ---")

# 'city' 컬럼이 '부산' 또는 '대구'인 경우 (isin() 사용)
print("\n4.1. `isin()`을 사용한 'city' 필터링 ('부산' 또는 '대구'):")
print(df[df['city'].isin(['부산', '대구'])])

# 위와 동일한 결과를 '|' 연산자로 구현
print("\n4.2. `|` 연산자를 사용한 'city' 필터링 ('부산' 또는 '대구'):")
print(df[(df['city'] == '부산') | (df['city'] == '대구')])
print("  - 단일 컬럼에 대한 다중 OR 조건은 `isin()`이 더 간결하고 가독성이 좋습니다.")
print("  - `|` 연산자는 서로 다른 컬럼 간의 OR 조건에 더 적합합니다.")


print("\n--- 5. `isin()`에 `NaN` 값 포함 시 ---")

df_nan_example = pd.DataFrame({
    'col_A': [1, 2, 3, np.nan, 5],
    'col_B': ['X', 'Y', 'Z', 'X', np.nan]
})
print("\n5.1. 결측치 포함 DataFrame:\n", df_nan_example)

# col_A가 2 또는 NaN인 행
print("\n5.2. col_A가 2 또는 NaN인 행:")
print(df_nan_example[df_nan_example['col_A'].isin([2, np.nan])])
print("  - `isin()`은 `np.nan`을 포함하는지 여부도 정확히 판단합니다.")

# col_B가 'X' 또는 NaN인 행
print("\n5.3. col_B가 'X' 또는 NaN인 행:")
print(df_nan_example[df_nan_example['col_B'].isin(['X', np.nan])])
```

#### 1.2.5. `query()` 메서드를 이용한 조건 검색

`query()` 메서드는 Pandas `DataFrame`에서 SQL과 유사한 문자열 기반의 조건식을 사용하여 데이터를 필터링할 수 있게 해주는 강력하고 편리한 기능입니다. 복잡한 조건식을 작성할 때 코드의 가독성을 크게 높일 수 있으며, 특히 컬럼 이름에 공백이나 특수 문자가 포함된 경우 유용하게 활용됩니다.

**`query()` 메서드의 장점**:
*   **가독성**: 조건식을 문자열 형태로 직접 작성하므로, 여러 불리언 조건식을 괄호와 비트wise 연산자로 연결하는 것보다 직관적이고 읽기 쉽습니다.
*   **편의성**: 컬럼 이름을 직접 참조할 수 있어 `df['column_name']`과 같은 반복적인 구문을 피할 수 있습니다.
*   **공백/특수 문자 컬럼 처리**: 컬럼 이름에 공백이나 특수 문자가 포함된 경우, 해당 컬럼 이름을 백틱(`` ` ``)으로 묶어 쉽게 참조할 수 있습니다.
*   **외부 변수 참조**: `@` 기호를 사용하여 파이썬 스코프 내의 외부 변수를 조건식에 직접 포함시킬 수 있습니다.
*   **성능 최적화**: Pandas 내부적으로 C 엔진을 사용하여 조건식을 파싱하고 평가하므로, 매우 큰 `DataFrame`에서는 불리언 인덱싱보다 성능상 이점을 가질 수 있습니다. (항상 더 빠른 것은 아니며, 데이터 크기와 조건의 복잡성에 따라 다름)

**기본 사용법**:
`df.query('조건식')` 형태로 사용하며, 조건식은 문자열로 작성합니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
```

#### 1.2.6. `np.logical_and/or` 사용 (대안)

Pandas의 불리언 인덱싱에서 복합 조건을 구성할 때 비트wise 연산자(`&`, `|`, `~`)를 사용하는 것이 일반적입니다. 하지만 NumPy의 논리 함수 `np.logical_and()`, `np.logical_or()`, `np.logical_not()`를 사용하여 복합 조건을 구성하는 것도 가능하며, 경우에 따라 코드의 가독성을 높이는 대안이 될 수 있습니다.

**`np.logical_*` 함수의 특징**:
*   **명시성**: 함수 이름 자체가 수행하는 논리 연산을 명확하게 나타내므로, 코드의 의도를 쉽게 파악할 수 있습니다.
*   **인수 처리**: 여러 조건을 콤마(`,`)로 구분하여 인수로 전달할 수 있어, 비트wise 연산자처럼 각 조건을 괄호로 묶을 필요가 없습니다. (단, 각 조건식 자체는 여전히 괄호로 묶는 것이 안전합니다.)
*   **요소별 연산**: Pandas `Series`에 대해 요소별(element-wise) 논리 연산을 수행합니다.
*   **결측치(`NaN`) 처리**: `np.logical_*` 함수는 `NaN` 값을 `False`로 처리하는 경향이 있습니다. 이는 비트wise 연산자와의 미묘한 차이를 만들 수 있으므로 주의해야 합니다. (예: `True & NaN`은 `NaN`이지만, `np.logical_and(True, NaN)`은 `False`를 반환)

**언제 `np.logical_*` 함수를 고려할까?**
*   **가독성 선호**: 비트wise 연산자(`&`, `|`)가 익숙하지 않거나, 코드의 논리 흐름을 더 명시적으로 표현하고 싶을 때.
*   **복잡한 조건**: 매우 많은 조건을 `AND` 또는 `OR`로 연결해야 할 때, `np.logical_*` 함수가 중첩된 겹친 괄호 없이 더 깔끔해 보일 수 있습니다.
*   **NumPy와의 일관성**: 이미 NumPy 배열을 많이 다루고 있어 NumPy의 논리 함수 사용에 익숙한 경우.

**예시 코드 및 출력**:

```python
import numpy as np
import pandas as pd

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민', '김수경', '박영희', '최민수'],
    'kor': [90, 80, 70, 70, 60, 70, 95, 85],
    'eng': [99, 98, 97, 46, 77, 56, 88, 92],
    'mat': [90, 70, 70, 60, 88, 99, 80, 75],
    'city': ['서울', '부산', '서울', '대구', '부산', '서울', '인천', '부산'],
    'grade': ['A', 'B', 'C', 'D', 'C', 'B', 'A', 'B']
}
df = pd.DataFrame(data)
print("--- 원본 DataFrame ---\n", df)

print("\n--- 1. `np.logical_and()` 사용 (AND 조건) ---")

# 1.1. 국어 점수가 70점 이상이고 영어 점수가 90점 이상인 학생
# (df['kor'] >= 70)  -> [True, True, True, True, False, True, True, True]
# (df['eng'] >= 90)  -> [True, True, True, False, False, False, False, True]
# np.logical_and()는 두 불리언 Series를 인수로 받습니다.
print("\n1.1. 국어 점수가 70점 이상이고 영어 점수가 90점 이상인 학생:")
print(df[np.logical_and(df['kor'] >= 70, df['eng'] >= 90)])

# 1.2. 거주 도시가 '서울'이면서 수학 점수가 80점 이상인 학생
print("\n1.2. 거주 도시가 '서울'이면서 수학 점수가 80점 이상인 학생:")
print(df[np.logical_and(df['city'] == '서울', df['mat'] >= 80)])

print("\n--- 2. `np.logical_or()` 사용 (OR 조건) ---")

# 2.1. 국어 점수가 90점 이상이거나 영어 점수가 90점 이상인 학생
print("\n2.1. 국어 점수가 90점 이상이거나 영어 점수가 90점 이상인 학생:")
print(df[np.logical_or(df['kor'] >= 90, df['eng'] >= 90)])

# 2.2. 거주 도시가 '부산'이거나 '대구'인 학생
print("\n2.2. 거주 도시가 '부산'이거나 '대구'인 학생:")
print(df[np.logical_or(df['city'] == '부산', df['city'] == '대구')])

print("\n--- 3. `np.logical_not()` 사용 (NOT 조건) ---")

# 3.1. 국어 점수가 80점 미만이 아닌 학생 (즉, 80점 이상인 학생)
print("\n3.1. 국어 점수가 80점 미만이 아닌 학생:")
print(df[np.logical_not(df['kor'] < 80)])

# 3.2. 거주 도시가 '서울'이 아닌 학생
print("\n3.2. 거주 도시가 '서울'이 아닌 학생:")
print(df[np.logical_not(df['city'] == '서울')])

print("\n--- 4. 여러 조건을 `np.logical_*` 함수로 연결 ---")

# 4.1. 국어 점수가 80점 이상이고, 영어 점수가 90점 이상이며, 도시가 '서울'인 학생
condition_kor = df['kor'] >= 80
condition_eng = df['eng'] >= 90
condition_city = df['city'] == '서울'

print("\n4.1. 국어 점수가 80점 이상이고, 영어 점수가 90점 이상이며, 도시가 '서울'인 학생:")
print(df[np.logical_and(condition_kor, np.logical_and(condition_eng, condition_city))])
# 또는 더 간결하게:
# print(df[np.logical_and.reduce([condition_kor, condition_eng, condition_city])])

print("\n--- 5. 결측치(`NaN`) 처리 시 주의사항 ---")

df_nan_example = pd.DataFrame({
    'A': [1, 2, np.nan, 4],
    'B': [True, False, True, np.nan],
    'C': ['X', 'Y', 'X', 'Z']
})
print("\n5.1. 결측치 포함 DataFrame:\n", df_nan_example)

# 'A'가 2보다 크고 'B'가 True인 경우 (np.logical_and vs &)
# np.logical_and는 NaN을 False로 처리하는 경향이 있습니다.
print("\n5.2. 'A' > 2 이고 'B' == True 인 경우 (np.logical_and):")
print(df_nan_example[np.logical_and(df_nan_example['A'] > 2, df_nan_example['B'] == True)])
# 결과: A=4, B=NaN인 행은 (4>2=True, NaN==True=False) -> False
#       A=NaN, B=True인 행은 (NaN>2=False, True==True=True) -> False
#       (np.logical_and(False, True) = False)

print("\n5.3. 'A' > 2 이고 'B' == True 인 경우 (& 연산자):")
print(df_nan_example[(df_nan_example['A'] > 2) & (df_nan_example['B'] == True)])
# 결과: A=4, B=NaN인 행은 (4>2=True, NaN==True=False) -> False
#       A=NaN, B=True인 행은 (NaN>2=False, True==True=True) -> NaN (필터링 시 제외)
# 이 예시에서는 동일한 결과를 보이지만, NaN 처리 방식에 따라 미묘한 차이가 발생할 수 있습니다.
# 일반적으로 비트wise 연산자는 NaN을 전파(propagate)하는 반면, np.logical_* 함수는 NaN을 False로 간주하는 경향이 있습니다.
```

#### 1.2.7. 오류 예시 (`and`, `or` 사용 시)

Pandas `DataFrame`에서 복합 조건을 사용하여 데이터를 필터링할 때, 파이썬의 기본 논리 연산자 `and`, `or`, `not`을 사용하는 것은 흔한 실수이며 `ValueError`를 발생시킵니다. 이는 Pandas `Series`가 파이썬의 단일 불리언 값처럼 동작하지 않기 때문입니다.

**왜 `ValueError`가 발생하는가?**
*   **파이썬의 `and`, `or`**: 이 연산자들은 단일 불리언 값(예: `True`, `False`) 또는 불리언으로 평가될 수 있는 객체(예: `0`, `[]`, `None` 등)에 대해 작동합니다. 예를 들어 `if condition1 and condition2:`와 같이 사용될 때, `condition1`과 `condition2`는 각각 단일 `True` 또는 `False`로 평가되어야 합니다.
*   **Pandas `Series`**: `df['kor'] >= 80`과 같은 조건식은 단일 `True` 또는 `False`가 아니라, `DataFrame`의 각 행에 대한 `True`/`False` 값을 담고 있는 `Series` 객체를 반환합니다. (예: `[True, False, True, True]`)
*   **모호성 오류**: 파이썬 인터프리터는 `Series` 객체 전체를 단일 불리언 값으로 명확하게 평가할 수 없기 때문에 "The truth value of a Series is ambiguous" (`Series`의 참/거짓 값이 모호합니다)라는 `ValueError`를 발생시킵니다. 즉, `Series` 내부에 `True`와 `False`가 섞여 있을 때, 이 `Series` 전체가 `True`인지 `False`인지 판단할 수 없다는 의미입니다.

**해결책**:
Pandas에서는 `Series`의 각 요소에 대해 논리 연산을 수행하는 **비트wise 논리 연산자**를 사용해야 합니다.
*   **`&` (AND)**: 파이썬의 `and` 대신 사용합니다.
*   **`|` (OR)**: 파이썬의 `or` 대신 사용합니다.
*   **`~` (NOT)**: 파이썬의 `not` 대신 사용합니다.

또한, 각 개별 조건식은 연산자 우선순위 문제로 인해 **반드시 괄호 `()`로 묶어야** 합니다. 비교 연산자(`>=`, `==` 등)의 우선순위가 비트wise 연산자(`&`, `|`)보다 높기 때문에, 괄호로 묶지 않으면 예상치 못한 오류가 발생하거나 잘못된 결과가 나올 수 있습니다.

**예시 코드 및 출력**:

```python
import pandas as pd
import numpy as np

# 예시 데이터프레임 생성
data = {
    'name': ['홍길동', '임꺽정', '장길산', '홍경래', '이상민'],
    'kor': [90, 80, 70, 60, 50],
    'eng': [95, 85, 75, 65, 55]
}
df = pd.DataFrame(data)
print("--- 원본 DataFrame ---\n", df)

print("\n--- 1. `and` 사용 시 오류 예시 ---")
try:
    # 잘못된 사용: df['kor'] >= 70 과 df['eng'] >= 80 은 Series 객체임
    df_error_and = df[df['kor'] >= 70 and df['eng'] >= 80]
    print(df_error_and)
except ValueError as e:
    print(f"\n오류 발생 (파이썬 'and' 사용 시): {e}")
    print("설명: Pandas Series는 단일 불리언 값으로 평가될 수 없으므로 'and' 연산자를 직접 사용할 수 없습니다.")

print("\n--- 2. `or` 사용 시 오류 예시 ---")
try:
    # 잘못된 사용: df['kor'] >= 90 또는 df['eng'] >= 90 은 Series 객체임
    df_error_or = df[df['kor'] >= 90 or df['eng'] >= 90]
    print(df_error_or)
except ValueError as e:
    print(f"\n오류 발생 (파이썬 'or' 사용 시): {e}")
    print("설명: Pandas Series는 단일 불리언 값으로 평가될 수 없으므로 'or' 연산자를 직접 사용할 수 없습니다.")

print("\n--- 3. `not` 사용 시 오류 예시 ---")
try:
    # 잘못된 사용: not (df['kor'] >= 80) 은 Series 객체에 대해 작동하지 않음
    df_error_not = df[not (df['kor'] >= 80)]
    print(df_error_not)
except ValueError as e:
    print(f"\n오류 발생 (파이썬 'not' 사용 시): {e}")
    print("설명: Pandas Series는 단일 불리언 값으로 평가될 수 없으므로 'not' 연산자를 직접 사용할 수 없습니다.")
except TypeError as e: # Python 3.8+에서는 TypeError 발생 가능
    print(f"\n오류 발생 (파이썬 'not' 사용 시): {e}")
    print("설명: Pandas Series에 대해 파이썬의 'not' 연산자를 직접 사용할 수 없습니다.")


print("\n--- 4. 올바른 사용 예시 (비트wise 연산자 `&`, `|`, `~` 사용) ---")

# 4.1. 국어 점수가 70점 이상이고 영어 점수가 80점 이상인 학생 (AND)
print("\n4.1. 국어 점수가 70점 이상이고 영어 점수가 80점 이상인 학생:")
print(df[(df['kor'] >= 70) & (df['eng'] >= 80)])

# 4.2. 국어 점수가 90점 이상이거나 영어 점수가 90점 이상인 학생 (OR)
print("\n4.2. 국어 점수가 90점 이상이거나 영어 점수가 90점 이상인 학생:")
print(df[(df['kor'] >= 90) | (df['eng'] >= 90)])

# 4.3. 국어 점수가 80점 미만이 아닌 학생 (NOT)
print("\n4.3. 국어 점수가 80점 미만이 아닌 학생:")
print(df[~(df['kor'] < 80)])

# 4.4. 복합 조건과 괄호의 중요성
# (df['kor'] >= 70) & (df['eng'] >= 80) | (df['name'] == '이상민')
# 괄호가 없으면 연산자 우선순위 때문에 예상과 다른 결과가 나올 수 있습니다.
# (df['kor'] >= 70) & ((df['eng'] >= 80) | (df['name'] == '이상민'))
# 위와 같이 명확하게 괄호를 사용하여 의도를 표현하는 것이 중요합니다.
print("\n4.4. 국어 점수가 70점 이상이고 (영어 점수가 80점 이상이거나 이름이 '이상민'인) 학생:")
print(df[(df['kor'] >= 70) & ((df['eng'] >= 80) | (df['name'] == '이상민'))])
```
