## 1. 라벨 기반 인덱싱: `loc`와 `at`

Pandas의 `loc`와 `at`는 **라벨(label)** 기반의 인덱싱을 수행하는 데 사용됩니다. 즉, 행과 열의 이름(라벨)을 사용하여 데이터를 선택합니다. 이는 정수 위치 기반의 인덱싱(`iloc`, `iat`)과 명확히 구분되는 중요한 특징입니다.

### 1.1. `loc` (Label-location based indexer)

`loc`는 라벨을 사용하여 DataFrame의 행과 열을 선택하는 가장 강력하고 유연한 방법입니다. 단일 라벨, 라벨 리스트, 라벨 슬라이스, 불리언 배열 등 다양한 방식으로 사용할 수 있습니다.

`df.loc[행 선택, 열 선택]` 형태로 사용하며, `열 선택` 부분은 생략 가능합니다.

```python
import pandas as pd
import numpy as np

# 예제 DataFrame 생성
df_loc = pd.DataFrame({
    'col1': [1, 2, 3, 4, 5],
    'col2': [6, 7, 8, 9, 10],
    'col3': [11, 12, 13, 14, 15]
}, index=['row1', 'row2', 'row3', 'row4', 'row5'])
print("원본 DataFrame (loc 예제):")
print(df_loc)

# 1. 단일 행 선택
print("\n1. 단일 행 선택 ('row3'):")
print(df_loc.loc['row3'])

# 2. 여러 행 선택 (리스트)
print("\n2. 여러 행 선택 (['row1', 'row5']):")
print(df_loc.loc[['row1', 'row5']])

# 3. 행 슬라이싱 (라벨 기반, 끝점 포함)
print("\n3. 행 슬라이싱 ('row2':'row4', 끝점 포함):")
print(df_loc.loc['row2':'row4'])

# 4. 단일 값 선택 (행 라벨, 열 라벨)
print("\n4. 단일 값 선택 ('row3', 'col2'):")
print(df_loc.loc['row3', 'col2'])

# 5. 특정 행의 여러 열 선택
print("\n5. 특정 행 ('row2')의 여러 열 (['col1', 'col3']) 선택:")
print(df_loc.loc['row2', ['col1', 'col3']])

# 6. 여러 행의 여러 열 선택
print("\n6. 여러 행 (['row1', 'row4'])의 여러 열 (['col2', 'col3']) 선택:")
print(df_loc.loc[['row1', 'row4'], ['col2', 'col3']])

# 7. 불리언 인덱싱 (행 선택)
print("\n7. 불리언 인덱싱 (col1이 3보다 큰 행):")
print(df_loc.loc[df_loc['col1'] > 3])

# 8. 불리언 인덱싱과 열 선택 결합
print("\n8. 불리언 인덱싱 (col1이 3보다 큰 행)과 특정 열 ('col2') 선택:")
print(df_loc.loc[df_loc['col1'] > 3, 'col2'])

# 9. 모든 행 선택 및 특정 열 선택
print("\n9. 모든 행 선택 및 특정 열 (['col1', 'col3']) 선택:")
print(df_loc.loc[:, ['col1', 'col3']])

# 10. 값 할당 (단일 값)
print("\n10. 'row3', 'col2'에 99 할당 후 DataFrame:")
df_loc.loc['row3', 'col2'] = 99
print(df_loc)

# 11. 값 할당 (여러 값)
print("\n11. 'row1'과 'row5'의 'col1'에 각각 100, 200 할당 후 DataFrame:")
df_loc.loc[['row1', 'row5'], 'col1'] = [100, 200]
print(df_loc)

# 12. 값 할당 (불리언 인덱싱)
print("\n12. col1이 100보다 큰 행의 col3에 500 할당 후 DataFrame:")
df_loc.loc[df_loc['col1'] > 100, 'col3'] = 500
print(df_loc)
```

**`loc` 사용 시 중요 사항:**
- `loc`는 항상 **라벨**을 기반으로 작동합니다. 정수 인덱스를 사용하더라도, 그것이 라벨로 지정된 경우에만 작동합니다.
- 슬라이싱(`start:end`)을 사용할 때, `loc`는 `end` 라벨을 **포함**합니다. 이는 Python의 기본 슬라이싱(끝점 미포함)과 다릅니다.
- `loc`를 사용하여 값을 할당할 수 있습니다. 이는 원본 DataFrame을 직접 수정합니다.
- `loc`는 Series와 DataFrame 모두에서 사용할 수 있습니다.

### 1.2. `at` (At-location based accessor)

`at`는 `loc`와 유사하게 라벨 기반으로 작동하지만, **단일 스칼라 값**을 빠르고 효율적으로 접근하거나 설정할 때 사용됩니다. `loc`보다 훨씬 빠르지만, 단일 값에만 적용할 수 있다는 제약이 있습니다.

`df.at[행 라벨, 열 라벨]` 형태로 사용합니다.

```python
# 예제 DataFrame (위에서 사용한 df_loc 재활용)
print("원본 DataFrame (at 예제):")
print(df_loc)

# 1. 단일 값 접근
value_at = df_loc.at['row2', 'col2']
print("\n1. 'row2', 'col2'의 값 (at):", value_at)

# 2. 단일 값 설정
df_loc.at['row2', 'col2'] = 777
print("\n2. 'row2', 'col2'에 777 할당 후 DataFrame:")
print(df_loc)
```

**`at` 사용 시 중요 사항:**
- `at`는 오직 단일 행 라벨과 단일 열 라벨을 사용하여 단일 스칼라 값에 접근하거나 설정할 때만 사용합니다.
- `loc`보다 성능이 중요할 때 단일 값 접근/설정에 유용합니다.

### `loc`와 `at`의 차이점 요약

| 특징         | `loc`                                  | `at`                                   |
|--------------|----------------------------------------|----------------------------------------|
| **목적**     | 라벨 기반의 다양한 선택 및 할당        | 단일 스칼라 값의 빠른 접근 및 할당     |
| **입력**     | 단일 라벨, 라벨 리스트, 슬라이스, 불리언 | 단일 라벨 (행), 단일 라벨 (열)         |
| **반환**     | Series, DataFrame, 스칼라 값           | 스칼라 값                              |
| **성능**     | 유연하지만 `at`보다 느릴 수 있음       | 단일 값 접근/설정 시 `loc`보다 빠름    |
| **유연성**   | 높음                                   | 낮음 (단일 값에 한정)                  |

## 2. 정수 위치 기반 인덱싱: `iloc`와 `iat`

Pandas의 `iloc`와 `iat`는 **정수 위치(integer position)** 기반의 인덱싱을 수행하는 데 사용됩니다. 즉, 행과 열의 0부터 시작하는 정수 인덱스를 사용하여 데이터를 선택합니다. 이는 라벨 기반의 인덱싱(`loc`, `at`)과 명확히 구분되는 중요한 특징입니다.

### 2.1. `iloc` (Integer-location based indexer)

`iloc`는 정수 위치를 사용하여 DataFrame의 행과 열을 선택하는 강력하고 유연한 방법입니다. 단일 정수, 정수 리스트, 정수 슬라이스, 불리언 배열 등 다양한 방식으로 사용할 수 있습니다.

`df.iloc[행 위치, 열 위치]` 형태로 사용하며, `열 위치` 부분은 생략 가능합니다.

```python
import pandas as pd
import numpy as np

# 예제 DataFrame 생성
df_iloc = pd.DataFrame({
    'col_A': [10, 20, 30, 40, 50],
    'col_B': [60, 70, 80, 90, 100],
    'col_C': [110, 120, 130, 140, 150]
}, index=['first', 'second', 'third', 'fourth', 'fifth'])
print("원본 DataFrame (iloc 예제):")
print(df_iloc)

# 1. 단일 행 선택 (인덱스 2, 즉 'third' 행)
print("\n1. 단일 행 선택 (인덱스 2):")
print(df_iloc.iloc[2])

# 2. 여러 행 선택 (리스트, 인덱스 0과 4)
print("\n2. 여러 행 선택 ([0, 4]):")
print(df_iloc.iloc[[0, 4]])

# 3. 행 슬라이싱 (정수 위치 기반, 끝점 미포함)
print("\n3. 행 슬라이싱 (1:4, 인덱스 1, 2, 3 포함):")
print(df_iloc.iloc[1:4])

# 4. 단일 값 선택 (행 위치, 열 위치)
print("\n4. 단일 값 선택 (행 인덱스 2, 열 인덱스 1):")
print(df_iloc.iloc[2, 1])

# 5. 특정 행의 여러 열 선택
print("\n5. 특정 행 (인덱스 1)의 여러 열 ([0, 2]) 선택:")
print(df_iloc.iloc[1, [0, 2]])

# 6. 여러 행의 여러 열 선택
print("\n6. 여러 행 ([0, 3])의 여러 열 ([1, 2]) 선택:")
print(df_iloc.iloc[[0, 3], [1, 2]])

# 7. 불리언 인덱싱 (행 선택, loc와 동일하게 작동)
print("\n7. 불리언 인덱싱 (col_A가 30보다 큰 행):")
print(df_iloc.iloc[df_iloc['col_A'] > 30])

# 8. 모든 행 선택 및 특정 열 선택
print("\n8. 모든 행 선택 및 특정 열 ([0, 2]) 선택:")
print(df_iloc.iloc[:, [0, 2]])

# 9. 값 할당 (단일 값)
print("\n9. 행 인덱스 2, 열 인덱스 1에 999 할당 후 DataFrame:")
df_iloc.iloc[2, 1] = 999
print(df_iloc)

# 10. 값 할당 (여러 값)
print("\n10. 행 인덱스 0과 4의 열 인덱스 0에 각각 1000, 2000 할당 후 DataFrame:")
df_iloc.iloc[[0, 4], 0] = [1000, 2000]
print(df_iloc)
```

**`iloc` 사용 시 중요 사항:**
- `iloc`는 항상 **정수 위치**를 기반으로 작동합니다. 행 라벨이나 열 라벨과는 무관합니다.
- 슬라이싱(`start:end`)을 사용할 때, `iloc`는 `end` 위치를 **포함하지 않습니다**. 이는 Python의 기본 슬라이싱과 동일합니다.
- `iloc`를 사용하여 값을 할당할 수 있습니다. 이는 원본 DataFrame을 직접 수정합니다.
- `iloc`는 Series와 DataFrame 모두에서 사용할 수 있습니다.

### 2.2. `iat` (At-location based accessor by integer position)

`iat`는 `iloc`와 유사하게 정수 위치 기반으로 작동하지만, **단일 스칼라 값**을 빠르고 효율적으로 접근하거나 설정할 때 사용됩니다. `iloc`보다 훨씬 빠르지만, 단일 값에만 적용할 수 있다는 제약이 있습니다.

`df.iat[행 위치, 열 위치]` 형태로 사용합니다.

```python
# 예제 DataFrame (위에서 사용한 df_iloc 재활용)
print("원본 DataFrame (iat 예제):")
print(df_iloc)

# 1. 단일 값 접근
value_iat = df_iloc.iat[1, 1]
print("\n1. 행 인덱스 1, 열 인덱스 1의 값 (iat):", value_iat)

# 2. 단일 값 설정
df_iloc.iat[1, 1] = 888
print("\n2. 행 인덱스 1, 열 인덱스 1에 888 할당 후 DataFrame:")
print(df_iloc)
```

**`iat` 사용 시 중요 사항:**
- `iat`는 오직 단일 행 위치와 단일 열 위치를 사용하여 단일 스칼라 값에 접근하거나 설정할 때만 사용합니다.
- `iloc`보다 성능이 중요할 때 단일 값 접근/설정에 유용합니다.

### `iloc`와 `iat`의 차이점 요약

| 특징         | `iloc`                                 | `iat`                                  |
|--------------|----------------------------------------|----------------------------------------|
| **목적**     | 정수 위치 기반의 다양한 선택 및 할당   | 단일 스칼라 값의 빠른 접근 및 할당     |
| **입력**     | 단일 정수, 정수 리스트, 슬라이스, 불리언 | 단일 정수 (행), 단일 정수 (열)         |
| **반환**     | Series, DataFrame, 스칼라 값           | 스칼라 값                              |
| **성능**     | 유연하지만 `iat`보다 느릴 수 있음      | 단일 값 접근/설정 시 `iloc`보다 빠름   |
| **유연성**   | 높음                                   | 낮음 (단일 값에 한정)                  |

## 3. MultiIndex에서의 고급 인덱싱

Pandas의 MultiIndex(계층적 인덱스)는 DataFrame이나 Series에 여러 레벨의 인덱스를 부여하여 데이터를 보다 구조적으로 관리할 수 있게 합니다. MultiIndex에서의 데이터 선택은 일반적인 단일 인덱스보다 복잡할 수 있지만, `loc`와 `xs` 같은 도구를 사용하면 매우 강력하고 유연하게 데이터를 다룰 수 있습니다.

### 3.1. MultiIndex DataFrame 생성

먼저 MultiIndex DataFrame을 생성하는 방법을 살펴보겠습니다.

```python
import pandas as pd
import numpy as np

# MultiIndex 생성
index_tuples = [
    ('Seoul', 2020),
    ('Seoul', 2021),
    ('Busan', 2020),
    ('Busan', 2021),
    ('Jeju', 2020),
    ('Jeju', 2021)
]
multi_index = pd.MultiIndex.from_tuples(index_tuples, names=['City', 'Year'])

# MultiIndex DataFrame 생성
df_multi = pd.DataFrame(
    np.random.randint(10, 100, size=(6, 3)),
    index=multi_index,
    columns=['Temp', 'Humidity', 'Precipitation']
)
print("원본 MultiIndex DataFrame:")
print(df_multi)
```

### 3.2. `loc`를 이용한 MultiIndex 선택

MultiIndex DataFrame에서 `loc`를 사용하는 것이 가장 일반적이고 강력한 방법입니다. 각 레벨의 인덱스를 튜플 형태로 전달하여 선택합니다.

```python
# 1. 첫 번째 레벨 인덱스 선택
print("\n1. 첫 번째 레벨 인덱스 ('Seoul') 선택:")
print(df_multi.loc['Seoul'])

# 2. 특정 레벨의 조합 선택
print("\n2. 특정 레벨의 조합 (('Seoul', 2021)) 선택:")
print(df_multi.loc[('Seoul', 2021)])

# 3. 여러 레벨의 조합 선택 (리스트)
print("\n3. 여러 레벨의 조합 (['Seoul', 2020), ('Busan', 2021)]) 선택:")
print(df_multi.loc[[
    ('Seoul', 2020),
    ('Busan', 2021)
]])

# 4. 슬라이싱을 이용한 범위 선택 (첫 번째 레벨)
print("\n4. 슬라이싱을 이용한 범위 선택 ('Busan':'Jeju'):")
print(df_multi.loc['Busan':'Jeju'])

# 5. 내부 레벨 슬라이싱 (outer level이 정렬되어 있어야 함)
# df_multi = df_multi.sort_index() # 정렬되어 있지 않다면 먼저 정렬해야 함
print("\n5. 내부 레벨 슬라이싱 (모든 City의 2020년 데이터):")
print(df_multi.loc[(slice(None), 2020), :]) # slice(None)은 모든 값을 의미

# 6. 특정 레벨의 값과 특정 컬럼 선택
print("\n6. 특정 레벨의 값 (('Seoul', 2020))과 특정 컬럼 ('Temp') 선택:")
print(df_multi.loc[('Seoul', 2020), 'Temp'])

# 7. 특정 레벨의 값과 여러 컬럼 선택
print("\n7. 특정 레벨의 값 (('Busan', 2021))과 여러 컬럼 (['Humidity', 'Precipitation']) 선택:")
print(df_multi.loc[('Busan', 2021), ['Humidity', 'Precipitation']])

# 8. 불리언 인덱싱과 결합
print("\n8. 불리언 인덱싱 (Temp가 50보다 큰 'Seoul' 데이터)과 결합:")
print(df_multi.loc['Seoul'].loc[df_multi.loc['Seoul', 'Temp'] > 50])
```

**`loc`와 `slice(None)`:**
- `slice(None)`은 MultiIndex에서 특정 레벨의 모든 값을 선택할 때 사용됩니다. 이는 `:`와 동일한 의미를 가집니다.
- 예: `df_multi.loc[(slice(None), 2020), :]`는 모든 `City`에 대해 `Year`가 2020인 데이터를 선택합니다.

### 3.3. `xs` (Cross-section)를 이용한 MultiIndex 선택

`xs` 메서드는 MultiIndex에서 특정 레벨의 데이터를 교차 선택(cross-section)하는 데 유용합니다. `loc`보다 특정 상황에서 더 직관적이고 간결한 코드를 작성할 수 있습니다.

`df.xs(key, level=None, drop_level=True)` 형태로 사용합니다.

```python
# 1. 특정 레벨의 값 선택 (level 지정)
print("\n1. 'Year' 레벨에서 2020년 데이터 선택:")
print(df_multi.xs(2020, level='Year'))

# 2. 특정 레벨의 값 선택 (level 이름 지정)
print("\n2. 'City' 레벨에서 'Busan' 데이터 선택:")
print(df_multi.xs('Busan', level='City'))

# 3. 여러 레벨의 값 선택 (튜플로 key 전달)
print("\n3. 'City'가 'Seoul'이고 'Year'가 2021인 데이터 선택:")
print(df_multi.xs(('Seoul', 2021), level=['City', 'Year']))

# 4. `drop_level=False`로 레벨 유지
print("\n4. 'Year' 레벨에서 2020년 데이터 선택 (레벨 유지):")
print(df_multi.xs(2020, level='Year', drop_level=False))

# 5. 컬럼 레벨에서 교차 선택 (MultiIndex Columns인 경우)
# 예시를 위해 컬럼에 MultiIndex를 부여
multi_columns = pd.MultiIndex.from_tuples([
    ('Weather', 'Temp'),
    ('Weather', 'Humidity'),
    ('CityInfo', 'Population')
], names=['Category', 'Metric'])

df_multi_cols = pd.DataFrame(
    np.random.randint(10, 100, size=(6, 3)),
    index=multi_index,
    columns=multi_columns
)
print("\nMultiIndex Columns DataFrame:")
print(df_multi_cols)

print("\n'Weather' 카테고리의 모든 데이터 선택:")
print(df_multi_cols.xs('Weather', level='Category', axis=1))

print("\n'Metric' 레벨에서 'Temp' 컬럼 선택:")
print(df_multi_cols.xs('Temp', level='Metric', axis=1))
```

**`xs` 사용 시 중요 사항:**
- `key`: 선택하려는 레벨의 값입니다.
- `level`: `key`가 속한 레벨의 이름 또는 정수 위치입니다.
- `axis`: 인덱스 레벨에서 교차 선택할지(0 또는 'index'), 컬럼 레벨에서 교차 선택할지(1 또는 'columns') 지정합니다. 기본값은 0입니다.
- `drop_level`: 선택된 레벨을 결과 DataFrame에서 제거할지 여부를 지정합니다. 기본값은 `True`입니다.

### 3.4. `loc`와 `xs`의 비교

| 특징         | `loc`                                  | `xs`                                   |
|--------------|----------------------------------------|----------------------------------------|
| **목적**     | 라벨 기반의 일반적인 선택 및 할당      | MultiIndex에서 특정 레벨의 교차 선택   |
| **유연성**   | 매우 높음 (다양한 인덱싱 방식 지원)    | 특정 레벨 선택에 특화                 |
| **사용법**   | `df.loc[행, 열]`                       | `df.xs(key, level, axis)`              |
| **성능**     | `xs`가 특정 교차 선택 상황에서 더 빠를 수 있음 | 특정 교차 선택 상황에서 `loc`보다 빠름 |
| **주요 장점**| 모든 라벨 기반 선택 가능               | MultiIndex에서 특정 레벨의 데이터 추출이 간결 |

일반적으로 `loc`는 MultiIndex를 포함한 모든 라벨 기반 인덱싱에 대한 '만능 도구'이며, `xs`는 MultiIndex에서 특정 레벨을 기준으로 데이터를 추출할 때 코드의 가독성과 간결성을 높이는 데 유용합니다.

이 문서를 통해 Pandas DataFrame에서 데이터를 선택하고 접근하는 다양한 고급 인덱싱 기법을 이해하고, `loc`, `iloc`, `at`, `iat`의 정확한 사용법과 차이점을 파악하며, MultiIndex에서의 효율적인 데이터 선택 방법을 학습하셨기를 바랍니다.
