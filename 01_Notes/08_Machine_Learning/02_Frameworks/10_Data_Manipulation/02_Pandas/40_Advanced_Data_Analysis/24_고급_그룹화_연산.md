### 1. `agg()` (Aggregation) 메서드

`agg()` 또는 `aggregate()` 메서드는 `groupby`를 통해 생성된 각 그룹에 대해 **하나 이상의 요약 통계(집계)를 한 번에 계산**하기 위해 사용됩니다. `agg`의 핵심은 각 그룹의 데이터를 하나의 요약된 값으로 축소(reduce)하는 것입니다. 결과물은 그룹을 인덱스로 하는 새로운 `DataFrame`이 됩니다.

**1. 단일 컬럼에 여러 함수 적용**

가장 간단한 형태로, 특정 컬럼에 대해 여러 집계 함수를 리스트로 전달하여 한 번에 계산할 수 있습니다.

```python
import pandas as pd
import numpy as np

data = {
    '도시': ['서울', '서울', '부산', '부산', '서울', '부산'],
    '연도': [2020, 2021, 2020, 2021, 2022, 2022],
    '판매량': [100, 150, 80, 120, 130, 90],
    '비용': [50, 70, 40, 60, 65, 45]
}
df = pd.DataFrame(data)
print("Original DataFrame:\n", df)

# 도시별 판매량의 평균, 합계, 최대값, 최소값을 동시에 계산
city_sales_agg = df.groupby('도시')['판매량'].agg(['mean', 'sum', 'max', 'min'])
print("\n도시별 판매량 집계:\n", city_sales_agg)
```

**2. 여러 컬럼에 여러 함수 적용 (딕셔너리 활용)**

딕셔너리를 사용하면 각 컬럼마다 다른 집계 함수들을 유연하게 적용할 수 있습니다.

```python
# 도시별로 판매량은 평균과 합계를, 비용은 최소값과 최대값을 계산
multi_col_agg = df.groupby('도시').agg({
    '판매량': ['mean', 'sum'],
    '비용': ['min', 'max']
})
print("\n여러 컬럼에 여러 함수 적용:\n", multi_col_agg)
```
이 경우, 결과 `DataFrame`의 컬럼은 **다중 인덱스(MultiIndex)** 형태가 됩니다. 예를 들어, '판매량'의 '평균' 데이터에 접근하려면 `multi_col_agg['판매량']['mean']`과 같이 접근해야 합니다.

**3. 컬럼명 직접 지정 (Named Aggregation)**

결과 컬럼명을 더 직관적으로 만들고 싶을 때 **이름있는 집계(Named Aggregation)**를 사용합니다. `agg()` 함수에 `새컬럼명=('대상컬럼', '함수')`와 같은 키워드 인자를 전달하는 방식입니다. 이 방법은 코드가 명확해지고 결과물을 다루기 편해져 가장 권장되는 방식 중 하나입니다.

```python
# 집계 결과 컬럼에 사용자 정의 이름 부여
named_agg = df.groupby('도시').agg(
    평균_판매량=('판매량', 'mean'),
    총_비용=('비용', 'sum'),
    최대_판매량=('판매량', 'max'),
    데이터_개수=('연도', 'count')
)
print("\n컬럼명 변경 (Named Aggregation):\n", named_agg)
```

**4. 사용자 정의 함수 및 `lambda` 활용**

`agg`의 강력함은 내장된 함수 이름(문자열)뿐만 아니라, 사용자가 직접 정의한 함수나 `lambda` 표현식도 사용할 수 있다는 점에서 드러납니다.

```python
# 최대값과 최소값의 차이를 계산하는 함수
def peak_to_peak(arr):
    return arr.max() - arr.min()

# 사용자 정의 함수와 lambda를 함께 사용
custom_agg = df.groupby('도시').agg(
    판매량_범위=('판매량', peak_to_peak),
    비용_분산=('비용', lambda x: np.var(x)) # numpy 함수도 직접 사용 가능
)
print("\n사용자 정의 함수 및 lambda 활용:\n", custom_agg)
```

이처럼 `agg` 메서드를 활용하면, 복잡한 그룹별 요약 정보를 단 몇 줄의 코드로 간결하고 체계적으로 생성할 수 있어 특성 공학(Feature Engineering) 등에서 매우 유용하게 사용됩니다.


### 2. `transform()` 메서드

`transform()` 메서드는 `groupby` 연산의 결과를 **원본 DataFrame과 동일한 인덱스 및 모양으로 변환(transform)**하여 반환하는, 특성 공학(Feature Engineering)의 핵심 도구입니다。

**`agg()` vs `transform()`: 핵심 차이점**

이 둘의 차이를 이해하는 것이 매우 중요합니다.

-   `agg()`: 각 그룹을 **하나의 요약된 값**으로 축소합니다. 결과의 행 개수는 그룹의 수와 같습니다.
-   `transform()`: 각 그룹에 대해 연산을 수행하지만, 그 결과를 **원본의 모든 행에 맞춰 확장**합니다. 결과의 행 개수는 원본 DataFrame과 동일합니다.

| 원본 (`df`) | `df.groupby('도시')['판매량'].mean()` (agg) | `df.groupby('도시')['판매량'].transform('mean')` |
| :--- | :--- | :--- |
| **6 rows** | **2 rows** (그룹 개수) | **6 rows** (원본과 동일) |
| 각 행의 판매량 | 그룹별 평균 판매량 | 각 행이 속한 그룹의 평균 판매량 |

**주요 활용 시나리오**

`transform`은 그룹별 통계치를 활용하여 원본의 모든 행에 대한 새로운 정보를 생성하는 데 특화되어 있습니다.

**1. 그룹별 통계량을 새로운 특성으로 추가**

가장 기본적인 활용법으로, 각 데이터 포인트가 속한 그룹의 대표값을 새로운 컬럼으로 추가합니다.

```python
# 도시별 평균 판매량을 '도시별_평균_판매량' 컬럼으로 추가
df['도시별_평균_판매량'] = df.groupby('도시')['판매량'].transform('mean')
print("\nDataFrame에 그룹별 평균 추가:\n", df)
```

**2. 그룹 내 편차 및 순위 계산**

각 데이터가 그룹 평균에서 얼마나 떨어져 있는지, 또는 그룹 내에서 몇 등인지 등을 계산할 수 있습니다.

```python
# 각 판매량이 도시별 평균에서 얼마나 차이나는지 계산
df['평균대비_판매량_차이'] = df['판매량'] - df.groupby('도시')['판매량'].transform('mean')

# 도시 내 판매량 순위 계산
df['도시별_판매량_순위'] = df.groupby('도시')['판매량'].rank(method='max', ascending=False)
print("\n그룹 내 편차 및 순위 추가:\n", df)
```

**3. 그룹별 정규화 (Group-wise Normalization)**

데이터의 스케일을 그룹별 특성에 맞춰 조정합니다. 이는 전체 데이터를 한 번에 정규화하는 것보다 훨씬 정교한 방식입니다.

```python
# Z-score 정규화: (값 - 평균) / 표준편차
# 각 도시 내에서 판매량이 통계적으로 어떤 위치에 있는지 보여줌
df['판매량_Z-score'] = df.groupby('도시')['판매량'].transform(
    lambda x: (x - x.mean()) / x.std()
)
print("\n그룹별 Z-score 정규화:\n", df)
```

**4. 그룹별 결측치(NaN) 대체**

데이터 클리닝에서 매우 유용한 기법입니다. 전체 데이터의 평균이나 중앙값으로 채우는 것보다, 각 데이터가 속한 그룹의 통계량으로 채우는 것이 더 합리적일 때가 많습니다.

```python
# 결측치가 포함된 예제 데이터 생성
df_nan = df[['도시', '판매량']].copy()
df_nan.iloc[0, 1] = np.nan # 서울의 첫 판매량을 NaN으로 변경
print("\n결측치가 있는 원본:\n", df_nan)

# 도시별 판매량의 중앙값(median)으로 결측치 채우기
# 1. transform으로 각 행이 속한 그룹의 중앙값을 구함
group_median = df_nan.groupby('도시')['판매량'].transform('median')
# 2. fillna()를 사용하여 NaN을 그룹별 중앙값으로 대체
df_nan['판매량'] = df_nan['판매량'].fillna(group_median)
print("\n그룹별 중앙값으로 결측치 대체:\n", df_nan)
```

`transform`은 이처럼 그룹의 정보를 개별 행 수준으로 다시 가져와, 풍부한 특성을 만들거나 데이터를 정제하는 데 필수적인 역할을 합니다.

### 3. `filter()` 메서드

`filter()` 메서드는 이름 그대로 그룹화된 데이터에서 **조건을 만족하는 그룹 전체를 걸러내는** 역할을 합니다. 데이터 정제나 특정 조건을 만족하는 그룹만 분석하고 싶을 때 매우 유용합니다.

**`filter()` vs 일반적인 Boolean 인덱싱**

-   **일반 Boolean 인덱싱**: `df[df['판매량'] > 100]`처럼 **각 행(row)**을 기준으로 `True`/`False`를 판단하여 필터링합니다.
-   **`filter()`**: `df.groupby('도시').filter(lambda g: g['판매량'].mean() > 100)`처럼 **각 그룹(group)**에 대한 조건을 계산하고, 그 결과가 `True`인 그룹의 **모든 행**을 남기거나 버립니다.

**동작 방식**

`filter()`에 전달하는 함수(주로 `lambda`)는 각 그룹을 나타내는 `DataFrame`을 인자로 받아서, 최종적으로 **하나의 불리언 값(`True` 또는 `False`)**을 반환해야 합니다.
-   `True` 반환: 해당 그룹의 모든 행을 유지합니다.
-   `False` 반환: 해당 그룹의 모든 행을 제거합니다.

---**주요 활용 시나리오**

**1. 그룹의 크기(데이터 개수)를 기준으로 필터링**

분석에 필요한 최소한의 데이터 수를 확보하지 못한 그룹을 제외할 때 자주 사용됩니다.

```python
# 데이터가 3개 이상인 도시 그룹만 남기기
# 서울(3개), 부산(3개) 모두 조건을 만족하므로 모든 데이터가 남음
filtered_by_size = df.groupby('도시').filter(lambda g: len(g) >= 3)
print("데이터가 3개 이상인 도시:\n", filtered_by_size)

# 데이터가 4개 이상인 도시 그룹만 남기기 (조건을 만족하는 그룹 없음)
filtered_by_size_4 = df.groupby('도시').filter(lambda g: len(g) >= 4)
print("\n데이터가 4개 이상인 도시:\n", filtered_by_size_4) # 결과: Empty DataFrame
```

**2. 그룹의 집계값을 기준으로 필터링**

그룹의 합계, 평균, 표준편차 등 특정 통계량이 조건을 만족하는 그룹만 남깁니다.

```python
# 도시별 '판매량'의 합계가 300 이상인 그룹만 선택
filtered_by_sum = df.groupby('도시').filter(lambda g: g['판매량'].sum() >= 300)
print("\n판매량 합계가 300 이상인 도시:\n", filtered_by_sum)

# 도시별 '비용'의 평균이 55 이하인 그룹만 선택
filtered_by_mean = df.groupby('도시').filter(lambda g: g['비용'].mean() <= 55)
print("\n평균 비용이 55 이하인 도시:\n", filtered_by_mean)
```

**3. 그룹 내 특정 조건을 만족하는 데이터의 존재 여부로 필터링**

그룹 내에 특정 조건을 만족하는 데이터가 하나라도 있는지 여부로 그룹 전체를 필터링할 수 있습니다.

```python
# 그룹 내 '판매량'이 140을 초과하는 데이터가 하나라도 있는 그룹만 선택
# '서울' 그룹은 150이 있으므로 선택됨
filtered_by_any = df.groupby('도시').filter(lambda g: (g['판매량'] > 140).any())
print("\n판매량이 140을 초과하는 건이 있는 도시:\n", filtered_by_any)

# 그룹 내 모든 '연도'가 2020 이상인 그룹만 선택 (모든 그룹이 해당)
filtered_by_all = df.groupby('도시').filter(lambda g: (g['연도'] >= 2020).all())
print("\n모든 데이터가 2020년 이후인 도시:\n", filtered_by_all)
```

`filter()`는 이처럼 그룹 단위의 컨텍스트를 기반으로 데이터를 효과적으로 선별할 수 있게 해주어, 보다 정교한 데이터 전처리와 분석을 가능하게 합니다.


### 4. 실무 활용 시나리오

`agg`, `transform`, `filter`는 이론적인 개념을 넘어 실제 데이터 분석 현장에서 매우 유용하게 사용됩니다. 각 메서드가 어떤 시나리오에서 강력한 힘을 발휘하는지 구체적인 예시를 통해 알아보겠습니다.

**1. 특성 공학 (Feature Engineering)**

머신러닝 모델의 성능을 높이기 위해 기존 데이터로부터 새로운 정보를 담은 변수(특성)를 만들어내는 과정입니다.

-   **고객 행동 패턴 요약 (`agg`)**
    -   **시나리오**: 온라인 쇼핑몰의 고객별 구매 로그 데이터가 있을 때, 각 고객의 특성을 나타내는 지표를 생성하여 VIP 고객을 예측하는 모델을 만들고 싶다.
    -   **활용**: 고객 ID로 `groupby`한 후, `agg`를 사용하여 **고객별 총 구매액, 평균 구매액, 총 구매 횟수, 첫 구매일, 마지막 구매일** 등을 계산합니다. 이렇게 생성된 요약 테이블은 그 자체로 고객을 분류(segmentation)하거나 머신러닝 모델의 중요한 입력 데이터가 됩니다.

-   **그룹 내 상대적 위치 정보 추가 (`transform`)**
    -   **시나리오**: 부동산 매물 데이터에서, 각 매물이 속한 '지역구' 내에서 상대적으로 얼마나 비싼지 또는 싼지를 나타내는 특성을 만들고 싶다.
    -   **활용**: '지역구'로 `groupby`한 후, `transform`을 사용하여 **'지역구별 평당 평균 가격'** 컬럼을 추가합니다. 더 나아가, **'개별 매물 가격 - 지역구별 평균 가격'** 이나 **'개별 매물 가격 / 지역구별 평균 가격'** 과 같은 파생 변수를 만들어 해당 매물이 지역 평균 대비 고가인지, 저가인지를 명확히 보여주는 특성을 생성할 수 있습니다.

**2. 데이터 정제 및 이상치 탐지 (Data Cleaning & Anomaly Detection)**

-   **분석에 부적합한 그룹 제거 (`filter`)**
    -   **시나리오**: 설문조사 데이터에서, 응답 항목이 3개 미만인 불성실 응답자 그룹은 분석의 신뢰도를 떨어뜨릴 수 있어 제거하고 싶다.
    -   **활용**: '응답자 ID'로 `groupby`한 후, `filter(lambda x: len(x) >= 3)`를 적용하여 응답 기록이 부족한 사용자 그룹 전체를 데이터셋에서 제외합니다. 이를 통해 분석의 노이즈를 줄이고 결과의 신뢰도를 높일 수 있습니다.

-   **그룹별 이상치 식별 (`transform`)**
    -   **시나리오**: 여러 공장의 센서 데이터를 분석할 때, 특정 공장의 센서 하나가 유독 튀는 값을 보이는 경우를 찾아내고 싶다. 전체 데이터 기준으로는 정상 범위일 수 있지만, 해당 공장 내에서는 이상치일 수 있다.
    -   **활용**: '공장 ID'와 '센서 ID'로 `groupby`한 후, `transform`을 사용하여 각 센서 그룹별로 Z-score를 계산합니다. Z-score가 특정 임계값(예: 2 또는 3)을 초과하는 데이터를 이상치로 간주하고 원인을 조사하거나, 분석에서 제외하는 등 후속 조치를 취할 수 있습니다.

**3. 그룹별 정규화 및 스케일링 (Group-wise Scaling)**

-   **시나리오**: 여러 명의 학생에 대한 시험 점수 데이터가 있을 때, 각 '과목'의 난이도가 달라 점수 분포가 다르다. 과목 간 난이도 차이를 보정하고 학생의 상대적 성취도를 평가하고 싶다.
-   **활용**: '과목'으로 `groupby`한 후, `transform`을 사용하여 각 과목 내에서 점수를 0과 1 사이로 스케일링(Min-Max Scaling)하거나 표준화(Standardization)합니다. 이를 통해 특정 학생이 수학은 80점, 영어는 75점을 받았더라도, 각 과목 내에서의 상대적 위치를 비교하여 어떤 과목을 더 잘했는지 객관적으로 평가할 수 있습니다.

### 5. 요약 및 선택 가이드

`agg`, `transform`, `filter`는 각기 다른 목적과 반환 형태를 가지므로, 상황에 맞는 메서드를 선택하는 것이 중요합니다. 아래 요약표와 선택 가이드를 통해 세 메서드를 언제 사용해야 할지 명확히 이해해 보세요.

**한눈에 보는 세 가지 메서드 비교**

| 구분 | `agg()` (집계) | `transform()` (변환) | `filter()` (필터링) |
| :--- | :--- | :--- | :--- |
| **목적** | 그룹별 **요약 통계** 계산 | 그룹별 연산으로 **새로운 특성** 생성 | **조건을 만족하는 그룹** 선별 |
| **핵심 질문** | "각 도시의 총 판매량은?" | "각 판매량은 해당 도시 평균 대비 얼마나 차이 나는가?" | "평균 판매량이 100 이상인 도시는 어디인가?" |
| **반환 형태** | **축소됨** (그룹 수 × 집계 함수 수) | **원본과 동일** (원본 행 수 유지) | **일부만 남음** (조건 만족 그룹의 행만 유지) |
| **주요 사용처** | 대시보드용 요약 테이블, 특성 생성 | 특성 공학, 그룹별 정규화, 결측치 대체 | 데이터 정제, 이상치 그룹 제거, 특정 그룹 분석 |

---

**어떤 메서드를 사용해야 할까? (선택 가이드)**

내 분석 목적에 어떤 메서드가 맞는지 헷갈릴 때는, 내가 **최종적으로 원하는 결과물의 형태**가 어떤 모습인지 스스로에게 질문해 보세요.

**질문 1: "그룹별로 요약된 새로운 테이블을 만들고 싶은가?"**

-   **➡️ 예, 그렇습니다.**
-   **✅ `agg()`를 사용하세요.**
-   각 그룹(예: 도시)이 하나의 행이 되고, 각 열에 해당 그룹의 통계치(예: 평균 판매량, 총비용)가 요약된 결과를 원할 때 가장 적합합니다.

**질문 2: "기존 데이터프레임에 그룹별 계산 결과를 담은 새로운 컬럼을 추가하고 싶은가?"**

-   **➡️ 예, 그렇습니다.**
-   **✅ `transform()`을 사용하세요.**
-   원본 데이터의 모든 행을 그대로 유지하면서, 각 행에 자신이 속한 그룹의 정보(예: 도시별 평균 판매량)를 추가하여 새로운 특성을 만들고 싶을 때 사용합니다.

**질문 3: "특정 조건을 만족하는 그룹의 데이터만 남기고, 나머지는 버리고 싶은가?"**

-   **➡️ 예, 그렇습니다.**
-   **✅ `filter()`를 사용하세요.**
-   그룹 전체의 특성(예: 그룹의 데이터 개수, 그룹의 평균값)을 기준으로, 분석에 필요한 그룹만 선별하고 싶을 때 적합합니다.

**질문 4: "위 세 가지 방법으로 해결할 수 없는 더 복잡한 작업을 해야 하는가?"**

-   **➡️ 예, 그렇습니다.**
-   **✅ `apply()`를 고려하세요.** (이전 문서에서 다룸)
-   `apply`는 가장 유연하지만 성능이 느릴 수 있으므로, `agg`, `transform`, `filter`로 해결할 수 없는 복잡한 로직(예: 그룹별 상위 N개 추출)에 최후의 수단으로 사용하는 것이 좋습니다.

이 가이드를 통해 `groupby` 연산 시 마주치는 대부분의 상황에서 가장 효율적이고 적절한 메서드를 자신 있게 선택할 수 있을 것입니다.
