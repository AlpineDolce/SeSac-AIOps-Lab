# 선형 대수: 머신러닝의 언어

**머신러닝에서 데이터를 표현하고 변환하는 데 필수적인 선형 대수의 핵심 개념**

이 섹션은 스칼라, 벡터, 행렬, 텐서 등 선형 대수의 기본 데이터 구조를 이해하고, 덧셈, 곱셈, 전치 등 주요 행렬 연산을 학습합니다. 또한, 항등 행렬, 역행렬, 고유값 분해 등 고급 개념을 통해 데이터의 특징을 추출하고 차원을 축소하는 원리를 파악합니다.

---

### 주요 내용:

- [**01_스칼라_벡터_행렬_텐서.md**](./01_스칼라_벡터_행렬_텐서.md): 선형 대수의 기본 구성 요소인 스칼라, 벡터, 행렬, 텐서의 정의와 역할.
- [**02_행렬_연산.md**](./02_행렬_연산.md): 행렬의 덧셈, 곱셈, 전치 등 기본적인 행렬 연산의 규칙과 의미.
- [**03_항등_역행렬_고유값_분해.md**](./03_항등_역행렬_고유값_분해.md): 항등 행렬, 역행렬, 대각 행렬, 고유값(Eigenvalue)과 고유벡터(Eigenvector)의 개념 및 활용.
- [**04_벡터_내적_외적.md**](./04_벡터_내적_외적.md): 벡터의 내적(Dot Product)과 외적(Cross Product)의 기하학적 의미와 머신러닝에서의 활용.
