## 1. 크롤링 데이터 저장 및 관리

### 1.1. CSV 파일로 저장

CSV(Comma Separated Values) 파일은 데이터를 쉼표(,)로 구분하여 저장하는 가장 일반적이고 간단한 텍스트 파일 형식입니다. 스프레드시트 프로그램이나 다양한 데이터 분석 도구에서 쉽게 읽고 처리할 수 있어, 웹 크롤링 데이터를 저장하는 데 널리 사용됩니다.

```python
import csv
import pandas as pd

# 크롤링으로 수집된 데이터 (예시)
data_to_save = [
    {'title': '웹 크롤링 기초', 'author': '김철수', 'date': '2023-01-01'},
    {'title': '파이썬 Requests 활용', 'author': '이영희', 'date': '2023-01-15'},
    {'title': 'BeautifulSoup으로 데이터 파싱', 'author': '박민수', 'date': '2023-02-01'}
]

# 1. csv 모듈을 사용하여 CSV 파일로 저장
# 대량의 데이터를 한 번에 저장할 때 효율적입니다.
csv_file_path_csv_module = 'crawled_data_csv_module.csv'

# 헤더 (컬럼명) 정의
fieldnames = ['title', 'author', 'date']

with open(csv_file_path_csv_module, 'w', newline='', encoding='utf-8') as csvfile:
    writer = csv.DictWriter(csvfile, fieldnames=fieldnames)

    writer.writeheader() # 헤더 쓰기
    writer.writerows(data_to_save) # 데이터 쓰기

print(f"\nData saved to {csv_file_path_csv_module} using csv module.")

# 2. Pandas DataFrame을 사용하여 CSV 파일로 저장
# 데이터 분석 시 Pandas DataFrame 형태로 데이터를 다루는 경우가 많으므로 편리합니다.
df_data = pd.DataFrame(data_to_save)
csv_file_path_pandas = 'crawled_data_pandas.csv'

df_data.to_csv(csv_file_path_pandas, index=False, encoding='utf-8')
# index=False: DataFrame의 인덱스를 CSV 파일에 저장하지 않습니다.
# encoding='utf-8': 한글 깨짐 방지를 위해 UTF-8 인코딩을 명시합니다.

print(f"Data saved to {csv_file_path_pandas} using Pandas.")

# 저장된 CSV 파일 내용 확인 (선택 사항)
# with open(csv_file_path_pandas, 'r', encoding='utf-8') as f:
#     print("\n--- CSV File Content ---")
#     print(f.read())
```

> CSV 파일은 간단하지만, 인코딩, 구분자, 그리고 데이터 내 특수 문자 처리 등 몇 가지 실무적 고려사항이 있습니다.
> 
> *   **인코딩 (Encoding):**
>     *   한글 데이터가 포함된 경우, `encoding='utf-8'`을 명시하는 것이 중요합니다. 인코딩을 지정하지 않거나 잘못 지정하면 파일이 깨질 수 있습니다.
>     *   `newline=''` (csv 모듈): `csv.writer` 사용 시 `newline=''`을 `open()` 함수에 전달해야 합니다. 이는 운영체제별로 줄바꿈 문자를 다르게 처리하는 문제를 방지합니다.
> *   **구분자 (Delimiter):**
>     *   기본 구분자는 쉼표(`,`)이지만, 데이터 내에 쉼표가 포함될 경우 문제가 될 수 있습니다. 이때는 다른 문자(예: 탭 `	`, 파이프 `|`)를 구분자로 사용할 수 있습니다. (`delimiter='	'`)

### 1.2. JSON 파일로 저장

JSON(JavaScript Object Notation)은 경량의 데이터 교환 형식으로, 사람이 읽고 쓰기 쉽고 기계가 파싱하고 생성하기 쉽습니다. 웹 API에서 데이터를 주고받을 때 널리 사용되며, 계층적인 데이터 구조를 표현하는 데 적합하여 웹 크롤링 데이터를 저장하는 데 유용합니다.

```python
import json
import pandas as pd

# 크롤링으로 수집된 데이터 (예시)
data_to_save = [
    {'title': '웹 크롤링 기초', 'author': '김철수', 'tags': ['python', 'web', 'crawling']},
    {'title': '파이썬 Requests 활용', 'author': '이영희', 'tags': ['requests', 'http']},
    {'title': 'BeautifulSoup으로 데이터 파싱', 'author': '박민수', 'tags': ['beautifulsoup', 'html', 'parsing']}
]

# 1. json 모듈을 사용하여 JSON 파일로 저장
json_file_path_json_module = 'crawled_data_json_module.json'

with open(json_file_path_json_module, 'w', encoding='utf-8') as jsonfile:
    json.dump(data_to_save, jsonfile, ensure_ascii=False, indent=4)
    # ensure_ascii=False: 한글이 유니코드 이스케이프 시퀀스로 변환되지 않도록 합니다.
    # indent=4: JSON 파일을 4칸 들여쓰기하여 보기 좋게 만듭니다.

print(f"\nData saved to {json_file_path_json_module} using json module.")

# 2. Pandas DataFrame을 사용하여 JSON 파일로 저장
# Pandas DataFrame을 JSON으로 저장할 때, orient 옵션으로 다양한 JSON 형식을 지정할 수 있습니다.
df_data = pd.DataFrame(data_to_save)
json_file_path_pandas = 'crawled_data_pandas.json'

# orient='records': 각 로우를 JSON 객체로, 전체를 리스트로 저장 (가장 일반적)
df_data.to_json(json_file_path_pandas, orient='records', indent=4, force_ascii=False)
# force_ascii=False: 한글 깨짐 방지

print(f"Data saved to {json_file_path_pandas} using Pandas.")

# 저장된 JSON 파일 내용 확인 (선택 사항)
# with open(json_file_path_pandas, 'r', encoding='utf-8') as f:
#     print("\n--- JSON File Content ---")
#     print(f.read())
```

> **[실무 노트] JSON 저장 시 고려사항:**
> JSON 파일은 계층적 데이터를 저장하는 데 유리하며, 웹 API 통신에서 주로 사용됩니다. 저장 시 인코딩과 데이터 구조에 유의해야 합니다.
> 
> *   **인코딩 (Encoding):**
>     *   한글 데이터가 포함된 경우, `encoding='utf-8'`과 `ensure_ascii=False` (json 모듈) 또는 `force_ascii=False` (Pandas)를 함께 사용하여 한글이 깨지지 않도록 해야 합니다.
> *   **가독성 (Indentation):**
>     *   `indent` 옵션(json 모듈) 또는 `indent` 파라미터(Pandas)를 사용하여 들여쓰기를 적용하면 JSON 파일의 가독성이 크게 향상됩니다. 이는 디버깅이나 사람이 직접 파일을 확인할 때 매우 유용합니다.
> *   **데이터 구조 (Pandas `orient`):**
>     *   Pandas `to_json()` 메서드의 `orient` 파라미터는 JSON 출력 형식을 결정합니다. `records` (기본값)는 각 로우를 JSON 객체로, 전체를 리스트로 저장하여 가장 일반적인 형태입니다. `columns`는 컬럼을 키로, 각 컬럼의 값 리스트를 값으로 저장합니다. 데이터의 사용 목적에 따라 적절한 형식을 선택해야 합니다.
> *   **대용량 데이터:**
>     *   매우 큰 JSON 파일을 한 번에 메모리에 로드하여 처리하는 것은 비효율적일 수 있습니다. 이 경우, 데이터를 청크(chunk) 단위로 나누어 처리하거나, 스트리밍 파서(streaming parser)를 사용하는 것을 고려해야 합니다.
> *   **스키마 유연성:**
>     *   JSON은 스키마가 유연하여 다양한 형태의 데이터를 저장할 수 있습니다. 이는 웹 크롤링 시 웹 페이지마다 데이터 구조가 조금씩 다를 때 유용합니다. 하지만 데이터 분석 시에는 일관된 스키마로 정제하는 과정이 필요합니다.
>
> JSON 파일은 웹 크롤링 데이터를 저장하고 다른 시스템과 연동하는 데 매우 유용하지만, 데이터의 규모와 복잡성을 고려하여 적절한 저장 전략을 수립해야 합니다.

### 1.3. 데이터베이스에 저장

수집된 데이터가 대량이고, 구조화되어 있으며, 복잡한 쿼리나 분석이 필요할 경우 데이터베이스에 저장하는 것이 가장 효율적입니다. 데이터베이스는 데이터의 무결성을 보장하고, 인덱스를 통해 빠른 검색을 지원하며, SQL을 통해 강력한 분석 기능을 제공합니다. 여기서는 파이썬에서 가장 쉽게 사용할 수 있는 경량 데이터베이스인 SQLite를 예시로 설명합니다.

```python
import sqlite3
import pandas as pd
from sqlalchemy import create_engine

# 크롤링으로 수집된 데이터 (예시)
data_to_save = [
    {'title': '웹 크롤링 기초', 'author': '김철수', 'date': '2023-01-01'},
    {'title': '파이썬 Requests 활용', 'author': '이영희', 'date': '2023-01-15'},
    {'title': 'BeautifulSoup으로 데이터 파싱', 'author': '박민수', 'date': '2023-02-01'}
]

# 1. SQLite 데이터베이스 연결
# SQLAlchemy의 create_engine을 사용하면 Pandas와 쉽게 연동할 수 있습니다.
# sqlite:///crawled_data.db는 현재 디렉토리에 crawled_data.db 파일을 생성합니다.
engine = create_engine('sqlite:///crawled_data.db')

# 2. Pandas DataFrame을 데이터베이스 테이블로 저장
df_data = pd.DataFrame(data_to_save)
table_name = 'articles'

# if_exists 옵션:
# 'fail': 테이블이 존재하면 오류 발생
# 'replace': 테이블이 존재하면 삭제 후 새로 생성
# 'append': 테이블이 존재하면 데이터 추가
df_data.to_sql(table_name, con=engine, if_exists='replace', index=False)

print(f"\nData saved to SQLite database table '{table_name}' using Pandas.")

# 3. 데이터베이스에서 데이터 확인 (선택 사항)
with sqlite3.connect('crawled_data.db') as conn:
    cursor = conn.cursor()
    cursor.execute(f"SELECT * FROM {table_name}")
    rows = cursor.fetchall()
    print("\n--- Data from Database ---")
    for row in rows:
        print(row)

# 4. sqlite3 모듈을 사용하여 직접 데이터 삽입 (Pandas 없이)
# 이 방법은 Pandas DataFrame이 아닌 리스트나 딕셔너리 형태의 데이터를 직접 다룰 때 유용합니다.
with sqlite3.connect('crawled_data_direct.db') as conn_direct:
    cursor_direct = conn_direct.cursor()
    cursor_direct.execute('''
        CREATE TABLE IF NOT EXISTS articles_direct (
            title TEXT,
            author TEXT,
            date TEXT
        )
    ''')
    # 단일 로우 삽입
    cursor_direct.execute("INSERT INTO articles_direct (title, author, date) VALUES (?, ?, ?)",
                          ('새로운 기사', '김작가', '2024-01-01'))
    # 여러 로우 삽입 (executemany)
    more_data = [
        ('또 다른 기사', '이작가', '2024-01-02'),
        ('마지막 기사', '박작가', '2024-01-03')
    ]
    cursor_direct.executemany("INSERT INTO articles_direct (title, author, date) VALUES (?, ?, ?)", more_data)
    conn_direct.commit()
    print("\nData saved to SQLite database directly using sqlite3 module.")
```

> **[실무 노트] 데이터베이스 저장 시 고려사항:**
> 웹 크롤링 데이터를 데이터베이스에 저장할 때는 데이터의 규모, 사용 목적, 그리고 성능 요구사항을 고려해야 합니다.
>
> *   **스키마 정의:**
>     *   데이터베이스에 데이터를 저장하기 전에 테이블 스키마(컬럼명, 데이터 타입, 제약조건)를 명확하게 정의해야 합니다. Pandas `to_sql()`은 기본적으로 DataFrame의 데이터 타입을 기반으로 스키마를 추론하지만, 정확한 데이터 타입과 제약조건(예: `PRIMARY KEY`, `NOT NULL`)을 명시적으로 지정하는 것이 데이터 무결성 유지에 중요합니다.
> *   **중복 데이터 처리:**
>     *   웹 크롤링 시 중복된 데이터가 수집될 수 있습니다. `to_sql()`의 `if_exists` 옵션(`'append'`, `'replace'`) 외에도, 데이터베이스 레벨에서 `INSERT ... ON CONFLICT DO UPDATE` (PostgreSQL) 또는 `INSERT ... ON DUPLICATE KEY UPDATE` (MySQL)와 같은 `UPSERT` 기능을 사용하여 중복을 처리할 수 있습니다.
> *   **성능 최적화 (대량 데이터):**
>     *   **`to_sql()`의 `method='multi'`:** Pandas `to_sql()` 사용 시 `method='multi'` 옵션을 사용하면 여러 로우를 하나의 `INSERT` 문으로 묶어 전송하여 성능을 크게 향상시킬 수 있습니다.
>     *   **`LOAD DATA INFILE` (MySQL):** MySQL의 경우 `LOAD DATA LOCAL INFILE` 명령을 사용하면 CSV 파일 등을 매우 빠르게 데이터베이스에 로드할 수 있습니다. (자세한 내용은 [10_크롤링_성능_최적화.md](./10_크롤링_성능_최적화.md) 참조)
>     *   **트랜잭션:** 대량의 데이터를 삽입할 때는 트랜잭션으로 묶어 처리하여 데이터 일관성을 보장하고 성능을 향상시킵니다.
> *   **데이터베이스 선택:**
>     *   **SQLite:** 개발 및 테스트, 소규모 프로젝트, 로컬 데이터 저장에 적합합니다. 설치 및 관리가 매우 간편합니다.
>     *   **PostgreSQL, MySQL:** 다중 사용자 환경, 대규모 데이터, 높은 동시성, 복잡한 쿼리 처리가 필요한 운영 환경에 적합합니다.
> *   **데이터 모델링:**
>     *   수집된 데이터의 특성과 분석 목적에 맞춰 적절한 데이터 모델링(정규화/비정규화)을 수행하는 것이 중요합니다. 이는 데이터의 효율적인 저장과 검색, 분석에 큰 영향을 미칩니다.
>
> 데이터베이스에 데이터를 저장하는 것은 수집된 데이터를 체계적으로 관리하고, 향후 분석 및 활용을 위한 기반을 마련하는 중요한 단계입니다.
