## 1. 시퀀스 자료구조란?

**시퀀스(Sequence)**는 데이터에 순서(번호)를 붙여 나열한 자료구조입니다. 파이썬에서는 문자열, 리스트, 튜플이 대표적인 시퀀스 자료형이며, 다음과 같은 공통적인 특징을 가집니다.

- **순서(Ordering):** 저장된 요소들 사이에 순서가 존재합니다.
- **인덱싱(Indexing):** 각 요소에 부여된 고유 번호(인덱스)를 통해 개별 요소에 접근할 수 있습니다.
- **슬라이싱(Slicing):** 인덱스 범위를 지정하여 부분적인 요소들을 추출할 수 있습니다.
- **멤버십 연산:** `in`과 `not in` 연산자를 사용하여 특정 요소의 포함 여부를 확인할 수 있습니다.
- **길이 확인:** `len()` 함수를 사용하여 시퀀스의 길이를 확인할 수 있습니다.

## 2. 문자열 (String)

문자열은 문자의 시퀀스이며, **불변(immutable)** 객체입니다. 즉, 한 번 생성된 문자열의 내용은 변경할 수 없습니다.

### 2.1 문자열 인덱싱과 슬라이싱

```python
s = "Hello, Python!"

# 인덱싱 (Indexing)
print(f"첫 번째 문자: {s[0]}")      # 'H'
print(f"마지막 문자: {s[-1]}")     # '!'

# 슬라이싱 (Slicing)
print(f"0~4까지: {s[0:5]}")      # 'Hello' (끝 인덱스는 포함되지 않음)
print(f"7부터 끝까지: {s[7:]}")     # 'Python!'
print(f"처음부터 5까지: {s[:5]}")    # 'Hello'
print(f"전체 문자열: {s[:]}")       # 'Hello, Python!'
print(f"2칸씩 건너뛰기: {s[::2]}") # 'Hlo yhn'
print(f"역순으로: {s[::-1]}")     # '!nohtyP ,olleH'
```

### 2.2 문자열 주요 메서드

문자열 메서드는 원본을 변경하지 않고 **새로운 문자열을 반환**합니다.

| 메서드 | 설명 | 예시 |
| :--- | :--- | :--- |
| `split(sep)` | 구분자(`sep`)를 기준으로 문자열을 나누어 리스트로 반환합니다. | `'a,b,c'.split(',')` -> `['a', 'b', 'c']` |
| `join(iterable)` | 반복 가능한(iterable) 객체의 요소들을 문자열로 연결합니다. | `'-'.join(['a', 'b', 'c'])` -> `'a-b-c'` |
| `strip()` | 양쪽 끝의 공백이나 지정된 문자를 제거합니다. (`lstrip`, `rstrip`) | `'  hello  '.strip()` -> `'hello'` |
| `replace(old, new)` | `old` 문자열을 `new` 문자열로 교체합니다. | `'hello'.replace('l', 'L')` -> `'heLLo'` |
| `find(sub)` | `sub` 문자열이 처음 나타나는 인덱스를 반환합니다. 없으면 -1을 반환. | `'hello'.find('e')` -> `1` |
| `upper() / lower()` | 모든 문자를 대문자/소문자로 변경합니다. | `'Py'.upper()` -> `'PY'`, `'Py'.lower()` -> `'py'` |
| `len(s)` | 문자열의 길이를 반환합니다. (함수) | `len('hello')` -> `5` |
| `count(sub)` | 문자열 내에서 `sub` 문자열이 나타나는 횟수를 반환합니다. | `'banana'.count('a')` -> `3` |
| `startswith(prefix)` | 문자열이 `prefix`로 시작하면 `True`를 반환합니다. | `'hello'.startswith('he')` -> `True` |
| `endswith(suffix)` | 문자열이 `suffix`로 끝나면 `True`를 반환합니다. | `'hello'.endswith('lo')` -> `True` |
| `isdigit()` | 문자열이 모두 숫자로 구성되어 있으면 `True`를 반환합니다. | `'123'.isdigit()` -> `True` |
| `isalpha()` | 문자열이 모두 알파벳으로 구성되어 있으면 `True`를 반환합니다. | `'abc'.isalpha()` -> `True` |
| `isalnum()` | 문자열이 모두 알파벳 또는 숫자로 구성되어 있으면 `True`를 반환합니다. | `'abc123'.isalnum()` -> `True` |

```python
# 메서드 활용 예시
text = "  python is fun  "
words = "apple,banana,cherry"

# split
word_list = words.split(',')
print(f"split 결과: {word_list}")

# join
joined_str = " ".join(word_list)
print(f"join 결과: {joined_str}")

# strip, replace, upper
processed_text = text.strip().replace("fun", "powerful").upper()
print(f"처리된 텍스트: {processed_text}")

# 추가된 메서드 예시
some_string = "Python123"
print(f"'banana'.count('a'): {'banana'.count('a')}")
print(f"'hello'.startswith('he'): {'hello'.startswith('he')}")
print(f"'world'.endswith('ld'): {'world'.endswith('ld')}")
print(f"'123'.isdigit(): {'123'.isdigit()}")
print(f"'abc'.isalpha(): {'abc'.isalpha()}")
print(f"'Python123'.isalnum(): {'Python123'.isalnum()}")
```

## 3. 리스트 (List)

리스트는 다양한 타입의 데이터를 순서대로 저장할 수 있는 **가변(mutable)** 시퀀스입니다. 내용 변경이 자유롭습니다.

### 3.1 리스트 생성, 인덱싱, 슬라이싱

```python
# 리스트 생성
empty_list = []
numbers = [1, 2, 3, 4, 5]
mixed_list = [1, "hello", 3.14, True]

# 인덱싱과 슬라이싱 (문자열과 동일하게 동작)
print(f"numbers의 첫 요소: {numbers[0]}")
print(f"mixed_list의 마지막 요소: {mixed_list[-1]}")
print(f"numbers 슬라이싱: {numbers[1:4]}") # [2, 3, 4]
```

### 3.2 리스트 요소 추가, 수정, 삭제

리스트는 가변 객체이므로 원본이 직접 변경됩니다.

| 연산 | 설명 | 예시 |
| :--- | :--- | :--- |
| `append(x)` | 리스트 끝에 요소 `x`를 추가합니다. | `a.append(5)` |
| `insert(i, x)` | 인덱스 `i`에 요소 `x`를 삽입합니다. | `a.insert(1, 10)` |
| `extend(iterable)` | 리스트에 다른 리스트(iterable)를 이어 붙입니다. | `a.extend([6, 7])` |
| `pop(i)` | 인덱스 `i`의 요소를 제거하고 반환합니다. `i` 생략 시 마지막 요소. | `a.pop()` |
| `remove(x)` | 리스트에서 첫 번째로 나타나는 값 `x`를 제거합니다. | `a.remove(3)` |
| `del a[i]` | 인덱스 `i`의 요소를 제거합니다. (문법) | `del a[0]` |
| `a[i] = x` | 인덱스 `i`의 요소를 `x`로 수정합니다. | `a[0] = 100` |
| `clear()` | 리스트의 모든 요소를 제거합니다. | `a.clear()` |
| `index(x)` | 리스트에서 값 `x`가 처음 나타나는 인덱스를 반환합니다. | `a.index(20)` -> `1` |
| `count(x)` | 리스트에서 값 `x`가 나타나는 횟수를 반환합니다. | `a.count(1)` -> `2` |

```python
# 리스트 조작 예시
my_list = [10, 20, 30]
print(f"초기 리스트: {my_list}")

my_list.append(40)
print(f"append(40) 후: {my_list}")

my_list.insert(1, 15)
print(f"insert(1, 15) 후: {my_list}")

my_list.pop()
print(f"pop() 후: {my_list}")

my_list.remove(20)
print(f"remove(20) 후: {my_list}")

my_list[0] = 5
print(f"인덱스 0 수정 후: {my_list}")

# 추가된 메서드 예시
example_list = [1, 2, 2, 3, 4, 2]
print(f"example_list.count(2): {example_list.count(2)}")
print(f"example_list.index(3): {example_list.index(3)}")

example_list.clear()
print(f"clear() 후: {example_list}")
```

### 3.2.1 리스트 조작의 성능 고려사항

리스트는 매우 유연한 자료구조이지만, 특정 연산은 대규모 리스트에서 성능 저하를 일으킬 수 있습니다. 파이썬의 리스트는 동적 배열(Dynamic Array)로 구현되어 있어, 요소의 추가/삭제 시 내부적으로 배열의 크기를 조절하는 오버헤드가 발생할 수 있습니다.

-   **`append()` (리스트 끝에 추가):** 일반적으로 매우 효율적입니다. 대부분의 경우 O(1)의 시간 복잡도를 가지지만, 배열 크기 재할당 시 O(n)이 될 수 있습니다.
-   **`insert(index, item)` (리스트 중간에 삽입):** `index` 이후의 모든 요소를 한 칸씩 뒤로 밀어야 하므로, 리스트의 크기에 비례하는 O(n)의 시간 복잡도를 가집니다. 대규모 리스트에서 빈번한 삽입은 성능에 큰 영향을 미칩니다.
-   **`remove(item)` 또는 `del list[index]` (리스트 중간에서 삭제):** 요소를 삭제한 후 뒤의 모든 요소를 한 칸씩 앞으로 당겨야 하므로, `insert()`와 마찬가지로 O(n)의 시간 복잡도를 가집니다.
-   **`pop()` (리스트 끝에서 삭제):** `append()`와 유사하게 일반적으로 O(1)의 시간 복잡도를 가집니다.

**실무적 의미:**
-   대규모 리스트에서 중간 삽입/삭제가 빈번하게 필요하다면, `collections.deque`와 같은 다른 자료구조를 고려하는 것이 더 효율적일 수 있습니다. `deque`는 양쪽 끝에서의 삽입/삭제가 O(1)입니다.
-   데이터를 순차적으로 추가하는 경우에는 `append()`를 사용하는 것이 가장 효율적입니다.
-   리스트의 특정 위치에 있는 요소를 수정하는 `list[index] = value` 연산은 O(1)입니다.

### 3.3 리스트 정렬 (`sort()` vs `sorted()`)

- **`list.sort()`**: 리스트 **원본을 직접 정렬**하고 `None`을 반환합니다. (in-place sort)
- **`sorted(list)`**: 정렬된 **새로운 리스트를 반환**하고, 원본은 변경하지 않습니다. (out-of-place sort)

```python
numbers = [3, 1, 4, 1, 5, 9, 2]

# sort() - 원본 변경
print(f"정렬 전: {numbers}")
numbers.sort() # 오름차순 정렬
print(f"sort() 후: {numbers}")
numbers.sort(reverse=True) # 내림차순 정렬
print(f"내림차순 sort() 후: {numbers}")

# sorted() - 새로운 리스트 반환
numbers2 = [3, 1, 4, 1, 5, 9, 2]
new_sorted_list = sorted(numbers2)
print(f"sorted() 후 원본: {numbers2}")
print(f"sorted() 반환값: {new_sorted_list}")
```

### 3.4 리스트 복사 (Shallow vs Deep Copy)

리스트와 같은 가변 객체를 복사할 때는 주소 참조 문제에 유의해야 합니다.

- **얕은 복사 (Shallow Copy):** `copy()` 메서드나 `[:]` 슬라이싱을 사용. 최상위 객체만 복사하고, 내부에 중첩된 객체는 주소를 공유합니다.
- **깊은 복사 (Deep Copy):** `copy` 모듈의 `deepcopy()` 함수를 사용. 내부의 모든 객체까지 재귀적으로 복사하여 완전히 독립적인 객체를 만듭니다.

```python
import copy

# 얕은 복사
list_a = [1, [2, 3]]
list_b = list_a.copy() # 또는 list_a[:]

list_b[0] = 100
list_b[1].append(4)

print(f"얕은 복사 후 a: {list_a}") # [1, [2, 3, 4]] -> 중첩 리스트는 공유됨
print(f"얕은 복사 후 b: {list_b}") # [100, [2, 3, 4]]

# 깊은 복사
list_c = [1, [2, 3]]
list_d = copy.deepcopy(list_c)

list_d[0] = 100
list_d[1].append(4)

print(f"깊은 복사 후 c: {list_c}") # [1, [2, 3]] -> 영향 없음
print(f"깊은 복사 후 d: {list_d}") # [100, [2, 3, 4]]
```

### 3.5 리스트 컴프리헨션 (List Comprehensions)

**리스트 컴프리헨션(List Comprehensions)**은 파이썬에서 리스트를 생성하는 간결하고 효율적인 방법입니다. 기존 리스트나 다른 반복 가능한(iterable) 객체를 기반으로 새로운 리스트를 만들 때 사용되며, 가독성을 높이고 코드 줄 수를 줄여줍니다.

**기본 문법:** `[expression for item in iterable if condition]`

- `expression`: 각 `item`에 대해 수행할 연산.
- `item`: `iterable`에서 가져올 각 요소.
- `iterable`: 반복 가능한 객체 (리스트, 튜플, 문자열, range 등).
- `condition` (선택 사항): `item`을 포함할지 여부를 결정하는 조건.

```python
# 1. 간단한 리스트 생성
squares = [x**2 for x in range(1, 6)]
print(f"제곱 리스트: {squares}") # [1, 4, 9, 16, 25]

# 2. 조건문을 포함한 리스트 생성
even_numbers = [x for x in range(10) if x % 2 == 0]
print(f"짝수 리스트: {even_numbers}") # [0, 2, 4, 6, 8]

# 3. 중첩된 리스트 컴프리헨션 (Nested List Comprehensions)
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flattened_list = [num for row in matrix for num in row]
print(f"평탄화된 리스트: {flattened_list}") # [1, 2, 3, 4, 5, 6, 7, 8, 9]

# 4. 문자열 처리 예시
words = ["apple", "banana", "cherry"]
capitalized_words = [word.upper() for word in words if len(word) > 5]
print(f"대문자화된 긴 단어: {capitalized_words}") # ['BANANA', 'CHERRY']

# 5. 중첩된 조건문을 포함한 리스트 생성
# 1부터 100까지의 숫자 중 3의 배수이면서 5의 배수인 숫자만 필터링
filtered_numbers = [x for x in range(1, 101) if x % 3 == 0 if x % 5 == 0]
print(f"3과 5의 공배수: {filtered_numbers}") # [15, 30, 45, 60, 75, 90]

# 6. 딕셔너리 리스트에서 특정 조건에 맞는 값 추출
students = [
    {'name': 'Alice', 'score': 85, 'major': 'CS'},
    {'name': 'Bob', 'score': 92, 'major': 'EE'},
    {'name': 'Charlie', 'score': 78, 'major': 'CS'},
    {'name': 'David', 'score': 95, 'major': 'Math'}
]

# CS 전공 학생들의 이름만 추출
cs_students = [s['name'] for s in students if s['major'] == 'CS']
print(f"CS 전공 학생: {cs_students}") # ['Alice', 'Charlie'] # ['BANANA', 'CHERRY']
```

- **장점:**
  - **간결성:** 반복문과 조건문을 한 줄로 표현하여 코드가 짧아집니다.
  - **가독성:** 의도를 명확하게 전달하여 코드를 이해하기 쉽습니다.
  - **성능:** 일반적인 `for` 루프보다 내부적으로 최적화되어 더 빠르게 동작하는 경우가 많습니다.

리스트 컴프리헨션은 파이썬에서 데이터를 처리하고 변환하는 데 매우 강력하고 자주 사용되는 기능이므로, 숙달하는 것이 중요합니다.

## 4. 튜플 (Tuple)

튜플은 리스트와 유사하지만, 한 번 생성되면 내용을 변경할 수 없는 **불변(immutable)** 시퀀스입니다.

### 4.1 튜플의 정의와 불변성 (Immutability)

- 소괄호 `()`를 사용하여 생성합니다.
- 요소가 하나인 튜플은 반드시 뒤에 쉼표(`,`)를 붙여야 합니다. (예: `(1,)`)
- 불변이므로 요소의 추가, 수정, 삭제가 불가능합니다.

```python
# 튜플 생성
my_tuple = (1, 2, "three")
single_element_tuple = (1,) # 쉼표가 중요!
empty_tuple = ()

print(f"튜플: {my_tuple}")
print(f"첫 요소: {my_tuple[0]}")

# 튜플은 변경 불가
# my_tuple[0] = 100 # TypeError 발생

# 주의: 튜플 내부에 가변 객체가 있다면, 해당 가변 객체의 내용은 변경될 수 있습니다.
mutable_in_tuple = (1, [2, 3], 'a')
mutable_in_tuple[1].append(4) # 튜플 자체는 변경되지 않지만, 내부 리스트는 변경됨
print(f"가변 객체를 포함한 튜플: {mutable_in_tuple}") # (1, [2, 3, 4], 'a')
```

### 4.2 튜플 패킹과 언패킹

- **패킹(Packing):** 여러 개의 값을 하나의 튜플로 묶는 것.
- **언패킹(Unpacking):** 튜플의 각 요소를 여러 변수에 나누어 할당하는 것.

```python
# 패킹
packed_tuple = 1, 2, 3 # 소괄호 생략 가능
print(f"패킹된 튜플: {packed_tuple}")

# 언패킹
a, b, c = packed_tuple
print(f"언패킹 결과: a={a}, b={b}, c={c}")

# 변수 값 교환에 유용
x, y = 10, 20
x, y = y, x # (y, x) 튜플이 생성되고 언패킹됨
print(f"교환 후: x={x}, y={y}")
```

### 4.3 리스트와의 차이점 및 사용 시점

| 특징 | 리스트 (List) | 튜플 (Tuple) |
| :--- | :--- | :--- |
| **가변성** | 가변 (Mutable) | 불변 (Immutable) |
| **문법** | `[1, 2, 3]` | `(1, 2, 3)` |
| **속도** | 튜플보다 약간 느림 | 리스트보다 약간 빠름 |
| **메모리** | 튜플보다 더 많은 메모리 사용 | 리스트보다 적은 메모리 사용 |
| **주요 용도** | 수정이 필요한 데이터 모음 | 수정되면 안 되는 데이터 모음, 딕셔너리 키 |

**언제 튜플을 사용하는가?**

1.  **데이터의 불변성 보장:** 프로그램 실행 중에 변경되어서는 안 되는 값들을 저장할 때 (예: 좌표, 설정값, 함수의 반환 값).
2.  **딕셔너리 키:** 리스트는 가변이라 딕셔너리의 키가 될 수 없지만, 튜플은 불변이므로 키로 사용할 수 있습니다.
3.  **성능:** 약간의 성능 이점이 필요할 때.
4.  **의미 전달:** "이 데이터는 변경되지 않습니다"라는 의도를 코드에 명확히 나타낼 때.
