## 1. 함수의 기초

함수는 특정 작업을 수행하는 코드 블록을 묶어 놓은 것으로, 코드의 재사용성을 높이고 프로그램을 모듈화하여 가독성과 유지보수성을 향상시키는 데 필수적인 프로그래밍 구성 요소입니다.

### 1.1 함수 정의 (`def`)와 호출

*   **함수 정의 (`def`)**
    함수는 `def` 키워드를 사용하여 정의하며, 함수 이름 뒤에 괄호 `()`와 콜론 `:`을 붙입니다. 함수 본문은 들여쓰기하여 작성합니다.
    ```python
    # 함수 정의
    def greet():
        """간단한 환영 메시지를 출력하는 함수"""
        print("Hello, Python!")
    ```

*   **함수 호출**
    정의된 함수는 이름 뒤에 괄호 `()`를 붙여 호출합니다. 함수가 호출되면 함수 본문의 코드가 실행됩니다.
    ```python
    # 함수 호출
    greet()
    # 출력: Hello, Python!
    ```

### 1.2 매개변수(Parameter)와 인자(Argument)

함수는 외부로부터 값을 받아들여 처리할 수 있으며, 이때 매개변수와 인자의 개념이 중요합니다.

*   **매개변수(Parameter)**
    함수를 정의할 때 함수에 전달될 값을 받는 변수입니다. 함수 정의부의 괄호 `()` 안에 선언됩니다.
    ```python
    # 매개변수 `name`을 받는 함수 정의
    def greet_name(name): # `name`이 매개변수
        """이름을 받아 환영 메시지를 출력하는 함수"""
        print(f"Hello, {name}!")
    ```

*   **인자(Argument)**
    함수를 호출할 때 함수에 실제로 전달하는 값입니다. 함수 호출부의 괄호 `()` 안에 전달됩니다.
    ```python
    # 함수 호출 시 인자 전달
    greet_name("Alice") # "Alice"가 인자
    # 출력: Hello, Alice!
    greet_name("Bob")   # "Bob"이 인자
    # 출력: Hello, Bob!
    ```

### 1.3 `return`을 이용한 값 반환

함수는 작업을 수행한 후 그 결과를 호출한 곳으로 돌려줄 수 있습니다. 이때 `return` 키워드를 사용합니다.

*   **단일 값 반환**
    `return` 키워드 뒤에 반환할 값을 명시합니다. `return` 문이 실행되면 함수는 즉시 종료되고 지정된 값을 반환합니다.
    ```python
    # 두 숫자를 더한 결과를 반환하는 함수 정의
    def add(a, b):
        """두 숫자를 더한 결과를 반환하는 함수"""
        return a + b

    # 함수 호출 및 반환 값 사용
    result = add(5, 3)
    print(f"덧셈 결과: {result}") # 출력: 덧셈 결과: 8
    ```

*   **여러 값 반환**
    파이썬 함수는 여러 값을 반환할 수 있으며, 이 경우 값들은 튜플(tuple) 형태로 묶여서 반환됩니다. 호출하는 쪽에서는 튜플 언패킹을 통해 각 값을 개별 변수에 할당할 수 있습니다.
    ```python
    # 이름과 나이를 반환하는 함수
    def get_person_info():
        name = "Charlie"
        age = 25
        return name, age # 튜플 (name, age) 형태로 반환됨

    # 함수 호출 및 여러 값 언패킹
    person_name, person_age = get_person_info()
    print(f"이름: {person_name}, 나이: {person_age}") # 출력: 이름: Charlie, 나이: 25
    ```

*   **`return`이 없는 함수**
    함수 내에 `return` 문이 없거나, `return` 뒤에 아무 값도 명시하지 않으면, 함수는 기본적으로 `None`을 반환합니다.
    ```python
    def do_nothing():
        pass # 아무것도 하지 않는 함수

    result_none = do_nothing()
    print(f"반환 값: {result_none}") # 출력: 반환 값: None
    ```

### 1.4 함수 설계 원칙 및 고려사항

*   **단일 책임 원칙 (Single Responsibility Principle, SRP)**
    함수는 한 가지 명확한 책임만 가지도록 설계하는 것이 좋습니다. 즉, 함수는 하나의 일만 잘 수행해야 합니다. 이는 코드의 재사용성, 테스트 용이성, 그리고 유지보수성을 크게 높입니다.
    *   **나쁜 예시:** 데이터를 읽고, 처리하고, 저장하는 모든 로직이 하나의 함수에 포함된 경우.
    *   **좋은 예시:** 데이터를 읽는 함수, 데이터를 처리하는 함수, 데이터를 저장하는 함수를 각각 분리하는 경우.

*   **DRY (Don't Repeat Yourself) 원칙**
    동일하거나 유사한 코드 블록이 여러 곳에 반복될 경우, 이를 함수로 만들어 재사용하는 것이 좋습니다. 이는 코드의 중복을 줄이고, 변경이 필요할 때 한 곳만 수정하면 되므로 유지보수 비용을 절감합니다.

*   **KISS (Keep It Simple, Stupid) 원칙**
    코드를 가능한 한 단순하고 이해하기 쉽게 작성해야 합니다. 복잡한 함수는 작은 여러 함수로 분리하고, 명확한 이름을 사용하여 함수의 목적을 쉽게 파악할 수 있도록 합니다.

*   **부수 효과(Side Effect)와 순수 함수(Pure Function)**
    *   **부수 효과:** 함수가 외부 상태(전역 변수, 파일, 데이터베이스 등)를 변경하거나, 함수 호출 시점 외부에 영향을 미치는 것을 **부수 효과**라고 합니다. 부수 효과가 있는 함수는 예측하기 어렵고 테스트하기 어려워 코드의 복잡성을 증가시킬 수 있습니다.
        ```python
        # 부수 효과가 있는 함수 (외부 리스트를 변경)
        my_list = [1, 2, 3]
        def add_to_list(item):
            my_list.append(item)

        add_to_list(4)
        print(f"부수 효과 후 리스트: {my_list}") # [1, 2, 3, 4]
        ```
    *   **순수 함수:**
        -   동일한 입력에 대해 항상 동일한 출력을 반환합니다.
        -   외부 상태를 변경하지 않고, 외부 상태에 의존하지 않습니다.
        데이터 변환이나 계산을 수행하는 함수는 가능한 한 순수 함수로 작성하는 것이 좋습니다. 이는 코드의 테스트 용이성, 예측 가능성, 재사용성을 크게 높여줍니다.
        ```python
        # 순수 함수 (새로운 리스트를 반환)
        def add_to_new_list(original_list, item):
            new_list = list(original_list) # 원본 리스트 복사
            new_list.append(item)
            return new_list

        original = [1, 2, 3]
        modified = add_to_new_list(original, 4)
        print(f"순수 함수 후 원본 리스트: {original}") # [1, 2, 3]
        print(f"순수 함수 후 변경된 리스트: {modified}") # [1, 2, 3, 4]
        ```

## 2. 매개변수 고급 활용

파이썬 함수는 다양한 방식으로 매개변수를 정의하고 인자를 전달할 수 있어 유연하고 강력한 함수 설계를 가능하게 합니다. 이를 통해 함수의 재사용성을 높이고, 다양한 상황에 맞는 함수를 만들 수 있습니다.

### 2.1 기본값(Default Argument) 설정

매개변수에 기본값을 설정하면, 함수 호출 시 해당 인자를 생략할 경우 기본값이 사용됩니다. 기본값이 없는 매개변수는 항상 기본값이 있는 매개변수보다 먼저 정의되어야 합니다.

*   **기본 사용법**
    ```python
    def greet_with_default(name, greeting="Hello"):
        """기본 환영 메시지를 가진 함수"""
        print(f"{greeting}, {name}!")

    greet_with_default("David") # 기본값 사용: Hello, David!
    greet_with_default("Eve", "Hi") # 새로운 값 사용: Hi, Eve!
    ```

*   **주의: 가변 객체를 기본값으로 사용 시 함정 (Mutable Default Argument Pitfall)**
    파이썬에서 함수의 기본값은 함수가 정의될 때 **한 번만 평가**됩니다. 따라서 리스트, 딕셔너리, 집합과 같은 **가변(mutable) 객체**를 기본값으로 사용하면, 모든 함수 호출이 동일한 기본 객체를 공유하게 되어 예상치 못한 부작용을 일으킬 수 있습니다. 이는 파이썬 초보자들이 흔히 겪는 버그 중 하나입니다.

    **권장 패턴:** 가변 객체를 기본값으로 사용해야 할 때는 `None`을 기본값으로 설정하고, 함수 내부에서 `None` 여부를 확인하여 새로운 객체를 생성하는 패턴을 사용합니다. 이는 각 함수 호출이 독립적인 가변 객체를 가지도록 보장합니다.
    ```python
    def add_item(item, my_list=None):
        if my_list is None:
            my_list = []
        my_list.append(item)
        return my_list

    list1 = add_item(1)
    print(f"List 1: {list1}") # [1]
    list2 = add_item(2) # 새로운 리스트가 생성되므로 list1에 영향 없음
    print(f"List 2: {list2}") # [2] (각각 독립적인 리스트)

    # 잘못된 사용 예시 (예상치 못한 동작)
    def bad_add_item(item, my_list=[]): # my_list는 함수 정의 시 한 번만 생성됨
        my_list.append(item)
        return my_list

    bad_list1 = bad_add_item(1)
    print(f"Bad List 1: {bad_list1}") # [1]
    bad_list2 = bad_add_item(2) # bad_list1과 동일한 리스트 객체를 공유
    print(f"Bad List 2: {bad_list2}") # [1, 2] (bad_list1과 bad_list2가 같은 리스트를 공유)
    bad_list3 = bad_add_item(3, []) # 명시적으로 새 리스트 전달 시에는 문제 없음
    print(f"Bad List 3: {bad_list3}") # [3]
    ```

### 2.2 위치 인자(Positional Arguments)와 키워드 인자(Keyword Arguments)

함수를 호출할 때 인자를 전달하는 방식은 크게 두 가지로 나뉩니다.

*   **위치 인자 (Positional Arguments)**
    함수 호출 시 매개변수의 순서에 따라 값이 할당됩니다. 가장 기본적인 인자 전달 방식입니다.
    ```python
    def describe_person(name, age, city):
        print(f"이름: {name}, 나이: {age}, 도시: {city}")

    # 위치 인자 사용
    describe_person("Frank", 40, "Seoul")
    ```

*   **키워드 인자 (Keyword Arguments)**
    `매개변수명=값` 형태로 전달하여 순서에 상관없이 값을 할당할 수 있습니다. 코드의 가독성을 높이고 인자 순서 오류를 방지하는 데 유용합니다.
    ```python
    def describe_person(name, age, city):
        print(f"이름: {name}, 나이: {age}, 도시: {city}")

    # 키워드 인자 사용 (순서 변경 가능)
    describe_person(age=40, city="Seoul", name="Frank")
    ```

*   **위치 인자와 키워드 인자 혼합 사용**
    두 가지 방식을 혼합하여 사용할 수 있지만, **위치 인자가 항상 키워드 인자보다 먼저 와야 합니다.**
    ```python
    def describe_person(name, age, city):
        print(f"이름: {name}, 나이: {age}, 도시: {city}")

    describe_person("Grace", city="Busan", age=30)
    ```

### 2.3 위치 전용 인자 (Positional-Only Arguments)

파이썬 3.8부터 도입된 기능으로, 매개변수 이름 앞에 `/`를 사용하여 해당 매개변수가 반드시 위치 인자로만 전달되어야 함을 명시합니다. 이는 함수의 API를 명확히 하고, 사용자가 인자 이름을 사용하여 혼동하는 것을 방지합니다.

```python
def divide(a, b, /):
    """두 숫자를 나누는 함수 (a, b는 위치 인자로만 전달 가능)"""
    return a / b

print(f"나눗셈 결과: {divide(10, 2)}") # 위치 인자로만 호출 가능
# print(divide(a=10, b=2)) # TypeError: divide() got some positional-only arguments passed as keyword arguments: 'a, b'
```

### 2.4 키워드 전용 인자 (Keyword-Only Arguments)

매개변수 목록에서 `*` (별표) 또는 `*args` 뒤에 오는 매개변수는 반드시 키워드 인자로만 전달되어야 함을 명시합니다. 이는 함수의 가독성을 높이고, 인자의 의미를 명확하게 합니다.

```python
def create_user(name, *, age, city):
    """사용자 정보를 생성하는 함수 (age, city는 키워드 인자로만 전달 가능)"""
    print(f"이름: {name}, 나이: {age}, 도시: {city}")

create_user("Alice", age=30, city="New York") # 키워드 인자로 호출
# create_user("Bob", 25, "Seoul") # TypeError: create_user() takes 1 positional argument but 3 were given
```

### 2.5 가변 인자 리스트 (`*args`)

`*args`는 함수에 개수가 정해지지 않은 위치 인자들을 튜플 형태로 받을 때 사용합니다. `args`는 관례적인 이름이며, 다른 이름을 사용해도 됩니다.

```python
def sum_all(*numbers):
    """전달된 모든 숫자의 합을 반환하는 함수"""
    total = 0
    for num in numbers:
        total += num
    return total

print(f"합계: {sum_all(1, 2, 3)}") # 6
print(f"합계: {sum_all(10, 20, 30, 40)}") # 100
```

### 2.6 가변 키워드 인자 (`**kwargs`)

`**kwargs`는 함수에 개수가 정해지지 않은 키워드 인자들을 딕셔너리 형태로 받을 때 사용합니다. `kwargs`는 관례적인 이름이며, 다른 이름을 사용해도 됩니다.

```python
def print_info(**details):
    """전달된 모든 키워드 인자를 출력하는 함수"""
    for key, value in details.items():
        print(f"{key}: {value}")

print_info(name="Harry", age=28, city="London")
print_info(product="Laptop", price=1200)
```

*   **인자 전달 순서 규칙:**
    함수 정의 시 매개변수는 다음 순서로 와야 합니다:
    1.  일반 위치 인자
    2.  위치 전용 인자 (`/` 앞)
    3.  가변 위치 인자 (`*args`)
    4.  키워드 전용 인자 (`*` 또는 `*args` 뒤)
    5.  가변 키워드 인자 (`**kwargs`)

    ```python
    def complex_function(pos_arg1, pos_arg2, /, *args, kw_only_arg1, **kwargs):
        print(f"pos_arg1: {pos_arg1}")
        print(f"pos_arg2: {pos_arg2}")
        print(f"args: {args}")
        print(f"kw_only_arg1: {kw_only_arg1}")
        print(f"kwargs: {kwargs}")

    complex_function(1, 2, 3, 4, kw_only_arg1="hello", key1="value1", key2="value2")
    # Output:
    # pos_arg1: 1
    # pos_arg2: 2
    # args: (3, 4)
    # kw_only_arg1: hello
    # kwargs: {'key1': 'value1', 'key2': 'value2'}
    ```

### 2.7 함수 인자 언패킹 (Argument Unpacking)

`*` (별표)와 `**` (이중 별표) 연산자는 함수 정의 시 가변 인자를 받는 용도 외에, 함수를 호출할 때 시퀀스(리스트, 튜플)나 딕셔너리의 요소들을 함수의 인자로 "언패킹"하여 전달하는 데 사용됩니다. 이는 코드를 더욱 유연하고 간결하게 만들어 줍니다.

*   **`*` (시퀀스 언패킹):** 리스트나 튜플과 같은 시퀀스의 요소들을 개별적인 위치 인자로 함수에 전달합니다. 함수의 매개변수 개수와 언패킹되는 요소의 개수가 일치해야 합니다.
    ```python
    def print_numbers(a, b, c):
        print(f"a: {a}, b: {b}, c: {c}")

    my_list = [1, 2, 3]
    print_numbers(*my_list) # 1, 2, 3이 각각 a, b, c에 할당됨

    my_tuple = (4, 5, 6)
    print_numbers(*my_tuple) # 4, 5, 6이 각각 a, b, c에 할당됨
    ```

*   **`**` (딕셔너리 언패킹):** 딕셔너리의 키-값 쌍을 개별적인 키워드 인자로 함수에 전달합니다. 딕셔너리의 키는 함수의 매개변수 이름과 일치해야 합니다.
    ```python
    def print_person_info(name, age, city):
        print(f"이름: {name}, 나이: {age}, 도시: {city}")

    person_data = {'name': 'Alice', 'age': 30, 'city': 'New York'}
    print_person_info(**person_data) # 딕셔너리의 키와 값이 매개변수에 할당됨

    # 함수에 정의되지 않은 키가 딕셔너리에 포함된 경우 TypeError 발생
    # extra_data = {'name': 'Bob', 'age': 25, 'country': 'Korea'}
    # print_person_info(**extra_data) # TypeError
    ```

*   **실무적 의미:**
    -   **API 호출:** 외부 라이브러리나 프레임워크의 함수에 많은 인자를 전달해야 할 때, 인자들을 딕셔너리나 리스트로 구성한 후 언패킹하여 전달하면 코드가 훨씬 깔끔해집니다.
    -   **함수 재사용성:** 다양한 형태의 데이터를 받는 함수를 만들 때 유용합니다.
    -   **코드 가독성:** 특히 `**kwargs`와 함께 사용될 때, 함수가 어떤 키워드 인자들을 동적으로 처리하는지 명확하게 보여줄 수 있습니다.

### 2.8 `functools.partial`: 함수의 인자 고정

`functools` 모듈의 `partial` 함수는 기존 함수의 일부 인자를 미리 고정하여 새로운 함수를 만드는 데 사용됩니다. 이는 함수를 재사용하거나, 특정 컨텍스트에 맞게 함수를 커스터마이징할 때 유용합니다. 특히 고차 함수(higher-order function)나 콜백 함수를 다룰 때 람다 표현식의 대안으로 사용될 수 있습니다.

```python
from functools import partial

def multiply(a, b):
    return a * b

# b를 2로 고정한 새로운 함수 생성
double = partial(multiply, b=2)
print(f"double(10): {double(10)}") # 20

# a를 10으로 고정한 새로운 함수 생성
ten_times = partial(multiply, 10)
print(f"ten_times(5): {ten_times(5)}") # 50

# 데이터 과학 활용 예시: 특정 전처리 파이프라인에 함수 적용
# 예를 들어, 데이터 스케일링 함수에 특정 스케일링 파라미터를 미리 고정
def scale_data(data, factor, offset):
    return [x * factor + offset for x in data]

# 데이터를 0.5배 하고 10을 더하는 스케일러 생성
custom_scaler = partial(scale_data, factor=0.5, offset=10)

original_data = [1, 2, 3, 4, 5]
scaled_data = custom_scaler(original_data)
print(f"스케일링된 데이터: {scaled_data}") # [10.5, 11.0, 11.5, 12.0, 12.5]
```

*   **실무적 의미:**
    -   **코드 재사용성:** 반복적으로 사용되는 함수 호출 패턴을 간결하게 추상화할 수 있습니다.
    -   **유연한 API:** 특정 인자를 고정하여 더 특화된 함수를 생성함으로써, 라이브러리나 프레임워크의 API를 유연하게 활용할 수 있습니다.
    -   **콜백 함수:** 이벤트 핸들러나 콜백 함수로 전달될 때, 필요한 인자를 미리 바인딩하여 사용할 수 있습니다.

### 2.9 함수 어노테이션 (타입 힌트)

파이썬 3.5부터 도입된 타입 힌트(Type Hinting)는 함수의 매개변수와 반환 값에 예상되는 타입을 명시할 수 있게 해줍니다. 이는 코드의 가독성을 높이고, 개발 도구(IDE)의 자동 완성 및 정적 분석(예: MyPy)을 통해 잠재적인 오류를 미리 발견하는 데 도움을 줍니다. 타입 힌트는 런타임에 코드의 동작에 영향을 주지 않으며, 주로 개발 시점에 코드의 의도를 명확히 하는 데 사용됩니다.

함수 어노테이션(타입 힌트)에 대한 자세한 내용은 [13_고급_주제.md](./13_고급_주제.md)에서 더 깊이 다룹니다.

*   **`typing.Union`과 `typing.Optional`**
    -   `Union[X, Y]`: 매개변수나 반환 값이 `X` 타입이거나 `Y` 타입일 수 있음을 나타냅니다. (예: `Union[str, int]`)
    -   `Optional[X]`: 매개변수나 반환 값이 `X` 타입이거나 `None`일 수 있음을 나타냅니다. 이는 `Union[X, None]`의 축약형입니다. (예: `Optional[str]`)
    이러한 타입 힌트는 함수의 유연성을 표현하고, 코드의 의도를 더욱 명확하게 전달하는 데 도움을 줍니다.

*   **장점:**
    -   **가독성 향상:** 함수가 어떤 타입의 인자를 받고 어떤 타입의 값을 반환하는지 명확하게 알 수 있습니다.
    -   **오류 예방:** 개발 단계에서 타입 관련 오류를 미리 감지하여 런타임 오류를 줄일 수 있습니다.
    -   **IDE 지원 강화:** IDE가 더 정확한 코드 자동 완성, 리팩토링, 오류 검출 기능을 제공합니다.
    -   **협업 용이성:** 팀 프로젝트에서 코드의 의도를 명확히 전달하여 다른 개발자들이 코드를 더 쉽게 이해하고 사용할 수 있도록 돕습니다.

타입 힌팅은 특히 대규모 프로젝트나 라이브러리 개발 시 코드의 견고성과 품질을 높이는 데 필수적인 요소로 자리 잡고 있습니다.

파이썬 함수는 다양한 방식으로 매개변수를 정의하고 인자를 전달할 수 있어 유연한 함수 설계를 가능하게 합니다.

## 3. 변수의 유효 범위 (Scope)

변수의 유효 범위(Scope)는 변수가 코드 내에서 접근 가능한 영역을 의미합니다. 파이썬은 변수를 찾을 때 특정 규칙을 따르며, 이를 이해하는 것은 예상치 못한 오류를 방지하고 코드를 명확하게 작성하는 데 필수적입니다.

### 3.1 스코프 규칙 (LEGB Rule)

파이썬은 변수를 찾을 때 다음 순서로 스코프를 탐색합니다. 이를 **LEGB 규칙**이라고 합니다.

*   **L (Local):** 현재 함수 내의 로컬 스코프. 함수 내부에서 정의된 변수.
*   **E (Enclosing function locals):** 둘러싸는(Enclosing) 함수의 로컬 스코프. 중첩된 함수에서 바깥쪽 함수의 변수.
*   **G (Global):** 전역 스코프. 모듈(파일)의 최상위 레벨에서 정의된 변수.
*   **B (Built-in):** 파이썬 내장 스코프. `print`, `len`, `str` 등 파이썬이 기본으로 제공하는 함수나 상수.

변수를 참조할 때 파이썬은 이 순서대로 스코프를 검색하며, 변수를 찾으면 검색을 중단합니다. 변수를 찾지 못하면 `NameError`를 발생시킵니다.

### 3.2 전역 변수(Global)와 지역 변수(Local)

*   **지역 변수(Local Variable)**
    함수 내부에서 정의된 변수로, 해당 함수 내에서만 유효합니다. 함수가 종료되면 지역 변수는 소멸됩니다. 다른 함수나 함수 외부에서는 접근할 수 없습니다.
    ```python
    def my_function():
        local_var = 50 # 지역 변수
        print(f"함수 내부 - 지역 변수: {local_var}")

    my_function()
    # print(f"함수 외부 - 지역 변수: {local_var}") # NameError: name 'local_var' is not defined
    ```

*   **전역 변수(Global Variable)**
    함수 외부(모듈의 최상위 레벨)에서 정의된 변수로, 프로그램 전체에서 접근 가능합니다. 함수 내부에서 전역 변수를 참조하는 것은 가능하지만, 값을 변경하려면 특별한 키워드가 필요합니다.
    ```python
    global_var = 100 # 전역 변수

    def access_global():
        print(f"함수 내부 - 전역 변수: {global_var}") # 전역 변수 참조

    access_global()
    print(f"함수 외부 - 전역 변수: {global_var}")
    ```

### 3.3 `global` 키워드 사용법 (주의점 포함)

함수 내부에서 전역 변수의 값을 변경하려면 `global` 키워드를 사용해야 합니다. `global` 키워드 없이 전역 변수와 동일한 이름의 변수에 값을 할당하면, 해당 변수는 새로운 지역 변수로 간주되어 전역 변수에 영향을 주지 않습니다.

*   **`global` 사용 예시**
    ```python
    x = 10 # 전역 변수

    def modify_global():
        global x # 전역 변수 x를 사용하겠다고 선언
        x = 20   # 전역 변수 x의 값을 변경
        print(f"함수 내부 (global 사용): {x}")

    print(f"함수 호출 전: {x}") # 10
    modify_global()
    print(f"modify_global() 호출 후: {x}") # 20 (전역 변수 x가 변경됨)
    ```

*   **`global` 없이 지역 변수 생성 예시**
    ```python
    y = 100 # 전역 변수

    def create_local():
        y = 200 # 새로운 지역 변수 y 생성 (전역 y와는 별개)
        print(f"함수 내부 (local 생성): {y}")

    print(f"함수 호출 전: {y}") # 100
    create_local()
    print(f"create_local() 호출 후: {y}") # 100 (전역 변수 y는 변경되지 않음)
    ```

*   **`global` 사용 주의점:**
    `global` 키워드를 남용하면 코드의 가독성과 유지보수성이 떨어지고, 예상치 못한 부수 효과를 일으킬 수 있습니다. 전역 변수에 대한 의존성이 높아지면 코드의 흐름을 추적하기 어려워지고, 테스트 및 디버깅이 복잡해집니다. 가능한 한 함수는 매개변수를 통해 값을 받고 `return`을 통해 값을 반환하는 방식으로 설계하는 것이 좋습니다.

### 3.4 `nonlocal` 키워드 사용법 및 클로저 (Closures)

`nonlocal` 키워드는 중첩된 함수(nested function)에서 바깥쪽 함수의 지역 변수(enclosing scope)를 수정할 때 사용합니다. `global`이 전역 스코프의 변수를 다루는 반면, `nonlocal`은 현재 함수보다 한 단계 바깥에 있는 **둘러싸는(enclosing) 함수 스코프**의 변수를 다룹니다.

*   **`nonlocal` 사용 예시**
    ```python
    def outer_function():
        message = "Hello" # 둘러싸는 함수의 지역 변수

        def inner_function():
            nonlocal message # 바깥쪽 함수의 message 변수를 사용하겠다고 선언
            message = "Hello, World!" # 바깥쪽 함수의 message 변경
            print(f"내부 함수에서 변경된 메시지: {message}")

        inner_function()
        print(f"외부 함수에서 확인된 메시지: {message}")

    outer_function()
    # Output:
    # 내부 함수에서 변경된 메시지: Hello, World!
    # 외부 함수에서 확인된 메시지: Hello, World!
    ```

*   **`nonlocal` 없이 중첩 함수에서 변수 할당 시**
    `nonlocal` 키워드 없이 중첩 함수에서 바깥쪽 함수의 변수와 동일한 이름의 변수에 값을 할당하면, 새로운 지역 변수가 생성됩니다.
    ```python
    def outer_function_no_nonlocal():
        count = 0

        def inner_function_no_nonlocal():
            count = 1 # 새로운 지역 변수 count 생성 (바깥쪽 count와는 별개)
            print(f"내부 함수 count: {count}")

        inner_function_no_nonlocal()
        print(f"외부 함수 count: {count}")

    outer_function_no_nonlocal()
    # Output:
    # 내부 함수 count: 1
    # 외부 함수 count: 0
    ```

*   **클로저 (Closures)**
    클로저는 중첩된 함수가 자신의 외부(둘러싸는) 함수의 스코프에 있는 변수를 기억하고 접근할 수 있는 기능을 의미합니다. 외부 함수가 실행을 마친 후에도 내부 함수가 외부 함수의 변수에 접근할 수 있게 합니다. 이는 특정 상태를 유지하는 함수를 만들 때 매우 유용하며, 데코레이터나 콜백 함수 구현에 널리 활용됩니다.
    ```python
    def make_multiplier(x):
        # x는 make_multiplier의 지역 변수이지만, multiplier 함수에 의해 '기억'됩니다.
        def multiplier(n):
            return x * n # 외부 함수의 변수 x를 기억하고 사용
        return multiplier

    times3 = make_multiplier(3) # make_multiplier가 종료되어도 x=3이 기억됨
    times5 = make_multiplier(5) # make_multiplier가 종료되어도 x=5가 기억됨

    print(f"3에 10을 곱하면: {times3(10)}") # 30
    print(f"5에 10을 곱하면: {times5(10)}") # 50
    ```

*   **활용:** `nonlocal` 키워드와 클로저는 특정 상태를 유지하거나, 함수형 프로그래밍 패턴을 구현할 때 강력한 도구가 됩니다. 특히 데코레이터, 팩토리 함수, 콜백 함수 등 고급 파이썬 프로그래밍에서 자주 활용됩니다.

### 3.5 데코레이터 (Decorators)

데코레이터는 기존 함수의 코드를 수정하지 않고도 함수에 새로운 기능을 추가하거나 동작을 변경할 수 있게 해주는 강력한 디자인 패턴입니다. `@` 기호를 사용하여 함수에 적용합니다.

#### 3.5.1 함수를 꾸며주는 함수

데코레이터는 본질적으로 **함수를 인자로 받아 새로운 함수를 반환하는 함수**입니다. 이를 통해 코드 중복을 줄이고, 관심사를 분리(Separation of Concerns)할 수 있습니다.

```python
import functools

# 데코레이터의 기본 구조
def my_decorator(func):
    @functools.wraps(func) # 원본 함수의 메타데이터를 유지
    def wrapper(*args, **kwargs):
        print("함수 실행 전")
        result = func(*args, **kwargs) # 원본 함수 실행
        print("함수 실행 후")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    """인사를 출력하는 함수"""
    print(f"안녕하세요, {name}!")

say_hello("김철수")
print(f"함수 이름: {say_hello.__name__}") # functools.wraps 덕분에 'say_hello'가 출력됨
print(f"함수 독스트링: {say_hello.__doc__}")

# 인자를 받는 데코레이터
def repeat(num_times):
    def decorator_repeat(func):
        @functools.wraps(func)
        def wrapper_repeat(*args, **kwargs):
            for _ in range(num_times):
                result = func(*args, **kwargs)
            return result
        return wrapper_repeat
    return decorator_repeat

@repeat(num_times=3)
def greet_repeatedly(name):
    print(f"반복 인사: {name}")

greet_repeatedly("영희")
```
*   `say_hello()`를 호출하면 실제로는 `my_decorator`가 반환한 `wrapper` 함수가 실행됩니다.
*   `wrapper` 함수 내부에서 원본 함수인 `say_hello`가 실행되기 전후로 추가적인 로직을 수행할 수 있습니다.
*   `functools.wraps`를 사용하면 데코레이터가 적용된 함수의 `__name__`, `__doc__` 등 메타데이터가 원본 함수와 동일하게 유지되어 디버깅 및 문서화에 용이합니다.
*   데코레이터에 인자를 전달하려면 함수를 한 번 더 중첩하는 구조를 사용합니다.

#### 3.5.2 실용적인 데코레이터 예제 (로깅, 실행 시간 측정)

데코레이터는 로깅, 인증, 캐싱, 실행 시간 측정 등 다양한 곳에서 활용됩니다.


```python
import time
import logging
import functools

# 로깅 설정
logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(message)s')

def timer(func):
    """함수의 실행 시간을 측정하는 데코레이터"""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start_time = time.time()
        result = func(*args, **kwargs)
        end_time = time.time()
        print(f"'{func.__name__}' 함수 실행 시간: {end_time - start_time:.4f}초")
        return result
    return wrapper

def logger(func):
    """함수 호출 정보를 로그로 남기는 데코레이터"""
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        logging.info(f"'{func.__name__}' 함수 호출 시작")
        result = func(*args, **kwargs)
        logging.info(f"'{func.__name__}' 함수 호출 종료")
        return result
    return wrapper

@timer
@logger
def process_large_data(size: int):
    """시간이 오래 걸리는 작업을 시뮬레이션"""
    print(f"{size}개의 데이터 처리 중...")
    time.sleep(size * 0.1)
    print("처리 완료!")

process_large_data(5)

# functools.lru_cache: 메모이제이션 (Memoization) 데코레이터
# 함수의 결과를 캐시하여 동일한 인자로 다시 호출될 때 계산 없이 캐시된 결과를 반환합니다.
# 동적 계획법(Dynamic Programming)이나 반복적인 계산이 필요한 경우 성능을 크게 향상시킬 수 있습니다.
@functools.lru_cache(maxsize=None) # maxsize=None은 캐시 크기 제한 없음
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

print(f"\n피보나치(10): {fibonacci(10)}")
print(f"피보나치(20): {fibonacci(20)}") # 이미 계산된 값은 빠르게 반환
```

*   데코레이터를 여러 개 쌓아서 사용할 수 있습니다. 적용 순서는 가장 가까운 데코레이터부터입니다. (`timer(logger(process_large_data))`)
*   `*args`, `**kwargs`를 사용하여 원본 함수가 어떤 인자를 받더라도 처리할 수 있도록 유연하게 작성하는 것이 중요합니다.


## 4. 코드 문서화: 독스트링 (Docstrings, PEP 257)

**독스트링(Docstrings)**은 함수, 클래스, 모듈 등의 정의 바로 아래에 작성하는 문자열 리터럴로, 해당 코드 블록의 목적, 사용법, 매개변수, 반환 값 등을 설명합니다. 독스트링은 코드 자체에 포함된 문서이며, 파이썬의 중요한 자기 문서화 기능 중 하나입니다. PEP 257은 파이썬 독스트링에 대한 스타일 가이드라인을 제공합니다.

### 4.1 독스트링의 중요성 및 활용

*   **코드 가독성 및 유지보수성 향상:** 독스트링은 코드의 기능을 빠르게 이해하는 데 도움을 주어, 다른 개발자(미래의 자신 포함)가 코드를 더 쉽게 이해하고 유지보수할 수 있도록 합니다.
*   **자동 문서화 도구:** Sphinx와 같은 문서화 도구는 독스트링을 자동으로 추출하여 API 문서를 생성할 수 있습니다.
*   **IDE 지원:** 대부분의 통합 개발 환경(IDE)은 독스트링을 파싱하여 함수 호출 시 팝업 도움말 등으로 표시해 줍니다.
*   **`help()` 함수:** 파이썬 내장 `help()` 함수를 사용하여 객체의 독스트링을 콘솔에서 바로 확인할 수 있습니다.

```python
def example_function(param1, param2):
    """이것은 함수의 한 줄 요약 독스트링입니다.

    여기에 함수의 더 자세한 설명을 작성할 수 있습니다.
    여러 줄로 작성할 수 있으며, 함수의 동작 방식, 예외 처리 등을 설명합니다.

    Args:
        param1 (int): 첫 번째 매개변수. 정수형이어야 합니다.
        param2 (str): 두 번째 매개변수. 문자열이어야 합니다.

    Returns:
        bool: 작업 성공 여부를 반환합니다.

    Raises:
        ValueError: param1이 음수일 경우 발생합니다.
    """
    if param1 < 0:
        raise ValueError("param1은 음수일 수 없습니다.")
    print(f"param1: {param1}, param2: {param2}")
    return True

# 독스트링 확인
print(example_function.__doc__)
help(example_function)

# 함수 사용 예시
example_function(10, "test")
```

### 4.2 독스트링 스타일 (PEP 257 권장)

독스트링은 `"""` (세 개의 큰따옴표) 또는 `'''` (세 개의 작은따옴표)로 묶습니다. PEP 257은 독스트링 작성에 대한 표준 가이드라인을 제공하며, 일반적으로 다음과 같은 구조를 따릅니다.

*   **한 줄 독스트링:**
    간단한 함수나 클래스에 사용되며, 첫 줄에 함수의 간략한 목적을 작성합니다. 종료 따옴표는 첫 줄과 같은 줄에 위치합니다.
    ```python
    def add(a, b):
        """두 숫자를 더한 결과를 반환합니다."""
        return a + b
    ```

*   **여러 줄 독스트링:**
    더 복잡한 함수나 클래스에 사용되며, 다음과 같은 구조를 가집니다.
    1.  **한 줄 요약:** 첫 줄에 함수의 간략한 목적을 작성합니다.
    2.  **빈 줄:** 요약과 상세 설명 사이에 빈 줄을 둡니다.
    3.  **상세 설명:** 함수의 동작 방식, 알고리즘, 제약 사항, 사용 예시 등 필요한 추가적인 설명을 작성합니다.
    4.  **매개변수 (`Args`):** 각 매개변수의 이름, 타입, 설명을 명시합니다. (예: `param_name (type): description`)
    5.  **반환 값 (`Returns`):** 반환 값의 타입과 설명을 명시합니다. (예: `type: description`)
    6.  **예외 (`Raises`):** 발생할 수 있는 예외와 그 상황을 설명합니다. (예: `ExceptionType: condition`)

    ```python
    def calculate_area(width: float, height: float) -> float:
        """사각형의 넓이를 계산하여 반환하는 함수.

        이 함수는 주어진 가로와 세로 길이를 사용하여 사각형의 넓이를 계산합니다.
        음수 값이 입력될 경우 ValueError를 발생시킵니다.

        Args:
            width (float): 사각형의 가로 길이. 양수여야 합니다.
            height (float): 사각형의 세로 길이. 양수여야 합니다.

        Returns:
            float: 계산된 사각형의 넓이 (width * height).

        Raises:
            ValueError: 가로 또는 세로 길이가 음수일 경우 발생.
        """
        if width < 0 or height < 0:
            raise ValueError("가로와 세로 길이는 음수가 될 수 없습니다.")
        return width * height
    ```

*   **다양한 독스트링 포맷:**
    PEP 257은 일반적인 가이드라인을 제공하며, NumPy 스타일, Google 스타일, Sphinx 스타일 등 다양한 독스트링 포맷이 존재합니다. 이들 포맷은 매개변수, 반환 값, 예외 등을 구조화된 방식으로 표현하여 자동 문서화 도구와의 호환성을 높입니다. 프로젝트나 팀의 컨벤션에 따라 선택하여 일관성 있게 사용하는 것이 중요합니다.

    -   **NumPy/SciPy 스타일:** 과학 계산 라이브러리에서 널리 사용되며, 섹션 헤더(Parameters, Returns 등)를 사용합니다.
    -   **Google 스타일:** 간결하고 명확한 문법을 제공합니다.

**결론:** 독스트링은 코드의 품질을 높이고 협업을 용이하게 하는 중요한 요소입니다. 독스트링과 함께 타입 힌팅 및 `mypy`와 같은 정적 타입 검사 도구를 활용하면 코드의 견고성과 명확성을 더욱 높일 수 있습니다.

## 5. 람다 표현식 (Lambda Expression)

**람다 표현식(Lambda Expression)**은 파이썬에서 이름 없는(anonymous) 한 줄 함수를 생성하는 간결한 방법입니다. 주로 함수를 다른 함수의 인자로 전달하거나, 간단한 연산을 즉석에서 정의할 때 사용됩니다. 람다 표현식은 코드의 양을 줄이고 특정 상황에서 가독성을 높일 수 있습니다.

### 5.1 이름 없는 한 줄 함수

*   **기본 문법:** `lambda arguments: expression`
    -   `lambda`: 람다 함수를 정의하는 키워드.
    -   `arguments`: 함수가 받을 매개변수 (여러 개 가능, 쉼표로 구분).
    -   `expression`: 함수가 반환할 단일 표현식. 람다 함수는 복잡한 로직이나 여러 줄의 코드를 포함할 수 없으며, 오직 하나의 표현식만을 가질 수 있습니다.

    ```python
    # 일반 함수
    def add_normal(x, y):
        return x + y

    # 람다 함수
    add_lambda = lambda x, y: x + y

    print(f"일반 함수 덧셈: {add_normal(2, 3)}") # 출력: 일반 함수 덧셈: 5
    print(f"람다 함수 덧셈: {add_lambda(2, 3)}") # 출력: 람다 함수 덧셈: 5

    # 람다 함수를 즉석에서 사용 (변수에 할당하지 않고 바로 호출)
    print(f"즉석 람다: {(lambda x: x * x)(5)}") # 출력: 즉석 람다: 25
    ```

*   **매개변수 없는 람다**
    ```python
    greet_lambda = lambda: "Hello, World!"
    print(f"매개변수 없는 람다: {greet_lambda()}") # 출력: 매개변수 없는 람다: Hello, World!
    ```

### 5.2 고차 함수(Higher-Order Functions)와 함께 사용하기

람다 표현식은 함수를 인자로 받는 고차 함수(예: `map`, `filter`, `sorted`, `reduce`)와 함께 사용될 때 매우 강력합니다. 이들은 각각 시퀀스의 각 요소에 함수를 적용하거나, 특정 조건을 만족하는 요소만 필터링하는 데 사용됩니다.

*   **`map(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용한 결과를 반환합니다.
    ```python
    numbers = [1, 2, 3, 4, 5]

    # map과 람다: 각 숫자를 제곱
    squared_numbers = list(map(lambda x: x * x, numbers))
    print(f"제곱된 숫자: {squared_numbers}") # 출력: 제곱된 숫자: [1, 4, 9, 16, 25]
    ```

*   **`filter(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용하여 `True`를 반환하는 요소만 필터링하여 반환합니다.
    ```python
    numbers = [1, 2, 3, 4, 5]

    # filter와 람다: 짝수만 필터링
    even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
    print(f"짝수: {even_numbers}") # 출력: 짝수: [2, 4]
    ```

*   **`sorted(iterable, key=function)`:** `iterable`을 정렬할 때 `key` 인자에 람다 함수를 사용하여 정렬 기준을 정의할 수 있습니다.
    ```python
    students = [
        {'name': 'Alice', 'score': 85},
        {'name': 'Bob', 'score': 92},
        {'name': 'Charlie', 'score': 78}
    ]

    # 점수를 기준으로 정렬 (내림차순)
    sorted_students = sorted(students, key=lambda student: student['score'], reverse=True)
    print(f"점수 기준 정렬: {sorted_students}")
    # 출력: [{'name': 'Bob', 'score': 92}, {'name': 'Alice', 'score': 85}, {'name': 'Charlie', 'score': 78}]
    ```

*   **`functools.reduce(function, iterable)`:** `iterable`의 요소들을 누적적으로 `function`에 적용하여 단일 값을 반환합니다. (`functools` 모듈 필요)
    ```python
    from functools import reduce
    numbers = [1, 2, 3, 4, 5]

    # reduce와 람다: 리스트의 모든 요소 곱셈
    product_of_numbers = reduce(lambda x, y: x * y, numbers)
    print(f"숫자들의 곱: {product_of_numbers}") # 출력: 숫자들의 곱: 120 (1 * 2 * 3 * 4 * 5)
    ```

### 5.3 활용 시점 및 주의사항

*   **활용 시점:**
    -   **간단한 일회성 함수:** 코드를 간결하게 만들 수 있는 간단한 변환이나 필터링 로직에 적합합니다.
    -   **고차 함수의 인자:** `map()`, `filter()`, `sorted()`, `reduce()` 등 함수를 인자로 받는 함수에 콜백으로 전달할 때 유용합니다.
    -   **클로저의 간결한 표현:** 간단한 클로저를 만들 때 사용될 수 있습니다.

*   **주의사항:**
    -   **가독성 저해:** 람다 표현식은 한 줄로 제한되므로, 복잡한 로직을 람다로 표현하려고 하면 오히려 가독성이 떨어질 수 있습니다. 이 경우 일반 `def` 함수를 사용하는 것이 좋습니다.
    -   **디버깅의 어려움:** 람다 함수는 이름이 없기 때문에 스택 트레이스(stack trace)에서 디버깅하기 어려울 수 있습니다.
    -   **문(Statement) 사용 불가:** 람다 표현식은 `if`, `for`, `while`, `return` 등의 문(statement)을 포함할 수 없으며, 오직 표현식(expression)만을 가질 수 있습니다.

**결론:** 람다 표현식은 파이썬의 강력한 기능 중 하나이지만, 그 사용은 간결성과 가독성을 해치지 않는 범위 내에서 이루어져야 합니다. 적절한 상황에서 사용하면 코드를 더욱 효율적이고 파이썬스럽게 만들 수 있습니다.
