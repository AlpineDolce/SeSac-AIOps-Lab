## 1. 변수 (Variables)

변수는 데이터를 저장하는 메모리 공간에 붙여진 이름입니다. 파이썬에서는 변수를 선언할 때 별도의 타입 지정을 하지 않으며, 값이 할당될 때 자동으로 타입이 결정됩니다.

### 1.1 변수 선언 및 할당

변수를 사용하기 전에 먼저 값을 할당해야 합니다. 할당되지 않은 변수를 사용하려고 하면 `NameError`가 발생합니다.

```python
# 변수 선언 및 할당
name = "Alice"
age = 30
height = 175.5
is_student = True

# 변수 값 출력
print(f"이름: {name}")
print(f"나이: {age}")
print(f"키: {height}")
print(f"학생 여부: {is_student}")

# 변수 값 변경
age = 31
print(f"변경된 나이: {age}")
```

### 1.1.1 다중 할당 (Multiple Assignment)

파이썬에서는 여러 변수에 동시에 값을 할당할 수 있습니다. 이는 코드의 가독성을 높이고 줄 수를 줄이는 데 유용합니다.

```python
# 여러 변수에 동시에 값 할당
x, y, z = 10, 20, 30
print(f"x: {x}, y: {y}, z: {z}")

# 변수 값 교환 (임시 변수 없이)
a = 5
b = 10
a, b = b, a # a는 10, b는 5가 됨
print(f"교환 후 a: {a}, b: {b}")

# 동일한 값 할당
value = 100
var1 = var2 = var3 = value
print(f"var1: {var1}, var2: {var2}, var3: {var3}")
```



### 1.2 변수 네이밍 컨벤션 (PEP 8)

PEP 8은 파이썬 코드의 가독성을 높이기 위한 스타일 가이드입니다. 변수명에 대한 주요 권장 사항은 다음과 같습니다.

- **소문자와 언더스코어 사용 (snake_case):** 변수명은 모두 소문자로 작성하고, 여러 단어를 조합할 때는 언더스코어로 구분합니다.
  ```python
  user_name = "John Doe"
  total_score = 100
  ```
- **의미 있는 이름:** 변수가 어떤 데이터를 담고 있는지 명확하게 알 수 있도록 의미 있는 이름을 사용합니다.
  ```python
  # Bad
  x = 10
  y = "hello"

  # Good
  quantity = 10
  greeting_message = "hello"
  ```
- **예약어 사용 금지:** 파이썬의 예약어(예: `if`, `for`, `while`, `class`, `def` 등)는 변수명으로 사용할 수 없습니다.
  ```python
  # Bad
  # class = "Math" # SyntaxError 발생
  ```
- **숫자로 시작 금지:** 변수명은 숫자로 시작할 수 없습니다.
  ```python
  # Bad
  # 1st_name = "Alice" # SyntaxError 발생
  ```

- 변수명은 데이터의 의미를 명확하게 나타내도록 짧고 간결하면서도 의미를 명확히 전달하는 이름을 사용합니다. (예: `name`보다는 `user_name`이 더 명확)
- 소문자와 언더스코어(`_`)를 사용하는 스네이크 케이스(snake_case)를 따르는 것이 일반적입니다. (PEP 8 권장)
- 팀 프로젝트에서는 팀 내에서 합의된 네이밍 컨벤션을 따르는 것이 일관성 유지에 도움이 됩니다.

## 2. 기본 자료형 (Primitive Data Types)

파이썬은 다양한 종류의 데이터를 처리할 수 있도록 여러 내장 자료형을 제공합니다. 여기서는 가장 기본적인 자료형들을 살펴봅니다.

### 2.1 정수형 (int)

정수형은 양의 정수, 음의 정수, 0을 포함하는 숫자입니다. 파이썬에서는 정수의 크기에 제한이 없습니다.

```python
# 정수형 변수
num1 = 10
num2 = -5
num3 = 0
big_number = 12345678901234567890

print(f"num1: {num1}, 타입: {type(num1)}")
print(f"num2: {num2}, 타입: {type(num2)}")
print(f"num3: {num3}, 타입: {type(num3)}")
print(f"big_number: {big_number}, 타입: {type(big_number)}")
```

### 2.2 실수형 (float)

실수형은 소수점을 포함하는 숫자입니다. 부동소수점 방식으로 저장되며, 정밀도에 한계가 있을 수 있습니다.

```python
# 실수형 변수
pi = 3.14159
temperature = -2.5
zero_float = 0.0

print(f"pi: {pi}, 타입: {type(pi)}")
print(f"temperature: {temperature}, 타입: {type(temperature)}")
print(f"zero_float: {zero_float}, 타입: {type(zero_float)}")
```
#### 2.2.1 부동소수점 정밀도 문제와 `Decimal` 모듈 활용
- 금융 계산과 같이 정밀한 소수점 계산이 필요한 경우에는 `Decimal` 모듈을 사용하는 것이 좋습니다. 일반적인 `float`는 부동소수점 오차를 가질 수 있습니다.
  ```python
  from decimal import Decimal, getcontext

  # 기본 정밀도 설정 (28자리)
  getcontext().prec = 28

  # float의 부동소수점 오차
  print(f"0.1 + 0.2 (float): {0.1 + 0.2}") # 0.30000000000000004

  # Decimal을 사용한 정확한 계산
  d1 = Decimal('0.1')
  d2 = Decimal('0.2')
  d3 = Decimal('0.3')
  print(f"Decimal('0.1') + Decimal('0.2'): {d1 + d2}") # 0.3
  print(f"d1 + d2 == d3: {d1 + d2 == d3}") # True

  # 정밀도 제어 (반올림)
  getcontext().prec = 4 # 정밀도를 4자리로 설정
  d_pi = Decimal('3.1415926535')
  print(f"Decimal(pi) with prec 4: {d_pi}") # 3.142 (자동 반올림)

  # 특정 반올림 모드 적용
  from decimal import ROUND_HALF_UP
  getcontext().prec = 6
  d_val = Decimal('2.5')
  print(f"Decimal('2.5').quantize(Decimal('1.'), rounding=ROUND_HALF_UP): {d_val.quantize(Decimal('1.'), rounding=ROUND_HALF_UP)}") # 3
  ```

### 2.3 불리언형 (bool)

불리언형은 참(`True`) 또는 거짓(`False`) 두 가지 값만을 가집니다. 조건문이나 반복문에서 논리적인 판단을 할 때 주로 사용됩니다.

```python
# 불리언형 변수
is_active = True
has_permission = False

print(f"is_active: {is_active}, 타입: {type(is_active)}")
print(f"has_permission: {has_permission}, 타입: {type(has_permission)}")

# 비교 연산 결과
print(f"10 > 5: {10 > 5}")
print(f"5 == 5: {5 == 5}")
print(f"3 < 1: {3 < 1}")
```

### 2.4 None 타입

`None`은 값이 없음을 나타내는 특별한 타입입니다. 다른 언어의 `null`과 유사합니다.

```python
# None 타입 변수
result = None
data = None

print(f"result: {result}, 타입: {type(result)}")
print(f"data: {data}, 타입: {type(data)}")

# None과의 비교
if result is None:
    print("result는 값이 없습니다.")
```

- 변수를 초기화할 때 아직 할당할 값이 없거나, 함수가 반환할 값이 없을 때 `None`을 사용합니다.
- `None`인지 확인할 때는 `==` 대신 `is` 연산자를 사용하는 것이 권장됩니다. (`is`는 객체의 동일성을, `==`는 값의 동일성을 비교합니다.)

### 2.5 문자열 (str)

문자열은 텍스트 데이터를 나타내는 자료형입니다. 작은따옴표(`'`)나 큰따옴표(`"`)로 묶어서 표현합니다. 여러 줄의 문자열은 세 개의 따옴표(`'''` 또는 `"""`)로 묶습니다.

```python
# 문자열 변수
single_quote_str = 'Hello, Python!'
double_quote_str = "파이썬 프로그래밍"
multi_line_str = """이것은
여러 줄의
문자열입니다."""

print(f"single_quote_str: {single_quote_str}, 타입: {type(single_quote_str)}")
print(f"double_quote_str: {double_quote_str}, 타입: {type(double_quote_str)}")
print(f"multi_line_str: {multi_line_str}, 타입: {type(multi_line_str)}")

# 문자열 연결 (Concatenation)
greeting = "안녕"
name = "세계"
message = greeting + ", " + name + "!"
print(f"메시지: {message}")
```

### 2.5.1 문자열 포매팅 (f-string, format(), %)
- **f-string (Formatted String Literals):** 파이썬 3.6부터 도입된 가장 최신이자 권장되는 문자열 포매팅 방식입니다. 문자열 앞에 `f` 또는 `F`를 붙이고 중괄호 `{}` 안에 변수나 표현식을 직접 넣어 사용할 수 있어 가독성이 매우 높습니다.
  ```python
  name = "Alice"
  age = 30
  print(f"이름: {name}, 나이: {age}")
  print(f"내년 나이: {age + 1}")
  ```
- **`str.format()` 메서드:** `f-string` 이전에 주로 사용되던 방식입니다. 중괄호 `{}`를 플레이스홀더로 사용하고, `format()` 메서드의 인자로 값을 전달합니다. 인덱스나 키워드를 사용하여 순서를 지정할 수도 있습니다.
  ```python
  name = "Bob"
  age = 25
  print("이름: {}, 나이: {}".format(name, age))
  print("이름: {0}, 나이: {1}".format(name, age)) # 인덱스 사용
  print("이름: {n}, 나이: {a}".format(n=name, a=age)) # 키워드 사용
  ```
- **`%` 연산자 (구식 방식):** C언어의 `printf` 스타일과 유사한 구식 포매팅 방식입니다. `%s` (문자열), `%d` (정수), `%f` (실수) 등의 서식 지정자를 사용합니다. 가독성이 떨어지고 오류 발생 가능성이 높아 최신 파이썬에서는 권장되지 않습니다.
  ```python
  name = "Charlie"
  age = 35
  print("이름: %s, 나이: %d" % (name, age))
  ```
- **어떤 것을 사용할까?**
  - **`f-string`을 최우선으로 사용:** 가장 간결하고 가독성이 좋으며 성능도 우수합니다.
  - **`str.format()`:** `f-string`을 사용할 수 없는 환경(예: 파이썬 3.5 이하)이거나, 런타임에 포맷 문자열을 동적으로 생성해야 할 때 유용합니다.
  - **`%` 연산자:** 레거시 코드에서만 사용하고, 새로운 코드를 작성할 때는 피하는 것이 좋습니다.

- **문자열은 불변(immutable) 객체입니다.** 즉, 한 번 생성된 문자열은 내용을 변경할 수 없으며, 변경처럼 보이는 작업은 새로운 문자열을 생성하는 것입니다.
  - **실무적 의미:** 문자열을 변경하는 것처럼 보이는 연산(예: `+`를 이용한 연결, `replace()` 메서드)은 실제로는 **새로운 문자열 객체를 생성**합니다. 이는 메모리 사용과 성능에 영향을 줄 수 있으므로, 대량의 문자열 조작 시에는 `list.join()`과 같은 효율적인 방법을 고려해야 합니다.
  ```python
  s1 = "Hello"
  print(f"s1의 메모리 주소 (id): {id(s1)}")

  s2 = s1 + " World" # 새로운 문자열 객체 생성
  print(f"s2의 메모리 주소 (id): {id(s2)}")
  print(f"s1은 변경되지 않음: {s1}")

  # 대량의 문자열 연결 성능 비교
  import time

  num_iterations = 100000 # 10만 번 반복
  test_string = "a"

  # '+' 연산자를 이용한 연결
  start_time = time.time()
  result_plus = ""
  for _ in range(num_iterations):
      result_plus += test_string
  end_time = time.time()
  print(f"'+' 연산자 연결 시간: {end_time - start_time:.4f}초")

  # list.join()을 이용한 연결
  start_time = time.time()
  string_list = [test_string for _ in range(num_iterations)]
  result_join = "".join(string_list)
  end_time = time.time()
  print(f"'join()' 메서드 연결 시간: {end_time - start_time:.4f}초")
  ```

#### 2.5.2 `string.Template`를 이용한 안전한 문자열 대체
  `string.Template`는 `f-string`이나 `str.format()`보다 유연성은 떨어지지만, 보안에 민감한 환경에서 사용자 입력과 같은 신뢰할 수 없는 소스의 문자열을 대체할 때 안전하게 사용할 수 있습니다. 이는 `$변수명` 또는 `${변수명}` 형태의 플레이스홀더만 인식하여 코드 주입 공격(Code Injection)을 방지하는 데 도움을 줍니다.
  ```python
  from string import Template

  template_str = Template("Hello, $name! Your age is ${age}.")
  data = {'name': 'Alice', 'age': 30}
  print(template_str.substitute(data))

  # 안전하지 않은 입력 방지
  # malicious_data = {'name': 'Alice', 'age': '${os.system("rm -rf /")}'}
  # Template는 이를 실행하지 않고 문자열로 처리합니다.
  ```

#### 2.5.3 데이터 클리닝에서의 활용 (문자열 메서드)
- **데이터 클리닝에서의 활용:** `strip()`, `lower()`, `replace()`, `split()`, `join()` 등의 문자열 메서드는 데이터 전처리 과정에서 매우 빈번하게 사용됩니다. 예를 들어, 사용자 입력의 불필요한 공백 제거(`strip()`), 텍스트를 소문자로 통일(`lower()`), 특정 문자열 치환(`replace()`), 문장을 단어 단위로 분리(`split()`), 분리된 단어들을 다시 결합(`join()`)하는 등 데이터의 일관성을 확보하고 분석 가능한 형태로 가공하는 데 필수적입니다.

## 3. 타입 확인과 변환 (Type Checking & Casting)

파이썬은 동적 타이핑 언어이지만, 때로는 변수의 타입을 확인하거나 다른 타입으로 변환해야 할 필요가 있습니다.

### 3.1 `type()` 함수와 `isinstance()` 함수로 타입 확인

`type()` 함수는 객체의 타입을 반환합니다. 디버깅이나 특정 타입에 따라 다른 로직을 수행해야 할 때 유용합니다. 하지만 파이썬에서는 객체의 상속 관계를 고려하여 타입을 확인할 때는 `isinstance()` 함수를 사용하는 것이 더 권장됩니다.

`isinstance(object, classinfo)` 함수는 `object`가 `classinfo`의 인스턴스이거나 `classinfo`를 상속받은 클래스의 인스턴스인 경우 `True`를 반환합니다. 이는 다형성을 다룰 때 특히 중요합니다.

```python
# 다양한 변수의 타입 확인
num = 10
text = "Python"
is_valid = True
my_list = [1, 2, 3]

print(f"num의 타입: {type(num)}")
print(f"text의 타입: {type(text)}")
print(f"is_valid의 타입: {type(is_valid)}")
print(f"my_list의 타입: {type(my_list)}")

# type() vs isinstance() 예시
class Animal: pass
class Dog(Animal): pass

my_dog = Dog()

print(f"type(my_dog) is Dog: {type(my_dog) is Dog}")          # True
print(f"type(my_dog) is Animal: {type(my_dog) is Animal}")      # False (정확히 Dog 타입만 체크)

print(f"isinstance(my_dog, Dog): {isinstance(my_dog, Dog)}")    # True
print(f"isinstance(my_dog, Animal): {isinstance(my_dog, Animal)}") # True (Dog이 Animal의 자손이므로 True)

# 타입에 따른 조건문 (실무에서는 isinstance()를 더 선호)
if isinstance(num, int):
    print("num은 정수 또는 정수의 서브클래스입니다.")
```

### 3.2 명시적 형 변환 (Type Casting)

내장 함수를 사용하여 변수의 타입을 다른 타입으로 명시적으로 변환할 수 있습니다.

- **`int()`:** 숫자를 정수형으로, 문자열을 정수형으로 변환합니다. (문자열은 숫자로만 구성되어야 함)
- **`float()`:** 숫자를 실수형으로, 문자열을 실수형으로 변환합니다. (문자열은 숫자로만 구성되어야 함)
- **`str()`:** 모든 타입을 문자열로 변환합니다.
- **`bool()`:** 모든 타입을 불리언형으로 변환합니다. (0, None, 빈 문자열/리스트/튜플/딕셔너리 등은 `False`로 변환됨)

```python
# 숫자 -> 문자열
num_str = str(123)
print(f"123을 문자열로: '{num_str}', 타입: {type(num_str)}")

# 문자열 -> 정수
str_int = "456"
int_val = int(str_int)
print(f"'{str_int}'을 정수로: {int_val}, 타입: {type(int_val)}")

# 문자열 -> 실수
str_float = "78.9"
float_val = float(str_float)
print(f"'{str_float}'을 실수로: {float_val}, 타입: {type(float_val)}")

# 실수 -> 정수 (소수점 이하 버림)
float_to_int = int(3.14)
print(f"3.14를 정수로: {float_to_int}, 타입: {type(float_to_int)}")

# 불리언 변환
print(f"bool(0): {bool(0)}")         # False
print(f"bool(1): {bool(1)}")         # True
print(f"bool(''): {bool('')}")       # False (빈 문자열)
print(f"bool('hello'): {bool('hello')}") # True (내용이 있는 문자열)
print(f"bool([]): {bool([])}")       # False (빈 리스트)
print(f"bool(None): {bool(None)}")   # False
```

- 사용자 입력(`input()` 함수는 항상 문자열을 반환)을 숫자로 처리해야 할 때 `int()`나 `float()`를 사용합니다.
- 형 변환 시 발생할 수 있는 `ValueError` (예: 숫자로 변환할 수 없는 문자열을 `int()`로 변환 시도)에 대비하여 예외 처리를 고려해야 합니다.

### 3.3 타입 힌팅 (Type Hinting)

파이썬은 동적 타이핑 언어이지만, 파이썬 3.5부터 **타입 힌팅(Type Hinting)** 기능이 도입되어 변수, 함수 매개변수, 함수 반환 값 등에 타입을 명시할 수 있게 되었습니다. 이는 코드의 가독성을 높이고, 개발 도구(IDE)의 자동 완성 및 정적 분석(예: MyPy)을 통해 잠재적인 오류를 미리 발견하는 데 도움을 줍니다. 타입 힌팅은 런타임에 코드의 동작에 영향을 주지 않으며, 주로 개발 시점에 코드의 의도를 명확히 하는 데 사용됩니다.

```python
# 변수 타입 힌팅
age: int = 30
name: str = "Alice"
is_active: bool = True
price: float = 99.99

# 함수 매개변수 및 반환 값 타입 힌팅
def greet(name: str) -> str:
    return f"Hello, {name}!"

def add_numbers(a: int, b: int) -> int:
    return a + b

# 타입 힌팅을 사용한 함수 호출
message = greet("Bob")
print(message)

sum_result = add_numbers(10, 20)
print(sum_result)

# 잘못된 타입 사용 시 (런타임 오류는 발생하지 않지만, 정적 분석 도구에서 경고)
# sum_result_error = add_numbers("10", 20) # MyPy와 같은 도구에서 타입 불일치 경고
```

- **가독성 및 유지보수성 향상:** 코드만 보고도 변수나 함수의 예상 타입을 쉽게 파악할 수 있어 코드 이해도를 높입니다.
- **오류 사전 방지:** `MyPy`와 같은 정적 타입 검사 도구를 사용하면 런타임에 발생할 수 있는 타입 관련 오류를 개발 단계에서 미리 감지할 수 있습니다.
- **IDE 지원 강화:** IDE(예: VS Code, PyCharm)에서 타입 힌팅을 기반으로 더 정확한 자동 완성, 코드 탐색, 리팩토링 기능을 제공합니다.
- **협업 용이성:** 팀 프로젝트에서 코드의 의도를 명확히 전달하여 다른 개발자들이 코드를 더 쉽게 이해하고 사용할 수 있도록 돕습니다.

타입 힌팅은 특히 대규모 프로젝트나 라이브러리 개발 시 코드의 견고성과 품질을 높이는 데 필수적인 요소로 자리 잡고 있습니다.

## 4. 기본 입출력 (I/O)

파이썬에서 사용자로부터 데이터를 입력받거나 결과를 화면에 출력하는 기본적인 방법을 알아봅니다.

### 4.1 `input()` 함수로 사용자 입력받기

`input()` 함수는 사용자로부터 한 줄의 텍스트를 입력받아 문자열로 반환합니다.

```python
# 사용자 이름 입력받기
user_name = input("이름을 입력하세요: ")
print(f"안녕하세요, {user_name}님!")

# 숫자 입력받아 계산하기 (주의: input은 문자열 반환)
num_str1 = input("첫 번째 숫자를 입력하세요: ")
num_str2 = input("두 번째 숫자를 입력하세요: ")

# 문자열을 숫자로 변환 후 덧셈
try:
    num1 = int(num_str1)
    num2 = int(num_str2)
    sum_result = num1 + num2
    print(f"두 숫자의 합: {sum_result}")
except ValueError:
    print("유효한 숫자를 입력해주세요.")
```
- `input()` 함수는 항상 문자열을 반환하므로, 숫자나 다른 타입으로 사용하려면 반드시 적절한 형 변환을 해주어야 합니다.
- 사용자 입력은 예상치 못한 형식일 수 있으므로, `try-except` 블록을 사용하여 예외 처리를 하는 것이 안전합니다.

### 4.2 `print()` 함수와 f-string

`print()` 함수는 데이터를 화면에 출력하는 가장 기본적인 방법입니다. `f-string` (Formatted String Literals)은 파이썬 3.6부터 도입된 문자열 포매팅 방식으로, 변수 값을 문자열 안에 쉽게 삽입할 수 있어 가독성이 매우 높습니다.

```python
# 기본 print() 사용
print("Hello, Python!")
print(123)
print(True)

# 여러 값 출력 (쉼표로 구분하면 공백으로 자동 연결)
print("이름:", "김철수", "나이:", 25)

# f-string을 이용한 출력
name = "영희"
age = 22
print(f"이름: {name}, 나이: {age}")

# f-string에서 표현식 사용
price = 100
quantity = 5
print(f"총 가격: {price * quantity}원")

# f-string에서 포매팅 (소수점, 정렬 등)
pi = 3.1415926535
print(f"원주율: {pi:.2f}") # 소수점 둘째 자리까지
print(f"정렬: {name:<10}") # 10칸 확보 후 왼쪽 정렬
print(f"정렬: {age:>5}")   # 5칸 확보 후 오른쪽 정렬
```
- **f-string을 이용한 디버깅:**
  파이썬 3.8부터 f-string에 `=` 기호를 추가하여 변수 이름과 값을 함께 출력할 수 있습니다. 이는 디버깅 시 매우 유용하고 간결한 방법입니다. **특히 복잡한 데이터 구조나 중간 계산 결과를 빠르게 확인해야 하는 데이터 과학 작업에서 강력한 디버깅 도구로 활용될 수 있습니다.**
  ```python
  value = 123
  name = "데이터"
  print(f"{value=}") # 출력: value=123
  print(f"{name=}")  # 출력: name='데이터'
  print(f"{value * 2=}") # 출력: value * 2=246
  ```

- 디버깅 시 변수 값을 빠르게 확인하는 용도로 `print()`를 적극 활용합니다.
- 복잡한 문자열을 구성할 때는 `f-string`을 사용하는 것이 가장 파이썬스럽고 효율적입니다.

## 5. 연산자 (Operators)

연산자는 값(피연산자)에 대해 특정 연산을 수행하는 기호입니다. 파이썬은 다양한 종류의 연산자를 제공합니다.

### 5.1 산술 연산자

숫자 계산에 사용되는 연산자입니다. 파이썬의 연산자들은 객체 지향의 특징인 **연산자 오버로딩(Operator Overloading)**을 통해 사용자 정의 클래스에서도 특별한 동작을 하도록 정의될 수 있습니다. 이는 객체에 대한 연산을 직관적으로 만들고 코드의 가독성을 높여줍니다.

| 연산자 | 설명 | 예시 | 결과 |
| :--- | :--- | :--- | :--- |
| `+` | 덧셈 | `10 + 3` | `13` |
| `-` | 뺄셈 | `10 - 3` | `7` |
| `*` | 곱셈 | `10 * 3` | `30` |
| `/` | 나눗셈 (실수) | `10 / 3` | `3.333...` |
| `//` | 몫 (정수 나눗셈) | `10 // 3` | `3` |
| `%` | 나머지 | `10 % 3` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

```python
a = 10
b = 3

print(f"덧셈: {a + b}")
print(f"뺄셈: {a - b}")
print(f"곱셈: {a * b}")
print(f"나눗셈: {a / b}")
print(f"몫: {a // b}")
print(f"나머지: {a % b}")
print(f"거듭제곱: {a ** b}")
```

### 5.2 할당 연산자

변수에 값을 할당할 때 사용됩니다. 산술 연산자와 결합하여 사용하기도 합니다.

| 연산자 | 예시 | 설명 |
| :--- | :--- | :--- |
| `=` | `x = 10` | `x`에 `10`을 할당 |
| `+=` | `x += 5` | `x = x + 5`와 동일 |
| `-=` | `x -= 5` | `x = x - 5`와 동일 |
| `*=` | `x *= 5` | `x = x * 5`와 동일 |
| `/=` | `x /= 5` | `x = x / 5`와 동일 |
| `//=` | `x //= 5` | `x = x // 5`와 동일 |
| `%=` | `x %= 5` | `x = x % 5`와 동일 |
| `**=` | `x **= 5` | `x = x ** 5`와 동일 |

```python
x = 10
print(f"초기 x: {x}")

x += 5  # x = 10 + 5 = 15
print(f"x += 5 후: {x}")

x -= 3  # x = 15 - 3 = 12
print(f"x -= 3 후: {x}")

x *= 2  # x = 12 * 2 = 24
print(f"x *= 2 후: {x}")

x /= 4  # x = 24 / 4 = 6.0
print(f"x /= 4 후: {x}")
```

### 5.3 비교 연산자

두 값의 크기나 동일 여부를 비교하여 `True` 또는 `False`를 반환합니다.

| 연산자 | 설명 | 예시 | 결과 |
| :--- | :--- | :--- | :--- |
| `==` | 같다 | `10 == 10` | `True` |
| `!=` | 같지 않다 | `10 != 5` | `True` |
| `>` | 크다 | `10 > 5` | `True` |
| `<` | 작다 | `10 < 5` | `False` |
| `>=` | 크거나 같다 | `10 >= 10` | `True` |
| `<=` | 작거나 같다 | `10 <= 5` | `False` |

```python
a = 10
b = 5

print(f"a == b: {a == b}")
print(f"a != b: {a != b}")
print(f"a > b: {a > b}")
print(f"a < b: {a < b}")
print(f"a >= b: {a >= b}")
print(f"a <= b: {a <= b}")

# 문자열 비교 (사전 순)
print(f"'apple' > 'banana': {'apple' > 'banana'}") # False
```

### 5.4 논리 연산자

불리언 값을 조합하여 새로운 불리언 값을 만듭니다. 조건문에서 복합적인 조건을 만들 때 사용됩니다.

| 연산자 | 설명 | 예시 |
| :--- | :--- | :--- |
| `and` | 양쪽 모두 `True`일 때 `True` | `True and False` -> `False` |
| `or` | 둘 중 하나라도 `True`일 때 `True` | `True or False` -> `True` |
| `not` | 불리언 값을 반전 | `not True` -> `False` |

```python
age = 20
has_license = True

print(f"성인이고 면허가 있는가? {age >= 19 and has_license}") # True and True -> True
print(f"성인이거나 면허가 있는가? {age >= 19 or has_license}")  # True or True -> True
print(f"면허가 없는가? {not has_license}") # not True -> False

# 단축 평가 (Short-circuit evaluation)
# and: 첫 번째 False를 만나면 뒤는 평가하지 않음
print(False and print("이 메시지는 출력되지 않습니다."))

# or: 첫 번째 True를 만나면 뒤는 평가하지 않음
print(True or print("이 메시지는 출력되지 않습니다."))
```

### 5.5 멤버십 연산자 (`in`, `not in`)

시퀀스(문자열, 리스트, 튜플 등) 내에 특정 요소가 포함되어 있는지 확인합니다.

| 연산자 | 설명 | 예시 | 결과 |
| :--- | :--- | :--- | :--- |
| `in` | 요소가 시퀀스 안에 있으면 `True` | `'a' in 'apple'` | `True` |
| `not in` | 요소가 시퀀스 안에 없으면 `True` | `'z' not in 'apple'` | `True` |

```python
my_string = "hello python"
my_list = [1, 2, 3, 4, 5]

print(f"'h' in my_string: {'h' in my_string}")
print(f"'x' in my_string: {'x' in my_string}")
print(f"3 in my_list: {3 in my_list}")
print(f"6 not in my_list: {6 not in my_list}")
```

- 특정 문자열이 텍스트에 포함되어 있는지, 리스트에 특정 값이 있는지 빠르게 확인할 때 유용합니다.
- 데이터 필터링이나 유효성 검사 시 자주 사용됩니다.

### 5.6 식별 연산자 (`is`, `is not`)

두 변수가 동일한 객체를 참조하는지 (메모리 주소가 같은지) 확인합니다. `==`는 값의 동일성을 비교하는 반면, `is`는 객체의 동일성을 비교합니다.

**객체 동일성 (Identity) vs. 값 동일성 (Equality)**
- `is` 연산자는 두 변수가 **메모리 상에서 동일한 객체를 참조하는지(객체 ID가 같은지)** 확인합니다. 즉, 두 변수가 같은 메모리 주소를 가리키는지를 비교합니다.
- `==` 연산자는 두 객체의 **값이 같은지**를 비교합니다. 객체의 내용이 동일한지를 확인합니다.

이 두 연산자의 차이를 이해하는 것은 파이썬에서 객체를 다룰 때 매우 중요합니다. 특히 리스트나 딕셔너리 같은 가변 객체를 복사하거나 참조할 때 혼동하기 쉽습니다.

| 연산자 | 설명 | 예시 | 결과 |
| :--- | :--- | :--- | :--- |
| `is` | 두 변수가 동일한 객체를 참조하면 `True` | `a is b` | `True` (동일 객체) |
| `is not` | 두 변수가 동일한 객체를 참조하지 않으면 `True` | `a is not b` | `True` (다른 객체) |

```python
list1 = [1, 2, 3]
list2 = [1, 2, 3]
list3 = list1 # list3은 list1과 동일한 객체를 참조

print(f"id(list1): {id(list1)}")
print(f"id(list2): {id(list2)}")
print(f"id(list3): {id(list3)}")

print(f"list1 == list2: {list1 == list2}") # 값은 같으므로 True
print(f"list1 is list2: {list1 is list2}") # 다른 객체이므로 False

print(f"list1 == list3: {list1 == list3}") # 값은 같으므로 True
print(f"list1 is list3: {list1 is list3}") # 동일 객체이므로 True

# None과의 비교는 항상 is를 사용
my_var = None
print(f"my_var is None: {my_var is None}")
```
- **정수 및 문자열 인터닝 (Interning) 참고:**
  파이썬은 메모리 효율성을 위해 작은 정수(보통 -5부터 256까지)와 짧은 문자열을 미리 생성하여 캐시해 둡니다. 따라서 이 범위 내의 값들은 `is` 연산 시 `True`를 반환할 수 있습니다. 하지만 이 범위를 벗어나거나 동적으로 생성된 객체(예: `"a" * 1000`)는 `is` 연산 시 `False`를 반환할 수 있습니다. 이는 구현 세부 사항이며, `is`는 항상 객체 동일성을 확인한다는 본질은 변하지 않습니다.
  ```python
  a = 1
  b = 1
  print(f"1 is 1: {a is b}") # True (인터닝)

  a = 257
  b = 257
  print(f"257 is 257: {a is b}") # False일 수 있음 (인터닝 범위 밖)

  s1 = "hello_world"
  s2 = "hello_world"
  print(f"'hello_world' is 'hello_world': {s1 is s2}") # True일 수 있음 (짧은 문자열 인터닝)
  ```
- 리스트나 딕셔너리 같은 가변 객체를 다룰 때, `is`와 `==`의 차이를 이해하는 것이 중요합니다. 복사본인지 원본 객체인지 판단할 때 유용합니다.

### 5.7 비트 연산자 (Bitwise Operators)

비트 연산자는 숫자를 이진수(비트) 수준에서 직접 조작할 때 사용됩니다. 주로 저수준 프로그래밍, 암호화, 특정 알고리즘(예: 비트마스크)에서 활용됩니다. 데이터 과학이나 AI 분야에서 직접적으로 자주 사용되지는 않지만, 특정 최적화나 문제 해결에 유용할 수 있습니다.

| 연산자 | 설명 | 예시 |
| :--- | :--- | :--- |
| `&` | 비트 AND | `5 & 3` (0101 & 0011 = 0001 = 1) |
| `|` | 비트 OR | `5 | 3` (0101 | 0011 = 0111 = 7) |
| `^` | 비트 XOR | `5 ^ 3` (0101 ^ 0011 = 0110 = 6) |
| `~` | 비트 NOT (단항) | `~5` (~0101 = 1010 = -6) |
| `<<` | 왼쪽 시프트 | `5 << 1` (0101 << 1 = 1010 = 10) |
| `>>` | 오른쪽 시프트 | `5 >> 1` (0101 >> 1 = 0010 = 2) |

```python
a = 5  # 이진수: 0101
b = 3  # 이진수: 0011

print(f"5 & 3 = {a & b}") # 1 (0001)
print(f"5 | 3 = {a | b}") # 7 (0111)
print(f"5 ^ 3 = {a ^ b}") # 6 (0110)
print(f"~5 = {~a}")     # -6 (2의 보수 표현)
print(f"5 << 1 = {a << 1}") # 10 (1010)
print(f"5 >> 1 = {a >> 1}") # 2 (0010)
```

- **실용적 활용: 비트마스크 (Bitmasks)**
  비트마스크는 각 비트가 특정 상태(True/False)나 권한을 나타내는 데 사용되는 정수입니다. 여러 개의 불리언 플래그를 하나의 정수로 효율적으로 저장하고 조작할 수 있습니다. 데이터 과학에서는 특성(feature)의 존재 여부나 특정 조건의 조합을 간결하게 표현할 때 활용될 수 있습니다. **예를 들어, 설문조사 응답에서 여러 개의 선택지를 비트마스크로 저장하거나, 특정 데이터 포인트가 여러 범주에 동시에 속하는 경우를 효율적으로 표현하고 필터링하는 데 사용될 수 있습니다.**
  ```python
  # 권한 정의 (각 비트가 하나의 권한을 나타냄)
  READ = 0b001 # 1
  WRITE = 0b010 # 2
  EXECUTE = 0b100 # 4

  # 사용자 권한 설정
  user_permission = READ | WRITE # 읽기 및 쓰기 권한 (001 | 010 = 011 = 3)
  print(f"사용자 권한: {user_permission}")

  # 권한 확인
  print(f"읽기 권한이 있는가? {(user_permission & READ) == READ}") # True
  print(f"실행 권한이 있는가? {(user_permission & EXECUTE) == EXECUTE}") # False

  # 권한 추가
  user_permission |= EXECUTE # 실행 권한 추가
  print(f"실행 권한 추가 후: {user_permission}")

  # 권한 제거
  user_permission &= ~WRITE # 쓰기 권한 제거
  print(f"쓰기 권한 제거 후: {user_permission}")
  ```


### 5.8 연산자 우선순위 (Operator Precedence)
- 파이썬의 연산자에는 우선순위가 있습니다. 예를 들어, 곱셈과 나눗셈은 덧셈과 뺄셈보다 먼저 수행됩니다.
- 복잡한 표현식에서는 괄호 `()`를 사용하여 연산의 순서를 명확히 지정하는 것이 좋습니다. 이는 코드의 가독성을 높이고 예상치 못한 오류를 방지하는 데 도움이 됩니다.
  ```python
  # 괄호 없이
  result1 = 10 + 5 * 2  # 5 * 2가 먼저 계산되어 10 + 10 = 20
  print(f"Result 1: {result1}")

  # 괄호를 사용하여 순서 명확히
  result2 = (10 + 5) * 2 # (10 + 5)가 먼저 계산되어 15 * 2 = 30
  print(f"Result 2: {result2}")
  ```

#### 5.8.1 연산자 우선순위의 실무적 중요성
연산자 우선순위를 명확히 이해하고 활용하는 것은 코드의 정확성, 가독성, 그리고 유지보수성에 직접적인 영향을 미칩니다.

-   **정확성 보장:** 연산자 우선순위를 잘못 이해하면 예상과 다른 결과가 나올 수 있습니다. 특히 복잡한 수식이나 조건문에서 이러한 오류는 발견하기 어렵고 심각한 버그로 이어질 수 있습니다. 괄호 `()`를 사용하여 연산의 순서를 명시적으로 지정하는 습관은 이러한 잠재적 오류를 원천적으로 방지합니다.

-   **코드 가독성 향상:** 비록 연산자 우선순위 규칙을 알고 있더라도, 복잡한 표현식에서 괄호를 생략하면 코드를 읽는 사람이 연산 순서를 파악하기 위해 추가적인 노력을 해야 합니다. 괄호를 적절히 사용하면 코드의 의도를 명확하게 전달하여 다른 개발자(미래의 자신 포함)가 코드를 더 빠르고 정확하게 이해할 수 있도록 돕습니다.

-   **유지보수 용이성:** 시간이 지나 코드를 수정하거나 확장할 때, 연산 순서가 명확하게 표현된 코드는 변경으로 인한 부작용을 줄이고 안전하게 작업을 수행할 수 있게 합니다. 모호한 코드는 작은 수정에도 전체 로직을 재검토해야 하는 비효율을 초래합니다.

-   **데이터 분석 및 AI 모델:** 데이터 전처리 과정에서 복잡한 수치 연산이나 조건 필터링을 수행할 때 연산자 우선순위는 매우 중요합니다. 예를 들어, `df[(df['col1'] > 10) & (df['col2'] < 20)]`와 같은 조건문에서 괄호가 없다면 논리 연산자의 우선순위에 따라 의도치 않은 결과가 나올 수 있습니다. 모델의 손실 함수나 평가 지표를 구현할 때도 정확한 연산 순서가 필수적입니다.

**결론:** 연산자 우선순위는 파이썬의 기본 문법 중 하나이지만, 실제 개발에서는 괄호를 통한 명시적인 순서 지정이 코드의 품질을 높이는 핵심적인 습관입니다. "명시적인 것이 암시적인 것보다 낫다"는 파이썬의 철학을 따르는 좋은 예시입니다.


## 6. 객체의 가변성(Mutable)과 불변성(Immutable)

파이썬의 모든 데이터는 객체이며, 이 객체들은 크게 **가변(Mutable)** 객체와 **불변(Immutable)** 객체로 나뉩니다. 이 특성은 객체가 생성된 후 그 내용을 변경할 수 있는지 여부를 결정하며, 파이썬 프로그래밍의 중요한 동작 방식에 영향을 미칩니다.

### 6.1 불변(Immutable) 객체
생성된 후에는 그 값을 변경할 수 없는 객체입니다. 값을 변경하려는 시도는 새로운 객체를 생성하는 결과를 낳습니다.
-   **종류:** 숫자(int, float, complex), 문자열(str), 튜플(tuple), frozenset, None, bool
-   **특징:**
    *   메모리 효율성: 값이 변하지 않으므로, 여러 변수가 동일한 불변 객체를 참조해도 안전합니다.
    *   해시 가능(Hashable): 값이 변하지 않으므로 해시 값을 계산할 수 있어 딕셔너리의 키나 집합의 요소로 사용될 수 있습니다.
-   **예시:**
    ```python
    a = 10
    b = a
    print(f"a의 id: {id(a)}, b의 id: {id(b)}") # 동일한 id

    a += 1 # 새로운 int 객체 생성
    print(f"a의 id: {id(a)}, b의 id: {id(b)}") # a의 id가 변경됨
    print(f"a: {a}, b: {b}") # b는 여전히 10
    ```

### 6.2 가변(Mutable) 객체
생성된 후에도 그 내용을 변경할 수 있는 객체입니다.
-   **종류:** 리스트(list), 딕셔너리(dict), 집합(set)
-   **특징:**
    *   인플레이스(in-place) 변경: 객체 자체의 메모리 주소는 유지하면서 내부 값을 변경할 수 있습니다.
    *   별칭(Aliasing) 문제: 여러 변수가 동일한 가변 객체를 참조할 때, 한 변수를 통해 객체를 변경하면 다른 변수들도 변경된 객체를 보게 됩니다.
    *   **가변 기본 인자 함정:** 함수 정의 시 가변 객체(예: 리스트, 딕셔너리)를 기본 인자로 사용하면, 함수가 호출될 때마다 동일한 객체가 공유되어 예상치 못한 부작용을 일으킬 수 있습니다. (자세한 내용은 0430정리.md의 '2.1 기본값(Default Argument) 설정' 섹션 참조)
    *   해시 불가능(Unhashable): 값이 변할 수 있으므로 해시 값을 계산할 수 없어 딕셔너리의 키나 집합의 요소로 직접 사용될 수 없습니다.
-   **예시:**
    ```python
    list1 = [1, 2, 3]
    list2 = list1 # list1과 list2는 동일한 리스트 객체를 참조
    print(f"list1의 id: {id(list1)}, list2의 id: {id(list2)}") # 동일한 id

    list1.append(4) # list1을 통해 리스트 내용 변경
    print(f"list1의 id: {id(list1)}, list2의 id: {id(list2)}") # id는 여전히 동일
    print(f"list1: {list1}, list2: {list2}") # list2도 변경된 내용을 봄
    ```

### 6.3 해시 가능(Hashable) 객체와 그 중요성
해시 가능한 객체는 `__hash__()` 메서드를 가지고 있으며, 이 메서드가 반환하는 해시 값이 객체의 생명 주기 동안 변하지 않는 객체입니다. 또한 `__eq__()` 메서드를 통해 다른 객체와 비교 가능해야 합니다.
-   **중요성:** 딕셔너리(Dictionary)의 키와 집합(Set)의 요소는 반드시 해시 가능해야 합니다. 이는 딕셔너리와 집합이 내부적으로 해시 테이블(Hash Table)이라는 자료구조를 사용하여 데이터를 저장하고 검색하기 때문입니다. 해시 테이블은 키(또는 요소)의 해시 값을 사용하여 데이터를 빠르게 찾는데, 만약 키의 해시 값이 변한다면 데이터를 찾을 수 없게 됩니다.
-   **예시:**
    ```python
    # 불변 객체인 튜플은 딕셔너리 키로 사용 가능
    my_dict = {(1, 2): 'value'}
    print(my_dict)

    # 가변 객체인 리스트는 딕셔너리 키로 사용 불가능 (TypeError 발생)
    try:
        my_dict = {[1, 2]: 'value'}
    except TypeError as e:
        print(f"TypeError 발생: {e}")
    ```
