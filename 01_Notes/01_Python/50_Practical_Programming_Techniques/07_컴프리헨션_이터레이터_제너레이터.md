## 2. 이터레이터와 제너레이터 (Iterators & Generators)

파이썬에서 반복 가능한(iterable) 객체는 `for` 루프 등에서 순회될 수 있는 객체를 의미하며, 이터레이터(iterator)는 이러한 반복을 실제로 수행하는 객체입니다. 제너레이터(generator)는 이터레이터를 쉽게 생성할 수 있는 특별한 함수입니다.

### 2.1 `for` 루프의 동작 원리 (Iterables, Iterators)

`for` 루프는 내부적으로 다음과 같은 과정을 거쳐 동작합니다.

1.  `iter()` 함수를 호출하여 반복 가능한(iterable) 객체로부터 이터레이터(iterator) 객체를 얻습니다. 이때, iterable 객체의 `__iter__()` 메서드가 호출됩니다.
2.  이터레이터의 `next()` 메서드를 반복적으로 호출하여 다음 요소를 가져옵니다. 이때, iterator 객체의 `__next__()` 메서드가 호출됩니다.
3.  더 이상 요소가 없으면 `StopIteration` 예외가 발생하고, `for` 루프는 이 예외를 내부적으로 처리하여 반복을 종료합니다.

```python
my_list = [1, 2, 3]
my_iterator = iter(my_list) # 내부적으로 my_list.__iter__() 호출

print(f"첫 번째 요소: {next(my_iterator)}") # 1 (내부적으로 my_iterator.__next__() 호출)
print(f"두 번째 요소: {next(my_iterator)}") # 2
print(f"세 번째 요소: {next(my_iterator)}") # 3
# print(next(my_iterator)) # StopIteration 발생

# 문자열도 iterable
my_string = "abc"
string_iterator = iter(my_string)
print(f"문자열 첫 요소: {next(string_iterator)}") # a
```

**사용자 정의 이터러블 및 이터레이터 생성:**

클래스를 사용하여 사용자 정의 이터러블과 이터레이터를 만들 수 있습니다.
*   **이터러블(Iterable):** `__iter__` 메서드를 구현해야 합니다. 이 메서드는 이터레이터 객체를 반환해야 합니다.
*   **이터레이터(Iterator):** `__iter__` 메서드 (자기 자신을 반환)와 `__next__` 메서드를 구현해야 합니다. `__next__` 메서드는 다음 값을 반환하고, 더 이상 값이 없으면 `StopIteration` 예외를 발생시켜야 합니다.

```python
class MyRange:
    def __init__(self, start, end):
        self.current = start
        self.end = end

    def __iter__(self): # 이터러블 객체는 __iter__를 구현하여 이터레이터를 반환
        return self # 여기서는 자기 자신이 이터레이터 역할도 겸함

    def __next__(self): # 이터레이터 객체는 __next__를 구현하여 다음 값을 반환
        if self.current < self.end:
            num = self.current
            self.current += 1
            return num
        raise StopIteration # 더 이상 값이 없으면 StopIteration 발생

# MyRange 객체는 이터러블이므로 for 루프에서 사용 가능
for i in MyRange(1, 5):
    print(i)
# Output:
# 1
# 2
# 3
# 4

# 직접 이터레이터 사용
my_range_iter = iter(MyRange(1, 3))
print(next(my_range_iter)) # 1
print(next(my_range_iter)) # 2
# print(next(my_range_iter)) # StopIteration
```

### 2.2 `yield` 키워드를 사용한 제너레이터 함수

제너레이터 함수는 일반 함수처럼 정의되지만, `return` 대신 `yield` 키워드를 사용하여 값을 반환합니다. `yield`는 함수를 일시 중지시키고 값을 반환한 다음, 다음에 호출될 때 중지된 지점부터 실행을 재개합니다. 이를 통해 메모리에 모든 값을 한꺼번에 생성하지 않고, 필요할 때마다 값을 생성하는 이터레이터를 만들 수 있습니다.

*   **`yield from` (서브 제너레이터 위임):**
    `yield from`은 다른 제너레이터나 이터러블로부터 값을 `yield`할 때 사용됩니다. 이는 중첩된 제너레이터를 더 간결하게 작성하고, 서브 제너레이터의 값을 메인 제너레이터로 직접 전달하는 데 유용합니다.
    ```python
    def sub_generator():
        yield 'A'
        yield 'B'

    def main_generator():
        yield 1
        yield from sub_generator() # sub_generator의 값을 위임
        yield 2

    print(f"yield from 결과: {list(main_generator())}") # [1, 'A', 'B', 2]
    ```

### 2.3 메모리 효율성 측면에서의 장점

*   **지연 평가 (Lazy Evaluation):** 제너레이터는 모든 값을 미리 생성하여 메모리에 저장하지 않고, 요청이 있을 때마다 값을 하나씩 생성합니다. 이는 특히 대량의 데이터를 처리할 때 메모리 사용량을 크게 줄여줍니다. 대규모 파일 읽기, 네트워크 스트리밍 등 전체 데이터를 메모리에 로드할 수 없는 상황에서 매우 유용합니다. 딥러닝에서 대규모 데이터셋을 학습할 때 PyTorch의 `DataLoader`나 TensorFlow의 `tf.data` API가 내부적으로 이러한 지연 로딩(Lazy Loading) 개념을 활용하여 메모리 효율성을 극대화합니다. **파이썬 코드의 메모리 사용량을 분석하고 최적화하는 데는 `memory_profiler`나 `objgraph`와 같은 외부 라이브러리가 유용하게 사용될 수 있습니다.**
*   **무한 시퀀스 처리:** 제너레이터는 무한한 시퀀스를 표현할 수 있습니다. 예를 들어, 무한 피보나치 수열을 제너레이터로 구현할 수 있습니다.

```python
# 대량의 데이터 처리 예시
def large_list_processor(n):
    # 이 함수는 n개의 요소를 가진 리스트를 한꺼번에 생성하여 메모리에 로드합니다.
    # n이 매우 크면 메모리 문제가 발생할 수 있습니다.
    return [i * 2 for i in range(n)]

def large_generator_processor(n):
    # 이 제너레이터는 필요할 때마다 요소를 하나씩 생성하므로 메모리 효율적입니다.
    for i in range(n):
        yield i * 2

# 10억 개의 숫자를 처리한다고 가정
# data_list = large_list_processor(1_000_000_000) # 메모리 초과 가능성

data_generator = large_generator_processor(1_000_000_000) # 메모리 효율적

# 제너레이터는 필요한 만큼만 값을 생성
for _ in range(5):
    print(next(data_generator))
```

### 2.4 제너레이터 표현식 (Generator Expressions)

제너레이터 표현식은 리스트 컴프리헨션과 유사한 문법을 사용하여 제너레이터 객체를 생성하는 간결한 방법입니다. 소괄호 `()`를 사용하여 정의하며, 리스트 컴프리헨션과 달리 모든 요소를 메모리에 미리 생성하지 않고 필요할 때마다 값을 생성합니다.

**기본 문법:** `(expression for item in iterable if condition)`

```python
# 리스트 컴프리헨션 vs 제너레이터 표현식
list_comp = [x * x for x in range(1000000)] # 모든 요소를 메모리에 저장
gen_exp = (x * x for x in range(1000000)) # 필요할 때마다 요소 생성

print(f"리스트 컴프리헨션 타입: {type(list_comp)}") # <class 'list'>
print(f"제너레이터 표현식 타입: {type(gen_exp)}") # <class 'generator'>

# 제너레이터 표현식 사용 예시
sum_of_squares = sum(x*x for x in range(10))
print(f"0부터 9까지 제곱의 합: {sum_of_squares}") # 285

# 조건부 제너레이터 표현식
even_squares_gen = (x*x for x in range(10) if x % 2 == 0)
print(f"짝수의 제곱 제너레이터: {list(even_squares_gen)}") # [0, 4, 16, 36, 64]
```

*   **장점:**
    *   **메모리 효율성:** 대량의 데이터를 처리할 때 리스트 컴프리헨션보다 훨씬 적은 메모리를 사용합니다.
    *   **간결성:** 간단한 제너레이터를 한 줄로 빠르게 정의할 수 있습니다.
    *   **성능:** 모든 요소를 미리 생성하지 않으므로, 필요한 경우에만 계산하여 성능 이점을 얻을 수 있습니다.

제너레이터 표현식은 특히 `sum()`, `max()`, `min()`, `any()`, `all()` 등과 같이 이터레이터를 소비하는 함수와 함께 사용할 때 매우 효과적입니다.

### 2.5 `itertools` 모듈 소개

파이썬의 `itertools` 모듈은 효율적인 루프를 위한 빠르고 메모리 효율적인 이터레이터 빌딩 블록을 제공합니다. 이 모듈의 함수들은 제너레이터를 반환하며, 복잡한 반복 패턴을 간결하게 표현하고 처리할 수 있도록 돕습니다. 특히 무한 시퀀스나 조합, 순열 등을 다룰 때 매우 유용합니다.

- **`itertools.count(start=0, step=1)`: 무한 등차수열 생성**
    지정된 시작 값부터 일정한 간격으로 증가하는 무한 시퀀스를 생성합니다. 무한 루프나 고유 ID 생성 등에 활용될 수 있습니다.
    ```python
    import itertools

    # count(start, step): 무한 시퀀스 생성
    print("count 예시:")
    for i in itertools.count(10, 2): # 10, 12, 14, ... (무한)
        print(i)
        if i > 20: break
    # Output:
    # count 예시:
    # 10
    # 12
    # 14
    # 16
    # 18
    # 20
    # 22
    ```

- **`itertools.cycle(iterable)`: 요소 반복**
    주어진 이터러블의 요소를 무한히 반복합니다. 특정 패턴을 반복하거나, 라운드 로빈(round-robin) 방식으로 작업을 할당할 때 유용합니다.
    ```python
    # cycle(iterable): 요소 반복
    print("\ncycle 예시:")
    count = 0
    for item in itertools.cycle(['A', 'B', 'C']): # A, B, C, A, B, C, ... (무한)
        print(item)
        count += 1
        if count > 5: break # 예시를 위해 6번 반복 후 break
    # Output:
    # cycle 예시:
    # A
    # B
    # C
    # A
    # B
    # C
    ```

- **`itertools.chain(*iterables)`: 여러 이터러블 연결**
    여러 개의 이터러블을 하나로 연결하여 순차적으로 요소를 반환합니다. 여러 리스트나 튜플의 요소를 한 번에 처리할 때 편리합니다.

    ```python
    # chain(*iterables): 여러 이터러블 연결
    chained_list = list(itertools.chain([1, 2], ('a', 'b'), {10, 20}))
    print(f"\nchain: {chained_list}") # [1, 2, 'a', 'b', 10, 20] (순서는 보장되지 않음)
    ```

- **`itertools.combinations(iterable, r)`: 순서 상관없이 r개 선택 (조합)**
    주어진 이터러블에서 중복 없이 `r`개의 요소를 선택하는 모든 조합을 생성합니다. 순서가 중요하지 않은 경우의 수를 계산할 때 사용됩니다.
    ```python
    # combinations(iterable, r): 순서 상관없이 r개 선택
    combinations = list(itertools.combinations([1, 2, 3, 4], 2))
    print(f"combinations: {combinations}") # [(1, 2), (1, 3), (1, 4), (2, 3), (2, 4), (3, 4)]
    ```

- **`itertools.permutations(iterable, r=None)`: 순서 상관있게 r개 선택 (순열)**
    주어진 이터러블에서 중복 없이 `r`개의 요소를 선택하는 모든 조합을 생성합니다. 순서가 중요하지 않은 경우의 수를 계산할 때 사용됩니다.
    ```python
    # permutations(iterable, r=None): 순서 상관있게 r개 선택
    permutations = list(itertools.permutations([1, 2, 3], 2))
    print(f"permutations: {permutations}") # [(1, 2), (1, 3), (2, 1), (2, 3), (3, 1), (3, 2)]
    ```

- **`itertools.product(*iterables, repeat=1)`: 데카르트 곱**
    여러 이터러블의 데카르트 곱을 생성합니다. 중첩된 `for` 루프와 유사하게 모든 가능한 조합을 만들 때 사용됩니다. `repeat` 인자를 통해 동일한 이터러블을 여러 번 곱할 수 있습니다.
    ```python
    # product(*iterables, repeat=1): 데카르트 곱 (중첩 루프와 유사)
    prod = list(itertools.product(['A', 'B'], [1, 2]))
    print(f"product: {prod}") # [('A', 1), ('A', 2), ('B', 1), ('B', 2)]
    ```

#### 2.5.1 `itertools` 모듈의 고급 활용 (조합, 순열, 그룹화 예시)

- **`itertools.groupby(iterable, key=None)`: 요소 그룹화**
    연속된 동일한 키를 가진 요소들을 그룹화합니다. `groupby`는 연속된 요소만 그룹화하므로, 사용 전에 이터러블을 정렬하는 것이 일반적입니다. 데이터 분석에서 특정 기준으로 데이터를 묶어 처리할 때 매우 유용합니다.

    ```python
    import itertools

    # 요소 그룹화: groupby(iterable, key=None)
    # 연속된 동일한 키를 가진 요소들을 그룹화합니다.
    # 사용 전에 iterable을 정렬하는 것이 일반적입니다.

    # 예시: 이름의 첫 글자로 그룹화

    names = ['Alice', 'Anna', 'Bob', 'Charlie', 'Chris']
    names.sort() # groupby는 연속된 요소만 그룹화하므로 정렬이 중요

    for key, group in itertools.groupby(names, lambda name: name[0]):
        print(f"Key: {key}, Group: {list(group)}")
    # Output:
    # Key: A, Group: ['Alice', 'Anna']
    # Key: B, Group: ['Bob']
    # Key: C, Group: ['Charlie', 'Chris']
    ```

  *   **메모리 효율성:** `itertools` 함수들은 모든 결과를 메모리에 한꺼번에 생성하지 않고, 필요할 때마다 값을 생성하는 이터레이터를 반환하므로 대규모 데이터셋이나 무한 시퀀스를 다룰 때 매우 효율적입니다.
  *   **코드 간결성:** 복잡한 반복 로직을 몇 줄의 코드로 간결하게 표현할 수 있어 가독성과 유지보수성이 향상됩니다.
  *   **성능:** C로 구현되어 있어 파이썬 레벨의 루프보다 뛰어난 성능을 제공합니다.
  *   **데이터 과학 활용 시나리오:**
      *   **조합/순열 생성:** `itertools.combinations`나 `itertools.permutations`를 사용하여 특성 공학(Feature Engineering) 단계에서 새로운 특성 조합을 생성하거나, A/B 테스트의 모든 가능한 시나리오를 탐색할 때 유용합니다.
      *   **`groupby`를 이용한 시계열 데이터 분석:** `itertools.groupby`는 정렬된 시계열 데이터에서 특정 조건(예: 연속된 상승/하락 구간, 특정 이벤트의 연속 발생)에 따라 데이터를 그룹화하여 패턴을 분석하는 데 활용될 수 있습니다.
      *   **데이터 스트리밍 처리:** 대규모 로그 파일이나 센서 데이터 스트림을 처리할 때, `itertools`의 함수들을 조합하여 메모리 효율적으로 데이터를 필터링, 변환, 집계할 수 있습니다.

## 3. 유용한 내장 함수 (Useful Built-in Functions)

파이썬은 다양한 작업을 효율적으로 수행하는 데 유용한 많은 내장 함수를 제공합니다. 이 함수들은 C로 구현되어 있어 성능이 뛰어나며, 복잡한 로직을 간결하게 표현하여 코드의 가독성과 생산성을 높여줍니다. 이 섹션에서는 데이터 처리 및 분석에서 특히 자주 사용되는 핵심 내장 함수들을 실무적 관점에서 상세히 다룹니다.

### 3.1 `zip()`: 여러 시퀀스 병렬로 묶기

`zip()` 함수는 여러 개의 반복 가능한(iterable) 객체들을 병렬로 묶어, 각 객체의 요소들을 튜플 형태로 포함하는 이터레이터를 반환합니다. 데이터의 여러 특성을 레코드 단위로 묶거나, 두 개 이상의 리스트를 딕셔너리로 변환하는 등 데이터를 재구성할 때 매우 유용합니다.

#### 3.1.1 `zip()` 함수의 기본 사용법

`zip()`은 여러 이터러블을 인자로 받아, 동일한 인덱스에 있는 요소들을 튜플로 묶어줍니다. 반환된 `zip` 객체는 이터레이터이므로, `for` 루프나 `list()` 함수 등을 통해 소비할 수 있습니다.

```python
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]
cities = ['New York', 'London', 'Paris']

# 이름, 나이, 도시를 병렬로 묶기
zipped_data = zip(names, ages, cities)
print(f"zipped_data 타입: {type(zipped_data)}") # <class 'zip'> (이터레이터)

# zip 객체 순회
for name, age, city in zipped_data:
    print(f"이름: {name}, 나이: {age}, 도시: {city}")
# Output:
# 이름: Alice, 나이: 25, 도시: New York
# 이름: Bob, 나이: 30, 도시: London
# 이름: Charlie, 나이: 35, 도시: Paris

# zip 객체를 리스트로 변환
list_of_tuples = list(zip(names, ages))
print(f"리스트로 변환: {list_of_tuples}") # [('Alice', 25), ('Bob', 30), ('Charlie', 35)]
```

#### 3.1.2 `zip()`의 특징 및 실무적 활용

*   **길이가 다른 시퀀스 처리:** `zip()`은 인자로 전달된 시퀀스 중 **가장 짧은** 길이에 맞춰 요소를 묶습니다. 길이가 더 긴 시퀀스의 나머지 요소들은 무시됩니다.
    ```python
    names = ['Alice', 'Bob', 'Charlie']
    scores = [95, 88]
    
    for name, score in zip(names, scores):
        print(f"{name}: {score}")
    # Output:
    # Alice: 95
    # Bob: 88
    # 'Charlie'는 짝이 없어 무시됨
    ```

*   **`itertools.zip_longest`:** 모든 시퀀스의 길이를 맞추고 싶을 때는 `itertools.zip_longest`를 사용합니다. 가장 긴 시퀀스에 맞춰 묶고, 부족한 부분은 `fillvalue`로 채웁니다 (기본값은 `None`).
    ```python
    from itertools import zip_longest

    names = ['Alice', 'Bob', 'Charlie']
    scores = [95, 88]

    longest_zip = list(zip_longest(names, scores, fillvalue='N/A'))
    print(f"zip_longest 결과: {longest_zip}")
    # [('Alice', 95), ('Bob', 88), ('Charlie', 'N/A')]
    ```

*   **데이터 언패킹 (Unzipping / Transposing):** `*` 연산자와 함께 `zip()`을 사용하면 묶여 있던 데이터를 다시 원래의 개별 시퀀스로 분리(언패킹)할 수 있습니다. 이는 2차원 데이터의 행과 열을 바꾸는(transpose) 효과가 있습니다.
    ```python
    zipped_coords = [(1, 2), (3, 4), (5, 6)]
    x_coords, y_coords = zip(*zipped_coords)
    print(f"x 좌표: {x_coords}") # (1, 3, 5)
    print(f"y 좌표: {y_coords}") # (2, 4, 6)
    ```

*   **딕셔너리 생성:** 두 리스트(키 리스트, 값 리스트)를 사용하여 딕셔너리를 생성할 때 매우 유용합니다.
    ```python
    keys = ['name', 'age', 'city']
    values = ['David', 40, 'Seoul']
    person_dict = dict(zip(keys, values))
    print(f"생성된 딕셔너리: {person_dict}")
    # {'name': 'David', 'age': 40, 'city': 'Seoul'}
    ```

### 3.2 `enumerate()`: 인덱스와 값 동시 순회

`enumerate()` 함수는 반복 가능한 객체를 순회할 때 **인덱스**와 **값**을 함께 포함하는 이터레이터를 반환합니다. `for` 루프에서 `range(len(sequence))`와 같이 인덱스를 별도로 계산하는 것보다 훨씬 간결하고 파이썬스러운(Pythonic) 방법입니다.

#### 3.2.1 `enumerate()` 함수의 기본 사용법

`enumerate()`는 이터러블을 인자로 받아, `(인덱스, 값)` 형태의 튜플을 생성하는 이터레이터를 반환합니다. 기본적으로 인덱스는 0부터 시작하지만, `start` 매개변수를 통해 시작 인덱스를 지정할 수 있습니다.

```python
fruits = ['apple', 'banana', 'cherry']

# 기본 사용법 (인덱스 0부터 시작)
for index, fruit in enumerate(fruits):
    print(f"인덱스 {index}: {fruit}")
# Output:
# 인덱스 0: apple
# 인덱스 1: banana
# 인덱스 2: cherry

# 시작 인덱스 지정 (1부터 시작)
for index, fruit in enumerate(fruits, start=1):
    print(f"{index}번째 과일: {fruit}")
# Output:
# 1번째 과일: apple
# 2번째 과일: banana
# 3번째 과일: cherry
```

#### 3.2.2 `enumerate()`의 특징 및 실무적 활용

*   **가독성 및 유지보수성 향상:** `range(len())` 패턴에 비해 코드가 직관적이고 읽기 쉬워집니다.
    ```python
    # 비권장 방식
    for i in range(len(fruits)):
        print(f"인덱스 {i}: {fruits[i]}")

    # 권장 방식 (enumerate)
    for i, fruit in enumerate(fruits):
        print(f"인덱스 {i}: {fruit}")
    ```

*   **특정 조건의 인덱스 찾기:** 리스트를 순회하며 특정 조건을 만족하는 요소의 인덱스를 찾아야 할 때 유용합니다.
    ```python
    scores = [88, 92, 77, 95, 85]
    # 90점 이상인 첫 번째 학생의 인덱스 찾기
    for index, score in enumerate(scores):
        if score >= 90:
            print(f"첫 90점 이상 학생의 위치: {index+1}번째 (점수: {score})")
            break
    # Output: 첫 90점 이상 학생의 위치: 2번째 (점수: 92)
    ```

*   **데이터 처리 로그 생성:** 데이터 처리 파이프라인에서 현재 몇 번째 항목을 처리하고 있는지 로그를 남길 때 유용하게 사용할 수 있습니다.

### 3.3 `len()`, `max()`, `min()`, `sum()`: 기본 통계 함수

이 함수들은 시퀀스나 반복 가능한 객체의 기본적인 통계 정보를 계산하는 데 사용됩니다. 데이터의 크기를 확인하거나, 값의 범위를 파악하고, 합계를 구하는 등 데이터 분석의 기초적인 단계에서 필수적입니다.

#### 3.3.1 각 함수의 기본 사용법

*   **`len(iterable)`:** 객체의 길이(요소의 개수)를 반환합니다.
*   **`max(iterable, *, key=None, default=...)`:** 가장 큰 요소를 반환합니다.
*   **`min(iterable, *, key=None, default=...)`:** 가장 작은 요소를 반환합니다.
*   **`sum(iterable, /, start=0)`:** 모든 요소의 합을 반환합니다. `start`는 합계를 시작할 초기값입니다.

```python
numbers = [10, 20, 5, 30, 15]

print(f"요소의 개수 (len): {len(numbers)}")      # 5
print(f"최대값 (max): {max(numbers)}")        # 30
print(f"최소값 (min): {min(numbers)}")        # 5
print(f"합계 (sum): {sum(numbers)}")          # 80
print(f"합계 (초기값 100): {sum(numbers, 100)}") # 180

# 문자열에도 적용 가능 (사전 순)
words = ['apple', 'zebra', 'banana']
print(f"가장 큰 단어 (max): {max(words)}") # zebra
print(f"가장 작은 단어 (min): {min(words)}") # apple
```

#### 3.3.2 `key` 인자를 활용한 고급 활용

`max()`, `min()`, `sorted()`와 같은 함수들은 `key` 인자를 받아 비교 기준을 사용자 정의할 수 있습니다. `key`에는 각 요소를 비교하기 전에 적용할 함수(주로 `lambda` 함수)를 전달합니다. 이는 복잡한 데이터 구조에서 특정 속성을 기준으로 값을 찾을 때 매우 강력합니다.

```python
students = [
    {'name': 'Alice', 'score': 85, 'age': 20},
    {'name': 'Bob', 'score': 92, 'age': 22},
    {'name': 'Charlie', 'score': 78, 'age': 21}
]

# 점수가 가장 높은 학생 찾기
highest_score_student = max(students, key=lambda s: s['score'])
print(f"최고 득점자: {highest_score_student['name']} ({highest_score_student['score']}점)")

# 이름 길이가 가장 짧은 학생 찾기
shortest_name_student = min(students, key=lambda s: len(s['name']))
print(f"이름이 가장 짧은 학생: {shortest_name_student['name']}")

# 나이가 가장 어린 학생 찾기
youngest_student = min(students, key=lambda s: s['age'])
print(f"나이가 가장 어린 학생: {youngest_student['name']} ({youngest_student['age']}세)")
```

### 3.4 `all()`, `any()`: 조건 검사 함수

이 함수들은 반복 가능한 객체의 모든 요소 또는 일부 요소가 특정 논리 조건을 만족하는지 확인할 때 사용됩니다. 데이터 유효성 검사나 필터링 조건 설정에 유용합니다.

#### 3.4.1 `all()`과 `any()`의 기본 사용법

*   **`all(iterable)`:** `iterable`의 **모든** 요소가 참(Truthy)이거나 `iterable`이 비어 있으면 `True`를 반환합니다. 하나라도 거짓(Falsy)이면 `False`를 반환합니다.
*   **`any(iterable)`:** `iterable`의 **어떤 요소라도** 참(Truthy)이면 `True`를 반환합니다. `iterable`이 비어 있거나 모든 요소가 거짓(Falsy)이면 `False`를 반환합니다.

```python
bool_list1 = [True, True, False]
bool_list2 = [True, True, True]
empty_list = []

print(f"all({bool_list1}): {all(bool_list1)}") # False
print(f"all({bool_list2}): {all(bool_list2)}") # True
print(f"all({empty_list}): {all(empty_list)}") # True (비어 있으면 True)

print(f"any({bool_list1}): {any(bool_list1)}") # True
print(f"any({bool_list2}): {any(bool_list2)}") # True
print(f"any({empty_list}): {any(empty_list)}") # False (비어 있으면 False)
```

#### 3.4.2 실무적 활용 (데이터 유효성 검사)

`all()`과 `any()`는 제너레이터 표현식과 결합될 때 매우 강력합니다. 대량의 데이터를 메모리에 올리지 않고도 효율적으로 조건을 검사할 수 있습니다.

```python
# 데이터 유효성 검사 예시
records = [
    {'id': 'user1', 'value': 10},
    {'id': 'user2', 'value': 25},
    {'id': 'user3', 'value': -5},
    {'id': 'user4', 'value': 0}
]

# 모든 value가 양수인지 검사
all_positive = all(r['value'] > 0 for r in records)
print(f"모든 값이 양수인가? {all_positive}") # False

# 음수 값이 하나라도 있는지 검사
has_negative = any(r['value'] < 0 for r in records)
print(f"음수 값이 있는가? {has_negative}") # True

# 모든 ID가 'user'로 시작하는지 검사
all_valid_ids = all(r['id'].startswith('user') for r in records)
print(f"모든 ID가 유효한가? {all_valid_ids}") # True
```

### 3.5 `map()`, `filter()`: 함수형 프로그래밍 도구

`map()`과 `filter()`는 함수형 프로그래밍 스타일의 도구로, 시퀀스의 각 요소에 함수를 적용하거나 특정 조건을 만족하는 요소만 필터링하는 데 사용됩니다. 두 함수 모두 결과를 **이터레이터**로 반환하므로 메모리 효율적입니다.

#### 3.5.1 `map()`과 `filter()`의 기본 사용법

*   **`map(function, iterable, ...)`:** `iterable`의 각 요소에 `function`을 적용한 결과를 담은 이터레이터를 반환합니다.
*   **`filter(function, iterable)`:** `iterable`의 각 요소 중 `function`을 적용했을 때 결과가 `True`인 요소만 담은 이터레이터를 반환합니다.

```python
numbers = [1, 2, 3, 4, 5]

# map: 각 숫자를 문자열로 변환
str_numbers = list(map(str, numbers))
print(f"map 결과 (문자열 변환): {str_numbers}") # ['1', '2', '3', '4', '5']

# map: 각 숫자를 제곱 (lambda 사용)
squared_numbers = list(map(lambda x: x * x, numbers))
print(f"map 결과 (제곱): {squared_numbers}") # [1, 4, 9, 16, 25]

# filter: 짝수만 필터링
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(f"filter 결과 (짝수): {even_numbers}") # [2, 4]

# filter: None, 0, 빈 문자열 등 Falsy 값 제거
mixed_data = [0, 'hello', None, 100, '', True]
truthy_data = list(filter(None, mixed_data)) # function으로 None을 전달하면 Truthy 값만 필터링
print(f"filter 결과 (Truthy 값): {truthy_data}") # ['hello', 100, True]
```

#### 3.5.2 실무적 활용 및 컴프리헨션과의 비교

`map`과 `filter`는 유용하지만, 많은 경우 **리스트/제너레이터 컴프리헨션**이 더 명확하고 파이썬스러운 대안이 될 수 있습니다.

*   **가독성:** 간단한 변환이나 필터링의 경우, 컴프리헨션이 `lambda`를 사용하는 것보다 코드를 읽기 더 쉬울 수 있습니다.
*   **유연성:** 컴프리헨션은 `map`과 `filter`를 동시에 수행하는 등 더 복잡한 로직을 한 줄로 표현할 수 있습니다.

```python
# map -> 리스트 컴프리헨션
# squared_numbers = list(map(lambda x: x * x, numbers))
squared_numbers_comp = [x * x for x in numbers]
print(f"리스트 컴프리헨션 (제곱): {squared_numbers_comp}")

# filter -> 리스트 컴프리헨션
# even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
even_numbers_comp = [x for x in numbers if x % 2 == 0]
print(f"리스트 컴프리헨션 (짝수): {even_numbers_comp}")

# map과 filter 조합 -> 리스트 컴프리헨션
# 짝수의 제곱 구하기
even_squared_map_filter = list(map(lambda x: x*x, filter(lambda x: x % 2 == 0, numbers)))
even_squared_comp = [x*x for x in numbers if x % 2 == 0]
print(f"짝수의 제곱 (map/filter): {even_squared_map_filter}") # [4, 16]
print(f"짝수의 제곱 (컴프리헨션): {even_squared_comp}") # [4, 16]
```
**언제 `map`을 사용하는가?** 이미 정의된 함수를 각 요소에 적용하고 싶을 때 `map`이 더 간결할 수 있습니다.
```python
words = ['  apple ', ' banana  ', 'cherry']
# str.strip 함수를 모든 요소에 적용
stripped_words = list(map(str.strip, words))
print(f"공백 제거 (map): {stripped_words}") # ['apple', 'banana', 'cherry']
```

### 3.6 `sorted()`: 정렬된 새 리스트 반환

`sorted()` 함수는 반복 가능한 객체의 모든 요소를 정렬한 **새로운 리스트**를 반환합니다. 원본 객체는 변경하지 않는다는 점에서 리스트의 `sort()` 메서드와 구별됩니다. 데이터 분석에서 순위를 매기거나, 순서에 따라 데이터를 처리해야 할 때 필수적인 함수입니다.

#### 3.6.1 `sorted()` 함수의 기본 사용법

`sorted()`는 이터러블을 인자로 받아 정렬된 새 리스트를 반환합니다. `reverse`와 `key` 매개변수를 통해 정렬 방식을 제어할 수 있습니다.

```python
unsorted_list = [3, 1, 4, 1, 5, 9, 2]

# 오름차순 정렬 (기본값)
sorted_result = sorted(unsorted_list)
print(f"정렬된 리스트: {sorted_result}")       # [1, 1, 2, 3, 4, 5, 9]
print(f"원본 리스트 (변경 없음): {unsorted_list}") # [3, 1, 4, 1, 5, 9, 2]

# 내림차순 정렬 (reverse=True)
sorted_desc = sorted(unsorted_list, reverse=True)
print(f"내림차순 정렬: {sorted_desc}")       # [9, 5, 4, 3, 2, 1, 1]
```

#### 3.6.2 `key`를 이용한 사용자 정의 정렬

`key` 매개변수에 함수를 지정하여 복잡한 객체도 특정 기준에 따라 정렬할 수 있습니다. 이는 `max()`, `min()`의 `key` 인자와 동일하게 동작하며, 데이터 정렬에서 가장 강력한 기능 중 하나입니다.

```python
# 문자열 길이 기준으로 정렬
words = ['banana', 'apple', 'kiwi', 'cherry']
sorted_by_length = sorted(words, key=len)
print(f"길이 기준 정렬: {sorted_by_length}") # ['kiwi', 'apple', 'banana', 'cherry']

# 딕셔너리 리스트 정렬
students = [
    {'name': 'Alice', 'score': 85},
    {'name': 'Bob', 'score': 92},
    {'name': 'Charlie', 'score': 78},
    {'name': 'David', 'score': 92}
]

# 점수 기준 내림차순 정렬
sorted_by_score = sorted(students, key=lambda s: s['score'], reverse=True)
print("점수 기준 내림차순 정렬:")
for student in sorted_by_score:
    print(student)

# 다중 조건 정렬 (점수 내림차순, 이름 오름차순)
# 튜플을 반환하는 람다를 사용. 튜플은 앞에서부터 순서대로 비교됨.
# 점수는 내림차순이므로 -를 붙임 (숫자일 경우)
sorted_multi = sorted(students, key=lambda s: (-s['score'], s['name']))
print("다중 조건 정렬 (점수 내림차순, 이름 오름차순):")
for student in sorted_multi:
    print(student)
```
