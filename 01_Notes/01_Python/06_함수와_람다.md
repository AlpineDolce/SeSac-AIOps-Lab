## 1. 함수의 기초

함수는 특정 작업을 수행하는 코드 블록을 묶어 놓은 것입니다. 코드를 재사용하고, 프로그램을 모듈화하여 가독성과 유지보수성을 높이는 데 필수적입니다.

### 1.1 함수 정의 (`def`)와 호출

함수는 `def` 키워드를 사용하여 정의하며, 함수 이름 뒤에 괄호 `()`와 콜론 `:`을 붙입니다. 함수 본문은 들여쓰기하여 작성합니다.

```python
# 함수 정의
def greet():
    """간단한 환영 메시지를 출력하는 함수"""
    print("Hello, Python!")

# 함수 호출
greet()
```

### 1.2 매개변수(Parameter)와 인자(Argument)

- **매개변수(Parameter):** 함수를 정의할 때 함수에 전달될 값을 받는 변수입니다.
- **인자(Argument):** 함수를 호출할 때 함수에 실제로 전달하는 값입니다.

```python
# 매개변수를 받는 함수 정의
def greet_name(name): # name이 매개변수
    """이름을 받아 환영 메시지를 출력하는 함수"""
    print(f"Hello, {name}!")

# 함수 호출 (인자 전달)
greet_name("Alice") # "Alice"가 인자
greet_name("Bob")
```

### 1.3 `return`을 이용한 값 반환

함수는 `return` 키워드를 사용하여 결과를 호출자에게 반환할 수 있습니다. `return` 문이 없으면 함수는 기본적으로 `None`을 반환합니다.

```python
# 값을 반환하는 함수 정의
def add(a, b):
    """두 숫자를 더한 결과를 반환하는 함수"""
    return a + b

# 함수 호출 및 반환 값 사용
result = add(5, 3)
print(f"덧셈 결과: {result}")

# 여러 값 반환 (튜플 형태로 반환됨)
def get_person_info():
    name = "Charlie"
    age = 25
    return name, age

person_name, person_age = get_person_info()
print(f"이름: {person_name}, 나이: {person_age}")
```

- **함수의 역할:** 함수는 단일 책임을 가지도록 설계하는 것이 좋습니다. (Single Responsibility Principle)
- **재사용성:** 반복되는 코드를 함수로 만들어 재사용하면 코드 중복을 줄이고 유지보수성을 높일 수 있습니다.

## 2. 매개변수 고급 활용

파이썬 함수는 다양한 방식으로 매개변수를 정의하고 인자를 전달할 수 있어 유연한 함수 설계를 가능하게 합니다.

### 2.1 기본값(Default Argument) 설정

매개변수에 기본값을 설정하면, 함수 호출 시 해당 인자를 생략할 경우 기본값이 사용됩니다. 기본값이 없는 매개변수는 기본값이 있는 매개변수보다 먼저 와야 합니다.

```python
def greet_with_default(name, greeting="Hello"):
    """기본 환영 메시지를 가진 함수"""
    print(f"{greeting}, {name}!")

greet_with_default("David") # 기본값 사용: Hello, David!
greet_with_default("Eve", "Hi") # 새로운 값 사용: Hi, Eve!
```
- **주의: 가변 객체를 기본값으로 사용 시 함정 (Mutable Default Argument Pitfall)**
  파이썬에서 함수의 기본값은 함수가 정의될 때 **한 번만 평가**됩니다. 따라서 리스트, 딕셔너리, 집합과 같은 **가변(mutable) 객체**를 기본값으로 사용하면, 모든 함수 호출이 동일한 기본 객체를 공유하게 되어 예상치 못한 부작용을 일으킬 수 있습니다. 이는 파이썬 초보자들이 흔히 겪는 버그 중 하나입니다.
  
  **권장 패턴:** 가변 객체를 기본값으로 사용해야 할 때는 `None`을 기본값으로 설정하고, 함수 내부에서 `None` 여부를 확인하여 새로운 객체를 생성하는 패턴을 사용합니다. 이는 각 함수 호출이 독립적인 가변 객체를 가지도록 보장합니다.
  ```python
  def add_item(item, my_list=None):
      if my_list is None:
          my_list = []
      my_list.append(item)
      return my_list

  list1 = add_item(1)
  print(f"List 1: {list1}") # [1]
  list2 = add_item(2) # 새로운 리스트가 생성되므로 list1에 영향 없음
  print(f"List 2: {list2}") # [2] (각각 독립적인 리스트)

  # 잘못된 사용 예시 (예상치 못한 동작)
  def bad_add_item(item, my_list=[]): # my_list는 함수 정의 시 한 번만 생성됨
      my_list.append(item)
      return my_list

  bad_list1 = bad_add_item(1)
  print(f"Bad List 1: {bad_list1}") # [1]
  bad_list2 = bad_add_item(2) # bad_list1과 동일한 리스트 객체를 공유
  print(f"Bad List 2: {bad_list2}") # [1, 2] (bad_list1과 bad_list2가 같은 리스트를 공유)
  bad_list3 = bad_add_item(3, []) # 명시적으로 새 리스트 전달 시에는 문제 없음
  print(f"Bad List 3: {bad_list3}") # [3]
  ```

### 2.2 위치 인자(Positional Arguments)와 키워드 인자(Keyword Arguments)

- **위치 인자:** 함수 호출 시 매개변수의 순서에 따라 값이 할당됩니다.
- **키워드 인자:** `매개변수명=값` 형태로 전달하여 순서에 상관없이 값을 할당할 수 있습니다. 가독성을 높이고 인자 순서 오류를 방지합니다.

```python
def describe_person(name, age, city):
    print(f"이름: {name}, 나이: {age}, 도시: {city}")

# 위치 인자 사용
describe_person("Frank", 40, "Seoul")

# 키워드 인자 사용 (순서 변경 가능)
describe_person(age=40, city="Seoul", name="Frank")

# 위치 인자와 키워드 인자 혼합 사용 (위치 인자가 먼저 와야 함)
describe_person("Grace", city="Busan", age=30)
```

### 2.3 위치 전용 인자 (Positional-Only Arguments)

파이썬 3.8부터 도입된 기능으로, 매개변수 이름 앞에 `/`를 사용하여 해당 매개변수가 반드시 위치 인자로만 전달되어야 함을 명시합니다. 이는 함수의 API를 명확히 하고, 사용자가 인자 이름을 사용하여 혼동하는 것을 방지합니다.

```python
def divide(a, b, /):
    """두 숫자를 나누는 함수 (a, b는 위치 인자로만 전달 가능)"""
    return a / b

print(f"나눗셈 결과: {divide(10, 2)}") # 위치 인자로만 호출 가능
# print(divide(a=10, b=2)) # TypeError: divide() got some positional-only arguments passed as keyword arguments: 'a, b'
```

### 2.4 키워드 전용 인자 (Keyword-Only Arguments)

매개변수 이름 앞에 `*` 또는 `*args`를 사용하여 해당 매개변수가 반드시 키워드 인자로만 전달되어야 함을 명시합니다. 이는 함수의 가독성을 높이고, 인자의 의미를 명확하게 합니다.

```python
def create_user(name, *, age, city):
    """사용자 정보를 생성하는 함수 (age, city는 키워드 인자로만 전달 가능)"""
    print(f"이름: {name}, 나이: {age}, 도시: {city}")

create_user("Alice", age=30, city="New York") # 키워드 인자로 호출
# create_user("Bob", 25, "Seoul") # TypeError: create_user() takes 1 positional argument but 3 were given
```

### 2.5 가변 인자 리스트 (`*args`)

`*args`는 함수에 개수가 정해지지 않은 위치 인자들을 튜플 형태로 받을 때 사용합니다. `args`는 관례적인 이름이며, 다른 이름을 사용해도 됩니다.

```python
def sum_all(*numbers):
    """전달된 모든 숫자의 합을 반환하는 함수"""
    total = 0
    for num in numbers:
        total += num
    return total

print(f"합계: {sum_all(1, 2, 3)}") # 6
print(f"합계: {sum_all(10, 20, 30, 40)}") # 100
```

### 2.6 가변 키워드 인자 (`**kwargs`)

`**kwargs`는 함수에 개수가 정해지지 않은 키워드 인자들을 딕셔너리 형태로 받을 때 사용합니다. `kwargs`는 관례적인 이름이며, 다른 이름을 사용해도 됩니다.

```python
def print_info(**details):
    """전달된 모든 키워드 인자를 출력하는 함수"""
    for key, value in details.items():
        print(f"{key}: {value}")

print_info(name="Harry", age=28, city="London")
print_info(product="Laptop", price=1200)
```

- **인자 전달 순서:** 함수 정의 시 매개변수는 `일반 매개변수 -> 위치 전용 인자 (/) -> 키워드 전용 인자 (*) -> *args -> **kwargs` 순서로 와야 합니다.

- **`*args`와 `**kwargs`의 조합:**
  `*args`와 `**kwargs`는 함께 사용하여 함수가 어떤 종류의 인자든 유연하게 받을 수 있도록 합니다. 이들을 함께 사용할 때는 항상 `*args`가 `**kwargs`보다 먼저 와야 합니다.
  ```python
  def complex_function(arg1, arg2, *args, kwarg1, **kwargs):
      print(f"arg1: {arg1}")
      print(f"arg2: {arg2}")
      print(f"args: {args}")
      print(f"kwarg1: {kwarg1}")
      print(f"kwargs: {kwargs}")

  complex_function(1, 2, 3, 4, kwarg1="hello", key1="value1", key2="value2")
  # Output:
  # arg1: 1
  # arg2: 2
  # args: (3, 4)
  # kwarg1: hello
  # kwargs: {'key1': 'value1', 'key2': 'value2'}
  ```

### 2.7 함수 인자 언패킹 (Argument Unpacking)

`*` (별표)와 `**` (이중 별표) 연산자는 함수 정의 시 가변 인자를 받는 용도 외에, 함수를 호출할 때 시퀀스(리스트, 튜플)나 딕셔너리의 요소들을 함수의 인자로 "언패킹"하여 전달하는 데 사용됩니다. 이는 코드를 더욱 유연하고 간결하게 만들어 줍니다.

-   **`*` (시퀀스 언패킹):** 리스트나 튜플과 같은 시퀀스의 요소들을 개별적인 위치 인자로 함수에 전달합니다.
    ```python
    def print_numbers(a, b, c):
        print(f"a: {a}, b: {b}, c: {c}")

    my_list = [1, 2, 3]
    print_numbers(*my_list) # 1, 2, 3이 각각 a, b, c에 할당됨

    my_tuple = (4, 5, 6)
    print_numbers(*my_tuple) # 4, 5, 6이 각각 a, b, c에 할당됨
    ```

-   **`**` (딕셔너리 언패킹):** 딕셔너리의 키-값 쌍을 개별적인 키워드 인자로 함수에 전달합니다. 딕셔너리의 키는 함수의 매개변수 이름과 일치해야 합니다.
    ```python
    def print_person_info(name, age, city):
        print(f"이름: {name}, 나이: {age}, 도시: {city}")

    person_data = {'name': 'Alice', 'age': 30, 'city': 'New York'}
    print_person_info(**person_data) # 딕셔너리의 키와 값이 매개변수에 할당됨

    # 함수에 정의되지 않은 키가 딕셔너리에 포함된 경우 TypeError 발생
    # extra_data = {'name': 'Bob', 'age': 25, 'country': 'Korea'}
    # print_person_info(**extra_data) # TypeError
    ```

**실무적 의미:**
-   **API 호출:** 외부 라이브러리나 프레임워크의 함수에 많은 인자를 전달해야 할 때, 인자들을 딕셔너리나 리스트로 구성한 후 언패킹하여 전달하면 코드가 훨씬 깔끔해집니다.
-   **함수 재사용성:** 다양한 형태의 데이터를 받는 함수를 만들 때 유용합니다.
-   **코드 가독성:** 특히 `**kwargs`와 함께 사용될 때, 함수가 어떤 키워드 인자들을 동적으로 처리하는지 명확하게 보여줄 수 있습니다.

### 2.8 함수 어노테이션 (타입 힌트)

파이썬 3.5부터 도입된 타입 힌트(Type Hinting)는 함수의 매개변수와 반환 값에 예상되는 타입을 명시할 수 있게 해줍니다. 이는 코드의 가독성을 높이고, 개발 도구(IDE)의 자동 완성 및 정적 분석(예: MyPy)을 통해 잠재적인 오류를 미리 발견하는 데 도움을 줍니다. 타입 힌트는 런타임에 코드의 동작에 영향을 주지 않으며, 주로 개발 시점에 코드의 의도를 명확히 하는 데 사용됩니다.

함수 어노테이션(타입 힌트)에 대한 자세한 내용은 [0514정리.md의 '1. 타입 힌트 (Type Hinting)'](../01_Python/0514정리.md#1-타입-힌트-type-hinting) 섹션을 참조하세요.

- **`typing.Union`과 `typing.Optional`:**
  - `Union[X, Y]`: 매개변수나 반환 값이 `X` 타입이거나 `Y` 타입일 수 있음을 나타냅니다. (예: `Union[str, int]`)
  - `Optional[X]`: 매개변수나 반환 값이 `X` 타입이거나 `None`일 수 있음을 나타냅니다. 이는 `Union[X, None]`의 축약형입니다. (예: `Optional[str]`)
  이러한 타입 힌트는 함수의 유연성을 표현하고, 코드의 의도를 더욱 명확하게 전달하는 데 도움을 줍니다.

- **장점:**
  - **가독성 향상:** 함수가 어떤 타입의 인자를 받고 어떤 타입의 값을 반환하는지 명확하게 알 수 있습니다.
  - **오류 예방:** 개발 단계에서 타입 관련 오류를 미리 감지하여 런타임 오류를 줄일 수 있습니다.
  - **IDE 지원 강화:** IDE가 더 정확한 코드 자동 완성, 리팩토링, 오류 검출 기능을 제공합니다.
  - **협업 용이성:** 팀 프로젝트에서 코드의 의도를 명확히 전달하여 다른 개발자들이 코드를 더 쉽게 이해하고 사용할 수 있도록 돕습니다.

타입 힌트는 특히 대규모 프로젝트나 라이브러리 개발 시 코드의 견고성과 품질을 높이는 데 필수적인 요소로 자리 잡고 있습니다.

## 3. 변수의 유효 범위 (Scope)

변수의 유효 범위(Scope)는 변수가 코드 내에서 접근 가능한 영역을 의미합니다. 파이썬은 LEGB 규칙(Local -> Enclosing function locals -> Global -> Built-in)을 따릅니다.

### 3.1 전역 변수(Global)와 지역 변수(Local)

- **지역 변수(Local Variable):** 함수 내부에서 정의된 변수로, 해당 함수 내에서만 유효합니다. 함수가 종료되면 소멸됩니다.
- **전역 변수(Global Variable):** 함수 외부에서 정의된 변수로, 프로그램 전체에서 접근 가능합니다.

```python
global_var = 100 # 전역 변수

def my_function():
    local_var = 50 # 지역 변수
    print(f"함수 내부 - 전역 변수: {global_var}")
    print(f"함수 내부 - 지역 변수: {local_var}")

my_function()

print(f"함수 외부 - 전역 변수: {global_var}")
# print(f"함수 외부 - 지역 변수: {local_var}") # NameError: name 'local_var' is not defined
```

### 3.2 `global` 키워드 사용법 (주의점 포함)

함수 내부에서 전역 변수의 값을 변경하려면 `global` 키워드를 사용해야 합니다. `global` 키워드 없이 전역 변수와 동일한 이름의 변수에 값을 할당하면, 해당 변수는 새로운 지역 변수로 간주됩니다.

```python
x = 10 # 전역 변수

def modify_global():
    global x # 전역 변수 x를 사용하겠다고 선언
    x = 20   # 전역 변수 x의 값을 변경
    print(f"함수 내부 (global 사용): {x}")

def create_local():
    x = 30   # 새로운 지역 변수 x 생성
    print(f"함수 내부 (local 생성): {x}")

print(f"함수 호출 전: {x}") # 10
modify_global()
print(f"modify_global() 호출 후: {x}") # 20
create_local()
print(f"create_local() 호출 후: {x}") # 20 (전역 변수 x는 변경되지 않음)
```

- **`global` 사용 주의:** `global` 키워드를 남용하면 코드의 가독성과 유지보수성이 떨어지고, 예상치 못한 부작용을 일으킬 수 있습니다. 가능한 한 함수는 매개변수를 통해 값을 받고 `return`을 통해 값을 반환하는 방식으로 설계하는 것이 좋습니다.

### 3.3 `nonlocal` 키워드 사용법

`nonlocal` 키워드는 중첩된 함수(nested function)에서 바깥쪽 함수의 지역 변수(enclosing scope)를 수정할 때 사용합니다. `global`이 전역 변수를 다루는 반면, `nonlocal`은 현재 함수보다 한 단계 바깥에 있는 함수 스코프의 변수를 다룹니다.

```python
def outer_function():
    message = "Hello" # 바깥쪽 함수의 지역 변수

    def inner_function():
        nonlocal message # 바깥쪽 함수의 message 변수를 사용하겠다고 선언
        message = "Hello, World!" # 바깥쪽 함수의 message 변경
        print(f"내부 함수에서 변경된 메시지: {message}")

    inner_function()
    print(f"외부 함수에서 확인된 메시지: {message}")

outer_function()
# Output:
# 내부 함수에서 변경된 메시지: Hello, World!
# 외부 함수에서 확인된 메시지: Hello, World!

# nonlocal 없이 중첩 함수에서 변수 할당 시
def outer_function_no_nonlocal():
    count = 0

    def inner_function_no_nonlocal():
        count = 1 # 새로운 지역 변수 count 생성 (바깥쪽 count와 다름)
        print(f"내부 함수 count: {count}")

    inner_function_no_nonlocal()
    print(f"외부 함수 count: {count}")

outer_function_no_nonlocal()
# Output:
# 내부 함수 count: 1
# 외부 함수 count: 0
```

- **활용:** 클로저(closure)나 데코레이터(decorator)와 같이 중첩 함수를 사용하는 고급 패턴에서 유용하게 사용됩니다.

- **클로저 (Closures):**
  클로저는 중첩된 함수가 자신의 외부(둘러싸는) 함수의 스코프에 있는 변수를 기억하고 접근할 수 있는 기능을 의미합니다. 외부 함수가 실행을 마친 후에도 내부 함수가 외부 함수의 변수에 접근할 수 있게 합니다. 이는 특정 상태를 유지하는 함수를 만들 때 매우 유용하며, 데코레이터나 콜백 함수 구현에 널리 활용됩니다.
  ```python
  def make_multiplier(x):
      def multiplier(n):
          return x * n # 외부 함수의 변수 x를 기억하고 사용
      return multiplier

  times3 = make_multiplier(3)
  times5 = make_multiplier(5)

  print(f"3에 10을 곱하면: {times3(10)}") # 30
  print(f"5에 10을 곱하면: {times5(10)}") # 50
  ```

## 4. 코드 문서화: 독스트링 (Docstrings, PEP 257)

**독스트링(Docstrings)**은 함수, 클래스, 모듈 등의 정의 바로 아래에 작성하는 문자열 리터럴로, 해당 코드 블록의 목적, 사용법, 매개변수, 반환 값 등을 설명합니다. PEP 257은 파이썬 독스트링에 대한 스타일 가이드라인을 제공합니다.

- 독스트링은 `"""` (세 개의 큰따옴표) 또는 `'''` (세 개의 작은따옴표)로 묶습니다.
- `help()` 함수나 IDE의 도움말 기능을 통해 독스트링을 확인할 수 있습니다.
- **독스트링 스타일 (PEP 257 권장):**
  - **한 줄 요약:** 첫 줄에 함수의 간략한 목적을 작성합니다.
  - **상세 설명:** 필요에 따라 추가적인 설명을 작성합니다.
  - **인자 (Args):** 각 매개변수의 이름, 타입, 설명을 명시합니다.
  - **반환 (Returns):** 반환 값의 타입과 설명을 명시합니다.
  - **예외 (Raises):** 발생할 수 있는 예외와 그 상황을 설명합니다.
  ```python
  def calculate_area(width: float, height: float) -> float:
      """사각형의 넓이를 계산하여 반환하는 함수.

      Args:
          width (float): 사각형의 가로 길이.
          height (float): 사각형의 세로 길이.

      Returns:
          float: 계산된 사각형의 넓이.

      Raises:
          ValueError: 가로 또는 세로 길이가 음수일 경우 발생.
      """
      if width < 0 or height < 0:
          raise ValueError("가로와 세로 길이는 음수가 될 수 없습니다.")
      return width * height
  ```
  - **다양한 독스트링 포맷:** PEP 257은 일반적인 가이드라인을 제공하며, NumPy 스타일, Google 스타일, Sphinx 스타일 등 다양한 독스트링 포맷이 존재합니다. 프로젝트나 팀의 컨벤션에 따라 선택하여 일관성 있게 사용하는 것이 중요합니다.

```python
def calculate_area(width: float, height: float) -> float:
    """사각형의 넓이를 계산하여 반환하는 함수.

    Args:
        width (float): 사각형의 가로 길이.
        height (float): 사각형의 세로 길이.

    Returns:
        float: 계산된 사각형의 넓이.

    Raises:
        ValueError: 가로 또는 세로 길이가 음수일 경우 발생.
    """
    if width < 0 or height < 0:
        raise ValueError("가로와 세로 길이는 음수가 될 수 없습니다.")
    return width * height

# 독스트링 확인
print(calculate_area.__doc__)
help(calculate_area)

# 함수 사용 예시
area = calculate_area(10, 5)
print(f"계산된 넓이: {area}")

try:
    calculate_area(-1, 5)
except ValueError as e:
    print(f"에러 발생: {e}")
```

- **중요성:** 독스트링은 코드의 가독성과 유지보수성을 크게 향상시킵니다. 다른 개발자(미래의 자신 포함)가 코드를 이해하고 사용하는 데 필수적인 정보를 제공합니다. 특히 라이브러리나 프레임워크 개발 시에는 독스트링 작성이 더욱 중요합니다. 독스트링과 함께 타입 힌팅 및 `mypy`와 같은 정적 타입 검사 도구를 활용하면 코드의 견고성과 명확성을 더욱 높일 수 있습니다.

## 5. 람다 표현식 (Lambda Expression)

**람다 표현식(Lambda Expression)**은 이름 없는(anonymous) 한 줄 함수를 생성하는 간결한 방법입니다. 주로 함수를 다른 함수의 인자로 전달하거나, 간단한 연산을 즉석에서 정의할 때 사용됩니다.

### 5.1 이름 없는 한 줄 함수

**기본 문법:** `lambda arguments: expression`

- `lambda`: 람다 함수를 정의하는 키워드.
- `arguments`: 함수가 받을 매개변수 (여러 개 가능).
- `expression`: 함수가 반환할 단일 표현식. (복잡한 로직이나 여러 줄의 코드는 `def` 함수를 사용해야 함)

```python
# 일반 함수
def add_normal(x, y):
    return x + y

# 람다 함수
add_lambda = lambda x, y: x + y

print(f"일반 함수 덧셈: {add_normal(2, 3)}")
print(f"람다 함수 덧셈: {add_lambda(2, 3)}")

# 람다 함수를 즉석에서 사용
print(f"즉석 람다: {(lambda x: x * x)(5)}")
```

### 5.2 `map`, `filter`와 함께 사용하기

`map()`과 `filter()` 함수는 람다 표현식과 함께 사용될 때 매우 강력합니다. 이들은 각각 시퀀스의 각 요소에 함수를 적용하거나, 특정 조건을 만족하는 요소만 필터링하는 데 사용됩니다.

- **`map(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용한 결과를 반환합니다.
- **`filter(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용하여 `True`를 반환하는 요소만 필터링하여 반환합니다.

```python
numbers = [1, 2, 3, 4, 5]

# map과 람다: 각 숫자를 제곱
squared_numbers = list(map(lambda x: x * x, numbers))
print(f"제곱된 숫자: {squared_numbers}") # [1, 4, 9, 16, 25]

# filter와 람다: 짝수만 필터링
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(f"짝수: {even_numbers}") # [2, 4]

# sorted 함수와 람다: 딕셔너리 리스트 정렬
students = [
    {'name': 'Alice', 'score': 85},
    {'name': 'Bob', 'score': 92},
    {'name': 'Charlie', 'score': 78}
]

# 점수를 기준으로 정렬
sorted_students = sorted(students, key=lambda student: student['score'], reverse=True)
print(f"점수 기준 정렬: {sorted_students}")
# Output: [{'name': 'Bob', 'score': 92}, {'name': 'Alice', 'score': 85}, {'name': 'Charlie', 'score': 78}]

# functools.reduce와 람다: 리스트의 모든 요소 합산
from functools import reduce
product_of_numbers = reduce(lambda x, y: x * y, numbers)
print(f"숫자들의 곱: {product_of_numbers}") # 1 * 2 * 3 * 4 * 5 = 120
```

- **활용 시점:** 람다 표현식은 코드를 간결하게 만들 수 있지만, 복잡한 로직에는 적합하지 않습니다. 간단한 콜백 함수나 일회성 함수가 필요한 경우에 사용하는 것이 좋습니다. 가독성을 해치지 않는 범위 내에서 활용해야 합니다.
