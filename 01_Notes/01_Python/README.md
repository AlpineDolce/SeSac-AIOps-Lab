# 파이썬 학습 가이드: 데이터 과학자를 위한 실무 중심 로드맵

이 가이드는 데이터 과학 및 AI 개발에 필수적인 파이썬의 기초부터 고급 주제까지 체계적으로 다룹니다. 각 문서는 신입 데이터 과학자가 현업에 빠르게 투입될 수 있도록 실무적 관점에서 심사숙고하여 분할 및 목차를 보충했습니다. 모든 내용은 누락 없이 포함되어 있습니다.
