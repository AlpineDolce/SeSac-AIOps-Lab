## 2. 이터레이터와 제너레이터 (Iterators & Generators)

파이썬에서 반복 가능한(iterable) 객체는 `for` 루프 등에서 순회될 수 있는 객체를 의미하며, 이터레이터(iterator)는 이러한 반복을 실제로 수행하는 객체입니다. 제너레이터(generator)는 이터레이터를 쉽게 생성할 수 있는 특별한 함수입니다.

### 2.1 `for` 루프의 동작 원리 (Iterables, Iterators)

`for` 루프는 내부적으로 다음과 같은 과정을 거쳐 동작합니다.

1.  `iter()` 함수를 호출하여 반복 가능한(iterable) 객체로부터 이터레이터(iterator) 객체를 얻습니다.
2.  이터레이터의 `next()` 메서드를 반복적으로 호출하여 다음 요소를 가져옵니다.
3.  더 이상 요소가 없으면 `StopIteration` 예외가 발생하고, `for` 루프는 종료됩니다.

```python
my_list = [1, 2, 3]
my_iterator = iter(my_list)

print(f"첫 번째 요소: {next(my_iterator)}") # 1
print(f"두 번째 요소: {next(my_iterator)}") # 2
print(f"세 번째 요소: {next(my_iterator)}") # 3
# print(next(my_iterator)) # StopIteration 발생

# 문자열도 iterable
my_string = "abc"
string_iterator = iter(my_string)
print(f"문자열 첫 요소: {next(string_iterator)}") # a
```

### 2.2 `yield` 키워드를 사용한 제너레이터 함수

제너레이터 함수는 일반 함수처럼 정의되지만, `return` 대신 `yield` 키워드를 사용하여 값을 반환합니다. `yield`는 함수를 일시 중지시키고 값을 반환한 다음, 다음에 호출될 때 중지된 지점부터 실행을 재개합니다. 이를 통해 메모리에 모든 값을 한꺼번에 생성하지 않고, 필요할 때마다 값을 생성하는 이터레이터를 만들 수 있습니다.

```python
def my_generator():
    print("첫 번째 yield")
    yield 1
    print("두 번째 yield")
    yield 2
    print("세 번째 yield")
    yield 3

# 제너레이터 객체 생성
gen = my_generator()

# next()를 통해 값 가져오기
print(f"next(gen): {next(gen)}")
print(f"next(gen): {next(gen)}")

# for 루프와 함께 사용
print("\nfor 루프 사용:")
for value in my_generator():
    print(value)
```

### 2.3 메모리 효율성 측면에서의 장점

- **지연 평가 (Lazy Evaluation):** 제너레이터는 모든 값을 미리 생성하여 메모리에 저장하지 않고, 요청이 있을 때마다 값을 하나씩 생성합니다. 이는 특히 대량의 데이터를 처리할 때 메모리 사용량을 크게 줄여줍니다.
- **무한 시퀀스 처리:** 제너레이터는 무한한 시퀀스를 표현할 수 있습니다. 예를 들어, 무한 피보나치 수열을 제너레이터로 구현할 수 있습니다.

```python
# 대량의 데이터 처리 예시
def large_list_processor(n):
    # 이 함수는 n개의 요소를 가진 리스트를 한꺼번에 생성하여 메모리에 로드합니다.
    # n이 매우 크면 메모리 문제가 발생할 수 있습니다.
    return [i * 2 for i in range(n)]

def large_generator_processor(n):
    # 이 제너레이터는 필요할 때마다 요소를 하나씩 생성하므로 메모리 효율적입니다.
    for i in range(n):
        yield i * 2

# 10억 개의 숫자를 처리한다고 가정
# data_list = large_list_processor(1_000_000_000) # 메모리 초과 가능성

data_generator = large_generator_processor(1_000_000_000) # 메모리 효율적

# 제너레이터는 필요한 만큼만 값을 생성
for _ in range(5):
    print(next(data_generator))
```

### 2.4 제너레이터 표현식 (Generator Expressions)

제너레이터 표현식은 리스트 컴프리헨션과 유사한 문법을 사용하여 제너레이터 객체를 생성하는 간결한 방법입니다. 소괄호 `()`를 사용하여 정의하며, 리스트 컴프리헨션과 달리 모든 요소를 메모리에 미리 생성하지 않고 필요할 때마다 값을 생성합니다.

**기본 문법:** `(expression for item in iterable if condition)`

```python
# 리스트 컴프리헨션 vs 제너레이터 표현식
list_comp = [x * x for x in range(1000000)] # 모든 요소를 메모리에 저장
gen_exp = (x * x for x in range(1000000)) # 필요할 때마다 요소 생성

print(f"리스트 컴프리헨션 타입: {type(list_comp)}") # <class 'list'>
print(f"제너레이터 표현식 타입: {type(gen_exp)}") # <class 'generator'>

# 제너레이터 표현식 사용 예시
sum_of_squares = sum(x*x for x in range(10))
print(f"0부터 9까지 제곱의 합: {sum_of_squares}") # 285

# 조건부 제너레이터 표현식
even_squares_gen = (x*x for x in range(10) if x % 2 == 0)
print(f"짝수의 제곱 제너레이터: {list(even_squares_gen)}") # [0, 4, 16, 36, 64]
```

- **장점:**
  - **메모리 효율성:** 대량의 데이터를 처리할 때 리스트 컴프리헨션보다 훨씬 적은 메모리를 사용합니다.
  - **간결성:** 간단한 제너레이터를 한 줄로 빠르게 정의할 수 있습니다.
  - **성능:** 모든 요소를 미리 생성하지 않으므로, 필요한 경우에만 계산하여 성능 이점을 얻을 수 있습니다.

제너레이터 표현식은 특히 `sum()`, `max()`, `min()`, `any()`, `all()` 등과 같이 이터레이터를 소비하는 함수와 함께 사용할 때 매우 효과적입니다.

## 3. 유용한 내장 함수 (Useful Built-in Functions)

파이썬은 다양한 작업을 수행하는 데 유용한 많은 내장 함수를 제공합니다. 이들은 코드를 간결하고 효율적으로 작성하는 데 도움을 줍니다.

### 3.1 `zip()`: 여러 시퀀스 묶기

`zip()` 함수는 여러 개의 반복 가능한(iterable) 객체들을 병렬로 묶어 튜플의 이터레이터를 반환합니다. 길이가 다른 시퀀스가 주어지면 가장 짧은 시퀀스에 맞춰 요소들을 묶습니다.

```python
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]
cities = ['New York', 'London']

# zip으로 묶기
zipped_data = zip(names, ages, cities)
print(f"zipped_data 타입: {type(zipped_data)}") # <class 'zip'> (이터레이터)

# zip 객체 순회
for name, age, city in zipped_data:
    print(f"이름: {name}, 나이: {age}, 도시: {city}")
# Output:
# 이름: Alice, 나이: 25, 도시: New York
# 이름: Bob, 나이: 30, 도시: London
# (Charlie, 35는 cities가 짧아서 포함되지 않음)

# zip 객체를 리스트로 변환
list_of_tuples = list(zip(names, ages))
print(f"리스트로 변환: {list_of_tuples}") # [('Alice', 25), ('Bob', 30), ('Charlie', 35)]
```

### 3.2 `enumerate()`: 인덱스와 값 함께 순회하기

`enumerate()` 함수는 반복 가능한(iterable) 객체를 순회할 때 인덱스와 값을 함께 반환하는 이터레이터를 생성합니다. 기본적으로 인덱스는 0부터 시작하지만, `start` 매개변수를 통해 시작 인덱스를 지정할 수 있습니다.

```python
fruits = ['apple', 'banana', 'cherry']

# 기본 사용법
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")
# Output:
# 0: apple
# 1: banana
# 2: cherry

# 시작 인덱스 지정
for index, fruit in enumerate(fruits, start=1):
    print(f"{index}. {fruit}")
# Output:
# 1. apple
# 2. banana
# 3. cherry
```

### 3.3 `len()`, `max()`, `min()`, `sum()`

이 함수들은 시퀀스나 반복 가능한 객체의 기본적인 통계 정보를 얻을 때 사용됩니다.

- **`len(iterable)`:** 객체의 길이(요소의 개수)를 반환합니다.
- **`max(iterable)`:** 반복 가능한 객체에서 가장 큰 요소를 반환합니다.
- **`min(iterable)`:** 반복 가능한 객체에서 가장 작은 요소를 반환합니다.
- **`sum(iterable, start=0)`:** 반복 가능한 객체의 모든 요소의 합을 반환합니다. `start`는 초기값입니다.

```python
numbers = [10, 20, 5, 30, 15]

print(f"길이: {len(numbers)}") # 5
print(f"최대값: {max(numbers)}") # 30
print(f"최소값: {min(numbers)}") # 5
print(f"합계: {sum(numbers)}") # 80
print(f"합계 (시작값 100): {sum(numbers, 100)}") # 180

# 문자열에도 적용 가능 (사전 순)
words = ['apple', 'zebra', 'banana']
print(f"가장 큰 단어: {max(words)}") # zebra
print(f"가장 작은 단어: {min(words)}") # apple
```

### 3.4 `all()`, `any()`

이 함수들은 반복 가능한 객체의 모든 요소 또는 일부 요소가 특정 조건을 만족하는지 확인할 때 사용됩니다.

- **`all(iterable)`:** `iterable`의 모든 요소가 참(True)이거나 `iterable`이 비어 있으면 `True`를 반환합니다.
- **`any(iterable)`:** `iterable`의 어떤 요소라도 참(True)이면 `True`를 반환합니다. `iterable`이 비어 있으면 `False`를 반환합니다.

```python
boolean_list1 = [True, True, False]
boolean_list2 = [True, True, True]
empty_list = []

print(f"all({boolean_list1}): {all(boolean_list1)}") # False
print(f"all({boolean_list2}): {all(boolean_list2)}") # True
print(f"all({empty_list}): {all(empty_list)}") # True (빈 iterable은 항상 True)

print(f"any({boolean_list1}): {any(boolean_list1)}") # True
print(f"any({boolean_list2}): {any(boolean_list2)}") # True
print(f"any({empty_list}): {any(empty_list)}") # False (빈 iterable은 항상 False)

# 조건식과 함께 사용
numbers = [1, 2, 3, 4, 5]
print(f"모든 숫자가 0보다 큰가? {all(x > 0 for x in numbers)}") # True
print(f"짝수가 하나라도 있는가? {any(x % 2 == 0 for x in numbers)}") # True
```

### 3.5 `map()`, `filter()`

이 함수들은 람다 표현식과 함께 사용될 때 매우 강력합니다. 이들은 각각 시퀀스의 각 요소에 함수를 적용하거나, 특정 조건을 만족하는 요소만 필터링하는 데 사용됩니다. (자세한 내용은 0430정리.md 참조)

- **`map(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용한 결과를 반환합니다.
- **`filter(function, iterable)`:** `iterable`의 각 요소에 `function`을 적용하여 `True`를 반환하는 요소만 필터링하여 반환합니다.

```python
numbers = [1, 2, 3, 4, 5]

# map: 각 숫자를 제곱
squared_numbers = list(map(lambda x: x * x, numbers))
print(f"제곱된 숫자: {squared_numbers}") # [1, 4, 9, 16, 25]

# filter: 짝수만 필터링
even_numbers = list(filter(lambda x: x % 2 == 0, numbers))
print(f"짝수: {even_numbers}") # [2, 4]
```

### 3.6 `sorted()`

`sorted()` 함수는 반복 가능한(iterable) 객체의 모든 요소를 정렬한 **새로운 정렬된 리스트**를 반환합니다. 원본 객체는 변경하지 않습니다. (자세한 내용은 0425정리.md 참조)

```python
unsorted_list = [3, 1, 4, 1, 5, 9, 2]

sorted_result = sorted(unsorted_list)
print(f"정렬된 리스트: {sorted_result}") # [1, 1, 2, 3, 4, 5, 9]
print(f"원본 리스트: {unsorted_list}") # [3, 1, 4, 1, 5, 9, 2] (변경되지 않음)

# 내림차순 정렬
sorted_desc = sorted(unsorted_list, reverse=True)
print(f"내림차순 정렬: {sorted_desc}") # [9, 5, 4, 3, 2, 1, 1]

# 사용자 정의 정렬 기준 (key 매개변수)
words = ['banana', 'apple', 'cherry']
sorted_by_length = sorted(words, key=len)
print(f"길이 기준 정렬: {sorted_by_length}") # ['apple', 'banana', 'cherry']
```
