## 1. 딕셔너리 (Dictionary)

딕셔너리는 **키(Key)**와 **값(Value)**의 쌍으로 이루어진 자료구조입니다. 순서가 없으며(Python 3.7+부터는 삽입 순서 유지), 키를 통해 값에 빠르게 접근할 수 있습니다. 중괄호 `{}`를 사용하여 생성하며, 각 키-값 쌍은 콜론 `:`으로 구분하고 쉼표 `,`로 연결합니다.

### 1.1 Key-Value 구조의 이해

- **키(Key):** 고유해야 하며, 불변(immutable) 객체만 키로 사용할 수 있습니다. (예: 숫자, 문자열, 튜플)
- **값(Value):** 어떤 타입의 객체든 될 수 있으며, 중복될 수 있습니다.

딕셔너리는 해시 테이블(Hash Table)로 구현되어 있어, 키를 통한 값 검색이 매우 빠릅.

### 1.1.1 딕셔너리 성능 고려사항

딕셔너리는 파이썬에서 가장 효율적인 자료구조 중 하나로, 키를 통한 값 접근, 추가, 삭제가 매우 빠릅니다. 이는 딕셔너리가 내부적으로 해시 테이블(Hash Table)로 구현되어 있기 때문입니다.

-   **평균 시간 복잡도:**
    -   **검색 (Lookup):** O(1) (평균)
    -   **삽입 (Insertion):** O(1) (평균)
    -   **삭제 (Deletion):** O(1) (평균)

-   **실무적 의미:**
    -   대량의 데이터에서 특정 값을 빠르게 찾거나, 고유한 키-값 쌍을 저장해야 할 때 딕셔너리는 최적의 선택입니다.
    -   데이터베이스의 인덱스와 유사하게, 딕셔너리의 키는 데이터에 빠르게 접근할 수 있는 "색인" 역할을 합니다.
    -   키가 해시 가능(hashable)해야 한다는 제약이 있습니다. 즉, 키는 불변(immutable) 객체여야 합니다 (숫자, 문자열, 튜플 등). 리스트나 다른 딕셔너리는 가변 객체이므로 딕셔너리의 키로 사용할 수 없습니다.
        ```python
        # 리스트를 딕셔너리 키로 사용 시도 (TypeError 발생)
        try:
            my_dict = {[1, 2]: 'value'}
        except TypeError as e:
            print(f"\nTypeError 발생: {e}")

        # 튜플은 불변이므로 딕셔너리 키로 사용 가능
        my_tuple_key_dict = {(1, 2): 'value'}
        print(f"튜플을 키로 사용: {my_tuple_key_dict}")
        ```

### 1.2 딕셔너리 생성, 접근, 수정, 삭제

```python
# 딕셔너리 생성
empty_dict = {}
person = {"name": "Alice", "age": 30, "city": "New York"}
student_scores = dict(math=90, science=85, english=92) # dict() 생성자 사용

print(f"person 딕셔너리: {person}")
print(f"student_scores 딕셔너리: {student_scores}")

# 값 접근 (키 사용)
print(f"Alice의 나이: {person['age']}")

# 값 수정
person['age'] = 31
print(f"수정된 Alice의 나이: {person['age']}")

# 새 키-값 쌍 추가
person['occupation'] = 'Engineer'
print(f"직업 추가 후: {person}")

# 값 삭제
del person['city']
print(f"도시 삭제 후: {person}")

# 존재하지 않는 키 접근 시 KeyError 발생
# print(person['country']) # KeyError
```

### 1.3 딕셔너리 주요 메서드

| 메서드 | 설명 | 예시 |
| :--- | :--- | :--- |
| `keys()` | 딕셔너리의 모든 키를 반환합니다. | `person.keys()` |
| `values()` | 딕셔너리의 모든 값을 반환합니다. | `person.values()` |
| `items()` | 딕셔너리의 모든 키-값 쌍을 튜플의 리스트 형태로 반환합니다. | `person.items()` |
| `get(key, default)` | `key`에 해당하는 값을 반환합니다. `key`가 없으면 `default` 값을 반환 (기본값 `None`). `KeyError` 방지. | `person.get('name')`, `person.get('country', 'Unknown')` |
| `setdefault(key, default_value)` | `key`가 딕셔너리에 있으면 해당 값을 반환하고, 없으면 `default_value`로 설정한 후 반환합니다. | `person.setdefault('email', 'default@example.com')` |
| `update(other_dict)` | 다른 딕셔너리의 키-값 쌍으로 현재 딕셔너리를 업데이트합니다. | `person.update({'age': 32, 'email': 'a@example.com'})` |
| `pop(key, default)` | `key`에 해당하는 값을 제거하고 반환합니다. `key`가 없으면 `KeyError` 또는 `default` 반환. | `person.pop('occupation')` |
| `clear()` | 딕셔너리의 모든 요소를 제거합니다. | `person.clear()` |

```python
my_dict = {'a': 1, 'b': 2, 'c': 3}

print(f"키 목록: {my_dict.keys()}")
print(f"값 목록: {my_dict.values()}")
print(f"아이템 목록: {my_dict.items()}")

print(f"'a'의 값: {my_dict.get('a')}")
print(f"'d'의 값 (기본값 없음): {my_dict.get('d')}")
print(f"'d'의 값 (기본값 0): {my_dict.get('d', 0)}")

my_dict.update({'b': 20, 'd': 4})
print(f"update 후: {my_dict}")

popped_value = my_dict.pop('c')
print(f"pop('c') 후: {my_dict}, 제거된 값: {popped_value}")

my_dict.clear()
print(f"clear() 후: {my_dict}")
```

### 1.4 딕셔너리 컴프리헨션 (Dictionary Comprehensions)

리스트 컴프리헨션과 유사하게, 딕셔너리 컴프리헨션은 간결하게 딕셔너리를 생성할 수 있는 방법입니다.

**기본 문법:** `{key_expression: value_expression for item in iterable if condition}`

```python
# 리스트에서 딕셔너리 생성
keys = ['a', 'b', 'c']
values = [1, 2, 3]
my_dict = {k: v for k, v in zip(keys, values)}
print(f"zip을 이용한 딕셔너리: {my_dict}")

# 조건부 딕셔너리 생성
squares_dict = {x: x**2 for x in range(5) if x % 2 == 0}
print(f"짝수의 제곱 딕셔너리: {squares_dict}") # {0: 0, 2: 4, 4: 16}

# 기존 딕셔너리 변환
original_dict = {'apple': 10, 'banana': 20, 'cherry': 30}
price_in_usd = {k: v / 1000 for k, v in original_dict.items()}
print(f"가격 변환 딕셔너리: {price_in_usd}")
```

### 1.5 고급 딕셔너리 활용 (collections 모듈)

파이썬의 `collections` 모듈은 딕셔너리를 포함한 다양한 자료구조를 더욱 효율적으로 다룰 수 있는 특수 컨테이너 타입을 제공합니다. 특히 `defaultdict`와 `Counter`는 실무에서 매우 유용하게 사용됩니다.

#### 1.5.1 `defaultdict`

`defaultdict`는 존재하지 않는 키에 접근할 때 `KeyError`를 발생시키는 대신, 기본값을 자동으로 생성하여 반환하는 딕셔너리 서브클래스입니다. 주로 값을 리스트로 묶거나, 카운트를 할 때 초기화 과정을 간소화할 수 있습니다.

```python
from collections import defaultdict

# 기본값이 리스트인 defaultdict
word_groups = defaultdict(list)
words = ['apple', 'banana', 'apricot', 'berry', 'cat']

for word in words:
    word_groups[word[0]].append(word) # 첫 글자를 키로 사용하여 단어들을 그룹화

print(f"첫 글자별 단어 그룹: {word_groups}")
# Output: defaultdict(<class 'list'>, {'a': ['apple', 'apricot'], 'b': ['banana', 'berry'], 'c': ['cat']})

# 기본값이 정수인 defaultdict (카운팅에 유용)
word_counts = defaultdict(int)
sentence = "hello world hello python"

for word in sentence.split():
    word_counts[word] += 1

print(f"단어별 카운트: {word_counts}")
# Output: defaultdict(<class 'int'>, {'hello': 2, 'world': 1, 'python': 1})
```

#### 1.5.2 `Counter`

`Counter`는 해시 가능한(hashable) 객체들의 개수를 세는 데 사용되는 딕셔너리 서브클래스입니다. 요소들을 딕셔너리 키로, 그 개수를 값으로 저장합니다. 주로 빈도수 계산에 활용됩니다.

```python
from collections import Counter

# 리스트 요소 카운트
my_list = ['apple', 'banana', 'apple', 'cherry', 'banana', 'apple']
counts = Counter(my_list)
print(f"리스트 요소 카운트: {counts}")
# Output: Counter({'apple': 3, 'banana': 2, 'cherry': 1})

# 문자열 문자 카운트
text = "programming"
char_counts = Counter(text)
print(f"문자열 문자 카운트: {char_counts}")
# Output: Counter({'r': 2, 'g': 2, 'p': 1, 'o': 1, 'a': 1, 'm': 1, 'i': 1, 'n': 1})

# 가장 흔한 요소 찾기
print(f"가장 흔한 2가지 요소: {counts.most_common(2)}")
# Output: [('apple', 3), ('banana', 2)]
```

`defaultdict`와 `Counter`는 특정 패턴의 딕셔너리 사용을 간소화하고 코드의 가독성을 높여주며, 성능상 이점도 제공할 수 있습니다. 실무에서 데이터 처리 시 매우 유용한 도구입니다.

#### 1.5.3 `namedtuple`

`namedtuple`은 튜플의 불변성과 딕셔너리의 키 접근성을 결합한 자료구조입니다. 각 요소에 이름을 부여하여 코드의 가독성을 높이고, 인덱스 대신 이름으로 요소에 접근할 수 있게 합니다. 이는 특히 데이터베이스 레코드, CSV 파일의 행 등 구조화된 데이터를 다룰 때 유용합니다.

```python
from collections import namedtuple

# Point라는 이름의 namedtuple 정의 (x, y 필드 가짐)
Point = namedtuple('Point', ['x', 'y'])

# Point 객체 생성
p1 = Point(10, 20)
print(f"Point 객체: {p1}")
print(f"x 좌표: {p1.x}, y 좌표: {p1.y}") # 이름으로 접근
print(f"x 좌표 (인덱스): {p1[0]}") # 인덱스로도 접근 가능

# 불변성 확인
# p1.x = 30 # AttributeError: 'Point' object has no attribute 'x'

# 딕셔너리에서 namedtuple 생성
data = {'name': 'Alice', 'age': 30}
Person = namedtuple('Person', data.keys())
p2 = Person(**data)
print(f"Person 객체: {p2}")
```

#### 1.5.4 `OrderedDict`

`OrderedDict`는 일반 딕셔너리와 유사하지만, 항목이 삽입된 순서를 기억하는 딕셔너리 서브클래스입니다. 파이썬 3.7부터 일반 딕셔너리도 삽입 순서를 유지하게 되었지만, 이전 버전과의 호환성이나 순서 유지가 명시적으로 필요할 때 여전히 유용하게 사용될 수 있습니다.

```python
from collections import OrderedDict

# OrderedDict 생성
ordered_dict = OrderedDict()
ordered_dict['apple'] = 1
ordered_dict['banana'] = 2
ordered_dict['cherry'] = 3

print(f"OrderedDict: {ordered_dict}")

# 일반 딕셔너리와의 순서 비교 (Python 3.7+에서는 일반 딕셔너리도 순서 유지)
regular_dict = {}
regular_dict['apple'] = 1
regular_dict['banana'] = 2
regular_dict['cherry'] = 3

print(f"Regular Dict: {regular_dict}")

# 순서가 중요한 작업에서 유용
# 예를 들어, API 응답에서 필드의 순서가 중요한 경우
```


## 2. 집합 (Set)

집합은 중복을 허용하지 않고, 순서가 없는(unordered) 요소들의 컬렉션입니다. 수학의 집합 개념과 유사하며, 주로 중복 제거, 멤버십 테스트, 집합 연산에 사용됩니다.

### 2.1 Set의 정의와 특징

- 중괄호 `{}`를 사용하여 생성하지만, 키-값 쌍이 아닌 단일 요소들로 구성됩니다.
- 중복된 요소는 자동으로 제거됩니다.
- 순서가 없으므로 인덱싱이나 슬라이싱을 지원하지 않습니다.
- 변경 가능한(mutable) 객체는 집합의 요소가 될 수 없습니다. (예: 리스트, 딕셔너리)

### 2.1.1 집합 성능 고려사항

집합(Set)은 딕셔너리와 유사하게 해시 테이블(Hash Table)로 구현되어 있어, 멤버십 테스트(요소 존재 여부 확인), 추가, 삭제 연산이 매우 효율적입니다.

-   **평균 시간 복잡도:**
    -   **멤버십 테스트 (`in`):** O(1) (평균)
    -   **삽입 (`add()`):** O(1) (평균)
    -   **삭제 (`remove()`, `discard()`):** O(1) (평균)

-   **실무적 의미:**
    -   대량의 데이터에서 중복을 제거하거나, 특정 요소가 컬렉션에 포함되어 있는지 빠르게 확인해야 할 때 집합은 최적의 선택입니다.
    -   두 컬렉션 간의 공통 요소, 차이점 등을 효율적으로 찾을 때 집합 연산(합집합, 교집합, 차집합 등)을 활용하면 매우 빠르고 간결하게 코드를 작성할 수 있습니다.
    -   집합의 요소는 해시 가능(hashable)해야 한다는 제약이 있습니다. 즉, 요소는 불변(immutable) 객체여야 합니다 (숫자, 문자열, 튜플 등). 리스트나 딕셔너리는 가변 객체이므로 집합의 요소가 될 수 없습니다.

### 2.2 집합 생성, 추가, 삭제

```python
# 집합 생성
empty_set = set() # 빈 집합은 set()으로 생성해야 함 ({}는 빈 딕셔너리)
my_set = {1, 2, 3, 2, 1} # 중복 제거됨
colors = {'red', 'green', 'blue'}

print(f"my_set: {my_set}") # {1, 2, 3}
print(f"colors: {colors}")

# 요소 추가
my_set.add(4)
my_set.add(1) # 이미 존재하므로 변화 없음
print(f"add(4) 후: {my_set}")

# 여러 요소 추가 (iterable)
my_set.update([5, 6, 1])
print(f"update([5, 6, 1]) 후: {my_set}")

# 요소 삭제
my_set.remove(3) # 없는 요소를 remove 시 KeyError
print(f"remove(3) 후: {my_set}")

my_set.discard(10) # 없는 요소를 discard 시 에러 없음
print(f"discard(10) 후: {my_set}")

popped_element = my_set.pop() # 임의의 요소 제거 및 반환
print(f"pop() 후: {my_set}, 제거된 요소: {popped_element}")

my_set.clear()
print(f"clear() 후: {my_set}")
```

### 2.3 집합 연산

수학의 집합 연산을 지원합니다.

| 연산 | 메서드 | 기호 | 설명 | 예시 |
| :--- | :--- | :--- | :--- | :--- |
| 합집합 | `union()` | `|` | 두 집합의 모든 요소를 포함하는 새 집합 | `A | B` |
| 교집합 | `intersection()` | `&` | 두 집합에 공통으로 존재하는 요소를 포함하는 새 집합 | `A & B` |
| 차집합 | `difference()` | `-` | 첫 번째 집합에는 있고 두 번째 집합에는 없는 요소를 포함하는 새 집합 | `A - B` |
| 대칭 차집합 | `symmetric_difference()` | `^` | 두 집합 중 한쪽에만 존재하는 요소를 포함하는 새 집합 | `A ^ B` |
| 부분집합 | `issubset()` | `<=` | 첫 번째 집합이 두 번째 집합의 부분집합이면 `True` | `A <= B` |
| 상위집합 | `issuperset()` | `>=` | 첫 번째 집합이 두 번째 집합의 상위집합이면 `True` | `A >= B` |
| 공통 요소 없음 | `isdisjoint()` | | 두 집합이 공통 요소를 하나도 가지지 않으면 `True` | `A.isdisjoint(B)` |

```python
set1 = {1, 2, 3, 4, 5}
set2 = {4, 5, 6, 7, 8}

print(f"합집합: {set1.union(set2)}") # {1, 2, 3, 4, 5, 6, 7, 8}
print(f"교집합: {set1.intersection(set2)}") # {4, 5}
print(f"차집합 (set1 - set2): {set1.difference(set2)}") # {1, 2, 3}
print(f"차집합 (set2 - set1): {set2.difference(set1)}") # {6, 7, 8}
print(f"대칭 차집합: {set1.symmetric_difference(set2)}") # {1, 2, 3, 6, 7, 8}

set_a = {1, 2}
set_b = {1, 2, 3}
print(f"set_a가 set_b의 부분집합인가? {set_a.issubset(set_b)}") # True
print(f"set_b가 set_a의 상위집합인가? {set_b.issuperset(set_a)}") # True
```

### 2.4 frozenset (불변 집합)

`frozenset`은 `set`과 동일한 기능을 제공하지만, 한 번 생성되면 요소를 추가하거나 삭제할 수 없는 **불변(immutable)** 집합입니다. `frozenset`은 딕셔너리의 키나 다른 집합의 요소로 사용될 수 있습니다.

```python
my_frozenset = frozenset([1, 2, 3])
print(f"frozenset: {my_frozenset}")

# my_frozenset.add(4) # AttributeError: 'frozenset' object has no attribute 'add'

# 딕셔너리의 키로 사용
dict_with_frozenset_key = {frozenset([1, 2]): 'value'}
print(f"frozenset을 키로 사용: {dict_with_frozenset_key}")
```

### 2.5 집합 컴프리헨션 (Set Comprehensions)

리스트 및 딕셔너리 컴프리헨션과 유사하게, 집합 컴프리헨션은 간결하게 집합을 생성할 수 있는 방법입니다. 중복된 요소는 자동으로 제거됩니다.

**기본 문법:** `{expression for item in iterable if condition}`

- `expression`: 각 `item`에 대해 수행할 연산.
- `item`: `iterable`에서 가져올 각 요소.
- `iterable`: 반복 가능한 객체 (리스트, 튜플, 문자열, range 등).
- `condition` (선택 사항): `item`을 포함할지 여부를 결정하는 조건.

```python
# 1. 간단한 집합 생성 (중복 제거 확인)
squares_set = {x**2 for x in [1, 2, 2, 3, 4, 4, 5]}
print(f"제곱 집합: {squares_set}") # {1, 4, 9, 16, 25}

# 2. 조건문을 포함한 집합 생성
even_numbers_set = {x for x in range(10) if x % 2 == 0}
print(f"짝수 집합: {even_numbers_set}") # {0, 2, 4, 6, 8}

# 3. 문자열에서 고유한 문자 추출
unique_chars = {char for char in "hello world" if char.isalpha()}
print(f"고유한 문자 집합: {unique_chars}") # {'h', 'e', 'l', 'o', ' ', 'w', 'r', 'd'} (순서 없음)
```

- **장점:**
  - **간결성:** 반복문과 조건문을 한 줄로 표현하여 코드가 짧아집니다.
  - **가독성:** 의도를 명확하게 전달하여 코드를 이해하기 쉽습니다.
  - **자동 중복 제거:** 집합의 특성상 중복된 요소는 자동으로 제거됩니다.

집합 컴프리헨션은 고유한 요소들을 빠르게 추출하거나, 특정 조건을 만족하는 요소들로 집합을 구성할 때 유용합니다.

## 3. 자료구조 선택 가이드

파이썬의 다양한 내장 자료구조는 각각의 특징과 장단점을 가지고 있습니다. 데이터를 효율적으로 저장하고 처리하기 위해서는 상황에 맞는 자료구조를 선택하는 것이 중요합니다.

| 자료구조 | 특징 | 주요 용도 | 예시 |
| :--- | :--- | :--- | :--- |
| **리스트 (List)** | 순서 O, 중복 O, 가변 | 순서가 중요하고 요소의 추가/삭제/수정이 빈번한 경우 | 학생 성적 목록, 할 일 목록 |
| **튜플 (Tuple)** | 순서 O, 중복 O, 불변 | 데이터가 변경되지 않아야 할 때, 함수의 여러 반환 값, 딕셔너리 키 | 좌표 (x, y), DB 레코드, 함수 반환값 |
| **딕셔너리 (Dictionary)** | 순서 O (Python 3.7+), 키는 고유, 가변 | 키를 통해 값에 빠르게 접근해야 할 때, 구조화된 데이터 표현 | 사용자 정보, 설정 파일, JSON 데이터 |
| **집합 (Set)** | 순서 X, 중복 X, 가변 | 중복 제거, 멤버십 테스트 (빠름), 수학적 집합 연산 | 고유 사용자 ID 목록, 태그 목록, 두 목록의 공통 요소 찾기 |
| **frozenset** | 순서 X, 중복 X, 불변 | 집합을 딕셔너리의 키나 다른 집합의 요소로 사용해야 할 때 | 캐싱 키, 변경 불가능한 집합 |

## 4. 실세계 데이터 표현하기

파이썬의 자료구조는 복잡한 실세계 데이터를 효과적으로 모델링하고 처리하는 데 매우 유용합니다.

### 4.1 테이블/엑셀 데이터를 리스트와 딕셔너리로 표현하기

테이블 형태의 데이터(예: CSV, 엑셀 파일)는 파이썬에서 **딕셔너리의 리스트** 형태로 표현하는 것이 일반적이고 효율적입니다. 각 딕셔너리는 테이블의 한 행(레코드)을 나타내고, 딕셔너리의 키는 열(컬럼) 이름을 나타냅니다.

```python
# 학생 데이터 (테이블 형태)
students_data = [
    {'id': 1, 'name': '김철수', 'major': '컴퓨터공학', 'grade': 3.8},
    {'id': 2, 'name': '이영희', 'major': '경영학', 'grade': 4.2},
    {'id': 3, 'name': '박민수', 'major': '전자공학', 'grade': 3.5}
]

print(f"모든 학생 데이터: {students_data}")

# 특정 학생 정보 접근
print(f"첫 번째 학생 이름: {students_data[0]['name']}")

# 모든 학생의 전공 출력
print("\n모든 학생의 전공:")
for student in students_data:
    print(student['major'])

# 새로운 학생 추가
students_data.append({'id': 4, 'name': '최유리', 'major': '디자인', 'grade': 3.9})
print(f"\n새 학생 추가 후: {students_data}")
```

이러한 구조는 데이터베이스의 테이블이나 JSON 형식의 데이터를 다룰 때 매우 자연스럽게 매핑됩니다.

### 4.2 JSON 데이터와 딕셔너리의 관계

**JSON (JavaScript Object Notation)**은 웹 애플리케이션에서 데이터를 교환할 때 널리 사용되는 경량 데이터 교환 형식입니다. 파이썬의 딕셔너리와 리스트는 JSON 데이터 구조와 거의 1:1로 매핑됩니다.

- **JSON 객체 `{}`**는 파이썬 **딕셔너리 `{}`**에 해당합니다.
- **JSON 배열 `[]`**은 파이썬 **리스트 `[]`**에 해당합니다.
- **JSON 문자열 `""`**, **숫자**, **불리언(`true`/`false`)**, **`null`**은 파이썬의 **문자열**, **숫자**, **불리언(`True`/`False`)**, **`None`**에 각각 해당합니다.

파이썬의 `json` 모듈을 사용하면 JSON 문자열과 파이썬 객체(딕셔너리, 리스트 등) 간의 변환을 쉽게 수행할 수 있습니다.

```python
import json

# 파이썬 딕셔너리
python_data = {
    'name': 'John Doe',
    'age': 30,
    'isStudent': False,
    'courses': [{'title': 'Math', 'credits': 3}, {'title': 'History', 'credits': 2}]
}

# 파이썬 딕셔너리를 JSON 문자열로 변환 (직렬화)
json_string = json.dumps(python_data, indent=4, ensure_ascii=False)
print("\n--- Python 딕셔너리 -> JSON 문자열 ---")
print(json_string)
print(f"타입: {type(json_string)}")

# JSON 문자열을 파이썬 딕셔너리로 변환 (역직렬화)
parsed_data = json.loads(json_string)
print("\n--- JSON 문자열 -> Python 딕셔너리 ---")
print(parsed_data)
print(f"타입: {type(parsed_data)}")

# 파싱된 데이터 접근
print(f"첫 번째 과목 제목: {parsed_data['courses'][0]['title']}")
```

이러한 매핑 덕분에 파이썬은 웹 서비스 개발이나 API 연동 시 JSON 데이터를 다루는 데 매우 강력한 도구가 됩니다.
