## 1. 객체 지향 프로그래밍 (OOP) 개요

객체 지향 프로그래밍(OOP)은 프로그램을 객체들의 집합으로 파악하고, 객체들 간의 상호작용을 통해 프로그램을 구성하는 프로그래밍 패러다임입니다. 현실 세계의 사물과 개념을 모델링하여 코드를 더 직관적이고 관리하기 쉽게 만듭니다.

### 1.1 OOP의 필요성

- **코드 재사용성:** 한 번 작성된 클래스를 여러 곳에서 재사용하여 개발 시간을 단축하고 코드 중복을 줄입니다.
- **유지보수 용이성:** 객체 단위로 코드가 모듈화되어 있어, 특정 기능 변경 시 해당 객체만 수정하면 되므로 유지보수가 쉽습니다.
- **확장성:** 새로운 기능을 추가할 때 기존 코드를 크게 변경하지 않고도 확장이 용이합니다.
- **생산성 향상:** 잘 설계된 객체는 개발자가 복잡한 시스템을 더 쉽게 이해하고 개발할 수 있도록 돕습니다.
- **현실 세계 모델링:** 현실 세계의 개념(객체)을 코드에 직접적으로 반영하여 문제 해결에 대한 직관적인 접근을 가능하게 합니다.

### 1.2 클래스(Class), 객체(Object), 인스턴스(Instance)의 관계

- **클래스 (Class):** 객체를 생성하기 위한 **설계도** 또는 **틀**입니다. 객체가 가져야 할 속성(데이터)과 행동(함수)을 정의합니다. (예: `자동차 설계도`)
- **객체 (Object):** 클래스에 의해 생성된 **실체**입니다. 클래스의 정의에 따라 메모리에 할당된 실체입니다. (예: `실제 자동차`)
- **인스턴스 (Instance):** 특정 클래스로부터 생성된 객체를 지칭할 때 사용되는 용어입니다. 객체는 인스턴스의 일반적인 용어이며, 인스턴스는 특정 클래스와의 관계를 강조할 때 사용됩니다. (예: `현대 아반떼`, `기아 K5`는 `자동차 설계도`의 인스턴스)

```python
# Class (설계도)
class Dog:
    pass

# Object / Instance (실체)
my_dog = Dog() # Dog 클래스의 인스턴스이자 객체
your_dog = Dog() # 또 다른 Dog 클래스의 인스턴스이자 객체

print(f"my_dog의 타입: {type(my_dog)}")
print(f"my_dog와 your_dog는 같은 객체인가? {my_dog is your_dog}") # False, 다른 메모리 주소
```

## 2. 클래스 정의 및 인스턴스 생성

파이썬에서 클래스는 `class` 키워드를 사용하여 정의합니다.

### 2.1 기본 클래스 구조

클래스 이름은 일반적으로 대문자로 시작하는 `CamelCase`를 사용합니다. 클래스 본문에는 속성과 메서드를 정의합니다.

```python
class Person:
    # 클래스 속성 (모든 인스턴스가 공유)
    species = "Human"

    # 메서드 (클래스 내부에 정의된 함수)
    def say_hello(self):
        print("안녕하세요!")

# 인스턴스 생성
p1 = Person()
p2 = Person()

# 클래스 속성 접근
print(f"p1의 종: {p1.species}")
print(f"p2의 종: {p2.species}")

# 메서드 호출
p1.say_hello()
p2.say_hello()
```

### 2.2 생성자 (`__init__`)

`__init__` 메서드는 클래스의 특별한 메서드(매직 메서드 또는 던더 메서드)로, 클래스의 인스턴스가 생성될 때 자동으로 호출됩니다. 주로 인스턴스의 초기 상태를 설정(인스턴스 변수 초기화)하는 데 사용됩니다.

- `self` 매개변수는 항상 첫 번째 매개변수로 지정해야 하며, 생성되는 인스턴스 자신을 가리킵니다.

```python
class Car:
    def __init__(self, brand, model, year):
        """Car 클래스의 생성자"""
        self.brand = brand    # 인스턴스 변수
        self.model = model
        self.year = year
        self.is_running = False

    def start_engine(self):
        self.is_running = True
        print(f"{self.brand} {self.model} 엔진이 시작되었습니다.")

    def stop_engine(self):
        self.is_running = False
        print(f"{self.brand} {self.model} 엔진이 정지되었습니다.")

# 인스턴스 생성 시 __init__ 호출
my_car = Car("Hyundai", "Sonata", 2020)
your_car = Car("Kia", "K5", 2022)

print(f"내 차: {my_car.brand} {my_car.model} ({my_car.year})")
print(f"네 차: {your_car.brand} {your_car.model} ({your_car.year})")

my_car.start_engine()
print(f"내 차 엔진 상태: {my_car.is_running}")
```

### 2.3 인스턴스 메서드와 `self`

- **인스턴스 메서드:** 클래스 내부에 정의된 함수로, 첫 번째 매개변수로 항상 `self`를 가집니다. `self`는 메서드가 호출될 때 해당 메서드를 호출한 인스턴스 자신을 자동으로 전달받습니다.
- `self`를 통해 인스턴스 변수에 접근하거나, 다른 인스턴스 메서드를 호출할 수 있습니다.

```python
class Student:
    def __init__(self, name, student_id):
        self.name = name
        self.student_id = student_id
        self.grades = []

    def add_grade(self, grade):
        """학생의 성적을 추가하는 메서드"""
        self.grades.append(grade)
        print(f"{self.name}의 성적 {grade}가 추가되었습니다.")

    def get_average_grade(self):
        """학생의 평균 성적을 계산하여 반환하는 메서드"""
        if not self.grades:
            return 0
        return sum(self.grades) / len(self.grades)

# 인스턴스 생성
s1 = Student("김철수", "2023001")

# 인스턴스 메서드 호출
s1.add_grade(90)
s1.add_grade(85)
s1.add_grade(95)

print(f"{s1.name}의 평균 성적: {s1.get_average_grade():.2f}")
```

### 2.4 클래스 메서드 (`@classmethod`)

클래스 메서드는 `@classmethod` 데코레이터를 사용하여 정의하며, 첫 번째 매개변수로 클래스 자체(`cls`)를 받습니다. 인스턴스가 아닌 클래스 전체에 관련된 작업을 수행할 때 사용됩니다. 주로 팩토리 메서드(Factory Method)로 활용되어 객체 생성 방식을 다양화하거나, 클래스 변수에 접근하고 수정할 때 사용됩니다.

```python
class MyClass:
    class_variable = 0

    def __init__(self, value):
        self.instance_variable = value

    @classmethod
    def increment_class_variable(cls):
        cls.class_variable += 1
        print(f"클래스 변수 증가: {cls.class_variable}")

    @classmethod
    def create_from_string(cls, data_string):
        """문자열로부터 MyClass 인스턴스를 생성하는 팩토리 메서드"""
        value = int(data_string.split('-')[1])
        return cls(value)

# 클래스 메서드 호출
MyClass.increment_class_variable() # 클래스를 통해 호출

obj1 = MyClass(10)
obj2 = MyClass.create_from_string("data-20") # 팩토리 메서드 사용

print(f"obj1 인스턴스 변수: {obj1.instance_variable}")
print(f"obj2 인스턴스 변수: {obj2.instance_variable}")
```

### 2.5 정적 메서드 (`@staticmethod`)

정적 메서드는 `@staticmethod` 데코레이터를 사용하여 정의하며, `self`나 `cls` 매개변수를 받지 않습니다. 클래스나 인스턴스의 상태에 접근하지 않고, 단순히 클래스 내부에 논리적으로 관련된 함수를 묶어둘 때 사용됩니다. 일반 함수와 유사하지만, 클래스 이름 공간에 속한다는 의미를 가집니다.

```python
class MathUtil:
    @staticmethod
    def add(x, y):
        """두 숫자를 더하는 정적 메서드"""
        return x + y

    @staticmethod
    def multiply(x, y):
        """두 숫자를 곱하는 정적 메서드"""
        return x * y

# 정적 메서드 호출 (클래스 또는 인스턴스를 통해 호출 가능)
print(f"덧셈: {MathUtil.add(5, 3)}")
print(f"곱셈: {MathUtil.multiply(4, 2)}")

# 인스턴스를 통해서도 호출 가능하지만, self나 cls에 접근하지 않음
util = MathUtil()
print(f"인스턴스를 통한 덧셈: {util.add(10, 20)}")
```

### 2.6 객체의 문자열 표현 (`__str__`, `__repr__`)

파이썬 객체를 문자열로 표현할 때 사용되는 특별한 메서드(매직 메서드)입니다. 디버깅 및 사용자 친화적인 출력을 위해 중요합니다.

- **`__str__(self)`:** 객체의 "비공식적인" 또는 "사용자 친화적인" 문자열 표현을 반환합니다. `print()` 함수나 `str()` 함수를 사용할 때 호출됩니다.
- **`__repr__(self)`:** 객체의 "공식적인" 또는 "개발자 친화적인" 문자열 표현을 반환합니다. 객체를 다시 생성할 수 있는 코드를 포함하는 것이 일반적입니다. `repr()` 함수나 인터랙티브 쉘에서 객체를 그냥 입력했을 때 호출됩니다. `__str__`이 정의되지 않으면 `__repr__`이 대신 사용됩니다.

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __str__(self):
        """사용자 친화적인 문자열 표현"""
        return f"Point({self.x}, {self.y})"

    def __repr__(self):
        """개발자 친화적인 문자열 표현 (객체 재현 가능)"""
        return f"Point(x={self.x}, y={self.y})"

p = Point(10, 20)

print(f"print(p): {p}") # __str__ 호출
print(f"str(p): {str(p)}") # __str__ 호출
print(f"repr(p): {repr(p)}") # __repr__ 호출

# 인터랙티브 쉘에서 객체 입력 시 __repr__ 호출
# p
# Output: Point(x=10, y=20)
```

### 2.7 `dataclasses` 모듈: 데이터 클래스 간결하게 만들기

파이썬 3.7부터 표준 라이브러리에 포함된 `dataclasses` 모듈은 주로 데이터를 저장하는 목적의 클래스(데이터 클래스)를 간결하게 작성할 수 있도록 도와줍니다. `__init__`, `__repr__`, `__eq__` 등과 같은 보일러플레이트(boilerplate) 코드를 자동으로 생성해주어 코드량을 줄이고 가독성을 높여줍니다.

- **주요 특징:**
  - `@dataclass` 데코레이터를 사용하여 클래스를 정의합니다.
  - 타입 힌트를 사용하여 필드를 선언합니다.
  - `__init__`, `__repr__`, `__eq__` 등의 메서드가 자동으로 생성됩니다.
  - `default_factory`를 사용하여 가변 기본값을 안전하게 설정할 수 있습니다.

```python
from dataclasses import dataclass, field
from typing import List

@dataclass
class Product:
    name: str
    price: float
    quantity: int = 0 # 기본값 설정
    tags: List[str] = field(default_factory=list) # 가변 기본값은 default_factory 사용

    def total_price(self) -> float:
        return self.price * self.quantity

# 인스턴스 생성
p1 = Product("Laptop", 1200.0, 2)
p2 = Product("Mouse", 25.0, tags=["computer", "accessory"])

print(p1) # __repr__ 자동 생성
print(p2)

print(f"{p1.name}의 총 가격: {p1.total_price()}원")

# 동등성 비교 (자동 생성된 __eq__)
print(f"p1 == Product('Laptop', 1200.0, 2): {p1 == Product('Laptop', 1200.0, 2)}")

# 가변 기본값 문제 방지
p3 = Product("Keyboard", 75.0)
p4 = Product("Monitor", 200.0)

p3.tags.append("input")
p4.tags.append("display")

print(f"p3 tags: {p3.tags}") # ['input']
print(f"p4 tags: {p4.tags}") # ['display'] (서로 독립적)
```

- **실무적 의미:**
  - 데이터 모델링이 필요한 경우(예: API 응답 데이터, 데이터베이스 레코드, 설정 객체 등) `dataclasses`를 사용하면 코드를 훨씬 간결하고 명확하게 작성할 수 있습니다.
  - 특히 `__init__` 메서드에서 단순히 필드를 초기화하는 작업이 반복될 때 `dataclasses`는 개발 생산성을 크게 향상시킵니다.
  - `default_factory`를 통해 리스트나 딕셔너리 같은 가변 객체를 기본값으로 사용할 때 발생할 수 있는 예상치 못한 부작용을 안전하게 방지할 수 있습니다.

## 3. 변수의 종류: 인스턴스 변수와 클래스 변수

클래스 내에서 변수를 정의하는 위치에 따라 인스턴스 변수와 클래스 변수로 나뉩니다. 이 둘은 유효 범위와 사용 목적이 다릅니다.

### 3.1 인스턴스 변수 (Instance Variables)

- **정의:** `__init__` 메서드 내에서 `self.변수명` 형태로 정의됩니다. 각 인스턴스마다 독립적인 값을 가집니다.
- **특징:** 인스턴스마다 고유한 데이터를 저장할 때 사용됩니다.

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name   # 인스턴스 변수
        self.breed = breed # 인스턴스 변수

dog1 = Dog("바둑이", "진돗개")
dog2 = Dog("초코", "푸들")

print(f"Dog1 이름: {dog1.name}, 품종: {dog1.breed}")
print(f"Dog2 이름: {dog2.name}, 품종: {dog2.breed}")

dog1.name = "메리"
print(f"Dog1 이름 변경 후: {dog1.name}") # dog1만 변경됨
print(f"Dog2 이름: {dog2.name}") # dog2는 변경되지 않음
```

### 3.2 클래스 변수 (Class Variables)

- **정의:** 클래스 정의 블록 내에서, 메서드 외부에 직접 정의됩니다. 모든 인스턴스가 공유하는 변수입니다.
- **특징:** 모든 인스턴스가 공통으로 가지는 속성이나, 클래스 전체에 대한 정보를 저장할 때 사용됩니다.

```python
class Car:
    # 클래스 변수: 모든 Car 인스턴스가 공유
    wheel_count = 4
    total_cars_created = 0

    def __init__(self, brand, model):
        self.brand = brand
        self.model = model
        Car.total_cars_created += 1 # 인스턴스 생성 시 클래스 변수 증가

my_car = Car("Tesla", "Model 3")
your_car = Car("BMW", "X5")

print(f"내 차 바퀴 수: {my_car.wheel_count}") # 인스턴스를 통해 접근
print(f"네 차 바퀴 수: {your_car.wheel_count}")
print(f"총 생성된 자동차 수 (클래스 통해 접근): {Car.total_cars_created}")

# 클래스 변수 변경 (클래스를 통해 변경해야 모든 인스턴스에 반영)
Car.wheel_count = 6
print(f"바퀴 수 변경 후 내 차 바퀴 수: {my_car.wheel_count}") # 6
```

### 3.3 두 변수의 차이점과 사용 사례

| 구분 | 인스턴스 변수 (Instance Variables) | 클래스 변수 (Class Variables) |
| :--- | :--- | :--- |
| **정의 위치** | `__init__` 메서드 내 `self.변수명` | 클래스 정의 블록 내, 메서드 외부 |
| **유효 범위** | 각 인스턴스에 독립적 | 모든 인스턴스가 공유 |
| **접근 방법** | `인스턴스.변수명` | `클래스명.변수명` 또는 `인스턴스.변수명` |
| **변경 시** | 해당 인스턴스에만 영향 | 모든 인스턴스에 영향 (클래스 통해 변경 시) |
| **주요 용도** | 인스턴스별 고유 데이터 (예: 이름, 나이, 모델) | 모든 인스턴스가 공유하는 공통 데이터 (예: 바퀴 수, 총 생성 개수, 상수) |

**사용 사례:**

- **인스턴스 변수:** 사용자 이름, 계좌 잔액, 특정 자동차의 색상, 학생의 성적 등 각 객체마다 달라지는 정보.
- **클래스 변수:** 모든 자동차가 가지는 바퀴의 개수, 특정 게임의 총 플레이어 수, 원주율(PI)과 같은 상수, 클래스 인스턴스의 총 개수 등 클래스 전체에 걸쳐 공유되거나 변하지 않는 정보.

**주의:** 인스턴스를 통해 클래스 변수를 변경하려고 하면, 해당 인스턴스에만 새로운 인스턴스 변수가 생성될 수 있으므로, 클래스 변수는 가급적 `클래스명.변수명` 형태로 접근하고 변경하는 것이 좋습니다.
