## 1. 조건문 (Conditional Statements)

조건문은 특정 조건이 참(True)일 때만 코드 블록을 실행하도록 하는 문법입니다. 프로그램의 흐름을 제어하는 가장 기본적인 방법입니다.

### 1.1 `if`, `elif`, `else`를 이용한 분기 처리

- **`if`**: 가장 기본적인 조건문으로, 조건이 참일 때 코드 블록을 실행합니다.
- **`elif` (else if)**: `if` 조건이 거짓일 때, 다음 조건을 검사합니다. 여러 개의 조건을 순차적으로 검사할 때 사용합니다.
- **`else`**: `if`와 모든 `elif` 조건이 거짓일 때 실행되는 코드 블록입니다. `else`는 선택 사항이며, 단 한 번만 사용할 수 있습니다.

```python
# if 문 예시
score = 85
if score >= 90:
    print("A 학점")

# if-else 문 예시
if score >= 60:
    print("합격")
else:
    print("불합격")

# if-elif-else 문 예시
score = 75
if score >= 90:
    print("A 학점")
elif score >= 80:
    print("B 학점")
elif score >= 70:
    print("C 학점")
elif score >= 60:
    print("D 학점")
else:
    print("F 학점")

# 조건에 여러 논리 연산자 사용
age = 25
has_license = True
if age >= 18 and has_license:
    print("운전 가능")
else:
    print("운전 불가능")
```

- **들여쓰기(Indentation) 중요:** 파이썬은 코드 블록을 들여쓰기로 구분합니다. 조건문 아래의 들여쓰기된 코드는 해당 조건이 참일 때만 실행됩니다. 들여쓰기가 잘못되면 `IndentationError`가 발생하거나 논리적 오류가 발생할 수 있습니다.
- **조건식의 불리언 변환:** 조건문은 불리언 값(`True` 또는 `False`)을 기대합니다. 파이썬에서는 모든 객체가 불리언 값으로 평가될 수 있습니다. 숫자 0, `None`, 빈 문자열(`""`), 빈 리스트(`[]`), 빈 딕셔너리(`{}`) 등은 `False`로 간주되며(Falsy), 그 외의 대부분의 값은 `True`로 간주됩니다(Truthy).

### 1.2 조건부 표현식 (Conditional Expression)

조건부 표현식은 한 줄로 `if-else` 로직을 표현할 수 있는 간결한 문법입니다. 주로 변수에 값을 할당하거나 함수에서 값을 반환할 때 사용됩니다.

**기본 문법:** `value_if_true if condition else value_if_false`

```python
# 일반적인 if-else 문
score = 65
if score >= 60:
    message = "합격"
else:
    message = "불합격"
print(f"결과: {message}")

# 조건부 표현식 사용
message = "합격" if score >= 60 else "불합격"
print(f"결과 (조건부 표현식): {message}")

# 예시: 짝수/홀수 판별
number = 7
parity = "짝수" if number % 2 == 0 else "홀수"
print(f"{number}은 {parity}입니다.")

# 예시: 두 수 중 큰 값 찾기
a, b = 10, 20
max_val = a if a > b else b
print(f"더 큰 값: {max_val}")
```

- **간결성:** 코드를 한 줄로 줄여 가독성을 높일 수 있습니다.
- **복잡성 주의:** 너무 복잡한 조건이나 여러 `elif`가 필요한 경우에는 일반적인 `if-elif-else` 문을 사용하는 것이 가독성에 더 좋습니다.

## 2. 반복문 (Loops)

반복문은 특정 코드 블록을 여러 번 반복하여 실행할 때 사용됩니다. 데이터 처리, 자동화 등 다양한 프로그래밍 작업에 필수적입니다.

### 2.1 `for` 루프: 시퀀스 순회

`for` 루프는 리스트, 튜플, 문자열, 딕셔너리, 집합 등 반복 가능한(iterable) 객체의 모든 요소를 순회하며 코드 블록을 실행합니다.

```python
# 리스트 순회
fruits = ['apple', 'banana', 'cherry']
for fruit in fruits:
    print(f"과일: {fruit}")

# 문자열 순회
for char in "Python":
    print(f"문자: {char}")

# 딕셔너리 순회 (기본적으로 키 순회)
person = {'name': 'Alice', 'age': 30}
for key in person:
    print(f"키: {key}, 값: {person[key]}")

# 딕셔너리 키와 값 동시에 순회
for key, value in person.items(): # items(), keys(), values()는 뷰(view) 객체를 반환합니다. 이 뷰 객체는 반복 가능하지만 인덱스로 직접 접근할 수는 없습니다.
    print(f"키: {key}, 값: {value}")

# 인덱스와 값 동시에 순회 (enumerate)
for index, fruit in enumerate(fruits):
    print(f"{index}: {fruit}")

# 여러 시퀀스 동시에 순회 (zip)
names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]
for name, age in zip(names, ages):
    print(f"이름: {name}, 나이: {age}")

# 역순 순회 (reversed)
for i in reversed(range(5)):
    print(i, end=' ') # 4 3 2 1 0
print()

# 정렬된 순서로 순회 (sorted)
unsorted_numbers = [3, 1, 4, 1, 5]
for num in sorted(unsorted_numbers):
    print(num, end=' ') # 1 1 3 4 5
print()
```

- **`enumerate()`:** 반복 시 인덱스와 값을 동시에 얻을 수 있어 매우 유용합니다.
- **`zip()`:** 여러 개의 반복 가능한 객체를 동시에 순회할 때 사용합니다.
- **제너레이터 표현식과의 연계:** 대량의 데이터를 처리할 때 리스트 컴프리헨션 대신 제너레이터 표현식(`(expression for item in iterable if condition)`)을 `for` 루프와 함께 사용하면 메모리 효율성을 크게 높일 수 있습니다. 이는 모든 요소를 메모리에 미리 생성하지 않고 필요할 때마다 값을 생성하기 때문입니다. 자세한 내용은 [0502정리.md의 '2.4 제너레이터 표현식 (Generator Expressions)'](../01_Python/0502정리.md#24-제너레이터-표현식-generator-expressions) 섹션을 참고하세요。

  **실무적 의미:** 대규모 데이터셋을 다룰 때, 리스트 컴프리헨션은 모든 결과를 메모리에 한꺼번에 로드하여 메모리 부족 문제를 일으킬 수 있습니다. 반면 제너레이터 표현식은 필요한 시점에 데이터를 하나씩 생성하므로, 메모리 사용량을 최소화하고 효율적인 데이터 스트리밍 처리가 가능합니다.

- **명시적 이터레이션 (고급):** `for` 루프는 내부적으로 `iter()`와 `next()` 함수를 사용하여 동작합니다. 이를 이해하면 파이썬의 반복 메커니즘을 더 깊이 이해할 수 있습니다.
  ```python
  my_list = [1, 2, 3]
  my_iterator = iter(my_list) # 이터레이터 객체 얻기

  print(next(my_iterator)) # 1
  print(next(my_iterator)) # 2
  print(next(my_iterator)) # 3
  # print(next(my_iterator)) # StopIteration 발생
  ```

### 2.2 `while` 루프: 조건 기반 반복

`while` 루프는 특정 조건이 참(True)인 동안 코드 블록을 반복하여 실행합니다. 조건이 거짓이 되면 반복이 종료됩니다.

```python
# 1부터 5까지 출력
count = 1
while count <= 5:
    print(count)
    count += 1

# 사용자 입력으로 반복 제어
password = ""
while password != "1234":
    password = input("비밀번호를 입력하세요: ")
    if password == "1234":
        print("로그인 성공!")
    else:
        print("비밀번호가 틀렸습니다.")
```

- **무한 루프 주의:** `while` 조건이 항상 참이 되도록 작성하면 무한 루프에 빠질 수 있습니다. 반복을 종료할 수 있는 조건(예: `count += 1`, `break` 문)을 반드시 포함해야 합니다.

### 2.3 `range()` 함수 활용

`range()` 함수는 숫자 시퀀스를 생성하는 데 사용됩니다. `for` 루프와 함께 특정 횟수만큼 반복하거나, 숫자 범위 내에서 순회할 때 주로 사용됩니다.

- `range(stop)`: 0부터 `stop-1`까지의 정수 시퀀스 생성.
- `range(start, stop)`: `start`부터 `stop-1`까지의 정수 시퀀스 생성.
- `range(start, stop, step)`: `start`부터 `stop-1`까지 `step`만큼 증가/감소하며 정수 시퀀스 생성.

```python
# 0부터 4까지 (5번 반복)
for i in range(5):
    print(i, end=' ')
print()

# 1부터 5까지
for i in range(1, 6):
    print(i, end=' ')
print()

# 0부터 10까지 2씩 증가
for i in range(0, 11, 2):
    print(i, end=' ')
print()

# 10부터 1까지 1씩 감소
for i in range(10, 0, -1):
    print(i, end=' ')
print()
```

- `range()`는 리스트를 직접 생성하는 것이 아니라, 필요할 때마다 숫자를 생성하는 `iterable` 객체이므로 메모리 효율적입니다. 특히 큰 숫자 범위를 다룰 때 유용합니다.

## 3. 반복 제어

반복문이 실행되는 도중에 특정 조건에 따라 반복의 흐름을 변경해야 할 때 `break`, `continue`, 그리고 `else` 절을 사용합니다.

### 3.1 `break`: 반복 중단

`break` 문은 현재 실행 중인 반복문(가장 가까운 `for` 또는 `while` 루프)을 즉시 종료하고, 반복문 다음의 코드를 실행합니다.

```python
# 1부터 10까지 출력하다가 5를 만나면 중단
for i in range(1, 11):
    if i == 5:
        print("5를 만났습니다. 반복 중단!")
        break
    print(i)

# 무한 루프에서 특정 조건 시 break
while True:
    user_input = input("종료하려면 'q'를 입력하세요: ")
    if user_input == 'q':
        print("반복을 종료합니다.")
        break
    print(f"입력: {user_input}")
```

### 3.2 `continue`: 현재 반복 건너뛰기

`continue` 문은 현재 반복의 나머지 부분을 건너뛰고, 다음 반복(iteration)을 즉시 시작합니다.

```python
# 1부터 10까지 홀수만 출력
for i in range(1, 11):
    if i % 2 == 0: # 짝수이면 건너뛰기
        continue
    print(i)

# 특정 단어만 건너뛰기
words = ['apple', 'skip', 'banana', 'skip', 'cherry']
for word in words:
    if word == 'skip':
        continue
    print(f"처리 중인 단어: {word}")
```

### 3.3 `else` 절을 갖는 반복문

`for` 루프와 `while` 루프는 선택적으로 `else` 절을 가질 수 있습니다. 이 `else` 절은 반복문이 `break` 문에 의해 종료되지 않고, 모든 반복을 정상적으로 완료했을 때 실행됩니다.

```python
# for-else 예시 (정상 종료)
for i in range(5):
    print(i)
else:
    print("모든 반복을 완료했습니다.")

# for-else 예시 (break로 종료)
for i in range(5):
    if i == 3:
        print("3을 만났습니다. 반복 중단!")
        break
    print(i)
else:
    print("이 메시지는 출력되지 않습니다.") # break로 인해 실행되지 않음

# while-else 예시 (정상 종료)
count = 0
while count < 3:
    print(count)
    count += 1
else:
    print("while 루프가 정상적으로 종료되었습니다.")

# while-else 예시 (break로 종료)
count = 0
while count < 5:
    if count == 3:
        print("3을 만났습니다. while 루프 중단!")
        break
    print(count)
    count += 1
else:
    print("이 메시지는 출력되지 않습니다.") # break로 인해 실행되지 않음
```

- **활용:** 주로 반복문 내에서 특정 요소를 찾거나, 어떤 조건이 충족되었는지 여부를 판단할 때 유용합니다. `break` 없이 루프가 완료되면 `else` 블록이 실행되므로, "모든 항목을 확인했지만 조건에 맞는 것을 찾지 못했다"와 같은 시나리오에 적합합니다.

## 4. 중첩 반복문 (Nested Loops)

중첩 반복문은 반복문 안에 또 다른 반복문이 있는 구조를 말합니다. 주로 2차원 이상의 데이터를 처리하거나, 모든 가능한 조합을 생성할 때 사용됩니다.

### 4.1 2차원 데이터 처리 및 활용 예제

```python
# 2차원 리스트 (행렬) 순회
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

print("\n행렬 출력:")
for row in matrix:
    for element in row:
        print(element, end=' ')
    print() # 다음 행을 위해 줄 바꿈

# 구구단 출력
print("\n구구단:")
for i in range(2, 10): # 2단부터 9단까지
    for j in range(1, 10): # 1부터 9까지 곱하기
        print(f"{i} x {j} = {i*j}")
    print("-" * 10) # 각 단 구분선

# 모든 조합 생성
colors = ['red', 'blue']
sizes = ['S', 'M', 'L']

print("\n모든 색상-사이즈 조합:")
for color in colors:
    for size in sizes:
        print(f"색상: {color}, 사이즈: {size}")
```

- **성능 고려:** 중첩 반복문은 반복 횟수가 많아질수록 실행 시간이 기하급수적으로 늘어날 수 있습니다. 따라서 성능에 민감한 작업에서는 중첩 반복문의 사용을 최소화하거나, 더 효율적인 알고리즘(예: 해시맵 사용)을 고려해야 합니다.
- **가독성:** 중첩 레벨이 깊어질수록 코드의 가독성이 떨어지므로, 2-3단계 이상의 중첩은 피하는 것이 좋습니다. 필요한 경우 함수로 분리하여 복잡도를 줄일 수 있습니다.

### 4.2 `itertools.product`를 이용한 조합 생성

`itertools` 모듈의 `product` 함수는 여러 이터러블(iterable)의 데카르트 곱(Cartesian product)을 생성하여, 중첩 반복문을 사용하는 대신 모든 가능한 조합을 간결하고 효율적으로 얻을 수 있게 해줍니다. 이는 특히 여러 조건의 조합을 테스트하거나, 모든 경우의 수를 탐색해야 할 때 유용합니다.

```python
from itertools import product

colors = ['red', 'blue']
sizes = ['S', 'M', 'L']

print("\nitertools.product를 이용한 모든 조합:")
for color, size in product(colors, sizes):
    print(f"색상: {color}, 사이즈: {size}")

# 여러 리스트의 조합
numbers = [1, 2]
letters = ['a', 'b']
combinations = list(product(numbers, letters, colors))
print(f"\n숫자, 문자, 색상의 모든 조합: {combinations}")

# 실무 예시: 하이퍼파라미터 그리드 서치
# 머신러닝 모델의 최적 하이퍼파라미터 조합을 찾을 때 유용합니다.
learning_rates = [0.01, 0.1, 0.5]
epochs = [10, 50, 100]
batch_sizes = [32, 64]

print("\n하이퍼파라미터 그리드 서치 조합:")
for lr, ep, bs in product(learning_rates, epochs, batch_sizes):
    print(f"Learning Rate: {lr}, Epochs: {ep}, Batch Size: {bs}")
```
- **대규모 탐색 공간에서의 고려사항:**
  하이퍼파라미터 그리드 서치는 모든 조합을 탐색하므로 탐색 공간이 커질수록 계산 비용이 기하급수적으로 증가합니다. 매우 큰 탐색 공간에서는 모든 조합을 시도하는 대신, **랜덤 서치(Random Search)**나 **베이지안 최적화(Bayesian Optimization)**와 같은 더 효율적인 탐색 전략을 사용하는 것이 일반적입니다. 이는 제한된 시간 내에 더 좋은 성능을 내는 하이퍼파라미터 조합을 찾을 가능성을 높여줍니다.


- **장점:**
  - **간결성:** 중첩 `for` 루프보다 코드가 훨씬 간결하고 가독성이 좋습니다.
  - **효율성:** `itertools` 모듈은 C로 구현되어 있어 파이썬 레벨의 루프보다 성능이 뛰어납니다.
  - **메모리 효율성:** 모든 조합을 미리 메모리에 생성하지 않고, 필요할 때마다 하나씩 생성하는 제너레이터(generator)를 반환하므로 대규모 데이터셋에서도 메모리 효율적입니다.
