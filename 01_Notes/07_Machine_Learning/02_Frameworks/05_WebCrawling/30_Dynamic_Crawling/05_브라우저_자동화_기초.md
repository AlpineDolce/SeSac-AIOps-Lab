## 1. 왜 브라우저 자동화가 필요한가?

`requests`와 `BeautifulSoup` 조합은 빠르고 효율적이지만, 결정적인 한계가 있습니다. **자바스크립트(JavaScript)를 실행할 수 없다**는 것입니다.

현대 웹사이트들은 페이지가 처음 로드된 후, 자바스크립트를 통해 동적으로 콘텐츠를 불러오는 경우가 많습니다. (e.g., 댓글 목록, 상품 더보기, 실시간 차트 등) `requests`는 자바스크립트가 실행되기 전의 뼈대 HTML만 가져오므로, 이런 동적 콘텐츠는 수집할 수 없습니다.

이 문제를 해결하기 위해, 실제 웹 브라우저를 코드로 직접 제어하여 자바스크립트가 모두 실행된 후의 최종 렌더링 결과를 가져오는 방법이 바로 **브라우저 자동화**입니다.

## 2. Selenium: 브라우저 자동화의 표준

Selenium은 코드를 통해 웹 브라우저의 모든 행동(클릭, 키보드 입력, 스크롤 등)을 제어할 수 있게 해주는 라이브러리입니다.

**설정:**
```bash
# 셀레니움 라이브러리 설치
pip install selenium
```
최신 버전의 Selenium(4.6 이상)은 `WebDriver`(브라우저와 코드를 연결하는 다리 역할)를 자동으로 관리해주므로 설정이 매우 간편해졌습니다.

**기본 코드:**
```python
from selenium import webdriver
import time

# Chrome 브라우저에 대한 WebDriver 객체 생성
driver = webdriver.Chrome()

# 특정 URL로 이동
driver.get("https://www.google.com")

# 페이지 제목 출력
print(f"페이지 제목: {driver.title}")

# 3초간 잠시 대기
time.sleep(3)

# 브라우저 종료 (관련 프로세스 모두 정리)
driver.quit()
```

## 3. 안정성 확보의 핵심: `time.sleep()` 대신 `WebDriverWait`

위 예제의 `time.sleep(3)`은 심각한 문제를 가집니다. 인터넷이 느려 3초 안에 원하는 요소가 로드되지 않으면 에러가 발생하고, 반대로 1초 만에 로드되면 불필요하게 2초를 낭비합니다. 이런 불안정성을 해결하는 전문적인 방법이 바로 **명시적 대기(Explicit Wait)**입니다.

`WebDriverWait`는 특정 **조건(Expected Condition)**이 만족될 때까지 정해진 시간(timeout) 동안만 기다립니다. 조건이 충족되면 즉시 다음 코드를 실행하므로, 네트워크 속도에 관계없이 안정적이고 효율적인 코드를 작성할 수 있습니다.

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

driver = webdriver.Chrome()
driver.get("https://shopping.naver.com/home")

try:
    # <input> 태그를 찾아서 '아이폰' 입력
    # By.CSS_SELECTOR, By.ID, By.NAME 등 다양한 방식으로 요소를 찾을 수 있음
    search_box = driver.find_element(By.CSS_SELECTOR, "input._searchInput_search_text_3CUDs")
    search_box.send_keys("아이폰")
    search_box.submit()

    # 최대 10초까지 기다리되, class가 'product_info_main__piyRs'인 첫 번째 요소가 나타나면(presence_of_element_located) 진행
    # 이 요소가 나타날 때까지 코드는 대기함
    element = WebDriverWait(driver, 10).until(
        EC.presence_of_element_located((By.CSS_SELECTOR, "div.product_info_main__piyRs"))
    )
    print("검색 결과 첫 번째 상품을 찾았습니다.")

finally:
    driver.quit()
```

## 4. Headless 모드: 눈에 보이지 않게 빠르게

Headless 모드는 브라우저의 UI 창을 화면에 띄우지 않고, 백그라운드에서만 실행하는 방식입니다. 

- **장점:** UI 렌더링에 필요한 리소스를 아껴 **더 빠르고 가볍게** 동작합니다. 그래픽 인터페이스가 없는 서버 환경(e.g., Linux 서버)에서 크롤러를 실행할 때 필수적입니다.

```python
from selenium import webdriver

# Chrome 옵션 설정
options = webdriver.ChromeOptions()
options.add_argument("--headless") # Headless 모드 활성화
options.add_argument("--disable-gpu") # 일부 시스템에서 안정성을 위해 필요

# 옵션을 적용하여 WebDriver 객체 생성
driver = webdriver.Chrome(options=options)

driver.get("https://www.naver.com")
print(f"(Headless) 페이지 제목: {driver.title}")
driver.quit()
```

## 5. 차세대 자동화 도구: Playwright

Playwright는 Microsoft에서 만든 최신 브라우저 자동화 도구로, Selenium의 대안으로 빠르게 부상하고 있습니다.

- **장점:**
    - **자동 대기(Auto-wait):** 대부분의 경우 명시적 대기를 작성할 필요 없이 Playwright가 알아서 요소를 기다려줍니다.
    - **더 나은 비동기 지원:** `asyncio`와 완벽하게 통합되어 더 현대적인 비동기 코드 작성이 가능합니다.
    - **간편한 설치:** `playwright install` 명령 한 번으로 모든 브라우저(Chromium, Firefox, WebKit)에 대한 설정을 끝냅니다.
