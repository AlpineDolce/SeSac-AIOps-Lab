# 실무 웹 크롤링 가이드: 기초부터 자동화까지

이 가이드는 파이썬을 이용한 웹 크롤링(웹 스크레이핑)의 핵심 기술을 다룹니다. `Requests`, `BeautifulSoup`을 사용한 기초적인 정적 페이지 수집부터 `Selenium`을 활용한 동적 페이지 처리, `Scrapy` 프레임워크를 이용한 대규모 수집까지 학습합니다. 

나아가, 수집한 데이터를 안정적으로 운영하기 위한 데이터베이스 저장, Docker를 이용한 배포, `cron`을 이용한 자동화 등 부수적인 실무 내용까지 체계적으로 안내합니다.

---

### Part 1: 웹 크롤링 개요 및 아키텍처
- **학습 목표:** 웹 크롤링의 전체 프로세스와 핵심 라이브러리 생태계를 이해하고, 프로젝트의 규모와 목적에 맞는 기술 아키텍처를 설계하는 능력을 갖춥니다.
- **왜 중요한가?** 올바른 도구와 설계 사상을 초기에 선택하는 것이 전체 프로젝트의 개발 속도와 확장성, 안정성을 결정하기 때문입니다.

-   [**01_웹_크롤링_핵심_라이브러리_소개.md**](./01_웹_크롤링_핵심_라이브러리_소개.md): `Requests`, `BeautifulSoup`, `Selenium`, `Scrapy`의 특징과 역할을 비교하고, 상황에 맞는 최적의 도구를 선택하는 가이드를 학습합니다.
-   [**02_웹_크롤링_아키텍처.md**](./02_웹_크롤링_아키텍처.md): **요청-파싱-저장의 기본 파이프라인**과 **Scrapy 프레임워크 기반의 확장 가능한 아키텍처**를 비교하며 설계 사상을 이해합니다.

### Part 2: 정적 페이지 크롤링 (Requests & BeautifulSoup)
- **학습 목표:** `Requests`와 `BeautifulSoup`을 사용해 정적 웹 페이지의 정보를 자유자재로 추출하고, 로그인과 같은 상태 유지 방법을 학습합니다.
- **왜 중요한가?** 웹에 존재하는 가장 많은 형태의 데이터를 수집하는 기본기를 다지는 과정이며, 모든 크롤링 기술의 기초가 됩니다.

-   [**03_HTTP_통신과_Requests.md**](./03_HTTP_통신과_Requests.md): HTTP 요청/응답과 `Session` 객체를 활용한 로그인 및 쿠키 관리 방법을 학습합니다.
-   [**04_HTML_파싱과_BeautifulSoup.md**](./04_HTML_파싱과_BeautifulSoup.md): CSS 선택자를 활용한 정교한 탐색 및 **데이터 정제(cleaning)** 기법을 익힙니다.

### Part 3: 동적 페이지 처리 (Selenium & Playwright)
- **학습 목표:** `Selenium`과 `Playwright`로 자바스크립트로 렌더링되는 동적 웹 페이지를 자동 제어하고, 복잡한 웹 환경에 대응하는 고급 기법을 익힙니다.
- **왜 중요한가?** 현대 웹의 대부분을 차지하는 동적 콘텐츠(댓글, 인피니티 스크롤 등)를 수집하기 위한 필수 기술입니다.

-   [**05_브라우저_자동화_기초.md**](./05_브라우저_자동화_기초.md): Selenium, Playwright의 개념, Headless 최적화 및 **명시적 대기(`WebDriverWait`)를 통한 안정성 확보** 전략을 학습합니다.
-   [**06_브라우저_자동화_고급.md**](./06_브라우저_자동화_고급.md): **iframe, 팝업 처리** 및 `NoSuchElementException` 등 **상황별 예외 처리**를 통해 견고성을 높입니다.

### Part 4: 크롤링 프레임워크 (Scrapy)
- **학습 목표:** `Scrapy`의 구조(Spider, Pipeline, Middleware)를 이해하고, 비동기 기반의 구조화된 고성능 크롤러를 구축합니다.
- **왜 중요한가?** 대규모 데이터를 주기적으로 수집해야 할 때, 직접 모든 것을 구현하는 것보다 훨씬 빠르고 안정적이며 확장성 있는 시스템을 만들 수 있습니다.

-   [**07_Scrapy_소개_및_스파이더.md**](./07_Scrapy_소개_및_스파이더.md): Scrapy의 구조를 이해하고 **Spider를 작성하여 데이터를 추출**하는 방법을 학습합니다.
-   [**08_Scrapy_아이템_파이프라인.md**](./08_Scrapy_아이템_파이프라인.md): **Item Pipeline을 이용해 데이터 유효성 검사, 정제, DB 저장 등 후처리 작업을 자동화**하는 방법을 익힙니다.
-   [**09_Scrapy_미들웨어_및_설정.md**](./09_Scrapy_미들웨어_및_설정.md): **Downloader Middleware**를 활용해 **Proxy, User-Agent를 동적으로 변경**하는 방법을 학습합니다.

### Part 5: 법적 이슈 및 안티-크롤링 우회
- **학습 목표:** 크롤링의 법적/윤리적 경계를 명확히 인지하고, 기술적인 차단(안티-크롤링)을 합법적인 범위 내에서 우회하는 전략을 배웁니다.
- **왜 중요한가?** 데이터 수집 활동으로 인한 법적 분쟁을 피하고, 까다로운 사이트로부터 안정적으로 데이터를 수집하기 위해 반드시 알아야 합니다.

-   [**10_크롤링_윤리와_법규.md**](./10_크롤링_윤리와_법규.md): `robots.txt`를 넘어 **이용약관(ToS), 저작권, 개인정보보호법**의 핵심을 분석하고 법적 리스크를 회피합니다.
-   [**11_안티_크롤링_우회_전략.md**](./11_안티_크롤링_우회_전략.md): **IP 로테이션(Proxy), 브라우저 핑거프린팅, CAPTCHA 처리** 등 고급 우회 기법의 원리와 적용을 다룹니다.

### Part 6: 데이터 수집 시스템 운영 (DevOps/MLOps)
- **학습 목표:** 개발된 크롤러를 서버에 배포하고, 자동화된 스케줄링 및 모니터링 체계를 구축하여 완전한 데이터 수집 시스템을 운영합니다.
- **왜 중요한가?** 일회성 스크립트를 넘어, '스스로 동작하고 문제가 생기면 알려주는' 자산으로 만드는 과정입니다. 데이터의 가치는 지속적인 수집과 축적에서 나옵니다.

-   [**12_데이터_파이프라인_및_품질.md**](./12_데이터_파이프라인_및_품질.md): 수집 데이터의 **스키마 정의 및 유효성 검사(`pydantic`)**와 후처리 과정을 자동화합니다.
-   [**13_배포_및_컨테이너화.md**](./13_배포_및_컨테이너화.md): **Docker를 이용해 크롤러를 컨테이너화**하여 어떤 환경에서든 동일하게 실행되도록 패키징합니다.
-   [**14_스케줄링_및_자동화.md**](./14_스케줄링_및_자동화.md): **`cron` 또는 `Airflow`와 같은 워크플로우 관리 도구**를 사용해 크롤러를 주기적으로 실행하는 방법을 학습합니다.
-   [**15_모니터링_및_로깅.md**](./15_모니터링_및_로깅.md): **`logging` 모듈과 모니터링 시스템을 연동**하여 크롤러의 실행 상태, 성공/실패 여부를 추적하고 **장애 발생 시 알림**을 받도록 구성합니다.

### Part 7: 실전 프로젝트
- **학습 목표:** 위에서 배운 모든 이론과 기술을 종합하여, 특정 웹사이트의 데이터를 주기적으로 수집하고 DB에 저장하는 완전한 시스템을 처음부터 끝까지 구축합니다.
- **왜 중요한가?** 지식을 실제 문제 해결에 적용하는 경험을 통해 체화하고, 자신만의 포트폴리오를 만드는 과정입니다.

-   [**16_종합_프로젝트.md**](./16_종합_프로젝트.md): 위에서 배운 모든 요소를 종합하여 **특정 웹사이트의 데이터를 주기적으로 수집하고 DB에 저장하는 완전한 시스템**을 구축합니다.
