## 1. 프로젝트 목표

지금까지 배운 모든 이론과 기술을 종합하여, **"quotes.toscrape.com 웹사이트의 모든 인용문을 주기적으로 수집하여 데이터베이스에 저장하는 완전 자동화된 데이터 수집 시스템"**을 구축합니다.

- **수집 대상:** [http://quotes.toscrape.com](http://quotes.toscrape.com)
- **수집 데이터:** 인용문(text), 저자(author), 태그(tags)
- **핵심 요건:**
    1.  모든 페이지를 순회하며 데이터 수집 (Pagination)
    2.  수집된 데이터의 유효성 검사 및 정제
    3.  데이터베이스(SQLite)에 중복 없이 저장
    4.  전체 프로세스를 Docker 컨테이너로 패키징
    5.  `cron`을 이용해 매일 특정 시간에 자동 실행 및 로깅

## 3. 구축 로드맵 (Step-by-Step)

#### **Step 1: 프로젝트 환경 설정**
1.  프로젝트 디렉토리 생성 및 `venv` 가상환경 활성화
2.  `pip install scrapy pydantic`
3.  `scrapy startproject my_quotes .` 명령으로 Scrapy 프로젝트 구조 생성

#### **Step 2: 아이템 및 스파이더 개발**
1.  `items.py`: `Pydantic`을 이용해 `QuoteItem` 스키마(text, author, tags 필드) 정의
2.  `spiders/`: `quotes_spider.py` 스파이더 생성
3.  `parse` 메서드: `response.css()`를 이용해 현재 페이지의 모든 인용문 정보를 추출하여 `QuoteItem` 객체로 `yield`
4.  **페이지네이션(Pagination) 구현:**
    -   페이지 하단의 "Next →" 버튼의 링크(`href` 속성)를 찾습니다.
    -   `response.follow(next_page_url, callback=self.parse)`를 `yield`하여, 다음 페이지에 대해서도 `parse` 메서드를 재귀적으로 호출하도록 구현합니다.

#### **Step 3: 파이프라인 구축**
1.  `pipelines.py`: 2개의 파이프라인 클래스 작성
    -   `PydanticValidationPipeline`: Pydantic 모델로 데이터 유효성 검사
    -   `SQLitePipeline`: 검증된 아이템을 SQLite DB에 저장. `CREATE TABLE IF NOT EXISTS`로 테이블을 생성하고, `INSERT OR IGNORE INTO` 구문으로 중복 데이터 입력을 방지합니다.
2.  `settings.py`: `ITEM_PIPELINES`에 작성한 파이프라인들을 순서에 맞게 등록하고 활성화합니다.

#### **Step 4: Dockerfile 작성**
1.  프로젝트 루트에 `Dockerfile` 생성
2.  `python:3.9-slim`을 베이스 이미지로 사용
3.  `requirements.txt`를 생성하고, `Dockerfile` 내에서 `pip install -r requirements.txt` 실행
4.  프로젝트 전체 코드를 컨테이너로 복사
5.  `CMD ["scrapy", "crawl", "quotes"]`로 기본 실행 명령어 설정

#### **Step 5: 로컬 테스트**
1.  `docker build -t quotes-crawler .` 명령으로 도커 이미지 빌드
2.  `docker run --rm -v $(pwd)/data:/app/data quotes-crawler` 명령으로 컨테이너 실행
3.  로컬의 `data` 폴더에 `quotes.db` 파일이 생성되고, 내부에 데이터가 잘 저장되었는지 확인합니다.

#### **Step 6: 서버 배포 및 스케줄링**
1.  Git을 이용해 서버에 프로젝트 코드를 배포하고, 서버에 Docker를 설치합니다.
2.  서버에서 `docker build` 명령으로 이미지를 빌드합니다.
3.  `crontab -e` 명령으로 아래와 같이 스케줄을 등록합니다.
    ```crontab
    # 매일 아침 6시에 크롤러를 실행하고, 로그는 /var/log/quotes_crawler.log에 저장
    0 6 * * * cd /home/user/my_quotes && docker run --rm -v $(pwd)/data:/app/data quotes-crawler >> /var/log/quotes_crawler.log 2>&1
    ```
