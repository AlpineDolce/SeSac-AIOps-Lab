## 1. 차원 축소란?

현대 데이터는 점점 더 많은 특성(feature)을 가지는 고차원(high-dimensional) 형태로 나타나고 있습니다. 이러한 고차원 데이터는 분석과 모델링에 여러 어려움을 초래하는데, 이를 해결하기 위한 핵심 기법이 바로 **차원 축소(Dimensionality Reduction)**입니다. 차원 축소는 데이터의 **특성(feature) 개수, 즉 차원을 줄이는** 과정입니다. 이 과정에서 데이터의 본질적인 정보는 최대한 유지하면서, 모델의 성능을 향상시키고, 데이터를 시각화하며, 저장 공간을 절약하는 등 다양한 이점을 얻을 수 있습니다.

### 1.1. 차원의 저주 (Curse of Dimensionality)

데이터의 차원(특성 수)이 증가할수록, 동일한 데이터 양으로는 공간을 충분히 채우기 어려워 데이터 포인트들이 서로 멀어지고 희소(sparse)해지는 현상을 '차원의 저주'라고 합니다. 이는 고차원 공간에서 데이터가 직관과 다르게 행동하면서 다음과 같은 심각한 문제를 야기합니다.

*   **데이터 희소성 증가:** 차원이 증가할수록 데이터 공간의 부피는 기하급수적으로 커지지만, 데이터 포인트의 수는 그대로이므로 데이터가 공간에 매우 드문드문 존재하게 됩니다. 이는 데이터가 '텅 빈' 공간에 흩어져 있는 것처럼 보이게 합니다.
*   **거리 개념의 무의미화:** 고차원 공간에서는 모든 데이터 포인트 간의 거리가 거의 비슷해지는 경향이 있습니다. 이는 K-최근접 이웃(KNN)이나 클러스터링(K-Means 등)과 같이 거리 기반 알고리즘의 성능을 저하시킵니다.
*   **과적합 증가:** 모델이 불필요한 노이즈까지 학습하여 과적합될 위험이 커집니다. 고차원에서는 훈련 데이터에 완벽하게 맞는 복잡한 모델을 만들 수 있지만, 새로운 데이터에 대한 일반화 성능은 떨어집니다.
*   **계산 비용 증가:** 차원이 높을수록 데이터를 저장하고 처리하며 모델을 학습하는 데 필요한 계산 복잡도와 시간이 기하급수적으로 증가합니다.
*   **시각화의 어려움:** 3차원 이상의 데이터를 시각화하기 어렵기 때문에 데이터의 패턴이나 구조를 직관적으로 파악하기 힘들어집니다.

차원 축소는 이러한 '차원의 저주' 문제를 해결하는 핵심적인 방법입니다.

### 1.2. 특성 선택 vs. 특성 추출
차원 축소는 크게 두 가지 접근 방식으로 나뉩니다. 두 방법 모두 데이터의 차원을 줄이는 것을 목표로 하지만, 그 방식과 결과에 차이가 있습니다.

*   **특성 선택 (Feature Selection):**
    *   **개념:** 기존 특성들 중에서 모델의 성능에 가장 중요하거나 관련성이 높은 특성들만 **선택(select)**하는 방식입니다. 원본 특성의 부분집합을 사용합니다.
    *   **장점:**
        *   선택된 특성들이 원본 특성이므로 **해석이 용이**합니다. 어떤 특성이 모델에 중요한 영향을 미치는지 직관적으로 파악할 수 있습니다.
        *   계산 비용이 상대적으로 낮을 수 있습니다.
    *   **단점:**
        *   원본 특성들의 조합을 통해 새로운 정보를 생성하지 못합니다.
        *   중요한 정보가 여러 특성에 분산되어 있을 경우, 개별 특성을 선택하는 것만으로는 충분한 정보를 얻지 못할 수 있습니다.
    *   **예시:**
        *   **필터 방법 (Filter Methods):** 특성과 타겟 변수 간의 통계적 관계(상관관계, 카이제곱 통계량 등)를 기반으로 특성을 선택합니다. (예: `SelectKBest`)
        *   **래퍼 방법 (Wrapper Methods):** 특정 머신러닝 모델을 사용하여 특성 부분집합의 성능을 평가하고 최적의 부분집합을 찾습니다. (예: `RFE` - Recursive Feature Elimination)
        *   **임베디드 방법 (Embedded Methods):** 모델 학습 과정 자체에 특성 선택이 포함됩니다. (예: 라쏘 회귀의 L1 규제, 트리 기반 모델의 특성 중요도)

*   **특성 추출 (Feature Extraction):**
    *   **개념:** 기존 특성들을 조합하여 정보를 가장 잘 함축하는 **새로운 특성(new features)**을 만들어내는 방식입니다. 원본 특성 공간을 새로운 저차원 공간으로 변환합니다.
    *   **장점:**
        *   원본 특성들의 선형 또는 비선형 조합을 통해 **정보 손실을 최소화**하면서 차원을 줄일 수 있습니다.
        *   데이터의 잠재적인 구조나 패턴을 발견할 수 있습니다.
    *   **단점:**
        *   새롭게 생성된 특성들은 원본 특성과 직접적인 관계가 없으므로 **해석이 어려울 수 있습니다.**
        *   계산 비용이 특성 선택보다 높을 수 있습니다.
    *   **예시:**
        *   **주성분 분석 (PCA):** 데이터의 분산을 가장 잘 보존하는 새로운 직교 특성을 생성합니다.
        *   **t-SNE:** 고차원 데이터의 지역적 유사성을 보존하는 저차원 임베딩을 생성합니다.
        *   **비음수 행렬 분해 (NMF):** 비음수 제약 조건을 가진 새로운 특성을 생성합니다.
        *   **매니폴드 학습 (Manifold Learning):** 데이터가 놓여 있는 비선형적인 저차원 매니폴드를 찾아 새로운 특성을 생성합니다. (예: Isomap, LLE)

이 문서에서 다루는 PCA, t-SNE, NMF, Isomap, LLE는 모두 **특성 추출** 기법에 해당합니다.

## 2. 주성분 분석 (Principal Component Analysis, PCA)

### 2.1. 핵심 원리
PCA는 가장 널리 사용되는 **선형 차원 축소** 기법입니다. 데이터의 **분산(variance)을 가장 잘 보존**하는 새로운 직교 좌표계(축)를 찾아 데이터를 투영합니다. 이 새로운 축을 **주성분(Principal Component)**이라고 하며, 첫 번째 주성분이 데이터의 분산을 가장 많이 설명하고, 두 번째 주성분은 첫 번째와 직교하면서 나머지 분산을 가장 많이 설명하는 식으로 생성됩니다.

**작동 원리:**
PCA는 데이터의 공분산 행렬(Covariance Matrix)을 기반으로 작동합니다. 공분산 행렬은 특성들 간의 관계와 분산 정도를 나타냅니다. PCA는 이 공분산 행렬의 **고유 벡터(Eigenvector)**와 **고유 값(Eigenvalue)**을 계산합니다.

*   **고유 벡터:** 데이터의 분산 방향을 나타냅니다. 이 고유 벡터들이 새로운 주성분 축이 됩니다.
*   **고유 값:** 각 고유 벡터(주성분)가 설명하는 데이터 분산의 크기를 나타냅니다. 고유 값이 클수록 해당 주성분이 데이터의 중요한 정보를 더 많이 담고 있다는 의미입니다.

PCA는 고유 값이 큰 순서대로 고유 벡터를 선택하여 새로운 저차원 공간의 축으로 사용합니다. 원본 데이터를 이 새로운 축에 투영함으로써 차원을 축소하게 됩니다. 이때, 데이터의 분산이 가장 큰 방향으로 축을 설정하므로, 정보 손실을 최소화하면서 차원을 줄일 수 있습니다.

**데이터 전처리:**
PCA는 분산에 민감하므로, 각 특성의 스케일이 다를 경우 분산이 큰 특성이 주성분 결정에 더 큰 영향을 미 미칠 수 있습니다. 따라서 PCA를 적용하기 전에 `StandardScaler` 등을 사용하여 데이터를 **스케일링(Scaling)**하는 것이 일반적입니다.

### 2.2. 최적의 주성분 개수 선택
PCA를 통해 몇 개의 주성분으로 차원을 축소할지는 중요한 결정입니다. 너무 적은 주성분을 선택하면 정보 손실이 커지고, 너무 많은 주성분을 선택하면 차원 축소의 이점이 줄어듭니다. 최적의 주성분 개수를 선택하는 방법은 다음과 같습니다.

*   **설명 분산 비율 (`explained_variance_ratio_`):**
    *   `explained_variance_ratio_` 속성은 각 주성분이 전체 데이터의 분산을 얼마나 설명하는지를 나타냅니다. 이 값들을 합하면 누적 설명 분산(Cumulative Explained Variance)을 얻을 수 있습니다.
    *   일반적으로 누적 설명 분산이 95% 또는 99% 이상이 되는 지점까지의 주성분 개수를 선택합니다. 이는 대부분의 정보 손실 없이 차원을 효과적으로 줄일 수 있는 지점입니다.

*   **스크리 플롯 (Scree Plot):**
    *   각 주성분의 설명 분산 비율을 그래프로 그린 것을 스크리 플롯이라고 합니다. 이 그래프에서 설명 분산이 급격하게 줄어들다가 완만해지는 '팔꿈치(elbow)' 지점을 찾아 해당 주성분 개수를 선택하는 방법입니다.

*   **모델 성능 기반 선택:**
    *   차원 축소된 데이터를 사용하여 지도 학습 모델을 학습시킨 후, 교차 검증을 통해 모델의 성능이 가장 좋은 주성분 개수를 선택하는 방법입니다. 이는 가장 실용적인 방법 중 하나입니다.

**예시:**
```python
from sklearn.decomposition import PCA
from sklearn.datasets import load_iris
import matplotlib.pyplot as plt
import numpy as np

iris = load_iris()
X = iris.data

pca = PCA()
pca.fit(X)

# 각 주성분의 설명 분산 비율
explained_variance_ratio = pca.explained_variance_ratio_
print(f"각 주성분의 설명 분산 비율: {explained_variance_ratio}")

# 누적 설명 분산
cum_explained_variance = np.cumsum(explained_variance_ratio)
print(f"누적 설명 분산: {cum_explained_variance}")

# 스크리 플롯 시각화
plt.figure(figsize=(8, 5))
plt.plot(range(1, len(explained_variance_ratio) + 1), explained_variance_ratio, marker='o', linestyle='--')
plt.plot(range(1, len(explained_variance_ratio) + 1), cum_explained_variance, marker='o', linestyle='-', color='red')
plt.title('PCA 설명 분산 비율')
plt.xlabel('주성분 개수')
plt.ylabel('설명 분산 비율 / 누적 설명 분산')
plt.xticks(range(1, len(explained_variance_ratio) + 1))
plt.grid(True)
plt.legend(['개별 설명 분산', '누적 설명 분산'])
plt.show()
```

### 2.3. 장단점 및 사용 시나리오
PCA는 강력한 차원 축소 기법이지만, 모든 상황에 적합한 것은 아닙니다. 다음과 같은 장단점을 고려하여 사용 여부를 결정해야 합니다.

*   **장점:**
    *   **간단하고 빠름:** 계산이 비교적 간단하고 효율적이어서 대규모 데이터셋에도 적용하기 용이합니다.
    *   **데이터 압축:** 데이터의 차원을 효과적으로 줄여 저장 공간을 절약하고, 학습 시간을 단축시킵니다.
    *   **노이즈 제거:** 주성분 분석 과정에서 데이터의 노이즈를 제거하는 효과가 있습니다.
    *   **다중공선성 해결:** 특성들 간의 높은 상관관계(다중공선성) 문제를 해결하는 데 도움을 줍니다.
    *   **시각화:** 2차원 또는 3차원으로 축소하여 고차원 데이터를 시각화하는 데 활용될 수 있습니다.

*   **단점:**
    *   **선형성 가정:** 데이터가 선형적인 관계를 가질 때 가장 효과적입니다. 데이터에 비선형적인 구조가 있다면 PCA는 이를 잘 보존하지 못할 수 있습니다.
    *   **해석의 어려움:** 새로운 주성분은 원본 특성들의 선형 조합이므로, 각 주성분이 어떤 의미를 가지는지 직관적으로 해석하기 어려울 수 있습니다.
    *   **정보 손실:** 차원을 축소하는 과정에서 필연적으로 정보 손실이 발생합니다. 중요한 정보가 낮은 분산을 가질 경우 손실될 수 있습니다.
    *   **스케일에 민감:** 각 특성의 스케일이 다를 경우, 분산이 큰 특성이 주성분 결정에 더 큰 영향을 미치므로, 사전에 데이터 스케일링이 필수적입니다.

*   **사용 시나리오:**
    *   **차원의 저주 완화:** 고차원 데이터로 인한 성능 저하, 과적합, 계산 비용 증가 문제를 해결할 때.
    *   **데이터 압축 및 저장 효율화:** 대규모 데이터셋의 저장 공간을 줄이고자 할 때.
    *   **시각화:** 고차원 데이터를 2D 또는 3D로 축소하여 데이터의 분포나 패턴을 시각적으로 탐색하고자 할 때.
    *   **전처리:** 머신러닝 모델의 입력으로 사용하기 전에 데이터의 차원을 줄여 모델의 성능을 향상시키고자 할 때.

## 3. t-SNE (t-Distributed Stochastic Neighbor Embedding)

### 3.1. 핵심 원리
t-SNE는 고차원 공간에 있는 데이터 포인트 간의 **지역적 유사성(local similarities)**을 저차원 공간(주로 2D 또는 3D)에 최대한 보존하는 **비선형 차원 축소** 기법입니다. 특히 고차원 데이터의 시각화에 매우 강력한 성능을 보입니다.

**작동 원리:**
t-SNE는 고차원 공간과 저차원 공간에서 데이터 포인트 간의 유사성을 확률 분포로 표현하고, 이 두 분포 간의 차이를 최소화하는 방식으로 작동합니다.

1.  **고차원 공간에서의 유사성 측정:**
    *   고차원 공간에서 각 데이터 포인트 $x_i$와 $x_j$ 사이의 유사성 $p_{ij}$를 가우시안 분포(Gaussian distribution)를 사용하여 측정합니다. 가까운 포인트들은 높은 유사성을 가집니다.
2.  **저차원 공간에서의 유사성 측정:**
    *   저차원 공간(임베딩 공간)에서 각 데이터 포인트 $y_i$와 $y_j$ 사이의 유사성 $q_{ij}$를 스튜던트 t-분포(Student's t-distribution)를 사용하여 측정합니다. t-분포는 긴 꼬리를 가지고 있어, 저차원 공간에서 멀리 떨어진 포인트들이 고차원 공간에서 멀리 떨어져 있는 관계를 더 잘 반영할 수 있도록 돕습니다.
3.  **두 분포 간의 차이 최소화:**
    *   고차원 공간의 유사성 분포 $P$와 저차원 공간의 유사성 분포 $Q$ 간의 차이를 쿨백-라이블러 발산(Kullback-Leibler Divergence, KL Divergence)을 사용하여 측정하고, 이 KL 발산을 최소화하는 방식으로 저차원 공간의 데이터 포인트 위치를 최적화합니다.

**주요 특징:**
*   **지역적 구조 보존:** t-SNE는 특히 가까운 이웃 간의 관계를 보존하는 데 탁월합니다. 이는 고차원 데이터에서 군집(cluster)을 시각적으로 명확하게 구분하는 데 매우 효과적입니다.
*   **비선형성:** 선형 변환으로는 파악하기 어려운 데이터의 비선형적인 구조를 잘 포착합니다.
*   **시각화에 특화:** 주로 2차원 또는 3차원으로 데이터를 축소하여 시각화하는 데 사용되며, 클러스터링 결과를 직관적으로 보여주는 데 강력합니다.

### 3.2. PCA vs. t-SNE
PCA와 t-SNE는 모두 차원 축소 기법이지만, 그 작동 원리와 목적, 그리고 결과 해석에 있어 중요한 차이점을 가집니다. 이 두 기법을 이해하고 적절히 활용하는 것이 고차원 데이터 분석에서 매우 중요합니다.

**주요 차이점:**

| 특징 | PCA (Principal Component Analysis) | t-SNE (t-Distributed Stochastic Neighbor Embedding) |
| :--- | :--- | :--- |
| **알고리즘 유형** | **선형** 차원 축소 | **비선형** 차원 축소 |
| **보존 목표** | 데이터의 **전역적인(global) 분산** 보존 | 데이터의 **지역적인(local) 유사성** 보존 |
| **주요 용도** | 차원 축소, 노이즈 제거, 데이터 압축, 전처리 | **고차원 데이터 시각화**, 군집 구조 발견 |
| **결과 해석** | 각 주성분은 원본 특성의 선형 조합으로 해석 가능 | 임베딩된 클러스터 간의 거리나 크기는 의미 없음 |
| **계산 비용** | 비교적 낮음 (선형 대수) | **매우 높음** (특히 대규모 데이터셋) |
| **재현성** | `random_state` 설정 시 항상 동일 | `random_state` 설정 시에도 실행마다 약간 다를 수 있음 (최적화 과정의 무작위성) |
| **새로운 데이터 처리** | `transform()` 메서드를 통해 새로운 데이터에 직접 적용 가능 | 새로운 데이터에 직접 적용하기 어려움 (훈련 데이터와 함께 재학습 필요) |

**언제 PCA를 사용하고, 언제 t-SNE를 사용할까?**

*   **PCA 사용 시점:**
    *   **차원 축소 및 전처리:** 모델 학습 전에 데이터의 차원을 줄여 계산 효율성을 높이고 과적합을 방지하고자 할 때.
    *   **노이즈 제거:** 데이터에 노이즈가 많을 때, PCA를 통해 주요 분산 방향을 추출하여 노이즈를 줄일 수 있습니다.
    *   **데이터 압축:** 저장 공간을 절약하거나 데이터 전송 효율을 높이고자 할 때.
    *   **선형 관계 파악:** 데이터의 전체적인 선형 구조나 가장 큰 분산 방향을 파악하고자 할 때.

*   **t-SNE 사용 시점:**
    *   **고차원 데이터 시각화:** 데이터에 숨겨진 군집 구조나 패턴을 2D 또는 3D 공간에서 직관적으로 확인하고자 할 때 가장 강력한 도구입니다.
    *   **탐색적 데이터 분석 (EDA):** 데이터의 복잡한 비선형 구조를 이해하고, 잠재적인 그룹을 발견하고자 할 때 유용합니다.

*   **주의사항:**
    *   t-SNE는 주로 **탐색적 데이터 시각화**에 사용됩니다. t-SNE로 변환된 데이터를 직접 머신러닝 모델 학습에 사용하는 것은 권장되지 않습니다. 이는 t-SNE가 데이터의 지역적 구조를 왜곡할 수 있고, 새로운 데이터에 대한 변환이 어렵기 때문입니다.
    *   t-SNE 결과에서 클러스터 간의 거리나 크기는 특별한 의미를 갖지 않을 수 있습니다. 즉, 두 클러스터가 t-SNE 플롯에서 멀리 떨어져 있다고 해서 고차원 공간에서도 반드시 멀리 떨어져 있다는 것을 의미하지는 않습니다. 오직 **군집의 존재 여부와 내부의 응집도**에 집중하여 해석해야 합니다.

### 3.3. 주요 하이퍼파라미터
t-SNE는 파라미터 설정에 매우 민감하며, 특히 `perplexity`와 `learning_rate`는 결과에 큰 영향을 미칩니다.

*   `n_components`:
    *   **설명:** 임베딩할 목표 차원 수입니다. 주로 2 또는 3으로 설정하여 시각화에 사용됩니다.

*   `perplexity`:
    *   **설명:** 각 데이터 포인트의 '이웃' 수를 나타내는 개념적인 파라미터입니다. 지역적 및 전역적 구조의 균형을 조절합니다. `perplexity` 값이 작으면 지역적 구조에 더 집중하고, 크면 전역적 구조를 더 고려합니다.
    *   **범위:** 일반적으로 5에서 50 사이의 값을 사용합니다. 데이터셋의 크기에 따라 적절한 값을 찾아야 합니다.
    *   **영향:** 너무 작으면 노이즈가 많고, 너무 크면 여러 클러스터가 하나로 합쳐질 수 있습니다.

*   `learning_rate` (또는 `eta`):
    *   **설명:** 최적화 과정의 학습률입니다. 임베딩된 포인트들이 얼마나 빠르게 움직일지를 결정합니다.
    *   **영향:** 너무 작으면 수렴이 느리고, 너무 크면 포인트들이 불안정하게 움직여 최적해를 찾지 못할 수 있습니다. `auto` (기본값) 또는 100에서 1000 사이의 값을 권장합니다.

*   `n_iter`:
    *   **설명:** 최적화 과정의 최대 반복 횟수입니다. 충분히 큰 값으로 설정하여 수렴할 시간을 주어야 합니다.

*   `init`:
    *   **설명:** 저차원 임베딩의 초기화 방법입니다. `'random'` (기본값) 또는 `'pca'`를 사용할 수 있습니다. `'pca'`로 초기화하면 더 안정적인 결과를 얻는 데 도움이 될 수 있습니다.

*   `random_state`:
    *   **설명:** 재현성을 위한 난수 시드입니다. t-SNE는 무작위성이 포함된 알고리즘이므로, 동일한 결과를 얻기 위해 `random_state`를 설정하는 것이 중요합니다.

**하이퍼파라미터 튜닝:**
t-SNE는 파라미터에 매우 민감하므로, 다양한 `perplexity`와 `learning_rate` 조합을 시도하여 최적의 시각화 결과를 찾는 것이 중요합니다. 일반적으로 `perplexity`를 먼저 튜닝하고, 그 다음 `learning_rate`를 조정합니다. 여러 번 실행하여 결과의 안정성을 확인하는 것도 좋습니다.

## 4. 비음수 행렬 분해 (Non-negative Matrix Factorization, NMF)
NMF는 모든 원소가 **음수가 아닌 행렬**을 두 개의 비음수 행렬의 곱으로 분해하는 차원 축소 기법입니다. 원본 데이터가 덧셈으로 구성된다고 가정할 수 있는 경우에 특히 유용합니다.

**핵심 원리:**
NMF는 주어진 비음수 행렬 $V$를 두 개의 비음수 행렬 $W$와 $H$의 곱으로 근사합니다.

$ V \approx WH $

여기서:
*   $V$: 원본 데이터 행렬 (예: 문서-단어 행렬, 이미지 픽셀 값).
*   $W$: 기저(basis) 행렬 또는 특성(feature) 행렬. 원본 데이터의 잠재적인 구성 요소(예: 토픽, 이미지의 부분)를 나타냅니다.
*   $H$: 계수(coefficient) 행렬 또는 가중치(weight) 행렬. 각 원본 데이터 샘플이 기저 구성 요소들의 조합으로 어떻게 표현되는지를 나타냅니다.

NMF의 핵심은 $W$와 $H$의 모든 원소가 음수가 아니어야 한다는 제약 조건입니다. 이 제약 조건 덕분에 NMF는 '부분 기반(part-based)' 표현을 학습하는 경향이 있습니다. 예를 들어, 얼굴 이미지 데이터에 NMF를 적용하면 눈, 코, 입과 같은 얼굴의 부분들을 기저 구성 요소로 추출할 수 있습니다.

**주요 활용 분야:**
*   **텍스트 마이닝 (토픽 모델링):** 문서-단어 행렬을 문서-토픽 행렬과 토픽-단어 행렬로 분해하여 문서의 잠재적인 토픽을 추출합니다. 각 토픽은 특정 단어들의 비음수 가중치 조합으로 표현됩니다.
*   **이미지 처리:** 여러 이미지를 부분 이미지들의 조합으로 표현합니다. 예를 들어, 얼굴 이미지를 눈, 코, 입과 같은 부분들의 조합으로 분해할 수 있습니다.
*   **추천 시스템:** 사용자-아이템 평점 행렬을 분해하여 잠재 요인을 찾고, 이를 기반으로 사용자에게 아이템을 추천합니다.

**장점:**
*   **해석 가능성:** 비음수 제약 조건 덕분에 추출된 특성(기저 벡터)이 원본 데이터의 '부분'을 나타내어 해석이 용이합니다.
*   **희소성:** 결과 행렬 $W$와 $H$가 희소성을 가질 수 있어, 모델이 더 간결해집니다.
*   **차원 축소:** 고차원 데이터를 저차원으로 효과적으로 축소합니다.

**단점:**
*   **비음수 데이터에만 적용 가능:** 원본 데이터가 음수 값을 포함하면 NMF를 직접 적용할 수 없습니다.
*   **계산 비용:** 대규모 데이터셋에서는 계산 비용이 높을 수 있습니다.
*   **초기화에 민감:** 초기값 설정에 따라 결과가 달라질 수 있습니다.

### 4.1. 주요 하이퍼파라미터
NMF의 주요 하이퍼파라미터는 다음과 같습니다.

*   `n_components`:
    *   **설명:** 축소할 차원의 수, 즉 추출할 잠재 구성 요소(토픽, 부분)의 개수를 지정합니다. 이 값은 $W$ 행렬의 열 수이자 $H$ 행렬의 행 수가 됩니다.

*   `init`:
    *   **설명:** $W$와 $H$ 행렬의 초기화 방법을 지정합니다. `'random'` (기본값), `'nndsvd'`, `'nndsvda'`, `'nndsvdar'` 등이 있습니다. `nndsvd` 계열은 더 나은 초기화를 제공하여 수렴 속도를 높이고 더 좋은 결과를 얻는 데 도움이 될 수 있습니다.

*   `solver`:
    *   **설명:** 최적화에 사용할 알고리즘을 지정합니다. `'cd'` (좌표 하강법, 기본값) 또는 `'mu'` (승법 업데이트)가 있습니다.

*   `beta_loss`:
    *   **설명:** 손실 함수를 지정합니다. `'frobenius'` (프로베니우스 노름, 기본값), `'kullback-leibler'`, `'itakura-saito'` 등이 있습니다.

*   `max_iter`:
    *   **설명:** 최적화 과정의 최대 반복 횟수입니다.

*   `random_state`:
    *   **설명:** 재현성을 위한 난수 시드입니다.

## 5. 다른 매니폴드 학습 기법 (Other Manifold Learning Techniques)
매니폴드 학습(Manifold Learning)은 고차원 데이터가 실제로는 더 낮은 차원의 비선형 매니폴드(manifold) 상에 존재한다고 가정하고, 이 매니폴드를 찾아 데이터를 저차원으로 임베딩하는 비선형 차원 축소 기법입니다.

### 5.1. Isomap
Isomap은 고차원 공간에서 데이터 포인트 간의 **측지 거리(Geodesic Distance)**를 보존하면서 저차원으로 임베딩하는 **비선형 차원 축소** 기법입니다. 측지 거리는 데이터가 놓여 있는 매니폴드를 따라 측정되는 실제 거리입니다.

**핵심 아이디어:**
1.  **이웃 그래프 구축:** 각 데이터 포인트에 대해 K-최근접 이웃(K-NN)을 찾아 그래프를 구축합니다. 이웃이 아닌 포인트 간에는 연결이 없습니다.
2.  **측지 거리 계산:** 그래프 상에서 모든 데이터 포인트 쌍 간의 최단 경로 거리를 계산합니다. 이 거리가 고차원 매니폴드 상의 측지 거리를 근사합니다.
3.  **MDS (Multi-dimensional Scaling) 적용:** 계산된 측지 거리를 사용하여 MDS 알고리즘을 적용하여 데이터를 저차원 공간에 임베딩합니다. MDS는 거리 행렬을 입력으로 받아 저차원 공간에 데이터를 배치하여 원본 거리 관계를 최대한 보존합니다.

**장점:**
*   **전역적인 구조 보존:** 데이터의 전역적인 비선형 구조를 잘 보존합니다. 이는 데이터의 큰 그림을 이해하는 데 유용합니다.
*   **비선형 구조 처리:** 복잡한 비선형 매니폴드에 놓인 데이터를 효과적으로 처리할 수 있습니다.

**단점:**
*   **계산 비용이 높음:** 특히 대규모 데이터셋에서는 이웃 그래프 구축 및 최단 경로 계산에 많은 시간이 소요됩니다.
*   **노이즈에 민감:** 이웃 그래프 구축 단계에서 노이즈나 이상치에 의해 측지 거리 계산이 왜곡될 수 있습니다.
*   **`n_neighbors` 파라미터에 민감:** 이웃의 개수 설정에 따라 결과가 크게 달라질 수 있습니다.

#### 5.1.1. 주요 하이퍼파라미터
*   `n_neighbors`:
    *   **설명:** 이웃 그래프를 구축할 때 각 데이터 포인트에 대해 고려할 이웃의 개수입니다. 이웃의 개수는 측지 거리 계산의 정확도에 영향을 미칩니다.
    *   **영향:** 너무 작으면 그래프가 끊어져 측지 거리를 정확히 계산하기 어렵고, 너무 크면 지역적 구조가 무시되어 유클리드 거리와 유사해질 수 있습니다.

*   `n_components`:
    *   **설명:** 임베딩할 목표 차원 수입니다. 주로 2 또는 3으로 설정하여 시각화에 사용됩니다.

*   `metric`:
    *   **설명:** 이웃을 찾을 때 사용할 거리 측정 방법입니다. `'euclidean'` (기본값), `'manhattan'` 등이 있습니다.

*   `path_method`:
    *   **설명:** 최단 경로를 찾을 때 사용할 알고리즘입니다. `'auto'` (기본값), `'FW'` (Floyd-Warshall), `'D'` (Dijkstra) 등이 있습니다.

### 5.2. LLE (Locally Linear Embedding)
LLE는 각 데이터 포인트가 그 이웃들의 선형 조합으로 표현될 수 있다는 가정을 기반으로 합니다. 이 선형 관계를 저차원 공간에서도 보존하도록 데이터를 임베딩합니다.

**핵심 아이디어:**
1.  **이웃 찾기:** 각 데이터 포인트 $x_i$에 대해 K-최근접 이웃을 찾습니다.
2.  **선형 재구성 가중치 계산:** 각 데이터 포인트 $x_i$를 그 이웃들의 선형 조합으로 재구성하는 가중치 $W_{ij}$를 계산합니다. 이 가중치는 고차원 공간에서 $x_i$와 이웃들 간의 지역적인 선형 관계를 나타냅니다.
3.  **저차원 임베딩:** 계산된 가중치 $W_{ij}$를 저차원 공간에서도 그대로 유지하면서, 데이터 포인트 $y_i$를 재구성 오차를 최소화하는 방식으로 임베딩합니다. 즉, 저차원 공간에서도 각 데이터 포인트가 그 이웃들의 동일한 선형 조합으로 표현되도록 합니다.

**장점:**
*   **복잡한 비선형 구조 처리:** 데이터의 복잡한 비선형 매니폴드 구조를 잘 처리할 수 있습니다.
*   **지역적 구조 보존:** 데이터의 지역적인 선형 관계를 효과적으로 보존합니다.

**단점:**
*   **계산 비용이 높음:** 특히 대규모 데이터셋에서는 계산 비용이 높습니다.
*   **`n_neighbors` 파라미터에 민감:** 이웃의 개수 설정에 따라 결과가 크게 달라질 수 있습니다.
*   **노이즈에 민감:** 노이즈가 많은 데이터에서는 지역적인 선형 관계를 정확히 파악하기 어려울 수 있습니다.

#### 5.2.1. 주요 하이퍼파라미터
*   `n_neighbors`:
    *   **설명:** 각 데이터 포인트에 대해 고려할 이웃의 개수입니다. LLE의 핵심 파라미터이며, 지역적인 선형 관계를 정의하는 데 사용됩니다.
    *   **영향:** 너무 작으면 지역적 구조를 제대로 파악하지 못하고, 너무 크면 비선형 구조를 선형으로 근사하여 정보 손실이 발생할 수 있습니다.

*   `n_components`:
    *   **설명:** 임베딩할 목표 차원 수입니다. 주로 2 또는 3으로 설정하여 시각화에 사용됩니다.

*   `reg`:
    *   **설명:** 재구성 가중치 계산 시 사용되는 정규화 파라미터입니다. 작은 값을 사용하면 가중치의 안정성을 높일 수 있습니다.

*   `eigen_solver`:
    *   **설명:** 고유값 문제를 풀 때 사용할 솔버를 지정합니다. `'auto'` (기본값), `'arpack'`, `'dense'` 등이 있습니다.

*   `random_state`:
    *   **설명:** 재현성을 위한 난수 시드입니다.

## 6. 실습: 손글씨 숫자 데이터 시각화
고차원 데이터인 손글씨 숫자(digits) 데이터를 PCA와 t-SNE, Isomap, LLE를 사용하여 2차원으로 축소하고 시각화하여 비교해봅니다. 이를 통해 각 알고리즘의 특징과 시각화 능력을 이해할 수 있습니다.

```python
import matplotlib.pyplot as plt # 시각화 라이브러리
from sklearn.datasets import load_digits # 손글씨 숫자 데이터셋 로드
from sklearn.preprocessing import StandardScaler # 데이터 스케일링
from sklearn.decomposition import PCA # 주성분 분석
from sklearn.manifold import TSNE, Isomap, LocallyLinearEmbedding # t-SNE, Isomap, LLE
import numpy as np # 수치 연산

# 1. 데이터 로드
# load_digits() 함수는 0부터 9까지의 손글씨 숫자 이미지 데이터셋을 로드합니다.
# 각 이미지는 8x8 픽셀로, 총 64개의 특성을 가집니다.
digits = load_digits()
X, y = digits.data, digits.target # X는 특성 데이터, y는 타겟 레이블 (숫자 0-9)

print(f"원본 데이터 형태 (X): {X.shape}") # (1797, 64) - 1797개의 샘플, 64개의 특성
print(f"타겟 레이블 형태 (y): {y.shape}") # (1797,)

# 2. 데이터 스케일링
# PCA와 같은 거리 기반 알고리즘은 특성 스케일에 민감하므로 스케일링이 필수적입니다.
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)

# 3. 각 차원 축소 알고리즘 적용
# 목표 차원 수는 2로 설정하여 2D 평면에 시각화합니다.

# PCA로 차원 축소
# n_components=2: 2개의 주성분으로 축소
pca = PCA(n_components=2, random_state=42)
X_pca = pca.fit_transform(X_scaled)

# t-SNE로 차원 축소
# n_components=2: 2차원으로 축소
# init='pca': PCA로 초기화하여 더 안정적인 결과를 얻습니다.
# learning_rate='auto': 학습률 자동 설정
# n_iter=500: 최적화 반복 횟수
tsne = TSNE(n_components=2, random_state=42, init='pca', learning_rate='auto', n_iter=500)
X_tsne = tsne.fit_transform(X_scaled)

# Isomap으로 차원 축소
# n_neighbors: 이웃 그래프를 구축할 때 사용할 이웃의 개수
isomap = Isomap(n_components=2, n_neighbors=10)
X_isomap = isomap.fit_transform(X_scaled)

# LLE로 차원 축소
# n_neighbors: 이웃의 개수
lle = LocallyLinearEmbedding(n_components=2, n_neighbors=10, random_state=42)
X_lle = lle.fit_transform(X_scaled)


# 4. 시각화
# 각 알고리즘의 결과를 서브플롯으로 시각화하여 비교합니다.
fig, axes = plt.subplots(2, 2, figsize=(14, 12))
axes = axes.flatten() # 2x2 배열을 1차원으로 평탄화하여 쉽게 접근

# PCA 결과 시각화
# 각 데이터 포인트는 해당 숫자의 색상으로 표시됩니다.
axes[0].scatter(X_pca[:, 0], X_pca[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[0].set_title('PCA of Digits Dataset')
axes[0].set_xlabel('Principal Component 1')
axes[0].set_ylabel('Principal Component 2')

# t-SNE 결과 시각화
axes[1].scatter(X_tsne[:, 0], X_tsne[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[1].set_title('t-SNE of Digits Dataset')
axes[1].set_xlabel('t-SNE feature 1')
axes[1].set_ylabel('t-SNE feature 2')

# Isomap 결과 시각화
axes[2].scatter(X_isomap[:, 0], X_isomap[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[2].set_title('Isomap of Digits Dataset')
axes[2].set_xlabel('Isomap feature 1')
axes[2].set_ylabel('Isomap feature 2')

# LLE 결과 시각화
axes[3].scatter(X_lle[:, 0], X_lle[:, 1], c=y, cmap='viridis', alpha=0.7)
axes[3].set_title('LLE of Digits Dataset')
axes[3].set_xlabel('LLE feature 1')
axes[3].set_ylabel('LLE feature 2')

plt.suptitle('Dimensionality Reduction for Visualization', y=1.02) # 전체 제목
plt.tight_layout() # 서브플롯 간 간격 자동 조절
plt.show()
```

**실습 결과 해석:**

손글씨 숫자 데이터셋은 64차원의 고차원 데이터입니다. 이를 2차원으로 축소하여 시각화한 결과를 통해 각 차원 축소 알고리즘의 특징을 명확히 확인할 수 있습니다.

*   **PCA (Principal Component Analysis):**
    *   PCA 결과는 숫자 클래스들이 어느 정도 분리되기는 하지만, t-SNE나 다른 매니폴드 학습 기법만큼 명확하게 군집을 형성하지는 못합니다.
    *   이는 PCA가 데이터의 전역적인 분산을 최대로 보존하는 데 중점을 두기 때문입니다. 즉, 데이터의 전체적인 구조는 잘 보여주지만, 지역적인 군집 구조를 명확히 구분하는 데는 한계가 있습니다.

*   **t-SNE (t-Distributed Stochastic Neighbor Embedding):**
    *   t-SNE 결과는 각 숫자 클래스(0부터 9)가 매우 명확하게 분리된 군집을 형성하는 것을 볼 수 있습니다. 같은 숫자끼리는 가깝게, 다른 숫자끼리는 멀리 떨어져 있습니다.
    *   이는 t-SNE가 고차원 공간에서의 지역적 유사성을 저차원 공간에서 최대한 보존하는 데 탁월하기 때문입니다. 따라서 군집 시각화에 매우 효과적입니다.
    *   하지만 t-SNE 플롯에서 클러스터 간의 거리나 크기는 의미가 없다는 점을 다시 한번 강조합니다. 오직 군집의 존재 여부와 내부의 응집도에 집중해야 합니다.

*   **Isomap:**
    *   Isomap 결과도 t-SNE만큼은 아니지만, PCA보다는 숫자 클래스들을 더 잘 분리하는 경향을 보입니다. 특히 비선형적인 구조를 가진 데이터에서 PCA보다 우수한 성능을 보일 수 있습니다.
    *   Isomap은 측지 거리를 보존하므로, 데이터의 전역적인 비선형 구조를 파악하는 데 유용합니다.

*   **LLE (Locally Linear Embedding):**
    *   LLE 결과 또한 숫자 클래스들이 어느 정도 군집을 형성하는 것을 보여줍니다. LLE는 지역적인 선형 관계를 보존하므로, 데이터의 비선형적인 매니폴드 구조를 잘 반영합니다.
    *   Isomap과 마찬가지로 비선형 구조를 가진 데이터 시각화에 활용될 수 있습니다.

**결론:**
이 실습을 통해 PCA는 전역적인 구조를, t-SNE는 지역적인 군집 구조를 시각화하는 데 강점이 있음을 확인할 수 있습니다. Isomap과 LLE와 같은 매니폴드 학습 기법들도 비선형 구조를 가진 고차원 데이터 시각화에 유용하게 사용될 수 있습니다. 데이터의 특성과 분석 목표에 따라 적절한 차원 축소 기법을 선택하는 것이 중요합니다.

## 7. 차원 축소 알고리즘 비교 요약

다양한 차원 축소 알고리즘들은 각각 고유한 특징과 장단점을 가지며, 데이터의 특성과 분석 목표에 따라 적절한 알고리즘을 선택하는 것이 중요합니다. 다음 표는 주요 차원 축소 알고리즘의 특징을 요약한 것입니다.

| 특징 | PCA | t-SNE | NMF | Isomap | LLE |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **알고리즘 유형** | 선형 | **비선형** | 선형 | **비선형** | **비선형** |
| **주요 목표** | 전역적 분산 보존 | **지역적 유사성 보존** | 부분들의 합으로 분해 | 측지 거리 보존 | 지역적 선형성 보존 |
| **주요 용도** | 특성 추출, 노이즈 제거 | **고차원 데이터 시각화** | 토픽 모델링, 추천 시스템 | 비선형 구조 시각화 | 비선형 구조 시각화 |
| **계산 비용** | 낮음 | **매우 높음** | 중간 | 높음 | 높음 |
| **데이터 제약** | 없음 | 없음 | **비음수 데이터만 가능** | 없음 | 없음 |
| **장점** | 빠르고 해석 용이 | 군집 시각화에 탁월 | 부분 기반 해석 | 전역적 구조 보존 | 비선형 구조 처리 |
| **단점** | 비선형 구조 파악 어려움 | 느리고 파라미터 민감 | 음수 데이터 불가 | 느리고 노이즈 민감 | 느리고 이웃 수 민감 |

**차원 축소 알고리즘 선택 가이드:**

*   **목표가 데이터 시각화라면:**
    *   **t-SNE**가 가장 강력한 도구입니다. 특히 데이터에 명확한 군집 구조가 있을 때 이를 2D/3D 공간에 잘 표현해 줍니다. 하지만 계산 비용이 높고, 파라미터(`perplexity`, `learning_rate`)에 민감하며, 클러스터 간의 거리나 크기는 의미가 없다는 점을 유의해야 합니다.
    *   **Isomap**이나 **LLE**도 비선형 구조를 가진 데이터 시각화에 유용할 수 있습니다. Isomap은 전역적인 구조를, LLE는 지역적인 선형 관계를 보존하는 데 강점이 있습니다.

*   **목표가 차원 축소 및 전처리라면:**
    *   **PCA**는 가장 먼저 고려해야 할 선형 차원 축소 기법입니다. 계산이 빠르고 구현이 간단하며, 데이터 압축, 노이즈 제거, 다중공선성 해결에 효과적입니다. 하지만 데이터가 비선형적인 구조를 가질 때는 한계가 있습니다.
    *   **NMF**는 데이터가 비음수이고, 부분 기반의 해석 가능한 특성을 추출하고자 할 때 유용합니다. 텍스트 마이닝이나 이미지 처리 분야에서 특히 강점을 보입니다.

*   **데이터의 특성:**
    *   **선형 구조:** PCA가 적합합니다.
    *   **비선형 구조:** t-SNE, Isomap, LLE와 같은 매니폴드 학습 기법을 고려해야 합니다.
    *   **비음수 데이터:** NMF를 고려할 수 있습니다.
    *   **대규모 데이터:** PCA, NMF는 비교적 빠르지만, t-SNE, Isomap, LLE는 계산 비용이 높으므로 샘플링이나 다른 방법을 고려해야 할 수 있습니다.

**결론:**
차원 축소는 '차원의 저주' 문제를 해결하고, 데이터의 본질적인 구조를 파악하며, 모델의 효율성과 성능을 향상시키는 데 필수적인 기법입니다. PCA, t-SNE, NMF, Isomap, LLE 등 다양한 알고리즘들은 각각의 장단점과 적용 분야를 가집니다. 데이터의 특성과 분석 목표를 명확히 이해하고, 각 알고리즘의 원리를 바탕으로 적절한 기법을 선택하며, 필요에 따라 여러 방법을 조합하여 사용하는 것이 중요합니다. 이 문서를 통해 차원 축소에 대한 깊이 있는 이해를 얻고, 실제 데이터 분석 및 머신러닝 프로젝트에서 이 강력한 도구들을 효과적으로 활용할 수 있기를 바랍니다.
