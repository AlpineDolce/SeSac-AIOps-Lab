# Scikit-learn 학습 가이드: 데이터 과학자를 위한 실무 중심 로드맵

이 가이드는 Scikit-learn 라이브러리의 핵심 이론과 개념을 총체적으로 정리한 자료입니다. 데이터 전처리, 지도 학습, 비지도 학습, 모델 선택 및 평가, 파이프라인 구축, 모델 영속성, 그리고 다른 파이썬 라이브러리와의 연동을 포함한 머신러닝 워크플로우 전반을 상세히 다룹니다. 본 문서를 통해 Scikit-learn에 대한 깊이 있는 이해를 돕고, 실제 ML 문제 해결에 효과적으로 적용하는 역량을 강화하는 데 도움이 되기를 바랍니다.

- **학습 목표:** Scikit-learn 라이브러리의 기본 개념과 머신러닝 워크플로우를 이해하고, 라이브러리 사용을 위한 환경 설정 및 주요 구성요소를 파악합니다.
- **왜 중요한가?** Scikit-learn은 파이썬 머신러닝의 핵심 도구로, 그 시작과 워크플로우를 이해하는 것은 효율적인 모델 개발과 문제 해결의 첫걸음입니다.

### Part 2: 데이터 준비 및 특성 공학 (Data Preparation & Feature Engineering)
- **학습 목표:** 머신러닝 모델 학습을 위한 데이터 전처리 및 특성 공학 기법들을 Scikit-learn을 활용하여 실습하고, 데이터의 품질을 높이는 방법을 학습합니다.
- **왜 중요한가?** "Garbage In, Garbage Out"이라는 말처럼, 데이터 준비와 특성 공학은 모델 성능에 결정적인 영향을 미칩니다. 올바른 전처리 없이는 아무리 좋은 모델도 제 성능을 발휘하기 어렵습니다.
-   [**16_결측치_처리.md**](./16_결측치_처리.md): `SimpleImputer`, `KNNImputer`를 이용한 결측치 처리 방법과 고급 결측치 처리(IterativeImputer) 및 이상치(Outlier) 처리 전략을 학습합니다.
-   [**17_데이터_스케일링_및_변환.md**](./17_데이터_스케일링_및_변환.md): `StandardScaler`, `MinMaxScaler`, `RobustScaler` 등 데이터 스케일링 기법과 로그, Box-Cox 변환을 학습합니다.
-   [**18_범주형_데이터_인코딩.md**](./18_범주형_데이터_인코딩.md): `LabelEncoder`와 `OneHotEncoder`를 이용한 범주형 데이터 인코딩 방법을 학습합니다.
-   [**19_특성_생성_및_선택.md**](./19_특성_생성_및_선택.md): `PolynomialFeatures`, 상호작용 특성 등 특성 생성 및 Filter, Wrapper, Embedded 기반의 특성 선택 방법을 학습합니다. 날짜/시간 특성 공학 및 기본적인 텍스트/이미지 특성 추출 기법을 소개합니다.
-   [**20_불균형_데이터_처리.md**](./20_불균형_데이터_처리.md): `class_weight` 파라미터와 `imbalanced-learn` 라이브러리를 활용한 불균형 데이터 처리 방법을 학습합니다.
-   [**21_파이프라인_기초.md**](./21_파이프라인_기초.md): 데이터 누수 방지와 재현성 확보를 위한 `Pipeline`의 개념과 기본 사용법을 학습합니다.

-   [**25_회귀_선형모델_및_규제.md**](./25_회귀_선형모델_및_규제.md): 선형 회귀, 릿지, 라쏘, 엘라스틱넷 등 규제가 있는 선형 모델을 학습합니다. `SVR` (Support Vector Regressor)를 소개합니다.

### Part 4: 비지도 학습 (Unsupervised Learning)
- **학습 목표:** Scikit-learn의 비지도 학습 알고리즘(클러스터링, 차원 축소, 이상 탐지)을 이해하고, 레이블이 없는 데이터에서 패턴을 발견하고 구조를 파악하는 방법을 학습합니다.
- **왜 중요한가?** 비지도 학습은 레이블된 데이터가 부족하거나 데이터의 숨겨진 구조를 탐색해야 할 때 필수적입니다. 이는 데이터 이해도를 높이고 새로운 인사이트를 발굴하는 데 기여합니다.
-   [**28_클러스터링.md**](./28_클러스터링.md): K-평균(K-Means), DBSCAN, 계층적 군집 분석 등 클러스터링 알고리즘의 개념과 구현 방법을 학습합니다. 클러스터링 평가 지표를 다룹니다.
-   [**29_차원_축소.md**](./29_차원_축소.md): 주성분 분석(PCA), 비음수 행렬 분해(NMF), t-SNE 등 차원 축소 알고리즘을 학습합니다. 다른 매니폴드 학습 기법을 소개합니다.
-   [**30_이상_탐지.md**](./30_이상_탐지.md): `IsolationForest`, `OneClassSVM` 등 이상 탐지 알고리즘을 학습합니다.

### Part 5: 모델 검증 및 최적화 (Model Validation & Optimization)
- **학습 목표:** 모델의 성능을 정확하게 평가하고 최적의 하이퍼파라미터를 찾는 다양한 기법들을 학습하여, 일반화 성능이 뛰어난 모델을 구축하는 역량을 강화합니다.
- **왜 중요한가?** 모델 검증과 최적화는 과적합을 방지하고 실제 환경에서 모델이 얼마나 잘 작동할지 예측하는 데 필수적입니다. 이는 신뢰할 수 있는 머신러닝 모델을 만드는 핵심 과정입니다.
-   [**31_데이터_분할_및_교차_검증.md**](./31_데이터_분할_및_교차_검증.md): `train_test_split`, K-Fold, Stratified K-Fold 등 데이터 분할 및 교차 검증 기법을 학습합니다.
-   [**32_분류_모델_평가_지표.md**](./32_분류_모델_평가_지표.md): 정확도, 정밀도, 재현율, F1-점수, ROC/AUC 등 분류 모델의 성능 평가 지표를 학습합니다.
-   [**33_회귀_모델_평가_지표.md**](./33_회귀_모델_평가_지표.md): MAE, MSE, RMSE, R-제곱 등 회귀 모델의 성능 평가 지표를 학습합니다.
-   [**34_하이퍼파라미터_튜닝.md**](./34_하이퍼파라미터_튜닝.md): `GridSearchCV`, `RandomizedSearchCV`, 베이지안 최적화 등 하이퍼파라미터 튜닝 방법을 학습합니다. 조기 종료(Early Stopping) 기법을 소개합니다.
-   [**35_모델_비교_통계적_검정.md**](./35_모델_비교_통계적_검정.md): 여러 모델의 성능을 통계적으로 비교하는 방법을 학습합니다.

-   [**36_파이프라인_심화_ColumnTransformer.md**](./36_파이프라인_심화_ColumnTransformer.md): `ColumnTransformer`를 이용한 혼합 데이터 타입 전처리 등 고급 파이프라인 기법을 학습합니다.
-   [**37_모델_영속성_및_배포.md**](./37_모델_영속성_및_배포.md): `joblib`과 `pickle`을 이용한 모델 저장 및 로드, 배포 고려사항을 학습합니다. 모델 모니터링, 재학습 전략, A/B 테스트 개념을 소개합니다.
