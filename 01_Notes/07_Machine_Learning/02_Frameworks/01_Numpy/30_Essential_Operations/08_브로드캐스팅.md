## 1. 브로드캐스팅 (Broadcasting)

### 1.1. 브로드캐스팅 개념

브로드캐스팅은 NumPy가 서로 다른 형태(shape)의 배열 간에 **요소별(element-wise) 산술 연산**을 수행할 수 있도록 하는 강력한 메커니즘입니다. 작은 배열이 큰 배열의 형태에 맞춰 자동으로 확장되어 연산이 가능해집니다. 이는 명시적으로 배열의 형태를 맞추지 않아도 되므로 코드를 간결하게 만들고, C로 구현된 내부 루프를 활용하여 성능 이점을 제공합니다.

NumPy의 유니버설 함수(ufuncs)는 이러한 브로드캐스팅 기능을 기반으로 작동하며, 파이썬의 느린 `for` 루프를 사용하지 않고도 대규모 배열 연산을 매우 효율적으로 처리할 수 있게 합니다. 이는 NumPy의 핵심 연산이 C 언어로 구현되어 파이썬 인터프리터의 오버헤드를 줄이고, CPU의 SIMD(Single Instruction, Multiple Data) 명령어를 활용하며, 메모리 접근을 최적화하기 때문입니다.

```python
import numpy as np

arr_2d = np.array([[1, 2, 3],
                   [4, 5, 6]]) # 형태: (2, 3)
scalar = 10 # 스칼라 값

# 2D 배열과 스칼라 간의 덧셈 (스칼라가 배열의 모든 요소에 브로드캐스팅됨)
result_scalar_add = arr_2d + scalar
print(f"2D 배열 + 스칼라:\n{result_scalar_add}")
# 결과:
# [[11 12 13]
#  [14 15 16]]

vector_row = np.array([100, 200, 300]) # 형태: (3,)

# 2D 배열과 1D 행 벡터 간의 덧셈 (1D 벡터가 각 행에 브로드캐스팅됨)
result_vector_add = arr_2d + vector_row
print(f"\n2D 배열 + 1D 행 벡터:\n{result_vector_add}")
# 결과:
# [[101 202 303]
#  [104 205 306]]
```

### 1.2. 브로드캐스팅 규칙 및 예시

브로드캐스팅은 NumPy의 강력한 기능이지만, 그 규칙을 정확히 이해하는 것이 중요합니다. 두 배열의 형태가 호환되는지 여부는 다음 규칙에 따라 결정됩니다.

#### 1.2.1. 브로드캐스팅 규칙

1.  **차원 수가 더 작은 배열의 형태가 1인 차원으로 확장됩니다.**
    -   예: `(3,)` 형태의 1차원 배열과 `(2, 3)` 형태의 2차원 배열이 있다면, 1차원 배열은 `(1, 3)`으로 확장됩니다.
2.  **두 배열의 차원 크기가 일치하거나, 둘 중 하나의 차원 크기가 1이어야 합니다.**
    -   차원 크기가 1인 경우, 해당 차원은 다른 배열의 크기에 맞춰 확장됩니다.
    -   이 규칙을 만족하지 못하면 `ValueError`가 발생합니다.

#### 1.2.2. 브로드캐스팅 과정 (개념적 확장)

두 배열의 형태를 오른쪽에서 왼쪽으로 비교합니다. 다음 조건 중 하나라도 만족하면 해당 차원은 호환됩니다.

*   두 차원의 크기가 동일하다.
*   두 차원 중 하나의 크기가 1이다.

이 규칙을 통해 배열이 어떻게 확장되는지 이해할 수 있습니다.

#### 1.2.3. 예시 1: 2D 배열과 1D 배열

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]]) # 형태: (2, 3)
B = np.array([10, 20, 30]) # 형태: (3,)

# 브로드캐스팅 과정:
# A의 형태: (2, 3)
# B의 형태: (3,)  -> (1, 3)으로 확장 (규칙 1 적용)
# 이제 두 배열의 형태를 오른쪽에서 왼쪽으로 비교:
# - 마지막 차원: 3과 3 (일치) -> 호환
# - 두 번째 차원: 2와 1 (하나가 1) -> 호환, 1이 2로 확장
# 최종적으로 B는 A와 같은 (2, 3) 형태로 가상 확장되어 연산됩니다.

C = A + B
print(f"A + B:\n{C}")
# 결과:
# [[11 22 33]
#  [14 25 36]]
```

#### 1.2.4. 예시 2: 2D 배열과 (N, 1) 형태의 2D 배열

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]]) # 형태: (2, 3)
D = np.array([[100],
              [200]]) # 형태: (2, 1)

# 브로드캐스팅 과정:
# A의 형태: (2, 3)
# D의 형태: (2, 1)
# 이제 두 배열의 형태를 오른쪽에서 왼쪽으로 비교:
# - 마지막 차원: 3과 1 (하나가 1) -> 호환, 1이 3으로 확장
# - 두 번째 차원: 2와 2 (일치) -> 호환
# 최종적으로 D는 A와 같은 (2, 3) 형태로 가상 확장되어 연산됩니다.

E = A + D
print(f"\nA + D:\n{E}")
# 결과:
# [[101 102 103]
#  [204 205 206]]
```

#### 1.2.5. 예시 3: 두 배열 모두 브로드캐스팅이 필요한 경우

```python
import numpy as np

mat1 = np.array([1, 2, 3]) # 형태: (3,)
mat2 = np.array([[10],
                 [20]]) # 형태: (2, 1)

# 브로드캐스팅 과정:
# mat1의 형태: (3,)   -> (1, 3)으로 확장
# mat2의 형태: (2, 1)
# 이제 두 배열의 형태를 오른쪽에서 왼쪽으로 비교:
# - 마지막 차원: 3과 1 (하나가 1) -> 호환, 1이 3으로 확장
# - 두 번째 차원: 1과 2 (하나가 1) -> 호환, 1이 2로 확장
# 최종적으로 mat1은 (2, 3)으로, mat2는 (2, 3)으로 가상 확장되어 연산됩니다.

result_both_broadcast = mat1 + mat2
print(f"\nmat1 + mat2 (양쪽 브로드캐스팅):\n{result_both_broadcast}")
# 결과:
# [[11 12 13]
#  [21 22 23]]
```

#### 1.2.6. 호환되지 않는 형태의 예시

```python
import numpy as np

A = np.array([[1, 2, 3],
              [4, 5, 6]]) # 형태: (2, 3)
F = np.array([1, 2]) # 형태: (2,)

# 브로드캐스팅 과정:
# A의 형태: (2, 3)
# F의 형태: (2,)  -> (1, 2)로 확장
# 이제 두 배열의 형태를 오른쪽에서 왼쪽으로 비교:
# - 마지막 차원: 3과 2 (불일치, 둘 다 1이 아님) -> 호환되지 않음

try:
    G = A + F
    print(G)
except ValueError as e:
    print(f"\n오류 발생: {e}")
    print("A의 형태 (2, 3)과 F의 형태 (2,)는 브로드캐스팅 규칙에 따라 호환되지 않습니다.")
    print("F는 (1, 2)로 확장되지만, A의 마지막 차원 (3)과 F의 마지막 차원 (2)이 일치하지 않습니다.")
```

#### 1.2.7. `np.newaxis`를 이용한 명시적 차원 추가

때로는 브로드캐스팅 규칙을 명확히 하거나 특정 차원을 추가하여 브로드캐스팅을 가능하게 하기 위해 `np.newaxis`를 사용할 수 있습니다. `np.newaxis`는 배열에 크기가 1인 새로운 차원(축)을 추가하는 특별한 객체입니다. `np.newaxis`의 기본적인 사용법과 `np.expand_dims()`와의 비교에 대한 자세한 내용은 [05_배열_형태_변경.md](05_배열_형태_변경.md) 문서를 참고해 주세요.

여기서는 `np.newaxis`가 브로드캐스팅 규칙을 어떻게 만족시키고 연산을 가능하게 하는지에 초점을 맞춥니다.

**예시: 1차원 배열을 행 벡터로 변환하여 2차원 배열과 브로드캐스팅**

```python
import numpy as np

arr_2d = np.array([[1, 2, 3],
                   [4, 5, 6]]) # 형태: (2, 3)

arr_1d = np.array([10, 20, 30]) # 형태: (3,)

print(f"원본 2차원 배열:\n{arr_2d}, shape: {arr_2d.shape}")
print(f"원본 1차원 배열: {arr_1d}, shape: {arr_1d.shape}")

# arr_1d를 (1, 3) 형태로 확장하여 arr_2d (2, 3)과 브로드캐스팅 가능하게 만듭니다.
# arr_1d[np.newaxis, :]는 (1, 3)이 됩니다.
expanded_arr_1d = arr_1d[np.newaxis, :]
print(f"\nnp.newaxis를 이용해 확장된 1차원 배열: {expanded_arr_1d}, shape: {expanded_arr_1d.shape}")

# 브로드캐스팅을 이용한 덧셈
result = arr_2d + expanded_arr_1d
print(f"\n브로드캐스팅 덧셈 결과:\n{result}")
# 결과:
# [[11 22 33]
#  [14 25 36]]
# 설명: expanded_arr_1d (1,3)이 arr_2d (2,3)의 각 행에 브로드캐스팅되어 더해집니다.
```

**예시: 열 벡터와 행 벡터의 브로드캐스팅**

```python
import numpy as np

vec_col = np.array([1, 2, 3])[:, np.newaxis] # 형태: (3, 1)
vec_row = np.array([10, 20]) # 형태: (2,) -> (1, 2)로 브로드캐스팅됨

print(f"열 벡터 (vec_col):\n{vec_col}, shape: {vec_col.shape}")
print(f"행 벡터 (vec_row): {vec_row}, shape: {vec_row.shape}")

# 브로드캐스팅 과정:
# vec_col 형태: (3, 1)
# vec_row 형태: (2,) -> (1, 2)로 확장 (규칙 1 적용)
# 비교:
# - 마지막 차원: 1과 2 (하나가 1) -> 호환, 1이 2로 확장
# - 두 번째 차원: 3과 1 (하나가 1) -> 호환, 1이 3으로 확장
# 최종적으로 vec_col은 (3, 2)로, vec_row는 (3, 2)로 가상 확장되어 연산됩니다.

result_cross_broadcast = vec_col + vec_row
print(f"\nvec_col + vec_row (양쪽 브로드캐스팅):\n{result_cross_broadcast}")
# 결과:
# [[11 21]
#  [12 22]
#  [13 23]]
```


### 1.3. 브로드캐스팅의 한계 및 주의점

브로드캐스팅은 매우 편리하지만, 메모리 사용량에 주의해야 합니다. 브로드캐스팅은 실제로 데이터를 복사하여 배열을 확장하는 것이 아니라, **메모리를 효율적으로 사용하기 위해 가상으로 배열을 확장**하여 연산을 수행합니다. 하지만 연산의 결과물은 **확장된 크기의 새로운 배열**이 되어 메모리에 할당됩니다.

#### 1.3.1. 메모리 급증

매우 큰 두 배열을 브로드캐스팅하면, 결과 배열의 크기가 예상을 초과하여 메모리 부족(Out of Memory) 오류를 일으킬 수 있습니다.

```python
# 예시: 메모리 문제를 일으킬 수 있는 경우
import numpy as np

large_arr1 = np.random.rand(10000, 1)
large_arr2 = np.random.rand(1, 10000)

# 브로드캐스팅 결과는 (10000, 10000) 크기의 배열이 됨
# result = large_arr1 + large_arr2 # 약 800MB의 메모리 필요 (float64 기준)
```

#### 1.3.2. 의도치 않은 연산

브로드캐스팅 규칙을 잘못 이해하면, 의도치 않은 형태의 결과가 나올 수 있으므로 항상 연산 후 결과 배열의 `shape`을 확인하는 습관이 중요합니다.

#### 1.3.3. 대안

메모리가 우려되는 매우 큰 배열의 경우, `for` 루프를 사용하여 명시적으로 연산을 수행하거나, 데이터를 작은 청크(chunk)로 나누어 처리하는 방법을 고려할 수 있습니다. 이는 속도는 느려지지만 메모리 사용량을 제어할 수 있는 장점이 있습니다.

#### 1.3.4. 디버깅 팁

브로드캐스팅 관련 오류가 발생했을 때는 다음 사항들을 확인하여 문제를 해결할 수 있습니다.

*   **`shape` 속성 확인**: 연산에 참여하는 모든 배열의 `shape` 속성을 출력하여 브로드캐스팅 규칙에 맞는지 직접 비교해 봅니다.
*   **`np.newaxis` 활용**: 차원 수가 맞지 않거나 특정 차원의 크기를 1로 만들어야 할 경우 `np.newaxis`를 사용하여 배열의 형태를 명시적으로 조정해 봅니다.
*   **오른쪽에서 왼쪽으로 규칙 적용**: 브로드캐스팅 규칙을 적용할 때 항상 배열의 형태를 오른쪽에서 왼쪽으로 비교하는 것을 기억합니다.
*   **작은 예시로 테스트**: 복잡한 배열에서 문제가 발생하면, 동일한 형태의 더 작은 배열을 만들어 테스트해 보면 문제의 원인을 파악하기 쉽습니다.
