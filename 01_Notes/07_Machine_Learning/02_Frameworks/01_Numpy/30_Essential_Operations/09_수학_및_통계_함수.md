## 1. 선형대수 연산 (Linear Algebra Operations)

NumPy는 선형대수 연산을 효율적으로 수행하는 강력한 기능을 제공합니다. 이는 머신러닝, 통계, 물리학 등 다양한 분야에서 필수적입니다.

### 1.1. 행렬 곱셈 (Dot Product)

행렬 곱셈은 선형대수학의 핵심 연산 중 하나로, 두 행렬을 곱하여 새로운 행렬을 생성하는 연산입니다. NumPy에서는 `np.dot()` 함수나 Python 3.5+부터 지원되는 `@` 연산자를 사용하여 행렬 곱셈을 수행합니다. `@` 연산자는 행렬 곱셈에 특화되어 있어 가독성이 높고 일반적으로 선호됩니다.

**수학적 정의 및 규칙:**

행렬 $A$와 행렬 $B$를 곱하여 행렬 $C$를 얻는다고 할 때, $C = AB$ 입니다.
*   **차원 호환성**: 행렬 $A$의 열(column) 개수와 행렬 $B$의 행(row) 개수가 같아야 합니다. 즉, $A$가 $m \times n$ 행렬이고 $B$가 $n \times p$ 행렬일 때만 곱셈이 가능하며, 결과 행렬 $C$는 $m \times p$ 행렬이 됩니다.
*   **계산 방식**: 결과 행렬 $C$의 $i$번째 행, $j$번째 열의 요소 $C_{ij}$는 행렬 $A$의 $i$번째 행 벡터와 행렬 $B$의 $j$번째 열 벡터의 내적(inner product)으로 계산됩니다.

#### 1.1.1. 벡터 내적 (Inner Product of Vectors)

두 1차원 배열(벡터)의 내적은 각 요소의 곱을 모두 더한 스칼라 값입니다. 이는 두 벡터가 얼마나 같은 방향을 향하는지 나타내는 척도로 사용될 수 있습니다.

```python
import numpy as np

v = np.array([9, 10]) # 1차원 배열 (벡터)
w = np.array([11, 12]) # 1차원 배열 (벡터)

print(f"v: {v}")
print(f"w: {w}")

# 벡터 v와 w의 내적 (np.dot(v, w))
# 수학적으로는 v_1*w_1 + v_2*w_2 + ... + v_n*w_n
print(f"\n벡터 v와 w의 내적 (np.dot(v, w)): {np.dot(v, w)}") # 9*11 + 10*12 = 99 + 120 = 219
```

#### 1.1.2. 행렬 곱셈 (Matrix Multiplication)

두 2차원 배열(행렬)의 곱셈을 수행합니다. 결과는 새로운 행렬입니다.

```python
import numpy as np

x = np.array([[1, 2],
              [3, 4]]) # 2x2 행렬
y = np.array([[5, 6],
              [7, 8]]) # 2x2 행렬

print(f"x:\n{x}")
print(f"\ny:\n{y}")

# 행렬 x와 y의 곱셈 (np.dot(x, y))
# x (2x2) * y (2x2) -> 결과 (2x2)
print(f"\n행렬 x와 y의 곱셈 (np.dot(x, y)):\n{np.dot(x, y)}")
# 계산 과정:
# C[0,0] = x[0,0]*y[0,0] + x[0,1]*y[1,0] = 1*5 + 2*7 = 5 + 14 = 19
# C[0,1] = x[0,0]*y[0,1] + x[0,1]*y[1,1] = 1*6 + 2*8 = 6 + 16 = 22
# C[1,0] = x[1,0]*y[0,0] + x[1,1]*y[1,0] = 3*5 + 4*7 = 15 + 28 = 43
# C[1,1] = x[1,0]*y[0,1] + x[1,1]*y[1,1] = 3*6 + 4*8 = 18 + 32 = 50
# 결과:
# [[19, 22],
#  [43, 50]]

# Python 3.5+ 부터는 @ 연산자로 행렬 곱셈 가능 (권장)
print(f"\n행렬 x와 y의 곱셈 (x @ y):\n{x @ y}")
```

#### 1.1.3. 행렬과 벡터의 곱셈

행렬과 벡터의 곱셈은 행렬 곱셈의 특수한 경우로 볼 수 있습니다. 벡터는 행렬 곱셈 규칙에 따라 적절한 차원으로 해석됩니다.

```python
import numpy as np

x = np.array([[1, 2],
              [3, 4]]) # 2x2 행렬
v = np.array([9, 10]) # 1차원 배열 (벡터)

print(f"x:\n{x}")
print(f"\nv: {v}")

# 행렬 x와 벡터 v의 곱셈
# x (2x2) @ v (2,) -> v는 내부적으로 (2,1) 열 벡터로 간주되어 (2x1) 결과 반환
print(f"\n행렬 x와 벡터 v의 곱셈 (x @ v):\n{x @ v}")
# 계산 과정:
# C[0] = x[0,0]*v[0] + x[0,1]*v[1] = 1*9 + 2*10 = 9 + 20 = 29
# C[1] = x[1,0]*v[0] + x[1,1]*v[1] = 3*9 + 4*10 = 27 + 40 = 67
# 결과: [29, 67]

# np.dot()을 사용할 경우
print(f"\n행렬 x와 벡터 v의 곱셈 (np.dot(x, v)):\n{np.dot(x, v)}")
```

#### 1.1.4. 고차원 배열의 행렬 곱셈 (Generalized Dot Product)

`np.dot()` 함수는 2차원 이상의 배열에 대해서도 일반화된 행렬 곱셈을 수행할 수 있습니다. 이때 `np.dot(a, b)`는 `a`의 마지막 축과 `b`의 마지막에서 두 번째 축(또는 1차원 배열인 경우 마지막 축)을 따라 합을 계산합니다. `@` 연산자도 유사하게 작동합니다.

예를 들어, 3차원 배열 `A` (shape: `(i, j, k)`)와 3차원 배열 `B` (shape: `(k, l, m)`)의 행렬 곱셈은 `(i, j, l, m)` 형태의 결과를 반환합니다. 이는 `A`의 마지막 축 `k`와 `B`의 마지막에서 두 번째 축 `k`가 일치해야 합니다.

```python
import numpy as np

# 3차원 배열 예시
A_3d = np.arange(1, 28).reshape(3, 3, 3) # (3, 3, 3)
B_3d = np.arange(1, 28).reshape(3, 3, 3) # (3, 3, 3)

# A_3d의 마지막 축 (3)과 B_3d의 마지막에서 두 번째 축 (3)이 일치
result_3d = A_3d @ B_3d
print(f"3차원 배열 A_3d의 shape: {A_3d.shape}")
print(f"3차원 배열 B_3d의 shape: {B_3d.shape}")
print(f"\n3차원 배열 행렬 곱셈 결과 shape: {result_3d.shape}")
# 결과 shape: (3, 3, 3)
# (i, j, k) @ (k, l, m) -> (i, j, l, m)
# (3, 3, 3) @ (3, 3, 3) -> (3, 3, 3, 3) 이 되어야 하지만,
# NumPy의 @ 연산자는 스택된 행렬 곱셈을 수행합니다.
# 즉, (..., N, K) @ (..., K, M) -> (..., N, M)
# 여기서는 (3, 3, 3) @ (3, 3, 3) 이므로,
# 첫 번째 3은 스택된 행렬의 개수, (3, 3)은 각 행렬의 shape으로 간주됩니다.
# 따라서 결과는 (3, 3, 3)이 됩니다.

# np.dot()의 경우
# np.dot(A_3d, B_3d)는 A_3d의 마지막 축과 B_3d의 마지막에서 두 번째 축을 곱합니다.
# (3, 3, 3)과 (3, 3, 3)의 경우, (3, 3, 3)이 됩니다.
# A_3d의 (3,3) 행렬 3개와 B_3d의 (3,3) 행렬 3개를 각각 곱하는 형태가 됩니다.
```

### 1.2. 기타 선형대수 함수

`numpy.linalg` 모듈은 행렬 및 벡터 연산을 위한 광범위한 선형대수 함수를 제공합니다. 이 함수들은 데이터 분석, 머신러닝 알고리즘 구현, 공학 계산 등 다양한 과학 및 공학 분야에서 필수적으로 사용됩니다.

#### 1.2.1. 역행렬 (Inverse Matrix)

정방 행렬(square matrix) $A$에 대해 $A A^{-1} = A^{-1} A = I$ (단위 행렬)를 만족하는 행렬 $A^{-1}$를 $A$의 역행렬이라고 합니다. 역행렬은 선형 연립 방정식을 풀거나, 선형 변환을 되돌리는 데 사용됩니다. 모든 정방 행렬이 역행렬을 가지는 것은 아니며, 행렬식이 0이 아닌 경우에만 역행렬이 존재합니다 (비특이 행렬).

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

print(f"A:\n{A}")

# 역행렬 (Inverse Matrix)
inv_A = np.linalg.inv(A)
print(f"\nA의 역행렬 (np.linalg.inv(A)):\n{inv_A}")
# 결과:
# [[-2.   1. ]
#  [ 1.5 -0.5]]

# 검증: A * inv_A 가 단위 행렬(I)에 가까운지 확인
# 부동소수점 오차로 인해 완벽한 단위 행렬이 아닐 수 있습니다.
identity_check = A @ inv_A
print(f"\nA @ inv_A (단위 행렬 검증):\n{identity_check}")
# 결과는 [[1. 0.], [0. 1.]]에 매우 가까울 것입니다.
```

#### 1.2.2. 행렬식 (Determinant)

정방 행렬에 스칼라 값을 할당하는 함수로, 행렬의 특성을 나타내는 중요한 값입니다. 행렬식은 행렬이 나타내는 선형 변환이 공간을 얼마나 확장하거나 축소하는지, 그리고 변환이 공간의 방향을 바꾸는지 여부를 알려줍니다. 행렬식이 0이 아닌 경우에만 역행렬이 존재합니다.

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])

print(f"A:\n{A}")

# 행렬식 (Determinant)
det_A = np.linalg.det(A)
print(f"\nA의 행렬식 (np.linalg.det(A)): {det_A}") # 1*4 - 2*3 = 4 - 6 = -2

# 행렬식이 0인 경우 (특이 행렬) - 역행렬이 존재하지 않음
B = np.array([[1, 2],
              [2, 4]]) # 두 번째 행이 첫 번째 행의 2배
det_B = np.linalg.det(B)
print(f"\nB:\n{B}")
print(f"B의 행렬식 (np.linalg.det(B)): {det_B}") # 1*4 - 2*2 = 0

```

#### 1.2.3. 선형 연립 방정식 풀이 (Solve linear equations)

`Ax = b` 형태의 선형 연립 방정식에서 미지수 벡터 `x`를 찾습니다. 이는 역행렬을 계산하여 $x = A^{-1}b$ 로 푸는 것보다 수치적으로 더 안정적이고 효율적인 방법입니다.

```python
import numpy as np

A = np.array([[1, 2],
              [3, 4]])
b = np.array([5, 6])

print(f"A:\n{A}")
print(f"b: {b}")

# 선형 연립 방정식 풀이 (Solve linear equations)
# 1x + 2y = 5
# 3x + 4y = 6
x_solution = np.linalg.solve(A, b)
print(f"\n선형 연립 방정식의 해 (np.linalg.solve(A, b)): {x_solution}")
# 결과: [-4.   4.5]
# 검증: A @ x_solution 이 b와 가까운지 확인
print(f"검증 (A @ x_solution): {A @ x_solution}")
```

#### 1.2.4. 고유값 (Eigenvalues) 및 고유 벡터 (Eigenvectors)

정방 행렬 $A$에 대해 $Av = \lambda v$를 만족하는 스칼라 $\lambda$를 고유값(eigenvalue), 벡터 $v$를 고유 벡터(eigenvector)라고 합니다. 고유값과 고유 벡터는 주성분 분석(PCA), 스펙트럼 분석, 양자 역학 등 다양한 분야에서 시스템의 특성을 분석하는 데 사용됩니다.

```python
import numpy as np

M = np.array([[1, 2],
              [2, 1]])

print(f"M:\n{M}")

# 고유값과 고유 벡터 계산
eigenvalues, eigenvectors = np.linalg.eig(M)

print(f"\n고유값 (Eigenvalues): {eigenvalues}")
print(f"고유 벡터 (Eigenvectors):\n{eigenvectors}")
# 결과:
# 고유값: [ 3. -1.]
# 고유 벡터:
# [[ 0.70710678 -0.70710678]
#  [ 0.70710678  0.70710678]]
# 첫 번째 열이 첫 번째 고유값(3)에 해당하는 고유 벡터, 두 번째 열이 두 번째 고유값(-1)에 해당하는 고유 벡터입니다.
```

#### 1.2.5. 특이값 분해 (Singular Value Decomposition, SVD)

SVD는 임의의 $m \times n$ 행렬을 세 개의 행렬의 곱으로 분해하는 강력한 행렬 분해 기법입니다: $A = U \Sigma V^T$. 여기서 $U$와 $V$는 직교 행렬이고, $\Sigma$는 대각 행렬입니다. SVD는 차원 축소, 노이즈 제거, 추천 시스템 등 다양한 데이터 과학 및 머신러닝 응용 분야에서 활용됩니다.

```python
import numpy as np

A_svd = np.array([[1, 1],
                  [7, 7]])

print(f"A_svd:\n{A_svd}")

# SVD 수행
U, s, Vt = np.linalg.svd(A_svd)

print(f"\nU (좌측 특이 벡터):\n{U}")
print(f"s (특이값):\n{s}") # 특이값은 대각 행렬 Sigma의 대각 요소입니다.
print(f"Vt (우측 특이 벡터의 전치):\n{Vt}")

# 원본 행렬 복원 (검증)
Sigma = np.zeros((A_svd.shape[0], A_svd.shape[1]))
Sigma[:A_svd.shape[1], :A_svd.shape[1]] = np.diag(s)
reconstructed_A = U @ Sigma @ Vt
print(f"\n재구성된 A:\n{reconstructed_A}")
```

#### 1.2.6. 행렬 노름 (Matrix Norm)

행렬 노름은 벡터 노름의 개념을 행렬로 확장한 것으로, 행렬의 "크기"를 측정하는 방법입니다. 다양한 종류의 노름이 있으며, `np.linalg.norm()` 함수를 사용하여 계산할 수 있습니다.

```python
import numpy as np

M_norm = np.array([[1, 2],
                   [3, 4]])

print(f"M_norm:\n{M_norm}")

# Frobenius 노름 (기본값)
frobenius_norm = np.linalg.norm(M_norm)
print(f"\nFrobenius 노름: {frobenius_norm:.4f}")

# 1-노름 (열의 절댓값 합 중 최댓값)
one_norm = np.linalg.norm(M_norm, ord=1)
print(f"1-노름: {one_norm:.4f}")

# 무한대 노름 (행의 절댓값 합 중 최댓값)
inf_norm = np.linalg.norm(M_norm, ord=np.inf)
print(f"무한대 노름: {inf_norm:.4f}")
```

## 2. 집계 함수 (Aggregation Functions)

NumPy의 집계 함수(Aggregation Functions)는 배열의 데이터를 요약하고 분석하는 데 사용됩니다. 이 함수들은 배열의 모든 요소 또는 특정 축(axis)을 따라 연산을 수행하여 단일 값 또는 더 작은 차원의 배열을 반환합니다. 이는 데이터의 특징을 파악하고 통계적 분석을 수행하는 데 필수적인 도구입니다.

### 2.1. 기본 집계 함수

가장 일반적으로 사용되는 집계 함수들은 배열의 데이터를 요약하는 데 필수적입니다. 이 함수들은 `axis` 파라미터를 지정하지 않으면, 기본적으로 배열을 1차원으로 평탄화(flatten)한 후 **모든 요소에 대해 연산을 수행하며 스칼라 값을 반환**합니다.

*   `np.sum(arr)`: 배열의 모든 요소의 합계를 계산합니다. $\sum x_i$
*   `np.mean(arr)`: 배열의 모든 요소의 평균을 계산합니다. $\frac{\sum x_i}{N}$
*   `np.max(arr)`: 배열의 모든 요소 중 최댓값을 찾습니다.
*   `np.min(arr)`: 배열의 모든 요소 중 최솟값을 찾습니다.
*   `np.argmax(arr)`: 배열의 모든 요소 중 최댓값이 있는 **인덱스**를 반환합니다. (첫 번째로 나타나는 최댓값의 인덱스)
*   `np.argmin(arr)`: 배열의 모든 요소 중 최솟값이 있는 **인덱스**를 반환합니다. (첫 번째로 나타나는 최솟값의 인덱스)
*   `np.prod(arr)`: 배열의 모든 요소의 곱을 계산합니다. $\prod x_i$

**NaN (Not a Number) 값 처리:**
기본 집계 함수들은 배열에 `NaN` 값이 포함되어 있으면 결과도 `NaN`으로 반환하는 경우가 많습니다. `NaN` 값을 무시하고 연산을 수행하려면 `np.nansum()`, `np.nanmean()` 등 `nan` 접두사가 붙은 함수들을 사용합니다.

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5, 6])
print(f"원본 배열: {arr}")

print(f"\n합계 (np.sum(arr)): {np.sum(arr)}")
print(f"평균 (np.mean(arr)): {np.mean(arr)}")
print(f"최댓값 (np.max(arr)): {np.max(arr)}")
print(f"최솟값 (np.min(arr)): {np.min(arr)}")
print(f"최댓값의 인덱스 (np.argmax(arr)): {np.argmax(arr)}") # 6은 인덱스 5에 위치
print(f"최솟값의 인덱스 (np.argmin(arr)): {np.argmin(arr)}") # 1은 인덱스 0에 위치
print(f"곱 (np.prod(arr)): {np.prod(arr)}") # 1*2*3*4*5*6 = 720

# NaN 값 포함 예시
arr_nan = np.array([1, 2, np.nan, 4, 5])
print(f"\nNaN 포함 배열: {arr_nan}")
print(f"NaN 포함 배열의 합계 (np.sum(arr_nan)): {np.sum(arr_nan)}") # NaN 반환
print(f"NaN 무시하고 합계 (np.nansum(arr_nan)): {np.nansum(arr_nan)}") # NaN을 0으로 간주하고 합계 (1+2+0+4+5 = 12)
print(f"NaN 무시하고 평균 (np.nanmean(arr_nan)): {np.nanmean(arr_nan)}") # NaN을 제외하고 평균 (1+2+4+5)/4 = 12/4 = 3.0

# 배열 메서드 활용
print(f"\n배열 메서드 활용 (arr.sum()): {arr.sum()}")
print(f"배열 메서드 활용 (arr.mean()): {arr.mean()}")
```

### 2.2. `axis` 파라미터 활용

`axis` 파라미터는 다차원 배열에서 집계 연산을 수행할 **축(dimension)**을 지정하는 데 사용됩니다. NumPy 배열은 여러 개의 축을 가질 수 있으며, 각 축은 배열의 특정 차원을 나타냅니다. `axis`를 지정하면 해당 축을 따라 연산이 수행되고, 연산이 완료된 후 **지정된 축은 결과 배열에서 제거되거나(기본 동작) 크기가 1인 차원으로 유지됩니다(`keepdims=True` 사용 시)**.

**`axis`의 개념:**
`axis`는 연산이 "수행되는 방향" 또는 "축소될 축"을 의미합니다.
*   2차원 배열(행렬)에서:
    *   `axis=0`: 첫 번째 축(행)을 따라 연산합니다. 즉, 각 열(column)의 요소들을 위에서 아래로(수직 방향) 집계합니다. 결과 배열의 0번 축이 사라집니다.
    *   `axis=1`: 두 번째 축(열)을 따라 연산합니다. 즉, 각 행(row)의 요소들을 왼쪽에서 오른쪽으로(수평 방향) 집계합니다. 결과 배열의 1번 축이 사라집니다.
*   3차원 배열에서:
    *   `axis=0`: 깊이 방향으로 집계 (각 (행, 열) 위치의 요소들을 묶음)
    *   `axis=1`: 행 방향으로 집계 (각 (깊이, 열) 위치의 요소들을 묶음)
    *   `axis=2`: 열 방향으로 집계 (각 (깊이, 행) 위치의 요소들을 묶음)

#### 2.2.1. `axis=None` (전체 배열 연산)

`axis` 파라미터를 지정하지 않거나 `axis=None`으로 설정하면, 배열을 1차원으로 평탄화(flatten)한 후 **모든 요소에 대해 연산을 수행**합니다. 결과는 항상 스칼라 값입니다.

```python
import numpy as np

x = np.array([[1, 2, 3],
              [4, 5, 6]])

print(f"원본 배열 x:\n{x}, shape: {x.shape}")

# 모든 요소의 합계 (axis=None과 동일)
total_sum = np.sum(x)
print(f"\n모든 요소의 합계 (np.sum(x)): {total_sum}, type: {type(total_sum))}") # 1 + 2 + 3 + 4 + 5 + 6 = 21
print(f"모든 요소의 평균 (np.mean(x)): {np.mean(x)}")
```

#### 2.2.2. `axis=0` (열 방향 연산)

`axis=0`으로 설정하면 각 열(column)을 따라 연산을 수행합니다. 즉, 행(row)들을 따라 내려가면서 같은 열에 있는 요소들을 집계합니다. 2차원 배열의 경우, 결과는 각 열의 통계량이 되며, 결과 배열의 형태에서 0번 축(행)이 사라집니다.

```python
import numpy as np

x = np.array([[1, 2, 3],
              [4, 5, 6]])

print(f"원본 배열 x:\n{x}, shape: {x.shape}")

# 각 열의 합계 (axis=0)
sum_axis0 = np.sum(x, axis=0)
print(f"\n각 열의 합계 (np.sum(x, axis=0)): {sum_axis0}, shape: {sum_axis0.shape}") # [1+4, 2+5, 3+6] = [5 7 9]
# 원본 shape (2, 3)에서 axis=0이 사라져 (3,)이 됨

# 각 열의 평균
mean_axis0 = np.mean(x, axis=0)
print(f"각 열의 평균 (np.mean(x, axis=0)): {mean_axis0}, shape: {mean_axis0.shape}")

# 각 열의 최댓값
max_axis0 = np.max(x, axis=0)
print(f"각 열의 최댓값 (np.max(x, axis=0)): {max_axis0}, shape: {max_axis0.shape}")
```

#### 2.2.3. `axis=1` (행 방향 연산)

`axis=1`로 설정하면 각 행(row)을 따라 연산을 수행합니다. 즉, 열(column)들을 따라 가로로 이동하면서 같은 행에 있는 요소들을 집계합니다. 2차원 배열의 경우, 결과는 각 행의 통계량이 되며, 결과 배열의 형태에서 1번 축(열)이 사라집니다.

```python
import numpy as np

x = np.array([[1, 2, 3],
              [4, 5, 6]])

print(f"원본 배열 x:\n{x}, shape: {x.shape}")

# 각 행의 합계 (axis=1)
sum_axis1 = np.sum(x, axis=1)
print(f"\n각 행의 합계 (np.sum(x, axis=1)): {sum_axis1}, shape: {sum_axis1.shape}") # [1+2+3, 4+5+6] = [ 6 15]
# 원본 shape (2, 3)에서 axis=1이 사라져 (2,)이 됨

# 각 행의 최댓값
max_axis1 = np.max(x, axis=1)
print(f"각 행의 최댓값 (np.max(x, axis=1)): {max_axis1}, shape: {max_axis1.shape}")

# 각 행의 평균
mean_axis1 = np.mean(x, axis=1)
print(f"각 행의 평균 (np.mean(x, axis=1)): {mean_axis1}, shape: {mean_axis1.shape}")
```

#### 2.2.4. 고차원 배열에서의 `axis` 활용 (3차원 예시)

`axis` 파라미터는 3차원 이상의 배열에서도 동일한 방식으로 작동합니다. 지정된 축을 따라 연산이 수행되고 해당 축이 결과 배열에서 제거됩니다.

```python
import numpy as np

# 3차원 배열 (2개의 3x4 행렬 스택)
# shape: (2, 3, 4)
# axis 0: 층 (depth)
# axis 1: 행 (rows)
# axis 2: 열 (columns)
arr_3d = np.arange(24).reshape(2, 3, 4)
print(f"원본 3차원 배열 arr_3d (shape: {arr_3d.shape}):\n{arr_3d}")

# axis=0으로 합계 (층을 따라 합계)
# 결과 shape: (3, 4)
sum_axis0_3d = np.sum(arr_3d, axis=0)
print(f"\naxis=0으로 합계 (sum_axis0_3d, shape: {sum_axis0_3d.shape}):\n{sum_axis0_3d}")
# arr_3d[0] + arr_3d[1]

# axis=1으로 합계 (행을 따라 합계)
# 결과 shape: (2, 4)
sum_axis1_3d = np.sum(arr_3d, axis=1)
print(f"\naxis=1으로 합계 (sum_axis1_3d, shape: {sum_axis1_3d.shape}):\n{sum_axis1_3d}")
# 각 3x4 행렬에서 각 열의 합계 (행 방향으로 축소)

# axis=2으로 합계 (열을 따라 합계)
# 결과 shape: (2, 3)
sum_axis2_3d = np.sum(arr_3d, axis=2)
print(f"\naxis=2으로 합계 (sum_axis2_3d, shape: {sum_axis2_3d.shape}):\n{sum_axis2_3d}")
# 각 3x4 행렬에서 각 행의 합계 (열 방향으로 축소)
```

### 2.3. `keepdims` 파라미터

`keepdims=True`를 설정하면 집계 연산 후에도 결과 배열의 차원(dimension)을 유지합니다. 일반적으로 `axis` 파라미터를 사용하여 집계 연산을 수행하면 해당 축이 결과 배열에서 제거되어 차원이 축소됩니다. 하지만 `keepdims=True`를 사용하면, **연산이 수행된 축의 차원 크기가 1로 유지**되어 결과 배열의 차원 수가 원본 배열과 동일하게 됩니다.

이는 특히 **브로드캐스팅(Broadcasting)**을 활용할 때 매우 유용합니다. 브로드캐스팅은 서로 다른 형태(shape)의 배열 간에 연산을 수행할 수 있도록 NumPy가 자동으로 배열의 형태를 맞춰주는 기능입니다. `keepdims=True`를 통해 차원을 유지하면, 집계된 결과가 원본 배열과 호환되는 형태로 유지되어 추가적인 `reshape` 작업 없이도 쉽게 브로드캐스팅을 적용할 수 있습니다.

**예시:**

```python
import numpy as np

x = np.array([[1, 2, 3],
              [4, 5, 6]])

print(f"원본 배열 x:\n{x}, shape: {x.shape}")

# 1. `keepdims=False` (기본값)
# axis=0으로 합계 연산: 각 열의 합계를 계산합니다.
# 결과 배열의 shape에서 0번 축(행)이 사라집니다.
sum_axis0_no_keepdims = np.sum(x, axis=0)
print(f"\nsum(axis=0, keepdims=False): {sum_axis0_no_keepdims}, shape: {sum_axis0_no_keepdims.shape}")
# 결과: [5 7 9], shape: (3,)
# 이 결과는 원본 배열 x (shape: (2, 3))와 직접 브로드캐스팅하기 어렵습니다.
# 예를 들어, x - sum_axis0_no_keepdims를 시도하면 오류가 발생할 수 있습니다.
# print(x - sum_axis0_no_keepdims) # ValueError: operands could not be broadcast together with shapes (2,3) (3,)

# 2. `keepdims=True`
# axis=0으로 합계 연산: 각 열의 합계를 계산하지만, 0번 축의 차원을 1로 유지합니다.
sum_axis0_keepdims = np.sum(x, axis=0, keepdims=True)
print(f"sum(axis=0, keepdims=True): {sum_axis0_keepdims}, shape: {sum_axis0_keepdims.shape}")
# 결과: [[5 7 9]], shape: (1, 3)
# 이 형태는 원본 배열 x (shape: (2, 3))와 브로드캐스팅이 가능합니다.
# (2, 3) - (1, 3) -> (2, 3) - (2, 3)으로 확장되어 연산됩니다.

# `keepdims=True`를 사용한 브로드캐스팅 예시: 각 열에서 해당 열의 합계를 뺍니다.
# 예를 들어, 데이터 정규화(normalization) 시 각 특성(열)의 평균을 빼는 경우에 유용합니다.
result_broadcast = x - sum_axis0_keepdims
print(f"\nx - sum_axis0_keepdims (브로드캐스팅 예시 - 각 열에서 해당 열의 합계 빼기):\n{result_broadcast}")
# 계산 과정:
# [[1, 2, 3],   -   [[5, 7, 9]]
#  [4, 5, 6]]
#
# 브로드캐스팅 후:
# [[1, 2, 3],   -   [[5, 7, 9],
#  [4, 5, 6]]       [5, 7, 9]]
#
# 결과:
# [[1-5, 2-7, 3-9],
#  [4-5, 5-7, 6-9]]
# = [[-4, -5, -6],
#    [-1, -2, -3]]

# 다른 예시: axis=1 (행 방향)
# 각 행의 평균을 계산하고, 그 평균을 원본 배열의 각 행에서 웁니다.
mean_axis1_keepdims = np.mean(x, axis=1, keepdims=True)
print(f"\nmean(axis=1, keepdims=True): {mean_axis1_keepdims}, shape: {mean_axis1_keepdims.shape}")
# 결과: [[2.], [5.]], shape: (2, 1)

# 브로드캐스팅: (2, 3) - (2, 1) -> (2, 3) - (2, 3)
result_broadcast_row = x - mean_axis1_keepdims
print(f"x - mean_axis1_keepdims (브로드캐스팅 예시 - 각 행에서 해당 행의 평균 빼기):\n{result_broadcast_row}")
# 계산 과정:
# [[1, 2, 3],   -   [[2.],
#  [4, 5, 6]]       [5.]]
#
# 브로드캐스팅 후:
# [[1, 2, 3],   -   [[2., 2., 2.],
#  [4, 5, 6]]       [5., 5., 5.]]
#
# 결과:
# [[1-2, 2-2, 3-2],
#  [4-5, 5-5, 6-5]]
# = [[-1.,  0.,  1.],
#    [-1.,  0.,  1.]]
```

### 2.4. 고급 통계 및 논리 집계 함수

NumPy는 데이터의 분포, 경향성, 그리고 특정 조건의 만족 여부를 파악하는 데 필수적인 다양한 고급 통계 및 논리 집계 함수를 제공합니다. 이 함수들은 데이터 분석 및 머신러닝 전처리 과정에서 광범위하게 활용됩니다.

*   `np.std(arr, axis=None, ddof=0)`: 배열의 **표준 편차(Standard Deviation)**를 계산합니다. 표준 편차는 데이터가 평균으로부터 얼마나 퍼져 있는지를 나타내는 척도입니다.
    *   `ddof` (delta degrees of freedom): 분모에서 뺄 자유도 수를 지정합니다.
        *   `ddof=0` (기본값): 모집단 표준 편차를 계산합니다. (분모: N)
        *   `ddof=1`: 표본 표준 편차를 계산합니다. (분모: N-1) - 통계적 추론 시 일반적으로 사용됩니다.
*   `np.var(arr, axis=None, ddof=0)`: 배열의 **분산(Variance)**을 계산합니다. 분산은 표준 편차의 제곱으로, 데이터의 퍼짐 정도를 나타냅니다. `ddof` 파라미터는 `np.std`와 동일하게 작동합니다.
*   `np.median(arr, axis=None)`: 배열의 **중앙값(Median)**을 계산합니다. 중앙값은 데이터를 크기 순으로 정렬했을 때 가장 가운데에 위치하는 값으로, 이상치(outlier)에 덜 민감하여 데이터의 중심 경향을 파악하는 데 유용합니다.
*   `np.percentile(arr, q, axis=None)`: 배열의 `q`번째 **백분위수(Percentile)**를 계산합니다. 백분위수는 전체 데이터를 100등분 했을 때 특정 위치에 해당하는 값을 의미합니다. 데이터의 분포를 이해하고, 사분위수(quartile) 등을 계산하는 데 활용됩니다. `q`는 0에서 100 사이의 값입니다.
*   `np.all(arr, axis=None)`: 배열의 **모든 요소가 True인지** 확인합니다. (논리 AND 연산) 불리언(boolean) 배열에서 모든 조건이 만족하는지 검사할 때 사용됩니다.
*   `np.any(arr, axis=None)`: 배열의 **요소 중 하나라도 True인지** 확인합니다. (논리 OR 연산) 불리언 배열에서 하나 이상의 조건이 만족하는지 검사할 때 사용됩니다.

```python
import numpy as np

# 통계 함수 예시
data = np.array([10, 12, 23, 23, 16, 23, 21, 16])
print(f"원본 데이터: {data}")

print(f"\n표준 편차 (np.std(data)): {np.std(data):.2f} (모집단)")
print(f"표본 표준 편차 (np.std(data, ddof=1)): {np.std(data, ddof=1):.2f} (표본)")
print(f"분산 (np.var(data)): {np.var(data):.2f} (모집단)")
print(f"표본 분산 (np.var(data, ddof=1)): {np.var(data, ddof=1):.2f} (표본)")
print(f"중앙값 (np.median(data)): {np.median(data)}")

# 백분위수 예시
print(f"\n25번째 백분위수 (np.percentile(data, 25)): {np.percentile(data, 25)}") # Q1 (하위 25%)
print(f"50번째 백분위수 (np.percentile(data, 50)): {np.percentile(data, 50)}") # 중앙값 (Q2)
print(f"75번째 백분위수 (np.percentile(data, 75)): {np.percentile(data, 75)}") # Q3 (상위 25%)

# 논리 함수 예시
bool_arr1 = np.array([True, True, True])
bool_arr2 = np.array([True, False, True])
bool_arr3 = np.array([False, False, False])

print(f"\nbool_arr1: {bool_arr1}")
print(f"모든 요소가 True인가? (np.all(bool_arr1)): {np.all(bool_arr1)}") # True
print(f"하나라도 True인가? (np.any(bool_arr1)): {np.any(bool_arr1)}")   # True

print(f"\nbool_arr2: {bool_arr2}")
print(f"모든 요소가 True인가? (np.all(bool_arr2)): {np.all(bool_arr2)}") # False
print(f"하나라도 True인가? (np.any(bool_arr2)): {np.any(bool_arr2)}")   # True

print(f"\nbool_arr3: {bool_arr3}")
print(f"모든 요소가 True인가? (np.all(bool_arr3)): {np.all(bool_arr3)}") # False
print(f"하나라도 True인가? (np.any(bool_arr3)): {np.any(bool_arr3)}")   # False

# 다차원 배열에서의 논리 함수 (axis 활용)
matrix_bool = np.array([[True, False],
                        [True, True]])
print(f"\nmatrix_bool:\n{matrix_bool}")
print(f"각 열이 모두 True인가? (np.all(matrix_bool, axis=0)): {np.all(matrix_bool, axis=0)}") # [True False]
print(f"각 행이 모두 True인가? (np.all(matrix_bool, axis=1)): {np.all(matrix_bool, axis=1)}") # [False True]
print(f"각 열에 하나라도 True가 있는가? (np.any(matrix_bool, axis=0)): {np.any(matrix_bool, axis=0)}") # [True True]
print(f"각 행에 하나라도 True가 있는가? (np.any(matrix_bool, axis=1)): {np.any(matrix_bool, axis=1)}") # [True True]
```
