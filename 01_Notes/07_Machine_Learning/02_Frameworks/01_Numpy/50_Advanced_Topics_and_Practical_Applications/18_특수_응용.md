## 1. 신호 처리의 핵심: 푸리에 변환 (Fourier Transform)

NumPy의 `fft` 모듈은 시간 영역(time-domain)의 신호를 주파수 영역(frequency-domain)으로 변환하는 푸리에 변환 기능을 제공합니다. 이를 통해 신호를 구성하는 주파수 성분을 분석할 수 있어 오디오 필터링, 이미지 압축 등 다양한 분야에 활용됩니다.

### 1.1. 1D 푸리에 변환 및 역변환

1차원 푸리에 변환은 주로 시간에 따라 변하는 신호(예: 음성, 주가, 센서 데이터)를 분석하는 데 사용됩니다. 복잡해 보이는 신호 파형을 여러 개의 단순한 사인파(sine wave)의 합으로 분해하여, 어떤 주파수 성분이 얼마나 강하게 포함되어 있는지 파악할 수 있게 해줍니다.

#### 핵심 함수

*   **`np.fft.fft(a)`**: 입력 배열 `a`(시간 영역 신호)에 대해 **고속 푸리에 변환(Fast Fourier Transform, FFT)**을 수행합니다. 결과는 주파수 성분의 크기와 위상을 나타내는 복소수(complex number) 배열입니다.
*   **`np.fft.ifft(a)`**: `fft`의 결과(주파수 영역 신호)에 대해 **역 푸리에 변환(Inverse FFT)**을 수행하여 원본 시간 영역 신호를 복원합니다.
*   **`np.fft.fftfreq(n, d)`**: `fft` 결과의 각 요소에 해당하는 실제 주파수 값을 계산해주는 헬퍼 함수입니다.
    *   `n`: 샘플 개수 (변환할 배열의 길이).
    *   `d`: 샘플링 간격 (시간). `1 / sampling_rate`에 해당합니다.

#### 결과 해석하기

`fft`의 출력은 복소수 배열이므로, 보통 두 가지 정보를 추출하여 분석합니다.

1.  **진폭 스펙트럼 (Amplitude Spectrum)**: `np.abs(fft_result)`를 통해 각 주파수 성분의 강도(진폭)를 계산합니다. 이 값이 클수록 해당 주파수가 신호에 더 큰 영향을 미친다는 의미입니다.
2.  **위상 스펙트럼 (Phase Spectrum)**: `np.angle(fft_result)`를 통해 각 주파수 성분의 위상(시작점의 오프셋)을 계산합니다.

일반적으로는 진폭 스펙트럼을 분석하여 신호의 주요 주파수를 파악하는 데 집중합니다.

#### 예제: 여러 주파수가 혼합된 신호 분석

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 신호 생성
sampling_rate = 200  # 1초에 200번 샘플링
duration = 2         # 2초 동안의 신호
t = np.linspace(0, duration, sampling_rate * duration, endpoint=False)

# 주파수 7Hz (진폭 0.8)와 30Hz (진폭 0.5)의 두 사인파를 합성
signal = 0.8 * np.sin(2 * np.pi * 7 * t) + 0.5 * np.sin(2 * np.pi * 30 * t)

# 2. 푸리에 변환 수행
# signal 배열에 대해 FFT를 적용하여 주파수 영역으로 변환
fft_result = np.fft.fft(signal)
# fft 결과의 각 지점에 해당하는 실제 주파수 축 생성
n_samples = len(signal)
freq_axis = np.fft.fftfreq(n_samples, d=1/sampling_rate)

# 3. 결과 시각화
# FFT 결과는 대칭적이므로, 양수 주파수 영역(절반)만 확인
half_n = n_samples // 2

plt.figure(figsize=(14, 5))

# 시간 영역의 원본 신호
plt.subplot(1, 2, 1)
plt.plot(t, signal)
plt.title('Original Signal (Time Domain)')
plt.xlabel('Time (s)')
plt.ylabel('Amplitude')
plt.grid(True)

# 주파수 영역의 진폭 스펙트럼
plt.subplot(1, 2, 2)
# np.abs()를 통해 진폭을 계산하고, 정규화(2/n_samples)하여 실제 진폭과 유사하게 만듦
amplitude = np.abs(fft_result[:half_n]) * 2 / n_samples
plt.plot(freq_axis[:half_n], amplitude)
plt.title('Frequency Spectrum (Amplitude)')
plt.xlabel('Frequency (Hz)')
plt.ylabel('Amplitude')
plt.grid(True)
plt.xlim(0, 50) # 0~50Hz 범위만 확대해서 봄

plt.tight_layout()
plt.show()

# 4. 역변환을 통한 신호 복원
reconstructed_signal = np.fft.ifft(fft_result)

# 복원된 신호는 복소수이므로 실수 부분만 취함 (.real)
# np.allclose로 원본과 복원된 신호가 수치적으로 거의 동일한지 확인
is_reconstructed = np.allclose(signal, reconstructed_signal.real)
print(f"신호가 성공적으로 복원되었는가? {is_reconstructed}")
```
**결과 분석:**
*   왼쪽 그래프는 시간에 따라 출렁이는 복잡한 파형을 보여줍니다. 이 그래프만으로는 어떤 주파수가 섞여 있는지 알기 어렵습니다.
*   오른쪽 그래프(주파수 스펙트럼)는 명확하게 **7Hz**와 **30Hz**에서 높은 피크(peak)를 보여줍니다. 이는 원본 신호가 주로 7Hz와 30Hz의 사인파로 구성되어 있음을 의미합니다.
*   `np.fft.ifft`를 통해 변환된 주파수 데이터를 다시 시간 영역으로 완벽하게 복원할 수 있음을 `np.allclose` 결과(`True`)로 확인할 수 있습니다.

### 1.2. 2D 푸리에 변환 (이미지 처리)

2D 푸리에 변환은 1D 변환을 2차원으로 확장한 것으로, 주로 이미지 분석 및 처리에 사용됩니다. 이미지를 공간 주파수(spatial frequencies)의 합으로 분해하여, 이미지의 전반적인 밝기, 부드러운 영역, 그리고 날카로운 경계선과 같은 세부 정보를 분리하여 분석할 수 있게 해줍니다.

#### 공간 주파수(Spatial Frequencies)의 의미

*   **저주파(Low Frequencies)**: 이미지에서 색상이나 밝기가 서서히 변하는 영역을 나타냅니다. (예: 하늘, 벽, 부드러운 피부). 주파수 스펙트럼에서는 **중앙**에 위치합니다.
*   **고주파(High Frequencies)**: 색상이나 밝기가 급격하게 변하는 영역, 즉 **경계선(edge), 노이즈, 질감(texture)** 등을 나타냅니다. 주파수 스펙트럼에서는 **가장자리**에 위치합니다.

#### 핵심 함수

*   `np.fft.fft2(a)`: 2차원 배열(이미지)에 대해 2D FFT를 수행합니다.
*   `np.fft.ifft2(a)`: 2D FFT 결과를 다시 이미지로 복원합니다.
*   `np.fft.fftshift(a)`: `fft2`의 결과에서 (0,0)에 위치한 0-주파수 성분(DC component)을 배열의 **중앙**으로 이동시킵니다. 이는 주파수 스펙트럼을 시각적으로 분석하기 쉽게 만들어 줍니다.
*   `np.fft.ifftshift(a)`: `fftshift`로 이동된 스펙트럼을 다시 원래의 (0,0) 위치로 되돌립니다. 역변환(`ifft2`)을 수행하기 전에 반드시 적용해야 합니다.

#### 예제: 2D FFT를 이용한 이미지 필터링 (Low-pass Filter)

아래 예제는 이미지의 푸리에 변환을 수행한 후, 고주파 성분을 제거(Low-pass filter)하여 이미지를 부드럽게(blur) 만드는 과정을 보여줍니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 간단한 2D 이미지 생성 (중앙에 흰 사각형)
image = np.zeros((200, 200), dtype=np.float32)
image[75:125, 75:125] = 1

# 2. 2D 푸리에 변환 및 시프트
fft_image = np.fft.fft2(image)
fft_shifted = np.fft.fftshift(fft_image)

# 3. 주파수 스펙트럼 시각화
# 스펙트럼은 값의 범위가 매우 크므로 로그 스케일을 적용하여 시각화
magnitude_spectrum = np.log(1 + np.abs(fft_shifted))

# 4. 필터 생성 (Low-pass Filter)
# 중앙을 통과시키는 원형 마스크를 생성하여 고주파를 차단
rows, cols = image.shape
crow, ccol = rows // 2 , cols // 2
radius = 20
y, x = np.ogrid[-crow:rows-crow, -ccol:cols-ccol]
mask = x*x + y*y <= radius*radius

# 5. 필터 적용
# 마스크를 곱하여 고주파 성분 제거
fft_filtered = fft_shifted * mask

# 6. 역변환을 통한 이미지 복원
# 다시 0-주파수를 코너로 이동
fft_ishifted = np.fft.ifftshift(fft_filtered)
# 시간 영역으로 역변환
reconstructed_image = np.fft.ifft2(fft_ishifted)
# 실수 부분만 취함
reconstructed_image = np.abs(reconstructed_image)

# 7. 결과 시각화
plt.figure(figsize=(18, 6))
plt.subplot(1, 4, 1), plt.imshow(image, cmap='gray'), plt.title('Original Image'), plt.axis('off')
plt.subplot(1, 4, 2), plt.imshow(magnitude_spectrum, cmap='gray'), plt.title('Magnitude Spectrum'), plt.axis('off')
plt.subplot(1, 4, 3), plt.imshow(np.log(1 + np.abs(fft_filtered)), cmap='gray'), plt.title('Filtered Spectrum'), plt.axis('off')
plt.subplot(1, 4, 4), plt.imshow(reconstructed_image, cmap='gray'), plt.title('Reconstructed Image (Blurred)'), plt.axis('off')
plt.show()
```
**결과 분석:**
*   **Magnitude Spectrum**: 중앙에 밝은 점(저주파)과 십자 모양의 선(사각형 경계의 주파수 성분)이 나타납니다.
*   **Filtered Spectrum**: 원형 마스크를 곱하여 중앙의 저주파 성분만 남기고 가장자리의 고주파 성분은 제거했습니다.
*   **Reconstructed Image**: 고주파 성분이 제거된 스펙트럼을 다시 이미지로 복원하니, 사각형의 날카로운 경계선이 사라지고 전체적으로 부드러워진(흐릿해진) 이미지가 생성되었습니다. 이 원리를 이용하여 이미지 블러링이나 노이즈 제거 필터를 구현할 수 있습니다.

## 2. 데이터 모델링: 다항식 피팅 (Polynomial Fitting)

`np.polyfit`은 주어진 데이터를 가장 잘 근사하는 다항식의 계수를 찾아 데이터의 추세를 모델링하는 데 사용됩니다.

### 2.1. 과소적합과 과적합 (Underfitting & Overfitting)

다항식 피팅에서 모델의 성능과 일반화 능력을 결정하는 가장 중요한 요소는 **다항식의 차수(degree)**입니다. 차수를 어떻게 선택하느냐에 따라 모델은 데이터의 경향을 너무 단순하게 해석하거나(과소적합), 데이터의 노이즈까지 과도하게 학습하는(과적합) 문제를 겪을 수 있습니다.

#### 과소적합 (Underfitting)

*   **정의**: 모델이 너무 단순하여 데이터에 내재된 실제 패턴이나 추세를 제대로 포착하지 못하는 상태입니다.
*   **원인**: 일반적으로 다항식의 차수를 너무 낮게 설정했을 때 발생합니다.
*   **특징**:
    *   모델이 데이터의 복잡성을 따라가지 못합니다.
    *   학습 데이터에 대한 성능(정확도)과 테스트 데이터에 대한 성능이 모두 낮게 나타납니다. (높은 편향, High Bias)
*   **예시**: 곡선 형태의 데이터 분포를 직선(1차 다항식)으로 근사하려는 경우.

#### 과적합 (Overfitting)

*   **정의**: 모델이 너무 복잡하여 데이터의 실제 추세를 넘어, 학습 데이터에만 존재하는 무작위적인 노이즈(noise)까지 학습해버린 상태입니다.
*   **원인**: 다항식의 차수를 데이터의 복잡도에 비해 너무 높게 설정했을 때 발생합니다.
*   **특징**:
    *   학습 데이터에 대해서는 거의 완벽에 가까운 성능을 보입니다.
    *   하지만 학습에 사용되지 않은 새로운 데이터(테스트 데이터)에 대해서는 예측 성능이 급격히 떨어집니다. 즉, 일반화(generalization) 능력이 부족합니다. (높은 분산, High Variance)
*   **예시**: 약간의 오차를 포함하는 2차 곡선 형태의 데이터를 모든 점을 통과하는 15차 다항식으로 근사하려는 경우.

#### 예제: 차수에 따른 모델 성능 비교

아래 예제는 동일한 데이터에 대해 세 가지 다른 차수의 다항식을 피팅하여 과소적합, 적절한 적합, 과적합의 차이를 시각적으로 보여줍니다.

```python
import numpy as np
import matplotlib.pyplot as plt

# 1. 데이터 생성: 2차 함수 형태에 노이즈 추가
np.random.seed(42)
x = np.linspace(-5, 5, 100)
y_true = 0.5 * x**2 - 2 * x + 1
y_noisy = y_true + np.random.randn(100) * 2

# 2. 차수별 다항식 피팅
# 1차 다항식 (직선) -> 과소적합 예상
coeffs_underfit = np.polyfit(x, y_noisy, 1)
poly_under = np.poly1d(coeffs_underfit)

# 2차 다항식 (포물선) -> 적절한 적합 예상
coeffs_goodfit = np.polyfit(x, y_noisy, 2)
poly_good = np.poly1d(coeffs_goodfit)

# 15차 다항식 -> 과적합 예상
coeffs_overfit = np.polyfit(x, y_noisy, 15)
poly_over = np.poly1d(coeffs_overfit)

# 3. 결과 시각화
plt.figure(figsize=(12, 7))
plt.scatter(x, y_noisy, label='Original Noisy Data', alpha=0.5, s=20)
plt.plot(x, y_true, 'k--', label='True Trend (Underlying Function)')
plt.plot(x, poly_under(x), 'r-', label='Underfit (degree=1)')
plt.plot(x, poly_good(x), 'g-', linewidth=3, label='Good Fit (degree=2)')
plt.plot(x, poly_over(x), 'm--', label='Overfit (degree=15)')

plt.legend()
plt.ylim(-10, 30)
plt.title('Underfitting vs. Good Fit vs. Overfitting')
plt.show()
```
**결과 분석:**
*   **Underfit (빨간색 실선)**: 1차 다항식(직선)은 데이터의 전반적인 U자형 패턴을 전혀 따라가지 못합니다.
*   **Good Fit (초록색 굵은 실선)**: 2차 다항식은 데이터에 숨겨진 실제 추세(검은색 점선)를 매우 잘 근사합니다.
*   **Overfit (자주색 점선)**: 15차 다항식은 학습 데이터의 거의 모든 점을 통과하기 위해 매우 심하게 구불거리며, 이는 실제 추세가 아닌 노이즈에 과도하게 반응한 결과입니다. 이 모델은 이 데이터 범위 밖의 새로운 점을 예측하는 데 매우 부정확할 것입니다.

### 2.2. 새로운 `numpy.polynomial` API

전통적인 `np.polyfit`과 `np.poly1d` 함수들은 사용이 간편하지만, 수치적으로 불안정할 수 있으며 기능이 제한적입니다. 최신 NumPy에서는 이러한 단점을 보완한 `numpy.polynomial` 패키지 사용을 강력히 권장합니다. 이 패키지는 다항식을 객체로 다루어 더 안정적이고 일관성 있으며, 풍부한 기능을 제공합니다.

#### `Polynomial` 클래스

`numpy.polynomial`의 핵심은 `Polynomial` 클래스입니다. 이 클래스의 인스턴스는 하나의 다항식 모델을 나타냅니다.

*   **계수 순서**: `np.poly1d`와 가장 큰 차이점은 계수의 순서입니다. `Polynomial` 클래스는 **오름차순(ascending power)**으로 계수를 다룹니다. 즉, `Polynomial([c0, c1, c2])`는 $c_0 + c_1x + c_2x^2$를 의미합니다.

#### 주요 기능 및 사용법

1.  **`Polynomial.fit(x, y, deg)`**: 데이터를 피팅하여 최적의 계수를 가진 `Polynomial` 객체를 반환합니다. `np.polyfit` + `np.poly1d` 과정을 한 번에 수행하는 것과 같습니다.
2.  **객체를 함수처럼 사용**: 생성된 `Polynomial` 객체 `p`는 `p(x)`와 같이 함수처럼 호출하여 특정 `x`값에 대한 다항식의 결과(y)를 계산할 수 있습니다.
3.  **다양한 메서드**: 미분(`.deriv()`), 적분(`.integ()`), 근 구하기(`.roots()`) 등 다항식과 관련된 다양한 수학적 연산을 메서드로 제공합니다.

#### 예제: `Polynomial.fit`을 이용한 데이터 피팅 및 분석

```python
from numpy.polynomial import Polynomial

# 2.1 예제의 x, y_noisy 데이터를 그대로 사용
x = np.linspace(-5, 5, 100)
y_true = 0.5 * x**2 - 2 * x + 1
y_noisy = y_true + np.random.randn(100) * 2

# 1. Polynomial.fit으로 2차 다항식 피팅
# x, y 데이터에 가장 적합한 2차 다항식 모델 객체를 생성합니다.
p_fit = Polynomial.fit(x, y_noisy, 2)
print(f"피팅된 다항식 모델:\n{p_fit}")
print(f"\n피팅된 계수 (c0, c1, c2): {p_fit.convert().coef}")

# 2. 피팅된 다항식을 이용한 예측 및 시각화
plt.figure(figsize=(10, 6))
plt.scatter(x, y_noisy, label='Original Data', alpha=0.4)
plt.plot(x, p_fit(x), 'b--', label='Fitted Polynomial (New API)')
plt.title('Polynomial Fitting with numpy.polynomial')
plt.legend()
plt.show()

# 3. 다항식의 근(roots) 찾기
# p_fit(x) = 0 을 만족하는 x 값들을 찾습니다.
roots = p_fit.roots()
print(f"\n다항식의 근: {roots}")

# 4. 다항식 미분
# 1차 도함수를 구합니다.
p_deriv = p_fit.deriv()
print(f"1차 도함수: {p_deriv}")

# 도함수의 근은 원본 다항식의 극점(최소/최대) 위치에 해당합니다.
critical_point = p_deriv.roots()[0]
print(f"다항식의 극점 x좌표: {critical_point:.4f}")
```
**결과 분석:**
*   `Polynomial.fit`은 데이터에 가장 적합한 `Polynomial` 객체를 직접 반환하여 코드가 더 간결하고 객체지향적입니다.
*   생성된 객체는 피팅된 다항식 자체를 의미하며, `.roots()`, `.deriv()`와 같은 다양한 내장 메서드를 통해 피팅된 모델을 더 깊이 있게 분석할 수 있습니다. 이는 단순 계수 배열만 반환하는 `np.polyfit`에 비해 큰 장점입니다.

## 3. 신호 처리: 컨볼루션 및 상관 (Convolution and Correlation)

컨볼루션(Convolution)과 상관(Correlation)은 신호 처리, 이미지 처리, 통계학 등 다양한 분야에서 데이터의 패턴을 분석하고, 특징을 추출하며, 필터링하는 데 사용되는 핵심적인 수학적 연산입니다. NumPy는 이러한 연산을 효율적으로 수행하는 함수를 제공합니다.

### 3.1. 컨볼루션 (`np.convolve`)

컨볼루션은 두 개의 1차원 배열(신호 또는 필터)을 결합하여 새로운 배열을 생성하는 연산입니다. 한 배열을 뒤집은 후 다른 배열 위로 이동시키면서 요소별 곱셈을 수행하고 그 결과를 합산합니다. 이는 이동 평균, 신호 평활화, 필터링 등에 활용됩니다.

**핵심 함수:**
*   `np.convolve(a, v, mode='full')`: 두 1차원 배열 `a`와 `v`의 컨볼루션을 계산합니다.
    *   `mode`:
        *   `'full'` (기본값): 컨볼루션의 모든 지점을 계산합니다. 출력 크기는 `len(a) + len(v) - 1`입니다.
        *   `'valid'`: 컨볼루션의 모든 지점이 두 배열의 모든 요소와 겹치는 부분만 계산합니다. 출력 크기는 `max(len(a), len(v)) - min(len(a), len(v)) + 1`입니다.
        *   `'same'`: 출력 크기가 `a`와 동일하게 중앙에 맞춰집니다.

**예시 1: 신호 평활화 (Moving Average Filter)**
```python
import numpy as np
import matplotlib.pyplot as plt

# 노이즈가 포함된 신호 생성
np.random.seed(42)
signal = np.sin(np.linspace(0, 10, 100)) + np.random.normal(0, 0.5, 100)

# 이동 평균 필터 (커널) 생성
# 3개의 점을 평균내는 필터
kernel = np.ones(3) / 3

# 컨볼루션 적용 (신호 평활화)
smoothed_signal = np.convolve(signal, kernel, mode='valid')

plt.figure(figsize=(10, 5))
plt.plot(signal, label='Original Signal with Noise')
plt.plot(smoothed_signal, label='Smoothed Signal (np.convolve)', linewidth=2)
plt.title('Signal Smoothing using np.convolve')
plt.xlabel('Time Point')
plt.ylabel('Amplitude')
plt.legend()
plt.grid(True)
plt.show()
```
**설명:**
`np.convolve`를 사용하여 노이즈가 있는 신호를 이동 평균 필터로 평활화했습니다. `mode='valid'`는 필터가 신호의 모든 부분과 완전히 겹칠 때만 결과를 계산합니다.

**결과 분석:**
원본 신호의 노이즈가 제거되고 부드러워진 형태를 확인할 수 있습니다.

**예시 2: 엣지 검출 (Edge Detection)**
```python
import numpy as np

# 간단한 1D 이미지 (계단형 엣지)
image_1d = np.array([0, 0, 0, 1, 1, 1, 0, 0, 0])

# 엣지 검출 필터 (미분 필터)
edge_kernel = np.array([-1, 1])

# 컨볼루션 적용
edges = np.convolve(image_1d, edge_kernel, mode='valid')
print(f"원본 1D 이미지: {image_1d}")
print(f"엣지 검출 결과: {edges}")
```
**설명:**
`[-1, 1]` 필터는 인접한 픽셀 값의 차이를 계산하여 엣지(값이 급변하는 지점)를 검출합니다.

**결과:**
```
원본 1D 이미지: [0 0 0 1 1 1 0 0 0]
엣지 검출 결과: [ 0  0  1  0  0 -1  0  0]
```

### 3.2. 상관 (`np.correlate`)

상관(Correlation)은 두 신호가 얼마나 유사한지, 그리고 한 신호가 다른 신호에 대해 얼마나 지연되어 있는지(위상차)를 측정하는 연산입니다. 컨볼루션과 유사하지만, 필터를 뒤집지 않고 그대로 이동시키면서 곱합을 수행합니다. 패턴 매칭, 시간 지연 추정 등에 활용됩니다.

**핵심 함수:**
*   `np.correlate(a, v, mode='full')`: 두 1차원 배열 `a`와 `v`의 상관을 계산합니다. `mode` 인자는 `np.convolve`와 동일하게 작동합니다.

**예시 1: 패턴 매칭 (Template Matching)**
```python
import numpy as np
import matplotlib.pyplot as plt

# 긴 신호 (데이터)
long_signal = np.array([0, 0, 1, 2, 3, 2, 1, 0, 0, 0, 5, 6, 7, 6, 5, 0, 0])

# 찾고자 하는 짧은 패턴 (템플릿)
template = np.array([1, 2, 3, 2, 1])

# 상관 연산 수행
# mode='valid'를 사용하여 템플릿이 완전히 겹치는 부분만 계산
correlation_result = np.correlate(long_signal, template, mode='valid')

print(f"긴 신호: {long_signal}")
print(f"패턴: {template}")
print(f"상관 결과: {correlation_result}")

# 결과 시각화
plt.figure(figsize=(10, 5))
plt.plot(long_signal, label='Long Signal')
plt.plot(np.arange(len(correlation_result)) + (len(template) - 1) / 2, correlation_result, 'o-', label='Correlation Result')
plt.title('Pattern Matching using np.correlate')
plt.xlabel('Index')
plt.ylabel('Correlation Value')
plt.legend()
plt.grid(True)
plt.show()
```
**설명:**
`np.correlate`를 사용하여 긴 신호 내에서 특정 패턴이 나타나는 위치를 찾습니다. 상관 값이 높을수록 패턴과 신호가 유사하다는 의미입니다.

**결과 분석:**
그래프에서 상관 결과의 피크가 나타나는 지점이 긴 신호 내에서 템플릿과 유사한 패턴이 있는 위치임을 보여줍니다.

**예시 2: 시간 지연 추정 (Time Delay Estimation)**
```python
import numpy as np

# 원본 신호
signal_orig = np.array([0, 1, 2, 3, 4, 5, 4, 3, 2, 1, 0])

# 원본 신호를 3칸 지연시킨 신호 (노이즈 추가)
signal_delayed = np.array([0, 0, 0, 0, 1, 2, 3, 4, 5, 4, 3, 2, 1, 0]) + np.random.normal(0, 0.1, 14)

# 두 신호 간의 상관 계산
# mode='full'을 사용하여 모든 가능한 지연에 대한 상관 값을 계산
correlation_full = np.correlate(signal_orig, signal_delayed, mode='full')

# 상관 결과의 최대값이 나타나는 인덱스 찾기
# 이 인덱스는 두 신호 간의 상대적인 지연을 나타냅니다.
delay_index = np.argmax(correlation_full)
# 실제 지연은 (delay_index - (len(signal_orig) - 1))
estimated_delay = delay_index - (len(signal_orig) - 1)

print(f"원본 신호 길이: {len(signal_orig)}")
print(f"지연된 신호 길이: {len(signal_delayed)}")
print(f"상관 결과 배열 길이: {len(correlation_full)}")
print(f"상관 결과:\n{correlation_full}")
print(f"최대 상관 값 인덱스: {delay_index}")
print(f"추정된 시간 지연: {estimated_delay} (양수: signal_delayed가 signal_orig보다 뒤에 있음)")
```
**설명:**
두 신호 간의 상관을 계산하여, 한 신호가 다른 신호에 대해 얼마나 지연되어 있는지 추정합니다. 상관 결과의 최대값이 나타나는 지점이 가장 유사한 패턴을 보이는 지연 시간입니다.

**결과 분석:**
`estimated_delay` 값이 두 신호 간의 실제 지연 시간과 일치함을 확인할 수 있습니다.

## 4. 데이터 보간 (Data Interpolation)

데이터 보간(Interpolation)은 알려진 데이터 포인트들 사이의 중간 값을 추정하는 과정입니다. 이는 데이터에 누락된 값이 있거나, 불규칙한 간격의 데이터를 규칙적인 간격으로 변환해야 할 때 매우 유용합니다. NumPy는 1차원 선형 보간을 위한 `np.interp` 함수를 제공합니다.

**핵심 함수:**
*   `np.interp(x, xp, fp, left=None, right=None)`: 1차원 선형 보간을 수행합니다.
    *   `x`: 보간할 새로운 x 좌표(또는 값)들.
    *   `xp`: 알려진 데이터 포인트의 x 좌표(오름차순 정렬되어야 함).
    *   `fp`: 알려진 데이터 포인트의 y 좌표(xp에 대응하는 값).
    *   `left`: `x`가 `xp`의 최소값보다 작을 때 반환할 값. 기본값은 `fp[0]`입니다.
    *   `right`: `x`가 `xp`의 최대값보다 클 때 반환할 값. 기본값은 `fp[-1]`입니다.

**예시 1: 누락된 값 채우기 (선형 보간)**
```python
import numpy as np
import matplotlib.pyplot as plt

# 원본 데이터 (일부 누락된 값 시뮬레이션)
# x_known: 알려진 데이터 포인트의 x 좌표
# y_known: 알려진 데이터 포인트의 y 좌표
x_known = np.array([0, 1, 3, 4, 6, 7, 9])
y_known = np.array([0, 2, 1, 3, 5, 4, 6])

# 보간할 새로운 x 좌표 (누락된 지점 포함)
x_new = np.arange(10) # 0부터 9까지의 정수

# np.interp를 사용하여 선형 보간 수행
y_interpolated = np.interp(x_new, x_known, y_known)

print(f"알려진 x 좌표: {x_known}")
print(f"알려진 y 좌표: {y_known}")
print(f"보간할 새 x 좌표: {x_new}")
print(f"보간된 y 값: {y_interpolated}")

# 결과 시각화
plt.figure(figsize=(10, 6))
plt.plot(x_known, y_known, 'o', label='Known Data Points')
plt.plot(x_new, y_interpolated, 'x-', label='Interpolated Data Points')
plt.title('Linear Interpolation using np.interp')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.legend()
plt.grid(True)
plt.show()
```
**설명:**
`np.interp`는 `x_known`과 `y_known`으로 정의된 선을 따라 `x_new`에 해당하는 `y` 값을 선형적으로 추정합니다.

**결과 분석:**
그래프에서 알려진 데이터 포인트들 사이의 누락된 값들이 선형적으로 채워진 것을 확인할 수 있습니다.

**예시 2: 데이터 리샘플링 (Resampling)**
```python
import numpy as np
import matplotlib.pyplot as plt

# 원본 데이터 (불규칙한 간격)
x_original = np.array([0, 0.5, 1.2, 2.5, 3.0, 4.1, 5.0])
y_original = np.array([0, 0.8, 1.5, 2.0, 1.8, 1.0, 0.5])

# 규칙적인 간격의 새로운 x 좌표 생성
x_resampled = np.linspace(0, 5, 50) # 0부터 5까지 50개의 균등 간격 점

# np.interp를 사용하여 리샘플링
y_resampled = np.interp(x_resampled, x_original, y_original)

print(f"원본 x 좌표: {x_original}")
print(f"원본 y 좌표: {y_original}")
print(f"리샘플링된 x 좌표 (일부): {x_resampled[:5]} ... {x_resampled[-5:]}")
print(f"리샘플링된 y 값 (일부): {y_resampled[:5]} ... {y_resampled[-5:]}")

# 결과 시각화
plt.figure(figsize=(10, 6))
plt.plot(x_original, y_original, 'o--', label='Original Data (Irregular)')
plt.plot(x_resampled, y_resampled, '-', label='Resampled Data (Regular)')
plt.title('Data Resampling using np.interp')
plt.xlabel('X-axis')
plt.ylabel('Y-axis')
plt.legend()
plt.grid(True)
plt.show()
```
**설명:**
