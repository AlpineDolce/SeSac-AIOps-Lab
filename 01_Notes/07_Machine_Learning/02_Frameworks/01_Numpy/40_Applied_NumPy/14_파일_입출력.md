## 1. NumPy 바이너리 파일: `.npy`

NumPy 배열을 디스크에 저장하는 가장 표준적이고 효율적인 방법은 NumPy 고유의 바이너리 포맷인 `.npy` 파일을 사용하는 것입니다. 이 방식은 `np.save()` 함수로 배열을 저장하고 `np.load()` 함수로 불러오는 간단한 과정을 통해 이루어집니다.

### `.npy` 포맷의 특징

*   **효율성**: `.npy` 파일은 데이터를 압축하지 않은 순수한 바이너리 형태로 저장합니다. 이로 인해 텍스트 파일(예: CSV)보다 훨씬 빠르게 읽고 쓸 수 있으며, 파일 크기도 작습니다.
*   **정보 보존**: 배열의 데이터뿐만 아니라, 배열의 형상(`shape`), 데이터 타입(`dtype`), 스트라이드(strides)와 같은 모든 핵심 메타데이터가 파일에 함께 저장됩니다. 따라서 파일을 불러왔을 때 원본 NumPy 배열이 완벽하게 복원됩니다.
*   **플랫폼 독립성**: `.npy` 파일은 시스템 아키텍처(예: 윈도우, 리눅스, macOS)에 관계없이 동일하게 작동하여 데이터 공유에 용이합니다.

### `np.save()`: 단일 배열 저장하기

`np.save(file, arr, allow_pickle=True, fix_imports=True)` 함수는 단일 배열을 `.npy` 파일로 저장합니다.

*   **`file`**: 파일 경로. 일반적으로 `.npy` 확장자를 사용하지만, 명시하지 않아도 자동으로 추가됩니다.
*   **`arr`**: 저장할 NumPy 배열.
*   **`allow_pickle`**: 객체 배열(object array)을 저장할 때 피클링(pickling)을 허용할지 여부. 보안상의 이유로 신뢰할 수 없는 소스로부터 데이터를 로드할 때는 `False`로 설정하는 것이 안전합니다.

### `np.load()`: `.npy` 파일 불러오기

`np.load(file, mmap_mode=None, allow_pickle=False, fix_imports=True, encoding='ASCII')` 함수는 `.npy` (또는 `.npz`) 파일에서 배열 데이터를 불러옵니다.

*   **`file`**: 불러올 파일 경로.
*   **`mmap_mode`**: 메모리 매핑 모드. 대용량 파일을 다룰 때 유용하며, 자세한 내용은 [4. 대용량 배열을 위한 메모리 매핑](#4-대용량-배열을-위한-메모리-매핑-npmemmap) 섹션에서 다룹니다.
*   **`allow_pickle`**: `.npy` 파일이 피클링된 객체 데이터를 포함할 경우, 이를 로드할지 여부. 기본값은 `False`로, 보안을 위해 신뢰할 수 없는 파일에 대해서는 `True`로 설정하지 않는 것이 좋습니다.

### 사용 예제

다음은 배열을 생성하고, `.npy` 파일로 저장한 뒤, 다시 불러와 원본과 동일한지 확인하는 전체 과정입니다.

```python
import numpy as np
import os

# 1. 저장할 배열 생성
original_array = np.array([[1.5, 2.0, 3.8], [4.1, 5.9, 6.3]], dtype=np.float32)
print(f"원본 배열:\n{original_array}")
print(f"원본 배열의 형상: {original_array.shape}")
print(f"원본 배열의 데이터 타입: {original_array.dtype}")

# 2. 파일 이름 지정 및 저장
# 파일 확장자 .npy는 자동으로 추가됩니다.
file_path = 'my_first_array' 
np.save(file_path, original_array)
print(f"\n배열이 '{file_path}.npy' 파일로 저장되었습니다.")

# 3. 저장된 파일 로드
# np.load()는 파일 경로에 자동으로 .npy를 추가하여 파일을 찾습니다.
loaded_array = np.load(f'{file_path}.npy')
print(f"\n불러온 배열:\n{loaded_array}")
print(f"불러온 배열의 형상: {loaded_array.shape}")
print(f"불러온 배열의 데이터 타입: {loaded_array.dtype}")

# 4. 원본과 로드된 배열의 동일성 검증
# np.array_equal()은 두 배열의 형상과 요소가 모두 동일한지 확인합니다.
are_equal = np.array_equal(original_array, loaded_array)
print(f"\n원본 배열과 불러온 배열이 동일한가? {are_equal}")

# 5. 파일 덮어쓰기
# np.save()는 동일한 이름의 파일이 있으면 경고 없이 덮어씁니다.
new_array = np.arange(5)
print(f"\n새로운 배열로 덮어쓰기: {new_array}")
np.save(file_path, new_array)
reloaded_array = np.load(f'{file_path}.npy')
print(f"덮어쓴 후 다시 불러온 배열: {reloaded_array}")

# 6. 예제 실행 후 생성된 파일 삭제
os.remove(f'{file_path}.npy')
print(f"\n'{file_path}.npy' 파일이 삭제되었습니다.")
```

## 2. 여러 배열 저장하기: `.npz`

여러 개의 NumPy 배열을 하나의 파일에 묶어서 저장해야 할 때 `.npz` 포맷을 사용합니다. `.npz` 파일은 본질적으로 여러 `.npy` 파일을 하나로 묶은 압축되지 않은 아카이브(archive)이며, 각 배열은 고유한 키(이름)를 가집니다.

### `np.savez()`: 여러 배열 저장하기

`np.savez(file, *args, **kwds)` 함수는 여러 배열을 하나의 `.npz` 파일로 저장합니다.

*   **`file`**: 저장할 파일 경로. `.npz` 확장자가 자동으로 추가됩니다.
*   **`*args`**: 이름 없이 배열을 전달하면, NumPy는 자동으로 `arr_0`, `arr_1`, ... 와 같은 기본 키를 부여합니다.
*   **`**kwds`**: `이름=배열` 형태의 키워드 인자로 전달하면, 해당 이름이 배열의 키가 됩니다. **이 방식이 더 명시적이므로 권장됩니다.**

### `np.savez_compressed()`: 압축하여 저장하기

`np.savez_compressed(file, *args, **kwds)` 함수는 `np.savez()`와 동일한 방식으로 작동하지만, 데이터를 **압축**하여 저장합니다.

*   **장점**: 디스크 공간을 크게 절약할 수 있습니다. 특히 내용이 반복적이거나 희소(sparse)한 배열에서 효과적입니다.
*   **단점**: 파일을 읽고 쓸 때 압축 및 압축 해제 과정이 추가되므로 약간의 시간이 더 소요될 수 있습니다.

### `.npz` 파일 불러오기 및 데이터 접근

`np.load()` 함수는 `.npz` 파일을 불러오는 데에도 사용됩니다. `.npz` 파일을 로드하면 `NpzFile`이라는 특수한 객체가 반환됩니다.

*   **Lazy Loading**: `NpzFile` 객체는 파일을 열 때 모든 배열을 메모리로 읽어들이지 않습니다. 대신, 딕셔너리처럼 특정 키로 배열을 요청할 때 해당 배열만 메모리로 로드합니다. 이를 **지연 로딩(Lazy Loading)**이라고 하며, 대용량 `.npz` 파일을 다룰 때 메모리를 효율적으로 사용하는 데 도움이 됩니다.
*   **데이터 접근**: 딕셔너리와 유사하게 `loaded_data['키']` 형식으로 각 배열에 접근할 수 있습니다.
*   **자원 관리**: `NpzFile` 객체는 파일 핸들러를 열어두므로, 사용이 끝나면 `.close()` 메서드를 호출하여 명시적으로 닫아주거나, `with` 구문을 사용하여 자동으로 자원이 해제되도록 하는 것이 좋습니다.

### 사용 예제

```python
import numpy as np
import os

# 1. 저장할 여러 종류의 배열 생성
array_int = np.arange(10)
array_float = np.linspace(0, 1, 5) # 0과 1 사이를 5등분한 배열
array_str = np.array([['apple', 'banana'], ['cherry', 'date']])

print(f"저장할 정수 배열:\n{array_int}")
print(f"저장할 실수 배열:\n{array_float}")
print(f"저장할 문자열 배열:\n{array_str}")

# 2. np.savez()를 사용하여 키워드 인자로 저장
npz_path = 'my_archive.npz'
np.savez(npz_path, integers=array_int, floats=array_float, strings=array_str)
print(f"\n배열들이 '{npz_path}' 파일로 저장되었습니다.")

# 3. np.load()로 .npz 파일 불러오기 (with 구문 사용 권장)
with np.load(npz_path) as loaded_archive:
    print(f"\n저장된 배열의 키: {loaded_archive.files}")

    # 키를 사용하여 각 배열 데이터에 접근
    loaded_int = loaded_archive['integers']
    loaded_float = loaded_archive['floats']
    loaded_str = loaded_archive['strings']

    print(f"\n불러온 정수 배열:\n{loaded_int}")
    print(f"불러온 실수 배열:\n{loaded_float}")
    print(f"불러온 문자열 배열:\n{loaded_str}")

    # 원본과 동일한지 검증
    assert np.array_equal(array_int, loaded_int)
    assert np.array_equal(array_float, loaded_float)
    assert np.array_equal(array_str, loaded_str)
    print("\n모든 원본 배열과 불러온 배열이 동일함을 확인했습니다.")

# 4. np.savez_compressed()로 압축 저장하고 크기 비교
compressed_npz_path = 'my_archive_compressed.npz'
np.savez_compressed(compressed_npz_path, integers=array_int, floats=array_float, strings=array_str)
print(f"\n배열들이 '{compressed_npz_path}' 파일로 압축 저장되었습니다.")

# 파일 크기 비교
uncompressed_size = os.path.getsize(npz_path)
compressed_size = os.path.getsize(compressed_npz_path)
print(f"일반 .npz 파일 크기: {uncompressed_size} bytes")
print(f"압축 .npz 파일 크기: {compressed_size} bytes")

# 5. 예제 실행 후 생성된 파일 삭제
os.remove(npz_path)
os.remove(compressed_npz_path)
print(f"\n생성된 .npz 파일들을 삭제했습니다.")
```

## 3. 텍스트 파일 입출력

NumPy는 `.npy`나 `.npz` 같은 바이너리 포맷 외에도, 사람이 직접 읽고 수정할 수 있는 텍스트 파일 형식(예: CSV, TSV)으로 데이터를 저장하고 불러오는 기능을 제공합니다. 이는 다른 소프트웨어(예: Excel, R, Pandas)와 데이터를 주고받거나, 간단한 데이터를 직접 확인해야 할 때 유용합니다.

**장점:**
*   **가독성**: 메모장이나 Excel 같은 프로그램으로 쉽게 열어볼 수 있습니다.
*   **범용성**: 대부분의 데이터 분석 도구에서 지원하는 표준적인 형식입니다.

**단점:**
*   **효율성**: 바이너리 포맷에 비해 파일 크기가 크고, 읽고 쓰는 속도가 현저히 느립니다.
*   **정밀도 손실**: 부동 소수점(float) 데이터를 텍스트로 변환하는 과정에서 정밀도(precision)가 일부 손실될 수 있습니다.
*   **정보 손실**: 배열의 `shape`나 `dtype` 같은 메타데이터는 저장되지 않으므로, 불러올 때 명시적으로 지정해야 할 수 있습니다.

### `np.savetxt()`: 배열을 텍스트 파일로 저장하기

`np.savetxt(fname, X, fmt='%.18e', delimiter=' ', newline='\n', header='', footer='', comments='# ')` 함수는 배열을 텍스트 파일로 저장합니다.

*   **`fname`**: 저장할 파일 경로.
*   **`X`**: 저장할 1D 또는 2D 배열.
*   **`fmt`**: 데이터 포맷 지정자. `%d` (정수), `%.2f` (소수점 둘째 자리까지의 실수), `%s` (문자열) 등 C 스타일 포맷을 따릅니다.
*   **`delimiter`**: 각 열을 구분할 문자 (구분자). 쉼표(`,`)를 사용하면 CSV 파일이 됩니다.
*   **`header`**: 파일의 첫 줄에 추가할 문자열 (주석 처리됨).
*   **`footer`**: 파일의 마지막 줄에 추가할 문자열 (주석 처리됨).
*   **`comments`**: `header`와 `footer`의 각 줄 앞에 붙일 문자. 기본값은 `# `입니다.

### `np.loadtxt()`: 텍스트 파일에서 데이터 불러오기

`np.loadtxt(fname, dtype=<class 'float'>, comments='#', delimiter=None, skiprows=0, usecols=None)` 함수는 텍스트 파일에서 데이터를 읽어 배열을 생성합니다.

*   **`fname`**: 불러올 파일 경로.
*   **`dtype`**: 반환될 배열의 데이터 타입. 기본값은 `float`입니다.
*   **`comments`**: 주석으로 처리할 문자를 지정합니다. 이 문자로 시작하는 줄은 무시됩니다.
*   **`delimiter`**: 각 열을 구분하는 문자.
*   **`skiprows`**: 파일의 시작 부분에서 건너뛸 줄의 수. 헤더가 있는 파일을 읽을 때 유용합니다.
*   **`usecols`**: 읽어올 열(column)을 지정하는 정수 또는 튜플. (예: `usecols=(0, 2)`는 첫 번째와 세 번째 열만 읽어옵니다.)

### 사용 예제

```python
import numpy as np
import os

# 1. 저장할 2D 배열 생성
arr = np.arange(12, dtype=np.int32).reshape(3, 4)
print(f"저장할 배열:\n{arr}")

txt_path = 'my_data.csv'
# 2. np.savetxt()로 CSV 파일 저장
# 헤더를 추가하고, 각 열은 쉼표로 구분하며, 정수 형식으로 저장합니다.
header_info = 'col1, col2, col3, col4'
np.savetxt(txt_path, arr, fmt='%d', delimiter=',', header=header_info, comments='')
# comments=''로 설정하여 헤더에 '#'가 붙지 않도록 합니다.

print(f"\n배열이 '{txt_path}' 파일로 저장되었습니다.")
# 파일 내용을 직접 확인해 보세요.

# 3. np.loadtxt()로 데이터 불러오기
# skiprows=1로 설정하여 헤더를 건너뜁니다.
# dtype을 int로 지정하여 정수 배열로 불러옵니다.
loaded_from_txt = np.loadtxt(txt_path, dtype=np.int32, delimiter=',', skiprows=1)
print(f"\n'{txt_path}'에서 불러온 배열:\n{loaded_from_txt}")

# 4. 특정 열만 선택하여 불러오기
# usecols를 사용하여 첫 번째(0)와 세 번째(2) 열만 불러옵니다.
partial_cols = np.loadtxt(txt_path, dtype=np.int32, delimiter=',', skiprows=1, usecols=(0, 2))
print(f"\n첫 번째와 세 번째 열만 불러온 배열:\n{partial_cols}")

# 5. 예제 실행 후 생성된 파일 삭제
os.remove(txt_path)
print(f"\n'{txt_path}' 파일을 삭제했습니다.")
```


## 4. 대용량 배열을 위한 메모리 매핑 (`np.memmap`)

`np.memmap`은 NumPy에서 **RAM(메인 메모리)의 용량을 초과하는 매우 큰 배열을 처리**하기 위한 핵심 도구입니다. 디스크에 있는 파일을 메모리에 있는 배열처럼 취급하게 해주는 강력한 기능을 제공합니다.

### 4.1. 메모리 매핑이란?

메모리 매핑(Memory-mapping)은 파일의 내용을 메모리의 특정 주소 공간에 직접 연결(매핑)하는 운영체제의 기술입니다. NumPy의 `np.memmap`은 이 기술을 활용하여, 디스크 상의 파일을 마치 메모리에 전부 로드된 거대한 NumPy 배열인 것처럼 다룰 수 있게 해줍니다.

*   **동작 원리**: `np.memmap`으로 배열을 생성하면, NumPy는 실제로 배열 데이터 전체를 RAM으로 불러오지 않습니다. 대신, 배열의 특정 부분에 접근(예: 슬라이싱, 인덱싱)할 때 운영체제가 해당 부분의 데이터만 디스크에서 읽어와 RAM에 잠시 올려놓습니다. 배열의 내용을 수정하면, 이 변경 사항은 나중에 디스크 파일에 다시 기록됩니다.
*   **투명성**: 사용자는 이 모든 과정을 신경 쓸 필요 없이, 일반적인 NumPy 배열을 다루는 것과 동일한 방식으로 코드를 작성할 수 있습니다.

### 4.2. `np.memmap` 사용법

`np.memmap(filename, dtype=float, mode='r+', offset=0, shape=None, order='C')` 함수를 사용하여 메모리 매핑된 배열을 생성합니다.

*   **`filename`**: 디스크에 저장될 파일의 경로.
*   **`dtype`**: 배열의 데이터 타입.
*   **`shape`**: 배열의 형상(shape). 새 파일을 생성할 때 반드시 지정해야 합니다.
*   **`mode`**: 파일 접근 모드.
    *   `'r'`: 읽기 전용 (Read-only).
    *   `'c'`: 복사-후-쓰기 (Copy-on-write). 배열을 수정하면 변경 사항이 메모리에만 반영되고 원본 파일에는 영향을 주지 않습니다.
    *   `'r+'`: 읽기 및 쓰기 (Read-plus). 파일이 반드시 존재해야 하며, 변경 사항은 디스크의 원본 파일에 직접 반영됩니다.
    *   `'w+'`: 읽기 및 쓰기 (Write-plus). 파일이 존재하면 덮어쓰고, 없으면 새로 생성합니다.
*   **`offset`**: 파일 시작 지점으로부터 데이터가 시작될 위치(바이트 단위). 헤더가 있는 파일 등을 다룰 때 유용합니다.

### 4.3. 언제 사용해야 하는가?

1.  **RAM보다 큰 데이터셋 처리**: 분석하려는 데이터가 RAM 용량보다 커서 한 번에 불러올 수 없을 때 `np.memmap`은 거의 유일한 해결책입니다. 수십, 수백 GB의 데이터라도 슬라이싱과 인덱싱을 통해 효율적으로 접근하고 처리할 수 있습니다.
2.  **프로세스 간 데이터 공유 (IPC)**: 여러 파이썬 프로세스가 동일한 `np.memmap` 파일을 공유하여 데이터를 읽고 쓸 수 있습니다. 이는 데이터를 복사하는 비용 없이 대용량 정보를 공유할 수 있어, 병렬 처리(multiprocessing) 작업에 매우 효과적입니다.

### 4.4. `memmap` 사용 시 주의사항

*   **`flush()` 호출**: `mode`가 `'r+'` 또는 `'w+'`일 때, 배열의 내용을 변경해도 즉시 디스크에 쓰이지 않을 수 있습니다. 운영체제는 효율성을 위해 쓰기 작업을 버퍼링하기 때문입니다. 변경 사항을 반드시 디스크에 기록하려면 `memmap_array.flush()` 메서드를 명시적으로 호출해야 합니다.
*   **데이터 타입과 형상**: 기존 `memmap` 파일을 열 때는, 파일을 생성할 때 사용했던 `dtype`과 `shape`을 정확히 동일하게 지정해야 합니다. 정보가 일치하지 않으면 데이터를 잘못 해석하게 됩니다.
*   **자원 관리**: `memmap` 객체에 대한 참조가 사라져도 디스크의 파일은 자동으로 삭제되지 않습니다. 파일이 더 이상 필요 없다면 `os.remove()` 등을 통해 직접 삭제해야 합니다.

### 사용 예제

```python
import numpy as np
import os

mmap_path = 'large_dataset.mmap'
# 1GB 크기의 가상 데이터셋을 위한 형상과 타입 정의 (float64: 8 bytes)
# 125,000 * 1000 * 8 bytes = 1,000,000,000 bytes = 1 GB
data_shape = (125_000, 1000) 
data_dtype = np.float64

# 예제 실행 전, 혹시 파일이 남아있으면 삭제
if os.path.exists(mmap_path):
    os.remove(mmap_path)

# 1. 'w+' 모드로 파일 생성 및 데이터 쓰기
# 이 시점에 디스크에 1GB 크기의 파일이 생성됩니다.
print(f"'{mmap_path}' 파일 생성 중...")
mmap_writer = np.memmap(mmap_path, dtype=data_dtype, mode='w+', shape=data_shape)
print("파일 생성 완료.")

# 대용량 파일의 일부에만 접근하여 데이터 쓰기
print("파일의 일부에 데이터 쓰는 중...")
# 첫 번째 행에 0부터 999까지의 숫자를 씀
mmap_writer[0, :] = np.arange(data_shape[1])
# 5000번째 행에 5000을 씀
mmap_writer[5000, :] = 5000

# 변경 사항을 디스크에 확실히 기록
mmap_writer.flush()
print("데이터 쓰기 및 flush 완료.")

# 2. 'r' 모드로 파일 읽기
# 읽기 전용 모드로 파일을 열어 데이터를 확인합니다.
print("\n읽기 전용 모드로 파일 열기...")
mmap_reader = np.memmap(mmap_path, dtype=data_dtype, mode='r', shape=data_shape)

# 전체를 로드하지 않고 특정 부분만 읽어오는지 확인
print(f"첫 번째 행의 첫 5개 요소: {mmap_reader[0, :5]}")
print(f"5000번째 행의 첫 5개 요소: {mmap_reader[5000, :5]}")
assert mmap_reader[5000, 100] == 5000
print("데이터 읽기 확인 완료.")

# 3. 'r+' 모드로 파일 수정
print("\n읽기/쓰기 모드로 파일 열어 데이터 수정...")
mmap_modifier = np.memmap(mmap_path, dtype=data_dtype, mode='r+', shape=data_shape)
mmap_modifier[0, 0] = -999

mmap_modifier.flush()
print("데이터 수정 및 flush 완료.")

# 수정된 내용 확인
print(f"수정 후 첫 번째 행의 첫 5개 요소: {mmap_reader[0, :5]}")
assert mmap_reader[0, 0] == -999
print("데이터 수정 확인 완료.")

# 4. 객체 참조 삭제 및 파일 삭제
del mmap_writer, mmap_reader, mmap_modifier
os.remove(mmap_path)
print(f"\n'{mmap_path}' 파일이 삭제되었습니다.")
```
