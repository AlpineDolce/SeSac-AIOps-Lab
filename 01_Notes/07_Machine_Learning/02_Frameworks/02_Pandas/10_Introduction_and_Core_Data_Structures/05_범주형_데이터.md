## 1. 범주형 데이터(Categorical Data)란?

데이터 분석에서 데이터의 종류를 이해하는 것은 매우 중요합니다. 그중 '범주형 데이터(Categorical Data)'는 특정 분석 및 저장 방식에 최적화되어 있어 효율적인 데이터 처리를 가능하게 합니다. Pandas의 `CategoricalDtype`은 이러한 범주형 데이터를 효율적으로 저장하고 처리하기 위한 특별한 데이터 타입입니다.

### 1.1. 범주형 데이터의 정의

범주형 데이터는 **제한된 수의 고유한 값(범주, categories)**을 가지는 데이터를 의미합니다. 이 고유한 값들은 반복적으로 나타나며, 각 값은 특정 그룹이나 분류를 나타냅니다.

*   **예시**:
    *   **성별**: 남, 여
    *   **학년**: 1학년, 2학년, 3학년, 4학년
    *   **지역**: 서울, 부산, 대구, 제주
    *   **만족도**: 매우 불만족, 불만족, 보통, 만족, 매우 만족

### 1.2. 범주형 데이터의 종류

범주형 데이터는 범주들 사이에 순서가 있는지 여부에 따라 크게 두 가지로 나눌 수 있습니다.

*   **명목형 (Nominal Categorical Data)**:
    *   **특징**: 범주들 사이에 어떠한 순서나 등급도 존재하지 않는 데이터입니다. 단순히 서로 다른 그룹을 구분하는 역할을 합니다.
    *   **예시**: 성별, 혈액형(A, B, AB, O), 도시, 국적, 제품 유형.
    *   **활용**: 주로 빈도 분석, 그룹별 통계 등에 사용됩니다.

*   **순서형 (Ordinal Categorical Data)**:
    *   **특징**: 범주들 사이에 명확한 순서나 등급이 존재하는 데이터입니다. 범주 간의 상대적인 크기나 중요도를 나타낼 수 있습니다.
    *   **예시**: 학년(초급 < 중급 < 고급), 만족도(매우 불만족 < 불만족 < 보통 < 만족 < 매우 만족), 옷 사이즈(S < M < L < XL).
    *   **활용**: 순서에 기반한 정렬, 비교 연산 등에 사용됩니다.

### 1.3. 왜 범주형 데이터를 사용해야 하는가?

Pandas에서 범주형 데이터 타입을 사용하는 것은 여러 가지 중요한 이점을 제공하며, 특히 대규모 데이터셋을 다룰 때 그 효과가 두드러집니다.

*   **메모리 효율성**:
    *   **원리**: 고유한 값이 적고 반복되는 문자열 데이터가 많은 경우, Pandas는 각 고유한 문자열을 한 번만 저장하고, Series 내에서는 해당 문자열에 대한 정수형 코드(인덱스)를 저장합니다.
    *   **장점**: 각 문자열을 개별적으로 저장하는 대신 정수형 코드로 매핑하여 메모리 사용량을 크게 줄일 수 있습니다. 이는 수백만 행 이상의 대규모 데이터셋에서 수십 배 이상의 메모리 절약 효과를 가져올 수 있습니다.
    *   **예시**: '서울'이라는 문자열이 100만 번 반복될 때, 문자열로 저장하면 100만 * (문자열 길이 + 오버헤드)의 메모리가 필요하지만, 범주형으로 저장하면 '서울'이라는 문자열 자체는 한 번만 저장되고, Series 내에는 100만 개의 작은 정수 코드만 저장됩니다.

*   **연산 성능**:
    *   **원리**: Pandas는 범주형 데이터의 내부 정수 코드를 활용하여 일부 연산을 최적화합니다.
    *   **장점**: 그룹화(`groupby()`), 정렬(`sort_values()`), 병합(`merge()`)과 같은 연산에서 범주형 데이터는 일반 문자열 데이터보다 훨씬 빠르게 처리될 수 있습니다. 이는 내부적으로 문자열 비교 대신 정수 비교를 수행하기 때문입니다.

*   **데이터 유효성 및 일관성**:
    *   **원리**: 범주형 데이터는 유효한 범주(categories) 목록을 명시적으로 지정할 수 있습니다.
    *   **장점**: 데이터 입력 오류를 방지하고, 데이터의 일관성을 유지할 수 있습니다. 예를 들어, 성별 컬럼에 '남', '여' 외의 '남자', '여자' 또는 오타가 들어오는 것을 사전에 방지하거나 쉽게 식별할 수 있습니다.

*   **머신러닝 모델과의 호환성**:
    *   **원리**: 많은 머신러닝 알고리즘은 숫자형 데이터를 입력으로 받습니다. 범주형 데이터는 내부적으로 정수 코드로 저장되므로, 원-핫 인코딩(One-Hot Encoding)이나 레이블 인코딩(Label Encoding)과 같은 전처리 과정에서 효율적으로 활용될 수 있습니다.
    *   **장점**: 일부 머신러닝 라이브러리(예: Scikit-learn의 일부 모델)는 범주형 데이터를 직접 처리할 수 있어 추가적인 전처리 단계를 줄일 수 있습니다.

## 2. 범주형 데이터 생성

Pandas에서 범주형 데이터를 생성하는 방법은 다양하며, 데이터의 특성과 사용 목적에 따라 적절한 방법을 선택하는 것이 중요합니다. 가장 일반적인 방법은 기존 Series나 DataFrame 컬럼의 `dtype`을 `'category'`로 변환하는 것입니다.

### 2.1. `astype('category')`를 이용한 변환

`astype('category')`는 기존 Series나 DataFrame 컬럼을 범주형으로 변환하는 가장 간단하고 일반적인 방법입니다. 이 방법은 데이터에 있는 고유한 값들을 자동으로 범주로 인식합니다.

**핵심 개념**: `astype('category')`는 데이터에 존재하는 고유한 값들을 자동으로 범주(categories)로 인식하여 범주형 타입으로 변환합니다. 이 과정에서 각 고유값은 내부적으로 정수형 코드로 매핑됩니다.

**메모리 사용량 비교 예시**:

```python
import pandas as pd
import numpy as np

# 대규모 문자열 Series 생성
s_str_large = pd.Series(['apple', 'banana', 'cherry', 'date'] * 250000) # 100만개 데이터
print(f"원본 문자열 Series (dtype: {s_str_large.dtype}):")
print(s_str_large.head())
print(f"메모리 사용량 (object): {s_str_large.memory_usage(deep=True) / (1024**2):.2f} MB")

# 범주형으로 변환
s_cat_large = s_str_large.astype('category')
print(f"\n범주형 Series (dtype: {s_cat_large.dtype}):")
print(s_cat_large.head())
print(f"메모리 사용량 (category): {s_cat_large.memory_usage(deep=True) / (1024**2):.2f} MB")
```
**결과 분석**: 위 예시에서 볼 수 있듯이, `astype('category')`를 통해 문자열 Series를 범주형으로 변환하면 메모리 사용량이 **수십 배 이상** 줄어드는 것을 확인할 수 있습니다. 이는 대규모 데이터셋에서 메모리 효율성을 극대화하는 핵심 방법입니다.

**`astype('category')`의 특징 및 활용**

-   **자동 범주 인식**: 데이터에 존재하는 모든 고유한 값들을 자동으로 범주로 설정합니다.
-   **순서 없음 (기본)**: 이 방법으로 생성된 범주형 데이터는 기본적으로 순서가 없는(unordered) 명목형 범주로 간주됩니다. 순서가 필요한 경우 `ordered=True` 옵션을 사용하거나 `pd.Categorical()`을 명시적으로 사용해야 합니다.
-   **간단한 문법**: 기존 컬럼의 타입을 변경하는 가장 직관적인 방법입니다.

```python
# Series 변환 예시
s_str = pd.Series(['서울', '부산', '서울', '대구', '부산', '서울'])
print(f"\n원본 Series (dtype: {s_str.dtype}):\n{s_str}")

s_category = s_str.astype('category')
print(f"\n범주형 Series (dtype: {s_category.dtype}):\n{s_category}")
print(f"범주: {s_category.cat.categories}") # Series에 존재하는 고유한 값들이 범주가 됨
print(f"코드: {s_category.cat.codes}") # 내부적으로 매핑된 정수 코드 (알파벳 순서로 매핑)

# DataFrame 컬럼 변환 예시
df = pd.DataFrame({
    'City': ['서울', '부산', '서울', '대구', '부산'],
    'Sales': [100, 150, 120, 80, 130]
})
print(f"\n원본 DataFrame:\n{df}")
print(f"원본 'City' 컬럼 dtype: {df['City'].dtype}")

df['City'] = df['City'].astype('category')
print(f"\n'City' 컬럼 범주형 변환 후 DataFrame:\n{df}")
print(f"변환 후 'City' 컬럼 dtype: {df['City'].dtype}")
```
이 방법은 데이터에 이미 모든 범주가 포함되어 있고, 순서가 중요하지 않은 경우에 특히 유용합니다.


### 2.2. `pd.Categorical`을 이용한 명시적 생성

`pd.Categorical()` 함수를 사용하면 데이터와 함께 범주(categories)를 명시적으로 지정하여 범주형 객체를 생성할 수 있습니다. 이는 데이터에는 나타나지 않지만 분석에 포함되어야 하는 범주가 있거나, 범주의 순서를 직접 제어해야 할 때 유용합니다.

```python
import pandas as pd

# 데이터에 없는 범주를 포함하여 생성
data = ['A', 'B', 'A', 'C']
categories = ['A', 'B', 'C', 'D'] # 'D'는 데이터에 없지만 범주에 포함

# pd.Categorical 객체 직접 생성
cat_obj = pd.Categorical(data, categories=categories)
print(f"pd.Categorical 객체:\n{cat_obj}")
print(f"범주: {cat_obj.categories}") # 명시적으로 지정된 모든 범주 포함
print(f"코드: {cat_obj.codes}") # 데이터에 해당하는 값만 정수 코드로 매핑, 없는 범주는 -1

# pd.Categorical 객체로부터 Series 생성
s_cat_explicit = pd.Series(cat_obj)
print(f"\n명시적 범주형 Series:\n{s_cat_explicit}")
print(f"범주: {s_cat_explicit.cat.categories}")
print(f"코드: {s_cat_explicit.cat.codes}")
```
`pd.Categorical()`을 사용하면 데이터의 유효한 범주를 미리 정의하여 데이터 일관성을 강화할 수 있습니다.

### 2.3. 순서가 있는 범주형 데이터

범주형 데이터는 순서가 있을 수도 있고 없을 수도 있습니다. 학년(초급, 중급, 고급)이나 만족도(매우 불만족, 불만족, 보통, 만족, 매우 만족)와 같이 범주들 사이에 명확한 순서가 존재하는 경우 `ordered=True`를 설정하여 순서형 범주(Ordinal Categorical Data)로 지정할 수 있습니다. 이는 정렬이나 비교 연산에 영향을 미칩니다.

```python
import pandas as pd

data = ['중', '하', '상', '중']
levels = ['하', '중', '상'] # 순서를 명시적으로 지정 (가장 낮은 레벨부터 높은 레벨 순으로)

# 순서가 있는 범주형 Series 생성
ordered_cat = pd.Categorical(data, categories=levels, ordered=True)
s_ordered = pd.Series(ordered_cat)

print(f"순서가 있는 범주형 Series:\n{s_ordered}")
print(f"순서 여부: {s_ordered.cat.ordered}") # True
print(f"범주: {s_ordered.cat.categories}") # 정의된 순서대로 출력

# 순서에 따른 비교 연산
print(f"\n'중'보다 큰 값 (s_ordered > '중'):\n{s_ordered > '중'}") # '상'만 True
print(f"'하'와 같거나 큰 값 (s_ordered >= '하'):\n{s_ordered >= '하'}") # 모든 값 True
```
순서형 범주를 사용하면 데이터의 의미를 더 정확하게 반영하고, 순서 기반의 연산을 올바르게 수행할 수 있습니다.

### 2.4. 기존 범주형 Series에 새로운 범주 추가

이미 생성된 범주형 Series에 새로운 범주를 추가해야 할 때 `add_categories()` 메서드를 사용합니다. 이 메서드는 새로운 범주를 기존 범주 목록에 추가하지만, Series의 값 자체를 변경하지는 않습니다. 새로운 범주에 해당하는 값을 Series에 할당하면 해당 범주가 자동으로 인식됩니다.

```python
import pandas as pd

s = pd.Series(['A', 'B', 'C']).astype('category')
print(f"원본 Series:\n{s}")
print(f"원본 범주: {s.cat.categories}")

# 새로운 범주 'D' 추가
# add_categories()는 새로운 Series를 반환하므로, 결과를 다시 할당해야 합니다.
s_new_cat = s.cat.add_categories('D')
print(f"\n'D' 범주 추가 후 Series (값은 그대로):\n", s_new_cat)
print(f"새로운 범주: {s_new_cat.cat.categories}")

# Series 값에 새로운 범주에 해당하는 값을 할당하면 자동으로 변환됨
# s_new_cat에 'D' 범주가 추가되었으므로, 이제 'D' 값을 할당할 수 있습니다.
s_new_cat.loc[0] = 'D' # 'A'를 'D'로 변경
print(f"\n값 변경 후 Series:\n", s_new_cat)
print(f"변경 후 범주: {s_new_cat.cat.categories}")
```
`add_categories()` 외에도 `remove_categories()`, `rename_categories()`, `set_categories()` 등 다양한 메서드를 통해 범주를 관리할 수 있습니다.

### 2.5. `factorize()`를 이용한 효율적인 인코딩

`pd.factorize()`는 범주형 데이터를 숫자형으로 효율적으로 인코딩하는 저수준(low-level) 함수입니다. 특히 고유한 값이 많은(high cardinality) 범주형 데이터를 처리할 때 `astype('category')`보다 더 직접적이고 빠른 인코딩 방법을 제공할 수 있습니다.

**주요 특징:**
*   **정수형 코드와 고유값 배열 반환**: `factorize()`는 두 개의 NumPy 배열을 반환합니다. 첫 번째는 각 원본 값에 매핑된 정수형 코드(labels)이고, 두 번째는 고유한 원본 값들의 배열(uniques)입니다.
*   **성능 효율성**: 내부적으로 최적화되어 있어 대규모 데이터셋에서 매우 빠르게 작동합니다.
*   **순서 유지**: 기본적으로 원본 데이터에 나타나는 순서대로 고유값에 정수 코드를 할당합니다.

```python
import pandas as pd
import numpy as np

# 예시 데이터
data = pd.Series(['apple', 'orange', 'apple', 'banana', 'orange', 'apple'])
print("원본 Series:\n", data)

# factorize()를 이용한 인코딩
labels, uniques = pd.factorize(data)

print("\n인코딩된 정수형 코드 (labels):\n", labels)
print("고유한 값들 (uniques):\n", uniques)

# DataFrame에 적용 예시
df_factorize = pd.DataFrame({
    'Product': ['Laptop', 'Mouse', 'Keyboard', 'Laptop', 'Mouse'],
    'Region': ['East', 'West', 'East', 'North', 'West']
})
print("\n원본 DataFrame:\n", df_factorize)

# 'Product' 컬럼을 factorize
df_factorize['Product_Encoded'], product_uniques = pd.factorize(df_factorize['Product'])
print("\n'Product' 인코딩 후:\n", df_factorize)
print("Product 고유값:", product_uniques)

# 'Region' 컬럼을 factorize
df_factorize['Region_Encoded'], region_uniques = pd.factorize(df_factorize['Region'])
print("\n'Region' 인코딩 후:\n", df_factorize)
print("Region 고유값:", region_uniques)
```

**`factorize()` vs `astype('category')` vs `LabelEncoder`:**
*   **`astype('category')`**: Pandas의 `CategoricalDtype`을 사용하여 메모리 효율성을 높이고 특정 Pandas 연산의 성능을 향상시킵니다. 내부적으로 정수 코드를 사용하지만, `Series` 자체의 `dtype`을 변경합니다.
*   **`pd.factorize()`**: `Series`의 `dtype`을 변경하지 않고, 정수형 코드와 고유값 배열을 직접 반환합니다. 특히 머신러닝 모델의 입력으로 숫자형 데이터가 필요할 때 유용합니다.
*   **`sklearn.preprocessing.LabelEncoder`**: Scikit-learn의 `LabelEncoder`는 `fit()`과 `transform()` 메서드를 사용하여 범주형 데이터를 숫자형으로 변환합니다. `factorize()`와 유사한 목적을 가지지만, `LabelEncoder`는 클래스(객체)를 생성하고 관리해야 합니다.

`factorize()`는 특히 대규모 범주형 데이터를 빠르게 숫자형으로 변환해야 할 때 유용한 도구입니다.

## 3. 범주형 데이터 활용

범주형 데이터는 메모리 효율성, 연산 성능, 데이터 유효성 검사 등 다양한 측면에서 이점을 제공합니다.

### 3.1. 메모리 사용량 최적화

문자열 데이터가 반복될 때 범주형으로 변환하면 메모리 사용량을 크게 줄일 수 있습니다. 이는 특히 수백만 행 이상의 대규모 데이터셋에서 중요합니다.

```python
import pandas as pd
import numpy as np

# 100만 개의 반복되는 문자열 데이터 생성
np.random.seed(42)
colors = np.random.choice(['red', 'green', 'blue', 'yellow'], size=1_000_000)
s_str = pd.Series(colors)

# 문자열 Series의 메모리 사용량
print(f"문자열 Series 메모리 사용량: {s_str.memory_usage(deep=True) / (1024**2):.2f} MB")

# 범주형으로 변환 후 메모리 사용량
s_cat = s_str.astype('category')
print(f"범주형 Series 메모리 사용량: {s_cat.memory_usage(deep=True) / (1024**2):.2f} MB")

# DataFrame 컬럼의 메모리 사용량 비교
df_str = pd.DataFrame({'color': s_str, 'value': np.random.rand(1_000_000)})
df_cat = pd.DataFrame({'color': s_cat, 'value': np.random.rand(1_000_000)})

print(f"\n문자열 컬럼 포함 DataFrame 메모리 사용량: {df_str.memory_usage(deep=True).sum() / (1024**2):.2f} MB")
print(f"범주형 컬럼 포함 DataFrame 메모리 사용량: {df_cat.memory_usage(deep=True).sum() / (1024**2):.2f} MB")
```

### 3.2. 연산 성능 향상

그룹화(`groupby()`)나 정렬(`sort_values()`)과 같은 일부 연산에서 범주형 데이터는 내부적으로 정수 코드를 사용하므로 일반 문자열보다 더 빠르게 처리될 수 있습니다.

```python
import pandas as pd
import numpy as np
import time

np.random.seed(42)
data_size = 1_000_000

# 반복되는 문자열 데이터와 숫자 데이터 생성
colors = np.random.choice(['red', 'green', 'blue', 'yellow'], size=data_size)
values = np.random.rand(data_size)

df_str = pd.DataFrame({'color': colors, 'value': values})
df_cat = df_str.copy()
df_cat['color'] = df_cat['color'].astype('category')

print(f"데이터 크기: {data_size} 행")

# 문자열 컬럼으로 그룹화 및 합계 계산
start_time = time.time()
df_str.groupby('color')['value'].sum()
end_time = time.time()
print(f"문자열 그룹화 시간: {end_time - start_time:.4f} 초")

# 범주형 컬럼으로 그룹화 및 합계 계산
start_time = time.time()
df_cat.groupby('color')['value'].sum()
end_time = time.time()
print(f"범주형 그룹화 시간: {end_time - start_time:.4f} 초")
```

### 3.3. 범주 추가/삭제 및 이름 변경

범주형 Series의 `.cat` 접근자를 통해 범주를 관리할 수 있습니다. `add_categories()`, `remove_categories()`, `rename_categories()`, `remove_unused_categories()`, `set_categories()` 등의 메서드를 사용합니다.

```python
import pandas as pd

s = pd.Series(['A', 'B', 'C']).astype('category')
print(f"원본 Series:\n{s}")
print(f"원본 범주: {s.cat.categories}")

# 범주 추가
s_added = s.cat.add_categories(['D', 'E'])
print(f"\n범주 'D', 'E' 추가 후: {s_added.cat.categories}")

# 범주 삭제 (데이터에 없는 범주만 삭제 가능)
s_removed = s_added.cat.remove_categories(['E'])
print(f"\n범주 'E' 삭제 후: {s_removed.cat.categories}")

# 사용되지 않는 범주 삭제
s_unused = pd.Series(['X', 'Y']).astype(pd.CategoricalDtype(['X', 'Y', 'Z']))
print(f"\n사용되지 않는 범주 포함 Series:\n{s_unused}")
print(f"원본 범주: {s_unused.cat.categories}")
s_cleaned = s_unused.cat.remove_unused_categories()
print(f"사용되지 않는 범주 삭제 후: {s_cleaned.cat.categories}")

# 범주 이름 변경
s_renamed = s.cat.rename_categories({'A': 'Alpha', 'B': 'Beta'})
print(f"\n범주 이름 변경 후: {s_renamed.cat.categories}")

# 범주 목록을 완전히 재설정 (순서 변경 및 새 범주 추가/삭제 가능)
s_set_cat = s.cat.set_categories(['C', 'A', 'B', 'F'], ordered=True)
print(f"\n범주 목록 재설정 후 (순서 변경 및 새 범주 추가):\n{s_set_cat}")
print(f"새로운 범주: {s_set_cat.cat.categories}")
print(f"순서 여부: {s_set_cat.cat.ordered}")
```

### 3.4. 그룹화 및 시각화

범주형 데이터는 `groupby()` 연산에 매우 효율적이며, 시각화 라이브러리(예: Seaborn)에서 자동으로 범주를 인식하여 적절한 플롯을 생성하는 데 도움을 줍니다.

```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

# 예시 데이터 생성
df = pd.DataFrame({
    'City': pd.Categorical(['Seoul', 'Busan', 'Seoul', 'Daegu', 'Busan'],
                           categories=['Seoul', 'Busan', 'Daegu', 'Jeju'], ordered=False),
    'Sales': [100, 150, 120, 80, 130]
})

print(f"원본 DataFrame:\n{df}")

# City별 Sales 합계 (그룹화)
city_sales = df.groupby('City')['Sales'].sum()
print(f"\n도시별 판매 합계:\n{city_sales}")

# 시각화 (Seaborn이 범주형 데이터를 자동으로 인식)
plt.figure(figsize=(8, 5))
sns.barplot(x='City', y='Sales', data=df, ci=None)
plt.title('Sales by City')
plt.show()
```

### 3.5. 범주형 데이터의 정렬

순서가 있는 범주형 데이터는 정의된 순서에 따라 정렬됩니다. 순서가 없는 범주형 데이터는 범주 이름의 알파벳 순서(또는 내부 코드 순서)로 정렬됩니다.

```python
import pandas as pd

# 순서가 없는 범주형 데이터 정렬
s_unordered = pd.Series(['C', 'A', 'B', 'A']).astype('category')
print(f"순서 없는 범주형 Series:\n{s_unordered}")
print(f"정렬 후 (알파벳 순):\n{s_unordered.sort_values()}")

# 순서가 있는 범주형 데이터 정렬
data = ['중', '하', '상', '중']
levels = ['하', '중', '상']
s_ordered = pd.Series(pd.Categorical(data, categories=levels, ordered=True))
print(f"\n순서 있는 범주형 Series:\n{s_ordered}")
print(f"정렬 후 (정의된 순서):\n{s_ordered.sort_values()}")
```

### 3.6. 범주형 데이터와 결측치

범주형 데이터는 결측치(`NaN`)를 포함할 수 있습니다. `NaN`은 유효한 범주로 간주되지 않으며, `dropna()`나 `fillna()`와 같은 메서드를 통해 처리할 수 있습니다.

```python
import pandas as pd
import numpy as np

s_cat_nan = pd.Series(['A', 'B', np.nan, 'A', 'C']).astype('category')
print(f"결측치 포함 범주형 Series:\n{s_cat_nan}")
print(f"범주: {s_cat_nan.cat.categories}")

# 결측치 제거
s_dropna = s_cat_nan.dropna()
print(f"\n결측치 제거 후:\n{s_dropna}")

# 결측치 채우기
s_fillna = s_cat_nan.fillna('Unknown') # 'Unknown'은 새로운 범주로 추가됨
print(f"\n결측치 'Unknown'으로 채운 후:\n{s_fillna}")
print(f"새로운 범주: {s_fillna.cat.categories}")
```

### 3.7. 범주형 데이터를 이용한 필터링

범주형 데이터를 사용하여 데이터를 필터링하는 것은 일반 문자열이나 숫자 데이터와 유사하게 수행할 수 있습니다. `isin()` 메서드를 활용하면 여러 범주에 해당하는 데이터를 쉽게 선택할 수 있습니다.

```python
import pandas as pd

df = pd.DataFrame({
    'Product': pd.Categorical(['A', 'B', 'A', 'C', 'B', 'A']),
    'Region': pd.Categorical(['East', 'West', 'East', 'North', 'South', 'East']),
    'Sales': [100, 150, 120, 80, 130, 110]
})
print(f"원본 DataFrame:\n{df}")

# 특정 범주에 해당하는 행 필터링
df_filtered_product_A = df[df['Product'] == 'A']
print(f"\nProduct가 'A'인 행:\n{df_filtered_product_A}")

# 여러 범주에 해당하는 행 필터링 (isin 사용)
df_filtered_region = df[df['Region'].isin(['East', 'North'])]
print(f"\nRegion이 'East' 또는 'North'인 행:\n{df_filtered_region}")

# 순서형 범주를 이용한 필터링
s_ordered_filter = pd.Series(['중', '하', '상', '중']).astype(pd.CategoricalDtype(['하', '중', '상'], ordered=True))
print(f"\n순서형 Series:\n{s_ordered_filter}")
print(f"값이 '중' 이상인 데이터:\n{s_ordered_filter[s_ordered_filter >= '중']}")
```

## 4. 요약 및 모범 사례

이 섹션에서는 범주형 데이터의 핵심 개념을 요약하고, 실제 데이터 분석 프로젝트에서 이를 효과적으로 사용하기 위한 모범 사례를 제시합니다.

### 4.1. 핵심 요약

*   **범주형 데이터란?**: 제한된 수의 고유한 값(범주)을 가지는 데이터로, **명목형(순서 없음)**과 **순서형(순서 있음)**으로 나뉩니다.
*   **주요 이점**:
    *   **메모리 최적화**: 반복되는 문자열을 정수 코드로 매핑하여 메모리 사용량을 크게 절감합니다.
    *   **성능 향상**: `groupby`, `sort_values` 등 특정 연산에서 문자열 비교 대신 정수 비교를 통해 속도를 높입니다.
    *   **데이터 일관성**: 유효한 범주를 명시적으로 정의하여 데이터 입력 오류를 방지하고 일관성을 유지합니다.
*   **생성 방법**:
    *   `astype('category')`: 가장 간단한 방법으로, 데이터의 고유값을 자동으로 범주로 인식합니다.
    *   `pd.Categorical()`: 범주와 순서를 명시적으로 지정하여 생성하며, 데이터에 없는 범주도 포함할 수 있습니다.
*   **핵심 기능**:
    *   `.cat` 접근자: `add_categories`, `remove_categories`, `rename_categories` 등 범주를 관리하는 다양한 메서드를 제공합니다.
    *   순서형 데이터는 정의된 순서에 따라 정렬 및 비교 연산이 가능합니다.

### 4.2. 모범 사례 권장 사항

1.  **언제 범주형 데이터를 사용해야 하는가?**
    *   **낮은 카디널리티(Low Cardinality) 컬럼**: 고유한 값의 개수가 전체 데이터 행 수에 비해 현저히 적은 컬럼에 적합합니다. (예: 성별, 지역, 제품 카테고리, 상태 코드)
    *   **문자열 데이터**: 메모리 사용량이 높은 문자열 컬럼을 변환하면 효과가 극대화됩니다.
    *   **논리적 순서가 있는 데이터**: 만족도, 등급, 단계 등 순서가 중요한 데이터는 `ordered=True`로 지정하여 의미를 명확히 하고 순서 기반 연산을 활성화하세요.

2.  **언제 사용을 피해야 하는가?**
    *   **높은 카디널리티(High Cardinality) 컬럼**: 고유한 값의 개수가 매우 많은 컬럼(예: 사용자 ID, 고유한 타임스탬프, 설명 텍스트)은 범주형으로 변환할 경우 오히려 메모리 및 성능에 부담을 줄 수 있습니다.

3.  **효과적인 사용 전략**
    *   **명시적 범주 정의**: 데이터에 모든 범주가 포함되지 않을 수 있는 경우, `pd.Categorical`이나 `cat.set_categories()`를 사용하여 분석에 필요한 모든 범주를 명시적으로 정의하는 것이 좋습니다. 이는 `groupby` 시 누락된 범주도 결과에 포함시키는 등 예측 가능한 분석을 보장합니다.
    *   **데이터 클리닝 후 변환**: 범주형으로 변환하기 전에 데이터 클리닝(오타 수정, 공백 제거 등)을 먼저 수행하여 불필요한 범주가 생성되는 것을 방지하세요.
    *   **메모리 사용량 확인**: 변환 전후에 `df.info()` 또는 `df.memory_usage(deep=True)`를 사용하여 메모리 절감 효과를 직접 확인하고, 변환의 타당성을 검토하세요.
    *   **체이닝(Chaining) 활용**: `.cat` 접근자의 메서드들은 대부분 새로운 객체를 반환하므로, 여러 연산을 연결하여 코드를 간결하게 작성할 수 있습니다. (예: `s.cat.remove_unused_categories().cat.rename_categories(...)`)
    *   **결측치 처리 전략**: 범주형 데이터의 결측치는 `NaN`으로 표시됩니다. 이를 특정 값으로 채우려면(`fillna`), 해당 값이 범주에 포함되어 있거나 `add_categories`를 통해 먼저 추가해야 합니다.

다음은 모범 사례를 적용한 예시입니다.

```python
import pandas as pd

# 원본 데이터
df = pd.DataFrame({
    'grade': ['Gold', 'Silver', 'Bronze', 'Gold', 'Silver', 'Gold '], # 'Gold '에 공백 포함
    'performance': [95, 85, 75, 91, 88, 98]
})

# 1. 데이터 클리닝 (공백 제거)
df['grade'] = df['grade'].str.strip()

# 2. 논리적 순서와 전체 범주를 명시적으로 정의
grade_levels = ['Bronze', 'Silver', 'Gold', 'Platinum'] # 'Platinum'은 데이터에 없음
df['grade'] = pd.Categorical(df['grade'], categories=grade_levels, ordered=True)

print("변환 후 DataFrame 정보:")
df.info()

# 3. 순서에 기반한 필터링
print("
'Silver' 등급 이상인 데이터:")
print(df[df['grade'] >= 'Silver'])

# 4. 그룹화 시 모든 범주 포함 (누락된 'Platinum'도 결과에 표시)
print("
등급별 평균 performance:")
print(df.groupby('grade')['performance'].mean())
```
