# PyTorch 현실적인 데이터 처리: 불균형 데이터셋 (Imbalanced Dataset) 다루기

## 1. 불균형 데이터셋 (Imbalanced Dataset)이란?

불균형 데이터셋은 머신러닝 및 딥러닝 문제에서 특정 클래스(소수 클래스, Minority Class)의 샘플 수가 다른 클래스(다수 클래스, Majority Class)의 샘플 수보다 현저히 적은 경우를 의미합니다. 이러한 불균형은 현실 세계의 다양한 문제에서 흔히 발생합니다.

**예시:**
*   **사기 탐지**: 정상 거래가 사기 거래보다 훨씬 많습니다.
*   **질병 진단**: 건강한 사람의 데이터가 특정 희귀 질병을 가진 환자의 데이터보다 압도적으로 많습니다.
*   **이상 탐지**: 정상적인 시스템 동작 데이터가 비정상적인 이상 징후 데이터보다 훨씬 많습니다.
*   **결함 예측**: 정상 제품이 불량 제품보다 훨씬 많습니다.

## 2. 불균형 데이터셋의 문제점

불균형 데이터셋은 모델 학습에 심각한 문제를 야기할 수 있습니다. 대부분의 머신러닝 알고리즘은 데이터셋의 클래스 분포가 균등하다고 가정하고 설계되었기 때문입니다.

### 2.1. 오해의 소지가 있는 정확도 (Misleading Accuracy)

모델이 단순히 다수 클래스만 예측하더라도 전체 정확도(Accuracy)는 매우 높게 나올 수 있습니다. 예를 들어, 99%가 정상 거래이고 1%가 사기 거래인 데이터셋에서 모델이 모든 거래를 정상으로 예측하면 정확도는 99%가 됩니다. 하지만 이 모델은 단 하나의 사기 거래도 탐지하지 못하므로 실제로는 전혀 쓸모가 없습니다.

### 2.2. 모델 편향 (Model Bias)

학습 알고리즘은 전체적인 오류를 최소화하는 방향으로 최적화됩니다. 불균형 데이터셋에서는 다수 클래스의 오류를 줄이는 것이 전체 오류를 줄이는 데 더 효과적이므로, 모델은 소수 클래스를 무시하고 다수 클래스에 편향되어 학습될 가능성이 높습니다. 결과적으로 소수 클래스에 대한 예측 성능이 매우 낮아집니다.

### 2.3. 일반화 성능 저하

모델이 소수 클래스의 특징을 충분히 학습하지 못하므로, 실제 환경에서 소수 클래스에 해당하는 새로운 데이터가 들어왔을 때 이를 올바르게 분류하지 못하는 일반화 성능 저하가 발생합니다.

## 3. 불균형 데이터셋 처리 전략

불균형 데이터셋을 다루는 전략은 크게 데이터 레벨 전략과 알고리즘 레벨 전략으로 나눌 수 있습니다.

### 3.1. 데이터 레벨 전략 (Data-level Strategies)

데이터 레벨 전략은 데이터셋 자체의 클래스 분포를 변경하여 균형을 맞추는 방법입니다.

#### 3.1.1. 오버샘플링 (Oversampling)

소수 클래스의 샘플 수를 늘려 다수 클래스와 균형을 맞추는 방법입니다.

*   **무작위 오버샘플링 (Random Oversampling)**: 소수 클래스의 샘플을 무작위로 복제하여 추가합니다. 가장 간단한 방법이지만, 동일한 샘플이 반복되어 과적합의 위험이 있습니다.
*   **SMOTE (Synthetic Minority Over-sampling Technique)**: 소수 클래스 샘플의 특징 공간에서 이웃 샘플들을 찾아 선형 보간(interpolation)을 통해 새로운 합성(synthetic) 샘플을 생성합니다. 무작위 복제보다 과적합 위험이 적고 더 다양한 샘플을 생성합니다.
*   **ADASYN (Adaptive Synthetic Sampling)**: SMOTE와 유사하지만, 학습하기 어려운(밀집도가 낮은) 소수 클래스 샘플에 더 많은 합성 샘플을 생성합니다.

#### 3.1.2. 언더샘플링 (Undersampling)

다수 클래스의 샘플 수를 줄여 소수 클래스와 균형을 맞추는 방법입니다.

*   **무작위 언더샘플링 (Random Undersampling)**: 다수 클래스의 샘플을 무작위로 제거합니다. 간단하지만, 중요한 정보가 손실될 수 있다는 단점이 있습니다.
*   **Tomek Links**: 서로 다른 클래스에 속하는 두 샘플이 가장 가까운 이웃이고, 이들 사이의 거리가 특정 임계값보다 작을 때 이 두 샘플을 Tomek Link라고 합니다. 다수 클래스에 속하는 Tomek Link 샘플을 제거하여 클래스 경계를 더 명확하게 합니다.
*   **Edited Nearest Neighbors (ENN)**: 다수 클래스 샘플 중, 그 샘플의 k-최근접 이웃(k-NN) 중 다수 클래스에 속하지 않는 샘플이 있다면 해당 다수 클래스 샘플을 제거합니다.

#### 3.1.3. 복합 샘플링 (Combined Sampling)

오버샘플링과 언더샘플링을 함께 사용하여 두 방법의 장점을 취하고 단점을 보완합니다. 예를 들어, SMOTE로 소수 클래스를 오버샘플링한 후, Tomek Links나 ENN으로 다수 클래스를 언더샘플링하여 노이즈를 제거하고 클래스 경계를 정리할 수 있습니다 (예: SMOTEENN).

### 3.2. 알고리즘 레벨 전략 (Algorithm-level Strategies)

알고리즘 레벨 전략은 데이터 분포를 직접 변경하지 않고, 모델 학습 알고리즘 자체를 수정하여 불균형 데이터셋에 더 잘 작동하도록 하는 방법입니다.

#### 3.2.1. 클래스 가중치 (Class Weights)

손실 함수(Loss Function)에서 소수 클래스에 더 높은 가중치를 부여하여, 모델이 소수 클래스를 잘못 분류했을 때 더 큰 페널티를 받도록 합니다. 이는 모델이 소수 클래스에 더 집중하여 학습하도록 유도합니다.

#### 3.2.2. 샘플링 가중치 (Sample Weights)

각 샘플에 가중치를 할당하고, `DataLoader`가 배치를 구성할 때 이 가중치를 고려하여 샘플링합니다. 소수 클래스 샘플에 더 높은 가중치를 부여하면, 해당 샘플이 배치에 포함될 확률이 높아집니다.

#### 3.2.3. 앙상블 기법 (Ensemble Methods)

여러 모델을 조합하여 예측 성능을 향상시키는 방법입니다. 불균형 데이터셋에서는 다음과 같은 앙상블 기법이 효과적일 수 있습니다.

*   **배깅 (Bagging)**: 다수 클래스를 여러 서브셋으로 나누고, 각 서브셋과 소수 클래스를 결합하여 여러 개의 균형 잡힌 데이터셋을 만듭니다. 각 데이터셋으로 모델을 학습시킨 후 예측을 결합합니다 (예: BalancedBaggingClassifier).
*   **부스팅 (Boosting)**: 잘못 분류된 샘플에 더 높은 가중치를 부여하여 다음 모델이 해당 샘플에 더 집중하도록 합니다 (예: AdaBoost, XGBoost).

#### 3.2.4. 이상치 탐지 (Anomaly Detection)

만약 소수 클래스가 실제로 '이상치'나 '희귀 이벤트'를 나타내는 경우, 일반적인 분류 문제로 접근하기보다 이상치 탐지(Anomaly Detection) 알고리즘(예: One-Class SVM, Isolation Forest)을 사용하는 것이 더 적절할 수 있습니다.

## 4. PyTorch에서의 구현

PyTorch에서는 `nn.CrossEntropyLoss`의 `weight` 파라미터나 `torch.utils.data.WeightedRandomSampler`를 사용하여 불균형 데이터셋을 처리할 수 있습니다.

### 4.1. 클래스 가중치 적용 (`nn.CrossEntropyLoss`)

`nn.CrossEntropyLoss`는 `weight` 인자를 통해 각 클래스에 대한 손실 가중치를 설정할 수 있습니다. 이 가중치는 일반적으로 각 클래스의 샘플 수에 반비례하게 설정합니다.

```python
import torch
import torch.nn as nn

# 예시: 2개 클래스 (클래스 0: 다수, 클래스 1: 소수)
# 실제 데이터셋에서 각 클래스의 샘플 수를 계산해야 합니다.
class_counts = torch.tensor([900, 100]) # 클래스 0이 900개, 클래스 1이 100개

# 각 클래스에 대한 가중치 계산 (총 샘플 수 / (클래스 수 * 해당 클래스 샘플 수))
# 또는 단순히 다수 클래스 샘플 수 / 소수 클래스 샘플 수 로 비율을 사용할 수도 있습니다.
total_samples = class_counts.sum().float()
num_classes = len(class_counts)

# 가중치 계산: N / (C * N_k) (N: 총 샘플 수, C: 클래스 수, N_k: k번째 클래스 샘플 수)
# 이 가중치는 손실 함수에서 해당 클래스의 기여도를 조절합니다.
class_weights = total_samples / (num_classes * class_counts.float())
print(f"Calculated Class Weights: {class_weights}") # Tensor([0.5556, 5.0000])

# 손실 함수에 클래스 가중치 적용
criterion = nn.CrossEntropyLoss(weight=class_weights)

# 학습 루프 내에서 사용 예시:
# outputs = model(inputs)
# loss = criterion(outputs, labels)
# loss.backward()
```

### 4.2. `WeightedRandomSampler` 활용

`WeightedRandomSampler`는 `DataLoader`와 함께 사용하여 각 샘플이 배치에 포함될 확률을 가중치에 따라 조절합니다. 소수 클래스 샘플에 더 높은 가중치를 부여하여 학습 시 더 자주 샘플링되도록 합니다.

```python
import torch
from torch.utils.data import Dataset, DataLoader, WeightedRandomSampler
from collections import Counter

# 사용자 정의 Dataset (이전 예시에서 사용한 CustomDataset을 가정)
class CustomDataset(Dataset):
    def __init__(self, data, labels):
        self.data = torch.tensor(data, dtype=torch.float32)
        self.labels = torch.tensor(labels, dtype=torch.long)

    def __len__(self):
        return len(self.labels)

    def __getitem__(self, idx):
        return self.data[idx], self.labels[idx]

# 불균형 데이터셋 예시 생성
# 클래스 0: 900개, 클래스 1: 100개
majority_data = torch.randn(900, 2)
majority_labels = torch.zeros(900, dtype=torch.long)
minority_data = torch.randn(100, 2) + 2 # 특징을 약간 다르게
minority_labels = torch.ones(100, dtype=torch.long)

all_data = torch.cat((majority_data, minority_data), dim=0)
all_labels = torch.cat((majority_labels, minority_labels), dim=0)

# 데이터셋 인스턴스 생성
imbalanced_dataset = CustomDataset(all_data, all_labels)

# 각 클래스의 샘플 수 계산
label_counts = Counter(imbalanced_dataset.labels.tolist())
print(f"Label counts in imbalanced dataset: {label_counts}")

# 각 샘플에 대한 가중치 계산
# 소수 클래스 샘플에 더 높은 가중치를 부여하여 샘플링 확률을 높입니다.
# 가중치는 일반적으로 (총 샘플 수 / 해당 클래스 샘플 수)에 비례하게 설정합니다.
class_weights_for_sampler = {0: 1.0 / label_counts[0], 1: 1.0 / label_counts[1]}

sample_weights = [class_weights_for_sampler[label] for label in imbalanced_dataset.labels.tolist()]
sample_weights = torch.DoubleTensor(sample_weights) # WeightedRandomSampler는 DoubleTensor를 기대합니다.

# WeightedRandomSampler 생성
# num_samples: 한 에포크에 샘플링할 총 샘플 수 (보통 데이터셋 크기와 동일하게 설정)
```

## 5. 평가 지표 (Evaluation Metrics)

불균형 데이터셋에서는 정확도(Accuracy)만으로는 모델의 성능을 올바르게 평가하기 어렵습니다. 소수 클래스에 대한 모델의 실제 성능을 파악하기 위해 다음과 같은 지표들을 함께 사용해야 합니다.

### 5.1. 혼동 행렬 (Confusion Matrix)

모델의 예측이 실제 레이블과 어떻게 일치하거나 불일치하는지를 시각화한 표입니다. True Positive (TP), True Negative (TN), False Positive (FP), False Negative (FN) 값을 보여줍니다.

*   **TP (True Positive)**: 실제 양성(Positive)을 양성으로 올바르게 예측
*   **TN (True Negative)**: 실제 음성(Negative)을 음성으로 올바르게 예측
*   **FP (False Positive)**: 실제 음성을 양성으로 잘못 예측 (Type I Error)
*   **FN (False Negative)**: 실제 양성을 음성으로 잘못 예측 (Type II Error)

### 5.2. 정밀도 (Precision), 재현율 (Recall), F1-점수 (F1-score)

이 지표들은 특히 소수 클래스에 대한 모델의 성능을 평가하는 데 중요합니다.

*   **정밀도 (Precision)**: 모델이 양성으로 예측한 것들 중에서 실제로 양성인 비율. $Precision = TP / (TP + FP)$
*   **재현율 (Recall) / 민감도 (Sensitivity)**: 실제 양성인 것들 중에서 모델이 양성으로 올바르게 예측한 비율. $Recall = TP / (TP + FN)$
*   **F1-점수 (F1-score)**: 정밀도와 재현율의 조화 평균. 두 지표의 균형을 나타내며, 불균형 데이터셋에서 모델 성능을 평가하는 데 널리 사용됩니다. $F1 = 2 	imes (Precision 	imes Recall) / (Precision + Recall)$

### 5.3. ROC 곡선 및 AUC (Area Under the Curve)

*   **ROC (Receiver Operating Characteristic) 곡선**: 다양한 분류 임계값(threshold)에서 모델의 재현율(True Positive Rate)과 위양성률(False Positive Rate) 간의 관계를 시각화한 그래프입니다.
*   **AUC (Area Under the Curve)**: ROC 곡선 아래의 면적을 나타냅니다. 0.5에서 1.0 사이의 값을 가지며, 1.0에 가까울수록 모델의 분류 성능이 우수함을 의미합니다. 불균형 데이터셋에서 모델의 전반적인 분류 능력을 평가하는 데 유용합니다.

### 5.4. Micro vs. Macro Averages

다중 클래스 분류에서 불균형이 있을 때, 평균을 계산하는 방식에 따라 지표의 의미가 달라집니다.

*   **Micro Average**: 모든 클래스의 TP, FP, FN을 합산하여 전체적으로 지표를 계산합니다. 다수 클래스의 성능에 더 큰 영향을 받습니다.
*   **Macro Average**: 각 클래스별로 지표를 계산한 후, 그 값들을 단순히 평균합니다. 모든 클래스에 동일한 가중치를 부여하므로, 소수 클래스의 성능 변화를 더 잘 반영합니다.

## 6. 결론

불균형 데이터셋은 현실 세계의 딥러닝 문제에서 흔히 발생하는 도전 과제이며, 이를 간과할 경우 모델의 실제 성능이 저하될 수 있습니다. 데이터 레벨 전략(오버샘플링, 언더샘플링)과 알고리즘 레벨 전략(클래스 가중치, 샘플링 가중치)을 적절히 조합하여 데이터 불균형을 해소하고, 정확도 외에 정밀도, 재현율, F1-점수, AUC와 같은 다양한 평가 지표를 사용하여 모델의 성능을 종합적으로 평가하는 것이 중요합니다. PyTorch는 이러한 전략들을 구현할 수 있는 유연한 도구들을 제공하므로, 이를 잘 활용하여 불균형 데이터셋에서도 강건하고 효과적인 딥러닝 모델을 구축할 수 있습니다.
