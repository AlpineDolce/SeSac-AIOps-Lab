## 1. 어텐션 메커니즘 (Attention Mechanism)

### 1.1. 어텐션의 등장 배경 (Seq2Seq 모델의 한계)

순환 신경망(RNN) 기반의 Seq2Seq(Sequence-to-Sequence) 모델은 번역, 요약 등 다양한 시퀀스 생성 태스크에서 좋은 성능을 보였습니다. 하지만 고정된 크기의 컨텍스트 벡터(Context Vector)에 전체 입력 시퀀스의 정보를 압축해야 했기 때문에, 입력 시퀀스의 길이가 길어질수록 정보 손실이 발생하여 성능이 저하되는 **장기 의존성 문제**와 **정보 병목 현상**이라는 한계가 있었습니다.

어텐션(Attention) 메커니즘은 이러한 문제를 해결하기 위해 제안되었습니다. 이는 디코더가 출력 단어를 예측할 때, 입력 시퀀스의 모든 부분을 동일하게 참조하는 것이 아니라, **현재 예측에 더 관련 있는 입력 부분에 '집중(Attention)'하여 정보를 가져오도록 하는 메커니즘**입니다.

### 1.2. 어텐션의 기본 원리

어텐션 메커니즘은 크게 세 가지 요소로 구성됩니다.

*   **쿼리 (Query, Q)**: 현재 시점의 디코더 상태(또는 출력)로, 입력 시퀀스의 어떤 부분에 집중할지 묻는 '질문' 역할을 합니다.
*   **키 (Key, K)**: 입력 시퀀스의 각 요소(단어, 토큰)에 해당하는 정보로, 쿼리와 비교될 '열쇠' 역할을 합니다.
*   **값 (Value, V)**: 입력 시퀀스의 각 요소에 해당하는 실제 정보로, 쿼리와 키의 유사도에 따라 가중치가 부여되어 선택될 '내용' 역할을 합니다.

어텐션은 다음과 같은 단계로 작동합니다.

1.  **유사도 계산**: 쿼리(Q)와 모든 키(K) 간의 유사도(Attention Score)를 계산합니다. 내적(Dot Product), 가산(Additive) 방식 등이 사용됩니다.
2.  **가중치 계산**: 계산된 유사도 점수에 소프트맥스(Softmax) 함수를 적용하여 합이 1이 되는 어텐션 가중치(Attention Weight)를 얻습니다. 이는 각 입력 요소에 대한 '집중도'를 나타냅니다.
3.  **컨텍스트 벡터 생성**: 어텐션 가중치와 값(V)을 가중합하여 컨텍스트 벡터(Context Vector)를 생성합니다. 이 컨텍스트 벡터는 현재 예측에 필요한 입력 시퀀스의 정보를 요약한 것입니다.
4.  **출력 생성**: 컨텍스트 벡터와 현재 시점의 디코더 상태를 결합하여 최종 출력을 예측합니다.

### 1.3. 어텐션의 종류 (Soft Attention, Hard Attention 등)

*   **소프트 어텐션 (Soft Attention)**: 모든 입력 요소에 대해 가중치를 부여하고 가중합을 계산하는 방식입니다. 미분 가능하여 역전파가 가능하며 가장 널리 사용됩니다.
*   **하드 어텐션 (Hard Attention)**: 특정 입력 요소 하나만 선택하여 집중하는 방식입니다. 미분 불가능하여 강화 학습 기법 등이 필요합니다.
*   **글로벌 어텐션 (Global Attention)**: 모든 입력 시퀀스를 고려하여 어텐션 가중치를 계산합니다.
*   **로컬 어텐션 (Local Attention)**: 입력 시퀀스의 특정 윈도우(Window) 내에서만 어텐션을 계산하여 계산 효율성을 높입니다.

## 2. 트랜스포머 (Transformer)

### 2.1. 트랜스포머의 등장 배경

어텐션 메커니즘은 Seq2Seq 모델의 성능을 크게 향상시켰지만, 여전히 RNN의 순차적인 계산 구조를 가지고 있어 병렬화가 어렵고 긴 시퀀스 처리 시 계산 비용이 높다는 한계가 있었습니다. 2017년 구글이 제안한 **트랜스포머(Transformer)**는 이러한 RNN의 순환 구조를 완전히 제거하고, **오직 어텐션 메커니즘만을 사용하여 시퀀스 데이터를 처리**하는 혁신적인 아키텍처입니다.

### 2.2. 트랜스포머의 전체 구조

트랜스포머는 인코더(Encoder)와 디코더(Decoder) 스택으로 구성됩니다. 각 인코더와 디코더는 여러 개의 동일한 층(Layer)으로 쌓여 있습니다.

```mermaid
graph LR
    Input[입력 임베딩] --> PositionalEncoding[포지셔널 인코딩]
    PositionalEncoding --> EncoderStack[인코더 스택 (Nx)]
    EncoderStack --> DecoderStack[디코더 스택 (Nx)]
    DecoderStack --> Output[출력]
```

### 2.3. 인코더 (Encoder)

인코더는 입력 시퀀스를 받아 특징 벡터로 변환하는 역할을 합니다. 각 인코더 층은 두 개의 서브 계층으로 구성됩니다.

#### 2.3.1. 셀프 어텐션 (Self-Attention)

*   **원리**: 입력 시퀀스 내의 각 단어가 다른 모든 단어들과 얼마나 관련이 있는지를 계산하여, 문맥 정보를 반영한 새로운 표현을 생성합니다. 즉, '자기 자신'에 대한 어텐션을 수행합니다.
*   **Q, K, V**: 입력 시퀀스의 각 단어 임베딩이 쿼리(Q), 키(K), 값(V)으로 사용됩니다.

#### 2.3.2. 멀티 헤드 어텐션 (Multi-Head Attention)

*   **원리**: 셀프 어텐션을 여러 번('헤드' 수만큼) 병렬로 수행한 후, 그 결과들을 결합하는 방식입니다. 각 헤드는 입력 시퀀스에서 다른 종류의 관계나 특징에 집중할 수 있습니다.
*   **효과**: 모델이 다양한 관점에서 정보를 통합하고, 더 풍부한 문맥 정보를 학습할 수 있게 합니다.

#### 2.3.3. 포지션 와이즈 피드 포워드 네트워크 (Position-wise Feed-Forward Network)

*   각 위치(단어)마다 독립적으로 적용되는 완전 연결 신경망입니다. 비선형성을 추가하고 모델의 표현력을 높입니다.

#### 2.3.4. 잔차 연결 (Residual Connection)과 층 정규화 (Layer Normalization)

*   **잔차 연결**: 각 서브 계층의 입력과 출력을 더하여 기울기 소실 문제를 완화하고 깊은 네트워크의 학습을 용이하게 합니다.
*   **층 정규화**: 각 층의 출력을 정규화하여 학습을 안정화하고 가속화합니다.

### 2.4. 디코더 (Decoder)

디코더는 인코더의 출력과 이전 시점의 디코더 출력을 바탕으로 다음 단어를 예측하는 역할을 합니다. 각 디코더 층은 세 개의 서브 계층으로 구성됩니다.

#### 2.4.1. 마스크드 멀티 헤드 셀프 어텐션 (Masked Multi-Head Self-Attention)

*   훈련 시 미래의 단어를 참조하지 못하도록 마스킹(Masking)을 적용한 셀프 어텐션입니다. 이는 디코더가 순차적으로 단어를 생성하는 과정을 모방합니다.

#### 2.4.2. 인코더-디코더 어텐션 (Encoder-Decoder Attention)

*   인코더의 출력(메모리)을 키(K)와 값(V)으로 사용하고, 디코더의 이전 출력을 쿼리(Q)로 사용하여, 인코더의 어떤 부분에 집중할지 결정합니다. 이는 Seq2Seq 모델의 어텐션과 유사합니다.

### 2.5. 포지셔널 인코딩 (Positional Encoding)

트랜스포머는 RNN과 달리 순환 구조가 없기 때문에 단어의 순서 정보를 직접적으로 처리할 수 없습니다. 이를 위해 입력 임베딩에 단어의 상대적 또는 절대적 위치 정보를 추가하는 **포지셔널 인코딩**을 사용합니다.

## 3. 트랜스포머의 장점과 영향

*   **병렬 처리**: RNN의 순차적 계산을 제거하여 GPU를 이용한 병렬 처리가 가능해져 학습 속도가 비약적으로 빨라졌습니다.
*   **장기 의존성 문제 해결**: 어텐션 메커니즘을 통해 시퀀스 길이와 관계없이 모든 위치의 정보를 직접 참조할 수 있어 장기 의존성 문제를 효과적으로 해결합니다.
*   **전이 학습의 기반**: BERT, GPT 등 트랜스포머를 기반으로 하는 사전 학습 모델들이 자연어 처리 분야의 패러다임을 바꾸었으며, 다양한 NLP 태스크에서 전이 학습의 시대를 열었습니다.
