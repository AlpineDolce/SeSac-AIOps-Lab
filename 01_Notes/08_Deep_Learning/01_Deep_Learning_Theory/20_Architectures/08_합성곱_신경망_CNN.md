## 1. 합성곱 신경망 (Convolutional Neural Network, CNN) 개요

### 1.1. CNN의 등장 배경

기존의 다층 퍼셉트론(MLP)은 이미지와 같은 2차원 데이터를 처리하는 데 여러 한계를 가집니다. 이미지는 픽셀 수가 많아 입력 차원이 매우 크고, 이미지 내에서 특징의 위치가 바뀌면 다른 특징으로 인식하는 문제가 있었습니다. 또한, 이미지의 공간적 구조(Spatial Structure) 정보를 유지하기 어렵다는 단점이 있었습니다.

CNN은 이러한 문제를 해결하기 위해 이미지의 공간적 구조를 보존하면서 특징을 효과적으로 추출하도록 설계된 신경망입니다. 생물학적 시각 피질의 작동 방식에서 영감을 받았습니다.

### 1.2. CNN의 특징

*   **지역 수용장 (Local Receptive Fields)**: 뉴런이 전체 입력이 아닌 입력의 일부(지역)에만 연결됩니다. 이는 이미지의 지역적인 특징을 효과적으로 추출할 수 있게 합니다.
*   **가중치 공유 (Weight Sharing)**: 동일한 필터(가중치)를 이미지의 여러 위치에 적용하여 특징을 추출합니다. 이는 파라미터 수를 크게 줄이고, 특징의 위치 불변성(Translation Invariance)을 확보하는 데 기여합니다.
*   **계층적 특징 추출 (Hierarchical Feature Extraction)**: 낮은 층에서는 엣지, 코너와 같은 단순한 특징을, 높은 층에서는 객체의 부분이나 전체와 같은 복잡하고 추상적인 특징을 학습합니다.

## 2. CNN의 핵심 구성 요소

CNN은 주로 합성곱 계층(Convolutional Layer), 풀링 계층(Pooling Layer), 그리고 완전 연결 계층(Fully Connected Layer)으로 구성됩니다.

### 2.1. 합성곱 계층 (Convolutional Layer)

합성곱 계층은 CNN의 핵심으로, 입력 이미지에 필터(커널)를 적용하여 특징 맵(Feature Map)을 생성합니다.

#### 2.1.1. 필터 (Filter/Kernel)

*   작은 크기의 행렬로, 이미지의 특정 패턴(예: 수직선, 수평선, 특정 질감)을 감지하는 역할을 합니다.
*   필터는 입력 이미지 위를 슬라이딩하며 합성곱 연산을 수행합니다.

#### 2.1.2. 스트라이드 (Stride)

*   필터가 입력 이미지 위를 이동하는 간격입니다. 스트라이드가 1이면 필터가 한 칸씩 이동하고, 2이면 두 칸씩 이동합니다.
*   스트라이드가 커질수록 특징 맵의 크기는 작아집니다.

#### 2.1.3. 패딩 (Padding)

*   입력 이미지의 가장자리에 0과 같은 특정 값으로 채워 넣는 작업입니다.
*   **Valid Padding (No Padding)**: 패딩을 적용하지 않아 특징 맵의 크기가 줄어듭니다.
*   **Same Padding**: 패딩을 적용하여 특징 맵의 크기가 입력 이미지와 동일하게 유지되도록 합니다.
*   패딩을 사용하면 이미지의 가장자리 정보 손실을 방지하고, 특징 맵의 크기를 조절할 수 있습니다.

#### 2.1.4. 특징 맵 (Feature Map)

*   합성곱 연산의 결과로 생성되는 출력입니다. 각 특징 맵은 특정 필터가 입력 이미지에서 감지한 특징의 강도를 나타냅니다.
*   여러 개의 필터를 사용하면 여러 개의 특징 맵이 생성됩니다.

### 2.2. 풀링 계층 (Pooling Layer)

풀링 계층은 특징 맵의 크기를 줄여(다운샘플링) 파라미터 수를 감소시키고, 모델의 계산량을 줄이며, 과적합을 방지하는 역할을 합니다. 또한, 특징의 위치 변화에 대한 모델의 강건성(Robustness)을 높입니다.

#### 2.2.1. 맥스 풀링 (Max Pooling)

*   가장 일반적으로 사용되는 풀링 방식입니다. 필터 내에서 가장 큰 값을 선택하여 출력합니다.
*   주요 특징을 강조하고 노이즈에 덜 민감하게 만듭니다.

#### 2.2.2. 평균 풀링 (Average Pooling)

*   필터 내의 모든 값의 평균을 계산하여 출력합니다.
*   주로 CNN의 마지막 부분에서 특징 맵을 하나의 벡터로 압축할 때 사용됩니다.

### 2.3. 완전 연결 계층 (Fully Connected Layer)

합성곱 계층과 풀링 계층을 통해 추출된 특징 맵은 1차원 벡터로 평탄화(Flatten)된 후, 일반적인 다층 퍼셉트론과 같은 완전 연결 계층의 입력으로 들어갑니다. 이 계층은 최종 분류 또는 회귀를 수행합니다.

## 3. 주요 CNN 아키텍처

### 3.1. LeNet-5

*   1998년 얀 르쿤(Yann LeCun)이 제안한 최초의 성공적인 CNN 모델입니다. 손글씨 숫자 인식(MNIST)에 사용되었습니다.
*   합성곱 계층, 풀링 계층, 완전 연결 계층의 기본적인 구조를 확립했습니다.

### 3.2. AlexNet

*   2012년 ImageNet 대회에서 압도적인 성능으로 우승하며 딥러닝 부흥의 시발점이 된 모델입니다.
*   ReLU 활성화 함수, 드롭아웃, GPU 활용, 데이터 증강 등 현대 딥러닝의 주요 기법들을 도입했습니다.

### 3.3. VGGNet

*   2014년 ImageNet 대회에서 제안된 모델로, 작은 크기(3x3)의 합성곱 필터를 여러 층으로 깊게 쌓아 올린 것이 특징입니다.
*   모델의 깊이가 성능에 미치는 영향을 보여주었습니다.

### 3.4. GoogLeNet (Inception)

*   2014년 ImageNet 대회에서 VGGNet과 함께 제안된 모델입니다.
*   **인셉션 모듈(Inception Module)**이라는 독특한 구조를 사용하여, 다양한 크기의 필터와 풀링을 병렬로 적용하여 특징을 추출하고 이를 결합합니다. 이는 파라미터 수를 줄이면서도 네트워크의 폭을 넓히는 효과를 가집니다.

### 3.5. ResNet (Residual Network)

*   2015년 ImageNet 대회에서 제안된 모델로, **잔차 연결(Residual Connection)** 또는 **스킵 연결(Skip Connection)**을 도입하여 매우 깊은 신경망의 학습을 가능하게 했습니다.
*   입력 값을 출력에 바로 더해주는 방식으로, 기울기 소실 문제를 완화하고 학습을 안정화합니다.

### 3.6. DenseNet

*   ResNet의 아이디어를 확장하여, 각 층이 이전의 모든 층의 특징 맵을 입력으로 받고 자신의 특징 맵을 다음의 모든 층으로 전달하는 **밀집 연결(Dense Connection)** 구조를 가집니다.
*   정보 흐름을 극대화하고, 파라미터 효율성을 높이며, 기울기 소실 문제를 완화합니다.
