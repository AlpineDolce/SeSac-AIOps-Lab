## 1. 비지도 학습 (Unsupervised Learning) 개요

### 1.1. 비지도 학습이란?
비지도 학습은 라벨(label)이 없는 데이터를 사용하여 모델을 학습하는 머신러닝의 한 분야입니다. 시스템은 데이터 자체의 내재된 구조, 패턴, 관계를 스스로 발견해야 합니다. 이는 마치 정답지가 없는 문제집을 보고 데이터의 숨겨진 규칙성을 찾아내는 것과 같습니다. 지도 학습이 명시적인 정답(라벨)을 통해 학습한다면, 비지도 학습은 데이터의 본질적인 특성을 이해하는 데 중점을 둡니다.

### 1.2. 주요 태스크: 군집화, 차원 축소, 이상 탐지
- **군집화 (Clustering)**: 유사한 특성을 가진 데이터 포인트들을 하나의 그룹으로 묶는 작업입니다. 예를 들어, 고객 데이터를 기반으로 유사한 구매 패턴을 가진 고객 그룹을 찾아 마케팅 전략을 수립할 수 있습니다. (예: K-Means, DBSCAN)
- **차원 축소 (Dimensionality Reduction)**: 데이터의 주요 특징은 유지하면서 고차원 데이터를 저차원 공간으로 변환하는 기술입니다. 이는 데이터 시각화, 노이즈 제거, 저장 공간 절약 등에 유용합니다. (예: 주성분 분석(PCA), t-SNE, Autoencoder)
- **이상 탐지 (Anomaly Detection)**: 대부분의 데이터와 다른 패턴을 보이는 '이상치'를 탐지하는 기법입니다. 금융 사기 탐지, 시스템 오류 감지 등에서 활용됩니다.

## 2. PyTorch를 이용한 전통적인 비지도 학습

### 2.1. 오토인코더 (Autoencoders)
오토인코더는 입력을 압축(encoding)했다가 다시 원래 입력으로 복원(decoding)하도록 학습되는 신경망입니다. 이 과정에서 데이터의 중요한 특징을 압축된 형태로 학습하게 되며, 이를 '잠재 표현(latent representation)'이라 합니다.
- **인코더 (Encoder)**: 입력 데이터를 저차원의 잠재 공간으로 압축합니다.
- **디코더 (Decoder)**: 압축된 잠재 표현을 다시 원본 데이터 차원으로 복원합니다.
- **손실 함수**: 원본 입력과 복원된 출력 간의 차이(예: MSE)를 최소화하도록 학습합니다.
PyTorch에서는 `nn.Sequential`을 사용하여 간단하게 인코더와 디코더를 구현하고, 재구성 손실(reconstruction loss)을 통해 모델을 학습시킬 수 있습니다.

### 2.2. 변이형 오토인코더 (Variational Autoencoders, VAE)
VAE는 오토인코더를 확률적으로 변형한 생성 모델입니다. 잠재 공간을 특정 벡터가 아닌, 정규분포의 평균(mean)과 분산(variance)으로 학습합니다. 이를 통해 잠재 공간에서 샘플링하여 기존에 없던 새로운 데이터를 생성할 수 있습니다. VAE의 손실 함수는 재구성 손실과 잠재 공간의 분포를 정규분포에 가깝게 만드는 KL 발산(KL Divergence) 항으로 구성됩니다.

### 2.3. 생성적 적대 신경망 (Generative Adversarial Networks, GAN)
GAN은 생성자(Generator)와 판별자(Discriminator)라는 두 개의 네트워크가 서로 경쟁하며 학습하는 생성 모델입니다.
- **생성자**: 실제 데이터와 유사한 가짜 데이터를 생성합니다.
- **판별자**: 주어진 데이터가 실제인지 가짜인지 구별합니다.
생성자는 판별자를 속이려고 노력하고, 판별자는 더 정확하게 구별하려고 노력하는 과정에서 생성자는 점차 실제와 가까운 데이터를 만들게 됩니다.

## 3. 자기지도 학습 (Self-Supervised Learning)의 부상

### 3.1. 자기지도 학습이란? (라벨 없는 데이터의 재발견)
자기지도 학습(SSL)은 비지도 학습의 한 형태로, 데이터 자체에서 라벨을 생성하여 지도 학습 방식으로 모델을 학습시킵니다. 즉, 데이터의 일부를 '입력'으로, 나머지 일부를 '라벨'로 사용하는 "가짜" 지도 학습 문제를 만들어 해결하는 방식입니다. 이를 통해 라벨링 비용 없이 대규모 데이터셋을 활용하여 풍부한 표현(representation)을 학습할 수 있습니다.

### 3.2. 핵심 아이디어: Pretext Task
자기지도 학습의 핵심은 'Pretext Task(구실 과제)'를 설계하는 것입니다. 이는 모델이 데이터의 본질적인 구조를 학습하도록 유도하는 가짜 문제입니다.
- **이미지 분야 예시**:
  - **Image Inpainting**: 이미지의 일부를 가리고, 주변 픽셀을 이용해 가려진 부분을 예측하게 합니다.
  - **Jigsaw Puzzle**: 이미지를 여러 조각으로 나누고, 원래 위치를 맞추게 합니다.
  - **Colorization**: 흑백 이미지에 색을 입히게 합니다.
이러한 Pretext Task를 해결하는 과정에서 모델은 객체의 형태, 질감, 맥락 등 데이터의 의미론적 특징을 자연스럽게 학습하게 됩니다.

## 4. PyTorch를 활용한 대표적인 자기지도 학습 방법론

### 4.1. 대조 학습 (Contrastive Learning) 기반
대조 학습은 "비슷한 것은 가깝게, 다른 것은 멀게"라는 아이디어를 기반으로 합니다. 동일한 이미지에 다른 데이터 증강(augmentation)을 적용한 'positive pair'는 잠재 공간에서 가깝게, 서로 다른 이미지에서 온 'negative pair'는 멀게 만드는 방식으로 학습합니다.

#### 4.1.1. SimCLR (A Simple Framework for Contrastive Learning of Visual Representations)
SimCLR은 간단하면서도 강력한 대조 학습 프레임워크입니다.
1. 동일 이미지에 두 가지 다른 랜덤 증강을 적용하여 positive pair를 생성합니다.
2. 배치 내의 다른 모든 이미지는 negative pair로 간주합니다.
3. 인코더(보통 ResNet)를 통해 각 이미지의 잠재 표현을 얻습니다.
4. 작은 MLP 프로젝션 헤드를 통해 잠재 표현을 다른 공간으로 매핑합니다.
5. 이 공간에서 NT-Xent Loss를 사용하여 positive pair 간의 유사도는 최대화하고, negative pair 간의 유사도는 최소화합니다.
SimCLR은 큰 배치 사이즈와 강력한 데이터 증강이 성능에 중요하다는 것을 보여주었습니다.

#### 4.1.2. MoCo (Momentum Contrast for Unsupervised Visual Representation Learning)
MoCo는 SimCLR의 큰 배치 사이즈 의존성 문제를 해결하기 위해 '모멘텀 인코더'와 '큐(queue)'를 도입했습니다.
- **큐**: 이전 배치의 negative sample들을 저장하여, 현재 배치의 크기에 상관없이 많은 수의 negative sample을 활용할 수 있게 합니다.
- **모멘텀 인코더**: 큐에 있는 샘플들의 표현 일관성을 유지하기 위해, 온라인 인코더의 가중치를 부드럽게(모멘텀 업데이트) 복사하여 사용합니다. 이로써 학습 안정성을 높입니다.

### 4.2. 군집화 기반 및 비대칭 네트워크
Negative pair 없이 positive pair 만으로 학습하는 방법론들도 제안되었습니다. 이는 모든 샘플을 서로 밀어내는 '모델 붕괴(collapse)' 문제를 해결하기 위한 독창적인 아키텍처를 사용합니다.

#### 4.2.1. BYOL (Bootstrap Your Own Latent)
BYOL은 온라인(online) 네트워크와 타겟(target) 네트워크라는 비대칭 구조를 사용합니다.
1. 온라인 네트워크는 타겟 네트워크가 생성한 표현을 예측하도록 학습됩니다.
2. 타겟 네트워크는 온라인 네트워크의 가중치를 모멘텀 기반으로 업데이트합니다. (MoCo와 유사)
3. 온라인 네트워크에만 예측기(predictor) MLP를 추가하여 비대칭성을 만듭니다.
이 구조는 negative pair 없이도 모델 붕괴를 효과적으로 방지합니다.

#### 4.2.2. DINO (Emerging Properties in Self-Supervised Vision Transformers)
DINO는 Vision Transformer(ViT)에 자기지도 학습을 적용한 모델로, 별도의 라벨 없이도 이미지에서 객체 세분화(segmentation)와 같은 속성이 나타나는 것을 보여주었습니다. DINO는 BYOL과 유사하게 온라인(student) 및 타겟(teacher) 네트워크를 사용하지만, teacher의 출력을 sharpening하고 centering하여 붕괴를 방지하는 추가적인 메커니즘을 사용합니다.

## 5. 실전 적용 및 미래 전망

### 5.1. 비지도/자기지도 학습의 활용 분야
- **전이 학습 (Transfer Learning)**: 대규모 라벨 없는 데이터로 사전 학습(pre-training)한 모델을 소규모 라벨 있는 데이터로 특정 작업에 맞게 미세 조정(fine-tuning)하여 높은 성능을 달성합니다.
- **의료 이미지 분석**: 라벨링이 비싸고 어려운 의료 이미지 분야에서 이상 부위 탐지, 질병 분류 등에 활용됩니다.
- **자연어 처리**: BERT, GPT와 같은 언어 모델들은 자기지도 학습(Masked Language Model)을 통해 문맥을 이해하는 능력을 학습합니다.
- **콘텐츠 추천**: 사용자의 행동 데이터를 기반으로 유사한 콘텐츠나 사용자를 군집화하여 추천 시스템의 정확도를 높입니다.

### 5.2. 앞으로의 연구 방향과 과제
- **멀티모달 학습**: 이미지, 텍스트, 오디오 등 여러 종류의 데이터를 함께 사용하여 더 풍부한 표현을 학습하는 방향으로 발전하고 있습니다.
- **효율적인 학습**: SimCLR과 같이 큰 배치 사이즈나 많은 계산 자원을 요구하는 모델들의 효율성을 높이는 연구가 진행 중입니다.
- **견고성(Robustness)과 공정성(Fairness)**: 데이터 편향에 강하고, 다양한 도메인에 일반화 성능이 높은 모델을 만드는 것이 중요한 과제입니다.
- **이론적 기반 확립**: 왜 자기지도 학습이 효과적인지에 대한 이론적 이해를 높여, 더 체계적인 모델 설계의 기반을 마련하려는 노력이 계속되고 있습니다.
