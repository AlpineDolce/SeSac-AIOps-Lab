## 1. 딥러닝이란?

### 1.1. 딥러닝의 정의

딥러닝(Deep Learning)은 머신러닝의 한 분야로, **인간의 뇌를 모방한 인공 신경망(Artificial Neural Network)을 여러 층(Layer)으로 깊게 쌓아 올린(Deep) 구조**를 사용하여 데이터 내의 복잡하고 추상적인 패턴을 스스로 학습하는 기술입니다. 기존 머신러닝 기법들이 특징(Feature)을 사람이 직접 설계해야 했던 것과 달리, 딥러닝은 데이터로부터 특징 자체를 자동으로 추출하고 학습하는 능력을 가집니다.

### 1.2. 딥러닝의 특징

*   **자동 특징 추출 (Automatic Feature Extraction)**: 데이터의 원시 형태(Raw Data)로부터 고수준의 추상적인 특징을 자동으로 학습합니다. 이는 이미지의 엣지, 질감, 객체 부분 등을 계층적으로 학습하는 것과 같습니다.
*   **대규모 데이터 처리 능력**: 데이터의 양이 많아질수록 성능이 비약적으로 향상되는 경향이 있습니다. 이는 딥러닝 모델이 복잡한 패턴을 학습하기 위해 많은 데이터를 필요로 하기 때문입니다.
*   **비정형 데이터에 강점**: 이미지, 음성, 텍스트와 같은 비정형 데이터 처리에서 특히 뛰어난 성능을 보입니다. 이는 기존 머신러닝 기법으로는 다루기 어려웠던 영역입니다.
*   **계층적 학습 (Hierarchical Learning)**: 신경망의 각 층은 데이터의 다른 수준의 추상화를 학습합니다. 낮은 층에서는 단순한 특징을, 높은 층에서는 복잡하고 추상적인 특징을 학습합니다.

## 2. 딥러닝의 역사와 주요 발전

딥러닝은 최근에야 큰 주목을 받았지만, 그 뿌리는 수십 년 전으로 거슬러 올라갑니다.

### 2.1. 태동기 (1940년대 ~ 1980년대)

*   **1943년: McCulloch-Pitts 모델**: 최초의 인공 신경 세포 모델 제안. 뇌의 뉴런을 수학적으로 모델링.
*   **1958년: 퍼셉트론 (Perceptron)**: Frank Rosenblatt이 개발한 단일층 신경망. 간단한 선형 분류 문제 해결.
*   **1969년: Minsky와 Papert의 'Perceptrons'**: 퍼셉트론의 한계(XOR 문제 해결 불가)를 지적하며 신경망 연구의 첫 번째 침체기 유발.
*   **1974년: 역전파 알고리즘 (Backpropagation)**: Paul Werbos가 박사 학위 논문에서 역전파 알고리즘을 제안했으나, 당시에는 큰 주목을 받지 못함.
*   **1986년: 역전파 알고리즘 재발견 및 확산**: Rumelhart, Hinton, Williams가 다층 신경망 학습에 역전파 알고리즘을 적용하는 방법을 발표하며 신경망 연구의 부흥기 시작.

### 2.2. 침체기 (1990년대 ~ 2000년대 초반)

*   **신경망의 한계**: 당시 컴퓨터 성능의 한계, 대규모 데이터 부족, 그리고 기울기 소실(Vanishing Gradient) 문제 등으로 인해 깊은 신경망을 효과적으로 학습시키기 어려웠습니다. SVM(Support Vector Machine) 등 다른 머신러닝 기법들이 더 좋은 성능을 보이며 신경망 연구는 다시 침체기에 접어듭니다.

### 2.3. 부흥기 (2000년대 중반 ~ 현재)

*   **2006년: 딥러닝의 재발견**: Geoffrey Hinton 교수가 제한된 볼츠만 머신(RBM)을 이용한 비지도 사전 학습(Unsupervised Pre-training) 기법을 제안하며 깊은 신경망을 효과적으로 학습시킬 수 있음을 보여줌. '딥러닝'이라는 용어 확산.
*   **2012년: AlexNet의 등장**: ImageNet Large Scale Visual Recognition Challenge (ILSVRC)에서 Alex Krizhevsky, Ilya Sutskever, Geoffrey Hinton이 개발한 AlexNet이 압도적인 성능으로 우승. 대규모 데이터셋(ImageNet), GPU 컴퓨팅, ReLU 활성화 함수, 드롭아웃(Dropout) 등의 기술이 결합되어 딥러닝의 가능성을 입증.
*   **이후 발전**: CNN(VGG, ResNet, Inception 등), RNN/LSTM/GRU, GAN, Transformer 등 다양한 딥러닝 아키텍처와 기술들이 발전하며 음성 인식, 자연어 처리, 자율 주행 등 다양한 분야에서 혁혁한 성과를 거두고 있습니다.

### 2.4. 딥러닝의 성공 요인

최근 딥러닝의 폭발적인 성장은 다음과 같은 요인들이 복합적으로 작용한 결과입니다.

*   **빅데이터의 출현**: 인터넷과 모바일 기기의 확산으로 대규모 데이터셋(ImageNet, Wikipedia 등)이 구축되어 딥러닝 모델 학습에 필요한 충분한 데이터를 제공.
*   **GPU 컴퓨팅의 발전**: GPU(Graphics Processing Unit)는 병렬 연산에 특화되어 있어, 딥러닝 모델의 대규모 행렬 연산을 효율적으로 처리할 수 있게 됨.
*   **알고리즘 및 모델 구조의 발전**: ReLU 활성화 함수, 드롭아웃, 배치 정규화, 잔차 연결(Residual Connection) 등 새로운 알고리즘과 모델 구조가 기울기 소실 문제 등을 해결하고 학습을 안정화.
*   **오픈소스 프레임워크의 확산**: TensorFlow, PyTorch와 같은 사용하기 쉬운 오픈소스 딥러닝 프레임워크가 개발되어 연구자와 개발자들이 딥러닝 모델을 쉽게 구현하고 실험할 수 있게 됨.
