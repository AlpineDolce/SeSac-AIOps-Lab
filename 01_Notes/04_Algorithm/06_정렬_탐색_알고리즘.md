### 3.3. 정렬 알고리즘 (Sorting Algorithms)

정렬 알고리즘은 데이터를 특정 기준에 따라 순서대로 나열하는 알고리즘입니다. 효율적인 정렬은 데이터 처리 및 검색 성능에 큰 영향을 미칩니다.

#### 5.1.1. 버블 정렬 (Bubble Sort)

버블 정렬은 인접한 두 요소를 비교하여 정렬하는 가장 간단한 정렬 알고리즘입니다. 비효율적이지만 개념 이해에 용이합니다. 각 패스(pass)에서 가장 큰(또는 작은) 요소가 배열의 끝으로 '거품처럼' 이동합니다.

*   **개념:** 배열의 첫 요소부터 인접한 두 요소를 비교하여 정렬 순서에 맞게 교환합니다. 가장 큰(또는 작은) 요소가 배열의 끝으로 '거품처럼' 이동합니다.
*   **시간 복잡도:** `O(n^2)` (최선, 최악, 평균 모두)
*   **구현:**
```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        # 마지막 i개 요소는 이미 정렬되었으므로 제외
        for j in range(0, n - i - 1):
            # 현재 요소가 다음 요소보다 크면 교환
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
    return arr

# 예시
# print(bubble_sort([64, 34, 25, 12, 22, 11, 90])) # [11, 12, 22, 25, 34, 64, 90]
```
*   **특징:** 버블 정렬은 **안정 정렬(Stable Sort)**입니다. 즉, 값이 같은 요소들의 상대적인 순서가 정렬 후에도 유지됩니다.

#### 5.1.2. 선택 정렬 (Selection Sort)

선택 정렬은 배열에서 가장 작은(또는 큰) 요소를 찾아 정렬된 부분의 올바른 위치로 이동시키는 정렬 알고리즘입니다. 배열을 정렬된 부분과 정렬되지 않은 부분으로 나누고, 정렬되지 않은 부분에서 최솟값을 찾아 정렬된 부분의 끝으로 가져옵니다.

*   **개념:** 배열을 두 부분으로 나눕니다. 하나는 정렬된 부분, 다른 하나는 정렬되지 않은 부분. 정렬되지 않은 부분에서 최솟값을 찾아 정렬된 부분의 끝으로 가져옵니다.
*   **시간 복잡도:** `O(n^2)` (최선, 최악, 평균 모두)
*   **구현:**
```python
def selection_sort(arr):
    n = len(arr)
    for i in range(n):
        min_idx = i
        for j in range(i + 1, n):
            if arr[min_idx] > arr[j]:
                min_idx = j
        # 찾은 최솟값을 현재 위치(i)의 요소와 교환
        arr[i], arr[min_idx] = arr[min_idx], arr[i]
    return arr

# 예시
# print(selection_sort([64, 34, 25, 12, 22, 11, 90])) # [11, 12, 22, 25, 34, 64, 90]
```
*   **특징:** 선택 정렬은 일반적으로 **불안정 정렬(Unstable Sort)**입니다. 값이 같은 요소들의 상대적인 순서가 정렬 과정에서 바뀔 수 있습니다.

#### 5.1.3. 퀵 정렬 (Quick Sort)

퀵 정렬은 분할 정복(Divide and Conquer) 방식을 사용하는 효율적인 정렬 알고리즘입니다. 평균적으로 매우 빠르며, 대부분의 실제 환경에서 가장 많이 사용되는 정렬 알고리즘 중 하나입니다.

*   **개념:** '피벗(Pivot)' 요소를 선택하고, 피벗보다 작은 요소는 왼쪽으로, 큰 요소는 오른쪽으로 분할합니다. 이 과정을 재귀적으로 반복합니다.
*   **분할 (Partitioning):** 배열 내에서 '피벗(Pivot)' 요소를 선택하고, 피벗보다 작은 요소는 피벗의 왼쪽으로, 큰 요소는 피벗의 오른쪽으로 이동시킵니다. 이 과정을 통해 피벗은 최종 정렬 위치에 놓이게 됩니다. 피벗 선택 전략(예: 첫 번째 요소, 마지막 요소, 중간 요소, 랜덤 요소)에 따라 성능이 달라질 수 있습니다.
*   **시간 복잡도:** 평균 `O(n log n)`, 최악 `O(n^2)` (피벗 선택에 따라 달라짐)
*   **구현:**
```python
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2] # 간단하게 중간 요소를 피벗으로 선택
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

# 예시
# print(quick_sort([64, 34, 25, 12, 22, 11, 90])) # [11, 12, 22, 25, 34, 64, 90]
```

#### 5.1.4. 기타 정렬 알고리즘 개요 (병합 정렬, 힙 정렬 등)

*   **병합 정렬 (Merge Sort):** 분할 정복 방식. 데이터를 절반으로 계속 나누어 정렬한 후 다시 병합합니다. 안정 정렬(Stable Sort)입니다. `O(n log n)`. 추가적인 `O(n)` 공간이 필요합니다.
```python
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left_half = arr[:mid]
    right_half = arr[mid:]

    left = merge_sort(left_half)
    right = merge_sort(right_half)

    return merge(left, right)

def merge(left, right):
    merged = []
    left_idx, right_idx = 0, 0

    while left_idx < len(left) and right_idx < len(right):
        if left[left_idx] < right[right_idx]:
            merged.append(left[left_idx])
            left_idx += 1
        else:
            merged.append(right[right_idx])
            right_idx += 1

    merged.extend(left[left_idx:])
    merged.extend(right[right_idx:])
    return merged

# 예시
# print(merge_sort([64, 34, 25, 12, 22, 11, 90])) # [11, 12, 22, 25, 34, 64, 90]
```
*   **힙 정렬 (Heap Sort):** 힙 자료구조를 활용한 정렬. `O(n log n)`. 제자리 정렬(In-place Sort)입니다.
*   **삽입 정렬 (Insertion Sort):** 각 요소를 이미 정렬된 부분에 삽입합니다. `O(n^2)` (최선 `O(n)`). 작은 배열이나 거의 정렬된 배열에 효율적입니다.
```python
def insertion_sort(arr):
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1
        while j >= 0 and key < arr[j]:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key
    return arr

# 예시
# print(insertion_sort([64, 34, 25, 12, 22, 11, 90])) # [11, 12, 22, 25, 34, 64, 90]
```
*   **계수 정렬 (Counting Sort):** 요소의 범위가 작고 정수일 때 매우 효율적인 비비교 정렬(Non-comparison Sort)입니다. 각 요소의 개수를 세어 정렬합니다. `O(n + k)` (k는 값의 범위). 안정 정렬입니다.
*   **기수 정렬 (Radix Sort):** 자릿수(digit)를 기준으로 정렬하는 비비교 정렬입니다. 각 자릿수별로 안정 정렬(예: 계수 정렬)을 반복합니다. `O(d * (n + k))` (d는 자릿수, k는 기수).

#### 5.1.5. 정렬 알고리즘 성능 비교

| 알고리즘 | 시간 복잡도 (최악) | 시간 복잡도 (평균) | 공간 복잡도 | 안정성 |
| :--- | :--- | :--- | :--- | :--- |
| 버블 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 안정 |
| 선택 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 불안정 |
| 삽입 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 안정 |
| 퀵 정렬 | `O(n^2)` | `O(n log n)` | `O(log n)` (재귀 스택) | 불안정 |
| 병합 정렬 | `O(n log n)` | `O(n log n)` | `O(n)` | 안정 |
| 힙 정렬 | `O(n log n)` | `O(n log n)` | `O(1)` | 불안정 |

실제 환경에서는 데이터의 특성(정렬 여부, 중복 여부, 크기 등)에 따라 각 정렬 알고리즘의 성능이 달라질 수 있습니다. 예를 들어, 대부분의 언어에서 제공하는 내장 정렬 함수는 퀵 정렬, 병합 정렬, 또는 팀 정렬(Timsort)과 같은 하이브리드 정렬 알고리즘을 사용합니다.

### 3.4. 탐색 알고리즘 (Searching Algorithms)

탐색 알고리즘은 주어진 데이터 컬렉션에서 특정 요소를 찾는 알고리즘입니다.

#### 5.2.1. 선형 탐색 (Linear Search)

선형 탐색은 데이터를 처음부터 끝까지 순차적으로 비교하며 찾는 가장 간단한 탐색 알고리즘입니다. 데이터가 정렬되어 있지 않거나, 데이터의 양이 매우 적을 때 주로 사용됩니다。

*   **개념:** 배열의 모든 요소를 하나씩 확인하여 목표 값을 찾습니다.
*   **시간 복잡도:** `O(n)` (최악, 평균) - 배열의 모든 요소를 한 번씩 확인해야 할 수 있습니다。
*   **구현:**
```python
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i  # 요소를 찾으면 해당 인덱스 반환
    return -1 # 요소를 찾지 못하면 -1 반환

# 예시
# print(linear_search([10, 20, 80, 30, 60, 50, 110, 100, 130, 170], 110)) # 6
# print(linear_search([10, 20, 80, 30, 60, 50, 110, 100, 130, 170], 99))  # -1
```

#### 5.2.2. 이진 탐색 (Binary Search)

이진 탐색은 **정렬된 배열**에서 탐색 범위를 절반씩 줄여가며 요소를 찾는 효율적인 탐색 알고리즘입니다. 데이터가 정렬되어 있다는 강력한 전제 조건이 있습니다.

*   **개념:** 탐색 범위의 중간 요소를 확인하여 목표 값과 비교합니다. 목표 값이 중간 요소보다 작으면 왼쪽 절반에서, 크면 오른쪽 절반에서 다시 탐색합니다. 이 과정을 목표 값을 찾거나 탐색 범위가 없어질 때까지 반복합니다.
*   **시간 복잡도:** `O(log n)` - 탐색 범위가 매 단계 절반으로 줄어들기 때문에 매우 효율적입니다.
*   **전제 조건:** 데이터가 반드시 정렬되어 있어야 합니다.
*   **구현 (반복문):**
```python
def binary_search_iterative(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2 # 중간 인덱스 계산
        if arr[mid] == target:
            return mid # 목표 값을 찾으면 인덱스 반환
        elif arr[mid] < target:
            low = mid + 1 # 중간 값보다 크면 오른쪽 절반 탐색
        else:
            high = mid - 1 # 중간 값보다 작으면 왼쪽 절반 탐색
    return -1 # 목표 값을 찾지 못하면 -1 반환

# 예시
# print(binary_search_iterative([11, 12, 22, 25, 34, 64, 90], 25)) # 3
# print(binary_search_iterative([11, 12, 22, 25, 34, 64, 90], 99)) # -1
```
*   **구현 (재귀):**
```python
def binary_search_recursive(arr, target, low, high):
    if low > high:
        return -1 # 탐색 범위가 유효하지 않으면 -1 반환

    mid = (low + high) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search_recursive(arr, target, mid + 1, high)
    else:
        return binary_search_recursive(arr, target, low, mid - 1)

# 예시
# arr_rec = [11, 12, 22, 25, 34, 64, 90]
# print(binary_search_recursive(arr_rec, 25, 0, len(arr_rec) - 1)) # 3
# print(binary_search_recursive(arr_rec, 99, 0, len(arr_rec) - 1)) # -1
```
*   **변형:** 이진 탐색은 단순히 값의 존재 여부를 확인하는 것 외에도, 특정 값의 첫 번째/마지막 등장 위치 찾기, 특정 값보다 크거나 같은/작거나 같은 첫 번째 요소 찾기(Lower Bound/Upper Bound) 등 다양한 문제에 응용될 수 있습니다.

#### 5.2.3. 삼분 탐색 (Ternary Search)

삼분 탐색은 단조성을 가지는 함수(볼록 함수 또는 오목 함수, 즉 Unimodal Function)에서 최댓값 또는 최솟값을 찾는 데 사용되는 탐색 기법입니다. 이진 탐색이 단조 함수에서 특정 값을 찾는 데 사용되는 반면, 삼분 탐색은 함수의 최적점(극점)을 찾는 데 특화되어 있습니다.

##### 5.2.3.1. 개념 및 활용 (단조 함수 최적점 찾기)

*   **개념:** 탐색 구간을 3등분하여 두 개의 중간점(m1, m2)을 설정하고, `f(m1)`과 `f(m2)`를 비교하여 최적점이 존재하지 않는 1/3 구간을 버립니다. 이 과정을 반복하여 최적점에 수렴합니다. 이진 탐색과 유사하게, 매 단계 탐색 범위를 줄여나갑니다.
*   **시간 복잡도:** `O(log3 n)` - 매 단계 탐색 범위가 1/3로 줄어듭니다.
*   **활용:**
    *   최댓값/최솟값을 가지는 단조 함수에서 최적점을 찾을 때. (예: 포물선 함수의 꼭짓점 찾기)
    *   예: 특정 구간에서 함수의 최댓값 또는 최솟값을 찾는 문제.
*   **구현 (최댓값 찾기 예시):**
```python
def ternary_search_max(f, low, high, epsilon=1e-7):
    # f: 단조성을 가지는 함수 (예: 위로 볼록한 함수)
    # low, high: 탐색 구간의 시작과 끝
    # epsilon: 허용 오차 (탐색 정밀도)

    while (high - low) > epsilon:
        m1 = low + (high - low) / 3
        m2 = high - (high - low) / 3

        if f(m1) < f(m2):
            low = m1 # m1보다 m2가 더 크므로, 최댓값은 m1 오른쪽에 있음
        else:
            high = m2 # m2보다 m1이 더 크거나 같으므로, 최댓값은 m2 왼쪽에 있음

    return (low + high) / 2 # 최적점 근사값 반환

# 예시 함수 (위로 볼록한 포물선)
# def example_function(x):
#     return -(x - 5)**2 + 10 # x=5에서 최댓값 10

# print(ternary_search_max(example_function, 0, 10)) # 5.0에 가까운 값 출력
```

### 5.3. 투 포인터 (Two Pointers)

투 포인터는 배열이나 리스트와 같은 선형 자료구조에서 두 개의 포인터(인덱스)를 사용하여 문제를 해결하는 알고리즘 기법입니다. 주로 정렬된 배열에서 특정 조건을 만족하는 쌍이나 부분 배열을 찾을 때 효율적입니다.

#### 5.3.1. 투 포인터의 개념과 활용 조건

*   **개념:** 투 포인터는 배열이나 리스트와 같은 선형 자료구조에서 두 개의 포인터(인덱스)를 사용하여 문제를 해결하는 알고리즘 기법입니다. 이 두 포인터는 서로 다른 위치에서 시작하여(예: 양 끝에서 시작하여 안쪽으로 이동) 특정 조건을 만족하는 쌍이나 부분 배열을 효율적으로 탐색합니다. 또는 같은 위치에서 시작하여 한 방향으로 이동하며 특정 조건을 만족하는 구간을 찾기도 합니다.
*   **활용 조건:**
    *   데이터가 **정렬되어 있는 경우** (가장 일반적이고 효과적인 활용 사례).
    *   특정 조건을 만족하는 두 요소의 쌍(Pair)을 찾아야 할 때.
    *   부분 배열 또는 부분 문자열을 다룰 때.
    *   연결 리스트에서 사이클 감지, 중간 노드 찾기 등.
    *   배열에서 중복 요소 제거, 특정 값 이동 등.

#### 5.3.2. 투 포인터 활용 문제 (예: 정렬된 배열에서 합 찾기)

정렬된 배열에서 합이 특정 값(target)이 되는 두 요소를 찾는 문제입니다.

```python
def two_sum_sorted(arr, target):
    left, right = 0, len(arr) - 1 # 두 포인터를 배열의 양 끝에 초기화
    while left < right: # left 포인터가 right 포인터를 넘지 않을 때까지 반복
        current_sum = arr[left] + arr[right] # 현재 두 요소의 합 계산
        if current_sum == target:
            return [arr[left], arr[right]] # 합이 target과 같으면 결과 반환
        elif current_sum < target:
            left += 1 # 합이 target보다 작으면 left 포인터를 오른쪽으로 이동 (합을 증가)
        else:
            right -= 1 # 합이 target보다 크면 right 포인터를 왼쪽으로 이동 (합을 감소)
    return None # 조건을 만족하는 쌍을 찾지 못하면 None 반환

# 시간 복잡도: O(n) - 두 포인터가 배열을 한 번만 순회합니다。
# 공간 복잡도: O(1) - 추가적인 공간을 거의 사용하지 않습니다。

# 예시
# print(two_sum_sorted([1, 2, 3, 4, 5], 7)) # [2, 5]
# print(two_sum_sorted([1, 2, 3, 4, 5], 10)) # None
```

### 5.4. 슬라이딩 윈도우 (Sliding Window)

슬라이딩 윈도우는 배열이나 문자열의 '연속된 부분(Subarray/Substring)'을 효율적으로 탐색하는 알고리즘 기법입니다. 고정된 크기 또는 가변적인 크기의 윈도우(부분 구간)를 이동시키면서 문제를 해결합니다.

#### 5.4.1. 슬라이딩 윈도우의 개념과 활용

*   **개념:** 슬라이딩 윈도우는 배열이나 문자열의 '연속된 부분(Subarray/Substring)'을 효율적으로 탐색하는 알고리즘 기법입니다. 고정된 크기 또는 가변적인 크기의 윈도우(부분 구간)를 이동시키면서 문제를 해결합니다. 매번 전체 구간을 다시 계산하는 대신, 윈도우를 한 칸씩 이동시키면서 윈도우 내의 데이터를 효율적으로 갱신하고 계산하여 `O(N)` 또는 `O(N log N)`의 시간 복잡도를 달성합니다.
*   **활용:**
    *   **고정 크기 윈도우:** 특정 길이의 부분 배열/문자열에서 최대/최소 합, 평균 등을 찾을 때. (예: 최대 부분 배열 합, 특정 길이의 부분 문자열에서 중복 없는 문자 개수)
    *   **가변 크기 윈도우:** 특정 조건을 만족하는 가장 짧거나 긴 부분 배열/문자열을 찾을 때. (예: K개의 고유 문자를 포함하는 가장 긴 부분 문자열, 합이 특정 값 이상인 가장 짧은 부분 배열)
    *   **문자열 패턴 매칭:** 특정 패턴이 문자열 내에 존재하는지 확인할 때.

#### 5.4.2. 슬라이딩 윈도우 활용 문제 (예: 최대 부분 배열 합)

주어진 배열에서 길이가 `k`인 연속된 부분 배열의 최대 합을 찾는 문제입니다.

```python
def max_subarray_sum_fixed_window(arr, k):
    if k > len(arr): return None # 윈도우 크기가 배열 길이보다 크면 유효하지 않음

    # 초기 윈도우의 합 계산
    current_sum = sum(arr[:k])
    max_sum = current_sum

    # 윈도우를 배열의 끝까지 슬라이딩
    for i in range(k, len(arr)):
        # 윈도우 이동: 새로운 요소 추가, 가장 오래된 요소 제거
        current_sum += arr[i] - arr[i - k]
        # 최대 합 갱신
        max_sum = max(max_sum, current_sum)
    return max_sum

# 시간 복잡도: O(n) - 배열을 한 번만 순회합니다。
# 공간 복잡도: O(1) - 추가적인 공간을 거의 사용하지 않습니다。

# 예시
# print(max_subarray_sum_fixed_window([1, 4, 2, 10, 2, 3, 1, 0, 20], 4)) # 24 (4, 2, 10, 2)
```

### 5.5. 비트 연산 (Bit Manipulation)

비트 연산은 데이터를 비트(0과 1) 단위로 직접 조작하는 연산입니다. 매우 빠르고 효율적이며, 특정 문제 유형(집합 표현, 상태 관리, 최적화)에서 강력한 해결책을 제공합니다.

#### 5.5.1. 비트 연산자의 종류와 활용

비트 연산자는 정수형 데이터의 개별 비트(0 또는 1)를 직접 조작하는 연산입니다. 매우 빠르고 효율적이며, 특정 문제 유형(집합 표현, 상태 관리, 최적화)에서 강력한 해결책을 제공합니다.

*   `&` (AND): 두 비트가 모두 1일 때만 1을 반환합니다. (예: 특정 비트가 켜져 있는지 확인)
*   `|` (OR): 두 비트 중 하나라도 1일 때 1을 반환합니다. (예: 특정 비트를 켜기)
*   `^` (XOR): 두 비트가 다를 때 1을 반환합니다. (예: 비트 반전, 두 값 교환)
*   `~` (NOT): 비트를 반전시킵니다 (0은 1로, 1은 0으로). (예: 보수 계산)
*   `<<` (Left Shift): 비트를 왼쪽으로 이동시킵니다. `x << n`은 `x * (2^n)`과 같습니다. (예: 2의 거듭제곱 곱셈, 비트 마스크 생성)
*   `>>` (Right Shift): 비트를 오른쪽으로 이동시킵니다. `x >> n`은 `x // (2^n)`과 같습니다. (예: 2의 거듭제곱 나눗셈, 특정 비트 값 추출)

#### 5.5.2. 비트 마스크 (Bit Mask)

비트 마스크는 비트 연산을 사용하여 여러 개의 불리언(True/False) 상태를 하나의 정수로 표현하고 관리하는 기법입니다. 각 비트가 특정 상태나 속성의 존재 여부를 나타내며, 이를 통해 효율적인 집합 연산이나 상태 관리가 가능합니다。

*   **활용:**
    *   **부분집합 표현:** `n`개의 요소로 구성된 집합의 모든 부분집합을 `2^n`개의 비트 마스크로 표현할 수 있습니다. 각 비트가 해당 요소의 포함 여부를 나타냅니다。
    *   **상태 관리:** 여러 개의 스위치나 옵션 상태를 하나의 정수 변수로 간결하게 관리할 수 있습니다. (예: 게임에서 플레이어의 아이템 소유 상태, 퍼즐의 특정 칸 방문 여부)
    *   **권한 관리:** 사용자 권한을 비트 플래그로 설정하여, 여러 권한을 동시에 부여하거나 확인하는 작업을 효율적으로 수행합니다。
    *   **동적 계획법 (Dynamic Programming):** 특정 상태를 비트 마스크로 표현하여 DP 테이블의 인덱스로 활용하는 경우가 많습니다. (예: 외판원 문제)

#### 5.5.3. 비트 연산 활용 문제 (예: 부분집합, 상태 관리)

주어진 집합의 모든 부분집합을 생성하는 문제입니다.

```python
def generate_subsets(nums):
    n = len(nums)
    subsets = []
    # 2^n 개의 부분집합을 생성하기 위해 0부터 (2^n - 1)까지 반복
    for i in range(1 << n): # (1 << n)은 2의 n승을 의미
        current_subset = []
        # 각 비트(j)가 nums의 j번째 요소의 포함 여부를 나타냄
        for j in range(n):
            if (i >> j) & 1: # i의 j번째 비트가 1이면 (해당 요소가 부분집합에 포함됨)
                current_subset.append(nums[j])
        subsets.append(current_subset)
    return subsets

# 시간 복잡도: O(n * 2^n) - 2^n 개의 부분집합 각각에 대해 n개의 요소를 확인합니다。
# 공간 복잡도: O(n * 2^n) - 모든 부분집합을 저장합니다。

# 예시
# print(generate_subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```
