### 3.3. 정렬 알고리즘 (Sorting Algorithms)

정렬 알고리즘은 데이터를 특정 기준에 따라 순서대로 나열하는 알고리즘입니다. 효율적인 정렬은 데이터 처리 및 검색 성능에 큰 영향을 미칩니다.

#### 3.3.1. 버블 정렬 (Bubble Sort)

인접한 두 요소를 비교하여 정렬하는 가장 간단한 정렬 알고리즘입니다. 비효율적이지만 개념 이해에 용이합니다.

*   **개념:** 배열의 첫 요소부터 인접한 두 요소를 비교하여 정렬 순서에 맞게 교환합니다. 가장 큰(또는 작은) 요소가 배열의 끝으로 '거품처럼' 이동합니다.
*   **시간 복잡도:** `O(n^2)` (최선, 최악, 평균 모두)

#### 3.3.2. 선택 정렬 (Selection Sort)

배열에서 가장 작은(또는 큰) 요소를 찾아 정렬된 부분의 올바른 위치로 이동시키는 정렬 알고리즘입니다.

*   **개념:** 배열을 두 부분으로 나눕니다. 하나는 정렬된 부분, 다른 하나는 정렬되지 않은 부분. 정렬되지 않은 부분에서 최솟값을 찾아 정렬된 부분의 끝으로 가져옵니다.
*   **시간 복잡도:** `O(n^2)` (최선, 최악, 평균 모두)

#### 3.3.3. 퀵 정렬 (Quick Sort)

분할 정복(Divide and Conquer) 방식을 사용하는 효율적인 정렬 알고리즘입니다. 평균적으로 매우 빠릅니다.

*   **개념:** '피벗(Pivot)' 요소를 선택하고, 피벗보다 작은 요소는 왼쪽으로, 큰 요소는 오른쪽으로 분할합니다. 이 과정을 재귀적으로 반복합니다.
*   **시간 복잡도:** 평균 `O(n log n)`, 최악 `O(n^2)` (피벗 선택에 따라 달라짐)

#### 3.3.4. 기타 정렬 알고리즘 개요 (병합 정렬, 힙 정렬 등)

*   **병합 정렬 (Merge Sort):** 분할 정복 방식. 데이터를 절반으로 계속 나누어 정렬한 후 다시 병합합니다. 안정 정렬(Stable Sort)입니다. `O(n log n)`.
*   **힙 정렬 (Heap Sort):** 힙 자료구조를 활용한 정렬. `O(n log n)`.
*   **삽입 정렬 (Insertion Sort):** 각 요소를 이미 정렬된 부분에 삽입합니다. `O(n^2)` (최선 `O(n)`).

#### 3.3.5. 정렬 알고리즘 성능 비교

| 알고리즘 | 시간 복잡도 (최악) | 시간 복잡도 (평균) | 공간 복잡도 | 안정성 |
| :--- | :--- | :--- | :--- | :--- |
| 버블 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 안정 |
| 선택 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 불안정 |
| 삽입 정렬 | `O(n^2)` | `O(n^2)` | `O(1)` | 안정 |
| 퀵 정렬 | `O(n^2)` | `O(n log n)` | `O(log n)` (재귀 스택) | 불안정 |
| 병합 정렬 | `O(n log n)` | `O(n log n)` | `O(n)` | 안정 |
| 힙 정렬 | `O(n log n)` | `O(n log n)` | `O(1)` | 불안정 |

### 3.4. 탐색 알고리즘 (Searching Algorithms)

탐색 알고리즘은 주어진 데이터 컬렉션에서 특정 요소를 찾는 알고리즘입니다.

#### 3.4.1. 선형 탐색 (Linear Search)

데이터를 처음부터 끝까지 순차적으로 비교하며 찾는 가장 간단한 탐색 알고리즘입니다.

*   **개념:** 배열의 모든 요소를 하나씩 확인하여 목표 값을 찾습니다.
*   **시간 복잡도:** `O(n)` (최악, 평균)

#### 3.4.2. 이진 탐색 (Binary Search)

정렬된 배열에서 탐색 범위를 절반씩 줄여가며 요소를 찾는 효율적인 탐색 알고리즘입니다.

*   **개념:** 중간 요소를 확인하여 목표 값과 비교합니다. 목표 값이 중간 요소보다 작으면 왼쪽 절반에서, 크면 오른쪽 절반에서 다시 탐색합니다.
*   **시간 복잡도:** `O(log n)`
*   **전제 조건:** 데이터가 반드시 정렬되어 있어야 합니다.

#### 3.4.3. 삼분 탐색 (Ternary Search)

단조성을 가지는 함수(볼록 함수 또는 오목 함수)에서 최댓값 또는 최솟값을 찾는 데 사용되는 탐색 기법입니다. 이진 탐색이 단조 함수에서 특정 값을 찾는 데 사용되는 반면, 삼분 탐색은 함수의 최적점을 찾는 데 특화되어 있습니다.

##### 3.4.3.1. 개념 및 활용 (단조 함수 최적점 찾기)

*   **개념:** 탐색 구간을 3등분하여 두 개의 중간점(m1, m2)을 설정하고, `f(m1)`과 `f(m2)`를 비교하여 최적점이 존재하지 않는 1/3 구간을 버립니다. 이 과정을 반복하여 최적점에 수렴합니다.
*   **활용:**
    *   최댓값/최솟값을 가지는 단조 함수에서 최적점을 찾을 때.
    *   예: 특정 구간에서 함수의 최댓값 또는 최솟값을 찾는 문제.

### 3.11. 투 포인터 (Two Pointers)

투 포인터는 배열이나 리스트에서 두 개의 포인터(인덱스)를 사용하여 문제를 해결하는 알고리즘 기법입니다. 주로 정렬된 배열에서 특정 조건을 만족하는 쌍이나 부분 배열을 찾을 때 효율적입니다.

#### 3.11.1. 투 포인터의 개념과 활용 조건

*   **개념:** 두 개의 포인터가 서로 다른 위치에서 시작하여(보통 양 끝에서 시작하여 안쪽으로 이동하거나, 같은 위치에서 시작하여 한 방향으로 이동) 배열을 탐색합니다.
*   **활용 조건:**
    *   데이터가 정렬되어 있는 경우 (가장 일반적).
    *   특정 조건을 만족하는 두 요소의 쌍을 찾아야 할 때.
    *   부분 배열 또는 부분 문자열을 다룰 때.

#### 3.11.2. 투 포인터 활용 문제 (예: 정렬된 배열에서 합 찾기)

정렬된 배열에서 합이 특정 값(target)이 되는 두 요소를 찾는 문제입니다.

```python
def two_sum_sorted(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        current_sum = arr[left] + arr[right]
        if current_sum == target:
            return [arr[left], arr[right]]
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return None

# 예시
# print(two_sum_sorted([1, 2, 3, 4, 5], 7)) # [2, 5]
# print(two_sum_sorted([1, 2, 3, 4, 5], 10)) # None
```

### 3.12. 슬라이딩 윈도우 (Sliding Window)

슬라이딩 윈도우는 배열이나 문자열의 '연속된 부분(Subarray/Substring)'을 효율적으로 탐색하는 알고리즘 기법입니다. 고정된 크기 또는 가변적인 크기의 윈도우(부분 구간)를 이동시키면서 문제를 해결합니다.

#### 3.12.1. 슬라이딩 윈도우의 개념과 활용

*   **개념:** 윈도우를 한 칸씩 이동시키면서 윈도우 내의 데이터를 갱신하고 계산합니다. 매번 전체 구간을 다시 계산하는 비효율을 줄입니다.
*   **활용:**
    *   고정 크기 윈도우: 특정 길이의 부분 배열/문자열에서 최대/최소 합, 평균 등을 찾을 때.
    *   가변 크기 윈도우: 특정 조건을 만족하는 가장 짧거나 긴 부분 배열/문자열을 찾을 때.

#### 3.12.2. 슬라이딩 윈도우 활용 문제 (예: 최대 부분 배열 합)

주어진 배열에서 길이가 `k`인 연속된 부분 배열의 최대 합을 찾는 문제입니다.

```python
def max_subarray_sum_fixed_window(arr, k):
    if k > len(arr): return None

    current_sum = sum(arr[:k])
    max_sum = current_sum

    for i in range(k, len(arr)):
        current_sum += arr[i] - arr[i - k] # 윈도우 이동: 새로운 요소 추가, 오래된 요소 제거
        max_sum = max(max_sum, current_sum)
    return max_sum

# 예시
# print(max_subarray_sum_fixed_window([1, 4, 2, 10, 2, 3, 1, 0, 20], 4)) # 24 (4, 2, 10, 2)
```

### 3.13. 비트 연산 (Bit Manipulation)

비트 연산은 데이터를 비트(0과 1) 단위로 직접 조작하는 연산입니다. 매우 빠르고 효율적이며, 특정 문제 유형(집합 표현, 상태 관리, 최적화)에서 강력한 해결책을 제공합니다.

#### 3.13.1. 비트 연산자의 종류와 활용

*   `&` (AND): 두 비트가 모두 1일 때 1.
*   `|` (OR): 두 비트 중 하나라도 1일 때 1.
*   `^` (XOR): 두 비트가 다를 때 1.
*   `~` (NOT): 비트를 반전.
*   `<<` (Left Shift): 비트를 왼쪽으로 이동 (2의 거듭제곱 곱셈).
*   `>>` (Right Shift): 비트를 오른쪽으로 이동 (2의 거듭제곱 나눗셈).

#### 3.13.2. 비트 마스크 (Bit Mask)

비트 마스크는 비트 연산을 사용하여 여러 개의 불리언(True/False) 상태를 하나의 정수로 표현하고 관리하는 기법입니다. 각 비트가 특정 상태를 나타냅니다.

*   **활용:**
    *   부분집합 표현: `n`개의 요소로 만들 수 있는 모든 부분집합을 `2^n`개의 비트 마스크로 표현.
    *   상태 관리: 여러 개의 스위치나 옵션 상태를 하나의 변수로 관리.
    *   권한 관리: 사용자 권한을 비트 플래그로 설정.

#### 3.13.3. 비트 연산 활용 문제 (예: 부분집합, 상태 관리)

주어진 집합의 모든 부분집합을 생성하는 문제입니다.

```python
def generate_subsets(nums):
    n = len(nums)
    subsets = []
    for i in range(1 << n): # 2^n 개의 부분집합
        current_subset = []
        for j in range(n):
            if (i >> j) & 1: # j번째 비트가 1이면
                current_subset.append(nums[j])
        subsets.append(current_subset)
    return subsets

# 예시
# print(generate_subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```
