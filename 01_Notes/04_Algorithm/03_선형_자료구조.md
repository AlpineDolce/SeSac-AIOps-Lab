## 2. 선형 자료구조

선형 자료구조는 데이터를 순차적으로 저장하고 관리하는 방식입니다. 각 요소가 선형적인 순서로 연결되어 있어, 데이터의 접근 및 조작 방식이 비교적 직관적입니다.

### 2.1. 배열 (Array) 및 파이썬 리스트 (List)

배열은 가장 기본적인 자료구조로, 동일한 타입의 데이터를 연속된 메모리 공간에 저장합니다. 파이썬의 리스트는 이러한 배열의 개념을 확장한 동적 배열입니다.

#### 2.1.1. 배열의 특징과 메모리 구조

*   **연속된 메모리 할당:** 요소들이 메모리상에 연속적으로 저장되어 있어 인덱스를 통한 직접 접근(Random Access)이 가능합니다.
*   **고정 크기 (일반적인 배열):** 대부분의 언어에서 배열은 생성 시 크기가 고정됩니다. 파이썬 리스트는 동적 배열로 동작하여 크기 조절이 가능합니다.
*   **특징:**
    *   **장점:** 인덱스를 통한 접근이 `O(1)`로 매우 빠릅니다. 메모리 효율성이 좋습니다.
    *   **단점:** 삽입 및 삭제 시 요소들의 이동이 필요하여 `O(n)` 시간이 소요될 수 있습니다.

#### 2.1.2. 파이썬 리스트의 동적 배열 특성

파이썬의 리스트는 내부적으로 동적 배열(Dynamic Array)로 구현되어 있습니다. 이는 배열이 가득 찼을 때 자동으로 더 큰 공간을 할당하고 기존 요소들을 복사하는 방식으로 동작합니다. 이 과정은 상환 분석(Amortized Analysis)을 통해 평균 `O(1)`의 `append` 연산 성능을 보장합니다.

```python
my_list = []
my_list.append(1) # 리스트의 크기가 동적으로 증가
my_list.append(2)
print(my_list)
```

#### 2.1.3. 리스트와 튜플의 차이점

파이썬에서 리스트와 튜플은 모두 순서가 있는 컬렉션이지만, 중요한 차이점이 있습니다.

*   **리스트 (List):** 변경 가능(Mutable)합니다. 요소의 추가, 삭제, 수정이 자유롭습니다.
    ```python
    my_list = [1, 2, 3]
    my_list[0] = 10
    my_list.append(4)
    print(my_list) # [10, 2, 3, 4]
    ```
*   **튜플 (Tuple):** 변경 불가능(Immutable)합니다. 한 번 생성되면 요소를 변경할 수 없습니다.
    ```python
    my_tuple = (1, 2, 3)
    # my_tuple[0] = 10 # TypeError 발생
    print(my_tuple)
    ```

#### 2.1.4. 리스트 활용 문제 해결

##### 2.1.4.1. 정수 배열에서 가장 큰 두 수 찾기

주어진 정수 배열에서 가장 큰 두 수를 찾는 문제입니다.

```python
def find_two_largest(arr):
    if len(arr) < 2:
        raise ValueError("Array must contain at least two elements.")

    max1 = float('-inf')
    max2 = float('-inf')

    for num in arr:
        if num > max1:
            max2 = max1
            max1 = num
        elif num > max2:
            max2 = num
    return max1, max2

# 예시
# print(find_two_largest([1, 5, 2, 8, 3, 9])) # (9, 8)
```

##### 2.1.4.2. 회문(Palindromes) 찾기

문자열이 회문(앞으로 읽으나 뒤로 읽으나 같은 문자열)인지 판별하는 문제입니다.

```python
def is_palindrome(s):
    # 알파벳과 숫자만 남기고 소문자로 변환
    cleaned_s = ''.join(char.lower() for char in s if char.isalnum())
    return cleaned_s == cleaned_s[::-1]

# 예시
# print(is_palindrome("A man, a plan, a canal: Panama")) # True
# print(is_palindrome("race a car")) # False
```

##### 2.1.4.3. 0과 1로 구성된 배열 정렬하기

0과 1로만 구성된 배열을 정렬하는 문제입니다. (정렬 알고리즘을 사용하지 않고 효율적으로)

```python
def sort_zeros_ones(arr):
    left = 0
    right = len(arr) - 1

    while left < right:
        while arr[left] == 0 and left < right:
            left += 1
        while arr[right] == 1 and left < right:
            right -= 1
        if left < right:
            arr[left], arr[right] = arr[right], arr[left] # swap
            left += 1
            right -= 1
    return arr

# 예시
# print(sort_zeros_ones([0, 1, 0, 1, 1, 0])) # [0, 0, 0, 1, 1, 1]
```

##### 2.1.4.4. 제시된 합을 가진 부분 배열 찾기

주어진 배열에서 특정 합을 가지는 연속된 부분 배열을 찾는 문제입니다.

```python
def subarray_with_given_sum(arr, target_sum):
    current_sum = 0
    start_index = 0
    for i in range(len(arr)):
        current_sum += arr[i]
        while current_sum > target_sum and start_index <= i:
            current_sum -= arr[start_index]
            start_index += 1
        if current_sum == target_sum:
            return arr[start_index : i + 1]
    return None

# 예시
# print(subarray_with_given_sum([1, 4, 20, 3, 10, 5], 33)) # [20, 3, 10]
# print(subarray_with_given_sum([1, 4, 0, 0, 3, 10, 5], 7)) # [4, 0, 0, 3]
```

### 2.2. 스택 (Stack)

스택은 데이터를 일시적으로 저장하는 데 사용되는 선형 자료구조입니다. '마지막에 들어온 것이 가장 먼저 나간다'는 LIFO(Last-In, First-Out) 원칙을 따릅니다.

#### 2.2.1. LIFO (Last-In, First-Out) 원리

스택은 접시 쌓기나 동전 쌓기와 유사하게, 가장 최근에 추가된 요소가 가장 먼저 제거됩니다.

#### 2.2.2. 스택의 주요 연산 (Push, Pop, Peek)

*   **Push:** 스택의 맨 위에 요소를 추가합니다.
*   **Pop:** 스택의 맨 위 요소를 제거하고 반환합니다.
*   **Peek (Top):** 스택의 맨 위 요소를 제거하지 않고 반환합니다.
*   **isEmpty:** 스택이 비어있는지 확인합니다.
*   **size:** 스택에 있는 요소의 개수를 반환합니다.

#### 2.2.3. 파이썬 리스트를 이용한 스택 구현

파이썬의 리스트는 `append()`와 `pop()` 메서드를 제공하여 스택의 LIFO 동작을 쉽게 구현할 수 있습니다.

```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)

    def pop(self):
        if not self.is_empty():
            return self.items.pop()
        return None # 또는 예외 발생

    def peek(self):
        if not self.is_empty():
            return self.items[-1]
        return None

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)

# 예시
# my_stack = Stack()
# my_stack.push(10)
# my_stack.push(20)
# print(my_stack.peek()) # 20
# print(my_stack.pop())  # 20
# print(my_stack.size()) # 1
```

#### 2.2.4. 스택의 활용 사례 (괄호 매칭, 함수 호출 스택)

*   **괄호 매칭:** 수식이나 코드에서 괄호의 짝이 맞는지 검사할 때 사용합니다.
*   **함수 호출 스택 (Call Stack):** 프로그램에서 함수 호출의 순서를 관리하고, 함수가 종료될 때 이전 상태로 돌아가는 데 사용됩니다.
*   **역순 출력:** 문자열이나 리스트의 요소를 역순으로 처리할 때 유용합니다.
*   **DFS (깊이 우선 탐색):** 그래프나 트리를 깊이 우선으로 탐색할 때 사용됩니다.

#### 2.2.5. 스택의 장단점 및 주의사항

*   **장점:** 데이터 추가/삭제가 `O(1)`로 빠릅니다. 구현이 간단합니다.
*   **단점:** 중간 요소에 대한 접근이 어렵습니다. 크기 제한이 있을 수 있습니다.
*   **주의사항:** 스택이 비어있을 때 `pop`이나 `peek` 연산을 호출하면 오류가 발생할 수 있으므로, `is_empty()`로 확인하는 것이 좋습니다.

### 2.3. 큐 (Queue)

큐는 스택과 마찬가지로 데이터를 일시적으로 저장하는 데 사용되는 선형 자료구조입니다. '가장 먼저 들어온 것이 가장 먼저 나간다'는 FIFO(First-In, First-Out) 원칙을 따릅니다.

#### 2.3.1. FIFO (First-In, First-Out) 원리

큐는 줄 서기와 유사하게, 가장 먼저 추가된 요소가 가장 먼저 제거됩니다.

#### 2.3.2. 큐의 주요 연산 (Enqueue, Dequeue)

*   **Enqueue (Put):** 큐의 뒤(rear)에 요소를 추가합니다.
*   **Dequeue (Get):** 큐의 앞(front)에서 요소를 제거하고 반환합니다.
*   **Peek (Front):** 큐의 맨 앞 요소를 제거하지 않고 반환합니다.
*   **isEmpty:** 큐가 비어있는지 확인합니다.
*   **size:** 큐에 있는 요소의 개수를 반환합니다.

#### 2.3.3. `collections.deque`를 이용한 큐 구현

파이썬의 `collections` 모듈에 있는 `deque` (double-ended queue)는 양쪽 끝에서의 빠른 추가/삭제를 지원하여 큐를 구현하는 데 매우 효율적입니다.

```python
from collections import deque

class Queue:
    def __init__(self):
        self.items = deque()

    def enqueue(self, item):
        self.items.append(item)

    def dequeue(self):
        if not self.is_empty():
            return self.items.popleft()
        return None

    def peek(self):
        if not self.is_empty():
            return self.items[0]
        return None

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)

# 예시
# my_queue = Queue()
# my_queue.enqueue(10)
# my_queue.enqueue(20)
# print(my_queue.peek())   # 10
# print(my_queue.dequeue()) # 10
# print(my_queue.size())   # 1
```

#### 2.3.4. 큐의 활용 사례 (너비 우선 탐색, 작업 스케줄링)

*   **BFS (너비 우선 탐색):** 그래프나 트리를 너비 우선으로 탐색할 때 사용됩니다.
*   **작업 스케줄링:** 운영체제에서 프로세스 스케줄링이나 프린터 대기열 등 작업의 순서를 관리할 때 사용됩니다.
*   **캐시 (Cache):** LRU(Least Recently Used) 캐시 구현에 활용될 수 있습니다.

#### 2.3.5. 큐의 변형 구조 (우선순위 큐, 덱)

*   **우선순위 큐 (Priority Queue):** 요소들이 우선순위를 가지고, 가장 높은 우선순위의 요소가 먼저 제거되는 큐입니다. 힙(Heap) 자료구조로 구현됩니다.
*   **덱 (Deque, Double-Ended Queue):** 양쪽 끝에서 삽입과 삭제가 모두 가능한 큐입니다. `collections.deque`가 대표적인 예시입니다.

#### 2.3.6. 스택과 큐 비교

| 특징 | 스택 (Stack) | 큐 (Queue) |
| :--- | :--- | :--- |
| 원칙 | LIFO (Last-In, First-Out) | FIFO (First-In, First-Out) |
| 삽입 | Push (맨 위) | Enqueue (맨 뒤) |
| 삭제 | Pop (맨 위) | Dequeue (맨 앞) |
| 활용 | 함수 호출 스택, 괄호 매칭, DFS | 작업 스케줄링, BFS, 캐시 |

### 2.4. 링크드 리스트 (Linked List)

링크드 리스트는 데이터를 '노드(Node)' 단위로 저장하며, 각 노드가 다음 노드의 주소를 가리키는 방식으로 연결된 선형 자료구조입니다. 배열과 달리 요소들이 메모리상에 연속적으로 위치하지 않아도 됩니다.

#### 2.4.1. 개념 및 배열과의 차이점

*   **개념:** 데이터와 다음 노드를 가리키는 포인터(또는 참조)를 포함하는 노드들의 연결.
*   **배열과의 차이점:**
    *   **메모리 할당:** 배열은 연속적, 링크드 리스트는 비연속적.
    *   **크기:** 배열은 고정(동적 배열 제외), 링크드 리스트는 동적.
    *   **삽입/삭제:** 배열은 `O(n)`, 링크드 리스트는 `O(1)` (탐색 후).
    *   **접근:** 배열은 `O(1)` (인덱스), 링크드 리스트는 `O(n)` (순차 탐색).

#### 2.4.2. 단일 링크드 리스트 (Singly Linked List)

각 노드가 데이터와 다음 노드를 가리키는 하나의 포인터를 가집니다.

##### 2.4.2.1. 노드 구조 및 기본 연산 (삽입, 삭제, 탐색)

*   **노드 (Node):** `data`와 `next` (다음 노드 참조)로 구성됩니다.
*   **Head:** 리스트의 첫 번째 노드를 가리킵니다.
*   **기본 연산:**
    *   **삽입 (Insertion):** 특정 위치에 노드를 추가합니다. `O(1)` (위치를 알고 있을 때).
    *   **삭제 (Deletion):** 특정 노드를 제거합니다. `O(1)` (노드를 알고 있을 때).
    *   **탐색 (Search):** 특정 값을 가진 노드를 찾습니다. `O(n)`.

##### 2.4.2.2. 파이썬 구현

```python
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = Node(data)
        if self.head is None:
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:
            last_node = last_node.next
        last_node.next = new_node

    def prepend(self, data):
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node

    def delete_node(self, key):
        current_node = self.head
        if current_node and current_node.data == key:
            self.head = current_node.next
            current_node = None
            return
        prev_node = None
        while current_node and current_node.data != key:
            prev_node = current_node
            current_node = current_node.next
        if current_node is None:
            return # Key not found
        prev_node.next = current_node.next
        current_node = None

    def print_list(self):
        current_node = self.head
        while current_node:
            print(current_node.data, end=" -> ")
            current_node = current_node.next
        print("None")

# 예시
# my_list = LinkedList()
# my_list.append(1)
# my_list.append(2)
# my_list.prepend(0)
# my_list.print_list() # 0 -> 1 -> 2 -> None
# my_list.delete_node(1)
# my_list.print_list() # 0 -> 2 -> None
```

#### 2.4.3. 이중 링크드 리스트 (Doubly Linked List)

각 노드가 데이터와 함께 이전 노드와 다음 노드를 가리키는 두 개의 포인터를 가집니다. 양방향 탐색이 가능합니다.

##### 2.4.3.1. 개념 및 장점

*   **개념:** `data`, `next`, `prev` (이전 노드 참조)로 구성된 노드들의 연결.
*   **장점:**
    *   양방향 탐색이 가능하여 특정 노드에서 앞뒤로 이동하기 편리합니다.
    *   삭제 연산 시 이전 노드를 쉽게 찾을 수 있어 단일 링크드 리스트보다 효율적입니다.

##### 2.4.3.2. 파이썬 구현

```python
class DoublyNode:
    def __init__(self, data):
        self.data = data
        self.next = None
        self.prev = None

class DoublyLinkedList:
    def __init__(self):
        self.head = None

    def append(self, data):
        new_node = DoublyNode(data)
        if self.head is None:
            self.head = new_node
            return
        last_node = self.head
        while last_node.next:
            last_node = last_node.next
        last_node.next = new_node
        new_node.prev = last_node

    def print_list(self):
        current_node = self.head
        while current_node:
            print(current_node.data, end=" <-> ")
            current_node = current_node.next
        print("None")

# 예시
# my_doubly_list = DoublyLinkedList()
# my_doubly_list.append(1)
# my_doubly_list.append(2)
# my_doubly_list.print_list() # 1 <-> 2 <-> None
```

#### 2.4.4. 링크드 리스트의 활용 사례

*   **음악 플레이리스트:** 이전/다음 곡으로 이동하는 기능.
*   **웹 브라우저의 뒤로/앞으로 가기:** 방문 기록을 관리.
*   **LRU 캐시:** 최근 사용된 항목을 빠르게 접근하고, 오래된 항목을 제거.
*   **메모리 관리:** 운영체제에서 사용 가능한 메모리 블록을 관리.

#### 2.4.5. 성능 및 메모리 최적화 고려사항

*   **메모리 오버헤드:** 각 노드마다 포인터를 저장해야 하므로, 배열보다 메모리 사용량이 많을 수 있습니다.
*   **캐시 비효율성:** 요소들이 연속적으로 저장되지 않아 CPU 캐시 효율이 낮을 수 있습니다.
*   **적절한 선택:** 삽입/삭제가 빈번하고 순차 접근이 적은 경우에 유리하며, 인덱스 접근이 잦은 경우에는 배열이 더 적합합니다.
