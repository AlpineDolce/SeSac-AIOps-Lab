### 4.2. 그래프 (Graph)

그래프는 객체(정점 또는 노드)와 이들을 연결하는 관계(간선)를 표현하는 비선형 자료구조입니다. 복잡한 연결 관계를 모델링하고 분석하는 데 사용됩니다.

#### 4.2.1. 그래프의 개념과 용어

*   **정점 (Vertex/Node):** 그래프를 구성하는 기본 요소.
*   **간선 (Edge):** 두 정점을 연결하는 선.
    *   **방향 그래프 (Directed Graph):** 간선에 방향이 있는 그래프 (예: 일방통행 도로).
    *   **무방향 그래프 (Undirected Graph):** 간선에 방향이 없는 그래프 (예: 양방통행 도로).
    *   **가중치 그래프 (Weighted Graph):** 간선에 비용이나 거리를 나타내는 가중치가 있는 그래프.
*   **경로 (Path):** 정점들을 연결하는 간선들의 순서.
*   **사이클 (Cycle):** 시작 정점과 끝 정점이 같은 경로.
*   **차수 (Degree):** 정점에 연결된 간선의 수. (방향 그래프에서는 진입 차수, 진출 차수)
*   **연결 그래프 (Connected Graph):** 모든 정점 쌍 사이에 경로가 존재하는 그래프.
*   **부분 그래프 (Subgraph):** 원래 그래프의 일부 정점과 간선으로 구성된 그래프.

#### 4.2.2. 그래프 표현 방식 (인접 행렬, 인접 리스트)

그래프는 주로 두 가지 방식으로 표현됩니다.

*   **인접 행렬 (Adjacency Matrix):** `V x V` 크기의 2차원 배열을 사용하여 정점 간의 연결 관계를 나타냅니다. `matrix[i][j]`가 1이면 `i`와 `j`가 연결되어 있음을 의미합니다 (가중치 그래프에서는 가중치 값).
    *   **장점:** 두 정점 간의 연결 여부를 `O(1)`에 확인할 수 있습니다.
    *   **단점:** 간선이 적은 희소 그래프(Sparse Graph)에서는 메모리 낭비가 심합니다.
*   **인접 리스트 (Adjacency List):** 각 정점에 연결된 다른 정점들을 리스트로 저장합니다.
    *   **장점:** 간선이 적은 희소 그래프에서 메모리 효율적입니다. 모든 간선을 탐색하는 데 효율적입니다.
    *   **단점:** 두 정점 간의 연결 여부를 확인하는 데 `O(degree)` 시간이 소요됩니다.

```python
# 인접 리스트 예시 (무방향 그래프)
graph_adj_list = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

# 인접 행렬 예시 (무방향 그래프, 정점 0, 1, 2)
# matrix[0][1] = 1, matrix[1][0] = 1
graph_adj_matrix = [
    [0, 1, 1],
    [1, 0, 0],
    [1, 0, 0]
]
```

#### 4.2.3. 그래프 탐색 (DFS, BFS)

그래프의 모든 정점이나 특정 정점을 방문하는 방법입니다.

*   **깊이 우선 탐색 (DFS, Depth-First Search):** 한 방향으로 갈 수 있는 가장 깊은 곳까지 탐색한 후, 더 이상 갈 곳이 없으면 되돌아와(백트랙) 다른 경로를 탐색합니다. 스택(Stack) 또는 재귀(Recursion)를 사용하여 구현합니다.
    *   **활용:** 사이클 감지, 위상 정렬, 연결 요소 찾기.
*   **너비 우선 탐색 (BFS, Breadth-First Search):** 시작 정점에서 가까운 정점부터 차례대로 탐색합니다. 큐(Queue)를 사용하여 구현합니다.
    *   **활용:** 최단 경로 (간선 가중치가 없는 경우), 최단 거리, 미로 찾기.

```python
# DFS 예시 (재귀)
def dfs(graph, start_node, visited):
    visited.add(start_node)
    print(start_node, end=' ')
    for neighbor in graph[start_node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

# BFS 예시
from collections import deque

def bfs(graph, start_node):
    visited = set()
    queue = deque([start_node])
    visited.add(start_node)

    while queue:
        node = queue.popleft()
        print(node, end=' ')
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

# graph = { ... } (위의 graph_adj_list 예시)
# dfs(graph, 'A', set())
# bfs(graph, 'A')
```

#### 4.2.4. 최단 경로 알고리즘

두 정점 사이의 가장 짧은 경로를 찾는 알고리즘입니다.

##### 4.2.4.1. 다익스트라 (Dijkstra) 알고리즘

단일 시작점에서 다른 모든 정점까지의 최단 경로를 찾는 알고리즘입니다. 음수 가중치 간선이 없는 그래프에서만 작동합니다. 우선순위 큐를 사용하여 효율적으로 구현할 수 있습니다.

*   **시간 복잡도:** `O(E log V)` (우선순위 큐 사용 시) 또는 `O(V^2)` (인접 행렬 사용 시)

##### 4.2.4.2. 벨만-포드 (Bellman-Ford) 알고리즘

단일 시작점에서 다른 모든 정점까지의 최단 경로를 찾는 알고리즘입니다. 음수 가중치 간선이 있는 그래프에서도 작동하며, 음수 사이클을 감지할 수 있습니다.

*   **시간 복잡도:** `O(VE)`

##### 4.2.4.3. 플로이드-워셜 (Floyd-Warshall) 알고리즘

모든 정점 쌍 간의 최단 경로를 찾는 알고리즘입니다. 음수 가중치 간선이 있는 그래프에서도 작동하며, 음수 사이클을 감지할 수 있습니다. 동적 계획법을 사용합니다.

*   **시간 복잡도:** `O(V^3)`

#### 4.2.5. 최소 신장 트리 (Minimum Spanning Tree, MST)

연결된 비방향 가중치 그래프에서 모든 정점을 포함하면서 간선 가중치의 합이 최소가 되는 트리를 찾는 문제입니다.

##### 4.2.5.1. 프림 (Prim) 알고리즘

시작 정점에서부터 트리를 확장해나가며 MST를 구성합니다. 우선순위 큐를 사용하여 효율적으로 구현할 수 있습니다.

*   **시간 복잡도:** `O(E log V)` (우선순위 큐 사용 시) 또는 `O(V^2)` (인접 행렬 사용 시)

##### 4.2.5.2. 크루스칼 (Kruskal) 알고리즘 (참고)

가장 가중치가 작은 간선부터 선택하여 MST를 구성합니다. 사이클이 형성되지 않도록 분리 집합(Disjoint Set) 자료구조를 사용합니다.

*   **시간 복잡도:** `O(E log E)` 또는 `O(E log V)` (간선 정렬 시간 포함)

#### 4.2.6. 위상 정렬 (Topological Sort)

방향 비순환 그래프(DAG, Directed Acyclic Graph)의 정점들을 방향성에 거스르지 않도록 순서대로 나열하는 알고리즘입니다.

##### 4.2.6.1. 개념 및 활용 (작업 순서, 의존성 관리)

*   **개념:** 모든 간선 `u -> v`에 대해 `u`가 `v`보다 먼저 오도록 정점들을 선형적으로 정렬합니다.
*   **활용:**
    *   프로젝트 작업 순서 결정 (선행 작업이 완료되어야 다음 작업 시작 가능).
    *   컴파일러의 컴파일 순서 결정.
    *   데이터베이스의 트랜잭션 스케줄링.

#### 4.2.7. 네트워크 플로우 (Network Flow)

네트워크 플로우는 유량 네트워크(Flow Network)에서 소스(Source)에서 싱크(Sink)로 흐를 수 있는 최대 유량을 찾는 문제입니다.

##### 4.2.7.1. 최대 유량 (Maximum Flow) 문제

주어진 네트워크에서 소스에서 싱크로 보낼 수 있는 최대 유량을 찾는 문제입니다.

##### 4.2.7.2. 최소 컷 (Minimum Cut) 정리

최대 유량-최소 컷 정리(Max-Flow Min-Cut Theorem)에 따르면, 네트워크의 최대 유량은 소스에서 싱크를 분리하는 최소 컷의 용량과 같습니다.

##### 4.2.7.3. 포드-풀커슨 (Ford-Fulkerson) 알고리즘

잔여 네트워크에서 증가 경로(Augmenting Path)를 찾아 유량을 증가시키는 방식으로 최대 유량을 찾습니다.

##### 4.2.7.4. 딘츠 (Dinic) 알고리즘

포드-풀커슨 알고리즘의 개선된 버전으로, 블로킹 플로우(Blocking Flow) 개념을 사용하여 더 효율적으로 최대 유량을 찾습니다.

##### 4.2.7.5. 네트워크 플로우의 활용 사례 (매칭, 경로 최적화)

*   **이분 매칭 (Bipartite Matching):** 이분 그래프에서 최대 매칭을 찾는 문제.
*   **경로 최적화:** 물류, 교통 시스템 등에서 자원 흐름을 최적화.

#### 4.2.8. 고급 그래프 분석

##### 4.2.8.1. 강한 연결 요소 (Strongly Connected Components, SCC)

방향 그래프에서 서로 도달 가능한 정점들의 최대 집합입니다. 코사라주(Kosaraju) 알고리즘이나 타잔(Tarjan) 알고리즘으로 찾을 수 있습니다.

##### 4.2.8.2. 단절점 (Articulation Point) 및 단절선 (Bridge)

*   **단절점 (Articulation Point):** 해당 정점을 제거했을 때 그래프의 연결 요소 개수가 증가하는 정점.
*   **단절선 (Bridge):** 해당 간선을 제거했을 때 그래프의 연결 요소 개수가 증가하는 간선.

#### 4.2.9. 최소 비용 최대 유량 (Minimum Cost Maximum Flow, MCMF)

네트워크 플로우 문제의 확장으로, 각 간선에 유량뿐만 아니라 비용도 있을 때, 주어진 유량을 보내는 최소 비용을 찾는 문제입니다.

##### 4.2.9.1. 개념 및 활용

*   **개념:** 최대 유량을 보내면서 동시에 총 비용을 최소화하는 문제.
*   **활용:** 운송, 통신 네트워크 설계, 자원 할당.

#### 4.2.10. 이분 매칭 (Bipartite Matching)

이분 그래프(Bipartite Graph)에서 서로 연결되지 않은 간선들의 최대 집합을 찾는 문제입니다.

##### 4.2.10.1. 개념 및 활용 (최대 매칭, 최소 정점 덮개)

*   **개념:** 그래프의 정점 집합을 서로소인 두 개의 집합으로 나눌 수 있고, 모든 간선이 두 집합의 정점들을 연결하는 그래프.
*   **활용:**
    *   **최대 매칭 (Maximum Matching):** 최대한 많은 간선을 선택하여 어떤 두 간선도 공통 정점을 가지지 않도록 하는 문제.
    *   **최소 정점 덮개 (Minimum Vertex Cover):** 그래프의 모든 간선을 덮는 최소 정점 집합. (쾨니히의 정리: 이분 그래프에서 최대 매칭의 크기는 최소 정점 덮개의 크기와 같다.)

##### 4.2.10.2. 헝가리안 알고리즘 (Hungarian Algorithm) 개요

이분 그래프에서 최대 매칭을 찾는 알고리즘 중 하나입니다.

#### 4.2.11. 오일러 경로/회로 (Eulerian Path/Circuit)

그래프의 모든 간선을 정확히 한 번씩만 지나는 경로 또는 회로를 찾는 문제입니다.

##### 4.2.11.1. 개념 및 조건

*   **오일러 경로 (Eulerian Path):** 모든 간선을 한 번씩만 지나는 경로.
*   **오일러 회로 (Eulerian Circuit):** 모든 간선을 한 번씩만 지나 시작 정점으로 돌아오는 회로.
*   **조건:**
    *   무방향 그래프: 모든 정점의 차수가 짝수이면 오일러 회로가 존재. 홀수 차수를 가진 정점이 0개 또는 2개이면 오일러 경로가 존재.
    *   방향 그래프: 모든 정점의 진입 차수와 진출 차수가 같으면 오일러 회로가 존재. 특정 정점 하나는 (진출-진입)=1, 다른 정점 하나는 (진입-진출)=1이고 나머지는 같으면 오일러 경로가 존재.

##### 4.2.11.2. 플뢰리 (Fleury) 알고리즘 개요

오일러 경로/회로를 찾는 알고리즘 중 하나입니다.
