### 7.1. 그래프 (Graph)

그래프는 객체(정점 또는 노드)와 이들을 연결하는 관계(간선)를 표현하는 비선형 자료구조입니다. 복잡한 연결 관계를 모델링하고 분석하는 데 사용됩니다.

#### 7.1.1. 그래프의 개념과 용어 (심화)

그래프는 **정점(Vertex)** 또는 **노드(Node)**라 불리는 개체들의 집합과, 이들을 연결하는 **간선(Edge)** 또는 **링크(Link)**의 집합으로 구성된 자료구조입니다. `G = (V, E)`로 표기하며, V는 정점의 집합, E는 간선의 집합을 의미합니다. 그래프는 현실 세계의 복잡한 관계망(예: 소셜 네트워크, 도로망, 웹 페이지 연결)을 모델링하는 데 매우 유용합니다.

##### 1. 그래프의 기본 구성 요소

*   **정점 (Vertex / Node)**: 데이터를 표현하는 개체입니다. 지도 위의 도시, 소셜 네트워크의 사용자, 웹의 페이지 등이 정점의 예가 될 수 있습니다.
*   **간선 (Edge / Link / Arc)**: 두 정점 간의 관계를 나타냅니다. 간선은 방향성을 가질 수도 있고, 가중치를 가질 수도 있습니다.
    *   **인접 (Adjacency)**: 두 정점이 간선으로 직접 연결되어 있을 때, 이 두 정점은 **인접해 있다**고 말합니다.
    *   **부속 (Incidence)**: 한 정점이 특정 간선의 끝점일 때, 이 정점은 간선에 **부속되어 있다**고 합니다.

##### 2. 그래프의 종류

그래프는 간선의 특성에 따라 다양하게 분류됩니다.

*   **방향성에 따른 분류**
    *   **무방향 그래프 (Undirected Graph)**: 간선에 방향이 없는 그래프입니다. 두 정점 `(u, v)`를 잇는 간선은 `u`에서 `v`로도, `v`에서 `u`로도 갈 수 있음을 의미합니다. (예: 페이스북 친구 관계, 양방향 도로)
    *   **방향 그래프 (Directed Graph / Digraph)**: 간선에 방향이 있는 그래프입니다. 간선 `(u, v)`는 `u`에서 `v`로만 갈 수 있는 **아크(Arc)**를 의미합니다. (예: 트위터 팔로우 관계, 일방통행 도로)

*   **가중치에 따른 분류**
    *   **가중치 그래프 (Weighted Graph)**: 각 간선에 숫자 값(가중치, 비용, 거리 등)이 할당된 그래프입니다. (예: 도시 간의 이동 비용/거리를 나타내는 도로망)
    *   **비가중치 그래프 (Unweighted Graph)**: 모든 간선의 가중치가 동일하거나(보통 1로 간주), 가중치를 고려하지 않는 그래프입니다.

*   **연결 형태에 따른 분류**
    *   **단순 그래프 (Simple Graph)**: 두 정점 사이에 최대 하나의 간선만 존재하고, 자기 자신을 가리키는 **루프(Self-loop)**가 없는 그래프입니다. 대부분의 알고리즘은 단순 그래프를 가정합니다.
    *   **다중 그래프 (Multigraph)**: 두 정점 사이에 여러 개의 간선이 존재할 수 있는 그래프입니다. (예: 두 도시를 잇는 여러 항공 노선)
    *   **유사 그래프 (Pseudograph)**: 다중 그래프의 속성을 가지면서 루프도 허용하는 그래프입니다.

##### 3. 정점과 간선의 속성

*   **차수 (Degree)**: 한 정점에 연결된 간선의 개수입니다.
    *   **무방향 그래프**: 정점 `v`의 차수는 `deg(v)`로 표기합니다.
    *   **방향 그래프**:
        *   **진입 차수 (In-degree)**: 외부에서 해당 정점으로 들어오는 간선의 수입니다.
        *   **진출 차수 (Out-degree)**: 해당 정점에서 외부로 나가는 간선의 수입니다.
    *   **핸드셰이킹 정리 (Handshaking Lemma)**: 그래프의 모든 정점의 차수의 합은 간선 수의 두 배와 같습니다. (`Σ deg(v) = 2 * |E|`)

##### 4. 경로와 연결성

*   **경로 (Path)**: 한 정점에서 다른 정점으로 가는 간선들의 순차적인 나열입니다.
    *   **경로 길이 (Path Length)**: 경로에 포함된 간선의 수 (가중치 그래프에서는 가중치의 합).
    *   **단순 경로 (Simple Path)**: 시작과 끝 정점을 제외하고 중복되는 정점이 없는 경로입니다.

*   **사이클 (Cycle)**: 시작 정점과 끝 정점이 같은 경로입니다.
    *   **단순 사이클 (Simple Cycle)**: 시작과 끝 정점을 제외하고 중복되는 정점이 없는 사이클입니다.
    *   **비순환 그래프 (Acyclic Graph)**: 사이클이 없는 그래프를 의미합니다. 특히 **방향 비순환 그래프(Directed Acyclic Graph, DAG)**는 위상 정렬 등 여러 알고리즘에서 중요하게 다뤄집니다.

*   **연결성 (Connectivity)**
    *   **연결 그래프 (Connected Graph)** (무방향): 임의의 두 정점 사이에 항상 경로가 존재하는 그래프입니다.
    *   **연결 요소 (Connected Component)** (무방향): 연결 그래프의 최대 부분 그래프입니다. 비연결 그래프는 여러 개의 연결 요소로 구성됩니다.
    *   **강한 연결 (Strongly Connected)** (방향): 방향 그래프 내의 모든 정점 쌍 `(u, v)`에 대해, `u`에서 `v`로 가는 경로와 `v`에서 `u`로 가는 경로가 모두 존재하는 경우입니다.
    *   **약한 연결 (Weakly Connected)** (방향): 그래프의 모든 방향성을 무시했을 때(무방향 그래프로 변환했을 때) 연결 그래프가 되는 경우입니다.

##### 5. 부분 그래프

*   **부분 그래프 (Subgraph)**: 어떤 그래프 `G=(V, E)`에 대해, 정점 집합 `V'`가 `V`의 부분집합이고 간선 집합 `E'`가 `E`의 부분집합인 그래프 `G'=(V', E')`를 의미합니다.
*   **신장 부분 그래프 (Spanning Subgraph)**: 원래 그래프의 **모든 정점**을 포함하는 부분 그래프입니다. **최소 신장 트리(MST)**는 대표적인 신장 부분 그래프의 한 종류입니다.

#### 7.1.2. 그래프 표현 방식 (인접 행렬, 인접 리스트)

그래프는 컴퓨터 메모리에 저장되고 알고리즘에 의해 처리되기 위해 특정 방식으로 표현되어야 합니다. 주로 **인접 행렬(Adjacency Matrix)**과 **인접 리스트(Adjacency List)** 두 가지 방식이 사용됩니다. 각 방식은 장단점이 명확하여 그래프의 특성(정점 및 간선의 수)에 따라 적절한 것을 선택하는 것이 중요합니다.

##### 1. 인접 행렬 (Adjacency Matrix)

`V`개의 정점을 가진 그래프를 `V x V` 크기의 2차원 배열(행렬)로 표현하는 방식입니다. `matrix[i][j]`는 정점 `i`와 정점 `j` 사이의 연결 관계를 나타냅니다.

*   **표현 방식**:
    *   **무방향/비가중치 그래프**: `matrix[i][j] = 1`이면 `i`와 `j`가 연결되어 있음을 의미하고, `0`이면 연결되어 있지 않음을 의미합니다. 무방향 그래프의 경우 `matrix[i][j] = matrix[j][i]`로 대칭 행렬이 됩니다.
    *   **방향/비가중치 그래프**: `matrix[i][j] = 1`이면 `i`에서 `j`로 가는 간선이 있음을 의미합니다. `j`에서 `i`로 가는 간선이 없다면 `matrix[j][i]`는 `0`이 됩니다.
    *   **가중치 그래프**: `matrix[i][j]`에 간선의 가중치 값을 저장합니다. 연결되어 있지 않은 경우 `0` 또는 무한대(`∞`) 값을 사용합니다.

*   **장점**:
    *   두 정점 `i`와 `j` 사이에 간선이 존재하는지 여부를 `O(1)` 시간에 즉시 확인할 수 있습니다.
    *   간선 추가 및 삭제가 `O(1)` 시간에 가능합니다.
    *   구현이 비교적 간단합니다.

*   **단점**:
    *   **공간 복잡도**: 항상 `O(V^2)`의 공간을 필요로 합니다. 정점의 수가 많아지면 메모리 낭비가 심해집니다.
    *   **희소 그래프(Sparse Graph)**: 간선의 수가 정점 수에 비해 매우 적은 그래프에서는 대부분의 행렬 원소가 `0`이 되어 메모리 효율성이 매우 떨어집니다.
    *   모든 간선을 탐색하려면 `V^2`번의 반복이 필요합니다.

*   **적합한 경우**: 간선이 많은 **밀집 그래프(Dense Graph)**에 적합합니다.

```python
# 인접 행렬 예시 (무방향, 비가중치 그래프)
# 정점: 0, 1, 2, 3
# 간선: (0,1), (0,2), (1,3), (2,3)
adj_matrix_undirected = [
    [0, 1, 1, 0],  # 0번 정점: 1, 2와 연결
    [1, 0, 0, 1],  # 1번 정점: 0, 3과 연결
    [1, 0, 0, 1],  # 2번 정점: 0, 3과 연결
    [0, 1, 1, 0]   # 3번 정점: 1, 2와 연결
]

# 인접 행렬 예시 (방향, 가중치 그래프)
# 정점: 0, 1, 2
# 간선: 0->1 (가중치 5), 0->2 (가중치 3), 1->2 (가중치 2)
# 연결되지 않은 경우 무한대(float('inf')) 사용
adj_matrix_directed_weighted = [
    [0,   5,   3],
    [float('inf'), 0,   2],
    [float('inf'), float('inf'), 0]
]
```

##### 2. 인접 리스트 (Adjacency List)

각 정점에 연결된 다른 정점들을 리스트(또는 배열, 연결 리스트) 형태로 저장하는 방식입니다. 파이썬에서는 딕셔너리(Dictionary)와 리스트를 조합하여 구현하는 것이 일반적입니다.

*   **표현 방식**:
    *   **무방향/비가중치 그래프**: 각 정점 `u`에 대해 `u`와 연결된 모든 정점 `v`를 `u`의 리스트에 추가합니다. 무방향이므로 `v`의 리스트에도 `u`를 추가해야 합니다.
    *   **방향/비가중치 그래프**: 각 정점 `u`에 대해 `u`에서 나가는 간선 `(u, v)`가 있다면 `v`를 `u`의 리스트에 추가합니다.
    *   **가중치 그래프**: 리스트에 `(연결된 정점, 가중치)` 형태의 튜플이나 객체를 저장합니다.

*   **장점**:
    *   **공간 복잡도**: `O(V + E)`의 공간을 필요로 합니다. 정점의 수와 간선의 수에 비례하므로 희소 그래프에서 메모리 효율성이 뛰어납니다.
    *   특정 정점과 연결된 모든 간선을 탐색하는 데 `O(degree)` 시간이 소요되어 효율적입니다.
    *   간선이 적은 그래프에서 유리합니다.

*   **단점**:
    *   두 정점 `i`와 `j` 사이에 간선이 존재하는지 여부를 확인하려면 `i`의 인접 리스트를 순회해야 하므로 최악의 경우 `O(degree)` 시간이 소요됩니다.
    *   구현이 인접 행렬보다 약간 복잡할 수 있습니다.

*   **적합한 경우**: 간선이 적은 **희소 그래프(Sparse Graph)**에 적합합니다. 대부분의 실제 그래프(소셜 네트워크, 웹 그래프)는 희소 그래프이므로 인접 리스트가 더 자주 사용됩니다.

```python
# 인접 리스트 예시 (무방향, 비가중치 그래프)
# 정점: A, B, C, D, E, F
# 간선: (A,B), (A,C), (B,D), (B,E), (C,F), (E,F)
adj_list_undirected = {
    'A': ['B', 'C'],
    'B': ['A', 'D', 'E'],
    'C': ['A', 'F'],
    'D': ['B'],
    'E': ['B', 'F'],
    'F': ['C', 'E']
}

# 인접 리스트 예시 (방향, 가중치 그래프)
# 정점: 0, 1, 2
# 간선: 0->1 (가중치 5), 0->2 (가중치 3), 1->2 (가중치 2)
adj_list_directed_weighted = {
    0: [(1, 5), (2, 3)],
    1: [(2, 2)],
    2: []
}
```

##### 3. 인접 행렬 vs. 인접 리스트 비교

| 특징         | 인접 행렬 (Adjacency Matrix)                               | 인접 리스트 (Adjacency List)                               |
| :----------- | :--------------------------------------------------------- | :--------------------------------------------------------- |
| **공간 복잡도** | `O(V^2)`                                                   | `O(V + E)`                                                 |
| **간선 존재 확인** | `O(1)`                                                     | `O(degree)` (최악 `O(V)`)                                  |
| **모든 간선 탐색** | `O(V^2)`                                                   | `O(V + E)`                                                 |
| **간선 추가/삭제** | `O(1)`                                                     | `O(1)` (리스트 끝에 추가), `O(degree)` (삭제)              |
| **적합한 그래프** | 밀집 그래프 (Dense Graph, `E`가 `V^2`에 가까운 경우)       | 희소 그래프 (Sparse Graph, `E`가 `V`에 가까운 경우)        |
| **구현 복잡도** | 간단                                                       | 비교적 복잡                                                |

#### 7.1.3. 그래프 탐색 (DFS, BFS)

그래프 탐색은 그래프 내의 모든 정점이나 특정 정점을 체계적으로 방문하는 과정입니다. 이는 그래프의 구조를 이해하고, 특정 정점을 찾거나, 경로를 발견하는 등 다양한 문제 해결의 기초가 됩니다. 대표적인 두 가지 탐색 알고리즘은 깊이 우선 탐색(DFS)과 너비 우선 탐색(BFS)입니다.

##### 1. 깊이 우선 탐색 (DFS, Depth-First Search)

DFS는 한 방향으로 가능한 한 깊이 탐색해 나가는 방식입니다. 더 이상 깊이 들어갈 수 없으면, 가장 최근에 방문했던 정점으로 되돌아와(백트랙) 다른 방향으로 탐색을 계속합니다. 마치 미로를 탐색할 때 한 길을 끝까지 가보고 막히면 되돌아오는 것과 유사합니다.

*   **동작 원리**:
    1.  시작 정점을 방문하고 방문했음을 표시합니다.
    2.  현재 정점과 인접한, 아직 방문하지 않은 정점을 선택하여 그 정점을 시작으로 다시 DFS를 수행합니다.
    3.  더 이상 방문할 인접 정점이 없으면, 이전 정점으로 되돌아갑니다.
    4.  모든 정점을 방문할 때까지 반복합니다.

*   **구현**: 주로 **재귀(Recursion)**를 사용하거나, **스택(Stack)** 자료구조를 명시적으로 사용하여 구현합니다.

*   **시간 복잡도**: `O(V + E)` (정점의 수 `V`, 간선의 수 `E`). 모든 정점과 간선을 한 번씩 방문합니다.
*   **공간 복잡도**: `O(V)` (재귀 스택 또는 명시적 스택의 깊이).

*   **활용**:
    *   **사이클 감지**: 방향 그래프에서 DFS 중 이미 방문했지만 현재 경로에 있는 정점을 다시 만나면 사이클이 존재합니다.
    *   **위상 정렬 (Topological Sort)**: 방향 비순환 그래프(DAG)에서 정점들의 선형 순서를 찾을 때 사용됩니다.
    *   **연결 요소 (Connected Components) 찾기**: 무방향 그래프에서 모든 정점을 방문할 때까지 DFS를 반복하여 연결된 부분 그래프들을 찾습니다.
    *   **강한 연결 요소 (Strongly Connected Components, SCC) 찾기**: 방향 그래프에서 SCC를 찾는 알고리즘(코사라주, 타잔)의 기반이 됩니다.
    *   **경로 찾기**: 특정 정점까지의 경로를 찾는 데 사용될 수 있습니다.

```python
# DFS 예시 (재귀)
def dfs_recursive(graph, start_node, visited):
    visited.add(start_node) # 현재 노드 방문 처리
    print(start_node, end=' ') # 방문 순서 출력

    # 현재 노드와 연결된 모든 이웃 노드에 대해
    for neighbor in graph.get(start_node, []):
        if neighbor not in visited: # 아직 방문하지 않았다면
            dfs_recursive(graph, neighbor, visited) # 재귀적으로 DFS 수행

# DFS 예시 (스택 사용 - 반복문)
def dfs_iterative(graph, start_node):
    visited = set()
    stack = [start_node] # 스택에 시작 노드 추가
    visited.add(start_node) # 시작 노드 방문 처리

    while stack:
        node = stack.pop() # 스택의 최상단 노드 꺼내기
        print(node, end=' ') # 방문 순서 출력

        # 현재 노드와 연결된 모든 이웃 노드에 대해 (역순으로 스택에 넣어야 순서가 맞을 수 있음)
        # 일반적으로는 순서에 상관없이 넣어도 됨
        for neighbor in reversed(graph.get(node, [])): # 역순으로 넣으면 pop할 때 순서대로 나옴
            if neighbor not in visited:
                visited.add(neighbor)
                stack.append(neighbor)

# 예시 그래프 (인접 리스트)
sample_graph = {
    'A': ['B', 'C'],
    'B': ['D', 'E'],
    'C': ['F'],
    'D': [],
    'E': ['F'],
    'F': []
}

print("DFS (재귀):")
dfs_recursive(sample_graph, 'A', set()) # 출력: A B D E F C
print("\nDFS (반복):")
dfs_iterative(sample_graph, 'A') # 출력: A C F B E D (스택 구현 방식에 따라 순서가 다를 수 있음)
print("\n")
```

##### 2. 너비 우선 탐색 (BFS, Breadth-First Search)

BFS는 시작 정점에서 가까운 정점부터 차례대로 탐색해 나가는 방식입니다. 마치 물결이 퍼져나가듯이, 시작점에서 한 칸 떨어진 모든 정점을 먼저 방문하고, 그 다음 두 칸 떨어진 모든 정점을 방문하는 식으로 진행됩니다.

*   **동작 원리**:
    1.  시작 정점을 큐(Queue)에 넣고 방문했음을 표시합니다.
    2.  큐에서 정점을 하나 꺼내고 방문 순서를 출력합니다.
    3.  꺼낸 정점과 인접한, 아직 방문하지 않은 모든 정점을 큐에 넣고 방문했음을 표시합니다.
    4.  큐가 빌 때까지 2-3번 과정을 반복합니다.

*   **구현**: **큐(Queue)** 자료구조를 사용하여 구현합니다.

*   **시간 복잡도**: `O(V + E)` (정점의 수 `V`, 간선의 수 `E`). 모든 정점과 간선을 한 번씩 방문합니다.
*   **공간 복잡도**: `O(V)` (큐에 저장될 수 있는 최대 정점 수).

*   **활용**:
    *   **최단 경로 (Shortest Path)**: 간선에 가중치가 없는 그래프에서 시작 정점으로부터 모든 다른 정점까지의 최단 경로(최소 간선 수)를 찾는 데 사용됩니다.
    *   **최단 거리**: 미로 찾기, 퍼즐 게임 등에서 최단 거리를 찾는 데 활용됩니다.
    *   **연결 요소 (Connected Components) 찾기**: DFS와 유사하게 연결 요소를 찾을 수 있습니다.
    *   **이분 그래프 (Bipartite Graph) 판별**: 그래프가 이분 그래프인지 판별하는 데 사용됩니다.
    *   **네트워크의 레벨 탐색**: 소셜 네트워크에서 '친구의 친구'처럼 특정 레벨에 있는 노드를 찾는 데 유용합니다.

```python
# BFS 예시
from collections import deque

def bfs_explore(graph, start_node):
    visited = set()
    queue = deque([start_node]) # 큐에 시작 노드 추가
    visited.add(start_node) # 시작 노드 방문 처리

    while queue:
        node = queue.popleft() # 큐의 맨 앞 노드 꺼내기
        print(node, end=' ') # 방문 순서 출력

        # 현재 노드와 연결된 모든 이웃 노드에 대해
        for neighbor in graph.get(node, []):
            if neighbor not in visited: # 아직 방문하지 않았다면
                visited.add(neighbor) # 방문 처리
                queue.append(neighbor) # 큐에 추가

# 예시 그래프 (위의 sample_graph 사용)
print("BFS:")
bfs_explore(sample_graph, 'A') # 출력: A B C D E F
print("\n")
```

##### 3. DFS와 BFS 비교

| 특징         | 깊이 우선 탐색 (DFS)                                       | 너비 우선 탐색 (BFS)                                       |
| :----------- | :--------------------------------------------------------- | :--------------------------------------------------------- |
| **탐색 순서** | 한 방향으로 깊게, 막히면 되돌아옴 (스택처럼 LIFO)          | 시작점에서 가까운 순서대로 (큐처럼 FIFO)                   |
| **사용 자료구조** | 스택 (재귀 호출 스택 또는 명시적 스택)                     | 큐 (Queue)                                                 |
| **최단 경로** | 간선 가중치 없는 최단 경로 보장 안 함                      | 간선 가중치 없는 최단 경로 보장 (최소 간선 수)             |
| **활용 예시** | 사이클 감지, 위상 정렬, 연결 요소, 백트래킹 기반 알고리즘 | 최단 경로 (비가중치), 미로 찾기, 이분 그래프 판별, 네트워크 레벨 탐색 |
| **메모리 사용** | 그래프의 깊이에 비례 (깊은 그래프에서 스택 오버플로우 가능) | 그래프의 너비에 비례 (넓은 그래프에서 메모리 많이 사용)    |

#### 7.1.4. 최단 경로 알고리즘

최단 경로 알고리즘은 그래프에서 두 정점 사이 또는 한 정점에서 다른 모든 정점까지의 가장 짧은 경로를 찾는 데 사용됩니다. 여기서 '짧다'는 것은 일반적으로 간선의 가중치(비용, 거리, 시간 등)의 합이 최소가 되는 것을 의미합니다. 최단 경로 문제는 크게 두 가지로 나눌 수 있습니다.

*   **단일 시작점 최단 경로 (Single-Source Shortest Path, SSSP)**: 특정 시작 정점에서 그래프 내의 다른 모든 정점까지의 최단 경로를 찾는 문제.
*   **모든 쌍 최단 경로 (All-Pairs Shortest Path, APSP)**: 그래프 내의 모든 정점 쌍 간의 최단 경로를 찾는 문제.

##### 7.1.4.1. 다익스트라 (Dijkstra) 알고리즘

다익스트라 알고리즘은 **단일 시작점 최단 경로**를 찾는 가장 널리 사용되는 알고리즘 중 하나입니다.

*   **핵심 아이디어**: 시작 정점에서부터 거리를 점진적으로 확장해나가며, 아직 방문하지 않은 정점 중 가장 거리가 짧은 정점을 선택하여 최단 거리를 확정합니다. 그리디(Greedy) 방식으로 동작합니다.
*   **가정/제한**: **음수 가중치 간선이 없는 그래프**에서만 정확하게 작동합니다. 음수 가중치 간선이 존재하면 잘못된 결과를 도출할 수 있습니다.
*   **동작 방식**:
    1.  시작 정점의 거리를 0으로, 나머지 정점의 거리를 무한대로 초기화합니다.
    2.  우선순위 큐(Priority Queue)에 (거리, 정점) 쌍을 저장하여 현재까지 발견된 최단 거리가 가장 짧은 정점을 효율적으로 선택합니다.
    3.  우선순위 큐에서 정점을 하나 꺼내고, 해당 정점을 통해 인접한 정점들의 거리를 갱신할 수 있는지 확인합니다. 갱신이 가능하다면 우선순위 큐에 추가합니다.
    4.  우선순위 큐가 빌 때까지 반복합니다.
*   **시간 복잡도**:
    *   우선순위 큐(이진 힙) 사용 시: `O(E log V)` (간선 `E`, 정점 `V`)
    *   인접 행렬 사용 시: `O(V^2)`
*   **공간 복잡도**: `O(V + E)` (인접 리스트 및 거리 배열, 우선순위 큐)
*   **활용**: GPS 내비게이션 시스템의 최단 경로 탐색, 네트워크 라우팅 프로토콜 (OSPF), 지하철 최단 경로 안내 등.

```python
import heapq

def dijkstra(graph, start):
    distances = {node: float('inf') for node in graph} # 모든 정점까지의 거리를 무한대로 초기화
    distances[start] = 0 # 시작 정점의 거리는 0

    priority_queue = [(0, start)] # (거리, 정점) 형태로 우선순위 큐에 삽입

    while priority_queue:
        current_distance, current_node = heapq.heappop(priority_queue) # 가장 거리가 짧은 정점 꺼내기

        # 이미 처리된 정점이거나, 현재 거리가 더 길다면 스킵
        if current_distance > distances[current_node]:
            continue

        # 현재 정점과 연결된 이웃 정점들을 탐색
        for neighbor, weight in graph[current_node].items():
            distance = current_distance + weight
            # 더 짧은 경로를 발견하면 거리 갱신 및 우선순위 큐에 추가
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances

# 예시 그래프 (인접 리스트, 딕셔너리 형태로 가중치 표현)
# {정점: {이웃정점: 가중치, ...}, ...}
dijkstra_graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {}
}

print("다익스트라 결과 (시작 A):", dijkstra(dijkstra_graph, 'A'))
# 예상 출력: {'A': 0, 'B': 1, 'C': 3, 'D': 4}
print("\n")
```

##### 7.1.4.2. 벨만-포드 (Bellman-Ford) 알고리즘

벨만-포드 알고리즘은 **단일 시작점 최단 경로**를 찾는 알고리즘으로, 다익스트라와 달리 **음수 가중치 간선**이 있는 그래프에서도 작동합니다. 또한, **음수 사이클(Negative Cycle)**의 존재 여부를 감지할 수 있습니다.

*   **핵심 아이디어**: 모든 간선을 `V-1`번 반복하여 이완(Relaxation) 작업을 수행합니다. `V-1`번 반복하면 모든 최단 경로가 확정됩니다. `V`번째 반복에서도 거리가 갱신된다면 음수 사이클이 존재함을 의미합니다.
*   **가정/제한**: 음수 가중치 간선이 허용되지만, 음수 사이클이 없는 경우에만 최단 경로를 찾습니다. 음수 사이클이 존재하면 최단 경로가 무한히 작아질 수 있으므로, 이를 감지하여 알려줍니다.
*   **동작 방식**:
    1.  시작 정점의 거리를 0으로, 나머지 정점의 거리를 무한대로 초기화합니다.
    2.  모든 간선에 대해 `V-1`번 반복하여 이완 작업을 수행합니다. (이완: `u`에서 `v`로 가는 간선 `(u, v)`에 대해 `dist[v] > dist[u] + weight(u, v)`이면 `dist[v]`를 갱신)
    3.  `V`번째 반복에서도 거리가 갱신되는 간선이 있다면, 음수 사이클이 존재합니다.
*   **시간 복잡도**: `O(VE)`
*   **공간 복잡도**: `O(V)` (거리 배열)
*   **활용**: 네트워크 라우팅 프로토콜 (RIP), 음수 가중치 간선이 있는 그래프에서의 최단 경로 문제 해결.

```python
def bellman_ford(graph, start):
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # V-1번 반복하여 모든 간선에 대해 이완 작업 수행
    for _ in range(len(graph) - 1):
        for u in graph:
            for v, weight in graph[u].items():
                if distances[u] != float('inf') and distances[u] + weight < distances[v]:
                    distances[v] = distances[u] + weight

    # V번째 반복에서 음수 사이클 감지
    for u in graph:
        for v, weight in graph[u].items():
            if distances[u] != float('inf') and distances[u] + weight < distances[v]:
                print("음수 사이클이 감지되었습니다!")
                return None # 음수 사이클이 있으면 최단 경로를 정의할 수 없음

    return distances

# 예시 그래프 (음수 가중치 포함)
bellman_ford_graph = {
    'A': {'B': 6, 'C': 7},
    'B': {'D': 5, 'E': -4},
    'C': {'D': -3, 'E': 9},
    'D': {},
    'E': {'A': 2} # 음수 사이클을 만들 수 있는 간선 (E->A)
}

print("벨만-포드 결과 (시작 A):", bellman_ford(bellman_ford_graph, 'A'))
# 예상 출력: {'A': 0, 'B': 6, 'C': 7, 'D': 4, 'E': 2} (음수 사이클이 없는 경우)

# 음수 사이클 예시 (E->A 간선을 -5로 변경)
bellman_ford_graph_neg_cycle = {
    'A': {'B': 6, 'C': 7},
    'B': {'D': 5, 'E': -4},
    'C': {'D': -3, 'E': 9},
    'D': {},
    'E': {'A': -5} # 음수 사이클: A -> B -> E -> A (6 + (-4) + (-5) = -3)
}
print("벨만-포드 결과 (음수 사이클, 시작 A):", bellman_ford(bellman_ford_graph_neg_cycle, 'A'))
print("\n")
```

##### 7.1.4.3. 플로이드-워셜 (Floyd-Warshall) 알고리즘

플로이드-워셜 알고리즘은 **모든 쌍 최단 경로**를 찾는 동적 계획법(Dynamic Programming) 기반의 알고리즘입니다.

*   **핵심 아이디어**: `k`를 거쳐가는 경로를 고려하여 모든 정점 쌍 `(i, j)` 간의 최단 거리를 점진적으로 갱신합니다. `k`는 중간에 거쳐갈 수 있는 정점의 번호를 의미하며, `0`부터 `V-1`까지 증가시킵니다.
*   **가정/제한**: 음수 가중치 간선이 허용되지만, 음수 사이클이 없는 경우에만 최단 경로를 찾습니다. 음수 사이클이 존재하면 해당 사이클에 포함된 정점들의 거리가 무한히 작아질 수 있습니다.
*   **동작 방식**:
    1.  `dist[i][j]`를 `i`에서 `j`로 가는 직접 간선의 가중치로 초기화합니다 (연결되지 않은 경우 무한대).
    2.  `k`를 `0`부터 `V-1`까지 반복합니다. (중간 정점)
    3.  `i`를 `0`부터 `V-1`까지 반복합니다. (시작 정점)
    4.  `j`를 `0`부터 `V-1`까지 반복합니다. (도착 정점)
    5.  `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`로 거리를 갱신합니다.
*   **시간 복잡도**: `O(V^3)`
*   **공간 복잡도**: `O(V^2)` (거리 행렬)
*   **활용**: 모든 정점 쌍 간의 최단 경로가 필요한 경우 (예: 교통 네트워크에서 모든 도시 간의 최단 거리), 전이 폐쇄(Transitive Closure) 계산.

```python
def floyd_warshall(graph):
    V = len(graph)
    # 거리 행렬 초기화: 직접 간선 가중치 또는 무한대
    dist = [[float('inf')] * V for _ in range(V)]
    for i in range(V):
        dist[i][i] = 0 # 자기 자신으로의 거리는 0

    # 초기 간선 가중치 설정
    for u in graph:
        for v, weight in graph[u].items():
            dist[u][v] = weight

    # k를 중간 정점으로 사용하여 최단 경로 갱신
    for k in range(V):
        for i in range(V):
            for j in range(V):
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])

    # 음수 사이클 감지 (선택 사항)
    for i in range(V):
        if dist[i][i] < 0:
            print("음수 사이클이 감지되었습니다!")
            return None

    return dist

# 예시 그래프 (인접 리스트, 정점은 0부터 V-1까지의 인덱스)

    1: {0: float('inf'), 2: 4, 3: 1},

}

# 정점 개수 V를 명시적으로 전달하거나 graph에서 추론
# 여기서는 딕셔너리 키를 정점 인덱스로 사용한다고 가정

    fw_graph_adj_matrix[u][u] = 0 # 자기 자신으로의 거리는 0

# 플로이드-워셜 함수는 인접 행렬 형태의 그래프를 받는 것이 일반적
```

#### 7.1.5. 최소 신장 트리 (Minimum Spanning Tree, MST)

최소 신장 트리(MST)는 연결된 **비방향 가중치 그래프**에서 모든 정점을 포함하면서 간선들의 가중치 합이 최소가 되는 **트리(Tree)**를 찾는 문제입니다. '신장(Spanning)'이라는 말은 그래프의 모든 정점을 포함한다는 의미이며, '최소(Minimum)'는 간선 가중치의 합이 가장 작다는 의미입니다. MST는 사이클을 포함하지 않으며, `V`개의 정점을 가진 그래프에서 `V-1`개의 간선을 가집니다.

*   **주요 특징**:
    *   연결된 그래프여야 합니다.
    *   사이클이 없습니다.
    *   모든 정점을 포함합니다.
    *   간선 가중치의 합이 최소입니다.
*   **활용**: 네트워크 설계 (최소 비용으로 모든 노드 연결), 통신망 구축, 도로망 설계, 클러스터링 알고리즘 등.

##### 7.1.5.1. 프림 (Prim) 알고리즘

프림 알고리즘은 시작 정점에서부터 트리를 점진적으로 확장해나가며 MST를 구성하는 **탐욕(Greedy) 알고리즘**입니다.

*   **핵심 아이디어**: 현재까지 구성된 MST에 인접한 간선들 중에서 가장 가중치가 작은 간선을 선택하여 MST에 추가합니다. 이 과정에서 새로운 정점이 MST에 포함됩니다.
*   **동작 방식**:
    1.  임의의 시작 정점을 선택하여 MST에 포함시킵니다.
    2.  MST에 포함된 정점들과 MST에 포함되지 않은 정점들을 연결하는 간선들 중에서 가중치가 가장 작은 간선을 선택합니다.
    3.  선택된 간선과 그 간선이 연결하는 새로운 정점을 MST에 추가합니다.
    4.  모든 정점이 MST에 포함될 때까지 2-3번 과정을 반복합니다.
*   **데이터 구조**: 효율적인 구현을 위해 **우선순위 큐(Priority Queue)**를 사용하여 MST에 추가할 다음 간선을 빠르게 찾습니다.
*   **시간 복잡도**:
    *   우선순위 큐(이진 힙) 사용 시: `O(E log V)`
    *   인접 행렬 사용 시: `O(V^2)`
*   **공간 복잡도**: `O(V + E)` (인접 리스트 및 우선순위 큐)
*   **적합한 경우**: 간선이 많은 **밀집 그래프(Dense Graph)**에 유리합니다.

```python
import heapq

def prim(graph, start_node):
    min_spanning_tree = [] # MST에 포함될 간선들
    visited = set() # MST에 포함된 정점들
    # (가중치, 시작 정점, 끝 정점) 형태로 우선순위 큐에 저장
    # 시작 노드와 연결된 모든 간선을 큐에 추가
    edges = [(weight, start_node, neighbor) for neighbor, weight in graph.get(start_node, {}).items()]
    heapq.heapify(edges) # 우선순위 큐로 변환

    visited.add(start_node) # 시작 노드 방문 처리

    while edges and len(visited) < len(graph):
        weight, u, v = heapq.heappop(edges) # 가장 가중치가 작은 간선 꺼내기

        if v not in visited: # 새로운 정점이라면
            visited.add(v) # 방문 처리
            min_spanning_tree.append((u, v, weight)) # MST에 간선 추가

            # 새로 추가된 정점 v와 연결된 간선들을 큐에 추가
            for neighbor, next_weight in graph.get(v, {}).items():
                if neighbor not in visited:
                    heapq.heappush(edges, (next_weight, v, neighbor))
    return min_spanning_tree

# 예시 그래프 (인접 리스트, 딕셔너리 형태로 가중치 표현)
# {정점: {이웃정점: 가중치, ...}, ...}
prim_graph = {
    'A': {'B': 7, 'D': 5},
    'B': {'A': 7, 'C': 8, 'D': 9, 'E': 7},
    'C': {'B': 8, 'E': 5},
    'D': {'A': 5, 'B': 9, 'E': 15, 'F': 6},
    'E': {'B': 7, 'C': 5, 'D': 15, 'F': 8, 'G': 9},
    'F': {'D': 6, 'E': 8, 'G': 11},
    'G': {'E': 9, 'F': 11}
}

print("프림 알고리즘 결과:")
mst_prim = prim(prim_graph, 'A')
for edge in mst_prim:
    print(f"{edge[0]} - {edge[1]} (가중치: {edge[2]})")
# 예상 출력 (순서는 다를 수 있음):
# A - D (가중치: 5)
# D - F (가중치: 6)
# F - E (가중치: 8) (또는 E - C (가중치: 5) 먼저)
# E - C (가중치: 5)
# E - B (가중치: 7)
# E - G (가중치: 9)
print("\n")
```

##### 7.1.5.2. 크루스칼 (Kruskal) 알고리즘

크루스칼 알고리즘은 그래프의 모든 간선들을 가중치에 따라 정렬한 후, 가장 가중치가 작은 간선부터 선택하여 MST를 구성하는 **탐욕(Greedy) 알고리즘**입니다. 이때 사이클이 형성되지 않도록 주의합니다.

*   **핵심 아이디어**: 간선들을 가중치 오름차순으로 정렬하고, 정렬된 간선들을 하나씩 확인하면서 사이클을 형성하지 않는 간선만 MST에 추가합니다.
*   **동작 방식**:
    1.  그래프의 모든 간선을 추출하여 가중치에 따라 오름차순으로 정렬합니다.
    2.  각 정점을 독립적인 집합으로 초기화합니다 (분리 집합 자료구조 사용).
    3.  정렬된 간선들을 순회하면서, 현재 간선이 연결하는 두 정점이 서로 다른 집합에 속해 있다면 (즉, 사이클을 형성하지 않는다면) 해당 간선을 MST에 추가하고 두 집합을 합칩니다.
    4.  `V-1`개의 간선이 MST에 추가될 때까지 반복합니다.
*   **데이터 구조**: **분리 집합(Disjoint Set / Union-Find)** 자료구조를 사용하여 사이클 형성 여부를 효율적으로 확인하고 집합을 합칩니다.
*   **시간 복잡도**: `O(E log E)` 또는 `O(E log V)` (간선 정렬 시간 `O(E log E)`가 지배적이며, `log E`는 `log V^2 = 2 log V`이므로 `O(E log V)`로도 표현 가능)
*   **공간 복잡도**: `O(V + E)` (간선 리스트 및 분리 집합)
*   **적합한 경우**: 간선이 적은 **희소 그래프(Sparse Graph)**에 유리합니다.

```python
# 분리 집합 (Union-Find) 자료구조 구현
class DisjointSet:
    def __init__(self, vertices):
        self.parent = {v: v for v in vertices}
        self.rank = {v: 0 for v in vertices} # 트리의 높이 또는 크기

    def find(self, item):
        if self.parent[item] == item:
            return item
        self.parent[item] = self.find(self.parent[item]) # 경로 압축
        return self.parent[item]

    def union(self, set1, set2):
        root1 = self.find(set1)
        root2 = self.find(set2)

        if root1 != root2:
            # 랭크(높이)를 이용한 합치기 (Union by Rank)
            if self.rank[root1] < self.rank[root2]:
                self.parent[root1] = root2
            elif self.rank[root1] > self.rank[root2]:
                self.parent[root2] = root1
            else:
                self.parent[root2] = root1
                self.rank[root1] += 1
            return True # 합치기 성공
        return False # 이미 같은 집합에 속함 (사이클 형성)

def kruskal(graph):
    min_spanning_tree = []
    all_edges = []
    vertices = set()

    # 모든 간선 추출 및 정점 집합 생성
    for u in graph:
        vertices.add(u)
        for v, weight in graph[u].items():
            all_edges.append((weight, u, v))
            vertices.add(v)

    # 간선을 가중치 기준으로 오름차순 정렬
    all_edges.sort()

    # 분리 집합 초기화
    disjoint_set = DisjointSet(list(vertices))

    # 정렬된 간선들을 순회하며 MST 구성
    for weight, u, v in all_edges:
        if disjoint_set.union(u, v): # 사이클을 형성하지 않으면
            min_spanning_tree.append((u, v, weight)) # MST에 간선 추가
            if len(min_spanning_tree) == len(vertices) - 1: # V-1개의 간선이 모이면 종료
                break
    return min_spanning_tree

# 예시 그래프 (위의 prim_graph와 동일)
print("크루스칼 알고리즘 결과:")
mst_kruskal = kruskal(prim_graph)
for edge in mst_kruskal:
    print(f"{edge[1]} - {edge[2]} (가중치: {edge[0]})")
# 예상 출력 (순서는 다를 수 있음):
# A - D (가중치: 5)
# C - E (가중치: 5)
# D - F (가중치: 6)
# B - E (가중치: 7)
# F - E (가중치: 8) (또는 E - G (가중치: 9) 먼저)
# E - G (가중치: 9)
print("\n")
```

##### 7.1.5.3. 프림 vs. 크루스칼 비교

| 특징         | 프림 (Prim) 알고리즘                                       | 크루스칼 (Kruskal) 알고리즘                                |
| :----------- | :--------------------------------------------------------- | :--------------------------------------------------------- |
| **접근 방식** | 정점 중심 (MST를 확장해나감)                               | 간선 중심 (가장 작은 간선부터 선택)                        |
| **데이터 구조** | 우선순위 큐 (Priority Queue)                               | 분리 집합 (Disjoint Set / Union-Find)                      |
| **시간 복잡도** | `O(E log V)` 또는 `O(V^2)`                                | `O(E log E)` 또는 `O(E log V)`                            |
| **적합한 그래프** | 밀집 그래프 (Dense Graph)                                  | 희소 그래프 (Sparse Graph)                                 |
| **구현 복잡도** | 우선순위 큐 사용 시 비교적 간단                            | 분리 집합 구현이 필요하여 약간 더 복잡                     |
| **연결성 요구** | 시작 시 연결된 그래프여야 함                               | 간선 정렬 후 연결성 확인 (부분적으로 연결되지 않아도 시작 가능) |

#### 7.1.6. 위상 정렬 (Topological Sort)

위상 정렬(Topological Sort)은 **방향 비순환 그래프(DAG, Directed Acyclic Graph)**의 정점들을 방향성에 거스르지 않도록 선형적으로 나열하는 알고리즘입니다. 즉, 모든 방향 간선 `u -> v`에 대해 정렬된 순서에서 `u`가 `v`보다 항상 먼저 오도록 정점들을 배치하는 것입니다. 사이클이 존재하는 그래프에서는 위상 정렬이 불가능합니다.

##### 7.1.6.1. 개념 및 활용

*   **개념**: 정점들 간의 선행(precedence) 관계를 만족하는 순서를 찾는 것입니다. 예를 들어, 어떤 작업을 시작하기 전에 반드시 완료되어야 하는 선행 작업이 있을 때, 이 작업들의 순서를 정하는 데 사용됩니다.
*   **활용**:
    *   **프로젝트 작업 순서 결정**: 여러 작업 간의 의존성이 있을 때, 모든 작업을 수행할 수 있는 순서를 결정합니다. (예: 소프트웨어 빌드 시스템, 요리 레시피)
    *   **컴파일러의 컴파일 순서 결정**: 모듈 간의 의존성을 분석하여 컴파일 순서를 정합니다.
    *   **데이터베이스의 트랜잭션 스케줄링**: 트랜잭션 간의 의존성을 고려하여 실행 순서를 결정합니다.
    *   **과목 선수 과목 시스템**: 특정 과목을 수강하기 전에 들어야 할 과목들의 순서를 정합니다.

##### 7.1.6.2. 위상 정렬 알고리즘

위상 정렬을 수행하는 대표적인 두 가지 방법이 있습니다.

###### 1. 칸(Kahn) 알고리즘 (진입 차수 활용)

이 알고리즘은 진입 차수(In-degree)를 사용하여 위상 정렬을 수행합니다.

*   **핵심 아이디어**: 진입 차수가 0인 정점(즉, 선행 작업이 없는 정점)부터 시작하여, 해당 정점을 제거하면서 연결된 정점들의 진입 차수를 감소시킵니다. 진입 차수가 0이 된 정점들을 다시 큐에 추가하는 과정을 반복합니다.
*   **동작 방식**:
    1.  모든 정점의 진입 차수를 계산합니다.
    2.  진입 차수가 0인 모든 정점을 큐(Queue)에 넣습니다.
    3.  큐가 빌 때까지 다음을 반복합니다:
        *   큐에서 정점 `u`를 꺼내 위상 정렬 결과 리스트에 추가합니다.
        *   `u`에 연결된 모든 이웃 정점 `v`에 대해 `v`의 진입 차수를 1 감소시킵니다.
        *   만약 `v`의 진입 차수가 0이 되면, `v`를 큐에 추가합니다.
    4.  위상 정렬 결과 리스트의 길이가 전체 정점의 수와 같지 않다면, 그래프에 사이클이 존재하여 위상 정렬이 불가능합니다.
*   **시간 복잡도**: `O(V + E)` (정점의 수 `V`, 간선의 수 `E`)
*   **공간 복잡도**: `O(V + E)` (인접 리스트, 진입 차수 배열, 큐)

```python
from collections import deque

def topological_sort_kahn(graph):
    in_degree = {u: 0 for u in graph} # 모든 정점의 진입 차수 초기화
    for u in graph:
        for v in graph[u]:
            in_degree[v] += 1 # 간선 u -> v 에 대해 v의 진입 차수 증가

    queue = deque()
    for u in graph:
        if in_degree[u] == 0: # 진입 차수가 0인 정점들을 큐에 추가
            queue.append(u)

    result = []
    while queue:
        u = queue.popleft()
        result.append(u)

        for v in graph[u]:
            in_degree[v] -= 1 # u에 연결된 v의 진입 차수 감소
            if in_degree[v] == 0: # 진입 차수가 0이 되면 큐에 추가
                queue.append(v)

    if len(result) == len(graph): # 모든 정점이 정렬되었다면
        return result
    else:
        return "그래프에 사이클이 존재하여 위상 정렬이 불가능합니다."

# 예시 그래프 (인접 리스트)
# A -> B, A -> C, B -> D, C -> D, D -> E
dag_graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': ['E'],
    'E': []
}

print("칸 알고리즘 위상 정렬 결과:", topological_sort_kahn(dag_graph))
# 예상 출력: ['A', 'C', 'B', 'D', 'E'] 또는 ['A', 'B', 'C', 'D', 'E'] (순서는 다를 수 있음)

# 사이클이 있는 그래프 예시 (D -> A 추가)
dag_graph_with_cycle = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': ['D'],
    'D': ['E', 'A'], # D -> A 추가
    'E': []
}
print("사이클 있는 그래프 위상 정렬 결과:", topological_sort_kahn(dag_graph_with_cycle))
print("\n")
```

###### 2. DFS 기반 알고리즘

이 알고리즘은 깊이 우선 탐색(DFS)을 활용하여 위상 정렬을 수행합니다.

*   **핵심 아이디어**: DFS를 수행하면서 모든 자식 정점들을 방문한 후에야 현재 정점을 위상 정렬 결과 리스트의 맨 앞에 추가합니다. 이는 DFS가 끝나는 순서의 역순이 위상 정렬 순서가 됨을 이용합니다.
*   **동작 방식**:
    1.  `visited` 배열을 사용하여 각 정점의 방문 상태(미방문, 방문 중, 방문 완료)를 추적합니다.
    2.  모든 정점에 대해 DFS를 수행합니다.
    3.  DFS 함수 내에서, 현재 정점 `u`를 방문 중으로 표시하고, `u`의 모든 이웃 정점 `v`에 대해 재귀적으로 DFS를 호출합니다.
    4.  `u`의 모든 이웃 정점 방문이 완료되면, `u`를 방문 완료로 표시하고 위상 정렬 결과 리스트의 맨 앞에 추가합니다.
    5.  DFS 중 이미 방문 중인 정점을 다시 만나면 사이클이 존재함을 의미합니다.
*   **시간 복잡도**: `O(V + E)`
*   **공간 복잡도**: `O(V)` (재귀 스택 및 방문 배열)

```python
def topological_sort_dfs(graph):
    visited = {u: 0 for u in graph} # 0: 미방문, 1: 방문 중, 2: 방문 완료
    result = [] # 위상 정렬 결과 (역순으로 추가됨)

    def dfs_util(u):
        visited[u] = 1 # 방문 중으로 표시

        for v in graph[u]:
            if visited[v] == 0: # 미방문이면 재귀 호출
                if not dfs_util(v): # 사이클 감지 시 False 반환
                    return False
            elif visited[v] == 1: # 방문 중인 정점을 다시 만나면 사이클
                return False
        
        visited[u] = 2 # 방문 완료로 표시
        result.append(u) # 결과 리스트의 맨 앞에 추가 (DFS 종료 순서의 역순)
        return True

    for u in graph:
        if visited[u] == 0: # 미방문 정점에 대해 DFS 시작
            if not dfs_util(u):
                return "그래프에 사이클이 존재하여 위상 정렬이 불가능합니다."
    
    return result[::-1] # 역순으로 반환하여 올바른 위상 정렬 순서 생성

# 예시 그래프 (위의 dag_graph와 동일)
print("DFS 기반 위상 정렬 결과:", topological_sort_dfs(dag_graph))
# 예상 출력: ['A', 'B', 'C', 'D', 'E'] 또는 ['A', 'C', 'B', 'D', 'E']

# 사이클이 있는 그래프 예시 (D -> A 추가)
print("사이클 있는 그래프 DFS 기반 위상 정렬 결과:", topological_sort_dfs(dag_graph_with_cycle))
print("\n")
```

#### 7.1.7. 네트워크 플로우 (Network Flow)

네트워크 플로우는 유량 네트워크(Flow Network)에서 소스(Source)에서 싱크(Sink)로 흐를 수 있는 최대 유량을 찾는 문제를 다루는 분야입니다. 이는 자원의 흐름을 모델링하고 최적화하는 데 사용되는 강력한 도구입니다.

##### 7.1.7.1. 유량 네트워크의 개념

*   **유량 네트워크 (Flow Network)**: 각 간선에 **용량(Capacity)**이 할당된 방향 그래프 `G = (V, E)`입니다.
    *   **소스 (Source, `s`)**: 유량이 시작되는 정점.
    *   **싱크 (Sink, `t`)**: 유량이 끝나는 정점.
    *   **용량 (Capacity, `c(u, v)`)**: 간선 `(u, v)`를 통해 흐를 수 있는 최대 유량.
*   **유량 (Flow, `f(u, v)`)**: 간선 `(u, v)`를 통해 실제로 흐르는 유량. 다음 조건을 만족해야 합니다.
    *   **용량 제약 조건**: `0 <= f(u, v) <= c(u, v)` (간선을 통해 흐르는 유량은 용량을 초과할 수 없습니다.)
    *   **유량 보존 법칙**: 소스와 싱크를 제외한 모든 정점에서, 들어오는 유량의 총합은 나가는 유량의 총합과 같습니다. (`Σ f(v, u) = Σ f(u, v)` for all `u ≠ s, t`)
*   **네트워크의 총 유량**: 소스에서 나가는 총 유량 또는 싱크로 들어오는 총 유량.

##### 7.1.7.2. 최대 유량 (Maximum Flow) 문제

주어진 유량 네트워크에서 소스 `s`에서 싱크 `t`로 보낼 수 있는 **최대 유량**을 찾는 문제입니다. 이는 네트워크의 처리 능력을 최대로 활용하는 방법을 찾는 것과 같습니다.

##### 7.1.7.3. 최소 컷 (Minimum Cut) 정리

**최대 유량-최소 컷 정리(Max-Flow Min-Cut Theorem)**는 네트워크 플로우 이론의 가장 중요한 정리 중 하나입니다. 이 정리에 따르면, 유량 네트워크에서 소스 `s`에서 싱크 `t`로 보낼 수 있는 **최대 유량의 값은 `s`와 `t`를 분리하는 모든 컷(Cut) 중에서 용량이 가장 작은 최소 컷의 용량과 같습니다.**

*   **컷 (Cut)**: 정점 집합 `V`를 두 개의 서로소인 부분 집합 `S`와 `T`로 분할하는 것입니다. 이때 `s ∈ S`이고 `t ∈ T`여야 합니다.
*   **컷의 용량 (Capacity of a Cut)**: `S`에서 `T`로 향하는 모든 간선들의 용량 합.

이 정리는 최대 유량 문제를 최소 컷 문제로 변환하여 해결할 수 있음을 보여주며, 다양한 조합 최적화 문제에 응용됩니다.

##### 7.1.7.4. 포드-풀커슨 (Ford-Fulkerson) 알고리즘

포드-풀커슨 방법은 최대 유량을 찾는 일반적인 프레임워크입니다.

*   **핵심 아이디어**: 잔여 네트워크(Residual Network)에서 소스 `s`에서 싱크 `t`로 가는 증가 경로(Augmenting Path)를 반복적으로 찾아 유량을 증가시킵니다.
    *   **잔여 네트워크 (Residual Network)**: 현재 유량 상태에서 각 간선이 추가적으로 얼마나 많은 유량을 더 보낼 수 있는지(잔여 용량)와, 보냈던 유량을 되돌릴 수 있는 가상의 역방향 간선(역방향 용량)을 나타내는 그래프입니다.
    *   **증가 경로 (Augmenting Path)**: 잔여 네트워크에서 `s`에서 `t`로 가는 경로로, 이 경로를 따라 유량을 더 보낼 수 있습니다.
*   **동작 방식**:
    1.  초기 유량을 모든 간선에 대해 0으로 설정합니다.
    2.  잔여 네트워크를 구성합니다.
    3.  잔여 네트워크에서 `s`에서 `t`로 가는 증가 경로를 찾습니다 (DFS 또는 BFS 사용).
    4.  증가 경로가 존재하면, 해당 경로를 통해 보낼 수 있는 최대 유량(경로의 최소 잔여 용량)을 찾아 네트워크의 총 유량에 더하고, 간선들의 유량과 잔여 용량을 갱신합니다.
    5.  증가 경로를 더 이상 찾을 수 없을 때까지 2-4번 과정을 반복합니다.
*   **시간 복잡도**: 증가 경로를 찾는 방법에 따라 달라집니다.
    *   DFS 사용 시: `O(E * f_max)` (f_max는 최대 유량 값). 용량이 정수일 때만 유한하며, 비효율적일 수 있습니다.
*   **활용**: 최대 유량 문제의 기본적인 이해와 구현에 사용됩니다.

```python
from collections import deque

def bfs_find_path(graph, source, sink, parent):
    """BFS를 사용하여 잔여 네트워크에서 증가 경로를 찾습니다."""
    visited = {node: False for node in graph}
    queue = deque([source])
    visited[source] = True

    while queue:
        u = queue.popleft()
        for v, capacity in graph[u].items():
            if not visited[v] and capacity > 0: # 방문하지 않았고, 잔여 용량이 있다면
                visited[v] = True
                parent[v] = u # 경로 추적을 위해 부모 저장
                queue.append(v)
                if v == sink:
                    return True # 싱크에 도달하면 경로 찾기 성공
    return False

def ford_fulkerson(graph, source, sink):
    """Ford-Fulkerson 알고리즘 (Edmonds-Karp 구현 - BFS 사용)"""
    # 잔여 그래프 초기화 (원본 그래프의 용량을 복사)
    # graph[u][v]는 u->v 간선의 용량
    # residual_graph[u][v]는 u->v의 잔여 용량
    # residual_graph[v][u]는 v->u의 역방향 잔여 용량 (초기 0)
    residual_graph = {u: {v: graph[u].get(v, 0) for v in graph} for u in graph}
    for u in graph:
        for v in graph[u]:
            if v not in residual_graph:
                residual_graph[v] = {}
            if u not in residual_graph[v]:
                residual_graph[v][u] = 0 # 역방향 간선 초기화

    max_flow = 0
    parent = {node: -1 for node in graph} # 경로 추적을 위한 부모 배열

    while bfs_find_path(residual_graph, source, sink, parent):
        # 증가 경로를 통해 보낼 수 있는 최소 잔여 용량 (bottleneck capacity) 찾기
        path_flow = float('inf')
        s = sink
        while s != source:
            path_flow = min(path_flow, residual_graph[parent[s]][s])
            s = parent[s]

        # 증가 경로를 따라 유량 갱신
        max_flow += path_flow
        v = sink
        while v != source:
            u = parent[v]
            residual_graph[u][v] -= path_flow # 정방향 간선 용량 감소
            residual_graph[v][u] += path_flow # 역방향 간선 용량 증가
            v = parent[v]
    return max_flow

# 예시 그래프 (인접 리스트, 용량 표현)
# {정점: {이웃정점: 용량, ...}, ...}
flow_graph = {
    's': {'A': 10, 'B': 10},
    'A': {'C': 4, 'B': 2, 'D': 8},
    'B': {'D': 9},
    'C': {'t': 10},
    'D': {'C': 6, 't': 10},
    't': {}
}

print("최대 유량 (Ford-Fulkerson):", ford_fulkerson(flow_graph, 's', 't'))
# 예상 출력: 19
print("\n")
```

##### 7.1.7.5. 에드몬드-카프 (Edmonds-Karp) 알고리즘

에드몬드-카프 알고리즘은 포드-풀커슨 방법의 특정 구현으로, 증가 경로를 찾을 때 **BFS(너비 우선 탐색)**를 사용하여 최단 경로(간선 수가 가장 적은 경로)를 찾습니다.

*   **특징**: BFS를 사용하기 때문에 항상 최단 증가 경로를 찾으며, 이로 인해 포드-풀커슨 방법의 비효율성을 개선하여 다항 시간 복잡도를 보장합니다.
*   **시간 복잡도**: `O(VE^2)`

##### 7.1.7.6. 딘츠 (Dinic) 알고리즘

딘츠 알고리즘은 에드몬드-카프 알고리즘보다 훨씬 더 효율적인 최대 유량 알고리즘입니다.

*   **핵심 아이디어**:
    1.  **레벨 그래프 (Level Graph)**: BFS를 사용하여 소스 `s`로부터 각 정점까지의 최단 경로 길이를 계산하여 레벨을 부여합니다. 유량은 항상 레벨이 증가하는 방향으로만 흐릅니다.
    2.  **블로킹 플로우 (Blocking Flow)**: 레벨 그래프에서 `s`에서 `t`로 가는 경로들을 한 번에 여러 개 찾아 동시에 유량을 흘려보내는 '블로킹 플로우'를 찾습니다.
*   **시간 복잡도**: `O(V^2 E)` (일반 그래프), `O(V E^2)` (단위 용량 네트워크), `O(min(V^(2/3), E^(1/2)) E)` (특정 네트워크)
*   **활용**: 실제 문제에서 매우 빠른 성능을 보여주며, 복잡한 네트워크 플로우 문제 해결에 주로 사용됩니다.

##### 7.1.7.7. 네트워크 플로우의 활용 사례

네트워크 플로우는 다양한 실제 문제에 적용될 수 있습니다.

*   **이분 매칭 (Bipartite Matching)**: 이분 그래프에서 최대 매칭을 찾는 문제는 유량 네트워크로 변환하여 최대 유량 알고리즘으로 해결할 수 있습니다. (소스에서 왼쪽 집합으로, 왼쪽 집합에서 오른쪽 집합으로, 오른쪽 집합에서 싱크로 간선을 연결)
*   **프로젝트 선택 문제**: 여러 프로젝트 중 이익을 최대화하면서 제약 조건을 만족하는 프로젝트를 선택하는 문제.
*   **이미지 분할 (Image Segmentation)**: 이미지에서 객체와 배경을 분리하는 문제.
*   **교통 흐름 최적화**: 도시 내 교통 체증을 줄이기 위한 최적의 경로 및 신호등 제어.
*   **물류 및 공급망 관리**: 물품의 효율적인 운송 경로 및 창고 관리.
*   **순환 유량 (Circulation with Demands)**: 각 정점에 수요 또는 공급이 있는 네트워크에서 유량을 순환시키는 문제.

#### 7.1.8. 고급 그래프 분석

고급 그래프 분석은 그래프의 구조적 특성을 심층적으로 이해하고, 그래프 내의 중요한 요소나 취약점을 식별하는 데 중점을 둡니다. 이는 네트워크의 견고성, 정보 흐름, 시스템의 안정성 등을 분석하는 데 필수적입니다.

##### 7.1.8.1. 강한 연결 요소 (Strongly Connected Components, SCC)

강한 연결 요소(SCC)는 **방향 그래프(Directed Graph)**에서 서로 도달 가능한 정점들의 **최대 부분 집합**입니다. 즉, SCC 내의 임의의 두 정점 `u`와 `v`에 대해 `u`에서 `v`로 가는 경로와 `v`에서 `u`로 가는 경로가 모두 존재합니다. SCC로 분해된 그래프는 DAG(방향 비순환 그래프)가 되므로, 복잡한 방향 그래프를 단순화하여 분석하는 데 유용합니다.

*   **핵심 아이디어**: 방향 그래프를 SCC로 분해하면, 각 SCC는 하나의 '슈퍼 노드'처럼 간주될 수 있으며, 이 슈퍼 노드들 간의 관계는 DAG를 형성합니다.
*   **알고리즘**:
    *   **코사라주(Kosaraju) 알고리즘**: 두 번의 깊이 우선 탐색(DFS)을 사용합니다.
        1.  원본 그래프에서 DFS를 수행하고, 각 정점의 DFS 종료 시간을 기록합니다.
        2.  그래프의 모든 간선 방향을 뒤집은 전치 그래프(Transpose Graph)를 만듭니다.
        3.  전치 그래프에서 DFS 종료 시간이 가장 늦은 정점부터 시작하여 DFS를 수행합니다. 이때 방문하는 정점들이 하나의 SCC를 형성합니다.
    *   **타잔(Tarjan) 알고리즘**: 한 번의 깊이 우선 탐색(DFS)만을 사용하여 SCC를 찾습니다. DFS 탐색 중 각 정점의 방문 순서(discovery time)와 도달 가능한 가장 낮은 방문 순서(low-link value)를 기록하여 SCC를 식별합니다. 코사라주 알고리즘보다 효율적입니다.
*   **활용**:
    *   **의존성 분석**: 소프트웨어 모듈, 웹 페이지 등에서 순환 의존성을 찾아내고 해결하는 데 사용됩니다.
    *   **그래프 단순화**: 복잡한 방향 그래프를 SCC 단위로 단순화하여 다른 알고리즘 적용을 용이하게 합니다.
    *   **사회 연결망 분석**: 특정 그룹 내에서 정보가 자유롭게 순환하는 커뮤니티를 식별합니다.

##### 7.1.8.2. 단절점 (Articulation Point) 및 단절선 (Bridge)

단절점과 단절선은 **무방향 그래프(Undirected Graph)**의 연결성을 분석하는 데 사용되는 중요한 개념입니다. 이들은 그래프의 '취약점' 또는 '병목 지점'을 나타냅니다.

*   **단절점 (Articulation Point / Cut Vertex)**: 그래프에서 해당 정점을 제거했을 때, 그래프의 연결 요소(Connected Components)의 개수가 증가하는 정점입니다. 즉, 이 정점이 없으면 그래프가 두 개 이상의 분리된 부분으로 나뉘게 됩니다.
*   **단절선 (Bridge / Cut Edge)**: 그래프에서 해당 간선을 제거했을 때, 그래프의 연결 요소의 개수가 증가하는 간선입니다. 즉, 이 간선이 없으면 그래프가 두 개 이상의 분리된 부분으로 나뉘게 됩니다.

*   **핵심 아이디어**: DFS를 기반으로 각 정점의 방문 순서(discovery time)와 도달 가능한 가장 낮은 방문 순서(low-link value)를 사용하여 단절점과 단절선을 찾습니다.
    *   **단절점 조건**: 정점 `u`가 DFS 트리에서 `v`의 부모이고, `v`의 모든 자손이 `u`나 `u`의 조상으로 돌아가는 간선(back-edge) 없이 `u`를 통해서만 `u`의 조상에 도달할 수 있다면 `u`는 단절점입니다. (루트 노드의 경우 자식이 둘 이상일 때 단절점)
    *   **단절선 조건**: 간선 `(u, v)`에 대해 `v`의 모든 자손이 `v`를 통해서만 `u`나 `u`의 조상에 도달할 수 있다면 `(u, v)`는 단절선입니다.
*   **활용**:
    *   **네트워크 견고성 분석**: 통신 네트워크, 도로망 등에서 단일 장애 지점(Single Point of Failure)을 식별하여 시스템의 안정성을 높이는 데 사용됩니다.
    *   **사회 연결망 분석**: 특정 개인이나 관계가 커뮤니티를 분리시킬 수 있는 중요한 역할을 하는지 파악합니다.
    *   **회로 설계**: 전자 회로에서 특정 부품이나 연결이 전체 회로의 기능을 좌우하는지 분석합니다.

#### 7.1.9. 최소 비용 최대 유량 (Minimum Cost Maximum Flow, MCMF)

최소 비용 최대 유량(Minimum Cost Maximum Flow, MCMF) 문제는 일반적인 최대 유량 문제의 확장입니다. 각 간선에 유량 용량뿐만 아니라 **단위 유량당 비용(Cost per unit flow)**이 할당되어 있을 때, 소스에서 싱크로 특정 양의 유량을 보내는 데 드는 **최소 총 비용**을 찾는 문제입니다. 더 나아가, 최대 유량을 보내면서 동시에 그 유량을 보내는 데 드는 총 비용을 최소화하는 것을 목표로 합니다.

##### 7.1.9.1. 개념 및 문제 정의

*   **유량 네트워크**: 각 간선 `(u, v)`에 대해 다음 세 가지 속성이 정의됩니다.
    *   **용량 (Capacity, `c(u, v)`)**: 간선을 통해 흐를 수 있는 최대 유량.
    *   **비용 (Cost, `cost(u, v)`)**: 간선을 통해 단위 유량(1 unit flow)을 보낼 때 드는 비용.
    *   **유량 (Flow, `f(u, v)`)**: 간선을 통해 실제로 흐르는 유량.
*   **목표**:
    1.  소스에서 싱크로 보낼 수 있는 **최대 유량**을 찾습니다.
    2.  이 최대 유량을 보내는 여러 방법 중에서 **총 비용이 최소**가 되는 방법을 찾습니다.
    *   총 비용은 `Σ f(u, v) * cost(u, v)` (모든 간선에 대해)로 계산됩니다.

*   **활용**:
    *   **운송 및 물류 최적화**: 물품을 한 지점에서 다른 지점으로 운송할 때, 운송 비용을 최소화하면서 최대 물량을 처리하는 경로를 찾습니다. (예: 항공 화물, 해상 운송)
    *   **통신 네트워크 설계**: 데이터 전송 비용을 최소화하면서 네트워크의 최대 처리량을 유지하는 경로를 설계합니다.
    *   **자원 할당**: 제한된 자원을 여러 작업에 할당할 때, 총 비용을 최소화하면서 모든 작업을 완료하는 방법을 찾습니다.
    *   **생산 계획**: 생산 비용을 최소화하면서 수요를 충족시키는 생산 및 유통 계획을 수립합니다.

##### 7.1.9.2. MCMF 해결 알고리즘

MCMF 문제를 해결하는 대표적인 방법은 **연속 최단 경로(Successive Shortest Path) 알고리즘**입니다.

*   **핵심 아이디어**:
    1.  잔여 네트워크에서 소스에서 싱크로 가는 **최소 비용 경로**를 찾습니다.
    2.  이 경로를 따라 보낼 수 있는 최대 유량(경로의 병목 용량)을 보냅니다.
    3.  이 과정을 더 이상 유량을 보낼 수 없을 때까지 반복합니다.
    *   각 단계에서 최소 비용 경로를 찾는 것이 중요하며, 이때 간선 비용이 음수가 될 수 있으므로 벨만-포드(Bellman-Ford) 알고리즘이나 SPFA(Shortest Path Faster Algorithm)를 사용하거나, 포텐셜(Potential) 개념을 도입하여 다익스트라(Dijkstra) 알고리즘을 사용할 수 있습니다.

*   **알고리즘 단계 (연속 최단 경로)**:
    1.  초기 유량을 0으로 설정하고, 잔여 네트워크를 구성합니다. 이때 잔여 네트워크의 간선 비용은 원본 간선의 비용과 동일합니다. 역방향 간선의 비용은 원본 간선 비용의 음수 값입니다.
    2.  잔여 네트워크에서 소스 `s`에서 싱크 `t`로 가는 **최소 비용 경로**를 찾습니다. (예: 벨만-포드 또는 포텐셜을 이용한 다익스트라)
    3.  최소 비용 경로가 존재하면, 해당 경로를 통해 보낼 수 있는 최대 유량 `delta`를 결정합니다.
    4.  네트워크의 총 유량에 `delta`를 더하고, 총 비용에 `delta * (경로의 총 비용)`을 더합니다.
    5.  경로를 따라 유량을 갱신하고 잔여 네트워크를 업데이트합니다.
    6.  더 이상 최소 비용 경로를 찾을 수 없거나, 목표 유량에 도달할 때까지 2-5번 과정을 반복합니다.

*   **시간 복잡도**: 사용되는 최단 경로 알고리즘과 네트워크의 특성에 따라 달라집니다. 일반적으로 `O(F * (V log V + E))` 또는 `O(F * VE)` (F는 최대 유량)와 같이 유량 값에 비례하는 경우가 많습니다.

*   **다른 알고리즘**: 사이클 제거(Cycle Canceling) 알고리즘 등도 MCMF 문제를 해결하는 데 사용될 수 있습니다.

#### 7.1.10. 이분 매칭 (Bipartite Matching)

이분 매칭은 **이분 그래프(Bipartite Graph)**에서 특정 조건을 만족하는 간선들의 집합을 찾는 문제입니다. 이는 자원 할당, 스케줄링 등 다양한 실제 문제에 응용됩니다.

##### 7.1.10.1. 이분 그래프 및 매칭의 개념

*   **이분 그래프 (Bipartite Graph)**: 그래프의 모든 정점 집합 `V`를 서로소인 두 개의 부분 집합 `U`와 `W`로 나눌 수 있고, 모든 간선이 `U`의 정점과 `W`의 정점 사이에만 존재하는 그래프입니다. 즉, `U` 내의 정점끼리 또는 `W` 내의 정점끼리는 간선으로 연결되지 않습니다.
    *   **예시**: 남학생 집합과 여학생 집합, 작업자 집합과 작업 집합 등.
*   **매칭 (Matching)**: 그래프의 간선들 중에서, 서로 공통된 정점을 가지지 않는 간선들의 부분 집합입니다. 즉, 매칭에 포함된 어떤 두 간선도 동일한 정점에 연결되어 있지 않습니다.
*   **최대 매칭 (Maximum Matching)**: 주어진 그래프에서 가장 많은 수의 간선을 포함하는 매칭입니다.
*   **완벽 매칭 (Perfect Matching)**: 그래프의 모든 정점이 매칭에 포함된 간선에 의해 연결되는 매칭입니다. (모든 정점의 차수가 1인 매칭)

##### 7.1.10.2. 이분 매칭의 활용

*   **자원 할당**: 작업자들을 작업에 할당하거나, 학생들을 프로젝트에 배정하는 등 제한된 자원을 최적으로 할당하는 문제.
*   **스케줄링**: 회의실 예약, 비행기 이착륙 시간 배정 등 충돌 없이 최대한 많은 이벤트를 스케줄링하는 문제.
*   **네트워크 흐름**: 통신 네트워크에서 데이터 패킷의 경로를 최적화하는 문제.

##### 7.1.10.3. 이분 매칭 해결 알고리즘

이분 매칭 문제를 해결하는 여러 알고리즘이 있습니다.

###### 1. 최대 유량 기반 접근 (Max Flow based approach)

이분 그래프의 최대 매칭 문제는 유량 네트워크의 최대 유량 문제로 변환하여 해결할 수 있습니다.

*   **변환 방법**:
    1.  새로운 **소스(Source) 정점 `S`**와 **싱크(Sink) 정점 `T`**를 추가합니다.
    2.  `S`에서 `U`의 각 정점으로 용량이 1인 간선을 연결합니다.
    3.  `W`의 각 정점에서 `T`로 용량이 1인 간선을 연결합니다.
    4.  이분 그래프의 `U`에서 `W`로 가는 모든 간선에 용량이 1인 간선을 연결합니다. (방향은 `U`에서 `W`로)
    5.  이렇게 구성된 유량 네트워크에서 `S`에서 `T`로 가는 최대 유량을 찾습니다. 이 최대 유량의 값이 이분 그래프의 최대 매칭의 크기가 됩니다.
*   **장점**: 이미 구현된 최대 유량 알고리즘(예: 에드몬드-카프, 딘츠)을 활용할 수 있습니다.
*   **시간 복잡도**: 사용되는 최대 유량 알고리즘에 따라 달라집니다. (예: 에드몬드-카프 사용 시 `O(VE^2)`)

###### 2. 헝가리안 알고리즘 (Hungarian Algorithm)

헝가리안 알고리즘은 이분 그래프에서 **최소 비용 완벽 매칭(Minimum Cost Perfect Matching)**을 찾는 데 사용되는 알고리즘입니다. 단순히 최대 매칭을 찾는 것이 아니라, 각 간선에 비용이 있을 때 총 비용이 최소가 되는 완벽 매칭을 찾습니다.

*   **핵심 아이디어**: 비용 행렬을 변환하여 0을 포함하는 행과 열을 만들고, 이 0들을 사용하여 최적의 할당을 찾습니다.
*   **시간 복잡도**: `O(V^3)`
*   **활용**: 작업자-작업 할당 문제에서 총 비용을 최소화하는 경우.

###### 3. 홉크로프트-카프 (Hopcroft-Karp) 알고리즘

이분 그래프의 최대 매칭을 찾는 가장 효율적인 알고리즘 중 하나입니다.

*   **핵심 아이디어**: BFS를 사용하여 여러 개의 최단 증가 경로를 동시에 찾고, 이들을 한 번에 적용하여 유량을 증가시킵니다.
*   **시간 복잡도**: `O(E√V)`

##### 7.1.10.4. 쾨니히의 정리 (Konig's Theorem)

쾨니히의 정리는 이분 그래프에서 **최대 매칭의 크기**는 **최소 정점 덮개(Minimum Vertex Cover)의 크기**와 같다는 정리입니다.

*   **최소 정점 덮개 (Minimum Vertex Cover)**: 그래프의 모든 간선을 덮는(즉, 모든 간선이 최소한 하나의 끝점을 이 집합에 포함하는) 최소 정점 집합입니다.
*   **의미**: 이 정리는 이분 그래프에서 매칭 문제와 덮개 문제 사이의 강력한 이중성(duality)을 보여줍니다.

#### 7.1.11. 오일러 경로/회로 (Eulerian Path/Circuit)

오일러 경로(Eulerian Path)와 오일러 회로(Eulerian Circuit)는 그래프 이론의 고전적인 문제 중 하나로, 그래프의 모든 간선을 **정확히 한 번씩만** 지나는 경로 또는 회로를 찾는 문제입니다. 이는 18세기 쾨니히스베르크의 다리 문제(Königsberg Bridge Problem)에서 유래했습니다.

##### 7.1.11.1. 개념 및 존재 조건

*   **오일러 경로 (Eulerian Path)**: 그래프의 모든 간선을 정확히 한 번씩만 지나는 경로입니다. 시작 정점과 끝 정점이 다를 수 있습니다.
*   **오일러 회로 (Eulerian Circuit)**: 그래프의 모든 간선을 정확히 한 번씩만 지나며, 시작 정점으로 다시 돌아오는 회로입니다. 즉, 시작 정점과 끝 정점이 같습니다.

*   **존재 조건**: 그래프가 오일러 경로 또는 회로를 가지기 위한 필요충분조건은 다음과 같습니다. (고립된 정점은 무시)

    *   **1. 무방향 그래프 (Undirected Graph)**:
        *   **오일러 회로 존재 조건**: 그래프가 연결되어 있고, **모든 정점의 차수(Degree)가 짝수**여야 합니다.
        *   **오일러 경로 존재 조건**: 그래프가 연결되어 있고, **홀수 차수를 가진 정점이 정확히 0개 또는 2개**여야 합니다. (0개인 경우 회로가 존재하며, 이는 경로이기도 합니다. 2개인 경우, 이 두 정점이 경로의 시작점과 끝점이 됩니다.)

    *   **2. 방향 그래프 (Directed Graph)**:
        *   **오일러 회로 존재 조건**: 그래프의 모든 정점이 강하게 연결되어 있거나, 모든 정점의 진입 차수와 진출 차수가 같고, 모든 비고립 정점이 하나의 강한 연결 요소에 속해야 합니다.
        *   **오일러 경로 존재 조건**:
            *   모든 비고립 정점이 하나의 강한 연결 요소에 속해야 합니다.
            *   정확히 한 정점은 (진출 차수 - 진입 차수) = 1 이어야 합니다. (경로의 시작점)
            *   정확히 한 정점은 (진입 차수 - 진출 차수) = 1 이어야 합니다. (경로의 끝점)
            *   나머지 모든 정점은 진입 차수와 진출 차수가 같아야 합니다.

##### 7.1.11.2. 오일러 경로/회로를 찾는 알고리즘

오일러 경로/회로의 존재 여부를 확인하는 것은 위 조건들을 통해 쉽게 할 수 있지만, 실제로 경로/회로를 구성하는 것은 알고리즘이 필요합니다.

###### 1. 플뢰리 (Fleury) 알고리즘

플뢰리 알고리즘은 오일러 경로/회로를 구성하는 비교적 간단한 방법입니다.

*   **핵심 아이디어**: 현재 정점에서 다음 간선을 선택할 때, 해당 간선이 '단절선(Bridge)'이 아니면서(즉, 그 간선을 제거해도 그래프가 연결된 상태를 유지한다면) 그 간선을 우선적으로 선택합니다. 만약 단절선이 유일한 선택지라면 그 간선을 선택합니다.
*   **동작 방식**:
    1.  오일러 경로/회로의 존재 조건을 만족하는지 확인합니다.
    2.  시작 정점을 선택합니다 (회로의 경우 임의의 정점, 경로의 경우 홀수 차수 정점 중 하나).
    3.  현재 정점에서 나갈 수 있는 간선 중, 해당 간선을 제거했을 때 그래프가 단절되지 않는 간선을 우선적으로 선택하고 해당 간선을 제거합니다.
    4.  만약 현재 정점에서 나갈 수 있는 유일한 간선이 단절선이라면, 그 간선을 선택하고 제거합니다.
    5.  모든 간선을 방문할 때까지 반복합니다.
*   **단점**: 매 단계마다 간선이 단절선인지 확인해야 하므로 효율성이 떨어집니다.

###### 2. 히어홀처 (Hierholzer) 알고리즘

히어홀처 알고리즘은 플뢰리 알고리즘보다 더 효율적으로 오일러 회로를 찾는 방법입니다.

*   **핵심 아이디어**: 임의의 정점에서 시작하여 간선을 따라 이동하면서 방문한 간선을 제거하고, 더 이상 이동할 수 없을 때까지 경로를 만듭니다. 경로가 막히면, 현재까지 만들어진 경로에서 아직 방문하지 않은 간선이 남아있는 정점을 찾아 그 정점에서 다시 새로운 순환 경로를 시작합니다. 이 새로운 순환 경로를 기존 경로에 삽입합니다.
*   **동작 방식**:
    1.  오일러 회로의 존재 조건을 만족하는지 확인합니다.
    2.  임의의 정점 `u`에서 시작하여, `u`에서 나가는 간선을 따라 이동하며 경로를 만듭니다. 이때 방문한 간선은 그래프에서 제거합니다.
    3.  더 이상 이동할 수 없을 때까지 경로를 만듭니다. 이 경로는 `u`로 돌아오는 순환 경로가 됩니다.
    4.  만약 그래프에 아직 방문하지 않은 간선이 남아있다면, 현재까지 만들어진 경로에서 아직 방문하지 않은 간선이 남아있는 정점 `v`를 찾습니다.
    5.  `v`에서 다시 2-3번 과정을 반복하여 새로운 순환 경로를 만듭니다.
    6.  새로 만들어진 순환 경로를 `v`가 위치한 기존 경로의 지점에 삽입합니다.
    7.  모든 간선이 방문될 때까지 반복합니다.
*   **시간 복잡도**: `O(V + E)`

##### 7.1.11.3. 오일러 경로/회로와 해밀턴 경로/회로의 차이

*   **오일러 경로/회로**: 그래프의 **모든 간선**을 정확히 한 번씩 방문합니다.
*   **해밀턴 경로/회로**: 그래프의 **모든 정점**을 정확히 한 번씩 방문합니다. (시작/끝 정점 제외)

이 두 개념은 자주 혼동되지만, 해결하는 문제와 조건이 완전히 다릅니다. 해밀턴 경로는 NP-완전(NP-Complete) 문제로 알려져 있어, 오일러 경로/회로보다 훨씬 해결하기 어렵습니다.

##### 7.1.11.4. 활용 사례

*   **도로 검사 및 청소**: 모든 도로를 한 번씩만 지나면서 검사하거나 청소하는 최적의 경로를 찾는 문제.
*   **회로 기판 설계**: 모든 연결을 한 번씩만 지나면서 회로를 그리는 문제.
*   **우편 배달 경로**: 모든 거리를 한 번씩만 지나면서 우편물을 배달하는 경로.
