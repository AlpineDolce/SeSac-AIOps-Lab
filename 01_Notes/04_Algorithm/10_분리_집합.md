### 9. 분리 집합 (Disjoint Set Union, DSU)

분리 집합(Disjoint Set Union, DSU) 또는 서로소 집합(Union-Find)은 서로 겹치지 않는(서로소) 집합들의 모음을 관리하는 자료구조입니다. 각 원소가 어떤 집합에 속하는지, 그리고 두 원소가 같은 집합에 속하는지 등을 효율적으로 판단하고, 두 집합을 합치는 연산을 지원합니다. 그래프의 연결성 분석, 최소 신장 트리(MST) 구성, 네트워크 연결 관리 등 다양한 문제 해결에 활용됩니다.

#### 9.1. 분리 집합의 개념과 기본 연산

분리 집합 자료구조는 일반적으로 **트리의 숲(Forest of Trees)** 형태로 표현됩니다. 각 집합은 하나의 트리로 표현되며, 트리의 **루트 노드(Root Node)**가 해당 집합의 **대표 원소(Representative Element)**가 됩니다.

*   **기본 연산**:
    *   **`MakeSet(x)` / `Make_Set(x)` / `Init(x)`**: 원소 `x`를 포함하는 새로운 집합을 생성합니다. 초기에는 각 원소가 자기 자신을 대표 원소로 하는 독립적인 집합을 이룹니다.
        *   구현: `parent[x] = x`로 설정합니다.
    *   **`Find(x)`**: 원소 `x`가 속한 집합의 대표 원소를 찾습니다. 이 연산은 `x`에서 시작하여 부모 포인터를 따라 트리의 루트까지 이동합니다.
        *   구현: `x`의 부모가 `x` 자신이 될 때까지 `parent[x]`를 재귀적으로 또는 반복적으로 따라갑니다.
    *   **`Union(x, y)`**: 원소 `x`가 속한 집합과 원소 `y`가 속한 집합을 합칩니다. 두 집합의 대표 원소를 찾은 후, 한 대표 원소를 다른 대표 원소의 자식으로 만듭니다.
        *   구현: `root_x = Find(x)`, `root_y = Find(y)`. 만약 `root_x != root_y`이면 `parent[root_y] = root_x`와 같이 한쪽을 다른 쪽의 자식으로 만듭니다.

#### 9.2. 분리 집합의 성능 최적화 기법

기본적인 `Find`와 `Union` 연산은 트리의 높이에 따라 성능이 저하될 수 있습니다. 이를 개선하기 위해 두 가지 주요 최적화 기법이 사용됩니다.

*   **1. 경로 압축 (Path Compression)**:
    *   **개념**: `Find(x)` 연산을 수행할 때, `x`에서 루트까지의 경로에 있는 모든 노드들을 직접 루트에 연결하여 트리의 높이를 낮춥니다.
    *   **동작 방식**: `Find(x)`가 루트를 반환한 후, 경로를 다시 내려오면서 경로상의 모든 노드의 부모를 루트로 변경합니다.
    *   **효과**: 이후 동일한 노드나 그 자손에 대한 `Find` 연산의 속도를 크게 향상시킵니다. 트리가 거의 평평해집니다.

*   **2. 유니온 바이 랭크(Union by Rank) 또는 유니온 바이 사이즈(Union by Size)**:
    *   **개념**: `Union(x, y)` 연산 시, 두 집합의 대표 원소를 연결할 때 트리의 균형을 유지하여 트리의 높이가 불필요하게 높아지는 것을 방지합니다.
    *   **유니온 바이 랭크 (Union by Rank)**: 트리의 **높이(Rank)**를 기준으로 더 낮은 높이의 트리를 더 높은 높이의 트리에 연결합니다. 높이가 같을 경우, 한쪽을 다른 쪽에 연결하고 연결된 트리의 높이를 1 증가시킵니다.
    *   **유니온 바이 사이즈 (Union by Size)**: 트리의 **크기(Size)**(포함된 원소의 수)를 기준으로 더 작은 크기의 트리를 더 큰 크기의 트리에 연결합니다.
    *   **효과**: 트리의 높이를 최소한으로 유지하여 `Find` 연산의 효율성을 높입니다.

*   **시간 복잡도 (두 최적화 기법 적용 시)**:
    *   `MakeSet`, `Find`, `Union` 연산의 **상환 시간 복잡도(Amortized Time Complexity)**는 거의 상수 시간에 가깝습니다. 정확히는 **역 아커만 함수(Inverse Ackermann Function, `α(N)`)**에 비례합니다. `α(N)`은 `N`이 매우 큰 값일 때도 4 또는 5를 넘지 않는 매우 느리게 증가하는 함수이므로, 사실상 상수 시간으로 간주할 수 있습니다.

#### 9.3. 분리 집합의 파이썬 구현

```python
class DisjointSet:
    def __init__(self, n):
        # parent[i]는 i의 부모 노드를 저장합니다. 초기에는 각 원소가 자기 자신을 부모로 가집니다.
        self.parent = list(range(n)) 
        # rank[i]는 i를 루트로 하는 트리의 높이(또는 랭크)를 저장합니다. 유니온 바이 랭크에 사용됩니다.
        self.rank = [0] * n          
        # size[i]는 i를 루트로 하는 트리의 크기(포함된 원소 수)를 저장합니다. 유니온 바이 사이즈에 사용될 수 있습니다.
        # self.size = [1] * n 

    def find(self, i):
        """
        원소 i가 속한 집합의 대표 원소(루트)를 찾습니다.
        경로 압축(Path Compression)을 적용하여 트리를 평평하게 만듭니다.
        """
        if self.parent[i] == i: # i가 루트 노드인 경우
            return i
        # 재귀적으로 루트를 찾고, 경로상의 모든 노드의 부모를 루트로 변경합니다.
        self.parent[i] = self.find(self.parent[i])
        return self.parent[i]

    def union(self, i, j):
        """
        원소 i가 속한 집합과 원소 j가 속한 집합을 합칩니다.
        유니온 바이 랭크(Union by Rank)를 적용하여 트리의 균형을 유지합니다.
        """
        root_i = self.find(i) # i가 속한 집합의 대표 원소
        root_j = self.find(j) # j가 속한 집합의 대표 원소

        if root_i != root_j: # 두 원소가 다른 집합에 속해 있다면 합칩니다.
            # 랭크가 더 낮은 트리를 랭크가 더 높은 트리에 연결합니다.
            if self.rank[root_i] < self.rank[root_j]:
                self.parent[root_i] = root_j
            elif self.rank[root_i] > self.rank[root_j]:
                self.parent[root_j] = root_i
            else: # 랭크가 같으면 한쪽을 다른 쪽에 연결하고 랭크를 1 증가시킵니다.
                self.parent[root_j] = root_i
                self.rank[root_i] += 1
            return True # 합치기 성공
        return False # 이미 같은 집합에 속해 있음

# 예시 사용법
print("--- 분리 집합 예시 ---")
# 0부터 4까지 5개의 원소를 가진 분리 집합 초기화
ds = DisjointSet(5) 
print(f"초기 상태: {ds.parent}") # [0, 1, 2, 3, 4]

# 0과 1을 합칩니다.
print("Union(0, 1) 결과:", ds.union(0, 1)) # True
print(f"Union(0, 1) 후 parent: {ds.parent}") # [0, 0, 2, 3, 4] (0이 1의 부모가 됨)
print(f"Find(1) 결과: {ds.find(1)}") # 0 (경로 압축으로 parent[1]도 0이 됨)
print(f"Find(1) 후 parent: {ds.parent}") # [0, 0, 2, 3, 4]

# 2와 3을 합칩니다.
print("Union(2, 3) 결과:", ds.union(2, 3)) # True
print(f"Union(2, 3) 후 parent: {ds.parent}") # [0, 0, 2, 2, 4] (2가 3의 부모가 됨)

# 0과 2가 같은 집합에 속하는지 확인합니다.
print(f"Find(0) == Find(2) 결과: {ds.find(0) == ds.find(2)}") # False

# 0과 2를 합칩니다.
print("Union(0, 2) 결과:", ds.union(0, 2)) # True
print(f"Union(0, 2) 후 parent: {ds.parent}") # [0, 0, 0, 2, 4] (0이 2의 부모가 됨)

# 이제 0, 1, 2, 3이 모두 같은 집합에 속하는지 확인합니다.
print(f"Find(0) == Find(3) 결과: {ds.find(0) == ds.find(3)}") # True
print(f"Find(1) == Find(2) 결과: {ds.find(1) == ds.find(2)}") # True
print(f"Find(4) == Find(0) 결과: {ds.find(4) == ds.find(0)}") # False
print("\n")
```

#### 9.4. 분리 집합의 활용 사례

분리 집합 자료구조는 다양한 알고리즘 문제에서 효율적인 집합 관리 및 연결성 확인을 위해 사용됩니다.

*   **1. 그래프의 연결성 확인 및 사이클 감지**:
    *   **연결 요소(Connected Components) 찾기**: 그래프의 모든 정점을 순회하면서 `Find` 연산을 통해 같은 집합에 속하는 정점들을 그룹화하여 연결 요소를 찾을 수 있습니다.
    *   **사이클 감지**: 무방향 그래프에서 간선 `(u, v)`를 추가할 때, `Find(u)`와 `Find(v)`의 결과가 같다면 (즉, `u`와 `v`가 이미 같은 집합에 속해 있다면) 해당 간선은 사이클을 형성합니다. 이는 크루스칼 알고리즘에서 핵심적으로 사용됩니다.

*   **2. 최소 신장 트리 (Minimum Spanning Tree, MST) - 크루스칼 알고리즘**:
    *   크루스칼 알고리즘은 간선들을 가중치 오름차순으로 정렬한 후, 가장 가중치가 작은 간선부터 선택하여 MST를 구성합니다. 이때 분리 집합 자료구조를 사용하여 간선이 추가될 때마다 사이클이 형성되는지 여부를 효율적으로 확인합니다. `Union(u, v)` 연산이 성공하면 사이클이 형성되지 않고 간선을 MST에 추가할 수 있음을 의미합니다.

*   **3. 네트워크 연결 관리**:
    *   컴퓨터 네트워크에서 어떤 두 컴퓨터가 서로 연결되어 있는지(같은 네트워크 그룹에 속하는지)를 실시간으로 확인하고, 네트워크 병합 시 그룹을 업데이트하는 데 사용될 수 있습니다.

*   **4. 격자(Grid) 기반 문제**:
    *   **퍼콜레이션(Percolation)**: 격자에서 물이 흐를 수 있는 경로를 찾는 문제.
    *   **섬의 개수 세기**: 2D 격자에서 연결된 '1'의 덩어리(섬)의 개수를 세는 문제. 각 '1'을 원소로 보고 인접한 '1'들을 `Union` 연산으로 합쳐 하나의 집합으로 만듭니다. 최종적으로 `Find` 연산을 통해 서로 다른 대표 원소의 개수를 세면 섬의 개수를 알 수 있습니다.

*   **5. 친구 관계 또는 그룹 관리**:
    *   소셜 네트워크에서 친구 관계를 통해 형성되는 그룹을 관리하거나, 어떤 두 사람이 같은 그룹에 속하는지 확인하는 데 사용될 수 있습니다.
