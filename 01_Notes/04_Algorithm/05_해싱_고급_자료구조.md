### 3.5. 힙 (Heap) 및 우선순위 큐 (Priority Queue)

힙은 완전 이진 트리의 일종으로, 우선순위 큐를 구현하는 데 주로 사용되는 자료구조입니다. 부모 노드의 키가 자식 노드의 키보다 항상 크거나(최대 힙) 항상 작은(최소 힙) 특징을 가집니다.

#### 3.5.1. 힙의 개념과 종류 (최대 힙, 최소 힙)

*   **개념:** '힙 속성(Heap Property)'을 만족하는 완전 이진 트리.
*   **종류:**
    *   **최대 힙 (Max Heap):** 부모 노드의 키가 자식 노드의 키보다 항상 크거나 같습니다. (루트가 가장 큰 값)
    *   **최소 힙 (Min Heap):** 부모 노드의 키가 자식 노드의 키보다 항상 작거나 같습니다. (루트가 가장 작은 값)

#### 3.5.2. 힙의 주요 연산 (삽입, 삭제)

*   **삽입 (Insertion):** 새로운 요소를 힙의 마지막 위치에 추가한 후, 힙 속성을 만족할 때까지 부모 노드와 교환(Heapify-up)합니다. `O(log n)`.
*   **삭제 (Deletion):** 보통 루트 노드(최대/최소 값)를 삭제합니다. 루트를 제거한 후, 힙의 마지막 요소를 루트로 옮기고 힙 속성을 만족할 때까지 자식 노드와 교환(Heapify-down)합니다. `O(log n)`.

#### 3.5.3. 힙의 파이썬 구현 (`heapq` 모듈)

파이썬의 `heapq` 모듈은 최소 힙 기능을 제공합니다. 최대 힙은 요소에 음수 부호를 붙여 저장하는 방식으로 구현할 수 있습니다.

```python
import heapq

# 최소 힙
min_heap = []
heapq.heappush(min_heap, 4)
heapq.heappush(min_heap, 1)
heapq.heappush(min_heap, 7)
heapq.heappush(min_heap, 2)
print(min_heap) # [1, 2, 7, 4]
print(heapq.heappop(min_heap)) # 1
print(min_heap) # [2, 4, 7]

# 최대 힙 (음수 부호 활용)
max_heap = []
heapq.heappush(max_heap, -4)
heapq.heappush(max_heap, -1)
heapq.heappush(max_heap, -7)
heapq.heappush(max_heap, -2)
print(max_heap) # [-7, -4, -2, -1]
print(-heapq.heappop(max_heap)) # 7
print(max_heap) # [-4, -1, -2]
```

#### 4.1.4. 우선순위 큐로서의 힙 활용

우선순위 큐는 요소들이 우선순위를 가지고, 가장 높은 우선순위의 요소가 먼저 제거되는 추상 자료형입니다. 힙은 우선순위 큐를 구현하는 가장 효율적인 방법입니다.

*   **활용:**
    *   작업 스케줄링 (운영체제)
    *   네트워크 트래픽 관리
    *   최단 경로 알고리즘 (다익스트라)
    *   최소 신장 트리 알고리즘 (프림)

#### 4.1.5. 힙 정렬 (Heap Sort) 개요

힙 정렬은 힙 자료구조를 활용한 정렬 알고리즘입니다. 배열을 힙으로 만든 후, 가장 큰(또는 작은) 요소를 하나씩 추출하여 정렬합니다. `O(n log n)`의 시간 복잡도를 가집니다.

### 3.6. 해싱 (Hashing) 및 해시 테이블 (Hash Table)

해싱은 데이터를 효율적으로 저장하고 검색하기 위한 기법이며, 해시 테이블은 이를 구현한 자료구조입니다. 키-값 쌍을 저장하며, 평균적으로 `O(1)`의 시간 복잡도로 삽입, 삭제, 검색을 수행합니다.

#### 3.6.1. 해싱의 개념과 원리

*   **해싱 (Hashing):** 임의의 크기를 가진 데이터를 고정된 크기의 값(해시 값 또는 해시 코드)으로 변환하는 과정입니다. 이 변환을 수행하는 함수를 해시 함수(Hash Function)라고 합니다.
*   **원리:** 키를 해시 함수에 넣어 해시 값을 얻고, 이 해시 값을 인덱스 삼아 데이터를 저장하거나 검색합니다.

#### 3.6.2. 해시 테이블의 구조와 동작

*   **구조:** 키-값 쌍을 저장하는 배열(버킷 또는 슬롯)로 구성됩니다.
*   **동작:**
    1.  **삽입:** 키를 해시 함수에 넣어 해시 값을 얻고, 해당 인덱스에 값을 저장합니다.
    2.  **검색:** 키를 해시 함수에 넣어 해시 값을 얻고, 해당 인덱스에서 값을 찾습니다.
    3.  **삭제:** 키를 해시 함수에 넣어 해시 값을 얻고, 해당 인덱스에서 값을 제거합니다.

#### 3.6.3. 충돌 해결 전략 (개방 주소법, 체이닝)

서로 다른 키가 동일한 해시 값을 생성하는 경우를 '충돌(Collision)'이라고 합니다. 충돌을 해결하는 방법은 여러 가지가 있습니다.

*   **체이닝 (Chaining):** 동일한 해시 값을 가지는 모든 키-값 쌍을 링크드 리스트(또는 다른 자료구조)로 연결하여 저장합니다.
*   **개방 주소법 (Open Addressing):** 충돌이 발생하면 미리 정해진 규칙에 따라 다른 비어있는 버킷을 찾아 데이터를 저장합니다.
    *   **선형 탐사 (Linear Probing):** 충돌 시 다음 버킷을 순차적으로 탐사합니다.
    *   **제곱 탐사 (Quadratic Probing):** 충돌 시 제곱만큼 떨어진 버킷을 탐사합니다.
    *   **이중 해싱 (Double Hashing):** 두 번째 해시 함수를 사용하여 탐사 간격을 결정합니다.

#### 3.6.4. 파이썬 딕셔너리(dict)의 해시 테이블 구현

파이썬의 딕셔너리(`dict`)는 해시 테이블로 구현되어 있습니다. 따라서 키를 이용한 삽입, 삭제, 검색 연산이 평균 `O(1)`의 시간 복잡도를 가집니다.

```python
my_dict = {'apple': 1, 'banana': 2, 'cherry': 3}
print(my_dict['apple']) # O(1) 검색
my_dict['date'] = 4     # O(1) 삽입
del my_dict['banana']  # O(1) 삭제
```

#### 3.6.5. 해시 테이블의 시간 복잡도 및 활용 사례

*   **시간 복잡도:**
    *   평균: 삽입, 삭제, 검색 모두 `O(1)`
    *   최악: `O(n)` (모든 키가 동일한 해시 값을 가질 경우)
*   **활용 사례:**
    *   데이터베이스 인덱싱
    *   캐시 구현
    *   심볼 테이블 (컴파일러)
    *   중복 데이터 제거

### 3.7. 트라이 (Trie, Prefix Tree)

트라이는 문자열을 저장하고 효율적으로 검색하기 위한 트리 형태의 자료구조입니다. 특히 접두사(Prefix)를 기반으로 한 검색에 매우 강력합니다.

#### 3.7.1. 트라이의 개념과 구조

*   **개념:** 각 노드가 하나의 문자를 나타내며, 루트부터 특정 노드까지의 경로가 하나의 단어 또는 접두사를 나타냅니다.
*   **구조:**
    *   루트 노드는 비어있는 문자열을 나타냅니다.
    *   각 노드는 자식 노드들을 위한 맵(또는 배열)을 가집니다.
    *   단어의 끝을 표시하는 플래그(예: `is_end_of_word`)를 가집니다.

#### 3.7.2. 트라이의 주요 연산 (삽입, 검색, 접두사 검색)

*   **삽입 (Insertion):** 단어를 구성하는 각 문자를 따라가며 노드를 생성하거나 이동합니다. `O(L)` (L은 단어의 길이).
*   **검색 (Search):** 단어를 구성하는 각 문자를 따라가며 노드를 탐색합니다. `O(L)`.
*   **접두사 검색 (Prefix Search):** 특정 접두사를 가진 모든 단어를 찾습니다. `O(L + K)` (K는 접두사를 가진 단어들의 총 길이).

#### 3.7.3. 트라이의 활용 사례 (자동 완성, 사전, 스펠링 체크)

*   **자동 완성 (Autocomplete):** 검색창에 단어를 입력할 때 가능한 단어 목록을 추천합니다.
*   **사전 (Dictionary):** 단어의 존재 여부를 빠르게 확인합니다.
*   **스펠링 체크 (Spell Checker):** 오타를 감지하고 수정 제안을 합니다.
*   **IP 라우팅:** IP 주소의 접두사를 기반으로 라우팅 테이블을 관리합니다.

### 3.8. 균형 이진 탐색 트리 (Balanced Binary Search Tree)

이진 탐색 트리는 데이터가 편향되게 삽입될 경우 트리의 높이가 `O(n)`이 되어 탐색, 삽입, 삭제 성능이 `O(n)`으로 저하될 수 있습니다. 균형 이진 탐색 트리는 이러한 문제를 해결하기 위해 트리의 높이를 `O(log n)`으로 유지하는 자가 균형(Self-balancing) 트리입니다.

#### 3.8.1. 균형 이진 탐색 트리의 필요성

*   최악의 경우 `O(n)` 성능을 `O(log n)`으로 보장하여 안정적인 성능을 제공합니다.
*   대용량 데이터 처리 및 실시간 시스템에서 필수적입니다.

#### 3.8.2. AVL 트리 (AVL Tree)

*   **개념:** 모든 노드의 왼쪽 서브트리와 오른쪽 서브트리의 높이 차이가 1 이하인 이진 탐색 트리입니다.
*   **균형 인수 (Balance Factor):** `왼쪽 서브트리 높이 - 오른쪽 서브트리 높이` (값은 -1, 0, 1 중 하나).
*   **재균형:** 삽입 및 삭제 후 균형 인수가 1을 초과하면 회전(Rotation) 연산을 통해 트리를 재균형합니다.

#### 3.8.3. 레드-블랙 트리 (Red-Black Tree)

*   **개념:** 노드를 빨간색 또는 검은색으로 색칠하여 균형을 유지하는 이진 탐색 트리입니다. AVL 트리보다 덜 엄격하게 균형을 유지하지만, 삽입/삭제 시 회전 횟수가 적어 실제 성능이 더 좋을 수 있습니다.
*   **규칙:**
    1.  모든 노드는 빨간색 또는 검은색입니다.
    2.  루트 노드는 검은색입니다.
    3.  모든 리프 노드(NIL 노드)는 검은색입니다.
    4.  빨간색 노드의 자식은 모두 검은색입니다. (빨간색 노드가 연속될 수 없음)
    5.  어떤 노드로부터 그 노드의 자손 리프 노드까지의 모든 경로에는 같은 수의 검은색 노드가 있습니다.

#### 3.8.4. 활용 사례 (맵, 셋 구현)

*   **맵 (Map) 및 셋 (Set) 구현:** C++의 `std::map`, `std::set`이나 Java의 `TreeMap`, `TreeSet` 등 많은 표준 라이브러리에서 균형 이진 탐색 트리를 사용하여 정렬된 키-값 쌍 또는 고유한 요소 집합을 효율적으로 관리합니다.
*   **데이터베이스 인덱스:** B-트리/B+트리와 함께 데이터베이스 인덱스 구현에 사용됩니다.

### 3.9. 세그먼트 트리 (Segment Tree)

세그먼트 트리는 배열의 특정 '구간(Segment)'에 대한 질의(Query)를 효율적으로 처리하기 위한 트리 기반 자료구조입니다. 구간 합, 구간 최솟값/최댓값 등 다양한 구간 쿼리에 사용됩니다.

#### 3.9.1. 세그먼트 트리의 개념과 구조

*   **개념:** 주어진 배열을 이진 트리 형태로 분할하여 표현합니다. 각 노드는 특정 구간의 정보를 저장합니다.
*   **구조:**
    *   리프 노드: 배열의 단일 요소를 나타냅니다.
    *   내부 노드: 자식 노드들이 나타내는 구간의 정보를 합쳐서 저장합니다.
    *   완전 이진 트리의 형태를 가지며, 배열로 구현할 수 있습니다.

#### 3.9.2. 세그먼트 트리의 연산 (구간 합, 구간 최솟값/최댓값)

*   **구축 (Build):** 배열로부터 트리를 생성합니다. `O(n)`.
*   **업데이트 (Update):** 배열의 특정 요소가 변경될 때, 관련 노드들의 정보를 갱신합니다. `O(log n)`.
*   **쿼리 (Query):** 특정 구간에 대한 질의를 처리합니다. `O(log n)`.

#### 3.9.3. 세그먼트 트리의 파이썬 구현 개요

```python
# 세그먼트 트리 노드 (배열로 구현 시 생략 가능)
# class SegmentTreeNode:
#     def __init__(self, start, end, sum_val=0):
#         self.start = start
#         self.end = end
#         self.sum_val = sum_val
#         self.left = None
#         self.right = None

class SegmentTree:
    def __init__(self, arr):
        self.n = len(arr)
        self.tree = [0] * (4 * self.n) # 트리를 저장할 배열 (넉넉하게 4배)
        self._build(arr, 1, 0, self.n - 1)

    def _build(self, arr, node, start, end):
        if start == end:
            self.tree[node] = arr[start]
        else:
            mid = (start + end) // 2
            self._build(arr, 2 * node, start, mid)
            self._build(arr, 2 * node + 1, mid + 1, end)
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1] # 구간 합 예시

    def update(self, idx, val):
        self._update(1, 0, self.n - 1, idx, val)

    def _update(self, node, start, end, idx, val):
        if start == end:
            self.tree[node] = val
        else:
            mid = (start + end) // 2
            if start <= idx <= mid:
                self._update(2 * node, start, mid, idx, val)
            else:
                self._update(2 * node + 1, mid + 1, end, idx, val)
            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]

    def query(self, l, r):
        return self._query(1, 0, self.n - 1, l, r)

    def _query(self, node, start, end, l, r):
        if r < start or end < l: # 구간이 전혀 겹치지 않을 때
            return 0
        if l <= start and end <= r: # 구간이 완전히 포함될 때
            return self.tree[node]
        mid = (start + end) // 2
        p1 = self._query(2 * node, start, mid, l, r)
        p2 = self._query(2 * node + 1, mid + 1, end, l, r)
        return p1 + p2

# 예시
# arr = [1, 3, 5, 7, 9, 11]
# st = SegmentTree(arr)
# print(st.query(1, 4)) # 3 + 5 + 7 + 9 = 24
# st.update(2, 10) # arr[2]를 10으로 변경
# print(st.query(1, 4)) # 3 + 10 + 7 + 9 = 29
```

#### 3.9.4. 활용 사례 (구간 쿼리 문제)

*   **구간 합/최솟값/최댓값:** 배열의 특정 구간에 대한 합, 최솟값, 최댓값 등을 빠르게 계산해야 할 때.
*   **데이터 변경이 잦은 배열:** 배열의 요소가 자주 변경되면서 구간 쿼리가 필요한 경우.
*   **게임 개발:** 게임 맵의 특정 영역에 대한 정보 조회.

### 3.10. 펜윅 트리 (Fenwick Tree, Binary Indexed Tree)

펜윅 트리(Fenwick Tree) 또는 이진 인덱스 트리(Binary Indexed Tree, BIT)는 배열의 부분 합을 효율적으로 계산하고, 배열의 요소 값을 업데이트하는 데 사용되는 자료구조입니다. 세그먼트 트리보다 구현이 간단하고 상수 인자가 작아 더 빠를 수 있습니다.

#### 3.10.1. 펜윅 트리의 개념과 원리

*   **개념:** 배열의 각 요소가 특정 범위의 누적 합을 나타내도록 설계된 트리 형태의 자료구조입니다. 이진 표현의 특성을 활용하여 효율적인 연산을 가능하게 합니다.
*   **원리:** 각 인덱스의 이진 표현에서 가장 낮은 비트(Lowest Set Bit)를 이용하여 부모-자식 관계를 정의하고, 이를 통해 구간 합을 계산하거나 값을 업데이트합니다.

#### 3.10.2. 펜윅 트리의 연산 (누적 합, 값 업데이트)

*   **누적 합 (Prefix Sum):** `query(idx)`는 `arr[0]`부터 `arr[idx]`까지의 합을 `O(log n)` 시간에 계산합니다.
*   **값 업데이트 (Update):** `update(idx, val)`는 `arr[idx]`의 값을 `val`만큼 변경하고, 이에 영향을 받는 펜윅 트리 노드들을 `O(log n)` 시간에 갱신합니다.

#### 3.10.3. 펜윅 트리의 파이썬 구현 개요

```python
class FenwickTree:
    def __init__(self, n):
        self.n = n
        self.tree = [0] * (n + 1) # 1-based indexing

    # arr[idx]에 val을 더함
    def update(self, idx, val):
        idx += 1 # 0-based to 1-based
        while idx <= self.n:
            self.tree[idx] += val
            idx += (idx & -idx) # 다음 업데이트할 노드로 이동

    # arr[0]부터 arr[idx]까지의 합을 반환
    def query(self, idx):
        idx += 1 # 0-based to 1-based
        s = 0
        while idx > 0:
            s += self.tree[idx]
            idx -= (idx & -idx) # 다음 쿼리할 노드로 이동
        return s

    # arr[l]부터 arr[r]까지의 합을 반환
    def range_query(self, l, r):
        return self.query(r) - self.query(l - 1)

# 예시
# arr = [1, 3, 5, 7, 9, 11]
# ft = FenwickTree(len(arr))
# for i, val in enumerate(arr):
#     ft.update(i, val)

# print(ft.query(4)) # arr[0]~arr[4]의 합 (1+3+5+7+9 = 25)
# print(ft.range_query(1, 4)) # arr[1]~arr[4]의 합 (3+5+7+9 = 24)
# ft.update(2, 5) # arr[2]를 5만큼 증가 (원래 5였으므로 10이 됨)
# print(ft.query(4)) # 1+3+10+7+9 = 30
```

#### 3.10.4. 활용 사례 (구간 합, 빈도 계산)

*   **구간 합 쿼리:** 배열의 특정 구간 합을 빠르게 계산하고 업데이트해야 할 때.
*   **빈도 계산:** 특정 값의 빈도를 효율적으로 추적하고 쿼리할 때.
*   **역전쌍 (Inversion Count):** 배열에서 역전쌍의 개수를 세는 문제.

### 3.11. 투 포인터 (Two Pointers)

투 포인터는 배열이나 리스트에서 두 개의 포인터(인덱스)를 사용하여 문제를 해결하는 알고리즘 기법입니다. 주로 정렬된 배열에서 특정 조건을 만족하는 쌍이나 부분 배열을 찾을 때 효율적입니다.

#### 3.11.1. 투 포인터의 개념과 활용 조건

*   **개념:** 두 개의 포인터가 서로 다른 위치에서 시작하여(보통 양 끝에서 시작하여 안쪽으로 이동하거나, 같은 위치에서 시작하여 한 방향으로 이동) 배열을 탐색합니다.
*   **활용 조건:**
    *   데이터가 정렬되어 있는 경우 (가장 일반적).
    *   특정 조건을 만족하는 두 요소의 쌍을 찾아야 할 때.
    *   부분 배열 또는 부분 문자열을 다룰 때.

#### 3.11.2. 투 포인터 활용 문제 (예: 정렬된 배열에서 합 찾기)

정렬된 배열에서 합이 특정 값(target)이 되는 두 요소를 찾는 문제입니다.

```python
def two_sum_sorted(arr, target):
    left, right = 0, len(arr) - 1
    while left < right:
        current_sum = arr[left] + arr[right]
        if current_sum == target:
            return [arr[left], arr[right]]
        elif current_sum < target:
            left += 1
        else:
            right -= 1
    return None

# 예시
# print(two_sum_sorted([1, 2, 3, 4, 5], 7)) # [2, 5]
# print(two_sum_sorted([1, 2, 3, 4, 5], 10)) # None
```

### 3.12. 슬라이딩 윈도우 (Sliding Window)

슬라이딩 윈도우는 배열이나 문자열의 '연속된 부분(Subarray/Substring)'을 효율적으로 탐색하는 알고리즘 기법입니다. 고정된 크기 또는 가변적인 크기의 윈도우(부분 구간)를 이동시키면서 문제를 해결합니다.

#### 3.12.1. 슬라이딩 윈도우의 개념과 활용

*   **개념:** 윈도우를 한 칸씩 이동시키면서 윈도우 내의 데이터를 갱신하고 계산합니다. 매번 전체 구간을 다시 계산하는 비효율을 줄입니다.
*   **활용:**
    *   고정 크기 윈도우: 특정 길이의 부분 배열/문자열에서 최대/최소 합, 평균 등을 찾을 때.
    *   가변 크기 윈도우: 특정 조건을 만족하는 가장 짧거나 긴 부분 배열/문자열을 찾을 때.

#### 3.12.2. 슬라이딩 윈도우 활용 문제 (예: 최대 부분 배열 합)

주어진 배열에서 길이가 `k`인 연속된 부분 배열의 최대 합을 찾는 문제입니다.

```python
def max_subarray_sum_fixed_window(arr, k):
    if k > len(arr): return None

    current_sum = sum(arr[:k])
    max_sum = current_sum

    for i in range(k, len(arr)):
        current_sum += arr[i] - arr[i - k] # 윈도우 이동: 새로운 요소 추가, 오래된 요소 제거
        max_sum = max(max_sum, current_sum)
    return max_sum

# 예시
# print(max_subarray_sum_fixed_window([1, 4, 2, 10, 2, 3, 1, 0, 20], 4)) # 24 (4, 2, 10, 2)
```

### 3.13. 비트 연산 (Bit Manipulation)

비트 연산은 데이터를 비트(0과 1) 단위로 직접 조작하는 연산입니다. 매우 빠르고 효율적이며, 특정 문제 유형(집합 표현, 상태 관리, 최적화)에서 강력한 해결책을 제공합니다.

#### 3.13.1. 비트 연산자의 종류와 활용

*   `&` (AND): 두 비트가 모두 1일 때 1.
*   `|` (OR): 두 비트 중 하나라도 1일 때 1.
*   `^` (XOR): 두 비트가 다를 때 1.
*   `~` (NOT): 비트를 반전.
*   `<<` (Left Shift): 비트를 왼쪽으로 이동 (2의 거듭제곱 곱셈).
*   `>>` (Right Shift): 비트를 오른쪽으로 이동 (2의 거듭제곱 나눗셈).

#### 3.13.2. 비트 마스크 (Bit Mask)

비트 마스크는 비트 연산을 사용하여 여러 개의 불리언(True/False) 상태를 하나의 정수로 표현하고 관리하는 기법입니다. 각 비트가 특정 상태를 나타냅니다.

*   **활용:**
    *   부분집합 표현: `n`개의 요소로 만들 수 있는 모든 부분집합을 `2^n`개의 비트 마스크로 표현.
    *   상태 관리: 여러 개의 스위치나 옵션 상태를 하나의 변수로 관리.
    *   권한 관리: 사용자 권한을 비트 플래그로 설정.

#### 3.13.3. 비트 연산 활용 문제 (예: 부분집합, 상태 관리)

주어진 집합의 모든 부분집합을 생성하는 문제입니다.

```python
def generate_subsets(nums):
    n = len(nums)
    subsets = []
    for i in range(1 << n): # 2^n 개의 부분집합
        current_subset = []
        for j in range(n):
            if (i >> j) & 1: # j번째 비트가 1이면
                current_subset.append(nums[j])
        subsets.append(current_subset)
    return subsets

# 예시
# print(generate_subsets([1, 2, 3]))
# [[], [1], [2], [1, 2], [3], [1, 3], [2, 3], [1, 2, 3]]
```

### 3.14. 희소 테이블 (Sparse Table)

희소 테이블은 배열의 특정 구간에 대한 질의(Query)를 `O(1)` 시간에 처리하기 위한 자료구조입니다. 주로 RMQ(Range Minimum Query) 문제와 같이 변경이 없는(정적) 배열에서 구간 쿼리가 빈번할 때 사용됩니다.

#### 3.14.1. 희소 테이블의 개념과 원리

*   **개념:** 동적 계획법(DP)을 활용하여 미리 계산된 구간 정보를 저장하는 2차원 배열입니다. `dp[i][j]`는 `i`부터 `i + 2^j - 1`까지의 구간에 대한 쿼리 결과(예: 최솟값)를 저장합니다.
*   **원리:** 모든 가능한 구간을 저장하는 대신, 길이가 2의 거듭제곱인 구간들에 대한 정보를 저장하여, 임의의 구간을 이들의 조합으로 표현합니다.

#### 3.14.2. 희소 테이블의 구축 및 쿼리 (RMQ 문제)

*   **구축 (Build):** `O(n log n)` 시간.
    *   `dp[i][0]`은 `arr[i]` 자체의 값.
    *   `dp[i][j] = min(dp[i][j-1], dp[i + 2^(j-1)][j-1])` (RMQ 예시)
*   **쿼리 (Query):** `O(1)` 시간.
    *   구간 `[L, R]`에 대한 쿼리는 `k = floor(log2(R - L + 1))`을 이용하여 `min(dp[L][k], dp[R - 2^k + 1][k])`로 계산합니다.

#### 3.14.3. 희소 테이블의 장단점 및 활용 사례

*   **장점:** `O(1)` 쿼리 시간으로 매우 빠릅니다. 구현이 비교적 간단합니다.
*   **단점:** 배열의 요소가 변경될 경우 재구축해야 하므로, 정적 배열에만 적합합니다. `O(n log n)`의 공간 복잡도를 가집니다.
*   **활용 사례:**
    *   RMQ (Range Minimum Query) 문제.
    *   LCA (Lowest Common Ancestor) 문제의 전처리.

### 3.15. 제곱근 분할 (SQRT Decomposition)

제곱근 분할은 배열을 `sqrt(n)` 크기의 블록으로 나누어 구간 쿼리 및 업데이트를 처리하는 기법입니다. 세그먼트 트리나 펜윅 트리보다 느리지만, 구현이 더 간단하고 다양한 유형의 문제에 적용할 수 있습니다.

#### 3.15.1. 제곱근 분할의 개념과 원리

*   **개념:** 배열을 `sqrt(n)`개의 블록으로 나누고, 각 블록에 대한 요약 정보(예: 합, 최솟값)를 미리 계산해 둡니다.
*   **원리:** 구간 쿼리 시, 완전히 포함되는 블록은 미리 계산된 요약 정보를 사용하고, 부분적으로 걸치는 블록은 직접 순회하여 계산합니다.

#### 3.15.2. 제곱근 분할을 이용한 구간 쿼리 및 업데이트

*   **구축 (Build):** `O(n)`.
*   **업데이트 (Update):** 특정 요소가 변경되면 해당 블록의 요약 정보만 갱신합니다. `O(sqrt(n))`.
*   **쿼리 (Query):** `O(sqrt(n))`.

#### 3.15.3. 제곱근 분할의 장단점 및 활용 사례

*   **장점:** 구현이 간단하고, 다양한 유형의 구간 쿼리 및 업데이트 문제에 적용 가능합니다.
*   **단점:** 세그먼트 트리나 펜윅 트리보다 느립니다.
*   **활용 사례:**
    *   구간 합, 구간 최솟값/최댓값 쿼리.
    *   배열의 요소가 자주 변경되는 경우.
    *   오프라인 쿼리 (Mo's Algorithm 등).
