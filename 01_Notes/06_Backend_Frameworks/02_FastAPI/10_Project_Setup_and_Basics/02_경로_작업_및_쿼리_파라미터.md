## 1. 경로 작업 (Path Operations)

FastAPI에서 API 엔드포인트를 정의하는 것은 파이썬 함수를 작성하고, 그 위에 HTTP 메서드 데코레이터를 붙이는 방식으로 이루어집니다. 이를 '경로 작업(Path Operation)'이라고 부릅니다.

### 1.1. HTTP 메서드 데코레이터
FastAPI는 HTTP 메서드(GET, POST, PUT, DELETE 등)에 해당하는 데코레이터를 제공합니다. 이 데코레이터들은 특정 URL 경로와 HTTP 메서드에 대한 요청을 처리할 함수를 지정합니다.

-   `@app.get("/")`: GET 요청 처리
-   `@app.post("/")`: POST 요청 처리
-   `@app.put("/")`: PUT 요청 처리
-   `@app.delete("/")`: DELETE 요청 처리
-   `@app.options("/")`: OPTIONS 요청 처리
-   `@app.head("/")`: HEAD 요청 처리
-   `@app.patch("/")`: PATCH 요청 처리
-   `@app.trace("/")`: TRACE 요청 처리

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
async def read_root():
    return {"message": "GET 요청입니다."}

@app.post("/items/")
async def create_item():
    return {"message": "POST 요청입니다."}

@app.put("/items/{item_id}")
async def update_item(item_id: int):
    return {"message": f"PUT 요청입니다. item_id: {item_id}"}
```

### 1.2. 경로 작업 함수
경로 작업 함수는 비동기(`async def`) 또는 동기(`def`) 함수로 정의할 수 있습니다. FastAPI는 비동기 함수를 권장하며, 동기 함수는 내부적으로 스레드 풀에서 실행됩니다.

```python
# 비동기 함수 (권장)
@app.get("/async_example")
async def async_example():
    return {"message": "비동기 함수입니다."}

# 동기 함수
@app.get("/sync_example")
def sync_example():
    return {"message": "동기 함수입니다."}
```

## 2. 경로 파라미터 (Path Parameters)

경로 파라미터는 URL 경로의 일부로 포함되는 변수입니다. 특정 리소스(예: 특정 ID의 아이템)를 식별하는 데 사용됩니다.

### 2.1. 기본 사용법
경로 파라미터는 중괄호 `{}` 안에 변수 이름을 넣어 정의합니다. 경로 작업 함수의 인자로 동일한 이름의 변수를 선언하면 FastAPI가 자동으로 값을 매핑합니다.

```python
@app.get("/users/{user_id}")
async def get_user(user_id: int):
    return {"user_id": user_id}
```
위 예시에서 `/users/123`으로 요청하면 `user_id`는 `123`이 됩니다.

### 2.2. 타입 힌트와 데이터 유효성 검사
FastAPI는 파이썬의 타입 힌트를 적극적으로 활용합니다. 경로 파라미터에 타입 힌트를 지정하면, FastAPI는 자동으로 데이터 유효성 검사를 수행하고, 유효하지 않은 경우 `422 Unprocessable Entity` 에러를 반환합니다.

```python
@app.get("/items/{item_id}")
async def get_item(item_id: int): # item_id는 정수여야 함
    return {"item_id": item_id}

# /items/abc 로 요청 시 422 에러 발생
```

### 2.3. 사전 정의된 값 (Enum)
`Enum`을 사용하여 경로 파라미터가 가질 수 있는 값을 미리 정의하고 제한할 수 있습니다.

```python
from enum import Enum

class ModelName(str, Enum):
    alexnet = "alexnet"
    resnet = "resnet"
    lenet = "lenet"

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):
    if model_name is ModelName.alexnet:
        return {"model_name": model_name, "message": "Deep Learning FTW!"}
    if model_name.value == "lenet":
        return {"model_name": model_name, "message": "LeNet is a classic!"}
    return {"model_name": model_name, "message": "Have some residuals"}
```

## 3. 쿼리 파라미터 (Query Parameters)

쿼리 파라미터는 URL의 `?` 뒤에 `key=value` 형태로 추가되는 변수입니다. 주로 필터링, 정렬, 페이지네이션 등에 사용됩니다.

### 3.1. 기본 사용법
경로 작업 함수의 인자로 선언하되, 경로 파라미터처럼 `{}` 안에 포함되지 않은 변수는 자동으로 쿼리 파라미터로 인식됩니다.

```python
@app.get("/items/")
async def read_items(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}
```
위 예시에서 `/items/?skip=5&limit=20`으로 요청하면 `skip`은 `5`, `limit`은 `20`이 됩니다.

### 3.2. 기본값 설정
인자에 기본값을 할당하면 해당 파라미터가 제공되지 않았을 때 기본값이 사용됩니다.

```python
@app.get("/users/")
async def read_users(name: str = "Guest"): # name의 기본값은 "Guest"
    return {"name": name}
```

### 3.3. 선택적 파라미터 (Optional)
파라미터가 필수가 아닌 선택 사항일 경우, `typing.Optional`을 사용하고 기본값을 `None`으로 설정합니다.

```python
from typing import Optional

@app.get("/products/")
async def read_products(category: Optional[str] = None):
    if category:
        return {"category": category}
    return {"message": "모든 제품을 보여줍니다."}
```

### 3.4. 여러 값 받기 (List)
동일한 쿼리 파라미터 이름으로 여러 값을 받고 싶을 때, 인자의 타입 힌트를 `list`로 지정합니다.

```python
@app.get("/search/")
async def search_items(q: list[str] | None = None):
    if q:
        return {"query": q}
    return {"message": "검색어를 입력해주세요."}

# 예시: /search/?q=apple&q=banana
# 결과: {"query": ["apple", "banana"]}
```

## 4. Path와 Query 파라미터 조합

경로 파라미터와 쿼리 파라미터를 하나의 경로 작업 함수에서 함께 사용할 수 있습니다. 경로 파라미터는 경로에 정의된 순서대로, 쿼리 파라미터는 그 뒤에 선언된 순서대로 인식됩니다.

```python
@app.get("/users/{user_id}/items/{item_id}")
async def get_user_item(user_id: int, item_id: str, q: str | None = None, short: bool = False):
    item = {"item_id": item_id, "owner_id": user_id}
    if q:
        item.update({"q": q})
    if not short:
        item.update({"description": "이것은 매우 긴 설명입니다."})
    return item
```
위 예시에서 `user_id`와 `item_id`는 경로 파라미터이고, `q`와 `short`는 쿼리 파라미터입니다.

## 5. Path Operation Configuration

경로 작업 데코레이터는 API 문서화, 응답 상태 코드, 태그 등 다양한 설정을 위한 추가 인자를 제공합니다.

### 5.1. 응답 상태 코드 (status_code)
API 응답의 HTTP 상태 코드를 명시적으로 지정합니다.

```python
from fastapi import status

@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(name: str):
    return {"message": f"아이템 '{name}'이 생성되었습니다."}
```

### 5.2. 태그 (tags)
API 문서를 그룹화하기 위한 태그를 지정합니다. Swagger UI에서 API를 분류하는 데 사용됩니다.

```python
@app.get("/users/", tags=["users"])
async def get_users():
    return ["user1", "user2"]

@app.post("/users/", tags=["users"])
async def create_user():
    return {"message": "사용자가 생성되었습니다."}

@app.get("/items/", tags=["items"])
async def get_items():
    return ["item1", "item2"]
```

### 5.3. 응답 모델 (response_model)
경로 작업 함수의 응답 모델을 Pydantic 모델로 지정하여, API 응답의 스키마를 자동으로 문서화하고 유효성을 검사합니다. 이는 클라이언트가 받을 응답의 형태를 명확히 합니다.

```python
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None

@app.post("/items/", response_model=Item)
async def create_item(item: Item):
    return item
```
`response_model`을 사용하면, 실제 반환되는 데이터가 `Item` 모델의 스키마와 일치하는지 FastAPI가 검증하며, API 문서에도 해당 스키마가 정확하게 표시됩니다.
