## 1. FastAPI와 비동기 데이터베이스

FastAPI는 비동기(async/await) 프로그래밍을 기본으로 합니다. 이는 웹 요청 처리 시 I/O 바운드 작업(예: 데이터베이스 접근, 외부 API 호출)이 발생했을 때, 해당 작업이 완료될 때까지 기다리지 않고 다른 요청을 처리할 수 있게 하여 애플리케이션의 처리량(throughput)을 극대화합니다.

### 1.1. 왜 비동기 DB가 필요한가?
파이썬의 전통적인 데이터베이스 드라이버(예: `psycopg2` for PostgreSQL, `mysqlclient` for MySQL)는 동기(blocking) 방식으로 작동합니다. FastAPI의 비동기 경로 작업 함수 내에서 동기 DB 드라이버를 사용하면, DB 쿼리가 실행되는 동안 해당 워커 프로세스가 블로킹되어 FastAPI의 비동기적 장점을 제대로 활용할 수 없게 됩니다.

따라서 FastAPI의 고성능을 온전히 활용하려면, 데이터베이스 접근 또한 비동기 방식으로 이루어져야 합니다.

### 1.2. 주요 비동기 DB 드라이버
-   **`asyncpg`**: PostgreSQL을 위한 고성능 비동기 드라이버입니다.
-   **`aiomysql`**: MySQL을 위한 비동기 드라이버입니다.
-   **`aiosqlite`**: SQLite를 위한 비동기 드라이버입니다.
-   **`asyncio-odbc`**: ODBC를 통한 다양한 데이터베이스 연결을 위한 비동기 드라이버입니다.

이러한 드라이버들은 SQLAlchemy와 같은 ORM(Object-Relational Mapping)과 함께 사용되어 비동기 데이터베이스 연동을 가능하게 합니다.

## 2. 데이터베이스 설정

FastAPI 애플리케이션에서 데이터베이스 연결 정보를 관리하는 것은 중요합니다. 환경 변수를 사용하여 민감 정보를 분리하고, `DATABASE_URL`과 같은 통합된 URL 형식을 사용하는 것이 모범 사례입니다.

### 2.1. 환경 변수를 이용한 DB 설정
데이터베이스 접속 정보(사용자 이름, 비밀번호, 호스트 등)는 민감 정보이므로 코드에 직접 하드코딩해서는 안 됩니다. `python-decouple`이나 `pydantic-settings`와 같은 라이브러리를 사용하여 환경 변수에서 로드하는 것이 안전합니다.

```python
# .env 파일 예시
DATABASE_URL="postgresql+asyncpg://user:password@host:port/dbname"
# 또는
# DB_ENGINE=postgresql+asyncpg
# DB_USER=user
# DB_PASSWORD=password
# DB_HOST=host
# DB_PORT=port
# DB_NAME=dbname
```

### 2.2. 데이터베이스 URL 파싱
`SQLAlchemy`는 다양한 데이터베이스 드라이버를 지원하는 URL 형식을 사용합니다. (예: `postgresql+asyncpg://user:password@host:port/dbname`). `SQLAlchemy`의 `URL` 객체를 사용하면 이 URL을 파싱하여 각 구성 요소를 쉽게 얻을 수 있습니다.

```python
from sqlalchemy.engine import URL

db_url = URL.create(
    "postgresql+asyncpg",
    username="user",
    password="password",
    host="localhost",
    port=5432,
    database="dbname",
)
# 또는 환경 변수에서 읽어온 문자열 URL 사용
# db_url_str = os.getenv("DATABASE_URL")
# db_url = URL.create.from_string(db_url_str)
```

## 3. SQLAlchemy 2.0 스타일 비동기 세션 관리

SQLAlchemy는 파이썬에서 가장 널리 사용되는 ORM 중 하나입니다. SQLAlchemy 1.4부터 비동기 지원이 추가되었고, 2.0 스타일에서는 비동기 세션 관리가 더욱 간결해졌습니다.

### 3.1. 비동기 엔진 및 세션 생성
비동기 데이터베이스 연동을 위해서는 `create_async_engine`으로 비동기 엔진을 생성하고, `async_sessionmaker`를 통해 비동기 세션 팩토리를 만듭니다.

```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession

# 비동기 엔진 생성
engine = create_async_engine(
    "postgresql+asyncpg://user:password@localhost:5432/dbname",
    echo=True, # SQL 쿼리 로깅
)

# 비동기 세션 팩토리 생성
AsyncSessionLocal = async_sessionmaker(
    autocommit=False, # 자동 커밋 비활성화
    autoflush=False,  # 자동 플러시 비활성화
    bind=engine,      # 엔진 바인딩
    class_=AsyncSession, # 비동기 세션 클래스 지정
)
```

### 3.2. 의존성 주입을 이용한 세션 관리
FastAPI의 의존성 주입(Dependency Injection) 시스템을 활용하여 각 요청마다 데이터베이스 세션을 생성하고, 요청 처리 후 자동으로 세션을 닫는 패턴을 구현합니다. 이는 세션 관리를 간결하고 안전하게 만듭니다.

```python
from fastapi import Depends, HTTPException, status

async def get_db():
    async with AsyncSessionLocal() as session:
        try:
            yield session
        finally:
            await session.close()
```
위 `get_db` 함수는 FastAPI의 `Depends`를 통해 경로 작업 함수에 주입될 수 있습니다. `yield`를 사용하면 요청 처리 중에는 세션을 사용할 수 있고, 요청이 완료되면 `finally` 블록에서 세션이 자동으로 닫힙니다.

### 3.3. 비동기 모델 정의
SQLAlchemy 2.0 스타일에서는 모델을 정의할 때 `Mapped`와 `mapped_column`을 사용하여 타입 힌트를 명확히 하고, `AsyncAttrs` 믹스인을 사용하여 비동기 관계 로딩을 지원합니다.

```python
from sqlalchemy import Column, Integer, String
from sqlalchemy.ext.asyncio import AsyncAttrs
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column

class Base(AsyncAttrs, DeclarativeBase):
    pass

class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    username: Mapped[str] = mapped_column(String, unique=True, index=True)
    email: Mapped[str] = mapped_column(String, unique=True, index=True)
    hashed_password: Mapped[str] = mapped_column(String)
```

## 4. FastAPI에서 비동기 DB 연동 예시

### 4.1. 데이터베이스 연결 설정
`config.py`와 같은 별도 파일에 데이터베이스 연결 관련 설정을 모아두는 것이 좋습니다.

```python
# app/config.py
import os
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
from sqlalchemy.orm import DeclarativeBase
from dotenv import load_dotenv

load_dotenv() # .env 파일 로드

DATABASE_URL = os.getenv("DATABASE_URL", "postgresql+asyncpg://user:password@localhost:5432/dbname")

class Base(DeclarativeBase):
    pass

engine = create_async_engine(DATABASE_URL, echo=True)

AsyncSessionLocal = async_sessionmaker(
    autocommit=False,
    autoflush=False,
    bind=engine,
    class_=AsyncSession,
)

# 테이블 생성 (개발용)
async def init_db():
    async with engine.begin() as conn:
        await conn.run_sync(Base.metadata.create_all)
```

### 4.2. 모델 정의
`models.py` 파일에 SQLAlchemy 모델을 정의합니다.

```python
# app/models.py
from sqlalchemy import Column, Integer, String
from sqlalchemy.ext.asyncio import AsyncAttrs
from sqlalchemy.orm import Mapped, mapped_column
from .config import Base # config.py에서 Base 임포트

class User(Base):
    __tablename__ = "users"

    id: Mapped[int] = mapped_column(Integer, primary_key=True)
    username: Mapped[str] = mapped_column(String, unique=True, index=True)
    email: Mapped[str] = mapped_column(String, unique=True, index=True)
    hashed_password: Mapped[str] = mapped_column(String)

    def __repr__(self):
        return f"<User(id={self.id}, username='{self.username}')>"
```

### 4.3. 의존성 주입을 통한 세션 사용
`main.py`에서 `get_db` 의존성을 정의하고 경로 작업 함수에 주입합니다.

```python
# app/main.py
from fastapi import FastAPI, Depends, HTTPException, status
from sqlalchemy.ext.asyncio import AsyncSession
from .config import AsyncSessionLocal, init_db
from . import models, schemas # schemas는 Pydantic 모델 정의 파일

app = FastAPI()

# DB 초기화 (앱 시작 시)
@app.on_event("startup")
async def on_startup():
    await init_db()

# 데이터베이스 세션 의존성
async def get_db():
    async with AsyncSessionLocal() as session:
        try:
            yield session
        finally:
            await session.close()
```

### 4.4. CRUD 작업 예시
FastAPI 경로 작업 함수 내에서 비동기 세션을 사용하여 CRUD 작업을 수행합니다.

```python
# app/main.py (계속)
from typing import List
from pydantic import BaseModel
from sqlalchemy import select

# Pydantic 스키마 (schemas.py에 정의)
class UserCreate(BaseModel):
    username: str
    email: str
    password: str

class UserResponse(BaseModel):
    id: int
    username: str
    email: str

    class Config:
        from_attributes = True # SQLAlchemy 모델을 Pydantic 모델로 변환 시 필요

# 사용자 생성
@app.post("/users/", response_model=UserResponse, status_code=status.HTTP_201_CREATED)
async def create_user(user: UserCreate, db: AsyncSession = Depends(get_db)):
    hashed_password = user.password + "notreallyhashed" # 실제로는 bcrypt 등 사용
    db_user = models.User(username=user.username, email=user.email, hashed_password=hashed_password)
    db.add(db_user)
    await db.commit()
    await db.refresh(db_user)
    return db_user

# 사용자 목록 조회
@app.get("/users/", response_model=List[UserResponse])
async def read_users(skip: int = 0, limit: int = 100, db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(models.User).offset(skip).limit(limit))
    users = result.scalars().all()
    return users

# 특정 사용자 조회
@app.get("/users/{user_id}", response_model=UserResponse)
async def read_user(user_id: int, db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(models.User).filter(models.User.id == user_id))
    user = result.scalar_one_or_none()
    if user is None:
        raise HTTPException(status_code=404, detail="User not found")
    return user

# 사용자 업데이트
@app.put("/users/{user_id}", response_model=UserResponse)
async def update_user(user_id: int, user: UserCreate, db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(models.User).filter(models.User.id == user_id))
    db_user = result.scalar_one_or_one()
    if db_user is None:
        raise HTTPException(status_code=404, detail="User not found")
    
    db_user.username = user.username
    db_user.email = user.email
    db_user.hashed_password = user.password + "notreallyhashed" # 실제로는 bcrypt 등 사용
    
    await db.commit()
    await db.refresh(db_user)
    return db_user

# 사용자 삭제
@app.delete("/users/{user_id}", status_code=status.HTTP_204_NO_CONTENT)
async def delete_user(user_id: int, db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(models.User).filter(models.User.id == user_id))
    db_user = result.scalar_one_or_one()
    if db_user is None:
        raise HTTPException(status_code=404, detail="User not found")
    
    await db.delete(db_user)
    await db.commit()
    return
```
이처럼 FastAPI와 비동기 데이터베이스를 연동하면 고성능의 웹 애플리케이션을 구축할 수 있습니다.
